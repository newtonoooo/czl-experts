# 中标方案专家 · czl-bid-win-architect

一个把标书当**算分工具**的 WorkBuddy 专家。它不负责把句子写漂亮，负责让评委在打分那一栏找不到不给你高分的理由。

开发者：虫志龙（47190078@qq.com）　版本：1.0.1

## 它解决什么问题

大多数标书输在三件事上，而且都不是文笔问题：

1. **不知道分在哪。** 几十页招标文件，真正能通过写作改变的分往往只有 30-50 分，其余是资质和报价决定的。不知道这个数，力气全部打散。
2. **写了通用稿。** 换掉客户名还成立的段落，评委一眼看得出，但不会告诉你。
3. **时间花错地方。** 最后三天全用来润色一个 5 分的章节，而 20 分那一章还缺一个证据。

这个专家用七个环节把这三件事拆开：先算分，再定主题，再排结构，再修摘要，再模拟评审，再谈报价，最后体检。

## 七个环节

| 环节 | 做什么 | 产出 |
|---|---|---|
| 1 招标解码 | 拆评审办法，算可争取分，扫废标红线 | 分数地图 / 红线清单 / 隐性偏好 |
| 2 赢标主题 | 3-5 条客户专用、有证据的主题句，四道压力测试 | 主题矩阵 + 证据卡 |
| 3 三幕架构 | 理解—方案—结果重排章节，按分值分字数 | 章节蓝图 + 逐章任务书 |
| 4 摘要审查 | 五段式重写与体检 | 执行摘要 + 修改说明 |
| 5 评审模拟 | 四类评委视角打分，算追分杠杆 | 三档总分 + 追分 Top5 |
| 6 报价叙事 | 先算不做的代价，再让价格出现 | 报价叙事 + 三档配置 |
| 7 交付体检 | 占位符、客户名、编号、越界承诺 | 阻断/警告/建议清单 |

## 六个可执行脚本

不是"提示词模板"，是真能跑的分析工具（Python 3.8+ 标准库，无第三方依赖）：

```bash
# 拆招标文件 → 分数地图
python skills/bid-rfp-decode/scripts/rfp_decode.py 招标文件.txt --out ./out --total 100

# 主题压力测试
python skills/win-theme-forge/scripts/theme_stress.py themes.json

# 摘要体检（0-100 分）
python skills/exec-summary-polish/scripts/summary_audit.py 摘要.md --client 客户名

# 评审模拟 + 追分排序
python skills/blackhat-review/scripts/score_sim.py assess.json

# 报价价值测算
python skills/price-narrative/scripts/roi_model.py price.json

# 交付体检（有阻断项退出码 2）
python skills/bid-package-qc/scripts/qc_check.py ./标书目录 --client 客户名
```

外加 `scripts/verify_package.py`（发布前自检）与 `tools/png_tool.py`（头像处理）。

## 三条硬规矩

- **不编数据。** 案例、金额、比例没有出处，一律不写。宁可留 `[待补]`。
- **不承诺中标。** 只给分数区间与假设。谁保证中标，谁在骗你。
- **不贬对手。** 只写我方做对了什么。评委对贬低同行的方案有本能反感。

## 怎么用

第一次对话直接给它招标文件（评审办法那一章最重要），或者说"帮我拆评分表"。它会先算可争取分，再决定后面怎么走。

如果你只想改一处，直接说场景：

- "方案读起来像产品说明书" → 走三幕架构
- "摘要开头没劲" → 走摘要审查
- "明天要交，帮我查一遍" → 走交付体检
- "客户嫌贵" → 走报价叙事

## 它不做的事

- 不做法律意见。条款争议请找法务。
- 不代写虚假资质、业绩、社保材料。
- 不预测名次。分数区间不是中标概率。
- 不覆盖格式、签章、电子标上传规则——这些必须人工对照招标文件核。

## 安装

放到专家目录：

```
%USERPROFILE%\.workbuddy\plugins\marketplaces\my-experts\plugins\czl-bid-win-architect\
```

然后注册（让专家中心可见）：

```bash
python scripts/register_expert.py <expert-dir>
```
