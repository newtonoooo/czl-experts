## 一、必须先由你决定的三件事

### 1. 专家名称：「中标方案专家」

**两处取舍**

1. **没用"最强"**：《广告法》第九条禁止"国家级""最高级""最佳"等绝对化用语，商用名称属对外宣传，风险明确，所以放弃。
2. **"中标"二字的性质**：它描述服务目标（做的是中标的方案），不是对结果的保证。产品内部也明确禁止承诺中标。若平台审核偏严、要求解释措辞，可退到零风险备选 **投标方案专家**（去掉"中标"，最平实）。

**包名为什么不改**：平台规定 `name` 与 `agentName` 是专家唯一标识，改名必须重建专家、重新注册，原安装会失效。`czl-bid-win-architect` 本身与功能一致，故保留。

**若要换成备选名**：改三处即可——`plugin.json` 的 `displayName`/`profession`、`agents/czl-bid-win-architect.md` 的 frontmatter 与标题、`docs/上架文案.md` 的基础信息表。

### 2. 头像由 AI 生成，标识问题

头像是通过图像生成模型产出的原创图（无第三方素材、无参考他人作品），生成后经本地脚本裁切、去水印、缩放到 512×512。

**风险**：2025 年 9 月起施行的《人工智能生成合成内容标识办法》要求对 AI 生成的图片等内容添加显式标识。作为产品头像对外发布时，可能存在标识义务。当前头像图像本身不含标识（生成工具的水印已被我移除，因为水印含工具品牌，不适合作为产品头像）。

**三个选项**

| 选项 | 做法 | 代价 |
|---|---|---|
| A 保持现状 | 不标识 | 合规风险由你承担 |
| B 详情页说明 | 在 `docs/上架文案.md` 增加一行"头像由 AI 辅助生成" | 几乎无代价，推荐 |
| C 换自绘 | 用矢量工具重画同构图（文档堆叠 + 准星 + 箭头） | 半天工作量，彻底规避 |

**我的建议**：选 B。若平台方另有要求，再转 C。

当前 `LICENSE` 是**专有许可**（保留所有权利，允许自用，禁止再分发与转售）。

**风险**：部分专家市场要求上架内容采用特定开源许可（如 MIT）或要求授予平台分发权。这一点我无法从本地文件核实。

## 六、关于"图标变成字"：查到的原因与已做的防呆

这是你反馈的问题，我在客户端代码里找到了确切机制。

### 机制

客户端渲染专家图标的逻辑是：

```
读取 plugin.json 的 avatar 字段
  → 若为空，或不是 http(s)/data 开头
  → 去掉前导 "./"，相对专家目录解析成绝对路径
  → 必须仍在该专家目录内（否则丢弃）
  → 文件必须存在（否则丢弃）
  → 转成本地文件 URL 交给 <img>
```

任何一步失败，`avatar` 就变成空字符串；界面上的分支是 `if (src) 显示图片 else 显示名字首字的色块`。**所以"变成字"不是图片坏了，是图片地址被解析成了空。**

### 四种常见触发原因

| 原因 | 说明 | 怎么查 |
|---|---|---|
| A. 头像没进包 | 打包或导入时漏掉 `avatars/` 目录 | 解压 zip 看有没有 avatars/ |
| B. avatar 字段为空或用了别的字段名 | 有些包写 `iconUrl`/`avatarUrl`，客户端只认 `avatar` | 看 plugin.json |
| C. 路径逃逸或用绝对路径 | `../x.png` 或 `C:/...` 会被安全检查丢弃 | 看 avatar 值 |
| D. 文件名与声明不一致 | 大小写、后缀（`.PNG` vs `.png`）、多一层目录 | 逐个字符对 |

另有两种"看起来像同一个问题"的现象需要区分：

- **图位置是空的但不是字**：说明地址有值但图片损坏或格式不支持（WEBP 在部分版本缩略图不支持）。
- **所有专家都是字**：不是包的问题，是当前版本的头像解析路径不同，或该专家走了云端同步通道（云端映射里 avatar 会被置空）。

### 本产品做的防呆

1. `avatar` 写死为 `avatars/expert.png`：相对路径、纯 ASCII 文件名、无空格、无多余层级。
2. 头像为 8 位 RGB 的 PNG，512×512，232KB（远低于 500KB 上限），不用 WEBP、不用调色板格式。
3. `package_expert.py` 打包后实测 zip 内有 `avatars/expert.png`。
4. `scripts/verify_package.py` 按上述客户端链路逐步模拟：字段存在 → 路径在目录内 → 文件存在 → 格式/尺寸/体积合规。任一步失败直接报阻断。
5. zip 顶层目录名与 `name` 字段完全一致（`czl-bid-win-architect`），避免导入时路径对不上。

### 如果导入后仍然是字

按这个顺序查（每条都能在 1 分钟内得出结论）：

```bash
# 1. 文件在不在
ls "<专家目录>/avatars/expert.png"

# 2. 字段写的什么
python -c "import json;print(json.load(open('<专家目录>/.codebuddy-plugin/plugin.json'))['avatar'])"

# 3. 客户端链路能不能过
python scripts/verify_package.py "<专家目录>"
```

三条都过而界面仍是字，就是版本侧的解析差异，与包无关——此时换一个旧版本客户端验证，或把头像改成 `avatar.png` 放在专家根目录再试（把 `avatar` 改成 `avatar.png`）。
