# 废标风险清单（自查用）

> 这是一份自查清单，不是法律意见。具体判定以招标文件条款与评标委员会认定为准。遇到条款争议，请交由法务或招标代理机构确认。

## 一、程序性风险（最常见，也最冤）

| 风险点 | 检查动作 |
|---|---|
| 投标文件递交超时 | 电子标留意平台关闭时间，不要卡在最后 10 分钟上传 |
| 密封与标识不符要求 | 逐字对照"投标人须知"里的密封条款，包括封套字样、骑缝章 |
| 签章缺失 | 法定代表人签字、授权委托书、公章位置逐页核 |
| 授权委托书问题 | 日期、授权范围、被授权人身份证是否附 |
| 份数与装订 | 正本副本数量、是否胶装、是否分册 |
| 电子标格式 | 上传格式（PDF/专用格式）、单个文件大小上限、是否需要 CA 签章 |

## 二、资格性风险

| 风险点 | 检查动作 |
|---|---|
| 资质等级不够 | 逐条对照资格条件，注意"或"与"且"的区别 |
| 业绩不满足 | 数量、金额、时间范围、是否要求同类、是否要求验收证明 |
| 人员不满足 | 证书有效期、社保缴纳证明、是否要求在本单位名下 |
| 信用记录 | 信用中国、政府采购严重违法失信名单、行贿犯罪记录 |
| 联合体/分包 | 是否允许、协议是否随标提交 |

## 三、实质性响应风险

| 风险点 | 检查动作 |
|---|---|
| ★/▲ 条款未响应 | 逐条抄出，一条一条在响应表里对应 |
| 工期偏离 | 招标要求 90 天，方案写 100 天 = 实质性偏离 |
| 付款条件偏离 | 擅自修改付款比例通常构成偏离 |
| 质保期短于要求 | 常见隐性废标点 |
| 报价超最高限价 | 有些项目超限价直接废标，不进入评分 |
| 报价低于成本 | 需准备成本说明，否则可能被认定为不正当竞争 |

## 四、内容性风险（不至于废标，但会扣分或引发质疑）

| 风险点 | 后果 |
|---|---|
| 绝对化用语（最强、唯一、保证中标） | 违反广告法风险，且评委反感 |
| 无出处的数据 | 被要求澄清，澄清不了按虚假响应处理 |
| 承诺超出履约能力 | 中标后履约风险，严重时构成违约 |
| 贬低竞争对手 | 评委印象分下降 |
| 复制其他项目内容未改客户名 | 直接暴露"通用稿" |
| 案例涉及客户保密信息 | 可能引发侵权与合规问题 |

## 五、"看起来没问题但常出事"的五处

1. **响应表与正文不一致**：响应表说"完全响应"，正文写了偏离。以哪个为准常有争议，务必一致。
2. **金额大小写不一致**：以大写为准的规则很常见，一个笔误就是几万块的差。
3. **页码与目录不符**：评委会认为你连自己的文件都没校过。
4. **附件缺失**：证书过期、扫描件模糊、缺页。
5. **承诺函模板未替换**：留着他方公司名或项目名。

## 六、使用方式

1. 打印这份清单，逐条打勾。**打不了勾的写"未验证"，不要写"应该没问题"。**
2. 阻断级（可能导致废标）必须先清零，再谈分数。
3. 清单之外的风险，回到招标文件"投标人须知"和"评标办法"逐字读一遍——那里才是权威版本。

## 七、边界

本清单不构成法律意见，也不覆盖行业特殊规定（如建筑工程的企业资质动态核查、医疗器械的经营许可、涉密项目的保密资质）。涉及这些领域时，明确提示用户咨询专业机构。
