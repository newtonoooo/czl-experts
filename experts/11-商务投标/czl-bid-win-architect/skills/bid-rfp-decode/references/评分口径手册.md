# 评分口径速查

> 这份手册只解决一件事：拿到「评审办法」，怎么在 20 分钟内判断出分数的性质。不解释法规条文，具体条款以招标文件与《招标投标法》《政府采购法》原文为准。

## 一、三类分的区别

| 类型 | 特征 | 写作能改变多少 | 策略 |
|---|---|---|---|
| 门槛分 | 不满足即否决，通常不给分 | 0 | 只做核对，做到"齐全且可查" |
| 客观分 | 有明确对照表（几个业绩几分、什么证书几分） | 低，只影响呈现顺序 | 材料前置、目录化、便于核对 |
| 主观分 | "由评委根据…打分" | 高 | 全部叙事资源投在这里 |

**先算主观分总量。** 主观分 30 分以下的项目，把 80% 的写作精力投进去也是 30 分的天花板；这时候该谈的是报价与资质，不是文采。

## 二、常见评分项性质对照

| 评分项 | 通常性质 | 备注 |
|---|---|---|
| 投标报价 | 客观（公式计算） | 有些项目用低价优先法，有些用平均价法，算法决定报价策略 |
| 类似项目业绩 | 客观 | 看数量、金额门槛、时间范围、是否要求同类 |
| 项目团队 | 客观为主 | 证书可数，但"人员配置合理性"常含主观成分 |
| 项目理解/需求分析 | 主观 | 最容易写成行业综述，也是最容易拿分的一项 |
| 技术方案 | 主观 | 分差最大，通常 15-25 分 |
| 实施组织与进度 | 主观 | 评委看的是"能不能落地"，不是甘特图漂不漂亮 |
| 质量保障 | 主观 | 容易写成口号，写成"检查点 + 抽检比例 + 不合格处理"才拿分 |
| 售后服务 | 主观 | 响应时间、到场时间、备件、培训是四个抓手 |
| 演示/答辩 | 主观 | 现场分，写作只能准备脚本 |

## 三、读评审办法时最容易漏的四处

1. **分值藏在细则里**。有的文件只在"评分标准"表里给大项分值，细则里的子项另有小分。两边都要抓。
2. **"每项满分 X 分，扣完为止"**。这类条款意味着基础分容易拿，满分要靠细节堆。
3. **"不提供不得分"与"不提供扣 X 分"**。前者是硬门槛，后者是软扣分，处理优先级完全不同。
4. **加分项藏在"其他"里**。有些文件把本地化服务、自主知识产权、节能环保放在"其他"一栏，容易被忽略。

## 四、可争取度怎么打

| 分值 | 含义 | 典型场景 |
|---|---|---|
| 0 | 已定局 | 注册资本、既有资质等级 |
| 0.2-0.35 | 只能靠报价或历史材料 | 价格分、历史业绩数量 |
| 0.45-0.6 | 靠材料组织与呈现 | 业绩证明材料、团队证书编排 |
| 0.75-0.9 | 靠写作 | 理解、方案、措施、服务承诺 |
| 1.0 | 完全由本次写作决定 | 极少，通常是"方案创新性"这类 |

打分必须写理由。写不出理由的可争取度，等于拍脑袋。

## 五、和后续环节的接口

- 分数地图 → 赢标主题：只从可争取度 ≥0.75 的项里选主题，一项对一条。
- 分数地图 → 三幕架构：字数按分值占比分配，不按可争取度分配。
- 分数地图 → 评审模拟：每项的 rate 以此为起点调整。
- 分数地图 → 交付体检：评分项清单直接作为落点检查表。
