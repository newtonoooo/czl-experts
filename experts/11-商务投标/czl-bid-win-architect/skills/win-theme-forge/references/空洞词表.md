# 空洞词与替代写法

> 这些词的问题不是"不好"，是**不承担信息**。它们可以出现在任何一家公司的任何一份标书里，因此不能证明任何事。

## 一、一出现就删的

| 空洞词 | 为什么是空的 | 换成什么 |
|---|---|---|
| 强大的技术团队 | 谁都可以这么说 | 团队 12 人，其中 5 人有该项目所在行业 3 年以上经验 |
| 行业领先 / 国内领先 | 无出处即为虚标，且有合规风险 | 删掉，或给出可核的排名/份额/第三方报告 |
| 一流 / 顶尖 / 卓越 | 形容词，不可验证 | 换成做法或结果 |
| 全方位 / 一站式 | 描述范围，不描述能力 | 列出具体覆盖的 4 个环节 |
| 赋能 | 语义空洞 | 换成"把 X 的时间从 A 降到 B" |
| 丰富的行业经验 | 无数量 | 近 3 年完成同类项目 7 个，最大单项金额 480 万 |
| 致力于 | 表态，不是事实 | 直接说做什么 |
| 完善的售后体系 | 无指标 | 2 小时响应、24 小时到场、季度巡检 1 次 |
| 先进的技术架构 | 无对照 | 说明为什么这个架构适配客户的现状 |
| 深度融合 | 无对象 | 说清与哪个系统、通过什么接口、交换哪些字段 |

## 二、看起来专业但常常没用的

| 词 | 问题 |
|---|---|
| 成熟方法论 | 除非说出方法论名字和三个步骤，否则等于没写 |
| 闭环管理 | 闭环的判定标准是什么？谁签字？ |
| 全生命周期 | 从哪到哪？运维期算不算？ |
| 数字化转型 | 客户要的不是转型，是某张报表能按时出来 |
| 生态伙伴 | 具体是哪几家？在本项目里干什么？ |
| 敏捷迭代 | 迭代周期几周？谁验收？ |

## 三、句式层面的空话

| 句式 | 问题 | 改法 |
|---|---|---|
| 我们将高度重视…… | 态度不是方案 | 写第一周做什么 |
| 确保万无一失 | 承诺不可核 | 写回滚触发条件与责任划分 |
| 以客户为中心 | 谁都会说 | 写客户提需求后几小时内谁响应 |
| 严格按招标文件要求执行 | 这是义务不是优势 | 写超出要求的那一点 |
| 具有丰富的项目实施经验 | 无数量无场景 | 项目名 + 规模 + 一个指标 |

## 四、自查方法

写完一段，做两个动作：

1. **删除测试**：删掉这句，信息量变了吗？没变 → 删。
2. **替换测试**：把客户名换成同行另一家，这句话还成立吗？成立 → 这句不是为他写的。

两个测试都过不了的段落，就是占位符。

## 五、例外

有些场合必须用套话：格式性表述（"兹郑重承诺"）、法定表述（"完全响应招标文件全部条款"）、礼貌用语。这些不在本表范围内——判断标准是：**这句话是不是在承担一个具体承诺或具体信息**。是，就留；不是，就删。
