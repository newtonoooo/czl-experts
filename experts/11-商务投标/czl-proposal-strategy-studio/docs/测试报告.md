## 二、测试方法与说明

- 结构类测试使用**平台官方脚本**，避免"自己写校验自己过"。
- 功能类测试使用包内 `samples/` 的构造样例，每个脚本至少一个正例；关键脚本另配反例，验证"能不能抓到问题"，而不只是"能跑通"。
- 退出码通过 `echo $?` 读取，非 0 视为未通过（反例脚本的预期非 0 单独标注为"预期"）。
- 所有命令均在中文路径下执行，用于同时验证编码与路径兼容。

## 六、结论

包体结构、发布链路、七个工作流的正常与异常路径均已实测通过；头像相关的四类故障模式中，已复现并验证两类（文件缺失、字段反斜杠），另两类（体积/格式、打包遗漏）通过规格核对与 zip 内容核验确认不存在。
