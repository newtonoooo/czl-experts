# 标胜 · 专业方案策划与投标响应师

> 六道关做完一次投标：接单判断、评分表倒推、赢标主题、叙事成篇、价格叙事、红队体检。每条主张挂证据等级，缺项显式暴露。

开发者：虫志龙（47190078@qq.com）　版本：1.0.0　类型：Agent 型专家　分类：销售商务

## 它解决什么问题

写标书常见三种失败，都不是文笔问题：

1. **不该投的标投了**——资质差一项、关系一片空白，照样投入两周人力。
2. **该拿的分没拿**——评分表写了 30 分技术方案，正文却按"公司介绍—技术架构—服务承诺"的模板写，评委找不到对应内容。
3. **该守的线没守**——技术分第一，因为没盖骑缝章被判无效。

本专家把这三件事变成流程里的硬关卡：先判断，再拆表，再立意，再成篇，再算价，最后体检。

## 六个工作流

| 工作流 | 一句话 | 可运行脚本 |
|---|---|---|
| `bid-gatekeeper` 机会关 | 五维加权打分，给出投 / 条件投 / 不投 | `gate_score.py` |
| `rfp-decode` 读标关 | 评分表拆成得分点矩阵，抽出否决项 | `rfp_matrix.py` |
| `win-theme-forge` 立意关 | 3–5 张主题卡，过"三问" | `theme_check.py` |
| `narrative-build` 成篇关 | 五段式执行摘要 + 三段正文骨架 | `summary_lint.py` |
| `evidence-ledger` 证据账本 | 每条主张标 E1–E4，扫出无依据表述 | `claim_audit.py` |
| `price-story` 报价关 | 代价 → TCO → ROI → 三档报价 | `value_case.py` |
| `bid-redteam` 交标关 | 评委 + 对手双视角自评，核对交标六项 | `redteam_score.py` |

（成篇关与证据账本常同时进行，故为六关七技能。）

## 怎么用

直接说需求，专家会自己判断该进哪一关：

- "这个标要不要投？我把招标文件要点发你。" → 机会关
- "把评分办法拆一下，哪几项最值得投入？" → 读标关
- "我们凭什么赢？帮我提炼亮点。" → 立意关
- "写个执行摘要，700 字内。" → 成篇关
- "这句话有没有依据？" → 证据账本
- "报价怎么讲，要不要降价？" → 报价关
- "帮我把把关，会不会废标？" → 交标关
