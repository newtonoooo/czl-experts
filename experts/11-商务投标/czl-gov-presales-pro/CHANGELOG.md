# 更新日志

## 1.0.0 — 2026-10-28

首个发布版本。从零实现，包含主提示词、四个技能、三个工具、完整文档与原创头像。

### 新增：七关工作流（agents/czl-gov-presales-pro.md）

- 关口一 机会雷达：政策锚定 → 资金与立项核验 → 竞争位势 → 能力匹配 → 打分定档
- 关口二 需求共创：痛点—场景—建设内容三列拆解，验收口径前置
- 关口三 方案成形：按评分表搭骨架，场景串架构，差异化三条，量化价值表
- 关口四 标书体检：资格性/符合性/评分三层拆分，废标项作为硬闸门
- 关口五 报价与商务：三档成本、价格分敏感性、让利方式设计
- 关口六 答辩演练：15 分钟脚本、四类评委质询库、超时预案
- 关口七 中标交接：承诺台账、偏差红线、未中标复盘
- 输出规范：三档交付深度（决策备忘 / 体检报告 / 完整方案）、`[事实]/[推测]/[建议]` 标注
- 红线：不承诺中标、不参与围标串标、不伪造案例、不贬低对手、不承诺无依据的性能指标

### 新增：技能

- `gov-opportunity-radar`：七维加权模型（权重合计 1.00），资格项一票否决，缺维度时归一化而非按 0 分算；输出档位、分数表、短板三条与动作
- `tender-clause-audit`：19 条风险规则（密封签章、原件核验、保证金、授权、有效期、星号条款、业绩门槛、偏离、报价、技术响应、资质、财务信用、时间节点、安全合规等），按行号定位，分致命/严重/一般；附条款响应表与材料清单生成
- `proposal-architect`：按评分分值分配章节页数，单章上限 15 页，超出上限时从最肥章节回削；11 类关键词挂"必须出现的要素"；必备章节缺失检测
- `compliance-matrix`：等保控制项 72 项（三级过滤，二级 48 项）、密评 13 项、信创 10 项，支持 markdown / csv

### 新增：工具

- `tools/pack_check.py`：结构、引用、头像、zip 四层自检；对"头像路径失配"有专门的反向用例
- `tools/avatar_norm.py`：纯标准库 PNG 裁切与缩放（无 Pillow、无 ImageMagick 也能处理头像）
- `tools/selftest.py`：11 项功能与回归用例

### 已知限制

- 招标文件只接受 `.txt` / `.md`，PDF / Word 需先转文本（不做格式解析）
- 规则库是通用结构规则，不针对某一地区或某一代理机构的模板
- 合规矩阵按控制类别归纳并用自有表述重写，不是标准条文复制；评定以标准原文与测评机构意见为准
- 头像处理工具支持 8 位非隔行 PNG，不处理调色板与隔行 PNG
