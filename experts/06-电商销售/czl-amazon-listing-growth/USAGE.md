# 使用说明

面向第一次用这个专家的人。按顺序做，五分钟后能拿到第一份带判定的 Listing。

---

## 一、最短路径（三句话开始）

打开专家，直接说清四件事：**什么产品、去哪个站点、主关键词、卖多少钱**。

```
我有一款折叠硅胶咖啡杯，要上亚马逊美国站，卖 21.99 美金，主词是 collapsible coffee cup。
帮我写标题和五点，然后逐条告诉我哪里会被压、哪里会违规。
```

专家会先给你一张输入卡，问你缺的信息（材质、尺寸、资质、竞品）。答完就往下走。

**如果你只想改已有的 Listing**，直接把标题和五点粘进去，说"审一遍"，它会从 G2 接手，回头补 G0 的缺失项。

## 二、六个场景怎么开口

| 你想做的事 | 这样说 |
|---|---|
| 从零写一个 Listing | 「我要上 XX 产品，XX 站点，主词是 XX，帮我从零写，写完告诉我风险」 |
| 改造老链接 | 「这是我的标题和五点，帮我按合规和 AI 就绪度改一版，给出改前改后对照」 |
| 只查合规 | 「先别改，只告诉我这份文案哪些地方会违规、缺什么材料」 |
| 只打分 | 「已经写好了，帮我打 AI 推荐就绪度分数，告诉我客户最可能问什么、我答不上来的是哪几条」 |
| 关键词怎么分配 | 「我有一堆词：XX、XX、XX，帮我分到标题、五点、后台词，标题预算是多少」 |
| 被下架了 | 「我的 ASIN 被下架了，通知原文是：……，帮我做根因分析和申诉框架」 |

## 三、你会拿到什么

每次交付固定三块：

1. **成品**——可直接复制的纯文本（标题 / 五点 / 描述 / 后台词）。
2. **体检结论**——字符数、命中项、判定（GO / CONDITIONAL / BLOCKED）。
3. **下一步**——一句话，说清最该先做的那件事。

外加一份可存档的审计报告（需要时让它生成 `report.md`）。

## 四、自己跑脚本

专家会帮你跑，但你也可以自己跑。适合批量处理或想接进自己的流程。

### 1. 准备输入文件

```json
{
  "market": "US",
  "category": "food_contact",
  "brand": "NORDVIK",
  "title": "你的标题",
  "bullets": ["第一条", "第二条", "第三条", "第四条", "第五条"],
  "description": "你的描述",
  "search_terms": "后台搜索词",
  "attributes": {
    "material": "硅胶",
    "color": "灰色",
    "size": "350 ml",
    "weight": "180 g",
    "quantity": "1 个",
    "audience": "通勤族",
    "style": "折叠",
    "care": "可机洗"
  },
  "keywords": { "primary": ["collapsible coffee cup"], "secondary": [], "long_tail": [] }
}
```

只有 `title` 是硬必填。其余缺了会被记为扣分项，不会报错——所以你可以只贴标题先体检。

### 2. 跑命令

```bash
cd skills/listing-ops-kit/scripts

python listing_audit.py lint       --listing x.json --market US
python listing_audit.py compliance --listing x.json --market US --category food_contact
python listing_audit.py score      --listing x.json
python listing_audit.py keywords   --listing x.json --market US
python listing_audit.py report     --listing x.json --market US --category food_contact --out report.md
```

### 3. 看退出码

| 退出码 | 含义 | 该怎么办 |
|---|---|---|
| 0 | 通过 | 可以提交 |
| 1 | 有警告或条件项 | 看具体条目，能改就改 |
| 2 | 有阻断项 | **不要提交**，先改 |

接进批量脚本时用退出码判断，比解析文本可靠。

## 五、怎么读结论

### 文案体检

```
[BLOCK] TITLE_OVER_HARD @ title — 标题 238 字符，超过 US 站硬上限 200
        改法：删掉重复属性词，把超出部分移到五点或后台搜索词
```

`BLOCK` 必须改，`WARN` 建议改，`INFO` 看情况。每条都带改法，不用自己猜。

### 合规判定

| 判定 | 含义 | 动作 |
|---|---|---|
| **GO** | 无阻断、无未决条件 | 可以提交 |
| **CONDITIONAL** | 无阻断，有条件项 | 可提交，但清单里的材料要补 |
| **BLOCKED** | 有阻断项 | 不能提交，先解决最小集合 |

看到 `category_known: false`，说明你填的类目键没被覆盖，此时**类目门槛没核对过**，判定不完整。

### 就绪度分数

| 分数 | 含义 | 动作 |
|---|---|---|
| 85–100 | 结构完整 | 保持，转去做主图和评论 |
| 70–84 | 有明确缺口 | 按扣分项补，先补 D1（属性）和 D3（问答） |
| 50–69 | 只能回答基础问题 | 重写五点结构 |
| 0–49 | 基本无法被结构化召回 | 整体重写 |

**分数不预测销量。** 它衡量的是信息结构有没有漏洞。

## 六、常见问题

**Q：为什么它不直接告诉我佣金和 FBA 费用？**
A：因为各地费率会变，编一个数会误导你。它会标"未提供，未计入"，让你填真实值。

**Q：规则包里的字符上限和我后台看到的不一样？**
A：以后台为准。亚马逊按类目模板调整限制。告诉专家实际数值，它会按你的来。

**Q：它能不能保证我上架不被压？**
A：不能。它能做的是把可机器判定的问题（字符、符号、堆砌、宣称词）提前挑出来，把该准备的材料列清。审核是平台行为。

**Q：德语/日语文案质量怎么样？**
A：它按目标语言写，但**不保证母语地道**。不确定的表达会标 `[待校对]`，建议交母语者过一遍。

**Q：能不能帮我把竞品的文案改一改就用？**
A：不能。照抄他人 Listing 属侵权。它可以拆解竞品的结构（讲了哪几点、什么顺序），但文案必须用你自己产品的事实重写。

**Q：被下架了，它能帮我写申诉信吗？**
A：给你四段式框架和证据清单，但**不替你拍板最终文本**——申诉里的事实只能你确认。它也会拒绝编造理由。

## 七、边界

- 不构成法律意见
- 不构成对亚马逊政策的官方解释
- 不构成对销售结果的承诺
- 与亚马逊公司无隶属或合作关系

涉及侵权判定、认证机构选择、法律责任时，请找对应专业机构。
