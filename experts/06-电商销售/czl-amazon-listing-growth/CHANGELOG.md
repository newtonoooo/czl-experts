## [1.0.1] — 2026-10-28

### 修复 · 专家名称超出平台字数上限

平台对专家名称限制 **15 字**，v1.0.0 的中文名为 `专业亚马逊 Listing 增长官`，含两个空格共 **17 字**，超限 2 字，提交会被拦。

| 项 | v1.0.0 | v1.0.1 |
|---|---|---|
| 中文名 | 专业亚马逊 Listing 增长官（17 字） | **专业亚马逊Listing专家（14 字）** |
| 英文名 | Pro Amazon Listing Growth Officer | Pro Amazon Listing Specialist |

改法：去掉英文词前后的空格（省 2 字），把「增长官」改为「专家」，压到 14 字并留 1 字余量。

未采用 `专业亚马逊Listing增长官`——它正好 15 字、零余量，若平台对空格或全角字符另有计算规则会再次超限。

**产品定位未变**：仍是「撰写 + 合规 + 评分 + 申诉」六道闸门，职业定位仍为「亚马逊 Listing 撰写与合规增长顾问」，包名仍为 `czl-amazon-listing-growth`。仅显示名与版本号变化。

同步更新：`plugin.json`、agent 角色定义、README、NOTICE、SKILL.md 版本号，以及 `docs/` 下六份文档中的名称与版本引用。

## [1.0.0] — 2026-10-28

首个版本。全部内容为本次独立开发，不含任何既有专家产品的代码、提示词、文档或视觉资产。

### 新增 · 六道闸门

- **G0 输入体检**：七项输入清单、缺失项显式假设（含"影响哪道门"标注）、类目键映射。
- **G1 关键词预算**：词池归一化去重、token 重叠分组、标题字符预算先算后写。
- **G2 文案构建**：三套标题骨架（主词优先 / 场景优先 / 属性堆叠）、五点「锚点 + 利益 + 证据 + 场景」结构、描述四段式、后台词字节预算。
- **G3 合规放行**：词层 / 类目层 / 市场层三层扫描，输出 GO / CONDITIONAL / BLOCKED。
- **G4 AI 推荐就绪度**：七维加权 0–100，逐项扣分带改写动作，附未答问题清单。
- **G5 申诉框架**：根因 / 纠正 / 预防 / 证据四段式，附提交前自查表。

### 新增 · 审计引擎

`skills/listing-ops-kit/scripts/listing_audit.py`，纯标准库，五个子命令：

- `lint`：字符预算、全大写（品牌豁免）、非标准符号、词频堆砌、重复短语、五点数量与信息量、标题规格缺失。
- `compliance`：10 类宣称规则（绝对化 / 保证性 / 医疗功效 / 认证提及 / 兼容性 / 价格促销 / 竞品指名 / 环保 / 产地 / 绝对安全）、7 类目门槛、9 站点义务，条目级去重。
- `score`：D1 属性完整度 20、D2 场景人群 15、D3 问答覆盖 15、D4 实体一致性 15、D5 结构化 15、D6 差异化证据 10、D7 关键词自然度 10。
- `keywords`：去重、分组、按预算分配位置。
- `report`：合并为单份 Markdown 报告。

统一退出码 `0 / 1 / 2`，支持 `--json`。

### 新增 · 规则包

- `marketplace-rules.json`：9 站点字符基线 + 文案检查参数。
- `compliance-matrix.json`：宣称规则 + 类目门槛 + 市场义务，含 `dedupe` 去重键与免责字段。
- `copy-patterns.md`：标题三骨架、五点结构拆解、描述四段、多站点写作要点、改写对照表。
- `score-rubric.md`：七维评分口径，与代码实现逐项对齐。

### 新增 · 视觉

- `avatars/expert.png`：512×512 PNG，35.5 KB，由代码（SDF 渲染 + 盒式降采样）绘制，无外部素材、无生成式模型输出。

### 新增 · 文档

`docs/` 下七份：产品规格说明、工作流设计、平台展示文案、功能测试报告、商业发布风险清单、文件清单、开发记录、头像说明。

### 修复 · 开发期发现并修掉的 4 个实现缺陷

- 品牌名全大写被误判为格式违规 → 全大写检测加入品牌豁免。
- 关键词正常落位（3 次）被误判为重复 → 3-gram 重复阈值从 2 提到 4。
- `verdict` 与 `exit_code` 口径不一致（仅 INFO 时显示 WARN 但退出码 0）→ 统一为三态判定。
- 同一合规义务在类目层与市场层重复列出 → 条目级 `dedupe` 去重。

### 已知限制

- 字符上限与合规义务为配置基线，未逐条与官方原文比对，需使用者以后台与当地法规为准。
- 非英语站点只做字符与词表检查，不判断语法与地道程度。
- 真实导入后的界面渲染未验证（需图形界面操作）。
