# 头像说明

## 一、成品规格

| 项 | 值 |
|---|---|
| 路径 | `avatars/expert.png` |
| 尺寸 | 512 × 512 px（正方形） |
| 格式 | PNG，24 位真彩（colortype 2，无 alpha） |
| 体积 | 约 35.5 KB |
| 引用位置 | `plugin.json` → `"avatar": "avatars/expert.png"` |

## 二、视觉设计

| 元素 | 设计意图 |
|---|---|
| 深墨蓝底 + 顶部偏左柔光 | 稳重、专业，避免浅底在浅色列表里"糊掉" |
| 圆角方框描边 | 形成徽章感，在 64px 缩略图下仍有边界 |
| 三根递增圆角柱 | 表达"排名上升 / 越做越好"，是通用图形语言，不指向任何企业标志 |
| 琥珀色顶柱 | 单一强调色，视线落点明确；缩略图下仍可辨 |
| 灰蓝、米白、琥珀三色 | 三色以内，保证小尺寸不脏 |

**刻意避开的**：人物形象（避免"老登"观感）、字母与文字（避免缩略图糊成一团）、亚马逊的笑脸箭头（避免商标近似）、任何品牌标志或图标库素材。

## 三、生成方式

**纯代码绘制，无图像生成模型、无图库素材、无字体文件。**

脚本：`build/render_avatar.py`（随交付包外的构建目录提供，不在发布包内）

技术路径：
1. 1024 × 1024 画布逐像素计算。
2. 每根柱用**圆角矩形有向距离场（SDF）**求距离，覆盖率 `clamp(0.5 - d)` 得到解析抗锯齿。
3. 背景为竖直渐变 + 两处高斯型光斑（顶部柔光、琥珀光晕）。
4. 徽章边框同样用 SDF，按到边框线的距离给透明度。
5. 1024 → 512 用 2×2 盒式滤波降采样，边缘更干净。
6. 用 `zlib` + `struct` 直接写 PNG，无 Pillow。

复现命令：

```bash
python build/render_avatar.py build/avatar_raw
# 产出 build/avatar_raw/expert-1024.png（源图）与 expert.png（512 成品）
```

## 四、版权说明

- 图形由本项目代码生成，不含任何第三方素材、字体、图标、照片。
- 构图元素（柱状递增、圆角矩形、渐变）属通用图形语言，不构成对他人作品的复制。
- 不涉及肖像权、不使用生成式模型的输出，因此不存在"生成内容商用条款"的不确定性。
- 保留 1024 源图与生成脚本，作为创作过程证据。

## 五、替换方法

若要换头像，保持以下约束即可，无需改代码：

1. 512 × 512 正方形 PNG。
2. 体积 < 500 KB（当前 35.5 KB，余量充足）。
3. 文件名保持 `expert.png`，放在 `avatars/`。
4. `plugin.json` 中写 `avatars/expert.png`——**不要写 `./avatars/expert.png`**，也不要写绝对路径。

> 第 4 条不是风格偏好。平台在 zip 导入时对清单文件用后缀匹配、对头像用精确路径匹配，两者不对称；带 `./` 前缀或在 zip 里套一层目录，会出现"专家导入成功但头像变成首字"的现象。详见 `docs/开发记录.md` 第二节。
