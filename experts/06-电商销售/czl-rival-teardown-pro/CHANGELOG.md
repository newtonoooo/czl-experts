# 更新日志

本文件记录 czl-rival-teardown-pro 的版本变更。版本号遵循语义化版本：主版本.次版本.修订号。

## [1.0.0] - 2026-10-28

首个发布版本。

### 新增

- **五层拆解框架**：需求定位（L1）、表达（L2）、视觉（L3）、口碑（L4）、竞争格局（L5）。每层强制回答「做了什么选择 / 服务谁 / 代价是什么」三问，避免产出只有描述没有结论的报告。
- **四级证据体系**：E1 页面原文、E2 平台可核、E3 外部推断、U 待验证。报告内每条结论挂证据编号，报告末尾附证据索引。
- **强度评分卡**：五层加权（20/20/20/25/15）折算 0-100 分，输出强度档位与建议打法（正面压 / 单点突破 / 侧翼 / 换战场）。
- **八种切口模式**：场景切口、人群切口、参数越级、形态重构、服务承诺、内容信任、组合装/耗材绑定、价格带补位。每个模式附「对手为什么不做」的典型答案与伪切口清单。
- **可执行交付四件套**：主报告、打法卡（一页纸）、文案种子、证据台账。
- **工具箱 CLI**：`teardown_toolkit.py`，含 parse / ledger / score / scaffold / check / selftest 六个子命令，仅依赖 Python 标准库。
- **报告结构质检**：7 项自动检查（章节完整性、占位符残留、证据编号、样本量披露、缺口表、合规小节、绝对化用语），失败返回退出码 1。
- **发布前检查工具**：`tools/package_qa.py`，校验元数据字段、路径引用、头像规格、依赖纯净度，并可生成 data-URI 头像兼容版压缩包。
- **演示样例**：`samples/` 下提供完整填写的示例报告，用于展示格式与质检通过状态。

### 设计取舍

- 单竞品深度优先，不做多 ASIN 打包浅扫。多竞品时按优先级逐个深拆。
- 评论分析强制披露样本量与抽样方式，非随机抽样不得表述为总体比例。
- 未提供我方产品信息时，只输出竞品强度分，不输出胜率判断。

### 已知限制

- 不内置电商数据接口，销量、广告结构等硬数据依赖宿主环境工具或用户补充。
- 视觉层依赖图片内容描述；无法直接读图时降级为「文案反推」，置信度标记为低。
- 报告结构质检只校验形式完整度，不判断结论对错，结论质量仍取决于证据质量。
