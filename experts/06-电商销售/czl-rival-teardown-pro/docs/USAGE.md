# 使用说明

面向使用者的完整操作指引。三种使用方式，任选其一即可。

---

## 一、安装

### 方式 A：专家中心导入（推荐）

1. 打开 WorkBuddy → 左侧「专家」→「我的专家」→ 右上角导入。
2. 选择发布包 `czl-rival-teardown-pro.zip`。
3. 导入后在「我的专家」出现「拆敌」，头像为深蓝底 + 放大镜人物。
4. 点击即可开始对话。

### 方式 B：本地目录

把整个 `czl-rival-teardown-pro/` 目录放到：

```
<WorkBuddy 配置目录>/plugins/marketplaces/my-experts/plugins/
```

Windows 默认配置目录：`C:\Users\<用户名>\.workbuddy-ai`
然后重启 WorkBuddy，在「我的专家」中可见。

### 方式 C：不安装，直接用文档

把 `agents/czl-rival-teardown-pro.md` 和 `skills/rival-teardown-playbook/` 下的文件
当提示词模板使用，在任意对话里手动执行五层流程。功能等价，只是没有自动加载。

---

## 二、第一次使用

### 最简单的一句话

```
拆解这个竞品 B0XXXXXXXX，告诉我差异化怎么打
```

### 推荐给足信息（效果明显更好）

```
竞品：https://www.amazon.com/dp/B0XXXXXXXX
我的产品：同类收纳箱，售价 $24.99，现有优势是可折叠 + 加厚底板
本次想解决：主图第一句该讲什么，以及要不要做双只装
```

三个要素：**竞品是谁 / 我是谁 / 我要解决什么**。给全了，报告会直接落到动作上。

## 三、四种典型场景怎么问

### 场景 1 对手反超我，要快速复盘

```
这个竞品最近超过我了：B0XXXXXXXX。
帮我拆他这三个月在 listing 上做了什么改动，重点是主图和五点。
```

关注：L2 表达层 + L3 视觉层，以及 L5 的促销动作。

### 场景 2 上新品前对标

```
我要上一个宠物饮水机，对标 B0XXXXXXXX。
帮我把他的文案结构拆出来，我要写一个不一样的但同样有说服力的版本。
```

关注：L2 表达层 + 文案种子文件。

### 场景 3 主图/卖点不知道讲什么

```
B0XXXXXXXX 的评论帮我挖一下，用户到底因为什么买、因为什么退。
我要定主图第一句话。
```

关注：L4 口碑层（好评聚类 + 差评穿透 + QA 防线）。

### 场景 4 判断这个价格带还能不能进

```
这几个竞品分别在 $19.99 / $29.99 / $39.99：B0AAA、B0BBB、B0CCC。
帮我看看价格带还有没有空位，以及进去要打什么差异。
```

注意：多个竞品时会**逐个深拆**，不会打包浅扫；建议先指定 1 个主竞品。

## 四、没有抓取能力时怎么配合

抓取被挡（验证码、登录墙）时，专家会给你一份清单。按这个格式贴进来即可：

```
标题：（原文复制）

五点：
1. ...
2. ...
3. ...
4. ...
5. ...

价格：$29.99    评分：4.6    评论数：2143

主图：深灰背景，一个人站在箱子上
副图1：承重测试特写
副图2：装被子容量示意
副图3：折叠前后对比

评论（好评）：
- 5星：搬家装了满满一箱书都没塌...
- 5星：...

评论（差评）：
- 2星：底板接缝开了...
- 1星：...

QA：
Q: 能装下冬被吗？ A: ...
```

贴得越全，L3 视觉层与 L4 口碑层的置信度越高。

## 五、读懂交付物

### 5.1 主报告怎么看

先看 **0 一页速览**（5 行），再看 **9 强度评分卡**（要不要正面打），
然后直接跳到 **11 行动清单**（这周做什么）。
中间的 4-8 章是支撑材料，开会被人质疑时翻这里。

### 5.2 评分怎么解读

| 总分 | 档位 | 含义 | 建议 |
|---|---|---|---|
| ≥80 | 强敌 | 各层都强，正面拼资源不划算 | 换战场或侧翼，找结构性弱点 |
| 60-79 | 可战 | 有明显短板层 | 单点突破，选一层做到超过他 |
| <60 | 弱敌 | 整体偏弱 | 正面压，用表达与视觉对比抢流量 |

看**层间极差**比看总分更有用：极差 ≥20 说明对手偏科，短板层就是入口。

### 5.3 证据编号怎么用

`[E1-03]` 表示 E1 级（页面原文）第 3 条证据，去 `证据台账-*.csv` 第 3 行找原文。
`[E3-01]` 是外部推断，不能当事实用，需要复核。
看到结论没有编号，说明该结论应被当作「待验证」。

### 5.4 数据缺口表为什么重要

它告诉你这份报告**哪里不能信**。缺口项对应的那一层结论，置信度会被降级。
拿去开会时，主动说明缺口比被追问更专业。

## 六、手动使用 CLI（可选）

在专家包根目录执行：

```bash
# 1. 解析输入
python3 skills/rival-teardown-playbook/scripts/teardown_toolkit.py parse "https://www.amazon.com/dp/B08N5WRWNW"

# 2. 建台账
python3 skills/rival-teardown-playbook/scripts/teardown_toolkit.py ledger --asin B08N5WRWNW --out 证据台账.csv

# 3. 打分
python3 skills/rival-teardown-playbook/scripts/teardown_toolkit.py score \
  --positioning 78 --message 85 --visual 90 --voice 72 --arena 65

# 4. 生成骨架并填充
python3 skills/rival-teardown-playbook/scripts/teardown_toolkit.py scaffold \
  --asin B08N5WRWNW --date 2026-10-28 --out 竞品拆解.md --name "折叠收纳箱"

# 5. 质检
python3 skills/rival-teardown-playbook/scripts/teardown_toolkit.py check 竞品拆解.md
```

Windows 下把 `python3` 换成 `python`。

## 七、常见问题

**Q：为什么只拆一个竞品，不能一次拆五个？**
A：浅扫五个不如深拆一个。深拆产出的动作是可执行的，浅扫只能产出印象。
多竞品时按优先级排队，逐个拆。

**Q：没有销量数据怎么办？**
A：销量不会被编造。报告里会标「未获取」，并说明这影响哪一层结论。
需要销量时用第三方工具补，或提供你能拿到的数据。

**Q：报告里的「推断」能直接用吗？**
A：能用于决策参考，不能用于对外承诺。推断项都带 `[E3-]` 编号，建议先小成本验证。

**Q：文案种子能直接上架吗？**
A：不能。它是草稿，需要合规复核（绝对化用语、认证背书、参数真实性），
并且需要按实物参数校准。

**Q：可以分析非亚马逊平台吗？**
A：可以。五层框架与平台无关，但 ASIN 解析、类目排名等亚马逊特有逻辑会失效，
需手工提供对应平台的数据。

**Q：为什么报告一定要写「不能回答什么」？**
A：因为大部分误用来自「把推断当事实」。写清边界，报告才敢被拿去开会。

## 八、导入后头像显示为文字怎么办

如果导入到新的 WorkBuddy 后，专家头像显示成名字首字（文字块），说明本地头像路径
没有被解析成功。排查与修复步骤见 `docs/AVATAR-TROUBLESHOOTING.md`。
