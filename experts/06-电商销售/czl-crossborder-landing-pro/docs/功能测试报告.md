### T2 `landed_cost.py --selftest`

```
$ python landed_cost.py --selftest
selftest passed: 7 checks
```

覆盖断言：

1. 纯成本无费率时，落地成本 = 采购价、净利 = 售价 − 成本 − 佣金 − 广告；
2. 把「保本售价」代回模型，净利 ≈ 0（误差 < 1e-6）；
3. 把「目标净利率对应售价」代回，净利率 = 15%（误差 < 1e-6）；
4. 退货率 20% 时，`shipped_per_kept` = 1.25，且落地成本高于退货率 0% 的情形；
5. 退货率 = 100% 时抛 `ValueError`；
6. `cost_in_cny` 缺 `fx` 时抛 `ValueError`；
7. 140 CNY / 7.0 = 20 USD，采购项折算正确。

结论：**通过**。

## 三、测试中发现并已修复的问题

| # | 问题 | 发现方式 | 修复 |
|---|---|---|---|
| 1 | `landed_cost.py` 敏感性网格递归调用 `compute()` 导致 RecursionError | T2 首跑即崩 | 增加 `deep=False` 参数，网格内不再展开敏感性 |
| 2 | 敏感性网格读取了不存在的键 `净利率` | T2 第二次运行 | 改为 `net_margin` |
| 3 | `--cost-in-cny` 把配送费、仓储费也按汇率折算（目的国侧费用本就是目标币） | T6 结果与手工复算不符（配送费 5.16 偏高） | 折算范围收窄为采购/包装/头程三项，并在 docstring 与 `cost-lines.md` 写明 |
| 4 | `compliance_gate.py` 正文里用了中文引号包裹 ASCII 双引号，触发 SyntaxError | T3 首跑 | 改用「」 |
| 5 | 补货脚本海空切分逻辑三段式取整，边界下可能出现 海+空 ≠ 总量 | 代码走查 | 改为 `air = min(qty, ceil(daily×gap))`、`sea = qty − air`，并加断言 |
| 6 | 补货"最晚下单日"以在库耗尽日倒推，忽略在途，导致日期偏早 | T9 输出与直觉冲突 | 改为从"含在途可售天数"倒推；状态判定统一为"是否触及补货点" |
| 7 | 品牌未在前 N 词时复用了 `KEYWORD_MISS` 的改法建议，提示错位 | T8 输出审阅 | 新增 `BRAND_POS` 码与对应改法 |
| 8 | `money()` 对 `-0.00` 直接输出，表格出现「-0.00 USD」 | T7 输出审阅 | 绝对值 < 0.005 归零 |
| 9 | 头像 602 KB 超出 500 KB 上限，且右下角带生成工具水印 | T12 检查 | 裁剪水印区 + 面积平均缩放 + 256 色调色板量化，降至 132.4 KB |
