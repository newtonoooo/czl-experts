## 二、逐项风险与处置

### R1 版权：被认定为"改名复用"

| 项 | 内容 |
|---|---|
| 风险描述 | 同赛道已有跨境类专家（`cross-border-ecommerce-expert`，其提示词改编自 agency-agents，MIT 许可）。若表达高度相似，可能被质疑为改名复用 |
| 可能性 | 低 |
| 影响 | 中（下架、声誉） |
| 现有处置 | ① 结构不同：本产品是"六道闸门 + 四个脚本"的工程化结构，参考对象是"能力罗列 + 流程五步"的顾问式结构；② 表达不同：全部文本重写，无整句复用；③ 判定方法不同：本产品以三态放行、error 清零、保本三线作为核心判据，参考对象无这些机制；④ 有工具：四个脚本与两份机读规则表为参考对象所无 |
| 残余风险 | 若平台采用"功能相似即判重"的粗粒度规则，仍可能被人工复核 |
| 建议 | 保留 `docs/开发记录.md` 作为创作过程证据；如平台要求，可提交文件时间戳与写作顺序说明 |

> 补充说明：agency-agents 为 MIT 许可，理论上允许商业使用与再分发（需保留版权声明）。本项目**选择不复用**，是因为无法确认该专家包自身的授权链（其 MIT 声明覆盖范围、是否含其他来源内容）。这是风险规避，不是法律 necessity。

### R2 第三方组件许可

| 项 | 内容 |
|---|---|
| 风险描述 | 若打包他人 Skill（如 `browser-use`）会引入额外许可义务与安装依赖 |
| 可能性 | 已规避 |
| 影响 | — |
| 现有处置 | **未打包任何第三方 Skill**。参考对象附带的 `browser-use` 技能（MIT，需 `curl \| bash` 安装）未被引入。本产品的浏览器需求由 WorkBuddy 平台自身能力承担 |
| 残余风险 | 无 |
| 备注 | 若你希望增加浏览器自动化能力，需重新评估该组件的许可证与商业分发条件，并保留其 LICENSE 文件 |

### R3 合规内容的准确性

| 项 | 内容 |
|---|---|
| 风险描述 | 认证要求、税率、EPR 制度、周期区间可能与实际不符或已过时，用户据此决策可能受损 |
| 可能性 | 中（法规本身高频变动） |
| 影响 | 高（用户被扣货、罚款、下架） |
| 现有处置 | ① 定位为"作业清单，不是法律意见"（`LICENSE`、`agents` 提示词第八节、`compliance-matrix.md` 首段）；② 每个规则文件带 `meta.as_of = 2026-10`；③ 周期给区间并注明"不含排队与补测"；④ 不承诺周期、不承诺通过率；⑤ 提示"平台侧要求与国别法规是两道关" |
| 残余风险 | 用户仍可能把清单当作完整合规方案 |
| 建议 | 商业化前请一位跨境合规从业者做一次抽审（重点：EU GPSR、德国 VerpackG、美国 MoCRA、日本药机法四条） |

### R4 平台费率与字数上限

| 项 | 内容 |
|---|---|
| 风险描述 | 佣金率、配送费档位、标题字数上限会调整；`listing-profiles.json` 的默认值可能与当期不符 |
| 可能性 | 中 |
| 影响 | 中（测算偏差、文案被截断） |
| 现有处置 | ① 所有费率默认值为 0，缺参数标"待填"，不假装算过；② 字数上限写成可改的 JSON 并带 `as_of`；③ 输出固定提示"以后台当期限制为准" |
| 建议 | 每季度复核一次；把复核结果写进 `CHANGELOG.md` |
