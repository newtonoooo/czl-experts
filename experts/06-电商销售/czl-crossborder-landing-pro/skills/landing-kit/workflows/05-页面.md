# 工序 ⑤ 页面

## 名称

页面（Listing Build）——出可审的文案底稿，过体检再交付。

## 任务职责

把产品翻译成目标市场买家能读懂、平台不会拦的页面。产出《Listing 文案包》。
交付物是**底稿**，不是终稿：必须标出三处需母语审校的位置。

## 输入参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 平台档案 | 是 | amazon_us / amazon_de / amazon_uk / amazon_jp / tiktok_shop_us / shopee_sea / lazada_sea / temu_us / dtc |
| 产品事实 | 是 | 材质、尺寸、重量、容量、适用人群、使用场景、认证 |
| 卖点证据 | 是 | 每个卖点对应的可验证依据（测试报告、结构设计、材料牌号） |
| 目标关键词 | 是 | 3–8 个，按搜索量排序，来自工序 ② 的数据 |
| 品牌名 | 否 | 无品牌则标"白牌"，标题不以品牌开头 |
| 竞品页面 | 否 | 用于对比信息密度与图片结构，不用于抄文案 |

## 执行步骤

```
1  定结构：标题 → 五点 → 描述/A+ → 主图与附图 → 后台关键词
2  写标题：品牌 + 核心词 + 关键属性 + 规格，控制在平台上限内
3  写五点：每条一件事，顺序为 最痛的痛点 → 结构/材料证据 → 使用场景 →
   → 规格与兼容 → 售后与保障
4  写描述：前 300 字符说清"这东西解决什么问题"
5  过体检：
     python scripts/listing_lint.py --profile amazon_us --input listing.json
   error 必须清零；warn 逐条解释为什么可以留
6  标审校点：标题、卖点首句、场景描述三处，注明"需母语审校"
7  出《Listing 文案包》：定稿文案 + 体检结果 + 关键词覆盖表 + 待审校清单
```

## 判断条件

| 检查项 | 通过条件 |
|---|---|
| 标题长度 | ≤ 平台上限（脚本判定） |
| 禁词 | 0 命中（脚本判定，error） |
| 站外引流 | 0 命中：无邮箱、电话、网址、社交账号（脚本判定，error） |
| 关键词堆砌 | 同词根在标题 ≤2 次；描述 ≤6 次（脚本判定，warn） |
| 五点条数 | 与平台建议一致（脚本判定，warn） |
| 单位制 | 与目标市场匹配，必要时双标（脚本判定，info） |
| 卖点证据 | 每个卖点都能指到一条证据，指不到的删掉 |
| 母语审校 | 三处已标注，且已提醒送审 |

**content 级判断（脚本查不出的）**

- 标题里不能出现"最""第一""100%"类绝对化表达，也不能出现疗效、治疗、抗菌（除非有备案）。
- 尺寸与容量必须与实物一致，包装内数量必须与标题一致。
- 图片里的文字不能出现水印、二维码、其他平台 logo。

## 输出格式

```markdown
# Listing 文案包 · {产品} · {平台} · {YYYY-MM-DD}

## 标题（{n} 字符 / 上限 {m}）
{标题}

## 五点
1. …
2. …

## 描述
{前 300 字符独立成段，其后展开}

## 关键词覆盖
| 关键词 | 标题 | 五点 | 描述 | 后台 Search Terms |

## 图形脚本
| 图位 | 要传达的信息 | 画面描述 |

## 体检结果
{脚本原始输出}

## 待母语审校（3 处）
1. 标题：…
2. 卖点首句：…
3. 场景描述：…
```

## 异常处理

| 情况 | 处理 |
|---|---|
| lint 有 error | 改文案后重跑，不许改档案放宽规则来"通过" |
| 平台字数上限不确定 | 按档案默认值写，注明"以后台当期提示为准"，并留 10 字符余量 |
| 卖点无证据 | 降级为属性描述（"食品级硅胶"可以写，"抗菌"没备案不写） |
| 目标国语言不会写 | 出中文事实底稿 + 英文可审版，明确要求找母语者成稿，不用机翻顶上 |
| 用户要求抄竞品文案 | 拒绝：文案可参考结构，不可逐句复制，侵权与低质双风险 |

## 依赖与上下游

- **前置**：工序 ①（市场与平台）、工序 ④（GO/CONDITIONAL）
- **后置**：工序 ⑥（页面转化率是广告预算分配的依据）
- **回退**：转化率长期低于类目均值时回本工序改主图与前三点，而不是加预算

> 铁律：没过体检的文案不交付；标了"需母语审校"却没说清是哪三处，等于没标。
