## 一、这个专家解决什么问题

跨境出海的内容，市面上大多是"平台介绍 + 运营技巧"的通用建议。真正让卖家亏钱的，是五个很具体的地方：

| 坑 | 症状 | 这个专家怎么处理 |
|---|---|---|
| 算错账 | 出厂 30、卖 19.9 美金，以为毛利一半；算完头程、佣金、配送、退货、广告，净利是负的 | 按**每成交一单**算到岸成本瀑布，出保本售价、保本 ACOS、保本日销三条线 |
| 合规想当然 | 有 CE 报告就以为能进欧盟；不知道还要欧盟责任人、包装 EPR、本地语言标签 | 品类 × 国别合规矩阵，出阻断/条件/提示三级清单，给 GO / CONDITIONAL / BLOCKED |
| 页面靠机翻 | 标题堆 8 个关键词，写"best""100% safe"，五点里塞邮箱 | 按平台字数与禁词逐条体检，error 清零才交付，并标出三处必须母语审校 |
| 补货拍脑袋 | 卖爆了才下单，海运 42 天，断货两个月 | 补货点、在库耗尽日、最晚下单日、海空切分、占用资金 |
| 没有止损线 | ACOS 45% 还在"养词" | 开打前先算出保本 ACOS，写进投放表，连续 7 天越线就砍 |

## 二、六道闸门（全流程）

```
G0 立项  →  G1 选品  →  G2 成本  →  G3 合规  →  G4 页面  →  G5 冷启补货
```

| 闸门 | 过关条件 | 交付物 |
|---|---|---|
| G0 立项 | 成本口径、目的国、卖家身份三清 | 立项卡 |
| G1 选品 | 需求 / 竞争 / 价格带 / 合规四条判据有数据 | 选品判定 |
| G2 成本 | 净利率过 15%；低于 10% 不给"可以做" | 成本定价 |
| G3 合规 | 阻断项为 0（或已有明确路径与日期） | 合规放行单 |
| G4 页面 | 脚本 error 为 0，三处母语审校点已标 | Listing 文案包 |
| G5 冷启补货 | 每个广告活动有止损线，首单不超 45 天量 | 冷启补货表 |

单点问题可以只走相关闸门（如只问"这个价能不能做"就走 G2），但缺的参数会列成"待填"，不替用户猜。

## 三、四个计算脚本（纯标准库）

脚本在 `skills/landing-kit/scripts/`，`python` 直接跑，不需要装任何依赖：

```bash
python landed_cost.py --input case.json          # 到岸成本 + 三条保本线 + 阶梯 + 敏感性
python compliance_gate.py --category baby --market DE --market FR --have EU-RP
python listing_lint.py --profile amazon_us --input listing.json
python replenish_plan.py --input case.json       # 补货点 / 断货日 / 海空切分 / 占资金
```

| 脚本 | 输出重点 | 退出码 |
|---|---|---|
| `landed_cost.py` | 落地成本、保本价、保本 ACOS、保本日销、价格阶梯、敏感性网格 | 0 正常 / 2 参数错 |
| `compliance_gate.py` | GO / CONDITIONAL / BLOCKED + 阻断项 + 需备证据 + 谁办 + 周期 | 0 正常 / 2 参数错 |
| `listing_lint.py` | error / warn / info 三级，得分，逐条改法 | 0 无 error / 1 有 error |
| `replenish_plan.py` | 补货点、在库耗尽日、最晚下单日、海空切分、占用资金 | 0 正常 / 2 参数错 |

每个脚本都带 `--selftest`（各 7 项断言）与 `--json`。实跑样例见 `skills/landing-kit/scripts/fixtures/`。

## 七、与同类专家的区别

| 维度 | 常见的跨境类专家 | 本专家 |
|---|---|---|
| 输出形态 | 建议、清单、方案文字 | 算出来的表 + 放行结论 + 带日期的补货计划 |
| 数字来源 | 通用经验值（"佣金约 15%"） | 用户给的实际费率；缺的一律标"待填"并说明去哪查 |
| 合规 | 罗列"要认证" | 品类 × 国别三态判定，直接给 GO / CONDITIONAL / BLOCKED |
| 文案 | 直接生成 | 生成后必须过 lint，error 清零才交付 |
| 工具 | 无 | 四个可复算的脚本，自带 7 项自检与样例 |
| 边界 | 常常越界承诺 | 明确八类不接的活，含刷单、借证、保证排名 |
