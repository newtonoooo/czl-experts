# 使用说明 — 净利操盘手

## 一、怎么开始

不需要记命令。直接用业务语言提问，专家会自己判断走哪条线，并在需要时调用内置工具。

三句话能显著提高输出质量：

1. **说清平台**（天猫 / 京东 / 拼多多 / 抖音小店），四个平台的利润结构不一样
2. **给数**：客单价、拿货成本、退货率。这三个数决定一切
3. **说清时间点**（这周要定 / 大促前 / 已经开始了），决定它给方案还是给补救

## 二、六个场景怎么用

### 场景 1：判断一个链接赚不赚钱

**这样问**

> 这个链接卖 129，拿货 38，快递 6，退货率 18%，上个月投流花 8000 卖了 4 万，帮我算清到底赚不赚钱。

**你会得到**

- 九层成本瀑布（每层金额 + 占成交额比例）
- 单均贡献毛利（每单实际留下多少钱）
- 保本 ROI（广告 ROI 低于这个数就是亏）
- 保本成交价、盈亏平衡单量、最大可承受退货率
- 判定：健康 / 薄利 / 亏损

**追问更好用**

- "如果退货率涨到 25% 会怎样" → 出敏感性表
- "我这个店有 20 个链接，帮我排出亏损款" → 走批量测算

### 场景 2：定活动价

**这样问**

> 双 11 要报跨店满减再叠店铺券，女包客单 199，拿货 62，会不会亏？

**你会得到**逐层让利表（单品折扣 → 会员 → 店铺券 → 跨店分摊）、实收、保本实收、让利最大的一层。

**特别注意**：如果店铺券门槛按优惠后金额判定，你按原价设计的券可能根本不生效。工具会直接标"未达门槛"。

### 场景 3：备货与现金

**这样问**

> 活动 3 天，日常一天 20 单，预计翻 3 倍，供应商要提前 10 天，起订 50 件，单价 62，帮我算备多少、压多少钱。

**你会得到**建议采购量、采购金额、现金占用天数、现金峰值，以及 60%–150% 五档达成率下的断货量与占用资金。

**判断标准**：现金峰值超过你能动的钱，就减备货，不要靠账期硬扛。

### 场景 4：月度复盘

**这样问**

> 这个月 GMV 掉了 25%，UV 从 12 万降到 9.8 万，转化率 3.1% 降到 2.8%，客单 168 涨到 181，退款率 14% 涨到 19%。帮我拆一下。

**你会得到**四项贡献额、占总降幅比例、主因排序，以及"可以说 / 不能说"两句话。

**它的价值**在最后那两句：告诉你会上的边界在哪，别被问倒。

### 场景 5：文案会不会被罚

**这样问**

> 儿童保温杯写了"食品级 最安全 宝宝专用"，哪些会被罚？怎么改？

**你会得到**风险命中表（风险等级 / 类别 / 命中词 / 上下文 / 改法），以及标题结构问题（超长、堆砌、符号）。

**注意**：词表只覆盖文字。主图里的字、直播口播要单独过一遍。

### 场景 6：货盘该砍谁

**这样问**

> 店里有 30 个链接，一半不出单，帮我看看该砍哪些。

**你会得到**四角色判定表、毛利集中度、动销率、周转天数，以及"保谁 / 改谁 / 砍谁"三组动作，带具体数量和释放的资金。

## 三、工具参数速查

| 参数 | 含义 | 默认 |

| `--pack` | 包装耗材/单 | 0 |
| `--commission` | 平台佣金率（0.05 = 5%） | 0 |
| `--payment` | 支付手续费率 | 0 |
| `--tax` | 税费率（按收入） | 0 |
| `--refund` | 退货率 | 0 |
| `--return-ship` | 退货回程运费/退货单 | 0 |

批量 CSV 必需列：`sku, price, cost, ship, refund`；可选列见 `fixtures/skus.csv`。

## 四、怎么判断输出靠不靠谱

三问：

1. **每个数字有没有口径？** 只写"毛利率 32%"的，不能用；写"毛利率 32%（售价口径，未扣广告，含运费）"的才能用。
2. **有没有止损线？** 没有"花多少、到哪天、什么信号停"，方案没完成。
3. **查不到的东西有没有明说？** 平台费率、活动规则这类，写"以后台为准"是对的，填一个看起来合理的数才是错的。

## 五、常见问题

**Q：它会不会直接给我一个"万能运营方案"？**
不会。方案必须建立在你给的三个数上。缺数它会先要数，不会编。

**Q：平台规则它知道吗？**
知道方法，不记死数字。费率、报名门槛、字数上限会现场查，并注明查询日期；查不到就写"以后台公告为准"。

**Q：能不能帮我算"投多少能爆"？**
不能。流量没有保证这回事。它能给的是：在当前毛利结构下，你的出价上限是多少、亏多少该停。

**Q：文案词表是法律意见吗？**
不是。它是自查工具，覆盖常见高风险表达。被投诉或被立案时找律师。

**Q：会不会帮我写刷单方案？**
不会。会拒绝，并给合规替代方案（真实评价引导、老客召回、退货原因治理）。

**Q：能给竞品数据吗？**
只能给公开可查的（页面价、评价数、公开销量区间），并注明抓取日期。查不到就写查不到。

## 六、把它用成日常习惯

| 频率 | 用它做什么 |
|---|---|
| 上新前 | 一条链接账本，判断能不能做 |
| 每周一 | 批量账本，找出亏损款 |
| 报活动前 | 机制叠加 + 备货测算 |
| 活动后 3 天 | GMV 拆解 + 实际毛利复核 |
| 每月 | 货盘四角色体检 |
| 上架/改文案前 | 合规体检 |
