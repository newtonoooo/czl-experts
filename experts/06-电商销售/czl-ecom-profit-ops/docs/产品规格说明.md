## 一、目标用户与实际场景

### 用户画像

| 类型 | 规模特征 | 典型处境 |
|---|---|---|
| 单店店主 | 年 GMV 100 万–3000 万，3–15 人 | 自己在做运营，没有专职财务，账靠感觉 |
| 店铺运营 | 一人管多链接，背 GMV 与 ROI 双指标 | 上级要增长，自己不知道利润底线在哪 |
| 品牌电商负责人 | 多平台并行，有供应链团队 | 平台之间打法互相打架，价格体系混乱 |
| 新入行卖家 | 刚开店或刚转类目 | 只会抄同行，不懂成本结构 |

### 高频场景

1. 上新品前判断"这个价能不能做"
2. 月底发现 GMV 涨了但账上没钱
3. 大促报名截止前判断"这个机制会不会亏"
4. 备货决策：备多少、压多少钱
5. 月度复盘被问"为什么掉了"
6. 上架前担心文案被罚

## 二、要解决的问题

按优先级：

| # | 问题 | 现状 | 本产品的解法 |
|---|---|---|---|
| 1 | 利润算不清 | 用 GMV 减拿货价当毛利，漏运费、佣金、退货、广告 | 九层成本瀑布，输出单均贡献毛利与保本 ROI |
| 2 | 退货成本被低估 | 当成"少卖几单" | 回程运费 + 货损 + 二次销售率分开计 |
| 3 | 出价没有上限 | 凭"行业 ROI 3:1"这类说法出价 | 保本 CPC = 毛利率 × 转化率 × 客单价 |
| 4 | 优惠叠加算不清 | 每层单独看都"还行"，叠完亏 | 固定顺序逐层计算，标出让利最大的一层 |
| 5 | 大促压货压死现金流 | 只报销量目标，不算采购金额与占用天数 | 备货五档达成率 + 现金峰值 |
| 6 | 复盘停在"流量掉了" | 没有拆解方法，靠猜 | 四项逐项替换，贡献可精确加总 |
| 7 | 文案被罚 | 抄同行写法 | 六类风险体检 + 每处给替换写法 + 类目资质前置 |

## 三、必要输入与预期输出

### 最小输入集（缺一不可）

| 字段 | 为什么必须 | 拿不到时怎么办 |
|---|---|---|
| 客单价（成交价） | 所有比例的分母 | 让他去后台查，不替他假设 |
| 拿货成本（含到仓） | 毛利基础 | 同上 |
| 退货率 | 决定真实收入 | 给三档区间做区间账本，标明估算 |

### 完整输入集（按工作流）

| 工作流 | 输入 | 输出 |
|---|---|---|
| A 账本 | 售价、成本、运费、包装、佣金率、支付费率、税率、退货率、回程运费、退货处理费、二次销售率、广告占比、固定费用、基准单量 | 成本瀑布表；单均贡献毛利；保本 ROI；保本价；盈亏平衡单量；最大可承受退货率；判定 |
| B 货盘 | SKU 清单、售价、成本、近 30 天销量、库存、在架数 | 四角色表；毛利集中度；动销率；周转天数；保/改/砍三组动作 |
| C 流量 | 不含广告毛利率、转化率、客单价、当前 ROI、日预算 | 保本 CPC；三价位；预算三池分配；放量阶梯；止损金额 |
| D1 机制 | 活动前价、单品折扣、会员折扣、店铺券门槛与面额、跨店门槛与满减、整单金额、成本、费率 | 逐层让利表；实收；保本实收；让利最大层；判定 |
| D1 备货 | 日常日销、活动倍数、活动天数、提前期、安全天数、现有库存、起订量、单价、结算周期、账期 | 建议采购量；采购金额；现金占用天数；现金峰值；五档达成率风险 |
| D2 倒排 | 活动开始日、目标（GMV 或利润）、主推款、机制结论 | 按决策点的倒排表；三段预算；阶段放弃条件 |
| E 复盘 | 两期 UV、转化率、客单价、退款率 | 四项贡献与占比；主因排序；可以说/不能说 |
| F 合规 | 标题、详情、主图文案、口播稿、类目 | 风险命中表；替换写法；结构问题；资质清单 |

### 输出契约（统一交付物：操盘单）

五块固定顺序：结论 / 账本 / 动作 / 止损线 / 待确认。

任何一块缺失即视为未完成交付。

## 四、通用处理步骤

```
分诊（四类活）→ 取三个数（客单价/成本/退货率）
   → A 账本（必经）
   → B 货盘 / C 流量 / D 机制 / D 备货 / E 复盘 / F 合规（按需）
   → 操盘单五块 → 自检（能否被一句话问倒）
```

**强制顺序**：任何起量、加预算、报活动、改价的建议，必须先有 A 账本。跳过的代价要说清。

**分诊出口**三种：做 / 先补材料 / 不做（并说明什么时候再来）。

## 七、与既有同类产品的功能差异

功能层面的改进点（不含任何既有产品的文案或结构）：

1. **从利润倒推，而不是从增长正推**——先出账本，再谈起量。
2. **给出保本 ROI 与保本 CPC 两个可执行阈值**，而不是"ROI 3:1 算健康"这类通用说法。
3. **退货成本拆成四笔钱**，并要求用户填二次销售率。
4. **优惠叠加顺序固定化**，并输出"让利最大的一层"。
5. **备货测算给出断货与滞销双向风险**，而不是单给一个备货数字。
6. **复盘用逐项替换法**，保证四项贡献可加总，残差可校验。
7. **合规体检给替换写法**，并前置类目资质判断。
8. **不内置会过期的平台数字**，一律参数化。
