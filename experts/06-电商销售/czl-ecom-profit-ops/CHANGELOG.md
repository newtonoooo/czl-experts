# 更新日志

## 1.0.0 — 2026-10-27

首个正式版本。从零独立开发，不是对任何现有专家包的改名或删改。

### 新增

**七个工作流**

- `sku-margin`：九层成本瀑布，输出单均贡献毛利、保本 ROI、保本价、盈亏平衡单量、最大可承受退货率
- `assortment-roles`：引流/利润/形象/清货四角色判定，毛利集中度、动销率、库存周转、价格带断档
- `traffic-budget`：由毛利率反推保本 CPC，预算三池分配，放量阶梯，三层止损
- `promo-math`：优惠叠加实收与保本实收，备货量、采购金额、现金占用、五档达成率风险
- `campaign-runbook`：T-60 倒排，按决策点组织，含短周期版（<30 天）
- `funnel-review`：UV × 转化率 × 客单价 × (1−退款率) 逐项替换拆解，四项贡献可精确加总
- `copy-compliance`：六类文案风险体检 + 标题结构 + 类目资质清单

**四个工具（纯标准库，Python 3.8+，无第三方依赖）**

- `sku_margin.py`：`ledger` / `sensitivity` / `batch`
- `promo_math.py`：`stack` / `stock`
- `funnel_check.py`：`decompose`
- `copy_lint.py`：文案合规体检，支持 `--title --limit` 与 `--json`

**八张参考卡**

成本行清单、优惠机制手册、货盘角色手册、出价放量手册、T-60 倒排表、指标口径卡、风险表述清单、类目资质清单。

**其他**

- 原创头像 `avatars/expert.png`（512×512，无水印）
- 测试套件 `tests/run_tests.py`（工具用例 + 包结构 + 交叉引用）
- 交付文档六份：产品规格、使用说明、平台展示文案、文件清单与开发记录、测试报告、商业发布风险清单

### 设计取舍

- **不内置任何平台费率、佣金比例、标题字数上限。** 这些数字会变，写死等于制造错误。工具全部通过参数传入，参考卡只给公式和判断方法。
- **合规词表只做风险提示，不做法律结论。** 每处命中都给替换写法，不给"这条一定违法"的断言。
- **拒绝类能力写进主提示词。** 刷单、虚假交易、改评价、虚假比价一律拒绝并给替代方案。

### 已知限制

- 不接平台 API，不自动抓取后台数据；所有数据由用户输入。
- 不识别图片中的文字（主图文案需人工复核）。
- 不提供财税与法律结论，只做经营侧测算与材料梳理。
- 竞品数据只能给公开可查项，无法核验的部分会明确标注。
