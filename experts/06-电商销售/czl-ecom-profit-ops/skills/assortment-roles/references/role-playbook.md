# 货盘角色判定与动作库

## 一、角色判定表

| 指标 | 引流款 | 利润款 | 形象款 | 清货款 |
|---|---|---|---|---|
| 单均贡献毛利率 | < 25% | > 40% | > 45% | < 10% 或负 |
| 销量占比 | 高（> 40%） | 中（20%–40%） | 极低（< 5%） | 递减 |
| 毛利贡献占比 | < 15% | > 50% | < 10% | 负 |
| 广告依赖度 | 高 | 中 | 低 | 无 |
| 库存天数 | < 30 | 30–60 | < 15 | 只减不增 |
| 复购率 | 中 | 高 | 低 | 无 |

判定顺序：**先看毛利贡献占比，再看销量占比**。只看销量会把利润款误判成引流款。

## 二、五个健康阈值

| 指标 | 健康 | 警戒 | 危险 |
|---|---|---|---|
| 前 3 SKU 毛利占比 | < 55% | 55%–70% | > 70% |
| 动销率（30 天） | > 75% | 60%–75% | < 60% |
| 库存周转天数 | < 60 | 60–90 | > 90 |
| 价格带断档 | 无 | 断 1 档 | 断 2 档以上 |
| 引流款带来的新客占比 | > 30% | 15%–30% | < 15% |

阈值是经验值，不同类目差异大（生鲜、快时尚的周转天数要按周看）。写进操盘单时必须注明"经验阈值，非平台标准"。

## 三、角色错位的六个信号与改法

| 信号 | 说明 | 改法 |
|---|---|---|
| 引流款销量高、利润款不动 | 流量进来了但接不住 | 详情页做关联、利润款做主图对比模块、客服话术引导 |
| 利润款库存最深、卖得最慢 | 押错款 | 停止补货，改做小批量试销；把预算挪给动销好的款 |
| 清货款在补货 | 角色混乱，用清货价拉流量 | 立即停止补货；清货价不得用于长期引流 |
| 形象款有曝光无成交 | 只被当比价锚 | 接受它不卖，但必须出现在详情页做价格参照 |
| 全店单一价格带 | 没断档但也接不住高客单 | 加一个 1.5 倍价位的款做搭配销售 |
| 引流款带来大量低质流量 | 高退货、低复购 | 换引流款或换人群定向；宁可少流量 |

## 四、上新结构建议（无历史数据时）

首单按数量比 **5 : 3 : 1 : 1**：

- 引流款 5（低价、高频、易传播）
- 利润款 3（主力毛利）
- 形象款 1（价格锚）
- 清货款 1（老款或尾货）

首批采购金额比建议 **3 : 4 : 2 : 1**——引流款单价低但量要大，利润款单价高要控制深度。

## 五、砍单决策

砍的条件（三条同时满足才砍）：

1. 近 30 天销量为 0 或环比下降超 50%
2. 库存天数 > 90
3. 该款毛利贡献占比 < 3%

砍的方式按库存价值排序：

| 库存价值 | 处理方式 | 时间 |
|---|---|---|
| < 5000 元 | 直接清货价出清 | 2 周内 |
| 5000–30000 元 | 搭赠 / 组合套装 / 直播间福利 | 4 周内 |
| > 30000 元 | 分批清 + 折价给分销 / 尾货渠道 | 8 周内，按周复盘 |

**不要一次全砍。** 一次砍太多会影响店铺动销权重和搜索排名，分 2–3 批。

## 六、货盘与流量的关系（一句话）

流量永远应该往"贡献毛利最高且能承接"的款上走。**先定谁是利润款，再决定广告投给谁。** 反过来做，就是花钱给亏损款买曝光。
