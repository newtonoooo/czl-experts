# 风险表述清单与依据方向

> **这不是法律意见。** 本清单用于上架前的自查，覆盖常见高风险表达。具体认定以执法机关与平台规则为准；被投诉或被立案时请找律师。法规条文以现行有效文本为准，引用前请核对。

## 一、绝对化用语

《广告法》明确禁止在广告中使用"国家级""最高级""最佳"等用语。执法实践中，同类绝对化表达一并认定。

| 表达 | 为什么不行 | 替换方向 |
|---|---|---|
| 最好 / 最佳 / 最强 / 最优 | 无法验证的最高级 | 具体参数：保温 6 小时、承重 15kg |
| 最安全 | 安全无绝对 | 符合 GB XXX 标准 |
| 国家级 / 世界级 | 需国家认定，不得自封 | 删除；如有认定写证书名称 |
| 唯一 / 独家 / 首个 | 排他性主张 | 罕见、少见；或提供独家授权 |
| 顶级 / 极致 / 最高端 | 无客观标准 | 材质、工艺、产地 |
| 销量第一 / 排名第一 | 需统计机构、口径、期间 | 本店近 30 天售出 X 件 |
| 100% / 永久 / 万能 | 绝对化承诺 | 实测数据 + 样本量；质保年限 |
| 驰名商标 | 法律禁止用于广告宣传 | 删除 |
| 国家免检 | 该制度已取消 | 删除 |

**注意**：加"据称""据说""网友评价"不能免责，转述同样构成虚假或绝对化宣传。

## 二、功效宣称

| 领域 | 可以说 | 不能说 |
|---|---|---|
| 普通食品 | 成分、口感、食用方式、营养含量（按标准） | 治疗、预防疾病、保健功能（除保健食品） |
| 保健食品 | 批准证书载明的保健功能，须标"本品不能代替药物" | 扩大功能、治疗疾病、暗示疗效 |
| 化妆品 | 备案/注册的功效（清洁、保湿、美容修饰等） | 医疗术语、药效、绝对化效果、"药妆" |
| 医疗器械 | 注册证载明的适用范围 | 超出范围的疗效 |
| 消毒产品 | 卫生许可范围内的杀菌率（附检测报告） | 治疗皮肤病、抗病毒（超范围） |
| 儿童用品 | 适用年龄、材质、安全标准 | "宝宝专用"（无依据）、"医用级" |

**判定要点**：产品属于哪个注册/备案类别，就只能说该类别的功效。跨一句就是违规。

## 三、价格表述

依据方向：《价格法》《明码标价和禁止价格欺诈规定》（市场监管总局令第 56 号，2022 年 7 月 1 日施行）第十九条列举的价格欺诈行为，包括通过虚假折价、减价或者价格比较方式销售商品，以及使用欺骗性、误导性的语言、文字、数字、图片或者视频标示价格。该规定还明确：没有合理理由，不得在折价、减价前临时显著提高标示价格并作为折价、减价计算基准。

| 表达 | 风险 | 要求 |
|---|---|---|
| 原价 X 元 | 高 | 需有真实的、可作为比较基准的成交记录；"先涨后降"属禁止情形 |
| 划线价 | 高 | 同上；无依据即属虚假比较 |
| 专柜价 / 市场价 | 高/中 | 需凭证或注明来源 |
| 全网最低 / 史上最低 | 高 | 无依据即属虚假比较 |
| 亏本清仓 | 高 | 不可验证，删除 |
| 到手价 X 元 | 低 | 写清活动期间与适用条件 |

**实操**：促销价与比较基准都要留档。执法检查时看的是记录，不是话术。

## 四、诱导评价与虚假交易

| 表达/行为 | 风险 |
|---|---|
| 好评返现 / 五星好评返红包 | 高（平台明确禁止，且涉不正当竞争） |
| 刷单 / 空包 / 拍A发B | 高（虚假交易，平台处罚 + 可能行政处罚） |
| 联系买家删差评 / 改评价 | 高 |
| 晒图返现（要求正面评价） | 高 |

合规替代：包裹卡做**使用指导与售后入口**，不做评价交换；老客召回用真实权益，不用"好评换权益"。

## 五、紧迫感与稀缺性

"仅剩 X 件""最后一天""限时 3 小时"——**只要是真的就可以用，是假的就属虚假宣传**。

判断标准一句话：能不能拿出后台记录证明？拿不出就删。

## 六、站外导流

加微信、二维码、手机号、"私聊下单"——多数平台禁止引导站外交易，风险中到高。改为"咨询客服"。

## 七、标题结构检查

| 项 | 规则 | 说明 |
|---|---|---|
| 长度 | 各平台上限不同，且会调整 | 以商家后台发布规范为准，用 `--limit` 传入当期值 |
| 关键词堆砌 | 同一词出现 ≥3 次 | 会被判作弊降权 |
| 装饰符号 | ★ ☆ ◆ 【 】等 | 部分平台限制 |
| 无关词 | 蹭热点、跨类目词 | 影响人群标签精准度 |

## 八、自查流程（上架前 5 分钟）

1. `copy_lint.py` 跑一遍标题和详情
2. 高风险项逐条改写，中风险项找凭证，找不到就删
3. 主图文字单独看一遍（工具查不到图片里的字）
4. 直播口播稿按同一套词表过一遍
5. 类目资质在有效期内（见 `category-licenses.md`）
