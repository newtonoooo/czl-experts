# 类目资质清单：文案之前先看证

> 各平台在法规要求之上还会加自己的准入条件，且会调整。本表用于**判断"这个类目能不能直接卖"**，具体材料清单以后台类目资质页为准。资质不在有效期内，文案改得再干净也不能上架。

## 一、食品类

| 项 | 需要什么 | 备注 |
|---|---|---|
| 预包装食品 | 食品经营许可证（或生产许可证） | 经营范围须覆盖 |
| 散装食品 | 同上，另需储运条件证明 | 分装需另办 |
| 进口食品 | 入境货物检验检疫证明 + 中文标签 | 标签须符合国标 |
| 自制/现制 | 通常不允许网络销售 | 平台规则各异 |
| 酒类 | 食品经营许可证（含酒类） | 部分平台需额外报备 |

**文案边界**：不得宣称保健功能或疾病预防治疗。

## 二、保健食品

| 项 | 需要什么 |
|---|---|
| 批准文件 | 保健食品注册证书或备案凭证（"蓝帽子"） |
| 标识 | 必须标注"本品不能代替药物" |
| 功效 | 只能按证书载明的功能表述 |

**文案边界**：不得明示或暗示治疗作用，不得扩大功能范围。这是被处罚最密集的类目之一。

## 三、化妆品

| 项 | 需要什么 |
|---|---|
| 普通化妆品 | 备案编号 |
| 特殊化妆品（染发、烫发、祛斑美白、防晒、防脱发、宣称新功效） | 注册证书 |
| 进口化妆品 | 备案/注册 + 中文标签 |

**文案边界**：不得使用医疗术语（如"药妆""医学护肤"），不得宣称疗效，功效须与备案一致。

## 四、医疗器械

| 类别 | 需要什么 |
|---|---|
| 一类 | 备案凭证 |
| 二类 | 注册证 + 经营备案 |
| 三类 | 注册证 + 经营许可证 |

**文案边界**：只能表述注册证载明的适用范围。网络销售有额外限制（部分高风险品种禁售），以后台规则为准。

## 五、儿童与母婴

| 项 | 需要什么 |
|---|---|
| 玩具 | 3C 认证（列入目录的品类） |
| 童装/童鞋 | 符合 GB 31701 等强制性标准，标识齐全 |
| 婴幼儿配方乳粉 | 配方注册 + 经营许可，且平台通常限特定商家 |
| 儿童餐具/水杯 | 食品接触材料检测（GB 4806 系列） |

**文案边界**："宝宝专用""婴儿级""医用级"都需要依据，否则删。

## 六、电器与 3C

| 项 | 需要什么 |
|---|---|
| 强制性认证目录内产品 | 3C 证书 |
| 能效标识品类 | 能效备案 |
| 电池类 | 运输与安全证明（空运受限） |

## 七、其他常见需资质类目

| 类目 | 资质 |
|---|---|
| 图书/出版物 | 出版物经营许可证 |
| 农药/兽药 | 相应经营许可证 |
| 种子 | 种子经营备案 |
| 珠宝玉石 | 部分平台要求鉴定证书 |
| 二手/翻新 | 部分平台禁售或需专项报备 |
| 宠物食品 | 饲料生产/经营相关资质 |

## 八、判断流程

1. 先确认商品属于哪个监管类别（普通食品 / 保健食品 / 化妆品 / 医疗器械 / 普通工业品）
2. 查该类别需要的证照，确认在有效期内且经营范围覆盖
3. 查平台该类目的额外准入要求（部分类目需邀约或缴纳额外保证金）
4. 最后才写文案，且只在资质允许的范围内表述

**顺序不能反。** 先写文案再补资质，是最常见的翻车方式：文案已经承诺了资质给不了的东西，最后只能整链接重做。

## 九、需要向平台或专业人士确认的情形

- 宣称"新功效"的化妆品
- 进口但无中文标签的商品
- 含药食同源成分的普通食品
- 赠品属于受管制类目
- 跨类目组合套装（如"食品 + 餐具"）
- 直播中口播的效果描述

这些情形不要自己判断，让用户去问平台客服或专业机构，并在操盘单的"待确认"里写明由谁回答。
