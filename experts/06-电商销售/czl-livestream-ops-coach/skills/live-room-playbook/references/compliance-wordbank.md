# 违禁表述与替换词表

> **这不是法律意见。** 下面是直播话术里最容易出事、也最容易改的几类表述，以及可以直接替换的说法。
> 依据方向：《广告法》对绝对化用语与医疗用语的一般性规定、《食品安全法》对食品广告的约束、《反不正当竞争法》对虚假宣传的约束，以及各平台自身的直播行为规范。
> 具体条款、处罚标准、平台规则随时可能调整，**涉及实际执法判断请以官方最新文本和平台客服答复为准**。

---

## 一、绝对化用语

《广告法》禁止使用"国家级""最高级""最佳"等绝对化用语。实践中，凡是无法被证明、且含有"最/第一/唯一/顶级/极致"含义的表达，都属于高风险。

| 不要这样说 | 改成 |
|---|---|
| 全网最低价 | 本场专属价，比日常便宜 XX 元 |
| 最好用的 / 最好喝 | 我自己回购了三次的那一款 |
| 销量第一 / 行业第一 | 这个规格在我们店里卖得最多 |
| 唯一一款能做到 | 我目前没在同价位见过这个做法 |
| 顶级面料 / 顶级工艺 | 用的是 XX 克重的 XX 面料 |
| 百分百有效 / 绝对不会 | 绝大部分情况下 XX（并给出条件） |
| 史上最便宜 | 今年到目前为止我们做过的最低 |
| 全国包邮（实际有区域限制） | 除偏远地区外包邮，具体看商品页 |

**替换思路：绝对化 → 具体化。** 说不出具体数字，就说明这个卖点本身站不住。

## 二、功效与医疗暗示

非医疗、药品、医疗器械类商品，广告不得涉及疾病治疗功能，不得使用医疗用语，不得使人误认为与药品、医疗器械有关。

| 品类 | 高风险说法 | 可以这样说 |
|---|---|---|
| 化妆品/护肤 | 祛痘、消炎、修复受损屏障、治疗敏感 | 我自己用下来肤感是 XX；成分表里含 XX，主要作用是保湿 |
| 洗护 | 防脱生发、去屑止痒（暗示疗效） | 洗后头皮感觉清爽；适合 XX 发质日常清洁 |
| 食品（普通） | 增强免疫力、降三高、排毒、抗癌 | 配料是 XX，口感是 XX，适合当早餐/加餐 |
| 家居/床品 | 治疗颈椎病、改善失眠 | 高度是 XX，躺上去颈部有支撑感 |
| 服饰 | 塑形瘦身、矫正体态 | 版型是 XX，腰线位置在 XX |
| 器械/按摩仪 | 治疗腰痛、代替理疗 | 有 XX 档力度，用起来是 XX 感觉（并说明非医疗器械） |

**一条实用判断：** 如果这句话让观众觉得"用了能好"，而不是"用了是什么感觉"，就删掉。

## 三、保健食品与特殊品类

| 情形 | 要求 |
|---|---|
| 保健食品 | 不得涉及疾病预防、治疗功能，不得声称可以代替药物；必须提示"本品不能代替药物" |
| 药品/医疗器械 | 通常需广告审查批准文号，直播中不得随意宣称疗效；不确定就不讲 |
| 酒类 | 不得诱导、怂恿饮酒，不得表现饮酒动作，不得面向未成年人 |
| 金融/保险类 | 不得承诺收益、不得保本保收益；这类内容建议直接不碰 |
| 医疗美容 | 高风险，非持证机构不碰 |

## 四、虚假比价与假稀缺

《反不正当竞争法》禁止虚假或引人误解的商业宣传。以下做法都有风险：

| 做法 | 问题 | 改成 |
|---|---|---|
| 虚构原价（"原价 999，今天 99"但从未卖过 999） | 虚假价格 | 只报真实历史成交价，或只说"本场价" |
| 划线价无依据 | 同上 | 同上 |
| "最后 3 件"但补货不断 | 假库存 | 库存真实，补货就明说"又申请了 20 个" |
| 假倒计时反复重置 | 假限时 | 用真实下架时间，到点就下 |
| "仅此一场，明天涨价"但明天照旧 | 虚假陈述 | 不说未来价格，只说本场权益 |

**稀缺感可以真实存在，但不能伪造。** 真库存、真时间、真限量，三样都能查，才敢说。

## 五、贬低同行与摆拍对比

| 不要做 | 改成 |
|---|---|
| 点名或暗示某品牌"不行" | 只讲自己产品的参数与做法 |
| 摆拍"劣质产品"做对比 | 用自己产品的实测（倒水、摔、量尺寸），不出现其他品牌 |
| "市面上大部分都是假的" | "这个价位段工艺差异比较大，我们这款是 XX 工艺" |

## 六、诱导与站外交易

| 平台常见规则方向 | 说明 |
|---|---|
| 抖音 | 直播中口播引导加微信、留联系方式、引导站外成交，属于高风险行为 |
| 快手 | 禁止站外交易与私下转账 |
| 淘宝直播 | 禁止虚构成交量、库存、评价 |
| 视频号 | 对医疗健康、金融类内容审核更严 |

**通用做法：** 所有成交留在平台内，所有售后走平台通道。用户要加微信，回复"售后在订单页点客服，比微信快"。

---

## 七、未成年人

- 不诱导未成年人下单，不使用"小朋友让爸爸妈妈买"这类话术。
- 不使用不满十周岁的未成年人作为广告代言人。
- 面向儿童的商品，不做"吃了长高""用了变聪明"这类表述。

---

## 八、其他容易被忽略的

| 说法 | 问题 | 改成 |
|---|---|---|
| 假一赔十 / 假一赔万 | 承诺需真实可执行 | 按平台规则与店铺承诺说，不加码 |
| 无效退款 | 需明确条件 | "7 天无理由，按平台规则" |
| 央视上榜品牌 / 国家认证 | 需有真实依据 | 有证书就报证书名称与编号，没有就不提 |
| 冠军同款 / 明星同款 | 需有授权 | 不说 |
| 库存清仓最后一天（长期挂） | 虚假 | 说具体日期 |

## 九、自检三问（写完脚本逐条过）

1. 这句话有没有"最/第一/唯一/绝对/百分百"？有就改。
2. 这句话有没有让人以为"能治病/能变好"？有就改成感官描述。
3. 这句话里的数字（库存、价格、时间）能不能当场核实？不能就删。

三问全过，脚本才能交给主播。
