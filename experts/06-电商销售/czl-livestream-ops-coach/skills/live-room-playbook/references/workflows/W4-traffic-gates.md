# W4 流量闸门与投放节奏

## 一、职责

把"要不要投、投多少、什么时候加、什么时候停"这四件事，变成四个写在纸上的数字。
投放不是加油门，是设闸门：**过了线就开，破了线就关，中间不动。**

## 二、输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 单件净毛利 / 保本 ROI（`breakeven` 算出） | 是 | 所有闸门的基准线 |
| 客单价 | 是 | 算 CPA 上限 |
| 单场可承受最大亏损 | 是 | 决定预算上限 |
| 历史 ROI 与 CPA | 否 | 没有就按保本线的 1.3 倍做首场测试 |
| 自然流量现状 | 是 | 自然进房占比，决定投多少 |
| 账号处罚/限流记录 | 是 | 有处罚时不投，先修 |

## 三、三道闸门

### 闸门一：保本线（绝对线）

```
保本 ROI = 售价 / 单件净毛利          （由 breakeven 命令算出）
保本 CPA = 单件净毛利
```

**低于保本线的投放，每多花一块钱就多亏一块钱。** 这条线不打折、不谈判，无论"这场是战略性亏损"还是"要冲榜"。
如果业务上确实要战略性亏损，那就**明确写下亏多少、亏给谁看、亏完得到什么**，把它当成本而不是当投放。

### 闸门二：单场预算上限

```
单场预算上限 = min( 可承受最大亏损 / 单均亏损 , 保本 CPA × 目标付款单量 )
单均亏损 = 实际 CPA − 保本 CPA
```

举例：保本 CPA 54 元，实际跑出来 CPA 70 元，每单亏 16 元。可承受最大亏损 3000 元 → 上限约 187 单，对应预算约 13000 元。
**先算亏损上限，再定预算**，顺序反了就会在播到一半时被迫停投，流量断崖比不投更伤。

### 闸门三：放量与止损条件

| 条件 | 动作 | 观察窗口 |
|---|---|---|
| ROI ≥ 保本 × 1.2 | 预算加 30% | 加完至少等 30 分钟再看 |
| 保本 × 0.9 ≤ ROI < 保本 × 1.2 | 不动 | 不要因为"看着还行"就调 |
| ROI < 保本 × 0.9 | 预算减半或关停该计划 | 立即 |
| 单条计划花费 > 保本 CPA × 10 且零成交 | 立刻关 | 立即 |
| 计划跑 2 小时不消耗 | 按排查顺序查，见第六节 | 一次只改一个变量 |

## 四、投放节奏表（4 小时场）

| 时段 | 目的 | 预算占比 | 动作 |
|---|---|---|---|
| 开播前 30 分钟 | 预热，让系统先认识这场 | 10% | 小额起量，测素材与人群 |
| 0-15 分钟（建模期） | 拉第一批精准人 | 20% | 用引流款承接，重点看停留与互动 |
| 15-90 分钟 | 放大 | 30% | 主力款上线时同步加价，让进房与货对上 |
| 90 分钟-3 小时 | 稳定 | 30% | 只做加减，不做大改；每个波峰前 5 分钟加价 |
| 最后 40 分钟 | 收割 | 10% | 逐步降预算，把预算留给下一场 |

**核心原则：货到之前不要放量。** 投放带来的流量如果撞上利润款，等于把最贵的流量卖给最少的人。

## 五、自然流量的四个抓手

自然流量不是"求"来的，是四个指标撑起来的。这四个指标各有对应的动作，不要混着做。

| 指标 | 抓手 | 具体动作 |
|---|---|---|
| 停留 | 钩子密度 | 每 8-10 分钟一个钩子（抽奖/预告/问答） |
| 互动 | 指令设计 | 二选一提问 > 开放提问；点名欢迎 > 群发欢迎 |
| 点击 | 讲解与链接绑定 | 讲卖点的同一秒报链接序号 |
| 转化 | 价格锚定与稀缺 | 官方价→到手价→赠品→停 2 秒→报数字 |

**自然进房占比健康区间：** 冷启动 ≥30%，成长期 ≥50%，成熟期 ≥70%。
低于这个区间意味着你在租流量，不是在攒流量。此时的动作是修上面四项，不是再加预算。

## 六、投放花不出去的排查顺序

一次只改一个变量，改完等够一个观察窗口（至少 30 分钟）再看。

1. **素材**：是不是同一条素材跑了太久、点击率掉了？换一条同结构的。
2. **出价**：出价低于市场成交成本时，系统不给量。按保本 CPA 的 80% 起，逐步上调。
3. **人群**：定向太窄（叠加多个兴趣 + 地域 + 年龄）会导致池子太小。先放宽一层。
4. **账户**：余额、资质、审核状态、是否触发风控。这一层最容易被忽略。

## 七、判断条件

| 情况 | 判定 | 动作 |
|---|---|---|
| 自然进房占比 <20% | 流量全靠买 | 先修自然指标，投放只保留测试预算 |
| 保本 ROI <1.5 | 毛利结构撑不住投放 | 不投，回去改成本结构或提客单价 |
| 单场预算 > 可承受亏损 | 会中途被迫停投 | 砍预算或砍时长，不要赌后半场翻盘 |
| ROI 波动 >50% | 样本太小 | 单量 <20 时 ROI 不可信，只看方向 |
| 投放一停就归零 | 内容留人能力不足 | 回到 W2/W3，把人留住的功夫做在免费流量上 |
| 有处罚记录仍要投 | 违规风险 | 明确告知风险，方案里不写"保证能过审" |

## 八、输出格式

1. **保本测算表**（售价 / 成本 / 退货率 / 单件净毛利 / 保本 ROI / 保本 CPA）
2. **预算与闸门表**（预算上限 / 放量条件 / 止损条件 / 观察窗口）
3. **节奏表**（时段 / 预算占比 / 对应货位 / 动作）
4. **自然流量四项指标的目标值与现状**（各一行）

## 九、异常处理

| 异常 | 处理 |
|---|---|
| 用户没有毛利数据 | 不出预算与出价，只给"不投流版本"方案 |
| 用户要求"保证 ROI" | 拒绝承诺，改承诺"设好止损，最坏情况亏 X 元" |
| 投放跑起来但成交集中在低价品 | 流量与货不匹配，调整定向人群或把主力款前移 |
| 平台工具名称不懂 | 用通用说法（"付费流量工具"），不硬猜具体后台路径 |
| 大促期间成本整体上涨 | 保本线不变，压缩预算或提高客单价，不放松闸门 |
