# 单品脚本卡（模板）

> 一个品一张卡，讲 4-6 分钟。每句 ≤25 字。标注【念】【做】【看】【停】。
> 价格与赠品用占位符，现场以中控实际设置为准。

## 基本信息

| 项 | 内容 |
|---|---|
| 品名 | |
| 货位 | 引流款 / 承接款 / 主力款 / 利润款 / 收尾款 |
| 上链接时间 | 第 ____ 分钟 |
| 到手价 | 【价】元（官方价 ____ 元） |
| 赠品 | 【赠】 |
| 库存与释放 | 总 ____ 件；首放 ____ / 二次 ____ / 三次 ____ |
| 禁止说的点 | （本类目红线，见 compliance-wordbank） |

## 合规自检

- [ ] 无"最/第一/唯一/绝对/百分百"
- [ ] 无功效承诺、无医疗用语
- [ ] 价格、库存、时间可当场核实
- [ ] 无贬低同行、无摆拍对比
- [ ] 无站外引流话术
