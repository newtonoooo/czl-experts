## 二、风险清单

### R1 · 投资咨询资质 —— 等级：高 🔴（付费模式下可能阻塞）

**风险**
以收费方式向公众提供"个股买卖点位、仓位、止损"这类具体投资建议，
在监管口径下可能被认定为**证券投资咨询业务**。《证券法》与《证券投资顾问业务暂行规定》
对从事该业务有牌照要求（证券投资咨询机构资质、从业人员资格）。
个人开发者在无牌情况下**以营利为目的**提供具体买卖建议，存在合规风险。

**当前缓解**
- 产品定位写明"不推荐个股、不承诺收益、不代客下单"。
- 输出是"条件化分析"（若 A 则偏强、若跌破 B 则走弱），不是"买入/卖出"指令。
- 每个命令输出都带免责声明。
- 拒绝操纵类请求、拒绝预测式承诺。

**仍未解决**
免责声明不能消除"实质提供投资建议"的认定风险。付费会放大这一风险（因为有对价关系）。

**建议动作（请你决定）**
1. 若坚持付费上架：把能力介绍改写成"行情数据分析工具 / 交易纪律计算器"，
   通篇不出现"推荐""选股""买入信号"；类目选"数据工具"而非"投资顾问"。
2. 或改为**免费**上架，风险显著降低（无对价，性质更接近工具）。
3. 或在上架前咨询执业律师，取得书面意见。

**是否阻塞发布**：付费模式下建议先解决；免费模式可先上。

### R2 · 行情数据授权 —— 等级：高 🔴

**风险**
程序访问的是腾讯、新浪、东方财富面向行情页面公开使用的查询地址。
**没有任何书面授权、没有数据许可协议、没有 SLA**。
- 小规模个人使用：通常无人追究。
- 规模化商业运营（尤其付费）：可能违反数据提供方使用条款，
  或触及交易所行情信息的授权要求（沪深交易所对实时行情有明确的授权与收费体系）。

**当前缓解**
- 已在 `NOTICE.md` 如实披露使用了哪些域名、用途。
- 代码里做了主机冷却与限流，避免给对端造成压力。
- 不存储、不再分发原始行情数据（只在本机缓存 20–300 秒用于计算）。

**建议动作**
1. 上架初期按"个人工具"规模运营，不宣传"数据服务"。
2. 一旦有规模化收入，接入持牌数据源（交易所授权或万得/聚源等），
   把 `atd/quotes.py`、`atd/history.py` 的数据源层替换掉（接口已隔离在这两个文件里，替换成本低）。

**是否阻塞发布**：不阻塞上架；阻塞规模化。

### R3 · 平台运行环境兼容性 —— 等级：中 🟡

**风险**
平台文档说明付费资产"加密并在云端运行"。本产品依赖**本地 Python 执行脚本**，
且需要**访问外网**（腾讯 / 新浪行情接口）。
若平台运行环境不提供 Python 运行时或不允许出网，核心功能将失效——只剩提示词，
等于失去本产品全部差异化。

**当前缓解**
- 脚本对 Python 版本要求低（3.8+），无第三方依赖，理论上容易满足。
- 已尽量减少单次请求量（快照批量、情绪扫描 56 页但 2 秒完成）。
- 若无法出网，产品仍可给出方法论与仓位算法（`plan` 需要现价，无网时得由用户手输价格）。

**必须在真实环境验证**
上传后先用平台后台的"立即测试"跑三条命令：
```
python scripts/tapedesk.py doctor
python scripts/tapedesk.py quote 600519
python scripts/tapedesk.py pulse
```
若 `doctor` 有失败项，说明出网受限，需要改方案。

**是否阻塞发布**：未知，取决于实测结果。**这是上架前必须验证的第一项。**

### R4 · 数据源限流与波动 —— 等级：中 🟡

**风险**
- 东方财富 `push2*` 在本机实测因连续请求被临时断流（已降为备源）。
- 新浪全市场扫描一次要发 56 个请求，若平台侧 IP 共享、并发高，可能被风控。
- 极端行情下接口响应变慢。

**当前缓解**
- 主机连续失败 2 次冷却 90 秒；请求退避重试；双层缓存；三源降级。
- 情绪扫描失败时明确报"抓取失败"，不静默返回空数据。

**建议动作**
上架前在 9:30–10:00、14:30–15:00 两个高峰时段各压测一次，记录成功率。

**是否阻塞发布**：不阻塞。

### R5 · 免费转付费不可逆 —— 等级：中 🟡

**风险**
官方 FAQ 明确：为避免影响已安装用户，**当前阶段不支持免费资产转为付费**。
一旦以免费发布，后续想改收费需要重新发布一个新资产（老用户会被割裂）。

**建议动作**
上架前就定好：首发即付费，或首发免费且接受长期免费。
不存在"先免费试水再涨价"的路径。

**是否阻塞发布**：不阻塞，但**发布后无法反悔**，请先决定。

### R6 · 宣传用语合规 —— 等级：中 🟡

**风险**
- 你要求名称体现"专业""最强"这类修饰。**"最强""第一""顶级"属于《广告法》禁用的绝对化用语**，
  已有"专业"是可保留的（描述性质），但"最强"不建议使用。
- 本产品名称为"盘锋 · 专业A股盘中交易参谋"，未使用绝对化用语，当前合规。
- 平台对付费资产名称有限制：仅中英文、数字、"-"，不能含空格或特殊字符。"盘锋"符合。

**建议动作**
宣传文案严格按 `docs/平台展示文案.md` 第九节"宣传禁区"执行，不要写"抓涨停""稳赚""AI选股神器"。

**是否阻塞发布**：不阻塞。

**建议动作**

### R9 · 用户误用风险 —— 等级：低 🟢

**风险**
用户可能把条件化分析当成买卖指令，亏损后归咎于产品。

**当前处理**

- 拒绝推荐个股，改为询问用户逻辑。
- 用户情绪化（想加仓摊平）时先摆数字再谈选择。

**建议动作**
