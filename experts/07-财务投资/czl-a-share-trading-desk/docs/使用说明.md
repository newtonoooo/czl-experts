# 使用说明

盘锋 · 专业A股盘中交易参谋 v1.0.0

---

## 一、它能帮你做什么

| 你的处境 | 它能给的 |
|---|---|
| 想知道今天这个盘能不能做 | 情绪温度、风险等级、建议仓位上限（带原始计数，可自己核对） |
| 手里一只票不知道还能不能拿 | 趋势结构、关键价位、量价关系、三个观察点 |
| 想买但不知道买多少、亏多少走 | 仓位股数、止损位、R/T 止盈位、触发与放弃条件 |
| 不知道钱往哪个方向去 | 板块强度排行、龙头候选、主线还是情绪 |
| 想盯着某个价位 | 结构化预警清单，下次对话可以直接核对 |
| 收盘想知道今天到底发生了什么 | 复盘：盘面 → 持仓 → 预警 → 明日三个观察点 |

## 二、五句话开始

启用专家后，直接说人话，不需要记命令：

1. `现在大盘什么情绪，我该控制到几成仓？`
2. `帮我体检 300750，跌破哪里算走坏？`
3. `今天哪些板块是主线，龙头是谁？`
4. `我 20 万，想买中芯国际，止损放哪，买多少股？`
5. `茅台跌到 1300 提醒我`

## 三、它每次会怎么做

1. **先确认时段**：现在是盘前、竞价、早盘、午休、午盘还是收盘后。
   这决定了报告里写"实时"还是"上一交易日收盘"。
2. **再取数**：所有价格、指标、情绪分都来自脚本实测，不靠记忆。
3. **最后算账**：仓位、止损、止盈一律用公式算，不心算。
4. **给条件，不给结论**：不说"买"或"卖"，说"若 X 成立则偏强，若跌破 Y 则走弱"。

## 四、报告怎么看

每份报告底部都有一行固定格式：

```
数据：腾讯行情｜获取 2026-10-27 12:15｜今日盘中实时数据｜以上为公开数据与规则化计算的结果，不构成投资建议；据此操作风险自担。
```

四个要素：**来源、时间、数据性质、免责**。看到"上一交易日收盘数据"就说明现在不是盘中。

### 关键字段速查

| 字段 | 含义 | 怎么用 |
|---|---|---|
| 情绪温度 0-100 | 全市场广度与赚钱效应的加权分 | <20 冰点不抢反弹；40-60 中性可正常参与；≥80 过热要收紧 |
| 风险等级 | 情绪极端程度 + 跌停数 + 指数跌幅 | "高"时把建议仓位再打七折 |
| 建议仓位上限 | 环境允许的最大暴露 | 这是上限，不是目标 |
| 趋势评分 -100~+100 | 均线、偏离、MACD、KDJ 的合成 | ≥45 偏强 / ≤-45 偏弱 / 中间是震荡 |
| 日内位置 0-100 | 现价在当日最高最低之间的位置 | 90 以上说明在日内高位，追要注意回落 |
| 距涨停 / 距跌停 | 还有多少空间到板 | 涨停板上买不到，跌停板上卖不掉 |
| 约束项 | 仓位由"风险预算"还是"仓位上限"决定 | 知道卡在哪，才知道该调哪个参数 |

## 五、典型场景演练

### 场景 1：早上开盘前，不知道今天该不该动手

```
你：今天能动手吗？
它：先给情绪温度与风险等级，再说仓位上限。
    如果温度 32（偏冷），它会说"三成以内试错，别追"。
```

### 场景 2：手里的票跌了，想加仓摊平

```
你：我 30 买的，现在 26，要不要补？
它：先把数字摆出来——当前浮亏 13.3%，补一手后的平均成本、总敞口、最坏情况。
    然后才谈选择：补仓的前提是结构没坏，破位补仓是把小错变大错。
```

它不会直接说"别补"，但会把"补了以后你要扛多少"算给你看。

### 场景 3：给资金，要一份可执行的计划

```
你：我 20 万，想买中芯国际，怎么买？
它：1. 先取现价、ATR、涨停价
    2. 跑一次大盘情绪，拿到仓位上限
    3. 算：单笔风险 1% = 2000 元，ATR 止损 2 倍，得到每股风险
    4. 得出股数、占用资金、触发止损亏多少
    5. 给三个触发条件、放弃条件、分批止盈位
```

如果算出来不足 1 手，它会告诉你"1 手要多少成本、止损亏多少、占资金多少百分比"，
再给两条调整路径，而不是一句"买不了"。

### 场景 4：设了预警，隔天来问

```
你：茅台到 1300 了吗？
它：读清单文件 → 取现价 → 报事实：现价 1348.00，阈值 1300，未触发，还差 3.6%。
```

不会替你判断"该不该卖"，只告诉你条件有没有满足。

## 六、它不会做的事

- 不推荐"今天买哪只"。
- 不承诺收益，不说"必涨""稳赚""保本"。
- 不代客下单，不要你的账户和密码。
- 不碰港股、美股、北交所、可转债、期货、基金。
- 不做基本面估值与财报分析（这属于研究型工具的范围）。

## 七、常见问题

**Q：为什么有时候"量能"这项是中性 50 分？**
A：量能需要跟近 5 个交易日的平均成交额比较，而历史基准是本地逐日累积的。
装好后的前 3 个交易日样本不足，就按中性计，报告里会写明"历史样本不足"。这是刻意的诚实降级。

**Q：为什么板块"连续上涨"显示"—"？**
A：第一天没有历史可对比，只能标"需次日验证"。积累几天后会自动出现。

**Q：为什么涨停家数和我软件里看到的差一两家？**
A：这里按"昨收 × 板块限制比例"重算涨停价。新股上市首日无涨跌幅限制、除权日限制价会偏移，
这两种情况会差。通常不影响温度档位判断。

**Q：数据取不到怎么办？**
A：先让它跑一次自检（`doctor`），它会告诉你是哪一层失败。公开接口有频率限制，
连续高频请求会被临时断流，等 1-2 分钟再试。它不会拿旧价格冒充现价。

**Q：预警会自己弹出来吗？**
A：不会。这是对话内核对，不是服务器推送。需要秒级提醒请用券商 App，它做辅助分析。

**Q：能分析我的持仓组合吗？**
A：可以逐只体检，并算出"所有持仓同时触发止损时的总亏损占比"。
超过 6% 说明押在同一个逻辑上太重。

## 八、风险提示

本专家输出的一切内容均为公开数据与规则化计算的结果，**不构成投资建议，不推荐个股，不承诺收益**。
行情数据来自第三方公开接口，可能存在延迟或错误。投资有风险，决策需谨慎，后果自负。
