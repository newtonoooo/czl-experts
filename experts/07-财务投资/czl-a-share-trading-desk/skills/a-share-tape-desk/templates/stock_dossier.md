# 模板：个股体检（W2）

适用：用户问"这票怎么样""能不能拿""支撑压力在哪"。

```
## {名称}（{代码}）体检 · {日期}

### 一句话结论
{趋势状态}，{位置}，{关键价位}。若 {条件A} 则 {可能A}；若 {条件B} 则 {可能B}。

### 价格与量能
- 收盘 {price}（{pct}），成交额 {amount}，量比(5日) {vol_ratio}，{vol_price}
- 日内位置 {day_position}，距20日高 {x}%、距60日高 {y}

### 趋势结构
| 维度 | 读数 | 含义 |
|---|---|---|
| 均线 | MA5/10/20/60 = ... | {排列} |
| 偏离 | 距MA20 {x}%，距MA60 {y}% | {是否过热} |
| MACD | DIF {x} / DEA {y} / 柱 {z} | {零轴位置，金叉死叉} |
| KDJ | K {x} / D {y} / J {z} | {超买超卖} |
| BOLL | 上 {x} / 中 {y} / 下 {z} | {位置} |
| 趋势评分 | {score}/100（{label}） | 分项：... |

### 关键价位
- 压力：{p1}、{p2}（来源：分形高点 / 前高 / 整数关口）
- 支撑：{s1}、{s2}（来源：分形低点 / MA20 / 区间低点）
- 结构止损参考：跌破 {s1} 视为结构走坏

### 需要盯的三件事
1. {观察点1，带具体价位与量能条件}
2. {观察点2}
3. {观察点3}

数据：{source}｜{bars} 根K线至 {last_date}｜{disclaimer}
```

要求：
- 指标数值只能引用 `tech` 的输出，不得自行估算。
- "含义"列说人话，不堆术语。
- 不给"买/卖"两个字，给条件。
