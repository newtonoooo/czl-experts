# 情绪评分规则（可复算）

六项加权，总分 0–100。每一项的原始计数都会打印在报告里，用户可以自己核对。

| 分项 | 权重 | 计算 | 说明 |
|---|---|---|---|
| 涨跌家数 | 25 | 上涨占比在 0.15–0.75 之间线性映射到 0–100，再乘 0.25 | 0.15 视为冰点，0.75 视为普涨 |
| 涨停跌停 | 20 | `50 + 16×ln(1+涨停) − 22×ln(1+跌停)`，截断到 0–100 后乘 0.20 | 对数缩放，避免几十家涨停就把分数顶满；跌停惩罚更重 |
| 指数 | 15 | 三指数平均涨跌幅在 −1.5%~+1.5% 线性映射后乘 0.15 | 上证、深证成指、创业板指等权 |
| 赚钱效应 | 15 | (涨超5%家数 − 跌超5%家数)/有效家数×100，在 −8~+8 线性映射后乘 0.15 | 比单纯涨跌家数更贴近"今天做多能不能赚钱" |
| 量能 | 15 | 两市成交额 / 近5日均额，在 0.7–1.4 线性映射后乘 0.15 | 本地样本不足 3 天时按中性 50 计 |
| 中位涨幅 | 10 | 个股涨跌幅中位数在 −1.5%~+1.5% 线性映射后乘 0.10 | 用中位数而非均值，避免被个别极端票带偏 |

## 温度分档

| 总分 | 温度 | 含义 |
|---|---|---|
| < 20 | 冰点 | 普跌，情绪极度低迷 |
| 20–40 | 偏冷 | 跌多涨少，赚钱难 |
| 40–60 | 中性 | 涨跌均衡，看个股 |
| 60–80 | 偏热 | 涨多跌少，主线清晰 |
| ≥ 80 | 过热 | 普涨，短线风险在积累 |

## 风险等级（与温度分开，不重复计算情绪）

加分项：

| 条件 | 分 |
|---|---|
| 温度 ≥85 或 ≤15 | +2 |
| 温度 ≥75 或 ≤25 | +1 |
| 跌停家数 ≥20 | +2 |
| 跌停家数 ≥8 | +1 |
| 任一指数跌幅 ≤−1.5% | +1 |
| 跌超5%家数 ≥ 有效家数×15% | +1 |

| 合计 | 等级 | 说明 |
|---|---|---|
| ≥4 | 高 | 波动与分化同时放大，追高的回撤风险显著 |
| 2–3 | 中 | 结构性行情，方向对了才赚钱 |
| ≤1 | 低 | 情绪与波动都在正常区间，容错相对高 |

## 建议仓位上限

| 温度 | 上限 | 附加规则 |
|---|---|---|
| 冰点 | 20% | 风险等级为"高"时再打七折（实际 ≤40% 后再 ×0.7） |
| 偏冷 | 30% | 同上 |
| 中性 | 50% | 同上 |
| 偏热 | 60% | 同上 |
| 过热 | 30% | 过热反向收紧，兑现优先于加仓 |

## 这个分数不能做什么

- **不能预测**：它描述当前状态，不含任何未来信息。
- **不能替代个股判断**：指数平稳但个股分化时，情绪分可能很高而你的票在跌。
- **量能项在头几天不完整**：全市场成交额的历史基准是本地逐日累积的，样本不足 3 天时该项按中性计，
  报告里会写明"历史样本不足"。这是刻意设计的诚实降级，不是 bug。
- **涨停家数依赖涨跌停价重算**：新股上市首日无涨跌幅限制、除权日限制价会偏移，这两种情况可能少算或多算，
  误差通常在个位数家，不影响温度档位判断。
