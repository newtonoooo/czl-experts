# 变更日志

格式参考 Keep a Changelog，版本号遵循语义化版本（MAJOR.MINOR.PATCH）。

## [1.0.0] - 2026-10-27

首个公开发布版本。全新独立开发，非任何现有专家的改写或改名版本。

### 新增 · 数据引擎（`skills/a-share-tape-desk/scripts/atd/`）

- `codes`：沪深A股代码解析，主板/创业板/科创板识别，涨跌幅限制比例（含 ST 差异化），
  涨跌停价按分取整计算；北交所、港股、美股一律拒绝并给出原因。
- `net`：HTTP 层，含主机健康度（连续失败 2 次冷却 90 秒）、退避重试、磁盘与内存双层缓存、
  统一的抓取时间戳记录。
- `quotes`：腾讯行情主源 + 新浪备源，批量快照；涨跌幅/振幅/日内位置/跳空按原始价格重算，
  与厂商字段交叉校验并标注差异。
- `history`：前复权日线，腾讯主源 + 东方财富备源。
- `indicators`：MA/EMA/MACD/KDJ/RSI/BOLL/ATR 纯 Python 实现，分形支撑压力、量价关系、
  趋势评分（-100~+100），全部可复算。
- `market`：全市场分页扫描（5576 只，10 线程，实测 2.07 秒），本地统计涨跌家数、涨跌停家数、
  涨跌分布、成交额、赚钱效应，输出情绪温度、风险等级与建议仓位上限。
- `sectors`：行业 49 个 + 概念 175 个板块排行，龙头按「涨幅55%+成交额分位25%+换手分位12%+涨停8%」评分，
  板块历史逐日累积以判断连续上榜。
- `risk`：先定亏损再定仓位的仓位算法，ATR 止损，R 倍数止盈，0 股时给"最小可行规模"，
  组合层面同时止损的总敞口核算。
- `watch`：结构化 JSON 预警清单，8 种条件类型，跨对话可核对。
- `clock`：交易时段判定（盘前/竞价/早盘/午休/午盘/收盘竞价/已收盘/休市），
  已走完交易分钟数，数据性质（实时/定格/历史）判定。
- 命令行入口 `tapedesk.py`：`session` / `quote` / `tech` / `pulse` / `sectors` / `plan` /
  `watch` / `doctor` 共 8 个子命令，全部支持 `--json`。

### 新增 · 专家行为（`agents/`）

- 七条工作流：W0 接入路由、W1 行情速查、W2 个股体检、W3 大盘情绪、W4 板块龙头、
  W5 交易计划、W6 预警盯盘、W7 收盘复盘。每条含职责、输入、步骤、判断条件、输出、异常、依赖。
- 合规约束写进行为：不荐股、不承诺收益、不代客下单，拒绝操纵类请求；
  所有价格判断附风险提示；数据时间与性质必须标注。
- 统一降级表：接口失败先自检再如实告知，禁止用记忆中的价格替代。

### 新增 · 文档与测试

- `references/data-sources.md`：5 类接口的地址、字段映射、实测时间、编码与请求头要求。
- `references/indicator-math.md`：指标公式与国内软件口径对齐说明。
- `references/sentiment-rubric.md`：情绪评六项权重、温度分档、风险等级、仓位上限的完整规则。
- `references/risk-and-compliance.md`：仓位算法、合规红线、表述替换表、算法边界。
- `templates/`：行情速查、个股体检、大盘情绪、板块龙头、交易计划五类输出骨架。
- `tests/selftest.py`：25 个离线用例，覆盖代码解析、报文字段映射、指标、仓位、评分、预警、时段。
- `docs/`：使用说明、平台展示文案、开发记录、文件清单、功能测试报告、商业发布风险清单。
- `tools/png_crop.py`：零依赖 PNG 裁切/缩放/量化工具（构建头像用）。

### 已知限制（首个版本的诚实边界）

- 量能项依赖本地逐日累积的全市场成交额，前 3 个交易日内按中性 50 分计。
- 板块持续性需要多日样本，第 1 天只能标"需次日验证"。
- 涨停家数按涨跌停价重算，新股上市首日与除权日可能偏差。
- 未接入分时数据与龙虎榜；`history` 未使用分钟级数据。
- 预警为对话内核对，非服务器级实时推送。

### 未做（明确排除，避免误导）

- 不做基本面估值、不做财报分析、不做组合优化——这些属于其他类型的产品。
- 不做港股、美股、北交所、可转债、期货、基金。
