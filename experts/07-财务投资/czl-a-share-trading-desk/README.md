# 盘锋 · 专业A股盘中交易参谋

> Czl A Share Trading Desk · v1.0.0 · 开发者：虫志龙（47190078@qq.com）

一个盯盘的参谋，不是荐股的机器。

它只做三件事：把盘面数据取准、把能算的算清楚、把话说得让人能自己复核。
价格、涨跌幅、技术指标、大盘情绪分、仓位股数——全部由脚本计算，不靠模型估。

---

## 一、它与"研究型"专家的区别

| | 盘锋（本专家） | 研究定价类 | 投研决策类 |
|---|---|---|---|
| 回答的问题 | 现在什么位置、多少仓位、亏多少走 | 这家公司值多少钱 | 该不该配置、组合怎么调 |
| 时间尺度 | 当日到数周 | 季度到数年 | 季度到数年 |
| 核心产出 | 交易计划、情绪温度、板块龙头、预警 | 估值与安全边际 | 决策矩阵与仓位建议 |
| 数据重心 | 价、量、结构、全市场广度 | 财报、行业、可比公司 | 多角色交叉论证 |

盘锋不判断公司好坏，只判断"现在这个位置，用什么条件参与、用多少仓位、在哪里认错"。

## 二、六项能力

1. **实时行情** — 批量取沪深A股快照，含涨跌停价、换手、量比、PE/PB、市值。
   涨跌幅与振幅按价格重算，与厂商字段交叉校验，不一致就标注。
2. **技术体检** — 前复权日线上本地计算 MA/EMA/MACD/KDJ/RSI/BOLL/ATR，
   给出均线排列、量价关系、分形支撑压力、趋势分（-100~+100）。
3. **大盘情绪** — 每轮拉全市场 5500+ 只个股（约 2 秒），自己数涨跌家数、涨跌停家数、
   涨跌分布、成交额、赚钱效应，压成 0-100 情绪温度、风险等级与建议仓位上限。规则全部公开可复算。
4. **板块与龙头** — 行业 49 个 + 概念 175 个板块排行；
   龙头按"涨幅 55% + 成交额分位 25% + 换手分位 12% + 涨停 8%"评分，不是"谁涨得最高谁就是龙头"。
5. **交易计划** — 先定亏多少再定买多少：单笔风险预算 → 可买股数 → 仓位占比 → R 倍数止盈位。
   算不出整手时给"最小可行规模"，不只说一句买不了。
6. **预警清单** — 结构化 JSON，8 种条件（突破/跌破/涨幅/跌幅/涨停/跌停/量比/成交额），
   跨对话可核对、可留痕。

## 三、七条工作流

| 编号 | 名称 | 输入 | 输出 |
|---|---|---|---|
| W0 | 接入与路由 | 用户意图 | 一句话确认 + 走哪条流程 |
| W1 | 行情速查 | 代码 | 快照表 + 位置描述 |
| W2 | 个股体检 | 代码（可含成本） | 趋势表 + 关键价位 + 观察点 |
| W3 | 大盘情绪 | 无 | 温度/风险/仓位上限 + 结构表 |
| W4 | 板块龙头 | 可选方向 | 强度表 + 龙头候选 + 主线判定 |
| W5 | 交易计划 | 代码 + 资金 + 风险偏好 | 计划表 + 触发条件 + 放弃条件 |
| W6 | 预警盯盘 | 代码 + 条件 | 触发/未触发明细 |
| W7 | 收盘复盘 | 可选持仓 | 盘面 + 持仓 + 明日观察点 |

## 五、技术实现

```
czl-a-share-trading-desk/
├── .codebuddy-plugin/plugin.json     专家元数据
├── agents/czl-a-share-trading-desk.md  角色与七条工作流提示词
├── skills/a-share-tape-desk/
│   ├── SKILL.md                       技能调用说明与异常降级表
│   ├── scripts/tapedesk.py            命令行入口（8 个子命令）
│   ├── scripts/atd/                   数据引擎（10 个模块）
│   ├── references/                    数据源、指标公式、情绪规则、风控与合规
│   ├── templates/                     五类报告输出骨架
│   └── tests/selftest.py              25 个离线用例
├── avatars/                           原创头像（512×512）
├── tools/png_crop.py                  零依赖图像裁切工具（构建用）
└── docs/                              使用说明、开发记录、测试报告、风险清单
```

- **运行时零第三方依赖**：只用 Python 3.8+ 标准库（urllib / json / concurrent.futures / zlib）。
- **数据源**：腾讯行情（主）→ 新浪行情（备）→ 东方财富（备）。
  主机连续失败 2 次自动冷却 90 秒，所有请求带退避重试与本地缓存。
- **可复算**：情绪分、趋势分、仓位股数的每一项权重都写在 `references/` 里，用户能自己核对。

## 六、能力边界（请务必读）

- 数据来自公开行情接口，**没有 SLA、没有书面授权**，可能延迟或临时不可用。
- 情绪分描述的是"当前状态"，**不含任何预测信息**；量能项在本地历史不足 3 天时按中性计。
- 涨停家数按"昨收 × 板块限制比例"重算，新股上市首日（无涨跌幅限制）与除权日可能偏差。
- 仓位算法不含滑点、佣金、印花税；A 股 T+1，当日买入当日不能卖，止损只能次日执行。
- 预警是对话内核对，**不是服务器级实时推送**；秒级提醒请用券商 App。

## 七、合规声明

本专家输出的一切内容均为公开数据与规则化计算的结果，**不构成投资建议，不推荐个股，不承诺收益**。
投资有风险，决策需谨慎。使用者应自行判断并承担全部后果。
