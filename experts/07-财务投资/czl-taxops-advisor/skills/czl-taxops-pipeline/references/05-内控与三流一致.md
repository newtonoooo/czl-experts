# 05 内控与三流一致

小企业的内控不是制度汇编，是**四个开关**：钱、票、章、人。这四个开关里有任何一个落在同一个人手上，其他制度写得再漂亮也拦不住。

## 一、四把钥匙

| 钥匙 | 管什么 | 最小可行控制（10 人以下也做得到） |
| --- | --- | --- |
| **钱** | 银行账户、U 盾、备用金、收款码 | 网银 U 盾分人保管（制单与复核分开）；付款需两人以上可见；禁止用个人账户收公司货款 |
| **票** | 发票开具、作废、红冲、进项取得 | 开票与收款核对；作废红冲需审批留痕；进项发票登记台账 |
| **章** | 公章、财务章、法人章、合同章 | 三章不同人保管；用章登记；合同用章与财务用章分离 |
| **人** | 岗位、权限、交接 | 出纳不管账、会计不管钱；离职当日交接并改密码；财务系统权限按岗位给，不给"全权限"账号 |

判断方法很简单：**问一句"这件事如果他想做坏事，有没有第二个人会在过程中看到"**。没有，就是缺口。

## 二、五个环节，每个只记三个控制点

不要给用户一份 80 项的清单，他一项都不会做。每个环节给三个点，是他明天就能改的。

### 销售与收款

1. **订单、发货、开票、收款四处记录能对上**：客户名、金额、日期四栏能相互勾稽。
2. **折扣与退货必须有审批**：销售自己批折扣，等于没有毛利管理。
3. **收款与应收台账每月对一次**：以银行流水为准对台账，不以台账为准。

常见失守点：销售用个人微信收货款，月底才转公司账户；坏账核销由销售提、销售批。

### 采购与付款

1. **三单匹配**：采购申请（或合同）、入库验收单、发票，三者齐全才付款。
2. **供应商准入有比价记录**：哪怕只是两家报价的微信截图，也要留。
3. **大额付款双人复核**：金额门槛按公司规模定，5 万或 10 万，写进制度。

常见失守点：先付款后补单；关联方供应商未披露；同一供应商拆单规避审批门槛。

### 费用报销

1. **制度先有标准**：差旅、招待、交通的限额写清楚，没有标准的报销必然靠人情。
2. **票据与业务对应**：发票内容要能说明"为什么发生这笔支出"，只有一张餐饮发票说明不了。
3. **抽查机制**：每月抽查 10% 的单据，抽查人不能是报销人本人。

常见失守点：同一张发票重复报销（跨月最容易）；抬头是个人；把家庭消费混进公司账。

### 资金管理

1. **银行余额调节表按月做**：这是发现问题的第一道筛子，比任何制度都快。
2. **现金日清月结**：有备用金的必须盘点，签字。
3. **无账外资金**：私户收款、小金库，既是内控问题也是税务问题，一旦形成规模就是A级风险。

### 发票管理

1. **开票与实际业务一致**，品名、数量、金额不得"按客户要求"改。
2. **进项发票当月登记**，防止跨年找不到票、或收到失控票。
3. **作废与红冲有审批链**，且红冲原因要写清（退货、折让、开错）。

## 三、三流一致核查表

金税环境下，"合同、发票、资金"三条线指向同一个交易，是最基础的合规要求。不一致不必然违规，但**没有书面解释的不一致，在检查中很难自证**。

| 核对项 | 一致的标准 | 不一致时的合规处理 |
| --- | --- | --- |
| 主体 | 合同签约方、发票购销方、收付款账户名，三者同一 | 委托付款/收款：需三方协议或书面授权，注明"代收代付" |
| 金额 | 合同金额、发票价税合计、银行流水金额相符 | 分期、折让、质保金：需在合同或补充协议中约定 |
| 时间 | 业务发生、开票、收付款在合理期间内 | 跨期：留存发货单、验收单、结算单证明业务实际发生时间 |
| 内容 | 发票品名与合同标的、实际交付物一致 | 变更：需有变更协议；不得以"开票方便"改品名 |
| 流向 | 货物/服务的实际流向与合同一致 | 直发、代发：需在合同中约定交付方式 |

**四种最常见的不一致，及处理建议**：

1. **老板私户收款**（A 级）：收入不入账，同时触发增值税、企业所得税、股东个税风险。处理方向是停止 + 补记 + 评估补申报，而不是继续"过渡一下"。
2. **员工垫付后公司还款**：属正常，但要有报销单 + 发票 + 付款记录三件套，不能用"备用金"长期挂账。
3. **集团内代付**：需集团统一协议，注明代付范围与结算方式。
4. **供应商要求打到第三方账户**：要求供应商出具加盖公章的委托收款说明，否则不付。

## 四、报销审核：五看一查

审核一张报销单，按固定顺序看五处，再查一次：

1. **看抬头**：公司全称与纳税人识别号是否与营业执照一致。错一个字都不能抵进项、不能税前扣除。
2. **看内容**：品名与报销事由是否同一件事。办公用品发票报"客户招待"，是典型的票实不符。
3. **看金额**：单价 × 数量 = 金额，金额 + 税额 = 价税合计。三处必须自洽。
4. **看税率**：销售方适用税率是否合理。小规模开 13% 的专票，基本可以确定票有问题。
5. **看日期**：开票日期是否在业务发生期间内，是否超出公司报销时限（常见 30/60/90 天）。
6. **查一次真伪**：全国增值税发票查验平台，输入代码、号码、日期、金额（部分需校验码）。截图附在报销单后。

**不合规的六种情形及处理**：

| 情形 | 处理 |
| --- | --- |
| 抬头错误、税号错误 | 退回换开，不得自行涂改 |
| 无清单的汇总票（"办公用品一批"） | 要求补开清单，或换开明细 |
| 重复报销 | 建立发票号码台账，报销前查重 |
| 作废票、红冲票 | 不得报销，退回重开 |
| 开票时间与业务时间严重不符 | 要求说明，跨年调整需评估税前扣除年度 |
| 疑似虚开（无真实交易、资金回流） | 停止付款，不得抵扣，必要时向主管税务机关说明 |

## 五、30 天起步包

给没有内控的小公司，按这个顺序做，一个月能落地：

| 周 | 动作 | 验收标准 |
| --- | --- | --- |
| 第 1 周 | 把付款审批门槛写下来（多少钱谁批） | 一张纸，老板签字，全员知晓 |
| 第 2 周 | U 盾分人、财务系统权限按岗拆 | 出纳无法自己制单自己复核 |
| 第 3 周 | 建发票台账 + 报销前查重 | 台账能按发票号检索 |
| 第 4 周 | 做一次银行余额调节表 | 账实差异能逐笔说明 |

做完这四件事，再谈制度文本。反过来做（先写制度再落地）通常三个月后制度还在文件夹里。

```
【内控检查】环节：采购付款   检查人：___   期间：___

结论：□正常  □基本正常（3 项待改进）  □存在重大缺陷

主要发现（按风险分级）
A 级｜付款无入库验收单，9 月有 4 笔合计 18.6 万元直接付款
     整改：10 月 15 日前补验收记录；此后无验收单不予付款（责任人：___）
B 级｜供应商比价记录缺失，仅 1 家报价
     整改：11 月起 5 万元以上采购须两家报价（责任人：___）
C 级｜付款申请单未编号，不便追溯
     整改：12 月起启用连续编号（责任人：___）

验收方式：下月抽查 10 笔付款，三单齐全率应达 100%
```
