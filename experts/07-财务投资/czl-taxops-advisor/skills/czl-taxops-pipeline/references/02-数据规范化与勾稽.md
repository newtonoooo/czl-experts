# 02 数据规范化与勾稽

中小企业报表最常见的三个问题，都不是"分析错了"，而是"数进来就是错的"：单位混着用、期间不是一个点、小计不等于明细之和。这一节先把这三件事做干净。

## 一、五项规范化

| 项目 | 常见脏数据 | 处理动作 |
| --- | --- | --- |
| 单位 | 利润表用元，资产负债表用万元；口述用"万" | 全部折成**元**再算，输出时按需换算，并在表头写"单位：元" |
| 期间 | 利润表 9 月，资产负债表误用 8 月末 | 两者必须同一时点口径：利润表本期，资产负债表期末 |
| 正负号 | 成本费用有的填正数有的填负数 | 统一为**成本费用正数列示**，计算时做减法 |
| 含税口径 | 收入填的是开票金额（含税） | 含税收入 ÷（1＋税率）还原为不含税，再算毛利率 |
| 空值 | 空单元格与 0 混用 | 空＝未知（跳过该项检查），0＝确定为零（参与计算）。两者不能混 |

单位错位是最贵的错误：一份万元口径的表被当成元来算，资产负债率会算成 0.008%，看着像没问题，其实是没算。

## 二、勾稽检查清单

按顺序跑，前面的错了，后面的不用看。

### 1. 资产负债表

| 编号 | 关系式 | 不平时的含义 |
| --- | --- | --- |
| B1 | 资产总计 ＝ 负债合计 ＋ 所有者权益合计 | 录入错误、漏项、或未结转损益 |
| B2 | 资产总计 ＝ 流动资产合计 ＋ 非流动资产合计 | 明细汇总错，或有科目未归类 |
| B3 | 负债合计 ＝ 流动负债合计 ＋ 非流动负债合计 | 同上 |
| B4 | 货币资金 ≥ 0，且 ≤ 流动资产合计 | 现金为负说明账务处理有误（除非有透支科目单列） |

### 2. 利润表（阶梯逐级验算）

```
营业利润 = 营业收入 − 营业成本 − 税金及附加 − 销售费用 − 管理费用 − 研发费用 − 财务费用 + 投资收益
利润总额 = 营业利润 + 营业外收入 − 营业外支出
净利润   = 利润总额 − 所得税费用
```

三项都要单独验。只验最后一项"净利润"是不够的——中间某一级错了、上下相互抵消的情况真实存在。

### 3. 现金流量表

| 编号 | 关系式 |
| --- | --- |
| C1 | 经营净额 ＋ 投资净额 ＋ 筹资净额 ＝ 现金及现金等价物净增加额 |
| C2 | 期初现金 ＋ 净增加额 ＝ 期末现金，且期末现金与资产负债表货币资金衔接（允许因受限资金产生差异，差异需说明） |

### 4. 跨表合理性（不是等式，是预警）

| 检查 | 触发条件 | 含义 |
| --- | --- | --- |
| 毛利异常 | 毛利率 ＞ 80% 或 ＜ −20% | 可能是含税未还原、成本漏记、或行业特殊（软件、咨询毛利率高属正常） |
| 利润与现金背离 | 经营现金流与净利润差异率 ＞ 50% | 应收激增、存货积压、或收入确认偏早 |
| 费用率突变 | 某费用占收入比重环比变动 ＞ 5 个百分点 | 一次性支出、口径变化、或分类错 |
| 存货与成本背离 | 收入下降但存货上升 | 滞销或成本结转不足 |

## 三、工具输入字段表

`toolkit.py check` 与 `toolkit.py ratios` 共用同一个 JSON。字段名必须完全一致，缺失字段会被跳过而不是报错。

```json
{
  "unit": "元",
  "period": "2026-09",
  "days": 30,
  "balance_sheet": {
    "货币资金": 0,
    "应收账款": 0,
    "存货": 0,
    "流动资产合计": 0,
    "非流动资产合计": 0,
    "资产总计": 0,
    "流动负债合计": 0,
    "非流动负债合计": 0,
    "负债合计": 0,
    "所有者权益合计": 0
  },
  "income_statement": {
    "营业收入": 0,
    "营业成本": 0,
    "税金及附加": 0,
    "销售费用": 0,
    "管理费用": 0,
    "研发费用": 0,
    "财务费用": 0,
    "投资收益": 0,
    "营业利润": 0,
    "营业外收入": 0,
    "营业外支出": 0,
    "利润总额": 0,
    "所得税费用": 0,
    "净利润": 0
  },
  "cash_flow": {
    "经营活动现金流量净额": 0,
    "投资活动现金流量净额": 0,
    "筹资活动现金流量净额": 0,
    "现金及现金等价物净增加额": 0
  },
  "prior": {
    "balance_sheet": { "应收账款": 0, "存货": 0, "资产总计": 0, "所有者权益合计": 0 }
  }
}
```

说明：

- `prior` 放期初数，只有算平均余额类指标才需要。没有就省略，工具会退化为期末值口径并自动标注。
- `days` 是期间天数，月度填 30（或实际天数），季度 90，年度 365。周转天数依赖它。
- 单位写"元"或"万元"都行，但整份 JSON 只能用一个单位。
- 不要往 JSON 里写注释、千分位逗号、百分号。`1,200,000` 和 `12%` 都会导致解析失败。

## 四、差异定位法

勾稽不平的时候，别急着重录整张表。按这个顺序找，通常三步内定位：

1. **看差异金额的量级**。差 1 分钱：四舍五入。差整数（如 10,000、100,000）：某一笔漏记或多记。差额无规律：汇总口径错。
2. **看差额是否等于某个科目**。资产比负债＋权益多 58,000，去找有没有一笔 58,000 的费用没结转、或预付款没入账。
3. **看是否有跨期项**。上月计提本月支付、预付摊稍、收入跨月确认，都会让单月报表不平，但年度能平。这类差异要标"跨期项，年度可平"，而不是当错误。

三种情况都排除后仍不平，就如实写「差异 XX 元，未能定位」，并在交付物里把它列为待核事项。**不要为了让表平掉去调一个"其他"科目**——这是把问题埋起来，下次还会以更大的形式出现。

## 五、体检结果怎么呈现

不要输出"全部通过"就完事。按三档呈现：

```
【数据体检】2026年9月，单位：元
✓ 通过（5项）：B1 资产负债平衡、B2 资产分类、B3 负债分类、利润表三级阶梯、C1 现金三项合计
⚠ 差异（2项）：
   B4 货币资金 −3,200，流动资产品合计 128,000 → 差额可解释为信用卡透支未单列，建议核对
   毛利异常 毛利率 91%，营业收入 260,000，营业成本 23,400 → 请确认收入是否为含税口径
✗ 无法判断（1项）：C2 期末现金衔接，缺期初现金数据
```

每一项差异后面都要跟"最可能的原因"和"你需要做什么"。只报错不给出路的体检表，用户看一眼就关掉了。

## 六、放行判断

| 状况 | 是否进入 G2 |
| --- | --- |
| 全部通过 | 进入 |
| 有差异但已解释，且不影响盈利与现金结论 | 进入，在交付物中注明 |
| 资产负债不平 | **不进入**，先定位 |
| 利润表阶梯不平 | **不进入**，先定位 |
| 收入口径存疑（含税未还原） | 先确认口径再进入，否则毛利率结论必然错 |
