# 07 场景剧本

每个剧本四段：**听出什么信号 → 走哪几个阶段 → 关键判定 → 容易答错的地方**。照着走，比自由发挥稳。

---

## 剧本 1｜"这个月赚没赚钱？"

**信号**：老板只问利润，不看表；或者直接把利润表截一段发来。

**路径**：G1（只做利润表三级阶梯 + 收入口径）→ G2（结构 + 现金交叉）

**关键判定**
- 先确认收入是否含税。老板口述的"卖了一百万"九成是含税。未还原就报毛利率，一定虚高。
- 利润要和现金对一次。净利润 5 万但经营现金流 −8 万，回答"赚没赚钱"就必须分两句说。
- 问一句"你说的赚，是账面赚还是钱到手"。这不是废话，是把他的模糊问题变成可回答的问题。

**交付**：一页纸（收入 / 净利 / 现金三个数 + 一句归因 + 一件要做的事）

**容易答错**：直接回"净利率 4.9%，盈利能力偏弱"。老板不知道 4.9% 是好是坏，而且这个判断没有参照系。

## 剧本 2｜"账上没钱，但报表是赚的"

**信号**：利润为正、货币资金很低，老板觉得账做错了。

**路径**：G1（现金流量表 + 资产负债表衔接）→ G2（现金转换周期）

**关键判定**
1. 差额去哪了：应收增加、存货增加、还了应付、买了设备、还了贷款——五选一或几项组合，用资产负债表变动逐项对。
2. 算现金转换周期 = 应收天数 + 存货天数 − 应付天数。正得越大，越说明在给上下游垫钱。
3. 区分"暂时性"与"结构性"：旺季备货导致的占用是暂时性；应收天数从 45 天涨到 90 天是结构性。

**交付**：「利润到现金的桥」表——净利润起，逐项加回/减去营运资金变动与资本支出，落到经营现金流。

**容易答错**：说"这是应收账款管理问题"就收尾。要给出具体是哪几个客户、多少金额、超期多久。

## 剧本 3｜"供应商让我打到他私人账户"

**信号**：要求付款到非合同主体；或以"便宜两个点"为诱饵。

**路径**：G3（三流一致）→ G4（内控动作）

**关键判定**
- 三流不一致：合同方 A、收款方个人 B、发票开具方 A。这种组合没有书面授权，进项抵扣与税前扣除都可能被质疑。
- 更严重的情形：资金最终回流到公司相关人员，可能构成虚开或抽逃。
- 合规替代：要求对公收款；确需第三方的，取得加盖公章的《委托收款说明》，注明委托关系、金额、期限，并留存业务真实性证据（送货单、验收单）。

**交付**：一句话结论（能不能付）+ 需要补的三份文件 + 内控动作（把"非合同主体收款需书面授权"写进付款流程）

**容易答错**：只说"有风险，建议谨慎"。要给"付/不付"的明确判断和补齐路径。

## 剧本 4｜"发票开错了"

**信号**：抬头错、税率错、金额错、客户退票、跨月才发现。

**路径**：G1（票据分支）

**关键判定**
- 分四个象限：当月未认证 / 当月已认证 / 跨月未认证 / 跨月已认证。处理方式不同。
- 当月且未认证：作废重开。跨月或已认证：红字冲销后重开。跨年红冲的所得税影响需单独评估。
- 受票方角度：抬头或税号错误必须退回换开，不得自行涂改；涂改票不能抵扣、不能税前扣除。
- 谁的责任：开票方错 → 开票方红冲；受票方提供信息错 → 受票方出说明，仍需开票方操作。

**交付**：处理步骤（三步内）+ 需要留存的三份材料（红字信息表/情况说明/新票）

**容易答错**：一律说"作废重开"。跨月的作废是违规操作。

## 剧本 5｜"要不要升一般纳税人"

**信号**：客户要专票；或销售额接近 500 万；或同行都升了。

**路径**：G3（身份分支 + 税负测算）

**关键判定**
1. 算临界点：可抵扣采购占销售额比重 vs（销项税率 − 征收率）÷ 销项税率。13%/3% 对应约 77%。
2. 但先问客户结构：收入里有多大比例来自必须要专票的客户。这一条经常直接决定答案。
3. 问进项取得能力：上游是小作坊、个体户、自然人，测算里的"可抵扣"就是假的。
4. 说清单向门：登记后通常不能转回，这是不可逆决策。

**交付**：测算表（两种身份下的税负对比）+ 三条非税因素 + 一句结论

**容易答错**：只算税。或者承诺"升了能省 X 万"，税负受经营结构影响，不能承诺。

---

## 剧本 6｜"个体户，核定还是查账"

**信号**：新办个体户、工作室、小店；或收到税务通知要求建账。

**路径**：G3（身份 + 征收方式分支）

**关键判定**
- 核定征收：按核定的应税所得率或定额缴税，账务要求低，但成本票多的行业会吃亏（实际利润低于核定利润率时，核定反而多缴）。
- 查账征收：按实际利润计税，能享受小微优惠，但需要建账、票据齐全。
- 判断依据：毛利率水平、成本票据取得率、营业额规模、当地是否还批核定。
- 重要提醒：核定不等于不用记账。连续超限额、被要求建账而不建，会转查账并可能追溯。

**交付**：两种方式下的税负测算 + 选择建议 + 需要准备的材料清单

**容易答错**：说"核定更省事所以选核定"。省事和省钱经常是两件事。

## 剧本 7｜"员工报销拿不到发票"

**信号**：小额零星支出、向个人采购、临时用工、农村采购农产品。

**路径**：G3（发票分支）→ G4（制度动作）

**关键判定**
- 分三类：能取得发票的（必须取得）/ 依法可不用发票的（小额零星经营业务，凭收款凭证及内部凭证）/ 无法取得但真实发生的（做纳税调增，不能硬凑票）。
- 小额零星的标准与适用条件有明确规定，具体金额上限需核对当期口径，不要凭记忆报数。
- 红线：买票、找票、虚开。这类"解决方案"一律不给，直接说后果。

**交付**：三类情形对照表 + 一份《无票支出处理办法》（含审批层级与调增处理）+ 内部凭证模板要素

**容易答错**：一句"没有发票不能报销"。真实业务无票也能入账，只是税前不能扣，两件事要分开说。

## 剧本 8｜"税负率被预警了"

**信号**：电子税务局推送风险提示；或专管员约谈；或同行说"你税负太低了"。

**路径**：G3（税负分析）→ G2（经营解释）→ G4（应对动作）

**关键判定**
1. 先算清楚是哪个口径的税负率（增值税税负 = 应纳增值税 ÷ 不含税收入；企业所得税税负 = 应纳所得税 ÷ 收入），预警针对的通常是增值税。
2. 找合理解释：库存积压（进项留抵）、大额设备采购、季节性、客户结构变化、免税项目占比上升。这些都能解释低税负，且是真实原因。
3. 排除真问题：未开票收入未申报、进项不合规、视同销售漏报。
4. 应对：准备书面说明 + 支撑材料（合同、库存表、采购发票），主动沟通优于被动等。

**交付**：税负率测算 + 原因清单（合理/需整改分开）+ 说明材料清单

**容易答错**：建议"多开点票把税负做上去"。这是最危险的错误答案，等于建议虚开。

## 剧本 9｜"这个季度申报来不及了"

**信号**：临近 15 日、账没做完、发票没归集、人不在。

**路径**：G3（申报节奏分支，轻量）

**关键判定**
- 先确认是否真的来不及：多数税种的申报可以在数据不完整时先按已确认数申报，后续更正。
- 分清"逾期申报"与"逾期缴纳"：两者的后果不同（前者影响信用记录，后者产生滞纳金，按日万分之五）。
- 分清"可以更正"与"不能马虎"：增值税、企税预缴通常可更正申报；但连续零申报、长期亏损会引起关注。
- 确实无法按期：了解当地是否可申请延期申报（需符合条件并获批），不要自行"忘记"。

**交付**：三步应急清单（今天做什么、明天做什么、节后补什么）+ 逾期后果说明

**容易答错**：教用户"先零申报应付过去"。零申报是虚假申报，性质比逾期严重。

## 剧本 10｜"想给团队定预算，从哪开始"

**信号**：第一次做预算；或去年预算做完就没人看。

**路径**：G4（预算分支）

**关键判定**
1. 先定用途：是为了控制费用，还是为了排资金，还是为了考核。三种目的预算表结构不同。
2. 没有历史数据就做零基预算（从零论证每一笔），不要拍脑袋填增长率。
3. 颗粒度：20 人以下公司，预算科目不超过 20 行；行数太多必然没人维护。
4. 落地机制比表格重要：谁填、每月几号对、差异谁解释、超了怎么办。没有这四条，预算表第二个月就作废。

**交付**：预算骨架表（可直接填）+ 编制说明（每行填什么、数据从哪来）+ 月度差异分析表 + 一套运行规则

**容易答错**：给一张几十行的 Excel 就说"这是预算模板"。模板不解决运行问题。

## 剧本 11｜"股东借钱挂在其他应收款"

**信号**：其他应收款科目余额大且长期不变；股东个人消费由公司支付。

**路径**：G1（科目核查）→ G3（个税风险）→ G4（处理动作）

**关键判定**
- 股东借款年度终了未归还且未用于生产经营，可能被视为股息红利分配，按 20% 计征个人所得税。这是明确的规则，不是"可能有风险"。
- 区分性质：真实借款（有合同、有用途、有还款计划）/ 变相分配 / 费用挂账。
- 处理方向：年底前归还；或转为工资薪金（走个税）；或补充借款协议并明确用途与利息。

**交付**：余额与账龄 + 性质判断 + 三条处理路径及各自税负 + 时限提醒（年度终了前）

**容易答错**：说"挂账没事，大家都这么干"。这是实务中被追缴最集中的一项。

## 剧本 12｜"客户要求开票内容改一下"

**信号**："开成办公用品""开成咨询费""多开一点，税点我出"。

**路径**：G3（发票红线）

**关键判定**
- 票实不符即为虚开，不管是"帮忙"还是"客户要求"。开票方与受票方都可能被处罚。
- "多开一点"是虚开金额，涉及税款可能达到刑事门槛。
- 合规替代：如确实存在不同品类的真实交易，按实际拆分开具；如客户需要清单，按汇总开票附清单的规则处理。

**交付**：一句明确结论（不能开）+ 法律后果说明（补税、罚款、信用、涉刑）+ 合规替代方案

**容易答错**：含糊其辞地说"尽量不要"。这类问题必须给明确答案。
