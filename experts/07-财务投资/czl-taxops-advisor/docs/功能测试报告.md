### T05 比率与杜邦

命令：`python ... ratios --file samples/demo-2026-09.json --capex 20000`

实际输出节选：

```
存量类指标口径：平均值（含期初）
【偿债】流动比率 1.67 / 速动比率 1.33 / 资产负债率 50.00% / 现金比率 0.60 / 利息保障倍数 13.33
【营运】应收账款周转天数 3.3 天 / 存货周转天数 2.2 天 / 现金转换周期 —
【盈利】毛利率 26.00% / 营业利润率 6.29% / 净利率 4.93% / ROA 10.98% / ROE 22.55%
【现金】现金含量 −3.30 / 自由现金流（简化）−160,000.00 元
【杜邦拆解】ROE = 净利率 × 总资产周转率 × 权益乘数
  22.55% = 4.93% × 2.23 × 2.05
  校验：直接算 ROE = 22.55%
```

验证要点：
- 杜邦三因子乘积与直接计算的 ROE 一致（22.55%），说明口径统一（全部使用平均余额）。
- 每个指标后附公式，"现金转换周期"因缺应付账款字段显示为 `—` 而非 0。
- 输出末尾固定附"计算口径与读法参考，不构成优劣结论"，防止把工具输出当结论。

### T06 预算差异与量价拆分

命令：`python ... variance --file samples/variance-demo.json`

```
A产品   56,000.00  56,000.00   0.00   0.0%   -6,720.00
        量价拆分：价差 -6,720.00　量差 6,720.00　合计 0.00
B产品  128,000.00 118,800.00  -9,200.00  -7.2%  3,600.00
        量价拆分：价差 3,600.00　量差 -12,800.00　合计 -9,200.00
推广费  20,000.00  31,500.00  11,500.00  57.5%   —
合计差异：2,300.00元　其中价差 -3,120.00　量差 -6,080.00
```

验证要点：
- A 产品总差异为零，但价差与量差各 6,720 反向抵消——这正是量价拆分存在的意义，只看总额会得出"没问题"的错误结论。
- 无数量单价的科目（房租、推广费）自动退化为简单差额，不强行拆分。
- 恒等式成立：价差 + 量差 = 实际 − 预算。

## 四、发布包测试（`build_package.py`）

命令：`python dev/build_package.py czl-taxops-advisor dist`

```
输出：dist/czl-taxops-advisor-v1.0.0.zip
条目：17 个文件
大小：221.1 KB
[PASS] 所有条目位于 czl-taxops-advisor/ 根目录下   18 个文件
[PASS] 能定位到 plugin.json                  czl-taxops-advisor/
[PASS] 头像可按平台规则解析                        avatars/avatar-512.png → czl-taxops-advisor/avatars/avatar-512.png
[PASS] 头像数据非空                            168212 bytes
[PASS] agent 文件在包内                       czl-taxops-advisor/agents/czl-taxops-advisor.md
[PASS] SKILL.md 在包内                      czl-taxops-advisor/skills/czl-taxops-pipeline/SKILL.md
[PASS] 计算工具在包内                           czl-taxops-advisor/skills/czl-taxops-pipeline/scripts/toolkit.py
[PASS] 含 manifest.yaml                   兼容 YAML 读取方
[PASS] 未包含 dev/ 与 docs/（本地工具与交付文档）
[PASS] 解压后总大小 < 5MB                      278.1 KB
包内校验：10/10 通过
SHA256：6b46413cf0cec5817099dc2f28f9a2bf87da08f02c8714d1319e54e8fa34b773
```

说明：

- `条目：17` 为收集到的源文件数，`18 个文件` 为打包后实际条目数——差 1 是自动生成的 `manifest.yaml`。
- 包内不含 `dev/` 与 `docs/`，因此解压后体积（278 KB）明显小于项目全量（约 1.4 MB，含两版头像原图）。
- 打包可复现：连续两次构建 SHA256 一致（已实测）。初次构建时因 `manifest.yaml` 使用写入时刻作为时间戳而每次不同，已改为固定时间戳。

其中"头像可按平台规则解析"这一项，是**按平台导入时的解析算法复现**的（先找 `包名/头像相对路径`，再找 `头像相对路径`，找不到就退回原字符串，进而显示名称首字）。这是本次针对"图标变汉字"故障专门加的回归检查。
