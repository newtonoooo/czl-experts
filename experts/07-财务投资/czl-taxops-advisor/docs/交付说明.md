## 二、产品是什么

不是"财税问答机器人"，是一条**带放行条件的流程**：

```
G0 接单脱敏 → G1 数据校准 → G2 经营诊断 → G3 税务判定 → G4 方案 → G5 交付
                ↑ 勾稽不平不放行
```

三个拿得出手的差异点：

1. **先证明数字站得住**——四类勾稽校验（资产平衡、分类合计、利润表三级阶梯、现金三项合计），不平就停在 G1，不给经营结论。
2. **数字由工具算**——自带 `toolkit.py`（纯标准库），比率、杜邦、量价拆分、申报日历都能算，每行附公式，用户可手工复核。
3. **十二个场景剧本**——把"用户怎么问"和"该走哪条路"连起来，每个场景写明"容易答错的地方"。

## 六、关于原专家的权利处理（重要）

原专家的 `LICENSE` 是 **MIT，版权人 Qingflow**。这意味着：直接改名字发布其实是 MIT 允许的，但**必须保留其版权声明**——删掉声明再发布反而违约。

本产品没有走这条路：只提炼功能需求，全部重写。因此：

- 不构成衍生作品，不承担保留原声明的义务；
- 包内已扫描确认不含 `qingflow`、`轻流`、`finance-tax-expert`、`finance-tax-advisor`、`finance-tax-core-skills` 等标识；
- 商标不在 MIT 授权范围内，本产品未使用其品牌与推广链接。

需保留的判断：**这是一个独立实现，不是"改过的原包"**。两者的差别在结构——原产品是"五个并列技能 + 三份知识库"，本产品是"六阶段流水线 + 场景剧本 + 计算工具"，连失败模式都不同。
