# 使用说明

适用对象：拿到本专家包的使用者（老板、财务、代账、行政）。
阅读时间约 8 分钟，读完就能用。

---

## 一、安装

### 方式 A：导入发布包（推荐）

1. 打开 WorkBuddy → 左侧「专家」→ 专家中心 → 导入 / 上传本地专家包。
2. 选择 `dist/czl-taxops-advisor-v1.0.0.zip`（**不要解压后再压一次**，直接选这个 zip）。
3. 导入完成后在专家列表确认：名字是「财税全流程专家」，头像是一枚深藏青底、金色柱状、白色对勾的方形图标。

若头像显示成一个汉字（例如「财」），说明平台没能读到图片，按 `docs/头像故障诊断.md` 里的四个检查点排查。

### 方式 B：放到插件目录

把整个 `czl-taxops-advisor` 文件夹（注意：文件夹名必须保持 `czl-taxops-advisor`，不能改名）放进：

```
<用户目录>/.workbuddy/plugins/marketplaces/experts/plugins/
```

重启 WorkBuddy，在专家中心「我的专家」里会出现。

### 安装后检查（30 秒）

- 头像正常显示，不是文字。
- 点开后能看到简介与三条推荐提问。
- 输入"帮我做一次月度财税体检"，看它是否先问你要数据、而不是直接开始分析。

## 二、第一次怎么用

### 最省事的开场

直接把报表贴进去，一句话说明期间：

> 这是 2026 年 9 月的利润表和资产负债表，帮我做个体检。

它会先跑勾稽校验，把通过项、差异项、无法判断项列出来，然后再谈经营。

### 如果你只有零散数据

不要硬凑。直接说"我只有利润表，没有资产负债表"，它会告诉你这样只能做什么、不能做什么，并给出补哪一项最划算。

### 如果你只有一个具体问题

不要写"帮我看看财务"，写具体问题。对照表：

| 你想解决 | 怎么说 |
| --- | --- |
| 这个月赚没赚钱 | 「9 月收入 86 万，成本 63 万，费用 16 万，帮我看看赚了多少、钱在哪」 |
| 报表赚了但没钱 | 「净利润 4 万，但账上只剩 9 千，帮我找出钱去哪了」 |
| 不知道要报什么税 | 「小规模纳税人，9 月开票 8 万，这个季度要报哪些税、几号前报完」 |
| 发票有问题 | 「这张发票抬头写错了一个字，已经跨月了，怎么处理」 |
| 要不要升一般纳税人 | 「现在小规模，年销售 400 万，客户里有国企要专票，该不该升」 |
| 预算 | 「帮我搭一份 2027 年预算框架，收入按产品和量价拆，费用按部门拆」 |
| 内控 | 「公司 12 个人，出纳和会计是同一个人，采购付款没有任何验收单，从哪改」 |
| 风险排查 | 「股东借了 30 万挂在其他应收款，一年多了，有什么问题」 |

## 三、怎么准备数据（决定输出质量）

### 推荐：整理成 JSON

一次整理，反复使用。字段表见 `skills/czl-taxops-pipeline/references/02-数据规范化与勾稽.md` 第三节，样例见 `samples/demo-2026-09.json`。

最小可用版本（只有这些也能跑）：

```json
{
  "unit": "元",
  "period": "2026-09",
  "balance_sheet": {
    "流动资产合计": 0, "资产总计": 0, "流动负债合计": 0,
    "负债合计": 0, "所有者权益合计": 0
  },
  "income_statement": {
    "营业收入": 0, "营业成本": 0, "营业利润": 0, "利润总额": 0, "净利润": 0
  }
}
```

### 从 Excel 复制的三条注意

1. **不要带千分位逗号**。`1,200,000` 会让解析失败，改成 `1200000`。
2. **不要带百分号**。`12%` 改成 `0.12` 或直接给分子分母。
3. **空单元格留空，不要填 0**。空＝未知（跳过该项），0＝确定为零（参与计算），两者含义不同。

### 金额脱敏

可以把所有金额同时除以 10000（或任意同一系数），比例型指标不受影响。但**不要只删掉几笔大额**——那会破坏勾稽关系，校验一定不平。

## 四、怎么读它的输出

一份完整体检有五段，按顺序读：

1. **结论**（三句话）：状况、最大问题、先做什么。老板只看这段也够。
2. **数据与计算**：每行后面有口径标注。看到"（按期末值计算）"就知道这个指标比平均值口径略有偏差。
3. **待补清单**：最后一句会写"补哪一项最划算"。按这个补，性价比最高。
4. **风险台账**：A 级是 7 天内要动的，B 级 30 天，C 级本季度。A 级超过 3 条的，先做金额最大的那条。
5. **口径声明**：复核的人先看这段。里面有假设，假设不成立结论就要重算。

### 三个信号说明它在正常工作

- 它说"这一项无法判断，因为缺 XX"——说明没有硬编。
- 它给出"我不确定，建议向主管税务机关确认"——说明没有编条文。
- 它拒绝某个请求（如"帮我少交点税""开票内容改一下"）——说明红线在生效。

### 一个信号说明你可能问偏了

如果它开始输出大段税率表、列一堆政策名称，却没有针对你的数字——说明问题太宽。把问题收窄到"我这笔业务、这个金额、这个期间"。

## 五、自带工具怎么用（进阶）

装好后专家目录下有一个纯 Python 脚本，可以用命令行直接跑：

```bash
cd <专家目录>
python skills/czl-taxops-pipeline/scripts/toolkit.py selftest
python skills/czl-taxops-pipeline/scripts/toolkit.py check    --file samples/demo-2026-09.json
python skills/czl-taxops-pipeline/scripts/toolkit.py ratios   --file samples/demo-2026-09.json --capex 20000
python skills/czl-taxops-pipeline/scripts/toolkit.py variance --file samples/variance-demo.json
python skills/czl-taxops-pipeline/scripts/toolkit.py calendar --year 2026
```

- 只需要 Python 3.8+，不装任何库。
- `check` 加 `--strict`：有不平项时返回码 2，方便放进脚本流水线。
- 输出可以直接贴进报告，也可以作为复核依据。

## 六、常见问题

**Q：它能不能直接帮我报税？**
不能。它不登录电子税务局、不代填申报表，只给申报顺序、每栏对应哪个数据、以及容易错的地方。

**Q：税率说的准不准？**
税率与扣除标准标注了"截至 2026 年 10 月"，属于通行口径。优惠政策变动频繁，落地前请核对国家税务总局当期公告与电子税务局提示。这是本产品明确的限制，不是免责话术。

**Q：能不能一次问十个问题？**
可以，但质量会下降。建议一次一个阶段：先体检，再税务，再方案。每一步的结论会成为下一步的输入。

**Q：数据安全吗？**
不要粘贴身份证号、银行账号、U 盾信息。公司名、客户名、金额都可以脱敏（见第三节）。专家本身不会索取这些信息。

**Q：它说的和我的代账会计不一样，听谁的？**
听能拿出依据的那个。把它给的公式和口径拿去和会计对，对不上的地方就是真正需要搞清楚的地方——通常差在含税口径、平均/期末口径、或某笔跨期事项。

**Q：更新频率？**
政策调整（税率、优惠期限、申报规则）或平台清单格式变化时发布新版本，见 `CHANGELOG.md`。

## 七、一句话总结用法

**给数据、说清期间和身份、一次问一个阶段、看完结论先看待补清单。**
这四件事做到，输出质量和使用体验会明显不同。
