# 多标的对比模板

> 用于 2–5 只标的横向比较。超过 5 只先给排序表，只展开前 3 只。

## 一、对比矩阵

| 标的 | 总分 | 档位 | ① 估值 | ② 盈利 | ③ 成长 | ④ 健康 | ⑤ 技术 | ⑥ 资金 | 覆盖率 |
|---|---|---|---|---|---|---|---|---|---|
| {{name_1}} | | | | | | | | | |
| {{name_2}} | | | | | | | | | |

> 同一套阈值、同一数据截止日、同一复权方式。任一项不同则不可比，必须在表下注明差异。

## 二、差异归因

只写"分差来自哪个分项"，不写"A 比 B 好"：

- `{{name_1}}` 比 `{{name_2}}` 总分高 {{delta}} 分，主要差在 {{dim}}（{{factor}}：{{v1}} vs {{v2}}）。
- `{{name_2}}` 在 {{dim2}} 上反而更高，原因是 {{reason}}。

## 三、适用场景分离

结论落到"什么情况下选谁"，而不是"谁更好"：

- 若看重 {{condition_a}} → `{{name_a}}` 的分项更占优；
- 若担心 {{risk_b}} → `{{name_b}}` 在这一项上更薄。

## 四、共同风险

组合视角：如果两只标的在同一分项上都低分（例如同属高质押行业），要单独指出这是**共同暴露**，不是分散。

> 对比不构成推荐。同一行业的两只股票同时走弱时，分散无效。
