# 更新日志

本文件记录本专家包的版本变更。版本号遵循语义化版本：主版本.次版本.修订号。

## 1.0.1 — 2026-10-28

修复平台解析失败，并把平台校验规则固化成本地检查。

### 修复

1. **头像被判"格式不支持：无扩展名"**
   1.0.0 为了兼容自建分发，把 `avatar` 写成内联 data URI。平台校验器按文件路径解析该字段并检查扩展名，
   data URI 没有扩展名，直接解析失败。
   现在清单里 `avatar = "avatars/expert.png"`（带扩展名，可过校验）；
   需要"导入即显示图标"的本地分发场景，由 `build_dist.py --only local` 单独产出内联版本。

2. **`defaultInitPrompt.en` 与 `quickPrompts[0].en` 不一致**
   前者多了 `(Kweichow Moutai)`，平台要求两者逐字相同。已把 `defaultInitPrompt` 直接对齐到
   `quickPrompts[0]`（中英各一条），并在打包时强制同步，避免再次漂移。

### 新增

- `verify_package.py` 增加平台规则检查：头像扩展名、`defaultInitPrompt` 与首条快捷词一致性、
  包名正则、语义化版本、双语字段齐全、快捷词条数、tags 条数；支持 `--avatar-mode market|local` 两种口径。
- `build_dist.py` 改为一次产出两个包：
  - `czl-stock-panorama-1.0.1.zip`：平台提交版（头像用相对路径）
  - `czl-stock-panorama-1.0.1-local.zip`：本地分发版（头像内联 data URI）
  打包时直接写入内存中的清单，不改动磁盘上的 `plugin.json`。

### 变更

- 版本号 1.0.0 → 1.0.1。

## 1.0.0 — 2026-10-28

首个发布版本。

### 新增

- 专家主提示词：五阶段作业流程（口径对齐 → 取证 → 本地计算 → 写判断 → 交付自检），含八条交付闸门与明确的能力边界。
- 内置技能 `stock-panorama-core`：六维评分卡、关键价位、同业矩阵、数据体检。
- 本地规则引擎（纯 Python，零第三方依赖）：
  - `indicators`：SMA/EMA/MACD/KDJ/RSI/BOLL/ATR/乖离/量比/区间位置，250 根日 K 本地复算；
  - `schema`：单位归一化、字段校验、数据时效判定；
  - `scorecard`：六维加权评分、档位判定、多空证据反推、同业分位矩阵；
  - `levels`：支撑/压力/两倍 ATR 风险位；
  - `qa`：覆盖率、置信度、待人工确认项；
  - `report`：Markdown 报告渲染（七节结构）。
- 命令行四子命令：`check` / `score` / `report` / `levels`，带明确退出码（0 成功、2 输入不合法、1 运行异常）。
- 参考文档四份：打分规则（阈值逐条登记）、取数适配映射、A 股口径陷阱清单、报告标准。
- 模板三份：缺数询问单、一页速览、多标的对比。
- 原创头像：几何六边形环 + 三根递增柱，脚本生成（`tools/make_avatar.py`），1024/512 两种尺寸，并内联为 data URI。
- 工具链：包体检（`verify_package.py`）、打包（`build_dist.py`）、头像模式切换（`set_avatar_mode.py`）。
- 离线自测 54 项断言，覆盖指标、归一化、评分、价位、体检、报告、命令行、结果稳定性。

### 修复

以下三个缺陷是在自测与示例报告复核中发现并修正的，记录在此以便回溯：

1. **资金占比被放大 100 倍**：初版对所有百分数字段套用"≤1.5 视为小数"的启发式，导致 0.9% 的主力净流入占比被读成 90%。现在只对行业惯例明确的字段（ROE/毛利率/净利率/负债率/商誉/质押/第一大股东）自动换算，其余字段按原值使用并提示确认。
2. **"标准无保留意见"被判成非标**：字符串匹配先判断"保留意见"，而"标准无保留意见"包含这四个字，导致最健康的审计意见拿到 18 分。改为先认"无保留"，再认"无法表示/否定/保留意见"。
3. **价格显示 227.0075 这类精确的错觉**：支撑位由均线计算得来，展示层未做小数位规整。现统一保留两位。

### 已知限制

- 未在真实行情数据上做过端到端验证（本次开发环境未接入行情类 MCP），详见 `docs/功能测试报告.md`。
- 评分为固定阈值，未做行业自适应；行业差异依赖报告标注与同业对标缓解。
- 未包含组合层面的相关性/暴露分析，仅做多标的并列对比。
