# 来源与第三方组件说明

## 一、本包的创作方式

本专家包为独立开发成果，作者虫志龙。开发过程记录见 `docs/开发记录.md`。

- **提示词与技能协议**：依据"个股诊断"这一通用业务需求重新撰写，未复制任何现有专家包的文本。
- **Python 引擎**：全部为本包原创实现，指标算法依据公开的数学定义（简单移动平均、Wilder 平滑 RSI、指数平滑 MACD、总体标准差布林带、Wilder ATR 等）自行编写。
- **评分阈值**：由作者依据常见财务分析经验设定，属原创判断，不来自任何受保护的评分卡或研报模型。
- **文档与模板**：原创撰写。
- **头像**：由 `tools/make_avatar.py` 用几何图形程序化绘制，无任何第三方素材、无 AI 图像模型生成、无字体渲染，不涉及第三方图库授权。

## 二、运行时依赖

**无。** 引擎只使用 Python 标准库（`json` / `math` / `datetime` / `argparse` / `struct` / `zlib` 等）。
不需要 numpy、pandas、requests，也不需要联网。
