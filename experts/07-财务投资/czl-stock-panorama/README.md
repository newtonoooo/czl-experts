# 专业级个股全景诊断官（czl-stock-panorama）

一只 A 股，六个维度，一份能被人拿着原始数据逐条核对的诊断。

作者：虫志龙 · 47190078@qq.com · 版本 1.0.1

---

## 它解决什么问题

市面上的"个股分析"通常有三种毛病：

1. **口径不统一**：说"估值便宜"，但没说比什么便宜、用哪个口径的 PE、财报是哪一期；
2. **证据不成体系**：基本面、技术面、资金面各说各话，最后用"综合来看"收尾；
3. **缺失被话术填满**：拿不到数据就写"约为""大致"，读者无从知道哪里是空的。

这个专家把这些都变成结构化字段：每个维度有分项、有权重、有扣分理由；缺数据的地方写"未取到"，并直接降低结论置信度；总分算不出来时就明确写"暂不评级"，不允许估一个。

## 六维评分卡

| 维度 | 权重 | 看什么 |
|---|---|---|
| ① 估值 | 16% | PE(TTM)、PB、PEG、历史分位、相对行业中位、股息率 |
| ② 盈利质量 | 20% | ROE、毛利率、净利率、ROIC、周转率 |
| ③ 成长性 | 18% | 营收/净利同比、三年复合、单季同比 |
| ④ 财务健康 | 14% | 负债率、流动比率、现金流/净利、利息保障、商誉占比 |
| ⑤ 技术结构 | 20% | 均线排列、MACD、布林位置、RSI、乖离、量能、波动率 |
| ⑥ 资金与事件 | 12% | 主力净流入、北向、融资余额、股东户数、事件倾向、审计意见 |

权重合计 1.00，阈值全部公开（见 `skills/stock-panorama-core/references/scoring_rules.md`）。

## 三个真实的设计取舍

**固定阈值而不是"行业自适应"**：白酒和钢铁用同一套 PB 标准当然不合理。但固定阈值的优点是任何人在同一份数据上能算出同一个分，分歧会落在"你凭什么定 15% 这条线"，而不是"你到底算了什么"。行业差异靠两条路解决——报告里显式标注"该阈值不适用于本行业"，以及同业横向对标。

**缺失不补，只降置信度**：引擎里没有"行业均值兜底"这个逻辑。宁可写"未取到"，也不给一个看起来完整但来源不明的数。

**给条件不给预测**：输出的是"若 X 则 Y 更可能成立"和关键风险位，不是目标价。这是产品定位，不是能力不足。

## 快速开始

1. 把整个 `czl-stock-panorama/` 目录放进 `~/.workbuddy/plugins/marketplaces/my-experts/plugins/`；或导入 `dist/` 下的 zip——
   自己用选 `-local.zip`（图标正常显示），提交平台上架选不带后缀的那个（avatars/expert.png）；
2. 重启 WorkBuddy，在专家列表里选择「专业级个股全景诊断官」；
3. 直接说：`帮我诊断 600519`、`用同一套标准对比 000858 和 000568`。

想先看效果，不用装也能跑引擎：

```bash
cd skills/stock-panorama-core/scripts
python -m panorama.cli report --input ../examples/sample_input.json --out /tmp/report.md
```

样例输出见 `skills/stock-panorama-core/examples/sample_report.md`。

## 能力边界

- 只覆盖 A 股：港股、美股、期货、期权、场外产品不在范围内。
- 不预测涨跌、不给目标价、不给仓位建议、不承诺收益。
- 数据靠外部工具或用户提供。工具未授权时它会明确说"取数不可用"，而不是用记忆里的数字顶替。
- 评分是规则打分，不是机器学习模型，也不是概率。
