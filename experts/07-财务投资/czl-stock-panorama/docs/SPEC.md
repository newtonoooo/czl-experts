# 产品规格说明书

产品：专业级个股全景诊断官（包名 `czl-stock-panorama`）
版本：1.0.1　作者：虫志龙　日期：2026-10-28

---

## 1. 目标用户

| 用户类型 | 场景 | 真实诉求 |
|---|---|---|
| 有持仓的个人投资者 | 手里有一只票，涨了不知道该不该减，跌了不知道该不该补 | 想知道"现在是什么状态"，而不是"明天涨不涨" |
| 准备建仓的研究型用户 | 已经看过研报和财报，想验证自己的判断有没有漏项 | 需要一份能核对的清单，指出自己没看的地方 |
| 内容创作者 / 投顾助理 | 要写一篇个股分析，需要结构化素材 | 需要可引用的数据表格与证据链，不能编 |
| 学生 / 考证人群 | 练习基本面分析 | 需要方法论示范，知道每一步为什么这么做 |

**共同点**：都不缺"结论"，缺的是**结论怎么来的**。这是本产品的立足点。

## 2. 要解决的问题

1. **口径漂移**：不同来源的 PE 有 TTM/静态/动态三种，技术面有前复权/不复权两种，混用会得出相反结论。
2. **证据碎片化**：六个维度各说各话，没有统一权重，最后靠"综合来看"收尾，无法复核。
3. **缺失被掩盖**：拿不到数据时用"约为""行业平均"填空，读者无法分辨哪些是事实、哪些是推测。
4. **单向叙事**：看多的人只列利多，看空的人只列利空，双方都能自圆其说。
5. **算错不自知**：三十多个分项手算加权，出错概率极高且无痕迹。

## 3. 输入

**必要输入**
- 股票代码（6 位）或名称
- 数据截止日
- 数据本身：来自已授权 MCP 工具，或用户提供的截图/CSV/文本

**可选输入**
- 复权方式（默认前复权）
- 财务报告期（默认最新一期，TTM 优先）
- 同业样本（≥3 家时启用排名）
- 事件清单（公告日期、类型、摘要、倾向）

**输入格式**：结构化 JSON，键名固定（见 `skills/stock-panorama-core/examples/sample_input.json`）。非结构化输入（截图、文本）由专家逐项转写并回读确认。

## 4. 输出

| 档位 | 输出物 | 篇幅 |
|---|---|---|
| 速览 | 档位结论 + 三支撑 + 三风险 + 关键位 + 置信度 | ≤300 字 |
| 标准诊断 | 七节 Markdown 报告 | 3000–5000 字 |
| 对比 | 每只六维分 + 对比矩阵 + 差异归因 + 条件式结论 | 按标的数 |
| 机器可读 | `score.json`（六维分、覆盖率、价位、多空清单） | — |

**输出必须包含**：数据截止日、财务报告期、复权方式、置信度、覆盖率、免责声明。
**输出禁止包含**：目标价、收益率预测、买卖指令、收益承诺。

## 5. 处理步骤（通用流程）

1. **口径对齐**：确认标的、数据截止、报告期、复权、单位；缺省按默认并在报告标注。
2. **六块取证**：估值 / 盈利质量 / 成长 / 财务健康 / 技术 / 资金与事件；每块记来源与时间。
3. **本地计算**：指标复算 → 分项打分 → 维度加权 → 总分与档位 → 关键价位 → 同业分位 → 覆盖率与置信度。
4. **判断撰写**：把机械结论翻译成人话，补反方与反驳，给条件式结论。
5. **交付自检**：八条闸门逐条过，不过则改。

**判断条件（硬闸门）**
- 单维覆盖率 <40% → 该维不参与总分；
- 总覆盖率 <60% → 不给总分，档位 N/A；
- PE ≤0 → 估值维度不评分，标注"无经济含义"；
- 同业 <3 家 → 不做排名结论；
- 报告期距数据日 >300 天 → 置信度降级。

## 6. 工具能力要求

| 能力 | 用途 | 缺失时的降级 |
|---|---|---|
| K 线查询（250 根以上，OHLCV） | 本地复算技术指标 | 只做基本面，明确说明不含技术结论 |
| 财务指标查询（PE/PB/ROE 等） | 估值与盈利质量 | 请用户提供截图，逐项转写 |
| 财务报表（利润表/资产负债表/现金流） | 成长、健康、现金流质量 | 同上 |
| 实时行情 | 时间戳对齐、换手 | 用最近收盘代替并标注 |
| 资金流（主力净流入/北向/融资） | 资金面 | 该维降覆盖率 |
| 资讯与公告 | 事件催化 | 事件表留空并声明 |

**工具无关性**：能力与具体工具解耦，映射表见 `references/data_adapters.md`，换数据源只改表。

## 7. 质量 / 速度 / 稳定性要求

| 维度 | 要求 | 达成方式 |
|---|---|---|
| 可复核性 | 同一输入必须得到同一输出 | 纯函数引擎 + 固定阈值；自测含"两次运行结果一致"断言 |
| 可追溯性 | 每个数字能追到输入或引擎输出 | 分项表内含"取到的数"与"口径提示"列 |
| 诚实性 | 缺失不得被话术填补 | 缺字段写"未取到"；覆盖率与置信度进报告头 |
| 确定性 | 相同输入输出字节级一致 | 无随机数、无时间戳写入正文 |
| 速度 | 单只标准诊断 ≤2 分钟（不含取数等待） | 引擎单次计算 <0.1 秒；取数是瓶颈 |
| 稳定性 | 缺字段、空数组、负 PE、除零不崩溃 | 全部走 None 分支；自测覆盖空数据与亏损样本 |
| 可移植性 | 任意 Python 3.9+ 环境可跑 | 零第三方依赖 |

## 8. 非目标（明确不做）

- 不做涨跌预测、不做择时信号、不做量化回测；
- 不做组合优化与仓位建议；
- 不覆盖港股/美股/期货/期权；
- 不做舆情抓取与情绪打分（事件倾向由录入者判定）；
- 不提供交易执行、不代客理财。

## 9. 与通用"个股分析助手"的差异

| 维度 | 常见做法 | 本产品 |
|---|---|---|
| 评分 | 无权重，靠语言描述 | 六维固定权重，阈值逐条公开 |
| 缺失 | 用行业均值补 | 不补，降置信度并列出待补项 |
| 结论 | 给方向性建议 | 给状态 + 条件 + 风险位 |
| 一致性 | 每次分析口径可能不同 | 同一输入同一输出，可回归测试 |
| 多空 | 单向叙事 | 引擎强制反推空头证据 |
