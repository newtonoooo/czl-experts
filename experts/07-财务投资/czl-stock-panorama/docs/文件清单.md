# 文件清单

本清单按"这个文件对谁有用"组织，不是简单罗列。开发记录与测试报告另见同目录其他文件。

## 一、平台识别必需（删任何一个都无法加载）

| 文件 | 作用 | 说明 |
|---|---|---|
| `.codebuddy-plugin/plugin.json` | 专家清单 | 名称、版本、作者、双语文案、头像、技能与 agent 注册。目录名以点开头，部分解压工具会跳过，导入失败先查这里 |
| `agents/czl-stock-panorama.md` | 专家主提示词 | YAML frontmatter + 五阶段作业流程 + 八条交付闸门 + 能力边界 |
| `avatars/expert.png` | 头像文件 | 512×512 PNG，脚本生成 |

> `plugin.json` 的 `avatar` 现在是相对路径 `avatars/expert.png`——平台校验器按文件路径解析该字段并检查扩展名，写 data URI 会被判"无扩展名"。
> 需要"导入即显示图标"的本地分发版，由 `build_dist.py --only local` 单独产出（运行时替换为内联 data URI，不改磁盘上的清单）。详见 USAGE 第七节。

## 二、专家能力（技能 + 引擎）

| 文件 | 作用 |
|---|---|
| `skills/stock-panorama-core/SKILL.md` | 技能主文档：三档交付判断、五阶段流程、工具纪律、禁止事项 |
| `.../scripts/panorama/__init__.py` | 包版本与导出 |
| `.../scripts/panorama/indicators.py` | SMA/EMA/MACD/KDJ/RSI/BOLL/ATR/乖离/量比/区间位置，含从 K 线序列自动推导 |
| `.../scripts/panorama/schema.py` | 输入规范化：单位归一、字段类型校验、时效判定、覆盖率口径定义 |
| `.../scripts/panorama/scorecard.py` | 六维评分卡（权重、阈值、档位）、多空证据反推、同业分位矩阵 |
| `.../scripts/panorama/levels.py` | 支撑/压力/两倍 ATR 风险位 |
| `.../scripts/panorama/qa.py` | 覆盖率、置信度、待人工确认项、风险提示 |
| `.../scripts/panorama/report.py` | 七节 Markdown 报告渲染 |
| `.../scripts/panorama/cli.py` | 命令行入口：check / score / report / levels，退出码 0/1/2 |
| `.../tests/selftest.py` | 54 项离线断言，改任何规则后必须重跑 |

## 四、工具链（开发者用，安装后不参与运行）

| 文件 | 作用 |
|---|---|
| `tools/make_avatar.py` | 程序化绘制头像，输出 512/1024 PNG 与 data URI（需 Pillow） |
| `tools/set_avatar_mode.py` | 在"内联 data URI"与"相对路径"两种头像模式间切换 |
| `tools/verify_package.py` | 包体检：清单、路径、头像、脚本编译、frontmatter、文档、自测 |
| `tools/build_dist.py` | 一次产出两个 zip（平台提交版 + 本地 data URI 版），输出 sha256 |

## 六、发布产物（构建生成，不手工维护）

| 文件 | 作用 |
|---|---|

## 七、不随包分发

| 文件/目录 | 原因 |
|---|---|
| `__pycache__/` | 字节码缓存，由 `build_dist.py` 排除 |
| `avatars/avatar_data_uri.txt` | 中间产物，已从两个发布包中排除；保留在源目录，供 `build_dist.py --only local` 与 `set_avatar_mode.py` 使用 |
