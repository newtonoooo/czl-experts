# 使用说明

## 一、安装

### 本机（已注册）

```
%USERPROFILE%\.workbuddy\plugins\marketplaces\my-experts\plugins\czl-stock-research\
```

打开 WorkBuddy 左侧栏 **专家 → 我的专家**，找到「刻度」卡片，点击进入。

### 从压缩包导入到其他机器

1. 解压 `czl-stock-research.zip`
2. 确认解压结果为 `czl-stock-research/` 单层目录，且内部存在 `.codebuddy-plugin/plugin.json`
3. 将整个目录放入 `%USERPROFILE%\.workbuddy\plugins\marketplaces\my-experts\plugins\`
4. 重启 WorkBuddy，在「我的专家」确认出现

> `.codebuddy-plugin` 是隐藏目录。Windows 需开启"显示隐藏项目"，macOS 按 `Cmd+Shift+.`，否则复制时可能漏掉，导致专家无法识别。

### 自检命令

```bash
python scripts/validate_expert.py <专家目录>
python scripts/register_expert.py <专家目录>
```

## 二、配置

| 项目 | 要求 | 说明 |
|---|---|---|
| 联网检索 | 建议开启 | 财报、公告、行情均需实时检索；关闭时只能用你提供的数据 |
| 金融数据连接器 | 可选，建议 | 已连接时结构化数据优先取自它，缺失才降级到公开检索 |
| 文档生成能力 | 可选 | 需要 DOCX / XLSX 交付物时使用；不可用时降级为 Markdown |
| 绘图能力 | 可选 | 报告配图；不可用时交付数据表 + 脚本，并注明图表未生成 |

无强制账号、密钥或环境变量要求。本专家包不含任何脚本、网络请求代码或外部二进制依赖。

## 三、输入要求

### 通用三项

1. **标的**：公司名称或代码；做行业研究时给到子环节（"储能 PCS"而不是"新能源"）
2. **市场**：A 股 / 港股 / 美股，决定报告期与会计准则
3. **想要的产出**：快速判断 / 深度报告 / 模型 / 过会材料

### 涉及仓位的四项

缺任一项时，只会给推导框架与待填项，**不给百分比**：

1. 组合总规模
2. 现有持仓占比与成本价
3. 单笔风险预算（如"单笔最大亏损不超过组合 2%"）
4. 相关敞口（同行业、同风格）

这不是能力限制，是设计约束：缺数据还给精确仓位，等于编造。

### 表述建议

- 说清用途（给自己 / 给投委会 / 给客户），决定深度与口径
- 有时限就直说，会明示"本次覆盖了什么、没覆盖什么"
- 想验证既有判断，直接说"帮我找反证"比问"我这个判断对吧"更有效

## 四、操作流程

### 单点使用

一句话进对应模块：

| 你的说法 | 进入模块 |
|---|---|
| 这家公司是干什么的 / 快速看看 | 公司画像 |
| 值多少钱 / 贵不贵 / 给个目标价 | 建模与定价 |
| 跟同行比呢 / 搭个模型 | 建模与定价 |
| 财报出来了 / 超预期了吗 | 财报解读 |
| 写份报告 / 要能交出去的材料 | 报告构建 |
| 我该买多少 / 怎么止损 | 仓位计划 |
| 我这些持仓有问题吗 | 组合体检 |
| 这事影响多大 / 如果…会怎样 | 事件情景 |
| 这个行业怎么样 / 有什么标的 | 行业扫描 |
| 我这逻辑还成立吗 / 今天有什么 | 论点台账 |
| 过会材料 / 备忘录 | 决策备忘 |

### 串联使用

要"从看公司到定仓位"走全程时，按 **单票 → 组合** 的顺序推进：

```
公司画像 → 建模与定价 → （要交付就）报告构建 → 决策备忘 → 仓位计划 → 论点台账
```

每段结束会报一次当前结论和还缺什么，不会一口气跑完再给。

## 五、结果说明

### 会返回什么形态

| 场景 | 形态 |
|---|---|
| 单一指标、快速判断 | 对话直答，不生成文件 |
| 结构化分析、跟踪记录、简报 | Markdown |
| 要交出去的研究 | 自包含 HTML（双击可开、可打印） |
| 需走审批或存档 | DOCX |
| 财务模型 | XLSX |

### 每条结论都带什么

| 字段 | 说明 |
|---|---|
| 方向 | 看多 / 看空 / 中性 / 不做，四选一 |
| 目标价区间 | 上下界；点值只作参考 |
| 置信度 | 高 / 中 / 低 + 依据 + 不确定性来源 |
| 推翻条件 | 可观察事实 + 阈值，可被第三方独立判定 |
| 复核时点 | 具体日期或事件 |
| 数据截止 | 哪一天的数据 + 免责声明 |

### 数据标注

| 标注 | 含义 |
|---|---|
| `[MISSING]` | 查不到，如实标缺，未用估算值填空 |
| `[STALE]` | 超过 90 天，环境可能已变 |
| `[假设]` | 我们的推断或替代取值，非披露数据 |

### 会拒绝或降级的情况

- 内幕消息、未公开重大信息
- 要求承诺收益或给确定股价点位
- 数据不足时：降级为「监控项 / 等待证据 / 放弃」，并点名缺哪一块
- 图表无法生成时：交付数据表 + 脚本，注明"图表未生成"，不用文字描述冒充
- 要求"多写点显得充实"：拒绝注水，改为增加有信息量的分析维度

## 六、常见问题

**Q：为什么不肯直接说"能涨到多少"？**
不做点位预测。给区间、概率与敏感性，因为这三者才是可复核的。

**Q：为什么每条结论后面都有"什么情况下算我错了"？**
这是本产品的方法内核。一个无法被推翻的判断不值得下注。

**Q：为什么一定要我给组合规模才给仓位？**
缺规模只能算出比例约束，算不出绝对金额与最差情景损失。给了等于没给。

**Q：只想看结论，不想看推导过程？**
所有产出都是先结论后论证，读第一段即可。但推翻条件与数据来源不会省略。

**Q：能不能用它做行业研究不看个股？**
可以，用「行业扫描」，输出会收敛到"这个行业只交易哪一两个变量"和一份带验证动作的候选清单。

**Q：和市面上的股票研究工具有什么不同？**
别的工具给你一堆产物；这里每个产物都带推翻条件和置信度，且缺证据时会明确降级而不是硬给结论。
