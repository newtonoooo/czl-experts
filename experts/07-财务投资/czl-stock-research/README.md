## 它是什么

一个把"我觉得这家公司不错"变成**带刻度的判断**的工作台。

判断带刻度，指三件事同时成立：

1. **别人能复算你的数字** —— 关键假设全部成表，写明来源，标清是事实还是判断
2. **别人能判断你错了没有** —— 每条结论附推翻条件，且该条件可被第三方独立判定
3. **别人知道明天做什么** —— 落到评级、目标价区间、仓位与退出规则

缺一条，这份研究就还没做完。

## 十个模块，按研究对象划分

用户是按下什么决定提问的，所以模块按**对象范围**划，不按流程顺序划。

### 单票（看一家公司）

| 模块 | 用途 | 交付物 |
|---|---|---|
| `czl-company-map` 公司画像 | 第一次接触，判断值不值得深挖 | 一页纸：生意逻辑、收入结构、单位经济、竞争位势、矛盾点 |
| `czl-model-value` 建模与定价 | 要模型、要目标价 | 三表模型 + 三法估值 + 敏感性 + 目标价区间 |
| `czl-earnings-read` 财报解读 | 财报前后 | 前瞻情景表 或 业绩归因 + 估计修正 |
| `czl-report-build` 报告构建 | 要能交出去的文件 | 结构完整报告 + 图表 + 交付前质量闸 |

### 组合（看我的钱）

| 模块 | 用途 | 交付物 |
|---|---|---|
| `czl-position-plan` 仓位计划 | 该买多少、怎么退 | 风险预算 → 仓位 → 三道闸 → 退出规则 |
| `czl-portfolio-check` 组合体检 | 多个持仓的风险 | 四维敞口归集、重复赌注识别、压力情景 |

### 事件与行业

| 模块 | 用途 | 交付物 |
|---|---|---|
| `czl-event-scenario` 事件情景 | 一件事影响多大 | 概率分布 + 敏感性矩阵 + 当前价隐含假设 |
| `czl-sector-scan` 行业扫描 | 看行业、找标的 | 利润池定位 + 行业交易变量 + 候选清单 |

### 横向（任何结论都要流经）

| 模块 | 用途 | 交付物 |
|---|---|---|
| `czl-thesis-log` 论点台账 | 复盘、日常跟踪 | 支柱记分卡 + 反面证据栏 + 一页简报 |
| `czl-decision-memo` 决策备忘 | 过会、留档 | 平衡版备忘，允许结论是"不做" |

## 方法内核：八步

所有模块共用同一套动作，区别只在停在哪一步：

```
定义问题 → 盘点已知 → 写出可检验假设 → 量化 → 定价 → 定推翻条件 → 落动作 → 留记录
```

**两个中止点**：写不出可检验假设就停（降级观察）；关键数据缺失且无可替代就只给方向、不给目标价。不为了交付完整而糊过去。

## 四条硬规则

1. **证据分三级**：A 级公司披露 / B 级交易所与投资者关系 / C 级研报媒体。C 级未经 A 级核对不得进结论。
2. **三类标注必用**：`[MISSING]` 查不到、`[STALE]` 超 90 天、`[假设]` 我们的推断。不用看起来合理的数字填空。
3. **结论六件套**：方向、目标价区间、置信度、推翻条件、复核时点、数据截止。缺一不交付。
4. **反面证据对等**：提一条支持证据，就找一条可能的反面证据。用户只想听好话时，仍然先摆反面。

## 适合谁

- 买方研究员：覆盖多只股票，被要求给明确建议
- 卖方研究岗：要出深度报告与晨会观点
- 私募 / 家族办公室投资经理：自己看案子，无人复核
- 投研支持与风控岗：要判断别人递来的研究是否可靠
- 有财务基础的个人投资者：缺流程，不缺概念

## 不适合

- 需要实时行情下单、自动执行的场景
- 需要持牌投顾服务的场景
- 想获得确定性涨跌预测的人

## 使用须知

- 所有输出仅供研究参考，不构成个人投资建议，报告末尾自动附此声明
- 数据依赖外部检索，缺失会明确标注，不会编造
- 涉及内幕信息、未公开重大信息一律拒绝
- 未经确认的组合规模与成本，不会用来推导仓位百分比

详见 `USAGE.md`。
