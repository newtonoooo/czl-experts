# 报告构建

报告的价值不在长度，在**每一段都有来源、每一句都能被追问**。这一模块负责把前几个模块的产物装配成能交出去的东西。

## 职责

**做**：报告结构、章节内容、图表清单、装配、交付前质量闸口。
**不做**：不重新做估值（引用 `czl-model-value` 结果），不重新读财报（引用 `czl-earnings-read` 结论）。

## 输入参数

| 参数 | 必填 | 说明 | 缺失处理 |
|---|---|---|---|
| 标的 | 是 | — | 问 |
| 报告用途 | 是 | 对内决策 / 对外客户 / 存档 | 未说明则默认对内 |
| 目标篇幅 | 建议 | 10–15 页 或 30 页以上 | 按数据可得性给建议值 |
| 已有产物 | 建议 | 画像 / 模型 / 估值结论 | 缺则先补，不用占位内容顶 |
| 交付格式 | 是 | HTML / DOCX / Markdown | 默认 HTML（自包含可打印） |

## 依赖与关系

- **上游**：`czl-company-map`（业务章节）、`czl-model-value`（估值章节）、`czl-earnings-read`（业绩章节）
- **下游**：`czl-decision-memo`（要过会时）、`czl-thesis-log`（结论入库）
- **横向**：版式与精度要求见 `czl-delivery-standard.md`

## 执行步骤

### 阶段一：定骨架

先定章节，再写字。标准骨架（可按用途裁剪，不可改变顺序逻辑）：

```
1  结论页      评级 / 目标价区间 / 当前价 / 隐含空间 / 一句话逻辑
2  核心论点     3–4 条，每条附一个数字
3  公司做什么   生意逻辑 + 收入结构 + 单位经济
4  行业位置     结构 + 利润池 + 竞争位势
5  财务分析     历史三年 + 关键比率变化的原因
6  预测与假设   假设表（来源 / 事实还是判断）
7  估值         至少两法 + 敏感性 + 情景
8  风险         上行 / 下行 / 假设风险，三类分开
9  推翻条件与复核时点
10 附录         数据表 / 可比公司 / 来源清单
```

### 阶段二：逐章填充的规则

- **每章先写结论句**，再写支撑；不要从背景讲起
- 每个数字带来源与日期；C 级来源必须已核对
- 图表用真实数据绘制；不能用文字描述冒充图表
- 一页里不要出现孤立的小节标题或单张图独占版面

### 阶段三：图表清单（按需裁剪，不得少于 8 张）

| 图 | 用途 |
|---|---|
| 收入结构与增速 | 说明增长来自哪里 |
| 毛利率与费用率趋势 | 说明盈利能力变化 |
| 经营现金流 vs 净利润 | 说明盈利质量 |
| 与同业倍数对比 | 相对位置 |
| 自身历史估值带 | 当前位置 |
| 估值区间条（各方法并列） | 一目了然的结论 |
| 敏感性热力图 | 关键变量影响 |
| 情景价值对比 | 概率加权 |

### 阶段四：装配

- HTML：CSS 内联、响应式、含 `@media print`，双击可开
- DOCX：样式统一，页眉页脚与页码齐全，目录可跳转
- 引用：尽量给可点击链接；无链接则给文件标题与发布日期

### 阶段五：过闸

逐项核对：

- [ ] 结论页能在 30 秒内读懂
- [ ] 目标价是区间，不是点值
- [ ] 假设表每行都有来源，且标注"事实还是判断"
- [ ] 至少两种估值方法且解释了差异
- [ ] 敏感性矩阵已标注基本情景格
- [ ] 风险分三类，不是免责套话
- [ ] 推翻条件可被第三方独立判定
- [ ] 每个关键数字有来源与日期
- [ ] 图表为真实绘制，非文字描述
- [ ] 数据截止日 + 免责声明已附

## 判断条件

| 判据 | 处置 |
|---|---|
| 数据不足以支撑目标篇幅 | **缩短篇幅**，告知用户"数据只够支撑 X 页"，绝不凑页数 |
| 上游估值缺失 | 停止，说明需先完成 `czl-model-value`，不用占位内容续写 |
| 图表环境不可用 | 交付数据表 + 绘图脚本，明确写"图表未生成" |
| 用户要求"多写点显得充实" | 拒绝注水，改为增加有信息量的分析维度或附录 |

## 输出格式

- 文件命名：`[标的]_研究报告_[YYYYMMDD].[html|docx]`
- 首屏必须含：评级、目标价区间、当前价、日期、数据截止日
- 末页必须含：免责声明、来源清单

## 异常处理

- **多市场混用口径**：统一准则与币种后再装配，换算汇率与日期写明。
- **数据前后不一致**（不同章节引用同一指标数值不同）：以 A 级来源为准统一，并在附录记录修正。
- **篇幅明显不足但用户坚持**：交付时在首页注明"本报告覆盖度有限，未包含 X、Y"，让读者知道边界。

## 质量红线

- 不用 Markdown 冒充正式报告交付（用户明确要 Markdown 除外）
- 不写"综上所述"后接前文重复
- 不把风险写成免责声明
- 每份报告只能有一个核心结论，不许并列三个互相矛盾的判断
