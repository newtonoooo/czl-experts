# 决策备忘

推介是说服，备忘是帮忙做决定。区别在于：**备忘必须把反对自己的证据完整摆出来，并且允许结论是"不做"。**

## 职责

**做**：把散落研究整合成可拍板的文件，含多空两面、概率加权回报、执行计划、推翻条款。
**不做**：不做新研究（引用上游），不做仓位计算细节（`czl-position-plan`）。

## 输入参数

| 参数 | 必填 | 说明 | 缺失处理 |
|---|---|---|---|
| 备忘类型 | **是** | 新建仓 / 加减仓 / 退出 / 观察名单 | 必须问清，四种结构不同 |
| 公司或标的 | 是 | — | 问 |
| 上游结论 | 是 | 估值区间、论点、财报结论 | 缺则先补，不用占位 |
| 组合规模与风险预算 | 加减仓必需 | 推导仓位 | 缺 → 仓位写"待定 + 约束条件" |
| 现有持仓与成本 | 加减仓/退出必需 | 判断边际变化 | 缺 → 先索取，**不得代填** |
| 决策时限 | 否 | 时间紧时影响证据要求 | 默认不限 |

## 依赖与关系

- **上游**：`czl-model-value`、`czl-earnings-read`、`czl-thesis-log`
- **下游**：`czl-position-plan`（落地执行）、`czl-thesis-log`（入库跟踪）
- **横向**：见 `czl-verdict-standard.md` 与 `czl-delivery-standard.md`

## 执行步骤

### 第一步：定类型，四种写法不同

| 类型 | 必须额外回答 |
|---|---|
| 新建仓 | 为什么不买别的（机会成本） |
| 加仓 | 相对于现有仓位，边际新信息是什么 |
| 减仓 / 退出 | 是论点被推翻、价格到位，还是机会成本变了 |
| 观察名单 | 缺哪一块证据，什么条件下升级为正式研究 |

### 第二步：摘要先行

先写三到五句执行摘要，写不出说明还没想清楚。摘要必须含：标的是什么、为什么现在、目标回报、最大风险、建议动作。

### 第三步：摆事实（半页）

生意一句话、关键财务（市值、收入、利润、增速、行业关键指标）、股东与治理、近期股价与催化。**全部带报告期。**

### 第四步：论点支柱

3–5 条，每条含：

- 陈述
- 证据（定量为主，带来源与日期）
- **信心水平（高/中/低）**

信心水平必须诚实。全套"中"通常意味着没有真正评估过证据强度。

### 第五步：两头都写

这是备忘与推介的分界：

```
支持理由（最强的一条放最前）
反对理由（最强的一条放最前）
我们为什么不采纳反对理由 —— 逐条回应
```

反对理由不得放进脚注，不得用一句话带过。

### 第六步：概率加权回报

| 情景 | 概率 | 目标价 | 回报 | 关键假设 |
|---|---|---|---|---|
| 乐观 | X% | | +X% | |
| 基本 | X% | | +X% | |
| 悲观 | X% | | -X% | |

概率合计 100%。算出概率加权期望回报，并**对比机会成本**：现金、宽基指数、组合内现有替代标的。不比机会成本的推荐是不完整的。

### 第七步：风险与推翻条款

Top 5 风险，按"概率 × 影响"排序：

| 风险 | 概率 | 影响 | 缓释 |
|---|---|---|---|

**推翻条款**：什么可观察事实出现即判定为该决定错了。必须能被第三方独立判定。

**最差情景**：极端情况下的最大损失金额（不是百分比），以及这个金额是否可承受。

### 第八步：执行计划

建仓方式（一次/分批）、目标仓位与推导依据、加减规则、退出规则、预期持有期、流动性评估。

仓位不给数字时，给公式和所需输入项。

### 第九步：结论

四选一：**买入 / 卖出 / 持有 / 观察名单**。附信心、待确认事项、下次复盘日期。

## 判断条件

| 判据 | 处置 |
|---|---|
| 证据不足支撑结论 | 给"观察名单"，列缺哪几项证据、何时能拿到。不硬凑成买入 |
| 多空证据势均力敌 | 结论就是"等待证据"，写清等的是什么 |
| 缺组合数据 | 仓位写"待定"，附公式与所需输入 |
| 决策时限极短 | 摘要中明示"本备忘在 X 小时内完成，未覆盖 A、B" |
| 机会成本明显更优 | 直接给"不做"或"买替代标的" |

## 输出格式

```
════════════════════════════════════
投资决策备忘 | [标的]（[代码]）
类型：新建仓 / 加减仓 / 退出 / 观察    日期：YYYY-MM-DD
════════════════════════════════════
一、执行摘要（3–5 句）
二、建议        方向 | 目标价区间 | 信心 | 时间维度 | 仓位（或待定）
三、事实快照    生意 / 财务 / 治理 / 催化，全部带报告期
四、支持理由    （最强在前，每条带数字）
五、反对理由    （最强在前）+ 逐条回应
六、概率加权回报 三情景 + 期望值 + 机会成本对比
七、风险与推翻条款（Top5 + 推翻条件 + 最差情景金额）
八、执行计划    方式 / 规则 / 流动性
九、待确认事项与下次复盘日
十、附录        数据表 / 可比 / 来源清单
════════════════════════════════════
本备忘仅供研究讨论，不构成个人投资建议。数据截止 YYYY-MM-DD
```

## 异常处理

- **上游估值缺失**：不给目标价，改为"方向 + 需要的估值输入"，并在摘要首句说明。
- **加减仓但无持仓成本**：先索取；拿不到则只给"是否值得增加暴露"的判断，不给量。
- **用户要求"只写看好的一面"**：拒绝，说明备忘的功能是支持决策，单边材料会被任何一次质询击穿。
- **同一标的有两份互相矛盾的上游结论**：摆出两份并说明分歧点，不要静默选一个。

## 质量红线

- 没有反对理由的备忘，视为推介而非备忘
- 信心水平全套"中"，视为未评估
- 概率合计不到 100%，视为未完成
- "择机建仓"这类无法执行的表述一律不用
- 正文塞满细节、决策者看不到摘要，视为格式失败
