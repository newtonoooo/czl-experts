# 行业扫描

行业报告最容易变成资料汇编：市场多大、增速多少、有哪几家。这些是背景。这一模块的产出必须回答一句：**这条链上钱留在哪一环，这个行业当下只交易哪一两个变量。**

## 职责

**做**：产业链利润池定位、集中度与壁垒、行业交易变量、标的筛选与排序。
**不做**：不做单票估值（`czl-model-value`），不做行业公司的深度尽调（`czl-company-map`）。

## 输入参数

| 参数 | 必填 | 说明 | 缺失处理 |
|---|---|---|---|
| 行业或子行业 | 是 | 边界必须明确 | 给的是大词（如"新能源"）→ 先问子环节，否则结论无意义 |
| 用途 | 是 | 对外报告 / 内部立项 / 找标的 | 未说明则默认找标的 |
| 地域范围 | 建议 | 国内 / 全球 | 默认与用户市场一致 |
| 筛选条件 | 找标的时必需 | 市值段、风格、排除项 | 缺则默认不限，并在结果标注 |
| 时间窗 | 否 | 判断景气位置 | 默认近三年 + 未来两年 |

## 依赖与关系

- **上游**：无（可独立启动）
- **下游**：`czl-company-map`（逐个看候选）、`czl-model-value`（给候选定价）
- **横向**：来源分级见 `czl-evidence-standard.md`

## 执行步骤

### 第一步：先把边界钉死

"本报告覆盖范围为 XXX"，写不出来就先别写。边界包括：产品口径、上下游切到哪、地域、是否含非上市。

同一句"储能"，只做电芯、只做 PCS、做系统集成，三种口径的结论可以完全相反。

### 第二步：画钱流图，找利润池

不要只画产业链框图和箭头。每个环节标三样：

| 环节 | 毛利率 | 议价权（对上游/对下游） | 集中度 |
|---|---|---|---|

然后回答：**利润池在哪一环？** 常见情形是收入规模最大的一环利润最薄，而某个不起眼的中间环节拿走了大部分利润。

利润池位置决定后面所有判断，必须先定。

### 第三步：判断结构与壁垒

- **集中度**：前五份额。分散行业里"份额提升"的故事要格外谨慎。
- **壁垒类型**：只认五类——资本门槛、牌照与准入、技术专利、网络效应、切换成本。其余说法视为叙事。
- **壁垒在变强还是变弱**：这是判断长期盈利能力的核心，比当期增速重要。

### 第四步：找这个行业只交易的那一两个变量

每个行业当下都有一两个真正驱动估值的变量，其余是噪音。判断方法：

1. 看过去两年行业指数与该变量的相关性
2. 看卖方研报反复争论的是哪一个
3. 看公司电话会上被问最多的是什么

写成一句话，例如："这个行业当下只交易两件事：单位成本下降速度、以及补贴政策的延续性。"

**这一句是本模块的核心产出，写不出来等于没做。**

### 第五步：估值坐标

- 行业当前倍数与自身历史区间（看分位）
- 溢价/折价的来源（增速、利润率、格局）
- 近期并购交易倍数（最硬的锚）

### 第六步：标的筛选（用途为找标的时）

1. 把筛选条件翻译成**可复核的阈值**并全部写出来
2. 先剔拥挤：股东结构、空头比例、覆盖机构数、近三个月涨幅。拥挤的地方没有 alpha
3. 每个候选必须写出三样，写不出就删：
   - 一句话假设：市场现在怎么想，我认为哪里不对
   - 下一步验证动作：查哪张表、哪个指标、哪次会
   - 最快被推翻的方式：什么数据出现就说明错了
4. 按赔率、证据可得性、时间窗口排序，不按代码排

## 判断条件

| 判据 | 处置 |
|---|---|
| 行业口径过宽（跨多个商业模式） | 拆成子环节分别分析，不做强行概括 |
| 利润池无法定位（数据不透明） | 改用上市公司分部毛利反推，标注为间接推断 `[假设]` |
| 筛出 0 个候选 | 有效结果，说明是哪条约束卡住，不放低阈值硬凑 |
| 筛出 30 个以上 | 条件太松，先按拥挤度砍到 10 个以内 |
| 第三方市场规模数据互相矛盾 | 并列多口径 + 来源，选一个主口径并注明 |

## 输出格式

**行业分析**：

```
一、范围界定      口径 / 地域 / 时间 / 是否含非上市
二、钱流图        各环节毛利率、议价权、集中度
三、利润池        钱留在哪一环，为什么
四、结构与壁垒    集中度趋势，壁垒类型与强弱变化
五、交易变量      这个行业当下只交易哪一两件事 ← 核心
六、估值坐标      当前倍数 / 历史分位 / 并购倍数
```

**标的筛选**（叠加在上）：

```
七、筛选阈值      全部条件与数值
八、候选表        代码 | 名称 | 市值 | 关键倍数 | 一句话假设 | 拥挤度 | 下一步
九、优先级        先研究谁、为什么这么排
```

## 异常处理

- **市场规模数据只有付费源**：改用上市公司收入合计倒推，标为下限估计并说明方法。
- **子行业无上市公司**（纯一级市场）：说明无法用公开数据验证，结论降级为定性判断。
- **行业正在发生技术路线切换**：不做单一假设，按两条路线分别给情景，并指出切换的观测指标。
- **用户给了宽泛大词**：先给拆解建议（把大词拆成 3–5 个子环节），让用户选，不要自作主张选一个。

## 质量红线

- 不写"行业前景广阔"就收尾
- 价值链不标毛利率，等于没画
- 交易变量写成"增长与政策"，太笼统，必须具体到可观测指标
- 候选清单没有"下一步验证动作"，视为无效清单
