# 建模与定价

把"这家公司值多少"变成一个**别人能复算的区间**，而不是一个看着专业的数字。

## 职责

**做**：三表模型、DCF、相对估值、分部估值（需要时）、敏感性、目标价区间与评级。
**不做**：不做仓位（`czl-position-plan`），不做报告排版（`czl-report-build`）。

## 输入参数

| 参数 | 必填 | 说明 | 缺失处理 |
|---|---|---|---|
| 标的 | 是 | — | 问 |
| 历史财务（3–5 年三表） | 是 | 建模基数 | 拿不到则停止，说明缺什么 |
| 会计准则与币种 | 是 | 口径统一 | 从公告确认 |
| 稀释后股数 | 是 | 决定每股价值 | 缺则重算，标 `[假设]` 并提示 |
| 净债务与少数股东权益 | 是 | EV → 股权价值 | 缺则只给 EV，不给每股价值 |
| 无风险利率、β、股权风险溢价 | 是 | WACC 三要素 | 缺则给行业区间并标 `[假设]` |
| 可比公司范围 | 否 | 相对估值用 | 默认同市场同子行业 |

## 依赖与关系

- **上游**：`czl-company-map`（业务与单位经济）、`czl-earnings-read`（最新业绩）
- **下游**：`czl-report-build`、`czl-decision-memo`、`czl-position-plan`
- **横向**：方法论边界见 `czl-verdict-standard.md`

## 执行步骤

### 第一步：从单位经济搭收入

不要直接给增长率。先回到 `czl-company-map` 的单位经济，按 `量 × 价` 或 `客户数 × 单客收入` 推，再折成总增速。这样每一个增速假设都能被追问来源。

### 第二步：三表联动

利润表 → 资产负债表 → 现金流量表，三张必须闭合：

- 资产 = 负债 + 权益
- 现金变动与现金流量表一致
- 营运资金按周转天数推，不按收入比例拍

```
自由现金流（企业口径）= EBIT × (1 - 税率) + 折旧摊销 - 资本开支 - 营运资金增加
```

**不闭合的模型不许往下用**，先找平衡项。

### 第三步：算折现率

```
股权成本 = 无风险利率 + β × 股权风险溢价（+ 规模溢价，如适用）
债务成本 = 借款利率 × (1 - 税率)
加权成本 = 股权成本 × 股权占比 + 债务成本 × 债务占比
```

四个输入各自写来源：哪一期国债、β 用多长窗口、风险溢价用哪家口径。**抄行业惯例的 WACC 等于没有 WACC。**

### 第四步：DCF

```
企业价值 = 预测期现金流现值 + 终值现值
终值 = 末年现金流 × (1 + 永续增长率) ÷ (加权成本 - 永续增长率)
股权价值 = 企业价值 - 净债务 - 少数股东权益 + 联营投资
每股价值 = 股权价值 ÷ 稀释后股数
```

永续增长率不得超过长期名义经济增长。终值占企业价值超过 75%，必须在结论里明写"本估值主要由终值假设驱动"。

### 第五步：至少再一种方法

| 方法 | 适用 | 关键 |
|---|---|---|
| 相对估值（可比公司） | 有足够同类标的 | 每家可比公司写入选理由；用中位数与分位数，不用均值 |
| 分部估值 | 业务差异大的集团 | 各分部独立估值后加总，扣控股折价 |
| 资产价值 | 地产、资源、重资产 | 资产重估与隐含折价 |
| 股息折现 | 稳定高派息的成熟公司 | 派息率与增长率 |

**行业特殊口径**（用之前先说清为什么）：银行看市净率与净资产收益率的关系，保险看内含价值，地产看资产净值，SaaS 看收入倍数与增长质量关系，生物医药看管线风险调整价值。

### 第六步：敏感性与情景

- 双变量矩阵 5×5，标注基本情景所在格
- 三情景各给概率（合计 100%）
- 反推一句：**当前股价对应的是哪一组假设**

## 判断条件

| 判据 | 处置 |
|---|---|
| 三表不闭合 | 停止，修模型，不带病输出 |
| 终值占比 > 75% | 结论中明示依赖终值；补做退出倍数法交叉验证，两者差异大要解释 |
| 两种方法结果差异 > 40% | 不得简单加权，须说明差异来源（周期位置、可比性、口径）并给出取舍理由 |
| 亏损公司 | DCF 可用（现金流口径），须写明亏损期长度与转正条件；不使用市盈率 |
| 周期性行业 | 用中周期正常化盈利，不得用周期顶/底一年数据外推 |
| 数据不足无法建模 | 只给方向与情景框架，不给目标价；标 `[MISSING]` |

## 输出格式

```
一、口径声明      市场 / 准则 / 币种 / 数据截止 / 股数口径
二、关键假设表    假设项 | 取值 | 来源 | 事实还是判断
三、三表摘要      收入/利润/现金流三年预测要点
四、DCF 结果      每股价值 + 终值占比
五、相对估值      可比表（含每家入选理由）+ 隐含区间
六、敏感性矩阵    5×5，标注基本情景格
七、情景与概率    悲观/基本/乐观 + 概率 + 每股价值
八、结论          评级 | 目标价区间 | 当前价 | 隐含空间 | 置信度 | 推翻条件 | 复核时点
九、当前股价隐含什么假设
```

**目标价必须给区间**。点估计只作为区间内的参考值出现。

## 异常处理

- **股数口径不明**（期权、可转债、回购未定）：按最稀释口径算一遍、按当前口径算一遍，两个结果都给，说明差额。
- **会计政策变更**：先按新口径重述历史，再建模；无法重述则注明口径断裂，只做区间不报趋势。
- **汇率**：多币种业务统一到报告币种，写明换算汇率与日期。
- **可比公司少于 5 家**：说明样本不足，相对估值降为参考，以 DCF 为主。

## 质量红线

- 假设表缺任何一行，估值结论不得对外
- 不写"当前股价隐含什么假设"的估值，等于没做定价
- 不给区间只给点值，视为未完成
- 不许用行业平均替代缺失的本公司数据
