# 财报解读

同一份财报，两个问题：**业绩发布前该怎么看**，**发布后到底改变了什么**。方向搞反，整篇作废。

## 职责

**做**：业绩前瞻、业绩归因、质量判定、估计修正、论点影响。
**不做**：不做完整估值（`czl-model-value`），不做组合动作（`czl-position-plan`）。

## 输入参数

| 参数 | 必填 | 说明 | 缺失处理 |
|---|---|---|---|
| 公司 + 报告期 | 是 | — | 问 |
| 业绩公告原文或正式新闻稿 | 分析模式必需 | 判定依据 | 拿不到则只做前瞻，并说明 |
| 共识预期 | 前瞻模式必需 | 判断预期差的基准 | 缺失则用自身估计，标 `[假设]`，不得称其为"共识" |
| 上期指引 | 建议 | 判断指引变化 | 缺失可略，但需注明 |
| 电话会记录 | 建议 | 管理层表述 | 拿不到要明说"未获取电话会内容" |

## 依赖与关系

- **上游**：`czl-company-map`（知道业务才能解释分部变化）
- **下游**：`czl-model-value`（改估值）、`czl-thesis-log`（记论点变动）、`czl-report-build`（要出业绩报告）
- **横向**：来源分级见 `czl-evidence-standard.md`

## 执行步骤

### 第一步：判定模式

1. 确认公司与报告期
2. 查该期是否已披露
3. **已披露 → 分析模式；未披露 → 前瞻模式**
4. 已披露但超过一个季度未更新 → 先确认是否拿错了期，再决定是否动手

> 财报数据必须当期检索。记忆中的数字一律不可用。

### 第二步（前瞻模式）：建立观察框架

1. 收集共识：收入、每股收益、关键运营指标、发布日期与时段
2. 把指标**排序**，只留投资者真正盯的 2–3 个，其余归入附表
3. 三情景表：乐观 / 基本 / 悲观，各给收入、每股收益、关键驱动、可能的股价反应方向
4. 催化清单：决定市场反应的三到五个因素，按权重排
5. 波动预期：期权隐含波动与历史业绩日实际波动对比——这决定赔率而不只是方向

### 第三步（分析模式）：先定性，再定量

1. **超没超**：收入、每股收益、关键指标、指引，四项分别对比共识
2. **好事还是账面好事**：这句话必须先说——
   - 质量型：量价齐升、结构改善、份额提升
   - 账面型：低基数、一次性收益、费用递延、税率下降、汇兑
   两类对后续估值的含义完全不同
3. **拆归因**：分部 / 区域 / 产品；毛利率与费用率变动逐项归因到价格、结构、规模、一次性
4. **分列一次性项目**：与可持续盈利能力分开列，不得混在一起讲
5. **读管理层表述**：只引用原文要点，不转述语气

### 第四步：改估计

| 项目 | 原估计 | 实际 | 差异 | 原因 |
|---|---|---|---|---|

再把前瞻估计逐项更新：原本年、新本年、原下一年、新下一年，并逐条说明改了什么假设、为什么改。

### 第五步：判性质

这是全篇最重要的一句，必须明确落到三者之一：

- **论点级**：关键支柱被证实或被推翻 → 动评级/仓位
- **估计级**：数字挪了逻辑没变 → 调目标价，评级不变
- **噪音**：一次性、可逆、非经常 → 记录，不动手

## 判断条件

| 判据 | 处置 |
|---|---|
| 收入超预期但经营性现金流恶化 | 判为质量存疑，重点查应收与存货 |
| 每股收益超预期但收入不及 | 判为账面型，查一次性收益与税率 |
| 指引下调但当期超预期 | 以指引为准，市场通常交易指引 |
| 口径变更（分部调整、会计政策） | 先按新口径重述历史再比较；无法重述则不做同口径趋势结论 |
| 拿不到共识 | 改为"自身估计 vs 实际"，标明不是共识 |

## 输出格式

**前瞻模式**（一页纸）：

```
共识表 → 必须关注的 2–3 个指标及理由 → 三情景表 → 催化清单 → 交易设置（含"预期是否已打满"）
```

**分析模式**（结构化短文，不必凑页数）：

```
一、一句话结论      质量型 or 账面型，对论点影响是论点级/估计级/噪音
二、四项对比表      收入 / 每股收益 / 关键指标 / 指引
三、归因            分部与费用率，一次性项目单列
四、估计修正        旧→新，逐条说明假设变化
五、估值影响        目标价区间如何移动
六、下一个验证点    看什么、什么时候能看到
```

两种模式都以数据截止日 + 免责声明收尾。

## 异常处理

- **业绩已发布但未获取公告原文**：只用可核实的数据，明确写"未取得公告原文，部分项目缺失"，不得凭二手报道下结论。
- **公司未按季披露**（部分港股、部分海外市场）：按半年报口径处理，说明频率差异。
- **数据源冲突**（不同数据库每股收益口径不同）：以公司公告为准，注明其他来源差异原因。
- **公司撤回指引**：这是重大信号，单独成段说明，不要并入普通表述。

## 质量红线

- 不许用上一季或去年同期数字冒充本期
- 不许把股价涨跌当成业绩好坏的证据——先看预期差
- 不写"业绩超预期"却不给对比基准
- 一次性项目不拆分，视为未完成
