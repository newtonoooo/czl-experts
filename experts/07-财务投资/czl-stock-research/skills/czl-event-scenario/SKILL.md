# 事件情景

用户问的是"会发生什么"，你要回答的是"**市场已经假设了什么，所以真实结果会落在哪一侧**"。这两个问题差一层，差的那一层就是全部价值。

## 职责

**做**：事件定性、历史类比、传导链、概率分布、敏感性矩阵、隐含假设反推。
**不做**：不做完整估值（`czl-model-value`），不做仓位（`czl-position-plan`）。

## 输入参数

| 参数 | 必填 | 说明 | 缺失处理 |
|---|---|---|---|
| 事件描述 | 是 | 什么事、涉及谁 | 说不清则不分析，先问 |
| 时点 | 是 | 确定日期或预期窗口 | 未知 → 标"软窗口"并给观察方式 |
| 当前价格 | **是** | 反推隐含假设的前提 | 无价格则不做本模块最有价值的那一步，需说明 |
| 估值锚 | 建议 | 现有目标价或倍数 | 缺 → 做简化锚并标 `[假设]` |
| 是否持仓 | 否 | 决定要不要给动作 | 无 → 只给事件影响 |
| 关键变量候选 | 否 | 做敏感性用 | 按事件类型自动选 |

## 依赖与关系

- **上游**：`czl-model-value`（估值锚）、`czl-earnings-read`（若事件为业绩）
- **下游**：`czl-position-plan`（事件前后动作）、`czl-thesis-log`（记录事件对论点的影响）
- **横向**：结论标准见 `czl-verdict-standard.md`

## 执行步骤

### 第一步：把事件归到一类

| 类型 | 例子 | 影响窗口 | 特点 |
|---|---|---|---|
| 业绩类 | 财报、预警、指引调整 | 1–5 个交易日 | 高频、可类比 |
| 公司行动 | 并购、分拆、回购、增发、换帅 | 1–20 个交易日 | 一次性、路径复杂 |
| 监管类 | 政策、审批、裁定 | 即时到数月 | 二元、尾部厚 |
| 行业类 | 对手动作、技术突破、供需变化 | 数周到数月 | 传导慢、易被低估 |
| 宏观类 | 利率、汇率、贸易、地缘 | 即时到数月 | 影响面广、个体差异大 |

类型决定后面用什么方法：业绩类适合历史类比，监管类适合概率树，宏观类适合敏感性。

### 第二步：找可类比先例（不是找平均值）

1. 找 3–5 个同类先例
2. 每个记录：当时的预期、实际结果、股价反应幅度、持续时间
3. **归纳的是量级，不是均值**。写下"这类事件通常反应 X%–Y%，持续 Z 天"，不要写"平均反应 4.2%"

先例不可比时要明说，不要硬套。

### 第三步：画传导链（三层）

不要跳步。事件到股价之间必须有可描述的链条：

```
短期（交易日）  情绪与仓位调整 → 涨跌幅
中期（季度）    预期修正 → 盈利预测变化 → 倍数重估
长期（年度）    基本面结构变化 → 竞争格局或商业模式改变
```

每一层写清：改变了哪个财务科目、改变多少、什么时候体现在报表上。**写不出中期这一层的，说明事件影响不了基本面，只是情绪。**

### 第四步：给概率，不给伪精确

| 结果 | 概率 | 股价影响 | 基本面影响 |
|---|---|---|---|
| 好于预期 | X% | +X% | — |
| 符合预期 | X% | ±X% | — |
| 差于预期 | X% | -X% | — |
| 概率加权 | | ±X% | |

概率合计 100%。估不准就给区间（如 30%–45%）并说明为什么宽，**不要写 42% 这种没有依据的精确值**。

### 第五步：敏感性

挑 2–4 个对结论影响最大的变量，做双变量 5×5 矩阵。常见组合：

- 政策力度 × 执行时间
- 收入增速 × 利润率
- 折现率 × 永续增长率
- 份额变化 × 行业增速

标注基本情景格，并排出弹性顺序（哪个变量最要命）。

### 第六步：反推当前价格隐含什么

这是本模块不可省的一步：

> 当前价 ¥XX 对应的是"增速 X%、利润率 Y%、倍数 Z 倍"这一组假设。若事件结果低于这组假设，股价下行；高于则上行。

有了这一句，用户才知道自己在赌什么。

## 判断条件

| 判据 | 处置 |
|---|---|
| 事件无法影响中期基本面 | 明说"这是情绪事件，不改变盈利预测"，只给短期影响 |
| 找不到可比先例 | 写"无可靠先例"，改用基本面推演，不硬套均值 |
| 变量高度相关（如增速与利润率同向） | 改用命名情景组合，不用单变量交叉 |
| 概率估不出 | 给区间 + 理由，不给点值 |
| 极端情景损失超过组合可承受范围 | 单独警示，并建议转 `czl-position-plan` 处理 |

## 输出格式

```
一、事件定性      类型 / 时点 / 二元还是连续
二、可比先例      3–5 个，含量级区间与持续时间
三、传导链        短期 / 中期 / 长期，逐层写改变哪个科目
四、概率分布表    三档 + 概率 + 股价影响 + 概率加权
五、敏感性矩阵    5×5，标注基本情景，附弹性排序
六、隐含假设      当前价对应哪一组假设 —— 本模块核心结论
七、动作建议      事前布局 / 事后反应 / 对冲 / 观望，四种成本都算
```

## 异常处理

- **事件时间完全未知**：单列"时点未知但重要"，给观察方式（盯什么公告、什么渠道、什么频率）。
- **消息未经证实**（传闻、市场传言）：标注"未证实"，分"若属实"与"若不属实"两条路径各给影响。
- **同一事件有多个版本的政策文本**：以正式发布稿为准，草案仅作情景输入并注明。
- **用户问"涨还是跌"**：不回答方向点值，改给区间、概率与隐含假设。

## 质量红线

- 讨论事件"好不好"而不讨论"相对预期如何"，视为跑偏
- 没有概率的清单不是情景分析
- 不写"当前价格隐含什么"，视为未完成
- 概率必须合计 100%，不许只给其中两档
