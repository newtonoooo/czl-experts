# 公司画像

给一个第一次接触的公司，产出**一页能用来做决定**的画像，而不是一份公司简介。

## 职责

**做**：说清生意逻辑、收入结构、单位经济、竞争位势、数据口径。
**不做**：不做估值判断（那是 `czl-model-value`），不写行业长文（那是 `czl-sector-scan`）。

## 输入参数

| 参数 | 必填 | 说明 | 缺失处理 |
|---|---|---|---|
| 公司名称或代码 | 是 | — | 缺则直接问，不猜 |
| 市场 | 建议 | 决定报告期与会计准则 | 由上下文推断，输出中声明所用口径 |
| 指定报告期 | 否 | 用户有特定要求时 | 默认取当前可得最新一期 |
| 关注点 | 否 | 用户特别在意某项（如现金流、海外占比） | 无则按标准结构 |

## 依赖与关系

- **上游**：无（可独立启动）
- **下游**：`czl-model-value`（要定价）、`czl-earnings-read`（要看某期业绩）、`czl-thesis-log`（要把假设记下来）
- **横向**：所有输出遵守 `czl-evidence-standard.md`

## 执行步骤

1. **定口径**。市场、财年截止日、记账币种、会计准则四项先定下来，写在最前面。这四项不写，后面的数字无法比较。
2. **一句话说清怎么赚钱**。写不出这一句，说明还没看懂，不要往下写。
3. **拆收入结构**。按业务线 / 产品 / 区域 / 客户类型至少拆一层，标出各自占比与增速方向。只有总数没有结构，等于没有信息。
4. **算单位经济**。找出这门生意的基本单元（一辆车、一个门店、一个用户、一吨产能、一单交易），看单单元的收入、成本、毛利、回收期。这一步决定了后面模型能不能立住。
5. **定位竞争位势**。对手是谁、凭什么不被替代、份额在升还是在降。护城河只认三样：切换成本、规模效应、牌照或资源独占。其余说法视为叙事。
6. **找矛盾点**。这家公司身上最说不通的地方是什么（高增长却低现金流、高毛利却低 ROE、份额升却降价）。矛盾点往往就是后面研究的入口。

## 判断条件

| 判据 | 处置 |
|---|---|
| 拿不到当前应有报告期，只能拿到更早一期 | 标 `[STALE]`，并在页首注明实际采用日期 |
| 收入结构无法拆分（公司只披露总数） | 说明披露受限，改用成本结构或产能结构侧写，并标注为间接推断 `[假设]` |
| 单位经济算不出（数据不足） | 明确写"单位经济无法测算，缺 X"，不要用行业平均硬代 |
| 业务已发生重大变化（重组、剥离主业） | 以变化后的口径为主，历史数据仅作参考并注明不可直接比较 |

## 输出格式

一页，固定七块：

```
① 口径       市场 / 财年 / 币种 / 准则 / 数据报告期
② 生意       一句话：卖什么给谁，怎么收钱
③ 收入结构   业务线或区域占比 + 增速方向（表格）
④ 单位经济   基本单元 + 单单元收入/成本/毛利/回收期
⑤ 位势       主要对手 / 份额方向 / 护城河来源（只认三类）
⑥ 矛盾点     最说不通的一到三处
⑦ 下一步     建议进哪个模块，以及需要先补哪项数据
```

页脚固定：数据截止日 + 「仅供研究参考，不构成个人投资建议」。

## 异常处理

- **非上市公司**：改用招股书、评级报告、债券募集说明书；在页首标明"非上市，数据可靠性为 B 级"。
- **同一指标多个来源打架**（如市值含/不含限售股）：并列两个数值并注口径，不选一个蒙过去。
- **关键项拿不到**：写 `[MISSING]`，留空比估算好。空缺本身就是决策信息。
- **公司业务极度多元**：不做强行概括，改为分板块各给一句话，并提示应进 `czl-model-value` 的分部估值分支。

## 质量红线

- 没有报告期的数字，一律不写
- "致力于成为行业领导者"这类话一句都不要出现
- 护城河结论必须有可验证依据（客户留存、单位成本曲线、牌照清单），不接受叙事
- 矛盾点必须写，写不出说明看得不够
