# 专业回测台 · Pro Backtest Desk

一个把「一句话的交易想法」变成**可复算、可挑错、能拿去讨论**的回测的 WorkBuddy 专家。

不是选股器，不给目标价，不预测涨跌。它做四件事：锁口径、验数据、写代码、挑自己的错。

- 开发者：虫志龙（47190078@qq.com）
- 版本：1.0.0
- 适用平台：WorkBuddy（专家中心 · 自定义专家）
- 运行依赖：Python 3.9+（**只用标准库，不需要 pandas / numpy / matplotlib**）；报告自检脚本可选 Node 14+

---

## 它能做什么

| 场景 | 例子 |
|---|---|
| 规则型策略回测 | "沪深300ETF，MA20 上穿 MA60 买、下穿卖，2020 年至今，扣费后赚不赚" |
| 事件研究 | "央行降息后持有 20 个交易日，平均收益、中位数、胜率" |
| 组合轮动 | "两只 ETF 谁 20 日动量强就持谁，每 5 个交易日看一次" |
| 稳健性 / 成本压力 | "这组参数是不是过拟合""成本翻 4 倍还成立吗" |
| **复核别人的回测** | "我这套年化 80%、夏普 5，帮我审一下哪儿是未来函数" |

不做的：分钟/Tick 级、期权与可转债定价、完整多因子截面选股流水线。

## 三分钟自检（装完先跑这个）

在专家包根目录执行：

```bash
python tools/selftest.py                    # 1) 内核 13 例自检
python kit/examples/run_ma_cross.py         # 2) 均线策略：出三件套 + index.html
python kit/examples/run_event_study.py      # 3) 事件研究
python kit/examples/run_rotation.py         # 4) 双标的轮动
node tools/check_report.js out/index.html   # 5) 报告渲染自检（可选，需 Node）
```

全绿说明：撮合、费用、手数、T+1、预热隔离、强平、指标、导出、报告都能跑通。

> `data/demo_bars.csv` 是**合成数据**（`tools/gen_demo_bars.py` 用固定随机种子生成），
> 只用来验证流程，不是任何真实标的的行情。看到 -8% 这类的数字不要当结论。

## 设计上的四个取舍

1. **不依赖 pandas**。很多人机器上没有 pandas，一装就报错。内核只用 `csv/math/statistics/json`，装到哪都能跑；代价是速度慢一些（千根 bar 级别无感）。
2. **报告自己画图，不用 matplotlib**。matplotlib 中文字体在 Windows 上经常豆腐块，且要额外装。报告用内联 SVG，双击 HTML 就能看，还能直接发给别人。
3. **默认做稳健性扫描**。只给一个参数下的收益，是回测最常见的骗人方式。包里把参数扫描与成本压力做成默认动作。
4. **把"审计"当独立工作流**。跑通 ≠ 可信。审计单要求逐项给证据，找不到问题也要写"怀疑过什么、怎么排除"。

## 已知边界

- 日线级别；不还原盘中触发顺序，止损/止盈成交价是近似值
- 不建模冲击成本、涨跌停无法成交、停牌期间的撮合细节
- 参数扫描不替代样本外验证（分段回测可以，但不是严格 walk-forward）
- 所有结果仅用于研究与复核，不构成投资建议
