# 更新日志

格式：语义化版本。每条写清「变了什么」和「对用户意味着什么」。

## 1.0.0 — 2026-10-28

首个发布版本。

### 新增

- **五条工作流**：立项与口径锁定 → 取数与体检 → 引擎构建 → 对抗式自检 → 交付与复现，每一步都有输入/判断/输出/异常出口。
- **回测内核 `kit/btcore.py`**（纯标准库）
  - 次日开盘成交的 pending 队列，天然隔离未来函数
  - 账户恒等式 `equity = cash + Σ(数量×收盘价)`
  - 佣金（含最低收费）/ 印花税 / 过户费 / 滑点参数化，A 股/港股/美股三套预设
  - 手数取整、T+1 锁定、样本末强制清仓（`eod_close`）
  - 指标：累计/年化收益、年化波动、夏普、索提诺、卡玛、最大回撤及谷底日期、胜率、盈亏比、在场时间、费用合计
  - 事件研究：`event_study` / `event_stats`，样本不足不伪造
  - 参数扫描：`param_sweep`，单点失败不拖垮整表
- **报告引擎 `kit/btreport.py` + 自包含模板**：KPI 六卡、净值曲线（含基准与成交标记）、回撤、单笔盈亏分布、月度热力表、成交明细、口径说明、免责声明；中文/英文双语；无 CDN、无字体依赖。
- **三个可运行范例**：均线交叉（含参数扫描与成本压力）、事件研究、双标的动量轮动。
- **工具**：`selftest.py`（13 例）、`check_report.js`（9 项渲染检查）、`bars_from_table.py`（Markdown/TSV/CSV → 内核契约）、`verify_avatar.py`（头像配置体检）、`shrink_avatar.py`（纯标准库 PNG 裁剪缩放）、`gen_demo_bars.py`（合成演示数据）。
- **文档**：产品规格、使用说明、平台文案、文件清单、开发记录、功能测试报告、商业发布风险清单、版权与来源说明。

### 设计决定

- 不依赖 pandas / numpy / matplotlib：装到任何有 Python 的机器都能跑，代价是速度略慢。
- 报告自绘 SVG 而非 matplotlib：避免中文字体豆腐块，且报告可单文件转发。
- 稳健性与成本压力做成默认动作，而不是可选项。
- 审计独立成工作流：跑通不等于可信，未过审计不得交付。

### 已知问题

- 日线无法还原盘中触发顺序，止损/止盈成交价为近似值（文档已注明，不打算在 1.x 修复）。
- 参数扫描不替代严格 walk-forward，计划在 1.1 增加分段辅助函数。
- 组合模式只支持「一仓一只 + 目标权重」，尚未支持持仓数量约束与再平衡偏离阈值（计划 1.2）。
