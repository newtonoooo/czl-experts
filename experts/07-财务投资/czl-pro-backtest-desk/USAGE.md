# 使用说明

## 一、安装

1. 打开 WorkBuddy → 左侧「专家」→「我的专家」→ 导入专家包（`czl-pro-backtest-desk.zip`）。
2. 导入后重启一次客户端（让专家列表与头像重新扫描）。
3. 在会话右下角选择「专业回测台」，开始对话。

> 如果导入后小图标显示成"名字首字"的色块，见文末「头像排查」。

## 二、怎么问（越具体越省时间）

### 最少信息版（专家会追问 1—3 个问题）

> 帮我回测一个策略：沪深300ETF，MA20 上穿 MA60 买入，下穿卖出，2020 年至今。

### 一次说清版（推荐）

> 回测沪深300ETF（510300），收盘价 MA20 上穿 MA60 买入、下穿卖出，每次满仓，次日开盘成交，
> 佣金万 2.5、卖出印花税万 5，滑点 5bp，区间 2020-01-01 到 2024-12-31，跟买入持有比一下。

### 事件研究

> 过去五年每次降息公告后，买入沪深300ETF 持有 20 个交易日，平均收益、中位数、胜率、最好最差。

### 复核别人的回测

> 我这份脚本年化 80%、夏普 5，帮我看看哪里是未来函数 / 漏了什么成本。（把脚本或结果贴上来）

### 稳健性

> 这组参数（5/20）是不是过拟合？帮我扫一下 fast 3/5/10 × slow 15/21/40，再做个成本 1×/2×/4× 压力。

## 三、它会怎么走

1. **口径卡**：先把标的、区间、信号、成交、仓位、费用、基准列出来给你确认（能默认的会直接默认并写明）。
2. **取数体检**：取日线、补预热段、跑八项体检，报告缺多少数据。
3. **写脚本跑数**：生成 `run_xxx.py` + 三件套（净值/成交/指标）。
4. **对抗自检**：12 项审计 + 数值红线 + 手算一笔 + 首末笔记录检查。
5. **交付**：HTML 报告 + 六段式结论（结论/口径/执行/结果/局限/复现）。

## 四、产物在哪

默认写在工作目录（通常是当前项目目录）：

```
run_xxx.py                  本次回测脚本（可单独复跑）
out/index.html              报告（双击浏览器打开）
out/xxx_equity.csv          逐日净值
out/xxx_trades.csv          已平仓记录
out/xxx_summary.json        指标与元信息
out/sweep.json              参数扫描与成本压力（若做过）
```

## 五、常用参数与默认值

| 项 | 默认 | 怎么改 |
|---|---|---|
| 成交时点 | 次日开盘 | 说"当日收盘成交"（会被提示这是未来函数） |
| 仓位 | 单标的 95% 满仓 | 说"每次 30%""固定 10 万" |
| 手数 | A 股 100 股 / 美股 1 股 / 港股 100 股 | 说"港股每手 500 股" |
| 费用 | A 股 佣金 2.5bp（最低 5 元）+ 印花税 5bp + 过户费 0.1bp + 滑点 5bp | 给具体数值 |
| 止损 | 不加 | 说"跌 8% 止损" |
| 基准 | 同标的买入持有 | 说"跟沪深300指数比" |
| 报告语言 | 跟随你的提问语言 | 说"用英文出报告" |

## 六、判读回测结果的三条经验

1. **先看回撤，再看收益**。年化 20% 配 60% 回撤，实盘拿不住。
2. **先看交易笔数**。5 年 3 笔的交易，无论收益多好都不构成统计证据。
3. **先看参数曲面**。只有一个参数点赚钱，等于没有结论。

## 七、常见问题

**Q：一定要装 pandas 吗？**
不用。内核只用 Python 标准库。报告也不需要 matplotlib。

**Q：能跑分钟线吗？**
不能。日线及更低频是本专家的边界，分钟级需要另一套撮合假设。

**Q：数据从哪来？**
优先用环境里已安装的行情命令行工具；没有就用你提供的 CSV；再没有才用公开数据源，并会在回复里写明来源。

**Q：能给我买卖建议吗？**
不能。它只说"这套规则在这段历史里做了什么"。

## 八、头像排查（导入后图标变成文字）

现象：专家列表里显示的是名字首字色块，不是图片。

原因只有一类：**头像没被解析成可用地址**。WorkBuddy 只认三种写法——

1. `http(s)://…` 绝对地址
2. `data:image/…` 内联数据
3. **相对专家包根的路径**，且文件真的存在、且在包目录内

以下写法一定失效：绝对本地路径（`C:\…`）、`file://`、`local-file://`、路径大小写与磁盘不一致（macOS/Linux 区分大小写）、文件根本没打进 zip。

自查：

```bash
python tools/verify_avatar.py <专家包目录>
```

它会把 `plugin.json` 的 `avatar` 字段解析成绝对路径，逐项检查是否存在、是否越界、尺寸与体积是否达标。

如果检查通过但界面仍是色块：
1. 完全退出 WorkBuddy 再启动（客户端会缓存一份展示快照，里面记的是**上一台机器的绝对路径**）；
2. 确认导入的是最新 zip（旧包里可能没有 `avatars/` 目录）；
3. 仍不行就把 `avatars/avatar.png` 直接替换一张同名 512×512 PNG。
