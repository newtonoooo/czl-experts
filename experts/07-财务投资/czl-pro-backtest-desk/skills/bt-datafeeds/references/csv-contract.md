# 数据 CSV 契约

内核（`kit/btcore.py:load_bars`）只接受这一种格式。转换脚本见 `tools/bars_from_table.py`。

## 必需列

| 列 | 类型 | 约束 |
|---|---|---|
| `date` | 字符串 | `YYYY-MM-DD`；也接受 `YYYY/MM/DD`、`YYYYMMDD`，读入时自动归一 |
| `open` | 浮点 | > 0 |
| `high` | 浮点 | ≥ max(open, close) |
| `low` | 浮点 | ≤ min(open, close) |
| `close` | 浮点 | > 0 |

## 可选列

| 列 | 说明 |
|---|---|
| `volume` | 成交量。**必须在清单里写明单位是股还是手**，否则量比类信号会差 100 倍 |
| `amount` | 成交额，内核暂不使用，可保留 |
| `symbol` | 单文件多标的时使用；单标的文件可省略（由文件名或参数指定） |

## 约定

- 编码 UTF-8（带不带 BOM 都行，读取时按 `utf-8-sig` 处理）
- 千分位逗号会被自动去掉（`1,234,567` → `1234567`）
- 空值、`-`、`NaN`、`null` 所在行会被跳过（不是补 0）
- 日期重复时保留最后一条
- 行按日期升序排列，乱序会被自动排序

## 不该做的事

- ❌ 用 Excel 把日期保存成 `2024/1/2`（月日不补零）——能读，但拼接两年数据时容易错位，统一补零
- ❌ 把停牌日补成"前一日收盘价、成交量为 0"却不写进清单——可以补，但必须记录，否则回撤会被低估
- ❌ 混用不复权与前复权（分红除权日会出现一个假跳空，均线信号会被打乱）
- ❌ 用成交额冒充成交量（列名写 volume 但填的是 amount）
