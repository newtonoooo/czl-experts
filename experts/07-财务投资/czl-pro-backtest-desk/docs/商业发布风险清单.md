说明：本清单区分「已验证」「未验证」「需你决定」三类，不做乐观推定。

| 项 | 结论 | 依据 |

| 回测内核与报告引擎 | 本次原创实现，未使用第三方回测框架 | `kit/btcore.py`、`kit/btreport.py` 全部为本次编写 |

## 二、第三方依赖与商业可用性

| 依赖 | 是否随包分发 | 许可证 | 商业分发风险 |
|---|---|---|---|
| Python 标准库 | 否 | PSF License（允许商业使用） | 无 |
| Node.js（仅自检脚本用） | 否 | MIT | 无 |
| 行情 CLI（可选，如 westock-data / westock-tool） | **否**，仅在用户环境已安装时调用命令 | 未核实（不在本包内） | **中**：若未来把那套 CLI 打包进本产品再分发，需先确认其许可与商业使用条款 |
| 图像生成服务 | 否 | 平台能力 | 低：生成图已去除工具水印；若平台对生成内容另有约定，以上架协议为准 |

**结论**：当前包内不存在需要随包授权的第三方代码，商业分发的主要依赖风险为"零"；唯一需要注意的是**不要**把外部行情 CLI 的文件打进包里。

## 五、技术风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 用户机器没有 Python | 无法跑脚本 | README 首屏写明要求；无 Python 时专家仍可给方法、口径与审计建议，但会明确说明"本次未执行回测" |
| 行情源不可用 | 拿不到数据 | 走用户 CSV；再不行只交付方法与脚本骨架，并在回复里说明 |
| 日线近似误差 | 止损成交价与实盘有差异 | 文档与回复均强制说明（`skills/bt-engine`、`bt-delivery`） |
| 演示数据被误当真实结论 | 误导 | 文件名、README、报告副标题、回复均标注"合成数据" |
| 头像导入后显示为文字 | 观感差 | `tools/verify_avatar.py` + 导入后重启说明；详见 `docs/头像图标问题排查.md` |

## 六、需要你决定的事项

1. **分成与定价**：平台条款未核实，需你在提交上架时确认；我不代为假设比例。
2. **金融类准入**：是否以个人开发者身份发布金融工具类专家，需你判断平台政策与自身合规边界。
3. **是否保留"复核别人的回测"这一功能**：它是差异点，但也可能被理解为"评价他人产品"。当前写法只针对"代码与结果"，不针对任何具体产品或作者。
4. **是否在包内保留 `out/` 示例产物**：保留便于用户直观看到效果，但会增加 360 KB 体积；删掉不影响功能。
5. **头像是否再迭代**：当前为深蓝+金色、30 岁上下的职业形象，符合"干练不老成"的要求；如需更中性或更抽象（不用人像），可再出一版。

## 七、结论

- **可发布**：包结构、头像、字段、功能测试均已本地验证通过。
- **发布前必须补做**：平台创作者协议与分成条款的人工核实（我无法代替你同意条款）。
- **无需处理**：第三方代码许可（本包不含）。
- **建议保留**：`NOTICE.md`、`LICENSE`、免责声明三件套，它们是审核时最有力的自查材料。
