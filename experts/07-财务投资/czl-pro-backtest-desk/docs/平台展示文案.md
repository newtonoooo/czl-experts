## 详情页文案（长描述）

**它做什么**

把一个交易想法拆成五步走完：先锁口径（标的、区间、信号、成交、仓位、费用、基准），再体检数据（预热段、复权、缺口、单位），然后生成可直接复跑的 Python 脚本，接着**假定代码里有 bug** 做 12 项对抗审计，最后出一份自包含的 HTML 报告和一段说实话的结论。

**它擅长什么**

- 规则型策略：均线、突破、动量、网格、量价、择时切换
- 事件研究：某个事件后持有 N 个交易日的收益分布（平均/中位/胜率/最好最差）
- 组合轮动：多标的、目标权重、定期再平衡
- 稳健性：参数扫描 + 成本 1×/2×/4× 压力测试
- **复核别人的回测**：指出最可能是未来函数、漏成本、挑区间的地方

**它不做什么**

分钟/Tick 级回测、期权与可转债定价、完整多因子选股流水线、以及任何形式的买卖建议。

**为什么不一样**

1. 零第三方依赖：只用 Python 标准库，不需要 pandas / numpy / matplotlib，装到哪都能跑。
2. 报告自绘 SVG：不依赖中文字体，双击就能看，单文件可转发。
3. 稳健性是默认动作：不只给你最优点，还告诉你九组参数里有几组为正。
4. 审计独立成流程：跑通不等于可信，审计不过不给结论。

**适合谁**

有交易想法需要验证的个人投资者、要给客户解释策略的投顾、写策略复盘的内容作者、拿到别人回测结果需要判断真假的人、以及想学一套完整工程做法的学习者。

## 使用须知（详情页底部）

- 需要本机有 Python 3.9+；报告自检脚本可选 Node 14+。
- 行情数据优先使用环境中已安装的行情工具，也可直接提供 CSV；数据来源会在回复中说明。
- 所有回测结果仅用于研究与复核，不构成投资建议。
