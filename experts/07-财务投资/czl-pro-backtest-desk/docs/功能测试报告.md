## 三、端到端示例

### T-A 均线交叉（`kit/examples/run_ma_cross.py`）

```
累计收益 -8.12%｜年化 -2.34%｜回撤 -34.30%｜夏普 -0.03｜交易 32 笔
买入持有基准 -11.62%
```
- 产物：`out/ma_demo_equity.csv`（936 行）、`_trades.csv`（32 行）、`_summary.json`、`out/sweep.json`
- 参数扫描：9 组（fast 3/5/10 × slow 15/21/40）全部为负，最好 MA5/MA40 为 -2.05%
- 成本压力：1× -8.12% → 2× -9.51% → 4× -12.23%
- 检查：策略与基准同量级（-8% vs -12%），未见异常，符合预期

### T-B 事件研究（`kit/examples/run_event_study.py`）

```
事件数 12｜平均 +0.60%｜中位 +1.40%｜胜率 58.3%｜最好 +15.96%｜最差 -15.84%
```
- 产物：`out/event_trades.csv`、`out/event_stats.json`、`out/event_index.html`
- 检查：报告未出现夏普/年化/最大回撤（事件研究不应有组合指标）；成交表列名为"事件/买入日/卖出日/收益"

### T-C 双标的轮动（`kit/examples/run_rotation.py`）

```
累计 +1.24%｜年化 +0.35%｜回撤 -51.80%｜夏普 0.16｜平仓 59 笔｜在场 100%
```
- 产物：`out/rotation_*` 三件套 + `out/rotation.html`
- 检查：`trades.csv` 中 `rotate_out` 与 `rotate_in` 交替出现，先卖后买顺序正确

## 七、测试中发现并已修复的问题

| 问题 | 现象 | 修复 |
|---|---|---|
| 预热段偷偷交易 | `equity[0]` 为 923,977 而非 1,000,000 | 引擎只在评估区间调用策略，加单测守住 |
| 强平后净值口径 | 强平后直接写 `cash`，忽略残留持仓 | 改为 `broker.equity(marks)` |
| 买卖次数无法区分 | 只有 `trade_count` | Broker 分别计数 `buy_fills` / `sell_fills` |
| 事件研究报告出现空月度卡 | 事件模式无月度数据 | 模板空数组时隐藏该卡片 |
| 事件研究成交表列名错 | 显示"标的/买入价" | 增加 `table_mode="event"` 切换列名 |
| 示例文案写死 | 参数扫描结果变了文案不变 | 改为从扫描结果计算后再拼文案 |
| 单测资源告警 | 文件句柄未关 | 改用 `with` 打开 |
