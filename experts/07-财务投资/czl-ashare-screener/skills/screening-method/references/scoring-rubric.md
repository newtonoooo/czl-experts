# 五维评分卡（scoring-rubric）

本文件是 `scripts/rank_universe.py` 的口径说明，**两者必须一致**。改动任何一处分段函数，必须同步改另一处并重跑 `--selftest`。

## 一、总分结构

| 维度 | 代号 | 中线跟踪权重 | 短线观察权重 |
|------|------|--------------|--------------|
| 基本面质量 | fundamental | 25 | 20 |
| 技术面位置 | technical | 25 | 30 |
| 资金面强度 | capital | 20 | 20 |
| 估值吸引力 | valuation | 15 | 15 |
| 事件与预期 | event | 15 | 15 |

- 权重合计恒为 100。
- 每个维度内部先算 0—1 的子分，再加权成维度分；维度分乘权重即该维贡献分。
- 总分 = Σ(维度分 × 可用权重) ÷ Σ(可用权重) × 100。**缺失维度不参与分母**，权重自然放大。

## 二、打分方式

每个指标先经**分段线性映射**到 0—1：给定若干 `(指标值, 得分)` 锚点，锚点之间线性插值，锚点之外取端点值。下表只列锚点。

## 三、基本面质量（25）

| 指标 | 内部权重 | 锚点（指标值 → 子分） |
|------|----------|------------------------|
| ROE（%） | 0.40 | 0 → 0；5 → 0.25；10 → 0.55；15 → 0.80；20 → 1.00 |
| 净利增速（%） | 0.25 | -20 → 0；0 → 0.30；15 → 0.65；40 → 1.00 |
| 营收增速（%） | 0.15 | -10 → 0；0 → 0.30；15 → 0.70；30 → 1.00 |
| 毛利率（%） | 0.10 | 5 → 0.15；20 → 0.50；50 → 1.00 |
| 资产负债率（%） | 0.10 | 20 → 1.00；50 → 0.65；70 → 0.30；85 → 0.00 |

负债率是**逆向指标**：越低越好。银行、地产等特殊行业的负债率不可与制造业同尺比较，遇到时必须在交付中单独声明"该行业负债率口径不适用"，并把负债率子分置为 `N/A`。

## 四、技术面位置（25）

| 指标 | 内部权重 | 规则 |
|------|----------|------|
| 均线排列 | 0.30 | 价 > MA20 > MA60 → 1.00；价 > MA20 且未 > MA60 → 0.70；价 > MA60 但未 > MA20 → 0.40；两项都不满足 → 0.15。只有一条均线时：价 > MA20 → 0.70，否则 0.20；仅有 MA60 时：价 > MA60 → 0.40，否则 0.20 |
| 距 250 日高点（%） | 0.25 | -70 → 0.15；-50 → 0.35；-30 → 0.70；-15 → 1.00；-5 → 0.55；0 → 0.20 |
| 量比 | 0.15 | 0.5 → 0.15；1.0 → 0.35；1.5 → 0.75；2.5 → 1.00；4.0 → 0.60；6.0 → 0.30 |
| RSI14 | 0.30 | 20 → 0.20；30 → 0.60；45 → 1.00；60 → 0.80；70 → 0.40；80 → 0.15 |

「距高点」是**钟形**而非单调：太贴近高点（>-3%）位置风险高，太深（<-50%）说明趋势破坏，-15% 附近最优。

## 五、资金面强度（20）

| 指标 | 内部权重 | 规则 |
|------|----------|------|
| 5 日主力净流入 / 总市值（%） | 0.55 | -1.0 → 0；0 → 0.30；0.5 → 0.80；1.5 → 1.00 |
| 换手率（%） | 0.25 | 0.3 → 0.15；1.0 → 0.35；3.0 → 0.80；8.0 → 1.00；15.0 → 0.60；25.0 → 0.20 |
| 当日主力净流入方向 | 0.20 | > 0 → 0.80；= 0 → 0.35；< 0 → 0.15 |

用**占市值比例**而不用绝对金额，否则大盘股天然占优。缺少市值时该子项置 `N/A`，不得用行业均值替代。

## 六、估值吸引力（15）

| 指标 | 内部权重 | 锚点（指标值 → 子分） |
|------|----------|------------------------|
| PE-TTM（倍） | 0.45 | ≤ 0 → 0.05（亏损单列，不按低估处理）；5 → 1.00；15 → 0.95；25 → 0.70；40 → 0.40；60 → 0.18；100 → 0.05 |
| PB（倍） | 0.30 | 0.5 → 1.00；1.5 → 0.85；3.0 → 0.55；5.0 → 0.30；8.0 → 0.10 |
| 股息率（%） | 0.25 | 0 → 0.20；1.5 → 0.60；3.0 → 0.90；5.0 → 1.00 |

跨行业 PE 不可直接横比。同一份榜单若横跨 3 个以上行业，必须在交付中提示"PE 未做行业中性化，跨行业排序仅供参考"。

## 七、事件与预期（15）

- 输入 `event_score`（0—100，由取数阶段对财报窗口、公告、行业景气度做定性判断后给出）→ 除以 100 作为维度分。
- 无 `event_score` → 该维度为 `N/A`，权重转移，**不得给 0 分**。
- 该维是唯一带主观成分的维度，交付时必须写明"事件分由人工规则赋值，非量化指标"。

## 八、档位与排序

| 维度分 | 档位 |
|--------|------|
| ≥ 0.70 | 强 |
| 0.45—0.70 | 中性 |
| < 0.45 | 弱 |

排序键（依次）：
1. 总分降序；
2. 资金面维度分降序；
3. 距 250 日高点升序（越接近高点越靠后）。

## 九、风险闸门（打分之前）

| 闸门 | 判定 | 默认阈值 |
|------|------|----------|
| ST / 退市风险 | `is_st` 为真 | — |
| 停牌 | `suspended` 为真 | — |
| 流动性 | 成交额低于下限 | 5,000 万元 |
| 价格异常 | 连续涨停天数 | ≥ 3 日 |
| 关键字段缺失 | `price`/`market_cap`/`roe`/`pe_ttm` 缺失数 | ≥ 2 个 |
| 维度覆盖率 | 可用权重 ÷ 总权重 | < 50% |

命中任一条即淘汰，进"闸门淘汰表"并写明原因；用户可人工放行，放行后在榜单永久标注。

## 十、风险标注（不淘汰）

命中以下条件只做提示，不影响排序：距 250 日高点 > -3%、RSI ≥ 75、PE-TTM > 60、近期有涨停、成交额 < 1.5 亿。
