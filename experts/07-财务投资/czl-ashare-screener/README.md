# 专业级A股选股引擎（czl-ashare-screener）

开发者：虫志龙 · 47190078@qq.com

一个把"模糊选股想法"变成"可复核流水线"的 A 股多因子筛选专家。它不报票，它给你一条能自己走一遍的路：条件合约 → 逐票取数 → 风险闸门 → 五维打分 → 观察清单。

## 类型

Agent 型（单个 AI 专家），附带方法技能 `screening-method`。

## 它解决什么问题

| 常见做法的问题 | 本引擎的做法 |
|----------------|--------------|
| 一句话需求直接出一堆股票，条件对不对没人知道 | 先把需求编译成**条件合约表**，逐条回显，用户能当场改 |
| 只说"入选了几只"，不说筛掉了什么 | 给**漏斗台账**，每一步剔除几个都要有数字 |
| 分数是模型口算的，对不上 | 权重与分段函数全部落在脚本里，**确定性计算**，同输入同输出 |
| 缺数据时按 0 分或均值补齐，分数虚高 | 缺失维度置 `N/A`、权重转移、低覆盖率标的直接判"数据不足" |
| ST、连板、低流动性混在榜单里 | **风险闸门**前置淘汰，单独列表说明卡在哪一条 |
| 结论不可复现 | 输出**复现指令**（条件 JSON），任何人可重跑 |

## 核心能力

1. **条件编译**：自然语言 → 字段 / 算子 / 阈值 / 单位 / 剔除规则，落不到字段的要求会明确写进"未编译说明"，不偷偷丢弃。
2. **分级取数**：有行情类 MCP 时自动逐票取数；没有时转入"贴数据"模式；两者都没有时只交付合约，不编造任何数字。
3. **六道风险闸门**：ST/退市、停牌、流动性、连续涨停、关键字段缺失、维度覆盖率低于 50%。
4. **五维打分**：基本面 25 / 技术面 25 / 资金面 20 / 估值 15 / 事件 15（短线模式技术 +5、基本面 -5）。
5. **九段交付**：结论 → 合约 → 漏斗 → 榜单 → 单票卡 → 淘汰表 → 时点与覆盖率 → 复现指令 → 免责声明。

## 使用示例

- 我关注半导体，市值100亿以上，ROE大于8%，近5日主力资金净流入为正。先给我条件合约，再按五维打分出一张观察清单。
- 我手上有一批候选股的数据，等下贴给你。请按同一套标准打分排序，并告诉我哪几只卡在风险闸门上。
- 想找低位放量突破的票，排除ST和连续涨停，不要给我已经涨到天上的。

## 使用前提

- **有行情类 MCP**（如通达信 MCP 的选股 / 行情 / 指标 / K 线工具）：全自动取数，最完整。
- **没有**：专家会给出字段模板，你把数据贴进来，同样能算分排序。
- **都没有**：只出条件合约和取数清单，明确告知"本轮未取数"。

打分脚本需要本机有 `python3`（仅标准库，无第三方依赖）。

## 安装

将专家目录放到专家目录下：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/czl-ashare-screener/
```

然后注册使其在 WorkBuddy 中可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

（`register_expert.py` 位于 WorkBuddy 内置技能 expert-manager 的 scripts 目录。）

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir> <output-dir>
```
