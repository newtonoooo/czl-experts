# 版本更新日志

本项目遵循语义化版本（MAJOR.MINOR.PATCH）。日期均为北京时间。

---

## [1.0.0] - 2026-10-28

首个公开发布版本。包含完整的六阶段选股流水线与确定性打分引擎。

### 新增

**专家主流程**
- 六阶段工作流：需求对齐（S0）→ 条件编译（S1）→ 分级取数（S2）→ 风险闸门（S3）→ 五维打分（S4）→ 编排交付（S5）。
- 条件合约（Condition Contract）：把自然语言需求编译成字段 / 算子 / 阈值 / 单位 / 剔除规则的结构化表格，逐条回显供用户校正；无法落到字段的要求写入"未编译说明"，不静默丢弃。
- 三级取数策略：L1 自动调用行情类 MCP → L2 用户提供表格 → L3 只交付合约、不出榜单，任何情况下不编造数据。
- 六道风险闸门：ST/退市、停牌、流动性不足、连续涨停、关键字段缺失、维度覆盖率低于 50%。
- 风险标注（不淘汰）：贴近 250 日高点、RSI 偏高、PE 偏高、近期涨停、成交额偏低。
- 九段式交付：结论 / 合约 / 漏斗台账 / 榜单 / 单票卡 / 淘汰表 / 时点与覆盖率 / 复现指令 / 免责声明。

**方法库（skills/screening-method）**
- `scoring-rubric.md`：五维评分卡的完整口径，含全部锚点与分段函数，与脚本一一对应。
- `field-dictionary.md`：33 个标准字段、别名表、单位规则、取数模板、数据源优先级。
- `output-templates.md`：九段交付模板、单票卡模板、三种特殊场景收尾写法。
- `compliance-guardrails.md`：六类禁用词、替代表达、免责声明四要素、发布前 10 项自检、越界请求处理口径、行业特殊口径。
- `rank_universe.py`：确定性打分引擎，仅依赖 Python 标准库。支持 `--format json`、`--top N`、`--selftest`。

**工程**
- 10 项自检断言（`--selftest`）：权重合计、确定性、闸门命中、覆盖率闸门、排序合理性、缺失不补零、权重重分配、分数区间、单位解析、短线权重切换。
- 示例数据 `examples/sample_universe.json`：6 只虚构标的，覆盖通过 / 连板淘汰 / 低覆盖淘汰三种情形。

### 设计决策

1. **权重与分段函数写进代码，不交给模型口算**：语言模型做加权算术不稳定，且两次结果可能不同；固化进脚本后同输入必得同输出。
2. **缺失维度退出加权而不是记 0 分**：记 0 会把"没数据"惩罚成"数据差"，是同类工具最常见的失真来源。
3. **覆盖率作为独立闸门**：仅 15% 覆盖率的标的算出的高分没有意义，直接判"数据不足"而非"质地差"。
4. **风险闸门放在打分之前**：避免"高分垃圾"，也让淘汰原因必须被显式列出。
5. **条件合约先于结果**：把纠错成本从"看完一堆股票之后"提前到"看表格的时候"。

### 已知限制

- 事件维度（15 分）的 `event_score` 需人工或规则赋值，是唯一含主观成分的维度，交付时需声明。
- PE 未做行业中性化，跨行业榜单只能参考。
- 依赖本机 Python 3.8+ 运行打分脚本；无 Python 时退化为手算并标注误差可能。
- 行情数据依赖环境内的 MCP 或用户提供，产品本身不含数据源。

### 合规

- 全流程不含买卖指令、价格预测与收益承诺；禁用词表覆盖六类高风险表达。
- 涉及具体标的时强制输出免责声明四要素。
- 未声称任何官方授权、持牌资质或合作关系。
