## 二、工具子命令清单

| 子命令 | 功能 | 退出码含义 |
|--------|------|-----------|
| `entry-check` | 分录批次校验（平衡/单据/期间/异常特征） | 1 = 存在 R0 |
| `rollforward` | 四柱滚算 | 1 = 滚算与账面不符 |
| `bank-rec` | 银行余额调节表 | 1 = 两侧调节后仍不等 |
| `depreciation` | 折旧计算（四种方法） | 0（参数错则 2） |
| `amortize` | 摊销计划 | 0（参数错则 2） |
| `variance` | 差异分解（价/量/结构） | 1 = 残差不为 0 |
| `tieout` | 三表勾稽 | 1 = 有勾稽不成立 |
| `materiality` | 重要性测算 | 0 |
| `selftest` | 内置自检 8 用例 | 1 = 有失败 |
| `list` | 列出命令 | 0 |

## 四、原创性与来源说明

- **提示词与工作流**：六个工作流的九字段卡片结构、风险分级模型、四柱滚算主线、空话黑名单、证据分级、结账依赖分层，均为本次独立设计。未复制任何现有专家包的文案段落、表格样式或工作流定义。
- **代码**：`bin/ledgerkit.py` 全部自行编写，未引入外部代码片段；算法为通用会计公式（价量分解、直线/双倍余额递减/年数总和折旧、余额调节表），属公共领域方法。
- **规范引用**：文中提及的 CAS 科目编码、报表列报要求、勾稽关系属公开的专业规范与通用实务常识，按事实性引用处理，未整段复制准则原文。
- **数据分析**：开发前对一类通用"企业财务会计专家"包做了功能结构分析（能力清单、流程划分），仅用于界定需求边界；其具体文案、代码、表格未进入本包。
