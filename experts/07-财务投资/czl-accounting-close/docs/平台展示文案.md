## 三、详细介绍（详情页正文）

### 中文

**它不是一个"讲准则"的助手，是一个"把账做平"的助手。**

会计的日常不是研究准则，是把凭证做平、把余额对上、把报表勾稽过、把波动说清楚。这四件事里，只有一件跟准则理解有关，其余都是规则和算术。账衡把这两样都落成了可执行的东西。

**工作方式：四段闭环**

接单 → 做平 → 校表 → 归档。每一步都有明确的完成判据，不达标不进入下一步。

- **接单**：先要六件事——账套主体、会计期间、准则与金额单位、科目体系、数据来源、交付对象。缺什么、缺了会怎样，开工前一次说清，不做完再返工。
- **做平**：凭证平（借贷差 0）、账账平（四柱滚算闭合）、账实平（与银行对账单、往来函证一致）。
- **校表**：三表之间五条勾稽关系逐条核，一条不成立不出表。
- **归档**：每条结论挂数据来源，每个未决事项单列编号，底稿要能让第二个人独立复核。

**六个工作流**

1. 接单与任务单——缺件清单、风险分级（红线/关注/常规）、任务分流
2. 分录编制——业务定性、价税分离（专票/普票）、14 类业务分录库、折旧摊销
3. 对账与调节——账证→账账→账实三步顺序、银行余额调节表、差异归因矩阵、未达账项台账
4. 三表与勾稽——CAS 列报要点、五条勾稽、间接法调整项、附注提示
5. 差异分解——价格/数量/结构三因分解、费用四拆、空话黑名单、证据分级
6. 结账排程与审计交接——T-2 至 T+5 日历、依赖分层、关键路径、PBC 清单、函证要点

**随包计算工具**

`ledgerkit.py` 提供 9 个命令：分录校验、四柱滚算、银行调节表、折旧（四种方法）、摊销、差异分解、三表勾稽、重要性测算、自检。纯 Python 标准库、无第三方依赖、不联网、金额用 Decimal 计算不产生尾差。支持机器可读输出，结果可直接进底稿。

**三条它坚持的规矩**

- 借贷不平不给结果，差额不用"取整差异"糊过去。
- 无原始单据的分录只给标红草稿，并写明缺哪张单据。
- 不用调平分录掩盖差异——差异只有两种结局：查明改正，或如实挂账待查。

**适用与不适用**

适合：中小企业会计、财务主管、代账会计、内审与 FP&A，做月末结账、单笔业务判断、对账、出表、波动说明、审计备料。

不适合：需要注册会计师意见、税务定性结论、完整合并报表、ERP 实施、投资估值的场景。

### 英文

An accounting close workbench, not a standards lecturer. It runs a four-stage loop — intake, balance, tie-out, archive — and refuses to move forward when a stage is unmet. CAS is the default basis; IFRS and US GAAP switch by flagging differences only.

Six workflows cover intake gating, journal entries with VAT split, account reconciliation, three-statement tie-out, variance decomposition and close scheduling with audit hand-over. A bundled stdlib-only CLI (`ledgerkit.py`) performs the arithmetic: entry balance checks, four-column roll-forward, bank reconciliation, depreciation under four methods, amortisation, price/volume/mix decomposition, five tie-out relationships and materiality. Decimal-based, offline, machine-readable output.

Three non-negotiables: never output an unbalanced entry, never book without source documents, never plug a difference with an adjusting entry.

## 七、常见问答（详情页 FAQ）

**Q：支持中国会计准则吗？**
默认就是中国企业会计准则（CAS），科目、发票、增值税、折旧口径都按中国实务。需要 IFRS 或 US GAAP 时只标差异点，不重编整套账。

**Q：会不会自己编数据？**
不会。所有推算、假设、按比例估的金额都会标出来，并注明不能进正式报表。缺件会先出清单，不会静默补位。

**Q：能连我的 ERP 吗？**
不连。数据靠粘贴、上传（Excel/CSV/PDF/图片）或结构化 JSON 提供，数据不出本机。

**Q：出的东西能直接给审计吗？**
能给到"审计可以直接用"的程度：底稿有编号、结论有来源、未决事项单列。但不构成审计结论。

**Q：需要装什么环境？**
如果用随包计算工具，需要 Python 3.8+，无第三方包。只用对话功能则不需要任何环境。
