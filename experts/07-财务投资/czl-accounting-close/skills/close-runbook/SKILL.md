# W6 结账排程与审计交接

结账不是"最后几天赶工"，是一条有依赖关系的流水线。哪一步没做完，后面全部堵住。这一节给两样东西：一条能照着走的日历，一份能让审计师闭嘴的资料清单。

## 工作流卡片

| 字段 | 内容 |
|------|------|
| **工作流名称** | W6 结账排程与审计交接（close-runbook） |
| **任务职责** | 排出结账日历与依赖关系，跟踪状态，识别关键路径；期末后组织审计资料交接 |
| **输入参数** | 结账目标日（T+N）；团队人员与职责；账套数量；需出的报表口径（单体/合并）；审计要求的时间与清单；上期结账天数与卡点 |
| **执行步骤** | ① 定目标日与人员分工 → ② 按依赖分层排任务 → ③ 出日历表（每日任务/责任人/前置） → ④ 出状态看板 → ⑤ 每日跟踪，识别堵点 → ⑥ 关账前置检查 → ⑦ 审计交接：出 PBC 清单与函证安排 → ⑧ 归档 |
| **判断条件** | 关键路径任务延迟 → 立即重排后续，不接受"先出表后补"；关账前置检查未过 → 不锁期；审计资料缺口涉及 R0 → 先补件再提交 |
| **输出格式** | 结账日历表 + 状态看板 + 关键路径说明 + 关账前置检查表 + PBC 清单 + 函证安排表 |
| **异常处理** | 人员缺席 → 标出可替代岗位与该岗不可替代的原因；跨期调整 → 走审批并单列，不进常规结账流程；需反结账 → 先确认上一期是否已对外报出，再决定反结账或本期调整 |
| **必要依赖** | 无强制工具依赖；调用 W1—W5 的产出作为任务输入。可用 `ledgerkit.py materiality` 定复核门槛 |
| **与其他工作流关系** | 是 W1—W5 的调度总控；日历中的每个任务对应下游某个工作流；审计交接收集的正是 W2—W5 的底稿 |

## 依赖分层

```
L1 无前置，可 T+1 立刻开工
   银行流水 / payroll / 折旧 / 摊销 / 暂估 / 关联方单据收集

L2 依赖 L1
   银行调节表 / 收入确认 / 应收应付子账核对 / 期末调汇 / 剩余计提

L3 依赖 L2
   全部资产负债表科目对账 / 关联交易抵销 / 对账调整分录 / 试算平衡

L4 依赖 L3
   税务计提 / 权益变动 / 首版三表 / 勾稽校验 / 差异分析初稿

L5 依赖 L4
   管理层复核 / 终版报表 / 锁期 / 报告包 / 审计资料准备
```

**关键路径**：银行流水 → 日记账 → 子账核对 → 科目对账 → 税务计提 → 三表 → 复核 → 锁期。

想缩短结账天数，只有三条路是真的有用：把 L1 的重复分录做成模板自动生成；把对账从月末集中改成月中滚动；把关联方核对提前到月中做一次预对。其他手段（催得更紧、加班更多）不改变关键路径。

## 状态看板

| 任务 | 责任人 | 截止 | 状态 | 堵点 | 影响 |
|------|--------|------|------|------|------|

状态只用五个值：**未开始 / 进行中 / 已完成 / 受阻 / 有风险**。其中"受阻"必须写清卡在谁那里，"有风险"必须写清预计晚几天、影响哪张表。

每日站会只问三句：昨天完成了什么、今天卡在哪、需要谁配合。不问进度百分比。

## 关账前置检查（不通过不锁期）

- [ ] 试算平衡，借贷合计相等
- [ ] 五条勾稽关系全部通过
- [ ] 全部银行账户调节表已完成，无未查明差异
- [ ] 往来账龄已更新，超 90 天有说明
- [ ] 存货盘点差异已处理并入账
- [ ] 固定资产本期增减已入账，折旧已提
- [ ] 税费计提完整（增值税、附加、所得税、个税）
- [ ] 关联交易已识别并核对
- [ ] 所有 R0 事项已清除，R1 有复核签字
- [ ] 未决事项清单已随报表一并提交
- [ ] 报表版本号与锁期时间已登记

## 审计交接（PBC 清单）

按科目组织，审计师要什么先给什么，别一次性把整个共享盘丢过去。

| # | 资料 | 覆盖期间 | 提供形式 | 责任人 |
|---|------|---------|---------|--------|
| 1 | 科目余额表（含期初/发生/期末） | 全年 | Excel | 总账 |
| 2 | 全部记账凭证及附件索引 | 全年 | 系统导出 + 扫描件目录 | 总账 |
| 3 | 银行对账单与余额调节表 | 每月 | PDF + 调节表 | 出纳 |
| 4 | 应收账款账龄表与坏账计提测算 | 期末 | Excel + 计算说明 | 往来 |
| 5 | 应收/应付函证清单与地址 | 期末 | Excel | 往来 |
| 6 | 存货盘点表与跌价测算 | 期末 | Excel + 盘点签字页 | 成本 |
| 7 | 固定资产卡片与折旧计算表 | 全年 | 系统导出 | 资产 |
| 8 | 借款合同、担保与抵押资料 | 存续期 | PDF | 资金 |
| 9 | 收入合同与履约进度支持 | 抽样 | PDF | 收入 |
| 10 | 税费申报表与完税凭证 | 全年 | PDF | 税务 |
| 11 | 关联方清单与交易明细 | 全年 | Excel | 合并 |
| 12 | 期后事项说明与或有事项清单 | 期后 | Word | 财务负责人 |

**函证要点**：

- 银行函证：账户完整性（含零余额、已销户）、借款、担保、票据、受限资金一次问全，避免二次函证。
- 往来函证：抽样覆盖大额 + 异常 + 关联方；地址由我方独立核实，不经业务员转交。
- 函证差异：逐笔查明，属时间性的写清截止日差异，属错报的调整账面。

## 结账复盘（每次结账后 3 天内做完）

只问四个问题，答案写进下月日历：哪一步比计划慢了、为什么慢、下月怎么提前、谁负责改。不复盘的话，同一个卡点会连续卡十二个月。
