# W5 差异分解与说明

差异分析最容易变成作文。写"受市场环境影响""行业普遍下滑""属正常波动"，看起来有字，实际零信息。这一节的全部要求可以压成一句：**每个解释都要能被别人拿数据推翻或证实。**

## 工作流卡片

| 字段 | 内容 |
|------|------|
| **工作流名称** | W5 差异分解（variance-drill） |
| **任务职责** | 把总差异拆到可解释的驱动上，按重大性筛选，写出带数字与事实的说明 |
| **输入参数** | 对比口径（本期 vs 上期 / 预实 / 同比）；金额或量价明细（按产品或科目）；业务量指标（台数、单量、人数、面积）；已知一次性事项；重大性门槛 |
| **执行步骤** | ① 定门槛（`materiality` 或用户给定） → ② 算总差异与变动率 → ③ 按产品或科目拆价/量/结构（`variance`） → ④ 标记超门槛项 → ⑤ 对每项找可验证事实 → ⑥ 按"一段一驱动"写说明 → ⑦ 输出待查清单 |
| **判断条件** | 差异额 < 明显微小临界值 → 只列不解释；差异超门槛但无事实支撑 → 写"待查"并给排查方向，禁止编原因；拆分后残差 ≠ 0 → 输入有误，先修数据 |
| **输出格式** | 差异总表 + 三因分解表（含占比）+ 逐项说明（含证据等级）+ 待查清单 + 一句结论 |
| **异常处理** | 只有总额没有明细 → 给"最小可拆版"（总额 + 已知一次性事项 + 剩余待查）；量价数据缺失 → 只做金额差与结构占比，明确写"未做量价拆分"；口径变更（合并范围、科目重分类）→ 先做可比性调整再分解 |
| **必要依赖** | `bin/ledgerkit.py variance`、`materiality` |
| **与其他工作流关系** | 上游 W4（报表数据）；差异原因若为记账错误回流 W2/W3；产出供 W6 的管理层复核环节使用 |

## 第一步：先定门槛

没有门槛的差异分析等于流水账。门槛三档：

| 档位 | 参考值 | 用途 |
|------|--------|------|
| 整体重要性 | 收入的 0.5% / 税前利润的 5% / 资产的 0.5% | 判断这一项要不要写进报告 |
| 实际执行的重要性 | 整体的 50%—75% | 判断要不要逐笔查清 |
| 明显微小错报临界值 | 执行重要性的 3%—5% | 低于此值只列数不解释 |

```bash
python bin/ledgerkit.py materiality -f 重要性输入.json
```

## 第二步：拆驱动

**收入三拆**（默认方法，加法严格闭合）：

```
价差 = (本期单价 − 上期单价) × 本期数量
量差 = (本期数量 − 上期数量) × 上期单价
结构 = 量差合计 − 纯数量差      （纯数量差 = 总量变动 × 上期均价）
```

校验：价差 + 纯数量差 + 结构 = 本期金额 − 上期金额。残差不为 0 就是输入错了。

```bash
python bin/ledgerkit.py variance -f 差异输入.json
```

**费用四拆**：

| 驱动 | 算法 | 什么时候用 |
|------|------|-----------|
| 人头 | 人数变动 × 上期人均 | 人力密集型费用 |
| 薪酬 | 人数不变 × 人均变动（调薪、奖金） | 有调薪或奖金的月份 |
| 业务量 | 单量/台数变动 × 单位成本 | 与收入同向变动的费用 |
| 一次性 | 逐笔列举 | 咨询费、诉讼费、搬迁费、裁员补偿 |

拆不出来的一律进"未解释"，占总额比例必须写出来。**未解释超过 20%，这份分析不能发布。**

## 第三步：写说明（这一节决定质量）

**结构固定**：一句结论（谁、多少、方向）＋ 一到两个可核对的事实 ＋ 后续走势判断。超过三句就删。

合格示例：

> 销售费用环比 +42.6 万（+31%），主因是 9 月新增 3 场线下展会，单场 11.8 万，共 35.4 万；其余项目合计 +7.2 万，分散在差旅与样品。展会费用 10 月不再发生，预计下月回落至 8 月水平。

不合格示例（这些写法一律重写）：

| 空话 | 问题 |
|------|------|
| "受市场环境影响，收入有所下降" | 没有数字，没有机制，谁都能这么说 |
| "费用增加主要系业务规模扩大所致" | 规模扩大多少？费用弹性多少？无法验证 |
| "属正常波动范围" | 谁的正常？范围是多少？门槛在哪里？ |
| "公司加强了成本管控" | 这是结论不是原因，且不可证伪 |
| "该变动符合公司经营计划" | 计划是多少？差异去了哪里？ |

**证据分级**（每条说明末尾标一个字母，方便复核人判断可信度）：

- **A** 有单据/合同/系统明细支撑
- **B** 有业务方书面说明或会议纪要
- **C** 出自口述
- **D** 推理得出，尚未验证

标 C/D 的条目必须同时出现在待查清单里。

## 输出格式

```
差异分析 · 销售费用 · 2026-09 vs 2026-08 · 单位：万元

【结论】+42.6 万（+31%），超实际执行重要性 12 万；其中 35.4 万来自三场展会，属一次性支出。

| 项目       | 8月   | 9月   | 差异   | 占比   | 说明                     | 证据 |
|-----------|-------|-------|--------|--------|--------------------------|------|
| 展会费     | 0.0   | 35.4  | +35.4  | 83.1%  | 3 场，单价 11.8 万        | A    |
| 差旅费     | 18.2  | 22.4  | +4.2   | 9.9%   | 出差人次 61→74           | A    |
| 样品费     | 5.1   | 7.9   | +2.8   | 6.6%   | 新品打样 2 批             | B    |
| 其他       | 14.1  | 14.3  | +0.2   | 0.5%   | 低于临界值                | —    |
| 合计       | 37.4  | 80.0  | +42.6  | 100%   |                          |      |

三因分解：价格 0.0 / 数量 +35.4 / 结构 +7.2（结构为差旅与样品占比上升）

【待查】
1. 样品费 +2.8 万（证据 B），需补打样审批单 → 责任人：采购 张__，10/28 前
```

## 异常处理

- **口径不可比**：本期新增合并主体、科目重分类、政策变更，一律先做可比性调整，再比。调整过程单列，不改原数。
- **同比与环比冲突**：一个涨一个跌时，两个都摆出来，说明季节性因素，不要只挑好看的那个。
- **数据只有总额**：给"总额 + 已知一次性事项 + 剩余待查"三段式，并明确写"未做量价拆分"，不硬拆。
- **一次性事项识别**：看摘要关键词（展会、诉讼、搬迁、裁员、罚款、捐赠）＋ 看该科目历史是否有余额。历史无余额、本期突然出现的大额，优先按一次性处理并标注待确认。
- **差异方向与业务常识相反**（收入涨、成本降）：这本身就是异常信号，必须单列为待查，不许用"效率提升"糊过去。
