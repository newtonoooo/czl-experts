# 使用说明

## 一、怎么开始

装好后直接在对话里说人话，不需要记命令、不需要先配置。

第一次对话它会问你要标的。给代码、全称、简称都行（`600519`、`贵州茅台`、`茅台` 都能锁到 `600519.SH`）。

**简称有歧义时会反问**，比如"中金"可能是中金公司 601995，也可能是中金黄金 600489。这不是啰嗦——分析错标的比不分析更糟。

## 二、五种常用任务，怎么描述最有效

### 1. 个股诊断

```
帮我诊断一下宁德时代（300750），我要知道它值不值得继续花时间
```

**它会给**：六维打分（生意质量/财务质量/定价位置/交易结构/资金与预期/事件与风险）+ 最要命的那一条 + 一句附证伪条件的结论。

**加分说法**：告诉我你的角度——`我只看短线` 或 `我打算拿两年`。权重会随之调整。

### 2. 估值定价

```
这票现在贵不贵？给我一个区间，并告诉我当前价格隐含了什么增长假设
```

**它会给**：相对估值（自身分位 + 同业对比）+ 绝对估值（两阶段 DCF）+ **隐含预期反推**——把当前市值代回模型，倒推出"市场在假设它未来五年每年增长多少"，再和你已知的事实对照。

**这条最有用**：不说"市场错了"，只说"市场假设了什么"，对不对由你判断。

**要提供**：自由现金流、净债务、股本。没有就说没有，它会退回到只用相对估值，并注明置信度降级。

### 3. 大盘复盘

```
帮我做今天的大盘复盘，给出情绪温度和明日三个可验证的观察点
```

**它会给**：指数与广度、涨停结构（含炸板率）、量能对比、板块主线判定（连续 3 日+龙头+量能，三者缺一算脉冲）、情绪温度及四项分项、三条明日可验证观察项。

**不会给**：明天涨还是跌。

### 4. 写成稿

```
把刚才的分析整理成一篇能发出去的稿子，HTML 和 Markdown 都要
```

**它会给**：`{代码}-{任务}-{日期}.html`（自包含、断网可开、A4 可打印）+ 同名 `.md`（可复制进编辑器）。

**七段固定**：结论 → 证据 → 分歧 → 定价 → 情景 → 风险 → 来源。

**对外发布稿会额外调整**：标题留悬念不给结论、首段用具体数字切入、术语首次出现加解释、结尾不抒情。

### 5. 持仓体检 / 观点复核

```
我手里这几只：600519 100股、000858 1000股、300750 500股，风险是不是堆在一处了
```

**它会给**：集中度（单票/单行业/风格）、相关性（看驱动因子不看行业名）、事件撞车时间轴、流动性（持仓占日均成交额比例）、尾部暴露（哪几只可能同时坏）。

```
三个月前我说它增速换挡，现在还算数吗
```

**它会给**：调出台账原条目，**先只看证伪条件是否发生**，再判对/错/未了结。不看价格先判定，避免被结果倒推理由。

## 三、手动跑脚本

所有脚本纯标准库，Python 3.9+ 直接跑。在包根目录执行。

### 取数

```bash
# 实时行情（多只用逗号分隔）
python skills/ar-evidence/scripts/arfetch.py quote --codes 600519,000001

# 五大指数
python skills/ar-evidence/scripts/arfetch.py index

# 前复权日K（--fq qfq|hfq|none）
python skills/ar-evidence/scripts/arfetch.py kline --code 600519 --days 250
```

失败时会返回结构化错误并提示降级路径，退出码 3。**它不会返回编造的数字。**

### 指标

```bash
python skills/ar-evidence/scripts/arindicators.py --file bars.json
python skills/ar-evidence/scripts/arindicators.py --csv bars.csv
```

输出 MA5/10/20/60/120/250、MACD（含金叉死叉）、KDJ、RSI14、BOLL（含轨道位置）、ATR、量比、5/20/60/250 日收益、年化波动、最大回撤、250 日价格分位。

数据不足时对应字段为 `null`，不做近似。

### A股规则

```bash
# 板块与幅度
python skills/ar-evidence/scripts/arrules.py board --code 300750

# 涨跌停价
python skills/ar-evidence/scripts/arrules.py limit --code 000001 --prev-close 12.34

# 价格校验（--st 用于主板 ST 股，幅度按 5%）
python skills/ar-evidence/scripts/arrules.py check --code 600519 --prev-close 1500 --price 1650
```

价格取整用 `Decimal` + `ROUND_HALF_UP`，与交易所口径一致（不用 Python 内建 `round`，那是银行家舍入，会在 `.005` 上出差）。

### 估值

```bash
# 两阶段 DCF
python skills/ar-value/scripts/arvalue.py dcf --fcf 100 --wacc 9 --growth 12 --years 5 --terminal 2 --net-debt 200 --shares 12.56

# 隐含增长反推（--ev = 总市值 + 净债务）
python skills/ar-value/scripts/arvalue.py implied --ev 3000 --fcf 100 --wacc 9 --years 5 --terminal 2

# 敏感性表
python skills/ar-value/scripts/arvalue.py sens --fcf 100 --wacc 8,9,10 --growth 8,12,16
```

永续增长率 >3% 会被**直接拒绝**，WACC ≤ 永续增长也拒绝。这不是限制，是防止把乐观写进公式。

### 渲染与闸门

```bash
python skills/ar-thesis/scripts/arreport.py --input draft.json --out 600519-diagnosis-20261029.html
python skills/ar-quality/scripts/archeck.py --doc 600519-diagnosis-20261029.html \
        --evidence data/600519-evidence-20261029.json --code 600519 --data-as-of 2026-10-29
```

`draft.json` 结构见 `skills/ar-thesis/references/draft-schema.md`。

闸门退出码：`0` 放行，`1` 打回，`2` 输入错误。加 `--json` 拿结构化结果。

### 持仓

```bash
python skills/ar-position/scripts/arposition.py check --file holdings.json
python skills/ar-position/scripts/arposition.py events --file events.json
python skills/ar-position/scripts/arposition.py corr --file series.json
```

## 四、读报告时看什么

1. **先看结论段的最后一句**——那是证伪条件。说不出什么情况下算错，就不算结论。
2. **再看每条证据后面的方括号**：`[事实]` 公告原文，`[披露]` 公司的说法，`[共识]` 市场预期，`[推算]` 它自己算的，`[假设]` 为跑模型设的前提，`[判断]` 主观结论。
3. **第三看分歧段**——它反驳的是不是对方最强的版本。打稻草人就是没做功课。
4. **第四看定价段的假设表**——每个数能不能自己代进去复算。
5. **最后看来源表**——每个关键数字有没有出处，质量是不是 `primary`。

## 五、常见问题

**问：数据是实时的吗？**
盘中是延迟十几秒到一分钟的快照，非交易时段是上一交易日收盘。报告里会标"盘中快照 HH:MM"或具体日期，不会写"最新"糊过去。

**问：为什么拿不到财务数据？**
包内没有财务数据库，只有公开行情接口。财务需通过你连接的金融工具或联网检索补充。拿不到时报告会标 `[MISSING]` 并说明"该数据缺失会导致哪个结论不成立"。

**问：为什么老让我确认股票代码？**
简称重名在 A 股很常见（中金、东方、平安都有多个）。锁错标的后面的分析全废，多问一句比返工便宜。

**问：能不能直接告诉我买不买？**
不能。这是产品边界，不是能力不足。会给条件化情景：若 X 成立则 Y 情景下赔率更有利，若 X 被推翻则结论反转。判断权在你。

**问：能不能把免责声明去掉？**
不能。这段是内容能公开发布的前提。可以调整措辞，但"不构成投资建议"的实质不能删。

**问：报告能发公众号吗？**
可以。说"发公众号"会切到对外发布稿模式。但发布前请自行确认平台对证券类内容的资质要求——这是发布者的责任，工具不代你承担。

**问：闸门打回了怎么办？**
按提示改。最常见的三类：数字没登记台账（把派生数字也登记为 `estimated`）、正文写了"今日"但数据不是当天、目标区间没写假设。

## 六、出错时

| 现象 | 原因 | 处理 |
|---|---|---|
| `fetch_failed` | 接口变更、限流或被墙 | 换网络，或走已连接的金融工具；报告标注 `[FALLBACK]` |
| 指标大面积 `null` | K 线不足（新股或次新股） | 减少指标窗口，报告中注明样本不足 |
| 闸门 A4 匹配率低 | 派生数字未登记台账 | 把区间上下限、增速、占比都登记为 `estimated` |
| 闸门 A5 不通过 | 数据非当日但写了"今日" | 改为具体日期 |
| 渲染报错 | `draft.json` 缺字段 | 按报错提示的键名补齐，参考 draft-schema.md |
