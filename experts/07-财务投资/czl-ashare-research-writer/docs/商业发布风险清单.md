# 商业发布风险清单

> 逐条列出可预见的风险、判断依据、已做的缓解，以及需要开发者本人决定的事项。
> 标注说明：**高** = 可能导致下架、投诉或法律纠纷；**中** = 影响用户体验或审核通过率；**低** = 可接受。

## 一、合规与法律

### R1｜不构成投资建议的边界（高）

**风险**：产品输出个股分析、估值区间、情景判断，若被理解为"荐股"，可能触及《证券法》关于证券投资咨询业务须持牌的规定。

**依据**：证券投资咨询业务需取得证监会业务资格；无资质向不特定对象提供个股买卖建议并收费属违规。

**已做**：
- agent 提示词层面禁止输出买入/卖出/加仓/清仓等操作指令
- 闸门 A1 机器拦截"建议买入/满仓/抄底/清仓/必涨"等表述
- 每份产出固定免责声明，且明确不可由用户要求删除
- 只给条件化情景，不给点位预测

**仍需注意**：若用户把产出直接当作荐股内容对外发布并收费，风险转移给发布者。建议在商品详情页明示"本工具产出的内容需使用者自行承担发布责任"。

### R2｜名称含"专业"是否构成资质暗示（中）

**风险**：名称"专业A股投研主笔"中的"专业"可能被解读为资质宣称。

**依据**：广告法对"国家级""最高级"等绝对化用语有限制；"专业"不在禁用词之列，但若配合"持牌""认证"等表述则构成虚假宣传。

**已做**：展示文案中不含"持牌""认证""官方""合作"等字样；`docs/平台展示文案.md` 第十节明确了禁用表述清单。

**结论（已定）**：保留"专业"。它描述的是能力属性（做完整流程、按专业方法），不是资质等级，与"持牌/认证/官方"无关；展示文案已全篇回避资质暗示。若平台单独提出异议，备用名为"全流程A股投研主笔"，功能描述不变。

### R3｜行情数据的使用条件（中）

**风险**：产品调用新浪财经、东方财富的公开 HTTP 接口取数，未取得书面授权；产出物中转载行情数据可能涉及数据提供方的使用条款。

**依据**：公开接口可访问不等于可商用转载；数据权利归提供方。

**已做**：
- `NOTICE.md` 明确声明与上述机构无合作、授权或背书关系
- 产出物强制标注数据来源与获取时间
- 内置接口失败降级与显式回报，不缓存、不再分发原始数据

**待决**：若商业化规模较大，建议评估采购合规数据源（如持牌数据商），或与平台确认此类调用的合规边界。

### R4｜用户输入未公开信息的处理（低）

**风险**：用户可能提供内幕信息并要求据此分析。

**已做**：agent 提示词明确"用户提供未公开信息时拒绝使用，仅基于公开信息继续"。

## 二、版权与原创性

### R5｜与既有专家包的功能重叠（中）

**风险**：本产品分析过 6 个同类专家包，功能范围与其中若干存在重叠；平台审核可能判定"差异化不足"。

**依据**：功能重叠本身不构成侵权（思想与功能不受著作权保护），但平台可能设有原创性或差异度要求。

**已做**：
- `NOTICE.md` 逐包列出"分析到的能力"与"未采用的部分"
- `SPEC.md` 第 2 节记录了六个共性缺口的推导过程
- 所有提示词、规则、脚本为本产品新写，未复制参考包文本
- 差异化点集中在：可降级取数、A股规则校验、证据六类标注、隐含预期反推、交付闸门、观点台账

**待决**：若平台要求提交原创性说明，可直接使用 `NOTICE.md` 第三、四节。

### R6｜"通用方法"与"专有表达"的界线（低）

**风险**：DCF 公式、技术指标算法、A股交易规则属公开通用知识，可自由使用；但若某段文字与参考包高度相似，可能被认定抄袭。

**已做**：全部文本重新撰写；公式与算法为通用数学表达，不构成他人专有表达。

### R7｜头像的版权（低，已消除）

**风险**：初版头像由生成模型产出，成品右下角带平台水印，且生成内容的商用授权状态不明。

**已做**：弃用该图并删除，改为 `tools/make_avatar.py` 纯几何绘制（矩形填充 + 像素运算 + 手写 PNG 编码），不含任何第三方素材与生成模型痕迹，可复现。

**举证**：保留生成脚本，任意机器重跑可得到相同结果。

## 三、技术与运营

### R8｜公开接口失效（高）

**风险**：新浪、东财接口可能改版、限流、加验证或关闭，导致取数失败。

**已做**：
- 三级降级（公开接口 → 已连接金融工具 → 联网检索）
- 单源超时 8 秒即降级，总预算 30 秒
- 失败时返回结构化错误与降级提示，退出码 3
- 不编造数据，不静默补数

**残留**：若三级全失效，个股诊断能力大幅下降（只能做定性分析）。建议在商品说明中提示"依赖公开数据接口，极端情况下可能不可用"。

### R9｜数据准确性（中）

**风险**：公开接口可能返回脏数据（字段错位、单位错误、延迟数据）。

**已做**：
- 闸门 A6 用涨跌停规则反查现价合理性（现价超出涨跌停区间即判数据异常）
- 闸门 A5 检查"今日/最新"与实际数据日期是否一致
- 证据台账强制标注质量标记，非 `primary` 时置信度不得为"高"

### R10｜闸门误判（中）

**风险**：数字匹配率检查（A4）可能因正文含派生数字而误判。

**已做**：默认阈值 75%，可用 `--threshold` 调整；已在规则中明确"派生数字须以 estimated 登记台账"；实测样本匹配率 0.93-0.96。

**残留**：报告数字极多时仍可能触发误判，此时按提示补登记即可，不阻塞使用。

### R11｜情绪温度等经验参数未经回测校准（中）

**风险**：`ar-tape` 的情绪温度四项映射曲线为经验设定，未用历史数据做统计校准，可能在某些市场环境下失真。

**已做**：报告中强制列出四项分项原始分，读者可自行质疑与重算；不把温度作为唯一结论依据。

**待决**：后续版本可用历史数据回归校准，或在展示中标注"经验参数"。

### R12｜"专业"承诺与实际能力的落差（中）

**风险**：产品无财务数据库、无一致预期数据、无龙虎榜明细，若用户按"专业投研"预期使用，可能失望。

**已做**：README 与 USAGE 均设"做不到"清单；报告中缺失数据标 `[MISSING]` 并说明影响；展示文案第十节列出禁用表述。

## 五、结论

- **可发布**：当前包无第三方代码、无第三方素材、无水印、无未授权内容，许可证与来源说明齐备。
- **必须先做**：确认 D5（发布责任提示）落到商品页；确认数据来源标注在产出物中生效（已强制）。
- **建议做**：主动提交原创性说明；对"专业"一词准备替代方案。
- **长期风险**：公开接口稳定性（R8）与数据合规（R3），随使用规模上升而放大。
