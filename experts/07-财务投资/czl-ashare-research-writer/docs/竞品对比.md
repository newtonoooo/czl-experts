- **口径**：只对比实际读过全部文件的包；未实测的产品不列入评分，只在文末做定性提及

## 三、优势（哪几件事只有它能做）

### 优势一：~~不装任何东西就能跑（唯一）~~

~~这是最实际的一条。6 个参考包里，星辰依赖数据源 key、通达信系依赖 MCP、回测明算依赖 westock CLI、严估深依赖金融连接器。~~**~~只要有一环没配好，整套能力归零。~~**

本产品只用 Python 标准库：`urllib` 取数、`decimal` 算价格、`zlib` 写 PNG、纯循环算指标。实测在无任何第三方包的环境（Python 3.13，无 numpy/pandas/requests）直接跑通全链路。

**可验证**：`python tests/test_all.py`，21 项无需预装任何东西。

### 优势二：A股规则先校验再分析（唯一有机器校验）

涨跌停价（主板 10% / ST 5% / 双创 20% / 北交所 30%）、T+1、停牌、复权口径、北向口径——这些会让结论**直接错掉**的规则，其他包最多在"注意事项"里写一句。

本产品把它做成可执行校验：

```bash
python skills/ar-evidence/scripts/arrules.py check --code 600519 --prev-close 1500 --price 1650
```

而且涨跌停价用 `Decimal + ROUND_HALF_UP`，不用 Python 内建 `round`（银行家舍入，`.005` 处会与交易所差一分）。

**最能说明问题的一条**：北向资金 2024 年 8 月起已无实时净流入披露。闸门 A7 会直接拦下"今日北向净买入 XX 亿"这类表述——参考包里没有一个覆盖这个口径变化。

### 优势三：交付闸门（内容类唯一）

回测明算有严格自检链，但只针对回测。**针对研究内容的质检闸门，10 个包里只有本产品有。**

7 项机器检查 + 4 项人工判据，未过不放行：

| 项  | 拦什么                 |
| -- | ------------------- |
| A1 | "必涨""建议买入""满仓"等禁用词  |
| A2 | 缺免责声明               |
| A3 | 七段结构缺段              |
| A4 | 数字与证据台账匹配率 <75%     |
| A5 | 写"今日"但数据不是当天        |
| A6 | 台账现价超出涨跌停区间（抓数据源异常） |
| A7 | 北向实时净流入口径           |

**开发中它真的拦住了东西**：一份完全合规的报告因"区间上下限没登记台账"被判 A4 不通过。这正是它该做的——派生数字也必须可追溯。

### 优势四：成品是文件，不是聊天记录

10 个包里，只有星辰提到 HTML 输出（但只给色彩规范，无渲染器）、严估深要求 HTML（无工具）、回测明算有 dashboard（只限回测）。

本产品产出：`{代码}-{任务}-{日期}.html`（自包含、无 CDN、断网可开、A4 可打印、内联 SVG 走势）+ 同名 `.md`（可复制进编辑器），两份由同一份 draft 生成，内容必然一致。

### 优势五：隐含预期反推是固定步骤，不是可选项

多数工具的估值停在"给一个区间"。区间本身不回答最关键的问题：**这个价已经把什么好事算进去了。**

本产品强制做一步反推：

```bash
python skills/ar-value/scripts/arvalue.py implied --ev 3000 --fcf 100 --wacc 9 --years 5 --terminal 2
# 当前价格隐含未来 5 年自由现金流复合增速约 19.7%
```

然后对照历史增速与行业增速，判断这个假设是否站得住。这一步比给目标价有用得多，因为**它不说"市场错了"，只说"市场假设了什么"**。

### 优势六：观点台账可记分

`ar-position` 记录每次判断（含证伪条件与复核日），到期复核时**先只看证伪条件是否发生，再记录价格**——避免被结果倒推理由。判定只留三档：对 / 错 / 未了结。

不留"部分对"，因为那是最容易自欺的一档：涨了说逻辑兑现，跌了说外部扰动。

参考包里，A股交易助手的 watchlist 只记价格，严估深的 thesis-tracker 有框架但无字段约束。

## 四、与自有 4 个包的分工

不是抢饭吃，是各管一段：

| 你的问题                | 用哪个         |
| ------------------- | ----------- |
| 这只票值多少钱、逻辑站不站得住     | 刻度（深度研究与定价） |
| 今天盘中怎么做、什么位置进       | 盘锋（盘中参谋）    |
| 从 5000 只里筛出符合条件的一批  | 选股引擎        |
| 我这个策略历史上管不管用        | 专业回测台       |
| **把上面的东西写成能交出去的稿子** | **本产品**     |

本产品的独特位置是**最后一段**：前面四个都能产出结论，但都不能产出"能直接发出去/能过会"的文件，也没有交付前的质检。反过来，本产品不做深度定价模型（那是刻度的活）、不做盘中（盘锋）、不做全市场筛选（选股引擎）、不做回测（回测台）。

## 五、劣势（这一节不修饰）

### 劣势一：没有财务数据库，六维诊断只跑得动一半

这是最实质的短板。`ar-autopsy` 设计了六个维度，但包里只有行情接口：

- 生意质量、财务质量 → **需要财务数据**，包内没有
- 定价位置 → 需要 PE/PB 历史序列，包内没有
- 资金与预期 → 需要资金流与一致预期，包内没有
- 只有交易结构（技术面）是自足的

**对比**：通达信系通过 MCP 有完整财务与资金数据；回测明算通过 westock 有结构化财报；严估深有完整估值体系。

**现状**：缺数据时标 `[MISSING]`，权重按剩余维度归一，置信度自动降级——诚实，但**能力确实弱于有数据源的对手**。

**什么时候会补**：v1.1 计划接入至少一个公开财务接口（如东财 F10 结构化端点），但稳定性与合规性需先验证。

### 劣势二：无 MCP 集成，数据深度打不过通达信系

不绑 MCP 是刻意的选择（为了免配置），代价是**放弃了最好的结构化数据源**。装了通达信 MCP 的用户，用诊断师能拿到 DDX/DDY、北向持仓、龙虎榜席位、财务明细，这些本产品拿不到。

**如果你的环境已经配好通达信 MCP，诊断师在数据维度上强于本产品。**

### 劣势三：不做回测，无法回答"这策略历史上管不管用"

本产品只回答"现在怎么判断"，不回答"过去这样判断有没有效"。回测明算与专业回测台在这件事上是唯一选择。

这也是 SPEC 里明确划出的边界（不做分钟级回测、不做因子检验），不是遗漏，但确实是能力空白。

### 劣势四：无选股能力，不能从全市场筛标的

`ar-intake` 只做单一标的锁定。要"筛出 ROE>15% 且站上 MA60 的股票"，得用选股引擎或通达信猎手。

本产品是**给定标的之后的深度加工**，不是发现标的的工具。

### 劣势五：只覆盖 A 股，港美股一概不做

星辰覆盖 A/H/美/日/韩/台六个市场；严估深按美股卖方范式设计。本产品在 `ar-intake` 里明确拒绝非 A 股标的。

对只做 A 股的人是优点（专注），对跨市场配置的人是硬伤。

### 劣势六：图表能力弱，只有内联 SVG 折线

为了"断网可开"，放弃了 CDN 图表库。代价：**画不了 K 线图、雷达图、堆叠柱**，只有折线、圆点、矩形。星辰和严估深可以用 ECharts 出更丰富的图。

做深度报告时，这会明显不够看。

### 劣势七：多策略框架是短板

星辰内置 15+ 策略（缠论、波浪、龙头首板等），给定策略名就能按该框架分析。本产品的六维诊断只有一套框架，不分策略。

对做短线、打板、缠论的人，本产品的方法论不对口。

### 劣势八：经验参数未校准

`ar-tape` 的情绪温度用四项加权合成，四项映射曲线（如"成交额/20日均值 1.3 倍→80 分"）是经验设定，**没用历史数据做回归校准**。某些市场环境下可能失真。

报告里强制列出四项原始分供读者质疑，但这只是缓解，不是解决。

### 劣势九：未在客户端内验证

本包按 WorkBuddy 专家包结构组织，但**未在客户端实际导入并触发 skill 调用验证过**。这是上架前的阻断项，已写入 `docs/功能测试报告.md` 第六节。

### 劣势十：单一 agent，无多智能体协作

复杂任务（如"研究一个行业并出三份报告"）没有并行分工能力，只能串行做完。对超长任务效率不如多 agent 编排方案。

## 六、什么场景选它，什么场景别选

| 你的需求               | 建议                |
| ------------------ | ----------------- |
| 要把研究写成能发/能过会的文件    | **选它**            |
| 要一份能被追问、能复核的诊断     | **选它**            |
| 环境干净、不想配 MCP 与 key | **选它**            |
| 要防止内容踩合规线          | **选它**            |
| 要记录并复盘自己的判断对错      | **选它**            |
| 要完整财务分析、资金流、龙虎榜    | 别选，用通达信诊断师（需 MCP） |

| 要从 5000 只里筛股       | 用选股引擎或通达信猎手       |
| 要验证策略历史表现          | 用回测明算或专业回测台       |
| 要做缠论、打板、波浪         | 用星辰               |
| 要分析港股美股            | 用星辰或严估深           |
