# 大盘与板块复盘

复盘不是把涨跌数字念一遍。**它要回答的是：今天的钱在做什么，这个做法能持续几天。**

## 职责

**做**：市场广度、涨停结构、量能对比、板块轮动、情绪温度、明日观察点。
**不做**：不预测指数点位、不推荐板块、不给个股结论（交 `ar-autopsy`）。

## 输入参数

| 参数 | 必填 | 说明 | 缺失处理 |
|---|---|---|---|
| 日期 | 否 | 默认最近交易日 | 非交易日则回退到上一交易日并注明 |
| 范围 | 否 | 全市场 / 指定板块 / 指定指数 | 默认全市场 |
| 用户关注 | 否 | 某板块或某持仓 | 有则追加针对性段落 |

## 六个观察面

### 1. 指数与广度

不能只看指数涨跌。**指数涨但八成股票跌，是分歧；指数跌但六成股票涨，是换手。**

- 上证 / 深成 / 创业板指 / 科创50 / 北证50 的涨跌幅与成交额
- 上涨家数 : 下跌家数、涨幅 >5% 家数、跌幅 >5% 家数
- 涨停家数 / 跌停家数 / 炸板率（开板数 ÷ 触板数）

### 2. 涨停结构

涨停板是 A 股情绪的体温计，但要看结构而不是数量。

- 连板高度（最高连板数）、连板股数量分布
- 首板 / 二板 / 三板以上各自数量
- 涨停原因归类：政策、业绩、题材、重组、超跌反弹
- 是否有一字板（说明买不到，不代表情绪强）

判据：炸板率 >40% → 情绪转弱；连板高度连续下台阶 → 退潮期；首板数量骤增而连板减少 → 资金不敢接力。

### 3. 量能

- 全市场成交额，与近 5 日、20 日均值对比
- 量能变化与指数方向的组合：放量上涨（健康）、放量滞涨（派发）、缩量上涨（惜售或无人接）、缩量下跌（观望）

### 4. 板块轮动

- 涨幅前 10 / 后 10 板块
- 主线判定：连续 3 日以上居前 + 有龙头 + 有成交量 → 主线；单日冲高 → 脉冲
- 板块内部分化度：是普涨还是只有龙头涨（普涨=资金充裕，独涨=抱团）

### 5. 情绪温度

给 0-100 的温度值，由四项合成，**必须列出各项分数，不许只给总分**：

| 项 | 权重 | 依据 |
|---|---|---|
| 广度（涨跌家数比） | 30% | |
| 高度（连板高度与连板数） | 25% | |
| 量能（成交额分位） | 25% | |
| 赚钱效应（涨幅>5% 家数占比） | 20% | |

分档：0-20 冰点 / 21-40 偏冷 / 41-60 中性 / 61-80 偏热 / 81-100 过热。

### 6. 明日观察点

给 3 条**可验证**的观察项，不写"关注市场情绪变化"这种废话：

- 若 {某板块} 明日不能放量突破 {某位置}，则今日的强势属于脉冲
- 若 {某指标} 跌破 {某数值}，则情绪进入退潮
- {某事件} 明日公布，是本周唯一能改变主线的变量

```markdown

## 涨停结构

## 量能

```

## 判断条件

| 情形 | 动作 |
|---|---|
| 非交易日 | 回退上一交易日，标题注明日期，不写"今日" |
| 半天交易 | 标注"半日数据，量能不可与全日对比" |
| 数据只到指数不到个股 | 只出指数与板块，明确说广度数据缺失，不给温度分 |
| 用户问"明天涨不涨" | 拒绝点位预测，改为给三档情景与触发条件 |
| 单一板块暴涨 | 必须查是否有个股停牌/复牌造成的失真 |

## 异常处理

- 涨停家数统计口径不一致（是否含 ST、是否含北交所）→ 注明口径，同一报告内不混用。
- 成交额含北交所与否会导致数值差 1-2%，注明即可，不必纠结。
- 遇到指数编制调整或熔断等极端情况，说明异常，不强行归因。
