# 六维打分细则

打分的作用不是得出一个精确的分数，是**逼自己把六个维度都看一遍**，并让"哪一维拖后腿"变得可见。

分数只在维度内部有意义，跨公司比较时须说明样本。

## 通用规则

- 每维以 60 分为"符合行业正常水平"的基准。
- 加分靠可验证的事实，不靠叙事。
- 减分项一旦是"一票否决项"（见末节），直接覆盖总分。
- 某一维数据缺失：标 `[MISSING]`，该维不参与加权，剩余维度按比例归一。

## 维度一 · 生意质量（25%）

| 分档 | 判据 |
|---|---|
| 85-100 | 护城河明确且可指认（牌照/成本/网络/转换成本/品牌之一），毛利率连续 5 年稳定或上行，客户分散 |
| 70-84 | 有竞争优势但依赖单一因素，毛利率稳定 |
| 55-69 | 竞争充分，毛利率随行业波动 |
| 40-54 | 毛利率连续 3 年下滑，或前五大客户占比 >50% |
| <40 | 无定价权，靠价格战维持份额，或商业模式依赖补贴 |

## 维度二 · 财务质量（25%）

四项各自打分后取平均：增长、盈利、现金流、资产质量。

| 子项 | 满分条件 | 扣分信号 |
|---|---|---|
| 增长 | 扣非净利三年复合 >15% 且波动小 | 增长全靠非经常性损益；单季跳变无解释 |
| 盈利 | ROE >15%，且拆解后主要由净利率或周转驱动 | 高 ROE 全靠杠杆（权益乘数 >4） |
| 现金流 | 经营现金流/净利润连续三年 >1 | 连续两年 <0.8；应收账款激增 |
| 资产质量 | 商誉/净资产 <10%，无大额在建工程长期挂账 | 商誉/净资产 >30%；其他应收款异常 |

## 维度三 · 定价位置（15%）

| 分档 | 判据 |
|---|---|
| 85-100 | PE/PB 分位 <30%，且 ROE 分位 >60%（便宜且质量好） |
| 70-84 | 估值分位低于质量分位 |
| 55-69 | 两者大致匹配 |
| 40-54 | 估值分位高出质量分位 20 个百分点以上 |
| <40 | 估值分位 >80% 而 ROE 分位 <50%（贵且没有理由） |

周期股改用 PB 分位与历史盈利中枢，且必须写明"当期 PE 处于盈利高点，失真"。

## 维度四 · 交易结构（15%）

| 分档 | 判据 |
|---|---|
| 85-100 | 多头排列，量价配合，日均成交额 >5 亿，无停牌历史 |
| 70-84 | 趋势向上但量能一般 |
| 55-69 | 均线交织，方向不明 |
| 40-54 | 空头排列但成交尚可 |
| <40 | 流动性枯竭（日均 <5000 万）或长期停牌或连续一字板 |

## 维度五 · 资金与预期（10%）

| 分档 | 判据 |
|---|---|
| 85-100 | 机构持仓上升，一致预期上调，覆盖机构 >10 家 |
| 70-84 | 预期稳定，资金温和流入 |
| 55-69 | 无明显方向 |
| 40-54 | 一致预期下调，或机构持仓连续下降 |
| <40 | 覆盖机构 <3 家且成交萎缩（定价效率差） |

## 维度六 · 事件与风险（10%）

| 分档 | 判据 |
|---|---|
| 85-100 | 未来 6 个月无重大风险事件，有明确正向催化 |
| 70-84 | 有常规事件但可控 |
| 55-69 | 有解禁/减持但比例小 |
| 40-54 | 未来 3 个月解禁 >10% 总股本，或质押 >50% |
| <40 | 触及退市指标，或存在重大诉讼/立案调查 |

## 一票否决项

出现任意一条，不再加权，直接给"排除"或"仅观察"：

1. 财务造假嫌疑：审计意见非标、经营现金流与利润长期背离且无解释
2. 退市风险：触及财务类或交易类退市指标
3. 治理失效：控股股东大额占用资金、违规担保
4. 流动性枯竭：日均成交额 <1000 万或长期停牌
5. 主体已变：借壳/重组后历史财务不可比，且新主体无足够披露

## 加权与结论

```
总分 = 生意×0.25 + 财务×0.25 + 定价×0.15 + 交易×0.15 + 资金×0.10 + 事件×0.10
```

| 总分 | 结论 | 下一步 |
|---|---|---|
| 80+ | 值得深入研究 | 进 `ar-value` |
| 65-79 | 有条件关注 | 写明成立条件 |
| 45-64 | 只跟踪 | 写观察触发点 |
| 30-44 | 有明显硬伤 | 指出是哪一维 |
| <30 | 排除 | 一句话说清 |

**分数必须能被推翻**：在结论里写一句"若某维的判断被修正，总分与结论如何变化"。
