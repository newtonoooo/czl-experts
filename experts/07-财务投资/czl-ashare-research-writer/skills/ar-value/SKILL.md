# 估值定锚

估值不是算出一个数，是回答：**现在这个价，已经把什么好事算进去了。**

一个说不出"市场在假设什么"的估值，等于没做。

## 职责

**做**：多方法交叉、显式假设表、隐含预期反推、三档情景、敏感性。
**不做**：不给单点目标价、不写"必到 XX"、不做仓位（交 `ar-position`）。

## 输入参数

| 参数 | 必填 | 说明 | 缺失处理 |
|---|---|---|---|
| 标的代码 | 是 | — | 交 `ar-intake` |
| 当前价与市值 | 是 | 来自证据台账 | 无则先取数 |
| 盈利预测基础 | 是 | 最近 8 期财务 | 缺失则只做相对估值 |
| 估值方法偏好 | 否 | 相对 / 绝对 / 都要 | 默认都要 |
| 时间维度 | 否 | 6 个月 / 12 个月 / 3 年 | 默认 12 个月 |

## 方法一 · 相对估值（必做）

### 1. 自身历史分位

取近 5 年（不足则取上市以来）PE-TTM、PB 序列，算出当前值所处百分位。**给数值，不给形容词。**

```
当前 PE-TTM 28.4x，近 5 年百分位 62%（区间 15.2x-65.8x，中位数 26.1x）
```

### 2. 同业横截面对比

选 5-10 家可比公司（同申万二级行业、市值相近、商业模式相似），比 PE/PB/PS/EV-EBITDA，给出中位数与四分位。

**必须说明可比性**：不同板块（主板 vs 创业板）估值中枢不同；ST 股不可并列；亏损公司 PE 无意义，改 PS 或 EV/Sales。

### 3. 得出区间

以自身分位与同业中位数为两个锚，取交集或给出分歧：

```
相对估值区间：{低} - {高} 元（对应 PE {a}x - {b}x）
```

## 方法二 · 绝对估值（有条件必做）

适用：现金流可预测、非强周期、非重资产扩张期。不适用时明确写"本标的现金流波动大，DCF 结果仅供参照"，不硬套。

### 简化两阶段模型（`scripts/arvalue.py` 可算）

```
企业价值 = Σ FCFF_t / (1+WACC)^t  +  TV / (1+WACC)^n
TV = FCFF_n × (1+g) / (WACC - g)
FCFF = EBIT × (1-税率) + 折旧摊销 - 资本开支 - 营运资本增加
WACC = E/(D+E) × Re + D/(D+E) × Rd × (1-税率)
Re = Rf + β × ERP + 规模/治理溢价
```

A股参数默认值（须在报告中列出，且允许用户改）：

| 参数 | 默认 | 说明 |
|---|---|---|
| Rf | 10 年期国债收益率 | 取当日实际值 |
| ERP | 5.5% | A股长期股权风险溢价经验值 |
| β | 行业 β 或自算 | 须注明来源与窗口 |
| 永续增长 g | 2.0% | 不得超过长期名义 GDP 增速 |
| 税率 | 15% 或 25% | 按实际高新技术资质 |

**永续增长超过 3% 的模型一律不接受**，那是把乐观写进了公式。

## 方法三 · 隐含预期反推（最有价值的一步）

不做这一步的估值，是在猜价格；做了这一步，才知道价格在赌什么。

把当前市值代入模型，倒推市场隐含的假设：

```
当前市值隐含：未来 5 年营收复合增速需达 {X}%，或净利率需从 {a}% 提升至 {b}%，或永续增长需达 {c}%。
对照：过去 3 年实际复合增速 {Y}%，行业平均 {Z}%。
判断：{该隐含假设是偏乐观 / 合理 / 偏悲观}，理由是 {}。
```

输出一句人话：**"这个价，等于假设它未来五年每年增长 18%。它过去三年做到了 11%。"**

## 三档情景

| 情景 | 触发条件 | 关键假设 | 对应价值 |
|---|---|---|---|
| 乐观 | 写具体可观察事件 | 增速 a%、利润率 b% | X-Y 元 |
| 中性 | 现状延续 | 增速 c%、利润率 d% | X-Y 元 |
| 悲观 | 写具体可观察事件 | 增速 e%、利润率 f% | X-Y 元 |

概率权重：三档给权重（合计 100%），并说明权重依据。**不给权重的三档情景是摆样子。**

## 敏感性

至少给一张二维表：增速 × 折现率（或 PE × 净利率），行列各 3 档，中间格是中性情形。

## 输出

```markdown
## 定价结论
合理价值区间：{低} - {高} 元（当前 {现价} 元，处于区间 {位置}）
方法与权重：相对估值 {x}% / 绝对估值 {y}%
置信度：{高/中/低}，因为 {一句话}

## 市场在假设什么
当前价格隐含 {}。这个假设 {成立的可能性}，因为 {}。

## 假设表
| 假设 | 取值 | 依据/来源 | 若变动会怎样 |

## 情景
| 情景 | 触发 | 价值区间 | 权重 |

## 敏感性
{二维表}
```

## 判断条件

| 情形 | 动作 |
|---|---|
| 公司亏损 | 不用 PE，改 PS/EV-Sales/PB，或直接说"无盈利，估值不适用" |
| 强周期（钢煤化工航运） | 用 PB 与历史盈利中枢，不用当期 PE；明确提示"低 PE 可能是盈利高点" |
| 金融股 | 用 PB-ROE 框架，不用 FCFF |
| 重资产扩张期 | FCFF 为负属正常，改用 EV/EBITDA 与产能投放节奏 |
| 两种方法结论差异 >30% | 不平均。找出差异来源并说明，倾向更保守的一种 |
| 缺关键财务 | 只做相对估值，并写"缺绝对估值交叉验证，置信度降为中" |

## 异常处理

- 财务为负或异常（如 EBIT 为负）→ DCF 不成立，直接跳过并说明。
- 可比公司不足 3 家 → 放弃同业对比，只用自身分位 + 绝对估值。
- 近期有重大重组 → 历史财务不可比，估值只能基于备考报表或重组后逻辑，须显著标注。

## 与其他工作流的关系

- 上游：`ar-evidence`、`ar-autopsy`（生意与财务结论是估值假设的输入）
- 下游：`ar-thesis`（定价章节）、`ar-quality`（检查假设是否列全）
- 不与 `ar-tape` 直接耦合：市场情绪可影响短期价格，但不改内在价值结论
