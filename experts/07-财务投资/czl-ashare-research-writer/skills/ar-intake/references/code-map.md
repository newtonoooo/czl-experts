## 描述性说法的处理

用户给"沪市股王""锂电龙头""白酒老二"这类说法时：

1. 给出 2-3 个最可能的候选，附一句判断依据（市值、行业地位）。
2. 让用户选，**不要自作主张选一个往下做**。
3. 若用户坚持"你看着办"，选市值最大的那个，并在报告开头写明"按 XX 口径锁定为 XXXX"。

## 特殊状态

| 状态 | 识别方式 | 处理 |
|---|---|---|
| ST / *ST | 证券简称前缀 | 幅度 5%（主板），必须显著提示退市风险 |
| 退市整理期 | 简称含"退" | 只出风险清单，不出估值 |
| 长期停牌 | 行情时间戳长期不更新 | 技术面结论全部失效 |
| 新股（上市 <60 交易日） | 上市日期 | 均线类指标无意义，须注明样本不足 |
| 北交所 | 8xx/920 | 流动性与主板差异大，横向比较须说明 |
