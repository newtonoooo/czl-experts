## 它到底做什么

市面上多数股票分析工具的组织方式是：**数据维度 → 分析模块 → 拼成报告**。

这个产品的组织方式是：**要交付什么 → 要回答哪个问题 → 最少需要什么证据 → 证据能不能拿到 → 怎么说才不算骗人**。

差别在结果上很直白：前者给你一堆分析，后者给你一份**能落款、能被复核、能被追问**的文件。

具体做四件事：

| 你问 | 它给 | 典型耗时 |
|---|---|---|
| 这票值不值得看？ | 六维诊断 + 一句可证伪的结论 | 1-2 分钟 |
| 贵不贵？ | 两种方法交叉的区间 + 当前价格隐含了什么增长 | 约 1 分钟 |
| 今天市场在干什么？ | 广度/涨停结构/量能/主线/情绪温度/三个可验证观察点 | 1 分钟 |
| 帮我写成能发的稿 | 七段结构 HTML（可打印）+ 同源 Markdown | 1-2 分钟 |

另外两条：持仓敞口体检（集中度/相关性/事件撞车/流动性），以及观点台账（记录每次判断、到期复核、只判对/错/未了结）。

## 三个不太一样的地方

**1. 不装东西也能跑。**
取数走三级降级：公开接口 → 你已连接的金融工具 → 联网检索。全部脚本只用 Python 标准库，不需要 numpy / pandas / requests，不需要开通任何付费数据通道。取不到就明说取不到，给一份"缺什么、缺了会导致哪个结论不成立"的清单，不编数。

**2. A 股规则先校验，再分析。**
涨跌停（主板 10%、ST 5%、双创 20%、北交所 30%）、T+1、停牌、复权、龙虎榜、解禁、退市线——这些会让结论直接变错的东西，每次强制过一遍机器校验。特别是**北向资金**：2024 年 8 月起已无实时净流入披露，任何"今日北向净买入 XX 亿"都是错的，闸门会直接拦。

**3. 交付前过闸门，不过不放行。**
7 项机器检查 + 4 项人工判据：禁用词、免责声明、七段完整性、数字可追溯率、时间口径、涨跌停合规、北向口径。实测中它能拦住"区间上下限没登记台账"这类隐蔽问题——派生数字也必须可追溯。

## 和别人比

同类专家包大多各有专长：有的绑 MCP 拿结构化财务（数据更全）、有的内置 15+ 策略（打法更多）、有的专做回测（验证历史）。这份产品的取舍不一样：

**它强在"能不能交出去"**——零依赖可跑、A股规则先校验、成品是自包含文件、交付前过闸门、每个数字可追溯、每个判断可记分。

**它弱在"数据有多深"**——没有财务数据库，六维诊断里只有技术面是自足的；不绑 MCP，所以拿不到龙虎榜席位、DDX 这类明细；不做回测、不做选股、不做港美股。

完整的能力矩阵、6 项优势与 10 项劣势、什么场景该选谁，都在 `docs/竞品对比.md`，劣势一节没有修饰。

## 快速开始

对话里直接说人话即可，不需要记命令：

```
帮我诊断一下贵州茅台（600519）
```
```
这票现在贵不贵？给我区间，并说明当前价格隐含了什么增长
```
```
把刚才的分析整理成稿，HTML 和 Markdown 都要
```

想手动跑脚本（在包根目录）：

```bash
# 1. 取行情
python skills/ar-evidence/scripts/arfetch.py quote --codes 600519

# 2. 取前复权日K
python skills/ar-evidence/scripts/arfetch.py kline --code 600519 --days 250

# 3. 算指标
python skills/ar-evidence/scripts/arindicators.py --file bars.json

# 4. 估值与隐含预期反推
python skills/ar-value/scripts/arvalue.py implied --ev 3000 --fcf 100 --wacc 9 --years 5 --terminal 2

# 5. A股规则校验
python skills/ar-evidence/scripts/arrules.py check --code 600519 --prev-close 1500 --price 1650

# 6. 渲染报告
python skills/ar-thesis/scripts/arreport.py --input draft.json --out 600519-diagnosis-20261029.html

# 7. 交付闸门
python skills/ar-quality/scripts/archeck.py --doc 600519-diagnosis-20261029.html \
        --evidence data/600519-evidence-20261029.json --code 600519
```

## 边界（写清楚，避免误会）

**不做**：
- 不预测点位、不给"明天涨跌"
- 不给买入/卖出/加仓/清仓的操作指令，只给条件化情景
- 不做分钟级或 tick 级回测，不做期权、可转债定价
- 不接交易接口，不代替下单
- 不触碰内幕信息，用户提供未公开信息时明确拒绝

**做不到**：
- 行情来自公开接口，有延迟，非交易级
- 无财务数据库，深度财务分析需用户提供或联网检索
- 一致预期、龙虎榜明细等数据需外部工具补充，缺失时报告会标注
