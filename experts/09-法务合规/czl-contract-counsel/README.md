# 契约守门人（czl-contract-counsel）

由**虫志龙**独立开发的条款级合同审查顾问：起草能签的合同、逐条查风险、比对版本、核验法条、跟踪履约节点。**纯本地运行，不依赖任何第三方签署或审查服务。**

## 类型

Agent 型（单个 AI 专家）· 行业分类：法务安全（11-SecurityCompliance）

## 一句话定位

站在你这边的合同把关人——把"要不要签、哪里要改、改完怎么谈、签完别漏事"这四件事一次做完，并落成可交付的文件。

## 五条工作流

| 代号 | 名称 | 干什么 | 产出 |
|---|---|---|---|
| W1 | 起草台 | 把业务诉求装配成条款齐备的合同 | `.docx` 合同 + `.md` 预览 + `.meta.json` |
| W2 | 审查台 | 逐条识别风险，分级、给改法、给依据 | 风险报告 `.md` + 结构化 `.json` |
| W3 | 比对台 | 判两版差异，分出"必须谈"和"可以让" | 变更分级报告 + 谈判清单 |
| W4 | 依据核查 | 把"我觉得"换成"哪一条这么规定" | 条号 + 要点 + 置信度 |
| W5 | 履约跟踪 | 谁在什么时候该干什么 | 履约台账 + 到期提醒 |

## 支持的合同类型

采购/买卖、技术服务、房屋租赁、劳动合同、保密协议（NDA）、借款。共 72 条原创通用条款，31 条可解释审查规则，覆盖 4 部法律 44 条导航。

## 使用示例

- 帮我起草一份办公用品采购合同：我方是甲方（采购方），供应商是乙方，含税总价 20 万元，验收后 30 天付款。
- 帮我审一下这份租房合同，我是租客，重点看押金退还和提前解约，有问题的条款直接告诉我怎么改。
- 对方回传了修改版，帮我比一下和原版差在哪，哪些条款是必须谈的。
- 劳动合同期限 1 年，最多可以约定多长试用期？给我条号和要点。
- 合同签完了，帮我把付款、验收、质保这几个节点排进台账。

## 技术特点

- **零第三方依赖**：只用 Python 3.8+ 标准库，`python -c "import"` 不需要装任何包，商业分发无依赖授权问题。
- **自研 DOCX 写入器**：按 OOXML 最小可用子集生成合同文档（A4、宋体小四、1.5 倍行距、首行缩进、表格框线、签署区），不引入 python-docx。
- **可解释规则引擎**：31 条规则均为「触发方式 + 为什么是问题 + 怎么改 + 法律依据」四段式，用户能看到结论是怎么来的。
- **数据不出本机**：合同正文只在本地解析、比对、生成；仅核验法条时检索公开法规，不传合同内容。

## 安装与注册

```bash
# 1. 把专家包放到专家目录
~/.workbuddy/plugins/marketplaces/my-experts/plugins/czl-contract-counsel/

# 2. 注册（使专家在 WorkBuddy 中可见）
python3 <expert-manager>/scripts/register_expert.py <专家包目录>

# 3. 校验（可选）
python3 <expert-manager>/scripts/validate_expert.py <专家包目录>
```

## 使用前自检

```bash
python skills/contract-counsel-toolkit/scripts/cc.py doctor
```

正常输出 `"ok": true`，并列出条款库、规则表、法条索引、DOCX 写入器四项检查结果。

## 边界与免责

- 不代签、不盖章、不出具律师函、不承诺诉讼结果、不评估对方资信。
- 不生成规避法律强制性规定、阴阳合同、虚假出资等条款。
- 输出为起草与自查用途的参考文本与风险提示，不构成法律意见；标的额较大或涉及股权、担保、涉外、建设工程、金融产品的交易，请交执业律师复核。
