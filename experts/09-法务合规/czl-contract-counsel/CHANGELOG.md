# 版本更新日志

遵循语义化版本：主版本（不兼容变更）· 次版本（新增能力）· 修订号（修正与优化）。

## [1.0.0] - 2026-10-26

首个发布版本。独立开发，不基于任何第三方合同产品或电子签服务的代码、提示词与条款库。

### 新增

- **专家主体**：`契约守门人（Contract Sentinel）`，Agent 型单专家，分类 11-SecurityCompliance，作者虫志龙。
- **主提示词**：五条工作流路由、站位判断、输入完整性分级、执行纪律、交付四段体例、边界声明。
- **W1 起草台**：6 类合同（采购 / 技术服务 / 房屋租赁 / 劳动合同 / 保密协议 / 借款）的条款装配，支持条款覆盖、增删、站位差异化。
- **W2 审查台**：要素覆盖检查 + 31 条可解释规则（regex / numeric / absent / mutual / conditional_absent 五类检测器），输出风险表、必改 Top3、缺失要素、0-100 风险分与四档结论。
- **W3 比对台**：条号对齐 / 顺序对齐双策略，文本相似度 + 数值集合比对 + 甲乙方指向翻转识别，变更三级分类与谈判清单。
- **W4 依据核查**：本地法条索引（4 部法律 44 条导航 + 10 个高频场景索引），条号置信度分级，需复核项显式标注。
- **W5 履约跟踪**：节点台账（新增 / 导入 / 列表 / 到期 / 完成 / 删除 / 报告），状态按当天日期实时计算。
- **原创条款库**：72 条通用商务条款，覆盖标的、价款、交付、验收、质保、知识产权、保密、违约、解除、不可抗力、送达、争议解决等要素。
- **原创风险规则表**：31 条规则，每条含触发方式、风险说明、改法、法律依据与置信度。
- **原创头像**：512×512 PNG，415 KB，深蓝灰背景 + 双页合同叠成盾形 + 金线印章符号。
- **文档集**：产品规格、使用说明、五条工作流规格、输入输出规范、开发记录、文件清单、测试报告、商业发布风险清单、平台展示文案。

### 技术实现

- **零第三方依赖**：仅用 Python 3.8+ 标准库（`zipfile` / `re` / `json` / `difflib` / `zlib` / `datetime` / `argparse`）。
- **自研 DOCX 写入器**（`cc_docx.py`）：按 OOXML 最小可用子集生成 `[Content_Types].xml`、`_rels/.rels`、`word/document.xml`、`word/styles.xml`、`word/settings.xml`、`docProps/*`；支持标题、段落、首行缩进、表格框线、两栏签署区、分页；内置结构校验。
- **自研 DOCX 读取**：直接解析 `word/document.xml` 提取正文，兼容 Word / WPS 保存的文件。
- **条款切分三级退化**：`第X条` → 序号标题 → 空行段落。
- **金额工具**：阿拉伯数字 → 人民币中文大写（含角分、万亿级），比例合计校验。
- **误报控制**：全文类规则不按条款重复报；对等表述（"另一方有权解除""双方承担保密义务"）不判为不对称；纯排版差异不计入变更。

### 验证

- 工具箱自检 6/6 通过；起草 → docx 结构校验通过；docx 回读信任链打通（生成件再审查 0 误报，风险分 100）。
- 风险样例（故意写坏的租赁合同）9 条中命中 5 高 / 7 中 / 2 低，植入的 5 个高风险全部识别。
- 版本比对样例识别 7 处重大变更，含 1 处甲乙方指向翻转。
- 台账导入 5 个节点，日期推算正确，临近提醒生效。
- 第三方 DOCX 阅读器（pandoc）可正常解析生成文件。
- 详细结果与未验证项见 `docs/TEST_REPORT.md`。

### 已知限制

- 不支持 PDF / 图片 / `.doc` 解析（无 OCR 与 PDF 依赖），需用户转换格式。
- 规则库覆盖常见失衡条款，无法覆盖行业特殊监管与交易背景。
- 法条索引中标注 `confidence=verify` 的条号需以官方文本复核。
- 未在真实 Word / WPS 客户端中做人工打开验证（自动化环境禁止 COM 调用），仅完成结构与第三方解析器验证。
