# 沙特商务拓展专家·旗舰版（czl-saudi-market-entry-pro）

一个用「闸门制」做沙特市场进入的工作台。不是给你讲沙特有多大机会，而是把你从「想进沙特」推到「知道第一步递什么材料、第二步见谁、哪一步会卡住、卡住要多少钱」。

- 开发者：虫志龙（47190078@qq.com）
- 版本：1.0.0
- 类型：Agent 型（单个专家）
- 分类：07-SalesCommerce（销售商务）

## 它解决什么问题

沙特市场最常见的失败，不是选错行业，而是拿着没做完的功课见了不该见的人，然后被一个不能兑现的承诺绑了三年。这个专家把「进入沙特」拆成六道必须逐道通过的闸门，每道门都要给出判定结论和一份可交付文件，上一道没结论就不往下走。

| 闸门 | 回答什么 | 交付物 |
|---|---|---|
| G0 立案 | 这件事到底是什么、成功标准是什么 | 立案卡 |
| G1 准入 | 能不能做、要哪些许可、货能不能进 | 准入判定书 |
| G2 路径 | 独资 / 合资 / 代理 / 许可 / RHQ / 特区怎么选 | 路径决策备忘（三年账） |
| G3 渠道 | 找谁、怎么筛、哪家不能签 | 伙伴评分卡 + 尽调清单 |
| G4 投标 | 该不该投、缺什么资格 | 投标资格核对表 + 商机优先级 |
| G5 落地 | 怎么启动、什么时候会死 | 落地清单 + 风险台账 |

## 三个不一样的地方

1. **有闸门，不是有话题**：每个结论都要过判定，`GO / CONDITIONAL / BLOCKED` 三态明确，阻断项必须写成「谁、向谁、交什么、多久」。
2. **有工具，不是只有建议**：五个零依赖 Python 脚本做准入规则匹配、三年账、伙伴评分、商机排序，算得出来、可复核。
3. **有红线，不是有求必应**：代持、挂名、虚假本地化、规避制裁、非正规佣金一律不接，并给合法替代。

## 安装

**推荐通道：我的专家（my-experts）**

1. 打开 WorkBuddy → 专家 → 我的专家 → 导入专家，选择 `czl-saudi-market-entry-pro.zip`；
2. 或手动把解压后的 `czl-saudi-market-entry-pro/` 目录放到
   `<配置目录>/plugins/marketplaces/my-experts/plugins/` 下；
3. 重启后在小图标列表中可见。

> 不要把这个包放进 `plugins/marketplaces/experts/`（官方市场目录）。该通道的头像走 CDN 路径解析，本地相对路径会 404，专家图标会退化成文字。详见 `docs/03-使用说明.md` 的「头像为什么显示成文字」。

## 边界

- 不提供法律意见、税务申报、审计签字、认证代办；这些需要沙特当地持牌机构。
- 政策、费率、清单、门槛随时可能调整，所有结论都标注检索日期与待核实项。
- 不承诺中标、获批、签下代理；只承诺过程与判定逻辑。
