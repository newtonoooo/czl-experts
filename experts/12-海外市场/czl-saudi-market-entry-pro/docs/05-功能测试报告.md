## 七、诊断性测试：头像显示为文字的原因

| 测试 | 方法 | 结果 |
|---|---|---|
| 相对路径是否被拼成 CDN 地址 | 读取客户端 `app.asar` 中 `resolveExpertAvatarUrl` / `buildExpertUrl` 实现 | 是，基址为 `https://acc-1258344699.cos.accelerate.myqcloud.com/workbuddy/expert-marketplace` |
| 该 CDN 上是否存在 `avatars/expert.png` | HTTP GET | **404 Not Found** |
| 官方专家清单的头像命名规则 | 下载 `expert_center.json`（429 个专家） | 一律为 `/avatars/<专家ID>.png` |
| 目标专家是否在官方清单中 | 检索 `saudi` | **不在清单中** |
| 本地专家通道是否走磁盘解析 | 读取 `readCustomExpertFromDir` / `resolveAvatarUrl` | 是，存在且 ≤5MB 时内联为本地 URL |
| 官方专家清单可达性 | HTTP GET `expert_center.json` | 200，1.16 MB |

结论：图标变文字是**加载通道问题**，不是图片问题。装到 `my-experts` 通道即可正常显示。修复路径见 `docs/03-使用说明.md` 第四节。
