# 05 · 成本栈卡（G5）

> 目的：把前面所有选择折算成"每单位成本多少、几年回本、哪一项最致命"。
> 税率、费率、电价属于高频变动项，本卡给**结构与该问的问题**，具体数值必须现查并在输出里标注时点。

## 一、成本栈（从下往上搭）

| 层 | 成本项 | 口径陷阱 |
|---|---|---|
| 一次性 | 土地 / 厂房 / 设备 / 安装 / 备用金 | 设备的海运、保险、清关、安装调试常被漏算，实际比报价高 15%–30% |
| 固定 | 厂房折旧、设备折旧、常驻人员、保险、许可年费 | 折旧年限与税务口径不一致会导致现金流与利润表打架 |
| 变动 | 原材料、进口件、能源、直接人工、包装、内陆运费 | 进口件要按"到岸 + 关税 + 清关 + 内陆"算，不是 FOB |
| 隐性 | 融资成本、汇兑损益、合规与审计、社区与公关、停工损失 | 融资成本在 High-yield 环境下可能是最大单项 |

## 二、税与费（口径要点）

| 项 | 结构 | 要问清楚什么 |
|---|---|---|
| 企业所得税 | 统一税率对一般企业适用，特定行业与自由区另有安排 | 你的项目适用哪一档？激励是"核减应纳税所得"还是"免税期"？ |
| 增值税 | 标准税率，部分必需品低税率或免税 | 进项能否抵扣？出口是否零税率？退税周期多久？ |
| 关税 | 按 HS 归类，工业品分档 | 设备是否可申请投资法下的免税？原料与成品的税率差多少？ |
| 预提税 | 股息、利息、特许权使用费分档，居民与非居民不同 | 中埃税收协定能否降低税率？需不需要备案？ |
| 社保 | 雇主与雇员分担，基数含部分津贴 | 实际缴费基数是否按"基本工资 + 津贴"？ |
| 其他 | 印花、地方费、工业培训费、出口负担返还（EBR） | EBR 的申请条件与到账周期 |

**不要**在文件里写"埃及企业所得税 22.5%"就完事。要写"一般企业适用 22.5%（现行），你的项目若获激励则按核减后应纳税所得计算，核减比例取决于所在区域分类，需 GAFI 书面确认"。

## 三、能源

- 工业用电分电压等级与用量档位计价，大工业用户还有需量电费。**用平均电价算成本会低估 10%–20%**。
- 天然气价格对用气大户分档，化肥、陶瓷、玻璃等能源密集行业要单独谈。
- 电力可靠性是成本项：停电导致的停工损失、自备发电机的柴油成本，必须进模型。
- 可再生能源自供（光伏 + 储能）在部分场景已具备经济性，但要看并网政策与余电收购安排。

## 四、人工（用 `tools/labor_cost.py`）

全口径 = 基本工资 + 固定津贴 + 变动津贴 + 雇主社保 + 加班 + 招聘与培训 + 离职补偿计提。

三个必须分开的数：

1. **法定最低工资**：合规底线，不等于市场工资。
2. **市场工资带**：按岗位与技能分层，技术工与普工差距大。
3. **全口径成本**：在 2 的基础上加 30%–45%（社保、津贴、福利、离职计提）。

用平均工资算人工是最常见的错误。工程类、连续生产类还要算倒班系数。

## 五、融资

| 渠道 | 特点 | 注意 |
|---|---|---|
| 本地银行埃镑贷款 | 利率高，随政策利率波动 | 高利率环境下长期埃镑债务会吃掉利润 |
| 本地银行美元贷款 | 额度紧，需外汇收入支撑 | 通常要求出口收汇或外汇存款质押 |
| 中资银行 / 出口信贷 | 期限长，绑定设备采购 | 需主权或银行担保，审批周期长 |
| 多边机构（IFC / EBRD / 亚投行） | 期限长、条件透明 | 环境与社会标准要求高，准备期长 |
| 融资租赁 | 适合设备 | 实质利率要算清 |

**判定**：如果融资成本占单位成本 >8%，方案对该利率高度敏感，必须做利率上升 300bp 的压力测试。

## 六、三档情景

| 情景 | 假设 | 看什么 |
|---|---|---|
| 基准 | 汇率按 G1 基准档，产能利用率第 2 年达 70% | 回本期 |
| 承压 | 贬值 20%，售价调价滞后 2 个季度，利用率 60% | 现金流最低点、是否需要追加资本 |
| 恶化 | 贬值 40%，进口件受限，利用率 50% | 止损线是否触发 |

## 七、判定红线

- 回本期 >7 年 → 建议改路径或改体量。
- 单一成本项占比 >45% → 必须给该单项的替代方案。
- 本地含量不达协定门槛 → 出口关税优惠失效，需重算到岸竞争力。
- 现金流最低点出现负值且无追加资本来源 → STOP。

## 八、输出要求

`05-unit-economics.md` + `cost-model.json`。后者必须能被第三方用同样的输入复算出同样的数字，字段名不得随意改。

## 复核渠道

- 埃及税务局（ETA）：税率、申报、裁定
- 埃及海关 / Nafeza：关税、ACID
- 社保局：缴费比例与基数
- 电力与天然气公司：工业费率与接入
- 银行：实际可得利率与费用
