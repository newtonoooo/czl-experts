# 08 · 风险台账卡（G6）

> 目的：把"风险"从形容词变成可每周盯的表。

## 一、台账字段（缺一列就不合格）

| 字段 | 要求 |
|---|---|
| ID | R01、R02……，全案唯一 |
| 风险描述 | 一句话说清"什么事件会影响什么指标" |
| 类别 | 汇率 / 政策监管 / 审批延误 / 土地与公用工程 / 劳工 / 供应链 / 安全地缘 / 合作方 / 税务争议 / 退出 |
| 触发信号 | 可观测、可量化。例："央行连续两次加息"、"ACID 退单率 >10%" |
| 概率 | 低 / 中 / 高（附一句依据） |
| 影响 | 用钱或时间表达。例："追加资本 300 万美元"、"投产延后 6 个月" |
| 等级 | 概率 × 影响 的矩阵结果 |
| 责任人角色 | 角色不写人名。例："财务负责人"、"项目经理" |
| 观察频率 | 周 / 月 / 季 |
| 预备动作 | 触发后 30 天内要做的具体动作 |
| 复核日期 | 下次复核的具体日期 |

## 二、分级矩阵

| 概率 \ 影响 | 低（<100 万美元或 <1 个月） | 中 | 高（>500 万美元或 >6 个月） |
|---|---|---|---|
| 高 | 中 | 高 | 极高 |
| 中 | 低 | 中 | 高 |
| 低 | 低 | 低 | 中 |

"极高"级必须有一条**止损线**：达到什么条件就停、停的时候损失多少。

## 三、埃及场景的高频风险（按类别）

### 汇率与外汇
- 触发信号：平行市场价差扩大、银行外汇额度紧张、进口付汇排队时间变长。
- 预备动作：把美元收入优先归集、提前锁定下季度进口付汇、与供应商谈埃镑计价。

### 政策与监管
- 触发信号：激励政策修订、本地含量比例上调、进口限制清单扩容。
- 预备动作：把"政策变更"写进投资协议的保护条款；保留可切换的供应方案。

### 审批延误
- 触发信号：golden license 受理后 60 天无进展、环评被要求补件两次以上。
- 预备动作：并行推进备选地块；把"政府审批"从关键路径上摘出来做成并行任务。

### 土地与公用工程
- 触发信号：交付时间表二次延期、电力容量确认函迟迟不出。
- 预备动作：合同里写清延期违约金与退出权；预留自备发电方案。

### 劳工与技能
- 触发信号：关键技术岗位招聘周期 >90 天、离职率 >15%/年。
- 预备动作：与职业院校合作定向培养；外籍技术员工作许可提前 4 个月启动。

### 供应链
- 触发信号：单一供应商占比 >60%、关键件交期从 30 天变 60 天。
- 预备动作：本地二供开发；关键件安全库存从 30 天提到 60 天。

### 安全与地缘
- 触发信号：红海航线保险费率跳升、区域冲突升级。
- 预备动作：改航线预案、库存前置、人员撤离预案。此类风险只做情景准备，不做预测。

### 合作方
- 触发信号：对方连续两次未按期提供承诺的资源、关联交易披露不完整。
- 预备动作：启动治理条款中的审计权；准备股权调整方案。

### 税务争议
- 触发信号：收到税务稽查通知、转让定价被质疑。
- 预备动作：同步准备同期资料；聘请当地税务顾问介入。

### 退出
- 触发信号：连续 3 个季度未达预算的 70%。
- 预备动作：启动退出评估（转让 / 收缩 / 关停），并在台账里更新预计退出成本。

## 四、写台账的四条纪律

1. 每条风险必须有触发信号。没有信号的风险叫"担忧"，不叫风险。
2. 影响必须量化。写不出钱就写时间，写不出时间就写"无法量化，需在 G5 补测"。
3. 责任人写角色。写人名会在人员变动后失效。
4. 台账每季度全量复核一次，复核结果写进文件，不要口头过。

## 五、输出要求

`07-risk-ledger.md` 至少 8 条，其中"极高"级不超过 3 条（超过说明方案本身有问题，应回 G3/G4 重做）。文末附一页"止损线清单"。
