# 09 · 国家计划与政策窗口卡（G6）

> 目的：知道"有哪些窗口可以申报"，以及"申报不等于拿到"。
> 政策名称与目标会随政府调整变化，使用前必须核对最新公告。

## 一、Egypt Vision 2030 的三个支柱

| 支柱 | 方向 | 对企业的含义 |
|---|---|---|
| 经济 | 提高增长质量、发展制造与出口、扩大私营部门比重 | 制造业、出口导向、本地化配套项目更容易获得政策支持 |
| 社会 | 教育、健康、就业、社会保障 | 劳动密集项目在就业承诺上有议价空间，也承担相应义务 |
| 环境 | 可再生能源占比、水资源效率、城市可持续 | 高耗水高排放项目审批更严；绿色项目有额外窗口 |

**用法**：不是拿来做 PPT 背景，而是用来判断"你的项目在政府叙事里站在哪一侧"。站在顺风侧，审批和拿地会更顺；站在逆风侧（高耗水、高排放、纯进口分销），要有额外解释。

## 二、可申报的政策窗口（类型）

| 窗口类型 | 内容 | 申报要点 |
|---|---|---|
| 投资法激励 | 投资成本核减、特定区域/行业优惠 | 需在设立阶段就确定制度归属，事后补申通常无效 |
| 自由区 / 经济区待遇 | 关税与税收待遇、简化监管 | 需满足出口比例与本地含量要求 |
| Golden license | 一揽子许可合并 | 材料完整性决定周期；不能替代环评与公用工程接入 |
| 工业本地化计划 | 对特定品类的本地化比例要求与配套支持 | 与整车/整机厂绑定，需先有锚定客户 |
| 可再生能源与绿氢 | 并网、土地、购电协议 | 并网排队是主要瓶颈；承购协议是关键 |
| 出口支持 | 出口负担返还（EBR）等 | 需完整出口单证与本地增值证明；到账周期较长 |
| 中小企业与就业补贴 | 培训、用工补贴 | 金额有限，但对冲爬坡期人工成本有用 |

## 三、申报的现实节奏

1. **制度归属要早定**：走一般制度还是激励制度，在公司设立时就决定了，事后切换成本很高。
2. **材料一次做对**：退回重排是最常见的时间杀手。建议一次性准备"公司文件 + 可研 + 财务模型 + 用地意向 + 环评分类意见"五件套。
3. **并行不串联**：许可之间能并行的要并行（如环评与电力接入申请），把"等审批"从关键路径上摘出去。
4. **书面留痕**：所有口头承诺都要转成会议纪要或书面答复，否则人员一换就归零。

## 四、常见误解

| 误解 | 实际 |
|---|---|
| "拿到 golden license 就能开工" | 还需用地交付、施工许可、电力接入 |
| "自由区就是完全免税" | 进入境内销售要缴关税；有出口比例要求 |
| "政策写了鼓励，我就能拿到" | 需要满足前置条件并通过审核，额度可能受年度预算限制 |
| "签了 MOU 就算落地" | MOU 通常无法律约束力，土地与许可才是实质 |
| "本地含量可以事后补" | 原产地资格在出口申报时就要成立，事后无法追溯 |

## 五、给客户的一句话

政策窗口的价值不在"能省多少钱"，而在"能不能把时间压下来"。在埃及，**时间成本往往比税优更值钱**。

## 复核渠道

- 埃及计划与经济发展部：Vision 2030 与年度计划
- GAFI：投资激励与 golden license
- SCZone：经济区政策
- 贸工部 / IDA：工业本地化与行业政策
- 电力与可再生能源主管部门：并网与购电协议
