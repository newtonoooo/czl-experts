# 02 · 法律与投资制度卡（G0 / G4）

> 目的：把"能不能做、以什么身份做、拿地靠什么、钱怎么出去"四件事讲清楚。
> 本卡不构成法律意见。所有条款以官方文本与当地持牌律师意见为准。

## 一、投资法框架（2017 年第 72 号法及后续修订）

三套制度并存，选错制度会白白丢掉激励：

| 制度 | 适用 | 核心内容 | 注意 |
|---|---|---|---|
| 一般制度 | 绝大多数项目 | 国民待遇、利润与资本可汇出、不得随意国有化 | 汇出以完成外资登记与完税为前提 |
| 激励制度 | 特定区域/特定行业 | 投资成本核减（从应纳税所得额中扣除投资成本的一定比例） | 核减比例与区域分类挂钩，A 类区域高于 B 类；实际可用额度受当年利润限制，**不是一次性全额抵免** |
| 特殊制度 | 自由区、经济区、技术区 | 关税与税收待遇不同，监管口径不同 | 自由区"境内关外"，产品进入埃及境内销售按成品缴关税 |

**Golden license（一揽子许可）**：由 2023 年前后的修法引入，把多个部门的许可合并为一份批复，目的是压缩审批时间。实践要点：

- 它替代的是**部分**许可，不是全部；环评、消防、电力接入通常仍要单独走。
- 申请材料的完整性决定周期，缺件会被退回重排。
- 拿到批复后仍需在开工前完成用地交付与施工许可。

> 以上制度细节请以 GAFI 现行公告与法律原文为准，并请当地律师就"你的项目属于哪一档"出具书面意见。

## 二、公司形式怎么选

| 形式 | 适合 | 优势 | 约束 |
|---|---|---|---|
| 有限责任公司（LLC） | 绝大多数生产型、贸易型项目 | 独立法人、责任有限、设立相对快 | 股东人数与出资安排需符合公司法；部分行业有外资股比限制 |
| 股份公司（JSC） | 需要多轮融资、计划上市 | 可公开发行、治理结构完整 | 设立成本与合规成本高 |
| 外国公司分支机构 | 工程承包、项目公司前期 | 由母公司直接承担，便于投标 | 对母公司的成立年限与资质有要求；不能从事部分受限业务 |
| 代表处 | 市场调研、联络 | 设立最简单 | 不得从事经营活动、不得开票收款 |
| 自由区企业 | 出口导向制造、转口贸易 | 关税与税收待遇优 | 销售到境内要缴关税；有出口比例与本地含量要求 |

**判定顺序**：先看行业有没有外资股比限制 → 再看是否需要投标资质 → 再看是否需要自由区待遇 → 最后才看税。顺序反了会做出无法执行的结构。

## 三、土地与厂房

- 外资取得土地通常是**用益权或长期租赁**，不是所有权；边境与西奈半岛区域有额外限制。
- 工业用地主要来自三个口子：IDA 的工业区、SCZone 的经济区、私营开发商园区。三者的地价、交付条件、电力接入责任差别很大。
- **土地交付时间**是排期里最容易被低估的一项。签约到"三通一平"可用，常见 6–18 个月，取决于地块现状。
- 拿地前必须确认：地块性质（工业/物流/混合）、容积率与建筑密度、电力容量是否已到位、排水与污水处理归属、是否有历史权属争议。

## 四、许可链条（顺序不能乱）

```
公司设立（GAFI / 商业登记）
  → 税务登记（取得税号）
  → 海关备案（如需进出口）
  → 环评分类与批复（EEAA）
  → 工业许可（IDA，按行业）
  → 用地交付与施工许可
  → 电力/水/气接入合同
  → 消防与职业安全验收
  → 投产前联合检查
```

**关键判断**：哪一份文件拿到才允许动土？通常是施工许可 + 用地交付。哪一份拿到才允许进口设备？通常是海关备案 + 投资法下的设备免税批复。把这两个节点标在排期上，客户就知道什么时候必须把钱准备好。

## 五、外汇与利润汇出

| 环节 | 要求 | 失败后果 |
|---|---|---|
| 资本金汇入 | 通过银行渠道、办理外资登记 | 未登记 → 后续汇出被拒 |
| 完税 | 企业所得税清缴 | 欠税 → 汇出被卡 |
| 分红汇出 | 董事会决议 + 完税凭证 + 银行外汇可用性 | 外汇紧张时排队，时间不可控 |
| 关联方费用 | 需符合转让定价规则与预提税 | 被认定为利润转移 → 补税加罚 |

## 六、合规红线（会直接导致停产/罚没的）

1. 未做环评即开工建设。
2. 进口设备以"临时进口"名义入境后转作自用未补税。
3. 自由区企业将产品销往境内未按成品缴关税。
4. 外籍员工工作许可与实际岗位不符。
5. 关联交易定价无文档支撑。

## 复核渠道

- GAFI：投资法、激励申请、公司设立、golden license
- IDA：工业许可、工业用地
- EEAA：环评分级与批复
- 埃及海关 / Nafeza：进出口备案与 ACID
- 埃及税务局（ETA）：税号、申报、裁定
