# 03 · 使用说明

## 一、安装

把整个目录放到专家目录下：

```
<WorkBuddy 配置目录>/plugins/marketplaces/my-experts/plugins/czl-egypt-strategy-pro/
```

Windows 下通常是：

```
C:\Users\<用户名>\.workbuddy-ai\plugins\marketplaces\my-experts\plugins\czl-egypt-strategy-pro\
```

然后注册（让它出现在专家列表里）：

```bash
python scripts/register_expert.py <专家目录>/czl-egypt-strategy-pro
```

`scripts/` 指 WorkBuddy 内置的 expert-manager 技能目录。如果只是通过界面导入 zip，可跳过这一步。

> **注意**：专家包必须放在上面这个专家目录下才会被检测到。把包复制到别处（例如工作区的交付快照目录）再跑校验脚本，会报"专家不在专家目录下"——这是路径检查，不是内容有问题。交付快照只用于查看与上传，不要从快照目录直接安装。

## 二、第一次对话

选一个入口，不要一上来就问"介绍下埃及"。

**推荐开场**：

> 我们计划在埃及建一条面向本地和欧洲市场的中型产线，预算两千万美元以内。请从案头立档开始，一步步带我到能签字的落地方案。

专家会先问你六项参数（做什么、卖给谁、多大、多少钱、多久、亏得起吗），然后按 G0 → G6 推进。

**如果你只想快速判断**：

> 我们做汽车线束，年出口 3000 万美元，主要是给欧洲 Tier1。现在想改成在埃及本地生产，先帮我判断该不该去。

这种问法会触发 G1 + G2 的快速版，不会走全流程。

## 三、四种使用姿态

| 姿态 | 说法 | 得到什么 |
|---|---|---|
| 快速判断 | "先帮我判断该不该去" | 判定 + 3–5 条理由，不出文件 |
| 单点求解 | "埃镑再贬 25% 我毛利会怎样" | 直接给压力测试表 |
| 走完流程 | "从案头立档开始，一步步来" | 七道闸门 + 七份文件 |
| 复盘纠偏 | "项目卡在审批，帮我看看哪一步错了" | 定位到具体闸门重做 |

## 四、怎么问才有用

**好问题**：带参数、带约束、带目标。

> 我们做食品加工，本地销售占 70%，进口原料占物料成本 55%，预算 800 万美元，18 个月内要出货，能接受第一年亏 100 万美元。帮我走一遍。

**坏问题**：没有参数，只能得到泛泛的框架。

> 埃及投资环境怎么样？

后者不是不能用，但专家只能给框架和需要补的参数，给不出判定。

## 五、工具怎么用

工具在 `tools/`，全部标准库，直接跑：

```bash
# 汇率压力测试
python tools/fx_stress.py examples/g1-fx-stress.json

# 选址打分
python tools/site_score.py examples/g3-site-score.json

# 路径比选
python tools/entry_route.py examples/g4-entry-route.json

# 到岸成本
python tools/landed_cost.py examples/g5-landed-cost.json

# 全口径人工
python tools/labor_cost.py examples/g5-labor-cost.json

# 自检（发布前必跑）
python tools/selftest.py
```

加 `--json` 输出结构化结果，方便贴进 `cost-model.json`。

也可以把 `--demo` 当参数模板：先跑 demo 看输出长什么样，再照着 `examples/*.json` 改成自己的数。

## 六、文件放哪

建议每做一个案子建一个文件夹：

```
cases/2026-埃及线束项目/
  00-case-file.md
  01-macro-fx-brief.md
  02-sector-screen.md
  03-site-scorecard.md
  04-entry-route.md

  cost-model.json
  06-mobilization-plan.md
  07-risk-ledger.md
```

七份文件加起来通常 15–30 页，正好是一次董事会的材料量。

## 七、常见问题

**Q：为什么它老问我"卖给谁"？**
A：内销和出口是两套完全不同的账。内销看本地购买力与渠道，出口看原产地规则与港口效率。这一项错了，后面全错。

**Q：为什么不肯给我一个"埃及汇率会到多少"的答案？**
A：点位预测不可靠且会误导决策。它给的是"贬 10/25/40% 时你的毛利怎么变"，这比点位有用。

**Q：数字和我在新闻里看到的不一样？**
A：大概率是口径不同（财年 vs 日历年、城市 vs 全国、月末 vs 年均）。让它把口径和时点标出来，再判断谁对。

**Q：能直接生成 Word/PPT 吗？**
A：输出是 Markdown，字段结构完整，粘进 Word 或交给文档工具转换即可。它不直接产 docx。

**Q：导入后图标变成一个汉字怎么办？**
A：见 `08-图标显示问题诊断.md`，一条命令可修。

## 八、边界提醒

- 它的结论是决策框架，不是法律、税务、审计意见。签约前必须由当地持牌机构复核。
- 它的数据来自公开渠道，有滞后。所有关键数字在正式文件里都要标注检索日期。
- 它不承诺审批结果、补贴额度、税收裁定。
