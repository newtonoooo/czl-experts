# 02 · 工作流说明

七道闸门，顺序执行。每道闸门的结构固定为：**名称 / 职责 / 输入 / 步骤 / 判断 / 输出 / 异常 / 依赖 / 与其他闸门的关系**。

---

## G0 案头立档

- **名称**：案头立档（Case Framing）
- **职责**：把"我们想去埃及"变成一份可计算的案子。
- **输入**：六项基本参数（做什么、卖给谁、体量、资本、时间窗、风险偏好）。
- **步骤**：
  1. 逐项补齐六项；对"卖给谁"要求给出本地/出口比例。
  2. 把客户语言翻译成模型参数：币种结构、进口件占比、用工规模、电力负荷。
  3. 从订单来源与结算币种反推真实目的（出口基地 / 本地市场 / 原产地规避）。
  4. 列出未经确认的假设，逐条标注"若错误的后果"。
- **判断**：缺 ≥3 项 → 拦停，只输出一页补料清单；缺 1–2 项 → 用行业默认值继续，标注"假设值"。
- **输出**：`00-case-file.md`。
- **异常**：客户说不出体量 → 给保守/中性/进取三档让其选；客户说不清卖给谁 → 默认"本地为主 + 出口为辅"并标注。
- **依赖**：无。
- **关系**：后续六道闸门的全部输入来自这里；G0 的假设在 G5 会被逐一检验。

## G1 环境体检

- **名称**：环境体检（Macro & FX Fitness）
- **职责**：判断此刻进场，钱进得去、利润出得来吗。
- **输入**：G0 参数 + 币种结构 + 融资币种。
- **步骤**：
  1. 取当期汇率、通胀、政策利率、储备，标注口径与时点。
  2. 调 `fx_stress.py` 跑 0 / 10 / 25 / 40 四档情景，取毛利变动与现金缺口。
  3. 拆解资金出入境三条路径（资本金、关联方贷款、利润汇出）的卡点。
  4. 计算净美元敞口与建议对冲比例。
- **判断**：三条红线任一触发 → CONDITIONAL 或 STOP（进口件 >60% 无对冲；20% 贬值毛利率掉 >8pp；回款 >180 天无本地融资）。
- **输出**：`01-macro-fx-brief.md` + 判定。
- **异常**：取不到当期汇率 → 用最近可得时点并在文件顶部标注，禁止用记忆值。
- **依赖**：`fx_stress.py`、`references/01-macro-fx.md`、`references/10-data-ledger.md`。
- **关系**：STOP 回 G0 重设参数；CONDITIONAL 的条件作为参数带入 G5。

## G2 赛道筛选

- **名称**：赛道筛选（Sector Screen）
- **职责**：判断品类在埃及是政策顺风还是结构逆风。
- **输入**：G0 的产品定义 + G1 判定。
- **步骤**：五维打分（供给缺口 / 替代空间 / 协定覆盖 / 门槛可达 / 竞争缓和），每项写一句理由；梳理竞争格局；给出切入角度（整机 vs 配套、高端 vs 性价比）。
- **判断**：加权 <3.0 → 换品类或换角度；本地已有 ≥3 家同质产能且无差异化理由 → 拦停。
- **输出**：`02-sector-screen.md`。
- **异常**：品类不在六卡之内 → 用五维框架现场建卡，标注"非标品类，置信度下调一档"。
- **依赖**：`references/07-sector-screens.md`。
- **关系**：决定 G3 的候选落点集合。

## G3 落点选址

- **名称**：落点选址（Site & Zone Fit）
- **职责**：排出候选落点顺序，并说清"为什么不是第一名"。
- **输入**：G2 赛道 + G0 的内销/出口比例。
- **步骤**：
  1. 按业务性质重设权重（出口导向：物流 30%；内销导向：物流 15%、劳动力 20%）。
  2. 调 `site_score.py` 打分。
  3. 做 ±10% 权重敏感性，记录翻转点。
  4. 列出待核实项（电力容量、交付时间、污水、通勤）。
- **判断**：分差 <5 → 并列，给二选一；>15 → 单一推荐并写备选反超条件。
- **输出**：`03-site-scorecard.md`。
- **异常**：客户已锁定地块 → 跳过排序，改做"地块适配性体检"。
- **依赖**：`site_score.py`、`references/03-sites-zones.md`。
- **关系**：落点决定 G5 的地价、电价、物流半径参数。

## G4 进入路径

- **名称**：进入路径（Entry Route）
- **职责**：在六条路径中选一条，并把退出写在同一页。
- **输入**：G3 落点 + G0 资本与时间约束 + 技术保密要求。
- **步骤**：
  1. 明确三条硬约束：技术能否外流、是否需要投标资质、能否等 24 个月。
  2. 调 `entry_route.py`：**先过滤再排序**。
  3. 对合资/并购补治理条款清单。
  4. 写明退出方式与预计退出成本。
- **判断**：资本 <500 万美元且 18 个月内要出货 → 绿地全资出局；技术不能外流 → 排除代工与纯代理。
- **输出**：`04-entry-route.md`。
- **异常**：客户已签意向书 → 转"条款体检"，逐条标出不利条款。
- **依赖**：`entry_route.py`、`references/04-entry-routes.md`。
- **关系**：路径决定 G5 的成本结构与 G6 的许可顺序。

## G5 单位经济与合规建模

- **名称**：单位经济（Unit Economics & Compliance）
- **职责**：把选择折算成单位成本、回本期、最致命项。
- **输入**：G3 成本参数 + G4 路径 + G0 体量。
- **步骤**：
  1. `landed_cost.py` 算进口到厂单价（含清关、内陆、滞港、在途资金）。
  2. `labor_cost.py` 算全口径人工（含社保、津贴、离职计提）。
  3. 补税、能源、融资、合规成本。
  4. 跑基准 / 承压 / 恶化三档，输出 `cost-model.json`。
- **判断**：回本期 >7 年 → 改路径或改体量；单项占比 >45% → 必须给替代方案；本地含量不达协定门槛 → 重算出口竞争力；现金流最低点为负且无追加资本 → STOP。
- **输出**：`05-unit-economics.md` + `cost-model.json`。
- **异常**：客户只给总额不给单价 → 反推单位成本并请其确认。
- **依赖**：`landed_cost.py`、`labor_cost.py`、`references/05-cost-stack.md`、`references/06-customs-logistics.md`。
- **关系**：唯一可能推翻 G3/G4 的闸门。推翻必须回退重做，不允许在 G5 内部打折消化。

## G6 落地排期与风险台账

- **名称**：落地排期（Mobilization & Risk Ledger）
- **职责**：把方案变成 12 个月动作序列 + 可每周盯的风险表。
- **输入**：G1–G5 全部结论。
- **步骤**：
  1. 匹配政策窗口（投资法激励、自由区、golden license、出口支持）。
  2. 排许可顺序：公司设立 → 税务登记 → 海关备案 → 环评 → 工业许可 → 用地交付 → 电力接入 → 验收。
  3. 标出关键路径与可并行任务。
  4. 建风险台账（≥8 条），每条带触发信号与预备动作。
  5. 写止损线。
- **判断**：关键路径上"等审批" >3 个月 → 必须给并行备选；台账 <8 条 → 视为分析不足。
- **输出**：`06-mobilization-plan.md` + `07-risk-ledger.md`。
- **异常**：客户只要方案不要排期 → 输出精简版（里程碑 + 风险前五）。
- **依赖**：`references/09-vision-programs.md`、`08-risk-ledger.md`、`11-deliverable-templates.md`。
- **关系**：终点闸门，输出即交付包。

## 中断与切换

| 用户行为 | 系统响应 |
|---|---|
| 在 G5 中途要求"先查个汇率" | 暂停，按 G1 口径给数，回到 G5 时提示参数已更新 |
| 要求"别那么长" | 切换为 5–8 条结论 + 判定，保留证据等级 |
| 要求"给我推导" | 展开为"参数 → 计算 → 结论 → 反例" |
| 提出完全无关的问题 | 正常对话回答，不启动闸门 |
| 跳过某道闸门 | 允许，但输出顶部标注"该结论建立在未验证假设上"并列出待补输入 |

## 闸门之间的数据流

```
G0 参数 ──► G1 判定 ──► G2 赛道 ──► G3 落点 ──► G4 路径 ──► G5 单位经济 ──► G6 排期与风险
   ▲           │                        │            │            │
   └───────────┴────────────────────────┴────────────┴────────────┘
                     任一闸门判定为 STOP 或 G5 推翻前序，回到对应闸门
```
