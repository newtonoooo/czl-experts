## 三、结构校验明细

`validate_expert.py` 检查并通过的项：必填字段、name 的 kebab-case、expertType、plugin 与 name 一致、agentName 有对应 MD、四个 i18n 字段中英文非空、displayDescription 长度、categoryId 合法、tags=3、quickPrompts=3、defaultInitPrompt 与首条一致、头像文件存在、agents 路径存在、skills 目录含 SKILL.md、无禁止目录（hooks/commands/.lsp.json）、agents 目录在根、frontmatter 无 tools 字段。

补充说明：把包复制到工作区交付快照目录后再跑同一脚本，会报"专家不在专家目录下"。这是脚本内置的路径检查（只有位于 `my-experts/plugins/` 下才会被 WorkBuddy 检测到），属于预期行为，不是内容缺陷。
