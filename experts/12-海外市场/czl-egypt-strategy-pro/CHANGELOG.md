# 更新日志

格式遵循语义化版本：`MAJOR.MINOR.PATCH`。

## 1.0.0 — 2026-10-28

首个版本，独立实现，不基于任何既有专家包的代码、提示词或数据文件。

### 新增

- **七道闸门工作流**：G0 案头立档 → G1 环境体检 → G2 赛道筛选 → G3 落点选址 → G4 进入路径 → G5 单位经济 → G6 落地排期与风险台账。每道闸门固定输出 PASS / CONDITIONAL / STOP 判定与对应文件。
- **主 Agent 提示词** `agents/egypt-strategy-pro.md`：定义闸门顺序、判定红线、证据分级 E1–E4、数据纪律与输出规范。
- **技能包** `skills/egypt-landing-desk/`：SKILL.md 索引 + 12 张原创参考卡（方法、宏观汇率、法律投资、落点园区、进入路径、成本栈、清关物流、赛道筛选、风险台账、国家计划、数据台账、文件模板）。
- **六个标准库工具**：
  - `fx_stress.py` — 四档贬值情景、毛利变动、现金缺口、维持毛利率所需涨价幅度、净美元敞口
  - `site_score.py` — 百分制加权打分、±10% 权重敏感性、并列/倾向/明确三态判定
  - `entry_route.py` — 硬约束先行过滤（资本/周期/技术外流）再四维排序，附退出成本
  - `landed_cost.py` — FOB→到厂单价，含关税、清关、内陆、滞港预备金、在途资金、增值税可抵扣开关
  - `labor_cost.py` — 全口径人工（社保、津贴、加班、招聘、离职计提）与单位产品人工
  - `selftest.py` — 11 条断言回归，退出码即结论
- **头像工具**：`avatar_prep.py`（裁剪/降采样/data URI）、`apply_inline_avatar.py`（相对路径与内联一键切换）。
- **原创头像** `avatars/expert.png`：512×512 PNG，埃及女性顾问形象（深青西装、金色耳饰、开罗天际线背景），扁平插画风格，虚构人物，不含真人肖像。
- **文档**：产品规格、工作流说明、使用说明、平台展示文案、功能测试报告、商业发布风险清单、文件清单与开发记录、图标显示问题诊断。

### 修复

- 针对"专家导入后图标回退成专家名首字"的问题，内置内联头像切换开关，并在 `docs/08-图标显示问题诊断.md` 中给出代码层面的成因分析与四套修复方案。

### 已知限制

- 不内置宏观数据库，实时指标需外部核对。
- 头像在部分宿主版本/通道下仍可能回退为文字，需手动执行 `apply_inline_avatar.py --apply`。
- 参考卡中的费率、门槛为结构性描述，具体数值需现查。
