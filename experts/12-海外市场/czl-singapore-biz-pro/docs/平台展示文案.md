## 四、详情页长文案

### 它不给你一份公司名单，它给你一套能落地的判断

进入新加坡市场，最难的不是"找不到公司"，而是"找错了公司还不知道错在哪"。把集团当成本地实体、把行业相关当成采购需求、把知名企业排在第一——这些错误会让团队白跑三个月。

「新加坡商务拓展专家·旗舰版」把商务拓展拆成六段可验证的流程：

**定标 → 建池 → 排序 → 进入 → 接触 → 跟踪**

- **定标**：先把你的产品、客单价、买方角色问清楚，缺的信息登记成假设，不猜。
- **建池**：按监管名录、企业登记、协会展会、企业一手信息四条路径找候选，每家过"实体四问"。
- **排序**：适配度（Fit）与开发优先级（Priority）分开算，排序只看 Priority；每家必须写三条反证并回应。
- **进入**：先判采购主体（业主自采 / 总包 / 集成商 / 集团集采），再谈路径，不笼统建议"找代理"。
- **接触**：给部门与职能、给首触由头、给三个接触顺位，不给编造的人名邮箱。
- **跟踪**：30/90/180 天动作，每条挂假设编号与成功判据，写清什么时候该停。

### 三条硬约束

1. **每条事实带证据编号**：末尾附台账（来源｜日期｜URL｜等级 A–D），无法确认的写进"待核实清单"。
2. **不给伪精确分数**：只输出高/中/低档位，并说明档位依据。
3. **不给绝对化结论**：没有"一定""必然""绝对适合"，只有"构成较强信号""尚不能确认"。

### 适合谁

- 准备进入新加坡的中国制造商、品牌方、设备与 SaaS 厂商
- 已设新加坡公司、要找本地客户与渠道的中资企业
- 要找代理、经销商、系统集成商、售后伙伴的团队
- 评估新加坡作为区域总部的投资团队

### 不适合谁

- 想直接买一份企业名录的（这里给的是筛选逻辑与优先级，不是数据库）
- 需要法律、税务、签证个案办理的（会转介持牌机构）
- 需要征信报告或个人联系方式的（不提供）

## 五、卖点三条（用于推广位）

1. **六段式流程，不是一次性问答**：每段有判断门，信息不足会停下来问，而不是编一份看起来完整的报告。
2. **双层评分 + 反证强制**：解决"最像客户的不一定最该打"这个老问题。
3. **带工具**：附评分器、证据台账校验器、包体检与打包脚本，结果可复现。

## 六、FAQ

**Q：会不会直接给我一堆大公司名字？**
A：不会。候选池要过"实体四问"，只有 C/D 级线索的企业会进"观察区"，不参与排序。

**Q：能不能给我采购负责人的联系方式？**
A：不提供个人联系方式。给的是部门、职能与公开可验证的入口，例如供应商注册页、招标公告页。

**Q：数据从哪来？**
A：优先政府与法定机构、企业官网与年报、协会与展会名录。每条引用都带来源、日期与链接，并标注证据等级。

**Q：能不能保证拿到订单？**
A：不能，也不做这种承诺。给的是"验证动作 + 成功判据 + 停止判据"，把不确定性显性化。
