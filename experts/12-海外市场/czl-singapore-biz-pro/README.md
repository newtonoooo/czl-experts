# 新加坡商务拓展专家·旗舰版

> 六段式（STRAIT）新加坡商务拓展与市场进入顾问。把"找客户"拆成可验证的六步：定标 → 建池 → 排序 → 进入 → 接触 → 跟踪。

- 专家标识：`czl-singapore-biz-pro`
- 类型：Agent 型（单专家）
- 分类：销售商务（`07-SalesCommerce`）
- 版本：1.0.0
- 开发者：虫志龙（47190078@qq.com）

## 一、它解决什么问题

面向中国企业进入新加坡市场时最常见的四个卡点：

| 卡点 | 常见错误做法 | 本专家的做法 |
|------|-------------|-------------|
| 不知道打谁 | 列一堆知名大公司 | 先定 ICP，再按四条路径建候选池，每家过"实体四问" |
| 分不清主体 | 把集团、子公司、仓库、项目混为一谈 | 区分七类实体，明确"推荐的是哪个法律主体" |
| 排不出优先级 | 按规模或知名度排序 | Fit 与 Priority 两层分开打分，排序只看 Priority，每家必须写反证三条 |
| 拿不到入口 | 直接建议"找代理" | 先判定采购主体与公开采购入口，再给路径与切换触发条件 |

## 二、怎么用

### 三种模式

| 你说什么 | 它会做什么 |
|---------|-----------|
| "帮我在新加坡筛选 3 家最值得开发的 XX 客户" | 全流程：定标 → 建池 → 排序 → 路径 → 首触 → 90 天计划 |
| "XX 公司在新加坡有没有工厂" | 快速核查：事实 + 证据 + 缺口，300 字内 |
| "代理、子公司、项目合作怎么选" | 决策对比：维度表 + 结论 + 触发条件 |

### 示例提示词

1. 帮我在新加坡筛选 3 家最值得优先开发的工业自动化客户，并给出切入路径
2. 我要把产品卖进新加坡，帮我比较代理、子公司和项目合作三条路径
3. 给我一份新加坡 XX 行业的 90 天 BD 行动计划，含接触对象和验证动作

### 输出长什么样

```
一、结论先行（3–5 行）
二、定标结果（ICP 卡 + 假设登记 H1..Hn）
三、候选与排序（账户｜实体｜Buying Signal｜Fit｜Priority｜反证｜结论）
四、进入路径（采购主体｜路径｜触发条件）
五、首次接触（第一顺位部门/职能 + 首触由头 + 禁区）
六、90 天行动（动作｜对象｜假设｜成功判据｜转向）
七、待核实清单
八、证据台账（E1..En）
```

## 三、核心机制

### 证据编号制

每条事实都有编号（E1、E2…），末尾给出台账：来源名｜日期｜URL｜等级（A/B/C/D）。没编号的内容只能是推断，D 级证据不能进正文。

### 双层评分

- **Fit**：需求匹配、场景体量、预算能力、技术邻接、增长性。
- **Priority**：信号等级、可进入性、供应商锁定、12 个月转化、决策链、周期。

只输出"高/中/低"档位，不输出 87.3 分这类伪精确值。

### 反证强制

每个账户必须写三条"为什么它可能不该被开发"，并逐条回应。反证不足三条或未回应，不得进前三。

### 采购信号分级

一级（招标/RFQ）→ 二级（投资/扩建公告）→ 三级（组建团队/招聘）→ 四级（行业背景）。只有一级才算"存在明确采购机会"。

## 四、附带工具

脚本在 `skills/czl-sg-bd-core/scripts/`，纯标准库，无需安装依赖：

| 脚本 | 用途 | 示例 |
|------|------|------|
| `score.py` | 双层评分与门禁判定 | `python score.py account.json --explain` |
| `ledger_check.py` | 证据台账校验 | `python ledger_check.py ledger.csv` |
| `pack_check.py` | 专家包体检（含 zip 头像解析模拟） | `python pack_check.py <expert-dir>` |
| `build_zip.py` | 生成合规发布包 | `python build_zip.py <expert-dir>` |

模板在 `skills/czl-sg-bd-core/assets/templates/`：需求定标问卷、账户卡片、候选池表、证据台账、90 天计划。

## 五、能力边界

- 不提供企业征信报告、个人联系方式、商业机密。
- 不代替律师、会计师出具法律、税务、审计意见。
- 不承诺任何商务结果；所有结论都附带验证动作与停止判据。
- 企业事实必须实时检索并注明来源，历史信息会标注时间。

## 六、安装

把整个目录放到专家目录下：

```
<WORKBUDDY_CONFIG_DIR>/plugins/marketplaces/my-experts/plugins/czl-singapore-biz-pro/
```

然后在 WorkBuddy 中导入该目录或使用生成的 zip 包（见 `docs/` 中的发布说明）。
