# STRAIT 六段 SOP 卡

每段一张卡：输入 → 步骤 → 判断门 → 输出 → 异常 → 依赖。判断门不过，不得进入下一段。

---

## S — Scope 需求定标

**输入**：用户原话（产品、目标、约束）。

**步骤**

| # | 动作 | 产出 |
|---|------|------|
| 1 | 抽取 8 项最小信息集，逐项标"已知/部分/未知" | 信息完整度表 |
| 2 | 未知项转假设 H1..Hn，每条写"若不成立的后果" | 假设登记表 |
| 3 | 中→英关键词映射，标注可能的 SSIC 方向 | 关键词矩阵 |
| 4 | 生成 ICP 卡（行业、规模档、地理范围、触发事件、排除条件） | ICP 卡 |

**判断门 G1**：已知项 ≥5，且"产品/服务"与"买方角色"两项必须有值。
- 不通过：只问 3 个问题（一次问完），不输出任何名单。
- 通过但假设多：在输出开头显著标注"本分析基于 H1、H2"，并说明假设反转时的结论变化。

**输出**：ICP 卡 + 假设登记 + 关键词矩阵。

**异常**：用户只给行业名不给产品 → 视为未知，按"通用设备/服务"最保守假设处理，并说明该假设会显著降低名单精度。

**依赖**：无。

## T — Target 候选池构建

**输入**：ICP 卡 + 关键词矩阵。

**四条路径**

| 路径 | 用途 | 典型入口 |
|------|------|---------|
| 监管与持牌名录 | 判断"谁被允许做这门生意" | 各监管机构公开目录 |
| 官方企业登记与统计 | 判断"谁真实存在、行业代码" | 企业登记开放数据、统计口径表 |
| 协会/商会/展会名录 | 判断"谁在这个圈子里活跃" | 商会会员目录、展会参展商名单 |
| 企业一手信息 | 判断"谁正在发生变化" | 官网、招聘页、新闻稿、年报 |

**实体四问**（逐条回答，答不出即降级）

1. 法律主体：集团 / 新加坡法人 / 分公司 / 合资公司？
2. 本地存在：有 UEN 线索或官网本地页面？
3. 业务相关：本地实体承担的业务是否与产品相关（不是集团全球业务）？
4. 采购主体：总部集采 / 本地运营 / 项目公司 / 总包 / 集成商？

**判断门 G2**：进入排序池需至少 1 条 A 或 B 级证据同时支持"本地存在"与"业务相关"。
- 只有 C/D 级线索 → 进"观察区"，单列，不参与排序。
- 只有集团层面信息 → 标注【新加坡实体待核实】，进观察区。

**输出**：候选池表（10–25 家），字段见 `06-output-templates.md`。

**异常**：候选不足 5 家 → 换词重检（英文行业词、SSIC 方向、上下游词），仍不足则如实说明"公开信息池偏薄"，并给出 2 条替代路径。

**依赖**：`05-sg-data-sources.md`。

## R — Rank 双层评分与反证

**输入**：候选池表 + 证据台账。

**步骤**

1. 逐家打 Fit 五维（需求匹配、场景体量、技术邻接、预算能力、增长性）。
2. 逐家打 Priority 六维（信号等级、可进入性、决策链、周期、供应商锁定、12 个月转化）。
3. 每家写反证三条，并逐条回应。
4. 按 Priority 排序；Fit 与 Priority 冲突时写解释段。
5. 置信度低于阈值的账户降为"资格待定"。

**判断门 G3**：前 3 名需 ≥2 条独立证据，且反证已回应。
- 不通过：降级并说明缺哪条证据、用什么动作补。

**输出**：排序表 + 反证摘要 + 一句话结论。

**异常**：某维度全池无数据 → 该维度整体置"信息不足"，不参与加权，并在方法说明中写明"本次排序未使用该维度"。

**依赖**：`03-scoring-models.md`、`scripts/score.py`。

## A — Access 进入路径

**输入**：排序前 3–5 家。

**采购主体五问**

1. 最终业主是谁？
2. 采购主体是谁（自采 / 总包 / 集成商 / 集团集采）？
3. 公开入口在哪（Tender 页 / 供应商注册 / 采购系统 / 政府平台）？
4. 本地化要求是什么（本地公司、认证、业绩、售后）？
5. 现有供应商是开放替换还是长期锁定？

**路径候选**：跨境直供 / 本地代理 / 经销 / SI 联合 / 项目制 / 子公司或合资。

**判断门 G4**：采购主体未确认 → 输出"路径待确认" + 两条并行验证动作。
- 禁止在未确认采购主体时直接推荐"找代理"。
- 禁止因企业有政府或国资背景就直接推定走政府平台。

**输出**：路径建议 + 切换触发条件 + 不建议路径及原因。

**异常**：企业采购完全封闭（集团统一采购、长期独家）→ 明确写"本账户不适合直供"，改为伙伴进入或放弃，并给出判断依据。

**依赖**：`04-entity-and-signal.md`。

## I — Interaction 首次接触

**输入**：路径建议 + 该账户的公开变化事实。

**角色地图五位置**

| 位置 | 关心什么 | 用什么材料 | 常见异议 |
|------|---------|-----------|---------|
| 业务发起人 | 产能、成本、交期、合规 | 同行对标、单点收益测算口径 | "现在这样也能跑" |
| 技术评估人 | 兼容性、稳定性、维护 | 接口清单、验收标准、故障处理 | "你们没有本地案例" |
| 采购执行人 | 流程、比价、合规 | 供应商资料包、资质文件 | "没在供应商名录里" |
| 财务与合规 | 付款条件、汇率、制裁筛查 | 付款方案、合规声明 | "预付比例太高" |
| 最终签署人 | 风险与责任 | 一页纸决策摘要 | "先看看再说" |

**首触四要素**：可验证的具体变化 → 一句话价值假设 → 最小承诺请求 → 退出选项。

**输出**：首触要点 + 三个接触顺位 + 话术禁区。

**异常**：找不到任何公开变化 → 说明"缺乏由头"，改为行业活动或协会渠道建立初次接触，不硬发销售邮件。

**依赖**：`02-evidence-standard.md`（事实必须可引用）。

## T — Track 行动计划

**输入**：全部前序结论。

**三段时间**

| 阶段 | 目标 | 典型动作 |
|------|------|---------|
| 0–30 天 | 验证假设 | 补实体证据、确认采购主体、锁定部门入口 |
| 30–90 天 | 建立对话与样板 | 首触、现场踏勘、试点方案、伙伴初谈 |
| 90–180 天 | 转化与复制 | 报价、合同条款、第二家复制 |

**每条动作五要素**：动作｜对象｜假设编号｜成功判据（可观测）｜失败后的转向。

**输出**：行动计划表 + 复盘口径 + 停止投入判据。

**异常**：用户没有资源执行 → 把动作压缩到 3 条以内，只保留"能证伪核心假设"的动作。

**依赖**：`06-output-templates.md`、`assets/templates/bd-plan.md`。
