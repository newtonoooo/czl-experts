# 合作风险矩阵与条款建议

## 一、七类风险

| 风险 | 观察点 | 等级判断依据 | 可执行风控动作 |
|------|--------|-------------|---------------|
| 主体风险 | 签约主体与谈判主体是否一致、是否新设 SPV | 主体成立年限、注册资本、是否与集团混同 | 签约前索取 ACRA 企业信息摘要；要求母公司担保或预付款 |
| 财务与履约风险 | 付款能力、历史履约 | 公开财务、诉讼记录、供应商口碑 | 分阶段收款、信用证或保函、设置交付里程碑 |
| 商业模式风险 | 对方是否靠转手获利而非自用 | 是否为贸易商、是否要求独家 | 约定年度最低采购量，未达标自动降为非独家 |
| 合作冲突风险 | 是否代理竞品、是否要求排他 | 代理品牌清单、独家条款范围 | 限定排他范围（区域/行业/客户），设业绩考核与退出条款 |
| 合同风险 | 交付标准、验收口径、知识产权归属 | 条款是否可量化 | 验收标准写可测指标；IP 归属与二次开发权单独约定 |
| 声誉风险 | 是否涉制裁、重大负面、争议性业务 | 监管公告、司法记录、主流媒体报道 | 签约前做制裁与出口管制筛查；合同中加入合规陈述与终止权 |
| 跨境风险 | 外汇、税务、数据、认证 | 付款路径、数据出境、产品认证 | 明确贸易术语与税务承担；数据条款单独约定；提前做认证清单 |

## 二、风险等级定义

| 等级 | 含义 | 处理 |
|------|------|------|
| 低 | 有公开信息支持其正常履约 | 常规条款 |
| 中 | 存在信息缺口或轻微负面 | 补证据 + 加强条款 |
| 高 | 有明确不利事实，但可通过条款缓释 | 担保、分期、试点先行 |
| 极高 | 主体不明、涉制裁、重大诉讼 | 暂停合作，先做合规审查 |

规则：不得因单条负面新闻直接判"极高"。风险结论必须写清时间、性质、来源、当前状态四项。

## 三、按合作模式的条款重点

| 模式 | 必设条款 | 常见坑 |
|------|---------|--------|
| 非独家代理 | 区域与客户范围、价格体系、支持义务 | 对方要求"先给独家再谈业绩" |
| 独家代理 | 年度最低采购量、考核节点、未达标降级、终止补偿 | 只写"尽力推广" |
| 经销 | 库存与售后责任、窜货限制、退换货 | 库存压在对方仓库却算作已销售 |
| 系统集成商联合 | 报价分工、客户归属、知识产权与源代码 | 项目归属不清导致重复报价 |
| 项目制合作 | 验收标准、工期违约、变更计价 | 验收标准写"满足业主要求" |
| 本地子公司/合资 | 股权与治理、出资节奏、退出机制、竞业 | 小股东无否决权却被要求承担连带责任 |

## 四、风险输出的固定格式

每条风险按四行写：

```
风险：<一句话>
依据：<事实 + E 编号 + 时间>
影响：<对本次合作的具体影响>
动作：<合同条款 / 尽调动作 / 决策建议>
```

禁止只写"存在一定风险，建议谨慎合作"。

## 五、合作前必须核实的问题清单

1. 签约主体的法定名称与 UEN 是否与谈判对象一致？
2. 若为子公司，母公司是否愿意出具担保？
3. 对方是否代理我们的直接竞品？排他范围具体到什么层级？
4. 付款条件、币种、汇率风险由谁承担？
5. 产品认证与本地合规由谁负责、周期多长？
6. 售后责任边界在哪（谁备件、谁派人、响应时限）？
7. 数据与图纸的归属、保密期限、违约救济？
8. 争议解决地与适用法律？仲裁机构的裁决在对方资产地是否可执行？

## 六、合规边界

- 不提供征信报告、司法记录原件、个人背景调查。
- 制裁与出口管制筛查只做"提示与动作建议"，不代替法律意见。
- 涉及合同文本的最终效力，提示由新加坡持牌律师审阅。
