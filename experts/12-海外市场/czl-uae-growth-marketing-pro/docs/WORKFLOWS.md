# 工作流定义

本文档是工作流的**契约**：每个工作流的职责、输入参数、执行步骤、判断条件、输出格式、异常处理、依赖关系。主提示词（`agents/czl-uae-growth-marketing-pro.md`）负责执行，本文档负责说清边界。

---

## W0 · 路由

| 项 | 内容 |
|----|------|
| **职责** | 判断这是快诊、单点还是全案，避免用全案的力气回答一个单点问题 |
| **输入** | 用户原始需求文本 |
| **步骤** | 1. 检查是否含预算数字<br>2. 检查是否含时间窗<br>3. 检查是否含明确 KPI<br>4. 按命中数量定级 |
| **判断条件** | 预算+目标+要方案 → 全案；只要一个交付物 → 单点；单一问题无预算 → 快诊 |
| **输出** | 一个模式标签 + 要跑的工作流清单 |
| **异常** | 需求完全无法归类 → 按快诊处理，先给判断再问是否展开 |
| **依赖** | 无 |
| **关系** | 所有工作流的入口 |

## W1 · Objective & Offer（目标与供给校验）

| 项 | 内容 |
|----|------|
| **职责** | 把模糊需求转成可建模参数；缺关键项就停 |
| **输入** | 品类、目标、预算、时间窗、人群线索（五要素） |
| **执行步骤** | 1. 逐项检查五要素<br>2. 缺项判断是否可从上下文合理推断<br>3. 可推断 → 标注为假设继续；不可推断 → 停止<br>4. 生成参数表 |
| **判断条件** | 缺预算或目标 → **停止**，只输出提问清单；缺其他项且可推断 → 继续并标注 |
| **输出格式** | 参数表（品类/目标/预算/时间窗/人群/约束/待确认假设） |
| **异常处理** | 用户拒绝给预算 → 转"比例配比模式"，输出百分比结构 + 三档预算情景，明确说明无法给绝对触达量 |
| **依赖** | 无 |
| **关系** | 下游 W2/W3/W4/W5 全部依赖本段参数 |

## W2 · Audience tiering（人群分层）

| 项 | 内容 |
|----|------|
| **职责** | 把"阿联酋消费者"拆成可投放的层 |
| **输入** | W1 参数表；`skills/uae-market-intel/data/audience_segments.json` |
| **执行步骤** | 1. 读五个人群层<br>2. 按品类文化属性/价格属性/场景属性判断必列层<br>3. 定义核心层/扩展层/机会层<br>4. 给每层的语言、主媒介、决策驱动、预算占比 |
| **判断条件** | 强文化属性品类（食品/服饰/美妆/家居/婚庆）→ 必须做本国公民 vs 阿拉伯外籍差异<br>强价格属性（快消/电信/电商大促）→ 必须拆南亚层价格带<br>强场景属性（旅游/餐饮/免税/酒店）→ 必须单列游客层 |
| **输出格式** | 分层表：层 / 画像 / 语言 / 主媒介 / 决策驱动 / 建议预算占比 |
| **异常处理** | 用户人群定义与市场结构冲突（如只打本地人但产品是低价快消）→ 先指出结构性风险，再给两条路径（坚持原定位说明规模上限 / 调整分层说明改动成本） |
| **依赖** | `uae-market-intel` 技能 |
| **关系** | 输出决定 W3 的 `--audience` 参数 |

## W3 · Spend architecture（渠道配比与预算建模）

| 项 | 内容 |
|----|------|
| **职责** | 把预算变成渠道分配 + 采买逻辑 + KPI 目标区间 |
| **输入** | 预算、目标、人群层、行业、城市 |
| **执行步骤** | 1. 跑 `bin/uae_plan.py` 得基线<br>2. 校验三类角色是否覆盖<br>3. 补脚本算不出的四项：创意产能、归因现实、渠道可行性、采买现实<br>4. 输出配比表 |
| **判断条件** | 预算 <5 万 → 最多 2 渠道，禁止铺开<br>5~30 万 → 2~4 渠道，必须含 1 个信任层<br>>30 万 → 三层完整 + 测试预算 10~15% |
| **输出格式** | 渠道表（渠道/角色/预算/占可投放/曝光/触达/采买口径）+ 素材要求表 + 建模假设段 |
| **异常处理** | 预算与目标明显不匹配 → 明确说不匹配，给三个替代（缩地理/缩人群/拉时间）<br>脚本返回 `no channel fits` → 降 `--reserve`、换低价渠道、或建议提预算 |
| **依赖** | `uae-channel-mix` 技能、`bin/uae_plan.py`、`uae-market-intel` 渠道目录 |
| **关系** | 上游接 W2，下游喂 W4（渠道清单）与 W5（文案规格） |

## W4 · Islamic & local calendar（节点排期）

| 项 | 内容 |
|----|------|
| **职责** | 把投放节奏绑到阿联酋真实日历 |
| **输入** | 时间窗、年份、官方斋月起始日（可选） |
| **执行步骤** | 1. 跑 `bin/uae_campaign_calendar.py`<br>2. 有官方日期则用 `--ramadan-start` 覆盖<br>3. 判断投放窗口与哪些节点重叠<br>4. 重叠节点给"模式切换"说明<br>5. 输出倒推里程碑 |
| **判断条件** | 窗口与斋月重叠 → **必须**输出斋月模式（时段/调性/内容形态三项都改）<br>与国庆日重叠 → **必须**过 W5 爱国表达审查<br>无固定窗口 → 给最优起投窗口 + 避开清单 |
| **输出格式** | 时间轴表（窗口/起止/类型/动作/预算倾斜）+ 倒推里程碑（素材锁定/预算锁定/上线预热） |
| **异常处理** | 用户指定宗教节日当天做硬广 → 提示风险，建议改品牌向内容或顺延，但不替用户决定<br>年份超出 2024-2035 → 脚本拒绝，需人工指定 |
| **依赖** | `bin/uae_campaign_calendar.py` |
| **关系** | 依赖 W3 的渠道清单决定各渠道素材截止时间 |

## W5 · Safety & script（合规与双语文案）

| 项 | 内容 |
|----|------|
| **职责** | 文案进制作前拦下风险，并给 AR+EN 双版本 |
| **输入** | 待审文案、行业、投放渠道、节点 |
| **执行步骤** | 1. 跑 `bin/uae_compliance.py`<br>2. 按退出码分支处理<br>3. 人工复核脚本覆盖不到的四类（语境/视觉/方言/暗示）<br>4. 按六条双语规则重写阿语<br>5. 输出风险清单 + 双语终稿 |
| **判断条件** | 退出码 1（有 High）→ **阻断**，给替代表达等确认<br>仅 Medium → 可交付，置顶风险提示<br>全 Low → 正常交付 |
| **输出格式** | 合规结论 + 风险清单表 + 阿语版 + 英语版 + 视觉注意事项 |
| **异常处理** | 用户坚持保留 High 表达 → 记录"已提示未采纳"，保留风险提示，不删不改用户决定<br>要求直译 → 给直译版同时给建议改写版<br>涉牌照审批 → 明确指向主管机构 |
| **依赖** | `uae-brand-safety` 技能、`bin/uae_compliance.py` |
| **关系** | 上游接 W3 的渠道规格，下游喂 W6 第 6、7 项 |

---

## W6 · QA Gate（质检门）

| 项 | 内容 |
|----|------|
| **职责** | 交付前最后一道关，八项全过才算完成 |
| **输入** | W1~W5 全部产出 |
| **检查项** | 1. 五要素齐且假设已标注<br>2. 人群分到层，无笼统结论<br>3. 预算加总等于总预算（误差 0）<br>4. 每渠道有角色、KPI、素材需求<br>5. 排期绑定真实节点与倒推时间<br>6. 合规扫描已跑，风险已列<br>7. 双语齐备，阿语非直译<br>8. 数据标了口径与核实路径 |
| **判断条件** | 任一项不通过 → 回到对应工作流补，**不输出"基本完成"版本** |
| **输出格式** | 通过：正常交付；退回：指出哪一项、回哪个工作流 |
| **异常处理** | 用户催交付但质检未过 → 说明具体缺口，给"可先交付的部分"与"待补部分"，不整体放行 |
| **依赖** | W1~W5 |
| **关系** | 全流程终点 |

## 工作流关系图

```
用户需求
   │
   ▼
 W0 路由 ──快诊──→ 单项（W2 或 W5）
   │
   └─全案─→ W1 ──缺关键项──→ 提问清单（停）
              │
              ▼
             W2 ──→ W3 ──→ W4
              │      │      │
              └──────┴──────┴──→ W5 ──High 风险──→ 阻断，改写
                                     │
                                     ▼
                                    W6 ──不通过──→ 回对应工作流
                                     │
                                     ▼
                                   交付
```

## 数据流向

| 从 | 到 | 传什么 |
|----|----|--------|
| W1 | W2/W3/W4 | 品类、目标、预算、时间窗 |
| W2 | W3 | `--audience` 参数、人群预算占比 |
| W3 | W4 | 渠道清单（决定各渠道素材截止） |
| W3 | W5 | 文案规格（比例、时长、语言版本） |
| W4 | W5 | 节点（决定调性与禁忌） |
| W5 | W6 | 合规结论、双语终稿 |
