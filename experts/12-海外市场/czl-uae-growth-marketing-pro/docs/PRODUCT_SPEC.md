## 1. 需求来源

本产品面向"要进阿联酋、或已在阿联酋要放量"的营销决策者。它的需求不是从某个既有产品复刻而来，而是从**实际投放会失败的环节**倒推出来的。

### 1.1 目标用户

| 用户 | 场景 | 真实痛点 |
|------|------|---------|
| 出海品牌市场负责人 | 第一次进阿联酋，要一份能过会的投放方案 | 不知道人群怎么切，渠道报价看不懂，被代理牵着走 |
| 跨境电商运营 | 斋月/DSF 大促前要排期与预算 | 每年都在"临时抱佛脚"，素材来不及做 |
| 本地代理商策略岗 | 给客户做提案，需要可辩护的数字 | 拍脑袋给百分比，客户一问依据就崩 |
| 中小企业主 | 预算有限，只能选一两个渠道 | 不知道哪个渠道对自己这个品类真的有效 |

### 1.2 使用场景（按发生频率）

1. **预算分配**：「30 万迪拉姆怎么分」——最高频。
2. **节点排期**：「斋月怎么打」——季节性高峰。
3. **文案合规**：「这句话能不能说」——交付前最后一关。
4. **人群判断**：「先打本地人还是外籍」——立项阶段。
5. **渠道诊断**：「TikTok 对我们这个品类有用吗」——复盘阶段。

### 1.3 需要解决的问题

| # | 问题 | 现状 | 本产品的解法 |
|---|------|------|------------|
| P1 | 人群笼统化 | 把 1000 万常住人口当一个市场 | 五层人群强制分层，每层给语言/媒介/驱动/敏感点 |
| P2 | 预算靠拍脑袋 | 百分比凭经验，加总还对不上 | 确定性模型，分配精确到 AED，可复算 |
| P3 | 渠道角色不清 | 只列渠道名，不说买什么 | 信任/发现/转化三分法，每个渠道给采买逻辑与素材要求 |
| P4 | 节点节奏错位 | 斋月当淡季，或当普通旺季 | 日历引擎，含夜间模式、倒推里程碑、工作日回退 |
| P5 | 合规事后补救 | 文案做完才发现违规 | 交付前扫描，High 风险直接阻断 |
| P6 | 阿语靠机翻 | 逐句直译，读起来像机器 | 六条双语文案硬规则，阿语按同目标重写 |
| P7 | 数据无口径 | 精确百分比无来源 | 每个数值带 basis 字段，区间优于点值 |

## 2. 输入与输出

### 2.1 必要输入（五要素）

| 要素 | 类型 | 缺失处理 |
|------|------|---------|
| 品类/供给 | 文本 | 追问 |
| 目标 | 枚举：声量/考虑/转化/留存 | 追问 |
| 预算 | 数值 AED | 追问；拒绝提供则转比例模式 |
| 时间窗 | 日期或节点 | 追问；无则给建议窗口 |
| 人群线索 | 文本 | 追问；无则按品类默认分层并标注假设 |

可选高价值输入：现有效率数据、已有素材清单、竞品参考、牌照约束、语言要求、地理范围。

### 2.2 预期输出

| 模式 | 触发条件 | 输出 | 篇幅 |
|------|---------|------|------|
| 快诊 | 单一问题、无预算 | 结论 + 依据 + 1 个行动建议 | ≤400 字 |
| 单点 | 明确要一个交付物 | 该段完整产出 | ≤800 字 |
| 全案 | 有预算 + 有目标 | 五段完整方案 + 质检结论 | 按段展开 |

全案固定结构：一句话结论 → 关键假设 → 人群分层 → 渠道与预算 → 节点排期 → 文案与合规 → 衡量方式 → 风险提示。

## 3. 通用处理步骤

```
① 路由判断（快诊/单点/全案）
② W1 五要素校验 ──缺关键项──→ 停止，只输出提问清单
③ W2 人群分层（三层结构）
④ W3 预算建模（调用 uae_plan.py，再人工校准）
⑤ W4 节点排期（调用 uae_campaign_calendar.py）
⑥ W5 合规扫描 + 双语文案（调用 uae_compliance.py）
⑦ W6 八项质检 ──不通过──→ 回到对应工作流
⑧ 交付
```

## 5. 质量、速度、稳定性要求

| 维度 | 要求 | 达成情况 |
|------|------|---------|
| **准确性** | 预算分配加总误差必须为 0 | 达成：整数分配 + 断言，58 项测试覆盖 7 档预算 × 4 目标 |
| **可复现** | 相同输入必得相同输出 | 达成：无随机数、无时间依赖（除日历的当前年份默认值） |
| **可追溯** | 每个数字能说明来源与口径 | 达成：basis 字段 + 建模假设段强制输出 |
| **速度** | 单次脚本调用 < 1 秒 | 达成：实测 0.02~0.05 秒 |
| **稳定性** | 非法输入不崩溃，给明确退出码 | 达成：退出码 0/1/2/3/4 语义化 |
| **可验证** | 每条规则有对应测试 | 达成：58 单元测试 + 24 集成检查 |

## 7. 明确不做的事

1. 不承诺 ROI、转化率或任何确定结果。
2. 不编造案例、客户、奖项、官方合作。
3. 不代替法律意见（牌照、审批、内容审查）。
4. 不提供真实投放账户接入（无密钥、无网络）。
5. 不对宗教、王室、性别议题做价值判断，只做营销可行性说明。
