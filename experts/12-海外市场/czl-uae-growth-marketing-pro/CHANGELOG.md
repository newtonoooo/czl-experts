# 更新日志

本产品遵循语义化版本（MAJOR.MINOR.PATCH）。

---

## [1.0.1] - 2026-10-28

头像改为具有阿联酋本地特征的人物形象，并提高图标兼容性。

### 变更

- **头像换成人物**：年轻阿联酋男性形象，白色 kandura + 白色 ghutra + 黑色 agal，短须，神情自信，深青底配极淡几何纹样。去掉原先的纯几何徽标。
- **输出格式改为 RGB（PNG colour type 2）**：不再使用带 alpha 的 RGBA 与透明圆角。部分客户端对 RGBA 头像的加载更挑剔，改成全幅不透明 RGB 与多数可用专家包一致，减少一个变量。
- **体积降到 200KB**：512×512，比上一版 268KB 更小，远离 500KB 上限。
- **去除生成工具水印**：生成图右下角带工具水印，通过裁剪 880×880 干净区域重新出图，成品无任何水印。

### 工具增强

- `bin/avatar_tool.py` 新增 `--crop X,Y,W,H`（裁剪）与 `--flatten HEX`（合成到指定底色并输出 RGB）。
- 新增 `tests/test_avatar.py`，9 项测试覆盖解码、裁剪、RGB 编码、圆角 alpha、成品规格。

### 测试

- 单元测试从 58 项增至 67 项，全通过。

## [1.0.0] - 2026-10-28

首个正式版本。全流程五段式 OASIS 框架，三个自建知识库，四个零依赖脚本，58 项单元测试。

### 新增

**核心能力**

- OASIS 增长框架：Objective → Audience → Spend → Islamic calendar → Safety，每段独立质量门。
- 三种执行模式路由：快诊 / 单点 / 全案，按预算、时间窗、KPI 三个信号判断。
- 五层人群分层：本国公民、阿拉伯外籍、南亚外籍、欧美外籍、游客，含语言、媒介、决策驱动、敏感点与预算指数。
- 渠道角色三分法：信任层 / 发现层 / 转化层，配比必须覆盖三类，缺类需说明原因。
- 八项交付质检门，任一项不通过即退回，不输出"基本完成"版本。

**工具脚本**

- `bin/uae_plan.py`：确定性渠道预算模型。两级分配（先按目标分角色，再按适配度分渠道），整数分配恒等于可投放预算，低于渠道起投门槛的渠道自动剔除并重分配。
- `bin/uae_compliance.py`：22 条规则的合规扫描，覆盖宗教、政治王室、性别身体、酒精赌博、绝对化用语、比较广告、价格折扣、金融收益、医疗健康、教育承诺、文化适配十一类。退出码即判断条件。
- `bin/uae_campaign_calendar.py`：斋月/开斋节/宰牲节/国庆日/DSF/开学季节点引擎，支持官方日期覆盖、自动平移全部伊斯兰历节点、工作日回退（周五至周日不设截止日）、ICS 导出。
- `bin/package_check.py`：包规范、资产规则、内部完整性三层自检，33 项检查。
- `bin/avatar_tool.py`：零依赖 PNG 归一化，1024 → 512 正方形、透明圆角、自适应行过滤压缩。

**知识库**

- 13 个渠道的采买参数与素材要求。
- 12 个行业的渠道偏置与合规红线。
- 5 个人群层的完整画像。
- 每个数值带 `basis` 口径字段，区分官方统计 / 行业报告 / 平台自述 / 规划区间。

**文档**

- 产品规格说明、工作流定义、测试报告、商业发布风险清单、开发记录、平台展示文案。
- 图标回退为文字的诊断报告与四条自查清单。

### 修复

- 预算分配在角色覆盖保证下会互相覆盖，导致信任层被转化层顶掉。改为"必需角色优先占位 + 剩余按分数填充"。
- 渠道分配可能低于自身起投门槛（如 25 万预算下户外广告分到 5.25 万，低于 6 万门槛）。改为分配后校验并重分配。
- 渠道占比以总预算为分母，导致合计只有 90%（测试预留 10%）。改为以可投放预算为分母。
- 截止日回退只跳过周六周日，周五仍被当作安全截止日。阿联酋周五为政府半日，改为回退至周一至周四。
- `--format json` 下占比字段精度不一致。

### 已知限制

- 合规扫描基于关键词，无法判断语境、视觉与方言，High 结论必须人工复核。
- 知识库数值为建模区间，非审计数据，对外发布前须以平台实时报价与官方统计复核。
- 伊斯兰历日期为估算，须以官方观月公告覆盖。
- 未内置真实投放账户数据接口，效果验证依赖用户提供的后台数据。
