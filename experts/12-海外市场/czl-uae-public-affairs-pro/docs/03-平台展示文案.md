## 四、详细介绍（详情页正文）

**你面对的不是"阿联酋"，是七个各自独立的酋长国。**

同一个业务，在阿布扎比、迪拜、沙迦可能走三条完全不同的路径；同一个酋长国内部，本土公司、普通自由区公司、金融自由区公司、离岸公司又是四套监管环境。市面上大多数回答把这一切压成一句"在阿联酋一般需要…"，这句话在决策会上没法用。

**阿联酋公共事务权威顾问**把这个过程拆成七条可执行的工作流：

- **W0 受理与范围界定**：12 项简报字段，一次问全，缺什么先告诉你。
- **W1 政策与监管情报扫描**：把业务动作翻译成 12 个监管域，定位联邦 / 酋长国 / 自由区三层主管机构。
- **W2 七酋长国分层评估**：8 维矩阵按业务动作加权，给推荐序、给取舍、给"若选 A 必须先解决的三件事"。
- **W3 利益相关方与决策路径映射**：审批层 / 影响层 / 监督层三层链，排出接触顺序、渠道、时点与成功信号，并强制做反腐败检查。
- **W4 沟通策略与红线校验**：14 项红线体检 + 违规表达改写对照，官方口径版与社媒版分开给。
- **W5 风险量化与交付物装配**：五维打分（规则确定性 / 审批可控性 / 时间不可控性 / 声誉外溢性 / 执法严厉度），≥65 分自动附停止条件与升级路径，输出一页纸、决策备忘、回函框架。
- **W6 危机快车道**：T0–T3 分级，0–6h / 6–24h / 24–72h 动作表，中英双语三段式声明。

**它的三个硬规矩**：数字必须带口径，给不出就写"待核实"；每条判断标注来源等级（A 官方原文 / B 官方公告 / C 权威媒体 / D 推断）；每份输出末尾固定"信息截止日 + 三条待复核项"。

**它不做**：不出法律意见书、不承诺审批结果、不提供规避监管的方案、不评价阿联酋内政与皇室事务、不给官员个人联系方式。
