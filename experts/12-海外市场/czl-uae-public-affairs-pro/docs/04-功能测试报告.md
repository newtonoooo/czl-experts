### T-10 图像处理链路 ✅
```
png_tool.py info   → size: 1024x1024  bytes: 779056
png_tool.py crop-resize --crop 124,0,780,780 --size 512
                   → wrote avatars/expert.png 512x512 308805 bytes
```
说明：裁切区域上边界为 0、下边界 780，原图水印位于 y≈975 以下，故被完全排除；左右边界收至青绿底块以内，避免出现竖向接缝。
