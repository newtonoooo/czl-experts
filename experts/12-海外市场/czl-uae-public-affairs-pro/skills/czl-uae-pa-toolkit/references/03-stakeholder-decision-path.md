# 03 · 利益相关方与决策路径映射

> 用途：W3。目标是把"该找谁"变成"按什么顺序、用什么理由、用什么渠道、什么时候推进"。

---

## 一、三层模型

```
┌──────────────── 监督层（审计 / 合规 / 执法 / 司法）────────────────┐
│  作用：事后追责。不需要日常维护，但一旦触发，影响最大              │
└──────────────────────────────────────────────────────────────────┘
┌──────────────── 审批层（发牌 / 发证 / 备案 / 审批）────────────────┐
│  作用：决定"能不能做"。必须正式、留痕、按流程                     │
└──────────────────────────────────────────────────────────────────┘
┌──────────────── 影响层（商会 / 协会 / 招商 / 社区 / 媒体 / 合伙人）──┐
│  作用：决定"快不快、顺不顺"。是信息与背书的主要来源               │
└──────────────────────────────────────────────────────────────────┘
```

**推进顺序**：影响层建认知 → 审批层做正式预沟通 → 审批层提交 → 监督层保持合规留痕。**不要**从审批层硬闯，也不要把影响层当审批层用。

---

## 二、影响层常见主体与用法

| 主体类型 | 能提供什么 | 正确用法 | 错误用法 |
|---|---|---|---|
| 商会（如迪拜商会、阿布扎比商会、各酋长国商会） | 会员网络、行业活动、政策意见反馈渠道 | 通过商会活动建立行业存在感，获取政策解读 | 要求商会"帮忙催审批" |
| 行业协会 / 商业理事会 | 行业标准参与、同行经验、集体发声 | 加入协会、参与工作组 | 借协会名义施压 |
| 自由区招商部门 | 落地方案、牌照选型、园区资源 | 作为一站式对接窗口，索取书面方案 | 把招商承诺当审批结论 |
| 投资促进机构（如 ADIO） | 投资便利、对接政府资源 | 大额投资时作为统一入口 | 认为其可替代行业监管审批 |
| 本地合伙人 / 分销商 | 市场通道、本地信誉 | 明确合同边界与合规条款 | 让其代为处理监管申报 |
| 社区 / 部落代表 / 本地意见领袖 | 社会接受度、劳资关系缓冲 | 通过企业社会责任项目建立长期关系 | 临时抱佛脚、现金往来 |
| 媒体与行业媒体 | 议题设置、危机时的第三方声音 | 长期供稿与背景沟通 | 危机时才第一次接触 |

## 三、审批层推进表（模板）

| 顺序 | 对象类型 | 关切点 | 我方价值主张 | 渠道 | 时点 | 成功信号 |
|---|---|---|---|---|---|---|
| 1 | 自由区招商 | 投资额、就业、产业匹配 | 投资计划 + 用工计划 | 招商对接会 | T-90 天 | 拿到书面牌照方案 |
| 2 | 经济发展部门 | 合规性、活动代码匹配 | 业务说明 + 合规承诺 | 正式预沟通函 | T-60 天 | 明确所需文件清单 |
| 3 | 行业监管机构 | 技术标准、安全 | 认证与检测报告 | 正式提交 | T-45 天 | 受理回执 |
| 4 | 市政/民防 | 场地与安全 | 图纸与消防方案 | 线上系统 | T-30 天 | 现场检查通过 |
| 5 | 劳动主管部门 | 配额与酋化 | 用工计划 + 培训计划 | 系统申请 | T-20 天 | 配额批复 |

> 时点为示意，实际以受理周期为准；每个节点必须留书面记录（回执、邮件、系统截图）。

## 四、沟通礼仪与实操要点（公共事务层面）

1. **正式优先**：审批类事项一律走正式渠道，口头承诺不作为依据。
2. **阿语优先**：对外正式函件建议附阿语版本，至少标题与关键段落；由母语者终校。
3. **层级对等**：派出的代表职级与被访机构层级匹配，不要越级施压。
4. **一次问清**：会前准备问题清单，会上一次问完，避免反复打扰。
5. **留痕**：每次沟通后 24 小时内发会议纪要确认。
6. **斋月与节假日**：斋月期间工作时间缩短、节奏放慢；周五为休息日（周末为周六周日）；重大宗教节日期间不安排推进动作。
7. **礼物与招待**：遵循公司反腐败政策与本地惯例的交集，取更严格者；政府客户尤其严格。

## 五、反腐败与利益冲突检查（强制）

涉及政府客户、国企、政府基金、政府采购时，必须逐项确认：

- [ ] 是否存在中间人/代理？合同、佣金比例、交付物是否书面化？
- [ ] 佣金是否与"审批结果"挂钩？（若挂钩 → 红线，必须改结构）
- [ ] 是否有政府官员持股、亲属关联、兼职？
- [ ] 礼品、招待、差旅赞助是否超公司政策阈值并留档？
- [ ] 是否做过制裁与负面名单筛查？
- [ ] 投标文件中的资质、业绩、本地化含量是否真实可核？

任一项不通过 → 不得进入 W4 对外沟通阶段，先整改结构。

## 七、异常处理

| 情况 | 处理 |
|---|---|
| 客户要求"找关系加速" | 拒绝；改为正式预沟通 + 招商背书 + 完整文件 |
| 审批方口头表示"没问题" | 记录但不作为结论，继续走正式流程 |
| 多机构要求互相冲突 | 以书面要求为准，冲突点书面请示，保留往来 |
| 本地合伙人要求代为申报 | 拒绝；申报主体必须是企业自身或持牌代理 |
