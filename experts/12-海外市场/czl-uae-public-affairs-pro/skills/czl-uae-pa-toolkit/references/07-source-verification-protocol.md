# 07 · 信息源分级与时效校验协议

> 用途：全流程。本产品最容易被质疑的地方是"信息是否可信"。本协议给出统一标准。

---

## 一、四级来源

| 等级 | 定义 | 举例 | 使用规则 |
|---|---|---|---|
| **A** | 官方法律法规、官方公报、政府门户原文 | 联邦法律文本、部长决定、官方公报、监管机构规则页 | 可作为结论唯一依据 |
| **B** | 官方机构公告、指南、年报、招标文件 | 部委发布的服务指南、自由区官方费用页、监管机构问答 | 可作为主要依据，注明发布日期 |
| **C** | 权威媒体、律所与会计师事务所公开简报、行业协会报告 | 主流财经媒体、国际律所客户提示 | 可作支撑，不得单独支撑重大结论 |
| **D** | 经验推断、行业传闻、单一口头信息 | "听说""一般做法是" | 必须标注"推断"，只能作为待核实线索 |

---

## 二、时效校验（每条关键信息都要做）

1. **标注日期**：发布日期 + 生效日期（如不同，两者都写）。
2. **确认现行有效**：是否被修订、废止、暂停执行？过渡期到何时？
3. **确认适用范围**：联邦 / 某酋长国 / 某自由区；某行业 / 全行业；某规模以上企业。
4. **确认机构是否仍在**：阿联酋机构重组频繁，旧名称可能已合并。
5. **超过 12 个月的信息**：默认标"可能已更新"，必须复核后再用于结论。

---

## 三、五个高频信息陷阱

| 陷阱 | 表现 | 破解 |
|---|---|---|
| **把政策宣示当已生效法规** | 引用"战略""愿景""计划"当义务 | 区分"战略文件"与"具有约束力的法规" |
| **把自由区规则当全境规则** | 用自由区做法推断本土要求 | 分列三层，逐层确认 |
| **把旧版费用当现价** | 用几年前的注册费做成本模型 | 只采用官方书面报价，标注报价日期 |
| **把中文二手解读当原文** | 中文自媒体转述的"新规" | 回溯到官方原文或官方英文页 |
| **把个别案例当普遍规则** | 一家企业获批就认为普遍可行 | 要求书面规则依据，而非案例类比 |

---

## 四、来源标注格式

```
（来源：{机构} · {文件/公告名} · {发布或生效日} · {A/B/C/D} 级）
```

示例：
```
（来源：联邦税务局 · 企业所得税指引 · 2025-xx-xx · A 级）
（来源：某自由区官网牌照页 · 2026-xx-xx · B 级）
（来源：行业访谈 · 2026-xx · D 级，推断）
```

---

## 五、无法核实时的标准写法

```
【待核实】关于 {事项}，目前未取得官方原文。初步判断为 {判断}（推断，D 级）。
建议核实渠道：{机构官网/书面询价/持牌顾问}
建议问法："{具体问题}"
影响：若该判断不成立，{哪条结论需要修改}
```

**禁止**：编造条文编号、编造机构联系人、编造费率与时限。

---

## 六、交付前最后三问

1. 我的结论里，有没有一条只靠 D 级信息支撑？
2. 我引用的规则，是不是最新版本、适用我的客户？
3. 我给的数字，客户拿去用会不会因为口径不对而出错？
