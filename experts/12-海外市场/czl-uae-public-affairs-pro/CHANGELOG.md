# 更新日志

本产品遵循语义化版本（MAJOR.MINOR.PATCH）。版本变更以「功能 / 修复 / 兼容 / 文档」四类记录。

---

## [1.0.0] — 2026-10-28

首个公开发布版本。由虫志龙独立开发，从需求定义、工作流设计、提示词撰写、参考手册、脚本、头像到打包体检全部重新实现，未复用任何既有专家包的提示词、文档或代码。

### 新增 · 工作流
- 建立 **W0–W6 七条工作流**：受理与范围界定、政策与监管情报扫描、七酋长国分层评估、利益相关方与决策路径映射、沟通策略与红线校验、风险量化与交付物装配、危机快车道（0–72 小时）。
- 每条工作流明确「职责 / 输入参数 / 执行步骤 / 判断条件（G0–G6）/ 输出格式 / 异常处理 / 依赖关系」。
- 新增 **Q1–Q4 四道质量闸门**：结构、依据、数字口径、红线。
- 新增 **异常处理总表**（8 类高频边界场景）。

### 新增 · 方法论与手册
- 7 份原创作业手册：酋长国画像与八维矩阵、12 个监管域×三层主管机构索引、三层决策链映射法、14 项沟通红线体检表、五维风险打分模型、5 类交付物模板、四级信息源与时效校验协议。
- 提出「先认层、再认机构」的三层监管结构（联邦 / 酋长国 / 自由区），以及「同国不同辖区」分层要求。

### 新增 · 可执行组件
- `scripts/risk_score.py`：五维风险打分，支持区间分、6 套行业权重预设、JSON 输出、高风险阈值提示。
- `scripts/brief_check.py`：12 项任务简报完整性校验，输出闸门判定与建议工作流路由。
- `templates/`：一页纸、决策备忘、监管回函框架、危机声明（中英双语）。
- `tools/build_package.py`：结构体检 + 确定性打包 + zip 回读验证。
- `tools/png_tool.py`：纯标准库 PNG 裁切与缩放（用于头像规范化）。

### 新增 · 品牌与视觉
- 产品名称：阿联酋公共事务权威顾问（UAE Public Affairs Authority Advisor）。
- 包标识：`czl-uae-public-affairs-pro`。
- 原创头像：512×512 PNG，扁平矢量风格，深青绿与银灰配色，含七边形符号与天际线元素；已去除生成工具水印。

### 修复 · 兼容性
- 头像引用统一写作 `./avatars/expert.png`，避免相对路径解析歧义。
- 打包脚本强制「zip 顶层目录唯一且与 `plugin.name` 一致」，并在打包后回读验证头像条目可被命中，用于规避「导入后头像回退成文字」的问题。

### 文档
- 产品规格说明、使用说明、平台展示文案、功能测试报告、商业发布风险清单、开发记录与文件清单。

### 已知限制
- 参考手册为方法论框架，不含法规条文全文；具体条文须由使用者按 `07` 号手册的协议核验官方原文。
- 未内置实时政策抓取能力，政策时效依赖使用者或对话中的检索行为。
- 阿语对外件需本地母语者终校，专家本身不保证阿语表达的地道性。
