本文件说明本产品在开发过程中涉及的第三方组件、公开规范与公开信息的使用情况，供商业发布前的合规核查使用。

**核查日期**：2026-10-28
**结论摘要**：本产品**不包含**任何第三方代码库、不包含任何第三方版权文本、不依赖外部付费数据源。运行时脚本仅使用 Python 标准库。

## 一、运行时依赖

| 依赖 | 版本要求 | 许可 | 是否随包分发 | 说明 |
|---|---|---|---|---|
| Python 标准库（`json` / `argparse` / `zipfile` / `zlib` / `struct` / `re` / `os` / `sys`） | Python 3.8+ | PSF License（允许商业使用与再分发） | 否（随宿主环境提供） | 两个作业脚本与两个工具脚本均只使用标准库 |
| WorkBuddy 客户端 | 任意支持 Agent 型专家的版本 | 由客户端厂商授权 | 否 | 本产品为客户端插件，不修改客户端 |

**未使用**：无第三方 pip 包、无 npm 包、无前端框架、无图片素材库、无字体文件、无图标库。

## 二、公开规范的使用

| 规范 | 用途 | 使用方式 |
|---|---|---|
| WorkBuddy 专家包规范（plugin.json 字段、agents/skills 目录约定、头像规格） | 使产品可被客户端识别 | 按规范实现，未复制规范文档原文 |

## 三、公开信息的使用

本产品的参考手册（`skills/czl-uae-pa-toolkit/references/`）中涉及的阿联酋政府机构名称、酋长国名称、自由区名称、税制与监管框架等，属于**公开事实性信息**，不构成他人作品。

- 所有手册文本由开发者**独立撰写**，未复制、改写或汇编任何第三方的知识库、法规汇编、咨询报告或付费数据库内容。
- 手册定位为**方法论与判断框架**（如何判断、如何填表、如何校验），不收录法规条文全文。
- 手册中不给出可能失真的精确费用与时限，统一要求使用者以官方书面报价与官方公告为准。

## 五、明确未使用的第三方内容

为避免权利瑕疵，本产品**未使用**以下内容：

1. 任何其他 WorkBuddy 专家的提示词、工作流定义、文档或代码。
2. 任何第三方「阿联酋法律法规知识库」「国别投资指南」的整理文本。
3. 任何政府机构发布的品牌视觉规范文件、徽标、标识。
4. 任何商业数据库、律所客户简报的原文。
5. 任何人物肖像、名人形象、真实企业标识。
