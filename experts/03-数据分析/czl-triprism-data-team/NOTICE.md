## 二、第三方代码依赖

**无。**

本产品的全部 Python 代码只使用 Python 3.9+ 标准库：

```
argparse csv datetime hashlib html io json math os re statistics
struct sys tempfile time traceback zipfile zlib xml.etree.ElementTree
```

标准库随 Python 发布，适用 PSF License，允许商业使用与再分发。
因此本产品**不包含任何需要单独授权、署名或开源披露的第三方代码**。
