# 任务书（T1）

开工前用这张表跟用户对齐。**填不满就别开工**，填满之后一次问清，不要来回挤牙膏。

---

## 基本信息

| 项 | 内容 |
|---|---|
| 数据文件 | 路径 / 工作表名 |
| 一行代表什么 | 例如：一行 = 一个区域一个产品线一个月的销售汇总 |
| 时间跨度 | 起 → 止，粒度 |
| 行数 / 列数 | 由体检结果填 |

## 分析目标（勾选）

- [ ] 走势：这段时间怎么变的
- [ ] 结构：内部由什么组成、集中度如何
- [ ] 异常：哪里不对劲
- [ ] 全要（默认）

| 问题 | 回答 |
|---|---|
| 核心指标是哪个字段？含税/不含税？ | |

## 受众与交付

| 项 | 内容 |
|---|---|
| 给谁看 | 自己决策 / 财务复核 / 向上汇报 |
| 要哪些格式 | HTML / 一页纸 / 幻灯片 / Excel（默认全给） |
| 敏感字段 | 有无姓名、手机、薪资等需要脱敏的列 |
