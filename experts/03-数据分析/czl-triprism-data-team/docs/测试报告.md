## 三、端到端验证（人工执行）

```
输出：report.html / onepager.md / deck.html / deck_spec.json / workbook.xlsx
耗时：0.02–0.04 秒
```

| HHI | 3,548 | Σ(share²)×10000 | ✅ |

### 3.2 缺陷数据集 `dirty_demo.csv`（22 行）

```
gate: warn    grade: C（68 分）    verify: PASS
检出：整行重复 2 行、未来日期 1 处、样本偏少
```

### 3.3 埋点验证

在 `sales_demo.csv` 第 78 行（2025-09 华南 专业版）人为把销售额压到 42%：

- 验伤线检出 `group_deviation`：该行为同组中位数的 53%（59,514 vs 112,148）
- 同时检出成本侧异常（第 105 行成本为中位数 142%）
- 结论复算仍 PASS

**说明**：单靠整列稳健 z 无法发现该异常（组内季节性波动大），
因此补充了"组内相对中位数偏离 ≥40%"规则。这是测试驱动出的功能改进。
