> WorkBuddy Expert（Team 型）· 分类 04-DataAI
> 开发者：虫志龙 · 47190078@qq.com · v1.0.2

---

## 一句话

**一份表格进，三路并行会诊：先给数据做体检定可信度，再冻结指标口径，走势 / 拆解 / 验伤三条线同时分析，每条结论回原表复算一次，最后交付网页报告、一页纸、幻灯片和 Excel 底稿。**

---

## 它和「让 AI 分析一下这张表」的区别

| 普通做法 | 三棱镜 |
|---|---|
| 直接把表丢给模型，让它"看看" | 先体检、定级、拦掉不可用的数据 |
| 三个视角由同一个模型轮流模拟 | 三位成员**真的并行**跑，职责互斥 |
| 三个人各算一套分母 | 口径先冻结，全流程同一个分母 |
| 数字靠模型心算 | 数字全部由本地工具链算出 |
| 结论写完就发 | 每条结论回原表复算，对不上就作废 |
| 只给一份文档 | 四件套，按场景选 |

---

## 团队

| 成员 | 职责 | 不做什么 |
|---|---|---|
| **主理人** | 守闸门、冻口径、派单、合成、交付 | 不亲自算数 |
| **走势官** | 方向、斜率、环比同比、拐点、季节性、带区间外推 | 不拆结构、不判异常 |
| **拆解官** | 占比、Top-N、帕累托、集中度、结构位移 | 不讲趋势、不判异常 |
| **验伤官** | 离群、组内偏离、负值、重复、缺失、未来日期、规则违背 | 不解释原因、不替客户删数据 |
| **校验官** | 逐条复算、冲突仲裁、决定哪些话能进报告 | 不产出新结论 |

---

## 五阶段流水线

```
P0 接料 → P1 体检（闸门）→ P2 冻口径 → P3 三路并行 → P4 质证 → P5 交付
```

任何一步不过，不进入下一步。体检 `block` 就直接停，不产出任何结论。

## 交付物

| 文件 | 用途 |
|---|---|
| `report.html` | 完整报告：结论 → 体检 → 三线 → 证据链 → 口径（可打印 PDF） |
| `onepager.md` | 一页纸：三句话 + 关键数字 + 下一步 |
| `deck.html` / `deck_spec.json` | 幻灯片网页版 / 交给 PPT 能力生成 .pptx |
| `workbook.xlsx` | 六表底稿：概览/走势/结构/异常/证据链/体检明细 |

---

## 技术底子

- **纯 Python 标准库**，不依赖 pandas / numpy / openpyxl / python-pptx
- 自带 CSV / XLSX 读取（含共享字符串、日期格式识别）
- 自带 XLSX 写出（OOXML 直拼 + zip 打包）
- 自带 PNG 处理工具（构建期用于处理视觉资源）
- 全程本地，不上传任何原始数据
