# 更新日志

本项目遵循语义化版本：`主版本.次版本.修订号`。

- 主版本：工作流结构变更、输出格式不兼容
- 次版本：新增分析能力、新增交付格式
- 修订号：修复缺陷、调整文案与样式

---

## [1.0.2] — 2026-10-28

修复 Team 型专家上传时的第二条校验不通过。功能无变更。

### 修复

- **新增插件根目录 `settings.json`**。平台上传校验要求 Team 型专家必须在 plugin root
  提供该文件，缺失时报「settings.json 不存在或无法读取」。
  内容为 `{"agent": "czl-triprism-data-team"}`，与 `plugin.json` 的 `agentName` 一致。

### 说明

- 该文件形态取自平台内置插件（`welcomemode-work/settings.json` 为 `{"agent": "work"}`），
  与客户端 `readGeneratedAgentOverride()` 的解析规则一致（只接受单字段 `agent`）。
- 平台在激活专家时会清理这类文件（视作「生成的 agent 覆盖」），因此**安装副本可能在首次
  激活后丢失该文件**。这不影响运行（团队配置来自 `plugin.json` 的 `teamInfo` 与 `members`），
  但重新打包时必须从源码目录打，不要从安装目录打。

### 工程改进

- `tools/verify_package.py` 新增 settings.json 检查：是否存在、是否合法 JSON、
  `agent` 是否为字符串、是否与 `agentName` 一致。

## [1.0.1] — 2026-10-28

修复平台上传校验不通过的问题。功能无变更。

### 修复

- **tags 由 4 个改为 3 个**。平台上传校验要求 tags 固定 3 个，原「本地处理」标签移除，
  保留「数据分析 / 数据体检 / 结论可复算」，其中「结论可复算」是本产品与同类最核心的差异点。
- **defaultInitPrompt 与 quickPrompts[0] 对齐**。平台要求两者中英文完全一致（含标点），
  原先是两段不同的文案。现将「经营会诊」开场语同时作为默认提示与第一条快捷提示。

### 变更

- 移除 `leader` 与 `icon` 两个字段。这两个字段在本机 24 个专家包中仅本包使用，
  属平台非标准字段；团队团长已由 `members[].role = "lead"` 表达，头像已由 `avatar` 表达，
  两个字段无实际作用，删除以降低上传被拒风险。
- `displayDescription.zh` 由 96 字压缩至 57 字，对齐已通过校验的包（普遍 ≤60 字）。
- 版本号 1.0.0 → 1.0.1。

### 工程改进

- `tools/verify_package.py` 新增四条平台规则检查：
  tags 数量、quickPrompts 数量、defaultInitPrompt 与 quickPrompts[0] 一致性、
  非标准字段提示。以后打包前跑一次即可拦截同类问题。

## [1.0.0] — 2026-10-28

首个公开版本。从零实现，非任何既有专家包的改名或改写。

### 新增

**团队与流程**
- 五人团队：主理人 + 走势官 + 拆解官 + 验伤官 + 校验官
- 五阶段闸门式流水线：接料 → 体检 → 冻口径 → 三路并行 → 质证 → 交付
- 派单信封与回传信封协议，成员职责互斥，禁止越界
- 失败隔离：单路失败不影响其余两路，报告注明缺失视角

**体检与闸门**
- 逐列类型推断（数字 / 日期 / 文本 / 空），阈值 95% / 80%
- 时间轴自动识别与粒度推断（日 / 周 / 月 / 季 / 年）
- 质量评分 A–D 与三态闸门（pass / warn / block）
- `block` 时直接停止，产出 `blocked.md` 说明拦截原因

**口径层**
- 口径 JSON 结构与机器校验（字段存在性、类型匹配、粒度合法性、分母非零）
- 自动起草时按「金额类关键词优先 + 波动性」排序指标，避免围绕无意义列展开

**三路分析**
- 走势：OLS 斜率、R²、CV、环比、同比、平滑后拐点检测（前后各留 2 期）、
  月份季节指数（≥24 期）、线性外推（3 期，±1.96×残差标准差）
- 拆解：占比、Top-N、累计占比、帕累托临界点、HHI 与集中度分级、
  首末期结构位移、双维度交叉
- 验伤：稳健 z（MAD）、IQR 提示、**组内偏离（稳健 z ≥3.5 或相对中位数偏离 ≥40%）**、
  负值、重复行、缺失聚集、未来日期、业务规则违背；三级严重度

**证据链**
- 每条结论附 `recheck` 规格，9 种算子：`delta_pct` / `mom_pct` / `inflection_delta` /
  `share` / `hhi` / `share_shift` / `value_at` / `duplicate_rows` / `row_count`
- 复算三态 PASS / FAIL / SKIP，容差 0.5% 或 0.01
- FAIL 结论自动降级为 D 并从正文剔除；SKIP 强制标注"未复算"
- 冲突仲裁规则：复算通过优先 → 口径明确优先 → 样本多优先 → 方向相反则并列陈述

**交付**
- `report.html`：七节结构，内联 SVG 图表（折线含预测区间、横向条形），可打印 PDF
- `onepager.md`：三句话 + 关键数字 + 下一步
- `deck.html`：16:9 幻灯片，走势页与结构页内嵌同源图表
- `deck_spec.json`：交给平台 PPT 能力生成 .pptx
- `workbook.xlsx`：六表底稿（概览/走势/结构/异常/证据链/体检明细）
- `run.json`：输入 sha256、耗时、输出清单

**工具链**
- 零第三方依赖，纯 Python 标准库
- 自实现 CSV / XLSX 读取（共享字符串、日期数字格式、内联字符串）
- 自实现 XLSX 写出（OOXML 直拼 + zip）
- 自实现 PNG 编解码 / 裁剪 / 双线性缩放（构建期处理头像）
- 统一 CLI，四种退出码：0 成功 / 2 输入错误 / 3 体检拦截 / 4 复算失败

**文档与测试**
- 32 项自动化测试，7 个分组，全部通过
- 9 份文档：产品规格、使用说明、平台展示文案、开发记录、测试报告、文件清单、风险清单等
- 5 张原创头像，统一视觉体系，512×512

### 已知限制

- 不支持 `.xls` 旧二进制格式（提示另存为 `.xlsx` / `.csv`）
- 不生成 `.pptx` 本体，只产出 `deck_spec.json`
- 不做因果推断，不做预测建模
- 未在 macOS / Linux 实测
- 生成式头像的商用授权需使用者自行确认（见风险清单 R3）
