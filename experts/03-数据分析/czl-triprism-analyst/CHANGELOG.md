# 更新日志

本项目遵循语义化版本：`主版本.次版本.修订号`。

- 主版本：工序结构变更、输出格式不兼容
- 次版本：新增分析能力、新增交付格式
- 修订号：修复缺陷、调整文案与样式

---

## [1.0.0] — 2026-10-28

首个版本。由同作者的「三棱镜·专业数据分析专家团」（Team 型）改编为 Agent 型单专家，
共用同一套工具链与分析纪律，形态从「多角色并行」改为「单角色三视」。

### 新增

**工序**
- 六道工序：接料 → 体检（闸门）→ 冻口径 → 三视 → 复算 → 交付
- 三视职责互斥：走势（时间）、拆解（结构）、验伤（质量），越界即错
- 体检闸门三态：pass / warn / block；block 时产出 `blocked.md` 并停止

**分析能力**
- 走势：OLS 斜率、R²、CV、环比、同比、平滑后拐点（前后各留 2 期）、
  月份季节指数（≥24 期）、线性外推（3 期，±1.96×残差标准差）
- 拆解：占比、Top-N、累计占比、帕累托临界点、HHI 与集中度分级、
  首末期结构位移、双维度交叉
- 验伤：稳健 z（MAD）、IQR 提示、组内偏离（稳健 z ≥3.5 或相对中位数偏离 ≥40%）、
  负值、重复行、缺失聚集、未来日期、业务规则违背；三级严重度

**证据链**
- 每条结论附 `recheck` 规格，9 种算子
- 复算三态 PASS / FAIL / SKIP，容差 0.5% 或 0.01
- FAIL 自动降级为 D 并从正文剔除；SKIP 强制标注"未复算"

**交付**
- `report.html`（七节结构，内联 SVG 图表，可打印 PDF）
- `onepager.md`（三句话 + 关键数字 + 下一步）
- `deck.html` + `deck_spec.json`（16:9 幻灯片，走势页与结构页内嵌图表）
- `workbook.xlsx`（六表底稿）
- `run.json`（输入 sha256、耗时、输出清单）

**工具链**
- 零第三方依赖，纯 Python 标准库
- 自实现 CSV / XLSX 读取、XLSX 写出、PNG 编解码与缩放
- 统一 CLI，四种退出码：0 成功 / 2 输入错误 / 3 体检拦截 / 4 复算失败

**文档与测试**
- 32 项自动化测试，7 个分组，全部通过
- 7 份文档 + 发布前自检脚本
- 1 张原创头像（512×512）

### 与专家团版的差异（改编说明）

- 去掉 `teamInfo` / `members` / `settings.json`，改为 `expertType: "agent"` 单 agent 结构
- 去掉建队与派单协议，改为一条命令跑完三视
- 保留：体检闸门、口径冻结、三视职责划分、复算引擎、证据分级、四件套
- 代价：不再有独立校验官交叉质证，复算的保证来自确定性引擎而非角色隔离

### 已知限制

- 不支持 `.xls` 旧二进制格式
- 不生成 `.pptx` 本体，只产出 `deck_spec.json`
- 不做因果推断，不做预测建模
- 未在 macOS / Linux 实测
