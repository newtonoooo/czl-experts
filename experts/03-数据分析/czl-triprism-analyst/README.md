## 一句话

**一份表格进，三个角度看：先给数据做体检定可信度，再冻住指标口径，走势 / 结构 / 异常三视各看一遍，每条结论回原表复算，最后交付报告、一页纸、幻灯片和 Excel。**

---

## 它和「让 AI 分析一下这张表」的区别

| 普通做法 | 三棱镜 |
|---|---|
| 直接把表丢给模型，让它"看看" | 先体检、定级、拦掉不可用的数据 |
| 一个视角看到底 | 三个视角各看一遍，互不越界 |
| 分母临时决定 | 口径先冻结，全流程同一个分母 |
| 数字靠模型心算 | 数字全部由本地工具链算出 |
| 结论写完就发 | 每条结论回原表复算，对不上就作废 |
| 只给一份文档 | 四件套，按场景选 |

---

## 三道分析工序

| 视角 | 只看什么 | 明确不看 |
|---|---|---|
| **走势** | 方向、斜率、环比同比、拐点、季节性、带区间外推 | 结构占比、异常判定 |
| **拆解** | 占比、Top-N、帕累托、集中度 HHI、首末结构位移 | 时间趋势、异常判定 |
| **验伤** | 离群、组内偏离、负值、重复、缺失、未来日期、规则违背 | 解释原因、替用户删数据 |

---

## 六道工序

```
S0 接料 → S1 体检（闸门）→ S2 冻口径 → S3 三视 → S4 复算 → S5 交付
```

体检 `block` 就直接停，不产出任何结论。口径没定死不出任何百分比。复算 FAIL 的结论从正文剔除。

## 交付物

| 文件 | 用途 |
|---|---|
| `report.html` | 完整报告：结论 → 体检 → 三视 → 证据链 → 口径（可打印 PDF） |
| `onepager.md` | 一页纸：三句话 + 关键数字 + 下一步 |
| `deck.html` / `deck_spec.json` | 幻灯片网页版 / 交给 PPT 能力生成 .pptx |
| `workbook.xlsx` | 六表底稿：概览/走势/结构/异常/证据链/体检明细 |

## 与「专家团版」的区别

| | 本专家（单人版） | 专家团版 |
|---|---|---|
| 执行 | 一个专家依次跑三道工序 | 三个成员并行跑 |
| 速度 | 一条命令跑完，更快 | 建队派单，开销更大 |
| 复算 | 引擎复算（机械保证） | 引擎复算 + 独立校验官仲裁 |
| 局限 | 自己写的结论自己复算，**缺一层独立质疑** | 有独立角色交叉质证 |

如果你的场景要求「必须有人独立质疑结论」，用专家团版；如果只是要一份算得清、能复算的报告，单人版更快。

## 技术底子

- **纯 Python 标准库**，不依赖 pandas / numpy / openpyxl / python-pptx
- 自带 CSV / XLSX 读取（共享字符串、日期格式识别）
- 自带 XLSX 写出（OOXML 直拼 + zip）
- 全程本地，不上传任何原始数据
