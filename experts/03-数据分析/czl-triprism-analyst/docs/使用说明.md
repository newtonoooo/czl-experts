# 三棱镜 · 使用说明

v1.0.0 · 虫志龙 · 47190078@qq.com

---

## 一、它是什么

一个 WorkBuddy 专家。选它，把表格丢进来，说清你想看什么，它会：

1. 先给表做体检（能不能用、能支撑多强的结论）
2. 冻住指标口径
3. 三个视角各看一遍（走势 / 结构 / 异常）
4. 每条结论回原表复算
5. 交付四件套

---

## 二、怎么用（对话方式，推荐）

在 WorkBuddy 里选择「三棱镜·专业数据分析专家」，然后：

```
帮我分析这份销售表，走势、结构、异常都要看，最后给我能开会的报告：sales_2025.xlsx
```

或者更省事：

```
先告诉我这张表能不能用：orders.csv
```

它会先问你三件事（表是什么、最关心什么、给谁看），答完就开工。

### 你会拿到什么

| 文件 | 什么时候看 |
|---|---|
| `report.html` | 想核对结论怎么来的 |
| `onepager.md` | 只想看三句话 |
| `deck.html` | 要投屏汇报 |
| `workbook.xlsx` | 财务要核对明细 |

## 三、怎么用（命令行方式）

适合批量处理、集成到自己的流程。

### 3.1 定位工具目录

```
~/.workbuddy-ai/plugins/marketplaces/my-experts/plugins/czl-triprism-analyst/tools
```

找不到就搜：

```bash
find ~ -maxdepth 8 -type d -name "czl-triprism-analyst" 2>/dev/null
```

下文用 `<TOOLS>` 代指该目录。

### 3.2 一条命令跑完

```bash
python <TOOLS>/triad_cli.py run \
  --path 你的表.xlsx \
  --outdir out \
  --title "2025 年度经营会诊" \
  --metric 销售额 --dimension 区域 产品线 --grain month
```

产出：`report.html`、`onepager.md`、`deck.html`、`deck_spec.json`、`workbook.xlsx`，
以及 `profile.json` / `contract.json` / `bundle.json` / `verify.json` / `run.json`。

### 3.3 分步跑（需要控制每一步时）

```bash
# 1. 只体检，看摘要
python <TOOLS>/triad_cli.py profile --path data.csv --brief

# 2. 只跑某一个视角
python <TOOLS>/triad_cli.py analyze --path data.csv --contract contract.json \
  --lanes integrity --out integrity.json

# 3. 复算
python <TOOLS>/triad_cli.py verify --path data.csv --bundle bundle.json \
  --out verify.json --demote-out bundle.verified.json
```

### 3.4 参数表

| 参数 | 作用 | 默认 |
|---|---|---|
| `--path` | 数据文件（必填） | — |
| `--sheet` | 工作表名 | 第一张 |
| `--outdir` | 输出目录（`run` 必填） | — |
| `--out` | 单文件输出路径 | — |
| `--contract` | 自定义口径 JSON | 自动起草 |
| `--title` | 报告标题 | 文件名 + "三视角数据会诊" |
| `--metric` | 指定指标（可多个） | 自动排序 |
| `--dimension` | 指定拆解维度（可多个） | 自动选取 |
| `--grain` | 时间粒度 `day/week/month/quarter/year` | 自动推断 |
| `--lanes` | 只跑指定视角 `course composition integrity` | 全部 |
| `--formats` | 输出格式 `html,deck,xlsx,md` | 全部 |
| `--brief` | 只打印给模型看的体检摘要 | 关 |

### 3.5 退出码

| 码 | 含义 | 你要做什么 |
|---|---|---|
| 0 | 成功 | — |
| 2 | 输入错误（文件不存在、格式不支持、口径不合法） | 看报错信息修正输入 |
| 3 | 体检闸门拦截（数据不足/无数值列） | 补数据，不要绕过 |
| 4 | 复算失败 | 检查口径是否被改动，重跑 |

## 四、自定义口径

不指定 `--contract` 时会自动起草一份。要精确控制就自己写：

```json
{
  "contract_version": 1,
  "table": "sales_2025.xlsx",
  "sheet": "明细",
  "grain": "month",
  "time_field": "月份",
  "metrics": [
    { "id": "M1", "name": "销售额", "field": "销售额", "agg": "sum",
      "unit": "元", "definition": "含税订单金额合计，不含运费与退款" }
  ],
  "ratios": [
    { "id": "R1", "name": "成本率", "numerator": "成本", "denominator": "销售额" }
  ],
  "dimensions": ["区域", "产品线"],
  "filters": [
    { "field": "订单状态", "op": "not_in", "value": ["已取消", "测试单"] }
  ],
  "rules": [
    { "id": "RULE1", "type": "max_single", "field": "销售额",
      "threshold": 500000, "message": "单笔超 50 万需二次审批" }
  ]
}
```

然后：

```bash
python <TOOLS>/triad_cli.py run --path sales_2025.xlsx --contract my_contract.json --outdir out
```

口径写不对会当场报错（字段不存在、类型不符、粒度非法、分母为 0），不会带着错口径往下跑。

## 五、报告怎么读

`report.html` 七节，按顺序看：

1. **一页纸结论** — 先看这里，4 条结论带等级与"已复算"标签
2. **数据体检** — 这份数据能信几分
3. **走势线** — 时间维度怎么变，含拐点与外推
4. **拆解线** — 内部由什么组成，集中度多少
5. **验伤线** — 哪里可能不对，建议动作是什么
6. **证据链** — 每条结论的复算值，PASS/FAIL/SKIP
7. **口径与免责** — 指标定义与使用限制

### 等级怎么理解

| 等级 | 含义 | 能不能写进汇报 |
|---|---|---|
| A | 样本足、复算过、口径无争议 | 直接写 |
| B | 复算过，但样本偏少或含假设 | 写，但要带条件 |
| C | 方向性判断 | 只作观察 |
| D | 复算失败/数据不足 | 不会出现在正文 |

## 六、常见问题

**Q：能处理 Excel 多个 sheet 吗？**
能，但要指定 `--sheet "明细"`。不指定就取第一张，并在报告里注明。

**Q：为什么我的表被拦了？**
通常是：行数 < 10、没有数值列、只有一列。报告会写清拦截原因，补齐后重跑。

**Q：为什么结论是 B 不是 A？**
样本量或拟合优度不够。看报告"数据体检"章节的具体原因，那是真实限制。

**Q：能出 PPT 吗？**
`deck.html` 可直接投屏或打印成 PDF。要 `.pptx` 时，让它把 `deck_spec.json` 交给平台的 PPT 能力生成。

**Q：数据会被上传吗？**
不会。全部本地处理，工具链零网络请求。

**Q：能改数据吗？**
不能。只读原表、只标问题，不改你的文件。

**Q：中文列名/中文日期能识别吗？**
能。`2025年3月`、`2025/03/01`、`20250301` 都能解析。

**Q：这和"三棱镜·专业数据分析专家团"有什么区别？**
团版是三个成员并行 + 独立校验官交叉质证；本版是一个专家依次跑三道工序，更快更省，但没有独立角色质疑结论。要"有人替老板再问一遍"，用团版。

## 七、出问题怎么办

| 现象 | 处理 |
|---|---|
| 报"不支持的扩展名" | `.xls` 请另存为 `.xlsx` 或 `.csv` |
| 报"找不到文件" | 检查路径；Windows 路径含空格要加引号 |
| 报"口径校验失败" | 按错误信息改 `contract.json`，通常是字段名写错 |
| 报告图表空白 | 数据里没有可用时间序列，属正常降级 |
| 结论全是 D | 复算失败，检查是否改了源文件或口径 |
