## 一、为什么做这个版本

同作者的「三棱镜·专业数据分析专家团」（`czl-triprism-data-team`）是 Team 型多成员结构，
上架时遇到平台对 Team 型的两项额外约束：

1. `tags` 必须固定 3 个
2. 必须在插件根目录提供 `settings.json`（内容为 `{"agent": "<主 agent 名>"}`）

这两条本身不难满足，但反映出一件事：**Team 型的产品形态更重，用户每次调用都要建队、派单、汇总，
对于"只想把一张表算清楚"的场景是过度设计。**

所以做了这个 Agent 型单专家版本：
- 保留团版的分析纪律（体检闸门、口径冻结、三视划分、复算引擎、证据分级）
- 去掉协作开销（建队、派单、回传信封）
- 形态更轻，安装与上架都少一层约束

## 二、改编时保留了什么、去掉了什么

### 保留（这是产品的价值所在，不能丢）

| 机制 | 为什么必须留 |
|---|---|
| **体检闸门 A–D** | 没有它，坏数据上照样能生成"看起来专业"的垃圾结论 |
| **口径冻结** | 三个视角用同一分母，否则报告会自己打自己 |
| **三视职责互斥** | 走势不讲结构、验伤不定性质，越界就是错 |
| **确定性工具链** | 数字由代码算，模型只叙述——这是可信度的地基 |
| **recheck 复算规格** | 每条结论可被同一份数据重算，PASS/FAIL/SKIP 三态 |
| **A/B/C/D 证据分级** | 让读者知道该信到几分 |
| **四件套交付** | 网页看过程、一页纸发群、幻灯片开会、Excel 核对 |

### 去掉（团版特有，单版不需要）

| 机制 | 去掉的原因 | 替代方案 |
|---|---|---|
| `TeamCreate` 建队 | 单 agent 无需建队 | 直接跑 CLI |
| `AgentTool` 派单 + 回传信封 | 无成员可派 | 一条 `run` 命令跑完三视 |
| 独立校验官交叉质证 | 单人无法真正独立 | 复算由确定性引擎执行（机械保证，不依赖自我审查） |
| `teamInfo` / `members` / `settings.json` | Agent 型不需要 | 单 `agents` 数组 + `agentName` |

### 明确承认的代价

团版的"可复算"来自**两层**：引擎复算 + 独立角色仲裁。
单版只剩**一层**：引擎复算。

这不是文字游戏，是真实差异：

- 引擎能保证"数字算对了"
- 但"该不该这么问"、"这个结论有没有过度解读"——需要另一个角色来质疑
- 单版里，出题人和判卷人是同一个人

因此产品文档与 agent 提示词里都写明了这条局限，并在用户问起时如实回答
（见 `agents/czl-triprism-analyst.md` 第十一节）。

## 四、平台上传校验：两条硬规则（踩坑记录）

### 4.1 tags 必须固定 3 个

团版首次上传报 `tags 须固定 3 个，当前 4 个`。
本版一开始就按 3 个设计：数据分析 / 数据体检 / 结论可复算。

### 4.2 Team 型必须有 settings.json

团版第二次上传报 `settings.json 不存在或无法读取`。

排查过程：
1. 本机 24 个专家包全都没有这个文件——因为它们都是 agent 型
2. 平台内置插件里有：`welcomemode-work/settings.json` 内容为 `{"agent": "work"}`
3. 客户端 `readGeneratedAgentOverride()` 只接受单字段 `agent` 的字符串

结论：Team 型专家的 `settings.json` 用来指定会话默认 agent（团长），形态是 `{"agent": "<agentName>"}`。

**本版是 agent 型，不需要这个文件**（本机 24 个 agent 型包均无）。
`verify_package.py` 已改为按 `expertType` 条件校验：team 必查，agent 不查。

### 4.3 默认提示必须等于第一条快捷提示

`defaultInitPrompt` 与 `quickPrompts[0]` 的中英文必须逐字一致（含标点）。
本版一开始就对齐。

### 4.4 经验总结

平台字段规则没有公开文档，只能靠「已知能通过的样本」反推。
本机 24 个已通过校验的包给出的共同特征：

| 特征 | 合规包的实际值 |
|---|---|
| `tags` 数量 | 全部 3 个 |
| `quickPrompts` 数量 | 全部 3 条 |
| `defaultInitPrompt == quickPrompts[0]` | 全部为真 |
| `displayDescription.zh` 长度 | 41–52 字 |
| 非标准字段 | 无（`leader`、`icon` 等仅个别包有，属冗余） |

以上全部写进 `tools/verify_package.py`，打包前跑一次即可拦截。
