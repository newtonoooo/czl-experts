## R1 · 原创性

**判断依据**

- 提示词、技能包、代码、文档均为同作者原创
- 与团版（`czl-triprism-data-team`）共用工具链，属同一作者的内部复用，不涉及第三方权利
- 未复制其他作者专家包的任何内容
- 继承的仅是"多视角分析 + 多格式交付"这类通用方法论，属思想层面

**需要你做的**：确认开发过程中未把他人提示词原文交给第三方"改写"，也未复制其文件内容。

---

## R2 · 第三方代码

**结论：无风险。**

全部 Python 代码仅使用标准库（argparse/csv/datetime/hashlib/html/io/json/math/os/
py_compile/re/statistics/struct/sys/tempfile/time/traceback/zipfile/zlib/xml）。
标准库适用 PSF License，允许商业使用与再分发。

无 npm 包、无字体文件、无图标库、无 CDN 引用（图表为内联 SVG，字体用系统字体）。

## R3 · 头像使用权

**事实**：`avatars/expert.png` 由同作者自有品牌图（团版主理人头像，AI 生成后经人工设定
视觉概念、裁水印、缩放处理）裁切 40px 边距后缩放到 512×512。

**风险点**

1. AI 生成内容的可版权性较弱（多数法域对纯 AI 生成内容不给著作权）。
   本图经过人工设定概念 + 裁切 + 缩放 + 统一体系，有一定独创性投入，但保护力度弱于手绘。
2. 生成工具的服务条款是否允许商业销售，需你查阅所用工具的用户协议。

**替代方案（若上述不成立）**

- 用矢量工具按现有视觉概念重绘棱镜徽标，产出 SVG 后导出 PNG。几何图形本身不构成他人作品，重绘后版权清晰。
- 或改为纯文字标识（单字 + 色块）。

**与团版的关系**：两个包共用同一品牌视觉体系（深墨蓝底 + 青/琥珀双色 + 棱镜分光），
取景不同（团版留白多、本版裁切放大），属同一作者的品牌延展，不涉及第三方。

## R4 · 头像显示（**未实测上传**）

**已知机制**

- 自定义专家通道（`my-experts`）：`avatar` 本地相对路径 → `local-file://` → 正常显示
- 插件市场通道（`experts`）：`avatar` 会被丢弃或拼成远程 CDN 地址 → 404 → 显示首字占位

**已做**：投放到 `my-experts` 并登记、`avatar` 用 `avatars/expert.png`（不带 `./`、不带前导 `/`）、
512×512、162KB（远低于 5MB 上限）。

**需要你做的**：上传后在专家列表确认图标显示正常；若显示首字，检查安装路径落在
`cache/experts/` 还是 `cache/my-experts/`。

## R5 · 名称重复（**云端未查**）

**已查**：本机 `my-experts` 下 23 个专家包，无「三棱镜」「TriPrism」「专业数据分析专家」字样
（团版是「三棱镜·专业数据分析专家团」，与本版差一个「团」字）。

**未查**：云端专家中心全量名称库。

**需要你做的**：在专家中心搜索「三棱镜」「棱镜」「数据分析」，确认无重名或高度近似。

**注意**：团版与本版同属三棱镜品牌，若两个都上架，需在详情页首段说明区别
（单版=一个专家三道工序，团版=三个成员并行+独立校验）。

## R6 · XLSX 兼容性（**未人工打开**）

**已做**：zip 完整性、全部 XML 良构、自身解析器回读内容一致。

**未做**：用 Excel / WPS 实际打开确认无"修复"提示。

**需要你做的**：打开一次 `out/sales/workbook.xlsx`，确认无提示、格式正常。
若有问题，降级方案：改为输出多个 CSV，或在文档注明"请用 WPS 打开"。

---

## R7 · 平台规则（**需你查阅**）

本机文档（workbuddy.cn/docs）未检索到专家中心关于**原创性审核标准**与**商业分成比例**的条款。

**需要你做的**

1. 查阅上架协议：是否要求独家、是否要求著作权声明、分成比例、结算方式
2. 确认是否允许 MIT 许可的包上架（部分平台要求专有许可）
3. 确认是否允许包内包含可执行 Python 脚本（本包会在本地运行脚本）

**若平台不允许本地脚本**：降级为纯提示词版会丧失"可复算"能力，不建议。

---

## R8 · 结论误用

**风险**：用户把 B/C 级结论当作 A 级写进决策材料，或把外推当预测。

**已做**

- 每条结论强制带等级与复算状态
- 报告"口径与免责"章节声明"不构成审计、税务或投资意见"
- 外推强制带区间与置信度，R²<0.5 标"低"
- 使用说明明确"不替客户做业务决策"

**需要你确认**：免责措辞是否足够（如需更强表述，可改 `triad_render.py` 的 `footer_note`）。

## R11 · 上传校验规则不公开

**事实**：同作者的团版两次上传被拒，暴露出两条未公开规则：

- `tags` 须固定 3 个
- Team 型必须在 plugin root 提供 `settings.json`

这两条在本地 `app.asar` 中搜不到，说明校验在服务端。

**已做**：统计本机 24 个已通过包的字段规格，反推出共同特征
（tags=3、quickPrompts=3、default 与首条一致、displayDescription ≤60 字、无非标准字段），
写入 `tools/verify_package.py`，本包已全部通过。

**残余风险**：可能还存在未暴露的规则。上传若再报错，把原文贴出来，按同样方法反推。

---

## R12 · 与团版混淆

两个包同属「三棱镜」品牌，功能高度重合（同一工具链）。

**风险**：用户不知道该选哪个；若两个都上架，可能被平台判定为重复上架。

**建议**

- 只上架一个（推荐本版：结构更轻、上传约束更少）
- 若两个都上，详情页首段必须写明区别，且标签错开（团版可加「多专家并行」，本版加「单人快跑」）
- 或把团版下架，保留本版

**需要你决定**：是只上本版，还是两个都上。

## 我不能替你确认的事

1. 平台对原创性的具体审核口径与分成比例
2. AI 图像生成工具的服务条款是否允许商业转售
3. 云端专家中心是否已有同名/近似名产品

这些需要你或你的法务确认。在此之前，本包可作内测与小范围试用，**不建议直接公开售卖**。
