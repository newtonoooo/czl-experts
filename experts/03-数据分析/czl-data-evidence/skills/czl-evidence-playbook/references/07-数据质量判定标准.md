# 07 · 数据质量判定标准

> 评级不是为了给数据打分，是为了告诉用户"这份数据能撑多大的结论"。

## 一、五个维度

| 维度 | 看什么 | 为什么影响结论 |
|---|---|---|
| 完整性 | 关键字段缺失率 | 缺失不是随机的，会系统性偏某一类样本 |
| 连续性 | 时间有无断档 | 断档会把趋势读成断崖或跳升 |
| 唯一性 | 重复行占比 | 重复会等比放大所有总量 |
| 一致性 | 同一含义是否多套值 | 口径冲突能让结论反向 |
| 充分性 | 关键分组的样本量 | 小样本的差异大概率是噪声 |

## 二、评级表

| 维度 | A | B | C | D |
|---|---|---|---|---|
| 关键字段完整率 | ≥99% | 95–99% | 80–95% | <80% |
| 时间连续性 | 无断档 | 断 1–2 天 | 断 3–7 天 | 断 >7 天 |
| 重复行 | 0 | <0.5% | 0.5–3% | >3% |
| 口径一致性 | 完全一致 | 轻微不一致 | 需人工裁定 | 严重冲突 |
| 关键分组样本量 | ≥200 | ≥100 | ≥30 | <30 |

整体评级取**最低项**，并对用户说明是哪一项拖下来的。

## 三、评级对应能做什么

| 整体 | 能给的结论 | 不能做的 |
|---|---|---|
| A | A 级结论（可直接决策） | —— |
| B | A 或 B 级，取决于对照与区间 | 不能做细分到小群体的结论 |
| C | 最高 B 级，且必须随结论附质量账 | 不能做归因，只能描述 |
| D | 只做数据问题诊断 | 不出任何业务结论 |

## 四、常见质量问题清单（照着查）

**完整性类**

- [ ] 关键列（日期、金额、主体）有空值
- [ ] 空值集中在某类状态或某段时间
- [ ] 用 0 代替缺失（金额为 0 但状态为已支付）

**连续性类**

- [ ] 周末/节假日无数据（真无业务 vs 未采集）
- [ ] 某天数据量异常少（采集失败）
- [ ] 时间字段格式混用（2026/6/1 与 2026-06-01）

**唯一性类**

- [ ] 同一订单多行（拆单或重复导出）
- [ ] 导出多次后追加导致整体重复
- [ ] 同一主体多账号未合并

**一致性类**

- [ ] 状态字段与金额不联动（退款未冲销）
- [ ] 单位混用（元/万元、件/箱）
- [ ] 同一品类多种写法（"女装"/"女装类"/"WOMEN"）
- [ ] 分类树改版后新旧编码并存

**充分性类**

- [ ] 某渠道只有几十单却被拿来对比
- [ ] 新上线功能样本不足一周就下结论

## 五、清洗留痕怎么写

每做一步处理，记一行：

| 动作 | 影响行数 | 原因 | 是否可逆 |
|---|---|---|---|
| 删除金额为空的行 | 312（3.1%） | 无法计入销售额 | 可逆（保留原文件） |
| 合并重复订单号 | 58 | 导出重复 | 可逆 |
| 统一品类写法 | 1240 | 名称不一致 | 可逆（保留映射表） |

原则：**只删不能用的，不改能用的**。改过的值要留映射表。

## 六、什么时候该停下来

三种情况不继续：

1. 整体 D 级；
2. 关键字段缺失 >20%；
3. 时间断档跨越了要对比的两个期。

停下来不是失败，是避免给出一个会被业务当场推翻的结论。
