# 03 · 归因五法：选型与操作

> 五种方法各治一种病。用错方法，算得再准也是错的。

## 一、怎么选（一张判断表）

| 你手上的情况 | 用哪一法 | 不用另外四种的理由 |
|---|---|---|
| 有金额 + 数量，想知道总量变化从哪来 | **结构分解** | 漏斗答不了"哪块";同期群答不了当期 |
| 有分步人数，想知道卡在哪 | **漏斗** | 分解答不了链路；分群答不了顺序 |
| 有用户 + 时间，想知道留存是真差还是结构变了 | **同期群** | 分解看的是总量；漏斗看的是单次转化 |
| 整体与某组结论相反 | **分群对比** | 其余方法都在整体层面，会掩盖反向 |
| 有对照组，想知道改动有没有用 | **实验/准实验** | 其余只能给相关，不能给因果 |

**一句话原则**：能构造对照的，优先实验；构造不了的，老老实实说相关。

## 二、结构分解：量、价、结构

总量 = 量 × 价。分组后：

```
总变化 = Σ(Δ量ᵢ × 基期价ᵢ) + Σ(基期量ᵢ × Δ价ᵢ) + Σ(Δ量ᵢ × Δ价ᵢ)
         └── 量的贡献 ──┘   └── 价的贡献 ──┘   └── 交互项 ──┘
```

读法：

- 量贡献为主 → 客流/需求问题，往渠道和流量看；
- 价贡献为主 → 定价、促销、折扣结构问题；
- 交互项很大 → 结构在变（高价品占比变了），此时必须按组讲，不能给整体。

校验：各项之和与总变化的差额应小于 1%；超过说明维度没拆全或数据有重复。

## 三、漏斗：跌幅要看"相对跌幅"，不是绝对量

每步两个数：

- 单步转化率 = 下一步 / 本步
- 相对跌幅 = （本期单步率 − 基期单步率）/ 基期单步率

找"相对跌幅明显大于相邻步"的那一步。绝对人数掉得多，往往只是因为基数大。

**必须换算成钱**：这一步恢复到基期水平，能多带来多少单 × 客单价 = 可回收金额。没有这个数，漏斗只是好看。

## 四、同期群：横看质量，纵看体验

矩阵：行 = 首次出现月份，列 = 之后第 N 个月。

- **横看**（同一列不同行）：新群比老群差 → 获客质量或渠道结构变了；
- **纵看**（同一行不同列）：衰减斜率变陡 → 产品或体验出问题。

两个方向常常同时发生，要分开说。常见错误是拿"总体留存率"下结论——它会被新老结构的变化直接带偏。

## 五、分群对比：专门用来抓辛普森悖论

步骤：

1. 选一个对业务有解释力的维度（渠道、地区、新老客、价格带）。
2. 各组分别算指标。
3. 找方向相反的组。
4. 看该组权重是否足以扭曲整体。

若存在：整体结论不能直接给，必须按组给。报告写成"整体看起来 X，但这是由 A 组结构变化造成的，B/C 组实际是 Y"。

## 六、实验与准实验：只有这里有因果

**真实验**：随机分流。前提是分流真的随机（看基线是否可比，而非听人保证）。

**准实验**三种常用构造：

| 构造 | 适用 | 风险 |
|---|---|---|
| 前后对比（有对照地区/门店） | 线下、区域性活动 | 对照区与实验区不可比 |
| 断点回归 | 有阈值规则（满减、等级） | 阈值附近样本太少 |
| 双重差分 | 有面板数据 | 平行趋势假设不成立就失效 |

报法固定三件：**效应量、区间、样本量**。只报"提升了 3 个百分点"不合格。

## 七、五种方法的边界（写进报告）

| 方法 | 测不到什么 |
|---|---|
| 结构分解 | 测不到"为什么量变"，只测"哪里变" |
| 漏斗 | 测不到流失原因，只测流失位置 |
| 同期群 | 测不到当期收入影响 |
| 分群对比 | 测不到因果，只能说相关 |
| 实验 | 测不到长期效应（除非跑得够久） |
