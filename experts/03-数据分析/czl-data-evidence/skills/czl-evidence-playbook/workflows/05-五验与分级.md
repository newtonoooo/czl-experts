# W5 · 五验与分级

## 职责

结论出门前的最后一道关。逐条过五验，填证据账，给结论定 A/B/C/D。**这道工序不许跳，也不许先定级再补验。**

定级的目的是把风险说清楚，不是给结论贴金。

## 输入参数

| 参数 | 是否必需 | 说明 | 缺失时怎么办 |
|---|---|---|---|
| 待验结论 | 必需 | 一句可判断真假的话 | 写成问句就说明还没形成结论，回 W4 |
| 数据来源 | 必需 | 文件、字段、时间范围 | 缺 → 直接判 D，无法举证 |
| 方法记录 | 必需 | 用了哪一法、参数是什么 | 缺 → 判 C，只能当观察 |
| 基线/对照 | 验证所需 | 历史同期、对照组、行业参考 | 缺 → 对照验不过，最高 B 级 |

## 执行步骤

**第一步：把结论写成可判断的句子。**

不合格：「六月表现不好。」
合格：「六月销售额环比下降 18%，主要来自华东区低价商品占比上升（贡献 -11.2 个百分点），而非整体涨价或客流下滑。」

**第二步：逐条过五验。**

| # | 验什么 | 具体动作 | 判据 |
|---|---|---|---|
| 1 | 口径验 | 拿口径账对一遍：分子分母、时间窗、排除项是否与分析时一致 | 不一致 → 重算或并列 |
| 2 | 分布验 | 看中位数、P90、去极值后结果是否仍成立 | 结论仅由 <5% 样本支撑 → 不过 |
| 3 | 对照验 | 有无基线；季节/大促/行业能否解释掉差异 | 无基线 → 降级；能解释掉 → 结论改写为"属正常波动" |
| 4 | 效应验 | 效应量多大；区间多宽；值不值得动 | 区间跨 0 → 改判"未测出差异"；效应小于行动成本 → 明确说不值得改 |
| 5 | 反例验 | 主动构造能推翻结论的情形并去找 | 找到 → 改结论；找不到 → 在证据账写"已查，未找到" |

**第三步：定级。**

| 级 | 判定条件（同时满足） |
|---|---|
| A | 五验全过；有对照；有效应量与区间；反例查过 |
| B | 口径与分布都过；缺对照或缺区间（二者只缺一）；或关键分组样本 30–200 |
| C | 只有单点数据、无基线；或时间窗不足两个周期；或方法为描述性 |
| D | 任一验明确不过：口径错、被极端值带偏、差异在噪声内、方法不适配 |

**第四步：填证据账。** 每条结论一行，五验各一列，写"过/不过/未做"，不许留空。留空等于没过。

## 判断条件

| 判断点 | 条件 | 动作 |
|---|---|---|
| 结论句能否证伪 | 不能 | 改写成可证伪句；改不了就删掉这条结论 |
| 五验有"未做" | 任一项 | 该项按"不过"处理，直接降级 |
| 级别为 D | 是 | 不写进正文结论，只在附录留"已排除的解释"，避免用户误读 |
| 全部结论都是 C | 是 | 明确告诉用户：这次只能给方向，不能给动作；说明补什么能升级 |
| 结论与用户预期相反 | 是 | 单独用一段说明"为什么和直觉不一样"，把口径和样本摆出来 |

## 输出格式

`T5-证据账.md` 一份，表格固定列：

| # | 结论 | 数据来源 | 方法 | 效应量/区间 | 口径验 | 分布验 | 对照验 | 效应验 | 反例验 | 级别 | 什么会推翻它 |

另附"降级说明"：每条被判 B/C/D 的结论，写一句降级原因和升级条件。

## 异常处理

- **用户不接受降级**：不改级别。把"如果不看级别直接执行，最坏情况是什么"写清楚，让用户带着风险决策。
- **两条结论互相矛盾**：不并列给出。回 W4 查是否有口径或分组差异，查不出就两条都降 C。
- **反例找到了但没法排除**：结论降级并在正文写明"存在未排除的替代解释：××"。
- **时间不够做反例验**：标"未做反例验"，最高 B 级。

## 必要依赖

`templates/T5-证据账.md`；区间与检验口径见 `references/04-统计检验速查.md`；陷阱清单见 `references/05-常见归因陷阱.md`。

## 与其他工作流的关系

- **上游**：W4 的归因结果。
- **下游**：W6 只允许使用 A 与 B 级结论写正文动作；C 级进"观察项"；D 级进附录。
- **回流**：判 D 且原因是方法错 → 回 W4；原因是口径错 → 回 W1；原因是数据脏 → 回 W2。
