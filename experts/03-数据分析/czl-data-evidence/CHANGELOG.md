# 变更日志 · CHANGELOG

## v1.0.0 — 2026-10-26

首个版本，从零独立开发。

### 开发方式说明

本产品不是任何现有专家包的改名版本。需求阶段只做了功能归纳（这类产品通常要覆盖：澄清需求、数据体检、探索、归因、检验、汇报），实现阶段的提示词、工作流、模板、参考文档、脚本代码、头像与文案全部新写。没有复制第三方专家包的提示词文本、工作流定义、脚本代码或参考文档内容。

### 已知限制

- 未做多角色协作：单 Agent 设计，复杂项目需人工拆分；
- `ab_test.py` 的 t 分位数用二分法近似，极端小样本（每组 <10）时区间仅供参考；
- `doc_export.py` 只支持有限的 Markdown 子集（标题、段落、列表、表格、代码、引用、加粗、行内代码）；
- 知识库口径以 2026-10 编写时的通用实践为准，不含任何平台的实时规则；
- 未做 Excel（.xlsx）直读，需要另存为 CSV。
