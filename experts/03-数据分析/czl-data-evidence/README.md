## 一、它解决什么问题

不是"不会算数"，是三种判断失误：

1. **口径不明就开算**——"销售额"含不含退款、"活跃"是登录还是下单，口径不同，结论可以相反；
2. **把噪声当信号**——几百单的波动被说成趋势，看一周数据就改策略；
3. **归因停在现象**——说"转化率低"，不说哪一步低、低多少、和谁比、值多少钱。

数证台的做法：先立口径，再体检数据，用五道验证把结论分成四档——**A 可直接决策 / B 有条件可用 / C 仅供观察 / D 不成立**。你拿到的不只是结论，还有"这句话能拿去做多大的决定"。

## 二、三账五验

三本账留痕，五道验过关。

| 三账 | 记什么 |
|---|---|
| 口径账 | 每个指标的分子、分母、时间窗、排除项、边界情况 |
| 质量账 | 行列数、缺失、重复、异常值、口径冲突、可用性评级 |
| 证据账 | 每条结论的数据来源、方法、效应量与区间、反例检查、级别 |

| 五验 | 问什么 | 不过怎么办 |
|---|---|---|
| 口径验 | 算的是不是提问人以为的那个数 | 改口径重算，或两种口径并列 |
| 分布验 | 有没有被少数样本带偏 | 看中位数与分位数，去极值重算 |
| 对照验 | 季节、大促、自然波动能否解释掉 | 补基线或降级 |
| 效应验 | 差多少、区间多宽、值不值得动 | 给区间；效应太小就说"不值得改" |
| 反例验 | 什么数据会推翻我 | 主动去找，找到就改结论 |

## 三、六道工序

| 工序 | 产物 |
|---|---|
| W1 立项与口径 | 分析任务书 + 口径账 |
| W2 数据体检 | 质量账 + A/B/C/D 可用性评级 |
| W3 探索与假设 | 假设清单（每条带可验证预测） |
| W4 归因五法 | 量价分解 / 漏斗 / 同期群 / 分群对比 / 实验与准实验 |
| W5 五验与分级 | 证据账 + 结论定级 |
| W6 交付与落地 | 一页纸 / 完整报告 / 看板规格 |

## 五、三步上手

1. **装**：放进 `~/.workbuddy/plugins/marketplaces/my-experts/plugins/`，或用专家中心导入 zip。
2. **说一句**：「这是我们店上半年的订单表，六月掉了 18%，帮我找到掉在哪。」缺的信息它按惯例补，补了什么写在任务书上。
3. **看级别**：每份交付都有 A/B/C/D 和"什么情况下这结论会翻"。不认，就改假设，它重算。

脚本可以直接跑（本地有 Python 3.8+ 即可，无第三方依赖）：

```bash
cd skills/czl-evidence-playbook/scripts
python profile_table.py ../samples/orders_demo.csv --by 渠道 --key 订单号
python period_compare.py ../samples/orders_demo.csv --date 支付日期 --value 金额 --qty 件数 \
    --period 2026-05:2026-06 --by 渠道
python ab_test.py --control 51/1000 --treat 78/1000
```

样例数据的真值全部可手算，见 `samples/README.md`；跑出来不一致，说明参数用错了，先别信结论。

## 六、能力边界（先说清楚）

| 不做 | 原因 |
|---|---|
| 销量、流量、股价预测 | 无法保证，容易让人据此压货压钱 |
| 审计、税务、法律意见 | 需持牌专业机构 |
| 个人身份信息明细（手机号、身份证、住址） | 最小必要原则，只接聚合或脱敏数据 |
| 抓取第三方平台数据 | 合规风险，只处理用户主动提供的数据 |
| 替用户美化结论 | 与产品立场冲突 |
