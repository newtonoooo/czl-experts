# 签约版权字段检查表

> 闸门：第六道 · 变现闸　｜　模块编号：G6-06　｜　适用：准备签约，需要看清合同里哪些条款时

## 一、这个模块解决什么

签约是全书收益结构的终点。这个模块给的是“签约时该问哪些问题”的清单，不构成法律意见。

## 二、判断标准

必须逐项确认的六个字段：

| 字段 | 要问清楚什么 |
|---|---|
| 授权范围 | 只授信息网络传播权，还是含改编权 |
| 独家性 | 是否独家、独家期限、到期后如何处理 |
| 分成基数 | 按什么口径算（流水？净收入？） |
| 结算周期 | 多久结一次、达到多少起结 |
| 完本要求 | 最低字数、最长断更天数、未达标后果 |
| 解约条件 | 什么情况下能解约、解约后版权归属 |

**纪律**：本模块不构成法律意见，重大条款请咨询专业人士。

## 三、操作步骤

1. 拿到合同，逐项对照上表找出对应条款；
2. 找不到的，标注“未约定”，未约定等于按对方解释；
3. 把六项写成自己的问题清单，逐条去问；
4. 得到答复后书面留存。

## 四、输出模板

```
授权范围：<...>
独家性：<...>
分成基数：<...>
结算周期：<...>
完本要求：<...>
解约条件：<...>
未约定项：<列表>
待确认问题：<列表>
```

## 五、三个常见误判

- **只看分成比例不看基数**：比例高但基数小，拿得更少。
- **忽略改编权**：改编权往往是长期价值最大的一块。
- **口头承诺当条款**：没写进合同的都不算。
