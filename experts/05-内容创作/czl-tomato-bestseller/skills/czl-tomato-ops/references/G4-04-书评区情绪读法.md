# 书评区情绪读法

> 闸门：第四道 · 爆发闸　｜　模块编号：G4-04　｜　适用：评论区很热闹，但不知道是好事还是坏事时

## 一、这个模块解决什么

评论区不是口碑，是体温。要读的是情绪极性、争论对象、以及有没有自发创作。三类信号指向完全不同的处理方式。

## 二、判断标准

| 信号 | 含义 | 处理 |
|---|---|---|
| 争剧情（谁该和谁在一起、谁对谁错） | 健康，说明读者投入 | 不动，甚至可顺着争论推进 |
| 争设定（战力不对、时间线乱） | 危险，说明逻辑失守 | 立刻补设定，别再辩 |
| 只夸不讨论 | 中性偏冷，读者没投入 | 补冲突，制造可站队的立场 |
| 自发二创/长评/角色应援 | 强信号 | 保护，不要打断 |
| 骂主角但不弃书 | 强信号（情绪绑架成功） | 不要改人设，这是资产 |

## 三、操作步骤

1. 抽样 30 条近期评论，按上表分类计数；
2. 看争论焦点落在剧情还是设定；
3. 若设定类占比超过三成，优先修逻辑；
4. 记录读者反复提到的疑问，写进后续章节作为伏笔回应。

## 四、输出模板

```
样本：<N> 条
剧情争论：<n>　设定争论：<n>　纯夸：<n>　二创：<n>
极性：健康 / 危险 / 冷
优先动作：<补设定 / 补冲突 / 保持不动>
```

## 五、三个常见误判

- **把差评当失败**：骂主角但不弃书，是最好的留存信号。
- **在评论区辩论设定**：越辩越显得没想清楚，用正文回应。
- **只看好评**：只看好评会得到“一切正常”的错觉。
