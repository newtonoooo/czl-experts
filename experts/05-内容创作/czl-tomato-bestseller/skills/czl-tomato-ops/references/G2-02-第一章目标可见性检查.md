# 第一章目标可见性检查

> 闸门：第二道 · 开局闸　｜　模块编号：G2-02　｜　适用：担心读者看完第一章不知道主角要干什么时

## 一、这个模块解决什么

检查第一章结束时，读者能否用一句话说出“主角想要什么”。说不出来，第二章的追读就没有动力。

## 二、判断标准

第一章结束时必须能让读者回答：

1. 主角**想要**什么（具体、可验证，不是“变强”而是“拿回被夺走的东西”）；
2. 谁**挡着**他；
3. 如果失败会**失去**什么。

三问缺一，目标不可见。

## 三、操作步骤

1. 读完第一章，遮住后文，自己回答三问；
2. 再找一个人读，让他回答同样三问；
3. 两人答案不一致 → 目标模糊；
4. 修法：把目标写成主角的一句台词或一个具体动作，放在第一章后半段。

## 四、输出模板

```
想要：<具体目标>
阻碍：<谁>
代价：<失去什么>
可见性：清晰 / 模糊 / 不可见
修法：<加哪句台词或哪个动作>
```

## 五、三个常见误判

- **把“变强”当目标**：太抽象，读者无法判断进度。
- **目标放在第 3 章**：超过第一章，留存已经掉完了。
- **目标只有作者知道**：作者心里清楚不算，读者读到才算。
