# 章末钩子密度体检

> 闸门：第三道 · 留存闸　｜　模块编号：G3-01　｜　适用：手里有几十章正文，想一次性看钩子够不够时

## 一、这个模块解决什么

把钩子从“感觉有”变成“统计有”。逐章打等级，算两个数：达标率和等级分布。这是留存闸最基础的一张体检表。

## 二、判断标准

| 指标 | 合格线 | 说明 |
|---|---|---|
| 达标率（★★★★ 及以上占比） | 前 10 章 ≥ 80%，日常期 ≥ 50% | 低于这条线，追读会慢性流失 |
| 三连低（连续 3 章 ≤ ★★★） | 0 处 | 三连低是明确的掉量信号 |
| 五连同型（连续 5 章同一类钩子） | 0 处 | 读者会预判，预判即弃书 |
| 无钩章（★） | 0 处 | 出现在任何位置都算硬伤 |

## 三、操作步骤

1. 取最近 30 章，逐章只读最后一个自然段；
2. 按 G2-04 的五级标准打等级；
3. 算出达标率，标出三连低与五连同型的位置；
4. 只改不达标章的最后 3 行，不动正文。

## 四、输出模板

```
样本：第 <A>–<B> 章
达标率：<X>%
三连低：第 <N>–<N> 章
五连同型：第 <N>–<N> 章
待改章号：<列表>
改法：<把结果改代价 / 把解答改半解>
```

## 五、三个常见误判

- **把每章都改成 ★★★★★**：等级没有起伏，读者会麻木，反而降低敏感度。
- **只在结尾加问句**：伪钩子，读者一眼看穿，还会觉得廉价。
- **改钩子不改后文**：钩子许了愿，下一章必须接住，否则透支信任。

## 六、关联模块

与 G2-04（分级标准）配套；改完用 G3-02 检查信息增量是否跟上。
