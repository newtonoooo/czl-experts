# 可拍场景与名场面埋点

> 闸门：第六道 · 变现闸　｜　模块编号：G6-05　｜　适用：决定要往改编方向走，需要在写作时就埋点时

## 一、这个模块解决什么

可拍场景不是写完再挑，是写的时候就有意识地造。这个模块给的是埋点标准，不是灵感。

## 二、判断标准

一个合格的可拍场景必须同时满足：

1. **有具体的物理空间**（在哪、什么时间、有什么物件）；
2. **有对抗**（两个人或两种立场在同一空间里冲突）；
3. **有一句能被记住的台词**；
4. **有一个视觉符号**（一个动作、一件物品、一个画面可以做成海报/片花）。

**密度要求**：每卷 ≥ 3 个合格场景，每 30 章 ≥ 2 个名场面。

## 三、操作步骤

1. 按四条标准检查已有章节，标出合格场景；
2. 数一数每卷密度够不够；
3. 不够的卷，在“转折点”处补一个场景；
4. 每卷挑一个场景做“片花版”改写（3 句话能说清的版本）。

## 四、输出模板

```
第 <N> 卷
合格场景：<N> 个（第 X 章 <场景名>）
名场面：<N> 个
缺口：<N> 个
补点方案：<在第几章补什么场景>
```

## 五、三个常见误判

- **把打斗当可拍场景**：没有对抗内核的打斗，拍出来是特效堆砌。
- **名场面靠人数堆**：人多不等于记得住，符号才记得住。
- **临时补拍点**：写到一百章再补，前面结构接不上。
