# 设定与战力自洽校验

> 闸门：第五道 · 续航闸　｜　模块编号：G5-03　｜　适用：读者开始挑逻辑漏洞时

## 一、这个模块解决什么

长篇最常崩的两处：战力随剧情浮动，规则随需要改变。这类崩塌是慢性的，等读者吵起来已经晚了。

## 二、判断标准

三项校验：

| 项 | 检查方式 | 不合格表现 |
|---|---|---|
| 战力 | 给主要角色做一张数值/等级表，按章回填 | 同一角色前后差距无解释 |
| 规则 | 把世界规则列成清单，逐条找出处 | 规则只出现一次，之后再没用过 |
| 时间线 | 按章记日期/季节/事件间隔 | 前后时间对不上 |

**判据**：任何一次“突然变强/突然失效”，正文里必须给出一句原因。

## 三、操作步骤

1. 建三张表：角色战力表、世界规则表、时间线表；
2. 按章回填，只填有变化的地方；
3. 标出无解释的变化；
4. 用一句话在正文补解释，或在后续章节补一个设定支撑。

## 四、输出模板

```
角色战力表：<N> 人，异常 <n> 处
规则表：<N> 条，仅出现一次 <n> 条
时间线：跨 <N> 天/月，冲突 <n> 处
优先修：<位置 + 补法>
```

## 五、三个常见误判

- **靠“他突破了”一句话糊过去**：突破要有前置铺垫。
- **规则越写越多**：新规则会稀释旧规则，总量要控制。
- **只查主角战力**：配角战力乱，读者一样出戏。
