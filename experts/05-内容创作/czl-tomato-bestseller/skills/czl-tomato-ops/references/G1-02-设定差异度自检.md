# 设定差异度自检

> 闸门：第一道 · 选题闸　｜　模块编号：G1-02　｜　适用：题材容量够，但担心“又是那本”的时候

## 一、这个模块解决什么

把“我这个设定很新”这种主观感觉，拆成四条可对照的差异点，判断读者能不能一句话说出你和同类不一样在哪。

## 二、判断标准

差异必须落在以下四层之一，越靠下越有效：

| 层级 | 差异类型 | 强度 | 说明 |
|---|---|---|---|
| 表层 | 设定名词不同（换个世界名、换个系统名） | 最弱 | 读者感知不到 |
| 中层 | 能力/规则不同（金手指机制变了） | 中 | 能撑前 30 章 |
| 深层 | 关系不同（谁和谁站在对立面） | 强 | 能撑全书的冲突 |
| 底层 | 视角不同（谁在讲这个故事，站在什么位置看） | 最强 | 同类题材也能写出完全不同的书 |

**判定**：差异只在表层 → 不算差异；差异落在深层或底层 → 成立。

## 三、操作步骤

1. 用一句话写出“这本书讲的是谁、想要什么、被什么挡住”；
2. 拿这句话去对照同类三本书，逐本看是否成立——如果三本都能套用，说明差异不成立；
3. 把差异点定位到上表的层级；
4. 若只落在表层，往下一层改：改关系，或者改视角。

## 四、输出模板

```
一句话核心：<谁 + 想要 + 被挡>
对照同类：A 书 / B 书 / C 书
差异层级：表层 / 中层 / 深层 / 底层
差异成立：是 / 否
若不成立，建议下沉到：<改关系 or 改视角的具体方案>
```

## 五、三个常见误判

- **把“设定更复杂”当差异**：复杂不等于不同，读者只记得住一句话。
- **用自己的熟悉度判断新鲜度**：你写了三个月，早就不觉得新了，读者是第一次见——要用同类对照，不用自我感觉。
- **差异放在配角身上**：主角层的差异才算数。
