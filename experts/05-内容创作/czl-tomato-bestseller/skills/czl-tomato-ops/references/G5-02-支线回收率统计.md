# 支线回收率统计

> 闸门：第五道 · 续航闸　｜　模块编号：G5-02　｜　适用：担心埋了很多线但都没收时

## 一、这个模块解决什么

逐条统计埋下的线有没有回收。回收率低会导致两个后果：读者觉得白看，你自己也失去可用素材。

## 二、判断标准

| 回收状态 | 定义 | 处理 |
|---|---|---|
| 已回收 | 明确交代了结果 | 归档 |
| 半回收 | 提过但没交代结果 | 补一句交代 |
| 未回收 | 埋下后再没出现 | 优先处理 |
| 失效 | 因剧情变化已无意义 | 明确作废，不要留 |

**合格线**：已回收 + 明确作废 ≥ 70%。低于这条线，读者会开始怀疑作者忘了。

## 三、操作步骤

1. 从第一章开始翻，列出所有“埋了但没交代”的点；
2. 逐条标注状态；
3. 未回收的按“能否在 3 章内交代”分类；
4. 不能交代的，明确作废：在正文里给一句交代，比永远悬着好。

## 四、输出模板

```
总埋点数：<N>
已回收：<n>　半回收：<n>　未回收：<n>　作废：<n>
回收率：<X>%
优先处理：<列表>
处理批次：<第几章到第几章补完>
```

## 五、三个常见误判

- **以为读者会忘**：核心读者记得比作者清楚。
- **一次性全交代**：变成流水账，分 3–5 章自然带出。
- **把作废当失败**：明确作废是专业操作，悬着才是失误。

## 六、关联模块

回收动作会占用张力余额，需与 G5-01 一起算。
