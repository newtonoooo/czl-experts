# 前三章高光前移重排

> 闸门：第四道 · 爆发闸　｜　模块编号：G4-03　｜　适用：流量进来了但首章跳出率高时

## 一、这个模块解决什么

把原本在第 5–10 章的高光片段，前移到前三章。这是窗口期唯一允许的大幅结构调整，做完就要冻结。

## 二、判断标准

前移的前提：

1. 该片段**不依赖前文设定**也能读懂；
2. 前移后**不影响主线逻辑**（只是时间位置变了）；
3. 前移后前三章的章末等级不降反升。

三条任一不满足，不做前移。

## 三、操作步骤

1. 列出前 10 章所有高光片段；
2. 筛出满足上面三条的候选；
3. 选一个移到第 2 或第 3 章；
4. 补平被抽走那章的缺口（用别的情节填，不要留空）。

## 四、输出模板

```
候选片段：<...>
前移目标章：第 <N> 章
依赖检查：通过 / 不通过
缺口填补方案：<...>
前移后三章章末等级：★★★★/★★★★/★★★★★
```

## 五、三个常见误判

- **把高潮前移当成“把结局提前”**：移的是一个小高光，不是主线结果。
- **前移后留坑不填**：被抽走的那章会变成废章。
- **窗口期反复前移**：每移一次，读者数据和你的判断都乱一次。
