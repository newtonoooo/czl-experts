# 变更日志 · czl-tomato-ops

遵循 [语义化版本](https://semver.org/lang/zh-CN/)：主版本号 = 架构变更，次版本号 = 新增模块或工具，修订号 = 修正与文案。

---

## v1.0.0 — 2026-10-27（首次发布）

**产品定位**：连载决策参谋。判断一本书该继续、该救、该压缩还是该完结，不代写正文。

### 新增 · 架构

- 确立**六闸门生命周期模型**：选题 → 开局 → 留存 → 爆发 → 续航 → 变现。
- 每道闸门统一四件套：判断标准 / 失守症状 / 抢救动作 / **退出条件**。
- 确立**结论卡**输出格式（7 项），任何判定必须按此结构交付，缺项视为未完成。

### 新增 · 知识模块（42 份）

- G1 选题闸 7 份（赛道容量、差异度、读者画像、同类表现、换核换壳、弃题清单、试水节奏）
- G2 开局闸 7 份（首屏压强、目标可见性、首次兑现、钩子分级、重写流程、死法 12 例、自检表）
- G3 留存闸 8 份（钩子密度、信息增量、三章起伏、对话规则、补钩子包、情绪三线、习惯窗口、掉量解剖）
- G4 爆发闸 6 份（窗口承接、加更平衡、高光前移、评论读法、流量归因、窗口排产）
- G5 续航闸 7 份（张力余额、支线回收、自洽校验、高潮分布、大纲三层、断更风险、完结止损）
- G6 变现闸 7 份（收益结构、有效阅读口径、奖励条件、改编评分、埋点标准、合同六字段、IP 长期价值）

### 修正（发布前测试发现）

- `gate1_rival_read.py`：输出中的转义百分号 `%%` 未生效，显示为字面双百分号 → 已修正。
- `gate3_hook_audit.py`：合格判定未包含"无钩章"条件，导致存在无钩章时仍判合格 → 已修正，现要求达标率、三连低、无钩章三项同时满足。

### 已知限制

- `gate2_pressure.py` / `gate3_hook_audit.py` / `gate4_sentiment.py` 采用关键词规则，属初筛工具，不能替代人工判读。
- `gate3_hook_audit.py` 依赖章节标题行识别，无标题的稿件无法切章。
- 本版本不含联网检索能力，平台政策类数据需人工核对后台。
