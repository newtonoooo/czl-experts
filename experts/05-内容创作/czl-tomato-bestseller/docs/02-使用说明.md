# 使用说明 · 番茄爆款小说操盘手

> 版本 v1.0.0　｜　适用平台：WorkBuddy 专家中心

---

## 一、安装

### 方式 A：从 zip 安装

1. 解压 `czl-tomato-bestseller-v1.0.0.zip`；
2. 把解压出的 `czl-tomato-bestseller` 整个文件夹放到：
   ```
   C:\Users\<你的用户名>\.workbuddy\plugins\marketplaces\my-experts\plugins\
   ```
3. 重启 WorkBuddy；
4. 左侧【专家】→【我的专家】，看到「番茄爆款小说操盘手」即安装成功。

### 方式 B：直接使用脚本（不装专家）

脚本是独立 CLI，解压后即可运行：

```bash
cd czl-tomato-bestseller/skills/czl-tomato-ops/scripts
python gate1_topic_scan.py --help
```

要求 Python 3.8+，无需安装任何第三方包。

## 二、四种用法（按你手里的东西选）

### 用法 1 · 只有一个题材想法

直接说：

> 「我准备开一本番茄连载，题材是（你的题材），主角是（一句话设定），先过选题闸。」

它会给你五维评分、最弱一维、以及"开 / 调整后开 / 弃"的结论。

### 用法 2 · 有正文，想检查开局

> 「这是我前三章，帮我过开局闸。」

它会检查首屏 200 字压强、第一章目标可见性、首次兑现时机、章末钩子等级，然后给出 8 项自检表结果。

### 用法 3 · 有后台数据，想知道为什么掉

> 「这是我的逐章留存（贴数据），完读率从第 40 章开始掉，帮我做掉量解剖。」

它会：找拐点 → 往前回看 1–3 章 → 按四类病灶归因（钩子弱 / 增量低 / 情绪断供 / 设定混乱）→ 给优先处理章号。

**关键原则**：原因永远在拐点之前，不在拐点那一章。

### 用法 4 · 写到中段写空了

> 「我写到 80 章，感觉主线越写越空，帮我盘一下该继续还是收尾。」

它会盘张力余额、支线回收率、战力自洽，然后按组合表给出三种处置之一：继续 / 压缩收尾 / 加速完结 / 立即完结。

## 三、脚本单独使用

### 常用四条

```bash
# 1. 选题五维评分（每维 1-5 分，5 最好）
python gate1_topic_scan.py --capacity 4 --diff 2 --reader 3 --rivals 4 --monetize 3

# 2. 章末钩子体检（需要章节标题行）
python gate3_hook_audit.py --file 我的稿子.md --window 30

# 3. 掉量解剖（每行：章号,留存率）
python gate3_drop_autopsy.py --file 留存.csv --top 3

# 4. 稿件导出
python draft_exporter.py --file 我的稿子.md --to html
```

### 输入文件格式

| 脚本 | 文件格式（每行一条） |
|---|---|
| `gate1_rival_read.py` | `书名,是否更新(1/0),字数万,是否进推荐(1/0)` |
| `gate3_info_gain.py` | `章号,增量类型...`（事实/关系/能力/处境/认知/情绪） |
| `gate3_drop_autopsy.py` | `章号,留存率` |
| `gate4_sentiment.py` | 一行一条评论 |
| `gate5_tension.py` | `承诺名,预计兑现章,难度(高/中/低),是否兑现(1/0)` |
| `gate5_thread_close.py` | `支线名,状态`（已回收/半回收/未回收/作废） |
| `gate5_consistency.py` | `角色,章号,数值,是否有解释(1/0)` |
| `gate6_revenue.py` | `分项名,金额` |

### 返回码约定

| 返回码 | 含义 |
|---|---|
| 0 | 正常；判定为"合格/通过" |
| 1 | 运行正常，但判定为"不合格"（可据此做 CI 判断） |
| 2 | 输入错误（文件不存在、字段不足、参数越界） |

## 四、判断结果怎么读

每次判定都是这个格式：

```
【闸门】第 3 道 · 留存闸
【结论】抢救
【依据】
  1. 第 14–17 章连续四章章末等级 ≤ ★★★
  2. 第 15 章信息增量为 0（只有情绪）
  3. 第 18 章起留存斜率变陡
【最弱一环】第 15 章，主角一整天没有任何主动选择
【抢救动作】
  1. 第 15 章补一个不可逆的小代价（今天可做）
  2. 第 16–17 章章末改为"代价"收尾
  3. 第 18 章开头接住第 17 章埋的问题
【退出条件】改完这三处，若 7 天后留存仍无回升，进入切书评估
【本次假设】假设你说的"完读率"指首章到末章的留存率
```

**读法**：先看【结论】，再看【最弱一环】，最后看【抢救动作】。动作永远按优先级排，第一条是当天能做的。

## 五、常见问题

**Q：它会不会替我把书写完？**
不会。它给判断和动作清单，正文必须你自己写。核心人设、主线冲突、关键转折它不代笔。

**Q：脚本的判定准不准？**
`gate2_pressure.py`、`gate3_hook_audit.py`、`gate4_sentiment.py` 用关键词规则，是**初筛**，必须人工复核。其余脚本是纯算术（比例、缺口、回收率），结果可靠。

**Q：为什么它不给具体金额？**
平台金额与档位变动频繁，写死必然过时、误导。所有涉及钱的回答都让你回后台核对当月公告。

**Q：能不能判断"这本能不能爆"？**
不能，也不会假装能。没有正文、没有数据、没有同类样本时，"能不能爆"是无依据的猜测。它能给的是：这个题材在五个维度上各缺什么。

**Q：写完的书能用来做改编评估吗？**
能。用 G6-04 五维评分（场景可视度、单元结构、名场面密度、人物辨识度、题材适配），15 分以上才建议主动推。
