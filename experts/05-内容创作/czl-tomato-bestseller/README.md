## 一、它是干什么的

市面上的写作工具大多在解决"怎么写得更好"。这个产品解决另一个问题：

**这本书还值不值得写下去。**

它不给文采建议，不代写正文，只做三件事：

1. **在投错时间之前叫停**——开题前先算，命中率不够就劝你别开；
2. **在崩盘之前定位**——掉量了，告诉你崩在第几章、哪一段、什么原因；
3. **在该收的时候收**——写到中段写空了，帮你判断压缩收尾还是立刻完结。

判断风格是**三选一**：过 / 抢救 / 退出。没有"再观察观察"这个选项。

## 二、六道闸门

一本书从开题到完结要过六道闸，每道闸统一四件套：判断标准、失守症状、抢救动作、**退出条件**。

| 闸门 | 回答的问题 | 什么时候进来 |
|---|---|---|
| **G1 选题** | 这本书值不值得开 | 只有一个题材想法 |
| **G2 开局** | 前三章留不留人 | 开篇没人看 |
| **G3 留存** | 第 10–30 章能不能养成习惯 | 完读率在掉 |
| **G4 爆发** | 推荐流量接不接得住 | 上推荐了、流量来了 |
| **G5 续航** | 长篇会不会崩 | 写到中段写空了 |
| **G6 变现** | 怎么变成钱与资产 | 关心收益与改编 |

**不许跳闸**：开局没过不谈留存，留存没过不谈变现。不同闸门的问题解法互相冲突，混在一起就是灾难。

## 四、快速开始

### 安装

把整个目录放到专家目录，重启客户端：

```
C:\Users\<你的用户名>\.workbuddy\plugins\marketplaces\my-experts\plugins\czl-tomato-bestseller\
```

或用打包好的 zip 解压到该位置。

### 脚本单独使用

不装专家也能用，脚本是独立 CLI：

```bash
cd skills/czl-tomato-ops/scripts

# 选题五维评分（每维 1-5 分）
python gate1_topic_scan.py --capacity 4 --diff 2 --reader 3 --rivals 4 --monetize 3

# 章末钩子体检
python gate3_hook_audit.py --file 我的稿子.md

# 掉量解剖
python gate3_drop_autopsy.py --file 留存.csv

# 导出稿件
python draft_exporter.py --file 我的稿子.md --to html
```

要求 Python 3.8+，零第三方依赖。每个脚本都有 `--help`。

- `gate2_pressure.py`、`gate3_hook_audit.py`、`gate4_sentiment.py` 用关键词规则判定，只是初筛；
- `gate3_hook_audit.py` 需要章节标题行（`第N章` 或 `## 第N章`）才能切章；
- 不含 docx 导出（需第三方库，为保持零依赖暂不引入）；
- 所有判断阈值是经验值，不是平台官方标准。
