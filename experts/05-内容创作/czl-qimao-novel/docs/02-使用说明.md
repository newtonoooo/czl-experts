# 使用说明 · 七猫爆款小说生成专家

## 一、装在哪里

专家目录（本机）：

```
C:\Users\丛自龙\.workbuddy\plugins\marketplaces\my-experts\plugins\czl-qimao-novel\
```

WorkBuddy 只在专家目录下扫描，**放到别处不会被识别**。打包文件在 `my-experts/dist/czl-qimao-novel.zip`，可直接用于导入。

## 二、怎么开始

打开专家，按你现在的位置选一句话：

| 你的状态 | 第一句话怎么说 |
|---|---|
| 只有想法 | 「我有个女频年代重生的想法，先过选品站」 |
| 有稿没投 | 「帮我看看这份大纲和两万字够不够投七猫」 |
| 已签约卡数据 | 「十万字均留 9%，帮我算档位和缺口」 |
| 要谈签约 | 「日更 6000 能撑住吗，帮我把收入算清楚」 |

专家会先问四个问题（频道题材、核心爽点、日更能力、当前阶段），答完就开工。答不上来的可以先空着，但对应那一站只能给范围，不能给结论。

## 三、七站怎么走

### Q1 选品

告诉专家题材，它会查主收盘、给对标书、做五维评分。

判定为「返工」时，优先改**壳**不改**核**。换壳成本最低：把"总裁"换成"厂长"，把"豪门"换成"供销社"，情绪不变，读者群就换了。

### Q2 包装

要五个书名、三个简介。别一次只让起一个名字——起名的本质是下注，一次只下一注没法比较。

### Q3 结构

最重要的是**结局方向**。说不清最后一场戏是什么，说明故事还没成立，先别写正文。

### Q4 样章

前 200 字是硬指标。专家会指出缺"有人/有事/有不对劲/有具体物"里的哪一项，缺哪项就只改开头。

### Q5 上架

三万字前把分类、标签、简介、存稿四件事确认掉。分类选错，等于把书放在错误的货架上。

### Q6 档位

给三个数：十万字均留、日阅读 UV、频道类型。专家会告诉你落在第几档、单价多少、离下一档差几个点。

**注意 UV 门槛**：15% 以上的档位都有 UV 要求，均留够了 UV 不够，单价拿不满。

### Q7 现金流

给日更字数、千字价、签约模式。专家会算月收入，并告诉你四个日更档位的差别，以及断更的代价。

## 四、脚本怎么用

如果直接用命令行（在 `skills/czl-qimao-ops/scripts/` 下）：

```bash
python q1_topic_fit.py --channel nv --genre 年代重生 --scores 4,3,5,3,5
python q2_title_pack.py --titles "书名一" "书名二"
python q3_outline_audit.py --file 大纲.md --words 1200000
python q4_sample_gate.py --file 前三章.md
python q6_retention_tier.py --retention 9 --uv 300 --type normal
```

不需要装任何第三方库。Windows 下用 `python`，macOS/Linux 用 `python3`。

## 五、常见问题

### Q：导入到另一台电脑后，专家列表里小图标变成文字了

这不是你这台机器的问题，也不是包坏了。三种原因，按顺序查：

1. **压缩包根目录多套了一层。** 正确结构是压缩包解开后第一层就是 `.codebuddy-plugin/`、`agents/`、`avatars/`、`skills/`。如果解开后还有一层同名文件夹，导入后能找到名字却找不到头像。
2. **点开头的目录被丢了。** `.codebuddy-plugin` 是隐藏目录，部分解压工具或网盘转存会跳过点开头的文件。丢了它，专家只剩一个名字，图标与描述都是空的。
3. **客户端缓存了旧卡片。** 之前导入过同名专家，卡片缓存里 `avatar` 是空字符串，重导不会刷新。彻底退出客户端再进一次；仍不行就把旧目录删掉重导。

本包已按官方规范处理：头像文件名固定为 `avatars/expert.png`，字段写 `"avatar": "avatars/expert.png"`（不带 `./`），图片为 512×512、RGB、PNG、474KB。导入后核对这个文件在不在，是最快的判断方法。

### Q：脚本跑不了怎么办

看报错。绝大多数是路径里有空格没加引号，或者文件编码不是 UTF-8。脚本会自动试 UTF-8 与 GBK，两者都不是就报错让你另存。

跑不了就按参考卡手算，**不要编结果**。

### Q：专家给的分档和我在后台看到的不一样

平台会调规则。以作者后台为准，本包的表格是 2025-02 版本的公开数据。发现不一致就告诉专家"官方页更新了"，它会重新查。

### Q：能不能让它直接写整本书

能写章节，但不做整本代写。原因写在 `R8`：平台已对纯 AI 批量生产建立识别机制，且"工作室"式投稿是明文禁止的。结构、判定、算账归工具，正文归你。

## 六、五本台账

长篇连载必须维护，否则写到 60 章一定穿帮：

1. **人物账**：谁、要什么、怕什么、在哪一章死/退场。
2. **地点账**：出现过的地方、方位关系。
3. **伏笔账**：埋什么、第几章埋、第几章收。
4. **战力/资源账**：每一级的能力边界、突破条件。
5. **时间线**：故事内时间与章节对应。

每完成一批章节更新一次。台账不更新等于没写。

## 七、边界

- 不承诺签约、不承诺收入、不承诺推荐位。
- 不提供法律意见，合同条款只提醒你看哪三处。
- 不做跨平台规则换算。
- 不代写、不洗稿、不帮规避查重。
