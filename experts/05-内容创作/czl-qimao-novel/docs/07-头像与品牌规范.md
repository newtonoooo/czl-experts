# 头像与品牌规范

## 设计决策

| 项目 | 决策 | 理由 |
|---|---|---|
| 形态 | 品牌徽标，不含人物 | 专家列表页头像约 48px，人物头像在这个尺寸下五官糊成一团；符号化图形识别度更高，也避免"像老登"的观感 |
| 主符号 | 数字 7，由一张折起的纸构成 | 7 对应七猫；折纸对应"稿纸/书页"，一眼看出行业；折痕只有一处，缩到 48px 仍成立 |
| 配色 | 深墨蓝 #12203A + 暖金 #E8A33D→#C9822B | 深蓝压住专业感，金色给"爆款/收益"的联想；与浅色主题的列表页对比度足够 |
| 构图 | 满幅、无边框、四周留白 8% | 满幅避免圆形裁切后出现白边；留白保证小尺寸不贴边 |
| 材质 | 纸纤维纹理 + 单向柔光 | 纯扁平会像通用图标，加一点纸张质感与专业出版物的调性一致 |
| 禁止元素 | 猫、爪印、动物、人物、文字、水印 | 猫是平台方品牌联想，商用头像使用动物造型有混淆风险；文字在 48px 下不可读 |

## 生成参数（可复现）

- 工具：ImageGen
- 尺寸：512 × 512
- 风格描述：flat vector brand emblem, numbered 7 built from one folded paper sheet, deep ink navy background, amber-gold gradient, full-bleed, no border
- 后处理：裁切 488×488 区域去除工具水印，双线性重采样回 512×512，PNG（RGB）

## 文件规格

| 项 | 值 |
|---|---|
| 路径 | `avatars/expert.png` |
| 尺寸 | 512 × 512 |
| 色彩类型 | RGB（colortype 2，无 alpha） |
| 大小 | 474 KB（上限 500 KB） |
| 命名 | `expert.png`（平台约定名，与 50+ 个在架专家一致） |

## 为什么文件名必须是 expert.png

平台的专家选择器在拿不到头像时会退化成"显示名称首字"的文字占位。触发条件是解析到的专家记录里 `avatar` 为空或路径取不到文件。

官方规范允许自定义文件名，但在架专家的实际做法几乎统一为 `avatars/expert.png`。为了让"导入到另一台机器"这条路径最不容易出问题，本包采用约定名，且字段值不带 `./` 前缀：

```json
"avatar": "avatars/expert.png"
```

## 品牌使用边界

- 头像可用于本专家在平台内的展示，以及开发者的作品集说明。
- 不得改动后用于其他产品，造成来源混淆。
- 图标与"七猫"文字商标无关联，本产品非七猫官方产品，也不代表七猫立场。

## 可替换说明

换图只需替换 `avatars/expert.png`，保持 512×512、PNG、≤500 KB，字段无需改动。
