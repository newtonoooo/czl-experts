# 更新日志

格式：语义化版本。`MAJOR` 不兼容改动，`MINOR` 新增能力，`PATCH` 修正。

## [1.0.0] - 2026-10-30

首个公开发布版本。独立开发，非任何现有专家包的改名或改写。

### 新增

- **七站流水线**：Q1 选品、Q2 包装、Q3 结构、Q4 样章、Q5 上架、Q6 档位、Q7 现金流。每站产出带判定的工单（放行/返工/止损），并写明下一站进入条件。
- **专家主提示词** `agents/czl-qimao-novel.md`：含七站的动作、判定规则、异常处理、输入输出规范、数据口径三分法与禁止事项。
- **技能层** `skills/czl-qimao-ops/`：
  - `SKILL.md`：执行层说明与脚本用法。
  - 8 张参考卡：主收盘图谱、投稿包规范、书名与简介语法、开篇压强四件事、留存分档与跃迁、全勤与产能、节点作战、审核与合规红线。
  - 7 张工单模板。
  - 6 个离线脚本（纯标准库）：
    - `q1_topic_fit.py` 题材匹配与五维判定
    - `q2_title_pack.py` 书名五类语法体检
    - `q3_outline_audit.py` 大纲八项结构体检
    - `q4_sample_gate.py` 样章压强与钩子体检
    - `q6_retention_tier.py` 留存档位定位（官方分档表）
    - `q7_cash_flow.py` 全勤与保底现金流核算
- **原创头像** `avatars/expert.png`：数字 7 折纸徽标，深墨蓝 + 暖金，512×512，474 KB。
- **文档**：产品规格说明、使用说明、平台展示文案、文件清单与开发记录、功能测试报告、商业发布风险清单、头像与品牌规范。

### 设计要点

- 把"编辑签约"前置为第一道门槛，顺序上先判断能不能签，再决定写不写。
- 把留存从"趋势"改成"档位"：按官方分档表定位单价与缺口，而不是笼统建议提升追读。
- 新增财务层：全勤档位、20 万字上限、每月一天请假、断更导致整月全勤归零，全部可计算。

### 已知限制

- 分档数据为 2025-02 版官方福利页，平台调整后需同步。
- 脚本只做规则匹配与算术，不做文本审美判断。
- 不做跨平台规则换算。
- 未在 macOS / Linux 实机测试，仅在 Windows 11 + Python 3.13 验证。

### 未包含（刻意不继承）

- 英文摘要输出、Mermaid 关系图、`init-novel.sh` 初始化脚本、`.learnings/` 目录结构。这些属于同类产品的具体实现，本版本用独立的工单体系与五本台账替代。
