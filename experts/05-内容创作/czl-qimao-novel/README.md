# 七猫爆款小说生成专家

一个针对**七猫中文网**连载场景的独立开发专家。不做"帮你写小说"，做的是把一本书送过七猫这条链路上真正会卡死人的三道门：编辑签约、留存档位、全勤现金流。

- 开发者：虫志龙（47190078@qq.com）
- 版本：1.0.0
- 类型：Agent 型专家
- 依赖：无。纯提示词 + 参考文档 + 六个 Python 标准库脚本，离线可跑
- 本产品为独立开发，非七猫官方产品，与七猫无合作关系

## 它解决什么

| 你会卡的地方 | 它给什么 |
|---|---|
| 不知道题材在七猫能不能站住 | 主收盘匹配 + 五维评分 + 对标书结构 + 止损线 |
| 投稿没回音 | 六段式大纲 + 两万字样章体检 + 编辑红笔十条 |
| 均留低但不知道差多少 | 官方分档表定位：第几档、单价多少、差几个点、缺多少 UV |
| 收入算不清 | 四个日更档位的现金流对比 + 断更真实代价 |
| 写到一半崩了 | 节点作战表 + 掉点定位法（卷→章→段）+ 止损判定 |

## 七站流水线

```
Q1 选品 → Q2 包装 → Q3 结构 → Q4 样章 → Q5 上架 → Q6 档位 → Q7 现金流
```

每站产出**一张工单**：站号、日期、输入摘要、判定（放行/返工/止损）、依据、交付物、下一站进入条件。判定只有三种，没有"基本可以"。

## 脚本

```bash
python q1_topic_fit.py --channel nv --genre 年代重生 --scores 4,3,5,3,5
python q2_title_pack.py --titles "书名一" "书名二"
python q3_outline_audit.py --file 大纲.md --words 1200000
python q4_sample_gate.py --file 前三章.md
python q6_retention_tier.py --retention 9 --uv 300 --type normal
python q7_cash_flow.py --daily 5000 --price 20 --mode baodi --plan 1200000
```

要求 Python 3.8+，无需安装任何第三方库。

## 数据口径

- **官方口径**：分成模式、全勤分档、20 万字上限、请假规则、稿费发放时间，引自七猫官方福利页（2025-02 版本），以作者后台为准。
- **经验值**：签约通过率、内投字数、测试节点等，明确标注"经验值，非官方"。
- **推算**：收入、缺口、风险，标注"推算"并写出假设。

三者不混着说。把行业传言当平台规则，是会让人做错决定的。

## 它不做什么

- 不承诺签约、不承诺收入、不承诺推荐位
- 不代写整本、不洗稿、不帮规避查重
- 不参与"工作室"式多人合写（七猫明文禁止）
- 不做其他平台的规则换算

## 安装

```

```

或直接导入打包文件 `dist/czl-qimao-novel.zip`。

导入后如果列表里没有图标、只显示文字，见 `docs/02-使用说明.md` 第五节。
