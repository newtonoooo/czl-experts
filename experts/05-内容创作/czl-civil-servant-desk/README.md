# 案头 · 公务员工作助理

给机关里要交件的人用的公文助手。**第一句话说完，第一条回复就是成稿。**

> 开发者：虫志龙　｜　47190078@qq.com　｜　版本 2.0.0　｜　包名 `czl-civil-servant-desk`

---

## 它只做一件事，但要做到底

**把稿子写出来，写成能直接进 OA 的样子。**

不讲课、不列方法、不先问一堆问题。信息不全就按最合理的写法先写一版，缺的地方在文中标 `【待补：要什么】`；写完自己过一遍，把问题改掉再交，而不是丢给你一张问题清单。

## 三条铁律

1. **第一条回复就是成稿**——回复的第一个字符是标题，前面不出现"好的""以下是""我来帮你写"；不许先提问。
2. **不编事实**——数据、人名、文号、政策依据只能来自你或你给的文件。结构可以推测，数字不能推测。
3. **不谎报**——Word 没生成就说没生成，校验没跑就不说"已校验"。

## 能写什么

法定 15 种：请示、报告、通知、通报、意见、决定、批复、函、纪要、决议、公报、公告、通告、议案、命令。
事务 7 种：讲话稿、工作方案、工作总结、述职报告、信息简报、调研报告、对照检查材料。

日常用得最多的是这四个：**请示（要钱要人）、报告（报情况）、通知（布置活）、函（平级商洽）**。

## 三个它比通用模型多做一步的地方

**一、上级文件落地。** 你把上级通知贴给它，它先把要求拆成条目（承接／配合／不适用），再写本级稿；报送对象、时间、格式三样一定出现在正文里。三条禁则：不加码、不抢功、不漏报送。

**二、口径与数据。** 同一指标全文只允许一个数；每个数带单位、带口径（时点／范围／来源）；不写"约""左右"；不换算单位。

**三、答问准备。** 你说"领导要问"，它另出一册：引用清单、专有名词、数据来源与口径、可能被追问的 5—8 个问题与建议答法、依据链、风险提示。**这一册不进附件**，是给你自己拿着用的。

## 长什么样

```
（稿件全文：标题 → 主送 → 正文 → 署名 → 日期）

——
核校备忘
· 按【通知】写，下行文，约 900 字
· 依据文号、台账格式两处待补，已在文中标出
```

备忘最多 4 行。没有"如需修改请随时告知"，没有"希望对你有帮助"。

## 出 Word

有 Python 环境时，按 GB/T 9704-2012 生成 docx（A4、页边距 37/35/28/26 毫米、三号仿宋、行距 28.9 磅、页码"— N —"）：

```bash
python bin/docx_export.py 定稿.txt --out 正文.docx
python bin/docx_check.py 正文.docx     # 结构校验，退出码 0 才算生成成功
```

没有 Python 也不影响交稿：它会给你稿面格式全文（可直接存成 txt）和一套版式参数，说明"本机未生成 docx，按上表套一下"。

## 装与自检

```bash
# 装：放在专家目录下即可被识别
~/.workbuddy/plugins/marketplaces/my-experts/plugins/czl-civil-servant-desk/

# 自检（15 项，exit 0 = 装上即可运行）
python bin/selftest.py
```

自检查什么：元数据一致、启动注入量、三条硬规则在位、docx 导出与校验、样稿要素。不联网、不装第三方包。

**为什么只有 1 个技能、2 个可选脚本**：启动时注入的指令越多，模型越容易跑偏。上一版 4 个技能合计 2.2 万字符，这一版压到 7.9 千。

## 不做的

不编数据；不处理涉密件（见密级即停）；不定密级、发文字号、印发范围（这三样办公室定）；不代签发；不评价政策本身。
