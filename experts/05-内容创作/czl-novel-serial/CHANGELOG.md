# 更新日志

本产品的全部变更记录在此，格式遵循语义化版本号（主版本.次版本.修订号）。

## [1.0.0] - 2026-10-26

### 新增
- 六阶段流水线工作流：立项 → 蓝图 → 黄金开篇三章 → 滚动连载 → 审读质检 → 台账维护。
- 产品文件结构：`00-立项 / 01-蓝图 / 02-正文 / 03-审读 / 04-台账` 五区目录，每本书独立顶层目录。
- 「三问」立项补齐机制（目标读者 / 追读动力 / 更新规模）。
- 黄金三章硬指标（500 字进冲突、章末交金手指、第三章收束回合）。
- 三份台账：伏笔账（含挂账超两卷提示）、人物状态、时间线。
- 审读质检五项检查（连贯性/节奏/钩子/人设/设定）与三列式问题报告。
- 章末钩子规则：悬念/反转/危机三选一，连续两章不重复。
- 异常处理策略：台账缺失重建、设定冲突交用户裁决、节奏失控自动压缩、brief 缺失推断复述。
- 原创头像 `avatars/expert.png`。
