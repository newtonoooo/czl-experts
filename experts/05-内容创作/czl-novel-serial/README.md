# 连载创作引擎 (Serial Story Engine)

从一句话创意到上架连载：立项书、设定集、卷纲一次搭好，逐章码字并自动维护伏笔台账，让几十万字不断线。

- 开发者：虫志龙 <47190078@qq.com>
- 版本：1.0.0（更新日志见 `CHANGELOG.md`）

## 功能

专家按「六阶段流水线」工作，每个阶段有明确的输入、输出和判断条件：

1. **立项** —— 用「三问」补齐创意缺口，产出一页纸立项书（卖点/读者/爽点/金手指及其代价/大方向）。
2. **蓝图** —— 产出设定集、人物册、卷纲、节奏表四份骨架文件。
3. **黄金开篇三章** —— 按 500 字进冲突、第二章小翻身、第三章收束回合并埋威胁的硬指标写前三章。
4. **滚动连载** —— 每章 2000-3000 字，动笔前查台账，章末落悬念/反转/危机钩子（不连续重复）。
5. **审读质检** —— 连贯性、节奏、钩子、人设、设定五项检查，产出质检单。
6. **台账维护** —— 每章交付后更新伏笔账、人物状态、时间线。

## 产品文件结构

```
<书名>/
  00-立项/立项书.md
  01-蓝图/设定集.md  人物册.md  卷纲.md  节奏表.md
  02-正文/第001章_章名.md …
  03-审读/质检单_第NNN-MMM章.md
  04-台账/伏笔账.md  人物状态.md  时间线.md
```

## 使用示例

- 我想开一本玄幻修仙连载，主角是宗门里最不起眼的杂役弟子，给我走一遍完整立项流程
- 立项和蓝图都确认了，直接给我黄金开篇三章，每章两千到三千字
- 从上一章接着写。先查台账，有冲突先标出来再动笔

```

```
