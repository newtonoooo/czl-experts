# 更新日志

语义化版本：主版本变更表示能力范围或输出契约不兼容；次版本新增能力；修订号修正问题。

## [2.0.0] — 2026-10-26

**重写为论文写作全流程产品。** 1.x 以流程管控（八阶段闸门 + 状态机）为核心，
写作能力偏薄；2.0 改为以十二个写作模块为核心，每个模块直接产出可用文字。

### 新增

- **主提示词重写**：写手型定位、"先给文字再给说明"、六条铁律、12 模块能力矩阵、
  写作执行规范（四步法 + 段落配方 + 语体要求）、输出格式、脚本调度、收口规则。
- **15 份写作手册**（1916 行）：写作总则、选题开题、文献综述、结构提纲、摘要关键词、引言、
  方法章、结果图表、讨论结论、中文润色、英文润色、降重查重、引用格式、答辩投稿、文体差异。
  每份含：段落配方 → 句式库 → 示范段落 → 常见错误对照。
- **13 份写作模板**（948 行）：题目候选表、开题报告、文献矩阵、摘要模板、分章写作卡、
  中文学术句式库（54 条）、英文学术句式库（47 条）、润色对照表、查重整改表、
  格式核对清单、答辩逐页讲稿、投稿信（3 种场景）、审稿回复（含不采纳写法）。
- **6 个写作工具**（1539 行，纯标准库）：
  - `wordstat.py` 按章字数与配比、图表计数、目标对比。
  - `abstract_check.py` 摘要五要素、字数、关键词质量、中英文数字一致性。
  - `style_lint.py` 套话密度、长句、连续短句、连接词连用、段首雷同、英文被动、重复词。
  - `cite_format.py` GB/T 7714 ↔ APA ↔ MLA ↔ IEEE 互转 + 缺项与重复检查。
  - `dup_scan.py` 与源文本 n-gram 重合比对，定位未标注重复。
  - `figtable.py` 图表编号重复/跳号/悬挂引用。
- **54 个测试用例**（523 行）+ 2 份夹具（示例论文、对照源文本），全部通过。

### 移除

- `gate.py` 八阶段状态机与 `thesis-state.json`（用户反馈：不要流程框架，要写作功能）。
- `evidence_ledger.py` / `revision_track.py`（主张台账、修订追踪表）。
- 旧版 `references/` 12 份流程规范与 `templates/` 9 份表格。

### 变更

- 展示定位：论文写作架构师 → **论文写作全流程导师**；英文 End-to-End Thesis Writing Coach。
- 三条示例问法改为写作类（写方法章、定题目、改摘要）。
- 标签：论文全流程写作 / 分章成稿 / 润色与格式。

### 已知限制

- 引用转换不处理拼音与刊名缩写，需人工调整（输出逐条标注）。
- 题注与摘要要素识别为启发式，特殊模板可能漏判。
- 不覆盖 SPSS / LaTeX 的软件层问题。
