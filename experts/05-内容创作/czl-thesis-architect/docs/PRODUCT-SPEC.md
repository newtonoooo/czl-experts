# 产品规格说明（2.0.0）

编写：虫志龙　日期：2026-10-26

本版按用户反馈重做：**要论文写作功能本身，不要流程框架。** 因此本规格以"能写什么、写出什么"
为核心，功能清单逐项列到可交付物级别。

---

## 1. 目标用户

| 用户 | 场景 | 卡在哪 |
|---|---|---|
| 本科生 | 毕业论文 8000—15000 字，2—4 个月 | 不会写研究问题；综述写成读书笔记；摘要写成导语 |
| 硕士生 | 学位论文 3—5 万字；或期刊投稿 | 方法章交代不清；结果夹叙夹议；返修改不完 |
| 课程/学年论文作者 | 1—2 周 | 时间紧，需要直接可用的段落 |
| 需要指导学生的老师 | 批改与讲评 | 同类问题反复出现，缺可复用的改法 |
| 跨语言写作者 | 中文写、英文投 | 中式英语、术语不一致、引用格式要换成目标刊物 |

**非目标用户**：要代写整篇并当作自己原创的人；要伪造数据或规避查重的人；要软件安装排障的人。

## 3. 输入规范

| 输入 | 必需性 | 缺省处理 |
|---|---|---|
| 要写哪一部分 / 已有草稿 | 必需 | 无输入时给四入口让用户选 |
| 研究主题、数据、样本信息 | 强烈建议 | 缺则用 `〔待补：…〕` 占位，继续写可写的部分 |
| 学校模板 / 期刊要求 | 建议 | 按 GB/T 7714-2015 与通用惯例，标注"以模板为准" |
| 字数要求 | 建议 | 按章节惯例比例（引言 8—10%、综述 20—25%……） |
| 文献原文 | 可选 | 无原文时只做结构与格式处理，不判断引用是否支撑论断 |

## 4. 输出规范

1. 默认输出**可粘贴的正文**（Markdown），不是建议清单。
2. 正文之后附三样：占位符清单、需核验的推断、下一段/下一章接什么。
3. 改稿给对照表：原文 / 改后 / 改了什么（≤8 字）/ 为什么。
4. 字数到位（要求 ±15%），标题按层级编号。
5. 所有推断标 `〔核验：…〕`，所有缺口标 `〔待补：缺什么｜从哪拿〕`。

## 5. 工具能力（6 个，纯标准库）

| 工具 | 输入 | 输出 | 判定依据 | 退出码 |
|---|---|---|---|---|
| `wordstat.py` | 正文 md | 分章字数/占比/段落/图表 + 偏差 | 章标记 + 计数 | 0 / 2 |
| `abstract_check.py` | 正文 md | 摘要字数、五要素、关键词、数字一致性 | 关键词启发式 + 数字集合比对 | 0 / 1 / 2 |
| `style_lint.py` | 正文 md | 套话密度、长句、连续短句、被动、重复词 | 词表 + 阈值 | 0 / 1 / 2 |
| `cite_format.py` | 参考文献 | 问题清单 + 转换后条目 | 正则要素 + 四种样式模板 | 0 / 1 / 2 |
| `dup_scan.py` | 正文 + 源文本 | 重合段清单（行号/长度/来源）+ 覆盖率 | 字符 n-gram 比对 | 0 / 1 / 2 |
| `figtable.py` | 正文 md | 题注清单 + 编号与引用问题 | 行首模式 + 引用模式 | 0 / 1 / 2 |

技术约束：Python 3.8+ 标准库；零第三方依赖；不联网；支持中文路径；自动尝试
utf-8-sig / utf-8 / gb18030 / utf-16。

## 6. 质量、速度、稳定性

| 维度 | 要求 | 实测 |
|---|---|---|
| 写作质量 | 段落有判断句；引用支撑所在判断；无空转句式 | 手册给配方与 30 组病句对照，脚本可复查 |
| 不编造 | 文献/数据/规定一律不造 | 提示词硬约束 + 占位符 + 摘要与引用检查兜底 |
| 速度 | 单文件检查 ≤2 秒（1 万字级） | 1859 字示例 <0.1 秒 |
| 稳定性 | 缺文件/空文件给中文提示与错误码，不抛栈 | 六个工具已覆盖 |
| 可维护 | 单一职责 + 共享 `_common.py`；改动必须同步测试 | 54 个用例覆盖六个工具与端到端 |

## 7. 与 1.0 的差别（为什么重做）

| | 1.0 | 2.0 |
|---|---|---|
| 核心 | 八阶段闸门 + 状态机 | 十二个写作模块 |
| 用户拿到 | 状态文件、台账 CSV、任务书 | 摘要、章节正文、改后段落、参考文献表 |
| 工具 | 流程检查（gate / ledger / track） | 写作检查（字数 / 摘要 / 语言 / 引用 / 重复 / 图表） |
| 适合 | 想被管住进度的人 | 想直接拿到文字的人 |

## 8. 非目标

不代写整篇并隐瞒；不做查重/AIGC 规避；不代检索付费库；不预测录用与通过率；
不处理 SPSS/LaTeX 安装与编译；不核验文献真实性（无联网比对能力）。

## 9. 验收标准

1. 12 个模块每个都有手册，且手册含配方 + 句式库 + 示范 + 错误对照。
2. 每个模块能独立产出交付物，不需要其他模块先完成。
3. 六个工具在正常/异常/边界输入下行为符合退出码约定，54 个用例全通过。
4. 专家包通过平台 `validate_expert.py`（0 错误）。
5. 所有对外文案与实际功能一致，无虚假资质或合作表述。
