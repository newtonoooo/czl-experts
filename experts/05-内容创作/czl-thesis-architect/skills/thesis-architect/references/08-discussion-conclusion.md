# W8 讨论与结论

产出：讨论正文（1200—2500 字）+ 结论 + 分层建议 + 研究局限。

## 一、讨论与结果的分工

| | 结果章 | 讨论章 |
|---|---|---|
| 做什么 | 报事实 | 解释事实 |
| 说什么 | 差多少、显著吗 | 为什么差、和谁一致、到什么边界 |
| 禁忌 | 不许解释 | 不许重复数字表 |

讨论章的公式：**发现 → 与文献对话 → 机制解释 → 替代解释 → 边界**。

## 二、四段配方

| 段 | 职责 | 写作要点 |
|---|---|---|
| 1 发现重述 | 两三句把主要发现说一遍（不带新数字） | 只讲方向与量级，不复制结果章 |
| 2 与文献对话 | 和谁一致、和谁冲突、为什么 | 至少三条文献，必须解释分歧 |
| 3 机制解释 | 为什么会出现这个结果 | 给出可检验的机制，不泛泛而谈 |
| 4 边界与局限 | 到哪为止、什么不能推 | 三条具体限制 + 对结论的影响 |

## 三、第 2 段（与文献对话）怎么写

这是讨论章最容易写空的地方。三个动作：

1. **一致**：我的结果支持谁，为什么。
2. **冲突**：和谁不一致，差异可能来自哪（样本、口径、时点、模型）。
3. **推进**：因此我比他们多知道了什么。

示范：

> 本研究发现的通勤时间效应，与王某（2021）在城区样本中的结论方向一致，但强度更大：
> 王某报告的相关系数为 −0.21，本研究为 −0.38。差异可能来自样本情境——城区学校服务结束时间
> 与下班时间普遍衔接较好，通勤的约束作用被削弱；县域学校的时段错配更明显，因此通勤的边际影响更大。
> 这一对比说明，同一机制在不同制度环境下强度不同，直接外推城区结论会低估县域的约束。
>
> 与李某（2020）的结论不同，本研究未发现家庭收入的显著作用。一种解释是样本内收入差异较小
> （三校家庭月收入中位数相差不足 8%），统计功效不足以检出；另一种解释是课后服务在县域属于
> 低收费项目，价格对参与的约束本就有限。两种解释都需要更大样本才能区分。

句式：

- "这一结果与 L1 的结论方向一致，但在强度上存在差异，可能源于……"
- "与 L2 不同，本研究未发现……，这可能是因为……，也可能是因为……"
- "上述对比提示，……的效应依赖于……条件。"

## 四、第 3 段（机制）怎么写

机制要能"拍出来"：说清谁在什么环节做了什么，导致什么。

- ✗ "这说明课后服务对学业成绩有促进作用。"（这是重复结果，不是机制）
- ✓ "机制上，服务时段延长直接替代了原本无人监管的放学后时段。在远郊校，这一时段原本多由
  祖辈照看，监管强度低；服务延长后，学生留在校内完成作业，作业完成率由 61% 升至 84%〔核验：数据〕，
  这可能是成绩差异的中间环节。"

写机制的三件套：**触发条件 → 中间环节 → 结果**。三者缺一，机制就是猜的。

## 五、局限怎么写（三条，要具体）

| 写法 | 例子 |
|---|---|
| ✗ 套话 | "受条件所限，本研究仍有不足，有待进一步研究。" |
| ✓ 具体 | "其一，横截面设计无法排除反向因果：成绩较好的学生可能更愿意参与。其二，样本为三所县域学校，外推至城区需谨慎。其三，参与时长依赖家长自报，可能高估实际到课。" |

每条限制后面加半句"对结论的影响"，否则读者不知道这条限制有多大关系。

## 六、结论章怎么写

结论只做三件事：回答研究问题、给分层建议、指出后续方向。**不引入任何新内容。**

### 结论第一段：回答

> 本研究以 X 县三所公办初中为对象，考察课后服务参与率的校际差异及其来源。结果表明，
> 三校参与率相差 33 个百分点，差异主要集中在组织实施环节；通勤时间是主要解释变量，
> 家庭收入的作用不显著。由此可以回答开篇提出的问题：县域学校参与率的差异，更多由
> 时间约束而非支付能力决定。

要点：回扣引言的研究问题，用"由此可以回答"这类明确的收口句。

### 建议：按对象分层，每条能追到结果

| 层级 | 建议 | 追溯到哪条结果 |
|---|---|---|
| 县级教育部门 | 允许学校按学区通勤半径调整服务结束时间 | 4.3 通勤时间与参与时长负相关 |
| 学校 | 对通勤超过 30 分钟的学生开设延时托管班 | 4.4 时段错配访谈 |
| 家长/社区 | 组建互助接送小组 | 4.4 祖辈照看监管强度低 |

规矩：**建议必须能指回某条结果**。指不回去的建议是空话，答辩时最容易被问倒。

### 后续方向：具体，不写"有待深入"

- ✗ "后续可进一步深入研究。"
- ✓ "后续需纵向追踪同一批学生的参与变化，以识别因果方向；并在城区样本中重复本设计，
  检验通勤效应的情境依赖性。"

## 七、句式库

**讨论开篇**

- "本节讨论三个问题：……"
- "上述结果可以从两个层面理解。"

**对话**

- "这一发现与……一致，但在……方面提供了新证据。"
- "与……的结论相反，本文认为……"
- "既有研究多强调……，本研究提示……同样重要。"

**机制**

- "其作用路径可能是：……，进而……"
- "一个可检验的推论是：若……成立，则在……中应观察到……"

**收口**

- "由此可以回答本文提出的问题：……"
- "本研究不主张……，只主张……"
- "在……条件下，这一结论成立；超出该条件，需另行检验。"

## 八、六个常见错误

| 错误 | 表现 | 改法 |
|---|---|---|
| 重复结果 | 讨论章把表 4-1 又念一遍 | 只讲方向，讲数字交给结果章 |
| 只有一致没有冲突 | 引的文献全都支持自己 | 必须找一条不一致的并解释 |
| 机制是猜的 | "可能与社会环境有关" | 给出触发条件—中间环节—结果 |
| 建议空泛 | "应加强重视、加大投入" | 每条追到一条结果 |
| 结论引入新内容 | 突然出现前文没提的数据 | 删，或回正文补 |
| 局限是套话 | "受条件所限" | 写三条具体的 |

## 九、自查

- [ ] 讨论四段齐全，第 2 段有至少一条冲突文献
- [ ] 机制写成"触发条件→中间环节→结果"
- [ ] 局限三条都带"对结论的影响"
- [ ] 结论第一段回答引言的研究问题
- [ ] 每条建议都能指回某条结果
- [ ] 结论无新内容、无新数字
