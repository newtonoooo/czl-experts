# W9 中文润色

产出：改后全文 + 对照表（改了什么/为什么）。

## 一、润色的顺序（不能倒）

1. **看功能**：这段想干什么？有判断句吗？没有先补判断句，不要动字。
2. **看顺序**：判断—支撑—边界的顺序成立吗？铺垫太长就挪后或删。
3. **看句子**：主语在不在、动词实不实、限定词有没有落空、长句要不要断。
4. **看用词**：术语一致、搭配得当、删冗余。

只做第 3、4 步的润色，是最常见也最没用的润色。

## 三、句长控制

- 中文论文句均 25—35 字为宜。超过 60 字的句子占 25% 以上，读起来吃力（`style_lint.py` 会报）。
- 长句多由多论点叠加造成，拆成两句：一句判断，一句说明。
- 连续四句 10 字以内，读起来像口号，学术文本不宜。长短交替。

示例：

- ✗ "本研究通过对三所学校为期一学年的参与数据进行收集整理分析，发现参与率存在显著差异，
  并且这一差异与家长的通勤时间存在负相关关系，而与家庭收入的关系不显著。"
- ✓ "本研究收集三所学校一学年的参与数据。分析显示，参与率存在显著差异，且与家长通勤时间负相关；
  家庭收入的作用不显著。"

## 四、衔接（避免"首先其次最后"）

| 关系 | 可用 | 不要用 |
|---|---|---|
| 递进 | 进一步、更关键的是、在此基础上 | 首先/其次/最后（连用三段像说明书） |
| 转折 | 然而、不过、与此相反 | 但是（口语感强，少量可用） |
| 因果 | 因此、由此、这意味着 | 所以说 |
| 并列 | 一方面……另一方面、同时 | 还有就是 |
| 举例 | 例如、以……为例 | 比如说 |
| 收束 | 综上、由此可以确认 | 总而言之 |

一段最多一个连接词。逻辑清楚了，连接词就该少。

## 五、学术化改写（口语→书面）

| 口语 | 书面 |
|---|---|
| 我们发现 | 本研究发现 / 分析显示 |
| 很多 | 较多 / 大量 / 多数 |
| 差不多 | 接近 / 约为 |
| 越来越 | 逐年上升 / 持续增加 |
| 搞不清楚 | 尚不明确 |
| 大概是因为 | 可能源于 |
| 这个事儿 | 该问题 |
| 特别重要 | 尤为关键（慎用，多用具体表述） |

## 六、术语一致性

同一概念只能一个叫法。开工前定表：

| 采用 | 禁用 | 定义 |
|---|---|---|
| 课后服务参与率 | 参加率、覆盖率 | 实际到课人数 ÷ 在籍人数 |
| 参与时长 | 服务时长 | 生均每周实际参加小时数 |

改了术语，回头用查找替换全文过一遍。混用术语会被评审当成两个指标。

## 七、改稿交付格式

不要逐句解释。给三样：

```
一、改后全文（可直接替换）
二、改动对照表（只列实质性改动，一般 5—12 条）
   | 原文 | 改后 | 改了什么 | 为什么 |
三、仍需你确认的地方（2—3 处涉及事实的改动）
```

对照表示例：

| 原文 | 改后 | 改了什么 | 为什么 |
|---|---|---|---|
| 在一定程度上说明了通勤的作用 | 通勤每增加 30 分钟，参与时长减少 0.7 小时 | 给量级 | 模糊限定无信息 |
| 通过对数据的分析，发现了显著差异 | 数据分析显示，三校差异显著 | 补主语 | 原句主语失踪 |
| 此问题需要引起我们的高度重视 | 该问题需在服务时段安排中优先处理 | 去呼吁腔 | 学术文本不表态 |

## 八、润色不许做的事

1. 不改作者的核心判断（可以调力度，不能改方向）。必须改时先说明"这已经不是润色"。
2. 不动数据和引用（一个字都不动）。
3. 不换掉术语表里定过的词。
4. 不为了"高级"堆四字词和长定语。学术文本的体面来自准确，不来自辞藻。
