# W3 结构与提纲

产出：三级提纲 + 每章字数预算 + 每章任务与出口 + 论证骨架。

## 一、先定主线，再分章

提纲不是章节名的排列，是论证的骨架。先写一句话主线：

```
在【什么条件】下，【什么因素】通过【什么机制】影响【什么结果】。
```

然后问：这句话的每一部分，由哪一章负责立住？

## 二、标准结构（学位论文）

| 章 | 职责 | 字数占比 | 常见错误 |
|---|---|---|---|
| 摘要 | 全文压缩（不编号） | 300—500 字 | 写成导语 |
| 第 1 章 引言 | 立问题、说缺口、给贡献 | 8—10% | 写成综述 |
| 第 2 章 文献与框架 | 对话、定概念 | 20—25% | 与后文脱节 |
| 第 3 章 研究设计 | 让别人能重做 | 15—20% | 写成教科书 |
| 第 4 章 结果/分析 | 报事实 | 20—25% | 夹叙夹议 |
| 第 5 章 讨论 | 解释、对比、边界 | 15—20% | 重复结果 |
| 第 6 章 结论与建议 | 收口、分层建议 | 5—8% | 突然升华 |
| 参考文献 / 附录 / 致谢 | — | — | 格式不统一 |

量化/实验型可把结果与讨论合并；人文型常把文本分析拆成两章。但**结果章不放解释、讨论章不重复数字**
这条要守。

## 三、每章六格（写提纲时必须填）

```
章号与标题：
职责（为哪条主张服务）：
必答问题（2—3 个）：
字数预算：
出口（把读者交给谁、接什么问题）：
不许写什么：
```

最后一格最关键。不写它，第 3 章一定会把第 2 章的背景重抄一遍。

## 四、标题怎么写

| 坏标题 | 问题 | 好标题 |
|---|---|---|
| 相关理论概述 | 看不出要做什么 | 课后服务效果的三种解释路径 |
| 问题分析 | 什么问题的什么方面 | 参与率差异为何出现在组织实施环节 |
| 对策建议 | 对策从哪来 | 面向通勤约束的服务时段调整 |

标题带动作或带判断，读者看目录就知道你的论证走向。

## 五、字数预算算法

1. 总字数已知（学校要求），或按学位类型估：本科 8000—15000，硕士 30000—50000。
2. 按上表比例分配，四舍五入到百位。
3. 每章再分到节（一般一章 3—5 节）。
4. 加总后与总字数差控制在 5% 内。
5. 写的时候盯住：某章超 40%，通常是越界写了别章的内容。

## 六、提纲自检四问

1. **删章测试**：随便删一章，论文还完整吗？完整 → 该合并或删。
2. **倒读测试**：只读每章最后一段，能串成完整论证吗？不能 → 出口没写。
3. **归属测试**：每条主要结论都能找到"主战场"章节吗？两条抢同一章 → 分工不清。
4. **比例测试**：文献章 > 35% 而结果章 < 15%，说明读得多做得少，评审会这么看。

## 七、六种常见结构病

| 病 | 症状 | 处方 |
|---|---|---|
| 三段式空洞 | 现状—问题—对策，每段都泛 | 换成"机制—证据—边界" |
| 综述独立成章但与后文无关 | 第 2 章的框架第 4 章不用 | 只留会被用到的概念 |
| 方法章写成教科书 | 解释什么是问卷、什么是 SPSS | 只写"我怎么做的、为什么这么做、怎么防偏" |
| 结果章夹叙夹议 | 报一个数解释一句 | 结果只报，讨论集中解释 |
| 结论章突然升华 | 出现前文没提过的建议 | 建议必须能追到某条结果 |
| 两章职责重叠 | 第 4 章和第 5 章都在解释 | 按"报事实 / 解释事实"切开 |

## 八、交付格式

```
一、一句话主线
二、论证骨架（主线下挂 3—5 个前提，每个挂章节）
三、三级提纲（章—节—小节，带字数）
四、每章六格（表格）
五、字数预算表（合计与总字数对比）
六、结构自检结果（四问逐条）
```

## 九、给用户的一句话提醒

提纲阶段最省时间的动作是**砍**：砍掉与主线无关的章，砍掉撑不起的小节。
一篇文章讲清一件事，比讲三件事各讲三分要好。
