# 写作总则：所有章节通用

## 一、三条标准

学术写作只求三件事，其余都是风格：

1. **明确**：读者不用猜主语是谁、条件是什么、程度多少。
2. **可核验**：每个判断都能指回数据、文献或推理步骤。
3. **克制**：不夸大、不抒情、不用力过猛。

"文采"在论文里不是加分项，清晰才是。

## 二、段落配方（写任何一段都用）

| 段型 | 结构 | 起句示例 |
|---|---|---|
| 立论 | 判断句 + 理由 + 限定条件 | "本研究认为，参与率的校际差异主要来自通勤时间。""这一结果可以归因于两项制度安排的叠加。" |
| 举证 | 数据/引文 + 一句解读 | "2022—2023 学年，三校参与率分别为 82.1%、64.5% 与 48.7%。" |
| 反驳 | 对立解释 + 为何不成立 | "一种可能的解释是家庭收入差异。但三校生均家庭收入差距不足 8%，难以解释 33 个百分点的落差。" |
| 过渡 | 已答 + 未答 + 本节要做什么 | "上述分析确认了差异的存在，但尚未说明差异如何形成。" |
| 收束 | 回扣本节问题 + 交出下一问 | "由此可以确认，差异主要发生在组织实施环节。接下来要问的是，这一环节受什么约束。" |

**判断句是段落的命。** 把每段第一句单独抽出来，能不能串成一条完整论证？串不起来，就有段落只是资料。

一段一个动作。一段里既举证又反驳又过渡，读者跟不上。超过 400 字的段落，几乎一定藏着第二个论点。

## 三、时态与人称

| 位置 | 中文 | 英文 |
|---|---|---|
| 方法与结果 | 过去时态陈述（"本研究选取……""共回收有效问卷 312 份"） | 过去时（"Data were collected…""We recruited…"） |
| 普遍结论 | 现在时（"这一机制在县域学校同样成立"） | 现在时（"This pattern holds in county schools."） |
| 文献评述 | "陈某（2022）发现……" | "Chen (2022) found…" |
| 图表说明 | 现在时（"图 3-1 显示……"） | 现在时（"Figure 3-1 shows…"） |

人称：中文学位论文一般避免"我"，用"本研究""本文"；英文期刊多用 "we"，单人作者可用 "I"（人文学科）或被动（理工）。

## 四、断言强度（hedging）必须与证据匹配

| 证据强度 | 中文 | 英文 |
|---|---|---|
| 强（多来源一致、有因果识别） | 表明、证实、可以确定 | demonstrates, establishes, shows |
| 中（单来源、相关关系） | 提示、倾向于、与……一致 | suggests, indicates, is consistent with |
| 弱（间接、个案、推测） | 可能、或与……有关、有待检验 | may, might, appears to, is likely to |

自查：把结论句的动词圈出来，问一句"我的证据支持这个动词吗"。单一样本的相关分析写成"证实了"，是最容易被审稿人抓的地方。

## 五、引用怎么嵌进句子

| 方式 | 形态 | 用在哪 |
|---|---|---|
| 引证 | "已有研究显示 X 与 Y 正相关（陈某，2022）" | 结论已被普遍接受 |
| 引述 | "陈某（2022）在 X 县发现……但样本仅两所学校" | 需要评价、需要立缺口 |
| 直引 | "「……」"（陈某，2022：47） | 原句本身是关键（定义、政策原文、争议表述） |

规矩：直引不超过全文 5%；引述必须带评价；一条引用只支撑一个论断；引用放句末，不打断句读。

## 六、图表的三条硬规矩

1. 图题在下，表题在上（中文惯例；英文期刊按刊物要求，多数统一在上）。
2. 正文必须写出"如图 X 所示""见表 X"，**禁止"见下图""如上表"**。
3. 图表不能替代文字：正文要说清"这张图让我看到什么"，不能让读者自己算。

三线表：顶线、表头线、底线，无竖线；表头标单位；数据来源写在表下。

## 七、十条空转句式（写完自查，出现就改）

| 空转句 | 问题 | 改法 |
|---|---|---|
| 随着社会经济的不断发展 | 万能开头，与本课题无关 | 直接给现象或数据 |
| 近年来，X 越来越受到关注 | 谁在关注、关注什么 | 给政策、事件或数据拐点 |
| 具有重要的理论意义和现实意义 | 谁的意义、什么意义 | 删，或写清对哪个理论/哪类实践有用 |
| 不仅……而且…… | 常掩盖"A 和 B 是一件事" | 拆两句，或删一半 |
| 在一定程度上说明了 | "一定程度"是多少 | 给方向与量级 |
| 起到了积极的推动作用 | 谁的、多大、怎么测 | 给机制或删 |
| 为后续研究奠定了基础 | 什么基础 | 删，或写清留下什么具体问题 |
| 综上所述 | 综述没真收束时才需要 | 用一句实质结论替代 |
| 值得注意的是 | 真值得注意的会自己跳出来 | 删 |
| 有待进一步深入 | 等于没说 | 写清"需要什么设计、在什么情境" |

一段里出现两处以上，这段基本是在填字，重写。

## 八、写作节奏

- 一次写一节（800—1500 字），不要一次写一章。
- 写的时候不回头改。写完一节再统一过一遍。
- 卡住通常是四种原因：主张没证据（回去补材料）、章节职责重叠（改提纲）、题目太大（砍范围）、
  还没形成判断（先用一句话写下"我认为"，再找证据）。这四种都在上一层，不在语言层，硬改字没用。

## 九、交付前自检（每节都过）

- [ ] 首段能独立说清"本节要干什么"
- [ ] 每段有判断句，没有纯资料段
- [ ] 每条引用都在支撑它所在的那句判断
- [ ] 术语全文一致（改过的术语回头改了全文）
- [ ] 数字带口径（分母是什么、时段是什么、单位是什么）
- [ ] 无空转句式
- [ ] 字数在要求 ±15%
- [ ] 占位符 `〔待补〕` 与 `〔核验〕` 已列成清单

## 十、占位与核验

- `〔待补：缺什么｜从哪拿〕`——我没有的材料，绝不编。
- `〔核验：这句依据用户口述的 X，请核对原始数据〕`——我推断出来的内容，必须标。
- 交付时把这两类标记汇总成清单，用户一眼能看到哪些要自己填。
