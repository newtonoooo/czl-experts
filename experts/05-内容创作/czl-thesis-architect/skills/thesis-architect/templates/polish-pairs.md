# 润色对照表

> 改稿时用这张表记录"改了什么、为什么"。只列实质性改动，一般 5—12 条。

## 对照表

| # | 原文 | 改后 | 改了什么 | 为什么 |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

**"改了什么"只用四个字**：补主语 / 给量级 / 拆长句 / 去呼吁 / 删空话 / 换动词 / 调语序 / 补限定。

## 常用改写类型速查

| 类型 | 典型病 | 改法示例 |
|---|---|---|
| 补主语 | 通过对数据的分析，发现了差异 | 数据分析显示，三校差异显著 |
| 给量级 | 在一定程度上说明了通勤的作用 | 通勤每增加 30 分钟，参与时长减少 0.7 小时 |
| 拆长句 | 一句 70 字带三个分句 | 拆成两句：判断 + 说明 |
| 去呼吁 | 需要引起我们的高度重视 | 该问题需在服务时段安排中优先处理 |
| 删空话 | 众所周知、值得注意的是 | 直接说 |
| 换动词 | 起到了积极的推动作用 | 使参与率提高 14 个百分点 |
| 调语序 | 铺垫三句才给观点 | 判断句提前 |
| 补限定 | 通勤时间影响参与率 | 在县域学校，通勤时间影响参与率 |

## 三档改动强度（交付时标明）

| 档 | 动什么 | 用途 |
|---|---|---|
| 轻（校对） | 标点、错字、术语统一 | 交稿前 |
| 中（润色） | 句长、衔接、动词、空话 | 常规改稿 |
| 重（改写） | 段落结构、论证顺序 | 重复率高或逻辑乱 |

**重改前必须说明**："这已经不是润色，段落结构和论证顺序会变，核心判断我不会动。"

## 不许改的四样

1. 作者的核心判断（可调力度，不改方向）
2. 数据与引用（一个字都不动）
3. 术语表里定过的词
4. 作者/导师的语体偏好（要短句就短句，要书面就书面）

## 交付格式

```
一、改后全文
二、改动对照表（上表）
三、仍需你确认的两三处（涉及事实的改动）
```
