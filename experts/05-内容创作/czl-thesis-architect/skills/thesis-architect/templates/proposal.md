# 开题报告模板

> 按学校模板调整章节名，但结构不要少：背景 → 意义 → 现状 → 内容 → 方法 → 进度 → 文献。

## 一、研究背景与问题（约 15%）

（政策/现象 + 数据 → 张力 → 问题）

```
20XX 年以来，……在……推开，覆盖……〔核验：数据来源〕。
然而，同一政策框架下，不同……的实际执行并不一致：……。
这一差异提出了一个具体问题：……？
```

## 二、研究意义（约 8%）

- 理论层：对哪个具体争论/概念有补充
- 实践层：对谁有用、怎么用

（不写"具有重要的理论意义和现实意义"）

## 三、国内外研究现状（约 25%）

按争议或机制组织，三到四组：

**3.1 第一组：……**
（他们做了什么 → 结论 → 局限）

**3.2 第二组：……**

**3.3 研究评述**
（分歧在哪、缺口是什么、本文接哪一块）

## 四、研究内容（约 20%）

| 内容 | 对应章节 | 要回答什么 |
|---|---|---|
| 内容一 | 第 4 章 4.2 | |
| 内容二 | 第 4 章 4.3 | |
| 内容三 | 第 4 章 4.4 | |

## 五、研究方法与技术路线（约 20%）

| 项 | 内容 |
|---|---|
| 研究设计 | （横截面/纵向/案例/实验/混合；为什么不用别的） |
| 研究对象 | （选取标准、样本量、抽样方式） |
| 数据收集 | （工具、时间、程序、回收率） |
| 数据分析 | （描述统计、模型、编码规则） |
| 效度与限制 | （三条具体威胁及应对） |

技术路线图（文字版）：

```
文献梳理 → 概念框架 → 工具设计 → 预调研 → 正式施测 → 数据分析 → 访谈补充 → 结论
```

## 六、进度安排（约 5%）

按周排，留 20% 缓冲。

| 时间 | 任务 | 产出 |
|---|---|---|
| 第 1—2 周 | 文献检索与精读 | 文献矩阵 20 篇 |
| 第 3—4 周 | 问卷/提纲设计 | 工具定稿 |
| 第 5—6 周 | 预调研与修订 | 预调研报告 |
| 第 7—8 周 | 正式收集数据 | 有效样本 |
| 第 9—11 周 | 数据分析 | 结果章初稿 |
| 第 12—14 周 | 撰写与修改 | 全文初稿 |
| 第 15—16 周 | 格式与查重 | 定稿 |

## 七、参考文献（约 7%）

15—40 条，格式按学校要求（见 W11）。

## 附：开题答辩预判问题

1. 题目为什么是这个范围？再大一点行不行？
2. 数据拿得到吗？拿不到怎么办？
3. 为什么用这个方法，不用另一种？
4. 你和某某（2020）比，多知道什么？
5. 时间够吗？哪一步最可能拖？
