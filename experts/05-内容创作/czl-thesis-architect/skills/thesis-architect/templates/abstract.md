# 摘要模板（中英）

## 中文摘要（300—500 字，硕士 500—800）

**槽位 1 · 目的（1—2 句）**

```
____（现象/问题）在____（范围）中存在明显差异，但既有研究多集中于____，对____讨论不足。
本研究要回答的问题是：____？
```

**槽位 2 · 方法（1—2 句）**

```
本研究以____为对象，采集____（时间/样本量/数据）+____（辅助材料），
通过____（方法）考察____。
```

**槽位 3 · 结果（2—3 句，必须有数字）**

```
结果显示，____分别为____，相差____；控制____后差异仍然显著，
而按____分组后差异缩小至____，说明____是主要解释变量。
```

**槽位 4 · 结论（1—2 句）**

```
研究认为，____的关键不在____，而在____。
```

**槽位 5 · 边界（1 句，可选但建议）**

```
受____限制，本研究仅报告____，不作____。
```

## 英文摘要（150—250 words）

```
Participation in ____ varies widely across ____, yet existing evidence comes mostly from ____
and offers little on ____. Drawing on ____ (n = ____) from ____, this study examines ____.
Rates differed by ____ (____%, ____% and ____%) and remained significant after controlling for ____;
grouping by ____ reduced the gap to ____, indicating ____ as the main explanatory factor.
____ further show that ____. The findings suggest that ____ depends less on ____ than on ____.
The ____ design limits causal inference.
```

英文要点：

- 一句一义，不用分号串烧。
- 数据用 `Drawing on / Using / Based on` 引出。
- 结论用 `The findings suggest that`，不用 `prove`。

## 关键词

```
关键词：____；____；____；____（3—5 个）
Keywords: ____; ____; ____; ____
```

选词禁用：研究、分析、对策、思考、初探、浅析、探析。
