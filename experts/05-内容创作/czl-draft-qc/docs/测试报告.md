## 三、关键区分度验证

质检脚本的核心价值是区分好坏。两份自写样本对照：

| 样本 | 字数 | 句长 CV | 套话 | 元叙述 | 总分 | 结论 |
|---|---|---|---|---|---|---|
| `samples/bad_sample.md`（刻意模仿 AI 腔） | 435 | 0.63 | 15 处 | 2 处 | **44.0** | 需修（有硬伤） |
| `samples/good_sample.md`（真人叙事写法） | 566 | 0.583 | 0 处 | 0 处 | **98.9** | 可发 |

**反直觉现象**：坏样本的句长 CV 反而更高（节奏项满分 20/20），因为它把长句和短句清单混在一起，"句式丰富"了。这正是为什么必须**硬伤优先于总分**：它的 44 分全部由套话、元叙述、同构短句扣出来。

此现象已写入 `skills/quality-gate/references/rules.md`。

## 三之一、选题查重的区分度验证

用两份样本验证 `topic_score.py` 能不能真的分辨"5 个"和"1 个的 5 种说法"：

| 样本 | 内容 | 结果 |
|---|---|---|
| `topics_demo.json` | 5 个选题，其中第 1 和第 5 个是同一件事的两种说法 | **exit 1**，抓出相似度 0.45 的重复对 |
| `topics_clean.json` | 5 个选题，五个角度各不相同 | **exit 0**，无重复 |

同时验证了打分排序是否符合直觉：`topics_demo` 里"中考体育分值上涨"（空角度、无素材）40 分垫底，而"分值涨到 70 分但训练周期没变"82 分居首——这正是"具体锚点 + 角度张力"该起的作用。

### 本轮修掉的一个误判

第一版量词表只收了 `个/年/月/日/岁/块/份/人/天/篇/次/条/所/校/科/分`，导致"体育选考**三项**，哪**一项**最不值得练"被判"具体性 0 分"——它明明有一个明确的选择指向。

修正：量词表补 `项/门/种/类/步/张/届/名/位/组/场/套/期/本/页/章`，并新增 CHOICE 规则（`哪一/哪个/哪种/该不该/要不要/值不值`）作为"选择指向"的加分项。该题从 67 分升到 81 分。

**教训与上次字体 fallback 同类**：启发式规则永远在用词表的覆盖度换准确率，样本里没覆盖到的说法，就会误判成"没有"。

## 三之二、排版 linter 的抓取能力验证

`check_wx_html.py` 的价值在于"能抓出来"。用一份故意写坏的文件（`samples/bad_html.html`）验证：

| 埋的雷 | 是否被抓 |
|---|---|
| `display:grid` + `grid-template-columns` | ✅ FAIL |
| `display:flex` | ✅ FAIL |
| `position:absolute` + 负 margin | ✅ FAIL |
| `<script>` | ✅ FAIL |
| 表格缺 `table-layout:fixed` 与 `<colgroup>` | ✅ FAIL ×2 |
| 圆点缺 `width/height` | ✅ FAIL |
| 容器无 `max-width` | ✅ FAIL |
| `font-family:'Noto Serif SC'`（无 fallback） | ✅ FAIL |
| `box-shadow` | ⚠ WARN |
| `linear-gradient` | ⚠ WARN |
| 外链图片 | ⚠ WARN |
| `<style>` 里用 class 选择器 | ⚠ WARN |

**8 FAIL ／ 4 WARN 全部命中，零漏报。** 反面验证：正常渲染的 `demo.html` 是 0 FAIL ／ 0 WARN，说明规则没有误伤。

### 本轮修掉的一个真 bug

字体 fallback 检查在 v2.1.0 之前**从未生效**：正则写成 `[^;\"']+`，排除了单引号，而样式里的字体名普遍用单引号包裹（`font-family:'Noto Serif SC',serif`），导致这条规则匹配不到任何内容，永远静默通过。

修正为只排除双引号后，负样本从 7 项 FAIL 变成 8 项——补上了漏掉的那一项。

**教训**：自检工具自身也需要用负样本验证，否则"全绿"可能只是"没检查"。
