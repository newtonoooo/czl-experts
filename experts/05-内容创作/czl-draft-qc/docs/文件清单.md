## 二、四个技能的职责边界

| 技能 | 输入 | 输出 | 判定通过的标准 |
|---|---|---|---|
| `topic-radar` | 账号方向 + 一个关键词 | 5 张选题卡片 | `topic_score.py` exit 0（无重复） |
| `draft-foundry` | 选定的题 | 骨架 → 初稿 | `outline_check.py` exit 0（每节点有"读者得到"） |
| `quality-gate` | 一篇稿子 | 体检报告 + 改稿对照 | 无硬伤且总分 ≥75 |
| `publish-kit` | 定稿（可含图） | HTML（5 套配色之一）+ 图片上传清单 | `check_wx_html.py` exit 0（无 FAIL） |

**账号信息（公众号名称 + 账号方向）是四个技能共同的输入前提**，且只能由用户提供——包里没有任何预设值。

## 五、五套配色的样张

`skills/publish-kit/samples/preview_*.html` 是同一篇稿子在五套配色下的输出，用于对比与验收。浏览器直接打开即可。

重生成：

```bash
for th in a-ink b-navy c-dai d-chestnut e-graphite; do
  python skills/publish-kit/scripts/render_wechat.py samples/demo.md \
    --out samples/preview_$th.html --theme $th
done
```

## 六、账号相关字段的取值规则

| 字段 | 谁能填 | 缺失时 |
|---|---|---|
| `footer_name` | 只能是用户自己的公众号名 | 整块落款不输出 |
| `footer_slogan` | 用户的账号定位 | 不输出 |
| `tag` / `tag2` | 用户能给就给，不能给按内容拟 | 可省略 |
| `theme` | 用户指定或脚本随机 | 随机 |

**禁止**：填写示例号名以外的任何虚构账号、使用他人账号名、把某账号的语气当成产品默认语气。
