# 热点判别手册

> 选题最容易出的错，不是没想到，是**把一个旧话题当成新热点**，写出来读者一句"这不是去年的事吗"就走了。

## 一、什么才算"热点"：五条标准

一条消息要同时满足前三条，才算可写的热点。

| # | 标准 | 怎么验证 |
|---|---|---|
| 1 | **有出处** | 能指到具体文件、公告、发布会、官方账号，不是"网上都在说" |
| 2 | **有时间** | 知道它是什么时候发生的，最好精确到日 |
| 3 | **有变化** | 相比之前变了什么（数字、规则、范围），没变化就不是新闻 |
| 4 | 有人受影响 | 能说出"谁的日子会因此不一样" |
| 5 | 还没被写烂 | 同题已有很多号写过时，只能靠新角度取胜，不能靠"最早" |

**只满足第 4、5 条，不满足前三条 → 这是"常见话题"，不是热点。** 常见话题可以写，但要按常销题处理：不强调时效，强调有用。

## 二、搜索策略

### 查询词怎么构造

同一个关键词，至少三组查询，覆盖不同侧面：

| 方向 | 查询式 | 想拿到什么 |
|---|---|---|
| 官方口径 | `<关键词> 2026 通知 文件` | 政策原文、发布时间、具体条款 |
| 民间讨论 | `<关键词> 家长 讨论 争议` | 真实困惑点（这是选题的金矿） |
| 数据变化 | `<关键词> 数据 上涨 下降 比例` | 可用于支撑的硬数字 |

补充查询（按需）：

- `<关键词> 最新消息` — 判断是否有近期动态
- `<关键词> 辟谣 假的` — 排查是否已被证伪的传言
- `<关键词> 外地 对比` — 找横向参照，常能出好角度

### 搜完之后必须做的一件事

**给每条信息标上时间**。没有时间的信息不能用，因为你不知道它是不是三年前的。

## 三、来源分级

写作时按这个顺序采信，越靠前越可靠：

| 级别 | 来源 | 用法 |
|---|---|---|
| A | 政府部门、考试院、学校官网公告 | 可直接引用，注明文号与日期 |
| B | 官方媒体（新华社、人民日报、本地党媒） | 可引用，注明媒体与日期 |
| C | 行业媒体、正规教育类媒体 | 可作参考，不作为唯一依据 |
| D | 自媒体、家长群截图、营销号 | **只能当"民间关注点"**，不能当事实 |

**D 级内容的价值**：它告诉你家长在担心什么，这是选题的入口；但它说的"政策"不能信。

## 四、假热点的四种长相

| 长相 | 识别方法 | 处理 |
|---|---|---|
| **旧闻翻炒** | 一搜发现去年就有同样标题 | 查最早发布时间；旧的就按常销写，别装新闻 |
| **单条爆料** | 只有一个营销号在说，官方无任何回应 | 不写，或写成"这个说法在传，但查无出处" |
| **标题党放大** | 原文说"研究讨论"，标题写"确定实施" | 回到原文看措辞 |
| **地域错位** | 外地的政策被当成本地在传 | 核对发文单位与适用范围 |

## 五、时效判断

不同热点有不同保质期，卡片上必须标出来：

| 窗口 | 类型 | 例子 |
|---|---|---|
| **3 天** | 突发事件、成绩公布 | 中考出分、录取线公布 |
| **7 天** | 政策发布、报名开始 | 招生方案发布 |
| **30 天** | 趋势性变化、季节节点 | 新学期开学、体育改革落地 |
| **长期** | 结构性变化 | 中考科目调整（影响三年） |

**窗口过了还能写的**：改成常销题，把"最新"改成"怎么回事"，把时效性换成解释性。

## 六、搜不到东西时怎么办

这是常态，不要硬编。

1. **直说**："这个词近期没有可核实的新进展。"
2. **改出常销选题**：读者对这件事的长期困惑，三年后仍然成立。
3. **换个切法**：不写"政策变了没有"，写"家长最常问的三个问题"。
4. **给一个更窄的词**：请用户把范围收到"人群 + 场景"，例如从"教育"收到"成都初三家长 + 体育选考"。

**绝对不能做的**：把记忆里的旧信息包装成"最近"，或者编一个"据了解"。
