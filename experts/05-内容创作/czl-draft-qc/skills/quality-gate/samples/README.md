# 这里的文件是什么

这两个文件是 `quality_gate.py` 的**回归样本**，只用于跑测试，不是产品模板。

| 文件 | 用途 | 当前基线 |
|---|---|---|
| `bad_sample.md` | 反例：AI 腔明显的稿子 | 总分 44，6 项硬伤，脚本应 exit 1 |
| `good_sample.md` | 正例：真人写法的稿子 | 总分 98.9，无硬伤，脚本应 exit 0 |

## 题材为什么是升学的

它是这套评分规则最早被标定的一批文本。**换题目就要重新标定所有阈值**（八项指标的权重、硬伤的判定线、44 与 98.9 这两个锚点），
很容易把已经验证过的区分度弄丢，所以保留原样。

## 这不代表产品预设了领域

本专家不预设任何行业、地区或读者类型——公众号名称与账号方向全部由使用者提供，
主 Agent 里写死了「没有任何默认值」。

如果你在这里看到升学相关的内容，那是**测试数据的题材**，不是产品的默认输出方向。
想知道产品默认长什么样，看 `skills/publish-kit/samples/preview_*.html`（那篇是中性题材）。
