# 工序 03 · 成稿

## 名称

成稿（Drafting）—— 把一条选题做成一张能直接发的笔记卡。

## 职责

产出完整笔记卡：5 个标题候选、封面三行、正文全文、首评、3+3+2 标签、配图脚本。正文必须是整段可复制的干净文本。

这道工序最容易犯的错是"写得好但没人点"。所以顺序是：**先定标题和封面，再写正文**。标题定不下来，正文写了也是白写。

## 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `topic` | 是 | 一条选题（含搜索词、角度、骨架） |
| `material_card` | 是 | 素材卡 |
| `position_card` | 否 | 定位卡，用于把握语气 |
| `constraints` | 否 | 不能说的、必须说的、字数、是否出镜 |

## 执行步骤

**第 1 步：写 5 个标题，覆盖 ≥3 类结构。**

五类结构见 `references/01-title-engineering.md`：留空型、代价型、对照型、亲历型、清单型。

硬要求（三条，缺一条重写）：

1. 至少 3 个标题含**可核对的量**（数字/价格/时长/次数）或**一个越界动作**（拆了、翻了 200 条评论、问了店员）
2. 至少 1 个标题是留空型：给前提，不给结论
3. 没有一个标题把全文结论说完

每个标题后面标：结构类型 + 它赌的是什么人群。

**第 2 步：定封面三行。**

- 主标：≤9 字，一句话说清这篇在讲什么
- 副标：一个具体数字或动作，负责把人拉进来
- 角标：身份或场景（"租房第三年""预算 2000"），负责让人对号入座

配图形式三选一：实物特写、前后对照、手持手机截图。详见 `references/02-cover-spec.md`。

**第 3 步：选骨架写正文。**

四种骨架（`references/03-body-skeletons.md`）：

| 骨架 | 适合 | 结构 |
|---|---|---|
| 亲历型 | 有真实过程 | 场景 → 具体动作 → 结果（带数字）→ 反常识发现 |
| 清单型 | 有多个可并列项 | 一句结论 → 逐项（每项：是什么+多少钱+适合谁）→ 淘汰了哪个 |
| 对照型 | 有可比对象 | 两个对象 → 三个维度比 → 谁赢在哪 → 我的选择 |
| 拆解型 | 有专业信息 | 一个现象 → 为什么会这样 → 三个判断方法 → 一个反例 |

正文长度：图文 400–700 字（经验值，随类目差异大；知识类可到 900）。短不是优点，信息密度才是。

**第 4 步：写前 3 行。** 折叠前只露 3 行，这 3 行必须交出具体承诺。

- ✅ `手裂到开口那天我换了第四支，才发现不是缺水。三支的钱白花了，说说区别。`
- ❌ `大家好，今天想和姐妹们聊聊护手霜这个话题。`

**第 5 步：埋一个能回答的问题。** 放正文倒数第二段或首评。问题必须指向具体对象，答案自带信息。

**第 6 步：首评。** 首评是自己发的第一条评论，作用是补充正文放不下的信息，或把问题抛出去。30 字内，一句话。

**第 7 步：标签 3+3+2。**

- 3 个品类词（别人搜这个品类时能搜到你）
- 3 个场景词（人群/季节/使用场景）
- 2 个长尾或人群词

不许堆无关热词。堆热词会被判不相关，且拉低账号垂直度。详见 `references/04-tag-and-search.md`。

**第 8 步：配图脚本。** 每张图写清拍什么、什么光、几张。

- 封面 1 张（按第 2 步）
- 信息图 1–2 张（价格、对比、步骤）
- 实拍 2–4 张（场景、细节、上手）

**第 9 步：交 04 质检。** 不在 03 自评通过，直接送闸。

## 判断条件

- 标题 5 个里有 3 个以上是同一个结构 → 重写，用户没有选择余地。
- 正文里出现"品质""高端""性价比之王"这类无信息形容词 → 替换成具体事实，替换不了就删句。
- 所有数字都能在素材卡里找到出处；找不到的，改成定性描述或标 `〔待补〕`。
- CTA 只能有一个。收藏理由 / 求同款 / 蹲后续，三选一。

## 输出格式

严格用 `templates/T4-note-card.md`。六块齐全，正文区保持干净（不夹批注），批注统一放卡片末尾"可选微调"。

## 异常处理

| 异常 | 处理 |
|---|---|
| 素材撑不起 400 字 | 缩到 300 字以内的单点笔记，不注水。宁可短 |
| 用户要求"写得高级一点" | 高级 = 具体 + 克制。少用形容词，多给事实；把"高级感"翻译成可执行动作 |
| 用户要求必须出现品牌名 | 出现，但放在第三段之后，且配一个具体事实（克数/价格/成分），不做开头植入 |
| 用户要求写"全网最低" | 拒绝，改"我比对到的价格是 X，你那边多少" |
| 五种标题结构都想试 | 5 个标题里挑 3 类已覆盖，剩余 2 个可重复结构，但不能全同 |
