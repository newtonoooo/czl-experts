# 工序 01 · 定位

## 名称

定位（Positioning）—— 把"我想做小红书"变成一句能落地的话。

## 职责

决定这个账号**对谁说话、给什么、凭什么**。产出三个互斥的备选角，每个角都能直接推出选题。

定位不是写简介。定位是**排除**：明确不服务谁，不写什么。

## 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `material_card` | 是 | 00 工序的素材卡 |
| `account_state` | 是 | 新号 / 有粉不动 / 转型；粉丝量级、历史内容类型 |
| `capacity` | 是 | 每周能出几篇、能不能出镜、有没有拍摄条件 |
| `goal` | 否 | 涨粉 / 带货 / 引流到私域 / 品牌。缺省涨粉 |

## 执行步骤

**第 1 步：写定位句。** 一句话四段式，缺一段不算定位：

```
对〔具体人群〕，在〔具体场景〕，我给〔具体东西〕，凭〔可验证的证据〕。
```

- ✅ `对租单间的年轻女生，在搬家第一周，我给「2000 元内把空房填满」的清单，凭我自己搬过三次的账单。`
- ❌ `分享美好生活，记录日常` —— 四段全缺。
- ❌ `专注家居好物推荐` —— 有人群没有场景，有东西没有证据。

**第 2 步：出三个互斥的角。** 互斥的标准：至少一维不同。

| 维度 | 举例 |
|---|---|
| 人群不同 | 学生党 / 上班族 / 宝妈 |
| 场景不同 | 搬家 / 通勤 / 熬夜 |
| 证据类型不同 | 亲测账单 / 对比测评 / 行业内部视角 |

三个角都长得一样（都在讲"好物推荐"）就是没做定位，重来。

**第 3 步：每个角给三条内容支柱。** 支柱 = 能连续写 10 篇不重复的方向。

每条支柱必须能对上素材：`这条支柱我手上有没有料？没有的话多久能补到？`

**第 4 步：写"不写什么"。** 一句话说清排除项：

- 不写没用过的东西
- 不写超出预算 3 倍的东西（读者对不上）
- 不写成分科普（我讲不过专业号，这是拿短板打人家长板）

这一步经常被跳过，但它比"写什么"更能决定账号能不能立住。

**第 5 步：选角。** 三选一，给推荐理由，理由必须包含"为什么另外两个不选"。

## 判断条件

- 三个角不互斥 → 重做第 2 步。
- 某个角的三条支柱里，有两条拿不出素材 → 这个角是幻觉，删掉。
- 用户已有 5000 粉以上且内容稳定 → 跳过本工序，直接进 02，只做轻微收拢。
- 用户想同时做两个完全不同的赛道（如美妆 + 考研）→ 明说这是两个号，让他选一个，不帮他"融合"。

## 输出格式

用 `templates/T2-position-card.md`：

```
定位句（主推角）：对〔人群〕，在〔场景〕，我给〔东西〕，凭〔证据〕。
备选角 A / B：各一句 + 互斥点说明
内容支柱（3 条）：方向 + 现有素材量 + 缺口
不写什么：3–5 条
推荐与理由：选哪个、为什么另外两个不选
账号简介（1 句，20 字内）
```

## 异常处理

| 异常 | 处理 |
|---|---|
| 用户说"我也不知道自己有什么特别的" | 换问法，问他三个具体问题：上次别人夸你什么、你比同事多花了钱在什么上、你在这个事上踩过什么坑。答案里通常就是角 |
| 用户坚持要"什么都能发" | 明说后果：内容不聚拢，标签打不住，推荐流量散。给"主线 + 20% 杂项"的折中方案 |
| 用户身份是品牌方而非个人 | 定位对象换成"使用者"而不是"品牌"，品牌视角写不出人味 |
| 用户要模仿某个大号 | 可以学结构，不能学人设。给"同结构 + 你的证据"的替换版 |

## 与其他工序的关系

- 前置：`00 收料`。
- 后继：`02 选题`。定位卡的"三条支柱"直接变成选题矩阵的三个分组。
- 回流：`06 复盘` 若发现某类内容持续跑不动，回到本工序检查是不是支柱选错了，而不是改稿。
