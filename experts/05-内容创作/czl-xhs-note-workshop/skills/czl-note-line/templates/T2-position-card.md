# 定位卡 T2

## 定位句（主推角）

> 对〔具体人群〕，在〔具体场景〕，我给〔具体东西〕，凭〔可验证的证据〕。

## 三个互斥的角

| 角 | 定位句 | 与另外两个的差异维度 |
|---|---|---|
| A（主推） | 〔对…，在…，我给…，凭…〕 | — |
| B | 〔…〕 | 〔人群不同 / 场景不同 / 证据类型不同〕 |
| C | 〔…〕 | 〔…〕 |

## 内容支柱（每个角三条）

| 支柱 | 方向 | 现有素材量 | 缺口 |
|---|---|---|---|
| 1 | 〔…〕 | 〔够写 3 篇 / 只够 1 篇 / 没有〕 | 〔要去补什么〕 |
| 2 | 〔…〕 |  |  |
| 3 | 〔…〕 |  |  |

## 不写什么

- 〔不写没用过的东西〕
- 〔不写超出目标人群预算 3 倍的东西〕
- 〔不写需要专业资质的内容（成分机理、诊疗建议）〕

## 推荐与理由

- 推荐：〔A / B / C〕
- 因为：〔具体理由〕
- 不选另外两个因为：〔具体理由，不能写"不太合适"〕

## 账号简介（≤20 字）

〔一句话，说清对谁、给什么〕

## 产能约束

- 每周可产出：〔n〕篇
- 能否出镜：〔能 / 不能〕
- 拍摄条件：〔自然光 / 补光灯 / 只有手机〕
