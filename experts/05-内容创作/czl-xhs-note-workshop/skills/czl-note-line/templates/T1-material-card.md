## 素材三问

| 问 | 结果 | 依据 |
|---|---|---|
| 有具体物（数字/价格/时间/地点/可拍动作） | ☐ 有 ☐ 无 | 〔列出命中的具体物〕 |
| 有对照组（前后/别家我家/买前买后） | ☐ 有 ☐ 无 | 〔对照组是什么〕 |
| 有代价（钱/时间/坑/放弃） | ☐ 有 ☐ 无 | 〔代价是什么〕 |

**命中数：〔0 / 1 / 2 / 3〕 → 产能：〔不能写 / 短笔记 / 正式笔记 / 可拆多篇〕**

## 可切角度预判

- 〔亲历：可以写"用了 60 天"这条线〕
- 〔账单：有价格和购买次数，可切〕
- 〔拆解：缺成分信息，暂时切不动〕

## 风险项

- 〔例："修复"涉及功效暗示，正文不能用〕
- 〔例：截图含他人昵称，需打码〕
