# 合规红线

这一份是工作用清单，不是法律意见。规则会变，发布前以最新官方文本和平台规则页为准。

清单的作用是**在写的时候就避开**，不是发出去之后去申诉。命中的处理方式一律是"给替换写法"，不是"删掉算了"——删掉信息，笔记就废了。

---

## 一、绝对化用语

依据：《广告法》第九条明确禁止使用"国家级""最高级""最佳"等用语。实践中被认定属于绝对化表述的词远多于这三个。

| 类型 | 常见词 | 替换写法 |
|---|---|---|
| 最高级 | 最、最好、最强、最低价、最优、第一、首个、唯一、独家 | 给出可核对的比较：`我比对到的 6 个链接里最低` |
| 绝对 | 100%、绝对、彻底、永久、永不、根治 | 给条件：`连续用 30 天，我的情况是…` |
| 权威背书 | 国家级、国家级认证、专家推荐、央视推荐、官方指定 | 删掉，或写清具体机构与文件号（须真实存在） |
| 排他 | 全网独家、仅此一家、无人能及 | 删掉 |

判断方法：**能不能被验证为假？** 不能验证的最容易踩线；能验证但你没验证的，更容易出事。

## 二、功效与医疗暗示

这一条是美妆、护肤、食品、保健类最容易踩的。

| 场景 | 不能出现 | 可以说 |
|---|---|---|
| 护肤/个护 | 修复、治疗、消炎、杀菌、祛痘、祛斑、抗敏、去湿疹 | `我这边用下来，第二天没那么紧`（限于个人体验，且须真实） |
| 食品 | 减肥、瘦身、降三高、排毒、增强免疫、防癌 | `我一顿吃这个，热量大概 300 大卡`（客观数据） |
| 保健食品 | 任何疾病预防、治疗功能；且必须标注"本品不能代替药物" | 只能在批准的功效范围内表述 |
| 医疗器械 | 无资质不谈疗效 | 只描述使用感受，不做效果承诺 |
| 教育 | 保证通过、保过、包就业、提分 XX 分 | `我自己的备考时间安排是这样` |
| 金融 | 保本、保收益、稳赚、必涨 | `我自己的持仓比例，不构成建议` |

核心原则：**说自己的经历，不说产品的功能。** `我用了之后手不那么紧` 是经历；`这个能修复屏障` 是功能宣称，需要依据。

## 三、站外导流

平台普遍不允许把用户导到站外。以下都算：

- 直接写微信号、手机号、二维码
- 谐音、拆字、拼音首字母（`V：xxx`、`薇`、`+v`）
- `私我`、`评论区留联系方式`、`主页看简介`
- 引导到其他平台（`去某宝搜…`、`某红书同名`）
- 图片里藏二维码或水印联系方式

替换：把交易动作留在平台内（店铺链接、商品卡）。需要在平台内沟通的，用平台自带的私信功能，不在正文里引导。

## 四、虚假体验与虚假数据

依据：《反不正当竞争法》对虚假宣传有明确约束；平台对"未使用宣称使用"也有处置规则。

| 行为 | 判定 | 处理 |
|---|---|---|
| 没用过写"亲测""自用三年" | 虚假体验 | 必须改。改成第三方观察或删掉 |
| 编造销量、回购率、好评数 | 虚假数据 | 必须删。要写就写真实可查的 |
| 摆拍"使用前后"但条件不一致 | 误导性对照 | 重拍，条件一致；做不到就不做对照 |
| 收了钱写"纯自费" | 隐瞒利益关系 | 须披露合作，按平台报备 |
| 搬运他人图片当自己的 | 侵权 + 虚假 | 不用，或用并注明来源且获授权 |

这一条比极限词更危险：极限词通常是被判违规，虚假体验可能同时涉及民事与行政责任。

## 五、AI 生成内容

国家层面对人工智能生成合成内容有标识要求（相关规定自 2025 年 9 月起施行），平台也有对应规则。要点：

- 由 AI 生成的图片、视频、音频内容，按要求需要做标识
- 平台发布环节通常提供"AI 生成"声明选项
- 笔记正文全部或主要由 AI 生成且涉及事实陈述时，风险更高

操作建议：AI 生成或大幅修改的视觉素材，发布时如实勾选声明；正文里的事实必须来自真实素材，不能由模型补。

**不要把这条当形式。** 声明是低成本的，被判定隐匿才是高成本的。

## 六、其他易忽略的红线

| 类型 | 注意 |
|---|---|
| 未成年人 | 不出现未成年人带货、不诱导未成年人消费、不使用未成年人形象做推广 |
| 他人隐私 | 截图里的昵称、头像、手机号、地址一律打码 |
| 医疗场景 | 医院、诊室、病床背景出现真人时，需注意肖像与隐私 |
| 危险行为 | 不展示可能被模仿的危险操作（明火、高空、药物混用） |
| 迷信与玄学 | 不做运势承诺、不做"转运""化解"类功效表述 |
| 竞品贬损 | 不点名贬低同行；对比只比可验证的参数 |

## 七、发布前四问

1. 全篇有没有一个词，是我无法证明的"最/第一/唯一"？
2. 有没有把"产品功能"写成"我的经历"，或者反过来把"我的经历"写成了"产品功效"？
3. 有没有任何形式把用户往站外引？
4. 所有"我做过"的事，我是不是真的做过？

四问全过，再走人味闸。
