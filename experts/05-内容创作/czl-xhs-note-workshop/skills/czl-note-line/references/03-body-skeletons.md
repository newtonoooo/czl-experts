# 正文骨架

正文不是作文。正文是一份**读者愿意看完的说明书**。

小红书的正文有两个物理约束：折叠前只露约 3 行；读者在手机上滑动，段落长了会跳。这两条决定了写法。

---

## 一、前 3 行预算

折叠线之上大约 3 行字。这 3 行要交出**读者能得到什么**。

三种能用的开头：

| 型 | 例 | 作用 |
|---|---|---|
| 结论先行 | `手霜不是越厚越好，涂完十分钟还黏的那支，我停了。` | 给判断 |
| 代价开场 | `三支加起来 217 块，只有一支没白买。` | 给可信度 |
| 场景切入 | `成都十一月，手背裂口那道印子，我到第三年才知道怎么处理。` | 给画面 |

三种不能用的开头：

- `大家好，我是××，今天想和大家聊聊…` —— 自我介绍占掉了全部预算
- `最近很多姐妹私信问我…` —— 没有信息，只有铺垫
- `这个话题我憋了很久…` —— 情绪铺垫，读者不欠你耐心

## 二、四种骨架

### 骨架 A：亲历型

适合有真实过程的事：用了多久、去了哪、做了什么。

```
场景（1 段，给画面）
    ↓
具体动作（2–3 段，我做了什么，越具体越好）
    ↓
结果（1 段，带数字）
    ↓
反常识发现（1 段，我原来以为 X，其实是 Y）
```

判断标准：读者看完能不能复现你的动作。不能复现，就是情绪文，不是亲历文。

### 骨架 B：清单型

适合多个可并列项：好物、方法、清单。

```
一句结论（这篇解决什么）
    ↓
逐项：是什么 + 多少钱 + 适合谁（每项 2–3 行，不展开）
    ↓
淘汰了哪个，为什么（这一步最值钱，别人都不写）
```

要点：**每项都要有价格或数量**。没有量的清单是目录，不是内容。
关键：一定要写"淘汰了什么"。只写留下了什么，读者会怀疑你什么都推荐。

### 骨架 C：对照型

适合有可比对象：两个产品、两种做法、前后变化。

```
两个对象（各一句，说清是什么）
    ↓
三个维度逐个比（每个维度给一个可感知的观察，不是参数表）
    ↓
谁赢在哪（明确结论，不要"各有千秋"）
    ↓
我的选择与理由
```

要点：对比维度必须**能感知**。`保湿力`是不可感知的，`涂完十分钟后手背还黏不黏`是可感知的。

### 骨架 D：拆解型

适合有专业信息：成分、原理、行业规则、判别方法。

```
一个现象（大家都会遇到的困惑）
    ↓
为什么会这样（1–2 段，讲清机制，不堆术语）
    ↓
三个判断方法（可当场用）
    ↓
一个反例（什么情况下这套不成立）
```

要点：术语出现必须立刻翻译成日常说法。`封闭性保湿剂` → `在皮肤表面盖一层油膜，水出不去`。
反例不能省。没有反例的科普像广告。

## 三、互动埋点

评论要被"邀请"出来，不是被"要求"出来。

| 位置 | 埋法 | 例 |
|---|---|---|
| 正文倒数第二段 | 具体提问，指向对象 | `你们那边超市这个卖多少？我这边 39` |
| 首评 | 补充信息 + 抛问题 | `补一句：这支含香精，介意的话看第二支` |
| 正文中间 | 留一个未解的细节 | `第二步我到现在也没搞明白为什么，有人知道吗` |

三种无效提问：

- `你们觉得呢` —— 没有对象
- `你们也这样吗` —— 只能答一个字
- `评论区告诉我` —— 命令式，且没说告诉什么

## 四、CTA 三选一

一篇只用一个。用两个等于没有。

| CTA | 话术 | 适合 |
|---|---|---|
| 收藏理由 | `下次买之前翻出来对一遍` | 清单、对照、方法 |
| 求同款/求补充 | `你们有更好的说一声，我加进来` | 测评、合集 |
| 蹲后续 | `第二支还没试完，试完再说` | 连载、长期测试 |

`点赞关注不迷路`这类通用 CTA 不放正文。它不提供信息，只增加噪声。

## 五、长度与排版

| 项 | 建议 | 理由 |
|---|---|---|
| 字数 | 400–700（知识类可到 900） | 低于 300 难以交付价值，高于 900 完读率下降 |
| 段落 | 每段 1–3 行 | 手机上一屏约 5–7 行 |
| 空行 | 段间必空一行 | 密集文本在手机上会跳读 |
| emoji | 全文 ≤5 个，且不用于分段装饰 | 每段开头一个 emoji 是最典型的机器味 |
| 序号 | 用 `1.` `2.` 或 `①②`，全文统一一种 | 混用显得随手 |

## 六、正文自检

1. 前 3 行有没有具体承诺？
2. 每个数字能不能在素材里找到出处？
3. 段落有没有超过 4 行的？
4. 有没有一段是完全没有功能的（纯过渡、纯抒情）？—— 允许有一两段，多了就是水。
5. 埋的那个问题，能被具体回答吗？
6. CTA 是不是只有一个？
7. 把正文读出声，有没有哪句你作为真人不会这么说？
