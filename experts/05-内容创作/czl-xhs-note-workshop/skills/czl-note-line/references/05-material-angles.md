# 素材十二切

同一条素材，切法不同，能出的笔记数量差三倍。只会"亲历"一种切法的人，一条料只能写一篇，写完就断粮。

以下十二种切法，每一种都写清：需要什么料、出什么形态、什么情况下切不动。

---

## 一、事实类（有具体物就能切）

### 1. 亲历角

- **需要**：一段真实发生过的过程，带时间线
- **形态**：场景 → 动作 → 结果 → 反常识
- **例**：`连续 21 天不点外卖，账单少了 640`
- **切不动**：用户没做过，只有"听说"

### 2. 对照角

- **需要**：两个可比对象，一个共同维度
- **形态**：两方 → 三维度 → 谁赢 → 我的选择
- **例**：`39 的和 168 的，差在涂完十分钟`
- **切不动**：只有一个对象，或两个对象不在同一量级

### 3. 拆解角

- **需要**：一个能讲清机制的信息（成分、原理、规则）
- **形态**：现象 → 为什么 → 三个判断法 → 反例
- **例**：`为什么涂完还是干：不是水不够，是油膜没了`
- **切不动**：用户只有结论没有机制，硬讲会出错

### 4. 账单角

- **需要**：一串真实支出数字
- **形态**：总额 → 逐项 → 哪笔值哪笔亏 → 重来会怎么花
- **例**：`搬一次家花了 4300，其中 1100 是白花的`
- **切不动**：只有模糊印象（"花了不少"）

---

## 二、选择类（有取舍就能切）

### 5. 清单角

- **需要**：三个以上可并列项，每项有价格或数量
- **形态**：一句结论 → 逐项（是什么/多少钱/适合谁）→ 淘汰了哪个
- **例**：`试了 12 支，留下 3 支，条件只有两个`
- **切不动**：只有一两项，凑数会注水

### 6. 淘汰角

- **需要**：明确放弃过的东西，以及放弃的理由
- **形态**：放弃了什么 → 为什么 → 换成什么 → 换完的差别
- **例**：`我把家里的不粘锅全扔了，换成一口铁锅`
- **切不动**：用户不敢说缺点（怕得罪品牌）

### 7. 避坑角

- **需要**：真实踩过的坑，最好带损失
- **形态**：坑是什么 → 怎么踩进去的 → 损失多少 → 怎么识别
- **例**：`装修第三个月才知道，这句话是报价单里的坑`
- **切不动**：坑是"听说别人踩过"，不是自己踩的

### 8. 时间线角

- **需要**：跨时间的记录（照片、数据、账目）
- **形态**：起点 → 关键节点 → 现在 → 回看最有效的一步
- **例**：`第 1 天 / 第 30 天 / 第 90 天，同一面墙`
- **切不动**：没有留存历史记录，事后补不出来

---

## 三、场景类（有处境就能切）

### 9. 场景还原角

- **需要**：一个具体场景的细节（时间、地点、在场的人）
- **形态**：还原那一刻 → 当时的处理 → 事后想来该怎样
- **例**：`凌晨两点在急诊排队，我才知道家里该备什么`
- **切不动**：场景是拼凑的，细节经不起追问

### 10. 工具流角

- **需要**：一套自己常用的流程和工具
- **形态**：我的一天/一周怎么运转 → 每个环节用什么 → 省下多少时间
- **例**：`一个人带娃做饭，我靠三个锅和一张表`
- **切不动**：流程是临时想的，没真跑过

### 11. 提问征答角

- **需要**：一个自己没解决的问题，且问题足够具体
- **形态**：我遇到什么 → 我试过什么 → 卡在哪 → 求具体经验
- **例**：`手裂口反复三个月，试过四种，还是不行，有人真治好过吗`
- **切不动**：问题太宽（"怎么护肤"没人答得上来）
- **注意**：这类内容价值在评论区，正文要给足背景，否则没人愿意答

### 12. 反面教材角

- **需要**：自己做砸过的事，且能说清原因
- **形态**：我做错了什么 → 当时怎么想的 → 错在哪 → 正确做法
- **例**：`第一次装修，我把钱全花在了看不见的地方`
- **切不动**：用户不愿意暴露失败

---

## 切法组合表

一条素材命中三问中的两问以上，通常能切出 2–4 个角。常见组合：

| 素材特征 | 可切角 |
|---|---|
| 有过程 + 有花费 | 亲历 + 账单 + 淘汰 |
| 有对比 + 有价格 | 对照 + 清单 + 淘汰 |
| 有专业信息 + 有实测 | 拆解 + 避坑 + 亲历 |
| 有失败经历 | 反面教材 + 避坑 + 提问征答 |
| 有长期记录 | 时间线 + 亲历 + 场景还原 |

**一条素材切出来的多篇，必须间隔 ≥5 天发**（见工序 05）。同一周连发同素材的不同角，读者会觉得你在重复。

---

## 什么样的素材切不动

判断很简单：**能不能拍出一张具体的图？**

- 能拍出来（有物件、有场景、有屏幕）→ 至少能切两角
- 拍不出来（全是感受和评价）→ 一个角都切不动，回去补料

这条比任何方法论都实用。
