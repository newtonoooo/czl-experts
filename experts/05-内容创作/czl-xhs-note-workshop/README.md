## 这是什么

一条把素材变成笔记的生产线。

你把手上有的东西丢进来——产品资料、一次真实经历、店里拍的照片、课程大纲、竞品截图——它按七道工序往下走：收料、定位、选题、成稿、质检、排期、复盘。出来的不是"思路"和"建议"，是一张**能直接按下发布的笔记卡**：5 个标题候选、封面三行字、整段可复制的正文、首评、8 个标签、配图脚本。

它不是账号运营顾问。投放、达人报价、代运营不在范围内。

## 和"多问几个选题"的区别

三样东西是真实实现，不是话术：

**一、两道闸，机器先过一遍。**
发布前必须过合规闸和「人味闸」。前者查绝对化用语、功效暗示、站外导流、虚假体验、AI 内容标识；后者查中文 AI 腔十二种（替读者总结、每段都有功能、三段排比、结尾升华等）。这两道闸有可执行脚本 `note_lint.py`，41 条规则，输出命中项与改法，退出码可直接串进流水线。不服判定，它把命中的原句列给你看。

**二、四个判断器，判断比写作值钱。**
素材能不能写（三问）、标题有没有自答、前 3 行值不值得展开、有没有埋一个能被具体回答的问题。这四条当场能用，不需要工具。

**三、复盘给的是唯一动作，不是五条建议。**
四级漏斗（曝光 → 点击 → 互动 → 转化）定位断在哪一级，只给 1 个下一轮动作，并要求写清验证时点。给五个动作等于没给。

## 七道工序

| # | 工序 | 产出 |
|---|---|---|
| 0 | 收料 | 素材卡 + 缺口清单 |
| 1 | 定位 | 定位卡（3 个互斥的角） |
| 2 | 选题 | 选题矩阵（≥20 行，带优先级） |
| 3 | 成稿 | 笔记卡 |
| 4 | 质检 | 通过 / 打回清单（硬闸） |
| 5 | 排期 | 7/14/30 天发布日历 |
| 6 | 复盘 | 诊断表 + 唯一动作 |

## 三个脚本

纯 Python 3 标准库，不装依赖、不连网、不登录、不依赖任何 MCP 服务。

```bash
# 笔记体检：41 条规则，退出码 0 通过 / 1 阻断 / 2 输入错误
python skills/czl-note-line/scripts/note_lint.py 笔记卡.md --json 报告.json

# 生成发布日历：自动拉开同素材间隔，标出留白与未排项
python skills/czl-note-line/scripts/build_calendar.py 选题.csv --start 2026-11-01 --per-week 3 --days 30 --out 日历.csv

# 整链自测：18 项检查，结果可复现
python skills/czl-note-line/scripts/selftest.py
```

## 试试这样问

- 我手上有一款护手霜和二十几条用户反馈，想在小红书起号。帮我把素材切成选题，先写 5 篇能直接发的笔记。
- 上一篇笔记曝光 3000、点击 120、点赞 9。封面和标题都在这里，帮我判断问题出在哪一级，下次改什么。
- 我一个人做账号，每周只能出 3 篇。帮我排一个 30 天的发布日历，素材要能反复用。

## 安装

把整个目录放到专家目录下：

```
%WORKBUDDY_CONFIG_DIR%/plugins/marketplaces/my-experts/plugins/czl-xhs-note-workshop/
```

然后注册（让它在专家中心可见）：

```bash
python <expert-manager 目录>/scripts/register_expert.py <本目录>
```

## 边界

不做代发布、不做养号刷量、不做批量搬运他人内容；不写用户没亲历的经历；不写医疗诊断、投资建议；不做未成年人带货。

平台规则会变，合规词表是下限不是上限。发布前请以自己的后台提示和平台最新规则为准。
