## 这是什么

一套把"网文写作"拆成七道可验收工序的工具。它不生产"看起来像小说的文字"，它生产的是一本**经得起自己检查**的书。

和大多数写作助手的区别只有一条：**我说的每一句"有问题"，都有数字和段号跟着。**

## 三十秒上手

装好之后，第一次说话可以直接给一句：

> 我想写一本末世女主的书，不要感情线，发在番茄，大概 100 万字。

它会先判断这条路能不能走，给三个卖点方向和三个书名，然后问你要不要直接写开篇。

如果你已经有稿子：

> 我这本书写到第 87 章了，手上有 30 万字旧稿。

它会先建档案、反推人物与伏笔、跑一次结构核查，然后告诉你欠什么。

## 七道工序

| 工序 | 你什么时候会用到 | 它给你什么 |
|---|---|---|
| 侦察 | 还没想好写什么 / 书名定不下来 | 赛道判断、三个卖点、三个书名 |
| 架构 | 要立设定、排大纲、设计开篇 | 可判定的规则表、人物卡、卷章大纲 |
| 铸造 | 要写正文 | 写作包 + 正文 |
| 调音 | 稿子读着像机器写的 | 14 项指标、分数、定位到句的改法 |
| 台账 | 每章写完 / 隔天回来 | 写到哪、欠什么、下一步 |
| 诊断 | 追读掉了 | 掉点定位 + 改稿工单 |
| 交付 | 要投稿 / 要导出 | 简介三版、标签、样章、全本 |

**顺序不能乱**，尤其这两条：
- 正文没过"调音"不许入档。
- 档案有阻断项不许写下一章。

## 三个常用命令

在作品目录里跑（需要 Python 3.9+，无第三方依赖）：

```bash
# 建项目
python skills/czl-continuity-keeper/scripts/nproj.py init --dir . --title "书名" --target 1000000

# 每章：体检 → 入档
python skills/czl-voice-tune/scripts/voice_scan.py chapters/ch-001.md --json qc/ch-001.report.json
python skills/czl-continuity-keeper/scripts/nproj.py commit --dir . --chapter 1 --file chapters/ch-001.md --title "章名"

# 结构核查
python skills/czl-continuity-keeper/scripts/lint_project.py --dir .
```

## 人味体检看什么

14 项，其中四项是阻断项（不清零不交付）：

| 项 | 阈值 | 为什么卡它 |
|---|---|---|
| 连续短句 | 最长连排 < 3 | 碎片化节奏是最明显的机器指纹 |
| 破折号密度 | ≤ 2 处/千字 | 破折号被当成节拍器用 |
| 「不是…而是」 | ≤ 1 处/章 | 作者在替读者做判断 |
| 万能词/陈词 | < 5 处 | 「寂静」「诡异」「瞳孔一缩」不携带画面 |

其余十项是提示项，可结合语境豁免，但豁免要写理由。

## 常见问题

**Q：能模仿某位作者的文风吗？**
A：不模仿具体作者。可以给语感参数（平均句长、对话占比、描写密度、比喻密度），照参数写出来的是你的东西。

**Q：能保证签约/爆款吗？**
A：不能。它只负责把稿子里能被检查出来的问题清掉。

**Q：没有 Python 怎么办？**
A：七道工序照走，但档案和人味体检无法落盘核验。这种情况下它会明确告诉你"未经脚本核验"，不会假装检查过。

**Q：写到一半想改前面的设定？**
A：改，但要重跑结构核查。已入档的章会被标"待复核"，拦着你不许往前写——这是故意的。

## 边界

- 不复制他人作品，不做真实作者风格模仿。
- 不承诺过稿、签约、收益。
- 不代投、不刷量。
- 涉政、涉黄、涉未成年人不当内容一律不写。

## 头像说明

专家头像为虚拟人物插画，由生成式图像工具产出后经人工处理（裁去工具角标、缩放到 512×512、降色压缩）。人物为虚构角色，不使用任何真人肖像，原图留档不随包分发。
