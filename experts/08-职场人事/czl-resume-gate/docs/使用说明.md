# 使用说明 · 简锋

面向使用者的操作手册。不需要懂脚本，按第一种用法直接说人话就行。

---

## 一分钟上手

在 WorkBuddy 里选中「简锋」，然后：

```
帮我看看这份简历能不能过初筛。

（把简历粘在下面；有目标岗位的 JD 也一起粘上来）
```

它会先告诉你**卡在哪一关**，再给不超过 6 条必须改的地方，每条都带"证据"和"改成什么"。

---

## 五种常见用法

### 1. 我不知道为什么投了没回音

```
我投了 40 份，只有 2 个面试。帮我看看问题在哪。
[简历]
```

→ 得到：三闸门评分 + 致命项清单 + 一句结论（能投 / 小修 / 必须重写 / 重建）。

### 2. 我知道有问题，但不知道改哪句

```
帮我把工作经历改一版，太像岗位说明书了。
[简历第 2 段]
```

→ 得到：逐条 Before→After（一次 3-5 条）+ 需要你自己回填的数据清单。

### 3. 我要投一个具体岗位

```
这是我的简历，这是 JD。帮我看看差在哪，能改的先改。
[简历] [JD]
```

→ 得到：JD 四栏拆解 + 覆盖矩阵 + 三类缺口（真缺 / 可迁移 / 要提前）+ 投递建议。

### 4. 我要出文件

```
把改好的简历导成 Word 和能打印的版本，文件名按"姓名-岗位"。
```

→ 得到：`.docx` + A4 打印版 `.html` + `.txt`（平台在线填表用）+ 六项自查结果。

### 5. 我要从零写

```
我从零写，5 年产品经理，投 SaaS 公司。
```

→ 它会先给骨架（章节 + 每段该放什么），你确认后再填内容。不会一上来给你一篇模板文。

---

## 它会做什么、不会做什么

**会**

- 指出你的简历会死在哪一关，并给具体改法
- 把"负责 X"改成"做了什么、做到什么程度"
- 告诉你哪些数字必须自己补，以及补不上时怎么退一步写
- 拆 JD，把"可迁移"的经验捞回来（很多人低估了自己）
- 出 Word / 打印版 / 纯文本三种文件

**不会**

- 替你编数字、编经历、编职级
- 承诺"改完一定能过"
- 给"女生别写婚育""35 岁要藏年龄"这类建议
- 帮你自动投递

---

## 关于数字：它一定会问你

这是它最不讨喜的地方，但也是最有用的一点。

它不会写"提升了 30%"，它会写：

```
【待补：这次活动带来了多少新增用户？基数是多大？统计了几天？】
```

补不上时它会给你退路：**用规模替代效果**——"覆盖华北 12 家门店、持续 2 周"，比一个编出来的百分比安全得多。

面试第三轮深挖、入职背调、试用期第一次汇报，编的数字在这三处都会爆。

## 自己跑脚本（可选）

如果你想自己看机械指标，在专家包目录下执行：

```bash
# 体检
python skills/resume-audit/scripts/resume_audit.py 我的简历.md

# 带 JD 一起
python skills/resume-audit/scripts/resume_audit.py 我的简历.md --jd 岗位.md

# 机器可读结果
python skills/resume-audit/scripts/resume_audit.py 我的简历.md --json

# JD 覆盖匹配
python skills/jd-tailor/scripts/jd_match.py --jd 岗位.md --resume 我的简历.md

# 导出
python skills/resume-export/scripts/md2docx.py 我的简历.md -o 张三-产品经理-5年.docx
python skills/resume-export/scripts/md2html.py 我的简历.md -o 张三-产品经理-5年.html --theme navy
python skills/resume-export/scripts/md2txt.py 我的简历.md -o 张三-产品经理-5年.txt
```

**打印成 PDF**：用 Chrome / Edge 打开生成的 .html → Ctrl+P → 纸张 A4 → 缩放 100% → 保存为 PDF。

需要 Python 3.8 以上，不需要装任何包。

---

## 文件命名与投递

```
张三-产品经理-5年-20261026.docx
```

不要用 `简历.pdf`、`我的简历最终版3(1).pdf`。HR 一天看两百份，文件名是第一个信号。

## 常见问题

**Q：评分 62 分是不是很差？**
分只用来排序问题。看致命项：0 条就能投，3 条就先改。不要追分数。

**Q：我没给 JD，能做吗？**
能。会跳过定制，只做体检和重写。但同一份简历投所有岗位，转化率必然低。

**Q：简历是图片/扫描件可以吗？**
不行。图片里的文字提取不出来，这本身就是第一个致命问题。先转成文本。

**Q：它会不会把我的公司名写错？**
不会改写任何事实性内容。所有公司、职位、时间、数据都保持你给的原样。

**Q：我的简历有身份证号、家庭住址，要删吗？**
建议删。这些信息不加分，而且有泄露风险。它会主动提醒。

**Q：英文简历支持吗？**
支持。英文简历按英文惯例处理：无照片、无生日、过去时、动词开头、一页（10 年以内经验）。

## 边界与免责

- 它的判断基于公开简历惯例与文本规则，**不掌握任何公司的内部筛选偏好**，也不保证录用结果。
- 简历内容的真实性由你自己负责。它只改表达，不改事实。
- 脚本在本地运行，不上传简历文本到外部服务。但如果你在对话中粘贴简历，请知悉对话内容会经过模型处理。
