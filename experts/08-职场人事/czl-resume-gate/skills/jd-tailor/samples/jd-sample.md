# 高级数据分析师（虚构岗位）

> 本文件为测试用虚构 JD，公司与团队信息均为编写样例。

## 岗位职责

1. 负责业务数据的日常监控与异常定位，定期产出经营分析报告；
2. 搭建并维护核心指标体系，统一跨部门数据口径；
3. 支持 A/B 测试的设计、执行与效果评估；
4. 与产品、运营协作，推动数据驱动的策略落地。

## 任职要求

1. 本科及以上学历，统计、数学、计算机相关专业；
2. 3 年以上数据分析相关工作经验；
3. 精通 SQL，熟悉 Python 进行数据处理；
4. 熟悉 Tableau 或 Power BI 等可视化工具；
5. 具备较强的沟通表达能力和跨部门协作能力。

## 加分项

1. 有用户增长或电商行业经验者优先；
2. 了解机器学习常用算法者优先；
3. 有数据建模经验者优先。
