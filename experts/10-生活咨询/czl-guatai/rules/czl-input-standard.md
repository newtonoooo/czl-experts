# 输入规范

本文件规定"什么样的输入才算能用"。凡不符合的，先修输入，不排盘。

## 一、八项字段

| 字段 | 必填 | 格式 | 常见错误 |
|---|---|---|---|
| 公历年月日 | 是 | `YYYY-MM-DD` | 把农历当年月日；把"85 年"当成 1985 而实际是民国 85 年 |
| 出生时刻 | 强烈建议 | `HH:MM`，24 小时制 | 把"下午三点"记成 03:00 |
| 性别 | 是 | 男 / 女 | — |
| 出生地 | 建议 | 城市名或经度 | 用籍贯代替出生地 |
| 历法口径 | 是 | 公历 / 农历 | 民族地区与老一辈常报农历 |
| 时辰来源 | 建议 | 记录 / 记忆 / 指定 | 把"我妈说我是中午"当成精确 12:00 |
| 是否闰月 | 农历必问 | 是 / 否 | 闰月与正常月紫微月序不同 |
| 时区 | 海外必问 | UTC±N | 直接用北京时间算海外出生 |

## 二、时间口径

- 用户报的时间默认是**当地标准时**。不要替他先换算真太阳时，交给引擎。
- 23:00–00:59 出生，默认按**晚子时**处理（23 点后日柱进次日）。若用户流派不同，显式切换。
- 出生时刻距节气交节 ≤ 60 分钟，必须提示：年/月柱以精确交节时刻为界。

## 三、完整度判级

| 级 | 判据 |
|---|---|
| S | 八项齐全，或提供了现成命盘 |
| A | 年月日时 + 性别齐全，缺出生地 |
| B | 缺时辰，或时辰存疑 |
| C | 只有问题 |

## 四、禁止的输入处理方式

- **禁止猜时辰**。宁可按 B 级轻量出盘，也不许"我猜你是卯时"。
- **禁止把用户的记忆当作记录**。记忆得来的时辰要标来源。
- **禁止静默修正**。用户给的日期与农历不符，要指出来，不能默默改掉。
- **禁止跨时区套用**。海外出生先换算当地标准时，再按当地经度校正。

## 五、冲突处理

用户提供的资料与引擎结果冲突时（例如用户说"我是甲子日"但引擎算出乙丑日）：

1. 以用户的**原始记录**（出生证明、医院记录）为准；
2. 若用户只是"印象"，以引擎为准，并说明差异；
3. 差异可能来自换日法、时区、农历闰月——逐项排查，不要一句"以你为准"了事。
