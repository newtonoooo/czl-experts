# 过白话（终稿翻译层）

**职责**：把已经算完、已经读完的东西，翻成一个普通人能读懂的版本。**盘不动、结论不改，只换说法。**

## 为什么要有这一步

盘面是给内行看的。用户里十个有九个不知道"伤官"是什么、"化忌"是什么意思、"体用"在讲谁。你直接把技术版丢过去，他只能点头，回家一想全是问号——**读不懂的结论等于没给结论**。

## 三条硬指标（不过就是没做完）

1. **第一段 ≤ 80 字**，能一口气念完，念完对方就知道你是什么人。
2. **每个术语当场翻译**，翻译方式必须是"生活里长什么样"，不是"某书里定义是什么"。
3. **每条判断后跟一句场景句**——"这在你身上大概是这样：……"，让人能对上自己的经历。

## 禁用词表（出现即视为未翻译）

`喜用神` `忌神` `用神` `身强` `身弱` `格局` `化忌` `化禄` `空亡` `旬空` `体用` `世应` `六亲` `建除` `值神` `十二长生`

这些词**不是不能说**，而是说了必须在同一句里翻掉。例如：

- ❌ "你身弱，喜印比"
- ✅ "你这盘自己是偏弱的，得靠外面的东西撑——学历、资质、平台背书这类，比硬扛有用"

- ❌ "伤官透干，见官为祸"
- ✅ "你嘴上有本事，说得出别人说不出的话；但在规矩很硬的单位里容易顶撞上级，这不是脾气问题，是你的表达方式太直接"

## 四步改写

### 第一步：先写一句话版

≤ 40 字，可以说给家人听的那种。

> 例：一个心细、嘴上厉害、靠本事吃饭的人，今年开始被推到要负责任的位置上。

### 第二步：写三段话

| 段 | 回答什么 | 篇幅 |
|---|---|---|
| 你是什么人 | 天生的运行方式：靠什么驱动、哪里弱、怎么耗自己 | 150–250 字 |
| 你现在在哪一段 | 大运/大限/流年 → 换成"哪十年、哪一年、在考什么" | 150–250 字 |
| 你能做什么 | 2–4 条能当天做的动作 | 100–150 字 |

### 第三步：术语对照表

三列：**术语 / 白话 / 在你身上**。第三列必须具体到他这一盘，不能是通用解释。

| 术语 | 白话 | 在你身上 |
|---|---|---|
| 伤官 | 表达和输出的那股劲 | 两个壬水透在月干和时干，说明你说话的锋利度是摆在明面上的，藏不住 |

### 第四步：把数字翻成感受

- 百分比 → "占几成"、"偏多/偏少"
- 大运 → "从 X 岁到 Y 岁这十年"
- 神煞 → "有一种外力：……"（不要用"贵人星"三个字打头）
- 空亡 → "这项目前是虚的，看得见摸不着"

## 诚实底线（改写不等于美化）

- **不许删掉不利信息**。财弱就说财弱，别说"你的财富格局独特"。
- **不许把"弱"说成"不好"**。偏弱是结构，不是评价。
- **不许为了好懂加因果**。"你财弱所以你会穷"是错的；"你财弱，所以靠运气型收入不稳，适合把本事做成可重复卖的东西"才对。
- **不许用比喻替代判断**。比喻只能帮忙理解，不能当结论。

## 输出格式

```
【一句话】
……

【你是什么人】
……

【你现在在哪一段】
……

【你能做什么】
1. ……
2. ……

【术语对照】
表格

【几个容易误解的地方】
- 你可能以为 X 是不好的，其实它指的是 Y
```

## 在流程中的位置

**最后一步，所有交付都要过。** 顺序：

```
出盘 → 读盘 → 过白话 → 过边界 → 交付
```

技术版**不要丢**：作为附录放在白话版后面（或另存一份），懂行的用户会要。

## 异常处理

| 情况 | 处理 |
|---|---|
| 用户本身懂命理 | 跳过本层，直接给技术版；或问一句"要不要白话版" |
| 内容太长翻不动 | 砍领域，不砍翻译。宁可只说三件事，也每件都说人话 |
| 某些结论本身不确定 | 白话版里也要标"这条把握不大"，不能因为说得顺就抹掉不确定性 |
| 涉及边界内容（疾病/官司/投资） | 先过 `czl-boundary-guard`，再翻白话；顺序不能反 |
