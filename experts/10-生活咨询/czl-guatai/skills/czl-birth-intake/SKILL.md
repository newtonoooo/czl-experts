# 生辰采集与完整度定级

**职责**：把用户嘴里零散、口语、带误差的出生信息，变成一张干净的输入卡，并且**说清楚这卡有多完整**。

## 为什么要这一步

排盘错，多半不是算错，是喂错。年份记成农历、时辰记错一小时、出生地当成了户籍地——错一项，盘就整体偏。这一步只做一件事：**在出盘前把误差掐掉**。

## 必收字段（八项）

| 字段 | 说明 | 缺了会怎样 |
|---|---|---|
| 公历年月日 | 优先公历；若给农历，先转公历再走 | 无法排盘 |
| 出生时刻 | 24 小时制到分钟 | 丢时柱；紫微丢命宫；八字起运无法定 |
| 性别 | 男/女 | 大运、大限的顺逆无法判 |
| 出生地 | 到市即可（用于取经度） | 真太阳时校正缺失，边界时辰可能错一格 |
| 历法口径 | 用户给的是公历还是农历 | 可能整体错一个月 |
| 时辰来源 | 记忆 / 出生证明 / 长辈口述 | 决定可信度 |
| 是否闰月 | 农历输入时必问 | 农历闰月错，月柱与命宫全错 |
| 现居地/时区 | 海外出生时需要 | 时区错，整盘错 |

## 完整度分级

| 级 | 判据 | 允许做到什么 |
|---|---|---|
| S | 八项齐全，或用户给出现成命盘截图 | 全量出盘 + 多体系交叉 + 出图 |
| A | 有年月日时 + 性别，无出生地 | 标准解读，按东八区标准时算并声明 |
| B | 年月日有，时无或存疑 | 只出三柱或并列两盘，聚焦结构，不下判断句 |
| C | 只有问题 | 转梅花/六爻/塔罗，或先问清需求 |

## 执行步骤

1. **复述确认**：把用户说的整理成一行，读回去让他点头。
   `公历 1990-06-15 约 08:30，女，四川成都出生，时辰为母亲回忆`
2. **判断历法**：用户报"1990 年五月廿三"这类，先问清是农历还是公历。若是农历，用 `oracle.py lunar --lunar 1990 5 23` 转公历，并确认是否闰月。
3. **取经度**：按出生地查常用城市经度（见 `czl-oracle-engine` 的参数表）。查不到就让用户给大致经度，或降级为 A 级。
4. **标记时辰可信度**：
   - 出生证明 / 医院记录 → 可直接用
   - 长辈回忆"大概早上" → 取区间中点算一次，同时把相邻时辰再算一次做对照
   - 完全不知 → 走 B 级
5. **算出真太阳时**：由引擎完成。若校正后跨了时辰，**必须提示**："按经度校正后为 07:25，落在辰时；若按标准时 08:30 则仍是辰时/巳时边界"——这类提示比结论本身更值钱。
6. **交底**：明确告知级别、缺项代价、本次结论的强度上限。

## 判断条件

- 校正后时辰变化 → 两盘并列，让用户用"更像哪一个"来选，不要替他选。
- 出生时刻距交节 ≤ 60 分钟 → 引 `nearby_terms` 提示，年/月柱以精确交节时刻为界。
- 用户在海外出生 → 先换算到当地标准时，再按当地经度校正；不要套东八区。

## 输出格式

```
输入卡
  公历：1990-06-15 08:30（女）
  农历：庚午年五月廿三（由引擎换算）
  出生地：成都 104.06°E
  真太阳时：07:25（经度差 -63.8 分，均时差 +16.0 分）
  时辰：辰时（校正后与校正前一致）
资料级别：A（缺出生地精确到区县，经度误差 < 0.5°，不影响时辰判定）
缺项代价：无关键缺项
```

## 异常处理

| 情况 | 处理 |
|---|---|
| 用户坚持"就是子时"但无记录 | 照做，但在输出里标"时辰来源：用户指定，未经记录核实" |
| 生日在 23:00–00:59 | 明确问一句用哪种换日法，默认 23:00 换日并说明 |
| 农历生日落在闰月 | 必须确认是闰月还是正常月，两者月柱相同但紫微月序不同 |
| 用户不愿给出生地 | 降 A 级，声明真太阳时未校正，边界时辰结论标注"待确认" |
