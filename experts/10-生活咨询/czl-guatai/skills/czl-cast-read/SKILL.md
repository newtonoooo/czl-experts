# 起卦与当下问事

**职责**：回答一个**现在时**的问题。不成立终身标签，只回答"这件事，此刻"。

## 一条铁律：三选一，不混用

梅花、六爻、塔罗是**三套独立体例**，混着读就是拿三把尺子量一个东西，越量越乱。

| 用户在问什么 | 用哪个 | 理由 |
|---|---|---|
| 快速看趋势、看大势、要一个"体用"的方向感 | 梅花易数 | 结构最轻，体用生克即可定性 |
| 具体事的成败、何时、谁占优势；有明确对手或标的 | 六爻纳甲 | 六亲、世应、动爻能落到具体对象与时间 |
| 心理层面、关系互动、我自己卡在哪 | 塔罗 | 面向处境与心态，不擅长判具体事件 |
| 用户指定体系 | 照用户 | 但要说清该体系答不了什么 |

## 一、梅花易数读法

**取盘**：`oracle.py meihua`（时间起卦），或 `--numbers A B`（用户报数）。

**读法三步**：
1. **体用定大势**：`ti_yong.relation`
   - 用生体 → 外部条件帮你，可进
   - 体生用 → 你在付出，防耗
   - 体克用 → 你能拿下，但费手
   - 用克体 → 外部压你，宜守
   - 比和 → 势均，看过程
2. **互卦看过程**：`hu` 是中间会发生什么。互卦见冲克，说明过程里有一道坎。
3. **变卦看落点**：`bian` 是最终形态。变卦比本卦和缓，则收得住；更烈，则中途会升级。

**动爻**：`moving_line` 指出变化从第几爻起。爻位对应阶段：初爻=事之初，二=内部，三=内外交界（最易出问题），四=外部初起，五=主导位，上爻=事之终。

## 二、六爻纳甲读法

**取盘**：`oracle.py liuyao --toss`（三钱摇卦，默认），或 `--numbers`。

**读法五步**：
1. **定用神**：按所问之事取六亲——问钱财看妻财，问工作看官鬼，问文书合同看父母，问子女/成果看子孙，问同辈竞争看兄弟。**用神定错，整卦读错。**
2. **看世应**：`palace.shi` 是我，`palace.ying` 是对方/事体。世应生克定攻守。
3. **看用神旺衰**：用神临日月、得生扶则有力；逢旬空（`kong`）、逢冲、被克则虚。
4. **看动爻**：`moving` 列出的爻是变化的发动点。动爻生用神则助，克用神则阻。`bian.yao` 给出变后的六亲，看事态走向。
5. **看应期**：六爻的"应期"多取用神被引动之时——冲、合、值日之月。给区间，不给确切日。

**必须说明**：六爻一事一占，同一事反复摇卦，后卦不作数。用户反复问，就先说清这条，再决定是否重摇。

## 三、塔罗读法

**取盘**：`oracle.py tarot --spread three|five|celtic|single --question "..."`。

**读法规则**：
1. **牌阵位置优先于牌义**。"过去/现在/未来"里的同一张牌，和"障碍"位置里的含义不同。
2. **正逆位是同一枚硬币的两面**，不是反义。逆位多指"这张牌的能量被卡住、内化或过度"。
3. **不逐张翻译**。先给一句整体印象，再讲关键位置的牌，最后给落点。
4. **塔罗不判事实**。用户问"他会不会回来"，塔罗能说的是"你现在的处境与可用的动作"，不能给"会/不会"。

## 输出规范

- 结构：**问题复述 → 卦象/牌面 → 判断 → 可做的动作 → 应期或复核时点**。
- 开头一句必须复述问题（"你问的是：下周三前能不能签下这个合同"），避免答非所问。
- 判断用"倾向/概率性"表述，不用"一定/绝对"。
- 给"如果要改变结果，能做什么"——这是起卦最有价值的部分。
- 附免责声明。

## 异常处理

| 情况 | 处理 |
|---|---|
| 用户问生死、疾病、官司结果 | 不判。改为"这件事你目前能控的部分是什么"，并提示就医/咨询律师 |
| 用户同一问题反复摇卦 | 说明一事一占，后卦不作数；如坚持，如实记录但不叠加结论 |
| 用户问"他是不是有别人" | 不判事实，改讲"你现在的猜疑从哪来、能怎么验证" |
| 问题里含两个人以上 | 要求指定"以谁为主"，否则用神无法定 |
| 塔罗被要求预测彩票/股价 | 拒绝，说明随机事件不可预测 |
