# 择日择时

**职责**：把"哪天好"从"翻黄历找宜字"变成**一份能排进日程表的候选清单**。

## 先说清能做到什么

本产品做的是**四层简化择日**：建除十二神、黄道黑道值神、二十八宿、日冲煞。这四层能筛掉明显不合适的日子，但**不等于完整黄历**——完整黄历还要叠几十项神煞、主事人生辰合参、方位与天气。

所以交付时**必须**带上这句话：**"这是四层筛选后的候选，最终请结合主事人生辰与现实条件确认。"** 不许把自己的输出称作"黄历宜忌"。

## 执行步骤

### 第一步：锁定三件事

用户说"下月搬家哪天好"，先问清：

1. **主事人是谁**——夫妻二人搬家，要两个人的生肖都避开；公司开业，法人为主事人。
2. **时间窗有多硬**——能改期到两个月内，还是必须在这周？窗口越硬，越要在"可接受的次优日"里找，而不是硬推最优日。
3. **有没有不可动的现实约束**——场地档期、亲友到场、租金起算日、医生排期。这些常常比择日更决定结果。

### 第二步：跑候选

```bash
python "<引擎目录>/oracle.py" pick --from 2026-11-01 --to 2026-11-30 \
  --purpose 嫁娶 --avoid-zhi 卯 --limit 8
```

`--purpose` 可选：`嫁娶` `开市` `搬家` `签约` `出行` `动土` `入学` `求医` `安葬` `通用`。
`--avoid-zhi` 传主事人生肖对应地支（鼠子 牛丑 虎寅 兔卯 龙辰 蛇巳 马午 羊未 猴申 鸡酉 狗戌 猪亥），可传多个时改跑两次再取交集。

### 第三步：读评分，不迷信评分

引擎给的是四层加权分（建除 3 分 / 值神 2 分 / 宿 1 分 / 日冲 −4 分）。读法：

- **先剔除冲日**：分数再高，冲主事人生肖的一律不用。
- **再看建除是否合用途**：嫁娶取成、满、定；开市取成、开、满；动土避开破、危。
- **再看值神**：黄道六神（青龙、明堂、金匮、天德、玉堂、司命）加分。
- **最后看宿**：宿的吉凶各家略有出入，只作参考，不作定盘。

### 第四步：挑时辰

用 `day` 子命令拿当日的 `good_hours`（黄道吉时），结合现实排期：

- 婚宴看开席时间是否落在吉时
- 签约看双方能同时到场的时间
- 动土看施工队进场时间

**不要为了吉时而牺牲到场率。** 人到齐比时辰重要，这条要跟用户说。

### 第五步：交付

排序表 + 每条的理由 + 一个"如果你只能选一天，我建议哪天"的明确答案。

## 用途与建除对照（简化版）

| 用途 | 优先建除 | 避开建除 |
|---|---|---|
| 嫁娶 | 成、满、定 | 破、危、闭、平 |
| 开市 | 成、开、满 | 破、危、闭 |
| 搬家 | 成、开 | 破、危、闭 |
| 签约 | 成、定、满 | 破、危 |
| 出行 | 建、开、成 | 破、危、闭 |
| 动土 | 成、开 | 破、危、闭、平 |
| 求医 | 除、破 | 满、闭 |
| 入学 | 成、开 | 破、危 |

## 单日速查（用户只问"今天宜什么"）

直接跑 `oracle.py today` 或 `day --date`，把建除、值神、宿、冲煞、吉时、宜忌六项用一段话说完，不生成文件。

## 输出规范

- 候选日表：日期 / 干支 / 农历 / 建除 / 值神 / 宿 / 评分
- 每个推荐日必须带**理由**，"这天好"不算理由
- 必须给"我的建议"——只排表不给判断，等于把活推回给用户
- 必须提醒现实约束的优先级
- 附免责声明

## 异常处理

| 情况 | 处理 |
|---|---|
| 时间窗内无合意日 | 明说"这个窗口里没有特别合适的"，给次优日并说明妥协在哪一层 |
| 主事人不止一个 | 分别取冲忌地支，取都不冲的交集；交集为空则明说冲突，让用户定谁优先 |
| 用户问"必须某天，能不能破" | 说明择日是概率性参考，现实需要就办，可用当日吉时与方位做补偿，但不宣称"已化解" |
| 涉及手术择日 | 明确**以医生排期为准**，择日只作心理支持，绝不建议因此推迟必要的治疗 |
| 涉及诉讼开庭 | 以法律程序为准，不做"胜诉日"判断 |
