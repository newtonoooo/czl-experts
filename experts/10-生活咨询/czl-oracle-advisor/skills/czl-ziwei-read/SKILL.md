# 紫微斗数解读

**职责**：把十二宫盘读成"各领域的位置与力度"，特别是"当前这十年在考什么"。

## 前置

必须先有 `czl-oracle-engine` 的 `ziwei` JSON。紫微以农历月日时排盘，农历由引擎换算，不要自己换。

## 读盘顺序（顺序不能乱）

### 一、命宫定人

看 `ming_palace` 与命宫主星（`palaces` 中 `is_ming: true` 那一宫的 `stars`）。

- **有主星**：以主星为骨架说结构。
- **空宫**（`empty: true`）：借对宫（迁移宫）主星看，并明确说"命宫无主星，取迁移宫借星，性质偏向外显与借力"。

主星的白话对照（只取结构，不作吉凶）：

| 主星 | 结构特征 |
|---|---|
| 紫微 | 要主导权，适合定规则的位置，怕被架空 |
| 天机 | 脑子转得快，善谋不善守，容易在变动中获益 |
| 太阳 | 外显、肯担，付出型，怕被消耗 |
| 武曲 | 执行与数字，务实，情绪表达偏少 |
| 天同 | 求安稳、重感受，抗压需要缓冲 |
| 廉贞 | 边界感强，有张力，适合有规则的竞争场 |
| 天府 | 库藏型，稳守与积累见长 |
| 太阴 | 内敛、细腻，长于经营不显眼的部分 |
| 贪狼 | 交际与欲望驱动，多才多欲 |
| 巨门 | 靠言语与辨析立足，易生口舌 |
| 天相 | 辅佐与形象，适合做二把手或枢纽 |
| 天梁 | 规则与庇护，适合专业与把关 |
| 七杀 | 决断与冲劲，敢开不敢守 |
| 破军 | 破旧立新，先破后成，过程颠簸 |

**双星同宫**：两颗要合起来读，如"紫微天府"是"既要主导又要守成"，容易在扩张与保守之间反复。

### 二、身宫定着力点

`is_shen` 那一宫是"后天真正花力气的地方"。身宫落在财帛 → 一生用力在钱上；落在官禄 → 用力在事业；落在夫妻 → 用力在关系。这一句往往比命宫更让用户"对上号"。

### 三、四化定引动

看 `sihua`（生年四化）落在哪些星、哪一宫：

- **化禄**：资源与顺手的部分
- **化权**：要争、要控的部分
- **化科**：被看见、被认可的部分
- **化忌**：卡住、反复、需要长期处理的部分

**忌不是灾**，是"这里需要多花力气"。把忌说成灾，就是恐吓；把忌说成"必有一劫"，就是行骗。正确说法：**"廉贞化忌在夫妻宫，意味着亲密关系里的边界议题会反复出现，需要你用规则而不是情绪来处理。"**

### 四、十二宫分域

按用户问的领域展开，每宫给"位置 + 主星 + 一句结论"：

| 宫 | 领域 | 看什么 |
|---|---|---|
| 命宫 | 本人 | 主星与四化 |
| 兄弟 | 同辈与合伙 | 有无煞忌，合作宜忌 |
| 夫妻 | 亲密关系 | 主星性质决定相处模式 |
| 子女 | 子女与作品 | 也看创作与项目产出 |
| 财帛 | 现金流 | 赚钱方式，不看金额 |
| 疾厄 | 身心消耗 | **只讲消耗倾向，绝不诊断** |
| 迁移 | 外出与外部机会 | 空宫借星时的关键位 |
| 交友 | 团队与部属 | 组织里的人际结构 |
| 官禄 | 事业位置 | 适合的组织形态 |
| 田宅 | 不动产与家庭 | 也看居所稳定性 |
| 福德 | 内在满足 | 抗压与精神供给 |
| 父母 | 长辈与上级 | 也看体制资源 |

### 五、大限定十年

`dayun.list` 给出每十年落在哪一宫、起于虚岁几岁。找出当前年龄所在的那一格，然后：

- 该宫主星 → 这十年主考什么
- 该宫四化 → 这十年什么被引动
- 该宫与大限三方四正的关系 → 顺还是拧

给"这十年在考什么"的一句话，例如：**"33–42 走田宅宫，太阳坐守：这十年重心在居所与家庭基建，也是把'根'扎下来的十年，不是冲刺的十年。"**

### 六、流年定当年

`flow_year` 给出流年落宫与虚岁。把流年宫与大限宫叠起来看：同宫则主题加倍，对宫则内外拉扯。

## 输出规范

- 六段式。
- 盘面依据段要写清"命宫在哪、主星是什么、四化怎么落"，用户可自行核对。
- 每个领域结论都要有"为什么"（哪个宫、哪颗星、哪一化）。
- 不下"必离""必破财"这类断言。
- 附免责声明。

## 常见误读纠正

| 用户说法 | 你的纠正 |
|---|---|
| "我命宫空宫是不是命不好" | 空宫只是结构不同，借对宫看，反而适应性更强 |
| "化忌是不是很凶" | 化忌是需要长期处理的课题，不是灾 |
| "我是不是犯小人" | 看交友宫与巨门的位置，讲具体的相处结构 |
| "七杀坐命是不是命硬" | 七杀是抗压驱动型结构，讲清代价与用法 |

## 异常处理

| 情况 | 处理 |
|---|---|
| 无时辰 | 紫微命宫依赖时辰，无法排盘。如实说明，改走八字 B 级或起卦 |
| 闰月生日 | 确认是否闰月后重跑，闰月与正常月紫微月序不同 |
| 用户给的是公历 | 直接传公历给引擎，农历由引擎换算，不要自己算 |
| 用户拿别的软件的盘来对 | 逐项核对命宫、五行局、紫微落宫；不一致时说明流派差异（如庚干四化有两说），不争对错 |
