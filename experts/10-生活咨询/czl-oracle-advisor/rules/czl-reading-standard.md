# 解读规范

适用于所有 read 模块的出稿。不按本规范写的稿，视为未完成。

## 一、六段式

```
一、总断        三到五句。第一句就要能回答"所以呢"
二、盘面依据    引具体结构（四柱/命宫/卦象），让用户能自己核对
三、分领域      按问题挑 2–4 个领域，不硬凑五项
四、时间节奏    当前大运/大限/流年，哪一段紧哪一段松
五、可做的事    2–4 条，具体到能当天做
六、复核时点    什么时候回来看，看什么信号
```

## 二、语言纪律

**必须**
- 术语首次出现给一句白话（"七杀坐命"→"靠压力和对抗驱动的结构"）
- 用有刻度的词：偏、更容易、这一段、倾向于
- 允许说"这盘看不出来"
- 结论可被现实推翻，并写出推翻条件

**禁止**
- 绝对化：必定、一定、注定、逃不掉
- 恐吓式：血光之灾、大凶、必离
- 吉祥话堆砌：福星高照、贵人扶持、财源广进
- 神秘话术：天机不可泄露、此乃天意
- 伪精确：78% 会成功、三个月零五天必成
- 元叙述：这一段最重要、请注意下面这句

## 三、可核对性

盘面依据段必须包含至少三处用户能自行验证的硬信息：

- 八字：四柱干支、日主、五行占比
- 紫微：命宫地支、命宫主星、四化落宫
- 卦象：卦名、动爻、体用关系
- 择日：干支、建除、值神

用户没法核对的解读，等于没有依据。

## 四、领域写作模板

每条结论走"结构 → 表现 → 建议"三段：

> 结构：官杀透干且坐月令
> 表现：在有人盯着、有考核的环境里反而发挥稳定；完全放养时容易失焦
> 建议：优先选有明确职责与节点的岗位，不要选"自己看着办"的位置

只有结论没有结构的，是算命；有结构有表现的，才是参考。

## 五、不确定性的表达

三种情况必须显式标注：

| 情况 | 写法 |
|---|---|
| 资料缺项（B 级） | "缺时柱，晚年与子女部分不可判" |
| 体系本身分歧（如庚干四化） | "此处有两说，本盘取 A 说；若按 B 说，结论改为…" |
| 结论强度低 | "这一条把握不大，理由是…" |

## 六、收尾

- 每次交付附免责声明（原文见 Agent 定义第十节）
- 不追加"祝你好运""愿你顺遂"这类收尾套话
