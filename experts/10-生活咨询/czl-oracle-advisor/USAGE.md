## 二、想让结果更准，多给三样东西

| 给什么 | 为什么 |
|---|---|
| **出生地**（到城市即可） | 用来做真太阳时校正。成都和上海差 70 分钟，跨时辰就会换时柱 |
| **出生的具体时刻** | 没时辰只能看年月日三柱，时柱、紫微命宫、大运起运都判不了 |
| **事件的时间窗** | "下个月"和"三个月内"筛出来的候选日完全不同 |

出生时刻记不清，直接说"我妈说我是中午"，不要编一个精确时间。会给两个候选时辰的盘对照，你自己看哪个更像。

## 三、各功能怎么用

### 1. 看结构（八字）

适合问：我是什么样的人、适合什么方向、五行缺什么、今年大势。

输出会给：四柱表、五行占比条、旺衰判断、大运时间轴、未来几年流年。每一条都能自己在盘面上对上。

### 2. 看领域（紫微）

适合问：我的事业位置、财、感情、这十年在考什么。

输出会给：命宫/身宫、十二宫主星、生年四化、大限。术语第一次出现会有白话解释。

### 3. 问当下（起卦）

适合问：这个 offer 接不接、要不要开口、这周能不能谈成。

- 快速看大势 → 梅花易数
- 具体事件成败 → 六爻（摇卦）
- 我自己卡在哪 → 塔罗

**一次只问一件事**，同一件事不反复摇——这是六爻的规矩，反复摇后卦不作数。

### 4. 挑日子（择日）

适合问：婚礼、开业、搬家、签约、动土、入学。

输出会给：候选日排序表 + 每天的理由（建除、值神、宿、冲谁）+ 当日吉时。

**会明确告诉你**：这是四层筛选的候选，不是完整黄历；最终还要看场地、亲友、你自己的日程。

### 5. 要成品（出图）

说一句"出个图"或"要能发给我妈的"，会生成一个 HTML 文件：

- **单文件**，不联网也能打开
- 六个体系各自配色（八字黑金、紫微深蓝、梅花素纸、六爻墨朱、塔罗深紫、择日墨绿）
- 手机上看会自动变成单列
- 可以打印，也可以存成 PDF（浏览器打印 → 另存为 PDF）

## 四、结果怎么看

每条解读按这个结构给：

```
结构   盘面上是什么（可核对）
表现   现实中长什么样（能对上你的经历）
建议   可以怎么做（能当天做的）
```

看到只有"结论"没有"结构"的，可以直接追问："这条是从盘面哪一项看出来的？"

结尾还会有：

```
可做的事    两到四条，具体
复核时点    什么时候回来看，看什么信号
```

**复核时点**是重点——它让这件事变成可验证的：到了那个时间，如果信号没出现，说明这条判断该修正。

## 五、这些事我不会做

- 不判断疾病、不建议停药、不解释症状
- 不预测官司胜负
- 不承诺收益、不推荐股票彩票
- 不说"能活多久"
- 不给小孩贴"读书不行""婚姻不顺"这类标签
- 不声称能"化解"，不卖任何东西

被问到这些时，会给一个替代的问法——通常是把"结果"换成"你在这件事里的位置和能做的动作"。

## 六、常见问题

**Q：为什么同一个问题，我说得越具体，答案越长？**
因为具体的问法能定位到具体的结构。问"我运势怎么样"只能给你整体气候；问"今年要不要换工作"能给到流年、大运、可行动作。

**Q：不同体系结论不一样，听谁的？**
会说清为什么不一样（时间尺度不同 / 看外还是看内 / 输入有误差），然后给"出现什么信号就信哪边"。不会挑一个顺耳的说。

**Q：我拿别的软件的盘来对，对不上怎么办？**
逐项核：命宫、五行局、紫微落宫、四柱。常见差异来自三处：换日法（23 点还是 0 点）、是否做真太阳时校正、紫微庚干四化有两说。会说明本产品取哪一种。

**Q：闰月生日怎么办？**
直接说"我是闰六月的"，会按闰月排。闰月与正常月的紫微月序不同，八字月柱按节气不受影响。

**Q：能存档吗？**
可以让它顺手存一份 JSON，下次对比用。
