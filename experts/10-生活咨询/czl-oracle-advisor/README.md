## 一、这是什么

一个把**六套传统体例**装进同一套计算内核的参谋工具：

| 体系 | 能回答什么 |
|---|---|
| 子平八字 | 结构是什么、五行怎么偏、大运流年走到哪一段 |
| 紫微斗数 | 十二宫落在哪、主星是什么、这十年在考什么 |
| 梅花易数 | 这件事的体用关系，进还是退 |
| 六爻纳甲 | 具体事件的成败、谁占优、什么时候动 |
| 塔罗 | 我在这件事里的位置、卡在哪 |
| 择日择时 | 哪几天合适、哪个时辰合适、冲谁 |

**关键差别**：所有盘面由内置引擎（Python，纯标准库）计算，不靠模型记忆推演。节气精确到秒级误差、农历含闰月与 2033 年边界、六十四卦装卦、紫微十四主星定位，都是算出来的，可以复核。

## 二、平台展示文案

**一句话（列表页）**
把八字、紫微、卦象与择日做成一套可核对的参考框架，出盘有依据，读盘给动作。

**能力介绍（详情页）**
以八字、紫微、卦象与择日为决策参考框架，把看不清的事拆成可核对的结构与可执行的动作。

**标签**
八字排盘 · 卦象占断 · 择日择时

**推荐提问（首屏三条）**
1. 帮我排个八字盘，看看我的结构和今年该注意什么
2. 帮我起一卦，看这件事现在该进还是该退
3. 下个月要办婚礼，帮我挑几个日子并排出吉时

**适合谁**
- 想认真看一次自己结构的人（而不是刷个"今日运势"）
- 卡在一个决定上，需要多一个视角来交叉验证的人
- 要挑日子、要排时辰，希望有理由而不只是"黄历说宜"的人
- 对术数有兴趣、想看清每个结论怎么推出来的人

**不适合谁**
- 想听"必涨必成必离"这类确定答案的人——本产品不给
- 想找"化解改运""开光法事"的人——本产品不做，也不收费做
- 需要医疗、法律、投资专业意见的人——请找对应专业人士

## 三、它能做什么 / 不做什么

**做**
- 排盘：四柱八字、紫微斗数、梅花、六爻、塔罗、日课
- 定级：先判断你给的资料到哪一级，说清缺项会让哪块结论变软
- 校正：按出生地经度做真太阳时校正，边界时辰会提示
- 择日：按用途（嫁娶/开市/搬家/签约/动土…）筛候选日并给理由
- 交叉：两套体系结论打架时，说清为什么打架、什么条件下信哪边
- 出图：生成单文件 HTML，六个体系各自一套视觉语言，可直接发人/打印

**不做**
- 不断疾病、寿命、官司胜负、彩票股价
- 不承诺收益，不给"必"字结论
- 不给未成年人贴宿命标签
- 不声称能化解、不卖法器符咒、不做付费改运
- 不编造"祖传秘传"之类资质

## 四、快速上手

在对话里直接说人话即可，三种最常用：

```
帮我排个八字：1990年6月15日早上8点半左右，女，成都出生
```

```
帮我起一卦，我正在犹豫要不要接一个offer
```

```
11月想搬家，帮我挑三个日子，我属兔
```

要成品页面时说一句"出个图"或"要能发给我妈的"，会生成 HTML 文件并给出路径。

## 六、技术特征

- **零第三方依赖**：纯 Python 3.8+ 标准库，不需要联网、不需要安装包
- **可离线**：排盘、渲染全部本地完成
- **可复核**：每条结论都能对上盘面上的具体字段
- **星历精度**：节气时刻与紫金山天文台发布值偏差 ≤ 21 秒（详见 TEST-REPORT）
- **农历**：定朔定气法自算，含闰月，能正确处理 2033 年"闰十一月"这类边界年
