# W6 陪练复盘与家长协同

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 陪练复盘与家长协同（czl-bio-practice） |
| **任务职责** | 把"讲过了"变成"做对了"：用提问阶梯陪练，把错题归到五类，排出复习间隔，给家长一份能照着做的简报。 |
| **输入参数** | 必填：错题（题干 + 学生答案 + 标准答案）、这一轮讲了什么。建议：最近三次练习的正确率、每周可用时间、家长想解决的具体困扰。 |
| **执行步骤** | ①按提问阶梯陪练（复述→解释→变式→迁移） → ②每道错题归入五类之一并给二次检验方式 → ③按正确率决定下一步难度 → ④排复习间隔（当天/第 3 天/第 7 天/第 14 天） → ⑤给家长简报（三句话 + 一个动作 + 一个禁区） |
| **判断条件** | 同类错因连续 3 次 → 换讲法（换图、换类比、换顺序），不再重复原讲法；正确率 ≥80% → 加变式与限时；正确率 50%—80% → 同一难度再练一组；<50% → 退回上一环重走链条，不加新内容 |
| **输出格式** | 归因表（题号 / 错因 / 证据 / 二次检验）+ 四周复习排期表 + 家长简报（不超过 150 字）。学生侧只给"今天做什么"，不给整套计划。 |
| **异常处理** | 家长想替孩子做题 → 明确说"这道题得他自己写，您可以负责计时"；孩子明显疲劳或抵触 → 降到 10 分钟微练，只做一道；家长要求承诺提分 → 拒绝并给可观测指标；连续两周无变化 → 回 W1 重测，不在 W6 里硬撑 |
| **必要依赖** | `references/review-schedule.md`（间隔与复习方式）、`references/parent-scripts.md`（话术库与禁区） |
| **与其他工作流的关系** | 上游：W1—W5 任一工作流的执行记录。下游：四周后回到 W1 重测；错因若集中在"过程不清"，转 W2。 |

## 一、陪练三条规矩

1. **只提问，不代答。** 学生卡住时，给一个更小的问题，不给答案。给答案一次，这一轮就白练了。
2. **等满十秒。** 提问后闭嘴数十秒。沉默不是不会，是在组织语言；三秒就补话，等于替他思考。
3. **错了先问思路。** "你刚才想到哪一步了？"——先让他把路径说出来，再决定是补链、补条件，还是补表述。

## 二、提问阶梯（四层，逐层上）

| 层 | 问什么 | 通过标准 | 卡住时退回 |
|---|---|---|---|
| 复述 | "这一步在哪发生？需要什么？" | 说出场所与条件 | 回 W2 重走链 |
| 解释 | "为什么会这样？换成……还成立吗？" | 说出因果，能换条件 | 回复述层 |
| 变式 | "把条件改成……，答案怎么变？" | 独立答对，理由正确 | 回解释层 |
| 迁移 | "这跟上次那道题像在哪？" | 能自己指出同类点 | 停留在变式层多练一组 |

**一次陪练只走到一层为止。** 四层全走一遍，学生只会记住"今天做了很多题"。

## 三、错因归因（每道题只归一类）

| 类型 | 二次检验怎么做 | 通过标准 |
|---|---|---|
| 过程不清 | 隔一天，不看笔记画链条 | 8 环以内全对 |
| 概念混淆 | 给一组对比表，让他自己填第三列 | 三列都填对 |
| 条件缺失 | 把他的答案遮住结论句，只留前半句 | 能自己补上条件 |
| 读图失位 | 换一张同类图，只问"关键点在哪" | 五秒内指出拐点 |
| 表述失分 | 同一答案按四要素重写一遍 | 四要素齐全 |

归因表和二次检验要写在同一张纸上。**没有二次检验的归因，等于没归因。**

## 四、复习间隔（不要凭感觉"多看看"）

| 时间 | 做什么 | 时长 |
|---|---|---|
| 当天 | 合上材料复述一遍链条 | 5 分钟 |
| 第 3 天 | 做一道变式题，不看笔记 | 10 分钟 |
| 第 7 天 | 空白纸重画链条 + 一道错题重做 | 15 分钟 |
| 第 14 天 | 混合两道旧题 + 一道新题（限时） | 20 分钟 |

第 14 天还错的题，不是"再练一遍"能解决的，回 W1 重新定位。详细安排见 `references/review-schedule.md`。

## 五、家长简报（150 字以内，超了家长不看）

固定三段：

```
【这周的情况】他能独立画出光反应到暗反应的链，场所和条件没漏；条件变化题还会错一半。
【今晚您做一件事】把这张链图收走，让他空白纸重画一遍，画完对照原图找差。
【一件别做的事】别问"记住了吗"，改问"CO₂ 突然没了，哪一步先停"。
```

三段的顺序不能换：**先说做到了什么，再说今晚做什么，最后说别做什么。** 先讲问题，家长会焦虑；只讲问题不讲动作，家长会加量。

## 六、每周十分钟的检查动作

家长每周只做一件事，不要多：

| 动作 | 怎么做 | 看什么 |
|---|---|---|
| 抽一道题让学生讲 | 随机抽本周的一道错题，让他讲给你听 | 讲得顺不顺，卡在哪一句 |
| 空白纸复述 | 给一张白纸，让他画本周的链 | 有没有漏场所、漏条件 |
| 对照答案找差 | 让他自己比对，说出差在哪 | 说不说得出来 |

**家长不判对错，只记录"卡在哪一句"。** 判对错是老师的事，家长判错会吵起来。

## 七、什么时候该停

| 信号 | 处理 |
|---|---|
| 连续三道题都错在同一处 | 停，回 W2 重走链，不要再刷题 |
| 学生开始烦躁、走神 | 停，改做一道他会的题，收个尾结束 |
| 连续两周指标没动 | 回 W1 重测，检查是不是一开始就定位错了 |
| 家长开始替孩子回答 | 停，把家长请出这个环节，改为事后看记录 |

停不是放弃，是不把时间花在无效重复上。**一节课的价值在"通了一条链"，不在"做了几道题"。**
