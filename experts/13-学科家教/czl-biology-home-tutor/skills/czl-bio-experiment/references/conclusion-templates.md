# 结果与结论句式库（czl-bio-experiment 参考）

实验题的结论句是采分点密集区。写"意思差不多"通常拿不到分，写"要素齐全的句式"才拿。本文件给的是可套用的句式骨架，不是标准答案。

---

## 一、结论句的骨架

```
在【实验条件】下，【自变量】对【因变量】有【促进 / 抑制 / 无明显】影响，
且【随……的变化趋势 / 最适值 / 阈值】。
```

三个要素缺一个扣一分，很常见。

| 要素 | 缺了会怎样 | 例 |
|---|---|---|
| 条件 | 结论变成"放之四海皆准"，被判过头 | "在一定浓度范围内" |
| 方向 / 趋势 | 只说"有影响"，等于没说 | "先增多后减少" |
| 限定 | 由一次实验推普遍规律 | "在本实验条件下" |

---

## 二、五种常用句式

**句式 1｜验证某因素有作用**

> 在相同且适宜的其他条件下，X 组（处理组）的〔观测指标〕高于/低于 Y 组（对照组），说明〔自变量〕对〔因变量〕有促进/抑制作用。

**句式 2｜求最适值**

> 在〔范围〕内，随〔自变量〕升高，〔观测指标〕先增后减，在〔具体值〕附近达到最大值，说明最适〔自变量〕约为〔值〕。

**句式 3｜验证两种因素的关系**

> 〔观测指标〕随〔自变量 A〕的变化幅度，在〔自变量 B〕较高时更大，说明 B 会影响 A 的作用效果。

**句式 4｜判断某物质是否为必需**

> 去除〔某物质〕后〔观测指标〕显著下降，重新添加后恢复，说明〔某物质〕是该过程所必需的。

**句式 5｜评价类结论**

> 该设计缺少〔空白对照 / 重复 / 可测指标〕，导致〔结果无法归因 / 偶然误差大 / 结论不可靠〕，应〔补一组不做处理的对照组 / 每组增加样本并重复 / 改用……作为观测指标〕。

## 三、预期结果的三分支写法

不要押一个结果。写成"若……则……"，覆盖三种可能：

```
若处理组〔指标〕显著高于对照组，则说明该处理有促进作用；
若处理组显著低于对照组，则说明该处理有抑制作用；
若两组无显著差异，则说明该处理无明显作用。
```

判据：**写出三分支的答案，永远比写一个"一定会升高"的答案安全。** 除非题目明确要求"预测结果"，否则三分支是标准做法。

## 四、常见病句与改法

| 病句 | 病在哪 | 改后 |
|---|---|---|
| 说明生长素能促进生根 | 缺浓度、缺条件、缺趋势 | 在一定浓度范围内，随生长素类似物浓度升高，生根数先增后减 |
| 因为加了酶所以气泡多 | 因果太浅，没说明酶的作用 | 酶降低了 H₂O₂ 分解所需活化能，反应速率加快，单位时间气泡数增多 |
| 结果证明假设成立 | 不可证伪，且没写结果 | 处理组生根数（均值 12.3 条）显著高于对照组（5.1 条），支持该浓度促进生根的假设 |
| 其他条件相同且适宜 | 概括，通常不给分 | 温度、光照、处理时间分别如何控制（逐条写） |
| 说明光合作用增强了 | 缺条件、缺指标 | 在光强低于饱和点的范围内，随光强增大，O₂ 释放速率增大 |

## 五、采分点拆解示例

题目：设计实验探究某浓度生长素类似物对插条生根的作用，并预期结果与结论。（6 分）

| 采分点 | 分值 | 写法 |
|---|---|---|
| 取材与分组 | 1 | 取生长状况相同的同种枝条若干，随机均分为甲、乙两组 |
| 自变量处理 | 1 | 甲组浸泡在该浓度溶液中，乙组浸泡在等量蒸馏水中，相同时间 |
| 无关变量控制 | 2 | 温度、光照、水分、处理时间相同（写出至少两条具体控制方法） |
| 观测指标 | 1 | 相同时间后统计每组生根条数的平均值 |
| 结果与结论 | 1 | 三分支表述，且结论句含条件与趋势 |

对照这张表，学生自己能看出丢在哪一格。

## 六、一句话提醒

结论句写完，读一遍，问自己：**"这句话拿到另一个实验里还成立吗？"** 成立，说明条件写少了；不成立，才算写对了。
