# 变量矩阵与控制方法库（czl-bio-experiment 参考）

## 一、变量矩阵的四列怎么填

| 列 | 填什么 | 一句话检验 |
|---|---|---|
| 自变量 | 你改变的那个因素，带取值范围 | 别人能照着设几组吗 |
| 因变量 | 随自变量变化的生物量 | 它是"变"的那个吗 |
| 观测指标 | 把因变量变成数字的方法 | 能测出数字吗 |
| 无关变量 | 会捣乱但你不研究的因素 | 每条后面有没有跟控制方法 |

**最常见的三处漏填**：观测指标没写时间点、无关变量没写控制方法、自变量没写范围。

## 二、教材常见实验的变量清单

| 实验 | 自变量 | 因变量 / 观测指标 | 关键无关变量 |
|---|---|---|---|
| 比较过氧化氢在不同条件下的分解 | 催化剂种类（FeCl₃ / 过氧化氢酶）、温度 | 气泡产生速率、带火星木条复燃情况 | H₂O₂ 浓度与体积、pH、观察时间 |
| 影响酶活性的条件 | 温度（或 pH）梯度 | 反应速率（气泡数 / 褪色时间 / 产物量） | 酶浓度、底物浓度、反应时间 |
| 探究酵母菌细胞呼吸的方式 | 有无氧气 | CO₂ 产生量（澄清石灰水浑浊程度）、酒精生成（重铬酸钾变色） | 葡萄糖浓度、菌种与接种量、温度、培养时间 |
| 绿叶中色素的提取和分离 | 提取液种类（无水乙醇 / 水） | 滤纸条上色素带的条数与宽度 | 叶片种类与新鲜程度、研磨程度、层析液、划线次数 |
| 环境因素对光合作用的影响 | 光照强度 / CO₂ 浓度 / 温度 | O₂ 释放量、CO₂ 吸收量、上浮叶圆片数 | 叶片来源与大小、NaHCO₃ 浓度、水温、光照距离 |
| 探究植物细胞的吸水和失水 | 外界溶液浓度 | 质壁分离程度（原生质层与细胞壁的分离比例） | 细胞种类与活性、处理时间、温度 |
| 探究生长素类似物促进插条生根的最适浓度 | 类似物浓度梯度 | 生根条数与平均根长 | 枝条种类、粗细、长度、芽数、处理时间、温度、水分 |
| 培养液中酵母菌种群数量的变化 | 时间（或温度、营养条件） | 显微镜计数（血细胞计数板） | 取样前是否摇匀、取样时间、计数方法 |
| 土壤中小动物类群丰富度的研究 | 取样地点 / 土层深度 | 物种数与个体数 | 取样器规格、取样时间、分离方法 |
| 调查人群中的遗传病 | 遗传病种类 | 发病率 | 调查人群、样本量、统计口径 |

## 三、控制方法库（写完"无关变量"这一列，从这里挑）

| 类别 | 控制方法 | 适用 |
|---|---|---|
| 材料一致 | 同种、同品种、同生长状况、同部位、同大小 | 植物、动物、组织 |
| 随机分组 | 抽签、随机数表 | 避免人为挑选 |
| 数量足够 | 每组若干个个体（不用 1 个） | 降低个体差异 |
| 重复 | 同一处理做 3 次，取平均值 | 降低偶然误差 |
| 环境恒定 | 恒温箱、恒温培养箱、遮光或定时光照 | 温度、光照 |
| 缓冲 | 加缓冲液维持 pH | 酶实验、培养实验 |
| 时间统一 | 同一时间点观察、同一时长处理 | 全部实验 |
| 操作统一 | 同一人、同一工具、同一手法 | 测量类 |
| 空白/溶剂对照 | 只加溶剂（如只加蒸馏水、只加乙醇） | 药物、试剂处理 |

**写法示例**（照这个格式写，一条一行）：

```
无关变量：枝条粗细与长度 → 选取粗细、长度一致的枝条
          处理时间 → 各组同时浸泡相同时间
          温度 → 置于同一恒温培养箱
          水分 → 同一时间、等量浇水
```

## 四、变量写不清的三种典型表现

| 表现 | 例 | 改成 |
|---|---|---|
| 自变量无范围 | "不同浓度的生长素" | "0、10⁻⁸、10⁻⁷、10⁻⁶ mol/L 四个浓度" |
| 因变量不可测 | "观察生长情况" | "14 天后统计平均生根条数" |
| 无关变量一句带过 | "其他条件相同且适宜" | 拆成 3—4 条，每条给方法 |

## 五、单变量自检三问

写完设计，问自己三句：

1. 两组之间，除了自变量，还有别的不同吗？（有 → 改）
2. 我的观测指标，能不能给出一个数字？（不能 → 换指标）
3. 换一个人照做，能不能得到同样的结果？（不能 → 补细节）
