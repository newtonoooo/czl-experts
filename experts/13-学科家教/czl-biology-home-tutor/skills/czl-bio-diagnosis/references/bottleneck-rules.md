# 断点判定规则与高频断点清单（czl-bio-diagnosis 参考）

## 一、判定总则

1. **一个断点一条证据。** 证据必须是孩子写下的原句、说出的原话，或者视频/照片里能看到的作答痕迹。
2. **先排除非学科原因。** 时间不够、看不清图、看错题号、计算失误，这四种都不算五类断点，先排掉再归因。
3. **归一类，不归两类。** 一道题同时像两类，往下追一层再定；追不出就写"待确认"，别硬判。
4. **诊断卡里不许出现评价词。** "粗心""不认真""基础差""态度问题"一律删掉，换成可观察的行为。

## 二、五类的细化判据

### 1. 过程不清

| 追一层 | 通过的表现 | 不通过的表现 |
|---|---|---|
| 顺序 | 能按时间/因果说出先后 | 顺序颠倒（如先还原 C₃ 再固定 CO₂） |
| 场所 | 每步能说出在细胞哪一部分 | 全部答"叶绿体""细胞里" |
| 物质 | 能说出每步的进入物与产出去向 | 只记得开头和结尾，中间空 |
| 条件 | 能说出每步需要什么（光、酶、能量、载体） | 把条件当结果（"因为有 ATP 所以产生 ATP"） |

### 2. 概念混淆

看三处边界：**定义的第一句、成立条件、反例**。

| 常混的一组 | 分界一句话 |
|---|---|
| 细胞呼吸 / 呼吸运动 | 前者是细胞内的氧化分解，后者是呼吸肌的运动，两者不在一个层面 |
| 无氧呼吸 / 发酵 | 高中教材里常作同义使用，但产物要分清（乳酸 / 酒精 + CO₂） |
| 协助扩散 / 主动运输 | 前者顺浓度不耗能（需载体），后者逆浓度耗能 |
| 净光合 / 真光合 | 真光合 = 净光合 + 呼吸消耗；"净为零"不等于"不进行光合" |
| 激素 / 酶 | 激素传递信息不催化，酶催化不传递信息 |
| 基因突变 / 基因重组 | 前者产生新基因，后者只产生新组合 |
| 种群 / 群落 | 前者是同种个体，后者是所有生物 |
| 演替 / 次生演替 | 后者是原有土壤条件基本保留的演替 |

### 3. 条件缺失

三个特征：方向对但没限定、换条件答案不变、答案里没有一个"在……条件下"。

判据：把他的答案遮住一半，只留结论句，看这句话是否"放到任何情境下都成立"。**处处成立的结论句，就是缺条件。**

### 4. 读图失位

| 症状 | 具体表现 |
|---|---|
| 不看轴 | 说不清横轴是时间还是浓度，纵轴是速率还是量 |
| 不找对照 | 图上有多条线，不知道哪条是对照组 |
| 关键点错位 | 把最高点当拐点，把交点当终点 |
| 趋势说不全 | 只说"升高"，不说"先快后慢""超过某值不再变" |
| 多因素漏看 | 双曲线题只看一条，忽略另一条代表的条件 |

### 5. 表述失分

| 症状 | 例 | 改法 |
|---|---|---|
| 缺主语 | "因为酶" | "因为该阶段需要酶催化" |
| 缺条件 | "光合速率增大" | "在一定光强范围内，随光强增大，光合速率增大" |
| 现象当结论 | "曲线往上走了" | "随……增大，……增大" |
| 因果倒置 | "因为产生了 ATP，所以进行了光反应" | "光反应产生 ATP，为暗反应供能" |
| 答非所问 | 问"原因"答"结果" | 回读题干动词：问原因就写"因为……" |

## 三、高频断点清单（按模块，用于快速定位）

| 模块 | 最常断的一环 | 追问一句就能验 |
|---|---|---|
| 蛋白质 | 氨基酸数、肽键数、水分子数的换算 | "100 个氨基酸一条链，肽键几个？" |
| 物质运输 | 主动运输的三个条件（载体、能量、逆浓度） | "低温为什么会影响主动运输？" |
| 酶 | 影响酶活性曲线的"不变段"含义 | "超过最适温度后为什么降下来，是酶没了还是活性低了？" |
| 细胞呼吸 | 无氧呼吸第二阶段不产生 ATP | "无氧呼吸两个阶段，哪个产 ATP？" |
| 光合 | 光反应与暗反应的物质互供 | "光反应给暗反应什么？暗反应还它什么？" |
| 光合 | 条件突变后 C₃/C₅ 的增减 | "突然断 CO₂，C₃ 怎么变？" |
| 细胞分裂 | 染色体数、DNA 数、染色单体数的区分 | "着丝粒分裂后，染色体数变不变？" |
| 减数分裂 | 同源染色体行为与配子种类 | "一个精原细胞能产生几种精子？" |
| 遗传 | 判显隐的两条口诀及适用前提 | "父母都没病孩子有病，是什么遗传？" |
| 伴性遗传 | 伴 X 隐性的"母病子必病" | "为什么男性患者多于女性？" |
| 变异 | 三种可遗传变异的区分 | "同源染色体交叉互换属于哪种变异？" |
| 神经调节 | 静息电位与动作电位的离子基础 | "静息时膜外是正还是负？靠什么维持？" |
| 体液调节 | 分级调节与反馈调节的区别 | "甲状腺激素多了，谁被抑制？" |
| 免疫 | 二次免疫为什么快而强 | "记忆细胞什么时候起作用？" |
| 种群 | J 型与 S 型的条件差 | "S 型曲线里，什么时候增长最快？" |
| 生态 | 能量传递效率与"最多/至少"的计算 | "问'至少消耗'用哪个数字？" |

## 四、常见误判（这几条判错，四周全白排）

| 表面像 | 实际是 | 怎么分辨 |
|---|---|---|
| 过程不清 | 表述失分 | 让他口述一遍：说得出、写不出 = 表述；说不出 = 过程 |
| 概念混淆 | 读图失位 | 换成纯文字的同概念题，能对 = 读图问题 |
| 方法不会 | 计算失误 | 同一题让他重算一次，第二次对 = 失误 |
| 知识不会 | 时间不够 | 空白集中在卷末 = 时间；空白分散 = 知识 |
| 不认真 | 题干条件没读懂 | 让他圈出题干里的条件词，圈不全 = 读题训练不足 |

## 五、样本不够时怎么办

| 手上有 | 能判 | 不能判 |
|---|---|---|
| 只有分数 | 只能判"需要更多材料" | 任何具体断点 |
| 1 道错题 | 这一道题的断点 | 是不是普遍问题 |
| 1 张完整卷面 | 断点类型与集中模块 | 长期习惯、稳定性 |
| 卷面 + 笔记 + 口述 | 五类里的大多数 | 考试心态、时间分配 |

样本不足时，诊断卡第一行必须写"样本不足，以下为初步判断"，并列出补哪两份材料能定性。
