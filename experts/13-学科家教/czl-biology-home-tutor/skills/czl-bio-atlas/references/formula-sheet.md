# 计算类公式与算式模板（czl-bio-atlas 参考）

每个公式都配一句"什么时候用"，避免学生把公式当口诀乱套。凡涉及教材具体数值（如 ATP 个数、能量传递效率范围）的，以课本表述为准。

---

## 一、蛋白质与核酸

| 求什么 | 公式 | 用的时候注意 |
|---|---|---|
| 肽键数 | 氨基酸数 − 肽链数 | 环肽不适用（环肽肽键数 = 氨基酸数） |
| 脱水数 | 等于肽键数 | 生成水分子数与肽键数相同 |
| 游离氨基（羧基）数 | 肽链数 + R 基上的数目 | 题干不说 R 基，就是至少"肽链数"个 |
| 相对分子质量 | 氨基酸总质量 − 脱水总质量 | 有 —S—S— 时再减 2H |

**算式示例**：100 个氨基酸形成 2 条肽链 → 肽键 98 个，脱水 98 个，至少 2 个游离氨基。

## 二、光合与呼吸

```
真光合速率 = 净光合速率 + 呼吸速率
光合产 O₂ 量 = 释放到外界的 O₂ 量 + 呼吸消耗的 O₂ 量
光合耗 CO₂ 量 = 从外界吸收的 CO₂ 量 + 呼吸产生的 CO₂ 量
```

| 场景 | 用哪条 |
|---|---|
| 题干说"测得 O₂ 释放量" | 这是净光合，求总光合要加呼吸 |
| 题干说"黑暗中释放 CO₂" | 这是呼吸速率 |
| 题干说"叶绿体吸收 CO₂" | 这是总光合（叶绿体只吸收不释放） |

**判据**：主语是"叶片/植株"，多是净量；主语是"叶绿体"，多是总量。

## 三、遗传概率

**三条规则，按顺序用**：

1. **乘法**：两个独立事件同时发生 → 概率相乘（如"既 A 又 B"）。
2. **加法**：互斥事件任一发生 → 概率相加（如"AA 或 Aa"）。
3. **条件概率**：已知表现型正常，求携带者概率 → **分母要去掉患病个体**。

**算式示例**：一对表现型正常的夫妇生了一个患病孩子（常染色体隐性）。求再生一个正常孩子是携带者的概率。

```
父母均为 Aa（由"无中生有"判定为隐性，患儿 aa）
正常孩子的基因型空间：AA : Aa = 1 : 2
携带者概率 = 2/3（不是 1/2，因为分母只算正常孩子）
```

**四个常见陷阱**：

| 陷阱 | 处理 |
|---|---|
| 问"男孩中患病概率" | 分母只算男孩，不再乘 1/2 |
| 问"生一个患病男孩" | 要乘性别概率 1/2 |
| 出现致死基因型 | 先去掉致死个体，再重算分母 |
| 两种遗传病同时问 | 分开算，再相乘；注意"只患一种"要用加法 |

## 四、基因频率与基因型频率

| 情形 | 用什么 |
|---|---|
| 自由交配（随机交配）且无突变、无选择 | 用基因频率，配子随机结合 |
| 自交（自花传粉） | 用基因型频率逐代推算 |
| 已知各基因型个体数 | 基因频率 = 该基因数 ÷ 该位点基因总数 |

**算式示例**：AA 30 个、Aa 60 个、aa 10 个（共 100 个个体）。

```
A 的频率 = (30×2 + 60) / 200 = 0.6
a 的频率 = (10×2 + 60) / 200 = 0.4
自由交配下一代 aa = 0.4² = 0.16
```

## 五、细胞分裂与数目变化

| 求什么 | 方法 |
|---|---|
| 染色体数 | 数着丝粒个数 |
| DNA 数 | 数 DNA 分子数（有染色单体时与染色单体数相同） |
| 染色单体数 | 有染色单体时 = DNA 数；着丝粒分裂后 = 0 |
| 细胞周期时长 | 某期细胞数 ÷ 观察细胞总数 × 周期总时间 |

## 六、生态系统能量

| 问法 | 算法 |
|---|---|
| 求"至少消耗"生产者 | 目标量 ÷ 20% ÷ 20% …（逐级除） |
| 求"最多消耗"生产者 | 目标量 ÷ 10% ÷ 10% …（逐级除） |
| 求"最多获得" | 生产者量 × 20% × 20% … |
| 求"至少获得" | 生产者量 × 10% × 10% … |

**记忆锚**：**"至少"配"高效"（20%），"最多"配"低效"（10%）。** 这条锚只用来记方向，算式必须写出来。

**算式示例**：人要增加 1 kg 体重（最高营养级），至少消耗植物多少？

```
1 ÷ 20% ÷ 20% = 25（kg）
```

## 七、显微镜与观察

| 求什么 | 方法 |
|---|---|
| 放大倍数 | 目镜倍数 × 物镜倍数（放大的是长度或宽度，不是面积） |
| 视野中细胞数变化 | 放大倍数变为 n 倍，一行细胞数变为 1/n，视野面积内细胞数变为 1/n² |
| 物像移动方向 | 物像偏哪往哪移（与实物方向相反） |

## 八、种群数量

| 模型 | 公式 / 特征 |
|---|---|
| J 型 | Nt = N₀ × λᵗ（λ 为一年后的数量倍数） |
| S 型 | 有 K 值；K/2 时增长速率最大 |
| 标志重捕 | 总数 ≈（第一次捕获并标记数 × 第二次捕获数）÷ 第二次中带标记数 |

**注意**：标志物脱落会使估算值偏大；标记影响活动能力也会使估算偏差。判断方向时问一句"分母变大还是变小"。
