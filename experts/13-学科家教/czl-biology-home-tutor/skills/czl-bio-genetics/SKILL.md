# W3 遗传推理

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 遗传推理（czl-bio-genetics） |
| **任务职责** | 把一道遗传题按四步推到底，每一步留下依据；给出概率并说明算法。不直接给答案，先让学生走第一步。 |
| **输入参数** | 必填：题干原文、系谱图或杂交组合（图要能看清个体编号与患病标记）、题目问什么（基因型/概率/判断）。建议：学生已写出的部分、教材版本。 |
| **执行步骤** | ①判显隐性（给判据，不说"看得出来"） → ②定基因位置（常染色体/伴 X/伴 Y/母系，逐条排除） → ③推每个相关个体的基因型（不确定的用"?"并列出可能） → ④按题目问法算概率（写明乘法、加法还是条件概率） → ⑤回读题干验证（有没有致死、有没有"男孩中"这类限定） |
| **判断条件** | 系谱图看不清 → 请重拍，不猜；判据不足（如只有一代） → 明确写"信息不足，有两种可能"，分情况讨论；出现致死基因型 → 先剔除致死，再重算分母；两种遗传方式都不能排除 → 保留两种，各算一遍 |
| **输出格式** | 四步推理单（表格，每步一行：结论 + 依据）+ 标注后的系谱说明（个体基因型逐个列出）+ 概率算式（不跳步）+ 一道同类迁移题 |
| **异常处理** | 学生只要答案 → "答案在你手上，我给你第一步，你自己往下走"；涉及基因连锁与交换值的定量计算 → 一句"这超出高中要求"后停止；题干自相矛盾（判据互相冲突） → 指出矛盾点，请核对原题；孩子把"概率"与"比例"混用 → 先纠正表述再算 |
| **必要依赖** | `references/pedigree-protocol.md`（标注规范与判据全表）、`references/probability-drills.md`（原创题与分步解析）、`czl-bio-atlas/references/formula-sheet.md`（概率与基因频率公式） |
| **与其他工作流的关系** | 上游：W1 判定为遗传专项；若减数分裂链不清，先回 W2 修链再回来。下游：错题进 W6 的归因表；概率表述问题转 W6 的表述训练。 |

## 一、四步法总表（每步都要写依据）

| 步 | 要得到的结论 | 依据从哪来 | 常见丢分点 |
|---|---|---|---|
| 1 判显隐 | 显性 / 隐性 | "无中生有""有中生无"两条判据 | 把"代代相传"直接当显性 |
| 2 定位置 | 常染色体 / 伴 X / 伴 Y / 母系 | 正反交、交叉遗传、性别比例、父传子 | 跳过这步直接套伴性规律 |
| 3 推基因型 | 每个相关个体的基因型 | 由子代反推亲代，由亲代推子代 | 不确定的硬写成确定 |
| 4 算概率 | 一个分数 | 乘法、加法、条件概率 | 分母没去掉患病个体 |

**顺序不能换。** 先算概率再定位置，是这类题最大的失分来源。

## 二、第一步：判显隐性（只用两条判据）

| 判据 | 结论 | 注意 |
|---|---|---|
| 双亲都正常，子代有患病 | **隐性** | 只判显隐，判不了位置 |
| 双亲都患病，子代有正常 | **显性** | 同上 |
| 代代都有患者，且男女比例接近 1:1 | 倾向显性，但**不能定论** | 隐性在人群中也可能代代出现 |
| 患者隔代出现、男性明显多于女性 | 倾向伴 X 隐性 | 仍需第二步验证 |

判据不足时，写"显隐性待定，两种假设分别推"，不要硬猜。

## 三、第二步：定位置（逐条排除）

| 位置 | 支持证据 | 排除证据 |
|---|---|---|
| 常染色体隐性 | 男女患病机会均等；近亲婚配后代风险升高 | 女患者父亲正常（若为伴 X 隐性则应患病） |
| 伴 X 隐性 | 男性患者多于女性；母病子必病；女病父必病；交叉遗传 | 女患者父亲正常；母亲患病而儿子正常 |
| 伴 X 显性 | 女性患者多于男性；父病女必病；子病母必病 | 父病女正常；子病母正常 |
| 伴 Y | 患者全为男性；父传子、子传孙 | 出现女性患者 |
| 母系（线粒体） | 母亲患病，子女全患病；父亲患病，子女不患病 | 母亲正常而子女患病 |

**排除法的用法**：先找一条"绝不成立"的证据把选项砍掉，剩下的再比。比"哪条更像"可靠得多。

## 四、第三步：推基因型（不确定就写"?"）

符号约定（写进推理单，孩子照抄）：

| 符号 | 含义 |
|---|---|
| A_ | 至少有一个 A，另一个未知 |
| Aa / aa | 已确定 |
| ? | 信息不足，可能有两种 |
| ① ② ③ | 个体编号，与题干一致 |

推的顺序：**先定隐性纯合（最好定）→ 再定其双亲 → 再往兄弟姐妹推 → 最后推到旁系。**

不确定的个体不要硬写。写"?"并把两种可能列出来，比写错一个更好拿分——很多题的最后一问就是"若……则……"。

## 五、第四步：算概率（写明用了哪条规则）

| 情形 | 规则 | 写法 |
|---|---|---|
| 两个独立事件同时发生 | 乘法 | P = P₁ × P₂ |
| 互斥事件任一发生 | 加法 | P = P₁ + P₂ |
| 已知表现型正常 | 条件概率 | 分母去掉患病个体 |
| 问"男孩中患病" | 条件概率 | 不再乘 1/2 |
| 问"生一个患病男孩" | 乘法 | 患病概率 × 1/2 |
| 有致死基因型 | 先剔除 | 分母去掉致死个体 |

四个陷阱的完整处理见 `czl-bio-atlas/references/formula-sheet.md` 第三节。

## 六、输出模板

```
【遗传推理单】题干编号 ①②③……
第1步 判显隐：隐性
  依据：②③表现型正常，其子代④患病（无中生有）

第2步 定位置：常染色体
  依据：若为伴X隐性，女患者④的父亲②必患病，而②正常 → 排除；伴Y有女性患者 → 排除

第3步 推基因型
  ④ aa ← 由表现型直接定
  ② Aa、③ Aa ← 子代 aa，双亲各提供一个 a
  ① AA 或 Aa（?）← 表现型正常，父母未知

第4步 算概率
  问：①与一携带者婚配，子代患病概率
  ① 为 Aa 的概率 = 2/3（父母 Aa×Aa，正常子代中 AA:Aa = 1:2）
  子代患病 = 2/3 × 1/4 = 1/6
  规则：条件概率（分母去掉 aa）+ 乘法

回读：题干未提致死，未限定性别，答案 1/6 成立
迁移题：把①换成"①的妹妹"，其余不变，答案是多少？
```

## 七、推不下去的三种情形

| 症状 | 原因 | 处理 |
|---|---|---|
| 推到一半两种可能都成立 | 信息确实不足 | 分情况写，各给结论，并说明"若补充……可确定" |
| 概率算出大于 1 | 分母没去掉患病个体，或把互斥当独立 | 回头重算分母 |
| 基因型推出来与表现型矛盾 | 显隐或位置判错 | 退回第 1、2 步，不要在第 3 步硬修 |

第三种最常见。**在第 3 步硬修，是最费时间也最不讨好的做法。**
