# 遗传概率练习与分步解析（czl-bio-genetics 参考）

六道原创题，覆盖最常丢分的六种情形。**先让学生做，再看解析。** 解析里写的是"每一步为什么"，不是"答案是什么"。

---

## 练习 1｜条件概率：分母要去掉患病个体

**题**：一对表现型正常的夫妇生了一个患病孩子（常染色体隐性遗传）。若他们再生一个表现型正常的孩子，这个孩子是携带者的概率是多少？

**解析**

1. 由"无中生有"判隐性，父母均为 Aa，患儿 aa。
2. 正常子代的基因型空间：AA : Aa = 1 : 2。
3. 已知这个孩子正常，分母只算正常孩子：携带者概率 = **2/3**。

**错在哪**：答 1/2 的，是把分母算成了全部子代。题目已经告诉你"这个孩子正常"，患病的那 1/4 不能进分母。

---

## 练习 2｜"患病男孩"与"男孩中患病"不是一回事

**题**：红绿色盲为伴 X 隐性。母亲为携带者（X^B X^b），父亲正常（X^B Y）。求：①生一个患病男孩的概率；②生一个男孩，其患病的概率。

**解析**

1. 子代四种，各占 1/4：X^B X^B（正常女）、X^B X^b（携带女）、X^B Y（正常男）、X^b Y（患病男）。
2. ①"患病男孩"= 同时满足"男孩"和"患病" = X^b Y = **1/4**。
3. ②"生一个男孩，其患病"= 已知是男孩，分母只算男孩（X^B Y 与 X^b Y）= **1/2**。

**错在哪**：两问都答 1/4，或都答 1/2。判断标准只有一句：**"已知……"出现没有。** 出现就是条件概率。

---

## 练习 3｜致死基因型：先减掉，再算比例

**题**：小鼠毛色由一对等位基因控制，黄色（A）对灰色（a）显性，且 AA 胚胎期致死。两只黄鼠交配，子代中黄鼠与灰鼠的比例是多少？

**解析**

1. 双亲均为 Aa（黄鼠，且 AA 致死，所以黄鼠只能是 Aa）。
2. Aa × Aa → 1 AA : 2 Aa : 1 aa。
3. AA 致死 → 存活个体为 2 Aa : 1 aa。
4. 黄 : 灰 = **2 : 1**。

**错在哪**：答 3 : 1 的，忘了 AA 活不下来。**看到"致死"两个字，先把致死基因型划掉再算。**

---

## 练习 4｜自由交配用基因频率，自交用基因型频率

**题**：某植物种群中 AA 占 30%、Aa 占 60%、aa 占 10%，群体足够大。求：①随机交配一代后 aa 的比例；②自交一代后 aa 的比例。

**解析**

① 随机交配：
```
A 的频率 = (30×2 + 60) / 200 = 0.6
a 的频率 = (10×2 + 60) / 200 = 0.4
aa = 0.4 × 0.4 = 0.16（16%）
```

② 自交（各自繁殖，不互相授粉）：
```
AA 30% 自交 → 30% AA
Aa 60% 自交 → 15% AA + 30% Aa + 15% aa
aa 10% 自交 → 10% aa
aa 合计 = 15% + 10% = 25%
```

**错在哪**：两问都用基因频率算，得 16% 和 16%。**自由交配改变基因型频率、不改变基因频率；自交使纯合子比例上升。** 这两句要能背下来。

---

## 练习 5｜两对基因自由组合：先分开算，再相乘

**题**：基因型为 AaBb 的个体自交（两对基因独立遗传）。求子代中表现型与亲本不同（即不表现为双显性）的比例。

**解析**

1. 一对一对算：Aa × Aa → 显性 3/4、隐性 1/4；Bb × Bb 同理。
2. 双显性（A_B_）= 3/4 × 3/4 = 9/16。
3. 与亲本表现型不同 = 1 − 9/16 = **7/16**。

**错在哪**：直接答 9:3:3:1 的四个数，却答不上"其中重组类型是多少"。**两对基因的题，永远先拆成两个一对基因的题。**

---

## 练习 6｜伴 X 显性：先画配子，再谈比例

**题**：抗维生素 D 佝偻病为伴 X 显性遗传。一名患病女性（X^D X^d）与正常男性（X^d Y）结婚。求：①生一个患病孩子的概率；②生一个女孩，其患病的概率。

**解析**

1. 母亲产生两种卵细胞：X^D、X^d，各 1/2；父亲产生两种精子：X^d、Y，各 1/2。
2. 四种组合：

```
女儿：X^D X^d（患病）1/2 ；X^d X^d（正常）1/2
儿子：X^D Y（患病）  1/2 ；X^d Y（正常）  1/2
```

3. ① 患病孩子 = 患病女儿 1/4 + 患病儿子 1/4 = **1/2**。
4. ② 已知是女孩，分母只算女儿（X^D X^d 与 X^d X^d 各占一半）= **1/2**。

**换一个条件再练**：若母亲为纯合 X^D X^D、父亲正常（X^d Y）：
```
女儿：X^D X^d，全部患病
儿子：X^D Y，全部患病
```
① 患病孩子 = **1**；② 生一个女孩，其患病 = **1**。

**错在哪**：只记"伴 X 显性女患者多"，不会画配子。**伴性题一律先画配子组合，再谈比例。** 纯合与杂合两种情形必须分开算，这一步错了，两问全错。

---

## 六题对应的六个易错点（给学生的一句话总结）

| 题 | 易错点 | 一句话 |
|---|---|---|
| 1 | 条件概率 | 题目说"已知正常"，分母就只剩正常 |
| 2 | 性别限定 | "患病男孩"要乘 1/2，"男孩中患病"不乘 |
| 3 | 致死 | 先划掉致死基因型，再算比例 |
| 4 | 交配方式 | 自由交配看基因频率，自交看基因型频率 |
| 5 | 自由组合 | 拆成两个一对基因，算完再相乘 |
| 6 | 配子组合 | 先画配子，再谈男女比例 |
