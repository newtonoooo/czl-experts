# 系谱图推理规范（czl-bio-genetics 参考）

## 一、标注符号（照抄到纸上，不要自己另发明）

| 符号 | 含义 | 写法 |
|---|---|---|
| □ / ○ | 正常男性 / 正常女性 | 题干通常已给 |
| ■ / ● | 患病男性 / 患病女性 | 题干通常已给 |
| Ⅰ、Ⅱ、Ⅲ | 世代 | 从上往下编号 |
| 1、2、3 | 同一代从左到右的个体编号 | Ⅰ-1、Ⅱ-3 这种写法 |
| ◇ | 性别未知或未出生 | 概率题常用 |
| A_ | 显性表现型，另一个等位基因未知 | 写在个体旁 |
| ? | 信息不足 | 必须列出两种可能 |

推理单上每个个体只写一个符号，不要写"（可能）Aa 或 AA"这种长句，占地方且容易看错。

## 二、判定流程（按顺序问四个问题）

**问 1：有没有"无中生有"或"有中生无"？**

- 双亲正常 → 子代患病：**隐性**
- 双亲患病 → 子代正常：**显性**
- 都没有：进入问 2，按两种假设各推一次

**问 2：能不能用一条证据砍掉伴性？**

| 想砍掉 | 找这条证据 |
|---|---|
| 伴 X 隐性 | 女患者的父亲正常；或母亲患病而儿子正常 |
| 伴 X 显性 | 男患者的女儿正常；或儿子患病而母亲正常 |
| 伴 Y | 出现女性患者 |
| 母系 | 母亲正常而子女患病；或父亲患病而子女患病 |

砍完之后如果只剩一种，位置就定了。剩两种以上，继续问 3。

**问 3：男女比例有没有明显偏向？**

男性患者显著多于女性 → 倾向伴 X 隐性；女性显著多于男性 → 倾向伴 X 显性；接近 1:1 → 倾向常染色体。**这只是倾向，不能单独当结论。**

**问 4：还剩两种可能怎么办？**

分情况写。"若为常染色体隐性，则……；若为伴 X 隐性，则……"。多数题的最后一问会给一个附加条件（如"经查 Ⅱ-3 不携带致病基因"），条件一给，答案就唯一。

## 三、判据速查表

| 遗传方式 | 必成立 | 必不成立 |
|---|---|---|
| 常染色体隐性 | 男女均可患病；近亲婚配风险升高 | — |
| 常染色体显性 | 代代可有患者；男女均等 | — |
| 伴 X 隐性 | 母病子必病；女病父必病 | 女患者父亲正常；母亲患病儿子正常 |
| 伴 X 显性 | 父病女必病；子病母必病 | 男患者女儿正常；儿子患病母亲正常 |
| 伴 Y | 患者全为男性；父传子、子传孙 | 出现女性患者 |
| 母系 | 母病子女全病；父病子女不病 | 母亲正常而子女患病 |

**"必成立"是用来验证的，"必不成立"是用来排除的。做题时先用排除，再用验证。**

## 四、完整演示（原创题，可当例题讲）

**题干**：某单基因遗传病系谱如下——Ⅰ-1（正常男）与Ⅰ-2（正常女）生有 Ⅱ-1（患病男）、Ⅱ-2（正常女）；Ⅱ-2 与 Ⅱ-3（正常男）生有 Ⅲ-1（患病女）、Ⅲ-2（正常男）。问：该病的遗传方式，以及 Ⅱ-2 与 Ⅱ-3 再生一个患病孩子的概率。

**第一步 判显隐**

Ⅱ-2 与 Ⅱ-3 均正常，生有患病女儿 Ⅲ-1 → 双亲正常、子代患病 → **隐性**。

**第二步 定位置**

假设伴 X 隐性：Ⅲ-1 为患病女性（XᵃXᵃ），其父亲 Ⅱ-3 必为 XᵃY，即必患病。但 Ⅱ-3 表现正常 → **排除伴 X 隐性**。
伴 Y：Ⅲ-1 为女性患者 → 排除。母系：母亲 Ⅱ-2 正常而女儿患病 → 排除。
→ **常染色体隐性**。

**第三步 推基因型**

设致病基因为 a。

| 个体 | 基因型 | 依据 |
|---|---|---|
| Ⅲ-1 | aa | 患者，隐性纯合 |
| Ⅱ-2 | Aa | 表现正常但生有 aa 子代 |
| Ⅱ-3 | Aa | 同上 |
| Ⅱ-1 | aa | 患者 |
| Ⅰ-1、Ⅰ-2 | 均 Aa | 表现正常，生有 aa 子代 |
| Ⅲ-2 | AA 或 Aa（?） | 表现正常，父母均 Aa，AA:Aa = 1:2 |

**第四步 算概率**

Ⅱ-2（Aa）× Ⅱ-3（Aa）→ 子代 aa 概率 = 1/4。

若题目改问"再生一个正常男孩的概率"：1/4 患病 → 正常 3/4，再乘性别 1/2 → 3/8。

若改问"再生一个男孩，其患病的概率"：性别已定，不再乘 1/2 → 1/4。

**回读**：题干未提致死、未限定性别，1/4 成立。

## 五、三种非常规图型怎么读

| 图型 | 读法 |
|---|---|
| 杂交组合表（正交/反交） | 正反交结果不同 → 与性别相关，优先想伴性；结果相同 → 多为常染色体 |
| 表格型（亲代×子代数量） | 先算子代性状分离比，3:1 提示杂合自交，1:1 提示测交 |
| 电泳图 | 先数条带：一条带 = 纯合，两条带 = 杂合；再对应个体编号 |

## 六、讲这道题时的三句固定话术

1. "先说结论，再说依据。依据里必须有'如果……就矛盾'这一句。"
2. "不确定的个体写问号，不要写'大概'。问号能拿分，'大概'不能。"
3. "算完回读一遍题干，看有没有'男孩中''再生一个''至少'这类限定词。"
