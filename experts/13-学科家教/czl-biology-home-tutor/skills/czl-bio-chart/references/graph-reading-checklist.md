# 读图清单（czl-bio-chart 参考）

## 一、逐项打勾清单（读任何一张图都走一遍）

**第一步：轴**

- [ ] 横轴是什么，单位是什么
- [ ] 纵轴是什么，单位是什么（速率还是总量，这一条最容易错）
- [ ] 纵轴起点是不是 0；不是 0 时，视觉上的"翻倍"可能只是 10% 的变化
- [ ] 横轴是时间、浓度还是距离；是对数刻度还是等距刻度

**第二步：对照**

- [ ] 图上有几条线/几组柱子，哪一组是不处理的对照
- [ ] 图例里每个条件分别对应哪条线
- [ ] 有没有"标准"曲线（如最适条件下的曲线）

**第三步：关键点**

- [ ] 起点（与纵轴交点）的数值
- [ ] 拐点在哪，拐点前后各是什么因素在限制
- [ ] 极值（最高/最低）出现在哪个横坐标
- [ ] 与横轴的交点（净效应为零的位置）
- [ ] 两条线的交点

**第四步：分段**

- [ ] 上升段：斜率说明了什么
- [ ] 平台段：什么因素成了限制
- [ ] 下降段：是抑制、失活，还是消耗完了

**第五步：写**

- [ ] 结论句有"条件 + 范围 + 趋势 + 关键值"四样

## 二、四种必记的斜率含义

| 段 | 斜率 | 生物学含义 |
|---|---|---|
| 上升段 | 正 | 该因素仍在起促进作用；斜率大说明敏感 |
| 平台段 | 约等于 0 | 该因素不再是限制因素，另有因素限制 |
| 下降段 | 负 | 出现抑制（如高温使酶失活、浓度过高抑制生根） |
| 陡降 | 绝对值很大 | 通常意味着结构被破坏，不只是活性下降 |

**判据**：平台段答"受 X 限制"，下降段答"X 过高导致……"。这两句是最常考的采分点。

## 三、单位陷阱（每年都有人栽）

| 陷阱 | 例 | 处理 |
|---|---|---|
| 速率 vs 总量 | mg/h 与 mg | 问"共产生多少"要乘时间 |
| 每克 vs 每株 | mg/g·h | 问整株要乘质量 |
| 百分比 vs 绝对量 | 增长率下降 ≠ 数量下降 | 只要增长率为正，数量仍在增加 |
| 光照强度单位 | klx 与 lx | 差 1000 倍 |

**"增长率下降但数量仍在增加"是高频陷阱**，看到"增长率"三个字先停一秒。

## 四、柱状图与误差线

| 现象 | 能得出的结论 | 不能得出的结论 |
|---|---|---|
| 两柱高度差大，误差线不重叠 | 两组差异显著 | 差异的具体原因（还需其他证据） |
| 两柱有高度差，但误差线重叠 | 不能确定有差异 | 不能说"有促进作用" |
| 只有一根柱 | 什么也说明不了 | 任何组间比较 |

**误差线重叠时说"有显著差异"，是评价题里最常见的错。**

## 五、表格题四步

1. 读表头：每一列是什么量、什么单位。
2. 排序：按数值从大到小排一遍，极值立刻出来。
3. 分组：把相近的数值归堆，看有几档。
4. 算比值：相邻两档的比值比差值更能说明规律（尤其浓度、温度类）。

## 六、示意与照片类

| 类型 | 先找 | 再看 |
|---|---|---|
| 过程示意图 | 箭头方向（物质流向） | 每个箭头上标的酶/条件 |
| 细胞分裂图 | 染色体形态与位置 | 有无同源染色体、是否联会、着丝粒是否分裂 |
| 电泳图 | 条带数量 | 一条带 = 纯合，两条带 = 杂合；条带位置对应片段大小 |
| 显微照片 | 比例尺 | 结构相对位置，不猜具体倍数 |

## 七、写完结论后的三句自检

1. 我的结论里有没有"在……范围内"？
2. 我有没有把平台段写进去？
3. 我用的数值，是图上读出来的，还是我猜的？

第三问最重要。**图上读不出的数字，一律不许写进答案。**
