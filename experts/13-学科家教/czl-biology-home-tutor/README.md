# 卓识教育-高中生物学习辅导专家

品牌：卓识教育；出镜教师：青禾老师。一个只做高中生物一对一的辅导专家。看孩子自己做出来的错题定位断点，把过程讲成一条能复述的因果链，带做实验设计与图表题，最后把能照着问的话交给家长。

开发：虫志龙（47190078@qq.com）
版本：1.0.2　　类型：Agent 型（单专家）　　分类：教育学习

## 一、它解决什么

高中生物的分数上不去，通常不是"背得少"，而是三件事：

- **过程是断的**。光合、呼吸、基因表达、免疫应答，中间某一环没通，后面全连坐。
- **条件是漏的**。答案方向对，但没写"在什么条件下"，采分点拿不到。
- **图是读不出来的**。曲线题只看高低，不看轴、不看对照、不看拐点。

这个专家不灌鸡汤、不押题、不代写作业。它做的事只有四件：定位断点、重走链条、陪练迁移、交给家长一个动作。

## 二、怎么用（三种人，三种打开方式）

**学生自己用**

> "光合和呼吸老混，帮我把这两条链画出来，再出两道题验一下。"

> "这道系谱图我推到一半推不下去了。"（附题目照片）

**家长用**

> "孩子高一，生物总在及格线上下，说背了也记不住。先做一次学情诊断，再给四周安排。"

> "他错题本抄了一堆，但下次还错，我该怎么管？"

**家教 / 机构老师用**

> "周末两小时一对一，帮我排一个时段结构，要带当堂检测。"

## 三、六个工作流

| 编号 | 工作流 | 什么时候用 |
|---|---|---|
| W1 | 学情首诊与四周计划 | 说不清哪不会、刚开始补、要一个基线 |
| W2 | 过程攻坚 | 名词会背、顺序说不清；两个过程老是混 |
| W3 | 遗传推理 | 系谱图、概率、伴性遗传、致死题 |
| W4 | 实验设计与评价 | 实验题写不满、要设计对照、要写结论 |
| W5 | 图表专项 | 曲线/表格/柱状图读不出信息 |
| W6 | 陪练复盘与家长协同 | 讲过了还是错、要复习排期、家长要办法 |

一般路径：**W1 定位 → W2—W5 单点攻坚（一次只开一个）→ W6 复盘 → 四周后回 W1 重测。**

## 四、它会给你什么

- 学情诊断卡（五类断点，每条带证据原句）
- 四周优先级表（每周一个主任务 + 一个可观测指标）
- 过程链图（每环标场所与条件，断点标出来）
- 遗传四步推理单（判显隐 → 定位置 → 推基因型 → 算概率，每步留依据）
- 实验六步设计单 + 变量矩阵 + 结论句式
- 读图单（四问四答）+ 数据提取表
- 错题归因表 + 复习排期 + 家长简报（150 字以内）

## 五、它不会做什么

- 不代写作业、不代做试卷、不给可直接誊抄的答案。
- 不押题、不承诺提分数字。
- 不讲大学内容；确需延伸会先标注"超出高考范围"。
- 不涉及疾病的诊断、用药与治疗建议。
- 不评价具体学校与老师。

## 六、用之前准备好这三样（诊断更准）

1. 最近一次生物卷子（正反面 + 答题卡）
2. 2—3 道错题：题干、孩子写的答案、标准答案
3. 教材版本（人教 / 苏教 / 北师大 / 浙科）

只有一句"生物不好"也能用，但会先给"最小诊断版"，并注明哪一步是推测。

## 八、安装

**方式一（推荐）**：在 WorkBuddy 的专家中心用"导入"选择本包的 zip，确认后即可在"我的专家"里看到。

**方式二（手动）**：把整个目录放到

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/czl-biology-home-tutor/
```

然后执行注册脚本（在专家包管理器 skill 的 `scripts/` 下）：

```bash
python3 register_expert.py <上述目录>
```

## 九、头像

`avatars/expert.png`，512×512 PNG，约 300—400 KB。可自行替换，要求：正方形、PNG/JPG、≤500 KB。

## 十、一个提醒

这个专家所有结论的前提是"先看孩子的实际作答"。如果你直接问"遗传怎么学"，它会先问你要一道题。这不是拖延——没有一道具体的题，任何诊断都是猜。
