# 卓识教育-高中物理学习辅导专家（czl-physics-home-tutor）

一个面向中国高中生的物理家庭辅导专家。它不替你讲完一道题，它先判断孩子卡在哪，
再按固定的六段把题拆开，最后留下两道变式题和一张错因卡。

- 花名：顾衡
- 职业定位：卓识教育-高中物理学习辅导专家
- 开发者：虫志龙（47190078@qq.com）
- 版本：1.0.2
- 类型：Agent 型（单个 AI 专家）

## 它解决什么问题

高中生物理丢分，很少是"没学过"，多半是四件事之一没有落地：

1. 不知道该用哪个模型（认不出题）；
2. 多过程题切不开段，衔接量丢失；
3. 规律挑错，或者挑了没检查适用条件；
4. 会做但写不到得分点上。

这四件事分别对应四类卡点（建模、过程、规律、运算），加上读题，共五类。
本专家用**三诊**把它们定位出来，再用**六段**逐段处理。

## 三诊六段

**三诊**：诉求分诊 → 卡点定位（含探测题） → 学情与版本核对。

**六段**：翻译题面 → 圈对象 → 切时间 → 挑工具 → 按点写 → 换皮再做。

每一段都有可见产出，没有产出不进下一段。

## 三条支线

- **实验线**：原理 → 器材 → 步骤 → 数据 → 误差 → 改进。
- **图像线**：读图五问（轴、斜率、面积、截距、拐点）。
- **家长线**：只问三句话，不抢答、不评价、不代读题。

## 交付物

一次辅导至少留下三样：分段讲解、两道变式题（换数字 + 换情境）、一条错因卡
（错因码 + 证据 + 补救动作 + 3/7/15 天回访）。模板在技能的 `templates/` 下。

## 内置工具

```bash
# 数值复核（同时提示常见错法）
python skills/czl-physics-coach/scripts/physics_check.py incline --m 2 --theta 30 --mu 0.2

# 变式题生成（答案由程序计算，不会出现"答案不整"）
python skills/czl-physics-coach/scripts/variant_gen.py --model energy --seed 7 --n 2

# 脚本自测（39 项断言）
python skills/czl-physics-coach/scripts/self_test.py
```

## 导入方式

1. **本机开发目录**：已放在 `~/.workbuddy/plugins/marketplaces/my-experts/plugins/` 并完成注册。
2. **从 zip 导入**：在 WorkBuddy「我的专家」中选择导入，指向 `dist/czl-physics-home-tutor-1.0.2.zip`。
3. **导入后图标显示为文字**：说明头像文件没有被解析到（平台规则是头像相对专家根目录解析，
   文件必须存在）。先确认 `avatars/expert.png` 是否随包解压出来；若文件在、图标仍未刷新，
   重启 WorkBuddy 再看。详见 `docs/02-使用说明.md` 第 6 节。
