## 0. 这份规格是怎么来的

先做功能分析，再写规格，最后才写实现。分析对象是一个已上架的同类高中物理辅导专家，
方法是逐文件阅读它的元数据、主提示词与说明文件，提取"它能完成什么任务"，
把它转成需求，再判断哪些不足需要补。

**边界**：分析阶段只提取功能与流程层面的信息；它的具体文案、比喻、句式没有被搬进本产品。
文字层面的独立性有可核查的证据，见 `04-文件清单与开发记录.md` 第 5 节的片段重合度检测
（12 字片段重合率 1.16%，均为"受力分析""动量守恒"这类通用物理词）。

## 1. 目标用户与实际使用场景

### 用户

| 用户 | 特征 | 他们真正的困难 |
|---|---|---|
| 高中生（高一至高三） | 听得懂课，做不出题；或者会做但拿不到分 | 不知道自己卡在哪，只知道"不会" |
| 陪读家长 | 大多不会物理，或只会一点 | 想帮忙，一开口就变成抢答和评价，最后吵架 |
| 家教/机构老师 | 需要稳定输出，不想每次现编讲义 | 缺固定流程与可复用的判据 |

### 五个真实场景

1. **晚上十点，一道多过程力学题卡住**：孩子说"不会"，家长看不出卡在哪。
2. **错题本越抄越厚，分数不动**：抄了答案，没定错因，也没回访。
3. **考完试要复盘**：家长想帮忙，但只会说"这题不是讲过吗"。
4. **实验题、图像题靠背**：原理说不清，数据处理不会写误差方向。
5. **考前要排计划**：知道要复习，不知道先补哪一块、多久回访一次。

## 2. 需要解决的问题

### 学生侧（学科问题）

| 编号 | 问题 | 现状 |
|---|---|---|
| P1 | 认不出题属于哪个模型 | 靠"见过"而不是靠特征判断 |
| P2 | 多过程题切不开段 | 漏掉转折事件，衔接量丢失 |
| P3 | 规律挑错或不查条件 | 有摩擦还用机械能守恒 |
| P4 | 会做但写不到得分点 | 跳步、缺单位、不写方向 |
| P5 | 错因只会归结为"粗心" | 无法对应补救动作 |

### 家长侧（协同问题）

| 编号 | 问题 | 现状 |
|---|---|---|
| P6 | 抢答、代读题、评价式反馈 | 越帮越抵触 |
| P7 | 不懂物理，无法判断孩子是否真懂 | 只能看答案对不对 |
| P8 | 不知道什么时候该停 | 情绪上头还在讲 |

## 3. 必要的输入与预期输出

### 输入（按必要性排序）

| 输入 | 必需 | 缺失时的处理 |
|---|---|---|
| 题面（文字或图片描述） | 是 | 请用户贴题；缺条件时明确指出缺什么，不补假设 |
| 年级 | 是 | 直接问，不默认 |
| 本次诉求（讲题/补概念/复盘/实验/图像/规划/家长求助） | 是 | 用一句话二选一问清："弄懂这道题，还是找出一直丢分的地方" |
| 教材版本、选科、考试地区 | 否 | 默认按人教版处理，并声明这是假设 |
| 最近分数与各题型失分 | 否 | 用于定基线；缺失时只做单题辅导，不做阶段规划 |
| 学生自己的解法/错解 | 否 | 强烈建议提供，用于定位卡点 |

### 输出（一次辅导的最小交付）

1. **分段讲解**：段号 + 每段对象/规律/方程；关键行标注这是第几个得分位。
2. **两道变式**：一道换数字、一道换情境，附答案与评分点。
3. **一条错因卡**：错因码 + 证据 + 补救动作 + 3/7/15 天回访日期。
4. （可选）**书写检查**：按六个得分位逐条指出缺哪一行。
5. （可选）**家长版摘要**：≤400 字，只写"做什么"，不写推导。

## 4. 通用处理步骤

### 主流程：三诊六段

```
受理
 ├─ 一诊 诉求分诊（七类）──→ 选择路线（主线 / 实验线 / 图像线 / 家长线）
 ├─ 二诊 卡点定位（四个动作，五类判据）
 ├─ 三诊 学情与版本核对（年级/版本/选科/地区/基线）
 └─ 六段
     ① 翻译题面：量清单 + 关键词
     ② 圈对象：受力图/场分布 + 研究对象声明
     ③ 切时间：时间轴 + 衔接量
     ④ 挑工具：定律 + 适用条件（写不出条件则退回③）
     ⑤ 按点写：六个得分位
     ⑥ 换皮再做：两道变式 + 错因卡 + 回访
```

### 分支判定

| 判定 | 走向 |
|---|---|
| 说不出已知/待求 | 走读题补救，再回主线 |
| 画不出受力图 | 走建模补救（模型图谱），再回主线 |
| 分不出段 | 走过程切分，不进入④ |
| 列得出方程解不出 | 直接进⑤，不重讲概念 |
| 问的是实验/图像 | 走支线，主线只保留⑤的书写规范 |
| 提问者是家长 | 走家长线，先给话术，不先讲物理 |
| 要求"把整份卷子做完" | 拒绝代做，改为挑三道精讲 |

### 异常处理

| 异常 | 处理 |
|---|---|
| 题面缺条件 | 指出缺哪个量，请补；不替题面设值 |
| 图像没有标度 | 说明无法定量，只能定性分析 |
| 学生答案与标准答案不一致且学生有理 | 逐步复核，确认后指出"这道题答案或评分标准可能有问题" |
| 涉及超纲工具 | 先说明"超出高考要求"，再决定是否使用 |
| 版本/选科不确定 | 标注"以你省考试说明和教材目录为准" |

## 6. 质量、速度、稳定性要求

### 质量（可核查）

| 指标 | 要求 | 现状 |
|---|---|---|
| 公式正确性 | 高中范围内无误 | 39 项断言覆盖主要模型，含动量与动能守恒的内部校验 |
| 数字与题面一致 | 题干公布的三角函数值与计算值必须同源 | 已改为同源生成，抽查一致 |
| 答案完整性 | 每题给答案 + 关键步骤 + 评分点 + 易错 | 生成器输出五项齐全 |
| 文本独立性 | 与同类产品的提示词无成段重合 | 12 字片段重合 1.16% |
| 输出结构 | 一次辅导三件交付物齐全 | 主提示词强制，缺一视为未完成 |

### 速度

| 操作 | 目标 |
|---|---|
| 单题讲解（不含长推导） | 一次回复内给出前两段 |
| 数值复核 | < 1 秒（无外部调用） |
| 变式出题 2 道 | < 1 秒 |
| 自测全跑 | < 3 秒 |

### 稳定性

- 参数非法 → 明确报错，不产生"看起来合理"的错误答案。
- 缺输入 → 追问，不默认。
- 不依赖网络与第三方服务，离线可用。
- 单文件损坏可定位：文件清单逐项标注职责。

## 8. 不做什么（范围外）

- 不代写作业、不代做试卷、不猜题、不押题。
- 不做大学物理内容；必要的延伸会标注"超出高考要求"。
- 不做手写图片 OCR，不批改整页扫描件。
- 不提供分省考试院政策的实时查询（只给核对方法）。
- 不承诺分数提升幅度。
- 不替代学校教师的教学进度安排。
