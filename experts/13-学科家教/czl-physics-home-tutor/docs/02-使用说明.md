# 使用说明

版本 1.0.2 ｜ 适用平台 WorkBuddy ｜ 包名 czl-physics-home-tutor

---

## 1. 三种安装方式

### 方式一：本机开发目录（开发者自用）

专家已放在：

```
C:\Users\丛自龙\.workbuddy\plugins\marketplaces\my-experts\plugins\czl-physics-home-tutor\
```

并已完成注册。打开 WorkBuddy → 左侧「专家」→「我的专家」即可看到「顾衡」。
若没出现，重启 WorkBuddy。

### 方式二：从 zip 导入（分发给别人）

1. 拿到 `dist/czl-physics-home-tutor-1.0.2.zip`；
2. WorkBuddy →「专家」→ 我的专家 → 导入，选择该 zip；
3. 导入完成后重启 WorkBuddy，再在专家列表中选中「顾衡」。

> zip 结构是「一个顶层目录 + 目录内文件」，这是 WorkBuddy 导出/导入的标准形式，
> 不要手动把文件摊平到 zip 根目录。

### 方式三：手动放置

把整个 `czl-physics-home-tutor` 文件夹复制到目标机器的
`<WorkBuddy 配置目录>/plugins/marketplaces/my-experts/plugins/` 下，重启即可。
配置目录默认是 `~/.workbuddy`（Windows 为 `C:\Users\<用户名>\.workbuddy`）。

## 2. 第一次对话怎么开

选中专家后，它会先问两件事：**年级**，以及**这次想解决什么**。

你可以直接说：

> 高二，物理一直七十多分，这道题不会（附题面）。

也可以用它自带的三个推荐问题开头：

- 孩子这道多过程力学题卡住了，帮我拆成段讲
- 帮我判断孩子物理到底卡在哪：是模型、过程、规律还是计算
- 周末我要陪孩子复盘错题，给我一套能照着做的流程

## 3. 七类场景，怎么问最有效

| 你想要 | 这样问 | 你会拿到 |
|---|---|---|
| 讲一道题 | "这道题孩子卡住了，题干是……" | 分段讲解 + 两道变式 + 错因卡 |
| 找病根 | "他总说粗心，帮我判断到底卡在哪" | 卡点判断 + 依据 + 探测题 + 补救动作 |
| 复盘错题 | "这道他做错了，错解是……" | 错因码 + 证据 + 一条补救 + 回访日期 |
| 补概念 | "老师讲懂了，自己做不会" | 概念补漏 + 两道原始模型题 |
| 实验题 | "这道实验题只会背答案" | 六步流程 + 数据处理写法 + 误差方向 |
| 图像题 | "v-t 图看不懂" | 读图五问 + 这道图的具体读法 |
| 家长求助 | "我一讲就吵架，怎么办" | 三句话话术 + 20 分钟流程 + 验收三条 |

### 提高效果的三个小动作

1. **把孩子的错解一起发**。错解比题目更能定位卡点。
2. **说明版本和地区**。人教/沪科/粤教、3+1+2 还是 3+3，会影响讲哪一册、讲到什么深度。
3. **要求它先只做第一段**。比如"先只帮我把已知和待求列出来"，避免一次给出全文、
   孩子只看答案。

## 4. 怎么配合内置工具

工具在 `skills/czl-physics-coach/scripts/`，本机需要 Python 3.9+（无需装任何库）。

```bash
# 1) 核对一个答案（会同时提示常见错法）
python physics_check.py incline --m 2 --theta 30 --mu 0.2
python physics_check.py collision --m1 2 --u1 6 --m2 4 --u2 0 --kind elastic

# 2) 出一组同型变式题（题干与答案一起给，答案由程序算）
python variant_gen.py --list
python variant_gen.py --model energy --seed 7 --n 2

# 3) 确认脚本本身没坏
python self_test.py
```

在对话里也可以直接说："用脚本核一下这个答案"，专家会调用对应脚本而不是心算。

## 5. 拿到输出后怎么用

### 学生

- 先只看第一段（翻译题面），自己把量清单填一遍，再往下看。
- 变式题必须**先做后看**。看了答案再做，等于没做。
- 错因卡贴在错题本第一页，3 天后回来重做。

### 家长

- 用 `templates/家长陪练单.md` 打印一张，按上面的三句话问。
- 只看三条验收：有没有写"对谁、从哪儿到哪儿"；有没有一行纯公式；结果有没有单位和方向。
- 不需要懂物理，也不需要判断对错。

### 老师/家教

- `templates/讲义模板.md` 直接填，省去每次排版。
- `variant_gen.py` 批量出同型题，避免手编数字出错。
- 一周结束用 `templates/错因卡.md` 的统计表看主码变化。

## 6. 故障排查

### 6.1 选中专家后，小图标不见了，显示成一个字

这是**头像没有被解析到**，不是专家坏了。平台的读取规则是：

> `plugin.json` 里的 `avatar` 会被当作**相对专家根目录**的路径去解析，文件必须真实存在，
> 且必须位于专家根目录之内；解析不到就返回空，界面退化为显示名字首字。

所以按下面顺序查，基本一次能定位：

1. **先看文件在不在**
   打开 `<配置目录>/plugins/marketplaces/my-experts/plugins/czl-physics-home-tutor/avatars/`，
   应该有 `expert.png`（约 421 KB）。没有 → 包在传输/打包时丢了 `avatars` 目录，
   用完整 zip 重新导入。
2. **再看名字对不对**
   `plugin.json` 写的是 `avatars/expert.png`，文件名必须一模一样，注意大小写
   （Windows 不区分，macOS/Linux 区分）。改成 `Expert.PNG`、`expert.jpg` 都会失效。
3. **最后重启**
   导入后界面可能还在用旧的专家列表缓存，重启 WorkBuddy 再选一次。

本包已按这三点做了防护：固定英文文件名、路径不带 `./`、体积 421 KB（远低于 500 KB 上限）、
PNG 8 位 RGB 非隔行。如果你拿到的包在这台机器上仍显示文字，按上面三步查，
并把第 1 步的目录截图发回来。

### 6.2 导入时提示「专家已存在」

同名专家已安装。先在「我的专家」里删掉旧的，再导入；或选择覆盖。

### 6.3 专家能选中，但回复很短、不按流程走

- 检查是不是只发了"在吗""你好"，没有给题或诉求；
- 明确说一句"按三诊六段来"，它会切回主流程；
- 长对话里上下文太杂时，新开一个会话。

### 6.4 脚本报「错误：xxx」

这是设计行为：参数不合理时直接报错，不返回近似值。按提示补齐参数即可。
例如 `--theta 0` 会报错，因为 0° 斜面没有下滑分力，模型不成立。

### 6.5 中文乱码（Windows 终端）

在 PowerShell 里先执行 `chcp 65001`，或把输出重定向到文件再用编辑器打开。

## 7. 更新与卸载

**更新**：用新版本 zip 覆盖导入（选择覆盖），或替换目录后重启。版本变化看 `CHANGELOG.md`。

**卸载**：在「我的专家」里删除该专家即可；手动安装的，删除
`plugins/marketplaces/my-experts/plugins/czl-physics-home-tutor/` 整个目录，重启。

卸载不会影响你的其他专家与会话记录。

## 8. 常见问题

**Q：它能不能直接给我整份卷子的答案？**
不能。这是明确的产品边界。它可以挑三道精讲、批改步骤、出同型题。

**Q：它会不会算错？**
物理推导仍由模型生成，存在出错可能。所以涉及具体数值时，让它调用 `physics_check.py`
复核；脚本覆盖不到的，它会说明"这需要看原题和评分标准"。

**Q：孩子基础很差，能用吗？**
可以，但要把诉求说清楚（"补概念"而不是"讲这道压轴题"）。它会先补模型再讲题。

**Q：家长完全不懂物理，会不会被绕进去？**
家长线是独立支线，只给三句话和验收三条，不需要物理知识。

**Q：支持哪些教材版本？**
以人教版（2019）为基准，其他版本给差异提示。具体册次以学生手里目录为准。
