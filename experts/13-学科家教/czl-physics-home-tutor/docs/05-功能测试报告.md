## 3. 关键测试的实际输出

### T02 官方校验

```
❌ 1 error(s):
   • plugin.json: invalid categoryId '15-Education'
```

判定：**不是产品缺陷**。`15-Education` 是线上教育类专家的实际取值
（`classroom-questioning-designer`、`teaching-objective-designer` 与目标专家均使用），
官方脚本的白名单只到 `12-IndustryConsultant`，属脚本滞后。详见 D01。

### T05 / T10 脚本自测

```
通过 39 项，失败 0 项
```

覆盖内容：
- 已知答案核对：匀变速、斜抛（射程 40 m）、斜面（N=17.32 N）、竖直圆周（√5 与 5 m/s）、
  弹性碰撞（-2 与 4 m/s，动能损失 0）、完全非弹性（2 m/s，损失 24 J）、机械能、感应、闭合电路。
- 异常输入：负质量、0 度倾角、零电阻、负抛射角、未知碰撞类型，全部抛 `ValueError`。
- CLI 返回码：正常 0、非法参数 2。
- 生成器：6 个模型各 7 个种子，字段完整性；同种子结果一致。

## 4. 缺陷记录

| 编号 | 现象 | 原因 | 处理 | 状态 |
|---|---|---|---|---|
| D01 | 官方校验报 `invalid categoryId '15-Education'` | 官方脚本白名单未收录教育分类 | 保留正确分类，在文档与风险清单中说明；用自建脚本按线上规则校验 | 已知外部问题，不修改 |
| D02 | 变式题题干写 `sin37°=0.6`，答案却按 0.6018 计算，两者不一致 | 题干用四舍五入值、计算用 `math.sin` | 改为同源取值：先四舍五入再计算，题干公布实际使用的值 | 已修复并回归 |
| D03 | 生成头像右下角带"AI生成 WORKBUDDY"水印 | 图像生成工具默认加水印 | 用镜像修补覆盖该区域并降采样重编码 | 已修复，人工目检确认无残留 |
| D04 | `avatars/.gitkeep` 空文件导致检查报警 | 初始化模板生成 | 删除该文件 | 已修复 |
| D05 | `displayDescription.zh` 53 字，超出 40–50 字要求 | 初稿偏长 | 压缩到 44 字 | 已修复 |
