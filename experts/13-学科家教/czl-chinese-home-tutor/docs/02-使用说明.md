# 使用说明

## 一、谁适合用

- 孩子读高一到高三，语文成绩卡住但说不清原因的家庭；
- 请了一对一家教，想知道这两小时该怎么用、效果怎么看的家长；
- 自己带学生的家教老师，需要一套可复用的时段结构与反馈话术；
- 想自己解决问题的高中生。

不适合：想找"万能作文模板""押题卷""保分方案"的人。本产品明确不做这些。

## 二、第一次怎么开始

### 1. 准备三样材料（原样拍照即可，不用整理）

1. 最近一次语文卷子，正反面，包括答题卡；
2. 最近写的一篇作文，最好是考试时写的；
3. 一道做错的文言题或阅读题：题干、孩子的答案、标准答案。

**先删掉姓名、学校、班级。** 删不掉的，系统会用"学生A"替代。

### 2. 说清三件事

年级、最近一次分数（或大致区间）、孩子自己觉得哪块最没底。

一句话就够：

> 高一，上次 92 分，他说文言最没底。

### 3. 等第一份诊断

第一次输出是"诊断卡"，不是学习计划。计划在诊断之后，因为不知道卡点排出来的计划是空的。

## 三、三种用法

### 家长

```
孩子高一，语文总在 90 分上下，说不清哪儿不会。先帮我做一次家庭学情诊断，再给四周计划。
```

拿到诊断卡后，重点看两处：**"卡住的"第一条**（这周只做这个）、**"今晚就能做"**（20 分钟，当天可完成）。

不要一次问五个问题。一次问一个，做完一个再问下一个。

### 学生

```
我作文总是写不长，想到什么写什么，帮我看看问题在哪。
```

学生端的回复会更短、更口语。规则是：只给方法和追问，不代写；要"帮我写一篇"，会改成"我们一起把第一段写出来"。

### 家教老师

```
明天两小时，学生高二，现代文主观题不分点。帮我排个时段表，讲练比别超过三成，再给我一段课后发给家长的话。
```

会拿到：时段表（含每段谁在动）、示范脚本、问题链、当堂检测、80 字家长反馈稿。

## 四、五个工作流怎么触发

| 你说的话 | 走哪个 | 拿到的第一句回应 |
|---|---|---|
| "不知道哪儿不会" | W1 首诊 | 要材料，或给最小诊断版 |
| "两小时怎么排" | W2 辅导设计 | 先确认能力点，再给时段表 |
| "这篇作文帮我看看" | W3 面批 | 先引一句原文说好在哪里 |
| "文言读不懂" | W4 诊所 | 先问错因，再给练法 |
| "怎么安排每周" | W5 系统 | 先算可用时间，再排 3-2-1 |

一句话里同时问两件事（如"作文和文言都不行怎么办"），会先做取舍，只做一件。

## 五、输出怎么用

- **诊断卡**：截图存手机，或打印贴冰箱。四周后拿出来对照。
- **面批单**：打印出来，让孩子拿着改，改完在"下次检查点"那行打勾。
- **周计划**：抄在便签上，只写时段和项目，不写目标口号。
- **复盘表**：每周日填一次，四周后一起看。

需要文件版时说一句"给我一份可打印的"，会生成文件供下载。

## 六、常见问题

### Q1：导入到另一台电脑后，专家列表里只有名字，没有头像，显示成一个字

这是客户端拿不到头像时的占位显示。按顺序查三件事：

1. **压缩包里有没有头像文件。** 正常结构是解压后第一层就是 `.codebuddy-plugin/`、`agents/`、`avatars/`、`skills/`，且 `avatars/expert.png` 存在。用本包自带脚本查最快：

   ```bash
   python bin/check_expert_package.py czl-chinese-home-tutor.zip
   ```

   若提示"压缩包内找不到头像条目"，说明打包时漏了 `avatars/`，重新打包即可。

2. **`.codebuddy-plugin` 目录是否被解压工具丢掉。** 这个目录以点开头，部分网盘转存或解压工具会跳过。丢了它，专家只剩名字。

3. **是否导入过同名专家。** 旧卡片缓存不会自动刷新。彻底退出客户端再进；仍不行就把旧目录删掉重导。

补充说明：仅仅"多套了一层文件夹"不会导致头像丢失，客户端会按清单所在目录去找。真正会导致丢图的是"清单在、图片不在"或"图片路径写错"。

### Q2：它为什么不给我作文打具体分数

因为打不准，而且会误导。默认给"四层定位"（审题、立意、材料与结构、语言）。坚持要分数时，会给区间并注明"以本省当年细则和学校评分为准"。

### Q3：能不能直接帮我写一篇

不能。会给诊断、追问和最多两句示范，其余由本人写。这是产品规则，不是能力限制。

### Q4：孩子不配合怎么办

先降量到 15 分钟，只做他愿意动的一项；两周内不谈方法，先恢复一次"完成"的体验。具体话术见 `skills/home-system/references/parent-scripts.md`。

### Q5：给的计划做不完

正常。完成率低于 60% 时不加量，先减项或换时段。计划是给人用的，不是给人考的。

### Q6：能不能保证提多少分

不能，也不会这么说。可以给四个可数的指标：周完成率、主观题分点率、作文成文时间、同一错因次数。

### Q7：教材版本不一样怎么办

以学生手上的课本为准。内置的教材地图用于定位与找同类篇目，不替代课本。

## 七、边界

- 不替代学校教学，不评价任课老师；
- 不替代专业测评与心理服务；孩子出现持续情绪问题，请联系学校心理老师，紧急情况拨打 110 或 120，心理援助热线 12356；
- 不收集、不保存学生的身份信息；
- 所有内容由 AI 生成，供家庭参考，需结合孩子实际情况判断。
