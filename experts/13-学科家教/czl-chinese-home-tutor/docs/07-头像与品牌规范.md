# 头像与品牌规范

## 一、文件规格（实测）

| 项 | 值 |
|---|---|
| 路径 | `avatars/expert.png` |
| 尺寸 | 512 × 512 |
| 位深 / 色彩类型 | 8 位 / RGB（colortype 2，无 alpha） |
| 大小 | 406,822 字节（397 KB，上限 500 KB） |
| 文件名校验 | 全部小写，无中文、无空格 |
| 字段写法 | `"avatar": "avatars/expert.png"`（不带 `./`） |

## 二、设计意图

头像要在一排专家卡片里被认出来，而卡片上的图通常只有 40—48 px。所以设计上做了四个取舍：

1. **正面半身、头部占比大。** 缩到 48 px 时，脸和眼镜仍然能辨认。
2. **暖米色背景 + 深墨蓝外套。** 明度高、对比强，缩小后不糊成一团。
3. **道具克制。** 只有一本书和背景里淡化的书堆、毛笔，不抢主体。
4. **无文字、无边框、无 logo。** 小尺寸下文字是噪点，边框会和卡片圆角打架。

形象设定：一位五十岁上下的男教师，灰白短发、细圆框眼镜、立领外套，手扶一本书，表情平和。对应产品定位"经验丰富、不推销、不制造焦虑"。

## 三、生成与后处理记录

| 步骤 | 内容 |
|---|---|
| 生成工具 | 图像生成模型（文生图） |
| 生成尺寸 | 1024 × 1024 |
| 提示词要点 | 暖色扁平矢量插画；中国高中语文教师，五十岁上下，灰白短发、细圆框眼镜；深墨蓝立领外套配米白衬衫；手扶一本书；暖米色背景，淡化书堆与毛笔剪影；正面半身、居中；无文字、无字母、无边框、无水印 |
| 后处理 1 | 裁掉底部 84 px，去除生成工具自动添加的水印区 |
| 后处理 2 | 剩余 1024×940，居中裁为 940×940 正方形（左偏移 42 px） |
| 后处理 3 | 面积重采样（area resample）缩到 512×512，转 RGB，PNG 压缩 9 级 |
| 工具 | 本包 `bin/prepare_avatar.py`（纯标准库，可复现） |

复现命令：

```bash
python bin/prepare_avatar.py <原始生成图>.png avatars/expert.png --crop 42,0,940,940 --size 512
```

## 四、为什么用 `expert.png` 这个文件名

平台规范允许自定义文件名，但压缩包导入时，客户端只在包内按 `<清单目录>/<avatar 字段>` 找文件。用最通用的 `expert.png`、字段值不带前缀，是让"换一台机器导入"这条路径最不容易出错的写法。

头像丢失会直接退化为"名称首字"文字占位，成因与排查见 `docs/05-功能测试报告.md` 第四节。

## 五、替换头像

1. 新图准备：正方形，建议 1024×1024，人物居中。
2. 处理：

   ```bash
   python bin/prepare_avatar.py 新图.png avatars/expert.png --size 512 --max-kb 500
   ```

3. 若新图带水印，先用 `--crop 左,上,宽,高` 裁掉。
4. 重新打包，并跑一次 `bin/check_expert_package.py dist/czl-chinese-home-tutor.zip`。

字段不用改，文件名不变。

## 六、品牌使用边界

- 头像可用于本专家在平台内的展示，以及开发者本人的作品集说明。
- 不得改动后用于其他产品，造成来源混淆。
- 不得把头像与"名校""名师""官方认证"等表述并列使用。
- "卓识教育"是系列品牌名，"砚耕"是该系列中的角色设定名，二者都不是真实人物；对外介绍时应写"开发者：虫志龙"，不要写成"砚耕老师本人开发"。
