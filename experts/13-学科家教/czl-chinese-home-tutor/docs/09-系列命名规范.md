# 系列命名规范（卓识教育）

## 一、系列名

**卓识教育**

- 取义：卓识＝看得比别人多一层。语文考到最后，比的不是谁背得多，是同一篇文章里谁能多看出那一层。
- 为什么用它做系列名：两个字＋"教育"，指向清楚，家长一眼知道是做什么的；跨学科中性，语文不偏文，数学不别扭。
- **已知重名情况（必须知道）**：截至 2026-10-31 检索，"卓识教育"至少有四家在用——InsightEdu 卓识教育（K-12 数学，themathinsights.com）、北京中德卓识教育咨询有限责任公司（china-sage.com）、德州经济技术开发区卓识教育培训学校有限公司、上海卓识成就教育科技（已吊销注销）。因此本名称存在商标冲突与来源混淆的可能性，**上架前须在第 41 类（教育、培训）做商标检索**；如有相同或近似注册，换前缀即可，包标识不用动。

## 二、命名公式

```
卡片名 displayName.zh ：卓识教育-高中{科目}学习辅导专家
职业头衔 profession.zh：卓识教育-高中{科目}学习辅导专家（与卡片名一致）
包标识 name          ：czl-{subject}-home-tutor
英文名 displayName.en：Zhuoshi Education - Senior High {Subject} Learning Expert
```

规则：

1. **分隔符只用 `-` 或 `—`**。平台名称字段只接受中英文、数字和这两个符号；用 `·`、`｜`、`/`、空格都会校验失败或显示异常。本系列统一用半角 `-`。
2. **卡片名 15 字**（4＋1＋10）。目前平台列表可完整显示；若某个客户端截断，改用短式：`卓识教育-高中语文辅导专家`（13 字），只删"学习"二字。
3. "教育"二字已含机构意味，对外文案不得再写"学院""研究院""中心""官方"等词，避免叠加成虚假主体。
4. 科目用高中通行叫法：语文、数学、英语、物理、化学、生物、政治、历史、地理。
5. 包标识一律小写、连字符，与目录名、agentName 完全一致，**永不随品牌名改动**（它是唯一键）。

## 四、系列内必须一致的五件事

系列感来自结构相同，不是名字相同。

1. **依据分级**：K（课标教材）/ R（公开研究）/ E（通用经验）/ I（推断）。
2. **辅导骨架**：回炉—示范—陪练—独立—收口，讲练比 3:7。
3. **三条硬边界**：不代写、不承诺分数、不评价任课老师。
4. **AI 标识**：完整产出末尾统一写"本内容由 AI 生成，供家庭参考，请结合孩子实际情况判断使用。"
5. **隐私**：只用"学生A"，不收集姓名、学校、班级、成绩。

各科可以不同的：诊断维度、材料形态、训练任务库。

## 五、前缀的禁用写法

| 不要这样写 | 原因 |
|---|---|
| 卓识教育·高中语文… | `·` 不在允许字符内 |
| 卓识教育 高中语文… | 含空格 |
| 卓识教育研究院-… | 叠加"研究院"，暗示登记主体，虚假宣传风险 |
| 卓识教育AI-… | 字母混排降低可读性，且像工具不像老师 |
| 卓识教育名师-… | "名师"属夸大用语 |
| 卓识教育提分-… | 承诺效果，违反合规要求 |
| 智源研究院-… | 真实机构（北京智源人工智能研究院）的官方简称，冒用构成虚假关联 |

## 六、上架前要查三件事

1. **商标**：第 41 类检索"卓识教育""卓识"，看是否有相同或近似注册。**本名称已有他人在用，这一项不能省。**
2. **同名专家**：在各市场搜"卓识教育""学习辅导"，确认没有在架同名前缀。
3. **字号登记**：如以"卓识教育"作为对外经营名称长期使用，建议完成个体工商户或公司登记，避免被认定为擅自使用他人有一定影响的企业名称。

## 七、视觉上的系列化

- 头像风格统一：暖色扁平插画、正面半身、纯色背景、无文字。
- 各科人物不同（年龄、性别、道具），但画风、构图、背景色调一致，排在一起像一套。
- 学科主色可微调（语文墨蓝、数学靛青、英语青绿、物理深紫），明度接近。
