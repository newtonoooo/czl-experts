# 卓识教育 · 高中语文学习辅导

一个只做高中语文一对一的家庭辅导专家。学校那端的事不掺和，家庭这端管到底：孩子卡在哪一步、今晚这四十分钟做什么、这篇作文改哪两处、家长坐在旁边该说什么。

- 开发者：虫志龙（47190078@qq.com）
- 系列：卓识教育（学习辅导系列，各科同名同前缀）
- 类型：Agent 型专家（单角色）
- 版本：1.0.0
- 分类：15-Education
- 标识：`czl-chinese-home-tutor`

## 它能做什么

| 编号 | 工作流 | 你说什么 | 它给什么 |
|---|---|---|---|
| W1 | 家庭学情首诊 | "语文一直 90 分上下，不知道哪儿不会" | 卡点定位表 + 四周优先级 + 今晚一个 20 分钟动作 |
| W2 | 一对一辅导设计 | "周末请了家教，两小时怎么安排" | 时段表 + 示范脚本 + 问题链 + 当堂检测 + 家长反馈稿 |
| W3 | 作文面批与升格 | "这篇作文帮我看看" | 面批单：亮点、两个主问题、可执行的改法、一句示范、一段重写任务 |
| W4 | 阅读与文言诊所 | "文言读不懂""阅读总丢分" | 五因分类表 + 每日 20 分钟练法 + 教材篇目定位 |
| W5 | 家庭学习系统与复盘 | "怎么安排每周时间" | 3-2-1 周计划 + 家长话术 + 四周指标 + 复盘会流程 |

## 三个特点

1. **先看证据再说话。** 要卷子、要作文、要原始作答。没有材料就给"最小诊断版"，并写清哪一步是猜的。
2. **给能执行的动作。** 不说"多读多写"，说"今晚 20 分钟，只改第 7 题，写成三行"。
3. **不越界。** 不代写、不承诺分数、不押题、不评价任课老师。孩子出现心理危机信号时，停止学业讨论，转向求助。

## 怎么用（三个例子）

**家长，第一次用**

> 孩子高一，语文总在 90 分上下，说不清哪儿不会。先帮我做一次家庭学情诊断，再给四周计划。

**家长，有作文**

> 这是孩子刚写的一篇作文，帮我面批：先找亮点，再挑两个最要紧的问题，给具体改法。

**家教老师，要备课**

> 明天两小时，学生现代文主观题不分点，帮我排一个时段表，讲练比别超过三成。

## 安装与导入

**本机使用**：把整个目录放到

```
<配置目录>/plugins/marketplaces/my-experts/plugins/czl-chinese-home-tutor/
```

然后注册：

```bash
python register_expert.py <专家目录>
```

**换机器**：直接用 `dist/czl-chinese-home-tutor.zip` 在客户端导入。导入后若列表里只显示名称首字、没有头像，先跑一次自检：

```bash
python bin/check_expert_package.py dist/czl-chinese-home-tutor.zip
```

它会直接指出头像条目是否落在客户端能解析的位置。成因分析见 `docs/05-功能测试报告.md` 第四节。

## 头像

`avatars/expert.png`，512×512、RGB、PNG、397 KB，为本产品用图像生成工具新做并裁去水印，未使用任何现有专家的头像或品牌素材。替换方法见 `docs/07-头像与品牌规范.md`。
