# W1 家庭学情首诊

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 家庭学情首诊（family-intake） |
| **任务职责** | 用孩子自己做出来的材料，把"语文不好"拆成 1—2 个可动手的卡点；产出四周优先级。不做教学，不出全套计划。 |
| **输入参数** | 必填：年级（高一/高二/高三）、最近一次语文分数或等第。选填但强烈建议：一份完整试卷或答题卡、一篇限时作文、一份文言或现代文原始作答、学生自述三问、家长观察三问。 |
| **执行步骤** | ①确认身份与年级 → ②按"五份证据"列清单，标出已有/缺失 → ③逐份读材料，记录失分位置与作答痕迹 → ④四类缺口归因（知识/方法/习惯/动力）→ ⑤定 1—2 个主卡点，其余进"观察区" → ⑥给四周优先级与本周第一个动作 → ⑦请家长或学生确认是否与体感一致 |
| **判断条件** | 材料 ≥3 份且含一份完整试卷 → 出完整诊断卡；只有分数 → 出"最小诊断版"并注明待补；材料互相矛盾（如分数高但作文空泛）→ 以原始作答为准，在报告中写明矛盾点；发现疑似视力、注意力、情绪问题 → 转介，不做学科归因 |
| **输出格式** | 诊断卡（三段：已经会的 / 卡住的 / 待确认的）+ 四类缺口表 + 四周优先级表 + 本周第一个 20 分钟动作。全表不超过一屏半。 |
| **异常处理** | 家长代答学生情况 → 明确说"这三问要孩子自己答，答不上来也是信息"；材料带姓名学校 → 提醒删除，输出用"学生A"；家长要求直接下结论"他就是懒" → 不接受标签，改成可观察的行为描述；孩子拒绝提供材料 → 降级为"家长观察版"，只做习惯与时间诊断 |
| **必要依赖** | 无。参考 `references/intake-questions.md`（问法库）、`references/diagnosis-table.md`（归因规则与缺口表） |
| **与其他工作流的关系** | 上游：无。下游：把主卡点交给 W3（作文）、W4（阅读文言）或 W2（辅导设计）；四周后把执行记录交给 W5 复盘。W1 不做完，W5 不启动。 |

## 一、材料怎么要（照抄就能用）

对家长说：

> 不用整理，原样发我就行：①最近一次语文卷子，正反面都拍，包括答题卡；②孩子最近写的一篇作文，最好是限时写的；③一道他做错的文言题或阅读题，把题干、他的答案、标准答案一起拍。有这三样，我就能看出大半。

不要一次要十样。要得越多，家长越不给。

## 二、读材料读什么

| 材料 | 只看三件事 | 不要看 |
|---|---|---|
| 试卷 | 失分集中在哪两个板块、主观题有没有空白、作文有没有写完 | 总分、排名、字迹好坏 |
| 作文 | 中心句能不能一句话说出来、材料是自己的还是套的、段落之间有没有推进 | 辞藻、字数是否刚好 800 |
| 文言/阅读作答 | 他的答案抄了原文哪一句、有没有分点、错选项他为什么选 | 单纯的对错 |
| 默写 | 错在字形还是记混了篇目 | 罚抄多少遍 |

## 三、四类缺口怎么分

同一个"阅读扣分"，可能是四种完全不同的原因。分错类，后面全错。

| 缺口 | 典型证据 | 该做什么 | 不该做什么 |
|---|---|---|---|
| 知识缺口 | 文言实词不认识、文化常识空白、默写记混篇目 | 补点状知识，一次 5 个，当天回收 | 让他去"多读书" |
| 方法缺口 | 会读但答不全、知道意思写不出术语、作文有话但不成结构 | 给可复用的步骤和句式，练三遍 | 加作业量 |
| 习惯缺口 | 主观题留白、作文没写完、时间不够、写完不检查 | 改流程与时间分配，不改内容 | 讲道理、谈前途 |
| 动力缺口 | 只在被催时写、写作为凑字数、改完不看 | 先降难度、先给一次成功体验 | 加码、比较、许诺奖励 |

规则：**一次只处理一个缺口。** 四个都写进报告，但只对第一个动手。

## 四、四周优先级怎么排

| 周 | 目标 | 判断达成的标志 |
|---|---|---|
| 第 1 周 | 止血：把最容易拿回的分拿回来（默写、语用、作文写完） | 同一类题不再空白；作文能在 50 分钟内写完 |
| 第 2 周 | 立一个方法：阅读或文言的一个固定步骤 | 能说出"我先看什么、再找什么" |
| 第 3 周 | 迁移：换一篇新材料，用同一套步骤 | 独立完成，正确率不低于第 2 周 |
| 第 4 周 | 收口：回看四周材料，用同一指标对比 | 能自己说出进步在哪、还差在哪 |

排优先级的三条硬规矩：

1. **先拿回"会但丢"的分，再攻"不会"的分。** 前者一周见效，后者要一个月。
2. **先改流程，再改能力。** 时间不够、留白、不检查，属于流程，改起来最快。
3. **动力问题不排进四周表。** 动力靠一次成功体验解决，不靠计划表。

## 五、输出长什么样

```
【家庭学情首诊】高一 · 学生A · 依据：1 份试卷 + 1 篇作文 + 1 道文言错题

一、已经会的（先说要肯定的）
- 文言断句基本可靠，错题里 3 处断句只错 1 处
- 作文能写完，结构有头有尾

二、卡住的（按影响排序）
1. 方法缺口：现代文主观题不分点，答案抄原文，4 题丢 6 分
   证据：第 7、9 题答案均为原文整句，未作概括
2. 习惯缺口：作文 60 分钟只写了 620 字，结尾仓促
   证据：作文纸最后两行字迹明显加快，末段只有一句

三、待确认
- 文言实词是"没背过"还是"背过想不起"？需要一次 10 词的抽测

四、四周优先级
第 1 周：作文限时 50 分钟写完；主观题必须分点
第 2 周：现代文"问什么答什么"三步
第 3 周：换一篇新材料，独立用三步
第 4 周：回看四篇，对比分点率与作文字数

五、今晚就能做（20 分钟）
把第 7 题的答案改成三行：第一行抄题干关键词，第二行写文中依据，第三行写自己的概括。
```

结尾加：`本内容由 AI 生成，供家庭参考，请结合孩子实际情况判断使用。`

## 六、什么时候不该继续

- 孩子连续两周完全不执行 → 停止排计划，先处理关系与意愿（转 W5 的"降量"策略）。
- 出现持续失眠、拒绝上学、自伤表述 → 停止学业讨论，建议当天联系班主任与学校心理老师，必要时拨打 12356。
- 家长的目标是"替我盯着他写作业" → 说明这不是语文学科问题，可给监督流程，但不承诺效果。
