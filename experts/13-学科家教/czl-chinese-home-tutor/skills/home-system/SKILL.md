# W5 家庭学习系统与复盘

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 家庭学习系统与复盘（home-system） |
| **任务职责** | 把 W1—W4 的结论变成一周可执行的时间表，四周收一次口；管流程、管话术，不管学科内容。 |
| **输入参数** | 必填：年级、每周可用于语文的总时长、家庭可陪读的人力。强烈建议：W1 诊断卡、W3/W4 的练习记录、孩子作息（几点到家、几点睡）。 |
| **执行步骤** | ①算清可用时间（不理想化）→ ②按 3-2-1 排周节奏 → ③把任务写进具体时段（周几、几点、多久）→ ④给家长三句固定话术与三条禁止 → ⑤定四周检查点与指标 → ⑥做复盘表 → ⑦约定停止条件 |
| **判断条件** | 每周可用时间 < 150 分钟 → 砍到"3 次微练 + 1 次复盘"，取消专题；高三 → 保留专题、微练改为隔天；家长无法陪读 → 改成孩子自记录 + 每周一次 10 分钟对话；连续两周未完成 → 降量 30%，不加压 |
| **输出格式** | 一周时间表（含具体时段与时长）+ 家长话术卡（3 句可说、3 句禁说）+ 四周指标表 + 复盘会 60 分钟流程。 |
| **异常处理** | 家长要求加量 → 先问"上周完成了多少"，完成率低于 60% 不加量；亲子冲突升级 → 暂停学科任务一周，只保留朗读；孩子用"我做了"应付 → 改为可见产出（拍照、录音、口述）；家长想公开比较成绩 → 拒绝，改为个人纵向对比 |
| **必要依赖** | W1 的卡点结论；参考 `references/weekly-plan.md`（周计划模板与时间预算）、`references/parent-scripts.md`（话术与冲突处理） |
| **与其他工作流的关系** | 上游：W1—W4。下游：四周后回到 W1 重诊，形成闭环。W5 不产生新的学科结论，只做执行与检验。 |

## 一、3-2-1 周节奏（默认方案）

| 类型 | 次数 | 单次 | 内容 | 合计 |
|---|---|---|---|---|
| 微练 | 3 | 20 分钟 | 朗读 / 文言 5 词 / 素材一条，三选一轮换 | 60 分钟 |
| 专题 | 2 | 40 分钟 | 阅读一篇或作文一段 | 80 分钟 |
| 复盘 | 1 | 60 分钟 | 错题重做 + 讲给家长听 + 定下周 | 60 分钟 |
| — | — | — | **一周合计** | **200 分钟** |

原则：

1. **总时长不超过 3.5 小时。** 超过的安排，第三周必然崩。
2. **微练不安排在睡前。** 睡前只做朗读，不做题。
3. **专题放在周末白天，一次只做一件。** 阅读和作文不要挤在同一天。
4. **复盘必须有一次"孩子讲、家长听"。** 讲不清的地方，就是没学会的地方。

## 二、时间表怎么落到纸上

不要写"每天练语文"，要写到几点几分：

```
周一 19:40—20:00  微练：读《赤壁赋》第一段，出声两遍
周三 19:40—20:00  微练：文言 5 词（除、迁、假、就、绝），各造一句
周六 09:00—09:40  专题：现代文一篇，只做 3 道主观题，两行式作答
周日 09:00—09:40  专题：作文提纲 + 只写第一个分论点段
周日 20:00—21:00  复盘：错题重做 2 题，讲给我听；定下周
```

固定时段比固定任务重要。时段一变，任务就没了。

## 三、家长只需要三句话

| 场景 | 说这句 | 为什么 |
|---|---|---|
| 开始前 | "今天做哪一项？做多久？" | 把决定权给他，同时明确边界 |
| 做完后 | "讲给我听一遍。" | 讲得清＝学会，讲不清＝没学会 |
| 卡住时 | "你觉得第一步该干什么？" | 不抢答，只推进 |

**三句禁说**：

- "你看看人家" —— 比较只会让他把语文和你绑在一起讨厌。
- "这么简单都不会" —— 一句话关掉后面所有对话。
- "考好了给你买……" —— 外部奖励会把"学会"替换成"换奖"。

## 四、四周指标：只看四个数

| 指标 | 怎么记 | 四周目标 |
|---|---|---|
| 周完成率 | 完成项 / 计划项 | 从 60% 提到 80%，不要求 100% |
| 主观题分点率 | 分点作答的题数 / 总题数 | 提高 30 个百分点 |
| 作文成文时间 | 从动笔到写完 | 压到 50 分钟以内 |
| 同一错因次数 | 每周同类错误计数 | 下降一半 |

四个数都记在冰箱贴或手机备忘录上。**不记分数**，分数受卷子难度影响，四周看不出真变化。

## 五、复盘会 60 分钟流程

| 分钟 | 环节 | 谁在说 | 要点 |
|---|---|---|---|
| 0—10 | 看记录 | 家长 | 只念完成率与四个数，不评价 |
| 10—30 | 孩子讲题 | 学生 | 挑 2 道错题，讲思路；讲不清的当场标记 |
| 30—45 | 看改动 | 学生 | 拿出改过的那一段，和原文对比读一遍 |
| 45—55 | 定下周 | 一起 | 只改一件事：加一项、减一项、或换时段 |
| 55—60 | 收口 | 学生 | 说一句"下周我要先做的那件事" |

复盘会不许出现：排名、亲戚家孩子、 "你对得起谁"、翻旧账。

## 六、什么时候该停

| 信号 | 处理 |
|---|---|
| 连续两周完成率低于 40% | 停一周，只保留朗读；找原因（时间、难度、关系） |
| 一提语文就吵 | 暂停学科任务两周，家长退出陪读，改为每周一次 10 分钟对话 |
| 孩子出现持续失眠、拒学、自伤表述 | 停止所有学业安排，联系班主任与学校心理老师；紧急情况拨打 110 或 120 |
| 家长比孩子更焦虑 | 先给家长做减法：把计划砍到只剩一项，等一周再谈 |

**这一条要记住**：计划是给人用的，不是给人考的。执行不下去，先改计划，不改孩子。
