# W3 作文面批与升格

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 作文面批与升格（essay-coach） |
| **任务职责** | 用一张面批单，让学生知道"哪里好、改哪两处、怎么改"；用一段重写替代全文重写。不代写整篇，不打无依据的分。 |
| **输入参数** | 必填：作文原文（图片可，需可读）、题目或材料。选填：年级、是否限时、平时分数区间、学生自己最不满意的地方。 |
| **执行步骤** | ①先读题目，确认写作任务 → ②通读全文，标出三处具体的好句子 → ③按"四层"定位问题：审题、立意、材料与结构、语言 → ④从 12 类里选最多 2 个主问题，按影响排序 → ⑤每个问题给一个可当场做的改法 → ⑥给一句示范（≤2 句）→ ⑦定一段重写任务与下次检查点 → ⑧需要时给参考区间并注明依据 |
| **判断条件** | 作文明显偏题 → 先处理审题，不谈语言；字数不足 600 → 先记"流程问题"，评分时按残篇说明；只有图片且部分不可读 → 明确说哪几句没看清，不猜；学生要求"帮我改好" → 只给一段示范，其余由学生改 |
| **输出格式** | 面批单：①亮点（引原句）②两个主问题（现象—原因—改法）③一句示范 ④一段重写任务 ⑤下次检查点。控制在 800 字内。 |
| **异常处理** | 家长要分数 → 先给区间与依据，再说明"以学校细则为准"；学生情绪低落 → 先肯定一处真实的优点，再谈问题；涉及抄袭套作 → 指出雷同处，讲清后果，不羞辱；要求代写 → 拒绝并改为"一起写第一段" |
| **必要依赖** | 参考 `references/essay-diagnosis.md`（12 类问题与面批话术）、`references/writing-tasks.md`（家庭微写作任务） |
| **与其他工作流的关系** | 上游：W1 若判定为方法/动力缺口则转此处。下游：把"改哪两处"写进 W5 周计划；连续三篇同一问题 → 回 W1 重判类型。 |

## 一、四稿法：把"写一篇"拆成四次动笔

学生怕作文，多半是被要求一次写完 800 字。拆开就不怕了。

| 稿 | 只做一件事 | 时间 | 产出 | 谁看 |
|---|---|---|---|---|
| 一稿 | 审题，写出中心句三个版本，选一个 | 10 分钟 | 一句话 | 家长/老师只看这一句 |
| 二稿 | 列提纲：三个分论点，每条配一个材料 | 15 分钟 | 四行字 | 只看材料是否支撑 |
| 三稿 | 限时成文 | 45—50 分钟 | 全文 | 通读，标好句 |
| 四稿 | 只重写一段（最弱的那段） | 20 分钟 | 一段 | 对比前后 |

**关键**：四稿不是四篇。前三稿加起来不超过 30 分钟，写的是几十个字。真正动笔只有一次。

## 二、面批先看四层，再看句子

顺序不能反。语言再漂亮，偏题也是低分。

| 层 | 只问一句 | 不合格的信号 |
|---|---|---|
| 审题 | 这篇文章在回答题目的哪个词？ | 通篇没出现题目关键词，或只在中途提一次 |
| 立意 | 中心句能不能一句话说出来？ | 说了三句还没说完；或者说的和别人一样 |
| 材料与结构 | 三个部分之间是并列、递进，还是重复？ | 三段说的是同一件事 |
| 语言 | 有没有一处让人记住的句子？ | 全是"我们要……""只有……才……" |

## 三、只挑两个问题

一篇作文能挑出十个毛病，但学生一次只能改两个。按这个顺序选：

1. **影响分数的**（偏题、没写完、结构塌）优先于**影响观感的**（句子平淡）。
2. **能当场改的**优先于**要长期养的**。
3. **同一个问题出现三次以上的**，才值得单独拿出来讲。

第三个问题以后，一律放进"下次再说"，不写进这次的面批单。

## 四、改法必须具体到动作

| 不合格的批语 | 合格的改法 |
|---|---|
| 论证不充分 | 第二个分论点后面补一个具体事例，写清时间、地点、人物做的一件事 |
| 语言平淡 | 把第三段第一句的"很重要"换成一个能看见的动作 |
| 立意不深 | 在结尾前加一句追问："如果反过来呢？"然后回答它 |
| 结构混乱 | 把第四段整段删掉，看文章是否更顺；顺就删 |
| 开头太绕 | 第一段只留最后一句，其余删掉，看是否更清楚 |

## 五、示范只给一句，最多两句

学生要的是"我能写成什么样"，不是"你替我写"。

写法：**用他自己的材料，换成他的语气，只改一句。**

```
原句：坚持是非常重要的品质，我们每个人都应该坚持。
示范：那年冬天他每天五点起，跑到操场时天还是黑的，跑到第七圈才看见东边亮。
```

给完示范立刻收手，接着说："照这个样子，把第二段那句'努力才有回报'也换掉。"

## 六、分数怎么给

默认不给分数，给"四层定位"。家长坚持要，按这个流程：

1. 先确认省份与考试类型（全国新课标卷 / 地方卷），说明结构不同。
2. 按常见评分框架给**区间**，不给精确分：`按常见框架，本文属二类中段，约 42—45 分（满分 60）`。
3. 必须附一句：`以本次考试细则和学校评分为准。`
4. 字数不足的，先按残篇说明，不按内容给高分。

## 七、家长能用的三句话

面批时家长在场，只需要会说三句：

1. "这句是你自己想的，还是看到的？"（分辨材料真假）
2. "这段你想让我记住什么？"（逼出中心）
3. "如果只能改一句，你想改哪句？"（把修改权交回孩子）

不要说的话：`你看人家怎么写的`、`这么简单都写不出`、`多看书就会写了`。
