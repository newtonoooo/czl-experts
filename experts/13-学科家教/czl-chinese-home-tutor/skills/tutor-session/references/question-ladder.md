# 问题链句式

> 用途：一对一里，老师最容易犯的错是"抢答"。这份句式让老师只推进、不代替。
> 方法为通用教学经验整理（E），不是固定话术，按学生语气调整。

## 一、四个万能追问

| 目的 | 句式 | 学生答"不知道"时 |
|---|---|---|
| 让他回到题 | "这道题让你干什么？圈出那个动词。" | 你把题干读一遍，读到"分析"就停 |
| 让他回到文 | "你这句话是从哪一行看出来的？读给我听。" | 给范围：第三段后三行 |
| 让他压缩 | "如果只准写八个字，你写哪八个？" | 给两个选项，让他选，再问为什么 |
| 让他自查 | "如果这答案给你批，你会扣哪一分？" | 指一处："这行和题目问的是同一件事吗？" |

## 二、按能力点分的问题链

### 1. 现代文·作用题

```
问：这道题问"作用"，是内容的作用还是结构的作用？
→ 问：这段前面写什么，后面写什么？
→ 问：它站在中间，最可能是干什么的？
→ 问：承上，承的是哪一句？启下，启的是哪一层？
→ 落笔：承上启下 + 承什么 + 启什么
```

### 2. 现代文·概括题

```
问：这段一共几句话？给每句标个号。
→ 问：哪几句说的是同一件事？合成一组。
→ 问：三组里，哪一组是作者真正想说的？
→ 问：用一句话说这组，不许用原文的形容词。
```

### 3. 文言·断句

```
问：这句话里，动词是哪个？
→ 问：谁在动？主语在哪？
→ 问：这个"而"连接的是两件事还是一件事？
→ 问：断在这里，读起来顺不顺？读一遍。
```

### 4. 文言·翻译

```
问：这句里有哪几个词你不确定？
→ 问：不确定的词，能不能用学过的课文推？（举一例课文）
→ 问：直译出来是哪几个字？先写下来，别润色。
→ 问：润色后，句子的主语还是原来那个吗？
```

### 5. 诗歌·情感

```
问：诗里出现了哪些具体的物？圈出来。
→ 问：这些物有什么共同点？（颜色、温度、动静）
→ 问：诗人在做什么动作？站在哪、看着哪？
→ 问：如果只说"思乡"，这首诗和后一首诗还有什么区别？
```

### 6. 作文·审题

```
问：题目里的关键词是哪几个？圈出来。
→ 问：这几个词之间是什么关系？并列、因果、还是转折？
→ 问：你第一反应想写的那件事，和题目的关键词对得上吗？
→ 问：如果换个角度，有没有一个更少人写的入口？
```

## 三、三个"不要问"

1. **不要问"懂了吗"** —— 学生一定说懂了。
2. **不要问"是不是这样"** —— 你在给他答案，他在点头。
3. **不要问"为什么这么简单都不会"** —— 这句一出口，后面二十分钟都白费。

## 四、卡住超过 2 分钟怎么办

按"半步提示"处理，一次只给半步：

| 半步 | 例子 |
|---|---|
| 给范围 | "答案在最后两段。" |
| 给类别 | "这是结构作用，不是内容作用。" |
| 给首字 | "第一句从'承上'开始写。" |
| 给对比 | "你写的这句，和答案差在哪？只找一个字。" |

给了半步还是不动，说明这个点超出他当前水平，记下来，换更简单的材料，不要原地耗。
