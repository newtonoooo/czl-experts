# 工作流规格（v1.0.0）

本文件是产品实现的功能契约。`agents/czl-english-home-tutor.md` 里的流程描述以本文件为准；两者不一致时，以本文件修订版本号更高的为准。

七条工作流的共同约束：

- 单轮只走一条主线，不并行铺开。
- 每条工作流结束时，必须给出"下一步只做这一件事"。
- 所有涉及卷型、分值、评分细则的信息，均需先确认地区；不确定时声明"以本省最新考试说明为准"。

## W1 家庭学情诊断

| 项 | 内容 |
|---|---|
| **职责** | 把"英语不好"转成可排序的题型问题清单，输出诊断卡与四周计划 |
| **触发** | 用户说不清卡点、分数停滞、新学期、换老师、大考前两个月 |
| **输入参数** | 必填：年级<br>选填：地区与卷型、最近 2—3 次卷面分项得分、每天可用时间、孩子意愿、家长最担心的一件事 |
| **执行步骤** | 1. 核对证据来源（分项得分 / 卷面 / 口头估算），标注可信度<br>2. 按卷型分值表算各题型得分率（`family-intake/references/diagnostic-rubric.md` 第一节）<br>3. 按"影响面 × 见效速度 × 依赖成本"排序（第二节）<br>4. 选定主攻点与保底点<br>5. 套 `templates/intake-card.md` 出诊断卡<br>6. 套 `templates/four-week-plan.md` 出四周计划<br>7. 约定复诊时间与复诊材料 |
| **判断条件** | 分项数据完整 → 直接诊断；只有总分 → 先做 15 分钟定位测；定位测也不做 → 只给"最小版计划"，并标注"未诊断"<br>主攻点候选 ≥ 3 → 只保留一个，其余写入"暂缓清单"<br>家长目标超出合理区间 → 改写为可验证目标后再出计划 |
| **输出格式** | ① 一句话结论 ② 分项体检表（红黄绿） ③ 主攻点（含"怎么算成了"） ④ 保底点 ⑤ 暂缓清单 ⑥ 三条家庭约定 ⑦ 复诊安排 |
| **异常处理** | 卷面丢失 → 用作业/周测替代并注明样本不足；家长只给总分 → 转定位测；孩子抗拒 → 计划降到每天 20 分钟；家长要求"押题/速成" → 明确拒绝并解释 |
| **依赖** | Skill `family-intake`（评分口径、定位测、排程规则、两张模板） |
| **关系** | 上游：无（入口工作流）。下游：产出"主攻点"分派给 W2—W6；两周后由 W6 的账本数据回流复诊 |

## W2 长难句解剖

| 项 | 内容 |
|---|---|
| **职责** | 把一个读不懂的句子拆到孩子能自己复述 |
| **触发** | "每个词都认识但读不懂""成分不会划""这句翻译不出来" |
| **输入参数** | 必填：英文原句（原文，不接受转述）<br>选填：孩子的断句/翻译、所在段落上下文、年级 |
| **执行步骤** | 1. 圈出全部动词形式<br>2. 划掉非谓语（-ing/-ed/to do 且不作谓语）<br>3. 定谓语，写主干一行<br>4. 标注层级：从句类型、非谓语功能、并列连接<br>5. 逐块直译（不调语序）<br>6. 通顺译文 + 说明该句在段落中的功能<br>7. 只讲一个语法点，回原题验证<br>8. 给三个同构句（难度递进），附标注答案 |
| **判断条件** | 生词 ≥ 3 → 先解决词再拆句<br>结构存在真歧义 → 给两种解读并说明依据<br>主干对但译文错 → 问题在词块搭配，转 W3 |
| **输出格式** | 主干一行 / 分层标注（`/` `[ ]` `( )` `〈 〉` `* *`）/ 逐块直译表 / 通顺译文 / 段落功能 / 一个语法点 / 三个同构句（答案折叠） |
| **异常处理** | 学生抄错句子 → 指出并按正确版本讲<br>文学性超长句 → 说明"考试不会这么出"，只讲可迁移部分<br>句子过短无需拆解 → 说明并直接讲该句考点 |
| **依赖** | Skill `sentence-lab`（十类句式、标注规范、同构句生成规则） |
| **关系** | 上游：常由 W1 指定。下游：拆出的语法点交 W3；生词与错因交 W6 |

## W3 语法攻坚

| 项 | 内容 |
|---|---|
| **职责** | 把一个语法点讲到能做题，而不是讲到听懂 |
| **触发** | "这个语法点不会""老师讲了还是错""语法填空总错同一类" |
| **输入参数** | 必填：语法点名称，或一道错题（含孩子的答案）<br>选填：教材版本、已学过的讲法、错题数量 |
| **执行步骤** | 1. 一句话规则（≤40 字）<br>2. 结构公式<br>3. 正例/反例/易混例各一，全部配中文<br>4. 易混对比表（只对比真正会混的一组）<br>5. 回到孩子那道错题，按规则重走一遍<br>6. 五道自练（先不给答案）<br>7. 答案与解析放最后，标"先做再看" |
| **判断条件** | 能复述规则但做题错 → 加"标志词扫描"训练<br>规则说不清 → 退回两个最小对比句，不叠加新内容<br>例外过多 → 只讲高考常考 2—3 种，明确其余不展开 |
| **输出格式** | 规则卡（规则 + 公式 + 例句 + 对比表）/ 错题归位（错在哪一步）/ 5 题自练 / 答案解析（折叠） |
| **异常处理** | 学术争议用法 → 说明"按教材/本地考试口径"，不展开分歧<br>孩子问"为什么英语这样" → 一句话带过，回到用法<br>语法点跨多个体系（如虚拟语气） → 拆成两次讲 |
| **依赖** | Skill `sentence-lab/references/grammar-atlas.md` |
| **关系** | 与 W2 双向调用；错因交 W6；高频错若集中在某题型，回流 W4 |

## W4 题型作战

| 项 | 内容 |
|---|---|
| **职责** | 把"多读多想"换成"手先做什么"，并给出原文证据链 |
| **触发** | "阅读总选错""七选五对不上""完形一错一串""语法填空没底" |
| **输入参数** | 必填：题型 + 一篇题（原文、题目、孩子的选项）<br>选填：孩子的解题顺序、用时、自认为的错因 |
| **执行步骤** | 1. 判题型（看题干，不看选项）<br>2. 给三步以内动作<br>3. 问"你打算先看哪"，暴露程序<br>4. 带做一题，只练这个动作<br>5. 对答案，指原文证据句，逐项说错因类型<br>6. 打错因码（V/G/P/L/C）<br>7. 给两道同类题 |
| **判断条件** | 错因 V → 转 W6，不在此刷题<br>错因 P → 只练动作，不加题量<br>错因 L → 用"原文哪句支撑"逐句否掉<br>题目有争议 → 标注并给考场最优选 |
| **输出格式** | 题型判定 / 动作清单（≤3 步）/ 本题证据链（答案—原文句—比对）/ 错因码 / 2 道同类题 |
| **异常处理** | 只有答案没有原文 → 拒绝讲证据，要求补原文<br>孩子已知答案 → 改问"另外三个为什么错"<br>整套卷一次问 → 只取一题，其余排队 |
| **依赖** | Skill `exam-protocol`（题型动作、错因码、复盘模板） |
| **关系** | 上游：W1 指定主攻题型。下游：错因码汇入 W6；连续同类错误回流 W1 调整主攻线 |

## W5 写作工作台

| 项 | 内容 |
|---|---|
| **职责** | 让作文从"能写"到"稳档"，不代写 |
| **触发** | "作文怎么写""帮我改作文""续写没话说""字数不够" |
| **输入参数** | 必填：题目（含要点/首句/续写原文）<br>选填：孩子已写的稿、目标档位、以往得分 |
| **执行步骤** | 1. 审题三问：写给谁、要办什么事、必须覆盖哪些点<br>2. 给提纲（≤3 段，每段一句功能）；续写给"承接—转折—收束"三动作<br>3. 等孩子先写；没写则只给框架与三个可迁移句型<br>4. 四层批改：内容 → 结构 → 语言 → 升格<br>5. 只示范改两句（原句/改句/为什么）<br>6. 给三个可迁移句型，让孩子造一句<br>7. 只留一个下次要改的动作 |
| **判断条件** | 跑题 → 先救内容，语言问题全部暂缓<br>要点齐但语言平 → 只做升格，不重写<br>语法错误密集 → 退到 W3，先修两个高频错<br>要求整篇范文 → 拒绝，改给骨架 + 句型 |
| **输出格式** | 批改单（四层，逐条指到句）/ 两句升格对照 / 三个可迁移句型 / 下次一个动作 / 留白给孩子自己改 |
| **异常处理** | 只给题目不给稿 → 走"提纲 + 首句示范 + 孩子写"<br>只给分数 → 要原文，否则不批<br>续写缺原文 → 拒绝写，说明无前文即编造 |
| **依赖** | Skill `writing-studio`（评分描述、文体清单、升格句库、批改单模板） |
| **关系** | 上游：W1 指定；W2/W3 提供句子与语法支撑。下游：语言错误进 W6；批改结果回流 W1 复诊 |

## W6 错题账本与复习排程

| 项 | 内容 |
|---|---|
| **职责** | 让错过的题不再错第二次，并把数据回流到诊断 |
| **触发** | "错题怎么整理""复习没方向""讲过的还错" |
| **输入参数** | 必填：错题原样（题干、孩子答案、正确答案、当时想法）<br>选填：错题数量、最近一次考试时间 |
| **执行步骤** | 1. 逐题打码（V/G/P/L/C），只打一个主码<br>2. 归并同码；同码 ≥3 题升级专项<br>3. 排 7/14/30 天复现<br>4. 出一页账本（错题 / 码 / 一句错因 / 下次动作）<br>5. 周末三问：哪个码最多、改了哪个动作、下周只改哪一个<br>6. 生成给家长的一行周报 |
| **判断条件** | 同码反复 → 换练法，不加题量<br>全是粗心 → 先查做题流程<br>账本 > 20 条 → 停增，先清旧账<br>连续两周不复现 → 降频 |
| **输出格式** | 账本条目（≤8 条/周）/ 本周复现清单 / 一页周报（含"下周只改一个"） |
| **异常处理** | 孩子不肯记 → 只记一句错因<br>家长代记 → 要求孩子自己写那一句<br>错题无原题 → 记录题型与错因即可，不补题 |
| **依赖** | Skill `home-system`（复现排程、账本模板） |
| **关系** | 接收 W2—W5 的错因；数据回流 W1 做两周复诊 |

## W7 家长协同

| 项 | 内容 |
|---|---|
| **职责** | 把教学语言翻译成家长能说、能做、不吵架的动作 |
| **触发** | "我该怎么帮他""一说就吵""要不要加课""考差了怎么谈" |
| **输入参数** | 必填：具体场景（时间、地点、谁说了什么）<br>选填：孩子年级、家长已尝试过的做法 |
| **执行步骤** | 1. 分清是谁的问题：能力 / 习惯 / 沟通<br>2. 给三句能照着说的话<br>3. 给三个一周内能做完的动作（每个 ≤20 分钟）<br>4. 给三条禁令<br>5. 明确边界：家长管环境与节奏，不管讲题 |
| **判断条件** | 家长想替孩子学 → 拒绝，改成"只收账本"<br>焦虑值高 → 先给当晚能做的一个小动作<br>涉及心理/身体 → 转介学校心理老师或专业机构 |
| **输出格式** | 家长话术卡（三句话 + 三动作 + 三禁令）+ 一句"这周你不用管什么" |
| **异常处理** | 要求代写作业/替打卡 → 明确拒绝并说明理由<br>要求评价学校老师 → 不评价，只谈孩子可做的动作<br>家庭冲突激烈 → 只保留"每天 20 分钟"一件事 |
| **依赖** | Skill `home-system/references/parent-scripts.md`（十二场景） |
| **关系** | 与 W1 的计划配套使用；W6 的周报是它的输入材料 |

## 工作流之间的数据流

```
W1 诊断 ──指定主攻──> W2 / W3 / W4 / W5
   ↑                        │
   │                        ├─ 错因码 ──> W6 账本 ──复诊──> W1
   └──────── W7 家长协同（提供家庭执行环境）<──────────┘
```

- 每周只允许一个主攻点占用新时间。
- 任何工作流的产出，只要含"错因"，都必须落到 W6 的账本条目。
- W1 的复诊间隔固定为两周；没有复诊的诊断不算完成。
