### T12 的说明（为什么保留 15-Education）

- 官方校验脚本内置 12 个分类（`01-ProductDesign` … `12-IndustryConsultant`），不含教育分类。
- 平台实际在用的教育分类是 `15-Education`：本机下载的 `senior-english-tutor`、`senior-math-tutor`、`senior-physics-tutor`、`senior-chemistry-tutor`、`senior-biology-tutor`、`senior-history-tutor`、`senior-chinese-personalized-teaching`、`math-mistake-coach`、`classroom-questioning-designer` 等均使用该值。
- 若改成白名单内的分类，产品会被放进错误类目（如"内容创作""行业顾问"），影响上架后的检索与审核。
- 处理方式：保留 `15-Education`，把官方打包脚本中止的事实写入文档，改用 `bin/package_expert.py` 生成同结构 zip。**风险已登记**，见 `商业发布风险清单.md` R3。

## 三、复现命令

```bash
# 1. 官方结构校验（预期出现 1 条 categoryId error）
python "<expert-manager>/scripts/validate_expert.py" "<专家目录>"

# 2. 注册（通过）
python "<expert-manager>/scripts/register_expert.py" "<专家目录>"

# 3. 头像与资源诊断（通过）
python "<专家目录>/bin/check_avatar.py" "<专家目录>"

# 4. 打包（38 文件 / 519.9 KB）
python "<专家目录>/bin/package_expert.py" "<输出目录>"

# 5. zip 校验
python -c "import zipfile;z=zipfile.ZipFile(r'<zip路径>');print(z.testzip(), len(z.namelist()))"
```

## 四、未验证事项（不得视为通过）

| 事项 | 原因 | 建议验证方式 |
|---|---|---|
| 真实对话质量 | 需要真实用户输入与人工判断，静态检查无法覆盖 | 用 5 个场景各跑一轮：诊断、拆句、语法、阅读、续写批改；检查是否守住"不代写""一次一个动作" |
| 平台审核与上架 | 需提交后才能验证 | 提交后关注：分类是否正确、头像是否显示、简介是否被要求修改 |
| 商业定价与分成 | 属平台商务条款 | 阅读开放平台协议，确认分成比例与结算方式 |
| 其他 WorkBuddy 版本 | 只在 5.9.3 上测过 | 在目标用户的主版本上各装一次，重点看头像与 skills 是否加载 |
| 地方卷适配 | 产品未内置地方卷细则 | 用上海/北京/天津各一个真实需求测试"先问地区"的触发 |
| 听力题型 | 无音频播放能力 | 确认输出只给动作与文本分析，不假装能放音 |
| 头像在新环境的实际显示 | 本机无法复现用户的新环境 | 到新环境跑 `bin/check_avatar.py`，并看界面 |

## 五、测试中发现的边界问题（已在产品中处理）

| 现象 | 处理 |
|---|---|
| 家长只给总分，AI 容易直接给计划 | 主提示词强制先做 15 分钟定位测，或标注"未诊断" |
| 学生要求整篇范文 | 红线明确拒绝，改给骨架 + 句型 + 两句示范 |
| 题目只有答案没有原文 | 要求补原文，不凭记忆编解析 |
| 用户省份非新高考全国卷 | 先问地区；不确定写"以本省最新考试说明为准" |
| 连续追问导致信息过载 | "一次一个动作"约束，每轮结尾只给一件事 |
