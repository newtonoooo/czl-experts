# 使用说明

## 一、它是什么

卓识教育-高中英语学习辅导专家（对话中自称渡语老师）是一个高中英语学习辅导专家。它不讲课、不刷题、不代写，只做三件事：

1. **看卷子**：从孩子自己的错题里找卡点，而不是从"英语不好"这种判断出发。
2. **修一环**：一次只改一个地方，给出能当天做的动作。
3. **给家长话术**：把"你要努力"换成能照着说的三句话。

适合：高一到高三学生，以及陪读家长。
不适合：想找人代写作业、想要整篇范文背诵、想押题的场景。

## 二、第一次怎么用（三步）

**第一步：给它一个具体处境**

不要问"怎么提高英语"，要给它一个能被检验的起点。例如：

> 孩子高一，英语 95/150。听力 24，阅读 25，七选五 5，完形 9，语法填空 7.5，应用文 10.5，续写 14。每天能学 30 分钟。

**第二步：让它出诊断卡，不要让它出计划**

先看它把问题排成什么顺序。如果顺序和你的直觉不一样，就问"为什么先修这块"。

**第三步：只执行一周**

一周后回来，把执行情况和新的错题给它。它会改计划，而不是加计划。

## 三、七种典型问法

| 你想解决 | 这样问 |
|---|---|
| 不知道哪块差 | "把这张卷子的分项得分拆一下，选出最该先修的一块" |
| 句子读不懂 | "这句读不懂：〈原句〉。先划主干，再给三个同结构的句子" |
| 语法点反复错 | "非谓语他总错，用一句话规则讲清，再给五道题，答案放最后" |
| 阅读总选错 | "这道题他选 B，答案 D。别直接讲答案，先说他该按什么顺序做" |
| 作文要改 | "这是他的读后续写〈贴原文〉，按评分维度批，只示范改两句" |
| 错题不复习 | "这是本周五道错题，帮我打错因码，排 7/14/30 天复现" |
| 一说就吵 | "昨晚因为背单词吵了一架，我该怎么说" |

## 四、输出怎么读

| 它会给你 | 你要看什么 |
|---|---|
| 诊断卡 | "主攻点"是不是只有一个；"怎么算成了"有没有数字 |
| 拆句标注 | 去掉括号后句子还成不成立；译文是不是人话 |
| 规则卡 | 规则是否 ≤40 字；例句是否有中文 |
| 证据链 | 有没有指出"原文哪一句"；没有就是没讲透 |
| 批改单 | 是不是只改了两句；有没有留给孩子自己改的地方 |
| 账本 | 有没有"下周只改一个"；条目是不是 ≤8 条 |

## 五、家长怎么配合

只做三件事：

1. **守时段**：每天那 20—30 分钟不被挤掉。
2. **收账本**：周末看一眼"下周只改哪一个"有没有写。
3. **不问排名**：问"这周哪个动作改了"。

不要做：坐在旁边指错、临时代替老师讲题、考完当天报班。

## 六、一个完整的四周循环

| 周 | 你做什么 | 它给你什么 |
|---|---|---|
| 第 1 周 | 报分项得分，做定位测 | 诊断卡 + 四周计划 |
| 第 2 周 | 每天按计划做，攒错题 | 拆句 / 规则卡 / 题型动作 |
| 第 3 周 | 把错题一次性发过去 | 错因码 + 复现清单 |
| 第 4 周 | 做一套整卷，报新分数 | 第二张诊断卡 + 调整后的计划 |

## 七、常见问题

**Q：能不能直接给我一篇范文？**
不能。会给结构骨架、三个可迁移句型和两句示范改写。整篇范文背下来，考场上一换题就废。

**Q：它说的分数目标靠谱吗？**
它不会承诺提分，只给"语法填空从 6 分稳定到 11 分"这类可验证的阶段目标。达不到就改计划，不叠加。

**Q：我们省不是新高考全国卷怎么办？**
第一次对话就说清省份和卷型。上海（概要写作）、北京、天津等地方卷题型不同，它会先问再给方案；不确定的地方会写"以你们省最新考试说明为准"。

**Q：孩子基础很差（60 分以下）怎么用？**
先只做两件事：句子骨架 + 语法填空。阅读和写作暂缓，等这两块稳了再加。

**Q：能不能替孩子写作业？**
不能。这是产品的硬边界，写在提示词的红线里。

## 八、边界与提醒

- 听力部分只能给解题动作和文本分析，不能播放音频。
- 语法只讲高考常考形式，不展开学术争议。
- 心理、身体、家庭矛盾超出范围，会建议转介学校心理老师或专业机构。
- 所有分数、题型、政策信息，以本省教育考试院最新文件为准。
