# 卓识教育 - 高中英语学习辅导专家

一个面向中国家庭的、独立开发的高中英语一对一辅导专家。它不搬运资料、不给现成答案，只做一件事：**从孩子自己的卷面出发，找出真正坏掉的那一环，一次修一环。**

- 开发者：虫志龙（47190078@qq.com）
- 版本：1.0.3
- 类型：Agent 型（单个 AI 专家）
- 分类：教育学习

## 它解决什么问题

| 家庭常见困境 | 这个专家怎么处理 |
|---|---|
| "分数上不去，但说不清哪块差" | 把总分拆到题型，算得分率与"可动的分"，只选一个主攻点 |
| "每个词都认识，句子读不懂" | 五步拆句：圈动词 → 去非谓语 → 定谓语 → 写主干 → 挂修饰 |
| "语法讲了就懂，做题就错" | 一句话规则 + 公式 + 对照例句 + 回原题验证，不铺陈体系 |
| "阅读总在两个选项之间选错" | 先定位、再比对、最后排除，每题给原文证据句 |
| "作文写不出、写不长" | 审题三问 + 三段提纲 + 孩子先写 + 四层面批，只示范改两句 |
| "错题整理了也不看" | 错因打码（V/G/P/L/C）+ 7/14/30 天复现 + 一页账本 |
| "我一说学习就吵" | 十二个场景的家长话术：三句话、三个动作、三条禁令 |

## 七条工作流

1. **W1 家庭学情诊断** —— 出诊断卡 + 四周计划
2. **W2 长难句解剖** —— 结构切分 + 直译 + 同构句
3. **W3 语法攻坚** —— 规则卡 + 易混对比表 + 五题自练
4. **W4 题型作战** —— 阅读/七选五/完形/语法填空的动作与证据链
5. **W5 写作工作台** —— 应用文与读后续写的四层批改
6. **W6 错题账本** —— 错因码与复现排程
7. **W7 家长协同** —— 家长话术卡与家庭约定

完整规格（输入、步骤、判断条件、输出、异常处理、依赖关系）见 `docs/工作流规格.md`。

## 使用示例

- "孩子高一，英语总在 95 分（满分 150）上下，说不清哪块坏了。先做一次家庭学情诊断，再给四周计划"
- "这是孩子读不懂的一个句子，帮我切出主干和修饰，再给三个同结构的句子练手"
- "这是孩子写的一篇读后续写，按评分维度给批注，挑两个最值得改的问题，只示范改两句"
- "他一说英语就烦，我一开口就吵，我该怎么说"
- "月考 108 分，语法填空错了 6 个，帮我看是哪个环节的问题"

## 边界（重要）

- **不代写**：不输出整篇作文、完整续写或整份答案供照抄；只给框架、句型与两句示范改写。
- **不承诺分数**：只给可验证的阶段目标（如"语法填空从 6 分稳定到 11 分"）。
- **不编造**：不虚构真题、评分细则或政策；卷型与分值以用户所在省份最新考试说明为准。
- **不越界**：心理、身体、家庭矛盾建议转介学校心理老师或专业机构。

## 安装

把整个目录放到专家目录：

```
<WORKBUDDY_CONFIG_DIR>/plugins/marketplaces/my-experts/plugins/czl-english-home-tutor/
```

Windows 默认：

```
C:\Users\<用户名>\.workbuddy\plugins\marketplaces\my-experts\plugins\czl-english-home-tutor\
```

注册后即可在「专家中心 - 我的专家」看到。

## 头像

`avatars/expert.png`，512×512，PNG，约 428 KB，本次由 AI 生成后裁切压缩，无水印、无文字。

替换头像时执行：

```bash
python bin/prepare_avatar.py <新图.png> avatars/expert.png --size 512 --max-kb 400
```

排查"头像显示成文字"：

```bash
python bin/check_avatar.py .
```

## 打包发布

```bash
python <expert-manager>/scripts/package_expert.py <本目录>
```

打包脚本会自动跳过隐藏文件（保留 `.codebuddy-plugin`）与临时文件。
