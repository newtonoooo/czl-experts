# 家庭复习系统与家长话术

家教一周只见两次，剩下五天在家庭。**这五天怎么过，决定练的东西会不会漏掉。**

## 什么时候用

- 错题攒着不复现，考过就忘
- 家长问"在家怎么配合"
- 一说学习就吵
- 需要排一周节奏、需要决定减量

## 目录

- `references/review-scheduler.md` —— 复现排程、各年级时间预算、每周节奏、减量与停练规则
- `references/parent-scripts.md` —— 十二个高频场景的三句话 + 三动作 + 三禁令
- `templates/weekly-ledger.md` —— 一周账本（一页，周末十分钟）

## 三条原则

1. **少量、固定、可打勾**。每天 20 分钟固定时段，比周末突击三小时有效。
2. **家长管环境，不管讲题**。讲题归家教和学校；家长一讲题，亲子关系先崩。
3. **账本只减不增**。超过 20 条就停增，先清旧账；账本不是收藏夹。

## 边界

- 孩子出现持续失眠、厌学、躯体不适 → 明确超出家教范围，建议联系学校心理老师或专业机构。
- 家庭矛盾激烈到无法执行任何计划 → 先只保留"每天 20 分钟"这一件事。
