# 五大题型：判定、动作、证据

> 每种题型只给三步动作。多于三步，孩子考场做不出来。

---

## 一、阅读理解

### 先判题型（看题干，不看选项）

| 题干长什么样 | 题型 | 动作重点 |
|---|---|---|
| mainly about / best title / purpose of the passage | 主旨 | 读首末段 + 各段首句 |
| according to the passage / why / when / how many | 细节 | 定位名词，比对动词 |
| infer / suggest / probably / likely | 推断 | 找"原文哪句能支撑" |
| the underlined word "..." probably means | 词义 | 看前后句的解释与并列 |
| attitude / tone / the author believes | 态度 | 找评价性形容词与转折 |

### 三步动作

**细节题**
1. 圈题干里的**专有名词、数字、时间**（这些词在原文里长得一样）。
2. 回原文找到那一句，划出来。
3. 把选项逐一和原句比对：**动词换了就是错**，范围变了也是错。

**主旨题**
1. 读第一段最后一句 + 最后一段第一句（作者通常在这两处亮观点）。
2. 看每段首句，判断是并列、递进还是转折。
3. 选"能盖住所有段"的选项；只盖住一段的，一律排除。

**推断题**
1. 先在原文找到对应段，划出**唯一**能支撑的句子。
2. 问自己："这句话能不能直接推出这个选项？"推不出就是过度推断。
3. 排除三类：原文没提（无中生有）、原文说了但反着说（因果倒置）、范围被放大（偷换范围）。

**词义猜测**
1. 看该词前后的**冒号、破折号、that is、or**——这些是解释信号。
2. 看并列结构：A and B 里 A、B 词性感情常一致。
3. 把猜的词代回原句，读一遍通不通。

**态度题**
1. 找形容词和副词（positive / doubtful / critical）。
2. 找转折词（but / however / yet）——转折后面才是真态度。
3. 中立态度极少是答案，除非全文纯说明。

### 证据链写法（讲题时必须这么写）

```
答案：C
证据：第 3 段第 2 句 "..."（原文）
比对：选项 C 把原文的 "reduce" 换成 "cut down"，同义；A 把 "some" 改成 "all"，范围放大。
```

**没有"证据句"的讲解，等于没讲。**

## 二、七选五

### 判定空位

| 空在哪 | 看什么 |
|---|---|
| 段首 | 看**下一句**的主语和代词，空前通常是概括句 |
| 段中 | 看**前一句的尾**和**后一句的头**，找指代和逻辑词 |
| 段尾 | 看**本段主旨**，空后若是新段，空处多为总结 |

### 三步动作

1. **先读选项，圈代词和连接词**：this / these / such / however / instead / for example。
2. **再读空前后各一句**，判断这里缺的是"概括""举例""转折"还是"结果"。
3. **代入检验**：把选项读进空里，检查三件事——代词指代是否成立、时态是否一致、逻辑词是否匹配。

### 常见陷阱

- 选项里出现原文同词，但**指代对象不对**（同词陷阱最常见）。
- 两个选项都"读着顺"，区别在**逻辑方向**（一个是补充，一个是对比）。
- 空后一句开头是 He / They，说明空处必须出现过对应的单数或复数名词。

## 三、完形填空

### 三步动作

1. **先读首句，定基调**：首句通常不设空，它定了人物、场景、情绪方向。
2. **通读一遍，只填"确定的"**（逻辑词、固定搭配），不确定的跳过。
3. **第二遍按"上下文线索"填**：每个空往前找一句、往后找一句，线索九成在附近。

### 四条线索

| 线索 | 例 |
|---|---|
| 复现 | 前文出现过同义或反义的词 |
| 搭配 | 固定短语（take pride in / be aware of） |
| 逻辑 | but / so / although 决定填正还是反 |
| 情感 | 全文基调是温暖还是紧张，决定形容词方向 |

### 常见陷阱

- 四个选项语法都对，只有**情感方向**不同——这时看全文基调，不看单句。
- 动词题看**主语是谁**，形容词题看**修饰谁**。

## 四、语法填空

### 两条线，先分再填

| 空型 | 只考什么 | 动作 |
|---|---|---|
| **有提示词** | 五类变形：名词单复数、形容词/副词级、动词时态语态、非谓语、词性转换 | 先判词性，再判形式 |
| **无提示词** | 四类词：冠词、介词、连词、代词 | 先判逻辑，再判搭配 |

### 有提示词的五问（按顺序问）

1. 这个词在句中做什么成分？（主/宾/定/状/表）
2. 需要换词性吗？（care → careful / carefully / carelessness）
3. 是谓语还是非谓语？（句子里已经有谓语了吗）
4. 主语和动作是什么关系？（主动 doing / 被动 done）
5. 时态看什么？（时间状语、上下文动词）

### 无提示词的四问

1. 前后是两个句子吗？→ 连词（and / but / because / which）
2. 名词前缺限定吗？→ 冠词（a / an / the）
3. 有固定搭配吗？→ 介词（depend on / in charge of）
4. 指代前面哪个名词？→ 代词（it / them / which）

### 铁律

**拼写零容错**。写完把填的词单独抄一遍，逐个字母核对。这一条能救 3—5 分。

## 五、听力

### 三步动作

1. **读题预判**：播放前扫题干，圈疑问词（what / why / how much），预判听什么。
2. **听转折**：but / actually / however 后面常是答案。
3. **记符号不记句子**：数字、时间用箭头和缩写，不写完整单词。

### 常见陷阱

- 选项里出现录音原词，往往是干扰；正确答案多是**同义替换**。
- 数字题会先给一个数再改口（"It was 20, but now 15"）。

---

## 六、争议题处理

三步：

1. **判断是否真争议**：两个选项都能从原文推出 → 争议；只有一个有证据句 → 不是争议，是没找到证据。
2. **给考场最优选**：选"证据句更直接、需要推理更少"的那个。
3. **标注**：`[争议] 本题 C、D 均可自圆其说；考场建议选 C，因为 C 有原句直接支撑，D 需要两步推理。`

不假装所有题都有唯一正解，也不把"我不会"说成"题有问题"。
