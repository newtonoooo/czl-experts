# 错因码表（V / G / P / L / C）

> 错题不分类，练一百道也没用。每题只打**一个**主码，其他记在备注。

## 五个码

| 码 | 名称 | 一句话判定 | 典型表现 |
|---|---|---|---|
| **V** | 词汇 | 把词换成认识的，这题就会做 | 题干或选项里有不认识的词；认识词但不知道搭配 |
| **G** | 语法 | 句子结构没读懂，或形式用错 | 长句断错主干；语法填空形式错 |
| **P** | 程序 | 没按固定动作做，直接选 | 没定位就选；没读完选项；没划关键词 |
| **L** | 逻辑 | 推理多走一步，或方向反了 | 推断过头；把"some"读成"all"；因果倒置 |
| **C** | 粗心 | 会做，但抄错、看漏、拼错 | 答案对但涂错；拼写少字母；单复数漏看 |

## 判定问句（按顺序问，先命中先定）

1. **把这句/这道题的词全换成他认识的词，他能做对吗？**
   能 → **V**；不能 → 下一问。
2. **他能说出这句话的主语和谓语吗？**
   不能 → **G**；能 → 下一问。
3. **他做题时有没有先定位/先划关键词？**
   没有 → **P**；有 → 下一问。
4. **他选这个选项的理由，原文哪一句支持？**
   找不到或推了两步以上 → **L**；找得到 → 下一问。
5. **他重做一遍能对，且不需要提示？**
   能 → **C**；不能 → 回到第 1 问。

## 每个码的处置

| 码 | 不要做 | 要做 |
|---|---|---|
| V | 让他抄单词十遍 | 只记**词块**（动词+介词、形容词+名词），放进句子里记 |
| G | 重讲整章语法 | 只修这一个结构，配 3 个同构句 |
| P | 加题量 | 固定三步动作，做题时口头念出来 |
| L | 说"你想太多" | 用"原文哪句能支撑"逐句否掉，练排除 |
| C | 说"细心点" | 改流程：做完先查拼写、再查单复数、最后查涂卡 |

## 复现排程

| 码 | 第 7 天 | 第 14 天 | 第 30 天 |
|---|---|---|---|
| V | 同词块新句 | 同词块改写句 | 混在阅读里认 |
| G | 同结构新句 | 换主语再拆 | 混在语法填空中 |
| P | 同题型新题 | 限时同题型 | 整卷中检验 |
| L | 同类型推断题 | 换话题推断 | 整卷中检验 |
| C | 流程自查表 | 流程自查表 | 不再单列 |

## 升级规则

- **同码 ≥ 3 题** → 升级为专项，回到对应工作流（V→词汇账本，G→W3，P/L→W4）。
- **同码连续两周不复现** → 降频，只留月度复现。
- **账本超过 20 条** → 停止新增，先清旧账。账本的作用是"减少"，不是"收集"。

## 一句话错因怎么写

格式：`我因为____，选了____，正确是____。下次先____。`

例：
> 我因为没定位就选（P），选了 B，正确是 D。下次先圈题干里的年份，再回原文找那一句。

**不写"粗心""没看清"**——这两个词不产生任何动作。
