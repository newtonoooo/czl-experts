# 高中语法十二讲（考点版）

> 每讲只保留"一句话规则 + 结构公式 + 例句 + 易混"。讲完必须回到孩子那道错题。

---

## 第一讲 句子骨架：五种基本句型

任何长句都是这五种骨架之一，加修饰。

| 句型 | 公式 | 例 |
|---|---|---|
| 主谓 | S + V | The train **arrived**. |
| 主谓宾 | S + V + O | She **read** the letter. |
| 主系表 | S + V + P | The soup **smells** good. |
| 主谓双宾 | S + V + IO + DO | He **gave** me a book. |
| 主谓宾补 | S + V + O + C | They **elected** him monitor. |

**判断口诀**：先找动词，再看动词后面能不能加"什么"、加了"什么"还缺不缺"怎么样"。

## 第二讲 定语从句

**一句话规则**：定语从句跟在名词后面，关系词在从句里**替那个名词充当一个成分**。

```
先行词 + 关系词 + （缺一个成分的）从句
```

| 关系词 | 在从句里充当 | 例 |
|---|---|---|
| who / whom | 主 / 宾（人） | The girl **who** won is my cousin. |
| which | 主 / 宾（物） | The book **which** you lent me is due. |
| that | 主 / 宾（人或物） | The man **that** called you is waiting. |
| whose | 定语 | The boy **whose** bike was stolen cried. |
| where / when / why | 状语 | This is the house **where** I grew up. |

**易混对比**

| 情况 | 用 that | 用 which |
|---|---|---|
| 介词后面 | ✗ | ✓ the room **in which** he lives |
| 非限制性（有逗号） | ✗ | ✓ My car, **which** is old, still runs. |
| 先行词是 all / everything / only / 序数词 | 优先 ✓ | 少见 |
| 指代前面整句话 | ✗ | ✓ He passed the exam, **which** surprised us. |

## 第三讲 名词性从句

**一句话规则**：从句整体当一个名词用，能当主语、宾语、表语、同位语。

| 类型 | 连接词 | 例 |
|---|---|---|
| that | 无意义、不作成分、不可省（主语/同位语从句） | **That** he lied is obvious. |
| whether / if | "是否" | I wonder **whether** he will come. |
| wh- | 有意义、作成分 | **What** he said surprised us. |

**四类位置**

- 主语：**What** matters is your attitude.
- 宾语：I don't know **where** he went.
- 表语：The problem is **that** we have no time.
- 同位语：The news **that** our team won excited everyone.

**易混：同位语从句 vs 定语从句**

| | 同位语从句 | 定语从句 |
|---|---|---|
| that 在从句里 | 不作成分，只起连接 | 作主语或宾语 |
| 能否换成 which | 不能 | 指物时可以 |
| 例 | The fact **that** he lied hurts. | The fact **that** he told me hurts. |

## 第四讲 状语从句

**一句话规则**：从句给主句提供时间、条件、原因、让步、结果、目的、比较、方式。

| 类型 | 常用连词 | 例 |
|---|---|---|
| 时间 | when / while / as / before / after / until / as soon as | **As soon as** he arrived, it began to rain. |
| 条件 | if / unless / as long as | **Unless** you hurry, you will miss it. |
| 让步 | although / though / even if / while | **Although** it was late, he kept working. |
| 原因 | because / since / as | **Since** you are here, let's start. |
| 结果 | so + adj./adv. + that；such + n. + that | He ran **so** fast **that** nobody caught him. |
| 目的 | so that / in order that | Speak louder **so that** everyone can hear. |
| 比较 | than / as ... as | She sings **better than** I do. |
| 方式 | as if / as though | He talks **as if** he knew everything. |

**三条铁律**

1. 主将从现：**If it rains** tomorrow, we **will** stay at home.
2. although 不与 but 同句；because 不与 so 同句。
3. until 与 not ... until 意思相反：He waited **until** she came.（等到她来）/ He **didn't** leave **until** she came.（她来了才走）

## 第五讲 非谓语动词

**一句话规则**：一个句子里只能有一个谓语；其余动词要变形成 doing / done / to do。

| 形式 | 含义 | 例 |
|---|---|---|
| doing | 主动、进行 | the man **standing** there（站在那里的人） |
| done | 被动、完成 | the letter **written** by him（他写的信） |
| to do | 目的、将来 | the meeting **to be held** tomorrow（明天要开的会） |

**三种主要用法**

- 作定语：The girl **singing** on stage is my sister.
- 作状语：**Having finished** his work, he went home.（先完成，后回家）
- 作宾语/补语：He avoided **answering**. / I saw him **crossing** the street.

**独立主格**：`名词 + 非谓语`，自带主语。
**Weather permitting**, we will go hiking.（天气允许的话）

**易混对比**

| 结构 | 意思 |
|---|---|
| stop **to do** | 停下来去做另一件事 |
| stop **doing** | 停止正在做的事 |
| remember **to do** | 记得要做（还没做） |
| remember **doing** | 记得做过（已做） |
| try **to do** | 努力去做 |
| try **doing** | 试着做做看 |

## 第六讲 时态

**一句话规则**：时态看两件事——**动作发生在什么时候**，**说话人站在什么时候看它**。

| 时态 | 用法 | 例 |
|---|---|---|
| 一般现在 | 习惯、真理、时刻表 | Water **boils** at 100℃. |
| 一般过去 | 过去某时的动作 | I **met** him yesterday. |
| 一般将来 | 将来 | I **will** call you tonight. |
| 现在完成 | 过去动作 + 对现在的影响；for/since | I **have lost** my key.（现在进不去） |
| 过去完成 | 过去的过去 | When I arrived, he **had left**. |
| 现在进行 | 此刻、近期安排 | She **is preparing** for the exam. |
| 过去进行 | 过去某时正在进行 | I **was reading** when he called. |
| 现在完成进行 | 从过去持续到现在 | He **has been studying** for three hours. |

**易混：现在完成 vs 一般过去**

| | 现在完成 | 一般过去 |
|---|---|---|
| 时间 | 不与具体过去时间连用 | 必须有或隐含具体过去时间 |
| 例 | I **have seen** the film.（知道内容） | I **saw** it last week. |

## 第七讲 被动语态

**一句话规则**：不知道、不必说、或想强调动作承受者时用被动；时态变化落在 be 上。

```
be（随时态变） + done
```

| 形式 | 例 |
|---|---|
| 一般现在被动 | English **is spoken** in many countries. |
| 情态被动 | The work **must be finished** today. |
| 非谓语被动 | **Being praised**, she smiled.（被表扬） |
| 完成被动 | **Having been told** the truth, he calmed down. |

**注意**

- 不及物动词无被动：happen / occur / rise / appear。
- 主动表被动：The book **sells** well. / The pen **writes** smoothly.

## 第八讲 虚拟语气

**一句话规则**：说的不是事实，就用"过去的形式"表示"现在/将来"，用"过去完成"表示"过去"。

| 时间 | if 从句 | 主句 |
|---|---|---|
| 与现在相反 | did / were | would / could / might + do |
| 与过去相反 | had done | would have done |
| 与将来相反 | did / were to do / should do | would do |

**例**：**If I were** you, I **would apologize**.（我不是你）
**If you had taken** my advice, you **would have passed**.（没听）

**其他高频**

- wish：I wish I **had studied** harder.（后悔）
- would rather：I would rather you **didn't go**.
- 建议/要求/命令（suggest / insist / demand / require / order）+ **(should) do**：He suggested that we **(should) leave** early.
  - 例外：suggest 表示"表明"时用陈述语气——His smile suggested that he **was** happy.
- 含蓄条件：**Without** your help, I **would have failed**.

## 第九讲 倒装

**一句话规则**：把"否定词、only + 状语、so/neither"放到句首，助动词提到主语前面。

| 触发 | 结构 | 例 |
|---|---|---|
| 否定词前置 | 助动词 + 主语 + 动词 | **Never have I** seen such a view. |
| Only + 状语 | 助动词 + 主语 | **Only then did I** realize the truth. |
| so / neither | So + 助动词 + 主语 | He likes tea. **So do I.** |
| 虚拟省略 if | Were / Had / Should + 主语 | **Had I known**, I would have called. |
| 地点状语前置 | 谓语 + 主语（全倒装） | On the hill **stands** a temple. |

## 第十讲 省略

**一句话规则**：重复的、能猜到的，就省掉；考试考的是"省了什么、还原成什么"。

| 类型 | 例 | 还原 |
|---|---|---|
| 状语从句省略 | When **asked**, he said nothing. | When he was asked |
| 不定式省略 | He refused to go, but I didn't want to. | to go |
| 比较句省略 | She runs faster than I. | than I do |
| 并列句省略 | She likes tea and coffee. | and (she likes) coffee |

## 第十一讲 主谓一致

**一句话规则**：先找真正的主语，再看它是单是复；中间插进来的短语不算。

| 情况 | 规则 | 例 |
|---|---|---|
| with / together with / as well as | 看前面 | The teacher, with his students, **is** here. |
| neither ... nor / either ... or / not only ... but also | 就近 | Neither you nor he **is** right. |
| the number of + 复数 | 单数 | The number of students **is** rising. |
| a number of + 复数 | 复数 | A number of students **are** absent. |
| 分数/百分数 + of + 名词 | 看名词 | Two thirds of the water **is** gone. |
| 时间/距离/金额 | 单数 | Ten years **is** a long time. |

## 第十二讲 语法填空：无提示词的三大件

**一句话规则**：没有提示词的空，只考四类词——冠词、介词、连词、代词。

| 类别 | 判断问句 | 例 |
|---|---|---|
| 冠词 | 这个名词是特指还是泛指？ | He is **an** honest boy. / **The** book on the desk is mine. |
| 介词 | 前后是什么搭配？ | depend **on** / in charge **of** / **at** night |
| 连词 | 两个句子是什么逻辑？ | I stayed home **because** it rained. |
| 代词 | 指代前面哪个名词？ | I lost my key and couldn't find **it**. |

**有提示词的空，只考五类变形**：名词单复数、形容词/副词比较级、动词时态语态、非谓语、词性转换（care → careful / carefully）。

**拼写零容错**：错一个字母整空 0 分。写完必回读拼写。
