# 卓识教育-高中历史学习辅导专家

一个面向家庭的高中历史一对一学习辅导专家。它不做题库，不代写作业，专做四件事：**看卷子找准卡点、把通史框架立起来、把材料题和论述题拆成可执行的动作、给家长一套能照着做的陪读流程。**

- 开发者：虫志龙（47190078@qq.com）
- 包标识：`czl-history-home-tutor`
- 版本：1.0.2
- 类型：Agent 型（单专家）
- 分类：15-Education

## 它解决什么问题

高中历史的分水岭不是"背没背过"，而是三件事：

1. **时间线是散的**——知道唐朝在前面，说不出唐朝什么样；中外一对就乱。
2. **材料题只会抄**——答案大段照抄材料，概括题写成翻译题，一道 12 分的题拿 5 分。
3. **家长想帮但一帮就吵**——除了"你怎么又错了""历史不就是背吗"，没有第三句话。

这个产品把这三件事拆成六个工作流，每个工作流都有输入、步骤、判断条件和交付物。

## 六个工作流

| 编号 | 名称 | 什么时候用 | 给你什么 |
|---|---|---|---|
| W1 | 家庭学情诊断 | 只知道分数，不知道卡在哪 | 六维卡点卡 + 四周路线 + 排除项 |
| W2 | 通史框架与阶段特征 | 时间线乱、时期分不清、中外对不上 | 轴 + 五维特征表 + 中外同期表 + 反向自测 |
| W3 | 史料实证与材料题 | 材料题答一半、只会抄原文 | 设问拆解 → 材料分层 → 得分对照 → 骨架答案 |
| W4 | 论述题 | 12 分开放题写不出 | 观点句式 + 论证模型 + 12 分制量表 + 自评清单 |
| W5 | 选择题错因门诊 | 总在两个选项里挑错 | 八类错因 + 七种干扰项套路 + 三道同因变式 |
| W6 | 家长陪读方案 | 我该怎么陪、怎么盯 | 周节奏表 + 话术卡 + 验收标准 + 三条禁止动作 |

路由规则写在 Agent 主提示词里：没有材料先取证（W1），有材料题先拆设问（W3），错因同类的先归因（W5），家长问"怎么陪"但没有诊断结论时先做 W1。

## 材料与方法

- `materials/`：教材单元对照、中外年代骨架、阶段特征五维表、易混概念辨析、卷型与分值、资料依据说明。
- `skills/*/references/`：评分量表、错因分类、术语替换表、话术卡、周节奏模板、框架自测题。
- 内容来源分三层，逐条写在 `materials/sources.md`：公开事实直接陈述，公开规范转述并标注，原创方法归开发者。**没有打包任何教材 PDF、教辅扫描件、课标全文或真题原卷。**

## 安装

把整个目录放到专家目录：

```
<WorkBuddy 配置目录>/plugins/marketplaces/my-experts/plugins/czl-history-home-tutor/
```

Windows 默认在 `C:\Users\<用户名>\.workbuddy\plugins\marketplaces\my-experts\plugins\`。

然后注册（否则专家中心看不到）：

```bash
python scripts/register_expert.py <专家目录>
```

或直接导入 `dist/czl-history-home-tutor.zip`。

**导入后请重启一次 WorkBuddy。** 展示快照会缓存头像的本地绝对路径，重启后才会按新路径重建。

## 头像

`avatars/expert.png`，512×512，PNG，约 394KB。

如果导入后小图标变成了名字首字（"卓"），先跑体检：

```bash
python tools/verify_avatar.py .
```

原因和修复办法见 `docs/07-头像失效排查与防错规范.md`。简单说：**客户端把头像路径相对包根解析，文件不存在就静默返回空字符串，前端于是画一个字。** 不报错，只能靠打包前体检拦住。

## 自检与出包

```bash
python tools/validate_package.py .   # 结构、字段、交叉引用、占位符
python tools/verify_avatar.py .      # 头像路径、存在性、尺寸、体积
python tools/build_release.py .      # 校验 + 打包 + 回读 zip 验收
```

`build_release.py` 会重新打开 zip，按客户端真实读取的路径再查一遍 plugin.json 和头像条目。**打包不算完，回读通过才算完。**

## 边界

- 不代写作业、不代考。可以批改、给骨架、给示范句。
- 只讲统编教材与课标范围内的内容，不做课外政治评论与争议议题的价值判断。
- 涉及国家统一、疆域、民族宗教、行政区划，按教材与中国官方立场表述。
- 不承诺提分。给的是可观察指标（错因是否收敛、设问是否答满）。
- 年代、人物、出处不确定时标 `【需核对教材】`，不臆造。
