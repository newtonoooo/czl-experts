# 产品规格说明

产品：卓识教育-高中历史学习辅导专家（`czl-history-home-tutor`）
开发者：虫志龙
版本：1.0.2
文档日期：2026-10-31

---

## 一、为什么做这个产品

### 1. 目标用户

| 用户 | 占比估计 | 真实诉求 | 判断标准 |
|---|---|---|---|
| 陪读家长（主力） | 约 6 成 | 我该做什么、别做什么，怎么判断有没有效 | 拿到方案今晚能不能照着做 |
| 学生本人 | 约 3 成 | 今晚这二十分钟做什么 | 动作是否具体到可以直接开始 |
| 家教／机构老师 | 约 1 成 | 一次课怎么排、怎么向家长交代 | 有没有可复用的时段蓝图与反馈稿 |

家长问得最多，学生问得最少。**产品必须先接住家长，再把镜头转向"孩子做出来的东西"。**

### 2. 使用场景

| 场景 | 典型开场 | 现在的困境 |
|---|---|---|
| 考后复盘 | "这次历史又没上 70" | 只会说"没背好"，不知道错在哪一类 |
| 日常辅导 | "材料题怎么教" | 家长讲不了，讲了自己也不确定对不对 |
| 考前冲刺 | "还有一个多月，先抓什么" | 五科同时要，历史被排在最后，没有取舍依据 |
| 长期规划 | "高一要怎么打基础" | 要么放养，要么提前刷题，两头都不对 |
| 亲子冲突 | "一让他学历史就吵" | 家长除了评价对错，没有第三句话 |

### 3. 要解决的问题（按痛感排序）

1. **诊断缺失**：家庭辅导最常见的起点是"分数低"，而不是"卡在哪一步"。凭分数补课，八成补错方向。
2. **方法缺失**：家长能盯时间，不能盯方法。"多背""多做题"是正确但对家庭无用的建议。
3. **落笔缺失**：孩子"看懂了但写不出"，缺的是设问拆解、分点、术语化这些动作，不是知识。
4. **角色错位**：家长把自己变成第二个老师，孩子把家庭变成第二个考场，两周内必然对抗。
5. **判断失效**：用分数当唯一验收指标，导致孩子在真正进步的那一周被批评。

## 二、产品是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 一套可执行的诊断与训练流程 | 题库、刷题软件 |
| 面向家庭的辅导方法系统 | 面向课堂的教案生成器 |
| 会批改、会给骨架、会给示范句 | 会代写整份作业 |
| 限定在教材与课标范围内 | 会评论现实政治与社会争议 |
| 给可观察指标 | 承诺提分 |

## 三、输入与输出规范

### 输入（按价值排序）

| 输入 | 必需性 | 没有时怎么办 |
|---|---|---|
| 年级 + 卷型 | 必需 | 直接问，一句话 |
| 近期卷子／错题（题号＋答案） | 强烈建议 | 走"三题取证法"降级诊断 |
| 孩子写的答案原文 | 批改必需 | 只讲方法，不批改 |
| 家长观察到的具体行为 | 建议 | 用问句库引导 |
| 每周可用时间、家长参与程度 | W6 必需 | 按 3 小时默认值给，并标注是默认值 |

### 输出（每个工作流固定交付物）

| 工作流 | 交付物 | 硬性要求 |
|---|---|---|
| W1 | 卡点卡 + 四周路线 + 排除项 | 卡点必须排序，且每个卡点挂卷面证据 |
| W2 | 轴 + 五维表 + 中外同期表 + 自测 | 每格必须有专有名词 |
| W3 | 设问拆解 + 分层 + 得分对照 + 骨架 | 判定只有"有／半／无"三档 |
| W4 | 观点句式 + 结构 + 量表 + 自评 | 观点必须可被反驳 |
| W5 | 错因判定 + 套路 + 三道变式 | 一题只归一类 |
| W6 | 周节奏 + 话术卡 + 验收 + 禁止动作 | 总量 3—4 小时，缺一天不补两天 |

**所有输出的共同要求：** 先结论后依据；表格优先；每个判断挂证据；结尾给一个 24 小时内能做完的动作。

## 四、与同类产品的差异（继承与补充）

目标产品（高中历史家教类专家）已经建立了不错的基础：通史框架、史料实证四步、论述题结构、教材范围约束。这些是这类产品的"通用正确做法"，本产品继承其**问题域**，但在以下六处做了补充或改造：

| # | 常见做法 | 本产品的改动 | 为什么 |
|---|---|---|---|
| 1 | 以"讲知识"为主，诊断靠问 | **六维诊断模型 + 卷面反查表**，无材料不出结论 | "基础不牢"是最省事也最没用的诊断 |
| 2 | 阶段特征按朝代平铺 | **五维表 + 填表铁律（每格必须有专有名词）** | 平铺的表学生只会看，不会用；空格本身就是诊断结果 |
| 3 | 材料题给"四步法"讲一遍 | **批改单**：逐点判有／半／无，并区分"过强／过弱／缺术语" | 学生要的不是方法名，是"我这句话该怎么改" |
| 4 | 论述题给结构与范文 | 给**观点句式 + 四种论证模型 + 9 分卷提一档的最小改动** | 范文会被抄，句式会被用；重写 9 分卷通常变 8 分 |
| 5 | 选择题按题讲 | **八类错因 + 七种干扰项套路 + 同因变式** | 讲十道不如归一类 |
| 6 | 家长端缺失或只有"多鼓励" | **W6 独立工作流**：角色三选一、周节奏、话术卡、三条禁止动作、验收看三样不看分数 | "家庭辅导"若不含家长，等于只做了一半 |

另外两处工程性改造：

- **判断条件写进契约。** 六个工作流都有"什么时候退回上一步"，避免模型在信息不足时硬给方案。
- **可验证性写进流程。** 打包前有头像体检与 zip 回读验收（见 `docs/07`），把"导入后图标变字"这类静默失败挡在上传之前。

## 五、必要的能力与技术接口

| 能力 | 用途 | 实现方式 |
|---|---|---|
| 长文本理解 | 读材料题、读学生答案 | 模型原生能力 |
| 结构化输出 | 表格、卡点卡、评分表 | 提示词约束 + references 模板 |
| 文件读取 | 用户提供的图片／文档 | 客户端文件能力 |
| 包内资料检索 | 查年代、概念、单元 | `materials/` 直接读取 |
| 结构化校验 | 发布前自检 | `tools/*.py`（纯标准库） |

**不依赖任何第三方服务、外部 API、网络请求。** 全部内容随包分发，离线可用。

## 六、质量、速度、稳定性要求

| 维度 | 要求 | 怎么保证 |
|---|---|---|
| 准确性 | 年代、人物、条约、单元标题不得错 | 集中在 `materials/` 单一来源；不确定标 `【需核对教材】` |
| 一致性 | 同一问题在不同轮次给出一致的判断口径 | 六维、八类错因、四维量表都是封闭集合，不允许临时发明分类 |
| 可用性 | 家长读完能立刻做一个动作 | 每条输出必须有"下一步动作"，且限定 24 小时内 |
| 速度 | 单次回答不堆砌 | 一次只解决一个卡点；超出的写进排队区 |
| 稳定性 | 信息不足时不硬给结论 | 每个工作流都有"退回"判断条件 |
| 可维护性 | 换人维护不改代码 | 知识在 `materials/`，方法在 `skills/*/references/`，提示词只做路由 |

## 七、合规设计（产品级约束）

1. **不代写**：可批改、给骨架、给示范句，不产出可上交的整份作业。
2. **教材范围**：只讲统编教材与课标范围；超范围明确说明"以课堂和教材为准"。
3. **主权表述**：涉及国家统一、疆域、民族宗教、行政区划，按教材与中国官方立场；台湾是中国不可分割的一部分，香港、澳门是中国的特别行政区。
4. **党史国史**：按教材与权威表述，不做延伸评论。
5. **不承诺提分**：改为可观察指标（错因收敛、设问答满）。
6. **不评价现实争议**：遇到即说明超出课程范围。
