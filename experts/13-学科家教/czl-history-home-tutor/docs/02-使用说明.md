# 使用说明

## 一、三十秒上手

选中「卓识教育-高中历史学习辅导专家」，第一句话按你的身份说：

| 你是谁 | 第一句可以这样说 |
|---|---|
| 家长 | "孩子高一，历史 62 分，材料题总答一半。我该从哪下手？" |
| 学生 | "我时间线特别乱，宋元和明清老混。怎么记？" |
| 家教 | "我一周给这个孩子上两次课，每次 90 分钟，先上什么？" |

**不要只说"历史怎么学"。** 越具体，第一次回答就越有用。信息不够时它会先问，而不是先给方案——这是设计如此。

---

## 二、三条典型路径

### 路径 A：家长，只知道分数

```
你：孩子高一，历史总在 60 分上下，说不清哪儿不会。

它：先确认一件事——你手上有最近的卷子吗？拍照就行，
    选择题错的那几页和材料题的答题区都要，答案也要。
    没有卷子的话，我们用"三题取证法"，十分钟也能定位。

你：卷子有，我拍给你。

它：【结论】主要卡在 D4 材料读取，本周先动"概括不抄原文"。

    | 维度 | 证据 | 严重度 | 杠杆 |
    | D4 材料读取 | 第17题(1)问，答案 80% 抄材料 | 高 | 高 |
    | D6 表达规范 | 第(2)问只答了一半设问 | 中 | 高 |
    | D1 时空定位 | 排序题错 2 道 | 中 | 中 |

    【四周路线】第 1 周改答题习惯 / 第 2 周补一个时段 /
    第 3 周材料题三步 / 第 4 周整卷限时

    【排除项】冷门史实、文采，这两项先不处理。

    【今晚你可以做的一件事】让孩子把第17题(1)问的答案，
    用不超过 20 字重写一遍，你只看字数，不看对错。
```

**注意最后那条"今晚做的一件事"。** 产品的所有输出都会落到一个具体动作上，不给"加强练习"这类空话。

### 路径 B：学生，时间线乱

```
你：宋元和明清我老混，特征记串。

它：先分清你是哪种乱——
    ① 记不住顺序，还是 ② 记得顺序但说不出各自的特征？

你：顺序知道，但一问你宋朝什么样，我就只能说"经济发达"。

它：【结论】这是特征缺口，不是顺序缺口。只练五维表，不背年表。

    | 维度 | 宋元 | 明清 |
    | 政治 | 二府三司、通判、转运使；元行省 | 废丞相设内阁；军机处 |
    | 经济 | 交子、市镇、重心南移完成 | 一条鞭法、摊丁入亩、白银货币化 |
    ...

    【记忆线索】不是口诀，是一条因果链：
    商品经济发展 → 市民阶层壮大 → 市民文化（词、话本、元曲）

    【反向自测，三分钟】
    1. "相权一分为三，选官靠考试……" → 哪个时期？
    ...
```

### 路径 C：家教，要排课

```
你：一周两次课，每次 90 分钟，这个孩子材料题特别弱。

它：【课时蓝图】90 分钟 = 讲 25 + 陪练 35 + 独立 25 + 收口 5
    【讲练比】不超过 3:7
    【问题链】不问"这段材料说了什么"，改问"这段材料能证明什么"
    【当堂检测】同类型、不同材料的三个小问
    【家长反馈稿】80 字以内，写"今天解决了什么、下次做什么"
```

## 三、六种问法，对应六个工作流

| 你说 | 走哪个 | 会给什么 |
|---|---|---|
| "不知道卡在哪" | W1 诊断 | 卡点卡 + 四周路线 |
| "时间线乱／记不住／中外对不上" | W2 框架 | 轴 + 五维表 + 自测 |
| 贴一道材料题 | W3 材料题 | 拆设问 → 分层 → 得分对照 |
| "12 分大题写不出" | W4 论述 | 观点句式 + 结构 + 量表 |
| 贴选择题错题 | W5 错因 | 八类归因 + 三道变式 |
| "我该怎么陪" | W6 家长 | 周节奏 + 话术卡 + 验收 |

一次问很多个时，它只会先做两个，剩下的写进"排队区"并说明为什么先放着。**这是有意的：一次改五个，一个都改不成。**

## 四、怎么给它材料，效果最好

| 给什么 | 怎么给 | 效果 |
|---|---|---|
| 卷子 | 拍照，含题号、选项、孩子的选择、材料题答题区 | 最好。能直接归因 |
| 只有错题 | 抄题干＋四个选项＋正确答案＋孩子选的那个 | 好。能做 W5 |
| 只有分数 | 说年级、卷型、选择题错几道 | 一般。只能给经验性假设 |
| 孩子口述 | 录音转文字，或直接复述 | 中等。能看时空与因果 |

**最没用的是"历史不好"四个字。** 这时候它会给取证清单，而不是方案——这不是敷衍，是因为凭分数猜病因的准确率太低。

---

## 五、它不会做的事

| 你说 | 它会 |
|---|---|
| "帮我把这篇历史小论文写完" | 给结构、给史实位置、给句式，让你自己填 |
| "这套卷子的答案给我" | 讲这一类题的解法，不逐题给答案 |
| "你觉得现在的中考/高考政策合理吗" | 说明超出课程范围，把话题拉回可考查内容 |
| "能保证我孩子提到 80 分吗" | 给可观察指标，不承诺分数 |
| "这个年份是几几年"（它不确定时） | 标 `【需核对教材】`，不编 |

## 六、家庭使用建议

1. **固定时间，不固定内容。** 每周三次、每次二十分钟，比周末突击三小时有效。
2. **家长只做流程管理员。** 定时间、收手机、记录完成；不讲课、不判对错。
3. **验收看三样**：时间线能不能口述、同一类错因有没有减少、概括能不能不抄原文。**不看分数。**
4. **缺一天不补两天。** 补齐必然导致总量翻倍，第三周停摆。
5. **导入后重启一次客户端**，否则头像可能仍显示为旧快照（详见 `docs/07`）。

## 七、常见问题

**Q：孩子高二选了历史，这个产品够用吗？**
够。W2 里有"选必与纲要怎么缝"的对照表（`materials/unit-map.md` 第四节），W6 有高二版周节奏（每周 3.5 小时）。

**Q：高三只剩几个月还有用吗？**
有用，但要换用法：跳过 W2 的全面建轴，直接用 W5（错因收敛）+ W3（分点作答）+ W3 的"分值换算点数"。这两项投入产出比最高。

**Q：不同省份教材／卷型不一样怎么办？**
先告诉它省份和年级。`materials/exam-format.md` 里明确写了"以本省当年考试院说明为准"，不会拿一套分值套全国。

**Q：能不能只问历史知识，不做诊断？**
可以。直接问"三省六部制怎么讲"，它按四步讲（定位时空→因果→经过→影响），讲完会附一句"这条知识会怎么考"。
