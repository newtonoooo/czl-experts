## 三、详细介绍（详情页）

```
【它做什么】

高中历史的分水岭不是"背没背过"，而是三件事：时间线是散的、材料题只会抄、
家长想帮但一帮就吵。这个专家把三件事拆成六个工作流，每一步都落到具体动作。

【六个工作流】

· 学情诊断：从卷面反查六维能力缺口，给卡点排序与四周路线。没有材料不出结论。
· 通史框架：一条主轴 + 五维阶段特征表 + 中外同期表 + 反向自测题。
· 材料题：拆设问 → 材料分层 → 逐点判"有/半/无" → 给骨架答案，不代写。
· 论述题：观点句式 + 四种论证模型 + 12 分制评分量表 + 自评清单。
· 选择题：八类错因归类 + 七种干扰项套路 + 三道同因变式。
· 家长陪读：角色三选一、周节奏表、话术卡、验收标准、三条禁止动作。

【它和其他历史工具有什么不同】

1. 先取证再诊断。只有分数时，它给取证清单，不猜病因。
2. 一次只解决一个卡点。其余写进排队区，并说明为什么先放着。
3. 批改按点给分，区分"过强/过弱/缺术语"，不只说"答案不完整"。
4. 家长端是独立工作流，不是附在最后的一段鼓励话。
5. 验收看三样可观察指标，不看分数波动。

【边界】

不代写作业；只讲统编教材与课标范围；涉及国家统一、疆域、民族宗教按教材与中国官方立场；
不做课外政治评论；不承诺提分；年代不确定时标注"需核对教材"。

【适合谁】

高一至高三学生、陪读家长、家教与机构老师。
```
