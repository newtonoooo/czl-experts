## 二、逐项风险

### R1 生成式头像的商用权利（🟡 需你确认）

| 项 | 内容 |
|---|---|
| 事实 | 头像由本机图像生成模型产出，未使用任何第三方图片素材、未参考他人作品 |
| 风险 | 生成模型的输出商用条款由**服务提供方**约定，可能要求标注、限制转售，或声明输出不承诺权利完整性 |
| 影响 | 若条款不允许商用，头像需替换 |
| 建议 | ① 查你所用生成服务的用户协议中"商业使用/输出归属"条款；② 保留生成记录（提示词、时间、本机路径）；③ 若条款不明，可用纯几何图形或文字标识自制头像替代（我可以另出一版无 AI 生成的方案） |
| 兜底方案 | `tools/prepare_avatar.py` 可把任意 512×512 图片规范化；换成自摄/自制图只需替换 `avatars/expert.png` 并重跑体检 |

### R2 知识内容的著作权边界（🟢 已按保守口径处理）

| 项 | 内容 |
|---|---|
| 已做 | ① 年代、事件、制度名、条约名、教材单元标题等**事实性内容**直接陈述；② 课标只取"五个素养的名称与一句话含义"，转述不引原文；③ 未打包任何教材 PDF、教辅扫描件、课标全文、真题原卷；④ 未标注教材页码（印次不同会错，也会造成"复制教材"的印象） |
| 仍存 | "阶段特征"的表述与教辅常见说法存在重合可能（同一史实的概括方式有限）。**表述为本产品自写，但无法保证与市面所有教辅零重合** |
| 影响 | 低。单句概括的独创性有限，且属事实性描述 |
| 建议 | 上架前用查重工具抽查 `materials/period-features.md`；若某段与特定教辅高度重合，改写那一句 |

### R3 与目标产品的相似度（🟡 需你判断）

| 项 | 内容 |
|---|---|
| 事实 | 功能域相近（都是高中历史家庭/一对一辅导）。提示词、六个工作流、references、材料、头像、名称、作者字段均为独立产出，未复制对方文件 |
| 风险 | 平台审核若以"功能高度相似"为由质疑，需要你提供独立开发证据 |
| 可提供的证据 | ① 本包的 37 个文件与目标产品文件结构不同（目标仅有 1 个 agent MD + 1 张头像，本包有 6 个 skill + 7 份材料 + 4 个工具 + 7 份文档）；② 六个工作流中 W1（六维诊断）与 W6（家长陪读）为目标产品所无；③ 本文件与 `docs/04` 记录了开发顺序；④ 头像为独立生成 |
| 建议 | 保留本目录的创建与修改时间线；上架时如被问及，直接提交 `docs/04` |

### R4 名称与商标（🟡 中等，需你确认）

| 项 | 内容 |
|---|---|
| 名称 | 「卓识教育-高中历史学习辅导专家」，英文 "Zhuoshi Education - Senior High History Learning Mentor" |
| 风险性质 | "卓识教育"是教育培训领域的常见字号组合，全国可能存在多家同名或近名的机构、已注册商标。若该字号不为你自有，存在两类风险：① 与在先商标或在先使用字号冲突；② 家长可能误认为某连锁机构的产品 |
| 与上一版的比较 | 风险**低于** v1.0.1 的「智源研究院」——后者直接撞上知名机构的通用简称（北京智源人工智能研究院，业内通称"智源研究院"），容易被读作隶属或授权关系；"卓识教育"指向分散，不易被误认为某一特定知名机构，但仍属需要自查的字号 |
| 与本任务约束的关系 | 若"卓识教育"是你实际在用的工作室/公司字号，则无问题；若既无主体也无授权，仍可能被理解为"借机构名义"，与"不虚构资质、不声称官方合作"的要求相悖 |
| 建议 | ① 到商标网检索第 41 类（教育服务）有无"卓识教育"在先注册；② 保留可证明主体的材料（营业执照、个体工商户字号等）；③ 若检索有冲突，改用「卓识历史学堂」「卓识学堂·高中历史」等仍保留"卓识"但不带"教育"字样的组合，规避行业通用词 |
| 改名成本 | 极低。改 `plugin.json` 与 `agent MD` 的 `displayName`/`profession` 四处字符串 + `docs/03` 一处表格，重跑 `tools/build_release.py` |
| 变更轨迹 | v1.0.0「鉴史堂—高中历史家教」→ v1.0.1「智源研究院·高中历史学习辅导专家」→ v1.0.2「卓识教育-高中历史学习辅导专家」。两次更名均按你的指定执行，旧名仅保留在 CHANGELOG 与测试记录中 |

### R5 平台规则未确认（🔴 需你确认）

| 项 | 内容 |
|---|---|
| 无法从本机核实的三件事 | ① 专家上架的分成比例与结算方式；② 原创性审核的具体标准（是否要求代码/提示词查重）；③ 教育类专家是否需要资质证明（如教师资格证、机构授权） |
| 影响 | 高。任一项不符可能导致下架或无法结算 |
| 建议 | 直接在开放平台后台或对接人处确认；**在确认前不要把本包作为"已通过审核"对外宣传** |

### R6 分类字段与官方校验脚本不一致（🟢 已处置）

| 项 | 内容 |
|---|---|
| 事实 | 本包用 `15-Education`；官方 `validate_expert.py` 的白名单只到 `12-IndustryConsultant`，因此报 1 个错误 |
| 判断依据 | 官方市场内 11 个教育类专家均使用 `15-Education`（含同类高中家教），说明该值是平台真实分类 |
| 处置 | 保留正确分类，不为通过脚本改成错误分类；在自建校验器中补充白名单并写明理由 |
| 残留风险 | 低。若平台审核以脚本输出为准，可能要求改回 12 类；此时应按平台要求调整，而不是继续解释 |

### R7 效果宣传合规（🟢 已规避）

- 全文未出现"提分 XX 分""帮助 XX 名学生"等表述。
- `docs/03` 明确要求示意图标"格式示意"。
- 产品内明确"不承诺提分"，改为可观察指标。
- **若后续要做效果宣传，必须先做前后测并留存原始数据，否则不建议写。**

### R8 内容时效性（🟡 需定期维护）

| 项 | 内容 |
|---|---|
| 风险点 | 教材修订、省份卷型调整、课标版本更新（现有 2017 年版 2020 年修订 / 2025 年修订讨论稿） |
| 影响 | 中。过期信息会直接误导家长 |
| 建议 | 每学年开学前核对三处：`materials/unit-map.md`（单元标题）、`materials/exam-format.md`（分值）、`materials/sources.md`（课标版本）。核对后在 `CHANGELOG.md` 记一条 |

### R9 内容立场与合规（🟢 已内置约束）

- Agent 提示词第七节写明：教材口径、主权表述规范、党史国史按权威表述、不做课外政治评论、不评价社会争议。
- 未涉及任何现实政治评论、民族宗教敏感表述、地域对立内容。
- 涉及台湾、香港、澳门一律按"中国不可分割的一部分 / 中国的特别行政区"表述，全包已检查无例外。

### R10 技术依赖（🟢 无）

- 无第三方 Python 包（`tools/*.py` 仅用 `json/struct/zlib/pathlib/subprocess/hashlib/zipfile`）。
- 无外部 API、无网络请求、无遥测。
- 因此不存在 GPL/AGPL 传染、SaaS 条款、密钥泄露等问题。

## 四、发布前必须完成的动作（按顺序）

1. `python3 tools/verify_avatar.py .` 退出码 0。
2. `python3 tools/build_release.py .` 第 4 步回读验收通过。
3. 在**另一台**机器导入 zip，重启客户端，确认图标为头像而非"智"字。
4. 按 `docs/02` 的三条路径各跑 5 轮对话，确认没有跳步诊断、没有代写。
5. 确认 R1、R4、R5 三项（头像条款、名称主体、平台规则）。
6. 完成后再对外使用"可上架/已发布"这类表述。

- 没有声称"无版权风险"。可确认的部分写"低风险"，不能确认的写"待确认"，没有一项写成"保证无风险"。
- 没有为了让包通过检查而删除任何版权声明或来源说明。
