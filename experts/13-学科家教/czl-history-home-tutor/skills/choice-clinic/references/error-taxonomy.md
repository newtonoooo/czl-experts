# 选择题错因八分类

用途：W5 第 2 步。**一道题只归一类**，归两类等于没归。

## E1 时空错位

| 项 | 内容 |
|---|---|
| 识别 | 题干给的是甲时期，选项写的是乙时期的现象；或排序题次序颠倒 |
| 典型 | 题干"明中期"，选项出现"内阁"却在讲"军机处"的职能 |
| 根因 | 时间轴没立住，只有朝代名没有年代 |
| 训练 | 在题干上写世纪；背相邻时期的分界事件（见 `materials/timeline-cn.md` 第四节） |
| 检测 | 给五个年代排序，全对才算过关 |

## E2 概念混淆

| 项 | 内容 |
|---|---|
| 识别 | 两个近义术语被当成同义词（君主专制／中央集权、井田制／均田制） |
| 典型 | 把"废丞相"说成"加强中央集权" |
| 根因 | 概念只有名字，没有边界 |
| 训练 | 一次只辨析一组，用"两栏对比 + 各举一例"（见 `materials/concepts.md`） |
| 检测 | 能说出两者的区别，并各举一个教材例子 |

## E3 主体错配

| 项 | 内容 |
|---|---|
| 识别 | 把 A 的主张、成就、政策安到 B 头上 |
| 典型 | 把洋务派的"中体西用"当成维新派主张 |
| 根因 | 人物／派别只有名字，没有主张清单 |
| 训练 | 做"派别—主张—实践"三列小表，一页一个时段 |
| 检测 | 随机抽三个人物，各说一条主张 |

## E4 程度失当

| 项 | 内容 |
|---|---|
| 识别 | 选项里出现"开始""完成""彻底""完全""根本""唯一" |
| 典型 | 把"有所发展"写成"彻底改变" |
| 根因 | 对历史过程的"程度"没有感觉 |
| 训练 | 程度词清单 + 每见必圈；建立"哪些事确实是'开始'"的短清单 |
| 检测 | 一道题里能圈出所有程度词，并判断是否过头 |

## E5 因果倒置

| 项 | 内容 |
|---|---|
| 识别 | 把结果当原因；把背景当影响；两个原因平铺不分主次 |
| 典型 | "鸦片战争的原因是《南京条约》签订" |
| 根因 | 因果只记了"有关系"，没记"谁在前、谁是根本" |
| 训练 | 三层层级表：根本／主要／直接，每层一条 |
| 检测 | 给一个事件，能说出三层原因且不重复 |

## E6 材料误读

| 项 | 内容 |
|---|---|
| 识别 | 以偏概全（抓一句当全部）、脱离材料（用常识代替材料）、误读转折（忽略"但"之后） |
| 典型 | 材料前半段讲繁荣，后半段讲局限，答案只写了繁荣 |
| 根因 | 没有分层读材料的动作 |
| 训练 | 先分层再选；每层写一句批注 |
| 检测 | 用一句话概括材料，不超过 20 字 |

## E7 设问误读

| 项 | 内容 |
|---|---|
| 识别 | 问"原因"答"表现"，问"反映"答"说明"，问"旨在"答"结果" |
| 典型 | 题干问"这表明"，学生按"这是因为"作答 |
| 根因 | 没圈设问动词 |
| 训练 | 圈动词 + 说出"这题在要什么" |
| 检测 | 连续五题，每题先用一句话说出设问要求 |

## E8 史观偏差

| 项 | 内容 |
|---|---|
| 识别 | 用今天标准评价当时；只从道德维度评价；只看单一维度 |
| 典型 | "闭关自守是愚蠢的决定"（以今律古） |
| 根因 | 缺"历史地看问题"的习惯 |
| 训练 | 每个评价题强制写"在当时条件下……"和"从长时段看……"两句 |
| 检测 | 能对一个政策同时给出当时的合理性与后来的局限 |

## 归档表模板

```
| 题号 | 我选的 | 正确答案 | 错因（E__） | 我当时想的是 | 属于不会还是没看 |
|---|---|---|---|---|---|
```

**"我当时想的是"这一栏必须填。** 空着的话，归因多半是错的——家长和老师猜的错因，和孩子真实的错因经常不是一回事。

## 一周后的复检

只统计一件事：**同一编号的错因，从几道降到几道。** 这个数字不变，说明训练方向错了，要换方法，不是加量。
