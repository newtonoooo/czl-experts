# W2 通史框架与阶段特征

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 通史框架与阶段特征（timeline-framework） |
| **任务职责** | 把"背年代"改成"记结构"：用**一条主轴 + 五维特征 + 中外对照**三件套，让学生能从"看到年代"推到"说出特征"，从"看到特征"反推"哪个时期"。 |
| **输入参数** | 必填：要处理的时段（如"秦汉""晚清""两次世界大战之间"）、年级。可选：现有笔记或时间轴照片、经常混淆的两组时期。 |
| **执行步骤** | ① 确认是"记不住年代"还是"记不住特征"（问法见下）→ ② 给主轴：只给这一段的起止与三到五个节点 → ③ 填五维特征表（政治／经济／思想文化／社会／对外与民族）→ ④ 加一列"同期世界"→ ⑤ 给一条记忆线索（不是口诀，是因果链）→ ⑥ 给反向自测（给特征猜时期）→ ⑦ 标出与相邻时段的**分界事件** |
| **判断条件** | 学生能背年代但不会答题 → 只做③④，跳过②；学生能说特征但记不住先后 → 只做②⑦；相邻时期混淆 → 强制加"分界事件对照"；高三综合复习 → 用"三条长线"（中央集权、经济重心、对外关系）串，不按朝代平铺 |
| **输出格式** | ① 主轴（一行：起止＋节点）② 五维特征表 ③ 中外同期表 ④ 记忆线索（三句话）⑤ 反向自测五题 ⑥ 分界事件清单 |
| **异常处理** | 时段太大（如"整个中国古代"）→ 先切成三到四段，一段一次；学生基础过弱 → 五维降到三维（政治／经济／文化）；教材版本不一致（如旧人教版专题体例）→ 先问版本再给表，不硬套；世界史与教材分期不一致（如"中古"起止）→ 以教材单元标题为准并标注 |
| **必要依赖** | `materials/timeline-cn.md`、`materials/timeline-world.md`、`materials/period-features.md`、`references/frame-drills.md` |

## 一、先分清两种"乱"

| 症状 | 真实缺口 | 练法 |
|---|---|---|
| "我知道唐朝在前面，但说不清唐朝什么样" | 特征缺口 | 五维特征表 + 反向自测 |
| "我知道宋朝很富，但不知道它排在哪儿" | 顺序缺口 | 主轴 + 分界事件 |
| "中国史还行，世界史一对就乱" | 对照缺口 | 中外同期表（同一行只放同一世纪） |
| "每个朝代都背了，一到材料题用不上" | 迁移缺口 | 用"特征→证据"训练：给特征，找教材里的对应史实 |

只练错的那一种。三种一起练，一周就崩。

## 二、五维特征表怎么填

以**一段时期**为单位，不按课时。每格只写一句，写不出就留空——空格本身就是诊断结果。

| 维度 | 要写什么 | 反例（不要这样写） |
|---|---|---|
| 政治 | 制度名称 + 权力往哪走（集中还是分散） | "政治清明""加强统治" |
| 经济 | 生产方式、土地关系、流通手段、重心在哪 | "经济繁荣" |
| 思想文化 | 主流思想是什么、有没有新因素、传播载体 | "文化昌盛" |
| 社会 | 阶层变动、人口流动、生活变化 | "社会安定" |
| 对外与民族 | 开放还是封闭、战争还是贸易、谁在主导 | "对外交往频繁" |

**填表铁律：每一格必须出现一个专有名词。** 出现不了专有名词，说明这一维是空的，不是"理解了"。

## 三、中外同期表怎么排

只排同一世纪，不排"同一时期"这种模糊说法。行的单位是世纪，不是朝代。

```
| 世纪 | 中国 | 世界 | 一句话对照 |
|---|---|---|---|
| 前 3–前 2 世纪 | 秦汉字制建立 | 罗马由共和走向帝国 | 两个大空间同时在做"整合" |
```

对照句只写"同"或"异"的**机制**，不写"都很繁荣"。

## 四、记忆线索：给因果链，不给口诀

口诀解决"顺序"，因果链解决"为什么是这个顺序"。

| 类型 | 例子 |
|---|---|
| 因果链 | 铁犁牛耕 → 井田制瓦解 → 土地私有 → 新兴地主 → 各国变法 → 郡县制 → 中央集权雏形 |
| 压力链 | 边疆压力 → 军费上升 → 赋税加派 → 农民负担 → 内乱 → 王朝更替 |
| 外溢链 | 新航路 → 商业革命 → 价格革命 → 封建地主收入下降 → 资产阶级力量上升 |

给完链子，让学生自己补一个"如果断在哪一环，后面会怎样"。这一步才是迁移训练。

## 五、反向自测（比正背有效）

给特征，猜时期。五题一组，三分钟内做完。

```
1. "相权被拆成三份，考试选官靠考试，土地税按资产分夏秋两次收" → ？
2. "皇帝直接管六部，另一个机构在边上拟旨，海外贸易只留一口" → ？
3. "机器生产进了城，工人集中在厂里，城市人口第一次超过农村（英国）" → ？
```

答不上来时，不要直接给答案，先给"这三个特征分别对应哪三个维度"，让他自己缩范围。

## 六、分界事件清单（防混淆的关键）

每组相邻时期只记**一个**分界事件，多了记不住。

| 分界 | 事件 |
|---|---|
| 先秦／秦汉 | 前 221 秦统一 |
| 秦汉／魏晋 | 220 汉亡（此后长期分裂） |
| 魏晋／隋唐 | 589 隋灭陈统一 |
| 隋唐／五代宋 | 907 唐亡 |
| 宋元／明 | 1368 明建立 |
| 明／清 | 1644 清入关 |
| 古代／近代 | 1840 鸦片战争 |
| 近代／现代 | 1949 中华人民共和国成立 |
| 世界：古代／中古 | 476 西罗马帝国灭亡（教材分期口径） |
| 世界：中古／近代 | 15 世纪末新航路开辟 |
| 世界：近代／现代 | 1917 俄国十月革命（教材分期口径） |

**注意：** 世界史分期各版本表述有差异，一切以学生手上教材的单元标题为准。有疑问时标注"以教材为准"，不要硬拗。

## 七、禁忌

- 不要给"年代大全"。给全表的唯一结果是学生放弃。
- 不要用"这一时期是我国历史上重要的转型期"这类话当特征。它适用于任何时期，所以什么也没说。
- 不要把中国史和世界史分开背完再对照。对照要在建表时就并进去。
