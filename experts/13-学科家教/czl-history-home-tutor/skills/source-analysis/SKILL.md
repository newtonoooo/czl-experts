# W3 史料实证与材料题

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 史料实证与材料题（source-analysis） |
| **任务职责** | 把"读材料—写答案"这个黑箱拆成四步可检查的动作，并给出**逐点对照的分数归属**，让学生知道每一分是怎么拿到或丢掉的。 |
| **输入参数** | 必填：材料原文（或照片转写）、设问、孩子写的答案。可选：参考答案、分值、年级、这道题的得分。**缺孩子的答案时只能讲方法，不能批改。** |
| **执行步骤** | ① 拆设问：圈出"根据材料／结合所学""概括／分析／说明／评价""几问、各几分" → ② 分层：按句号、分号、转折词把材料切成 2—5 层，每层一句批注 → ③ 提取：每层抽出"谁—做了什么—结果" → ④ 转化：把提取结果换成学科术语（见 `references/term-bank.md`）→ ⑤ 对照：孩子的答案逐点判"有／半／无"，给出得分归属 → ⑥ 改写：给一份"骨架式"答案（只给结构与关键词，不给完整成文） |
| **判断条件** | 设问含"根据材料"→ 答案必须有材料依据，纯用所学不得分；含"结合所学"→ 必须有材料之外的知识；含"概括"→ 不得照抄原文；含"分析"→ 必须有因果链；多问 → 分问作答，混在一起按一问给分；孩子答案全是原文摘抄 → 先停在这练"概括"，不往下讲 |
| **输出格式** | ① 设问拆解表（问什么／限制词／分值／答几点）② 材料分层批注 ③ 得分对照表（点／孩子写的／判定／该改成什么）④ 骨架答案 ⑤ 一个同类小练 |
| **异常处理** | 材料是图片且看不清 → 请对方转写或只讲方法；孩子没写答案 → 转"示范+仿写"模式；参考答案与设问不匹配 → 以设问为准并说明；开放型设问（"谈谈你的认识"）→ 转 W4 的结构，但史实仍从材料取；材料涉及超出教材的争议内容 → 只讲可考查部分，其余说明超出范围 |
| **必要依赖** | `references/question-types.md`（设问类型与答题动词）、`references/term-bank.md`（术语替换表）、`references/marking-sheet.md`（批改表模板）、`materials/concepts.md` |

## 一、四步法：每一歩都能被检查

### 第 1 步 拆设问（最容易被跳过，也是提分最快的一步）

拿到题先不看材料，只看设问，填这张表：

| 要填 | 例 |
|---|---|
| 问几问 | 两问，别当一问答 |
| 每问几分 | 6 分 + 8 分，决定答几点 |
| 答案来源 | "根据材料"／"结合所学"／"综合上述材料" |
| 答题动词 | 概括／分析／说明／评价／比较／指出 |
| 限制词 | 时间（"明清时期"）、空间（"西欧"）、主体（"政府"） |

**学生 80% 的"答偏"发生在这一步，不是发生在理解材料。** 只答第一问、把"分析"写成"概括"、把"根据材料"答成"背教材"，都是没拆设问。

### 第 2 步 分层

按标点与逻辑切，不按行切。

| 信号 | 怎么切 |
|---|---|
| 句号 | 一层一件事 |
| 分号 | 同一件事的两个方面 |
| "但""然而""不过" | 转折后是重点，常是命题落点 |
| "因此""故" | 结论层，往往是答案直接来源 |
| 引号内的原话 | 常是态度与立场的证据 |

层数控制在 2—5 层。切出 8 层说明切碎了，回到句号重切。

### 第 3 步 提取

每层只回答三个问题：**谁、做了什么、结果如何**。写在材料旁边，一句话一层。

不允许在这一步写"反映了""说明了"——那是第 4 步的事。提前评价会导致答案全是空词。

### 第 4 步 转化（术语化）

把口语换成本学科的说法。这一步决定"看着对但不得分"。

| 材料原话 | 转化后 |
|---|---|
| "官府不管了，让商人自己卖" | 政府放宽对商业的限制 |
| "读书人越来越多，考不上的人也多了" | 科举制发展，士人阶层扩大 |
| "机器一开，手工织布的都失业了" | 机器生产排挤手工业，传统手工业者破产 |
| "钱越来越不值钱" | 货币贬值，物价上涨 |

## 二、批改：按点给分，不按感觉给分

### 得分对照表（核心交付物）

| 应有点 | 孩子写的 | 判定 | 改成什么 |
|---|---|---|---|
| 材料层 1：政府放宽限制 | "政府支持商业" | 半 | 政府**放宽**对商业的限制（"支持"过强，材料只说不管） |
| 材料层 2：商人地位上升 | 未答 | 无 | 商人社会地位有所提高，可与士人交往 |
| 结合所学：商品经济繁荣 | "经济很好" | 无 | 商品经济发展，白银货币化（术语缺失不计分） |

**判定标准只有三档：**
- **有**：术语准确 + 与设问方向一致 → 满分点。
- **半**：方向对但表述过强／过弱／缺术语 → 一半分，并说明差在哪。
- **无**：无此点，或与设问方向不符 → 0 分，说明该点应从材料哪一层来。

### 批改时的三个禁止

1. 不许只写"答案不完整"。要指出缺的是哪一层、哪一问。
2. 不许用"语言不够精炼"当评语。要给出可替换的术语。
3. 不许直接把参考答案贴上去当批改结果。参考答案是给老师看的，学生需要的是"我怎么写到那一句"。

## 三、骨架答案怎么写（不代写）

给结构，不给整段成文。格式如下：

```
（1）第一问（6 分，答 3 点）
① 材料层1关键词 → 术语：______
② 材料层2关键词 → 术语：______
③ 结合所学：______（写出制度名或事件名）
```

学生填完空，才算练过。直接给成文答案，他抄完下次还是不会。

## 四、史料价值题（单独一类，答法不同）

设问常是"上述材料对研究某问题有何价值"。**标准动作是两头都说。**

| 要说 | 句式 |
|---|---|
| 能证明什么 | 该材料属于__（类型），可用于研究__（问题），其中"__"一句可佐证__ |
| 不能证明什么 | 但该材料受__（作者立场／记录目的／时代局限）影响，不能单独用于说明__，需与__（其他类型史料）互证 |

只说前半句，最多拿一半分。这是史料实证题最稳定的失分点。

## 五、类型与可信度速判

| 史料类型 | 通常价值 | 通常局限 |
|---|---|---|
| 档案、诏令 | 制度与官方行为的直接证据 | 只记录官方视角，隐去执行偏差 |
| 私人日记、书信 | 心态、日常、私密决策 | 自我美化，样本单一 |
| 报刊 | 舆论与时代氛围 | 有政治立场与审查 |
| 器物、遗址 | 物质生活、技术水平 | 难以直接反映观念 |
| 统计图表 | 趋势与规模 | 口径可能被政治干预（如户籍统计） |
| 后人著述 | 系统解释 | 隔了时代，含作者建构 |

**判断口诀：** 先问"谁在什么位置上写的"，再问"他为什么写"，最后问"他没写什么"。第三问最难，也最能拿分。

## 六、一个完整的示例骨架

材料（节选，示意）：
> "（明中期后）富室之称雄者，江南则推新安，江北则推山右。新安大贾，鱼盐为业……山右或盐、或丝、或转贩，其富甚于新安。"

设问：根据材料，概括明中期后商帮发展的特点。（6 分）

| 步 | 动作 |
|---|---|
| 拆设问 | 一问；6 分答 3 点；来源"根据材料"；动词"概括"；限制"明中期后" |
| 分层 | 层 1：富室以地域称雄（江南新安／江北山右）；层 2：经营行业（鱼盐、丝、转贩）；层 3：实力对比（山右富于新安） |
| 提取 | 按地域形成商人群体；经营大宗商品与长途贩运；不同商帮实力有差异 |
| 转化 | 出现地域性商人群体（商帮）；以盐、丝等大宗商品和长途贩运为主；商帮间实力不均 |
| 骨架 | ① 地域性商帮形成 ② 经营大宗商品与长途贩运 ③ 商帮实力存在差异 |

三句话，18 个字左右，6 分到手。**概括题不需要长，需要的是"每点一个术语"。**

## 七、禁忌

- 不要把"读不懂材料"当成阅读能力问题。多数情况是没拆设问，读的时候不知道要找什么。
- 不要让学生背"答题模板句"。模板句在材料不匹配时是负分。
- 不要在批改里写"多练就好了"。要写"下次这道题先画三条横线"。
