# W1 家庭学情诊断

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 家庭学情诊断（history-intake） |
| **任务职责** | 把"历史不好"这句模糊描述，换成一张**有排序、有证据、有排除项**的卡点卡，并给出四周可执行的路线。诊断的产物不是建议清单，是"先动哪一个"的决定。 |
| **输入参数** | 必填：年级、当前分数区间（或等级）、最近一次考试的卷子／答题卡（照片、题号＋答案均可）。强烈建议：孩子口述时间线的录音或转写、用过的课本、家长观察到的具体行为（"背了就忘""选择题总在两个里挑错""大题写不满"）。 |
| **执行步骤** | ① 判身份，问清年级与卷型 → ② 收材料，按"有／无材料"分流 → ③ 用六维定位表逐维打分（见下）→ ④ 用错题反查，把分数损失归到能力维度 → ⑤ 排"提分杠杆"顺序 → ⑥ 写四周路线（每周一个动作）→ ⑦ 写排除项（哪些不是问题，别再花时间） |
| **判断条件** | 无任何材料 → 只出"取证清单"，**不出诊断结论**；材料只覆盖一个题型 → 诊断只对该题型负责，其余标"未验证"；发现基础史实缺口超过该卷失分的 40% → 先补框架（转 W2），暂停题型训练；发现失分集中在选择题且错因相同 → 转 W5 优先 |
| **输出格式** | ① 一句话结论 ② 卡点卡（表：维度／表现证据／严重度／提分杠杆）③ 四周路线（表：周次／动作／每次时长／验收标准）④ 排除项 ⑤ 需要补的材料 |
| **异常处理** | 家长只肯给分数 → 用"三题取证法"（让孩子随口说三个年代、复述一个事件的因果、指出卷子上最没底的一道题），仍不成就降级为"经验性假设"并明确标注；分数与卷面明显矛盾（如 80 分但材料题几乎空白）→ 先问是不是不同卷型或赋分制；家长要求"直接说怎么补" → 先给一个最小动作垫住，再回来取证 |
| **必要依赖** | `references/intake-questions.md`（问句库）、`references/diagnosis-rubric.md`（六维评分标准）、`materials/exam-format.md`（卷型与分值，避免按错误卷型算分） |

## 一、六维定位表

分数只说明"丢了多少"，不说明"丢在哪"。六个维度覆盖高中历史失分的绝大多数情形，逐维给 0–2 分（0 = 明显缺口，1 = 不稳定，2 = 达标）。

| 维度 | 达标表现 | 典型失分证据 |
|---|---|---|
| D1 时空定位 | 能说出朝代／时期的起止与先后，能在一句话里给事件定位 | 把不同时期的事物混在一道题里；排序题必错；"明清"与"宋元"的特征互换 |
| D2 史实存量 | 关键事件、制度、人物、文件名能准确复述 | 措施题写不出具体制度名，只会写"加强管理" |
| D3 概念辨析 | 能区分易混概念（如郡县制／分封制、君主专制／中央集权） | 选项里两个近义概念分不清，靠感觉选 |
| D4 材料读取 | 能分层、能概括、能指出材料的立场与局限 | 照抄材料原文当答案；概括题写成翻译题 |
| D5 因果与解释 | 能分根本／主要／直接原因，能给出多因解释 | 因果倒置；只给一个原因就收笔；影响只写积极面 |
| D6 表达与规范 | 分点作答、术语准确、时序词清楚、字数达标 | 一段到底、口语化、答非所问、超出答题区域 |

**判定门槛：** 任意维度得 0 分且该维度对应题型的失分占全卷 25% 以上，即为"当周必须动"的卡点。

## 二、从错题反查维度（关键动作）

不要问孩子"你哪里不会"，孩子答不准。要看他在卷子上做了什么。

| 卷面现象 | 归到哪一维 | 备注 |
|---|---|---|
| 选择题错在同一时期的相邻选项 | D1 | 时空框架缺口，不是知识缺口 |
| 选择题错在不同时期的相似制度 | D3 | 概念辨析缺口 |
| 材料题答案与材料高度重合（大段抄写） | D4 | 缺"概括"这个动作 |
| 材料题只答一半设问 | D6 | 读题与分点习惯问题，提分最快 |
| 影响类设问只写积极面 | D5 | 缺"辩证"这个动作 |
| 小论文只有观点没有史实 | D2 + D5 | 先补史实支架，再练论证 |
| 会做的题也丢分（涂改、错位、超框） | 非学科问题 | 单列，不进六维 |

## 三、提分杠杆排序（不是按严重度排）

排序看三件事：**失分总量 × 修复速度 × 迁移面**。

| 优先级 | 情形 | 理由 |
|---|---|---|
| 高 | 只答一半设问、不分点、超框 | 一周能改，改完全卷受益 |
| 高 | 选择题错因集中在同一类 | 一类错因往往牵动 4–6 道题 |
| 中 | 材料题不会概括 | 需要三到四周，但跨所有材料题 |
| 中 | 阶段特征混乱 | 需要框架重建，见效慢但决定上限 |
| 低（先放着） | 冷门史实记不住 | 投入产出比低，考前再说 |
| 低（先放着） | 小论文文采不够 | 评分不看文采，看观点与史实 |

## 四、四周路线怎么写

每周只放**一个**主轴动作，加一个"每天十分钟"的固定动作。四周刚好覆盖"改习惯 → 补框架 → 练题型 → 上整卷"。

| 周 | 主轴 | 每天十分钟 | 验收 |
|---|---|---|---|
| 第 1 周 | 改答题习惯（分点、看全设问、抄题干关键词） | 复述一条时间线（说给家长听） | 下一次作业无"只答一半" |
| 第 2 周 | 补一个时段的阶段特征（只补一个，别贪） | 五个年代快问快答 | 能不看书画出该时段五维表 |
| 第 3 周 | 材料题三步（分层—概括—回扣设问） | 每天一道材料小题，只写提纲 | 概括不再抄原文 |
| 第 4 周 | 整卷限时（只做一组选择题＋一道材料题） | 错题口述错因 | 同类型错因减少一半 |

## 五、输出模板

```
【结论】一句话：主要卡在 ___，本周先动 ___。

【卡点卡】
| 维度 | 证据（哪道题、哪句话） | 严重度 | 杠杆 |
|---|---|---|---|
| D4 材料读取 | 第17题第(1)问，答案 80% 抄材料 | 高 | 高 |

【四周路线】四行表格，见上。

【排除项】以下三项暂不处理，原因：___

【还想看】如果方便，再给我 ___，可以把 D2 的判断确认下来。
```

## 六、禁忌

- 不要在没有卷面的情况下断言"你孩子是基础不牢"。基础不牢是最省事也最没用的诊断。
- 不要一次给五个卡点。排不出顺序，就等于没诊断。
- 不要把家长焦虑当学情。家长说"他很懒"，要追问"懒"的具体表现是什么时间、什么场景。
