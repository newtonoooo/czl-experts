# 资料依据与使用边界

本目录是产品自带的学科底稿。这份文件说明：**每条内容的依据是什么、哪些内容没有照搬、为什么这样处理。**

## 一、内容的三个来源层级

| 层级 | 内容 | 处理方式 |
|---|---|---|
| A 公开事实 | 年代、事件、制度名称、条约名称、单元标题 | 直接陈述。事实本身不产生著作权，可自由使用 |
| B 公开规范 | 历史学科核心素养的五个方面、课标对素养的界定、考试院公布的卷型与分值 | **转述并标注来源**，不整段引用原文 |
| C 原创整理 | 五维阶段特征表的填法、提分杠杆排序、错因八分类、评分量表、话术卡、四周路线 | 本产品原创，著作权归开发者所有 |

## 二、A 层：可核对的事实来源

| 内容 | 主要依据 |
|---|---|
| 中国史年代与事件 | 统编版《中外历史纲要（上）》通行叙述；中学历史教学通用纪年 |
| 世界史年代与事件 | 统编版《中外历史纲要（下）》通行叙述 |
| 教材单元结构 | 统编版高中历史教材现行单元标题（见 `unit-map.md`，已交叉核对） |
| 制度、条约、人物 | 教材通行表述 |

**边界说明：** 表中只给"节点"与"一句话意义"，不复制教材课文、不复制教材插图、不标注教材页码。需要精确到课文的表述时，请学生回教材核对。

## 三、B 层：公开规范与转述

| 内容 | 依据 | 本产品的处理 |
|---|---|---|
| 历史学科核心素养五个方面（唯物史观、时空观念、史料实证、历史解释、家国情怀） | 教育部《普通高中历史课程标准（2017 年版 2020 年修订）》 | 只使用五个素养的**名称与一句话含义**，用于组织方法论；不复制课标原文段落 |
| 素养之间的关系（唯物史观是理论保证、时空观念是学科本质体现等） | 同上 | 转述为教学语言，不逐字引用 |
| 选择性考试卷型与分值 | 各省考试院公布的试卷结构（如四川省 2025 年选择性考试试卷结构） | 只给结构与区间，明确标注"以本省当年说明为准" |
| 学业水平合格性考试范围 | 各省合格考方案 | 只作一般描述 |

**为什么不全篇引用课标：** 课标文本由教育主管部门发布，用于教学与教研；商业产品整段复制既不必要，也会带来授权风险。本产品只需要素养的"骨架"，转述足够，且更适合家长阅读。

## 四、C 层：本产品原创的部分

以下内容为本产品独立设计，未取自任何现有专家、教辅或课程：

1. **六维诊断模型**（D1—D6）与"提分杠杆"排序规则。
2. **五维阶段特征表的填表铁律**（每格必须出现专有名词）。
3. **材料题四步法**（拆设问 → 分层 → 概括 → 回扣）与"概括不抄原文"的判定标准。
4. **开放论述题的三段结构与 12 分制评分量表。**
5. **选择题错因八分类**与干扰项七套路。
6. **家长陪读的话术卡、验收标准、三条禁止动作。**
7. **四周路线的时间配比**与每周单一主轴的设计。
8. 全部表格的组织方式与文案表述。

## 五、没有做的事（重要）

- **没有下载或打包任何教材 PDF、教辅扫描件、课标全文、试卷原卷。** 这些内容的商业再分发需要授权，本产品不涉入。
- **没有复制任何现有专家产品的提示词、工作流文案、头像或宣传语。** 产品定位相近，实现独立。
- **没有使用任何第三方图片素材。** 头像为生成式原创，无第三方素材授权问题。
- **没有引用具体学校的内部数据、未公开的考试成绩或排名。**

## 六、如果要在产品里补外部资料

| 想补什么 | 可行做法 | 不可行做法 |
|---|---|---|
| 课标要点 | 转述 + 标注文件名与版本 | 整段复制课标原文 |
| 真题 | 引导用户自行提供其持有的试卷，产品只做方法讲解 | 打包分发真题原卷 |
| 教材内容 | 指向教材，让学生自己翻 | 扫描教材页面进包 |
| 学术观点 | 标注作者与出处，作"另一种解释"呈现 | 当作教材结论讲 |

## 七、引用规范（产品内输出时）

- 引教材：写"据统编版《中外历史纲要（上）》第三单元"，**不写页码**（版本印次不同，页码会错）。
- 引课标：写"据《普通高中历史课程标准（2017 年版 2020 年修订）》"，不引原文长句。
- 引考试院文件：写"据某省某年选择性考试试卷结构说明"。
- 年代不确定：写`【需核对教材】`，不猜。
