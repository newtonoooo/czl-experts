# 高频易混概念辨析

用途：W5 选择题错因里的"概念混淆"、W3 材料题术语准确度、W4 论述题史论表述。
用法：不要整篇读。学生错哪一组，只看那一组，看完立刻做一道同组变式。

## 一、制度类

### 1. 分封制 vs 郡县制

| | 分封制 | 郡县制 |
|---|---|---|
| 官员产生 | 血缘世袭 | 皇帝任免、不得世袭 |
| 与中央关系 | 诸侯有较大独立性 | 郡守县令直接对中央负责 |
| 经济基础 | 井田制 | 土地私有 |
| 选错信号 | 题干出现"世袭""诸侯""拱卫王室" | 题干出现"任免""考核""上计" |

### 2. 君主专制 vs 中央集权

这两个词常被当成同义词，实际管的是两件事：
- **君主专制**：皇权与相权的关系，权力向皇帝集中（如废丞相、设军机处）。
- **中央集权**：中央与地方的关系，权力向中央集中（如郡县制、推恩令、行省制）。

**判断口诀：** 题干在说"谁说了算"——皇帝还是宰相 → 君主专制；在说"谁管地方"——中央还是地方 → 中央集权。

### 3. 内阁 vs 军机处

| | 明朝内阁 | 清朝军机处 |
|---|---|---|
| 性质 | 皇帝的顾问侍从机构 | 皇帝的秘书班子 |
| 权力 | 有"票拟"权，无决策权 | 跪受笔录，无决策权 |
| 共同点 | 都不是法定中央一级行政机构，都是皇权强化的产物 |

### 4. 三公九卿 vs 三省六部

- 三公九卿（秦）：**一个丞相**总揽行政，皇权与相权矛盾尖锐。
- 三省六部（唐）：**相权一分为三**，互相牵制，皇权相对稳固。这是"分散相权"的典型设计。

### 5. 察举制 vs 九品中正制 vs 科举制

| | 标准 | 主导者 | 主要问题 |
|---|---|---|---|
| 察举 | 德行（孝廉） | 地方长官推荐 | 易被地方豪强把持 |
| 九品中正 | 门第 | 中正官 | "上品无寒门"，士族垄断 |
| 科举 | 考试成绩 | 中央 | 明清八股化后束缚思想 |

## 二、经济类

### 6. 井田制 vs 均田制

- 井田制：**奴隶制**土地国有，土地不得买卖，春秋战国瓦解。
- 均田制：**封建**国家把国有土地分配给农民耕种，隋唐实行，安史之乱后瓦解。

### 7. 租庸调制 vs 两税法

| | 租庸调（唐前期） | 两税法（唐后期） |
|---|---|---|
| 征税标准 | 人丁为主 | 资产为主 |
| 时间 | 一年一次 | 夏、秋两次 |
| 意义 | 保障农民生产时间 | 中国古代赋税制度的重大转折 |

### 8. 一条鞭法 vs 摊丁入亩

- 一条鞭法（明）：赋役合并，**折银征收**。
- 摊丁入亩（清）：把丁税摊入田赋，**废除了人头税**，国家对人身控制进一步松弛。

### 9. 自然经济 vs 商品经济

- 自然经济：自给自足，生产主要为满足自身需要。**近代"自然经济解体"指耕织分离、农产品商品化。**
- 商品经济：为交换而生产。宋代"商业革命"、明清"商品经济繁荣"都是这个层面。

### 10. 民族资本 vs 官僚资本 vs 外国资本

| | 主体 | 近代命运 |
|---|---|---|
| 民族资本 | 民间私人投资 | 受双重挤压，"短暂春天"后萎缩 |
| 官僚资本 | 国家政权控制 | 抗战后膨胀，成为革命对象 |
| 外国资本 | 列强在华企业 | 随不平等条约扩张 |

## 三、世界史类

### 11. 城邦 vs 帝国

- 城邦：小国寡民，公民直接参与政治（雅典）。
- 帝国：跨地域统治，靠官僚、军队、法律整合（罗马）。

### 12. 共和制 vs 民主制

- 共和制强调**权力制衡与法治**、元首由选举产生（罗马共和国、美国）。
- 民主制强调**主权在民**与多数决定（雅典公民大会）。
- 美国是"共和国"，不是"民主制"的简单同义词；答题时按教材表述。

### 13. 君主立宪 vs 民主共和

| | 君主立宪（英国） | 民主共和（美国、法国） |
|---|---|---|
| 国家元首 | 世袭君主，统而不治 | 选举产生，有任期 |
| 权力中心 | 议会 | 总统或议会 |

### 14. 文艺复兴 vs 启蒙运动

| | 文艺复兴（14—17 世纪） | 启蒙运动（17—18 世纪） |
|---|---|---|
| 批判对象 | 教会神学对人的束缚 | 封建专制制度与特权 |
| 核心主张 | 人文主义，肯定人的价值 | 理性、天赋人权、社会契约、三权分立 |
| 斗争形式 | 借古典文化外衣 | 直接提出制度构想 |

### 15. 新航路开辟 vs 工业革命

- 新航路：**空间**上的世界连成一体，商业革命与价格革命。
- 工业革命：**生产方式**上的机器化，世界市场最终形成。

### 16. 冷战 vs 热战

- 冷战：政治、经济、军事、意识形态的全面对抗，**未直接交战**（杜鲁门主义、马歇尔计划、北约华约）。
- 热战：局部战争（朝鲜战争、越南战争），是冷战的"代理人"表现。

### 17. 经济全球化 vs 区域集团化

- 全球化：全球范围的市场与规则一体化（WTO）。
- 区域集团化：区域内国家先行一体化（欧盟、北美自贸区）。**两者并行不悖，区域集团化常被视为全球化的阶段或对冲。**

## 四、史学方法类

### 18. 史实 vs 史论

- 史实：发生过什么（"1842 年签订《南京条约》"）。
- 史论：怎么评价（"中国开始沦为半殖民地半封建社会"）。
- **答案里出现"这说明""反映了"之后的内容，就是史论。** 材料题要求"根据材料说明"，必须有史实支撑史论，不能只给其中一半。

### 19. 一手史料 vs 二手史料

- 一手：当事人、当时人留下的（档案、日记、器物、当时报刊）。
- 二手：后人研究（教科书、论文、通史著作）。
- **一手不等于可信**：日记会自我美化，档案会有选择性记录。价值高不等于结论真。

### 20. 史料价值 vs 史料局限

答"史料价值"题的标准动作：**说清它能证明什么 + 它不能证明什么**。只说"是研究该问题的重要资料"是空话，不给分。
