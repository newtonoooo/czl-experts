# 世界史年代骨架（含中外对照）

用途：W2 建"中外同期表"、W3 判断材料的世界史背景。
**分期口径说明：** 世界史三分法（古代／中古／近代）各版本表述略有差异，本表按高中统编教材《中外历史纲要（下）》的单元标题口径处理；学生教材不同时以教材为准。

## 一、世界史节点

| 时间 | 事件 | 一句话意义 |
|---|---|---|
| 前 8—前 6 世纪 | 希腊城邦兴起 | 小国寡民、公民政治，雅典与斯巴达两种典型 |
| 前 509 | 罗马共和国建立 | 贵族与平民博弈，共和制度成型 |
| 前 5 世纪中期 | 雅典民主政治高峰 | 公民大会、抽签、津贴制 |
| 前 334—前 323 | 亚历山大东征 | 希腊化时代，欧亚非文化交汇 |
| 前 27 | 罗马帝国建立 | 由共和走向帝制，地中海成为"内海" |
| 395 | 罗马帝国分裂 | 东西两部分分立 |
| 476 | 西罗马帝国灭亡 | 教材分期中"古代"与"中古"的分界 |
| 622 | 伊斯兰教纪元开始 | 阿拉伯半岛统一进程加速 |
| 800 | 查理曼加冕 | 西欧封建王权与教会结合 |
| 1054 | 基督教会分裂 | 东西教会分立 |
| 1215 | 英国《大宪章》 | 以文件限制王权的早期实践 |
| 1453 | 拜占庭帝国灭亡 | 奥斯曼帝国控制东西商路，间接推动新航路探索 |
| 1492 | 哥伦布到达美洲 | 全球联系开始建立 |
| 1497—1498 | 达伽马到达印度 | 绕开地中海的新商路开通 |
| 1517 | 马丁·路德宗教改革 | 打破教会的精神垄断，民族语言与民族国家兴起 |
| 1519—1522 | 麦哲伦船队环球航行 | 地圆说得到实践证明，世界市场雏形出现 |
| 1588 | 英国击败西班牙"无敌舰队" | 海上力量格局转换 |
| 1640 | 英国革命开始 | 1688 光荣革命，1689《权利法案》确立君主立宪 |
| 1775—1783 | 美国独立战争 | 1776《独立宣言》，1787 宪法确立联邦制与三权分立 |
| 1789 | 法国大革命 | 《人权宣言》，摧毁封建等级制度 |
| 18 世纪 60 年代起 | 工业革命（始于英国） | 机器生产取代手工劳动，工厂制度确立 |
| 1848 | 《共产党宣言》发表 | 马克思主义诞生 |
| 1861 | 俄国农奴制改革；美国内战爆发 | 两国以不同方式扫除资本主义发展障碍 |
| 1868 | 明治维新 | 日本走上资本主义道路，同时保留大量封建残余 |
| 1871 | 德意志统一；巴黎公社 | 民族国家体系成形；无产阶级专政第一次尝试 |
| 1914—1918 | 第一次世界大战 | 欧洲优势地位动摇 |
| 1917 | 俄国十月革命 | 第一个社会主义国家建立 |
| 1919 | 巴黎和会与《凡尔赛条约》 | 凡尔赛—华盛顿体系建立 |
| 1929—1933 | 资本主义世界经济大危机 | 自由放任政策失灵 |
| 1933 | 罗斯福新政；希特勒上台 | 国家干预与法西斯化两条道路 |
| 1939—1945 | 第二次世界大战 | 雅尔塔体系取代凡尔赛体系 |
| 1945 | 联合国成立 | 战后国际组织体系建立 |
| 1947 | 杜鲁门主义、马歇尔计划 | 冷战全面展开 |
| 1949 / 1955 | 北约成立 / 华约成立 | 两大军事集团对峙，两极格局定型 |
| 1961 | 不结盟运动兴起 | 第三世界作为独立力量登上舞台 |
| 1991 | 苏联解体 | 两极格局终结，多极化趋势加强 |
| 1993 | 欧洲联盟成立 | 区域一体化深化 |
| 1995 | 世界贸易组织成立 | 全球贸易规则制度化 |

## 二、中外同期对照表（按世纪，不按朝代）

| 世纪 | 中国 | 世界 | 对照机制（不写"都很繁荣"） |
|---|---|---|---|
| 前 3 世纪末 | 秦建立中央集权体制 | 罗马向地中海扩张 | 都在做大空间整合，一个靠郡县官僚，一个靠军事与法律 |
| 1—2 世纪 | 东汉；儒学官方化 | 罗马帝国鼎盛；基督教传播 | 都以意识形态支撑大一统，路径不同 |
| 7—8 世纪 | 隋唐制度创新（三省六部、科举） | 阿拉伯帝国扩张；西欧封建化 | 一个靠考试选官，一个靠土地分封 |
| 11—12 世纪 | 宋代商品经济与市民文化 | 西欧城市兴起、大学出现 | 商业复兴同时发生，政治结构完全不同 |
| 14—16 世纪 | 明清强化专制、郑和下西洋 | 文艺复兴、新航路开辟 | 远洋能力都在，动机与结果分岔 |
| 17—18 世纪 | 明清鼎盛与闭关 | 英国革命、启蒙运动、工业革命前夜 | 一个固守农本，一个转向市场与技术 |
| 19 世纪中期 | 鸦片战争后的被动开放 | 工业革命扩散、资本主义世界市场形成 | 同一套世界市场，被动与主动两种接入方式 |
| 19 世纪末 | 甲午战败、维新变法 | 第二次工业革命、帝国主义瓜分世界 | 中国成为被瓜分对象 |
| 20 世纪上半叶 | 辛亥革命、新民主主义革命 | 一战、十月革命、大危机、二战 | 战争与革命互为背景 |
| 20 世纪下半叶 | 新中国成立、改革开放 | 冷战、殖民体系瓦解、全球化 | 中国从被隔离到深度参与 |

## 三、世界史分期争议处理

| 争议点 | 处理方式 |
|---|---|
| "中古"起止 | 教材以 476 年西罗马灭亡为起点，终于 15 世纪末；部分教材以 1453 年为节点 |
| "近代"起止 | 教材以新航路开辟为起点，终于 1917 年或 20 世纪初 |
| "现代"起点 | 教材以 1917 年十月革命为界 |
| 英国革命与"资产阶级革命"提法 | 教材用"英国资产阶级革命"；学术表述有差异，答题用教材口径 |

遇学生教材表述不同：先按教材，再补一句"另一种分期把某年作为节点"，不否定教材。
