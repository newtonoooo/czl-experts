# 阶段特征五维表

用途：W2 填表、W4 论述题史实支架、W5 判"时期错位"。
填表铁律：**每一格必须出现专有名词**。出现不了，说明这一维是空的，不是"理解了"。

## 一、中国古代

### 先秦（约前 2070—前 221）

| 维度 | 特征 |
|---|---|
| 政治 | 夏商王位世袭；西周分封制与宗法制互为表里；春秋战国礼崩乐坏，郡县制与官僚制在各国变法中出现 |
| 经济 | 井田制瓦解，土地私有确立；铁犁牛耕推广；工商食官被打破，私营工商业兴起 |
| 思想文化 | 商周甲骨文与青铜礼器；春秋战国百家争鸣（儒、道、墨、法），私学兴起 |
| 社会 | 士阶层崛起；宗法血缘纽带松弛；编户齐民雏形出现 |
| 对外与民族 | 华夏认同形成，"华夷"观念出现；周边戎狄蛮夷与中原互动交融 |

### 秦汉（前 221—220）

| 维度 | 特征 |
|---|---|
| 政治 | 皇帝制、三公九卿、郡县制；汉初郡国并行，后推恩令、刺史制度；中外朝削弱相权 |
| 经济 | 重农抑商；盐铁官营；均输平准；丝绸之路开通；田庄经济发展 |
| 思想文化 | 秦焚书坑儒；汉初黄老无为；汉武帝尊崇儒术，儒学成为正统；造纸术改进 |
| 社会 | 编户齐民；察举制选官；豪强地主势力成长 |
| 对外与民族 | 张骞通西域、设西域都护；北击匈奴；西南夷与百越纳入治理 |

### 魏晋南北朝（220—589）

| 维度 | 特征 |
|---|---|
| 政治 | 政权更迭频繁；九品中正制；士族门阀政治；北魏孝文帝改革 |
| 经济 | 北方战乱、人口南迁；江南开发；寺院经济与庄园经济并存 |
| 思想文化 | 佛教传入并本土化，道教兴起，三教并行；书法绘画自觉；《齐民要术》 |
| 社会 | 民族交融高潮；士族与庶族分野；户籍与赋役制度调整 |
| 对外与民族 | 北方民族内迁与汉化；佛教东传路线（西域—中原） |

### 隋唐（581—907）

| 维度 | 特征 |
|---|---|
| 政治 | 三省六部制成熟；科举制创立并发展；道、州、县三级；安史之乱后藩镇割据 |
| 经济 | 均田制与租庸调制，后改两税法；大运河沟通南北；坊市制；经济重心开始南移 |
| 思想文化 | 三教合一趋势；唐诗；雕版印刷；科举推动文化下移 |
| 社会 | 门阀衰落、庶族上升；城市生活丰富；胡风盛行 |
| 对外与民族 | 开放包容；遣唐使、玄奘西行、鉴真东渡；设都护府管理边疆 |

### 宋元（960—1368）

| 维度 | 特征 |
|---|---|
| 政治 | 宋：二府三司、通判、转运使，强干弱枝；元：行省制、宣政院，中央集权新形态 |
| 经济 | 商品经济繁荣；交子；市镇兴起；经济重心南移完成；海外贸易兴盛（市舶司） |
| 思想文化 | 理学形成并成为官方哲学；词、话本、元曲；活字印刷、指南针、火药外传 |
| 社会 | 市民阶层壮大；租佃关系普遍；四等人制（元） |
| 对外与民族 | 宋辽夏金并立；元统一后欧亚交通畅达；民族交融与回族形成 |

### 明清（1368—1840）

| 维度 | 特征 |
|---|---|
| 政治 | 明废丞相设内阁；清设军机处；密折制度；君主专制空前强化 |
| 经济 | 一条鞭法、摊丁入亩；高产作物传入；白银货币化；江南手工业出现雇佣关系 |
| 思想文化 | 八股取士；理学僵化；明末清初进步思想（黄宗羲、顾炎武、王夫之）；小说戏曲繁荣 |
| 社会 | 人口激增；宗族与乡绅治理；社会流动渠道收窄 |
| 对外与民族 | 郑和下西洋后转向海禁；统一多民族国家巩固（平定准噶尔、设驻藏大臣、改土归流）；闭关自守 |

## 二、中国近现代

### 晚清（1840—1912）

| 维度 | 特征 |
|---|---|
| 政治 | 主权逐步丧失；总理衙门设立；清末新政与预备立宪；革命派兴起 |
| 经济 | 自然经济开始解体；洋务企业与民族资本主义产生；通商口岸经济 |
| 思想文化 | 师夷长技—中体西用—维新变法—民主共和，层层递进；新式学堂与报刊 |
| 社会 | 社会结构分化；沿海与内地差距拉大；妇女缠足等旧俗受冲击 |
| 对外与民族 | 从朝贡体系被卷入条约体系；边疆危机（西北、西南、东南） |

### 民国（1912—1949）

| 维度 | 特征 |
|---|---|
| 政治 | 共和政体建立但有名无实；北洋军阀统治；国民政府形式统一；中共开辟革命新道路 |
| 经济 | 民族工业"短暂的春天"；官僚资本膨胀；农村经济凋敝 |
| 思想文化 | 新文化运动；马克思主义传播；三民主义发展；平民教育实验 |
| 社会 | 城市化与人口流动；战时人口大迁移；社会风俗变革 |
| 对外与民族 | 废除不平等条约的努力；抗日战争；战后国际地位提升 |

### 新中国（1949 至今）

| 维度 | 特征 |
|---|---|
| 政治 | 人民代表大会制度、中共领导的多党合作和政治协商制度、民族区域自治制度；社会主义民主法制曲折发展 |
| 经济 | 土地改革—三大改造—计划经济—改革开放—社会主义市场经济；工业化体系建立 |
| 思想文化 | 马克思主义指导地位确立；"双百"方针；科技（两弹一星、载人航天、杂交水稻） |
| 社会 | 社会保障体系建立；脱贫攻坚；城镇化 |
| 对外与民族 | 独立自主和平外交；和平共处五项原则；恢复联合国合法席位；一带一路；民族区域自治 |

## 三、世界史

### 古代希腊罗马

| 维度 | 特征 |
|---|---|
| 政治 | 雅典公民政治（公民大会、抽签、津贴）；罗马共和国（元老院、执政官）到帝国 |

| 维度 | 特征 |

| 维度 | 特征 |

## 四、怎么用这张表

1. **不要整表背。** 先挑当前要考的一段，只填这一段的五维。
2. **填完做减法。** 五格里哪一格写不出专有名词，就是这一段的缺口。
3. **对照着看。** 同一行放中国和世界，才能答出"同期比较"类设问。
4. **论述题取支架。** 写小论文时，从"政治＋经济"各取一条史实，比堆四条政治史实更能得分。
