# 资料包说明

## 包里有什么

| 文件 | 内容 | 生成方式 |
|---|---|---|
| `knowledge-map.md` | 15 个模块的知识树、分值权重经验值、年级进度对照 | 按课标模块结构自行编写 |
| `formula-sheet.md` | 8 类公式速查，含适用条件与易错提示 | 自行选编整理 |
| `method-cards.md` | 14 张方法卡（信号 / 动作 / 坑 / 一句话记法） | 原创 |
| `error-taxonomy.md` | C/M/A/W/R 五码的判据、例子、训练、验收 | 原创 |
| `exam-blueprint.md` | 19 题卷面结构、时间分配、得分倒推、时间黑洞 | 依据公开卷面结构自行整理 |
| `parent-guide.md` | 家长陪读手册（可做 / 不可做 / 话术 / 判断补课） | 原创 |

## 包里**故意没有**什么，以及为什么

| 没有收录 | 原因 |
|---|---|
| 教材原文、教材例题、教材习题 | 教材享有著作权，商业分发需要授权。本项目未取得授权，因此不收录 |
| 高考真题原文与官方答案 | 试题与答案的著作权归属需逐项核实，商业再分发存在风险，不收录 |
| 各类教辅、模拟卷、押题卷 | 同上，且质量与版权均不可控 |
| 名师课程讲义、机构内部资料 | 权利状态不明，不收录 |

**所以这个资料包里的每一段文字，都是为这个产品新写的。** 它不依赖任何教材的表述，也不复制任何试卷的内容。

需要真题怎么办：让学生用学校发的卷子，把错题按 `error-taxonomy.md` 的编码记进台账。真题目的是取样，不是收藏，学生手上的卷子已经够用。

## 引用与依据

- **模块结构**：依据《普通高中数学课程标准（2017 年版 2020 年修订）》的模块划分。该文件属于国家机关具有行政性质的文件，不在著作权保护范围内，本包引用的是其**模块名称与顺序**这一事实性信息，未复制正文表述。
- **卷面结构**：依据 2024 年起公开使用的新高考 19 题卷型（8 单选 + 3 多选 + 3 填空 + 5 解答，150 分）。各地、各年可能调整，正式备考以当年省级考试院文件为准。
- **公式**：数学公式属于客观事实，不受著作权保护；本包的**选编范围、条件标注、易错提示**为自行整理。
- **其余内容**：均为本项目原创，作者虫志龙。

## 使用建议

1. **先看 `error-taxonomy.md`。** 不懂五个码，后面所有工具都用不对。
2. 讲题时点名 `method-cards.md` 的卡号，比说"用导数做"有效。
3. 每两周用 `exam-blueprint.md` 的得分倒推表校准一次目标。
4. `parent-guide.md` 是给家长看的，不要给孩子看——里面的话术是给大人的。

## 维护

资料包随专家版本更新。修改任一文件后，请同步更新 `docs/文件清单.md` 的文件指纹，并跑一次 `python tools/check_package.py`。
