# 高中数学知识树（按课标模块整理）

> 用途：诊断时定位知识点归属、出题时核对是否超纲、跟家长解释"这一段在整张地图的哪个位置"。
> 说明：结构依据《普通高中数学课程标准（2017 年版 2020 年修订）》的模块划分，节点说明为本项目自行整理，不引用任何教材原文。

## 一、必修（高一上下学期）

### 1. 集合与常用逻辑用语

- 集合的表示与关系：列举法、描述法、子集、真子集、交集、并集、补集
- 充要条件：充分不必要、必要不充分、充要、既不充分也不必要
- 量词：全称量词与存在量词，命题的否定（"任意"↔"存在"，结论取反）

**诊断位置**：这部分失分通常表现为 C 码（把"充要"方向搞反），一般不影响后续，但会拖累所有"恒成立/存在"题。

### 2. 一元二次函数、方程和不等式

- 二次函数的三种形式与图像
- 一元二次不等式的解法（图像法、根分布）
- 基本不等式 $a+b\ge 2\sqrt{ab}\ (a,b>0)$ 及取等条件
- 分式不等式、绝对值不等式

**诊断位置**：这是导数压轴题的最后一步。很多"导数不会"其实是"二次不等式解错"。

### 3. 函数的概念与性质

- 定义域、值域、对应关系；分段函数
- 单调性、奇偶性、周期性、对称性
- 幂函数、指数函数、对数函数、对勾函数 $y=x+\frac ax$
- 函数图像变换：平移、伸缩、对称、绝对值

**诊断位置**：M 码高发区。学生能背性质，但不会"由 $f(x+1)$ 是偶函数推出对称轴"。

### 4. 三角函数

- 弧度制、任意角、三角函数定义
- 诱导公式（奇变偶不变，符号看象限）
- 图像与性质：周期、单调区间、对称中心/轴
- 恒等变换：和差角、二倍角、降幂、辅助角
- 函数 $y=A\sin(\omega x+\varphi)+k$ 的图像与参数意义

**诊断位置**：W 码高发（写单调区间不写 $k\in\mathbb{Z}$）。

### 5. 平面向量与复数

- 向量的线性运算、坐标运算、数量积、夹角、投影
- 向量的应用：证明平行垂直、求长度与角度
- 复数：代数形式、四则运算、共轭、模、几何意义

**诊断位置**：数量积符号与夹角范围（$\theta\in[0,\pi]$）是常见 C 码。

### 6. 立体几何初步

- 基本图形与三视图（部分省份已淡化）
- 点线面位置关系：平行、垂直的判定与性质
- 空间角与距离的初步认识
- 表面积与体积

**诊断位置**：证明题"跳步"多为 W 码（不写"因为…所以…"的定理名）。

### 7. 统计与概率（必修部分）

- 抽样方法、频率分布直方图、样本数字特征
- 古典概型、事件的关系与运算、互斥与对立

## 二、选择性必修

### 8. 空间向量与立体几何

- 空间直角坐标系、向量坐标运算
- 法向量的求法（解方程组取一组解）
- 线面角（用 $\sin$）、二面角（用 $\cos$ 并判钝锐）、点到面的距离

**诊断位置**：建系错误（三条轴不两两垂直）是最常见的"全盘皆错"起点。

### 9. 直线和圆的方程

- 直线：斜率、倾斜角、五种方程、平行垂直条件、点到直线距离
- 圆：标准方程、一般方程、直线与圆位置关系、弦长、切线

### 10. 圆锥曲线的方程

- 椭圆、双曲线、抛物线的定义、标准方程、几何性质
- 离心率、焦点三角形、焦半径、通径
- 直线与圆锥曲线：联立、韦达定理、弦长、面积、定点定值

**诊断位置**：压轴主战场。$\Delta\ge0$ 漏写、斜率不存在漏讨论，是两大固定失分点。

### 11. 数列

- 等差、等比数列的通项与求和
- 递推数列：累加、累乘、构造（$a_{n+1}=pa_n+q$）、$a_n=S_n-S_{n-1}$
- 求和方法：错位相减、裂项相消、分组求和、倒序相加
- 数列不等式：放缩后求和、数学归纳

### 12. 一元函数的导数及其应用

- 导数定义与几何意义（切线）
- 求导公式与法则（含复合函数）
- 单调性、极值、最值
- 导数与不等式：恒成立、证明不等式、零点问题
- 四类破题思路：隐零点、放缩、端点效应、同构

### 13. 计数原理

- 分类加法、分步乘法
- 排列组合：特殊元素优先、捆绑、插空、隔板
- 二项式定理：通项、系数与二项式系数

### 14. 随机变量及其分布

- 条件概率、全概率、独立性
- 二项分布、超几何分布、正态分布
- 分布列、期望、方差

### 15. 成对数据的统计分析

- 相关系数、回归方程（最小二乘）
- 独立性检验（$K^2$ 与临界值）

## 三、模块分值权重（近三年新高考Ⅰ卷的经验观察，非官方承诺）

| 模块 | 大致分值 | 备注 |
|---|---|---|
| 函数与导数 | 30–40 | 占比最高，且常出现在压轴位置 |
| 解析几何 | 22–27 | 一道大题 + 2–3 道选填 |
| 立体几何 | 17–22 | 一道大题 + 1–2 道选填 |
| 概率统计 | 17–22 | 情境题为主，阅读量大 |
| 数列 | 10–17 | 位置不固定，可能压轴 |
| 三角 | 10–15 | 常与解三角形合并 |
| 集合/复数/向量/不等式 | 15–20 | 基础分，必须全拿 |

> 这张表只用来决定复习优先级，不用来押题。考点顺序近两年被有意打散，按位置猜题会失手。

## 四、按年级的进度对照（人教 A 版常见进度，各校有差异）

| 学期 | 主要内容 |
|---|---|
| 高一上 | 集合与逻辑、不等式、函数性质、指数对数、三角函数 |
| 高一下 | 平面向量、复数、立体几何初步、统计概率 |
| 高二上 | 空间向量、直线与圆、圆锥曲线 |
| 高二下 | 数列、导数、计数原理、随机变量、统计案例 |
| 高三 | 一轮按模块、二轮按专题、三轮按套卷 |

**用法**：家长说"孩子高一"，就不要拿导数压轴题当例子；学生说"还没学导数"，诊断表里导数相关题目一律标注"未学，不计入断点"。
