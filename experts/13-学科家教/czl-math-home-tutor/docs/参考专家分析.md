# 参考专家分析与差异化定位

> 说明：本文件只做**功能层面的研究**，用于确立"要做什么、不要做什么"。文中不摘录参考专家的提示词原文，也不把其表述当作本产品的实现依据。参考对象为本地已安装的公开专家包，仅作能力范围与交互形态的对照。

## 一、参考对象的客观构成

| 项目 | 观察结果 |
|---|---|
| 包结构 | `.codebuddy-plugin/plugin.json` + `agents/<name>.md` + `avatars/expert.png` + `README.md` |
| 类型 | Agent 型（单专家），分类 `15-Education` |
| 提示词体量 | 单文件，按"覆盖内容 → 题型手册 → 工作流程 → 输出铁律"组织 |
| 附件 | 无脚本、无模板、无参考资料目录 |
| 头像 | 512×512 PNG，395 KB |

**结构结论**：这是一个"纯提示词"专家——全部能力压在一个 MD 里，没有可执行件、没有持久化、没有跨会话状态。

## 二、它做得好的地方（值得继承的经验）

1. **单文件即可用**：没有安装依赖，导入就能跑。这对分发极友好，本产品保留"无依赖可运行"这条底线。
2. **按模块给入口**：把内容按函数导数/三角/数列/立几/解几/概率分块，每块给典型方法。这是最符合学生查书习惯的组织方式。
3. **输出有硬格式**：要求先审题、再讲思路、再规范求解、再检验、再留自练。这套顺序本身是对的，本产品在"拆解"环节保留了"检验"和"留变式"两个动作。
4. **明确不代写作业**：边界清楚，减少误用。

## 三、它没有解决的四件事（本产品的切入点）

| 缺口 | 具体表现 | 后果 | 本产品的处理 |
|---|---|---|---|
| **没有定位手段** | 提示词按题型组织，但没有"怎么判断这个学生卡在哪"的流程 | 学生问"我 90 分怎么办"，只能得到一份通用建议 | 建 C/M/A/W/R 五码 + 断点排序 + 每条断点配动作与验收 |
| **没有持久化** | 无台账、无记录，每次对话从零开始 | "讲过的又错"无法被系统发现 | 错题台账 CSV + 1/3/7/21/45 天复现 + 周报 |
| **没有迁移设计** | 给"同类题"，但同类到什么程度没定义 | 学生练了 20 道同型题，换问法仍然不会 | 同型/换皮/换轴三档，明确"只有换轴预测考场表现" |
| **没有取舍策略** | 只有"怎么解"，没有"什么时候不该解" | 考场时间不够，会做的题没时间做 | 目标分倒推 + 每题时间上限 + 放弃线 |

另外两处可改进：

- **只有学生视角**。家长问"我怎么帮他"，得到的是学生版讲解。本产品分成学生通道与家长通道，家长版给话术与禁做清单。
- **全是文本，没有可执行件**。诊断排序、排期、时间分配都是可以算的，靠语言描述容易含糊。本产品把它们做成脚本，输出可打印的表格。

## 四、本产品的定位差异（一句话）

> 参考对象回答"这道题怎么做"；本产品回答"**这个孩子卡在哪、下一步练什么、什么时候该放弃**"。

| 维度 | 参考对象 | 本产品 |
|---|---|---|
| 组织轴 | 按题型（知识点） | 按流程（定位→拆解→训练→复盘） |
| 核心资产 | 题型方法手册 | 错因编码 + 四环流程 + 五个可执行脚本 |
| 状态 | 无状态 | 台账持久化，跨会话 |
| 对象 | 学生 | 学生 + 家长双通道 |
| 判据 | 讲得清不清楚 | 每份交付物是否带"下一步动作 + 时长 + 验收标准" |
| 附件 | 无 | 7 份资料 + 5 套模板 + 7 个脚本 |

**重叠部分**：知识点覆盖范围必然重叠（同一份课标），方法本身也是公共知识。差异不在"讲什么知识"，在"用什么流程讲、讲完留下什么"。

## 五、命名与查重

### 命名方案

| 字段 | 取值 |
|---|---|
| 包名 `name` | `czl-math-home-tutor`（czl- 前缀 + 功能名，kebab-case） |
| 目录名 | 与 `name` 完全一致 |
| Agent 文件名 | `czl-math-home-tutor.md`，与 `agentName` 一致 |
| 花名 `displayName.zh` | 陆九章 |
| 职业头衔 `profession.zh` | 卓识教育-高中数学学习辅导专家 |
| 英文名 | Lu Jiuzhang / Zhuoshi Education - Senior High Math Learning Coaching Expert |

**命名理由**
- `czl-` 前缀满足开发者标识要求，且与本机已有的 30 个 `czl-*` 专家形成同一产品线。
- `math-home-tutor` 与已有的 `czl-chinese-home-tutor`（语文家教）平行，语义清楚，不撞车。
- 头衔采用"品牌字号 + 学段学科 + 职能"结构：**卓识教育-高中数学学习辅导专家**。三段各管一件事——谁出品、教什么学段什么学科、做什么。对标参考对象的"老吴私塾·高中数学家教"是同一句式，但字号、学段措辞（学习辅导 vs 家教）、职能落点（专家 vs 家教）都不同。
- 花名"陆九章"取《九章算术》之"九章"，是数学意象，且为虚构人物，不对应任何真实教师。花名与头衔分工：头衔是产品定位，花名是这位老师的名字。

**改名记录**（两次，同一天）
1. v1.0.1：由"明算堂—高中数学家庭辅导"改为"智源研究院·高中数学学习辅导专家"。
2. v1.0.2：改为现名"卓识教育-高中数学学习辅导专家"。原因见下。

**为什么第二次要改**：`智源研究院` 是国内真实机构（北京智源人工智能研究院，BAAI）的常用简称。无授权使用会构成"虚构机构关联"，这不是商标近似问题，而是一眼可辨的身份冒用，风险等级高于普通重名。现名"卓识教育"是教育品牌字号，不指向任何具体机构，风险性质回到"可能与既有商标近似"，属于任何新品牌都要面对的常规问题。

### 查重结果

在本地已安装的 65 个专家 + `my-experts` 下本地专家中检索：

| 检查项 | 结果 |
|---|---|
| 包名 `czl-math-home-tutor` | 无重复 |
| 花名"陆九章" | 无重复 |
| 头衔"卓识教育-高中数学学习辅导专家" | 本地专家库无重复（**未做商标与全网检索，见风险清单 2.1**） |
| 近似名对照 | `math-mistake-coach`（数学错题陪练师）、`senior-math-tutor`（老吴私塾·高中数学家教）、`senior-english-tutor`（老吴私塾·高中英语家教）、`czl-chinese-home-tutor`（语文家教）——句式相近但名称不冲突 |

### 字符合规

原定要求：仅中英文、数字、`-`、`—`，不含空格与特殊符号。

| 字符串 | 组成 | 结论 |
|---|---|---|
| `卓识教育-高中数学学习辅导专家` | 中文 + 一个 `-`（U+002D 半角连字符） | 完全在字符集内，**无例外、无兼容说明** |
| `陆九章` | 纯中文 | 合规 |

上一版用的 `·`（U+00B7）虽然市场里同类专家也在用，但严格说超出字符集。改回 `-` 后这个隐患消除，上架表单不会因字符被拒。
