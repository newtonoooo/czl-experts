# 使用说明

## 一、装

### 方式 A：脚本安装（推荐）

```bash
cd czl-math-home-tutor
python tools/install.py
```

脚本会做三件事：复制到 `%USERPROFILE%\.workbuddy\plugins\marketplaces\my-experts\plugins\czl-math-home-tutor\`、写入 `marketplace.json`、回读并打印解析后的头像地址。

装完**退出 WorkBuddy 进程再打开**（不是关窗口），然后在「专家中心 → 我的专家」里找「陆九章」。

### 方式 B：平台导入

用 `dist/czl-math-home-tutor-1.0.0.zip` 走平台的导入功能。

> 导入后头像若显示成"陆"字，看 `docs/头像显示异常排查.md`，按第五节的六步查。

### 方式 C：手工

把整个 `czl-math-home-tutor` 目录放进 `%USERPROFILE%\.workbuddy\plugins\marketplaces\my-experts\plugins\`，然后在 `my-experts\.codebuddy-plugin\marketplace.json` 的 `plugins` 数组里加一条：

```json
{ "name": "czl-math-home-tutor", "source": "./plugins/czl-math-home-tutor",
  "description": "...", "version": "1.0.0" }
```

## 二、第一次对话怎么开始

不用背提示词，说清楚三件事就够：**年级 + 现在多少分 + 手上有什么**。

```
高二，月考 92 分，卷子在手上，导数大题和圆锥曲线基本空着
```

它不会立刻讲题，会先问几个问题定位。**这是设计如此**——没有定位就给方案，只能给通用建议。

## 三、五个典型用法

### 1. 考完试当晚：定位

```
孩子高二，这次月考 92，我把错的题号报给你：3、7、10、11、14、18、19
（或者直接拍卷子）
```

产出：断点排序表 + 错因码 + 每条断点的处方（含时长）+ 下次验收标准。

**你要做的一件事**：只看"这周只做三件事"那一节，其余先不看。

### 2. 一道题卡住：拆解

```
这道题孩子没思路：
已知函数 f(x)=e^x-ax 在 (0,+∞) 上单调递增，求 a 的取值范围
```

产出：解题卡七段。重点看【关键一步】和【三验】——这两段是能不能自己做出来的分水岭。

**注意**：一次只问一道。问三道，只会得到三份半懂的讲解。

### 3. 要练：出题

```
导数单调性这类题总错，出几道练练，最多 45 分钟
```

产出：同型/换皮/换轴三档，带答案（答案在最后，防止一眼看到）。

**提醒它**：如果孩子 90 分以下，说一声，它会减少换轴题的比例。

### 4. 错题整理：台账

```
把这周的错题整理成台账，我每周要能看到该复习哪些
```

产出：CSV 文件（Excel 可直接打开）+ 到期清单 + 周报模板。

**关键动作**：到期那天真的让孩子先做一遍再看答案。直接看答案标"会了"，台账就废了。

### 5. 考前两周：取舍

```
还有两周，目标 120，现在大概 95，怎么分配时间
```

产出：分题型得分目标 + 每题时间上限 + 明确的放弃线。

**用法**：打印出来，下次模考就按这个时间走，考完填复盘表。

## 四、家长怎么用（和孩子的用法不一样）

家长开口说"我是家长"或"怎么帮孩子"，它会切到家长通道：给话术、给禁做清单，不给数学推导。

```
我是家长，孩子数学一直 90 分左右，我该怎么帮他
```

会得到三样：孩子卡在哪（带证据）、这周家里做哪三件小事、哪三件事千万别做。

**别做的事**：不要拿家长版的话术去考孩子，那是给大人看的。

## 五、脚本怎么用（可选，不用也能用专家）

| 想做的事 | 命令 |
|---|---|
| 卷面得分 → 断点表 | `python skills/czl-math-diagnose/scripts/diagnose.py 成绩.csv --top 4` |
| 生成空白成绩表 | `python .../diagnose.py --template > 成绩.csv` |
| 验算一个答案 | `python .../verify.py --expr "x^2-3*x+2" --zero 1,2` |
| 单次训练配比 | `python .../drill.py --weak "导数:M,解几:M" --minutes 45` |
| 错题入账 | `python .../ledger.py add --csv 错题.csv --item "导数|M|题面摘要|正确入口"` |
| 今天该复习啥 | `python .../ledger.py due --csv 错题.csv` |
| 考场计划 | `python .../scoreplan.py --target 120 --current "单选=30,多选=9,填空=7,解答=35"` |
| 发布前自检 | `python tools/check_package.py --verbose` |
| 换头像 | `python tools/png_resize.py 原图.png avatars/expert.png --size 512 --palette 256 --expand` |

全部只需要 Python 3.8+，不装任何第三方库。

## 六、常见问题

**问：它会不会直接给答案？**
会给答案，但一定同时给"这一步凭什么"。如果只想要答案，它会说明"这次可以，下次这类题你还是会卡"。

**问：能不能让它一次讲完整张卷子？**
不会。会要求你挑一道最想弄懂的。整卷逐题讲，讲完一道都记不住。

**问：错题台账存哪？**
默认在工作目录下的 CSV，路径由你定。数据不上传，全在本地。

**问：讲的难度对不上孩子怎么办？**
直接说"太难了"或"太简单了"。它会降级或换档。降级表就是为这个准备的。

**问：能替代老师吗？**
不能。它替代的是"没人帮你判断卡在哪"这件事，不替代课堂教学。

## 七、卸载

删掉 `%USERPROFILE%\.workbuddy\plugins\marketplaces\my-experts\plugins\czl-math-home-tutor\` 目录，并从 `marketplace.json` 的 `plugins` 数组里删掉对应那一条。台账 CSV 在工作目录里，不受影响，需要保留就留着。
