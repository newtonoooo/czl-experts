## 一、起点：先看清楚参考对象是什么

只做了功能层面的观察，没有复制任何文件：

| 观察项 | 结果 | 对设计的直接影响 |
|---|---|---|
| 包结构 | plugin.json + 单 agent md + 头像 | 结构沿用平台规范（这是规范，不是某个人的作品） |
| 提示词组织 | 单文件，按"题型手册"分块 | 决定**不按题型组织**，改按四环流程组织 |
| 可执行件 | 无 | 决定必须做脚本，否则"排序/排期/分配"都只能靠嘴说 |
| 状态 | 无持久化 | 决定做台账 + 复现阶梯，这是最大的差异化 |
| 读者 | 只有学生 | 决定做学生/家长双通道 |

**结论**：可以继承的只有两条经验——单文件也能跑（保持零依赖）、输出要有硬格式（保持固定模板）。其余全部重做。

## 三、规格（40 分钟）

写 `docs/产品规格.md`。关键决定：

- 把"定位"放在第一环，而不是"讲题"。这是与参考对象最大的分岔。
- 交付物必须"可打印"：解题卡、诊断表、练习卷、台账、考场计划，全部给模板。
- 输出规范里加一条硬约束：**每条结论必须能指回证据**，指不回去的不许写。

## 四、提示词（核心，90 分钟）

`agents/czl-math-home-tutor.md`，十章：

1. 我做什么/不做什么（含不承诺提分）
2. 四环：定位→拆解→训练→复盘（附"用户给什么就走哪一环"的路由表）
3. 拆题五步：划条件→换说法→挑武器→摆式子→回头验
4. 卡住时的降级表（五档，逐格往下退）
5. 错因五码 C/M/A/W/R（含"主码怎么定"的单一变量法）
6. 双通道：学生版/家长版
7. 输出规范（解题卡、诊断表、台账三张表）+ 三条不许破的规矩
8. 工作流路由表
9. 学段与卷型判断（先问三件事）
10. 不接的活（五类）

**设计取舍**：拆题五步里，"挑武器必须写出淘汰另外两条的理由"和"摆式子要写出缺口"这两条是本产品独有。前者治"考场在错路上走十分钟"，后者治"思路对但不知道难在哪"。

## 五、五个技能

| 技能 | 核心设计 | 对应缺口 |
|---|---|---|
| `czl-math-decompose` | 五步 + 降级表 + 入口对照表（6 模块 × 识别信号/入口/淘汰什么/常见断点） | 讲题没有可复述的结构 |
| `czl-math-diagnose` | 断点按**失分绝对值**排序（不按得分率） | 补错地方 |
| `czl-math-drill` | 三档变式 + 按主码配比 + 硬预算 | 练了不迁移 |
| `czl-math-ledger` | 1/3/7/21/45 阶梯 + 卡三次转概念重讲 | 讲过的又错 |
| `czl-math-examroom` | 目标分倒推 + 每题时间上限 + 放弃线 | 考场不会取舍 |

每个 SKILL.md 都写了八段：职责边界、输入参数、执行步骤、判断条件、输出格式、异常处理、必要依赖、与其他工作流关系。

## 六、脚本开发与真实踩坑记录

全部纯标准库。以下是**实际遇到并修掉**的问题，不是事后补写的清单：

| # | 问题 | 现象 | 修法 |
|---|---|---|---|
| 1 | `verify.py` 负参数解析 | `--on -1,1` 被 argparse 当成选项，报 "expected one argument" | 加 `normalise_argv()`，把 `--on -1,1` 改写成 `--on=-1,1` |
| 2 | `diagnose.py` 性质自相矛盾 | 主码是 M（方法），"性质"却按得分率写成"基础缺口" | 主码存在时由码决定性质（`CODE_LABELS`），码缺失才按得分率 |
| 3 | `diagnose.py` 验收标准太软 | 得分率 18% 的断点，验收写"≥38%" | 改成绝对档位（C/R→60%，M→80%，A/W→90%） |
| 4 | `ledger.py` 主键类型错 | 新加的 id 是 int，`next_id()` 调 `.isdigit()` 崩溃 | 统一存 `str(id)`，读取时 `str()` 兜底 |
| 5 | `drill.py` 超预算 | 计划 45 分钟，实际排了 54 分钟 | 重写 `fit_tiers()`：先按占比取整，再从后往前削，最后用余额补同型题 |
| 6 | `scoreplan.py` 多选时间过高 | 3 道多选分到 20 分钟（6.7 分钟/题） | 调 `TIME_WEIGHT`（多选 1.7→1.25），并加 `SKIP_CAP` 硬上限（多选 5 分钟） |
| 7 | 头像超出体积上限 | 512×512 真彩 PNG 528 KB，超过 500 KB | 加中位切分量化 + 真彩回写（`--palette 256 --expand`），降到 214 KB |

**没有 Pillow 也没有 ImageMagick**，`Add-Type`（System.Drawing）被安全策略禁用，所以手写了 `png_resize.py`：自己解 PNG（IHDR/IDAT、五种滤波器逆变换）、自己做面积平均降采样、自己做中位切分量化、自己写回 PNG。这个工具留下来当发布工具用。

## 十一、留给下一版的事

1. `verify.py` 目前只做数值验证，不能做符号推导（如需，考虑可选依赖 sympy，但要保证无依赖也能降级）。
2. 地方卷型（北京、上海、天津、浙江）的卷面结构还没做进 `--paper` 参数。
3. 台账目前是单文件 CSV，如果条目超过 300 条，`stats` 的排序会变慢（实测 500 条仍在 0.2 秒内，暂不优化）。
4. 家长版话术还没有按学段细分（高一/高二/高三的家长焦虑点不一样）。
