# 训练：三档变式，只练一个动作

## 职责边界

只负责"练什么、练多少、什么时候停"。学生做完错了，进入 `czl-math-ledger`，不在本环节反复讲。

**不做**：不做学情诊断（断点必须来自 `czl-math-diagnose` 或用户明确说出）、不写整卷、不布置超过 45 分钟的作业。

## 输入参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 断点 | 是 | 至少一个知识点 + 错因码。用 `--weak "导数单调性:M,解析几何弦长:M"` |
| 可用时长 | 建议 | 默认 45 分钟。低于 20 分钟只做同型 |
| 教材版本 / 进度 | 可选 | 影响情境题的取材（人教A版/北师大版进度不同） |
| 学生水平 | 可选 | 90 分以下偏同型，110 以上偏换轴 |

**没有断点时怎么办**：不出题。改为先做三问（哪几道空着 / 哪几道写了没算完 / 哪几道以为会却错了），拿到信息再出。

## 执行步骤

### 步骤 1：定配比

跑 `python scripts/drill.py --weak "..." --minutes 45`。配比由主码决定：

| 主码 | 同型:换皮:换轴 | 理由 |
|---|---|---|
| C 概念 | 2:2:1 | 定义没立住，题量再多也是重复错误 |
| M 方法 | 2:2:2 | 缺入口，三档各练一次入口判断 |
| A 运算 | 5:2:1 | 靠量与限时，不靠难度 |
| W 书写 | 3:1:1 | 抄骨架 + 少量完整书写 |
| R 读题 | 3:2:1 | 读题划条件为主，题目本身可以很简单 |

判断条件：两个以上断点时，第一个占 60% 时间，其余只做维持（同型 + 换皮）。**一次只主攻一个**。

### 步骤 2：出题

三档的改动规则，出题时必须逐条对照：

| 档 | 只改什么 | 不许改什么 | 判据 |
|---|---|---|---|
| 同型 | 数字、符号、字母 | 结构、问法、步骤数 | 学生应该"一看就知道怎么做" |
| 换皮 | 情境（几何→应用→表格）、表述 | 解题动作 | 学生需要多读 30 秒才认出来 |
| 换轴 | 问法（求值↔求范围↔证存在↔求参数） | 知识点 | 学生需要自己判断走哪条路 |

判断条件：如果一道"换轴题"学生一看就知道用哪个方法，那它其实是换皮题，退回重出。

### 步骤 3：配答案

每题给三样：考点、改动点、答案。**不给解析**。

判断条件：答案必须自己算过一遍，或者用 `../czl-math-decompose/scripts/verify.py` 验过。算不出就换题，不许给"参考答案略"。

### 步骤 4：写停止条件

三档各有一条停止线，写进交付物：

- 同型连错 2 道 → 停，回拆题（动作没建立）。
- 换皮全对、换轴全错 → 下次时间全给换轴。
- 到时间就停，不管做到第几道。

## 输出格式

用 `templates/practice-set.md`。硬性要求：

1. 题目在上，答案单独放在最后一节，中间用分隔线隔开（防止一眼看到答案）。
2. 每道题标注档位（同型/换皮/换轴），学生知道自己在练什么。
3. 开头写清：本次只练 ____，用时上限 ____ 分钟，做到 ____ 就停。
4. 结尾留一行"做完把错题按格式发我"，格式给出示例。

## 异常处理

| 异常 | 处理 |
|---|---|
| 用户要"多出点" | 拒绝加量，改为"同样的时间，把同型换成换轴"。量不解决问题，档位才解决 |
| 用户要原题（某年高考题） | 不给整卷，但可以给"同知识点同难度的自编题"，并说明为什么不用原题（做过就会，测不出迁移） |
| 学生水平不明 | 按 90–110 分档出题（同型 2 + 换皮 2 + 换轴 1），并在交付物里写明假设 |
| 断点超过 4 个 | 只取失分最多的 2 个，其余记账。四个断点一起练等于没练 |
| 要求出竞赛难度 | 说明超出高中课标常规范围，问清目的（自招/强基）再决定是否接 |

## 必要依赖

- `scripts/drill.py` — 配比与时间盒计算
- `templates/practice-set.md` — 练习卷模板
- `../czl-math-decompose/references/route-table.md` — 出题时确定"这题考哪个入口"
- `materials/knowledge-map.md` — 核对知识点归属，防止超纲

## 与其他工作流的关系

```
diagnose ──断点──▶ drill ──学生做完──▶ ledger
                     │                    │
                     └──错了且想不通──▶ decompose
```

- 上游：断点表。没有断点表就出题 = 猜。
- 下游：做完的错题进 `czl-math-ledger`，由台账安排复现。
- 反向：如果连续两周同一断点的换轴题都错，回 `diagnose` 重定码（大概率 M 被判成了 A）。
