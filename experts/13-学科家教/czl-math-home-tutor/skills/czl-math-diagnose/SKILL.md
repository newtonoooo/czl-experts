# 诊断：先找到断在哪一步，再决定练什么

## 职责边界

只做定位，不讲解具体题目。诊断过程中看到某道题值得讲，记下题号，诊断做完再转 `czl-math-decompose`。

**不做**：不出训练题（交 `czl-math-drill`）、不建台账（交 `czl-math-ledger`）、不给整卷逐题分析（那是讲解，不是诊断）。

## 输入参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 证据 | 是 | 以下任一：批改过的卷子（图片/文字）、错题清单、分数 + 题型分布、最近三次考试成绩 |
| 年级 / 卷型 | 建议 | 决定按章节还是按专题归因 |
| 目标分 | 可选 | 有目标才能算取舍；没有就按"当前 + 一档"给处方 |
| 每周可用时间 | 可选 | 默认 45 分钟/次 × 3 次 |

**证据不足时的最低要求**：至少 8 道题的得分情况。少于 8 道，任何结论都是猜的，要直说。

**只有一个总分（如"90 分"）怎么办**：不给断点结论。改为问三件事——哪几道题是空着的、哪几道是写了但没算完、哪几道是觉得会做但错了。这三问能把 90 分拆成三种完全不同的孩子。

## 执行步骤

### 步骤 1：建表

逐题记录：题号、知识点、分值、得分、错因码（能定就定）。落成 CSV，用
`scripts/diagnose.py --template` 生成表头。

判断条件：一道题跨多个知识点时，记**失分发生的那个知识点**，不是题目的标题知识点。例：导数题最后卡在解二次不等式，知识点记"一元二次不等式"。

### 步骤 2：定错因码

对每道失分题问一句：**"如果只改一个地方就能做对，改哪里？"**

| 改哪里 | 码 |
|---|---|
| 定义/定理条件 | C |
| 从哪下手 | M |
| 某一个算错的数 | A |
| 补两行过程 | W |
| 重读一遍题 | R |

一道题只能有一个主码。定不出来就留空，不要硬填——空着比填错强。

### 步骤 3：跑排序

`python scripts/diagnose.py scores.csv --top 4`

排序按**失分绝对值**，不按得分率。理由：一个得分率 50% 但只值 5 分的知识点，优先级低于得分率 70% 但值 17 分的。按得分率排会把孩子送去补最不划算的地方。

判断条件：如果前四条断点的失分加起来不到总失分的 50%，说明失分很分散，问题在稳定性而不在某条线，处方改成"限时整卷 + 书写规范"，不要拆成四条线各练一点。

### 步骤 4：出处方

每条断点给：性质、动作、时长、依据、下次验收标准。

硬约束：
- 单次训练总时长 ≤ 45 分钟，到点就停。
- 一次只针对**一个主码**训练，其他码记账不训练。
- 每条处方必须能在家里独立完成，不依赖报班、不依赖买新资料。

### 步骤 5：写验收

"下次验收"必须可判定。合格写法："下次同类题得分率 ≥ 80%，且能独立写出入口那一行"。不合格写法："有进步""明显改善""掌握程度提高"。

## 输出格式

用 `templates/diagnosis-report.md` 的五段结构：样本 / 断点排序 / 错因码分布 / 处方 / 这周只做三件事。

给家长的版本额外加一段**"这三件事别做"**，放在最后。

## 异常处理

| 异常 | 处理 |
|---|---|
| 只有分数没有卷子 | 用三问法缩小范围，产出"待验证假设"而不是结论，并约下一次带卷子 |
| 家长把问题归因为态度 | 用错因码回应："这五道题里四道是 A 码（算错），改态度解决不了算错" |
| 卷子批改有误 | 指出来，按修正后的分数重算，并说明改动了哪几题 |
| 分数波动极大（一次 120 一次 85） | 不当成能力问题，先查是否时间不够 / 是否某模块整块放弃 |
| 学生已高三且只剩两个月 | 不做全面诊断，只做"能拿回来的分"：把 A、W 两码挑出来，C、M 两码放弃 |

## 必要依赖

- `scripts/diagnose.py` — 排序与处方生成（纯标准库）
- `templates/diagnosis-report.md` — 诊断表模板
- `samples/scores_demo.csv` — 可直接改用的样例（19 题新高考结构）
- `materials/error-taxonomy.md` — 错因码判据全文

## 与其他工作流的关系

```
        ┌──────────────┐
证据 ──▶│ diagnose 定位 │──▶ 断点表 ──┬──▶ decompose 讲透第一断点
        └──────────────┘             ├──▶ drill 配变式
                                     ├──▶ ledger 建台账
                                     └──▶ examroom 定取舍
```

- 下游全部依赖本环节的断点表。**没有断点表就往下走的，一律视为猜。**
- 反向：`czl-math-ledger` 的周报如果显示某条断点复现率不降，回到本环节重定码。
