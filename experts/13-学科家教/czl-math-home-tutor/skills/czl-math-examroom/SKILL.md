# 考场：把目标分拆成每题的时间上限和放弃线

## 职责边界

只管"考场上怎么分配与放弃"。不补知识点（转 `czl-math-diagnose` / `czl-math-decompose`）。

**不做**：不押题、不预测考什么、不评价某年卷子难易。**不承诺**"按这个做就能到 120"——计划解决的是浪费，不解决不会。

## 输入参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 目标分 | 是 | 0–150。没有目标分就无法取舍 |
| 当前各题型得分 | 建议 | `--current "单选=30,多选=9,填空=7,解答=35"`；不给则按常见得分率估算，并在输出里标注"估算" |
| 卷型 | 建议 | 新高考 19 题（默认）/ 22 题旧结构 |
| 考试时长 | 可选 | 默认 120 分钟 |
| 剩余备考时间 | 可选 | 决定这个计划是"练"还是"只用" |

**目标分明显不可达时**（如当前 40 分、目标 150），直接说不成立，并给出可达上限，不要给一个看起来努力的计划。

## 执行步骤

### 步骤 1：拆目标

```bash
python scripts/scoreplan.py --target 120 --current "单选=30,多选=9,填空=7,解答=35"
```

按"剩余空间"分配需要多拿的分，不平均分。理由：一个已经 75% 的题型再提 10 分，成本高于一个 50% 的题型提 10 分。

判断条件：如果算出的"需要多拿"超过总剩余空间，说明目标不可行，先降目标再谈计划。

### 步骤 2：定时间盒

默认 120 分钟，留 10 分钟检查，其余按"分值 × 题型耗时系数"分配（多选和填空每题比单选贵）。

判断条件：时间盒加总必须 ≤ 考试时长。任何一档低于 3 分钟/题，说明分配不现实，回到步骤 1 降目标。

### 步骤 3：写放弃线

按该题型的**目标得分率**给放弃规则：

| 目标得分率 | 放弃线 |
|---|---|
| ≥ 85% | 全做，单题超时先跳过，回头补 |
| 70–85% | 全做，单题硬超时立刻跳 |
| 50–70% | 只做有路的，其余按分钟硬控 |
| < 50% | 解答题只做第 (1) 问；多选只选确定的，不猜第三个 |

判断条件：放弃线必须写成"超过 X 分钟就停"这种可执行的话，不能写"适当放弃"。

### 步骤 4：给三条硬规矩

固定三条，每次都写：到点就走、写不完也要写式子、最后 10 分钟只做三件检查。

### 步骤 5：验算

把各题型目标分加起来，必须等于目标分（允许 ±1 的取整误差）。加不上就重算，不许交一份加不出总数的计划。

## 输出格式

用 `templates/exam-plan.md`：目标 → 分题型表 → 按题上限 → 三条硬规矩 → 一次模考后的复盘位。

表格列固定：题型 / 满分 / 当前 / 目标 / 需要多拿 / 建议用时 / 放弃线。

## 异常处理

| 异常 | 处理 |
|---|---|
| 用户只想"考高一点"没有具体分数 | 给三档（保底/目标/冲刺），每档一张表，让他选 |
| 当前分数是估的 | 标注"估算"，并说明第一次模考后要用实测替换 |
| 学生速度极慢（做不完一半） | 不做分数计划，先做"速度诊断"：限时做 8 道单选，看是读题慢、计算慢还是犹豫 |
| 目标是艺考/体育类低分要求 | 计划重心放在选填与解答第 (1) 问，解答后两题直接放弃，写清这个取舍 |
| 剩不到一个月 | 只保留"放弃线 + 三条硬规矩"，不再改知识结构 |

## 必要依赖

- `scripts/scoreplan.py` — 目标拆解、时间盒、放弃线（支持 `--json` 导出）
- `templates/exam-plan.md` — 计划表模板
- `materials/exam-blueprint.md` — 卷面结构与分值依据

## 与其他工作流的关系

```
diagnose ──各题型得分率──▶ examroom ──放弃线──▶ 平时训练也要按这个放弃
                              │
                              └──模考后实测──▶ diagnose（更新得分率）
```

- 上游：`czl-math-diagnose` 给出的分题型得分率（没有就用估算，并标注）。
- 下游：放弃线要回写到平时训练里——平时不舍得放弃，考场也舍不得。
- 反向：每次模考后用实测得分率重跑一次，计划才有意义。
