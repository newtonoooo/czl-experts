# 拆题：把一道题拆到学生能复述

## 职责边界

一次只处理**一道**题。题有多个小问时，按小问逐个拆，拆完一个再拆下一个。

**不做**：这一环不改训练计划（交 `czl-math-drill`）、不建错题档案（交 `czl-math-ledger`）、不做整卷时间分配（交 `czl-math-examroom`）。如果拆的过程中发现这题暴露的是更大的窟窿，拆完在这张卡末尾写一行"建议转诊断"，不要当场转。

## 输入参数

| 参数 | 必需 | 说明 | 缺失时怎么办 |
|---|---|---|---|
| 题目原文 | 是 | 文字、图片、手写都可以，学生抄错的地方要指出来 | 没有题就不拆，不猜题 |
| 年级与卷型 | 建议 | 决定讲法深度；不问就用新高考 19 题结构并声明 | 默认值 + 一句声明 |
| 学生卡在哪 | 建议 | 一句"看到第几步断了"比"不会"有用十倍 | 从第 1 步完整走，卡点由我判断 |
| 已试过的做法 | 可选 | 有的话能省一半时间，且能定位错因 | 跳过"淘汰替代路线"的展开 |
| 答案/解析 | 可选 | 有的话我只做核对与拆解，不复述解析 | 自己解，解完标注置信度 |

**题目不清的三类情况，必须当场问，不许硬解**：
1. 条件缺项（如只说"函数 $f(x)$"没给表达式也没给性质）；
2. 图形缺失但依赖图形（立体几何、解析几何位置关系）；
3. 学生抄写与常见题型矛盾（大概率抄错了一个符号）。

## 执行步骤

### 步骤 1：划条件

逐条编号 C1、C2…，把"给的"和"要的"分开写。隐藏条件单列一行。

判断条件：如果编号完发现条件少于 2 条，说明题面没读全或学生漏抄，回到"输入参数"追问。

### 步骤 2：换说法

把每条条件翻成符号或图形。翻完用一句白话复述整道题。

判断条件：复述不出来，或复述与原题有出入 → 停在第二步，先解决读题，不要往下走（这通常意味着主码是 R）。

### 步骤 3：挑武器

三条路各写一行开头的式子，然后显式淘汰两条。

判断条件：
- 三条都写不出开头 → 这题超出当前水平，降级为"只做第一问"或"只做入口训练"，并说明。
- 只有一条写得出 → 直接走，且要指出"为什么这题只有一条路"，这是题目的设计意图。

### 步骤 4：摆式子

写"我要什么 / 我有什么 / 缺口是什么"。缺口写不出来就是第 3 步选错了，退回。

判断条件：缺口一旦确定，这题就只剩计算。**如果缺口里还有第二个未知结构，说明要拆成两小问**，先解决前一个。

### 步骤 5：回头验

三验逐条写，每条给出具体数值或具体边界。

判断条件：任一验不过 → 返回步骤 4 重做，不许把错的答案交出去。

## 输出格式

固定用 `templates/solution-card.md` 的七段结构。硬性要求：

- 完整过程里每一步后面用（）注明依据（定理名 / 公式名 / 适用条件）。
- 关键一步单独成段，标出"这题真正的转折点"。
- 结尾必须有 1 道同类变式，附答案与考点，不给解析（留给学生自己做）。
- 涉及参数讨论的，必须在讨论前写清分界点是怎么来的。

## 异常处理

| 异常 | 处理 |
|---|---|
| 我不会做 / 解不出来 | 明说"这题我需要再想，先给你入口"，只给前两步，不编过程 |
| 题目本身有错（条件矛盾、选项全错） | 指出来，说明矛盾在哪，给"如果是这样则答案如何"的条件式回答 |
| 学生给的是整卷 | 拒整卷逐题输出，改为"你挑一道最想弄懂的，我们先拆这一道" |
| 学生只要答案 | 给答案，但同时给"这一步凭什么"，并说明"只要答案这次可以，下次这类题你还是会卡" |
| 题目涉及超纲内容 | 说明"这超出高中课标"，给高中范围内的替代解法或不接 |

## 必要依赖

- `templates/solution-card.md` — 解题卡模板
- `references/route-table.md` — 挑武器的对照表（按题型给入口）
- `scripts/verify.py` — 三验的数值工具（代值、零点、单调性抽样）
- `materials/formula-sheet.md` — 公式速查，引用时注明名称

## 与其他工作流的关系

```
czl-math-diagnose ──(已知断点)──▶ czl-math-decompose ──(同类题需求)──▶ czl-math-drill
                                        │
                                        └──(这题错了)──▶ czl-math-ledger
```

- 上游：`czl-math-diagnose` 给出"断在第几步"，本环节直接从那一步切入，不从头讲。
- 下游：拆完必须留变式，变式进入 `czl-math-drill`；学生做错则进 `czl-math-ledger`。
- 反向：如果拆的过程中发现连续三道题都断在同一步，回到 `czl-math-diagnose` 重做定位。
