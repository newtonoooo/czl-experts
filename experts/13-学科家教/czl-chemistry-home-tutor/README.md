# 卓识教育 · 高中化学学习辅导（顾衡）

**开发者**：虫志龙　**邮箱**：47190078@qq.com　**版本**：1.0.0

一个面向高中学生与陪读家长的化学一对一家教专家。它不替你写作业，也不承诺提分；它做的是把"化学不好"拆成可动手的一步，把每一步写成能照着做的动作。

## 一、它解决什么问题

高中化学的难点不在"知识点多"，在于三套语言同时在线：看得见的现象、看不见的微粒、写在纸上的符号，最后还要落到一个数上。孩子说"背不完"，多数时候是三套语言没接上。

这个专家按四层顺序讲：**宏观现象 → 微粒模型 → 符号表达 → 定量关系**。倒过来讲，孩子只能背。

## 二、七个工作流

| 编号 | 工作流 | 什么时候用 | 交付物 |
|---|---|---|---|
| W1 | 学情首诊 | 分数卡住，说不清哪儿不会 | 诊断卡 + 六周优先级 |
| W2 | 概念与原理讲解 | 结论会背、依据说不出 | 四层讲解卡 + 一个反例 |
| W3 | 化学用语与方程式门诊 | 方程式总扣分 | 批改单 + 三查表 |
| W4 | 定量计算门诊 | 平衡、pH、滴定、Ksp 算不明白 | 分步计算卡 + 同类题 |
| W5 | 推断题门诊 | 推断一断链就全错 | 题眼表 + 推断路线图 |
| W6 | 工艺流程与实验题 | 流程题看不懂在干什么 | 四段拆解表 + 目的句式 |
| W7 | 试卷复盘与提分路径 | 考完了不知怎么复盘 | 错因编码表 + 六周动作 |

七个工作流的关系、输入输出、判断条件与异常处理，见 `docs/工作流规格.md`。

## 四、怎么用

### 1. 导入

在 WorkBuddy 的专家中心选择"导入专家"，选中发布包 zip；或把整个目录放到
`<配置目录>/plugins/marketplaces/my-experts/plugins/` 下，再运行注册脚本。

导入后如果小图标变成文字，按 `docs/导入与图标排查.md` 逐条排查——**九成是头像路径或文件本身的问题，不是平台故障**。

### 2. 第一次对话

推荐从学情首诊开始，附三样材料：最近一次卷子、一道计算题的草稿、两个手写方程式。

也可以直接用三个推荐问法：

- 孩子高二，化学总在及格线上下，说不清哪儿不会。先做一次学情诊断，再给六周计划
- 这道化学平衡计算题他算了三遍都不对，帮我看看错在哪一步，再出两道同类题
- 工艺流程题一看就懵，帮我把这道题按步骤拆开，教他怎么找每一步的目的

### 3. 三个脚本

```bash
# 把任意 PNG 规范成 512×512 RGB 头像（可裁掉水印）
python bin/make_avatar.py 原图.png avatars/expert.png --crop 42,0,940,940

# 发布前自检：清单、引用、头像、注册状态
python bin/check_package.py .

# 由学情 JSON 生成六周计划
python bin/build_study_plan.py --profile profile.json --out 计划.md
python bin/build_study_plan.py --demo     # 试跑
```

三个脚本只依赖 Python 标准库，不需要安装任何第三方包。

## 五、边界（写在这里，也写进了提示词）

- **不代写作业、不代考、不押题。** 只给方法、同类题与批改。
- **不承诺分数。** 只给可观测指标：能不能配平并标条件、能不能说出判断依据、能不能独立完成同类题。
- **不编造来源。** 教材版本、考试结构、政策口径不确定时，明说"建议核对课本"。
- **实验安全。** 强腐蚀试剂、剧毒气体、易燃易爆物的操作，只讲原理，并写明须由教师指导、在具备条件的实验室完成。
- **隐私。** 输出中不出现真实姓名、学校、班级、排名。
