## 1.0.0 — 2026-10-31

首个公开版本。

### 新增

- **主 Agent 提示词**：面向高中学生与陪读家长的一对一家教定位；七条底线；四层表达链（宏观现象 → 微粒模型 → 符号表达 → 定量关系）；E1—E8 错因编码；七个工作流路由表。
- **7 个工作流技能**：
  - `czl-chem-intake` 学情首诊
  - `czl-chem-concept` 概念与原理讲解
  - `czl-chem-equation` 化学用语与方程式门诊
  - `czl-chem-calc` 定量计算门诊
  - `czl-chem-deduction` 推断题门诊
  - `czl-chem-process` 工艺流程与实验题
  - `czl-chem-review` 试卷复盘与提分路径
- **9 份自编教研资料**：元素化合物转化网络、有机官能团反应矩阵、计算模型与公式卡、实验与装置要点、工艺流程常见操作目的、错因编码表、化学用语规范清单、教材版本与选科差异、公开资料索引与授权说明。
- **4 份可打印模板**：学情诊断问卷、六周辅导计划、错题复盘卡、家长沟通话术卡。
- **3 个工具脚本**（仅依赖 Python 标准库）：
  - `bin/make_avatar.py` 头像裁切、面积重采样、RGB PNG 输出与大小控制
  - `bin/check_package.py` 发布前自检（清单、引用、头像可解码性、注册状态）
  - `bin/build_study_plan.py` 由学情 JSON 生成六周计划
- **原创头像**：`avatars/expert.png`，512×512，8 位 RGB，约 372 KB。
- **文档**：`docs/工作流规格.md`（工程规格）、`docs/导入与图标排查.md`（图标变文字的 6 类原因与排查）。

### 已知限制

- 不覆盖竞赛化学与大学先修内容；遇到时明确标注"超出高考范围"。
- 教材页码不写死，只按版本与目录指路，避免版本错位。
- 不内置题库：题目由用户提供，产品只负责诊断、讲解与出同类题的思路。
- 图像识别依赖用户上传清晰照片；糊图会明确说明可信度低。
