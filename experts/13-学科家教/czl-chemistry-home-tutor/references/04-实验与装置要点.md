# 实验与装置要点

> 用途：W6 实验题、W7 E7 编码训练、家长陪练时的操作提问。
> 安全说明：本文件只讲原理与规范。强腐蚀试剂、剧毒气体、加热加压的操作，**一律由教师指导、在实验室完成，不要在家尝试**。

## 一、常见气体制备

| 气体 | 药品 | 条件 | 收集方法 | 注意事项 |
|---|---|---|---|---|
| O₂ | KMnO₄（或 KClO₃+MnO₂） | 加热 | 排水法 / 向上排空气 | 试管口略向下，防冷凝水回流 |
| O₂ | H₂O₂ + MnO₂ | 常温 | 同上 | 不用加热，控制滴速 |
| H₂ | Zn + 稀硫酸 | 常温 | 排水法 / 向下排空气 | 先验纯再点燃 |
| CO₂ | CaCO₃（大理石）+ 稀盐酸 | 常温 | 向上排空气 | 不用稀硫酸（生成微溶 CaSO₄ 覆盖表面） |
| Cl₂ | MnO₂ + 浓盐酸 | 加热 | 向上排空气 | 尾气用 NaOH 吸收 |
| NH₃ | NH₄Cl + Ca(OH)₂ | 加热 | 向下排空气 | 试管口塞棉花；不能用 NH₄Cl 单独加热 |
| SO₂ | Na₂SO₃ + 浓硫酸 | 常温 | 向上排空气 | 尾气用 NaOH 吸收 |
| NO | Cu + 稀硝酸 | 常温 | 排水法 | 不能用排空气法（遇 O₂ 变 NO₂） |
| NO₂ | Cu + 浓硝酸 | 常温 | 向上排空气 | 有毒，通风橱内 |
| C₂H₄ | 乙醇 + 浓硫酸 | 170 ℃ | 排水法 | 温度计插液面以下，快速升温到 170 ℃ |
| C₂H₂ | 电石 + 饱和食盐水 | 常温 | 排水法 | 不能用启普发生器（反应剧烈、放热、有糊状物） |

## 二、气密性检查（四句话说完）

| 方法 | 操作 | 现象与结论 |
|---|---|---|
| 微热法 | 关闭出口，用手捂或微热容器 | 导管口有气泡冒出，冷却后导管内形成一段水柱 → 气密性良好 |
| 液差法 | 关闭出口，从长颈漏斗加水至浸没下端 | 静置后液面不下降 → 气密性良好 |
| 注水法 | 适用于带分液漏斗的装置 | 加水后液面稳定不降 → 良好 |

答题必须写全"**封口 → 操作 → 现象 → 结论**"四段，只写"检查气密性"不给分。

## 三、除杂顺序三条铁律

1. **先除杂，后干燥。** 干燥一定放在最后，否则除杂过程又会带进水。
2. **先除有毒有害气体，再除水。**
3. **洗气瓶"长进短出"，干燥管"大进小出"。**

| 气体 | 杂质 | 除杂试剂 | 顺序 |
|---|---|---|---|
| Cl₂ | HCl、H₂O | 饱和食盐水 → 浓硫酸 | 先除 HCl 再干燥 |
| CO₂ | HCl、H₂O | 饱和 NaHCO₃ → 浓硫酸 | 不能用 NaOH（会吸收 CO₂） |
| SO₂ | H₂O | 浓硫酸 | — |
| NH₃ | H₂O | 碱石灰 | 不能用浓硫酸 |
| C₂H₄ | SO₂、CO₂、H₂O | NaOH 溶液 → 碱石灰 | 先除酸性气体 |

## 四、干燥剂选择

| 干燥剂 | 能干燥 | 不能干燥 | 原因 |
|---|---|---|---|
| 浓硫酸 | 中性、酸性气体 | NH₃、H₂S、HI、HBr | 酸性/氧化性/成盐 |
| 碱石灰 | 中性、碱性气体 | CO₂、SO₂、Cl₂、HCl | 酸性气体被吸收 |
| 无水 CaCl₂ | 多数中性气体 | NH₃、乙醇 | 生成络合物 |
| P₂O₅ | 酸性、中性气体 | NH₃ | 酸性干燥剂 |

## 五、尾气处理

| 尾气 | 处理 | 备注 |
|---|---|---|
| Cl₂、SO₂、NO₂、H₂S | NaOH 溶液吸收 | 防倒吸 |
| HCl、NH₃ | 水或稀酸吸收 | 必须防倒吸 |
| CO | 点燃 | 先验纯 |
| H₂ | 点燃或收集 | 先验纯 |

**防倒吸三件套**：安全瓶（空瓶）、倒扣漏斗（边缘刚接触液面）、干燥管（大口朝下）。答题要写出"为什么能防"：增加气体与液面的接触面积、或提供缓冲空间。

## 六、物质检验与鉴别

| 对象 | 试剂 | 现象 |
|---|---|---|
| Fe³⁺ | KSCN 溶液 | 血红色 |
| Fe²⁺ | 先加 KSCN 不变色，再加氯水变红 | 说明原溶液含 Fe²⁺ |
| NH₄⁺ | 加 NaOH 加热，湿润红色石蕊试纸 | 试纸变蓝 |
| SO₄²⁻ | 先加盐酸无现象，再加 BaCl₂ | 白色沉淀 |
| CO₃²⁻ | 加盐酸，气体通入澄清石灰水 | 变浑浊 |
| Cl⁻ | 加稀硝酸酸化，再加 AgNO₃ | 白色沉淀 |
| 醛基 | 银氨溶液水浴 / 新制 Cu(OH)₂ 加热 | 银镜 / 砖红沉淀 |
| 酚羟基 | FeCl₃ 溶液 | 紫色 |
| 羧基 | NaHCO₃ | 放出 CO₂ |
| 淀粉 | 碘水 | 变蓝 |
| 蛋白质 | 灼烧 | 烧焦羽毛气味 |

## 七、四个高频设问的答法

| 设问 | 答题结构 |
|---|---|
| "为什么先…后…" | 说清前一步的作用 + 后一步若提前会有什么后果 |
| "能否用 X 代替 Y" | 先答能否，再从"是否引入杂质、成本、腐蚀性、反应条件是否可行"四维说理 |
| "如何提高产率/浸出率" | 增大接触面积、适当提高浓度/温度、延长反应时间、循环利用母液 |
| "判断沉淀是否完全" | 静置后向上层清液再滴加沉淀剂，若无沉淀生成则已完全 |

## 八、安全红线（讲实验必说）

1. 浓硫酸稀释：**酸入水**，沿器壁缓慢加入并搅拌，绝不能反过来。
2. 闻气体：扇闻，不能直接凑到瓶口。
3. 加热试管：液体不超过容积 1/3，试管口不对人。
4. 有毒气体（Cl₂、SO₂、NO₂、H₂S）：必须在通风橱中，尾气必须处理。
5. 可燃气体（H₂、CH₄、C₂H₂）：点燃前必须验纯。
6. 碱液溅到皮肤：大量水冲洗，再涂硼酸溶液；酸溅到皮肤：大量水冲洗，再涂碳酸氢钠溶液。
7. 凡涉及强腐蚀、剧毒、易爆的实验，**都要在教师指导、具备条件的实验室里做，不要在家尝试**。

## 九、装置图怎么读

1. 先找**发生装置**：固体加热 / 固液常温 / 液液加热。
2. 再找**净化装置**：洗气瓶里装的是什么，长进短出对不对。
3. 再找**收集装置**：密度、溶解性决定向上还是向下。
4. 最后找**尾气处理**：有没有防倒吸，吸收剂对不对。
5. 每一步问一句"如果这一步没有会怎样"，答案就是设问的答案。
