## 一、六条主线（只记起点、特征中间体、终点）

### 钠线

```
Na ──O2──> Na2O / Na2O2 ──H2O──> NaOH ──CO2──> Na2CO3 ⇌ NaHCO3
                                        │
                                        └──过量CO2──> NaHCO3 ──△──> Na2CO3
```

| 转化 | 方程式 | 备注 |
|---|---|---|
| Na → Na₂O₂ | $2\mathrm{Na} + \mathrm{O_2} \xrightarrow{\triangle} \mathrm{Na_2O_2}$ | 黄色火焰，产物淡黄 |
| Na₂O₂ + H₂O | $2\mathrm{Na_2O_2} + 2\mathrm{H_2O} = 4\mathrm{NaOH} + \mathrm{O_2}\uparrow$ | 氧为 −1 价，歧化 |
| Na₂O₂ + CO₂ | $2\mathrm{Na_2O_2} + 2\mathrm{CO_2} = 2\mathrm{Na_2CO_3} + \mathrm{O_2}$ | 供氧剂原理 |
| NaHCO₃ 受热 | $2\mathrm{NaHCO_3} \xrightarrow{\triangle} \mathrm{Na_2CO_3} + \mathrm{H_2O} + \mathrm{CO_2}\uparrow$ | 鉴别 Na₂CO₃ 与 NaHCO₃ 的常用法 |

**易错**：Na₂O₂ 不是碱性氧化物（与水反应生成碱的同时放出 O₂）；Na₂O₂ 中阴离子是 O₂²⁻。

### 铝线（两性）

```
Al ──> Al2O3 ──> AlCl3 ──NH3·H2O──> Al(OH)3 ⇌ NaAlO2
                    ↑                  │
                    └──────HCl─────────┘
```

| 转化 | 方程式 | 备注 |
|---|---|---|
| Al 与 NaOH | $2\mathrm{Al} + 2\mathrm{NaOH} + 2\mathrm{H_2O} = 2\mathrm{NaAlO_2} + 3\mathrm{H_2}\uparrow$ | 铝不是"跟碱反应"，是铝表面的氧化膜与铝都被碱溶解 |
| Al(OH)₃ 受热 | $2\mathrm{Al(OH)_3} \xrightarrow{\triangle} \mathrm{Al_2O_3} + 3\mathrm{H_2O}$ | — |
| Al³⁺ 与过量氨水 | $\mathrm{Al^{3+}} + 3\mathrm{NH_3\cdot H_2O} = \mathrm{Al(OH)_3}\downarrow + 3\mathrm{NH_4^+}$ | 用氨水不用 NaOH，防止沉淀溶解 |

**易错**：Al(OH)₃ 溶于强碱不溶于弱碱（氨水）；偏铝酸钠与少量/过量盐酸产物不同。

### 铁线

```
Fe ──Cl2──> FeCl3 ──Fe──> FeCl2
 │                            │
 └──O2/H2O──> Fe3O4           └──Cl2──> FeCl3
Fe2+ ──OH-──> Fe(OH)2 ──O2──> Fe(OH)3 ──△──> Fe2O3
```

| 现象 | 结论 |
|---|---|
| Fe(OH)₂ 白色 → 灰绿 → 红褐 | 被空气氧化，方程式：$4\mathrm{Fe(OH)_2} + \mathrm{O_2} + 2\mathrm{H_2O} = 4\mathrm{Fe(OH)_3}$ |
| Fe³⁺ + KSCN 变血红 | 检验 Fe³⁺；不是沉淀 |
| Fe²⁺ 加 KSCN 不变色，通 Cl₂ 后变红 | 检验 Fe²⁺ 的经典路径 |
| Fe³⁺ 与 Fe、Cu 反应 | $2\mathrm{Fe^{3+}} + \mathrm{Fe} = 3\mathrm{Fe^{2+}}$；$2\mathrm{Fe^{3+}} + \mathrm{Cu} = 2\mathrm{Fe^{2+}} + \mathrm{Cu^{2+}}$ |

### 氯线

```
Cl2 ──H2O──> HCl + HClO ──NaOH──> NaCl + NaClO
 │
 └──Fe/Cu──> 高价氯化物
```

| 转化 | 方程式 | 备注 |
|---|---|---|
| Cl₂ + 水 | $\mathrm{Cl_2} + \mathrm{H_2O} \rightleftharpoons \mathrm{HCl} + \mathrm{HClO}$ | 可逆，故氯水成分复杂 |
| Cl₂ + NaOH（冷） | $\mathrm{Cl_2} + 2\mathrm{NaOH} = \mathrm{NaCl} + \mathrm{NaClO} + \mathrm{H_2O}$ | 漂白液 |
| 漂白粉失效 | $\mathrm{Ca(ClO)_2} + \mathrm{CO_2} + \mathrm{H_2O} = \mathrm{CaCO_3}\downarrow + 2\mathrm{HClO}$ | 见光/受热 HClO 分解 |

**易错**：干燥的 Cl₂ 没有漂白性，漂白的是 HClO。

### 硫线

```
S ──O2──> SO2 ──O2/催化剂──> SO3 ──H2O──> H2SO4
H2S ⇌ S；SO2 + 水 ⇌ H2SO3
```

| 转化 | 方程式 | 备注 |
|---|---|---|
| SO₂ 与氯水 | $\mathrm{SO_2} + \mathrm{Cl_2} + 2\mathrm{H_2O} = \mathrm{H_2SO_4} + 2\mathrm{HCl}$ | 还原性 |
| SO₂ 与 H₂S | $\mathrm{SO_2} + 2\mathrm{H_2S} = 3\mathrm{S}\downarrow + 2\mathrm{H_2O}$ | 价态归中 |
| 浓硫酸与铜 | $\mathrm{Cu} + 2\mathrm{H_2SO_4}(浓) \xrightarrow{\triangle} \mathrm{CuSO_4} + \mathrm{SO_2}\uparrow + 2\mathrm{H_2O}$ | 浓硫酸表现氧化性 |

**易错**：SO₂ 使品红褪色可复原，Cl₂ 使品红褪色不可复原——这是区分两者的标准方法。

### 氮线

```
N2 ──H2──> NH3 ──O2/催化剂──> NO ──O2──> NO2 ──H2O──> HNO3
铵盐 ⇌ NH3（加碱加热）
```

| 转化 | 方程式 | 备注 |
|---|---|---|
| 合成氨 | $\mathrm{N_2} + 3\mathrm{H_2} \rightleftharpoons 2\mathrm{NH_3}$ | 高温高压催化剂，可逆 |
| NO → NO₂ | $2\mathrm{NO} + \mathrm{O_2} = 2\mathrm{NO_2}$ | 无色变红棕 |
| NO₂ 与水 | $3\mathrm{NO_2} + \mathrm{H_2O} = 2\mathrm{HNO_3} + \mathrm{NO}$ | 工业制硝酸 |
| 铜与稀硝酸 | $3\mathrm{Cu} + 8\mathrm{HNO_3}(稀) = 3\mathrm{Cu(NO_3)_2} + 2\mathrm{NO}\uparrow + 4\mathrm{H_2O}$ | 稀硝酸得 NO |

**易错**：浓硝酸与铜得 NO₂，稀硝酸得 NO；硝酸与金属反应**不生成 H₂**。

## 二、颜色与现象速查

| 物质/离子 | 颜色或现象 |
|---|---|
| Cu²⁺（水合） | 蓝色 |
| Fe³⁺（水合） | 黄色 |
| Fe²⁺（水合） | 浅绿色 |
| MnO₄⁻ | 紫红色 |
| Fe(OH)₃ | 红褐色沉淀 |
| Fe(OH)₂ | 白色，迅速变灰绿→红褐 |
| Cu(OH)₂ | 蓝色沉淀，加热变黑 |
| Al(OH)₃、Mg(OH)₂ | 白色沉淀 |
| AgCl / AgBr / AgI | 白色 / 淡黄色 / 黄色沉淀 |
| BaSO₄、CaCO₃ | 白色沉淀 |
| CuS、FeS、Ag₂S、PbS | 黑色沉淀 |
| Cl₂ | 黄绿色、刺激性气味 |
| NO₂ / Br₂（气） | 红棕色 |
| SO₂ | 无色、刺激性，使品红褪色 |

## 三、离子共存四条否决线

1. **生成沉淀、气体、弱电解质** → 不能大量共存。
2. **发生氧化还原** → 不能共存。典型：Fe³⁺ 与 I⁻、S²⁻；酸性条件下 NO₃⁻ 与 Fe²⁺、I⁻；MnO₄⁻（酸性）与 Cl⁻、Fe²⁺。
3. **双水解** → 不能共存。典型：Al³⁺ 与 CO₃²⁻、HCO₃⁻、AlO₂⁻、S²⁻；Fe³⁺ 与 CO₃²⁻、HCO₃⁻、AlO₂⁻。
4. **络合** → 不能共存。典型：Fe³⁺ 与 SCN⁻。

附加两条隐含条件，读题时必须圈出来：

- "无色溶液" → 排除 Cu²⁺、Fe³⁺、Fe²⁺、MnO₄⁻。
- "由水电离出的 $c(\mathrm{H^+}) = 1\times10^{-13}\ \mathrm{mol\cdot L^{-1}}$" → 溶液可能呈酸性，也可能呈碱性，两种都要试。
