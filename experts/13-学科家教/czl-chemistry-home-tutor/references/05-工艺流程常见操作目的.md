# 工艺流程常见操作目的

> 用途：W6 流程题"这一步为什么这么做"的标准答法；也用于 W7 复盘 E6 编码。
> 说明：自编教研整理。工艺细节各题不同，**目的要按题目条件说，不要套模板**。

## 一、四段骨架（先分段，再逐空）

| 段 | 核心任务 | 典型操作 |
|---|---|---|
| ① 原料处理 | 把目标元素从固相弄进液相 | 粉碎、焙烧、酸浸、碱浸、水浸 |
| ② 核心转化 | 把目标元素变成要的形式 | 氧化、还原、沉淀、置换、电解 |
| ③ 分离提纯 | 目标物与杂质分开 | 过滤、调 pH、萃取、反萃取、蒸馏 |
| ④ 产品成型 | 拿到合格产品 | 蒸发浓缩、冷却结晶、过滤、洗涤、干燥 |

## 二、操作目的速查表

### 原料处理段

| 操作 | 目的 | 追问要点 |
|---|---|---|
| 粉碎、研磨 | 增大接触面积，加快反应速率，提高浸出率 | 过细会怎样：能耗高、粉尘大、过滤困难 |
| 焙烧（空气中） | 除去硫、碳等；把难溶物转为可溶于酸的氧化物 | 为什么通空气：提供 O₂ 参与氧化 |
| 酸浸（稀硫酸） | 溶解金属氧化物，使目标离子进入溶液 | 为什么不用盐酸：挥发、腐蚀、可能引入 Cl⁻ |
| 碱浸 | 除油污；溶解 Al₂O₃、SiO₂ 等酸性/两性氧化物 | 铝为什么溶于碱：两性 |
| 水浸 | 溶解可溶性盐，与不溶物分离 | 为什么要加热：加快溶解 |

### 核心转化段

| 操作 | 目的 | 追问要点 |
|---|---|---|
| 加 H₂O₂ | 把 Fe²⁺ 氧化为 Fe³⁺，便于沉淀；不引入新杂质 | 为什么不用氯水：引入 Cl⁻；不用 HNO₃：产生氮氧化物 |
| 加 Na₂S / 通 H₂S | 沉淀 Cu²⁺、Pb²⁺ 等重金属离子 | 为什么控制用量：过量引入杂质、增加成本 |
| 加铁屑 | 把 Fe³⁺ 还原为 Fe²⁺，或置换出更不活泼金属 | 为什么过量：保证还原完全，过量可过滤除去 |
| 电解 | 把金属离子还原为金属单质 | 阴极产物是什么：看氧化性顺序 |

### 分离提纯段

| 操作 | 目的 | 追问要点 |
|---|---|---|
| 调 pH | 使 Fe³⁺、Al³⁺ 水解沉淀完全，而目标离子不沉淀 | 下限：杂质沉淀完全；上限：目标离子不沉淀 |
| 加 NaOH 调 pH | 沉淀金属离子 | 为什么不用氨水：成本、后续处理 |
| 加 CuO / Cu(OH)₂ / ZnCO₃ 调 pH | 消耗 H⁺ 且不引入新杂质 | 为什么不用 NaOH：会引入 Na⁺ |
| 萃取 | 用有机溶剂把目标物从水相转入有机相，实现富集分离 | 为什么选 CCl₄/苯：不互溶、溶解度差异大 |
| 反萃取 | 用 NaOH 等把目标物转回水相并回收有机相 | 为什么能反萃：生成可溶性盐 |
| 蒸馏/分馏 | 分离沸点不同的液体 | 温度计位置：支管口处 |

### 产品成型段

| 操作 | 目的 | 追问要点 |
|---|---|---|
| 蒸发浓缩 | 减少溶剂，使溶液接近饱和 | 为什么不能蒸干：杂质也会析出、产品可能分解 |
| 冷却结晶 | 适合溶解度随温度变化大的物质 | 为什么要缓慢冷却：晶体大、易过滤 |
| 蒸发结晶 | 适合溶解度受温度影响小的物质 | 为什么要趁热过滤：防止降温析出杂质 |
| 冰水洗涤 | 减少晶体溶解损失 | 为什么不用热水：溶解度大，损失多 |
| 乙醇洗涤 | 洗去表面水分，加快干燥，减少溶解损失 | 为什么不用水：溶解损失、干燥慢 |
| 低温干燥 | 防止产品分解或失去结晶水 | 为什么不用高温：分解、氧化 |

## 三、常见设问的标准句式

| 设问 | 答题结构 | 示例 |
|---|---|---|
| "粉碎的目的是" | 增大接触面积 + 加快反应速率 + 提高浸出率 | 三点按分值取舍，只写"增大接触面积"通常只拿一半 |
| "为什么要控制 pH 在 4—5" | 下限让 Fe³⁺ 沉淀完全；上限保证 Cu²⁺ 不沉淀 | 两边都要说 |
| "能否用 NaOH 代替 CuO" | 不能，会引入 Na⁺，且可能使目标离子沉淀 | 先说结论再说理由 |
| "为什么用冰水洗涤" | 降低溶解度，减少晶体损失 | 一句话说清"降低溶解度"+"减少损失" |
| "母液为什么要循环" | 提高原料利用率，减少污染物排放 | — |
| "如何提高产率" | 反应更完全 + 损失更少 + 循环利用 | 三方向各说一条 |

## 四、三个典型流程骨架

### 1. 铝土矿 → 氧化铝 → 铝

```
铝土矿(Al2O3、Fe2O3、SiO2) ──NaOH溶液──> 过滤
   滤液：NaAlO2（Na2SiO3）  滤渣：Fe2O3
   滤液 ──通CO2──> Al(OH)3↓ ──灼烧──> Al2O3 ──电解(冰晶石)──> Al
```

关键方程式：

- $\mathrm{Al_2O_3} + 2\mathrm{NaOH} = 2\mathrm{NaAlO_2} + \mathrm{H_2O}$
- $\mathrm{NaAlO_2} + \mathrm{CO_2} + 2\mathrm{H_2O} = \mathrm{Al(OH)_3}\downarrow + \mathrm{NaHCO_3}$
- $2\mathrm{Al_2O_3} \xrightarrow[\text{冰晶石}]{\text{电解}} 4\mathrm{Al} + 3\mathrm{O_2}\uparrow$

追问：为什么通 CO₂ 不用盐酸（避免引入 Cl⁻，且 CO₂ 便宜）；为什么加冰晶石（降低熔点，节约能源）。

### 2. 海水提溴

```
海水 ──Cl2──> Br2 ──空气吹出──> 用SO2吸收 ──Cl2──> Br2 ──蒸馏──> 液溴
```

关键方程式：

- $\mathrm{Cl_2} + 2\mathrm{Br^-} = 2\mathrm{Cl^-} + \mathrm{Br_2}$
- $\mathrm{Br_2} + \mathrm{SO_2} + 2\mathrm{H_2O} = \mathrm{H_2SO_4} + 2\mathrm{HBr}$

追问：为什么要"吹出—吸收—再氧化"（富集，提高浓度）；为什么用 SO₂ 吸收（把 Br₂ 还原为 HBr，便于富集）。

### 3. 侯氏制碱（纯碱）

$$\mathrm{NaCl} + \mathrm{NH_3} + \mathrm{CO_2} + \mathrm{H_2O} = \mathrm{NaHCO_3}\downarrow + \mathrm{NH_4Cl}$$

$$2\mathrm{NaHCO_3} \xrightarrow{\triangle} \mathrm{Na_2CO_3} + \mathrm{H_2O} + \mathrm{CO_2}\uparrow$$

追问：为什么先通 NH₃ 再通 CO₂（使溶液显碱性，增大 CO₂ 溶解度）；副产物 NH₄Cl 怎么处理（作氮肥，或循环）。

## 五、读流程图的三个动作

1. **抄条件**：题干的温度、pH、过量少量，全部标到对应箭头旁。
2. **编序号**：每个方框编 ①②③，答题按编号说话。
3. **标循环**：有回流的箭头，必问"循环的是什么、为什么能循环、不循环会怎样"。

## 六、三条提醒

- **不要背工艺。** 每个厂的流程都不一样，考的是"这一步除什么"，不是"这一步叫什么"。
- **不要漏掉"为什么不用另一个"。** 流程题的分数常在这个对比里。
- **方程式一定要写条件。** 焙烧、电解、加热这些条件本身就是得分点。
