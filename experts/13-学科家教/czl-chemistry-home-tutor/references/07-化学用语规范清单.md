# 化学用语规范清单

> 用途：W3 方程式门诊的逐条对照表；也是学生每天 5 分钟自检的工具。
> 用法：写完一个式子，从头到尾打勾；错一条改一条，不要一次改全部。

## 一、方程式十二查

| # | 查什么 | 合格标准 | 常见不合格 |
|---|---|---|---|
| 1 | 反应物与产物 | 符合该条件下的客观事实 | 稀硝酸写 NO₂、Fe 与 Cl₂ 写 FeCl₂ |
| 2 | 原子守恒 | 左右每种元素个数相等 | 少一个 H₂O |
| 3 | 电荷守恒（离子式） | 左右总电荷相等 | 左边 +2、右边 +4 |
| 4 | 电子守恒（氧化还原） | 升降总数相等 | 只配了原子没配电子 |
| 5 | 条件 | △、催化剂、高温、高压、光照，该标的都标 | 该加热没写 △ |
| 6 | 状态符号 | 气体 ↑、沉淀 ↓ | 生成气体不标 ↑ |
| 7 | 可逆号 | 可逆反应用 ⇌ | 用 = 代替 |
| 8 | 浓度标注 | 浓/稀要写清 | 浓硫酸、稀硝酸漏标 |
| 9 | 系数最简 | 化为最简整数比 | 全式乘了 2 没约 |
| 10 | 拆写正确（离子式） | 该拆的拆、不该拆的不拆 | 弱酸写成 H⁺ + 酸根 |
| 11 | 微溶物处理 | 澄清溶液拆、浊液不拆 | 石灰乳写成 Ca²⁺ + 2OH⁻ |
| 12 | 有机式 | 写结构简式、标条件、标小分子 | 只写分子式 |

## 二、离子方程式拆写速查

| 物质类型 | 拆不拆 | 写法 |
|---|---|---|
| 强酸：HCl、H₂SO₄、HNO₃、HBr、HI | 拆 | H⁺ + 酸根 |
| 强碱：NaOH、KOH、Ba(OH)₂ | 拆 | 金属离子 + OH⁻ |
| 可溶性盐 | 拆 | 金属离子 + 酸根 |
| 弱酸：CH₃COOH、H₂CO₃、HClO、HF | 不拆 | 写化学式 |
| 弱碱：NH₃·H₂O | 不拆 | 写 NH₃·H₂O |
| 水 | 不拆 | H₂O |
| 沉淀、气体、氧化物、单质 | 不拆 | 写化学式 |
| 微溶物 | 看状态 | 澄清石灰水拆；石灰乳不拆 |
| 酸式盐 | 看电离 | NaHCO₃ → Na⁺ + HCO₃⁻；NaHSO₄（水溶液）→ Na⁺ + H⁺ + SO₄²⁻ |
| 浓硫酸 | 一般不拆 | 写 H₂SO₄(浓) |

## 三、四类特殊方程式的写法

### 1. 热化学方程式

```
H2(g) + 1/2 O2(g) = H2O(l)   ΔH = -285.8 kJ·mol⁻¹
```

- 每个物质标状态：(g) 气、(l) 液、(s) 固、(aq) 溶液。
- $\Delta H$ 写在右边，带单位，吸热为正、放热为负。
- 系数改变，$\Delta H$ 同比例改变；方程式逆写，$\Delta H$ 变号。

### 2. 电极反应式

| 电极 | 写法 | 例（氢氧燃料电池，碱性） |
|---|---|---|
| 负极（氧化） | 失电子，写 $-\mathrm{e^-}$ | $\mathrm{H_2} + 2\mathrm{OH^-} - 2\mathrm{e^-} = 2\mathrm{H_2O}$ |
| 正极（还原） | 得电子，写 $+\mathrm{e^-}$ | $\mathrm{O_2} + 2\mathrm{H_2O} + 4\mathrm{e^-} = 4\mathrm{OH^-}$ |

检查：两式相加等于总反应；电荷必须平。

### 3. 电子式

- 先画原子骨架，再补成键电子对，最后补孤对电子。
- 共价化合物成键电子对写在两原子之间；离子化合物用方括号标电荷。
- 检查每个原子是否达到稳定结构（H 2 电子，其他 8 电子）。

### 4. 有机方程式

- 用结构简式，不用分子式（除非题目只要求分子式）。
- 条件写全：浓硫酸、△、NaOH 水溶液、NaOH 醇溶液。
- 小分子（H₂O、HX）不能漏。

## 四、符号与单位

| 符号 | 含义 | 注意 |
|---|---|---|
| ↑ | 气体生成 | 反应物中已有气体时不标 |
| ↓ | 沉淀生成 | 化学方程式与离子方程式都要标；只有题目明确要求"写离子符号"时才省略 |
| ⇌ | 可逆 | 弱电解质电离、水解、沉淀溶解、可逆反应 |
| △ | 加热 | 写在等号上方 |
| $\mathrm{mol\cdot L^{-1}}$ | 浓度单位 | 不能写成 mol/L 混排 |
| $\mathrm{kJ\cdot mol^{-1}}$ | 焓变单位 | 与 $\Delta H$ 配套 |

## 五、每天 5 分钟自检（打印贴桌）

```
今天写式子时，我漏了哪一项？
□ 条件    □ ↑↓    □ 配平    □ 电荷
□ 状态    □ 可逆号  □ 浓稀    □ 单位

漏的那一项，明天专门盯它。
```

## 六、三条提醒

1. **规范不是形式，是分数。** 高考按符号给分，阅卷不会因为"意思对了"给分。
2. **一次只改一个习惯。** 同时改四个符号习惯，一个都改不掉。
3. **改完要复述原因。** 能说出"我刚才漏的是条件"，才算真改。
