# 有机官能团反应矩阵

> 用途：W5 有机推断、W2 讲反应类型、W3 写有机方程式。
> 说明：自编教研整理，按高中课标范围编写。

## 一、一张主表：官能团 × 试剂 × 条件 × 现象

| 官能团 | 特征反应 | 试剂与条件 | 可观察现象 | 反应类型 |
|---|---|---|---|---|
| 碳碳双键 | 加成 | 溴水或 Br₂/CCl₄，常温 | 溴水褪色，不分层 | 加成 |
| | 加成 | H₂，Ni 催化、加热 | — | 加成（还原） |
| | 氧化 | 酸性 KMnO₄ | 紫色褪去 | 氧化 |
| | 加聚 | 催化剂 | — | 加聚 |
| 碳碳三键 | 加成 | 溴水、H₂/Ni | 溴水褪色 | 加成 |

## 二、反应类型速查

| 类型 | 判据 | 高中常见例子 |
|---|---|---|
| 取代 | 一上一下 | 烷烃卤代、苯的溴代/硝化、醇与 HX、酯化、水解 |
| 加成 | 只上不下 | 烯/炔与 Br₂、H₂、HX、H₂O；苯加 H₂；醛加 H₂ |
| 消去 | 一分为二，生成双键 | 卤代烃醇溶液消去、醇浓硫酸 170 ℃ |
| 氧化 | 加氧或去氢 | 醇→醛→酸、醛的银镜、烯炔与 KMnO₄ |
| 还原 | 加氢或去氧 | 醛/酮加 H₂、硝基苯还原为苯胺 |
| 加聚 | 双键打开相连 | 乙烯→聚乙烯、氯乙烯→聚氯乙烯 |
| 缩聚 | 有小分子生成 | 酯化型缩聚、氨基酸成肽 |

## 三、条件反推表（推断题最硬的线索）

| 条件 | 极可能是 |
|---|---|
| 浓硫酸、加热 | 酯化、醇脱水（分子内 170 ℃ / 分子间 140 ℃）、纤维素水解 |
| NaOH 水溶液、加热 | 卤代烃水解、酯水解 |
| NaOH 醇溶液、加热 | 卤代烃消去 |
| Br₂/CCl₄ | 烯、炔的加成 |
| 溴水 | 烯炔加成、酚的取代、醛的氧化（三者都会褪色，需配合其他信息） |
| 酸性 KMnO₄ | 烯炔、醛、酚、苯同系物侧链、醇的氧化 |
| H₂/Ni、加热 | 烯炔、苯环、醛、酮的加成（还原） |
| O₂/Cu 或 Ag、加热 | 伯醇→醛，仲醇→酮 |
| 银氨溶液、水浴 | 醛基 |
| 新制 Cu(OH)₂、加热 | 醛基（砖红）、羧基（蓝色沉淀溶解） |
| FeCl₃ | 酚羟基 |
| NaHCO₃ | 羧基（放 CO₂） |
| 浓溴水、白色沉淀 | 酚羟基 |

## 四、合成路线设计三原则

1. **先定官能团，再定碳骨架。** 目标分子有哪些官能团？每一步只改一个，不要一步改两个。
2. **官能团的引入顺序有讲究。** 先引入易被氧化的（如双键），最后引入氧化性条件强的步骤；酚羟基引入后不能再上强氧化条件。
3. **保护与去保护（了解即可）**：高中范围内只需知道"酚羟基易被氧化"，遇到多官能团分子先做不被氧化的那一步。

常见引入路径：

| 目标官能团 | 常见引入方式 |
|---|---|
| —X | 烷烃/苯环取代；醇与 HX |
| —OH（醇） | 卤代烃水解；醛/酮加氢；烯加水 |
| —OH（酚） | 苯环卤代后水解；异丙苯氧化法（工业） |
| —CHO | 伯醇氧化；烯的氧化（了解） |
| —COOH | 醛氧化；苯同系物侧链氧化；酯水解 |
| —COO— | 羧酸 + 醇酯化 |

## 五、同分异构体计数四步

1. **算不饱和度**：$\Omega = \dfrac{2C + 2 + N - H - X}{2}$，判断有没有环、苯环、双键。
2. **定碳骨架**：先画直链，再逐个减碳做支链（主链由长到短、支链由整到散、位置由心到边）。
3. **放官能团**：按对称性去重，注意"等效氢"。
4. **查重复**：把每个结构按系统命名法念一遍，名字一样就是同一个。

**常见坑**：把"位置异构"和"同一分子旋转后的样子"当成两个；忘记环状结构；忽略顺反异构（题目要求时才写）。

## 六、除杂与鉴别（实验题常考）

| 目标 | 方法 | 不能用什么 | 原因 |
|---|---|---|---|
| 除去乙烷中的乙烯 | 通入溴水洗气 | 酸性 KMnO₄ | 会把乙烯氧化成 CO₂，引入新杂质 |
| 除去乙酸乙酯中的乙酸 | 饱和 Na₂CO₃ 溶液，分液 | NaOH 溶液 | 会使酯水解 |
| 除去溴苯中的溴 | NaOH 溶液洗涤后分液 | 水 | 溴在水中溶解度小，除不净 |
| 鉴别苯与甲苯 | 酸性 KMnO₄ | 溴水 | 两者都能萃取溴，现象相同 |
| 鉴别乙醇与乙酸 | NaHCO₃ 或石蕊 | 闻气味（不规范） | 不能作为规范鉴别方法 |
| 鉴别葡萄糖与蔗糖 | 银氨溶液或新制 Cu(OH)₂ | 溴水 | 现象不特异 |

## 七、使用提醒

- 有机方程式同样要写条件、写结构简式、标小分子（如水、HX）。
- 有机推断的答案必须能"倒着走回去"：每一步都能用条件解释，才叫推出来。
- 本表只列高中范围，酯的皂化、油脂氢化、糖类水解属于"了解"层级，按学校要求取舍。
