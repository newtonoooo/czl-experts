# 学情诊断问卷

> 用法：家长或学生首次咨询时直接发这份问卷。**学生那三问必须孩子自己答**，家长代答的部分要标注。

## 一、基本信息（家长填）

| 项 | 内容 |
|---|---|
| 年级 | 高一 / 高二 / 高三 |
| 教材版本 | 人教版 / 鲁科版 / 苏教版 / 不确定（拍目录） |
| 选科 | 化学是否计入高考总分：是 / 否 / 还没定 |
| 最近一次化学成绩 | 分数或分数段（如 62/100，或班级中下） |
| 学校进度 | 现在学到哪一章 |
| 每周可用于化学的时间 | 小时 |

## 二、学生自述三问（孩子自己写，家长不代笔）

1. **你觉得化学最难的是哪一类题？**（选择题 / 方程式 / 计算 / 推断 / 流程 / 实验）
2. **考试时，你一般在哪儿开始卡住？**（读题就读不懂 / 写方程式 / 算到一半 / 最后检查）
3. **如果只能改一个毛病，你最想改哪个？**

> 提示：答不上来也是信息，写"不知道"就行。

## 三、家长观察三问

1. 孩子做化学作业时，**平均多久会停下来发呆一次**？停下来之后是查书、问人，还是跳过？
2. 错题发下来之后，他是**改一遍**、**抄一遍答案**，还是**看都不看**？
3. 考试前他会说"这次要考××"吗？还是完全不知道考什么？

## 四、材料清单（有几样发几样，不用凑齐）

- [ ] 最近一次化学卷子（正反面 + 答题卡批改处）
- [ ] 一道计算题的草稿（拍那一张纸）
- [ ] 两个手写方程式
- [ ] 一道做错的推断题或流程图题（题干 + 图 + 他的作答）
- [ ] 课本目录照片（不确定版本时）

## 五、我们不会做的事

- 不看排名下判断，只看出错的位置。
- 不承诺分数，只给可观测的动作。
- 不在输出里出现真实姓名、学校、班级。需要代称时用"学生A"。

## 六、收到材料后你会得到什么

1. 一张诊断卡：已经会的 / 卡住的 / 待确认的。
2. 一张错因编码表（E1—E8），告诉你主要问题属于哪一类。
3. 一份六周优先级表，每周只改一件事。
4. 本周第一个 20 分钟就能做的动作。
