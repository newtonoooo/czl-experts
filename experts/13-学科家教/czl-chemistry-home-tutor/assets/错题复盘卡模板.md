# 错题复盘卡

> 用法：每道错题填一张，卡片大小以"能贴在错题本上"为准。宁可只写三行，不要写满一页。

## 一、卡片正文

```
日期：______      题号：______      来源：______

【我原来的答案】
（照抄，包括错的步骤，不要美化）

【错在第几步】
□ 读题就偏了  □ 方程式错  □ 概念不清  □ 推断断链
□ 计算/单位   □ 流程目的  □ 实验表述  □ 表达不全

【正确的那一步】
（只写关键一步，不抄全解）

【下次怎么防】
（写一个动作，不写"要认真"）
例：写完方程式先查 ↑↓，再查条件。

【母题】
（这题换一个物质/换一个条件，还能不能做？写一句话）
```

## 二、编码对照（填卡时用）

| 勾选 | 编码 | 含义 |
|---|---|---|
| 概念不清 | E1 | 模型没建起来 |
| （符号问题） | E2 | 用语不规范 |
| 方程式错 | E3 | 配平/条件/产物 |
| 计算/单位 | E4 | 定量关系 |
| 推断断链 | E5 | 题眼没抓住 |
| 流程目的 | E6 | 不知道这一步为什么 |
| 实验表述 | E7 | 操作与装置答不全 |
| 表达不全 | E8 | 会做但没答到点上 |

## 三、一张卡的三条纪律

1. **只写一个错因。** 一张卡写五个问题，等于没复盘。
2. **"下次怎么防"必须是动作。** "认真一点""多检查"不是动作，删掉重写。
3. **一周后回看。** 只看"下次怎么防"那一行，问自己做到没有。

## 五、家长版用法（不碰学科）

家长只做三件事：

1. 提醒"今天填一张卡"。
2. 检查"下次怎么防"那一行**是不是一个动作**（不是"认真"就行）。
3. 周日把汇总表拍给老师。

不要替孩子判断对错，不要在旁边说"这么简单都不会"。
