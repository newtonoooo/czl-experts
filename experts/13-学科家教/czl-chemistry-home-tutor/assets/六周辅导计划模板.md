# 六周辅导计划模板

> 用法：W1 诊断后填写第 1—6 行；每周日晚上用 5 分钟在"完成情况"列打勾。

## 三、家长负责什么（写死，别扩大）

| 家长做 | 家长不做 |
|---|---|
| 掐时间 | 讲题 |
| 收材料、拍照 | 判断对错 |
| 每周日打勾 | 加作业量 |
| 提醒"今天只改这一样" | 比较、催促、许诺奖励 |

## 四、六周后的复盘（第 6 周末填）

| 指标 | 第 1 周 | 第 6 周 |
|---|---|---|
| 方程式漏条件（每 5 个里几处） | | |
| 计算题步骤齐全（每 5 题里几题） | | |
| 同类推断题独立完成（几分钟） | | |
| 主观题空白（每张卷子几处） | | |

**结论只写两句**：哪一项确实变了；哪一项没变，下一轮改什么。

## 五、三条提醒

1. 计划表不是给别人看的，**写多了等于没写**。
2. 期中、期末、月考周，计划减半，不断线。
3. 连续两周完不成，先砍内容，不要加时间。
