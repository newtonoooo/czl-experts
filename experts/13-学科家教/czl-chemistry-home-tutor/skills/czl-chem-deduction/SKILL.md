# W5 推断题门诊

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 推断题门诊（czl-chem-deduction） |
| **任务职责** | 教"从哪一头切进去"，把断链的位置显性化，让学生下次遇到同型题能自己起步。 |
| **输入参数** | 必填：题干与框图/转化关系（原图最佳）。选填：学生的作答与卡住的步骤、参考答案、限时情况 |
| **执行步骤** | ①通读题干，圈出所有"限定词"（颜色、状态、气味、条件、过量少量）→②建题眼表，把每个现象对应到 1—3 个候选物质→③选切入点（唯一物质优先）→④正向推 + 逆向推，两路在中间会合→⑤每确定一个物质，立刻回填框图并核对全部条件→⑥总结本题用的 2—3 个题眼→⑦出一道换物质的变式 |
| **判断条件** | 出现"唯一候选"→ 从这里起步；全部候选都 ≥2 个→ 找"能同时满足两个条件"的那个；推到中途与某条件矛盾→ 立刻回退，说明这条链被否掉（这一步最有教学价值）；有机题分子式已知→ 先算不饱和度；题目信息不足→ 明确说"这题缺条件"，不硬编 |
| **输出格式** | 题眼表（现象 → 候选 → 确定依据）+ 推断路线图（箭头 + 每一步依据）+ 断链点标记 + 变式题 |
| **异常处理** | 学生直接要答案 → 只给第一个物质，其余让他自己推；框图模糊 → 要求重拍或口述文字描述；一题卡住超过 10 分钟 → 给"最小提示"（指向一个现象），不给全解；涉及有毒气体（Cl₂、H₂S、SO₂）的实验描述 → 只讲推断逻辑，注明实验须在老师指导下进行 |
| **必要依赖** | `references/01-元素化合物转化网络.md`（无机骨架）、`references/02-有机官能团反应矩阵.md`（有机骨架） |
| **与其他工作流的关系** | 上游：W2 的模型、W3 的方程式（推断题最后一定要落成方程式）。下游：推断通了进 W6（流程题本质是推断 + 目的）；错题进 W7。 |

## 一、题眼表：先把线索捞干净，再动笔

| 线索类型 | 具体表现 | 第一候选 | 排除方法 |
|---|---|---|---|
| 颜色 | 黄色溶液 | Fe³⁺ | 加 KSCN 变血红确认 |
| | 浅绿色 | Fe²⁺ | 通 Cl₂ 后变黄 |
| | 蓝色溶液 | Cu²⁺ | 加 NaOH 得蓝色沉淀 |
| | 紫红色溶液 | MnO₄⁻ | 酸性条件氧化性更强 |
| | 红棕色气体 | NO₂ / Br₂ | 加水看是否褪色、是否得无色溶液 |
| | 黄绿色气体 | Cl₂ | 使湿润淀粉碘化钾试纸变蓝 |

## 二、无机推断的骨架：一张网络，不是一堆方程式

推断题考的从来不是"记住了多少方程式"，而是**这个物质在这个网络里的位置**。骨架按三条主线搭：

```
钠线：Na → Na2O/Na2O2 → NaOH → Na2CO3 ⇌ NaHCO3
铝线：Al → Al2O3 → AlCl3 → Al(OH)3 ⇌ NaAlO2（两性，既能溶于酸又能溶于碱）
铁线：Fe → FeCl2 ⇌ FeCl3 → Fe(OH)2 → Fe(OH)3 → Fe2O3
氯线：Cl2 → HCl → NaCl；Cl2 + NaOH → NaClO
硫线：S → SO2 → SO3 → H2SO4；H2S ⇌ S
氮线：N2 → NH3 → NO → NO2 → HNO3；铵盐 ⇌ NH3
```

**每条线只记三个东西**：起点、特征中间体、终点。中间的细节到用时再推。

## 三、有机推断：三步定骨架

1. **算不饱和度**：$\Omega = \dfrac{2C + 2 + N - H - X}{2}$。$\Omega = 1$ 可能是双键或一个环；$\Omega = 4$ 且含 6 个碳，优先想苯环。
2. **看条件反推反应类型**：条件是最硬的线索（见上表）。条件对不上，碳骨架推得再漂亮也是错的。
3. **盯官能团的变化**：每步只允许一个官能团变化，除非题目明说多步。

| 官能团 | 特征反应 | 判定用试剂 |
|---|---|---|
| 碳碳双键/三键 | 加成、加聚、氧化 | 溴水褪色、酸性 KMnO₄ 褪色 |
| 卤素原子 | 水解（—OH）、消去（双键） | NaOH 水溶液 / 醇溶液，看产物 |
| 羟基（醇） | 氧化成醛、酯化、消去 | Cu/Ag 催化加热 |
| 羟基（酚） | 弱酸性、显色、易取代 | FeCl₃ 显紫、与 NaHCO₃ 不反应（区别于羧酸） |
| 醛基 | 银镜、与新制 Cu(OH)₂ 砖红 | 银氨溶液、新制 Cu(OH)₂ |
| 羧基 | 酸性、酯化 | 与 NaHCO₃ 放出 CO₂ |
| 酯基 | 水解 | 酸性或碱性条件，产物两种 |
| 氨基 | 碱性、成肽 | — |

## 四、双通道法：正向与逆向同时开

- **正向**：从最确定的物质（唯一候选）出发，沿条件箭头推。
- **逆向**：从问题要的那个物质倒推，问"它上一步只能由谁得到"。
- **会合**：两条路在中间相遇时，通常只剩一种可能。**如果遇不上，说明前面有一条链错了，回退。**

断链处理三条：

1. **标未知块**：把不确定的物质画成方框，先不算它。
2. **找最少确定量**：先求"必须确定才能往下走"的那一个，其余搁置。
3. **用条件反查**：每确定一个物质，回头把题干条件全部对一遍，对不上就否掉。

## 五、示范：一条最小题眼链

> 某黄色溶液，加 KSCN 变血红；另取该溶液通入足量 Cl₂ 后，再加 KSCN 仍变血红。

- 第一步"加 KSCN 变血红" → 溶液含 Fe³⁺ → **黄色 = Fe³⁺ 的颜色**，不是溴水、不是碘水。
- 第二步"通 Cl₂ 后仍变红"只说明还有 Fe³⁺，**不能说明原来没有 Fe²⁺**；要证 Fe²⁺，得看通 Cl₂ 前后颜色的变化（浅绿 → 黄）。
- 结论：这题考的是"Fe³⁺ 的检验"和"Fe²⁺ 的检验不能共用同一试剂"。

一句话总结：**推断题的答案永远是"证据链"，不是"猜测"。**

## 六、练习法：一题三问

做完一道推断题，追问三句：

1. **切入点在哪？** 是哪个现象让它唯一。
2. **哪条链是唯一通路？** 如果去掉这个条件，还能不能推出来。
3. **换个物质会怎样？** 把 Fe 换成 Cu，哪些步骤要改。

三问答不上来，等于这题白做。
