## 一、四层表达链

讲任何概念都按这四层走，顺序不能颠倒。**倒过来讲，孩子只能背。**

| 层 | 要回答的问题 | 判断"这层通了"的标志 |
|---|---|---|
| 宏观现象 | 看得见什么？颜色、气体、沉淀、温度、电流 | 他能描述现象，而不是背结论 |
| 微粒模型 | 谁在动？谁给电子？哪边浓度高？ | 他能画出粒子，或说出"哪个粒子在增哪个在减" |
| 符号表达 | 怎么写才规范？ | 方程式配平、条件、状态齐全 |
| 定量关系 | 谁过量？算哪个量？ | 能说出已知量和未知量的关系式 |

## 二、五个高频概念的模型

### 1. 化学平衡与勒夏特列原理

- **模型**：正逆反应同时进行，速率相等时各组分浓度不再变化，但反应没有停。
- **判据**：$v_{正}=v_{逆}$，且各组分浓度保持不变。**只看浓度不变不够**——必须是"达到后不再变化"。
- **移动判据**：改变条件瞬间，比较 $v_{正}$ 与 $v_{逆}$ 谁大；或比较浓度商 $Q$ 与 $K$。
- **边界（学生最容易错的三条）**：
  1. 勒夏特列只判**方向**，不判**程度**，也不判**快慢**。
  2. "减弱"不等于"抵消"：加压后新平衡的浓度仍比原平衡高，只是没有"按比例"增高那么多。
  3. 催化剂、恒容下充入惰性气体，平衡**不移动**。

### 2. 电离与水解

| 对比项 | 电离 | 水解 |
|---|---|---|
| 谁在动 | 电解质本身离解成离子 | 盐的离子与水电离出的 $\mathrm{H^+}$ 或 $\mathrm{OH^-}$ 结合 |
| 典型 | $\mathrm{CH_3COOH \rightleftharpoons CH_3COO^- + H^+}$ | $\mathrm{CH_3COO^- + H_2O \rightleftharpoons CH_3COOH + OH^-}$ |
| 对水的影响 | 抑制水的电离（同离子效应为主） | 促进水的电离 |
| 常数 | $K_a$、$K_b$ | $K_h = K_w / K_a$（或 $K_w/K_b$） |

一句话记：**弱酸弱碱看电离，盐溶液看水解；酸抑制水，盐促进水。**

### 3. 沉淀溶解平衡与 Ksp

- **模型**：难溶电解质在饱和溶液里"溶解"与"沉淀"速率相等。
- **Ksp 只与温度有关**，与离子浓度无关；同离子效应让溶解度下降。
- **判据**：$Q > K_{sp}$ 析出，$Q = K_{sp}$ 饱和，$Q < K_{sp}$ 不析出。
- **易错**：把"溶解度小"等同于"Ksp 小"——不同类型（如 AgCl 与 Ag₂CrO₄）不能直接比大小。

### 4. 原电池与电解池

| | 原电池 | 电解池 |
|---|---|---|
| 能量 | 化学能 → 电能 | 电能 → 化学能 |
| 负极/阳极 | 负极：氧化，失电子 | 阳极：氧化，失电子（接电源正极） |
| 正极/阴极 | 正极：还原，得电子 | 阴极：还原，得电子（接电源负极） |
| 离子流向 | 阳离子向正极，阴离子向负极 | 阳离子向阴极，阴离子向阳极 |

记法：**"负阳氧"**——负极、阳极都发生氧化；原电池看负极，电解池看阳极。

### 5. 反应热与盖斯定律

- $\Delta H = $ 生成物总能量 $-$ 反应物总能量；吸热为正，放热为负。
- 键能法：$\Delta H = \sum E_{反应物键能} - \sum E_{生成物键能}$。
- 盖斯定律：方程式相加，$\Delta H$ 相加；方程式乘系数，$\Delta H$ 同乘；方程式逆写，$\Delta H$ 变号。
- **易错**：把"燃烧热"和"中和热"的定义条件搞混；忽略物质状态（气、液、固）对 $\Delta H$ 的影响。

## 三、反例法：一句话打掉错误直觉

| 错误直觉 | 一个反例 | 打掉之后留下什么 |
|---|---|---|
| 加压一定让平衡移动 | $\mathrm{H_2(g) + I_2(g) \rightleftharpoons 2HI(g)}$ 加压，平衡不移动 | 只有"气体系数和不相等"才有移动 |
| 温度升高，正反应速率增大、逆反应减小 | 升温后正逆速率**都**增大，只是增的幅度不同 | 温度改变的是速率常数，不是单向的 |
| 有沉淀生成就是复分解 | $\mathrm{Fe + CuSO_4 = FeSO_4 + Cu}$ 有固体析出，却是置换 | 看反应物类型，不看有没有固体 |
| 盐溶液一定中性 | $\mathrm{Na_2CO_3}$ 溶液显碱性 | 看是谁的盐，弱酸根水解 |

## 五、三条提醒

1. **不要用"理解一下"结尾。** 理解是结果，不是动作。动作是"你把这四层里第三层写给我看"。
2. **模型只讲到够用为止。** 高中阶段讲"有效碰撞"就够了，不必讲活化络合物；讲"离子浓度"就够了，不必讲活度系数。超纲的部分标注清楚，别让学生以为高考要考。
3. **讲完必须让他复述一遍。** 他说得磕巴的地方，就是他以为懂的地方。
