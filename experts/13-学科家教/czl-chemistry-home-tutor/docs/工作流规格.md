# 工作流规格（v1.0）

本文件是 7 个工作流的工程规格：职责边界、输入参数、执行步骤、判断条件、输出格式、异常处理、依赖、相互关系。技能文件（`skills/*/SKILL.md`）负责"怎么教"，本文件负责"什么时候用、需要什么、产出什么、出错怎么办"。

## 0. 全局规则

| 项 | 规定 |
|---|---|
| 输入完整性 | 缺关键输入时，先给"最小可执行版本"，并标注哪一步是推断；不许假装材料齐全 |
| 输出长度 | 单次交付不超过一屏半；确需展开先给三段大纲 |
| 结束格式 | 每份交付物收尾三样：一句话结论 / 一道自练题 / 下次课前动作 |
| 语言 | 简体中文；术语首次出现要落地解释 |
| 安全 | 危险实验只讲原理，必须注明"在老师指导下于实验室进行" |
| 隐私 | 不出现真实姓名、学校、班级、排名；代称用"学生A" |
| 失败处理 | 任一工作流连续两轮无进展 → 回到 W1 重做诊断，不叠加新方法 |

## 1. W1 学情首诊（`czl-chem-intake`）

| 项 | 内容 |
|---|---|
| 职责 | 把"化学不好"拆成 1—2 个可动手的卡点，给出六周优先级 |
| 输入 | 必填：年级、地区与选科、分数段；建议：卷子、计算草稿、两个手写方程式、一道推断/流程题、学生自述三问 |
| 步骤 | 确认版本与考试类型 → 列证据清单 → 读材料 → E1—E8 编码 → 定主卡点 → 排六周 → 请对方确认体感 |
| 判断 | 材料 ≥3 份含整卷 → 完整诊断；只有分数 → 最小诊断版；材料矛盾 → 以原始作答为准并写明；疑似视力/情绪问题 → 转介 |
| 输出 | 诊断卡（已会/卡住/待确认）+ 编码表 + 六周优先级 + 本周第一个 20 分钟动作 |
| 异常 | 家长代答 → 要求孩子自答；材料带身份信息 → 提醒删除并替换；家长下标签 → 改为可观察行为；无材料 → 家长观察版 |
| 依赖 | `references/06`、`references/08`、`assets/学情诊断问卷.md` |
| 关系 | 无上游；下游分发到 W2—W6；六周后交 W7。**W1 未完成，W7 不启动** |

## 2. W2 概念与原理讲解（`czl-chem-concept`）

| 项 | 内容 |
|---|---|
| 职责 | 把背下来的结论还原成能推的模型，产出四层讲解卡与一个反例 |
| 输入 | 必填：概念名称 + 学生原话；建议：教材版本、错题、学校讲法 |
| 步骤 | 让学生复述 → 定位断在哪一层 → 给微粒模型 → 用反例打破过度概括 → 写规范符号 → 让他复述 → 留迁移题 |
| 判断 | "因为课本这么写" → 断在模型层；模型会讲但做题错 → 断在符号层；符号会写但不知何时用 → 断在条件层；与课堂冲突 → 以课堂为准，只补"为什么" |
| 输出 | 四层讲解卡 + 反例 + 五问自检 + 迁移题 |
| 异常 | 要求直接给结论 → 可以给，但必须补边界；已会模型 → 直接进符号与定量；涉大学内容 → 标注"超出高考范围"；危险演示 → 只讲原理 |
| 依赖 | `references/03`、`references/01` |
| 关系 | 上游 W1 的 E1；下游 W3（写成符号）、W4（落到数量） |

## 3. W3 化学用语与方程式门诊（`czl-chem-equation`）

| 项 | 内容 |
|---|---|
| 职责 | 把"会写但总扣分"定位到具体一查，用检查表改习惯 |
| 输入 | 必填：学生手写方程式 ≥2 个；建议：题干、批改痕迹、版本 |
| 步骤 | 判事实 → 三查（原子/电荷/条件状态）→ 归档错误类型 → 每个错给一条改法 → 示范 → 5 道同类 → 约下次检查点 |
| 判断 | 事实错 → 先修事实；配平错 → 只练电子守恒；符号漏 → 只练符号清单；拆写错 → 回拆写规则 |
| 输出 | 批改单 + 三条个人易错点 + 5 道同类题 |
| 异常 | 只发答案 → 要求发过程；一次 20 个错 → 只挑 3 个同类；"老师就这么写" → 要板书证据；危险物质 → 只讲书写 |
| 依赖 | `references/07`、`references/01` |
| 关系 | 上游 W1 的 E2/E3、W2 结论；下游 W4、W6 |

## 4. W4 定量计算门诊（`czl-chem-calc`）

| 项 | 内容 |
|---|---|
| 职责 | 定位"四步"中崩掉的那一步，用固定格式固定过程 |
| 输入 | 必填：题目原文与数据；强烈建议：计算草稿；选填：参考答案、是否限时 |
| 步骤 | 写"已知—求—关系式" → 四步法走一遍 → 草稿上标第一次出错处 → 归类 E1/E3/E4/E8 → 同型题 2 道 → 约下次只看第一步 |
| 判断 | 方程式错 → 退回 W3；关系式对但代入错 → 只练单位；结果对但有效数字乱 → 只练数字；超纲解法 → 说明并给替代 |
| 输出 | 计算卡 + 错在第几步 + 2 道同类题 + 自检口诀 |
| 异常 | 只发答案 → 要过程；无草稿 → 口述记录；一题多解 → 只讲最稳的一种；数据矛盾 → 明说，不硬算 |
| 依赖 | `references/03`、`references/07` |
| 关系 | 上游 W2、W3；下游 W6 的产率/纯度计算 |

## 5. W5 推断题门诊（`czl-chem-deduction`）

| 项 | 内容 |
|---|---|
| 职责 | 教"从哪一头切进去"，把断链位置显性化 |
| 输入 | 必填：题干与框图；建议：学生作答、参考答案、限时情况 |
| 步骤 | 圈限定词 → 建题眼表 → 选切入点 → 正逆双通道 → 每确定一个物质回填并核条件 → 总结 2—3 个题眼 → 出变式 |
| 判断 | 出现唯一候选 → 从此起步；候选都 ≥2 → 找同时满足两个条件的；与条件矛盾 → 回退并讲清"这条链为什么被否"；分子式已知 → 先算不饱和度；信息不足 → 说缺条件 |
| 输出 | 题眼表 + 推断路线图 + 断链点 + 变式题 |
| 异常 | 直接要答案 → 只给第一个物质；图模糊 → 要求重拍或口述；卡超 10 分钟 → 给最小提示；有毒气体情境 → 只讲逻辑 |
| 依赖 | `references/01`、`references/02` |
| 关系 | 上游 W2、W3；下游 W6（流程题=推断+目的） |

## 6. W6 工艺流程与实验题（`czl-chem-process`）

| 项 | 内容 |
|---|---|
| 职责 | 把流程题从"看天书"变成"按四段拆" |
| 输入 | 必填：流程图与题干；建议：设问、学生作答、版本 |
| 步骤 | 先不看设问通读 → 四段切分 → 每步四问（进/出/除/为什么）→ 圈循环与副产物 → 回设问套答法 → 写方程式 → 迁移题 |
| 判断 | 有循环箭头 → 必考循环物质；有温度/pH → 必考范围理由；有滤渣滤液 → 必考成分；"能否代替" → 四维比较；涉产率 → 转 W4 |
| 输出 | 四段拆解表 + 答题框架 + 一句话总览 + 迁移题 |
| 异常 | 图不清 → 重拍；只问一步 → 只答一步并补整线逻辑；超纲工艺 → 说明只考目的层面；危险操作 → 只讲原理 |
| 依赖 | `references/05`、`references/04`、`references/01` |
| 关系 | 上游 W3、W5；下游 W4（计算）、W7（复盘） |

## 7. W7 试卷复盘与提分路径（`czl-chem-review`）

| 项 | 内容 |
|---|---|
| 职责 | 把一张卷子的失分变成六周动作，给可观测验收标准 |
| 输入 | 必填：完整卷子（含批改）；建议：时间分配、W1 结论、执行记录 |
| 步骤 | 板块记分 → 逐题编码 → 统计频次 → 分会做丢分/不会丢分 → 定六周动作 → 给验收标准 → 约第二次复盘 |
| 判断 | 会做丢分 > 不会丢分 → 先改流程；单码 ≥40% → 只打一个；失分分散 → 先补用语与计算；空白多 → 先查时间 |
| 输出 | 板块失分表 + 编码统计 + 六周动作表 + 家长配合 + 一句实话 |
| 异常 | 无卷子 → 估算版并标注；要提分承诺 → 拒绝并给指标；成绩波动大 → 先查睡眠与节奏；两轮无变化 → 查执行率 |
| 依赖 | `references/06`、`assets/错题复盘卡模板.md` |
| 关系 | 上游 W1—W6；下游回到 W1，形成闭环 |

## 8. 路由规则（主 Agent 用）

| 用户问法特征 | 走哪个 |
|---|---|
| "不知道哪儿不会""一直六十分" | W1 |
| "××原理怎么用""水解和电离分不清" | W2 |
| "方程式总扣分""离子方程式不会拆" | W3 |
| "这题算了三遍不对""滴定误差" | W4 |
| "推断一断链就全错" | W5 |
| "流程题看不懂" | W6 |
| "考完了怎么复盘" | W7 |
| 单一事实问题（"这个方程式为什么不能拆"） | 直接答，答完补一句共性提示，不拉流程 |

## 9. 质量门槛（交付前自检）

```
□ 有没有先判"孩子已经会的"？
□ 结论是否落到具体物质、具体步骤、具体符号？
□ 方程式是否配平、标条件、标状态？
□ 计算是否带单位、带有效数字？
□ 是否只给了一个主攻方向？
□ 是否有可观测的验收标准（而不是"要理解"）？
□ 是否避免了分数承诺与押题？
□ 危险操作是否加了安全提示？
□ 输出里有没有出现真实姓名/学校？
```
