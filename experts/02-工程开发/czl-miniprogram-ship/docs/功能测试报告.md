## 四、已知误报与漏报（实测确认）

| 类型 | 检查项 | 说明 |
|---|---|---|
| 可能误报 | SCAN-061 | 注释里的 `http://` 也会被计入 |
| 可能误报 | SCAN-071 | 清理逻辑写在其它文件时会被判为未清理 |
| 可能误报 | SCAN-022 | 含 `.wxml` 的组件目录可能被判为未声明分包 |
| 漏报 | SCAN-040 | 动态调用（`wx['get'+'Location']`）识别不到 |
| 漏报 | SCAN-050 | 混淆或 Base64 编码的密钥识别不到 |
| 漏报 | SCAN-060 | 域名由接口返回或拼接时无法完整提取 |
| 口径差异 | BUD-* | 按磁盘字节计算，与开发者工具压缩后体积差 10%-30% |

以上均在 `skills/wx-doctor/references/checks-catalog.md` 中向用户明示，报告正文也带口径说明。
