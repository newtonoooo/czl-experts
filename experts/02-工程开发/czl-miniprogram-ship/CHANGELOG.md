# 更新日志

本包版本独立编号，遵循语义化版本 `MAJOR.MINOR.PATCH`。

## 1.0.0 — 2026-10-28

首个发布版本。独立开发，不是任何现有专家包的改名或改写。

### 新增

**主 Agent（七道工作流）**

- W0 立项收口 → W1 骨架与预算 → W2 页面与组件 → W3 能力接入 → W4 云开发数据层 → W5 体检与提审预检 → W6 驳回整改
- 每个工作流写清职责、输入、步骤、判断条件、输出、异常处理、依赖、上下游关系
- 六条硬规则：无条目不开工、无预算不写页面、无脚本输出不说"通过"、不编造版本与规则、密钥不出前端、敏感类目先谈资质
- 交付台账五段结构（工程事实 / 条目进度 / 能力清单 / 未决与风险 / 提审记录）

**技能库（6 个）**

| 技能 | 内容 |
|---|---|
| `wx-scope` | 条目写法细则、选型口径、一页方案模板、台账工具 `ledger.py` |
| `wx-skeleton` | `app.json` 易错清单、分包与体积预算方法、规格文件模板 |
| `wx-page` | 列表/表单/弹窗/骨架屏实现要点、组件接口契约、页面与组件四件套模板 |
| `wx-capability` | 登录态链路、支付时序与幂等、隐私三层结构、订阅消息与分享红线 |
| `wx-cloud` | 集合建模、安全规则三态、云函数四段结构、越权自测三条 |
| `wx-doctor` | 体检工具、检查项目录（含每条盲区）、提审材料清单、排查树 |

**可执行工具（纯 Python 标准库，零第三方依赖）**

- `wx_doctor.py scan` —— 24 项静态检查，覆盖页面四件套、分包声明、tabBar、组件引用、隐私接口声明、密钥泄露、外链域名、代码坏味
- `wx_doctor.py budget` —— 主包/分包字节核算、85% 余量红线、超限定位、大文件排行、图片占比
- `wx_doctor.py preflight` —— 提审材料清单、采集接口清单、域名清单、类目合规提示
- `wx_doctor.py scaffold` —— 按规格生成含三态页面的可运行骨架
- `ledger.py` —— 条目台账，四态状态机，未绑文件的条目拒绝标记完成

**其它**

- 原创头像（512×512 PNG，1:1 扁平矢量风格）
- 一页方案模板、规格文件示例、云函数模板
- 使用说明、示例走法、许可与来源声明

### 已知限制

- 不覆盖真机表现、视觉质量、审核口径判断
- 体积按磁盘字节计算，与开发者工具压缩后体积存在 10%-30% 差异
- uni-app / Taro 需指向编译产物，否则结构检查结论仅供参考
- 平台上限与规则以官方文档为准，包内常量需随官方调整
