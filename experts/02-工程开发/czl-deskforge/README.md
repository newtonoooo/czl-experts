## 一、这是什么

一个**做台子的手艺人**。你说一句"我想记一下每天的学习情况"，它给你一个**单独的 HTML 文件**：双击就开，断网能用，手机电脑都行，数据在你自己浏览器里。

它不是"生成一段网页代码"的工具。它走完五道工序才交付，中间有三道闸门卡着：

```
收束 → 建模 → 装配 → 体检 → 上线
  │      │      │      │
  └──────┴──────┴──────┘
     三道闸门：模块 ≤4 / 数据有账 / 出厂零错误
```

**它和"堆模块清单"的做法不同**

| | 常见做法 | 桌匠 |
|---|---|---|
| 模块从哪来 | 预置一批模块，按场景挑 | **五种卡片原语**（清单 / 矩阵 / 表单 / 指标 / 时间）加参数配出来 |
| 质量靠什么 | 提示词里写一堆规范条目 | 规范 + **三个可执行的静态检查脚本**，出厂单附原始输出 |
| 交付什么 | 一个文件或一个链接 | **收束卡 + 数据账 + 工作台 + 出厂单** 四件 |
| 需求怎么定 | 对话里说说 | **收束卡**落成文件，模块超 4 个直接拒绝 |
| 出问题怎么办 | 事后补 | 装配过程一块一存档，坏了回滚，不边坏边修 |

## 二、五种卡片

所有模块都由这五种拼出来。参数见 `skills/deskforge-build-kit/references/card-primitives.md`。

| 原语 | 长什么样 | 典型用途 |
|---|---|---|
| **清单卡** | 一条一条的行，可勾 | 待办、错题、素材、跟进 |
| **矩阵卡** | 行 × 列小方格，按值染色 | 打卡热力、熟练度、复习计划 |
| **表单卡** | 上面填、下面提交 | 记一笔账、记一次训练 |
| **指标卡** | 大数字 + 环 / 柱 / 折线 | 本月支出、连续天数、完成率 |
| **时间卡** | 倒计时、日历格、今天/本周分组 | 考前倒计时、周计划、逾期顺延 |

组合规矩：一个模块 = 1 张主卡 + 0–2 张辅卡；表单卡必须有清单卡承接；指标卡必须写清口径。

## 三、三道闸门

| 闸门 | 卡什么 | 不过会怎样 |
|---|---|---|
| **收束闸** | 模块 ≤4；每块能答"填什么/看什么/据此判断什么" | 出分期表，本期只做 3 块 |
| **建模闸** | 字段有类型有示例；键名带 `czl_desk_` 前缀；3–5 条种子含 1 条逾期 | 不许开始写页面 |
| **出厂闸** | `blueprint_lint.py` 与 `dom_probe.py` error 为 0；人工四项走查通过 | 不交付 |

## 五、三十秒上手

```
「给我搭一个备考打卡台：每天记刷题量和错题，倒计时到考前，再看最近两周的趋势。今天要做的放最上面。」
```

它会先给你一张《收束卡》确认三块内容，再给数据和文件，最后附体检结果。

其他开场：

- 「想要一个我能坚持用的记账台，别让我把账弄丢」→ 收束 + 表单卡 + 指标卡
- 「孩子每天跳绳打卡，要有积分」→ 矩阵卡 + 指标卡（给孩子用会放大到 50px）
- 「这是上次搭的，跑一遍出厂体检，告诉我手机上哪里会出问题」→ 直接进工序 ④

## 六、三个检查工具

纯 Python 标准库，不联网、不装依赖：

```bash
python scripts/blueprint_lint.py --file 台子.html --prefix czl_desk_
python scripts/dom_probe.py --file 台子.html
python scripts/spec_card.py --input 需求.json --out 收束卡.md
```

| 工具 | 查什么 |
|---|---|
| `blueprint_lint.py` | 外链、emoji 图标、输入字号 <16px、点击区 <44px、存储键前缀、模块 >4、体积、viewport、安全区、TODO 残留 |
| `dom_probe.py` | `getElementById` 目标缺失、渲染函数互调成环、初始化入口不唯一、未定义调用 |
| `spec_card.py` | 模块 >4 拒绝、字段缺类型/缺示例、枚举缺取值、卡原语非法 |

退出码：`0` 通过 / `1` 有警告 / `2` 有错误。

## 七、它不做什么

不做账号、不做协作、不做推送、不存大文件、不做后台。一个个人自用的台子，加这些只是给自己添麻烦。
