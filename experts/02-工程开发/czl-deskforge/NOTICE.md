# 开发独立性与第三方说明 · NOTICE

**桌匠（czl-deskforge）v1.0.0**

本文件回答商业发布最容易被质疑的三个问题：这个包是谁写的、有没有拿别人的东西、能不能对外卖。

## 一、独立性声明

**本包为独立开发，不是改名移植。**

开发过程中的信息来源分为三类，分别处理如下：

| 来源 | 用途 | 处理方式 |
|---|---|---|
| **功能需求**（"做个人工作台"这件事要解决什么问题） | 用于写《产品规格说明》 | 只提取需求层面的问题清单（用户是谁、缺什么、要什么输入输出、验收标准），**不抄任何实现文本** |
| **通用技术**（HTML/CSS/JS、localStorage、SVG、响应式、JSON 导入导出） | 实现手段 | 属公共知识范畴，按通用做法实现 |
| **平台规范**（WorkBuddy 专家包目录结构、plugin.json 字段、校验脚本） | 打包合规 | 按平台规范执行，不是第三方创作内容 |

**明确未使用的部分**：

- 未复制任何现有专家的系统提示词、章节结构、条目化规范（如"若干条铁律"式组织）、工作流定义、示例数据、宣传文案；
- 未复制任何代码，包括页面模板、脚本片段、CSS 规则集；
- 未使用任何现有专家的头像、图标、配色方案或视觉资产；
- 未删除、未修改任何第三方包的版权声明（本机原有专家包均保持原样，只做只读分析）。

**功能重叠的说明**：本产品与市面上"个人工作台"类工具在**功能目标**上必然重叠（都要单文件、都要响应式、都要本地存数据），这属于品类共性；本包在模块组织方式（五种卡片原语）、质量保障方式（三个静态检查脚本 + 出厂单）、交付形态（四件套）上采用了不同的设计，具体差异见《产品规格说明》第十节。

## 三、第三方依赖核查

| 类别 | 是否打包 | 许可影响 |
|---|---|---|
| Python 标准库（`re`/`json`/`argparse`/`pathlib`/`sys` 等） | 否（随 Python 提供） | 使用 PSF 许可的运行时，不修改、不再分发 |
| 前端框架 / 图表库 / 图标字体 | **完全不使用** | 无 |
| 字体文件 | **不使用**（系统字体栈） | 无 |
| 图片素材 | **不使用**（图标全部内联 SVG path，本次手写） | 无 |
| 头像 | 是（AI 生成） | 由生成工具服务条款约束，发布前需按平台规则标注 AI 生成 |

**结论**：本包无第三方代码依赖，因此**不需要附带任何第三方许可证**，也不存在 GPL/AGPL 类传染性许可风险。
