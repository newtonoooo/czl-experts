# 专业建站上线专家

**开发者：虫志龙（47190078@qq.com）｜版本 1.0.0｜分类：技术工程**

把网站当交付物做，不当页面做。一个站从想法到上线走八道闸：立项、选型、骨架、页面、索引、
无障碍与体积、上线预检、上线后观察。每道闸都有明确的判据和产出，没过不许往下走。

## 它解决什么问题

网站出问题，很少是"代码不会写"，多是这样几件事：

- 需求没定死就开工，改到第七版还在改首页文案；
- 页面能打开，但手机端错位、读屏器读不出、搜不到；
- 照片按原图上传，首屏 4MB，用户两秒就走；
- 上线时把 `.env` 一起传了，或者上线后出事不知道退回哪一版。

这四类问题，本专家用"闸门 + 脚本"处理，不靠记性。

## 五个脚本（零第三方依赖，Python 3.8+）

| 脚本 | 用途 | 判定 |
|---|---|---|
| `project_scan.py` | 扫项目：类型、产物、上线素材、环境文件 | 输出结构报告 / JSON |
| `audit_html.py` | 静态体检 23 条规则：结构、可访问性、元信息 | 有阻塞或高危则退出码 2 |
| `budget_check.py` | 按 gzip 实测体积对预算（JS/CSS/图/合计） | 超预算退出码 2 |
| `seo_files.py` | 查每页 title/描述/canonical，生成 sitemap 与 robots | 可 `--write` 落盘 |
| `deploy_preflight.py` | 上线前 15 项：密钥、localhost、404、sourcemap、回滚标识 | 有阻塞则拒绝上线 |

脚本自带测试：`python tests/run_tests.py`（29 条用例，覆盖正常站、问题站、泄密产物、超预算产物）。

## 八道闸

| 闸 | 名称 | 产出 |
|---|---|---|
| W1 | 立项 | 一页立项单，含"本期不做" |
| W2 | 选型 | 三句话结论 + 目录骨架 |
| W3 | 骨架 | 可运行空壳 + README |
| W4 | 页面 | 完整页面代码 |
| W5 | 索引 | 元信息 + sitemap + robots |
| W6 | 无障碍与体积 | 体检报告 |
| W7 | 上线预检 | 上线手册（含回滚） |
| W8 | 上线后观察 | 72 小时观察表 + 复盘 |

## 怎么用

装上后直接说需求即可，例如：

- 「我想做个公司官网，现在只有一句话的想法。先把立项单跟我定清楚，再给选型结论和一版能跑起来的第一页。」
- 「这站下周要上线。把预检跑一遍：密钥泄露、本地地址残留、404 缺不缺、robots 和 sitemap，再告诉我上线出问题到底怎么退回去。」
- 「从代码层面体检这个站：无障碍、元信息 SEO、资源体积。按严重程度列出问题和规则编号、所在文件，然后把阻塞项直接改掉。」

## 边界

- 不承诺排名、流量、转化率；SEO 只谈可验证的结构与内容问题
- 不代做 ICP 备案、不代办域名实名，只给流程与材料清单
- 不做视觉设计定稿，不做后端业务系统
- 未经确认不执行部署、不改 DNS、不动生产环境变量

## 安装与打包

```bash
# 安装：放入专家目录后注册
python scripts/register_expert.py <专家目录>

# 打包分享
python scripts/package_expert.py <专家目录> <输出目录>
```
