## [1.0.0] - 2026-10-27

首个公开发布版本。独立开发，从零构建，非改名发布。

### 新增 · 定位与架构

- 确立产品定位：**产品决策审校**，不是文档代笔。核心判据为"拿到会上会不会被一句话问倒"。
- 建立**五道闸**主工作流：G1 分诊 → G2 证据 → G3 口径 → G4 对抗 → G5 交付，前闸不过不进后闸。
- 建立**决策类型路由表**：八类问法映射到对应技能与主交付物，避免所有请求都走同一套重流程。
- 建立**执行/决策分流**规则：纯执行问题不套决策框架。

### 新增 · 证据体系

- 定义五级证据标尺：A 一手行为数据 / B 一手原文 / C 公开可核事实 / D 转述二手 / X 无来源。
- 确立四条硬规则：结论等级取最强单条证据；同级矛盾降一级；投入与砍单类结论不得低于 B；对外宣称不得低于 C 且须带日期。
- 规定 X 级唯一合法形态为"假设 + 证伪方式"，禁止写成结论句。
- 新增反例检索纪律：找不到时只能写"未找到反例（范围、时间）"，不能写"没有反例"。
- 新增八条争议判例（截图数字、录音原话、官网宣称、11 人访谈、行业报告、自跑实验、流失问卷、模型推断）。

### 新增 · 指标口径

- 建立**六步口径流程**：口径卡 → 波动带 → 样本充分性 → 口径漂移 → 辛普森检查 → 归因候选。
- 明确判定只能写四种：真实变化 / 在正常波动内 / 口径变更不可比 / 样本不足。
- 归因候选表要求同时列出"部分支持""无证据""排除"三种状态，禁止只列支持结论的行。

### 新增 · 对抗与止损

- 建立**失效条件**固定写法："如果 ___ 在 ___ 内出现，则本结论不成立，应改为 ___"。
- 建立六类产品专有死因清单（没人需要 / 用不起来 / 算不过账 / 被替代 / 组织不接 / 活不下来）。
- 规定**止损线三要素**（投入上限、检查点、判定信号），缺一不许交付。
- 新增续投四档判定（加大投入 / 维持 / 冻结 / 下线）与下线四步前置动作。
- 新增七项偏差对照表（沉没成本、确认偏误、锚定、损失厌恶、社会证明、可得性、权威）。

### 新增 · 交付与组合

- 建立 **DoR 八项**与 **DoD 七项**，明确"功能开发完"不等于完成。
- 规格书定八节结构，每节给出精度要求与常见不合格写法。
- 验收标准强制一对一映射测试用例，异常路径数量应不少于正常路径的 1/3。
- 引入**变更成本账簿**：每次变更必须写"挤掉了什么"；累计超原估 30% 重过 G1。
- 组合取舍改用**装箱**而非排序：真实产能 = 人数 × 周数 × 有效投入 − 预留，必做项先扣，按密度装填。
- 新增三类对上的说法模板（砍范围 / 加人 / 改周期），要求每个选项都有代价。

### 新增 · 受众渲染

- 五类受众档案（高管 / 工程 / 跨部门 / 客户 / 董事会），各自的长度、入口句与证据密度。
- 状态色纪律：黄不是失败，升级要有触发条件，降级要写原因。
- 坏消息固定五段顺序，列明五种禁止写法（"由于一些原因""正在积极推进中""影响不大""争取""先说好消息"）。
- 请求写作规则：把"希望支持"改成带截止时间的具体动作。
- 一页决策记录格式，含"什么情况下重议"必填项。

### 新增 · 工具（纯标准库）

- `evidence_check.py`：台账机械体检。检查非法等级、D/X 级越级措辞、小样本百分比、反例检索缺失、单一来源依赖、结论越级、用途门槛（invest/cut/public/price/explore）。支持 `--json`、`--strict`。
- `metric_guard.py`：四个子命令。`card` 校验口径卡字段与含糊措辞；`baseline` 用中位数 + MAD 稳健带区分信号与噪声；`ab` 做两比例 z 检验并给 Wilson 区间、差值区间、MDE 与所需样本量；`simpson` 对比合计与组内加权方向，检出反转。
- `portfolio_fit.py`：产能校准 + 必做项预留 + 密度装填 + 吞吐比对 + ±20% 敏感性（脆弱项）+ 砍单原因 + "被体积挤掉的高产出项"提示。
- 三个脚本均提供固定夹具，覆盖正例、反例与非法输入。

### 新增 · 测试

- `tests/run_tests.py`：44 项回归断言，覆盖三个脚本的正常/异常/边界路径，以及包结构与元数据一致性（含头像尺寸与体积、frontmatter 禁 tools 字段、displayDescription 字数、tags/quickPrompts 数量、defaultInitPrompt 一致性）。
- 首次全量运行：44/44 通过。

### 新增 · 文档

- `README.md`：定位、差异化对照、五闸、七技能、三脚本、三场景、交付物、目录结构、适用范围、已知限制。
- `docs/产品规格说明.md`：目标用户、场景、问题、输入输出、处理步骤、工具接口、质量与性能要求。
- `docs/使用说明.md`：五种典型用法、提问方式、怎么读输出、常见误用。
- `docs/文件清单与开发记录.md`：逐文件职责、创作来源、开发时序、相似度审计结果。
- `docs/测试报告.md`：测试范围、用例清单、实际执行输出、未验证事项。
- `docs/平台展示文案.md`：上架用的名称、简介、详细介绍、标签、推荐问法（长短两版）。
- `docs/商业发布风险清单.md`：版权、许可、生成内容、平台规则、数据合规五类风险与处置建议。
- `LICENSE`：自定义商业使用许可 v1.0，明确授权范围、限制、方法论排除条款、免责与终止。

### 已知限制（v1.0.0）

- 不替代真实用户研究；无访谈数据时只给取证清单。
- 统计检验假设独立同分布，不处理埋点漏报与样本污染。
- 产能利用率默认 0.65，需按团队历史校准。
- 竞品信息依赖检索，可能滞后，已在文档中强制标注日期要求。
