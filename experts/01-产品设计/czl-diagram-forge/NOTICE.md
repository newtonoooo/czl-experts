# 第三方组件与权利说明

## 一、本包不含任何第三方代码

`czl-diagram-forge` 的全部运行时代码均为本项目独立编写，仅使用编程语言标准库：

| 运行环境 | 使用的库 | 性质 |
|---|---|---|
| Node.js（渲染引擎、CLI、自检） | `node:fs`、`node:path`、`node:url`、`node:os` | 语言标准库，随运行时提供 |
| Node.js | `zlib` 无需直接调用（PNG 编解码在 Python 侧） | — |
| Python（头像体检工具） | `json`、`os`、`struct`、`sys`、`zlib` | 语言标准库 |

- **无** npm 依赖，**无** `node_modules`
- **无** 打包进本项目的第三方源码、字体文件、图标资源
- **无** 运行时网络请求，不调用任何在线渲染服务

因此本包不涉及第三方代码的商业分发许可问题。

## 五、AI 生成内容说明

头像由 AI 图像生成模型生成。生成后经以下处理：裁去生成工具附加的水印区域、居中裁切为正方形、降采样至 512×512、重新编码为 PNG。

依据所在司法辖区的不同，纯 AI 生成图像的著作权归属可能存在差异。本包在 `LICENSE` 中声明的是**代码与文档**的 MIT 许可；头像的使用范围建议在实际商业化前结合发行平台的规则确认。
