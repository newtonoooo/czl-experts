## 三、功能风险

### R9 已知功能局限 —— 中风险（可能引发差评）

| 局限 | 影响 | 缓解 |
|---|---|---|
| 不支持从 `.mmd` 反向重建模型 | 用户拿着现成 Mermaid 想"重排版"，只能得到语法体检与建议 | README 与 SKILL.md 已明确写出；介绍文案未宣称支持 |
| 时序图无激活条、无嵌套 fragment | 复杂时序图表达力不足 | 文档已列出 |
| 思维导图仅横向树形 | 无法做环形/双向 | 文档已列出 |
| ASCII 不含饼图/四象限/柱线图图形 | 这三类只出列表 | 文档已列出 |
| 长链条（≥8 层）横排后过宽 | 缩放到文档宽度字号偏小 | 质量分主动提示"建议拆图" |

### R10 输出质量依赖输入质量 —— 低风险

质量分只能拦住**结构问题**（孤立节点、判断缺分支等），拦不住**业务错误**（流程本身写错了）。产品文案中未承诺"保证业务正确"。

### R11 环境依赖 —— 低风险

- 需要 Node.js ≥ 18。若用户环境无 Node，`render` 无法执行
- 已在 README 写明；纯 Python 的头像工具不受影响
- 未在 Node 18/20 实测（见测试报告第八节）
