# 更新日志

本项目遵循语义化版本（MAJOR.MINOR.PATCH）。日期格式 YYYY-MM-DD。

## [1.0.0] — 2026-10-28

首个公开版本。自研渲染引擎，零第三方依赖，完全离线。

### 新增

**图表类型（11）**
- 流程图 `flow`：支持 10 种节点形状、3 种线型、双向箭头、分组子图
- 状态图 `state`：状态迁移 + 起止伪状态
- 类图 `class`：5 种关系（继承/组合/聚合/关联/依赖）、构造型、成员分栏
- ER 图 `er`：PK/FK 角标、鸦爪基数符号
- 时序图 `sequence`：同步/异步/返回三类消息、注释、loop/alt/opt/par 逻辑块
- 甘特图 `gantt`：分段任务、里程碑、关键路径、日期或天数偏移
- 思维导图 `mindmap`：横向树形、层级自动配色
- 时间轴 `timeline`：上下交错卡片
- 饼图 `pie`：环形图 + 图例百分比
- 四象限 `quadrant`：双维度散点评估
- 柱线图 `xy`：柱状 / 折线 / 面积混合

**主题（12）**
- 浅色：graphite、paper、ocean、mint、sand、sakura
- 深色：midnight、carbon、nordic、forest、plum、slate
- 语义令牌 + 7 色角色板，换主题不重排

**输出格式（4）**
- SVG：矢量，含生成标记与 `<title>`
- HTML：单文件交互预览，支持主题切换、缩放、平移
- Mermaid：标准源码，可粘贴到任意支持 Mermaid 的平台
- ASCII：终端等宽文本图

**引擎**
- 分层图布局：环检测 → 最长路径分层 → 重心法排序 → 正交路由
- 四向布局变换：TB / LR / BT / RL，未指定时按结构画像自动选择
- 跨层边与回边走侧向通道，避免穿越中间层节点
- 中日韩文字全角计量，中英混排换行不截断词
- 边标签自动避让，绘制顺序在节点之上，不会被填充遮挡

**质检**
- `check`：模型结构校验（悬空边、重复 id、分组冲突、字段类型）
- `check`：Mermaid 源码静态体检（括号、块配对、空标签、特殊字符），精确到行号
- `review`：100 分制质量评分，每条扣分对应一个具体可读性问题

**工具**
- `selftest.mjs`：86 项自检，覆盖 11 类型 × 12 主题渲染矩阵与非法输入
- `avatar_check.py`：专家头像体检与规范化（纯标准库 PNG 解码/降采样/编码）

**文档**
- 六条工作流定义（分诊 / 建模 / 体检 / 渲染 / 复核 / 交付）
- 模型字段全表、Mermaid 语法速查、主题说明、CLI 参考、评分细则
- 11 份可直接运行的模板

### 已知限制
- 不支持从 `.mmd` 反向重建模型
- 时序图不支持激活条与嵌套 fragment
- 思维导图仅横向树形布局
- ASCII 输出不含饼图、四象限、柱线图的图形化表达（退化为列表）

### 兼容性
- Node.js ≥ 18
- 无第三方运行时依赖
- 无网络请求
