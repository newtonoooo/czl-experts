## 它解决什么问题

产品工作里最贵的浪费，不是写错一份文档，是**五份文档互相对不上**：

- 规格里写了 7 条需求，路线图里只剩 5 条，另外 2 条不知去向
- 汇报里说"转化提升 15%"，指标表里的目标值是 8%
- 每条结论都写得很肯定，但没人说得出这个数字是从哪来的
- 排期看起来排满了，但没人算过 6 个人 13 周到底能交付几个人周
- 风险章节写"风险可控"，等于没写

这个作战室用三件事把这些洞堵上：**证据分级、产能装箱、一致性闸**。

## 五个席位

| 席位 | 职责 | 你会拿到的产出 |
|------|------|----------------|
| **祁略** · 战略总参（主理人） | 立案、编排、四道闸、汇报改写、最终交付 | 决策简报、汇报包、一致性报告 |
| **柯证** · 证据官 | 用户与竞品取证，逐条判 A/B/C/D/X | 证据台账（CSV + MD） |
| **简文** · 需求架构师 | 需求规格、验收标准、范围台账 | 需求规格（九节） |
| **权衡** · 产能与优先级规划师 | 人周测算、装箱、砍单清单、止损线 | 产能排产（CSV + MD） |
| **验数** · 指标口径师 | 口径卡、护栏指标、口径体检 | 指标口径表 |

## 六段链与四道闸

```
S1 立案 → S2 取据 → S3 成文 → S4 排产 → S5 度量 → S6 汇报
   G1        G2                 G3                    G4
```

| 闸 | 拦什么 | 不通过会怎样 |
|----|--------|--------------|
| G1 立案闸 | 目标/用户/问题/成功定义/边界 五项不全 | 停下来问你，最多 3 个带选项的问题 |
| G2 证据闸 | 事实陈述没有出处，或 X 级证据被当结论 | 降级为假设，附最低成本取证动作 |
| G3 一致闸 | REQ/AC/MET/RM 断链，同一数字三处不一致 | 以口径表为准回改，不许各写各的 |
| G4 交付闸 | 行动没负责人、方案没止损线、Non-goals 不足 3 条 | 补写，补不出就删掉该方案 |

## 和通用产品助手有什么不同

| 常见做法 | 这里的做法 |
|----------|------------|
| 给一套 PRD 模板让你填 | 先过立案卡五问，答不出两项就不往下跑 |
| 每条结论都写得很肯定 | 每条事实标 EVD 编号与 A/B/C/D/X 等级，X 级只能写成假设 |
| 竞品分析凭印象写 | 只采公开可核实信息，标抓取日期，只看到宣传语最高判 C |
| 排完 RICE 分数就交差 | 算真实人周（人数 × 周数 × 专注系数），按依赖装箱，给砍单清单 |
| 指标掉了直接给归因 | 先查口径、查分母、查波动带、查辛普森反转，再说可能原因 |
| 风险写"风险可控" | 每个承诺写止损线：什么信号出现就停手 |
| 五份文档各写各的 | 交付前跑一致性脚本，断链和数字冲突逐条列出来 |

## 三个可直接用的开场

**1. 从零立项**
> 老板说要做 AI 助手，但没说给谁用、解决什么。我手上只有 8 条客户抱怨和一份竞品截图，帮我把它变成能立项的方案。

**2. 季度排产**
> 下季度 11 个候选需求，团队 6 个人，13 周。帮我定出真能做完的，并写清楚砍掉什么、砍了怎么跟老板交代。

**3. 指标复盘**
> 上个季度 MAU 涨了 9%，付费转化掉了 12%。先把口径和分母查清楚，再告诉我会上该怎么回答。

## 内置校验脚本

| 脚本 | 作用 | 什么时候跑 |
|------|------|------------|
| `evidence_grade.py` | 复算证据等级，抓无出处/无分母/绝对化措辞 | 柯证回传前 |
| `spec_lint.py` | 九节齐全性、AC 可测性、P0 占比、占位符 | 简文定稿前 |
| `capacity_pack.py` | 产能测算、依赖装箱、承诺率、超载告警 | 权衡出排产前 |
| `metric_check.py` | 口径卡完整性、辛普森反转检测 | 验数出表前 |
| `chain_check.py` | 跨文档断链与数字冲突 | 主理人交付前 |

全部纯标准库，无网络调用，可离线运行。用法见 `docs/使用说明.md`。

## 安装

1. 把整个 `czl-product-strategy-warroom` 目录放到 WorkBuddy 的本地专家市场目录：
   `~/.workbuddy-ai/plugins/marketplaces/my-experts/plugins/`
2. 确认 `~/.workbuddy-ai/plugins/marketplaces/my-experts/.codebuddy-plugin/marketplace.json` 里有对应条目（本包已附带注册脚本说明，见 `docs/使用说明.md`）
3. 重启 WorkBuddy，在专家列表中搜索「产品战略作战室」

**关于头像显示**：团队型专家的列表图标取自主理人（lead）成员的头像，且相对路径必须能被本地解析。本包所有头像为 384×384 PNG、单文件 < 250KB，并显式提供 `assistantAvatarUrl`。详细排查过程见 `docs/头像图标显示问题排查报告.md`。

## 已知限制

- 不会替你去查真实竞品网站。需要联网取证时，由主理人调用可用的检索能力，取证结果同样要过证据分级。
- 产能测算依赖你提供的人数和周期。你不给，它会停下来问，不会替你假设"资源充足"。
- 一致性脚本只做结构校验，不能判断业务判断对不对。它保证的是"文档之间不打架"，不是"结论一定正确"。
- 中文为主。英文输入可处理，但模板与话术以中文为准。
