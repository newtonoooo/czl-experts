## 一句话

你带着一件"还没想清楚、但已经有人在催"的事来，拿走一套**彼此对得上、能被追问、能被叫停**的决策包。

判断标准：这份包拿进会议室，会不会被一个认真的人一句话问倒。

---

## 为什么是"一个人五顶帽子"

产品链路要五件事：立案、取据、成文、排产、度量。团队版是五个 AI 各干一件；这一版是**一个 AI 按顺序戴五顶帽子**，每顶帽子只干一件事，干完落盘，再换下一顶。

关键不在"人少"，在**换帽时必须先落盘**——下一顶帽子只许读文件，不许依赖"我刚才想到过"。这条规矩把"自己审自己"的模糊地带压缩掉了大半。

| 帽 | 岗位 | 产出 |
|----|------|------|
| A | 立案官 | 立案卡（五要素 + 档位判定） |
| B | 证据官 | 证据台账（A/B/C/D/X + 反证候选） |
| C | 需求架构师 | 需求规格（九节 + 可测验收） |
| D | 产能规划师 | 产能排产（人周装箱 + 砍单清单 + 止损线） |
| E | 指标口径师 | 指标口径表（口径卡 + 护栏） |
| F | 参谋本人 | 决策简报 + 汇报三版 + 一致性报告 |

## 和团队版的区别

| 维度 | 团队版（作战室） | 单人版（本包） |
|------|------------------|----------------|
| 形态 | 1 主理人 + 4 席位，5 个 Agent 协作 | 1 个 Agent，内部轮换 5 顶帽子 |
| 速度 | 有编排与消息中转开销 | 直接往下跑，更快 |
| 对抗性 | 强：别人审你的证据 | 中：靠"反证义务 + 红队段落 + 脚本裁决"对冲 |
| 适用 | 决策金额大、不可逆、需要交叉验证 | 日常立项、季度规划、快速出包 |
| 输出 | 同一套文件与编号体系 | 同一套文件与编号体系 |
| 技能与脚本 | 7 技能 + 5 脚本 | 完全相同 |

**单人的真实局限**：你写的证据还是你自己审。所以本包强制三条对冲动作——每条 A/B 级结论必须写"反证候选"、汇报前必须写"三条最强否决理由"、自评冲突时以脚本为准。缺了这三条，单人版不如不做。

## 六段链与四道闸

```
S1 立案 → S2 取据 → S3 成文 → S4 排产 → S5 度量 → S6 汇报
   G1        G2                 G3                    G4
```

| 闸 | 拦什么 |
|----|--------|
| G1 立案闸 | 目标/用户/问题/成功定义/边界 五项不全 → 停下来问，最多 3 个带选项的问题 |
| G2 证据闸 | 事实没出处，或 X 级证据被当结论 → 降级为假设 |
| G3 一致闸 | REQ/AC/MET/RM 断链，同一数字多处不一致 → 以口径表为准回改 |
| G4 交付闸 | 行动没负责人、方案没止损线、Non-goals 不足 3 条 |

## 三个可直接用的开场

**1. 从零立项**
> 老板说要做 AI 助手，但没说给谁用、解决什么。我手上只有 8 条客户抱怨和一份竞品截图，帮我把它变成能立项的方案。

**2. 季度排产**
> 下季度 11 个候选需求，团队 6 个人 13 周。帮我定出真能做完的，并写清楚砍掉什么、砍了怎么跟老板交代。

**3. 指标复盘**
> 上个季度 MAU 涨了 9%，付费转化掉了 12%。先把口径和分母查清楚，再告诉我会上该怎么回答。

## 内置校验脚本

| 脚本 | 作用 |
|------|------|
| `evidence_grade.py` | 复算证据等级，抓无出处/无分母/绝对化措辞 |
| `spec_lint.py` | 九节齐全性、AC 可测性、P0 占比、占位符 |
| `capacity_pack.py` | 产能测算、依赖装箱、承诺率、超载告警 |
| `metric_check.py` | 口径卡完整性、辛普森反转检测 |
| `chain_check.py` | 跨文档断链与数字冲突 |

纯标准库，无网络调用，可离线运行。用法见 `docs/使用说明.md`。

## 安装

把整个 `czl-product-strategy-solo` 目录放到：

```
~/.workbuddy-ai/plugins/marketplaces/my-experts/plugins/
```

并在 `marketplaces/my-experts/.codebuddy-plugin/marketplace.json` 的 `plugins` 数组里加一条 `{"name":"czl-product-strategy-solo","source":"./plugins/czl-product-strategy-solo"}`，重启 WorkBuddy 后在专家列表搜索「产品战略参谋」。

单专家型只有一个 `avatar`，不涉及团队型"图标取成员头像"的路径问题。

安装后自检：`python tests/run_tests.py -v`

## 已知限制

- 不会替你去查真实竞品网站。需要联网取证时由运行环境提供检索能力，取证结果同样要过证据分级。
- 产能测算依赖你提供的人数和周期。不给就停下来问，不会假设"资源充足"。
- 一致性脚本只做结构校验，判断不了业务判断对不对。它保证"文档之间不打架"，不保证"结论一定正确"。
- 单人版对抗性弱于团队版。重大不可逆决策建议换用团队版或找人交叉审。
- 中文为主，英文输入可处理，但模板与话术以中文为准。
