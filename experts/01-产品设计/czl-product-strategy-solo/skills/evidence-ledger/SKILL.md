# 证据台账（Evidence Ledger）

## 核心立场

结论的高度不能超过证据的高度。这条不是道德要求，是工程要求——建立在 D 级证据上的路线图，会在第三个月用返工把省下的调研时间全部还回来。

## 五级定义

| 等级 | 判据（四项全中才是 A） | 用途 |
|------|------------------------|------|
| A | 一手 + 可复核 + 时效内（≤180 天）+ 口径匹配 | 结论依据 |
| B | 一手，但时效/样本/口径有一项瑕疵 | 结论依据 + 限制说明 |
| C | 二手可信（报告、媒体、公开评测、招聘推断） | 方向判断，不支撑数字 |
| D | 弱证据（单条抱怨、社媒个例、个人经验） | 仅作假设/线索 |
| X | 无出处 / 不可复核 / 由推断产生 | 禁止进结论 |

判级降级规则：四项判据每缺一项降一级；`source_type=none` 直接判 X。

## 执行步骤

1. **拆主张**：把一段话拆成单条可验证的事实句。一句话里有两个事实就拆两条。
2. **找源**：每条写清 `source_ref`（哪个系统、哪个页面、哪个文件、哪次访谈第几分钟）。
3. **判级**：按上表。拿不准时往低判，不往高判。
4. **补分母**：所有比例写清分子分母，缺分母判 X。
5. **写反证**：每条 A/B 级主张，尝试找一条能推翻它的证据；找不到就在 `note` 写"未找到反证"。
6. **脚本复核**：`python scripts/evidence_grade.py --csv 01-证据台账.csv`，等级以脚本为准。

## CSV 字段

| 字段 | 必填 | 说明 |
|------|------|------|
| id | 是 | EVD-01 |
| claim | 是 | 单条事实句 |
| source_type | 是 | primary / secondary / anecdote / none |
| source_ref | 是 | 可定位到原文的引用 |
| observed_at | 是 | YYYY-MM-DD |
| scope | 是 | 覆盖人群/范围 |
| sample | 否 | 样本量，比例类必填 |
| verified | 是 | yes / no |
| grade | 是 | 手填，脚本复算 |
| note | 否 | 限制、反证、口径说明 |

## 竞品证据的额外规则

- 只采公开可核实信息：官网功能页、定价页、更新日志、应用商店、公开文档、财报、公开演示视频。
- 每条写抓取日期，超过 90 天标"可能过期"。
- 只看到宣传语没看到实际界面 → 最高 C。
- "据说""内部消息""朋友在那家公司" → X，不写。
- 功能对比必须给判据：有/部分/无/未见，且"未见"不等于"无"，要写"未见公开说明"。

## 输出

- `01-证据台账.csv`（机器可读）
- `01-证据台账.md`（人可读，含分级统计、假设清单、取证动作）

## 脚本

```
python scripts/evidence_grade.py --csv <台账.csv> [--json]
```

检查项：必填字段缺失、等级与判据不一致、比例缺分母、绝对化措辞配低等级证据、X 级被用于结论、时效过期。退出码非 0 表示存在阻断项。
