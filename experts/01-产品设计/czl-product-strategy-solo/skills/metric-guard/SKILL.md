# 指标口径（Metric Guard）

## 铁律

**口径未定，不谈归因。**

指标掉 12% 有三种可能：生意变差、口径变了、分母变了。直接跳到第一种解释的人，通常在三周后发现是自己改过埋点。

## 口径卡（每指标一张）

| 字段 | 要求 |
|------|------|
| 一句话定义 | 在 <人群> 中，<时间窗> 内发生 <事件> 的比例/数量 |
| 分子 | 事件去重用户数 或 次数（必须写明） |
| 分母 | 同期活跃用户数（活跃定义必须写） |
| 统计粒度 | 用户 / 会话 / 订单 |
| 时间窗 | 自然周 + 时区 |
| 数据源 | 表名 + 取数归属 |
| 排除项 | 内部号、测试号、机器人 |
| 护栏指标 | 反向指标 + 阈值 |
| 读数节奏 | 谁、多久看一次 |
| 已知坑 | 口径变更史、双写期、跨端去重 |

## 体检顺序（不许跳步）

1. **查定义**：分子分母人群是否一致？口径最近改过吗？
2. **查分母**：分母变化 >10% 时先怀疑分母
3. **查波动带**：用近 8–12 周标准差算正常区间，带内不算异常
4. **查分群**：整体与分群方向是否相反（辛普森反转）
5. **再谈原因**：写成"若 X 成立，应观察到 Y"的可检验假设

## 辛普森反转怎么判

整体转化率上升，但每个渠道都下降 → 说明结构变了（高转化渠道占比变大），不是转化变好。

脚本会算：整体率、各分层率、方向一致性，并在方向相反时报警。

## 护栏指标

主指标必须配一个反向护栏，防止"指标达成、生意变差"：

| 主指标 | 常见护栏 |
|--------|----------|
| 转化率 | 退款率、投诉率、7 日留存 |
| 使用时长 | 次日回访率、卸载率 |
| 客单价 | 复购率、退货率 |
| 处理时效 | 差错率、返工率 |

## 脚本

```
python scripts/metric_check.py --cards <口径卡.csv>
python scripts/metric_check.py --segments <分层.csv>
```

- `--cards` 检查：必填字段、比率类指标是否有分子分母、是否配护栏、是否写排除项、是否写读数节奏
- `--segments` 检查：整体与分层方向是否反转（列：`segment,numerator,denominator`，首行可含 `__all__` 汇总行；若无汇总行脚本自行汇总）

## 反模式

- 改分母定义来凑目标（这是造假）
- 用"用户行为变化"解释未排除口径变化的数据
- 只报整体不报分群
- 成功标准只写"提升 X%"而没有基线
