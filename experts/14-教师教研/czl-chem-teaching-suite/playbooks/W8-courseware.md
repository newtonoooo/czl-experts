# W8 课件工场（Courseware Studio）

## 1. 工作流名称
W8 课件工场 —— 教材页 → 一节课的幻灯片。

## 2. 任务职责
识别教材对应页的结构与重难点，设计幻灯片大纲，产出可上课的 .pptx（封面 → 目录 → 分节 → 内容 → 小结）。环境不支持生成 PPT 时，降级为结构化大纲。

## 3. 输入参数
| 参数 | 必填 | 说明 |
|---|---|---|
| 教材素材 | 是 | 教材页图片 / 电子教材 PDF / 章节文字 |
| 课题与年级 | 是 | 用于定位章节 |
| 课时数 | 否 | 缺省 1 课时（约 14–18 页） |
| 风格要求 | 否 | 简洁学术 / 活泼图示 / 复习提纲式 |
| 是否需要配套学案 | 否 | 需要则联动 W1 |

## 4. 执行步骤
1. **读页**：识别章节标题、节内小标题、栏目（实验/思考与讨论/资料卡片/科学史话）、图表（装置图、微观示意图、数据表）。
2. **提重难点**：从栏目类型判断——"实验"多为探究重点，"思考与讨论"多为难点，"资料卡片"多为情境素材。
3. **写大纲**：按 5 段结构分配页数（1 课时约 14–18 页）：
   - 封面 1 页｜目录 1 页｜情境导入 1–2 页｜新知 6–9 页｜实验/模型 2–3 页｜应用 2 页｜小结 1 页｜作业 1 页
4. **逐页设计**：每页"一个观点 + 3–5 个要点 + 一个视觉元素"。视觉元素写清类型（装置示意图 / 价类二维图 / 微观粒子图 / 数据表 / 流程图），不写字幕式长句。
5. **标注难点**：在难点页加"此处停顿提问"标记，并给一句提问话术。
6. **生成**：优先用运行环境的演示文稿能力产出真实 .pptx；不可用时输出 Markdown 大纲并注明。
7. **自检**：每页字数 ≤80（要点式），无整段粘贴教材，公式与方程式书写规范，配色对比度足够（投影可读）。

## 5. 判断条件
| 情况 | 处理 |
|---|---|
| 教材页含实验 | 必做 1 页装置图 + 1 页"现象—结论"对照 |
| 教材页含微观示意 | 必做 1 页粒子模型，配一句"看得见的现象，看不见的粒子" |
| 复习课 | 改为"知识网 → 易错 → 真题 → 变式"结构，页数减到 10–12 |
| 只有章节名没教材页 | 先出大纲供确认，并明确"内容按课标口径，具体页码需教师补" |
| 环境不能生成 pptx | 输出逐页大纲（页码/标题/要点/配图说明），可直接照做 |

## 6. 输出格式
```
【课件大纲】
P1 封面：课题 / 年级 / 教材版本
P2 目录：3–4 个板块
P3–…（每页：标题 | 要点 3–5 条 | 视觉元素 | 备注/提问）
【重难点标注】哪几页是重点、哪几页是难点、建议停留时间
【素材缺口】需要教师补充的图片/实验照片清单
【文件】xxx_课件_年级_YYYYMMDD.pptx（或大纲 md）
```

## 7. 异常处理
- 教材页模糊/缺页：只做已识别部分，列出缺失页与影响。
- 页数不够（内容太多）：给"两课时拆分方案"，不硬压。
- 教师要求"把教材原文搬上去"：改为要点化改写（版权 + 可读性双重原因），并说明。
- 生成 pptx 失败：降级大纲，不假装已生成文件。

## 8. 必要依赖
- `knowledge/01-curriculum-map.md`（章节定位）
- `knowledge/09-quality-gates.md`（质检）
- 运行环境的演示文稿生成能力（PPT 生成技能 / python-pptx）

## 9. 与其他工作流的关系
- 上游：W1（教学设计确定后再做课件，顺序更顺）、W5（难点讲解页）。
- 下游：W2（课件末页的作业）、W1（配套学案）。
- 交付时附一句："这套课件第 7–9 页的难点，建议配一份 1 页学案（W5）。"
