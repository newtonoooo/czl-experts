# W7 化学工坊（Chemistry Workshop）

## 1. 工作流名称
W7 化学工坊 —— 化学学科独有的五类硬活：方程式、实验、有机路线、工业流程、计算。

## 2. 任务职责
用可校验的协议处理五类任务，每一步都能被教师复核。**区别于通用问答：这里必须给"校验行"，不只给结论。**

## 3. 输入参数
| 参数 | 必填 | 说明 |
|---|---|---|
| 子任务类型 | 是 | A 方程式 / B 实验方案 / C 有机路线 / D 工业流程 / E 计算 |
| 反应物与产物（A/C） | 视情况 | 至少给反应物；缺产物则先推可能产物再配平 |
| 介质条件（A） | 否 | 酸性/碱性/中性，缺省按题干推 |
| 实验目的与条件（B） | 视情况 | 制备什么、有什么仪器、几人一组 |
| 目标分子或起始物（C） | 视情况 | 给结构或名称 |
| 流程图或题干（D） | 视情况 | 图片/文字 |
| 已知量与所求（E） | 视情况 | 数值、单位、要求的有效数字 |

## 4. 执行步骤（按子任务分支）

### 4A 方程式与电极反应式
1. 写反应物与产物（难写的是产物，用价态变化/类别反应推）。
2. 标变价元素，算升降数。
3. 用最小公倍数定系数（氧化还原）；非氧化还原按原子守恒试配。
4. 补介质：酸性补 H⁺/H₂O，碱性补 OH⁻/H₂O。
5. **三行校验**：原子守恒（逐元素计数）→ 电荷守恒（左右电荷代数和）→ 得失电子守恒（升=降）。
6. 标条件与状态：△、催化剂、浓/稀、↑↓。
7. 离子方程式额外检查：强弱电解质是否拆对、是否该写离子、是否约成最简比。

### 4B 实验方案
1. 明确目的与原理（一句话：用什么反应、测什么量、除什么杂质）。
2. 选装置：发生 → 净化 → 干燥 → 主体反应/收集 → 尾气处理，逐段画清。
3. 查顺序：先除杂后干燥、防倒吸、防氧化、防潮解（每项写理由）。
4. 定操作：加药顺序、温度控制、停止时机、现象判据。
5. **安全闸**（强制，见 `knowledge/05-lab-safety.md`）：危化品清单、通风、防护、尾气/废液处理、意外处置。
6. 给"若失败"的排查表（3 条最常见失败原因与对策）。

### 4C 有机合成路线
1. 比对起始物与目标物的碳骨架与官能团差异。
2. 在 `knowledge/06-organic-map.md` 找转化路径（可能有多条）。
3. 选路线：步数少、条件温和、副反应少、原料易得（四条权衡，写出取舍理由）。
4. 写每步：反应物 + 试剂/条件 + 产物结构 + 反应类型。
5. 检查：碳原子数守恒、官能团保护/脱保护是否需要、立体化学是否要求。

### 4D 工业流程
按 `knowledge/07-industrial-flow.md` 四段式：
1. 原料预处理（粉碎/焙烧/酸浸/碱浸/氧化）——目的是什么。
2. 核心反应（转化/沉淀/还原）——写方程式。
3. 分离提纯（过滤/萃取/蒸馏/结晶）——为什么选这个方法。
4. 循环与绿色化学（母液回到哪、副产物怎么用、能耗与排放）。
5. 每一步追问："这一步不加会怎样"——这是流程题的通用问法。

### 4E 化学计算
1. 列已知（带单位）与所求。
2. 选模型：物质的量桥 / 守恒（质量、电荷、电子、原子）/ 差量 / 平衡常数 / Ksp / 热化学盖斯定律。
3. 写关系式（不带数字），再代数。
4. 算，保留有效数字（与题干给定数据一致）。
5. 验算：数量级是否合理、单位是否对、极端值是否荒谬。

## 5. 判断条件
| 情况 | 处理 |
|---|---|
| 反应物相同但条件不同（浓/稀、温度） | 产物可能不同，分别给并说明判据 |
| 有机路线有多条 | 给 2 条并标推荐理由（步数/条件/产率） |
| 实验涉及危化品 | 触发 R2 安全闸，先给风险与替代，再给方案 |
| 计算结果出现非整数/奇怪小数 | 先怀疑自己（系数/摩尔质量/单位），回溯复核 |
| 题干条件不足（缺浓度/温度） | 明确列出缺什么，给"在这些条件下答案会怎样变" |

## 6. 输出格式
```
【任务】子任务类型 + 一句话目标
【推理】关键判断（价态/介质/路线选择），≤5 行
【结果】方程式 / 装置流程 / 路线 / 计算过程
【校验】A：原子 ✓ 电荷 ✓ 电子 ✓（逐项数值）；E：量纲 ✓ 数量级 ✓
【易错】2–3 条
【安全】（B 必填）危化品 / 通风 / 防护 / 废弃物
```

## 7. 异常处理
- 方程式配不平：不要硬凑系数，回到价态重新判断产物（常见于歧化/归中反应）。
- 有机路线走不通：换官能团引入顺序，或改用保护基策略；说明为什么原路线不行。
- 实验方案有安全风险：拒绝危险步骤，给教材标准替代（如用低浓度、微量、封闭体系）。
- 计算数据自相矛盾：指出矛盾点，请教师核对原始数据。
