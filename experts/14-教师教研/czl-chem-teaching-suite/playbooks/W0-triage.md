# W0 受理分诊（Intake Triage）

## 1. 工作流名称
W0 受理分诊 —— 在动手之前，先把"教师手里的东西"翻译成"可执行的任务"。

## 2. 任务职责
- 判读教师上传的材料（教材页、题目照片、成绩表、实验报告、真题卷）。
- 判断真实意图属于 W1–W8 中的哪一条（或哪两条）。
- 当意图不明时，给出 2–3 个具体可选任务，而不是开放式提问。
- 输出一份"任务卡"，供后续工作流直接消费。

## 3. 输入参数
| 参数 | 必填 | 说明 |
|---|---|---|
| 材料 | 否 | 图片/PDF/表格/文本，可多份 |
| 一句话诉求 | 是 | 教师原话，哪怕是"帮我看看这个" |
| 年级与教材版本 | 否 | 缺省：高二 / 人教版（2019） |
| 时间约束 | 否 | "明天要上""周五要考" |

## 4. 执行步骤
1. **读材料**：先逐份识别类型与内容（教材页看章节标题与栏目；题目看题干、设问、分值；表格看表头与行列含义；实验报告看目的/步骤/现象/结论四栏是否齐全）。
2. **提取锚点**：每份材料提取 1 个锚点——章节名 / 题号与考点 / 数据字段 / 实验名称。
3. **判意图**：用锚点 + 原话匹配主智能体"工作流路由"表；命中多个时按路由判据取舍。
4. **补缺**：只补"没有它就出不了活"的参数，最多问 3 项，其余用默认档。
5. **出任务卡**：一屏之内说清"我理解你要什么 + 我打算怎么做 + 需要你确认的一件事"。

## 5. 判断条件
| 条件 | 走向 |
|---|---|
| 材料是教材页 + "做课件/上课" | W8 或 W1（要 PPT → W8；要教学流程 → W1） |
| 材料是题目 + "讲讲" | W6（真题）或 W5（知识点） |
| 材料是整份卷 + "分析" | W4；若同时要"讲评"→ W4 主 + W6 副 |
| 材料是学生答卷 + "批改" | W3 |
| 材料是成绩表 | W4 |
| 只有一句"帮我出套题" | W2，但必须先问用途（课堂练/周测/月考） |
| 材料读不清 | 说明读不清的部分，按已识别内容先给最小可用产物 |

## 6. 输出格式
```
【任务卡】
材料判读：<一句话，含锚点>
我理解你要：<工作流名>（W?）
我会先做：<3 步以内>
需要你定的一件事：<单选式，两三个选项>
补充说明：<缺省假设，一行>
```

## 7. 异常处理
- 材料与诉求矛盾（上传的是有机题，说要备无机课）：以材料为准提出疑问，不擅自替换。
- 上传多份不相关内容：按"最可能的一组"归并，其余列出待确认。
- 图片为整页拍歪/反光：只取可辨认区域，明确标注未识别部分。

## 8. 必要依赖
- 无外部依赖；仅需能读图片与文档。
- 判读章节时参考 `knowledge/01-curriculum-map.md`。

## 9. 与其他工作流的关系
- 上游：无（入口）。
- 下游：W1–W8 全部。
- W0 不产出教学内容，只产出"任务卡"；不得在 W0 阶段写教案或出题。
