# W1 备课台（Lesson Forge）

## 1. 工作流名称
W1 备课台 —— 从"课题"到"明天能上完的 40 分钟"。

## 2. 任务职责
产出一份可直接进课堂的教学设计：素养目标、重难点与突破策略、问题链、时间分配、板书、分层作业。实验课额外给实验组织方案与安全清单。

## 3. 输入参数
| 参数 | 必填 | 说明 |
|---|---|---|
| 课题 | 是 | 如"氧化还原反应""盐类的水解" |
| 年级 | 否 | 高一/高二/高三；缺省高二 |
| 课型 | 否 | 新授课/实验课/复习课/习题课；缺省新授课 |
| 课时 | 否 | 缺省 1 课时 40 分钟 |
| 教材版本 | 否 | 缺省人教版（2019） |
| 学情 | 否 | 已有基础、常见障碍；缺省"中等班"三档预设 |
| 特殊要求 | 否 | 公开课、同课异构、跨学科、信息化 |

## 4. 执行步骤
1. **定位**：在 `knowledge/01-curriculum-map.md` 找章节与课标内容要求，确认本课时"必学"与"可延后"的边界。
2. **定目标**：3–4 条，写成"行为动词 + 内容 + 可测评结果"，覆盖至少 2 个核心素养维度。不写"培养学生的……意识"这类不可测表述。
3. **找冲突点**：为本节课找一个真实认知冲突（实验现象反常、生活经验与结论矛盾、微观解释与宏观现象不符）。这是课堂的动力源。
4. **搭问题链**：4–6 问，从"看到什么"到"为什么"到"如果改变条件会怎样"到"能不能推广"。
5. **排时间**：情境 5′ → 探究 15′ → 建模/归纳 8′ → 应用 8′ → 小结与作业 4′（实验课按"讲—演—做—评"重排）。
6. **写板书**：给一版结构化板书（层级 ≤3 层），可直接抄到黑板。
7. **配作业**：基础 3 题 / 提高 2 题 / 挑战 1 题，标注对应目标编号。
8. **过闸**：按 `knowledge/09-quality-gates.md` 自检 G1–G5。

## 5. 判断条件
| 课型 | 骨架调整 |
|---|---|
| 新授课（概念） | 情境→实验/事实→归纳→模型→应用；重点是"概念怎么长出来" |
| 新授课（元素化合物） | 价类二维图为主线，性质由类别与价态推，实验验证 |
| 实验课 | 目的→原理→装置→步骤→现象记录表→结论→安全；教师演示与学生分组分开写 |
| 复习课 | 以"错题/真题"倒推知识网，先诊断后补漏，不重讲教材 |
| 习题课 | 选 3 道典型题，按"审题—建模—规范—变式"四段讲，不逐题对答案 |

判断"难点"的方法：学生需要的**前置知识**如果超过 2 个且不在上一课时，就是难点，必须给台阶（类比、模型、分步问题）。

## 6. 输出格式
```
【基本信息】课题/课型/课时/教材/班级层次
【教学目标】1–4 条（编号，可测评）
【重难点】重点 / 难点 / 突破策略（一句话一条）
【学情分析】已有基础 / 可能障碍 / 分层预设
【教学过程】表格：环节 | 教师活动 | 学生活动 | 设计意图 | 时间
【板书设计】层级文本
【分层作业】基础 / 提高 / 挑战（标目标编号）
【实验补充】（实验课）目的/原理/器材/步骤/现象记录表/安全提示
【需教师确认】重难点取舍、课时是否够用
```

## 7. 异常处理
- 课题跨两课时（如"化学平衡"）：先给"两课时拆分方案"，让教师选讲哪一段，不硬塞。
- 教材版本不明且章节差异大（如"原子结构"在必修与选必深度不同）：按课标最低要求写，标注可加深处。
- 教师要求"一节课讲完一章"：给"压缩版骨架 + 取舍清单"，明确哪些内容移到课后。
- 学校无实验条件：给"演示+视频+微型实验"三档替代，安全要求不降。

## 8. 必要依赖
- `knowledge/01-curriculum-map.md`（章节与课标）
- `knowledge/05-lab-safety.md`（实验课）
- `knowledge/09-quality-gates.md`（质检）
- 可选：`playbooks/W2-assessment.md`（配套练习）、`playbooks/W8-courseware.md`（配套课件）

## 9. 与其他工作流的关系
- 上游：W0（任务卡）。
- 下游：W2（配套作业/小测）、W8（课件）、W5（某个难点的深讲）。
- 交付后主动给"下一步"：这节课的 3 道配套变式（转 W2），或本节课件的 12 页骨架（转 W8）。
