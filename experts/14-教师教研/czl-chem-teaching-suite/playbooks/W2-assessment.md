# W2 命题坊（Assessment Forge）

## 1. 工作流名称
W2 命题坊 —— 先蓝图，后组卷，再出评分细则。

## 2. 任务职责
按用途与知识范围原创组卷：给出四维蓝图（模块 × 能力层级 × 素养 × 难度）供教师确认，再逐题命制，附答案、评分细则与命题自检结论。

## 3. 输入参数
| 参数 | 必填 | 说明 |
|---|---|---|
| 用途 | 是 | 课堂小练 / 课后作业 / 单元测 / 月考 / 模拟考 |
| 范围 | 是 | 章节或知识点列表（如"必修一第二章 + 离子反应"） |
| 题量与分值 | 否 | 按用途给默认（见下表），教师可改 |
| 难度配比 | 否 | 缺省 易:中:难 ≈ 5:3:2 |
| 情境要求 | 否 | 是否要工业流程/生活/史料情境，是否要图像题 |
| 已有素材 | 否 | 教师上传的旧题（仅作风格参考，不照抄） |

默认题量分值（可按本省结构替换）：

| 用途 | 时长 | 结构 |
|---|---|---|
| 课堂小练 | 10–15 min | 选择 6 题 × 3 分 + 1 道填空 12 分 |
| 课后作业 | 30 min | 选择 8 题 + 填空 3 题（分层标注） |
| 单元测 | 45 min | 选择 12 题 × 3 分 + 非选择 3 题 44 分 |
| 月考/模拟 | 75 min | 选择 14–15 题 × 3 分 + 非选择 4 题 55–58 分（对齐本省当年结构） |

## 4. 执行步骤
1. **定蓝图**：填四维表，一题一行。要求：考点不重复设问；同一能力层级不连续超过 3 题；至少 1 题带真实情境；至少 1 题考规范表达（方程式/单位/有效数字）。
2. **交教师确认**：蓝图先给，等确认再命题（教师说"直接出"才跳过）。
3. **逐题命制**：先写"考什么—怎么设问—答案长什么样"，再润色题干。题干不设陷阱式文字游戏，难度来自学科本身。
4. **写答案与细则**：非选择题给"给分点 + 分值 + 可接受的等价表述"。方程式类必须给配平依据。
5. **过自检 10 条**（见第 5 节），逐条打勾，不合格的题重写。
6. **成卷排版**：卷头（名称/时间/满分/可能用到的相对原子质量）→ 选择题 → 非选择题 → 答案与解析（单独成节，便于裁切）。

## 5. 判断条件：命题自检 10 条
1. 题干信息是否**足够且必要**（删掉任何一句都会导致不可解，或保留任何一句都会导致超纲）？
2. 选择题四个选项是否**同质同层**（不是三个明显错、一个明显对）？
3. 是否有**唯一正确答案**，且不存在"按另一本教材也成立"的争议解？
4. 计算题数据是否**凑得干净**（结果合理、有效数字一致、无循环小数乱尾）？
5. 图像/表格是否**自洽**（坐标轴、单位、曲线趋势与文字描述一致）？
6. 情境是否**真实可查**（工业流程、材料、药物不写成伪科学）？
7. 是否**考了想考的能力**（而不是考生僻记忆）？
8. 难度是否落在蓝图标注档位（易 ≤3 步、中 3–5 步、难 ≥5 步且有弯）？
9. 评分细则是否**可操作**（换一个老师评，给分一致）？
10. 是否存在**安全隐患或不当表述**（涉及危化品、受管制品、民族宗教、地域歧视）？

## 6. 输出格式
```
【双向细目表】
| 题号 | 考点 | 模块 | 能力层级 | 素养维度 | 题型 | 分值 | 难度 | 情境 |
【试卷正文】卷头 + 题目（每题末标分值）
【参考答案】每题：答案 + 依据（配平/守恒/公式）
【评分细则】非选择题：给分点表（点 | 分值 | 可接受表述）
【命题自检】10 条逐条结论（通过/已修改：说明）
【需教师确认】题量是否合卷、是否需替换某题
```

## 7. 异常处理
- 教师要求"直接抄某套卷"：拒绝整卷复制（版权），改为"同考点同难度原创替换"，并说明差异。
- 范围过大（"把高中化学都考一遍"）：给出 3 个可选细分范围让教师选。
- 要求超纲（如必修阶段考 Ksp 计算）：提示超纲，给"降维版"，并注明依据（课标要求）。
- 要求出"必考原题"：明确无法保证，改为"高频考法覆盖清单"。
