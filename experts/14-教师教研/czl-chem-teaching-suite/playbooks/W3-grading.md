# W3 批改台（Grading Desk）

## 1. 工作流名称
W3 批改台 —— 不只判对错，要判"错在哪一类"，并给出可执行的补救动作。

## 2. 任务职责
对化学方程式、计算题、实验题、实验报告按"书写规范 + 步骤得分点"批注；用统一错因码（E01–E14）分类；汇总班级共性错因；给评语与补救建议。

## 3. 输入参数
| 参数 | 必填 | 说明 |
|---|---|---|
| 学生作答 | 是 | 图片/文本/表格，可多份（用学生A/B 标识） |
| 题目与答案 | 是 | 教师提供，或由 W2 生成 |
| 评分标准 | 否 | 缺省按"步骤给分 + 规范扣分"通用规则 |
| 批改颗粒度 | 否 | 只判对错 / 标错因 / 写评语（缺省：标错因 + 一句评语） |

## 4. 执行步骤
1. **对齐题号与答案**：先建"题号—答案—给分点"对照，避免批改时错位。
2. **逐题判分**：按给分点给分，不按"看起来像"给分；每一步注明得/失分理由。
3. **标错因码**：每个失分点挂 1 个主码（必要时挂 1 个次码），码表见 `knowledge/03-error-codes.md`。
4. **分规范项**：单独统计"会做但被扣分"的规范性失分（条件符号、状态符号、单位、有效数字、有效数字位数、结构式写法），这部分是最容易提分的。
5. **汇总**：按题号统计错因频次 → 找出本班 3 个共性问题。
6. **写反馈**：每份给一句"最该改的一件事"，不写空泛评语。
7. **出数据**：生成 `批改_主题_日期.csv`（列：学生标识、题号、得分、满分、错因码、失分类型）。

## 5. 判断条件
| 情况 | 处理 |
|---|---|
| 答案正确但过程缺失 | 按"步骤分"扣，标 E08 规范表达 |
| 方程式配平对但条件漏 | 不整题判错，标 E04 条件符号，扣规范分 |
| 计算思路对、结果错 | 给过程分，标 E05 计算失误，指出错在第几步 |
| 单位/有效数字错 | 标 E06，单独汇总（这类错常被忽视，提分最快） |
| 学生答案有两种合理解释 | 不判错，注明"表述歧义，建议课堂澄清" |
| 图片无法辨认某一步 | 该步标"待核"，不计入错因统计 |

## 6. 输出格式
```
【批改总览】份数 / 平均得分率 / 规范失分占比
【逐题批注】
第 X 题（满分 n）：得分 m
  失分点：<步骤> → E05（计算失误）
  批注：<一句话，指出具体错在哪一步>
  正确写法：<关键行>
【共性错因 Top3】错因码 | 涉及题号 | 人次 | 典型表现
【给学生的建议】每人一句（不评价态度，只指出动作）
【数据文件】批改_主题_YYYYMMDD.csv
```

## 7. 异常处理
- 学生答案与题目不匹配（拍错页）：标注"题号疑似错位"，请教师确认后再判。
- 手写体难辨（如 2 与 z、0 与 O）：只判可辨认部分，列出存疑字符。
- 教师要求"都给高分"：拒绝篡改分数，可提供"评分标准放宽方案"由教师决定。
- 一次上传超过 20 份：先做 3 份样例确认口径，再批量（避免口径漂移）。

- 上游：W2（题目与答案）。
- 下游：W4（把错因数据汇总成班级诊断）、W5（针对 Top1 错因出讲解）。
- 交付时附一句："这 3 个共性错因可一键进 W4 出班级诊断，或进 W5 出针对性学案。"
