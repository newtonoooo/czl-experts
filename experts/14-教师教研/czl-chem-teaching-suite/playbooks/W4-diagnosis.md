# W4 诊断室（Diagnosis Room）

## 1. 工作流名称
W4 诊断室 —— 从分数表到"下一步教什么"。

## 2. 任务职责
统计均分、中位数、标准差、分数段、板块得分率、题目难度与区分度；用错因码定位失分结构；输出分层处方与两课时内的补救安排。

## 3. 输入参数
| 参数 | 必填 | 说明 |
|---|---|---|
| 成绩数据 | 是 | 两表之一：① 学生×题号得分；② 学生总分 + 各板块得分 |
| 满分与分值 | 是 | 各题/各板块满分，用于算得分率 |
| 试卷结构 | 否 | 板块划分（无机/有机/结构/原理/实验），缺省按题号推 |
| 班级信息 | 否 | 人数、层次（缺省中等班） |
| 历史对比 | 否 | 上次同类考试数据，用于看变化 |

## 4. 执行步骤
1. **清洗**：剔除缺考/零分异常（标注剔除规则，不静默删数据）。
2. **描述统计**：人数、均分、中位数、最高/最低、标准差、优秀率/及格率（阈值由教师定，缺省按满分 85%/60%）。
3. **分布**：五档分数段（如 90–100 / 80–89 / 70–79 / 60–69 / <60），给人数与占比。
4. **板块得分率**：各板块平均得分 ÷ 满分，找出最低两块。
5. **题目诊断**：难度 P = 平均得分/满分；区分度用高低分组（各取 27%）得分率差 D。标注 P<0.4（偏难）、P>0.85（偏易）、D<0.2（区分度不足）。
6. **错因归因**：把错因码落到知识点上，形成"错因码 × 知识点"矩阵，取 Top3–5。
7. **处方**：按三层给动作——保底（全班必做）、提升（中段）、拔高（前 20%），每条处方写"做什么 + 用多少时间 + 怎么检验"。
8. **出报告**：报告 + csv（清洗后数据与统计结果）。

## 5. 判断条件
| 现象 | 归因方向 |
|---|---|
| 均分正常但标准差大 | 分层严重 → 处方要分层，不搞全班统一补 |
| 均分低且标准差小 | 共性知识缺口 → 全班重讲 + 变式巩固 |
| 某题 P 很低但 D 也低 | 题本身有问题（超纲/表述歧义）→ 讲评时说明，不计入学生问题 |
| 某题 P 高 D 低 | 送分题 → 后续命题提高梯度 |
| 规范失分占比 >30% | 不是不会，是写不对 → 专项规范训练（方程式/单位/有效数字） |
| 板块得分率最低两块相近 | 选一个先补（课时有限），另一个给课后任务 |

## 6. 输出格式
```
【一句话结论】这次考试的真正问题不是 X，而是 Y。
【总体统计】人数/均分/中位/标准差/优秀率/及格率/分数段表
【板块得分率】表：板块 | 满分 | 均分 | 得分率 | 主要失分点
【题目诊断】表：题号 | 考点 | 难度P | 区分度D | 判定
【失分结构】错因码 Top3–5：码 | 含义 | 人次 | 关联知识点 | 典型表现
【分层处方】
  保底（全班，X 分钟）：……
  提升（中段，X 分钟）：……
  拔高（前 20%，X 分钟）：……
【两课时补救安排】第 1 课时做什么、第 2 课时做什么、怎么检验
【数据口径】清洗规则、阈值设定、缺失字段影响
```

## 7. 异常处理
- 只有总分没有题号：只能做分布与分层，明确说明"无法做题目诊断"，并给补录模板。
- 人数 <10：统计意义有限，只给描述性结论，不做区分度。
- 数据含姓名列：只取分数，输出时用"学生A/B…"或直接删列。
- 教师要求"预测下次能考多少"：拒绝绝对化预测，改为"若补上 Top2 错因，按本次数据估算可提升区间（附假设）"。
