# W6 真题解码（Gaokao Decoder）

## 1. 工作流名称
W6 真题解码 —— 把一道高考题拆成"考什么、怎么想、怎么写、怎么变"。

## 2. 任务职责
对教师提供的高考真题或高质量模拟题，做考点定位、思路还原、规范作答、评分点拆解、考法归类与变式设计。**不编造真题，不臆造答案。**

## 3. 输入参数
| 参数 | 必填 | 说明 |
|---|---|---|
| 题目 | 是 | 图片或文字；含设问与分值最佳 |
| 年份与卷别 | 否 | 教师能提供就标注；没有则写"未标年份" |
| 学生典型错误 | 否 | 用于针对性讲评 |
| 输出形态 | 否 | 讲评卡（1 页）/ 详解（多页）/ 归类专题 |

## 4. 执行步骤
1. **确认题源**：有年份卷别就标注（格式"20XX 年 XX 卷 第 X 题"）；无法确认的不标，绝不猜。
2. **考点定位**：模块（无机/有机/结构/原理/实验/流程）→ 知识点 → 能力层级（识记/理解/应用/分析评价）。
3. **思路还原**：写出"第一眼看什么 → 突破口在哪 → 卡点在哪 → 验证方式"。不要直接给答案。
4. **规范作答**：按阅卷标准写——方程式带条件与状态、计算带单位与有效数字、简答带关键词。
5. **评分点拆解**：非选择题按"给分点 × 分值"列表，指出哪些点是"写了就给"，哪些要"写到关键词"。
6. **考法归类**：这道题属于哪一类设问方式（原因解释/方案评价/数据推理/图像分析/合成设计），同类题的通用套路是什么。
7. **变式设计**：2 道——一道"换情境不换模型"，一道"加一步推理"。
8. **讲评建议**：给教师 2 分钟口头讲评脚本（先问什么、再点哪里）。

## 5. 判断条件
| 情况 | 处理 |
|---|---|
| 题源确定 | 正常标注年份卷别 |
| 题源不确定 | 标注"来源未确认，仅作考法示例"，不标年份 |
| 答案有争议（多解/超纲） | 并列说明，注明"按 XX 年阅卷口径"或"教材口径为……" |
| 图像题 | 先描述图像特征（轴、拐点、斜率、平台），再解释，不跳步 |
| 流程题 | 按 `knowledge/07-industrial-flow.md` 四段式拆 |
| 有机推断 | 按 `knowledge/06-organic-map.md` 官能团网络倒推 |

## 6. 输出格式
```
【题目】题源 + 题干（引用只到必要信息，不整段复制原卷）
【考点定位】模块 / 知识点 / 能力层级 / 素养维度
【思路分析】第一步……第二步……（标出突破口与卡点）
【规范解答】(1)……(2)……（方程式/计算过程完整）
【评分点】点 | 分值 | 关键词
【考法归类】设问类型 + 通用套路（3 条以内）
【易错点】3 条，写"错在哪里 + 为什么错"
【变式】变式1（同模型换情境）/ 变式2（加一步推理）
【讲评脚本】2 分钟口头版
```

## 7. 异常处理
- 教师要求"把近五年这个考点所有真题列出来"：不凭记忆罗列（易错），改为给"考法清单 + 检索路径"，并说明需要教师核对原卷。
- 题目图片缺设问：只解析可见部分，明确标注缺失。
- 要求"押题"：拒绝承诺，改为"高频考法 + 覆盖度分析"。

## 9. 与其他工作流的关系
- 上游：W0；W4（某题全班失分）。
- 下游：W2（把变式扩成小练）、W5（把考点扩成学案）、W1（把讲评做成复习课）。
- 交付时附一句："这道题的变式 2 可以直接进 W2 做成 12 分钟小练。"
