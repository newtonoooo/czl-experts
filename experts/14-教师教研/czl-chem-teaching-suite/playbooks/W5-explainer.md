# W5 讲解厅（Explainer）

## 1. 工作流名称
W5 讲解厅 —— 把一个"学生总听不懂"的点，拆成能听懂的四步。

## 2. 任务职责
产出学案式讲解材料：概念澄清 → 原理/模型（含推导）→ 典型例题 → 易错警示 → 变式练习。并给出教师版"讲法建议"（三种切入角度选一）。

## 3. 输入参数
| 参数 | 必填 | 说明 |
|---|---|---|
| 知识点 | 是 | 如"盐类水解的实质""电极反应式书写" |
| 学生障碍 | 否 | 教师描述的现象（"总把水解和电离搞混"） |
| 年级/层次 | 否 | 缺省高二中等班 |
| 输出形态 | 否 | 学案（学生用）/ 讲义（教师用）/ 两者都要 |
| 篇幅 | 否 | 1 页速查 / 2 页学案 / 专题（多页） |

## 4. 执行步骤
1. **定位障碍**：学生卡在"记不住"、"分不清"、"不会迁移"、"写不规范"中的哪一类。判断依据是教师描述 + 该知识点的常见错误（见 `knowledge/03-error-codes.md`）。
2. **选切入角度**（只选一个，不要三个都写）：
   - 宏观现象切入：适合元素化合物、实验类；
   - 微观模型切入：适合结构、反应机理、电解；
   - 数据/定量切入：适合平衡、Ksp、热化学。
3. **写概念澄清**：一句话定义 + 一个反例 + 一个常见误读。
4. **给模型**：能用图/表就不用长文字；推导给 3–5 步，不跳步。
5. **配例题**：1 道示范（完整规范过程）+ 1 道"半成品"（留空让学生补关键步）。
6. **易错警示**：3–5 条，写成"错误做法 → 为什么错 → 正确做法"三列。
7. **变式**：2–3 题，难度递增，标注对应障碍点。
8. **教师版附注**：一句话说明"这个点上，学生最容易在哪个瞬间走神/误解"。

## 5. 判断条件
| 障碍类型 | 处方重点 |
|---|---|
| 记不住 | 给结构化记忆框架（价类二维、转化网络），不给口诀堆砌 |
| 分不清 | 给对比表 + 判据（一句话可操作的判别规则） |
| 不会迁移 | 给"同构变式"3 连（换情境不换模型） |
| 写不规范 | 给书写模板 + 扣分点清单，练 2 遍 |

## 6. 输出格式
```
【一句话本质】……
【概念澄清】定义 / 反例 / 常见误读
【模型或推导】图或表 + 分步推导（≤5 步）
【示范例题】题干 → 思路 → 规范解答（标扣分点）
【半成品练习】留空的关键步
【易错警示】表：错误做法 | 为什么错 | 正确做法
【变式练习】2–3 题（标难度与对应障碍）
【教师版提示】讲到这里停一下问什么
```

## 7. 异常处理
- 知识点跨模块（如"电化学 + 平衡"）：先给"最小必要模型"，其余标"延伸阅读"。
- 教师要求"用口诀搞定"：可给 1 条辅助记忆，但必须同时给理解路径，不把口诀当方法。
- 学生层次差异大：同一份学案给"基础版/进阶版"两个版本，不要一份打天下。
- 涉及超纲内容：标注"超出必修要求，仅作拓展"。
