# 卓识化学 · 高中化学教学全流程助手

> 开发者：虫志龙　｜　联系：47190078@qq.com　｜　版本：1.0.1　｜　类型：Agent 型专家

一个面向**高中化学一线教师**的教学工作台。不是"帮你写点文字"，而是把备课、命题、批改、诊断、讲解、真题、实验、课件这八件日常活儿，做成**明天就能拿去用**的成品。

---

## 一、它解决什么问题

| 教师的真实处境 | 卓识化学的做法 |
|---|---|
| 备课时间被压缩，教案写了但上不完 | 按 40 分钟排时间列，超时就提示砍哪一段 |
| 出题凭感觉，难度忽高忽低 | 先出**四维蓝图**（模块×能力层级×素养×难度），确认后再命题 |
| 批改只判对错，讲评时说不清"为什么错" | 用 **E01–E14 错因码**给每个失分点打标，可跨次汇总 |
| 考完只知道均分，不知道下一步教什么 | 难度/区分度 + 错因矩阵 → Top3–5 + 分层处方 + 两课时安排 |
| 方程式配平"看着对"，学生照抄还是错 | 每个方程式必须附**原子/电荷/电子三项校验行** |
| 实验方案怕出事 | 强制过安全闸（危化品、通风、尾气、废液、禁止清单） |
| 真题讲完就完，不会迁移 | 考点定位 → 规范作答 → 评分点 → 考法归类 → 2 道变式 |
| 课件从零做，一下午没了 | 教材页 → 14–18 页大纲 → .pptx（或可照做的大纲） |

## 二、八条工作流

| 编号 | 名称 | 一句话 | 典型触发 |
|---|---|---|---|
| W0 | 受理分诊 | 先判读材料，再定任务 | "帮我看看这个" |
| W1 | 备课台 | 课题 → 可上课的 40 分钟 | "写教案""这一节怎么上" |
| W2 | 命题坊 | 蓝图 → 组卷 → 评分细则 | "出套单元测" |
| W3 | 批改台 | 错因码批注 + 共性错因 | "批改这些答卷" |
| W4 | 诊断室 | 分数 → 归因 → 处方 | "学情分析" |
| W5 | 讲解厅 | 概念 → 模型 → 例题 → 变式 | "学生听不懂" |
| W6 | 真题解码 | 考点 → 思路 → 评分点 → 变式 | "这道高考题怎么讲" |
| W7 | 化学工坊 | 配平/实验/有机/流程/计算 | "配平这个方程式" |
| W8 | 课件工场 | 教材页 → 幻灯片 | "做成课件" |

八条流不是孤立的：教案末尾会给你配套练习的入口，批改完会告诉你哪个错因该进诊断室，诊断完会指向讲解厅。**形成闭环**是它和"万能问答"最大的区别。

## 三、三条硬承诺

1. **可追溯**：每个专业结论都能说出依据——课标要求 / 教材章节 / 真题年份卷别 / 学科推理。不确定就降级表述，不编。
2. **可判分**：试题有答案、有评分细则、有给分点；两个老师用同一份细则评同一份卷，分数应当一致。
3. **可打印**：默认产出 A4 纵向的 .docx；成绩与错因另出 .csv（UTF-8 BOM，Excel 直接打开不乱码）。

## 四、怎么开始

### 安装

把整个 `czl-chem-teaching-suite/` 目录放进：

```
~/.workbuddy/plugins/marketplaces/experts/plugins/czl-chem-teaching-suite/
```

重启 WorkBuddy，在专家列表中选择「卓识化学」。

也可以直接把发布包 `dist/czl-chem-teaching-suite-1.0.1.zip` 通过「导入专家」导入（zip 内已保留单一顶层目录）。

### 第一句话可以这么说

- `帮我备《氧化还原反应》，人教版必修一，中等班，40 分钟`
- `出一套反应原理单元测，45 分钟，先给双向细目表`
- `这是我的月考成绩表，做学情分析，找出三个共性错因`
- `帮我配平这个方程式并给出校验`

### 不需要准备什么

课题名 + 年级就够跑。教材版本、班级层次、课时都有默认档（人教版 2019 / 高二 / 中等班 / 40 分钟），产物开头会标注用了哪一档，改一句话就能重出。

## 六、产品边界（它不做什么）

- 不提供教材、教辅、真题原文（版权原因），只做解析与归类，原文请用官方渠道。
- 不替教师做重难点取舍、课时安排、学生评价的最终决定，只给建议并标注"需教师确认"。
- 不给危险实验配方，不写违规操作；涉及安全一律按教材标准与实验室规范。
- 不承诺"必考""保过"" guaranteed 提分"这类话——它给的是可检验的过程，不是结果保证。
