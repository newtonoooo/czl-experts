# 09 质检闸门（交付前必过）

> 读它的时机：**每次交付前**。五道闸，全过才算完成；任何一闸不过，修改后重跑。

## G1 学科闸（正确性）

- [ ] 方程式：配平、电荷、电子转移三项都有校验行
- [ ] 计算结果：反代验算过，数量级合理
- [ ] 结构式/电子式：键数、孤对电子、电荷标注正确
- [ ] 概念表述：与课标/教材口径一致，没有"民间说法"
- [ ] 数据：没有来源的数字不出现；给出的数字标了口径

## G2 规范闸（可判分）

- [ ] 方程式有四要素（反应物产物、配平、条件、状态）
- [ ] 单位齐全且统一（mL/L、g/kg、kJ·mol⁻¹）
- [ ] 有效数字与题干数据位数匹配
- [ ] 简答题给的是"关键词句"而非长篇议论
- [ ] 表格有表头与单位，图有轴、单位、图注

## G3 安全闸（实验类必过）

- [ ] 危化品已点名并给了处置方式
- [ ] 通风、防护、尾气/废液处理已写
- [ ] 装置可行性（中学有器材）已确认
- [ ] 没有触碰"禁止清单"（见 `05-lab-safety.md` 第六节）
- [ ] 给了失败排查 3 条

## G4 可测闸（教学目标与作业）

- [ ] 每条教学目标含行为动词 + 内容 + 可测评结果
- [ ] 作业题标注对应目标编号
- [ ] 试题有分值、有答案、有评分点
- [ ] 难度与蓝图标注一致
- [ ] 时间估算（讲得完/做得完）

## G5 合规闸（隐私与版权）

- [ ] 无学生姓名、学号、可识别身份信息
- [ ] 未整段复制教材/教辅/试卷原文
- [ ] 真题标注了年份卷别，未编造
- [ ] 引用的外部资料来源可查
- [ ] 没有绝对化承诺（"必考""一定提分"）

## 交付前 12 条（按顺序打勾）

1. 产物是否回答了教师**原话里的那个问题**（而不是我擅长的那个）？
2. 开头是否有一句话结论？
3. 是否给了 2–3 个可调参数（教师能一句话改）？
4. 表格是否比大段文字多？
5. 有没有"综上所述""希望对您有帮助"这类填充句？（有则删）
6. 数字是否都带单位？
7. 方程式是否都带条件与校验？
8. 是否有"需教师确认"的标注（重难点、课时、分层）？
9. 打印版是否已生成（或已说明为何不能生成）？
10. 涉及数据时是否给了 csv？
11. 结尾是否给了 1 个延伸问题？
12. 文件名是否符合 `类型_主题_年级_YYYYMMDD`？

## 三条"看起来没问题但其实有问题"的自查

| 症状 | 实际问题 | 改法 |
|---|---|---|
| 内容很全，但教师不知道从哪看起 | 没有结论先行 | 开头加一句"这份材料的核心是……" |
| 题目都对，但学生一做就错 | 设问指向不清（问"原因"却要"目的"） | 每题只问一个思维节点 |
| 教案很漂亮，上不完 | 环节时间加起来超 40 分钟 | 用时间列求和，超了就砍"应用"环节 |
