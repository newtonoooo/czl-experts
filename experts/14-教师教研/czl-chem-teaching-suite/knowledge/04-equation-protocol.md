# 04 方程式协议（书写 · 配平 · 校验）

> 读它的时机：任何涉及方程式、离子方程式、电极反应式的任务。**核心要求：给结论，也给校验行。**

## 一、一个方程式必须齐四要素

1. **反应物与产物正确**（最难的一步，靠价态与类别推）
2. **配平**（原子守恒）
3. **条件**（△、催化剂、点燃、高温、浓/稀、光照）
4. **状态符号**（↑ 气体、↓ 沉淀；溶液中不标）

四要素缺一，在高考里就是扣分点（对应错因码 E04）。

## 二、氧化还原配平：五步法

以 `KMnO₄ + HCl(浓) → KCl + MnCl₂ + Cl₂↑ + H₂O` 为例：

1. **标变价**：Mn +7→+2（降 5）；Cl −1→0（升 1×2）。
2. **算升降总数**：Mn 得 5e⁻；每个 Cl₂ 失 2e⁻。
3. **定系数**：最小公倍数 10 → Mn 系数 2，Cl₂ 系数 5。
4. **配其余原子**：2KMnO₄ + 16HCl → 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O。
5. **校验**（必写）：
   - 原子：K 2=2，Mn 2=2，Cl 16=2+4+10 ✓，H 16=16，O 8=8 ✓
   - 电子：得 2×5=10，失 5×2=10 ✓

**歧化/归中反应**要特别小心：同一元素既升又降时，先判断产物价态是否合理（如 Cl₂ + NaOH 生成 Cl⁻ 与 ClO⁻，而不是 ClO₃⁻，除非加热）。

## 三、离子方程式：拆写规则

| 类型 | 拆不拆 | 例 |
|---|---|---|
| 强酸（HCl、H₂SO₄、HNO₃） | 拆 | H⁺ + Cl⁻ |
| 强碱（NaOH、KOH、Ba(OH)₂） | 拆 | Na⁺ + OH⁻ |
| 可溶性盐 | 拆 | NaCl → Na⁺ + Cl⁻ |
| 弱酸、弱碱（CH₃COOH、NH₃·H₂O） | 不拆 | 写分子式 |
| 沉淀（AgCl、BaSO₄、CaCO₃） | 不拆 | 写化学式 |
| 气体（CO₂、SO₂、NH₃） | 不拆 | 写化学式 |
| 氧化物（Fe₂O₃、MnO₂、CuO） | 不拆 | 写化学式 |
| 浓硫酸 | 不拆（以分子形式反应） | H₂SO₄(浓) |
| 微溶物（Ca(OH)₂、CaSO₄） | 看状态：澄清石灰水拆，悬浊液不拆 | 视情境 |

**三个必查**：① 电荷守恒（左=右）；② 原子守恒；③ 是否约成最简整数比（如 2H⁺+2OH⁻ 应写 H⁺+OH⁻）。

**易错示例**：
- 醋酸与 NaOH：`CH₃COOH + OH⁻ = CH₃COO⁻ + H₂O`（醋酸不拆）✓
- 碳酸钙与盐酸：`CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑`（CaCO₃ 不拆）✓
- 铁与稀硝酸（足量）：`Fe + 4H⁺ + NO₃⁻ = Fe³⁺ + NO↑ + 2H₂O`（注意介质 H⁺ 参与）✓

## 四、电极反应式：三步法

1. **判极**：原电池——负极氧化、正极还原；电解池——阳极（接正极）氧化、阴极（接负极）还原。
2. **写主物**：先写"谁变价、变成什么"，暂不配平。
3. **用介质配电荷**：酸性用 H⁺/H₂O，碱性用 OH⁻/H₂O，然后配平原子。

**示例（碱性氢氧燃料电池）**：
- 负极：`H₂ − 2e⁻ + 2OH⁻ = 2H₂O`
- 正极：`O₂ + 4e⁻ + 2H₂O = 4OH⁻`
- 总反应：`2H₂ + O₂ = 2H₂O`

**示例（铅蓄电池放电）**：
- 负极：`Pb + SO₄²⁻ − 2e⁻ = PbSO₄`
- 正极：`PbO₂ + 4H⁺ + SO₄²⁻ + 2e⁻ = PbSO₄ + 2H₂O`

校验：两电极得失电子数相等；相加后与总反应一致。

## 五、结构表示规范

| 表示 | 规范 | 常见错误 |
|---|---|---|
| 分子式 | C₂H₅OH 可，但有机题一般要求结构简式 | 把 C₂H₆O 当结构简式 |
| 结构简式 | CH₃CH₂OH；官能团不展开碳氢 | 写成 CH₃-CH₂-OH 带连线（可接受但非标准） |
| 电子式 | 用 · 或 × 表示最外层电子，离子加方括号与电荷 | 漏方括号、漏电荷、共价键画成离子 |
| 结构式 | 所有键画出 | 漏 H、键角明显错误 |

## 六、交付时必须带的"校验行"

```
【方程式】2KMnO₄ + 16HCl(浓) = 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O
【校验】原子：K2=2 Mn2=2 Cl16=2+4+10 H16=16 O8=8 ✓
【校验】电子：Mn 得 10e⁻，Cl 失 10e⁻ ✓
【条件】浓盐酸、加热（若题干为稀盐酸则不反应，需说明）
```

没有校验行的方程式，视为未完成（对应契约 C4 可复现）。
