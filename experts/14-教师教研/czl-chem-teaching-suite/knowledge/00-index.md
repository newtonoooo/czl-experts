# 知识库索引（Knowledge Router）

本目录是卓识化学的学科底座。**按需读取，不要一次全读。** 每个文件顶部都写了"什么时候读它"。

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| `01-curriculum-map.md` | 人教版（2019）五册章节、课标五大主题、学业质量水平 | 定位章节、写教学目标、判断是否超纲 |
| `02-exam-blueprint.md` | 新高考化学卷结构、能力层级、四维蓝图、难度标定、设问动词 | 命题、组卷、真题归类 |
| `03-error-codes.md` | E01–E12 错因码、判定信号、补救动作 | 批改、学情分析、讲解选点 |
| `04-equation-protocol.md` | 方程式书写/配平/离子式/电极式规范与校验 | 任何涉及方程式的任务 |
| `05-lab-safety.md` | 实验安全总则、危化品提示、装置顺序、事故处置、禁止清单 | 实验方案、实验课教案 |
| `06-organic-map.md` | 官能团转化网络（试剂/条件/类型） | 有机推断、合成路线 |
| `07-industrial-flow.md` | 工业流程四段式、常见操作目的库 | 流程题、工艺流程命题 |
| `08-formula-toolbox.md` | 计算模型（物质的量/守恒/差量/平衡/Ksp/热化学） | 任何计算 |
| `09-quality-gates.md` | G1–G5 质检闸门与交付前清单 | 每次交付前 |
| `10-source-index.md` | 权威公开资料索引、引用规范、版权边界 | 需要出处、需要拓展资料 |

## 使用约定

1. **先取后用**：写教案先读 01；出题先读 02；批改先读 03；碰方程式先读 04。
2. **一次最多读两个**：主文件 + 一个支撑文件。
3. **口径优先**：本目录内容与教师口述冲突时，以课标/教材口径为准，并说明差异。
4. **不替代教材**：本目录是"速查与判断框架"，不是教材原文；具体页码与原文表述请教师对照教材核对。
