# 07 工业流程四段式

> 读它的时机：流程题解析、工艺流程命题、条件控制类设问。

## 一、框架：所有流程题都拆成四段

```
原料预处理 → 核心反应/转化 → 分离提纯 → 循环与绿色化学
```

每一段只问三个问题：**这一步做什么？为什么这么做？不这么做会怎样？**

## 二、预处理：目的库（答题时对照取用）

| 操作 | 常见目的（写全才给满分） |
|---|---|
| 粉碎 / 研磨 | 增大接触面积，加快反应速率，使反应更充分 |
| 焙烧 / 煅烧 | 除去有机物或硫；使难溶物转化为可溶物；改变晶型便于浸出 |
| 酸浸 | 使金属氧化物溶解为可溶性盐；控制酸度防杂离子溶出 |
| 碱浸 | 除去油污；溶解两性氧化物（Al₂O₃）；使某些金属留在渣中 |
| 水浸 | 溶出可溶盐，与不溶杂质分离 |
| 氧化（通 O₂/H₂O₂/Cl₂） | 将低价离子氧化为高价，便于沉淀或浸出（如 Fe²⁺→Fe³⁺） |
| 还原 | 将高价离子还原为易沉淀或易浸出形态 |
| 调节 pH | 使特定离子水解沉淀而保留目标离子；抑制某离子水解 |
| 加沉淀剂 | 转化为更难溶沉淀（如加 Na₂S 除重金属） |
| 趁热过滤 | 防止目标产物在低温析出损失 |
| 洗涤（冰水/乙醇） | 减少溶解损失；乙醇洗涤可快速干燥、防氧化 |

## 三、核心反应：三类必写

1. **浸出反应**（氧化物 + 酸/碱）——写离子方程式。
2. **氧化还原反应**（变价）——写配平 + 电子守恒。
3. **沉淀/转化反应**——写离子方程式，注意 Ksp 大小关系（向更难溶方向转化）。

条件控制四问：**温度**（太高分解/挥发，太低速率慢）、**pH**（水解与沉淀的窗口）、**浓度/配比**（过量还是适量，过量后如何除去）、**时间**（反应完全 vs 效率）。

## 四、分离提纯：方法选择判据

| 目标 | 方法 | 判据 |
|---|---|---|
| 固液分离 | 过滤 | 一相为固体 |
| 溶质与溶剂分离 | 蒸发结晶 / 降温结晶 | 溶解度随温度变化小→蒸发；变化大→降温 |
| 互溶液体 | 蒸馏 / 分馏 | 沸点差 ≥30 ℃ |
| 溶质在两相中分配 | 萃取分液 | 溶质在萃取剂中溶解度大且不互溶 |
| 离子交换 | 离子交换树脂 | 去除特定离子 |
| 气体提纯 | 洗气 | 杂质与吸收剂反应，主体不反应 |

## 五、循环与绿色化学：四个得分点

1. **循环**：找出可返回上一步的母液/副产物（常考"母液返回浸出"）。
2. **原子经济性**：副产物是否有用、是否零排放。
3. **能耗**：是否需要高温高压，能否用余热。
4. **三废**：废气吸收、废水中和、废渣利用。

## 六、命题时的三个"反套路"

- 给一个"看起来多余"的步骤，问"能否省略"——考的是对副反应的理解。
- 给一组温度-产率数据，问"最佳温度"——要答"在此温度下产率已高且能耗低/副反应少"，不是简单读最高点。
- 给"母液循环"图，问"循环若干次后某离子浓度如何变化"——考积累效应。

## 七、常见失分点（E14）

- 目的只写"加快反应速率"，漏"使反应充分/提高浸出率"。
- 调节 pH 只写"使离子沉淀"，不写"哪种离子、为什么是它"。
- 洗涤目的只写"除去杂质"，不写"除去哪种可溶杂质、为什么用冰水/乙醇"。
- 循环只写"循环利用"，不写"返回到哪一步、循环的是什么"。
