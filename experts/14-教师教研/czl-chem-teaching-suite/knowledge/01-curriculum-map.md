# 01 课程地图（人教版 2019 · 课标对应）

> 口径：《普通高中化学课程标准（2017 年版 2020 年修订）》。章节名以人教版《普通高中教科书·化学》（2019 年版）为准。**读它的时机：定位章节、写教学目标、判断是否超纲。**

## 一、五册结构

### 必修 第一册（高一上）
| 章 | 节 | 高考地位 |
|---|---|---|
| 第一章 物质及其变化 | 物质的分类及转化 / 离子反应 / 氧化还原反应 | 全册地基，离子方程式与氧化还原是三年主线 |
| 第二章 海水中的重要元素——钠和氯 | 钠及其化合物 / 氯及其化合物 / 物质的量 | 物质的量是计算工具；钠氯是元素化合物起点 |
| 第三章 铁 金属材料 | 铁及其化合物 / 金属材料 | 变价金属，氧化还原的典型载体 |
| 第四章 物质结构 元素周期律 | 原子结构与元素周期表 / 元素周期律 / 化学键 | 周期律是推断题与结构题的公共基础 |

### 必修 第二册（高一下）
| 章 | 节 | 高考地位 |
|---|---|---|
| 第五章 化工生产中的重要非金属元素 | 硫及其化合物 / 氮及其化合物 / 无机非金属材料 | 硫氮是流程题与实验题的高频载体 |
| 第六章 化学反应与能量 | 化学反应与能量变化 / 化学反应的速率与限度 | 速率与限度是选必 1 的引桥 |
| 第七章 有机化合物 | 认识有机化合物 / 乙烯与有机高分子材料 / 乙醇与乙酸 / 基本营养物质 | 有机入门，官能团意识从此建立 |
| 第八章 化学与可持续发展 | 自然资源的开发利用 / 化学品的合理使用 / 环境保护与绿色化学 | 情境题素材库（绿色化学、资源利用） |

## 二、课标必修五大主题（写目标时的上位依据）

1. **化学科学与实验探究**：实验基本操作、物质的量、实验设计与评价、安全与规范。
2. **常见的无机物及其应用**：元素化合物性质与转化、离子反应、氧化还原。
3. **物质结构基础与化学反应规律**：原子结构与周期律、化学键、反应速率与限度、能量变化。
4. **简单的有机化合物及其应用**：官能团与性质、基本反应类型、生命中的有机物。
5. **化学与社会发展**：资源利用、环境保护、绿色化学、化学与生活。

选择性必修三模块：**化学反应原理**（能量 / 速率与平衡 / 水溶液离子平衡）、**物质结构与性质**（原子 / 分子 / 晶体）、**有机化学基础**（烃 / 衍生物 / 生物大分子 / 高分子）。

## 三、学业质量水平怎么用

| 水平 | 用途 | 命题特征 |
|---|---|---|
| 水平 1–2 | 合格性考试（学考） | 单点识记、直接应用 |
| 水平 3–4 | 等级性考试（高考） | 多知识点关联、真实情境、要求论证与设计 |

写教学目标时，用"水平 3"作默认档：**能在新情境中调用知识并说明理由**，而不是"记住某某"。

## 四、超纲判断的三条经验线

1. **必修阶段**不要求：Ksp 计算、电极反应式的复杂介质推导、晶胞密度计算、有机合成路线设计（只要求认官能团与基本反应）。
2. **选择性必修**才要求：盖斯定律、平衡常数计算、Ksp、晶胞、同分异构计数、合成路线。
3. **教材没有的定量结论**（如某些经验公式）不进课堂，除非作为拓展且标注。

## 五、章节 → 常见考法（命题时查）

| 模块 | 高频考法 |
|---|---|
| 物质分类与离子反应 | 离子共存、离子方程式正误判断、离子推断 |
| 氧化还原 | 配平、电子转移数目、氧化性还原性强弱、陌生方程式书写 |
| 元素化合物（钠氯铁硫氮） | 性质与转化、制备与除杂、实验探究、流程题原料 |
| 周期律与结构 | 位构性推断、电子排布、电离能电负性比较、化学键判断 |
| 反应原理 | 速率图像、平衡移动、K 计算、盖斯定律、电化学 |
| 水溶液 | pH 计算、滴定曲线、离子浓度排序、Ksp、盐类水解应用 |
| 有机 | 官能团性质、反应类型、同分异构、推断与合成 |
| 实验 | 装置选择与评价、操作目的、误差分析、定量实验 |
| 工业流程 | 预处理目的、条件控制、分离提纯、循环与绿色化学 |

> 章节名与节次以教材实际版本为准；不同版本（鲁科、苏教）顺序不同，但知识条目一致。
