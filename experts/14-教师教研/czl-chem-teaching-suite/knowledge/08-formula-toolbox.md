# 08 计算工具箱

> 读它的时机：任何定量任务。**原则：写关系式再代数，算完必须验算。**

## 一、物质的量：六条桥

| 已知 | 求 n | 公式 |
|---|---|---|
| 质量 m | n | n = m / M |
| 气体体积 V（标准状况） | n | n = V / 22.4 L·mol⁻¹ |
| 溶液浓度 c、体积 V | n | n = c · V（V 用 L） |
| 微粒数 N | n | n = N / N_A |
| 气体压强温度（理想气体） | n | pV = nRT |
| 反应热 | — | Q = n · ΔH（注意符号） |

常用 M（g·mol⁻¹）：H 1、C 12、N 14、O 16、Na 23、Mg 24、Al 27、Si 28、S 32、Cl 35.5、K 39、Ca 40、Fe 56、Cu 64、Zn 65、Ba 137、Ag 108。

## 二、四大守恒（化学计算的骨架）

1. **质量守恒**：反应前后总质量不变（用于差量与组成推断）。
2. **原子守恒**：某元素总量不变（用于多步反应"一步算"）。
3. **电荷守恒**：溶液中阳离子电荷总数 = 阴离子电荷总数（用于离子浓度比较）。
4. **电子守恒**：氧化剂得电子总数 = 还原剂失电子总数（用于氧化还原计算、电化学计算）。

**电子守恒的典型用法**：多步氧化还原不必写全方程式，直接"得失电子相等"列式。

## 三、差量法

适用：反应前后有质量/体积/压强差，且差值与反应量成比例。

```
Δm（实际）  /  Δm（理论，按方程式）  =  n（反应物） /  系数
```

典型：金属与酸反应后溶液增重；固体加热分解后质量减少；气体体积减少。

## 四、平衡与速率

| 量 | 公式 | 注意 |
|---|---|---|
| 平均速率 | v = Δc / Δt | 用浓度变化，单位 mol·L⁻¹·s⁻¹（或 min⁻¹） |
| 平衡常数 | K = ∏[生成物]^系数 / ∏[反应物]^系数 | 只含气体或溶液，纯固体/纯液体不写 |
| 浓度商 | Q，形式同 K，用瞬时浓度 | Q<K 正向，Q>K 逆向，Q=K 平衡 |
| 转化率 | α = 已转化 / 起始 ×100% | 与投料比有关 |
| 压强平衡常数 | Kp = ∏p(生成物)^系数 / ∏p(反应物)^系数 | 分压 = 总压 × 摩尔分数 |

## 五、水溶液

| 量 | 公式 | 说明 |
|---|---|---|
| 水的离子积 | Kw = c(H⁺)·c(OH⁻) = 1×10⁻¹⁴（25 ℃） | 温度升高 Kw 增大 |
| pH | pH = −lg c(H⁺) | 强酸直接算，弱酸先算电离度 |
| 电离常数 | Ka = c(H⁺)·c(A⁻)/c(HA) | 只与温度有关 |
| 水解常数 | Kh = Kw / Ka（弱酸根）；Kh = Kw / Kb（弱碱阳离子） | 越弱越水解 |
| 溶度积 | Ksp = c(Mⁿ⁺)^m·c(Aᵐ⁻)^n | 同类型难溶物比 Ksp 大小判沉淀先后 |
| 沉淀转化 | 向 Ksp 更小的方向进行 | 需比较同类型 |

## 六、热化学

1. **盖斯定律**：目标方程式 = 已知方程式的线性组合，ΔH 同样加减（注意反向变号、乘系数同乘）。
2. **燃烧热**：1 mol 纯物质完全燃烧生成稳定氧化物时的 ΔH（25 ℃、101 kPa），单位 kJ·mol⁻¹。
3. **中和热**：稀溶液中强酸强碱中和生成 1 mol H₂O 的 ΔH ≈ −57.3 kJ·mol⁻¹（教材值）。
4. **键能估算**：ΔH = Σ反应物键能 − Σ生成物键能（仅气态、近似）。

## 七、有效数字与单位（E08 的根源）

- 加减法：按**小数点后位数最少**的保留。
- 乘除法：按**有效数字位数最少**的保留。
- 题干给"0.1000 mol·L⁻¹"（4 位）→ 结果保留 4 位；给"0.1 mol·L⁻¹"（1 位）→ 结果保留 1–2 位。
- 单位必须跟数字走：c 用 mol·L⁻¹、V 用 L、m 用 g、ΔH 用 kJ·mol⁻¹。
- 常见陷阱：mL 未换算、cm³ 与 L 混用、质量分数与物质的量浓度混用。

## 八、验算四问

1. **数量级**对不对（结果是不是大得离谱/小得离谱）？
2. **单位**对不对（量纲能否约掉）？
3. **反代**回去是否成立（把答案代回原式）？
4. **极端值**检验（浓度取 0 或极大时，趋势是否合理）？
