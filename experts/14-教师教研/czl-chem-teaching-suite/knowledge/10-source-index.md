# 10 资料索引与引用规范

> 读它的时机：需要出处、需要拓展资料、需要判断"能不能引用原文"。

## 一、权威来源（按用途）

| 用途 | 来源 | 说明 |
|---|---|---|
| 课程标准 | 教育部《普通高中课程实施方案和课程标准（2017 年版 2020 年修订）》 | 教学目标、内容要求的最高依据；由人民教育出版社出版发行 |
| 教育部政策原文 | 中华人民共和国教育部官网 `www.moe.gov.cn` | 通知、方案类文件可查原文 |
| 教材与教师用书 | 人民教育出版社 `www.pep.com.cn` | 章节体系、教材表述、栏目设置的依据 |
| 数字教材与课程资源 | 国家中小学智慧教育平台 `basic.smartedu.cn` | 官方数字教材与课程资源入口 |
| 学科共同体 | 中国化学会 `www.chemsoc.org.cn` | 学科前沿、竞赛与科普信息 |
| 本省试卷结构 | 各省教育考试院/招生考试院官网 | **组卷前必须查本省当年结构** |
| 真题 | 各省教育考试院公布真题、权威教辅 | 引用必须能确认年份与卷别 |

> 以上为机构门户，具体栏目与链接会调整；需要引用时以检索到的当年页面为准，不凭记忆写链接。

## 二、引用规范（写进产物的格式）

| 场景 | 写法 |
|---|---|
| 引课标要求 | "依据课标'××'主题的内容要求"（写主题名，不编条目号） |
| 引教材 | "人教版选择性必修 1 第二章第二节"（只到节，不复制原文） |
| 引真题 | "20XX 年 XX 卷 第 X 题"（年份卷别不确定就不标） |
| 引数据 | "数据来源：<教师提供的成绩表>" 或 "<公开统计口径>" |
| 引外部观点 | "常见教学处理是……；另一种做法是……"（并列，不冒充权威） |

## 三、版权边界（本产品遵守的红线）

**可以做**：
- 引用章节标题、概念名称、课标条目名称；
- 用自己的话重述知识点与教学方法；
- 原创命题（情境取自公开的工业/生活常识）；
- 指路到官方平台，让教师自行获取教材与真题。

**不可以做**：
- 整段复制教材、教辅、试卷、教师用书原文；
- 把某套真题整卷搬运（即使是公开的，也可能有汇编版权）；
- 使用他人课件的版式、插图、动画；
- 声称"官方合作""指定用书""独家授权"。

## 四、找不到资料时怎么说

正确的说法：
> "这个结论我按课标口径给出；具体页码建议对照人教版选择性必修 1 第 X 章核对，我无法提供原文。"

错误的说法：
> "根据人教版第 87 页原文……"（没核对就写页码 = 编造）

## 五、给教师的"资料自备清单"

本产品不打包教材与真题（版权原因），建议教师自备：

1. 本人所用版本教材（纸质或官方数字教材）；
2. 近 3 年本省真题（教育考试院渠道）；
3. 本校近 2 次月考成绩表（用于 W4）；
4. 学生典型错题照片 5–10 份（用于 W3 建立错因基线）。

这四样备齐，本产品的八条工作流就能全部跑通。
