# 05 实验安全协议

> 读它的时机：设计实验方案、写实验课教案、评价装置。
> **本文件只给教材级标准操作与安全提示，不提供任何危险配方、超量操作或规避监管的做法。**

## 一、总则（每次实验方案必须写进"安全提示"栏）

1. **护具**：护目镜全程；接触腐蚀性试剂加手套；长发束起；不穿凉鞋。
2. **通风**：涉及 Cl₂、SO₂、NO₂、NH₃、HCl、H₂S、溴蒸气等刺激性/有毒气体，必须在通风橱或强力通风处进行，并配尾气吸收。
3. **少量**：课堂实验一律微量/小量；不因"现象明显"而加量。
4. **不入口**：实验室不饮食、不尝药、不直接闻（用手扇闻）。
5. **明火管理**：可燃气体（H₂、CH₄、C₂H₂）点燃前必须验纯；酒精灯不互点；加热试管口不对人。
6. **废液分类**：酸碱废液中和后排放；含重金属废液单独回收；有机废液不入水槽。

## 二、危化品提示（点名必须提示的几类）

| 物质 | 风险 | 课堂处置 |
|---|---|---|
| 浓硫酸、浓硝酸、浓盐酸 | 强腐蚀、挥发刺激 | 稀释放热（酸入水，沿壁缓慢），通风；不大量配制 |
| NaOH / KOH 固体 | 强腐蚀 | 用镊子取，避免接触皮肤；溅到立即大量水冲 |
| 氯气、二氧化硫、硫化氢 | 有毒、刺激 | 通风橱内微量制备，尾气用 NaOH 吸收 |
| 溴 | 强腐蚀、挥发 | 教材实验用溴水，不用液溴；通风 |
| 钠、钾 | 遇水剧烈反应 | 少量、煤油保存、镊子取、远离水 |
| 白磷 | 自燃 | 水中保存，不露天称量（中学一般不安排学生操作） |
| 硝酸银、铅盐、钡盐（可溶） | 重金属毒性 | 微量，废液回收，不排入水槽 |
| 乙醇、乙醚、苯 | 易燃/有毒 | 远离明火，通风；苯尽量用甲苯替代或只用模型 |

## 三、气体制备与净化的顺序（高频考点 + 安全点）

标准链路：**发生 → 除杂 → 干燥 → 主体反应/收集 → 尾气处理**

| 环节 | 要点 |
|---|---|
| 发生 | 固液不加热 / 固固加热 / 液液加热，装置与反应匹配 |
| 除杂 | 先除"会干扰后续的"杂质（如制 CO₂ 先去 HCl 再干燥） |
| 干燥 | 酸性气体用浓硫酸；碱性气体用碱石灰；NH₃ 不能用浓硫酸 |
| 收集 | 密度与溶解性决定（向上/向下排空气、排水法）；NO 只能用排水法 |
| 尾气 | Cl₂/SO₂/H₂S 用 NaOH 吸收；NH₃ 用稀酸吸收并防倒吸；CO 点燃 |

**防倒吸**三招：倒扣漏斗贴液面、安全瓶、末端加干燥管（或加热式）。写方案时必须说明用哪一招及理由。

## 四、常见事故处置（写进教案"应急"栏）

| 情况 | 处置 |
|---|---|
| 少量酸溅到皮肤 | 立即大量流水冲洗（≥15 分钟），再涂弱碱（如 3% NaHCO₃） |
| 碱溅到皮肤 | 大量流水冲洗，再涂弱酸（1% 硼酸） |
| 试剂入眼 | 立即用洗眼器/大量流水冲洗并就医，不揉眼 |
| 酒精灯打翻着火 | 湿抹布盖灭，不用水冲 |
| 少量有毒气体泄漏 | 立即开窗通风、撤离、报告 |
| 汞洒落（温度计破碎） | 撒硫粉覆盖，收集处理，通风 |

## 五、方案可行性的五个追问（交付前自问）

1. 这套装置在中学实验室**有器材**吗？
2. 尾气**去向明确**吗？
3. 加热方式**安全**吗（水浴/沙浴/直接加热）？
4. 现象**可观察**吗（颜色、沉淀、气体、温度）？
5. 失败时**怎么排查**（列 3 条最常见原因）？

## 六、禁止清单（红线，任何情况不给）

- 自制爆炸物、易燃气体的大量制备与点燃演示；
- 剧毒物质的提取、合成、提纯；
- 需要高压釜、强辐射、超低温等中学不具备条件的装置；
- "不用通风橱""用鼻子直接闻""徒手取强腐蚀试剂"等违规操作；
- 用生活用品替代专业器材的"土法"危险实验（如用饮料瓶做压力反应）。

教师坚持要做时：给**风险评估 + 教材标准替代方案 + 演示视频建议**，不提供具体危险参数。
