# 04　版本策略与更新日志

## 一、版本号规则

`主版本.次版本.修订号`（语义化版本）

| 位 | 什么时候加 | 例子 |
|---|---|---|
| 主版本 | 工作流结构、产物契约、清单字段发生不兼容变更 | 把 8 条流合并成 5 条 |
| 次版本 | 新增工作流 / 新增知识模块 / 新增输出格式 | 加 W9 竞赛辅导、加"错题本"导出 |
| 修订号 | 修正错误、改文案、调参数、补用例 | 修正一处配平示例、补 2 条路由用例 |

## 二、当前版本

**1.0.1**（2026-11-01）　首个公开发布版本（含上架校验修正）。

> 1.0.0 在提交平台时被四条校验拦下：简介 101 字超限、头像为 data URL 被判"无扩展名"、默认开场白与快捷指令不一致。1.0.1 已全部修正，工作流与知识库未改动。

完整变更见根目录 `CHANGELOG.md`。本文只记"版本相关的约定"。

## 三、兼容性说明

| 项 | 约定 |
|---|---|
| 清单格式 | 遵循 WorkBuddy 专家包 `plugin.json` 约定；不含自定义必填字段，缺失时不影响加载 |
| 知识库路径 | `knowledge/` 下文件名稳定；增删文件需同步 `plugin.json` 的 `knowledge` 数组与 `knowledge/00-index.md` |
| 工作流编号 | `W0–W8` 一经发布不改号（避免教师的使用习惯断裂）；新增流用 `W9` 起 |
| 错因码 | `E01–E14` 不改号；新增用 `E15` 起，废弃的码保留但标"不再使用" |
| 头像 | 默认内嵌 data URL；`tools/avatar_mode.py` 可切相对路径，切换不改变版本号 |

## 四、发布前检查清单（每次发版跑一遍）

```bash
python tools/validate_package.py       # 结构 / 清单 / 头像 / 命名 / 文案
python tools/selftest_workflows.py     # 九要素 / 引用 / 路由
python tools/build_release.py          # 打包 + SHA-256 + 自检
```

三条全绿，才改 `VERSION` 与 `CHANGELOG.md`。
