### T5 头像合规性（平台校验口径）

```
[INFO] avatar 字段类型：相对路径
[OK]   文件存在：334.1 KB
[OK]   PNG 尺寸：512x512
[NOTE] 当前为相对路径：这是市场提交的合规写法（平台认扩展名），上架后头像由平台传到 CDN，正常显示。
判定：提交态合规（本地私有导入可能显示为文字，可临时切 embed 验证）
```

平台校验只认 `png / jpg / webp` 扩展名，因此**提交形态必须写相对路径**。1.0.0 曾用内嵌 data URL（本地显示更稳），被平台判为"（无扩展名）"驳回，1.0.1 已改回相对路径。

同一工具对旧包（`highschool-chemistry-teacher`）的诊断，复现了"图标变文字"的三个条件：

```
[INFO] avatar 字段类型：相对路径
[INFO] 安装位置 marketplace：experts
[WARN] 不在 my-experts 下：市场/插件列表渲染会把相对路径拼成 CDN 地址…404 → 回退成名字首字
[WARN] 显示名「老师助手」与另外 7 个已安装专家重复
```

> 结论：**同一份相对路径，在市场上架后能正常显示（平台会把头像上传到 CDN），在本地私有导入时可能变文字**。两种场景要分开判断，不能用一个方案通吃。
