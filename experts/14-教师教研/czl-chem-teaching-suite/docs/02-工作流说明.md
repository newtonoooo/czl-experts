# 02　工作流架构说明

九条工作流不是九个并列功能，而是一条**教学闭环**上的九个站点。每条流的完整定义（职责/输入/步骤/判断/输出/异常/依赖/关系）在 `playbooks/` 里独立成卡，本文只讲它们怎么接。

## 一、闭环图

```
              ┌──────────────────────────────────────────────┐
              │                 W0 受理分诊                  │
              │        （判读材料 → 出任务卡 → 定流向）        │
              └───────┬──────────┬──────────┬───────────────┘
                      │          │          │
        ┌─────────────▼──┐  ┌────▼─────┐  ┌─▼────────────┐
        │  W1 备课台      │  │ W5 讲解厅 │  │ W6 真题解码   │
        │  教案/学案/板书  │  │ 学案/模型 │  │ 解析/变式     │
        └───┬────────┬───┘  └────┬─────┘  └──┬───────────┘
            │        │           │           │
            │        └─────┬─────┴───────────┘
            │              │ 产出"可练的题"
            │        ┌─────▼──────┐
            │        │  W2 命题坊  │  蓝图 → 组卷 → 评分细则
            │        └──┬──────┬──┘
            │           │      │ 学生作答
            │           │  ┌───▼────────┐
            │           │  │ W3 批改台   │ 错因码批注 + 共性错因
            │           │  └───┬────────┘
            │           │      │ 错因数据 (.csv)
            │           │  ┌───▼────────┐
            │           │  │ W4 诊断室   │ 统计 → 归因 → 处方
            │           │  └───┬────────┘
            │           │      │ Top 错因
            │           └──────┴────────► 回到 W5（出学案）/ W2（出专项）
            │
      ┌─────▼──────────┐        ┌──────────────────┐
      │ W7 化学工坊     │        │ W8 课件工场       │
      │ 配平/实验/有机/ │        │ 教材页 → 幻灯片   │
      │ 流程/计算       │        └──────────────────┘
      └────────────────┘
```

**一句话读法**：W1/W5/W6 产出"教什么"，W2 产出"练什么"，W3 产出"错在哪"，W4 产出"补什么"，补的结果回到 W1/W5。W7 是随时可插的学科工具箱，W8 是 W1 的展示层。

## 二、九要素速查表

| 工作流 | 职责 | 关键输入 | 核心判断 | 主输出 | 主要依赖 |
|---|---|---|---|---|---|
| W0 受理分诊 | 判读材料、定流向 | 材料 + 一句话诉求 | 意图命中哪条流 | 任务卡 | 无 |
| W1 备课台 | 课题 → 可上课设计 | 课题、年级、课型 | 课型决定骨架；前置知识 >2 即为难点 | 教案（含时间列/板书/分层作业） | 01 课程地图、05 安全 |
| W2 命题坊 | 蓝图 → 组卷 | 用途、范围、配比 | 自检 10 条 | 细目表 + 试卷 + 答案 + 细则 | 02 蓝图、04 方程式 |
| W3 批改台 | 按错因码批注 | 作答、答案、标准 | 规范失分单列 | 批注表 + 共性 Top3 + csv | 03 错因码 |
| W4 诊断室 | 分数 → 处方 | 成绩、满分、结构 | P/D 判定题目质量 | 报告 + 分层处方 + csv | 03 错因码、02 蓝图 |
| W5 讲解厅 | 讲透一个点 | 知识点、障碍类型 | 障碍类型决定处方 | 学案 + 半成品练习 | 03、04、08 |
| W6 真题解码 | 拆一道题 | 题目、年份卷别 | 题源确定与否 | 解析卡 + 变式 | 02、06、07 |
| W7 化学工坊 | 五类硬活 | 反应物/目的/路线/流程/已知量 | 子任务分支 + 校验 | 结果 + 校验行 + 安全栏 | 04、05、06、07、08 |
| W8 课件工场 | 教材页 → 幻灯片 | 教材页、课题、课时 | 栏目类型判重难点 | pptx 或逐页大纲 | 01 课程地图 |

## 三、交接约定（工作流之间传什么）

| 从 → 到 | 传递内容 | 格式要求 |
|---|---|---|
| W3 → W4 | 错因记录 | csv：学生标识、题号、得分、满分、错因码、失分类型 |
| W4 → W5 | Top 错因 + 涉及知识点 | 一句话 + 码 + 知识点 |
| W4 → W2 | 需强化考点 | 考点列表 + 建议题量 |
| W2 → W3 | 答案与评分细则 | 给分点表（点/分值/可接受表述） |
| W1 → W8 | 环节与重难点 | 教学过程表 + 重难点标注 |
| W6 → W2 | 变式题 | 题干 + 答案 + 难度标注 |
| W7 → W1 | 实验方案 | 装置流程 + 安全四行 |

**约定**：交接内容必须是**结构化**的（表/清单），不能是"上面说的那个"。这样教师换设备、换会话也能接上。

## 四、异常与降级（全局）

| 情况 | 全局处理 |
|---|---|
| 输入不全 | 用默认档先出，开头标注假设 |
| 材料读不清 | 只做可识别部分，列出"未识别"清单 |
| 跨 3 条以上流 | 拆任务清单，先做第 1 项 |
| 环境无 docx/pptx 能力 | 降级为排版文本 / 逐页大纲，明确标注 |
| 学科争议 | 并列两种口径 + 各自依据 |
| 违规请求 | 拒绝 + 给合规替代 |

## 五、扩展方式（后续版本）

- 新增工作流：在 `playbooks/` 增卡 → 主提示词路由表加一行 → `tools/selftest_workflows.py` 的 `CASES` 加两条用例 → CHANGELOG 记一条。
- 新增知识模块：放 `knowledge/` → 在 `00-index.md` 登记"什么时候读" → 在 `plugin.json` 的 `knowledge` 数组追加。
- 修改产物模板：只改对应 playbook 的"输出格式"节，不动主提示词（保持职责单一）。
