# 03　使用说明

## 一、安装（三种方式，任选）

### 方式 A：目录安装（推荐，便于改）

1. 把整个 `czl-chem-teaching-suite/` 复制到：
   ```
   ~/.workbuddy/plugins/marketplaces/experts/plugins/czl-chem-teaching-suite/
   ```
   Windows 下即 `C:\Users\<用户名>\.workbuddy\plugins\marketplaces\experts\plugins\`。
2. 若该目录下没有 `marketplace.json` 的登记项，可在同级的 `.codebuddy-plugin/marketplace.json` 的 `plugins` 数组里加一条：
   ```json
   { "name": "czl-chem-teaching-suite", "source": "./plugins/czl-chem-teaching-suite", "description": "卓识化学 · 高中化学教学全流程助手", "version": "1.0.1" }
   ```
3. 重启 WorkBuddy → 专家列表出现「卓识化学」。

### 方式 B：zip 导入

用 `dist/czl-chem-teaching-suite-1.0.0.zip` 走「导入专家」。zip 内已保留单一顶层目录，导入后会自动登记。

### 方式 C：市场投稿后安装

投稿通过后，在专家市场搜索「卓识化学」安装。**投稿前先执行**：

```bash
python tools/avatar_mode.py --mode relative
```

把头像切回平台标准的相对路径写法（平台会按该路径把头像上传到 CDN）。

## 二、第一次对话

选中「卓识化学」，直接说需求即可。三个开箱示例：

```
帮我备《氧化还原反应》，人教版必修一，中等班，40 分钟
```
→ 得到：素养目标 / 重难点 / 教学过程（含时间列）/ 板书 / 三层作业 / 需教师确认项。

```
出一套反应原理单元测，45 分钟，先给双向细目表
```
→ 先给蓝图（考点×模块×能力层级×难度×分值），你说"可以"，再出卷 + 答案 + 评分细则。

```
这是我的月考成绩表（上传 xlsx），做学情分析，找出三个共性错因
```
→ 得到：统计表 / 板块得分率 / 题目难度区分度 / 错因 Top3 / 分层处方 / 两课时安排 + csv。

## 三、怎么问效果更好

| 想得到 | 这样说 |
|---|---|
| 更贴合本校 | 补一句"我们用人教版，学生基础偏弱，40 分钟" |
| 更难的题 | "难度配比改成 4:4:2" |
| 只要一页 | "压成一页 A4，去掉解析" |
| 要能打印 | 默认就会给 docx；说"只要屏幕版"可省 |
| 换讲法 | "换个切入角度，用微观模型讲" |
| 只改一部分 | "第 3 题太难，换掉，其余不动" |

## 四、八条流怎么用（速查）

| 你说 | 它做 | 你还要做什么 |
|---|---|---|
| 写教案 | W1 | 确认重难点取舍、课时是否够 |
| 出题 | W2 | 确认蓝图；考完把答卷给它 |
| 批改 | W3 | 提供答案或让它用 W2 的答案 |
| 学情分析 | W4 | 提供成绩表（可删姓名列） |
| 讲知识点 | W5 | 告诉它学生具体卡在哪 |
| 讲真题 | W6 | 提供题目，最好带年份卷别 |
| 配平/实验/路线/流程/计算 | W7 | 提供反应物或目标物 |
| 做课件 | W8 | 提供教材页图片 |

## 五、产物在哪

- 对话里给一份**屏幕版**（结论 + 表格 + 使用提示）。
- 同时在当前工作目录生成**打印版** `类型_主题_年级_YYYYMMDD.docx`。
- 涉及成绩/错因时另出 `.csv`（UTF-8 BOM，Excel 双击不乱码）。
- 在结果区可直接预览与下载。

## 六、注意事项

1. **成绩表请删掉姓名列**。它只需要分数与题号；带姓名也不会用，反而增加泄露风险。
2. **真题请给原题**。它会标注年份卷别；没给年份它不会瞎编，但会自动降级为"来源未确认"。
3. **实验方案请说明学校条件**（有无通风橱、几人一组）。不说的话按"标准中学实验室、4 人一组"给。
4. **它会给"需教师确认"的标注**，那不是客套：重难点取舍、课时安排、分层方案最终由你定。
5. **课件生成看环境**。当前环境若无演示文稿能力，会给你逐页大纲（页码/标题/要点/配图说明），照着做 20 分钟能成。

## 七、常见问题

**Q：为什么它先给蓝图不直接出卷？**
A：直接出卷容易出现"前 5 题都是同一考点""难度全在中档"。蓝图是先对齐再动笔，改起来便宜。

**Q：错因码 E01–E14 学生要背吗？**
A：不用。码是给教师汇总用的；给学生的是具体动作（"这一步漏了条件符号"）。

**Q：能不能一次给三个需求？**
A：可以，但它会拆成任务逐个交付。想要快，一次一个最稳。

**Q：和通用 AI 有什么区别？**
A：三条：方程式必须带校验行；实验必须过安全闸；数据类必须出 csv 可汇总。这三条是硬约束，不是风格偏好。

**Q：导入后图标是文字怎么办？**
A：见 `docs/07-头像不显示排查.md`；本包默认已用内嵌头像规避。自检命令：`python tools/doctor_avatar.py .`
