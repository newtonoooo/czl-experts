# 01　产品规格说明

- 产品名：卓识化学（Zhuoshi Chemistry）
- 职称：卓识教育-高中化学老师助手
- 专家标识：`czl-chem-teaching-suite`
- 版本：1.0.1　｜　开发/维护：虫志龙（47190078@qq.com）
- 形态：Agent 型专家包（单智能体 + 工作流卡 + 知识库 + 资料包 + 本地脚本）

---

## 1. 目标用户

**主要用户**：普通高中化学教师（含高一至高三），每周 8–14 节课，带 2–4 个班，兼任备课组任务。

**次要用户**：
- 教研组长/备课组长：需要统一命题口径、汇总全年级错因；
- 师范生与新教师：需要"照着能上"的教案与讲解路径；
- 校外辅导教师：需要按学生错因出针对性练习。

**不是目标用户**：学生本人（本产品不设计为自学工具，产物面向教师复用）、大学化学、竞赛拔高训练（超出课标口径）。

## 2. 实际使用场景（来自一线常态）

| 场景 | 时间压力 | 现状痛点 | 本产品介入点 |
|---|---|---|---|
| 明天第一节要上新课 | 1 晚 | 教案写了但环节时间对不上，实验没想清楚安全 | W1 出可上课设计 + 实验安全四行 |
| 周五要交月考卷 | 2–3 天 | 出题凭经验，难度不稳，答案要自己再算一遍 | W2 先给四维蓝图，再逐题配答案与评分细则 |
| 两个班 90 份卷子要批 | 1 晚 | 只能打勾叉，讲评时说不清"为什么错" | W3 错因码批注 + 共性 Top3 |
| 考后年级组要分析 | 1 天 | 只会算均分，不知道下一步教什么 | W4 难度/区分度 + 分层处方 + 两课时安排 |
| 学生普遍卡在某点 | 随时 | 讲了三遍还是不懂，换个讲法没把握 | W5 模型化讲解 + 半成品练习 |
| 讲评真题 | 1 节 | 讲完就完，学生不会迁移 | W6 考点→评分点→变式 |
| 临时被问"这题怎么配平" | 立刻 | 怕讲错，尤其电极反应式 | W7 三项校验行，敢让学生抄 |
| 公开课/赛课要做课件 | 1 周 | 从零做 20 页，一下午没了 | W8 教材页→大纲→pptx |

## 3. 要解决的问题（按优先级）

1. **产物不可直接用**：通用 AI 给的教案"看着全，上不完"，试题"有答案没细则"。
2. **错误无法归因**：批改只到对错，无法回答"这个班到底缺什么"。
3. **学科特有的严谨性缺失**：方程式不校验、实验不谈安全、真题敢编年份。
4. **重复劳动**：同一份内容要改写成教案、练习、课件、分析四种形态。
5. **口径不统一**：同一备课组两位老师出题难度、评分标准不一致。

## 4. 输入规范

### 4.1 最小输入（有它就能开工）

| 工作流 | 最小输入 |
|---|---|
| W1 | 课题（如"盐类的水解"） |
| W2 | 用途（小练/单元测/月考）+ 范围（章节或知识点） |
| W3 | 学生作答（图片/文本）+ 题目与答案 |
| W4 | 成绩数据（学生×题号得分 或 学生总分+板块分）+ 满分 |
| W5 | 知识点（+ 学生障碍描述更佳） |
| W6 | 题目（图片/文字） |
| W7 | 反应物 / 实验目的 / 起始物与目标物 / 流程图 / 已知量与所求（按子任务） |
| W8 | 教材页图片或电子教材 + 课题 |

### 4.2 可选输入与默认档

| 参数 | 默认 |
|---|---|
| 教材版本 | 人教版（2019） |
| 年级 | 高二 |
| 班级层次 | 中等班 |
| 课时 | 40 分钟 |
| 难度配比 | 易:中:难 ≈ 5:3:2 |
| 详细度 | 中等 |

### 4.3 输入形态支持

- 图片：教材页、题目照片、学生答卷、成绩表截图（须可辨认）
- 文档：PDF / Word / 文本（电子教材、试题文档）
- 表格：xlsx / csv（成绩、错因统计）
- 语音转写文本（教师口述需求）

## 5. 输出规范

每份产物必须满足五条契约：

| 契约 | 判定标准 |
|---|---|
| C1 可上课 | 教学过程含时间列且合计 ≤ 课时；有板书；有作业 |
| C2 可判分 | 试题有答案 + 评分细则 + 给分点；批改有错因码 |
| C3 可追溯 | 专业结论标依据（课标/教材/真题年份卷别/推理） |
| C4 可复现 | 方程式有校验行；计算有"已知—求—式—代—答" |
| C5 可交回 | 默认 .docx（A4 纵向）；数据类另出 .csv |

**文件命名**：`类型_主题_年级_YYYYMMDD.docx`，例 `教案_盐类的水解_高二_20261101.docx`。

## 6. 通用处理步骤（所有工作流共用）

```
受理（W0 判读）→ 取知识（按路由读 knowledge/）→ 生成 →
过五闸（G1 学科 / G2 规范 / G3 安全 / G4 可测 / G5 合规）→
交付（屏幕版 + docx + 必要时 csv）→ 给下一步钩子
```

## 7. 工具能力与技术接口

| 能力 | 用途 | 依赖 |
|---|---|---|
| 图片/文档读取 | 读教材页、题目、答卷、成绩表 | 运行环境内置读取能力 |
| 文件写入 | 生成 .docx / .csv / .pptx | python-docx / 演示文稿能力（不可用时降级） |
| 计算 | 统计、配平校验、单位换算 | 运行时计算工具（不心算） |
| 本地脚本 | 包校验、头像诊断、打包 | Python 3.9+ 标准库，无第三方依赖 |
| 联网检索 | 核对课标/教材/卷结构 | 运行时联网能力（可选） |

**不依赖**：任何 MCP 连接器、任何第三方 API Key、任何外部数据库。装好即可用，离线可用（除需要联网核对的场景）。

## 8. 质量、速度、稳定性要求

| 维度 | 要求 | 保障手段 |
|---|---|---|
| 学科正确性 | 方程式/计算/结构式零错误 | 校验行 + 五闸 + 工具核算 |
| 可判分性 | 两位教师评分一致 | 评分细则写"给分点 × 分值 × 可接受表述" |
| 速度 | 单工作流首版 ≤ 1 轮对话内给出 | 按需读取（不预载全部知识库）；默认档先行 |
| 稳定性 | 缺参数不断流 | 默认档 + 降级策略（见主提示词第 7 节） |
| 一致性 | 同一输入两次产出结构一致 | 产物模板固化在 playbook 的"输出格式" |
| 安全 | 实验方案 100% 带安全栏 | G3 闸门为硬门槛 |

## 9. 非功能要求

- **隐私**：不收集学生姓名/学号；成绩只处理分数与题号。
- **版权**：不打包教材、教辅、真题原文；引用只到章节名与考点。
- **可维护**：知识库与工作流卡解耦，改一处不影响其他；版本号与 CHANGELOG 同步。
- **可审计**：每个脚本可独立运行并输出结论，测试报告记录真实执行结果。

## 10. 与同类产品的差异（定位）

| 维度 | 通用 AI 问答 | 单点工具型专家 | 卓识化学 |
|---|---|---|---|
| 覆盖 | 什么都能问，什么都不深 | 只做一件事 | 八条流首尾相接，形成教学闭环 |
| 产物 | 聊天文本 | 单一格式 | 屏幕版 + docx + csv |
| 学科严谨 | 经常不校验 | 视实现而定 | 方程式三项校验为硬要求 |
| 归因 | 无 | 无 | E01–E14 错因码可跨次汇总 |
| 安全 | 常忽略 | 常忽略 | 实验方案强制过安全闸 |
