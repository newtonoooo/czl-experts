# 05　版权、来源与合规说明

> 本文回答三件事：**内容从哪来、能不能商用、哪些地方还要你确认。**

## 一、本包内容的来源

| 类别 | 来源 | 处理方式 |
|---|---|---|
| 主提示词（`agents/`） | 本次为产品重新撰写 | 按"路由 + 契约 + 红线 + 异常"结构原创组织 |
| 工作流卡（`playbooks/` W0–W8） | 本次原创 | 每条按"职责/输入/步骤/判断/输出/异常/依赖/关系"九要素独立撰写 |
| 知识库（`knowledge/` 11 件） | 本次原创整理 | 学科内容依据公开课标与教材目录的事实性信息（章节名、主题名、知识条目），表述与组织方式为自撰 |
| 资料包（`materials/`） | 本次原创编制 | CSV 为自行整理的对照表；卷结构数字取自 2025 年各省公开公布的信息 |
| 头像（`avatars/`） | 本次用图像生成能力创作，再裁切、缩放 | 不含第三方素材、字体、图标；已去除生成工具默认水印 |
| 脚本（`tools/`） | 本次原创 | 仅使用 Python 标准库，无第三方依赖 |
| 文档（`docs/`） | 本次原创 | — |

## 二、与既有专家包的关系

本产品在立项时**只把既有高中化学专家包当作"功能需求分析"的参照**，用于回答"教师需要哪些能力"。具体边界：

| 项 | 是否使用 | 说明 |
|---|---|---|
| 功能清单（教案/命题/批改/学情/真题/配平/实验/课件） | 参考 | 属于通用教学需求，不构成受保护的表达 |
| 原有提示词文本 | **未复制** | 本包主提示词为重新组织，结构、章节、措辞均不同 |
| 原有 `references/` 知识文件 | **未复制** | 本包知识库为独立编写的 11 个文件，内容深度与组织方式不同（新增错因码、四维蓝图、方程式校验、流程四段式等） |
| 原有目录结构（`references/`） | **未沿用** | 本包改为 `playbooks/` + `knowledge/` + `materials/` + `tools/` 的分层结构 |
| 原有头像 | **未使用** | 本包头像为本次新生成 |
| 原有宣传文案、名称、职称 | **未使用** | 名称「卓识化学」、职称「卓识教育-高中化学老师助手」均为新定 |
| 原有许可证/版权声明 | 未删除、未修改 | 原包文件保持原样，未被改动 |

> 结论：本包是**按需求重新实现**的独立产品，不是改名换皮的产物。若平台审核需要，可提供本目录 `docs/08-开发记录.md` 作为创作过程的说明。

## 三、第三方内容与许可证

| 项 | 结论 |
|---|---|
| 代码依赖 | **无**。`tools/` 四个脚本只用 Python 标准库（`json/os/base64/struct/zipfile/hashlib/re/math` 等） |
| 图片素材 | **无第三方素材**。头像为生成后自行裁切；无图标库、无字体嵌入 |
| 教材原文 | **无**。不打包教材 PDF/扫描页；只引用章节名与知识条目 |
| 真题原文 | **无**。不打包试卷；解析时引用题源标识（年份+卷别），不整段复制 |
| 教辅题目 | **无**。试题一律原创或由教师提供后解析 |
| 开源许可证 | 不适用（无第三方代码） |
| 商标与机构名 | "人教版""人民教育出版社""教育部""中国化学会"等仅作**事实指称**，不表示任何合作、授权或背书 |

## 四、可以宣称什么、不可以宣称什么

**可以**（与实现一致）：
- 面向高中化学教师的教学全流程助手；
- 覆盖备课、命题、批改、诊断、讲解、真题、实验与计算、课件八类任务；
- 产物默认出打印版 docx，数据类出 csv；
- 方程式附三项校验，实验方案带安全栏。

**不可以**（本包文案中已全部避免）：
- "官方合作""官方认证""指定用书""独家授权"；
- "押中真题""保过""保证提分"；
- "由某名校/某机构研发"（除非你确有该资质并能提供证明）；
- "收录 N 套真题/全套教材"（本包不含原文）。

## 五、商业发布前仍需你确认的事项

| 事项 | 为什么需要你确认 | 建议动作 |
|---|---|---|
| 头像的著作权归属 | AI 生成图片的版权状态在各地司法实践中仍有差异；商用需谨慎 | 保留生成时间、提示词、原始文件（已在 `docs/08-开发记录.md` 记录）；如需绝对稳妥，可换用纯几何图形标识 |
| 平台分成与原创认定规则 | 各平台对"专家包"的商用条款不同 | 投稿前阅读平台最新协议；保留本包开发记录作为原创证据 |
| 教育类内容审核要求 | 部分平台要求教育类内容提供资质或免责声明 | 准备免责声明（已在 `LICENSE` 与本文第四节写明）；如平台要求资质，需你提供 |

| 商标使用 | 名称「卓识化学」「卓识教育」是否已被注册 | 商用前做一次商标检索；若冲突需改名（改名只动 `plugin.json` 与文档，不动工作流） |
