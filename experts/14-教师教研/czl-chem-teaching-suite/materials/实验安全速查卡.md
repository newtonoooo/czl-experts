# 化学实验室安全速查卡（一页版）

> 打印建议：A4 纵向，贴在实验室门后或备课夹首页。

## 进实验室之前

- 护目镜、实验服、长发束起、不穿凉鞋。
- 明确三件事：**用什么试剂、产生什么气体、废液倒哪里**。
- 检查：通风是否开启、洗眼器是否可用、灭火器位置。

## 四条铁律

1. **酸入水**，沿器壁缓慢，边加边搅；绝不反序。
2. **闻气用手扇**，不直接把鼻子凑上去。
3. **点燃可燃气体前必须验纯**（H₂、CH₄、C₂H₂）。
4. **尾气必须有去处**：Cl₂/SO₂/H₂S 用 NaOH 吸收；NH₃ 用稀酸并防倒吸。

## 常见风险物质（课堂只用小量）

| 物质 | 一句话风险 | 处置要点 |
|---|---|---|
| 浓硫酸 / 浓硝酸 | 强腐蚀、放热、挥发 | 通风、稀释规范、护目 |
| NaOH / KOH 固体 | 强腐蚀 | 镊子取、不裸手 |
| 氯气 / 二氧化硫 / 硫化氢 | 有毒刺激 | 通风橱、微量、尾气吸收 |
| 溴水 | 腐蚀挥发 | 通风、避免接触皮肤 |
| 钠 / 钾 | 遇水剧烈反应 | 煤油保存、镊子取、远离水槽 |
| 白磷 | 自燃 | 水中保存，中学不安排学生操作 |
| 银盐 / 铅盐 / 可溶钡盐 | 重金属毒 | 微量、废液回收 |
| 乙醇 / 乙醚 / 苯 | 易燃、有毒 | 远离明火、通风；苯尽量替代 |

## 事故处置（记住前 10 秒）

| 情况 | 立刻做 |
|---|---|
| 酸溅皮肤 | 大量流水冲 ≥15 min → 3% NaHCO₃ |
| 碱溅皮肤 | 大量流水冲 → 1% 硼酸 |
| 试剂入眼 | 洗眼器/流水冲 → 就医，不揉 |
| 酒精灯着火 | 湿抹布盖灭，不泼水 |
| 有毒气体泄漏 | 开窗、撤离、报告 |
| 汞洒落 | 撒硫粉、收集、通风 |

## 课堂实验方案必须写的四行

```
【安全】试剂风险：……
【通风】……
【防护】……
【废弃物】废液/尾气去向：……
```

缺这四行，方案不算完成。
