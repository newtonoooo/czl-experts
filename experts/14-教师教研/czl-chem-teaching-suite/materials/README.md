# 教学资料包说明

本目录是卓识化学的随身资料，全部为原创整理，**不含任何教材、教辅、试卷原文**。

## 一、包里有什么

| 文件 | 内容 | 怎么用 |
|---|---|---|
| `教材章节-考点对照表.csv` | 人教版（2019）五册 60 个节次 × 模块 / 课标主题 / 常见考法 / 高考权重 / 高频错因码 | 备课找定位、命题找覆盖、讲评找错因 |
| `错因码速查表.csv` | E01–E14 错因码及判定信号、补救动作 | 批改时对照打码；学情分析时汇总 |
| `高考化学卷结构对照.csv` | 主流新高考单科卷、广东卷、西北四省卷、传统理综卷的结构 | 组卷前先确认本省结构 |
| `公开资源索引.csv` | 官方与权威入口，附版权提示 | 找课标、教材、真题时按图索骥 |
| `实验安全速查卡.md` | 一页纸的实验室安全要点 | 打印贴在实验室或备课夹 |

## 二、包里没有什么（以及为什么）

| 没有 | 原因 | 替代做法 |
|---|---|---|
| 教材 PDF / 扫描页 | 教材受版权保护，不能打包分发 | 用官方数字教材或纸质教材；本产品只引用章节名与要点 |
| 高考真题原卷 | 真题汇编可能涉及汇编权 | 教师自备本省真题；本产品负责解析与考法归类 |
| 教辅题目 | 版权不明 | 一律原创命题，或由教师提供题目后解析 |
| 课件模板 / 插图 | 第三方素材授权不明 | 课件用纯文字 + 自绘示意图说明 |

## 三、建议的自备材料（四样）

1. 本人所用版本教材；
2. 近 3 年本省真题；
3. 本校近 2 次考试成绩表（只保留分数与题号，不含姓名）；
4. 学生典型错题照片 5–10 份。

四样齐了，八条工作流可以全部跑通。

## 四、数据口径提醒

- `高考化学卷结构对照.csv` 中的数字来自 2025 年各省公开公布的结构与真题卷头，**仅作参考**；组卷前请以本省当年正式文件为准。
- `教材章节-考点对照表.csv` 的"高考权重"是经验判断（高/中/低），不是统计结果，用于分配题量比例，不作绝对依据。
