# 使用说明

面向高中数学老师的操作手册。不需要懂技术，按场景照做即可。

## 一、它是什么，不是什么

**是**：一个教研工作台。你把要求说清楚，它出教案、出卷子、算学情、写讲评、做课件脚本，最后给你一个能直接打印的 Word。

**不是**：题库（不提供成题检索）、不是网盘（不存你的资料）、不是学生端（不面向学生）。

## 二、第一次用：三句话就够

打开专家，直接说你要干什么。它最多反问你三个问题，然后开工。

```
把《函数的单调性》备成一节 45 分钟的课，教案要能照着上，附板书设计和分层作业
```

```
按新高考 8+3+3+5 结构出一套「导数及其应用」单元卷，先给双向细目表
```

```
这是我们班这次月考的分题得分表，算出各题得分率、排出失分点，给两节课的讲评顺序
```

## 三、七个场景怎么用

### 场景 1 · 备一节课

**你给**：课题 + 年级 + 教材版本。可选：课型、班级均分、课时长度。

**它给**：教学目标（行为动词）、重难点、学情三行、时间预算表、问题链（含预期错误回答）、板书分区、三处卡点话术、分层作业。

**你会看到**：教案末尾有「需要你拍板的三处」——那是它不敢替你决定的地方（例题取舍、作业量、班级适配）。

**提醒**：如果它写"引导学生体会"，那是它的错。这类句子对任何一节课都成立，等于没写。你可以直接说"这句删了，换成具体动作"。

### 场景 2 · 出一套卷

**你给**：考试范围 + 卷型（单元测/月考）。可选：总分、题量、难度目标。

**流程是两步，不要跳过第一步**：

1. 它先给一张双向细目表（题号×考点×难度×分值×模块），并附体检结果：总分够不够、模块占比是否失衡、难度系数预估多少。
2. **你说"可以"，它才开始写题。**

**为什么要这样**：改表两分钟，改题两小时。

**如果它是单元卷**：告诉它"这是单元卷，整卷就考导数"，否则它会因为"单模块占比 100%"报错。它支持单元卷模式。

### 场景 3 · 批一个班的卷子

**你给**：学生作答照片（拍清楚）或文字，以及评分标准。

**它给**：逐题批注（哪一步错、扣几分、为什么）、错因码（概念/计算/审题/方法/规范）、两句评语（一句夸具体动作、一句改一个动作）、订正范围。

**评语的规矩**：不写"继续努力"。写"下次先在题目上圈出'取值范围'三个字"。

### 场景 4 · 算这次考得怎么样

**你给**：一张分题得分表。格式见下（CSV，Excel 另存即可）：

```
学号,1,2,3,...,19
01,5,5,0,...,9
02,5,0,5,...,12
```

**同时告诉它每题满分**，一句话就行：

```
这是我们班的分题得分表，满分是 5,5,5,5,5,5,5,5,6,6,6,5,5,5,13,15,15,17,17
```

**它给**：均分、中位数、标准差、分数段分布、各题得分率、讲评优先级排序。

**关键**：所有数字由脚本算，不是模型估的。报告里每个数都能复算。

**不想让学生姓名进系统**：用学号就行，它不会问姓名。

### 场景 5 · 讲透一个知识点

**你给**：知识点名称 + 学生层次。

**它给**：五段式学案——它解决什么问题 → 定义怎么长出来的 → 例题（标每步为什么）→ 三个反例 → 变式。

**三个反例是重点**。定义里每个词去掉会怎样，靠反例说清楚。

### 场景 6 · 拆一道压轴题

**你给**：题目原文（或照片）。

**它给**：得分点地图 + 三档打法：

- **保底**：4 分钟拿第 1 问的 5 分
- **争取**：7 分钟拿第 2 问的 5 分
- **放弃**：2 分钟写第 3 问的第一行，拿 1 分

目标写清楚：**这道题你应该拿 11–12 分**。拆解不是为了降低难度，是把"我做不到"变成"我能拿到 12 分"。

### 场景 7 · 做课件

**你给**：课题 + 教材版本。可选：常态课还是公开课、16:9 还是 4:3。

**它给**：逐页脚本。每页四样：页面内容、讲述词、停留秒数、与板书的同步点。

**"停留"这一栏最重要**——它逼你想清楚这一页是"我讲"还是"他们想"。

常态课 14–18 页。超过 20 页，说明在念 PPT。

## 四、想要 Word 文件

默认就会给。可打印的东西它都出 `.docx`：A4、宋体小四、1.5 倍行距、页脚带课题和页码。

如果你只想要对话里的内容，说一句"不用出文件"。

## 五、它什么时候会停下来问你

| 情况 | 它会怎么做 |
|---|---|
| 你没说年级或教材版本 | 问一次；你不答就按课标通用口径做，并在首页标注 |
| 分数表缺满分 | 停下来问，不猜 |
| 图片看不清 | 指出哪一题哪一步看不清，请补拍那一处，不臆造题干 |
| 一道题算不通 | 明说"第 18 题第(2)问我没验通"，不编一个答案 |
| 你要求改分/代写作业 | 拒绝，说明边界 |

## 六、附带的命令行工具（可选）

懂一点电脑的话，这六个脚本可以单独用，全部零依赖（只要装了 Python 3.8+）：

```bash
# 学情统计
python bin/score_report.py 成绩.csv --full-marks 5,5,5,6,6,6,5,5,5

# 细目表体检（--init 生成空白模板，--unit 表示单元卷）
python bin/blueprint.py --init 细目表.csv
python bin/blueprint.py 细目表.csv --unit

# 交付前质检
python bin/qa_gate.py 教案.md --kind lesson --minutes 45

# 转 Word
python bin/md_to_docx.py 教案.md -o 教案.docx --footer "函数的单调性 · 高二"

# 专家包自检（含头像排查）
python bin/check_package.py .

# 全部脚本自测
python bin/self_test.py
```

## 七、常见问题

**Q：它给的答案我不放心怎么办？**
A：看交付消息末尾的"校验回执"。五项分别代表：回代、边界、范围与符号、方法互证、题号对齐。有"未消除的不确定"那一行时，那是它自己没把握的地方，会明确告诉你题号。

**Q：能不能直接给我 PPT 文件？**
A：目前给逐页脚本（Word）。脚本里每页四要素齐全，照着做 20 分钟能出 PPT。如果你本机的 WorkBuddy 有 PPT 能力，可以让它把脚本转成 pptx。

**Q：能引用教材原图吗？**
A：不能自动引用。它会标"此处需引用教材 P××，请核对"，图由你自己拍或扫。这是版权问题，不是能力问题。

**Q：它会不会把我的成绩数据传出去？**
A：不联网。所有计算在本机脚本里完成，不写入任何外部服务。

**Q：单元卷为什么老是报"模块占比超限"？**
A：默认按综合卷的规则检查。单元卷加一句"这是单元卷"，它会切到单元卷模式，跳过这项检查。

**Q：教案里能不能不要"教学目标"那一堆？**
A：能。但建议留着——评课、检查、存档都要看这一栏。你要是不想写在正文，可以说"目标只写在文件属性里"。
