# 课件产线

课件和教案是两种东西。教案是给自己看的（怎么讲），课件是给学生看的（看什么）。

最常见的错误是把教案原样搬上屏幕——一页写满三百字，学生在下面抄板书，你在上面念 PPT。

**一页只说一件事。** 这是本产线唯一不能破的规矩。

## 一、先定三件事

| 项 | 说明 | 没给时默认 |
|---|---|---|
| 屏幕比例 | 16:9 / 4:3 | 16:9 |
| 使用场景 | 常态课 / 公开课 / 录课 | 常态课 |
| 学生手里有没有讲义 | 有讲义则页面可简；没有则关键步骤要留 | 有 |

**公开课与常态课的差别**：公开课要多两页（设计说明页、预设问答页），常态课不要——那些是给听课老师看的，不是给学生看的。

## 二、页面结构（8 段，按课时删减）

| # | 页面 | 内容要求 | 时长 |
|---|---|---|---|
| 1 | 封面 | 课题、年级、教材版本、授课人（占位） | 15″ |
| 2 | 学习目标 | 3 条，行为动词开头，学生能读懂 | 40″ |
| 3 | 情境导入 | 一个问题 + 一张图（占位），不写答案 | 4′ |
| 4 | 新知探究 | 拆成 2–4 页，每页一个问题 | 12′ |
| 5 | 例题精讲 | 一页题干，一页解答（分步出现） | 10′ |
| 6 | 变式训练 | 2–3 题，一页一题，留白给学生做 | 10′ |
| 7 | 课堂小结 | 一张结构图（不是文字列表） | 3′ |
| 8 | 分层作业 | 三档，一页放下 | 1′ |

> 一节课 45 分钟，控制在 **14–18 页**。超过 20 页，一定是在念 PPT。

## 三、每页必须写四样

不是"标题 + 要点"，是四样：

```
【第 7 页 · 新知探究】
页面内容：函数图像 + 一行问题（不写答案）
讲述词：看这条曲线，从左到右是升的。谁能说出"升"的数学说法？
停留：90 秒（等学生说，不说话）
板书同步：把学生的说法写在黑板左侧
```

**"停留"这一栏最重要。** 它逼你想清楚：这一页是"我讲"还是"他们想"。全是"我讲"的课件，等于没有课件。

## 四、公式与图形

- 公式：能写成纯文本的写纯文本（`f'(x)=3x²-6x`），必须用公式编辑器的标出来（`[公式] f'(x)=3x^2-6x`）。
- 图形：不生成图片，给**占位 + 数据 + 画法说明**。老师用几何画板或直接手画。
- 动画：不给动画文件，给文字建议。"此处用'擦除'方向从左到右，展示图像平移"。
- 表格：超过 5 行 4 列的表格，拆成两页。

## 五、版式规范

| 项 | 规格 |
|---|---|
| 标题字号 | ≥32pt |
| 正文字号 | ≥24pt（投影后排能看清的底线） |
| 单页文字 | ≤80 字（例题题干除外） |
| 配色 | 主色 1 种 + 强调色 1 种，不超过 3 色 |
| 背景 | 纯色或极浅纹理，不要渐变、不要装饰图 |
| 页脚 | 课题 + 页码，字号 14pt |

## 六、和教案怎么接

课件不是从零做，是从教案里抽：

```
教案的"问题链" → 课件的"新知探究"页（一个问题上页一页）
教案的"例题精讲" → 课件的"例题"页（题干一页，解答分步一页）
教案的"板书设计" → 课件的"小结"页（结构图同构）
```

**讲述词直接来自教案的"教师说什么"。** 不要另写一套，两套话会让老师上课时精神分裂。

## 七、交付

- 优先交付 `.pptx`（若环境支持）。
- 不支持时，交付**课件脚本 Word**（每页一张小卡，含上述四样字段），老师照着自己做，20 分钟能做完。
- 脚本里必须标"需要补充的素材"（实拍图、视频、教具），不要默认老师有。

## 边界

- 不杜撰教材原图。要引用教材图，标"引用：××版 P××，请核对"。
- 不做纯装饰性动画。每一处动画都要对应一个教学意图。
- 老师给了现成 PPT 要改——只改他指出的页，保留原模板。
