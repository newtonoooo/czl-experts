# 接单定档

一句"帮我备节课"里有五个变量，缺一个就会返工。这个 Skill 只干一件事：**在最少的提问次数里，把这五个变量固定下来。**

## 为什么不能边做边问

老师的时间是按"节课"算的。做了一半再问"你们班什么水平"，等于让他重说一遍。所以：**先定档，再动手；问不超过三个问题。**

## 工单卡

```
【工单】课题/考点：
【年级教材】高一 / 高二 / 高三 · 人教A版 / 人教B版 / 北师大版 / 苏教版 · 必修 / 选择性必修 · 章节
【用途】常态课 / 公开课 / 复习课 / 单元测 / 月考 / 作业 / 讲评 / 补差
【班级档位】基础班（均分 <90） / 中等班（90–115） / 提高班（>115）
【硬约束】课时长度 / 总分与题量 / 要不要 Word / 交付时间
```

## 只问这三个

按"改起来最贵"的顺序问，问到即停：

1. **给谁用**——年级 + 教材版本 + 章节。这一项错了，整篇作废。
2. **干什么用**——常态课和公开课是两种东西；单元测和月考也是两种东西。
3. **什么水平**——直接问均分，比问"基础好不好"准十倍。

课时长度、要不要 Word、交期，默认 45 分钟 / 要 / 尽快，不必问。

## 档位怎么用

档位不是标签，它直接改产出：

| 档位 | 例题起点 | 课堂节奏 | 作业配比（基础:提高:挑战） | 压轴题 |
|---|---|---|---|---|
| 基础班 | 教材例 1 原题 | 讲 20′ 练 20′ | 6 : 3 : 1（挑战为选做） | 不出，改"多拿 5 分题" |
| 中等班 | 教材例 2 变式 | 讲 15′ 练 25′ | 4 : 4 : 2 | 出，但拆成两问 |
| 提高班 | 直接上综合题 | 讲 10′ 练 30′ | 2 : 4 : 4 | 出，保留完整三问 |

## 路由判定

定完工单立刻判产线，判完只加载那一条，不要把五条全读一遍：

| 需求关键词 | 产线 |
|---|---|
| 备课、教案、教学设计、公开课、说课 | `lesson-forge` |
| 出卷、组卷、单元测、练习、题目、改编 | `paper-forge` |
| 批改、评语、错因、得分率、学情、讲评 | `paper-clinic` |
| 讲知识点、一题多解、变式、压轴题拆解 | `explain-lab` |
| 课件、PPT、大屏、导入动画 | `slide-deck` |
| 检查/审校已有材料 | `math-verify` + `bin/qa_gate.py` |

## 复合任务怎么排

老师一次给两件事时（"分析月考 + 备讲评课"），**串行不并行**：

```
P1 取证（算出得分率与失分点）
   ↓ 结论作为输入
P2 批改产线（定讲评顺序）
   ↓ 讲评课的主题由此确定
P2 教案产线（写讲评课教案）
```

前一段的结论必须是后一段的输入，否则就是两个独立任务，别硬串。

## 定完档要回一句

不要默默开工。用一行话把档位复述给老师，让他有机会当场改：

> 按"高二·人教A版·选择性必修二·5.3 导数与单调性 / 常态课 / 中等班 / 45 分钟"来做，先出教案，再出配套 Word。有出入你现在说。

## 边界

- 老师明确说"你别问了，直接做"——立刻按默认档做，首页列三条假设，不再追问。
- 老师给的信息自相矛盾（"高三复习课"却指定"必修一第一章"）——指出矛盾，让他二选一，别自己圆。
- 涉及具体班级学生姓名、身份证号等——不收、不存、不写进任何产出。
