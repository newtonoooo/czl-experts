# 教案产线

一份教案好不好，只用一个标准判：**换个老师拿着它进教室，能不能上下来。**

判断方法很土——把教案里所有"引导学生""激发兴趣""体会思想"划掉，看还剩多少字。剩下的才是教案。

## 开工前

先确认三件事（`intake-scope` 已定档的跳过）：课题与年级教材、课型、课时长度。
课型没说的话，默认**新授课**。

## 五种课型，五种写法

课型不同，结构就不同。用错模板是教案最常见的毛病——把复习课写成新授课，四十分钟讲不完。

| 课型 | 时间主轴 | 教案重点 | 常见错误 |
|---|---|---|---|
| 新授课 | 情境 5′ → 建构 15′ → 例题 12′ → 练习 10′ → 小结 3′ | 概念怎么长出来的 | 直接给定义，跳过建构 |
| 复习课 | 知识网 8′ → 典型题 20′ → 变式 12′ → 易错 5′ | 知识怎么串起来 | 变成重讲一遍新课 |
| 习题课 | 练 15′ → 讲 15′ → 再练 12′ → 归 3′ | 一类题的通用动作 | 一题一讲，不归纳 |
| 讲评课 | 数据 5′ → 错题 25′ → 变式 12′ → 订正 3′ | 讲哪几题、为什么讲这几题 | 从第 1 题讲到最后一题 |
| 章末课 | 结构 10′ → 综合 20′ → 检测 12′ → 布置 3′ | 全章的方法地图 | 罗列知识点，不给方法 |

每种课型的详细结构见 `references/lesson-architecture.md`。

## 三样必须有

### 一、时间预算表

每一段标分钟数，加起来必须等于课时长度。加起来超了，就删例题，不要压缩练习——练习是学生唯一在场的时间。

### 二、问题链

一节课 3–5 个问题，串成一条线，每个问题写三样：

```
问：……（停 X 秒）
预期：多数学生会说"……"
如果没人答：改成"……"（降一档的问法）
```

问题链的三个要求：

1. **上一个问题的答案，是下一个问题的起点。** 断了就是两个问题，不是一个链。
2. **至少有一个问题是"反例问"**——"如果 f(1)<f(2)，能不能说明它在 R 上递增？"，用来打掉想当然。
3. **不许问"是不是""对不对"。** 要问"为什么""凭什么""能不能举个反例"。

### 三、板书分区

不要写"板书设计：略"。画成三块，写清每块放什么、什么时候写：

```
┌──────────────┬──────────────┐
│ 左：知识主线  │ 右：例题演算  │
│ （随讲随写，  │ （例1 全程板书│
│  不擦）       │  例2 只写关键│
│              │  步）        │
├──────────────┴──────────────┤
│ 下：学生上台区 / 易错提醒条  │
└─────────────────────────────┘
```

## 三处卡点预案

写教案时就要预判：这节课学生最可能在哪三处卡住，卡住时你说什么。

| 卡点 | 学生表现 | 你的动作（写具体话术） |
|---|---|---|
| 概念抽象处 | 眼神空、翻书 | "先用一个具体的数试：取 x=2 和 x=3 代进去，看谁大" |
| 方法选择处 | 问"用哪个公式" | "先看已知给了边还是角，给了两边一角就余弦" |
| 步骤规范处 | 会做但被扣分 | "把'由题意得'改成'因为……所以……'，这一步值 2 分" |

## 分层作业

三档，各写清"给谁、几道、大约多久"：

- **基础**（全班必做）：教材课后对应题号 + 2 道改数字的同类题，10–15 分钟
- **提高**（中等以上）：2 道综合，15–20 分钟
- **挑战**（选做，不超过 5 人）：1 道开放题或压轴前两问，20 分钟，允许不做

作业量按档位调（见 `intake-scope` 的档位表）。**总时长不超过 40 分钟**是高中常态课的合理上限，超了要明说"这份作业偏多，可只做基础+提高"。

## 输出

正文按 `templates/lesson-plan.md` 的骨架写，不要自创章节顺序。
写完后用 `bin/qa_gate.py` 过一遍结构检查，再用 `bin/md_to_docx.py` 出 Word。

## 边界

- 教材页码、例题编号不能确定时不写具体页码，写"教材本节例 2 位置"，让老师对。
- 公开课额外要"设计说明"（为什么这么设计），常态课不要，写了是浪费。
- 老师给了现成教案要你改，只改他指出的部分，不重写——他已经上过一轮了。
