# 〔知识点〕讲解学案

**适用**：〔高二 · 选择性必修二 · 5.3〕　**配套课时**：〔1 课时〕　**前置知识**：〔函数单调性的定义〕

## 一、它解决什么问题

〔先给一个用旧工具算得出但算不快、或根本算不出的问题。〕

> 例：判断 f(x)=x³-3x 在 (1,+∞) 上的单调性。用定义要算 (x₁³-x₂³)-3(x₁-x₂) 的符号，式子长、容易错。有没有更快的办法？

## 二、定义怎么长出来的

| 步骤 | 内容 |
|---|---|
| 试一个数 | 〔取 x=2, x=3，算 f(2)=-2, f(3)=18，升了〕 |
| 再试一个 | 〔取 x=1.5，f(1.5)=-1.125，比 f(2) 大，说明不是一直升〕 |
| 发现规律 | 〔升降和 f'(x) 的符号对得上〕 |
| 提出猜想 | 〔f'(x)>0 则升，f'(x)<0 则降〕 |
| 验证 | 〔用定义证明这个猜想〕 |

## 三、定义与定理（逐字讲）

> 〔教材表述原文，标注版本页码，或写"教材本节定理"〕
> 设函数 y=f(x) 在某个区间内可导，如果 f'(x)>0，那么 f(x) 在这个区间内单调递增；如果 f'(x)<0，那么 f(x) 在这个区间内单调递减。

**逐字拆**：

| 词 | 作用 | 去掉会怎样 |
|---|---|---|
| "在某个区间内可导" | 保证导数存在 | 在 x=0 处不可导的函数不能用 |
| "某个区间" | 单调性是局部性质 | 说"f(x) 是增函数"没有意义，必须说"在……上" |
| "f'(x)>0" | 充分条件 | f'(x)≥0 且不恒为 0 也能推出递增，但反过来 f 递增不一定 f'>0（如 f(x)=x³ 在 x=0） |

## 四、例题（规范步骤，标每步为什么）

**例 1**：求 f(x)=x³-3x 的单调区间。

```
【解】
定义域：R ………………………………………………………… ① 先写定义域
f'(x) = 3x² - 3 = 3(x+1)(x-1) ……………………………… ② 求导并因式分解（便于判号）
令 f'(x) > 0，得 x < -1 或 x > 1 …………………………… ③ 解不等式
令 f'(x) < 0，得 -1 < x < 1 ………………………………… ④
所以 f(x) 在 (-∞,-1) 和 (1,+∞) 上单调递增，
在 (-1,1) 上单调递减 ………………………………………… ⑤ 结论写"和"，不写"∪"
```

**每步为什么**：① 单调区间必须在定义域内讨论；② 因式分解是为了后面判号不用再解二次；③④ 是同一件事的两面；⑤ 区间之间不能用并集符号——因为 f 在两个区间上分别增，不意味着在整个并集上增。

## 五、三个反例

| 反例 | 打掉什么想当然 | 正确认识 |
|---|---|---|
| f(x)=x³，f'(0)=0，但 f 在 R 上递增 | "f'>0 是必要条件" | f'>0 是充分不必要条件 |
| f(x)=1/x，在 (-∞,0) 和 (0,+∞) 上都递减，但在并集上不递减 | "两个区间都减，合起来也减" | 单调性不能跨区间合并 |
| f(x)=x+sinx，f'(x)=1+cosx≥0，f 递增 | "f'≥0 不能推出递增" | f'≥0 且零点不构成区间时，仍递增 |

## 八、易错警示

```
【错法】把单调递增区间写成 (-∞,-1)∪(1,+∞)
【为什么会这么错】图像看起来"两边都在升"，直觉上是一个整体
【反例】取 x₁=-2, x₂=2，f(-2)=-2 < f(2)=2，看起来升；但取 x₁=-0.5, x₂=0.5，
        f(-0.5)=1.375 > f(0.5)=-1.375，降了——所以并集上不单调
【正确动作】区间之间写"和"或逗号
```
