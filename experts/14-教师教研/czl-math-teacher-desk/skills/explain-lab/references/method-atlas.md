# 首步动作地图：六大模块

学生卡住时，缺的往往不是"知识"，是"看到这个条件，第一步做什么"。

本表只记**第一步动作**。第一步对了，后面是熟练度问题；第一步错了，后面全是白算。

## 一、函数与导数

| 题面特征 | 首步动作 | 常见弯路 |
|---|---|---|
| 求单调区间 | 先写定义域，再求 f'(x)，解不等式 | 忘了定义域，直接解 f'>0 |
| 求极值 | 求 f'(x)=0 的根，列表判变号 | 只令 f'=0 就说是极值点 |
| 含参讨论单调性 | 先找 f'(x)=0 的根，按根是否存在/是否在区间内分类 | 一上来就 a>0 / a<0 分，漏掉 a=0 |
| 恒成立求参数 | 分离参数（能分离时）或构造 g(x) 求最值 | 直接讨论，越讨越乱 |
| 证明不等式 | 作差构造 g(x)=f(x)-h(x)，证 g 最小值 ≥0 | 两边同时求导，越证越繁 |
| 零点个数 | 单调性 + 端点值符号 + 图像趋势 | 只算判别式（那只适用于二次） |
| 切线问题 | 设切点 (x₀, f(x₀))，用 f'(x₀) 写方程 | 把点当切点，直接代 f'(a) |

## 二、三角函数与解三角形

| 题面特征 | 首步动作 | 常见弯路 |
|---|---|---|
| 求值域/最值 | 化一角一函数（辅助角公式），再定范围 | 直接求导（能做但慢） |
| 图像平移 | 先把 x 的系数提出来，看整体相位 | 先平移后伸缩搞反 |
| 给边角关系求角 | 判断用正弦还是余弦：有平方用余弦，成比例用正弦 | 一律用正弦，出多解 |
| 判断三角形形状 | 边化角或角化边，统一成一边 | 边角混用，越化越乱 |
| 面积问题 | S = ½ab·sinC，配合余弦定理求第三边 | 忘乘 ½ |
| 多解判断 | 已知两边及一边对角，先算另一角的正弦，再看大边对大角 | 直接取锐角，漏钝角解 |

## 三、数列

| 题面特征 | 首步动作 | 常见弯路 |
|---|---|---|
| 由 Sₙ 求 aₙ | 分 n=1 与 n≥2 两段写 | 直接用 aₙ=Sₙ-Sₙ₋₁，漏 n=1 |
| 判断等差/等比 | 算 aₙ₊₁-aₙ 或 aₙ₊₁/aₙ，看是否为常数 | 只算前两项就下结论 |
| 递推构造 | 凑成 aₙ₊₁+c = k(aₙ+c) 的形式 | 硬猜通项 |
| 求和（等差×等比） | 错位相减，末项单独核对 | 末项符号错 |
| 求和（分式） | 裂项，先看分母差几 | 裂完不验第一项 |
| 求通项（含 Sₙ 混合式） | 消 Sₙ 或消 aₙ，二选一化成一类 | 两式相减后不做整理 |

## 四、立体几何

| 题面特征 | 首步动作 | 常见弯路 |
|---|---|---|
| 证明线面平行 | 在面内找一条平行线（中位线/平行四边形） | 直接建系（能证但要写一堆） |
| 证明线面垂直 | 找面内两条相交直线 | 只找一条 |
| 求二面角 | 建系，求两法向量，再判锐钝 | 法向量取反得负值直接交 |
| 求线面角 | 法向量与方向向量夹角，取正弦 | 当成二面角取余弦 |
| 求点到面距离 | 投影法或等体积法 | 建系后算错 |
| 存在性问题 | 设参数点坐标，代入条件解参数 | 只说"存在"，不给构造 |

**建系三步**：选原点（找三条两两垂直的线）→ 写六点坐标 → 验算（任取一条已知长度，用坐标算一遍对不对）。

## 五、解析几何

| 题面特征 | 首步动作 | 常见弯路 |
|---|---|---|
| 求轨迹/方程 | 设点 (x,y)，把条件翻译成等式，化简 | 先猜形状再凑 |
| 弦长问题 | 设直线（先判斜率是否存在），联立，韦达定理 | 忘讨论斜率不存在 |
| 中点弦 | 点差法，一步出斜率 | 硬联立（能做但慢且易错） |
| 定值/定点 | 设参数，算出目标式，看参数是否消掉 | 取两个特殊位置就下结论 |
| 最值问题 | 把目标化成单变量函数（用韦达消元） | 硬算距离公式 |
| 离心率范围 | 从条件列 a、b、c 的不等式 | 只列等式 |

**"斜率是否存在"这一句，每次设直线都要写。** 这是解析几何最稳定的送分点，也是最稳定的扣分点。

## 六、概率与统计

| 题面特征 | 首步动作 | 常见弯路 |
|---|---|---|
| 独立性检验 | 写零假设 → 算 χ² → 查表比较 → 下结论（四步不能少） | 直接说"有关" |
| 分布列 | 先列所有取值，再逐项算概率，最后验和=1 | 漏取值 |
| 条件概率 | 先写 P(B|A) 的定义式，再代 | 与 P(AB) 混 |
| 期望方差 | 先算分布列，再套公式 | 跳过分布列直接算 |
| 回归方程 | 先算 x̄、ȳ，再用公式求 b̂ | 公式记错（分子是 Σ(x-x̄)(y-ȳ)） |
| 古典概型 | 先定样本空间是否等可能 | 把不等可能当等可能 |

## 七、跨模块通用：三个"先写"

不管哪一模块，动笔前先写这三样，能省一半错：

1. **先写定义域/范围**（函数、三角、解析几何）
2. **先写"当……时"的讨论前提**（含参、分段、绝对值）
3. **先写"设"是什么**（设点、设线、设参数，写清范围）

## 八、怎么用这张表讲课

不要一次给全表。用法是**倒着用**：

```
学生做错一道题 → 问他"你第一步想做什么" → 对到表里 → 
告诉他这一格的动作 → 给两道同格题 → 只练这一个动作
```

一节课只练一格。练完这一格，他这一类题的首步就固定了。
