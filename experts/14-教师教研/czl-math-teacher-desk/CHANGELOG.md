# 更新日志

格式参照 Keep a Changelog，版本号遵循语义化版本。

## [1.0.0] - 2026-11-01

首个公开版本。产品代号「陈砚耕」，定位为**高中数学老师的教研工作台**（教师侧），
与同品牌的「卓识教育-高中数学学习辅导专家」（学生/家庭侧）为不同产品，功能不重叠。

### 新增

- **六段流水线**：接单定档 → 取证 → 制造 → 数学校验 → 出 Word → 归档。
  P0 与 P3 不可跳过；跨产线任务按"前段结论作为后段输入"串行编排。
- **7 个 Skill**：
  - `intake-scope` 接单定档（工单卡、档位表、只问三个问题、路由判定）
  - `lesson-forge` 教案产线（五种课型结构、问题链、板书分区、卡点话术）
  - `paper-forge` 命题产线（先摊表后写题、干扰项工程、步骤分细则）
  - `paper-clinic` 批改与学情（五类错因码、可挽回分×可教性的讲评排序）
  - `explain-lab` 讲解产线（五段式学案、首步动作地图、压轴三档打法）
  - `slide-deck` 课件产线（逐页四要素：内容/讲述词/停留/板书同步）
  - `math-verify` 数学校验（回代、边界、范围、方法互证、题号对齐五关）
- **6 个零依赖工具**（纯 Python 标准库）：
  - `score_report.py` 分题得分表 → 学情报告
  - `blueprint.py` 双向细目表生成与体检
  - `qa_gate.py` 交付前结构质检
  - `md_to_docx.py` Markdown → 可打印 Word（A4、中文排版、页脚页码）
  - `check_package.py` 专家包自检（含头像回落排查）
  - `self_test.py` 用已知答案样本自测全部脚本
- **4 份学科材料**：知识模块图谱、新高考卷结构与难度控制、28 条高频易错点库、公式定理速查。
- **原创头像**：512×512 PNG，174.9 KB，AI 生成后裁切去水印并量化压缩。
- **文档**：产品规格说明、工作流规格、使用说明、平台展示文案、开发记录、文件清单、
  功能测试报告、商业发布风险清单、头像显示成文字排查报告、教材资料获取指引。

### 设计决定

- `categoryId` 取 `15-Education`，与同品牌教育系列保持一致；本地
  `validate_expert.py` 的分类表仅收录 12 类，会判该项为错误，属工具版本滞后，
  已在 `docs/功能测试报告.md` 中如实记录。
- 不声明 `knowledge` 字段（非公开规范字段），学科材料由 Agent 按需 `Read`，
  避免启动时全量注入导致上下文膨胀。
- 头像体积控制在 200KB 以内（规范上限 500KB，运行时上限 5MB），
  为开放平台上传链路留余量。

### 未包含（有意为之）

- 教材原文、教辅原题、真题扫描件：涉及第三方版权，不纳入商业包。
- 学生姓名等个人信息：全部流程按学号处理，不收集、不存储。

### 已知限制

- 数学正确性依赖模型推理 + 五道校验流程，仍有出错可能，正式印发前须教师复核。
- 课件交付为逐页脚本，PPT 文件需在本机由 WorkBuddy 的 PPT 能力另行生成。
- `md_to_docx.py` 支持 Markdown 子集，复杂公式渲染为文本形式，不生成公式对象。
