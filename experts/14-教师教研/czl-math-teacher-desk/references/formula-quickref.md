# 公式定理速查

> 数学事实本身不受版权保护，本表为产品作者独立整理，供快速核对与生成讲解材料时引用。
> **使用时必须逐条核对**：符号、条件、适用范围，错一个符号整题作废。

## 一、代数与函数

| 名称 | 公式 | 条件/易漏 |
|---|---|---|
| 指数运算 | aᵐ·aⁿ=aᵐ⁺ⁿ，(aᵐ)ⁿ=aᵐⁿ，(ab)ⁿ=aⁿbⁿ | a>0 |
| 对数运算 | logₐ(MN)=logₐM+logₐN，logₐ(M/N)=logₐM−logₐN，logₐMⁿ=n·logₐM | M,N>0，a>0 且 a≠1 |
| 换底 | logₐb = ln b / ln a | a,b>0，a≠1 |
| 对数恒等 | a^(logₐN)=N | — |
| 二次求根 | x = [−b ± √(b²−4ac)] / (2a) | Δ=b²−4ac≥0 |
| 韦达定理 | x₁+x₂=−b/a，x₁x₂=c/a | a≠0，Δ≥0 |
| 基本不等式 | a+b ≥ 2√(ab) | a,b>0；取等 a=b |
| 均值不等式链 | 2/(1/a+1/b) ≤ √(ab) ≤ (a+b)/2 ≤ √((a²+b²)/2) | a,b>0 |

## 二、三角函数

| 名称 | 公式 |
|---|---|
| 平方关系 | sin²x+cos²x=1，1+tan²x=sec²x（不必记 sec） |
| 和角 | sin(A±B)=sinAcosB±cosAsinB |
| 和角 | cos(A±B)=cosAcosB∓sinAsinB |
| 和角 | tan(A±B)=(tanA±tanB)/(1∓tanAtanB) |
| 二倍角 | sin2A=2sinAcosA |
| 二倍角 | cos2A=cos²A−sin²A=2cos²A−1=1−2sin²A |
| 降幂 | sin²A=(1−cos2A)/2，cos²A=(1+cos2A)/2 |
| 辅助角 | a·sinx+b·cosx = √(a²+b²)·sin(x+φ)，tanφ=b/a |
| 正弦定理 | a/sinA = b/sinB = c/sinC = 2R |
| 余弦定理 | a² = b²+c²−2bc·cosA；cosA = (b²+c²−a²)/(2bc) |
| 面积 | S = ½ab·sinC = abc/(4R) = r·s（s 为半周长） |

**最易错**：辅助角的 φ 由 (a,b) 所在象限决定，不是 arctan(b/a) 直接取。

## 三、平面向量

| 名称 | 公式 |
|---|---|
| 数量积（定义） | a·b = \|a\|\|b\|cosθ |
| 数量积（坐标） | a·b = x₁x₂+y₁y₂ |
| 模 | \|a\| = √(x²+y²) |
| 夹角 | cosθ = (x₁x₂+y₁y₂)/(\|a\|\|b\|) |
| 共线 | x₁y₂−x₂y₁=0 |
| 垂直 | x₁x₂+y₁y₂=0 |
| 投影 | a 在 b 上的投影 = (a·b)/\|b\| |

**最易错**：夹角为钝角的条件是 a·b<0 **且** 两向量不共线（反向）；只写 a·b<0 会漏掉反向。

## 四、数列

| 名称 | 公式 | 条件 |
|---|---|---|
| 等差通项 | aₙ = a₁+(n−1)d | — |
| 等差求和 | Sₙ = n(a₁+aₙ)/2 = na₁+n(n−1)d/2 | — |
| 等比通项 | aₙ = a₁·q^(n−1) | q≠0 |
| 等比求和 | Sₙ = a₁(1−qⁿ)/(1−q) | q≠1；q=1 时 Sₙ=na₁ |
| 由 Sₙ 求 aₙ | aₙ = S₁ (n=1)；aₙ = Sₙ−Sₙ₋₁ (n≥2) | **分段必写** |
| 裂项 | 1/[n(n+k)] = (1/k)(1/n − 1/(n+k)) | k≠0 |

## 五、导数

| 函数 | 导数 |
|---|---|
| xⁿ | n·x^(n−1) |
| eˣ | eˣ |
| aˣ | aˣ·ln a |
| ln x | 1/x |
| logₐx | 1/(x·ln a) |
| sin x | cos x |
| cos x | −sin x |
| tan x | 1/cos²x |

| 法则 | 公式 |
|---|---|
| 和差 | (u±v)' = u'±v' |
| 积 | (uv)' = u'v+uv' |
| 商 | (u/v)' = (u'v−uv')/v² |
| 复合 | [f(g(x))]' = f'(g(x))·g'(x) |

| 应用 | 结论 |
|---|---|
| 单调递增 | f'(x)>0（充分）；f'(x)≥0 且零点不构成区间也递增 |
| 极值 | f'(x₀)=0 且 f' 在 x₀ 两侧变号 |
| 切线 | y − f(x₀) = f'(x₀)(x−x₀) |
| 凹凸（选） | f''>0 凹（下凸），f''<0 凸 |

## 六、解析几何

| 曲线 | 标准方程 | 关系 | 离心率 |
|---|---|---|---|
| 椭圆（焦点 x 轴） | x²/a²+y²/b²=1 (a>b>0) | c²=a²−b² | e=c/a∈(0,1) |
| 双曲线（焦点 x 轴） | x²/a²−y²/b²=1 | c²=a²+b² | e=c/a>1 |
| 抛物线 | y²=2px (p>0) | 焦点 (p/2,0)，准线 x=−p/2 | e=1 |

| 常用结论 | 内容 |
|---|---|
| 椭圆焦半径 | \|PF₁\|=a+ex₀，\|PF₂\|=a−ex₀ |
| 抛物线焦半径 | \|PF\| = x₀ + p/2 |
| 弦长（斜率 k） | \|AB\| = √(1+k²)·\|x₁−x₂\| = √(1+k²)·√Δ/\|a\| |
| 椭圆中点弦斜率 | 中点 (x₀,y₀)，k = −b²x₀/(a²y₀) |
| 双曲线中点弦斜率 | k = b²x₀/(a²y₀) |
| 双曲线渐近线 | y = ±(b/a)x |
| 点到直线距离 | d = \|Ax₀+By₀+C\|/√(A²+B²) |
| 圆 | (x−a)²+(y−b)²=r²；一般式 x²+y²+Dx+Ey+F=0，r=½√(D²+E²−4F) |

**最易错**：椭圆与双曲线的 a、b、c 关系相反，焦点在 y 轴时标准方程与渐近线都要换。

## 八、计数与概率统计

| 名称 | 公式 |
|---|---|
| 排列 | A(n,m) = n!/(n−m)! |
| 组合 | C(n,m) = n!/[m!(n−m)!] |
| 组合性质 | C(n,m)=C(n,n−m)，C(n,m)+C(n,m−1)=C(n+1,m) |
| 二项式通项 | T_{r+1} = C(n,r)·a^(n−r)·b^r |
| 条件概率 | P(B\|A) = P(AB)/P(A)，P(A)>0 |
| 全概率 | P(B) = ΣP(Aᵢ)P(B\|Aᵢ) |
| 期望 | E(X) = Σxᵢpᵢ |
| 方差 | D(X) = Σ(xᵢ−E(X))²pᵢ = E(X²)−[E(X)]² |
| 二项分布 | X~B(n,p)：E=np，D=np(1−p) |
| 超几何分布 | E(X) = nM/N |
| 线性变换 | E(aX+b)=aE(X)+b，D(aX+b)=a²D(X) |
| 回归 | b̂ = Σ(xᵢ−x̄)(yᵢ−ȳ)/Σ(xᵢ−x̄)²，â = ȳ − b̂x̄ |
| 独立性检验 | χ² = n(ad−bc)²/[(a+b)(c+d)(a+c)(b+d)] |

**最易错**：χ² 公式分子是 (ad−bc)² 再乘 n；分母是四个边缘和的乘积。写错分母是最高频错误。

## 十、核对纪律

公式表最大的风险是**记错一个条件**，比记不住更危险。用之前做三件事：

1. 看条件栏（a>0？a≠1？q≠1？Δ≥0？）
2. 用一组具体数代进去验一次
3. 量纲/量级检查（面积 vs 长度、概率是否 ≤1）
