# 卓识教育-高中数学老师助手（陈砚耕）

给高中数学老师用的**教研工作台**。它不做"教学设计示范"，它做明天上午能照着上的稿子。

一条流水线跑到底：**接单定档 → 取证 → 制造 → 数学校验 → 出 Word → 归档**。
其中"数学校验"是硬关卡：交付前每道题的答案都要过回代、边界、范围、方法互证、题号对齐五道检查，
不过关就不交付——宁可交一份标着"第 18 题没验通"的稿子，也不交一份全绿但错一题的稿子。

## 类型

Agent 型（单个 AI 专家），含 7 个可独立调用的 Skill 与 6 个零依赖命令行工具。

## 能做什么

| 老师想做的事 | 得到什么 |
|---|---|
| 备一节课 | 45 分钟时间预算表、问题链与预期回答、板书分区、三处卡点话术、分层作业 |
| 出一套卷 | 先给双向细目表（可脚本体检），确认后逐题写，附答案页与步骤分细则 |
| 批一个班 | 按评分细则分步批注、五类错因码、两句评语、下一步只改一件事 |
| 算这次考得怎么样 | 用脚本算均分/中位数/标准差/得分率，按"可挽回分×可教性"排讲评顺序 |
| 讲透一个知识点 | 五段式学案：困境→定义怎么长出来的→例题→三个反例→变式 |
| 拆一道压轴题 | 得分点地图 + 三档打法（保底/争取/放弃），目标 10–12 分 |
| 做课件 | 逐页脚本：页面内容、讲述词、停留秒数、板书同步点 |
| 查我这份卷子有没有问题 | 按严重度排序的问题清单（致命/严重/一般/建议） |

## 自带的六个工具（零依赖，纯标准库）

```bash
python bin/score_report.py 成绩.csv --full-marks 5,5,5,5,5,5,5,5,6,6,6,5,5,5,13,15,15,17,17
python bin/blueprint.py --init 细目表.csv && python bin/blueprint.py 细目表.csv
python bin/qa_gate.py 教案.md --kind lesson --minutes 45
python bin/md_to_docx.py 教案.md -o 教案.docx --footer "函数的单调性 · 高二 · 人教A版"
python bin/check_package.py .
python bin/self_test.py
```

- `score_report.py`：分题得分表 → 学情报告（均分、分数段、各题得分率、讲评优先级）
- `blueprint.py`：双向细目表生成与体检（总分、题量、结构、模块占比、难度系数）
- `qa_gate.py`：交付前结构质检（占位符、题号答案对齐、时间预算、空话套话）
- `md_to_docx.py`：Markdown → 可打印 Word（A4、宋体小四、页脚页码）
- `check_package.py`：专家包自检（含头像为什么变成文字的逐条排查）
- `self_test.py`：全脚本自测（用已知答案的样本比对，不是"跑通就算过"）

全部只用 Python 标准库，老师电脑上只要有 Python 3.8+ 就能跑。

## 内置学科材料

| 文件 | 内容 |
|---|---|
| `references/knowledge-map.md` | 必修+选择性必修模块图谱、课时建议、前后置依赖、课时不够时的取舍 |
| `references/exam-structure.md` | 新高考 8+3+3+5 结构、模块配比、难度控制、命题趋势、组卷检查清单 |
| `references/pitfall-library.md` | 28 条高频易错点，每条"错法→为什么会错→反例→正确动作" |
| `references/formula-quickref.md` | 公式定理速查（含条件与最易错处） |

这些材料为作者独立整理，不含教材原文扫描件。教材电子版的合法获取方式见 `docs/教材资料获取指引.md`。

## 使用示例

- 把《函数的单调性》备成一节 45 分钟的课，教案要能照着上，附板书设计和分层作业
- 按新高考 8+3+3+5 结构出一套「导数及其应用」单元卷，先给双向细目表
- 这是我们班这次月考的分题得分表，算出各题得分率、排出失分点，给两节课的讲评顺序
- 这道压轴题帮我拆成能拿分的阶梯，标清每步值几分
- 根据人教A版必修一《函数的概念》做一份课件，要逐页讲述词

