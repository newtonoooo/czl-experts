## 三、详细介绍（详情页）

**它解决什么问题**

备课两小时、命题靠感觉、批改口径不一、考完只知道平均分、讲评课按卷面顺序讲完下次照错——这些事占掉一线物理教师最多的下班时间。

**它怎么干**

按教学的真实顺序走一条闭环：定标 → 设计 → 命题 → 诊断 → 复盘。

- **备课**：先给一页定标单（四条素养目标，每条挂一句课上能问出口的检测话术），确认后给教案、学案、分层作业、板书三栏。
- **命题**：先出双向细目表，自动校验总分、加权难度、题型配比和预估用时；确认后再逐题命制，交付细目表、试卷、答案、评分细则四件套。
- **批改**：按"模型分—过程分—结果分"三步赋分，错因打到码（E01–E20），错误不连坐。
- **分析**：给一张成绩表，算出三率一分、逐题难度 P、区分度 D、分数段分布，按"人数 × 可迁移性"排出讲评优先级。
- **讲评**：一节课只打一到两个模型，按"数据 3′ → 错因回放 8′ → 重做 15′ → 变式 15′ → 检测 4′"排，配变式题与跟踪表。

**它的底线**

公式必带适用条件；答案必须能逐步复算；真题标年份卷别；教材原文不整段照抄；学生数据只要学号不要姓名。

**拿到的文件**

教案、学案、试卷、评分细则、学情报告、讲评设计都同时给 Markdown（可改）和 A4 打印版 docx（可印）。打印版边距 18mm、表格与题目不跨页、页眉有课题与版本、页脚有页码。

- 第一次用，直接给一个课题或一张成绩表，不用先介绍背景。

- 打印版在 Word 2016+ / WPS 中打开即可直接印。
- 重难点取舍、学情判断、课时安排以你自己为准，它给的是可改的初稿。
