# 使用说明

适用对象：高中物理教师、备课组长、教研员。
安装后无需任何配置，打开对话即可用；脚本零依赖，不需要装 Python 第三方库。

---

## 一、安装

**方式 A：专家中心导入（推荐）**

1. 打开 WorkBuddy → 左侧「专家」→ 右上角「导入专家」；
2. 选择 `czl-physics-teacher-desk.zip`；
3. 导入后在「我的专家」里出现「严知远 · 卓识教育-高中物理老师助手」；
4. 点开即可对话。

**方式 B：手动放入目录（开发/调试用）**

把整个 `czl-physics-teacher-desk/` 目录放到：

```
<WorkBuddy 配置目录>/plugins/marketplaces/my-experts/plugins/
```

重启后在专家中心可见。

> 目录结构不能改：`plugin.json` 必须在 `.codebuddy-plugin/` 下，`agents/`、`avatars/`、`skills/` 与它同级。

---

## 二、三个最常用的用法

### 1. 备课

你可以直接说：

> 帮我备一节《牛顿第二定律》新授课，人教 2019 版，2 课时，班里中等偏下。

它会先给**定标单**（目标、重难点、起点假设、课时切分），确认后给教案、学案、分层作业、板书结构，并导出一份 A4 打印版。

### 2. 命题

> 出一份力学单元卷：必修一第三章，100 分，75 分钟，难度 0.68，选择 8 道、实验 2 道、计算 3 道。

它先给**双向细目表**并自动校验总分/难度/配比/用时；你确认后逐题命制，最后给四件套：细目表、试卷、答案、评分细则。

### 3. 考完分析与讲评

> 这是月考成绩表，帮我算难度区分度，找共性错因，再排一节 45 分钟讲评课。

把 CSV（第一列学号，后面每列一题得分）发给它，它会跑统计、给错因排序和分层名单，再出讲评课设计。

## 三、脚本怎么用（可选）

脚本在 `skills/czl-physics-desk/scripts/`。会命令行就用，不会就让它代跑——你只需要说"帮我算一下"，它会调用。

```bash
# 生成细目表模板，填好后校验
python blueprint.py --template 细目表.csv
python blueprint.py --in 细目表.csv --out 细目表.md --total 100 --difficulty 0.65 --minutes 75

# 评分细则
python rubric_builder.py --template 步骤.csv
python rubric_builder.py --in 步骤.csv --out 评分细则.md --total 12

# 成绩分析
python item_analysis.py --scores 成绩.csv --full-marks "4,4,4,6,8,12,14" --class 高二3班 --out 学情.md

# 公式复核
python physics_calc.py --list
python physics_calc.py --formula kinematics.v --args v0=0,a=2,t=3

# Markdown 转 A4 打印版
python docx_lite.py --in 教案.md --out 教案.docx --title "牛顿第二定律" --meta "高二·人教2019"

# 自检（换电脑后先跑这个）
python self_test.py
```

**成绩表格式**（CSV，UTF-8）：

```csv
学号,Q1,Q2,Q3,Q4,Q5,Q6
01,4,4,6,5,9,10
02,4,2,6,8,7,6
```

第一列是学号，其余每列一题得分；也可以有"总分"列，有则优先用它。

## 四、输出与命名

- 默认输出到当前工作目录的 `输出/`；你也可以指定目录。
- 文件命名：`{日期}-{班级/范围}-{类型}-{课题}`，例 `20261101-高二3班-教案-牛顿第二定律.docx`。
- 文档类成品同时给 Markdown（可改）和 docx（可印）。

## 五、常见问题

### 1. 导入后专家图标显示成文字（首字）

图标是"头像文件没被读到"时的兜底显示（渐变底 + 名字首字）。平台读取头像的规则是：`plugin.json` 的 `avatar` 必须是**包内相对路径**，文件真实存在，且 ≤ 5 MB。常见原因按概率排：

| 原因 | 检查方法 | 处理 |
|---|---|---|
| zip 里没有 `avatars/` 目录 | 解压看目录 | 重新打包含头像的完整包 |
| `avatar` 写成了绝对路径或 `../` | 打开 plugin.json 看 | 改为 `avatars/expert.png` |
| 头像超过 5 MB | 看文件大小 | 压到 512×512、≤500 KB |
| 导入时先注册后放图 | 换头像后没重启 | 重启 WorkBuddy，重新选择该专家 |
| 项目协作场景的专家选择器只认 http/data 图 | 只在协作项目里出现 | 属平台侧限制，不影响专家中心与本对话 |

本包已按最严格口径处理：`avatars/expert.png`，512×512 PNG，约 240 KB，路径相对且大小写一致。

### 2. 脚本报"找不到文件"

Windows 下路径含中文或空格时用引号包起来：

```bash
python blueprint.py --in "E:/课件/高二 3 班/细目表.csv" --out "细目表.md"
```

### 3. 导出的 docx 打开是乱码

用 Word 2016 及以上或 WPS 打开；本包生成的 docx 为标准 OOXML，不含宏。

### 4. 成绩表列名不统一

脚本只认第一列为学号，其余列按题号处理；列名叫 Q1、第1题、1 都可以。

## 六、边界

- 只做高中物理（含选择性必修），不做大学物理与竞赛超纲题；
- 不代写学生作业、不押题；
- 不打包教材、教辅、真题原卷，需要原文请用正版渠道；
- 重难点取舍、学情判断、课时安排以你为准，它给的是可改的初稿。
