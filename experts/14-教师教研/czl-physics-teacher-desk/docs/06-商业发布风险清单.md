## 二、逐项说明

### R1 品牌使用权（中）

产品职称含"卓识教育"。这是用户指定的品牌前缀，但本次开发**未获得商标注册信息**。
若"卓识教育"为他人注册商标且用于同类服务，公开上架可能构成侵权或被平台下架。

处置：
1. 确认商标注册状态（国家知识产权局商标查询）；
2. 若无注册，评估是否作为未注册商标使用（同类服务仍有混淆风险）；
3. **替代方案**：改为不含品牌的名称，例如「物理教研台-高中物理老师助手」，包名不变。

### R2 同质化（中）

同一开发者名下已有学生端物理专家（面向家长与学生的"学习辅导"）。两者受众、产出、语气完全不同，
但平台审核或用户可能视为重复上架。

处置：上架文案第一句就写"教师侧"，推荐问法全部用教师语汇（课时、细目表、得分率），不使用"孩子""陪练"等词。

### R3 AI 生成头像（低）

头像由文生图模型生成，提示词自拟，未使用任何真人照片，也不指向特定真实人物。
风险点：极小概率与某真人相似；部分平台要求标注 AI 生成内容。

处置：保留生成原图与提示词（在包外 `build-assets/`）；如平台要求，勾选"AI 生成"标识。
**替代方案**：改用纯几何标识（如"力矢量 + 粉笔线"的抽象图形），完全规避肖像问题。

### R4 内容版权（低）

- 物理定律、公式、常数：公有领域，不受版权保护。
- 教材模块划分、四版对照：事实性信息，非表达性内容。
- 课标要求：转述，未整段引用。
- 错因码、评分规则、模板、脚本：本次原创。

处置：无需处理。后续若引入教材例题、真题原卷、教辅题目，须重新评估并标注来源。

### R5 第三方组件（无）

六个脚本仅使用 `argparse / csv / json / math / os / re / statistics / subprocess / sys / tempfile / zipfile / datetime / xml.sax.saxutils`，均为 Python 标准库，随 Python 解释器分发，不随本包分发。
包内无字体文件、无图片素材（头像为自有生成）、无开源库副本。

### R6 分类 ID（中）

平台市场内已有 11 个专家使用 `15-Education`（含官方上架的学科教师类），说明平台侧支持该分类；
但 `expert-manager` 内置校验脚本的白名单只列到 `12-IndustryConsultant`，会报 `invalid categoryId`。

本次处理：不改官方文件，另写 `build-tools/validate_package.py`，在内存中把 `15-Education` 加入白名单后调用官方校验，其余检查不变。此事已在测试报告与开发记录中写明。

处置：
1. 首选保留 `15-Education`（分类正确，用户能在"教育"下找到）；
2. 若平台审核因该字段拒绝，改 `09-OperationsHR`（会落在"运营人力"分类，展示位置不理想）；
3. 也可向平台反馈校验脚本白名单过期。

### R7 平台规则（中，未核实）

未取得平台的《专家上架协议》《原创性要求》《分成规则》原文，因此以下三点**无法确认**：
1. 是否要求提交原创声明或开发记录（本包已备 `docs/04`）；
2. 是否对"同类专家重复上架"有限制；
3. 分成比例与结算条件。

处置：提交前在开发者后台阅读协议原文；如需原创声明，直接引用 `docs/04-文件清单与开发记录.md` 的来源声明一节。

### R8 真题与教材（低）

包内没有任何真题原卷、教材正文、教辅题目。文档中提到的真题引用规则（标年份卷别、改动标"改编"）是**使用规范**，不是内容。

### R9 数据合规（中）

产品会接触成绩数据。已做的约束：只要学号；不索取姓名、身份证、家长电话；分析结果不写入公开目录。
残余风险：教师可能直接上传含姓名的表格。

处置：`使用说明` 已提示按学号处理；建议在首次分析时主动提醒一句"姓名列可以删掉，不影响统计"。

### R10 名称撞名（低）

已扫描本机全部市场的 `profession` 与 `displayName`，无同名。
"老师助手"是通用词，公开市场可能出现同名专家；如需独占，可加品牌前缀（与 R1 联动）。

## 三、明确未打包的组件及原因

| 组件 | 为什么没打包 | 替代方案 |
|---|---|---|
| 各版教材 PDF / 电子教材 | 版权所有，禁止再分发 | 文档给"内容块对照 + 页码指引"，教师用正版教材 |
| 教材插图、例题原图 | 同上 | 自绘示意图；引用标"改编" |
| 高考真题原卷 | 命题机构权利，整卷复制风险高 | 需要时引用单题并标年份卷别 |
| 教辅、模拟卷、机构讲义 | 权利不明 | 不用；需要时由教师自备 |
| 国家中小学智慧教育平台资源 | 仅限教学使用，不得商用 | 只做指路，不下载打包 |
| 带水印的 AI 生成原图 | 含水印，不适合商业分发 | 已移出包外，仅保留处理后的 512×512 头像 |

## 四、发布前必须由用户确认的 6 件事

1. **"卓识教育"是否可用**（R1）——决定是否改名；
2. **分类 ID 用 15 还是 09**（R6）——决定卡片落在哪个分类；
3. **定价与授权方式**（个人买断 / 机构采购 / 订阅）——影响 LICENSE 与文案；
4. **是否上架公开市场**——若仅内部使用，R1、R7 风险可暂缓；
5. **是否要英文版**——当前 en 字段为直译，未做本地化审校；
6. **是否补充其他教材版本的具体章节号**——需要用户提供手中教材目录。

## 五、结论

- 可发布的部分：专家包本体、脚本、模板、文档、头像、发布 zip。
- 需先决策的部分：R1 品牌、R6 分类。
- 不建议在未确认 R1 前做付费推广。
