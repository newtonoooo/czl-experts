# 卓识教育-高中物理老师助手（czl-physics-teacher-desk）

面向高中物理教师的**教师侧**全流程助手。不是给学生讲题的，是给老师出活的。

按"定标 → 设计 → 命题 → 诊断 → 复盘"一条闭环接活，产出教案、学案、双向细目表、试卷、评分细则、学情报告、讲评课设计，并同步给 A4 打印版 .docx。

## 一、能做什么

| 你说 | 它给 |

| 备一节《牛顿第二定律》，2 课时 | 定标单 + 教案 + 学案 + 分层作业 + 板书三栏 + 打印版 |

## 三、快速开始

1. 专家中心 → 导入专家 → 选 `dist/czl-physics-teacher-desk.zip`；
2. 直接说："帮我备一节《牛顿第二定律》新授课，人教 2019 版，2 课时"；
3. 想要打印版就说"出打印版"，或让它跑 `docx_lite.py`。

脚本为零依赖（只用 Python 标准库），在无网环境也能跑。自检：

```bash
cd skills/czl-physics-desk/scripts
python self_test.py
```

## 四、设计取向

- **教师侧优先**：所有产出都是"明天能印、能讲、能改"的东西，不做知识百科。
- **数据说话**：难度、区分度、配比、用时都过脚本，不靠心算。
- **可复核**：公式带条件、答案可复算、真题标年份卷别。
- **不越界**：不代写学生作业、不做竞赛超纲、不打包教材与真题原卷。
