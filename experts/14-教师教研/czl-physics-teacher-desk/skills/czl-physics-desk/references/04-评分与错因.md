# 04 评分与错因

## 一、三步赋分

批计算题不要一眼看答案打钩叉，按三步走：

| 步 | 看什么 | 给分依据 | 常见扣分 |
|---|---|---|---|
| 第一步：判模型 | 选了哪个规律、对象是谁、过程怎么分 | 模型选对即给"模型分" | 模型错 → 后面全错但可给"正确部分"的分 |
| 第二步：判过程 | 方程式是否列对、条件是否满足、方向是否声明 | 每个正确方程一个"过程分" | 方程对但代入错 → 只扣结果分 |
| 第三步：判结果 | 数值、单位、有效数字、方向 | 结果分 | 单位错扣一半结果分；有效数字不符扣 1 分 |

**核心原则：错误不连坐。** 模型错但受力分析图画对，该给的分照给；这是评分细则要写清楚的原因。

## 二、评分细则怎么写

一道 12 分的计算题，细则至少写到这个颗粒度：

```
第(1)问（4分）
  ① 正确画出受力分析图或写明研究对象 ......... 1分
  ② 列出牛顿第二定律方程 F−μmg = ma .......... 2分（方程正确但符号错给1分）
  ③ 代入数据并得出 a = 2.0 m/s²（带单位） ..... 1分（无单位扣0.5）

第(2)问（8分）
  ① 判断出两段过程并写出衔接量 v ............... 2分
  ② 第一段运动学方程 .......................... 2分
  ③ 第二段运动学方程 .......................... 2分
  ④ 结果 x = 12 m ............................. 2分（结果错但过程对，给前6分）
其他解法：用动能定理求解，①②合并给 4 分，其余同。
```

细则必须包含：**分步分值、可替代解法、典型错误扣分、结果的有效数字要求**。

## 三、错因码表

批改时给每题打一个主错因码（只打一个，多了等于没打）。

| 码 | 错因 | 典型表现 | 补救动作 |
|---|---|---|---|
| E01 | 模型误判 | 把圆周运动当平抛、把连接体当整体 | 给 2 道"先判模型"的辨析题 |
| E02 | 受力漏力/多力 | 漏摩擦力、多画向心力 | 强制按"重力-弹力-摩擦-其他"顺序画图 |
| E03 | 过程不分段 | 全程用一个方程 | 练"标节点、写衔接量" |
| E04 | 正方向混乱 | 同一题里正负号自相矛盾 | 每题首行写"取向右为正" |
| E05 | 条件不满足 | 有摩擦仍用机械能守恒 | 公式默写时同步写条件 |
| E06 | 公式记错 | 向心加速度写成 v²r | 公式卡 + 每日 5 题速答 |
| E07 | 单位/量纲错 | cm 当 m、忘记换算 | 列式后先查量纲再代数 |
| E08 | 有效数字 | 结果给 6 位小数 | 规定"与题给数据位数一致" |
| E09 | 计算失误 | 移项、开方、联立出错 | 关键步复算，用估算校验数量级 |
| E10 | 图像误读 | 斜率面积含义搞反 | 图像四问训练（轴/斜率/面积/截距） |
| E11 | 电路结构误判 | 串并联看错、电表内接外接 | 画等效电路图 |
| E12 | 电磁感应方向错 | 楞次定律只用右手定则 | "增反减同"口诀 + 磁通量增减判断 |
| E13 | 实验读数 | 不估读、量程看错 | 读数专项：分度值×估读位 |
| E14 | 数据处理 | 逐差法间隔数错、图像截距没用 | 给数据表重做一遍 |
| E15 | 误差分析空泛 | 只写"存在误差" | 要求写"哪一步、什么方向、如何减小" |
| E16 | 审题偏差 | 求"时间"答成"位移" | 圈出设问动词 |
| E17 | 表述不规范 | 没有文字说明、直接写数字 | 评分细则示范"三行式"作答 |
| E18 | 时间不够 | 会做但没写完 | 限时训练，先易后难 |
| E19 | 概念混淆 | 速度/加速度、功/能、场强/电势 | 对比表 + 反例 |
| E20 | 空白/放弃 | 压轴题完全不动笔 | 教"拿分策略"：先写研究对象和已知量 |

## 四、错因统计怎么做才有用

1. **按题统计**：每题主错因码的出现次数 → 找出"同一码出现在 3 道以上"的，那才是共性问题。
2. **按人统计**：每个学生的主错因码分布 → 分成三类：
   - 概念型（E01/E05/E19）：要重讲，不是多练；
   - 过程型（E02/E03/E04）：要改习惯，用模板强制；
   - 技术型（E07/E08/E09）：要限时训练和复算习惯。
3. **按分值加权**：错因造成的失分（不是人数）排序，决定讲评顺序。

## 五、讲评优先级矩阵

横轴＝涉及人数，纵轴＝可迁移性（这个错因会不会影响其他题）。

| | 可迁移性高 | 可迁移性低 |
|---|---|---|
| **人数多** | ① 必讲，且要重讲 | ② 讲，但点到为止 |
| **人数少** | ③ 编进作业，个别辅导 | ④ 不讲 |

一节课最多讲两个①。讲完必须配变式，否则下次照错。

## 六、评语怎么写

- 对题不对人：写"这一步漏了摩擦力"，不写"你太粗心"。
- 给下一步：每条评语后面跟一个动作（"下次列式前先写正方向"）。
- 不超过三句：多了学生不看。
- 分数旁边写"丢分点"，不写"加油"。
