# 09 工作流规范

> 每个工作流按九要素定义。九要素缺一，视为未完成设计。
> 调用关系：W1→W2→W3→W4→W5，W6 可挂在任一段之后；W4 的结论直接喂回 W1（下一轮定标）。

---

## W1 定标（anchor）

| 项 | 内容 |
|---|---|
| **任务职责** | 在写任何教学内容之前，确定"这节课让学生会什么、难在哪、学生从哪起步"，产出一页定标单。 |
| **输入参数** | 必填：课题、年级/选科；选填：教材版本（默认人教 2019）、课时数（默认 1）、班级层次（默认中等）、上次考试的薄弱点。 |
| **执行步骤** | ① 判定所属模块与册次 → ② 列 3–5 条可观测目标（每条挂行为动词 + 检测话术）→ ③ 定 1 个重点、1 个难点及突破手段 → ④ 写 3 档起点假设 → ⑤ 跨课时课题给课时切分表。 |
| **判断条件** | 课题跨章/跨课时 → 先出切分表等确认；目标写不出行为动词 → 回到教材找"学生要做什么"；难点判不出类型（概念型/过程型）→ 用 3 道诊断小题试判。 |
| **输出格式** | 一页定标单：目标表（素养 / 目标 / 检测话术）、重难点与突破、起点假设三档、课时切分（如需）。Markdown；需要时导出 docx。 |
| **异常处理** | T1 课题过泛 → 给 4–6 个候选具体课题；T2 缺版本年级 → 按人教 2019、高二选考班先做并标注；T3 缺学情 → 给三档差异点让老师勾。 |
| **必要依赖** | `references/01-课标与考向.md`、`references/07-版本课时与板书.md`。 |
| **与其他工作流** | 是 W2、W3 的前置；W4 的结论作为下一轮 W1 的输入（薄弱点参数）。 |

---

## W2 设计（design）

| 项 | 内容 |
|---|---|
| **任务职责** | 把定标单落成一节有时间轴的课，产出教案、学案、分层作业、板书结构。 |
| **输入参数** | W1 产出；课型（新授/实验/复习/习题）；课时；班级层次；器材条件（选填）；是否需要课件（选填）。 |
| **执行步骤** | ① 选课型模板 → ② 排时间轴（导入 3–5′、探究 20–25′、例题 8–10′、变式 5–8′、小结 3′、作业 2′）→ ③ 写问题链（3–5 问，每问对应一个目标）→ ④ 写例题（按"对象—方程—代入—结果"四行）→ ⑤ 出学案与分层作业（必做/选做/挑战）→ ⑥ 写板书三栏 → ⑦ 需要课件时给分页结构。 |
| **判断条件** | 实验课 → 走实验教案结构，不套新授课模板；班级偏基础 → 减探究环节、加示范；器材不足 → 加"替代方案"栏，不删实验。 |
| **输出格式** | 教案（含时间分配与教师/学生活动两栏）+ 学案 + 分层作业 + 板书结构；课件给分页大纲（标题/要点/备注）。 |
| **异常处理** | 课时不够 → 标出"可砍/不可砍"环节；无器材 → 视频/仿真/自制教具三选一；教材版本不明 → 按通用课标口径，标注可调。 |
| **必要依赖** | `references/05-实验清单.md`、`references/07-版本课时与板书.md`、`templates/教案-新授课.md`、`templates/学案与分层作业.md`。 |
| **与其他工作流** | 依赖 W1；产出的例题与作业可反哺 W3（作为题型样本）；课堂效果作为 W4 的对照基线。 |

## W3 命题（assess）

| 项 | 内容 |
|---|---|
| **任务职责** | 产出可直接印刷、可直接评分的四件套：双向细目表、试卷、参考答案、评分细则。 |
| **输入参数** | 必填：考查范围、用途（单元/期中期末/模拟/练习）、总分、时长；选填：难度预设（默认 0.65）、题型配比、是否要答题卡、禁用题型。 |
| **执行步骤** | ① 列考点清单（到二级）→ ② 生成细目表（题型×考点×认知层级×难度×分值×用时）→ ③ 用 `blueprint.py` 校验总分/难度/配比/用时 → ④ 老师确认后逐题命制 → ⑤ 配答案并独立复算 → ⑥ 用 `rubric_builder.py` 生成评分细则 → ⑦ 四查清单过一遍。 |
| **判断条件** | 正式考试 → 必须先出细目表等确认；课堂小练 → 可直接出题但开头列 3 行考点；总分与题量冲突 → 先算时间账再改题量。 |
| **输出格式** | 细目表（表）+ 试卷（题）+ 答案（分条）+ 评分细则（分步给分表）；默认同时导出 A4 docx。 |
| **异常处理** | 数据算不通 → 先定答案再反推数据；考点重复 → 换考点或改设问；超纲 → 给合规替代题；真题引用记不清年份 → 标"改编"。 |
| **必要依赖** | `references/03-命题规范.md`、`references/02-知识结构与公式.md`、`scripts/blueprint.py`、`scripts/rubric_builder.py`、`scripts/physics_calc.py`。 |
| **与其他工作流** | 依赖 W1（目标决定考什么）、W2（题型难度与课堂匹配）；产出直接进入 W4。 |

## W4 诊断（diagnose）

| 项 | 内容 |
|---|---|
| **任务职责** | 把成绩表变成可教学的结论：难度、区分度、分数段、共性错因、分层名单。 |
| **输入参数** | 必填：成绩表（学号 + 各题得分或总分）；选填：满分表（每题满分）、班级标签、错因码（批改时已打）。 |
| **执行步骤** | ① 清洗数据（缺考、满分核对）→ ② `item_analysis.py` 算三率一分、逐题 P 与 D（高低分组各 27%）→ ③ 按得分率排序找低分题 → ④ 打错因码并统计 → ⑤ 用优先级矩阵定讲评题 → ⑥ 出分层名单与补救任务。 |
| **判断条件** | 样本 < 30 → D 只作参考并标注；只有总分 → 只做分布与分层；某题得分率 > 0.95 → 不进讲评。 |
| **输出格式** | 学情报告：统计表（班级/题号）、分数段图（文字条形）、错因排序表、分层名单、下节课建议。 |
| **异常处理** | T5 缺分题得分 → 明确告知做不了 P/D；数据列名不规范 → 先规范化再算；缺考多 → 分母口径写清楚（实考人数）。 |
| **必要依赖** | `references/04-评分与错因.md`、`scripts/item_analysis.py`。 |
| **与其他工作流** | 依赖 W3（卷子与满分表）；输出喂给 W5（讲评选题）与下一轮 W1（薄弱点）。 |

---

## W5 复盘（reflect）

| 项 | 内容 |
|---|---|
| **任务职责** | 把诊断结论变成一节 45 分钟的讲评课，并配可迁移的变式与跟踪表。 |
| **输入参数** | W4 报告或错题清单；课时长度（默认 45′）；可用教具；是否要当堂检测。 |
| **执行步骤** | ① 按"三选三不选"定 1–2 个模型、3–5 道题 → ② 排时间轴（数据 3′、错因回放 8′、重做 15′、变式 15′、检测 4′）→ ③ 为每题写追问三连 → ④ 出变式题（换情境/换问法/换数据，一次只变一个）→ ⑤ 出当堂检测 1 题 → ⑥ 生成课后跟踪表。 |
| **判断条件** | 错因集中在 1 个模型 → 改成小专题课；错因分散在 5 个以上模型 → 只讲失分最高的两个；班级差异大 → 变式分两层。 |
| **输出格式** | 讲评课设计（时间轴 + 环节脚本）+ 变式题及参考答案 + 当堂检测 + 跟踪表。 |
| **异常处理** | 只有"平均分低" → 先要 3 道典型错题；课时被压到 20′ → 给"微讲评"版本（只保留错因回放 + 重做）。 |
| **必要依赖** | `references/06-讲评与补救.md`、`templates/讲评课设计.md`。 |
| **与其他工作流** | 依赖 W4；产出的变式题可回流 W3（作为下次命题素材）；跟踪结果进入下一轮 W1。 |

---

## W6 沉淀（document）

| 项 | 内容 |
|---|---|
| **任务职责** | 把一次备课/命题/讲评沉淀成一页可分享的教研材料。 |
| **输入参数** | 前序任一段的产出；用途（教研组分享/公开课说明/命题说明/青蓝工程带教）。 |
| **执行步骤** | ① 抽取设计决策（为什么这么定重点、为什么这么排顺序）→ ② 写取舍理由（放弃了什么、为什么）→ ③ 写预期效果与观测方式 → ④ 写"下次改哪里"→ ⑤ 压到一页。 |
| **判断条件** | 只存档 → 不写套话，只写决策与复盘；对外分享 → 补背景与学情，删内部信息。 |
| **输出格式** | 一页纸：背景 / 设计决策（3 条）/ 取舍 / 观测 / 改进。 |
| **异常处理** | 材料不足以支撑说明 → 只写"做了什么"，不编"效果如何"。 |
| **必要依赖** | `templates/教研记录.md`。 |
| **与其他工作流** | 可挂在 W2/W3/W5 之后；产出作为团队资产，不进入学生侧。 |

## 附：工作流选择决策树

```
老师的话里有没有"卷子/考试/命题"？ ──有──→ W3
        │没有
有没有"成绩/得分率/错因/分析"？ ──有──→ W4 →（是否要上课）→ W5
        │没有
有没有"讲评/补救/再练"？ ──有──→ W5
        │没有
有没有"备课/教案/学案/课时/公开课"？ ──有──→ W1 → W2
        │没有
有没有"总结/教研/分享/说明"？ ──有──→ W6
        │没有
按学生个人辅导处理或请老师补充一句需求
```

跨段请求（"备完课顺手出一份作业"）按主线走，附带产出放在同一次交付里，不拆成两轮。
