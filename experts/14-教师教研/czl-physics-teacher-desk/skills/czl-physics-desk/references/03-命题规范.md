# 03 命题规范

## 一、先有表，再有题

正式卷（单元、期中期末、模拟）必须先出双向细目表。没有表的卷子一定偏——要么考点重复，要么难点扎堆。

细目表的列：

| 题号 | 题型 | 考点（到二级） | 认知层级 | 预设难度 | 分值 | 预估用时 | 情境/模型 |
|---|---|---|---|---|---|---|---|
| 1 | 单选 | 匀变速图像 | 理解 | 0.85 | 4 | 1.5 min | 刹车 |
| … | | | | | | | |

认知层级只分四档：**识记 / 理解 / 应用 / 分析**。一张卷子里"识记"不超过 15%，"分析"不超过 50%，"理解+应用"不低于 35%（基础题保底）。单个考点不超过总分 18%。

表的校验（用 `scripts/blueprint.py` 自动跑）：
1. 分值合计 = 卷面总分；
2. 预设难度按分值加权 ≈ 目标难度（误差 ±0.03）；
3. 同一考点不超过总分 15%；
4. 题型配比符合约定（如选择 40–45%、实验 15–18%、计算 40–45%）；
5. 预估用时合计 ≤ 规定时长 × 0.9。

## 二、难度是设计出来的

调难度只动四个旋钮，不要靠"数字更丑"来变难：

| 旋钮 | 调易 | 调难 |
|---|---|---|
| 过程层数 | 1 段 | 2–3 段，需自己找衔接量 |
| 条件显隐 | 需要什么给什么 | 部分条件藏在图像/表格里 |
| 模型熟悉度 | 教材原模型 | 换情境、换问法、需重新建模 |
| 数学负担 | 一元一次 | 二次方程、联立、三角函数 |

一次只动一个旋钮。同时动两个，难度会失控。

## 三、题干规则

1. **一句话说清物理情景**：谁、在什么环境、做什么运动、受什么约束。不要用文学描写。
2. **数据自洽**：给的数据要能算出结果，且结果在合理范围（如人跑步速度不能是 30 m/s）。
3. **单位统一**：题干用国际单位，必要时在括号内换算；不混用 cm 和 m。
4. **g 值声明**：卷首统一写"取 g=10 m/s²"或"取 g=9.8 m/s²"，全卷一致。
5. **不设陷阱**：难度来自物理，不来自文字游戏（"不正确的是"加粗除外，这是规范）。
6. **图示规范**：标出正方向、已知量、坐标系；不画与解题无关的装饰。

## 四、选项设计（选择题）

- 正确项：表述完整、无条件歧义。
- 干扰项：来自**真实错误**，不是随便改数字。常见四类干扰——概念混淆（速度/加速度）、条件缺失（忽略摩擦）、符号错误（方向反）、半对半错（前半句对后半句错）。
- 四个选项长度接近，正确项不要明显最长。
- 多选题的正确项之间要独立，不要"选了 A 必然选 B"。
- 不出"以上都对/都不对"（除非确有必要）。

## 五、计算题规则

1. 设问分层：第 (1) 问保底（P≈0.7），第 (2) 问主体（P≈0.5），第 (3) 问拉开（P≈0.3）。
2. 每问的答案必须**由前一问的量或本问独立条件**推出，不能跳步。
3. 明确要求"写出必要的文字说明、方程式和重要演算步骤"。
4. 提供**评分细则**（见 `04-评分与错因.md`），标出每步分值。
5. 压轴题允许"半成品"：会做前两问也能拿 60% 分。

## 六、实验题规则

- 一道力学 + 一道电学是主流配置。
- 必有：仪器读数（含估读）、数据处理（图像或逐差）、误差分析（系统/偶然）。
- 创新点放在"改测量量"或"改电路"，原理仍在教材范围。
- 不考未学过的新器材原理，除非题干给出使用方法。

## 七、四查清单（交卷前逐条过）

- [ ] **查总分**：分值合计等于 100（或约定值），各题分值不缺不多。
- [ ] **查覆盖**：细目表上每个考点都有题，重点章节权重合理。
- [ ] **查难度**：加权难度在目标区间；没有连续 3 道同难度题。
- [ ] **查答案**：每题独立复算一遍；选择题答案唯一；计算题答案与评分细则一致；单位、有效数字正确。

外加三条容易被忽略的：
- [ ] 题号与答题卡一致；
- [ ] 图表编号与正文引用一致；
- [ ] 全卷没有出现两个"第 5 题"（合并修订时最常见）。

## 八、情境素材从哪来

| 来源 | 适用 | 注意 |
|---|---|---|
| 日常生活（电梯、刹车、拎水桶） | 概念题、单选题 | 数据要真实，别夸张 |
| 体育（跳高、投掷、滑冰） | 运动学、动量 | 避免具体运动员姓名与成绩 |
| 交通与安全（限速、反应距离） | 匀变速、动力学 | 数据用公开常识范围 |
| 航天与天体（卫星、空间站） | 万有引力 | 轨道参数别编得太离谱 |
| 能源与电力（输电、充电） | 电路、电磁感应 | 效率数据要合理 |
| 教材实验改造 | 实验题 | 不能用教材原图与原题 |

## 九、常见命题失误

| 失误 | 后果 | 修法 |
|---|---|---|
| 一道题里塞三个考点 | 难度失控、区分度反而低 | 拆成两题 |
| 数据凑不出整数就硬改 | 答案不唯一或自相矛盾 | 先定答案再反推数据 |
| 干扰项靠改数字 | 只考计算不考概念 | 换成概念型干扰 |
| 实验题考读数却不给量程 | 无法估读 | 题干或图注标量程与分度值 |
| 压轴题第一问就很难 | 全体失分，无区分 | 第一问降到 P≈0.7 |
| 全卷没有图像题 | 与考向脱节 | 至少 1 道图像题 |
