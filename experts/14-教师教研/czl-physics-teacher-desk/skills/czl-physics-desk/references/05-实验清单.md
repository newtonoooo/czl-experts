# 05 实验清单

> 只列教材标准实验。器材、步骤以本校实验室实际配置为准；涉及用电与打点计时器的操作，按实验室安全规程执行。

## 一、力学实验

### 1. 用打点计时器测速度与加速度

| 项 | 要点 |
|---|---|
| 原理 | 相邻计时点时间间隔 T=0.02 s（50 Hz）；v_n=(x_n+x_{n+1})/2T；逐差法 a=[(x₄+x₅+x₆)−(x₁+x₂+x₃)]/9T² |
| 关键器材 | 电磁打点计时器（4–6 V 交流）或电火花计时器（220 V 交流）、纸带、刻度尺 |
| 操作顺序 | 先接通电源，待打点稳定再释放纸带 |
| 易错 | 用直流电源；纸带与限位孔摩擦；刻度尺不估读；把 5 个间隔当 4 个 |
| 误差 | 系统：摩擦与空气阻力（使 a 偏小）；偶然：长度测量 |
| 数据处理 | 舍掉开头密集点，从清晰点起每 5 个间隔取一个计数点 |

### 2. 探究加速度与力、质量的关系

| 项 | 要点 |
|---|---|
| 原理 | 控制变量：m 一定看 a-F；F 一定看 a-1/m |
| 关键操作 | 平衡摩擦力（垫高木板，不挂钩码能匀速）；砂桶质量 m ≪ 小车质量 M |
| 易错 | 不挂纸带就平衡摩擦力；忘记满足 m≪M；a-F 图像不过原点没分析原因 |
| 图像分析 | 图线在 F 轴有截距 → 摩擦力未平衡够；在 a 轴有截距 → 平衡过度 |
| 误差 | 系统：m 不满足远小于 M 时，绳张力小于砂桶重力，图线上端弯曲 |

### 3. 验证机械能守恒定律

| 项 | 要点 |
|---|---|
| 原理 | mgh = ½mv²，比较 gh 与 v²/2 |
| 器材 | 重物（质量大、体积小）、打点计时器、纸带、刻度尺 |
| 易错 | 用天平测质量（其实不需要）；先放纸带后通电；用第一个点算速度（应取清晰点）；忘记因阻力导致 ΔEp 略大于 ΔEk |
| 误差 | 系统：阻力使动能增量偏小；偶然：测长度 |

### 4. 验证动量守恒定律

| 项 | 要点 |
|---|---|
| 方案 | 气垫导轨（光电门测速）或斜槽末端平抛（水平位移代替速度） |
| 原理 | m₁v₁ = m₁v₁′ + m₂v₂′；平抛方案中 v ∝ x |
| 易错 | 斜槽末端不水平；两次释放位置不同；用位移代替速度时忘记时间相同的前提 |
| 误差 | 导轨未调平、碰撞不在一维 |

## 二、电学实验

### 5. 测电源的电动势和内阻

| 项 | 要点 |
|---|---|
| 原理 | U = E − Ir，作 U-I 图，纵截距为 E，斜率绝对值为 r |
| 电路 | 电流表外接（相对电源），滑动变阻器限流 |
| 易错 | 纵轴不从零开始时直接读斜率（要用两点算）；电流表内接导致 E、r 测量值偏小 |
| 误差 | 系统：电压表分流，E 和 r 均偏小 |

### 6. 描绘小灯泡的伏安特性曲线

| 项 | 要点 |
|---|---|
| 电路 | 必须分压接法（要从零调）；电流表外接（灯丝电阻小） |
| 原理 | 灯丝电阻随温度升高而增大，曲线向上弯曲（斜率变小） |
| 易错 | 用限流接法导致调不到零；把 U-I 图斜率当电阻（应为 1/斜率或该点 U/I） |
| 误差 | 系统：电表内阻影响；温度变化本身是测量对象的一部分 |

### 7. 测金属丝的电阻率

| 项 | 要点 |
|---|---|
| 原理 | ρ = RS/L；S = πd²/4；R 用伏安法测 |
| 器材 | 螺旋测微器（估读到 0.001 mm）、毫米刻度尺、伏安法电路 |
| 易错 | 直径只测一次；有效长度取成整根丝；电流过大使丝发热 |
| 误差 | 直径测量误差被平方放大，应在不同位置测 3 次取平均 |

### 8. 练习使用多用电表

| 项 | 要点 |
|---|---|
| 步骤 | 机械调零 → 选挡 → 欧姆调零 → 测量 → 换挡重调 → 用完拨到 OFF 或交流高压挡 |
| 易错 | 换挡不重新欧姆调零；测电阻时手接触表笔金属部分；带电测电阻 |
| 读数 | 欧姆挡读数 × 倍率；电流电压挡看对应刻度并估读 |

## 三、热学、光学与振动

### 9. 探究气体等温变化的规律

| 项 | 要点 |
|---|---|
| 原理 | 玻意耳定律 pV = C（T 不变） |
| 器材 | 注射器 + 压强传感器（或压力表） |
| 易错 | 手握住注射器筒身（温度变化）；活塞漏气；未缓慢推拉 |
| 数据处理 | 作 p-1/V 图应为过原点直线，比 p-V 曲线更易判断 |

### 10. 用单摆测重力加速度

| 项 | 要点 |
|---|---|
| 原理 | g = 4π²L/T² |
| 摆长 | 悬点到球心的距离（线长 + 半径） |
| 操作 | 摆角 < 5°；测 30–50 次全振动总时间再除以次数；从最低点开始计时 |
| 易错 | 把线长当摆长；少数振动次数；在小角度外测量 |
| 误差 | 系统：空气阻力与悬点摩擦；偶然：时间测量（多次全振动可减小） |

### 11. 测玻璃的折射率

| 项 | 要点 |
|---|---|
| 原理 | n = sin i / sin r，插针法确定光路 |
| 操作 | 大头针间距尽量大；两针连线与界面交点准确 |
| 易错 | 玻璃砖两界面不平行导致侧移；针距太近；入射角太小（误差放大） |
| 误差 | 角度测量；界面画线偏差 |

### 12. 用双缝干涉测光的波长

| 项 | 要点 |
|---|---|
| 原理 | λ = dΔx / L |
| 操作 | 测 n 个条纹的总间距再除以 n；单缝与双缝平行 |
| 易错 | 数错条纹数（n 个间距对应 n+1 条亮纹）；未调出清晰干涉图样就测 |
| 误差 | 条纹间距测量（增大 L 或用更大间距） |
