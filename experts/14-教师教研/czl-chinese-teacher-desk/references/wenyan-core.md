## 二、18 个文言虚词｜K/R

| 虚词 | 主要用法（按考点频次排） |
|---|---|
| 而 | 连词：并列、承接、递进、转折、修饰；代词：你 |
| 何 | 疑问代词：什么、为什么、哪里；副词：多么 |
| 乎 | 语气词：疑问、反问、感叹；介词：相当于"于" |
| 乃 | 副词：就、才、竟然；代词：你的；判断副词：是 |
| 其 | 代词：他的、那；语气副词：大概、难道、一定；连词：如果 |
| 且 | 连词：并且、况且；副词：将要、暂且 |
| 若 | 代词：你、你的；连词：如果；动词：像 |
| 所 | 助词：与动词组成"所"字结构；"为……所……"表被动；名词：处所 |
| 为 | 介词：替、被、因为；动词：做、是、认为；语气词：呢 |
| 焉 | 兼词：于此；代词：哪里；语气词：了、呢 |
| 也 | 句末语气词：判断、陈述、疑问；句中：停顿 |
| 以 | 介词：用、凭、因为；连词：来、以致；动词：认为；名词：原因 |
| 因 | 介词：凭借、趁着、通过；副词：于是；动词：沿袭 |
| 于 | 介词：在、到、向、对于、比、被 |
| 与 | 介词：和、跟；连词：和；动词：给予、结交；语气词：欤 |
| 则 | 连词：就、却、那么；副词：就是；名词：准则 |
| 者 | 助词：……的人/事物；提顿；定语后置标志 |
| 之 | 助词：的、主谓之间取消独立性、宾语前置标志；代词：他/它/这；动词：往 |

判断口诀（E）：先看位置（句首/句中/句末），再看前后词性，最后看句子语气。三者冲突时以语意通顺为准。

## 三、特殊句式｜K

| 句式 | 标志 | 翻译处理 |
|---|---|---|
| 判断句 | ……者，……也／乃／即／则／皆／为 | 补"是" |
| 被动句 | 为……所……／见……于……／被／于 | 补"被" |
| 宾语前置 | 疑问代词作宾语、否定句代词宾语、"之/是"作标志 | 调序，宾语回到动词后 |
| 状语后置（介宾后置） | 于／以 引出的短语在动词后 | 调序，状语前移 |
| 定语后置 | 中心词 + 之 + 定语 + 者／数量词后置 | 调序，定语前移 |
| 主谓倒装 | 谓语在主语前（多见于感叹、疑问） | 调序 |
| 省略句 | 省主语、省宾语、省介词 | 补出，用括号标注 |
| 固定句式 | 无乃……乎／得无……乎／孰与／所以／何以……为 | 按固定译法整体译 |

## 四、翻译采分点操作法（六步）

1. **切句。** 按标点与主谓结构切成小句，一句一译。
2. **圈点。** 圈出三类采分点：一词多义实词、关键虚词、特殊句式。通常每句 2—3 个。
3. **直译。** 逐字对应，不先求顺。字字有着落，再调语序。
4. **补调。** 补省略成分（加括号），调倒装语序。
5. **润色。** 只在不改原意的前提下使句子通顺，不改换说法。
6. **回读。** 把译文放回上下文，看是否与前后文自洽；不自洽则回第 2 步重判。

### 评分惯例｜R

- 一句 4 分：2 个关键词各 1 分，句意通顺 2 分（或 3 个关键词各 1 分 + 句意 1 分，视题目细则）。
- 句意分不给"大致意思对"就满分，须无漏译、无错译。
- 意译过度导致关键词未落实的，按未译处理。

### 常见失分（E）

| 失分类型 | 表现 | 纠正 |
|---|---|---|
| 该译未译 | 人名地名之外的专有名词照抄 | 只有人名、地名、官名、年号可保留 |
| 以今律古 | "可怜"译成"值得同情" | 先查古义，再定 |
| 漏译虚词 | "之""而"直接跳过 | 虚词不译也要确认它不承担实义 |
| 句式未调 | 宾语前置照原序译 | 先判句式再译 |
| 通顺分丢 | 逐字硬译成病句 | 第 5 步必须做 |
