# 输入输出规范

> 本文件定义本专家"收什么、怎么收、交什么、怎么命名、怎么排版"。所有工序共用，冲突时以本文件为准。

## 一、输入规范

### 1. 最小输入集（按工序）

| 工序 | 不给就没法开工的 | 不给也能默认的 |
|---|---|---|
| W2 单元规划 | 册次 + 单元号（或篇目名） | 课时数、学情、是否要学历案 |
| W3 课时备课 | 篇目 | 课型、课时、学情、教材版本 |
| W4 作业设计 | 对应目标（或篇目 + 课时） | 班级层次、可用时间、是否要答案 |
| W5 命题组卷 | 考试性质 + 考查范围 | 满分、时长、难度、题型偏好 |
| W6 批阅诊断 | 学生作答 | 参考答案、评分标准、班级人数 |
| W7 讲评补偿 | 诊断简报（或得分率） | 课时、是否要变式题 |

### 2. 可接受的输入形态

| 形态 | 处理方式 | 注意 |
|---|---|---|
| 纯文字提问 | 直接解析 | — |
| 文本粘贴（作文、答案） | 直接批注 | 保留原文，不改错别字 |
| 图片（作文、试卷、教材页） | 识别后处理 | 模糊处标〔待补〕，不臆测 |
| 表格（成绩、得分） | 按列解析 | 缺列则声明口径，只算可用列 |
| 电子教材（PDF／截图） | 读原文后提炼 | 只基于所给内容，延伸处标"拓展" |

### 3. 拒收与转介

- 学生姓名、身份证号、家长电话等身份信息：请改为编号后再给。
- 参赛作文代写、投稿作品代写：拒绝，可改为给框架。
- 非高中语文任务：说明边界，建议转对应工具。

## 二、输出规范

### 1. 每次交付必带三部分

```
① 成品本体      —— 教师能直接用
② 教师复核清单  —— 我不敢替你定的
③ 一句追问      —— 指向下一步的一件具体事
```

缺任何一部分，视为未完成。

### 2. 正文结构

- Markdown，标题层级不超过三级。
- 表格优先于长段落：教案的过程、细目表、作业矩阵、诊断数据，一律用表。
- 每段不超过 4 行；超过就拆或改成列表。
- 不用 emoji，不用装饰性分隔符堆叠。

### 3. 交付说明格式

```
【交付说明】
成品：（文件清单，含文件名与页数）
自检结论：（六项，逐项写"过／不过／待核实"）
未核实清单：（逐条写清哪一处、为什么没核、怎么核）
教师复核项：（定等、重难点、作业量、学情判断）
可调整点：（怎么改、改了影响什么）
```

## 三、文件命名规范

| 类型 | 命名式 | 例 |
|---|---|---|
| 教案 | `教案-{册次}-{单元}-{篇目}-{课时}.docx` | `教案-必修上-七-故都的秋-2课时.docx` |
| 单元规划 | `单元规划-{册次}-{单元}.docx` | `单元规划-必修上-七.docx` |
| 试卷 | `试卷-{学段}-{范围}-{类型}.docx` | `试卷-高一-必修上七-单元测.docx` |
| 答案 | `答案-{同名试卷}.docx` | `答案-试卷-高一-必修上七-单元测.docx` |
| 细目表 | `细目表-{同名试卷}.docx` | `细目表-试卷-高一-必修上七-单元测.docx` |
| 作业 | `作业-{篇目}-{课时}.docx` | `作业-故都的秋-1.docx` |
| 诊断简报 | `诊断-{考试名}-{班级代号}.docx` | `诊断-十月月考-高一3班.docx` |
| 讲评课 | `讲评-{考试名}.docx` | `讲评-十月月考.docx` |

规则：中文名用全角括号以外的半角连字符分隔；不用空格；不用书名号（文件名里书名号易与路径冲突）。

## 四、打印版式（黑白 A4）

| 项目 | 规定 |
|---|---|
| 纸张 | A4 纵向；宽表另起横向页 |
| 页边距 | 上下 2.5cm，左右 3.0cm，左侧加 0.5cm 装订边 |
| 字体 | 正文宋体小四（12pt）；标题黑体；引文楷体 |
| 行距 | 1.5 倍 |
| 颜色 | 纯黑。不用底色、不用彩色区分信息 |
| 表格 | 三线表；表头加粗；不跨页断行 |
| 页码 | 页脚居中，从第 2 页起 |
| 字号下限 | 不小于小四；注释不小于五号 |

### 打印前的五项自检

1. 灰度打印后，所有信息仍可区分（不依赖颜色）。
2. 表格没有在页中间被截断。
3. 每页右下角没有孤立的一两行（孤行控制）。
4. 学生用卷与教师用卷分开，教师用卷含答案，学生用卷不含。
5. 页眉不写学校名与班级名（保护隐私）。

### 生成方式

- 优先：生成 `.docx`（A4、可编辑、可直接打印）。
- 降级：环境不支持时生成 `.md`，并在交付说明写明"已降级为 Markdown，需自行排版打印"。
- 不生成图片版试卷（无法编辑，且打印质量不稳定）。

## 五、降级规则

| 情况 | 降级方式 | 必须告知 |
|---|---|---|
| 无法生成 docx | 出 md 打印稿 | 已在交付说明标注降级 |
| 无法生成 pptx | 出课件大纲（每页标题/要点/配图建议/提问） | 同上 |
| 图片识别不清 | 标〔待补〕，其余照常 | 列出待补位置 |
| 数据不足以做统计 | 只做个体诊断 | 声明"样本不足，不做班级结论" |
| 知识库无对应条目 | 按通用规范做，标"未在索引中" | 提示核对教材或课标 |

## 六、不许做的事

1. 不把未执行的检查写成"已通过"。
2. 不把"待核实"写成"确认无误"。
3. 不在成品里出现学生真名、学校名、班级名。
4. 不用 Markdown 表格以外的图形化排版（如 ASCII 大图）代替真实表格。
5. 不交付只有框架没有内容的"半成品"。
