# W2 单元规划

## 1. 任务职责

把一个单元变成一张"目标—评价—活动"三列对齐的施工图。产出不是教学设计文章，是能贴在备课本上、后面每节课都照着走的那张表。

这一道工序解决的是"单篇备得细、单元合不上"的问题。判据：单元规划做完，每一课时的目标都能在这张表上找到出处。

## 2. 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 册次 + 单元号 | 是 | 如"必修上册第七单元" |
| 总课时 | 否 | 默认按教材建议课时，未给则按 9 课时排 |
| 学情 | 否 | 班级层次、已有基础、已知薄弱点 |
| 单元类型 | 否 | 阅读单元／活动单元／整本书单元／写作单元 |
| 是否要单元学历案 | 否 | 要则附学生用任务单 |

## 3. 执行步骤

1. **查单元归属。** 读 `references/textbook-index.md` 定位本单元篇目，读 `references/curriculum-map.md` 定人文主题与所属学习任务群。任务群归属标 R（教研共识），不标 K。
2. **提一条大概念。** 一句话，必须是"学生学完能带走的一个判断"，不是"本单元介绍了……"。写法：`通过（内容）理解（可迁移的认识）`。
3. **写三条单元目标。** 每条用一个可观测动词（梳理／比较／辨析／论证／仿写／评点），不用"体会""感受""培养"这类无法验证的词。三条目标分别对应：语言层面、思维层面、审美或文化层面。
4. **设两个评价任务。** 表现性任务，能收上来的东西：一篇短评、一张对比表、一次三分钟陈述、一份批注。每个任务写清"做什么、交什么、按什么标准算过"。
5. **排课时。** 按块分配，不按篇平均分：
   - 精读篇目：每篇 2 课时
   - 自读篇目：每篇 1 课时（任务单式）
   - 整合课：1—2 课时（比较、梳理、群文）
   - 写作：2 课时（指导 1 + 讲评 1）
   - 单元测评：1 课时
6. **标处理方式。** 哪几篇精读、哪几篇自读、哪几篇合并处理、哪一篇做写作范文。写明理由，一句话即可。
7. **接下游。** 明确哪几个课时要进 W3 出教案，哪几个节点要进 W5 出题。

## 4. 判断条件

| 情况 | 处理 |
|---|---|
| 活动单元（家乡文化生活、词语积累、逻辑的力量、信息时代的语文生活） | 走任务驱动，产出"活动流程 + 成果要求 + 评价量表"，不做文本细读 |
| 整本书单元（《乡土中国》《红楼梦》） | 改出"推进表"：周次／阅读范围／任务／检测方式，另附 2 个专题研讨设计 |
| 写作单元 | 走"作前指导—写作—批改—讲评"四段，目标写成可评的写作能力点 |
| 课时不足（少于建议课时 70%） | 出"保底版"：保精读 + 写作 + 测评，砍整合课，明确告知砍了什么 |
| 课时充裕（多于建议课时 130%） | 出"拓展版"：加群文比较、加整本书联动、加表达活动 |
| 教师只要一课 | 不硬做整单元，改走 W3，但在教案开头注明该课在单元中的位置 |

## 5. 输出格式

```
【单元施工图】必修上册 第七单元
人文主题：自然情怀｜任务群：文学阅读与写作（R）
大概念：写景散文的价值不在写了什么景，在作者用哪一种"看"的方式重组了景。

单元目标
1 语言：梳理三篇散文的写景句，比较句式与修辞选择的差异
2 思维：辨析"以我观物"与"以物观物"两种写法各自的效果边界
3 审美：评点一处最能体现作者心境转折的景物描写，说明依据

评价任务
任务一 景物描写对比表（3 篇 × 4 维度），课上完成，按"维度齐全/引文准确/结论有据"三项评
任务二 300 字评点一则，课后交，按"定位准/术语对/有文本依据"三项评

课时分配（共 9 课时）
14 故都的秋        精读  2 课时   → W3
15 我与地坛（节选）精读  2 课时   → W3
*荷塘月色          自读  1 课时   任务单式
16 赤壁赋          精读  2 课时   → W3
*登泰山记          自读  1 课时   与《赤壁赋》合并比较
单元整合 + 测评     1 课时         → W5 出单元测

处理理由：两篇自读不单讲，分别挂在相邻精读后做迁移；《赤壁赋》与《登泰山记》同为"夜游—悟理"结构，合并出比较课。
```

## 6. 异常处理

| 异常 | 处理 |
|---|---|
| 册次或单元号对不上教材 | 报"未在索引中找到"，请教师给篇目名，按篇目反查单元 |
| 教师给的课时与教材建议差距过大 | 按教师课时排，但开头提示"较建议课时少 X 课时，已砍整合课" |
| 单元含跨册篇目（如复习单元） | 按专题重组，标注"非教材原单元，为复习重组" |
| 学情完全空白 | 按平行班常规，标注假设，给出"若基础弱则……"的两处调整点 |

## 7. 必要依赖

- `references/textbook-index.md`（篇目与单元）
- `references/curriculum-map.md`（任务群与素养）
- `references/delivery-spec.md`（打印版式，若要学历案）

## 8. 与其他工作流的关系

- **上游**：W1 工序单。
- **下游**：单元目标下发到 W3（课时目标必须从这里长出来）、W4（作业按目标分层）、W5（测评按目标命题）。三者不得自拟目标。
- **回路**：W6 诊断出班级共性问题后，若属单元层面目标设定过高或过低，回 W2 修订目标，而非只改练习。
