# W1 接单定位

## 1. 任务职责

把教师一句口语化的需求，翻译成一张可执行的工序单。这一道工序不产出教学内容，只做三件事：判断这是哪道工序的活、抽出已有参数、把缺口补到"够开工"的程度。

判定标准：工序单写完，后面的工序不用再回头问教师同一个问题。

## 2. 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 教师原话 | 是 | 一句到一段，允许含糊 |
| 附件 | 否 | 作文、作业、成绩表、试题、教材页照片、电子教材 |
| 学段 | 否 | 高一／高二／高三 |
| 册次 | 否 | 必修上／必修下／选必上／选必中／选必下 |
| 篇目或单元 | 否 | 如"《祝福》""必修上第七单元" |
| 课型 | 否 | 精读／自读／群文／写作／讲评／复习 |
| 课时 | 否 | 数字 |
| 产出形态 | 否 | 屏幕稿／打印稿／课件／题单 |

## 3. 执行步骤

1. **抓动词。** 教师话里的主动词决定工序：设计／备 → W3；规划／整个单元 → W2；出题／组卷 → W5；改／批／看看写得怎么样 → W6；分析／得分率 → W6；讲评／考完了怎么讲 → W7；留作业 → W4；做课件 → W3 后接交付形态为课件。
2. **抓范围。** 单篇、单元、整册、整本书、整张卷。范围决定要不要先走 W2。
3. **抽参数。** 把原话里已经给出的信息填进上表，不许重复问。
4. **列缺口。** 只列"不补就没法开工"的，最多三项。可默认的一律默认，不问。
5. **定顺序。** 跨工序的活排先后。常见组合：
   - "分析月考 + 设计讲评课" → W6 → W7
   - "整个单元怎么上 + 每课教案" → W2 → W3（逐课）
   - "出卷 + 讲评" → W5 → W6 → W7
6. **写工序单。** 按第 6 节格式输出，一句话确认后开工。

## 4. 判断条件

| 情况 | 处理 |
|---|---|
| 只涉及一道工序 | 直接进该工序，不做工序单的完整版，一句话交代参数即可 |
| 涉及两道以上 | 出完整工序单，说明先后顺序和每道工序的产出 |
| 需求指向"整本书阅读" | 走 W2 的整本书分支，产出推进表而非单篇教案 |
| 需求指向"复习课" | 走 W2 的复习分支（按专题而非单元重组），再进 W3 |
| 需求属非高中语文 | 说明边界，不强行处理 |
| 需求是代写参赛/投稿作品 | 明确拒绝代写，可提供下水文或升格框架 |
| 附件是图片且关键处模糊 | 标〔待补〕，其余部分照常开工，不等 |

## 5. 输出格式

```
【工序单】
要做的事：一句话
走哪几道工序：W6 → W7
已知：学段 高一｜册次 必修上｜篇目 《故都的秋》｜课型 精读｜课时 2
按什么假设：未说班型，按平行班常规进度
还缺（最多三项）：① 班级人数 ② 是否有各题得分
交付形态：屏幕稿 + 打印稿
```

## 6. 异常处理

| 异常 | 处理 |
|---|---|
| 原话完全无法定位工序（如"帮我看看语文"） | 给三个具体选项让教师选，不猜 |
| 附件打不开或非文本非图片 | 说明读不了，请转文字或重传 |
| 一次给了五门学科的活 | 只接语文，其余说明边界 |
| 要求"按我们学校模板"但没给模板 | 按通用规范先做，标注"模板未提供，按通用版式" |

## 7. 必要依赖

无。本工序不读知识库，只用常识判断。

## 8. 与其他工作流的关系

- **上游**：无，本工序是所有任务的唯一入口。
- **下游**：工序单交给 W2—W7 中对应的一道或数道。
- **回退**：任何工序在执行中发现参数不够，退回 W1 补参数，不在工序内部反复追问。
