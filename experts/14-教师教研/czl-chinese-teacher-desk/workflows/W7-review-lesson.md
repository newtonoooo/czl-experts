# W7 讲评补偿

## 1. 任务职责

把"对答案"变成一节有增量的课。讲评课的目标不是让全班知道正确答案，是让同类题下次少错。

一节课只讲三个点，每个点都要走到"变式再测"。讲不完的，做成错题清单，不塞进课堂。

## 2. 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 诊断简报 | 是 | 由 W6 给；无则由本工序先从得分率提炼 |
| 各题得分率 | 否 | 有则按数据选点，无则按错因占比选点 |
| 课时 | 否 | 默认 1 课时 |
| 是否需要变式题 | 否 | 默认需要，每点一题 |
| 是否需要补偿作业 | 否 | 默认需要 |

## 3. 执行步骤

1. **选点。** 三个标准同时满足才讲：得分率低（低于 60%）、可迁移（换个文本还考）、有典型错例可展示。
2. **每点走四步。**
   - 错例：原样投出错答（去身份），不点名
   - 归因：让学生说"他为什么这么想"，把错误思路说出来
   - 正解路径：给可操作的三步，不给"要认真读"这类空话
   - 变式再测：换文本、同结构，当堂做，当堂对
3. **排时间。** 三点各 10—12 分钟，导入 3 分钟，收口 5 分钟。留 5 分钟机动。
4. **设计二次作答。** 至少一处让原来答错的学生重答一次，看见自己的变化。
5. **配补偿作业。** 只练错的那一类，不掺新内容；题量控制在 15 分钟内。
6. **收口。** 让学生自己写一句"下次遇到这类题，我先做什么"，教师收 3 张念出来。

## 4. 判断条件

| 情况 | 处理 |
|---|---|
| 某题得分率高于 85% | 不讲，最多一句带过 |
| 某题得分率低于 40% | 先判断是不是前置知识缺失；是则补前置，不直接讲题 |
| 课时只有 1 节而问题很多 | 只讲两点，其余列"错题微课清单"（题号 + 一句话错因），发下去自查 |
| 两节课连排 | 第一节讲两点 + 当堂再测，第二节讲一点 + 整卷回看 |
| 作文讲评 | 不讲范文，讲"三类开头／三类论证"的对比，用本班原句（匿名）做材料 |
| 班级差异极大 | 分层讲评：统一讲一点，其余两组分层任务 |

## 5. 输出格式

```
【讲评课教案】必修上第七单元测 讲评（1 课时 / 40 分钟）

讲评点选择依据：第 3 题得分率 38%，第 5 题 41%，第 6 题作文"引文支撑"项 44%。第 1、2 题 90% 以上，不讲。

| 时段 | 内容 | 教师动作 | 学生动作 |
|---|---|---|---|
| 0—3' | 整体：三句话说完本次情况 | 只报数据，不评价努力 | 对照自己的卷子 |
| 3—15' | 点一 第 3 题：有判断无引文 | 投一份错答，追问"他凭什么这么说" | 找出错答缺的那一步 |
| 15—27' | 点二 第 5 题：比较阅读找不到比较维度 | 给"三维定锚法"：人物/手法/意图 | 用新选段重做一遍 |
| 27—37' | 点三 作文：引文支撑 | 投三句本班原句（匿名），排优劣 | 改自己作文的一句 |
| 37—40' | 收口 | 收 3 张"下次先做什么" | 写一句话 |

变式再测（点一）
给一段 200 字课外散文，要求只写一句判断，且必须带引文。
评分：有判断 1 分，引文准确 1 分，两者扣合 1 分。

二次作答：请第 3 题原答错的三位同学重答，当场对比前后。

补偿作业（15 分钟内）
三道同结构小段，每题只写一句"判断 + 引文"。

板书
错在哪 → 为什么 → 怎么改 → 再来一次
```

## 6. 异常处理

| 异常 | 处理 |
|---|---|
| 没有得分率数据 | 按 W6 的错因占比选点，写明"按错因占比选点，非按得分率" |
| 错例涉及学生隐私 | 去姓名、去班级、改动词句细节，保留错误结构 |
| 学生要求"直接给答案" | 先给路径再给答案，答案放最后 2 分钟 |
| 讲评后仍大面积错 | 判定为目标或前置知识问题，回 W2 修订目标，不重复讲同一道题 |
| 教师想讲完整张卷 | 说明"讲完不等于讲会"，给两点方案 + 其余自查清单 |

## 7. 必要依赖

- W6 产出的诊断简报（强依赖，无此则本工序质量不可控）
- `references/exam-blueprint.md`（同类题结构）
- `references/essay-rubric.md`（作文讲评维度）
- `references/delivery-spec.md`（讲评稿打印版式）

## 8. 与其他工作流的关系

- **上游**：W6 诊断简报。
- **下游**：补偿作业回 W4 出题单；变式再测题回 W5 入下一次测验；再测结果回 W6 形成第二轮诊断。
- **闭环**：本工序是整条链的收口，也是下一轮的起点。若同一错因连续两轮未改善，回 W2 检查目标设定。
