# W8 交付闸门

## 1. 任务职责

任何成品出手前的最后一道关。六项硬检，任一项不过就打回对应工序重做，不许"先交付再说"。

这一道工序不生产内容，只做判定和说明。判定的结果必须写出来，包括没过的项。

## 2. 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 待交付成品 | 是 | 教案／题单／试卷／简报／讲评稿／课件 |
| 对应工序号 | 是 | 用于打回定位 |
| 教师原始需求 | 是 | 用于核对是否答非所问 |

## 3. 执行步骤

逐项过六关，每关给"过／不过／待核实"三种结论之一。

**第一关 学科正确**
- 译文、注释、字词解释逐条核；文言翻译以直译为主，意译处标注。
- 答案与文本对得上；赏析不贴空标签（说"借景抒情"必须指出哪句景、哪份情）。
- 拿不准的标"待核实"，不硬给。**标了待核实的项不算通过，算未核实。**

**第二关 四者一致**
- 目标动词 → 活动里有没有对应动作 → 作业里有没有练 → 评价里有没有测。
- 四者对不上，先改目标，不许改评价去迁就活动。

**第三关 分值自洽**
- 各题分值合计等于满分。
- 主观题采分点之和等于该题分值。
- 时间估算不超过考试时长（按每分钟 1.2 分估阅读题、作文按 50 分钟估）。

**第四关 引用可溯**
- 真题标年份与卷别。
- 引用他人题目标"改编自"。
- 原创标"原创"。
- 教材篇目、单元归属与 `references/textbook-index.md` 一致；该文件标"待核"的，此处同样标。

**第五关 黑白可打印**
- 纯黑文字，不依赖颜色区分信息。
- 字号不小于小四（12pt），行距 1.4—1.6。
- 表格不跨页断行；每页留装订边。
- A4 纵向；横向表格单独成页。

**第六关 隐私**
- 无学生姓名、学校、班级、学号原值。
- 一律用"学生 A""1 号"。
- 成绩数据只用于本次，不写入任何长期文件。

## 4. 判断条件

| 检查结果 | 处理 |
|---|---|
| 六项全过 | 交付，附交付说明 |
| 有一项"不过" | 打回对应工序，说明改什么，不出成品 |
| 有"待核实"项 | 可交付，但必须在交付说明里单列"未核实清单"，不许混在正文里 |
| 成品与教师原始需求不符 | 退回 W1 重定工序，不修补 |
| 教师明确要求"就这样吧，先给我" | 交付，但把未过项写在交付说明第一行，不隐藏 |

## 5. 输出格式

```
【交付说明】
成品：必修上第七单元测 试卷 + 答案 + 细目表（3 个文件）
自检结论
  学科正确    过（文言 2 处译法已核，见答案第 7 条）
  四者一致    过
  分值自洽    过（100 = 6+4+8+8+10+40+24）
  引用可溯    过（全部原创，页脚已标）
  黑白可打印  过（A4，小四，表格未跨页）
  隐私        过（无学生信息）

未核实清单
  1 教材第 6 课第二篇在不同印次有差异（《文氏外孙入村收麦》／《插秧歌》），本次按"插秧歌"命默写题，请你核对本校教材印次。

教师复核项
  1 作文 40 分按"内容 15／表达 15／发展 10"配比，若本校用 40 分四等量规，请替换。
  2 第 5 题定为区分题，若班级整体偏弱，可下调 2 分。

可调整点
  课时紧可删第 4 题（8 分），总分改 92，需另调细目表。
```

## 6. 异常处理

| 异常 | 处理 |
|---|---|
| 成品是图片或课件，无法核文字 | 核结构与来源，文字项标"未逐字核对" |
| 教师提供了本校评分标准 | 以本校标准为准，覆盖默认量规，并注明"按校标" |
| 发现前一工序有硬错误 | 直接退回，不在本工序修补 |
| 无法判断是否超纲 | 查 `references/curriculum-map.md`；仍未定的标"待核实"，不算过 |

## 7. 必要依赖

- `references/delivery-spec.md`（版式细则）
- `references/textbook-index.md`（篇目核对）
- `references/curriculum-map.md`（超纲判断）

## 8. 与其他工作流的关系

- **上游**：W2—W7 任一工序的成品。
- **下游**：交付给教师；教师反馈回 W1 开启新一轮。
- **强制**：本工序不可跳过。教师主动说"不用检查"时，仍执行，只把结论压缩为一行。
