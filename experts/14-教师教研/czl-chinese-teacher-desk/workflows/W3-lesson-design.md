# W3 课时备课

## 1. 任务职责

出一份能直接进教室的教案，不是教学设计论文。判据只有一条：教师拿着它，不用再想"这一环节让学生干什么"。

教案里每个活动都必须写清四件事：学生做什么、教师做什么、几分钟、怎么知道学生会了。

## 2. 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 篇目 | 是 | 篇名；群文课给多篇 |
| 课型 | 否 | 精读／自读／群文／写作／复习（默认精读） |
| 课时 | 否 | 默认 1 课时（40 或 45 分钟，未说按 40） |
| 学情 | 否 | 默认平行班常规 |
| 单元目标 | 否 | 由 W2 给；未做 W2 时由本工序自行对齐课标 |
| 教材版本 | 否 | 默认统编版 |

## 3. 执行步骤

1. **定课时目标。** 1—2 条，不超过 2 条。每条一个可观测动词 + 一个可交付的结果。写不成"学生能……"的句子，就是目标没想清。
2. **找"这一篇非教不可的一点"。** 一句话回答：换一篇别的文章，这个点上不出。找不到，说明这一课可以并入整合课。
3. **设计主问题。** 一个问题贯穿全课，必须是有争议或需证据的，不能是"本文写了什么"。
4. **搭三级问题链。** 主问题下挂三层：
   - 第一层：找得到（定位、复述、圈画）
   - 第二层：说得清（概括、比较、归纳）
   - 第三层：站得住（评价、质疑、迁移）
5. **排活动表。** 每个活动四栏：学生做什么／教师做什么／时长／达成标志。时长合计不得超课时。
6. **写板书。** 结构图，不是关键词堆。板书要能看出本课的思维路径。
7. **配作业。** 只写"练什么、几道、多久"，具体题单交 W4。
8. **留反思点。** 给教师两条"下课后自己看"的观察点，如"第三层问题有没有人真的提出反对意见"。

## 4. 判断条件

| 情况 | 处理 |
|---|---|
| 自读课文 | 不出逐句讲析，出"任务单 + 点拨预案"，教师只在卡点处出手 |
| 群文课 | 先定 2—3 个比较维度，再选文；不按篇依次讲 |
| 文言文 | 翻译与字词不占满堂，字词处理不超过课时 40%，其余给诵读、梳理、探究 |
| 诗歌 | 走"意象—意境—手法—情感"四步，但四步不平均用力，按本篇最突出的一点重锤 |
| 作文指导课 | 走"例文诊断—提炼方法—片段练—当堂评"四段，不讲空泛的"要深刻" |
| 课时只有 1 节而内容偏多 | 出"40 分钟压缩版"：保主问题 + 第三层，砍第一层的全班齐答，改为课前预习单 |
| 教师明确要"公开课/比赛课" | 照常出，但另附"设计说明"一页，说明每个环节的意图，供说课用 |

## 5. 输出格式

```
【教案】《故都的秋》 精读 2 课时（第 1 课时）

课时目标
1 找出文中五处对比性景物，说明各自落在哪个感官上
2 用"以我观物"解释作者为什么把"清、静、悲凉"写成一种美

这一篇非教不可的一点：同一座城，作者只挑"破、旧、微"的景来写，选景本身就是判断。

主问题：作者写故都的秋，为什么避开所有"好看"的景？

| 环节 | 学生做什么 | 教师做什么 | 时长 | 达成标志 |
|---|---|---|---|---|
| 导入 | 看两张北平秋景照片，说哪张更像文中写的 | 只问不评，把分歧留在黑板上 | 5' | 有人说"都不像" |
| 一层 找 | 圈出所有景物名词，按感官分类填表 | 巡视，记下分类分歧处 | 10' | 表格填满，分歧点被标出 |
| 二层 比 | 对比"陶然亭的芦花"与"破屋腰门前的牵牛花" | 追问：为什么不写前者 | 12' | 能说出"前者是别人的秋" |
| 三层 评 | 用一句话判断：这是写景还是写心境 | 板书两种答案，不裁决 | 8' | 有人引用原文支撑 |
| 收口 | 回看导入的两张照片，重答一次 | 对照前后答案差异 | 5' | 答案有变化且能说理由 |

板书
秋景（客观）→ 选景（过滤）→ 心境（清静悲凉）→ 审美判断
　　　　　↑ 破/旧/微

作业（交 W4 出题单）：背第 3 段；写 150 字，说你家窗外哪样东西"不好看但值得写"。

教师反思点
1 三层问题时，有没有学生真的反对"这是写心境"这个判断
2 导入的分歧到最后有没有被用上，还是被我自己收掉了
```

## 6. 异常处理

| 异常 | 处理 |
|---|---|
| 篇目不在统编版索引中 | 标注"非统编版篇目，按文本本身设计，单元归属待核"，照常出教案 |
| 教师只说篇名，其余全无 | 按精读 1 课时、平行班出，开头写明假设 |
| 要求"按某某名师课例" | 不给复刻，说明"课例有版权，我按同一思路另做设计"，出等效设计 |
| 篇目为长篇节选（如《红楼梦》回目） | 只处理所给节选，不代读全书；标注节选范围 |
| 课时冲突（目标 2 条但只够 1 条） | 砍第二条，把第二条移入作业或下课时，明确写出"移出" |

## 8. 与其他工作流的关系

- **上游**：W2 单元目标；未走 W2 时本工序自建目标并在交付说明中标注"未接单元规划"。
- **下游**：作业交 W4；本课对应的检测题交 W5；课堂实录式的共性问题交 W6。
- **闸门**：出口过 G2 一致性闸——课时目标、活动、作业三者对表，对不上先改目标。
