# W5 命题组卷

## 1. 任务职责

出一份能考、能改、能讲的卷子。流程固定为三段：先出双向细目表，再逐题命制，最后自检。三段不许合并。

判据：细目表上的每一格，卷面上都能找到对应的题；卷面上的每一道题，细目表上都能找到它考什么。

## 2. 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 考试性质 | 是 | 单元测／月考／期中期末／模拟考 |
| 考查范围 | 是 | 册次、单元、篇目，或"课内 70% + 课外 30%" |
| 满分与时长 | 否 | 默认 150 分 / 150 分钟；单元测默认 100 分 / 90 分钟 |
| 难度 | 否 | 默认易中难 3:5:2 |
| 题型偏好 | 否 | 如"不要选择题""要有情境任务" |
| 是否需要答题卡 | 否 | 需要则另排 |

## 3. 执行步骤

1. **定结构。** 按考试性质选卷面结构：
   - 模拟考、期末 → 参照 `references/exam-blueprint.md` 的新高考结构
   - 单元测 → 按"积累与运用／阅读／写作"三段压缩，课内为主
2. **出双向细目表。** 五列：题号／考点／题型／认知层级（识记·理解·分析·鉴赏·表达）／分值。另加难度列。
3. **校验细目表。** 四查：分值合计等于满分；考点覆盖全部单元目标；难度配比符合设定；认知层级不集中在识记。
4. **逐题命制。** 原创为主。情境化：给一个真实语境，不是干问"下列词语使用正确的是"。
5. **写答案与评分细则。** 主观题必须给采分点，采分点必须可数：答到哪几点给几分，答到意思但表述不同怎么给。
6. **自检。** 六项：答案唯一性、选项无歧义、无超纲、不与本卷他题重复、图文对应、时间估算。
7. **出命题说明。** 一页，给教研组看：考了什么、为什么这么配比、哪些题是区分题。

## 4. 判断条件

| 情况 | 处理 |
|---|---|
| 单元测 | 课内篇目占 70%，课外选文与课内同体同法 |
| 模拟考 | 严格按真题结构；选文长度、题量、分值均按真题 |
| 要求全选择题 | 只能用于识记与部分理解层；分析鉴赏层强改选择题会失真，需提示 |
| 要求"反套路" | 减少术语套答，增加"依据原文哪一句"的追问，但仍在课标范围内 |
| 文言文命题 | 课内例句 + 课外选段对照，实词虚词考点从 `wenyan-core.md` 取 |
| 默写命题 | 只从 `references/recitation-list.md` 的 72 篇中选，标篇目与作者 |
| 范围与课时明显不匹配 | 先提示"范围超出课时可覆盖量"，再按比例缩范围，不擅自删目标 |

## 5. 输出格式

```
【双向细目表】高一语文 必修上 第七单元测（100 分 / 90 分钟）

| 题号 | 考点 | 题型 | 层级 | 难度 | 分值 |
|---|---|---|---|---|---|
| 1 | 字音字形（课内 3 篇） | 选择 | 识记 | 易 | 6 |
| 2 | 写景句的感官分类 | 填空 | 理解 | 易 | 4 |
| 3 | 《故都的秋》选景意图 | 简答 | 分析 | 中 | 8 |
| 4 | 《赤壁赋》主客问答逻辑 | 简答 | 分析 | 中 | 8 |
| 5 | 课外散文比较阅读 | 简答 | 鉴赏 | 难 | 10 |
| 6 | 景物描写片段 | 写作 | 表达 | 中 | 40 |
| ... | | | | | |

分值合计 100 ✔｜考点覆盖 6/6 单元目标 ✔｜易中难 32:52:16（设定 3:5:2）✔

【试卷】……（略，另附）
【答案与评分细则】
3 题：①指出"清、静、悲凉"三词（3 分，各 1）②说明与选景的关系，须举出至少一处"破/旧/微"的景（3 分）③结论落到"选景即心境"（2 分）。意思对即可，未举原文例最多 5 分。
【命题说明】
区分题：第 5 题。设在此处是因为……（一句话）
```

## 6. 异常处理

| 异常 | 处理 |
|---|---|
| 教师只给"出套卷子"，范围全无 | 按最近单元 + 课内 70% 出，开头标假设 |
| 要求的满分与题量不匹配 | 给出两套配比方案让教师选，不硬凑 |
| 需要引用真题 | 标年份卷别；记不清年份的，改写并标"改编"，不标真题 |
| 选文需要原文 | 只选公版或自撰短文；当代作家作品需授权，改自撰或标"教师自备选文" |
| 要求出答案卡 | 另排，题号与卷面严格对应 |

## 7. 必要依赖

- `references/exam-blueprint.md`（结构、题型、分值、考点）
- `references/recitation-list.md`（默写）
- `references/wenyan-core.md`（文言考点）
- `references/essay-rubric.md`（作文题与评分）
- `references/delivery-spec.md`（试卷与答题卡版式）

## 8. 与其他工作流的关系

- **上游**：W2 单元目标（考点必须来自目标）、W4（错题集中的能力点优先入卷）。
- **下游**：卷子交 W6 批阅；批阅结果交 W7 讲评。
- **闸门**：出口过 G2（考点与目标一致）与 W8 的分值自洽项。
