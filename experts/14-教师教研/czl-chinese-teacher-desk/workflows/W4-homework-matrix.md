# W4 作业设计

## 1. 任务职责

把"分层作业"从口号变成一张能发下去的题单。分层不是把同一道题改难改易，是三个层次练三种不同的东西。

产出必须能回答三个问题：练的是哪条目标、每层多长时间、不做的部分怎么取舍。

## 2. 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 对应课时或单元目标 | 是 | 由 W2/W3 给；未给则由本工序先提炼三个能力点 |
| 班级层次 | 否 | 默认平行班（三层人数约 3:5:2） |
| 可用时间 | 否 | 默认课后 20 分钟 + 早读 10 分钟 |
| 是否周末／假期 | 否 | 是则加长周期任务 |
| 是否需要答案 | 否 | 默认给 |

## 3. 执行步骤

1. **定三个能力点。** 从目标里拆，每个能力点写成"能做什么"，不写"掌握……"。
2. **填矩阵。** 三层 × 三维，共九格，每格至少一道题：
   - 层：基础巩固（全班必做）／能力提升（多数做）／迁移挑战（选做）
   - 维：识记理解／分析鉴赏／表达运用
3. **配比与限时。** 基础 50%、提升 35%、挑战 15%；总时长不超过可用时间。每道题后标预计用时。
4. **写答案与批改要点。** 不只给答案，给"批这道题看什么"：采分点、常见错法、给分弹性。
5. **给取舍建议。** 明确"时间不够时先砍哪一道"，以及"哪一道不能砍"。
6. **标来源。** 原创标"原创"；改编标"改编自……"；引真题标年份卷别。

## 4. 判断条件

| 情况 | 处理 |
|---|---|
| 总时长超出可用时间 20% 以上 | 砍挑战层，并把砍掉的原因写出来 |
| 毕业班 | 基础层比例提到 60%，挑战层改为"限时套题中的一道" |
| 高一起始阶段 | 降低分析鉴赏比重，加识记与梳理 |
| 单元含整本书阅读 | 加"持续阅读任务"：每日页数 + 一句话批注，不计入当日时长 |
| 教师要求"不要抄写类" | 去掉机械抄写，改为"改错""重写段落""给同学批注" |
| 无现成题可用 | 全部原创，并在题单页脚标"原创题，可校内使用" |

## 5. 输出格式

```
【作业矩阵】《故都的秋》第 1 课时

能力点
A 能按感官给景物分类
B 能说出选景与心境的关系
C 能把"不好看但值得写"的感觉写成 150 字

|  | 识记理解 | 分析鉴赏 | 表达运用 |
|---|---|---|---|
| 基础（必做） | 默写第 3 段（5'） | 填感官分类表（4'） | —— |
| 提升（多数） | —— | 说明作者为何不写"陶然亭芦花"（6'） | 仿写一句"破屋秋景"（5'） |
| 挑战（选做） | —— | —— | 150 字：你家窗外"不好看但值得写"的东西（10'） |

总计：必做 9'，提升 11'，挑战 10'。全班底线 20 分钟内可完成。

批改要点
- 默写：错一字即扣，重点看"息列索落""疏疏落落"两组叠词
- 分类表：允许"触觉/味觉"归并，只要理由能自圆
- 仿写：不看辞藻，看有没有具体名词

取舍：时间不够先砍提升层的仿写，基础层默写不能砍。

来源：全部原创。
```

## 6. 异常处理

| 异常 | 处理 |
|---|---|
| 目标本身模糊，拆不出能力点 | 退回 W3/W2 改目标，不硬拆 |
| 教师给的可用时间极短（<10 分钟） | 只留一层一题，明确"今日只练一件事" |
| 三层人数严重不均（如全班都做挑战） | 提示"分层名存实亡"，建议改按错题分组 |
| 需要跨学科作业（如语文+历史） | 说明本工序只出语文部分，跨学科需另行协调 |

## 8. 与其他工作流的关系

- **上游**：W3 课时目标、W2 单元目标。
- **下游**：作业的批改结果进 W6，作为诊断证据之一；错误集中的题进 W7 做变式再测。
- **回路**：若某层作业连续两次全对或全错，说明分层位置错了，回 W4 重设层级。
