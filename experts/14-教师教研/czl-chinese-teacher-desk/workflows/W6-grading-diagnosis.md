# W6 批阅诊断

## 1. 任务职责

把"一篇篇改"升级为"改完能看出班级病灶"。

两件事必须都做：单份给到具体批注（学生拿到能改），班级给到共性问题（教师拿到能讲）。只做前者是批改，不是诊断。

## 2. 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 学生作答 | 是 | 文本或图片；可多份 |
| 题目与参考答案 | 否 | 有则按采分点批；无则先建采分点 |
| 评分标准 | 否 | 无则用高考等级量规 |
| 班级人数 | 否 | 影响是否做统计结论 |
| 是否需要分层名单 | 否 | 需要则用编号，不用姓名 |

## 3. 执行步骤

1. **建采分点。** 无答案时先拆：这道题答到哪几点算全对，每点几分。采分点必须可数。
2. **单份批注。** 每份写三行：得分点（拿到了什么）、失分点（丢在哪）、错因（归到下面六类之一）。
3. **错因归类。** 固定六类，不新增：
   - 审题偏差（问东答西）
   - 信息定位失败（找不到原文依据）
   - 理解偏差（读懂了但理解错）
   - 术语缺失（知道意思但说不出概念）
   - 表达不规范（懂但写不成得分句）
   - 时间不足（会但没写完）
4. **作文另走量规。** 四维：内容／结构／语言／发展等级。每维给档不给小数点；总分区间给窄一点，定等交教师。
5. **班级聚类。** 只做三件事：哪一类错因占比最高、它的典型表现是什么、举一个例证（去掉身份信息）。
6. **给干预建议。** 针对占比最高的两类错因，各给一条"讲什么 + 练什么 + 再测什么"。

## 4. 判断条件

| 情况 | 处理 |
|---|---|
| 样本少于 8 份 | 只做个体诊断，明确写"样本不足，不做班级统计结论" |
| 样本 8—29 份 | 给错因占比与典型表现，不给分数段分布结论 |
| 样本 30 份以上 | 可给分数段、板块得分率、分层名单（编号） |
| 作文与阅读混批 | 分开统计，不合并成一个"语文能力"结论 |
| 图片模糊不可辨 | 标〔待补〕，该份不入统计，不猜内容 |
| 无评分标准 | 用高考量规，写明"等次请按本校标准复核" |
| 教师只要"打个分" | 仍给三行批注，但压缩班级部分为一句话 |

## 5. 输出格式

```
【单份批注】1 号（阅读第 3 题，8 分，得 5 分）
得分点：指出了"清、静、悲凉"三词
失分点：未举原文例；结论停在"写出寂寞"，未落到"选景即心境"
错因：信息定位失败（未回原文找依据）

【班级诊断简报】共 42 份，有效 41 份

错因占比
信息定位失败 46% ｜表达不规范 27% ｜理解偏差 15% ｜审题偏差 7% ｜术语缺失 5% ｜时间不足 0%

主要问题（两类）
一 不回原文找依据：多数答案有判断无引文。典型表现：写"作者很孤独"，不写"从'破屋''漏下来的日光'可见"。
二 结论句写不成：知道意思，写成"表达了作者的感情"这类空句。

干预
讲：一节课只讲"判断 + 引文 + 推论"三句结构（对应 W7）
练：三道题，每题只要求写一句带引文的判断（对应 W4）
再测：同结构新选段一道，两周后（对应 W5）

不作结论项：本次未给各题得分，板块得分率无法计算。
```

## 6. 异常处理

| 异常 | 处理 |
|---|---|
| 成绩表缺各题得分，只有总分 | 只算均分、极值、分数段；声明板块得分率无法计算 |
| 学生答案与题目对不上（张冠李戴） | 退回确认，不强行批 |
| 出现学生姓名、学校、班级 | 立即改为编号，回复中不重复原信息 |
| 要求"给个排名" | 只给分层（A/B/C 层）与编号，不给名次序列 |
| 要求预测高考分数 | 明确拒绝预测，说明样本与口径不足 |
