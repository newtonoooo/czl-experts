# 卓识教育-高中语文老师助手

面向高中语文教师的**教学工作台**。不是一个"什么都能问"的聊天助手，而是按一条完整的教学链干活：单元怎么规划、这一课怎么上、作业怎么分层、卷子怎么出、批完怎么看、考完怎么讲。

- 包标识：`czl-chinese-teacher-desk`
- 版本：1.0.0
- 开发者：虫志龙（47190078@qq.com）
- 类型：Agent 型（单专家）
- 分类：15-Education

## 它和常见的"教案生成器"有什么不同

四件事：

1. **有单元层。** 先出单元施工图（目标—评价—活动三列对齐），再出单课教案。单课目标必须从单元目标长出来。
2. **有作业层。** 分层作业做成 3 层 × 3 维的九格矩阵，每格配题量与限时，并给出"时间不够先砍哪道"。
3. **有讲评层。** 从诊断简报直接生成讲评课：错例—归因—正解路径—变式再测四步，一节课只讲三个点。
4. **有闸门。** 任何成品交付前过六项硬检（学科正确、四者一致、分值自洽、引用可溯、黑白可打印、隐私）。不过就退回重做，不交付。

## 八道工序

| 序 | 工序 | 一句话 |
|---|---|---|
| W1 | 接单定位 | 把一句口语需求翻译成工序单 |
| W2 | 单元规划 | 目标—评价—活动三列对齐的施工图 |
| W3 | 课时备课 | 能直接进教室的教案，每个活动写清四件事 |
| W4 | 作业设计 | 分层作业矩阵 + 取舍建议 |
| W5 | 命题组卷 | 细目表 → 逐题 → 六项自检 |
| W6 | 批阅诊断 | 单份批注 + 班级共性聚类 |
| W7 | 讲评补偿 | 讲评课教案 + 变式再测 + 补偿作业 |
| W8 | 交付闸门 | 六项硬检，不合格不放行 |

## 随身资料（8 份）

`references/` 下有课标库、教材库、评量库共 8 份结构化资料：18 个学习任务群、五册教材篇目索引、新高考卷结构、72 篇背诵篇目、文言实词虚词与句式、作文量规、输入输出规范、资料包索引。

**不含教材原文。** 教材、教辅、当代作品的著作权归各自权利人，本包只做索引与教学设计，不复制原文。

## 怎么用

直接说你要干什么，越具体越好：

- "帮我把必修上册第七单元做成单元整体设计，含课时分配和评价任务"
- "《祝福》第二课时怎么上，重点是看客群像"
- "给我一份《故土》的分层作业，20 分钟以内"
- "按这个双向细目表出一份高一文言文阅读题"
- "这是月考成绩，帮我做学情诊断，再设计一节讲评课"

它会先给你一张工序单，确认后开工。产出默认带三样：成品本体、教师复核清单、一句追问。
