# 更新日志

本文件的格式参照 Keep a Changelog，版本号遵循语义化版本。

## [1.0.0] — 2026-11-01

首个发布版本。独立开发，非对现有专家包的改名或复刻。

### 新增

**架构**

- 「三库八序」工作流架构：课标库／教材库／评量库三库支撑，W1—W8 八道工序串成教学闭环。
- 三道闸门：G1 输入闸（W1）、G2 一致性闸（W2—W5 之后）、G3 交付闸（W8）。
- 闭环设计：W6 诊断 → W7 讲评 → 补偿作业回 W4、再测题回 W5、再测结果回 W6，同一错因连续两轮未改善则回 W2 修目标。

**工序卡（8 张）**

- W1 接单定位：口语需求 → 工序单，含八类缺口默认档。
- W2 单元规划：大概念 + 三条素养目标 + 两个表现性评价任务 + 分块课时 + 处理理由；活动单元、整本书单元、写作单元三条分支。
- W3 课时备课：主问题 + 三级问题链 + 四栏活动表（学生做什么／教师做什么／时长／达成标志）+ 板书路径 + 两条教师反思点。
- W4 作业设计：3 层 × 3 维九格矩阵，配比 50/35/15，逐题标限时，给取舍建议。
- W5 命题组卷：双向细目表五列 + 四查校验 + 六项自检 + 命题说明。
- W6 批阅诊断：六类固定错因 + 单份三行批注 + 班级三类共性聚类 + 样本量分档（<8 不做统计结论）。
- W7 讲评补偿：三点选择标准 + 四步讲评结构 + 二次作答 + 变式再测 + 补偿作业。
- W8 交付闸门：六项硬检，逐项给「过／不过／待核实」，未核实项单列。

**资料库（8 份）**

- `curriculum-map.md`：四素养、18 个学习任务群（含学分与学段归属）、学业质量五级。
- `textbook-index.md`：统编版五册（必修上下、选必上中下）全单元篇目索引，标注自读课文与 3 处印次差异。
- `exam-blueprint.md`：新高考卷结构、七板块考点与设问、校本卷模板、12 条命题自检、时间估算。
- `recitation-list.md`：72 篇背诵篇目（32 文 + 40 诗词曲），区分 60 篇高考常规范围。
- `wenyan-core.md`：120 实词清单、18 虚词用法、8 类特殊句式、翻译采分点六步法、五类常见失分。
- `essay-rubric.md`：作文等级量规、升格五步、班级共性问题库 10 类、评语三条硬要求。
- `delivery-spec.md`：输入最小集、输出三件套、文件命名、A4 黑白版式、降级规则。
- `materials-index.md`：资料清单、来源、校核状态、明确未带的六类内容。

**工具**

- `bin/check_package.py`：目录版与压缩包版双模自检，覆盖元数据、引用、头像、包结构、重名。
- `bin/make_avatar.py`：纯标准库头像加工，支持裁剪去水印、面积平均缩放到 512×512、输出 8 位 RGB。

**文档**

- 产品规格说明、使用说明、平台展示文案、文件清单与开发记录、功能测试报告、商业发布风险清单、头像与品牌规范、资料包索引，共 8 份。

**视觉**

- 原创头像 `avatars/expert.png`：暖色扁平插画，经验丰富的语文教师形象，墨蓝背景，512×512，8 位 RGB，约 397KB，无文字无水印。

### 已知限制

- 教材印次差异 3 处（必修上第 6 课第二篇、选必下第 7 课第一篇等），已在资料中标注〔待核〕，需教师按本校在用教材核对。
- 作文扣分细则、默写范围存在省际差异，默认按通行框架，需教师用本省细则覆盖。
- 未在真实课堂做对照实验，教学效果无实证数据；本包不承诺提分。
- 未做多客户端导入实测，仅做结构与格式校验（详见功能测试报告「未验证事项」）。
