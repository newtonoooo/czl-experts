## 三、讲评课教案（40 分钟）

### 目标

1. 能在答案中写出"判断 + 引文 + 推论"三句结构
2. 能把"表达了作者的感情"这类空句改写成有具体所指的结论句

### 时间表

| 时段 | 环节 | 教师动作 | 学生动作 |
|---|---|---|---|
| 0—3′ | 整体交代 | 只报数据，不评价努力程度 | 对照自己的卷子找出第 3、4 题 |
| 3—14′ | 点一 第 3 题 | 投一份错答，问"他凭什么这么说" | 找出错答缺的那一步 |
| 14—25′ | 点二 第 4 题 | 给"三维定锚法"，示范一次 | 用新选段重做一遍 |
| 25—35′ | 点三 表达 | 投三句本班原句（匿名），排序并说理由 | 改自己答案里的一句 |
| 35—40′ | 收口 | 收 3 张纸条，念出来 | 写一句"下次遇到这类题我先做什么" |

### 点一：第 3 题（得分率 38%）——有判断无引文

**错例（匿名，原样呈现）**

> 作者写这些景物是为了表达他很孤独。

**归因追问**（不问"对不对"，问"凭什么"）

1. 这句话有没有告诉你，作者是从哪一句读出"孤独"的？
2. 如果换成"表达了作者的悲伤"，能不能也这样说？为什么都能说？
3. 结论：**能套在任何一篇上的答案，等于没答。**

**正解路径（三步，板书）**

```
判断  →  引文  →  推论
他很孤独｜"破屋""漏下来的日光"｜破与漏，是他自己挑的景，不是客观的北平
```

**变式再测（当堂 6 分钟）**

给一段 200 字课外散文（另附）。要求：只写一句判断，且必须带引文。
评分：有判断 1 分，引文准确 1 分，两者扣合 1 分。

### 点二：第 4 题（得分率 41%）——找不到比较维度

**给方法：三维定锚**

| 维度 | 问什么 |
|---|---|
| 写了什么 | 两文的景物／人物／事件是否同类 |
| 怎么写 | 视角、顺序、句式、修辞的差异 |
| 为何写 | 两文各自的写作目的与读者 |

操作：三个维度里挑**差异最大**的一个展开，另两个各一句带过。不要三个平均用力。

**示范（教师做一次，5 分钟）**

以《故都的秋》与《济南的秋天》为例，选"怎么写"维度：前者用短句与破折号断开节奏，后者用长句铺陈。

**变式再测（当堂 5 分钟）**

另给两段同题短文，只要求写出"三维"中差异最大的那一维，并说明理由。

### 点三：表达不规范（跨题，27%）——空句改实句

**投三句本班原句（匿名），让学生排序**

```
A 表达了作者对故乡的思念之情。
B 结尾把镜头从院子推到院外那棵枣树，思念落在了具体的东西上。
C 作者很想念故乡。
```

排序：B > A > C。理由：B 有动作、有对象；A 有术语但无对象；C 连术语都没有。

**改写公式（板书）**

```
表达了 ____ 对 ____ 的 ____，通过 ____ 这一处写出来。
```

**当堂练（3 分钟）**：把 A 句按公式改写一次。

### 板书

```
一 判断 + 引文 + 推论        ← 第 3 题
二 写了什么 / 怎么写 / 为何写  ← 第 4 题
三 空句 → 实句：谁 对 谁 的 什么，通过哪一处
```

### 补偿作业（15 分钟内，交 W4 出题单）

1. 三段课外短文，每段只写一句"判断 + 引文"。
2. 两句空句改写，用公式。
3. 不掺新内容，不要求整篇作答。

### 收口（5 分钟）

每人写一句："下次遇到'分析表达效果'这类题，我先做什么。"
收 3 张念出来，只念动作，不念名字。
