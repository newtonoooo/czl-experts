## 一、产品定位

一句话：**给高中语文老师的教学流水线，不是给老师的问答机器人。**

定位的三条边界：

1. **服务对象是教师，不是学生和家长。** 所有输出都是教师能直接拿去上课、印发、讲评的东西；不写劝学话术，不做心理安抚，不承诺提分。
2. **做完整闭环，不做功能菜单。** 从单元规划一路做到试卷讲评，每一步的产出是下一步的输入。
3. **做"能交出去"的成品，不做"帮你想想"的建议。** 每个成品过六项硬检才交付。

## 二、目标用户

| 画像 | 特征 | 最痛的点 | 主要用哪几道工序 |
|---|---|---|---|
| 教龄 1—3 年的新教师 | 备课靠搜教案，课时常超时 | 不知道一节课的"量"该多大；目标写不准 | W2、W3、W4 |
| 教龄 5—15 年的骨干教师 | 单篇备课快，单元与命题费时 | 单元整体设计、命题配比、讲评课没抓手 | W2、W5、W7 |
| 备课组长／教研组长 | 要统一进度、统一测评 | 组内标准不一，缺少可复用的模板与量规 | W2、W5、W6、W8 |

不服务的对象：学生（另有一对一家教类产品）、家长、非语文学科教师、升学规划咨询。

## 三、实际使用场景

| 场景 | 触发时刻 | 输入 | 期望产出 |
|---|---|---|---|
| 开学前单元备课 | 开学前一周 | 册次 + 单元号 | 单元施工图（目标/评价/课时） |
| 前一晚备课 | 上课前一天晚上 | 篇目 + 课时 | 可上课的教案 + 作业 |
| 出单元测 | 单元结束前 | 范围 + 分值 | 细目表 + 卷 + 答案 |
| 月考后批改 | 考完当晚 | 学生答卷 + 答案 | 单份批注 + 班级简报 |
| 讲评课准备 | 讲评课前 | 诊断简报 | 讲评课教案 + 变式题 |
| 公开课／比赛课 | 提前两周 | 篇目 + 要求 | 教案 + 设计说明 |
| 教研组共享 | 学期初 | 本校模板 | 统一格式的成套材料 |

## 四、要解决的问题

### 4.1 四个核心痛点

1. **单元备不动。** 单篇能备，合起来不知道这个单元要让学生长成什么样。
2. **四张皮对不上。** 目标、活动、作业、测评各写各的，学生练的不是考。
3. **讲评课没抓手。** 考完对答案，一节课过去，同类题下次还错。
4. **批完只记得最差那两篇。** 班级共性问题说不清，干预靠感觉。

### 4.2 同类工具的五个空白（本产品的补强点）

| 空白 | 常见工具的做法 | 本产品做法 |
|---|---|---|
| 缺单元层 | 直接生成单篇教案 | W2 先出单元施工图，W3 的课时目标必须从单元目标长出来 |
| 缺教—学—评一致性 | 四个部分分别生成，不校验 | G2 一致性闸：目标动词→活动→作业→评价逐项对表，对不上先改目标 |
| 缺作业分层方法 | 说"分基础/提升/拓展"，不给矩阵 | W4 出 3 层 × 3 维九格矩阵，每格配题量与限时，给取舍顺序 |
| **缺试卷讲评** | 基本没有 | W7 专设：错例—归因—正解路径—变式再测四步，一节课三点，含二次作答 |
| 缺班级层面聚类 | 逐篇批改，无班级结论 | W6 固定六类错因 + 三类共性聚类 + 按样本量分档（<8 份不下班级结论） |

## 五、功能需求

### 5.1 功能清单

| 编号 | 功能 | 对应工序 | 优先级 |
|---|---|---|---|
| F1 | 需求识别与工序编排 | W1 | P0 |
| F2 | 单元整体设计（含活动单元、整本书、写作单元三分支） | W2 | P0 |
| F3 | 课时教案（含自读、群文、文言、诗歌四类差异处理） | W3 | P0 |
| F4 | 分层作业矩阵 | W4 | P1 |
| F5 | 命题组卷（细目表 + 逐题 + 自检） | W5 | P0 |
| F6 | 批阅与班级诊断 | W6 | P0 |
| F7 | 试卷讲评课设计与补偿 | W7 | P0 |
| F8 | 交付质检 | W8 | P0 |
| F9 | 课标／教材／评量三库查询 | references | P0 |
| F10 | 打印稿与课件大纲产出 | delivery-spec | P1 |

### 5.2 非功能需求

| 维度 | 要求 |
|---|---|
| 学科正确性 | 译文、答案、篇目归属不得出错；不确定标"待核实" |
| 可追溯 | 每条事实判断标 K/R/E/I；真题标年份卷别 |
| 可复核 | 每次交付附教师复核清单，列明 AI 不替教师定的项 |
| 隐私 | 不用学生真名、学校名、班级名；成绩数据不落盘 |
| 可打印 | A4 黑白可读，字号≥小四，表格不跨页 |
| 一致性 | 目标—活动—作业—评价四者对表 |

## 六、输入规格

### 6.1 最小输入集

| 工序 | 必需 | 可默认 |
|---|---|---|
| W2 | 册次 + 单元号 | 课时、学情 |
| W3 | 篇目 | 课型、课时、版本 |
| W4 | 目标或（篇目 + 课时） | 层次、时长 |
| W5 | 考试性质 + 范围 | 满分、时长、难度 |
| W6 | 学生作答 | 答案、评分标准 |
| W7 | 诊断简报 | 课时 |

### 6.2 输入形态

文本、粘贴、图片（作文/试卷/教材页）、表格（成绩）、电子教材（PDF/截图）。

### 6.3 输入降级（八档，仅在内部使用，不向教师输出编码）

| 缺口 | 默认档 | 交代方式 |
|---|---|---|
| 册次缺失 | 必修上册 | 开头注明假设 |
| 课时缺失 | 1 课时 | 同上 |
| 班型缺失 | 中等平行班 | 同上 |
| 课型缺失 | 精读 | 同上 |
| 作文无标准 | 高考量规 | 提示教师定等 |
| 成绩缺列 | 只用可用列 | 声明统计局限 |
| 图片不清 | 标〔待补〕 | 请补文字 |
| 真题年份不明 | 只解析可解析部分 | 标来源待核 |

## 七、输出规格

### 7.1 三件套（强制）

1. 成品本体
2. 教师复核清单
3. 一句追问

### 7.2 形态

- 屏幕稿：Markdown，标题不超三级，表格优先。
- 打印稿：A4 黑白，优先 `.docx`，降级 `.md` 并说明。
- 课件：按"封面—目标—逐环节—小结—作业"的 .pptx；降级为逐页大纲。

### 7.3 文件命名

`{类型}-{册次}-{单元}-{篇目}-{课时}.docx`，详见 `references/delivery-spec.md`。

## 八、通用处理步骤（编排逻辑）

```
教师输入
  ↓
W1 接单定位 —— 抓动词 → 定工序 → 抽参数 → 列缺口 → 排顺序
  ↓
（按需）W2 单元规划 —— 任务群 → 大概念 → 三目标 → 两评价任务 → 课时
  ↓
W3 课时备课 / W4 作业设计 / W5 命题组卷 —— 三者的目标同源
  ↓
G2 一致性闸 —— 四者对表，不过则改目标
  ↓
W6 批阅诊断 —— 六类错因 → 单份批注 → 班级聚类 → 干预建议
  ↓
W7 讲评补偿 —— 三点 → 四步 → 二次作答 → 变式再测 → 补偿作业
  ↓
W8 交付闸门 —— 六项硬检 → 交付说明（含未核实清单）
  ↓
回 W6 第二轮诊断（闭环）
```

## 九、工具能力与技术接口

| 能力 | 用途 | 依赖 |
|---|---|---|
| 文件读取 | 读知识库、读教师上传的文本 | 平台内置 |
| 图片识别 | 识别作文、试卷、教材页 | 平台内置 |
| 文档生成 | 生成可打印 .docx | 平台文档技能 |
| 演示生成 | 生成 .pptx 课件 | 平台演示技能 |
| 表格处理 | 解析成绩表 | 平台内置 |
| 不依赖外部网络接口 | 所有知识内置，离线可用 | — |

设计取舍：**不接外部题库与在线组卷接口**。原因：题库版权风险高，接口稳定性不可控，且会把产品绑定到第三方。命题一律原创。

## 十、质量、速度、稳定性指标

| 指标 | 目标 | 当前状态 |
|---|---|---|
| 学科事实准确率 | 抽检 100% 无硬错 | 已做资料交叉核对；生成内容需教师复核，未做大规模抽检 |
| 结构完整率 | 交付物三件套齐全率 100% | 由 W8 闸门强制 |
| 单工序响应 | 常规教案/题单在一次会话内完成 | 已验证（结构层面） |
| 稳定性 | 不依赖外部接口，无网络失败点 | 已满足 |
| 可打印合格率 | 100% 黑白可读 | 规范已定，实际打印未逐份验证 |

**不承诺教学效果。** 本产品无课堂对照实验数据，任何"提分"表述均不成立。

## 十一、不做什么

1. 不代写参赛作文、投稿作品、学生习作。
2. 不承诺分数、不预测高考成绩。
3. 不评价具体在职教师。
4. 不提供教材原文、教辅原题。
5. 不接小学、大学语文及非语文学科。
6. 不做升学规划咨询。
7. 不接外部题库接口。
