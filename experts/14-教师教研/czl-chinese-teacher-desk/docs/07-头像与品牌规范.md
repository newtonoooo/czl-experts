# 头像与品牌规范

## 一、视觉定位

**形象**：一位教了二十年书的语文教师。不是学者，不是主播，不是卡通吉祥物。

**要传达的三件事**：稳、有经验、手上有活。所以出现的道具是两样——一本翻旧的书（读过）和一支红笔（改过）。不要教鞭、不要奖杯、不要黑板上的公式。

**风格**：暖色扁平插画，正面半身，纯色深墨蓝背景，柔和暖光轮廓，无文字。与「卓识教育」系列其他学科保持同一画风，便于在列表中成组识别。

## 二、头像技术规格

| 项 | 规格 | 实测 |
|---|---|---|
| 文件 | `avatars/expert.png` | 已生成 |
| 格式 | PNG | PNG |
| 尺寸 | 512 × 512 | 512 × 512 |
| 位深 | 8 位 | 8 |
| 色彩类型 | RGB（2）或 RGBA（6） | RGB（2） |
| 体积 | ≤ 500 KB | 397.4 KB |
| 文字 | 无 | 无 |
| 水印 | 无 | 已裁除 |

## 三、生成与加工记录

**生成**：图像生成模型，1024 × 1024，高质量。

**Prompt（实际使用）**：

```
Professional flat-illustration avatar of a seasoned Chinese language and literature teacher,
a man in his early fifties with short neatly combed black hair and a touch of grey at the temples,
thin round metal glasses, warm composed expression with a faint knowing smile,
wearing a dark ink-blue mandarin-collar shirt under a light grey knit cardigan,
one hand holding a closed hardback book, the other holding a red marking pen,
subtle background elements of a stack of books, a folded lesson-plan folder and two faint
ink-wash mountain brush strokes, solid deep ink-blue background with soft warm rim light.
Bust shot, facing forward, perfectly centered, no text, no words, no letters, no numbers,
no watermark, clean simple background, high quality, professional, natural,
cohesive series illustration style with warm lighting and soft shadows.
```

**加工**：原图右下角有平台水印，需裁除后缩放到 512。

```bash
python bin/make_avatar.py avatars/<原图>.png avatars/expert.png --box 42,0,940,940 --size 512
```

`--box 42,0,940,940` 的含义：从 (42,0) 起取 940×940 区域，右、下各去掉 84 px，正好切掉水印区，同时保持人物居中。

**加工中发现并修正的问题**：首版缩放函数在 940→512 的非整数倍缩放时使用了统一除数，导致部分列周期性偏暗，出现竖条纹。已改为逐像素记录实际采样数后取平均，复检列均值相邻差从 12.45 降至 1.06。

## 五、为什么头像会"变成文字"（重要）

客户端在拿不到头像文件时，会用名称首字生成占位图。所以"小图标变成字"不是显示 bug，是**取图失败**。按发生概率排序：

| 序 | 原因 | 机理 | 本包的处理 |
|---|---|---|---|
| 1 | 压缩包内没有头像条目 | 客户端把 `avatar` 字段原样当相对路径解析，取不到文件就退化 | 打包后校验 zip 内 `czl-chinese-teacher-desk/avatars/expert.png` 存在 |
| 2 | `avatar` 字段为空或路径写错 | 同上 | 字段固定为 `avatars/expert.png`，无 `./` 前缀、无反斜杠 |
| 3 | 头像非 512×512 或超 500 KB | 部分端解码失败或拒绝加载 | 严格 512×512、397 KB |
| 4 | 头像带 alpha 或 16 位色深 | 旧版解码器不兼容 | 输出 8 位 RGB，丢弃 alpha |
| 5 | 打包时多套了一层目录 | 路径解析基准错位 | 压缩包顶层仅一层 `czl-chinese-teacher-desk/` |
| 6 | Windows 打包写入反斜杠路径 | zip 条目名不被识别 | 用脚本打包，条目统一正斜杠 |
| 7 | 清单目录名与客户端约定不符 | 元数据整体读不到 | 使用 `.codebuddy-plugin/plugin.json`（本机在架包的实际用法） |

**排查顺序**：解压 zip → 看 `plugin.json` 的 `avatar` 值 → 按该值在解压目录里找文件 → 找到则检查尺寸与体积，找不到则问题在打包。

`bin/check_package.py` 已把这七项做成自动检查，直接对 zip 跑一次即可。

## 六、品牌命名规范

**命名式**

```
卡片名 displayName.zh ：卓识教育-高中语文老师助手
职业头衔 profession.zh：卓识教育-高中语文老师助手
包标识 name          ：czl-chinese-teacher-desk
英文名 displayName.en：Zhuoshi Education - Senior High Chinese Teacher Assistant
```

**字符约束**：平台名称字段只接受中英文、数字、`-`、`—`。本包用半角 `-`，无空格、无 `·`、无 `/`。

**命名理由**

- 「卓识教育」为系列前缀，与系列内其他学科保持一致。
- 「高中语文」限定学段与学科，避免与小学、初中混淆。
- 「老师助手」限定服务对象是教师，与系列内面向学生和家长的「学习辅导专家」明确区分。
- 包标识不随品牌名变动，它是唯一键。

## 七、与系列内其他产品的关系（避免内部撞车）

| 产品 | 包标识 | 服务对象 | 输出 |
|---|---|---|---|
| 卓识教育-高中语文学习辅导专家 | `czl-chinese-home-tutor` | 学生与家长 | 一对一辅导方案、家庭学习计划 |
| **卓识教育-高中语文老师助手** | `czl-chinese-teacher-desk` | **教师** | **教案、试卷、作业、诊断、讲评课** |

两者功能域相邻但不重叠：前者面向"怎么教我的孩子"，后者面向"我怎么上这一节课、怎么出这张卷"。已做重名检查，`name` 与 `profession` 在市场内均无重复。

## 八、若要更换头像

1. 准备 512×512 正方形图，PNG 优先。
2. 若原图带水印或非正方形，用 `bin/make_avatar.py` 处理：

```bash
python bin/make_avatar.py 新图.png avatars/expert.png --size 512
```

3. 确认 `plugin.json` 的 `avatar` 仍为 `avatars/expert.png`。
4. 跑自检：`python bin/check_package.py .`
5. 重新打包并再对 zip 跑一次自检。
