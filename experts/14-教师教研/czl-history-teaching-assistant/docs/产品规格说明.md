## 一、目标用户与实际使用场景

### 用户画像（按优先级）

| 优先级 | 用户 | 每周在这件事上花多久 | 最痛的一点 |
|---|---|---|---|
| P0 | 高中历史任课教师（教龄 1–10 年，带 2–6 个班） | 备课 6–10 小时，批改 3–5 小时 | 时间是碎的，没有整块时间做深度设计 |
| P1 | 备课组长 / 教研组长 | 额外 3–5 小时做统一进度与命题 | 组内水平不齐，卷子难度和判分尺度都难统一 |
| P2 | 师范生 / 新入职教师 | 备课 10 小时以上 | 知道要"素养导向"，不知道具体怎么写 |
| P3 | 教培机构教研岗 | — | 需要批量产出，且要能复用 |

### 六个真实场景

**场景 1：周日晚上备课**
明天上午第一节要上《两宋的政治和军事》。手上有教材、教参、两套别人的课件，但拼不成一节自己的课。想要：45 分钟的完整流程 + 一组能用的材料 + 一份学案。

**场景 2：月考命题**
下周三月考，范围是纲要上第三、四单元。要 16 道选择 + 3 道材料题。想要：先看考点分布合不合理，再逐题出，最后有评分细则（不然两个老师判分不一样）。

**场景 3：批完两个班的材料题**
120 份卷子批完，人已经麻了。想知道：这个班到底错在哪一类，下节课 45 分钟该讲什么。想要：不用自己统计，直接给出错因分布和讲评脚本。

**场景 4：月考后教研会**
要在 20 分钟内说清这次考得怎么样、下次怎么办。想要：一张能被追问的统计表 + 三条能执行的动作。

**场景 5：小论文讲评**
学生写的小论文"看着都对，就是不给分"。想知道差在哪、怎么改。想要：按维度打分，每维说清"再往上一档缺什么"。

**场景 6：二轮复习**
要做到"唐宋变革"专题，手上材料散在纲要上第三单元和选必1 第一单元。想要：一条时间轴 + 一张阶段特征表 + 一份易混清单。

### 不服务的场景

- 大学历史专业课程、史学论文写作
- 历史小说、影视剧本的史实咨询
- 升学规划、志愿填报、录取预测
- 非历史学科（政治、地理、语文）
- 学生端的自主学习陪伴（本产品是教师工具，不是学生产品）

## 二、需要解决的问题

把上面六个场景抽象，得到五个真问题：

### 问题 1：备课的"最后一公里"

教师不缺素材，缺**把素材组织成一条教学逻辑**的时间。网上课件多，但都是别人的思路；直接放会卡，改了又不成体系。

**本质**：缺少一个"从课题到环节"的可复用结构。

### 问题 2：命题的质量不可控

手工出卷的三个失控点：
- 考点扎堆（同一单元占 40 分）
- 难度失衡（要么全班 80 分，要么全班 45 分）
- 细则缺失（"言之有理即可"等于没标准）

**本质**：缺少命题前的约束机制（蓝图）和命题后的校准机制（P 值与区分度回灌）。

### 问题 3：批改的成果不沉淀

批 120 份卷子，产出只有 120 个分数。错因分析停留在"概括能力差"这种无法执行的说法上。

**本质**：缺少固定编码，导致每次批改都是从零开始的经验判断，无法跨次累加。

### 问题 4：学情分析停在描述

"均分 62，及格率 70%"——这是描述，不是诊断。诊断要回答"谁、在哪个环节、掉了多少、下一步补什么"。

**本质**：缺少"统计量 → 归因类别 → 教学动作"的转换规则。

### 问题 5：方法论与教材脱节

很多教学法讲得很好，但落不到"这一课的第 12 分钟做什么"。

**本质**：缺少从抽象方法到具体课时的映射层。

## 三、必要的输入与预期输出

### 输入规范：任务卡

六个卡面，只有"范围"是硬门槛。

| 卡面 | 取值 | 缺失处理 |
|---|---|---|
| 学段 | 高一 / 高二 / 高三；新授 / 复习 | 默认高二新授 |
| 册次 | 纲要上/下、选必 1/2/3 | 由课题反推；反推不出才问 |
| **范围** | 单元 / 课 / 专题 / 考试范围 | **必须问到** |
| 用途 | 上课 / 作业 / 测验 / 讲评 / 留档 | 默认上课 |
| 约束 | 课时、题量、分值、难度、是否打印 | 按常规给，注明可改 |
| 已有材料 | 教材页、学生作答、成绩表、旧卷 | 有则用，无则跳过 |

### 输出规范：三件套

任何一次完整交付都包含三层，缺一层视为未完成：

| 层 | 形态 | 用途 |
|---|---|---|
| 屏幕版 | 对话内的结构化内容（表格优先） | 快速看、快速改 |
| 打印版 | .docx（默认）/ .html（兜底） | 直接印、直接发 |
| 留档版 | 结构化卡片（可复制进教师自己的资料夹） | 下次复用 |

### 各工作流的输出清单

| 工作流 | 输出 |
|---|---|
| W1 备课 | 定位句 / 3 条目标 / 史料链 2–3 则 / 问题链 4–6 问 / 45 分钟环节表 / 阶段特征表 / 分层作业 / 学案（学生版+教师版）/ 课件骨架 |
| W2 命题 | 双向细目表 / 试卷 / 答案与解析（含干扰项类型）/ 评分细则（三段式）/ 答题卡 / 难度结构小结 |
| W3 批改 | 采分表 / 逐份批改表 / 码频次 Top5 / 采分点得分率 / 三条教学动作 / 15 分钟讲评脚本 |
| W4 诊断 | 口径声明 / 统计表 / 三个异常发现 / 归因表 / 分层处方 / 40 字结论 |
| W5 论证 | 史料判定卡 / 四步拆解 / 答题骨架 / 四维评分表 / 改三处清单 / 升格示例 / 变式题 |
| W6 复习 | 时间轴表 / 阶段特征表 / 2 条因果链 / 易混清单 / 检测题 / A4 速记版 |

## 四、实现目标所需的通用处理步骤

六条工作流共享同一个五段骨架。这个骨架是本产品的架构，不是某条流的特例。

```
① 定位  → ② 取标  → ③ 选料  → ④ 建构  → ⑤ 质检交付
```

| 阶段 | 做什么 | 产出中间物 | 失败时 |
|---|---|---|---|
| ① 定位 | 把任务落到 L1/L2/L3 的坐标上 | 坐标三元组 | 落不到 → 列候选让教师选（X02） |
| ② 取标 | 取出对应的课标要求与能力层级 | 目标/考点清单 | 取不到 → 按通用课标口径并标注（X03） |
| ③ 选料 | 挑材料/数据/史料，形成有张力的组合 | 材料链 | 材料不可读 → 只做可辨部分（X04） |
| ④ 建构 | 按工作流模板组装 | 成品草稿 | 信息不足 → 按默认档出并声明假设（X08） |
| ⑤ 质检 | 过六道门（见下） | 质检结论 | 不过 → 修，或明说哪门没过 |

### 六道质检门

| 门 | 查什么 | 典型不过 |
|---|---|---|
| G1 史实 | 年代、人物、事件、制度归属、地域 | 行省制安到唐朝 |
| G2 落点 | 每条结论是否挂到课标/教材/史料 | 目标写"培养唯物史观" |
| G3 口径 | 统计量声明、真题标年份卷别 | 只给均分不给中位数 |
| G4 可用 | 打印出来能不能直接用 | 主观题没留白 |
| G5 边界 | 有无越界承诺 | "覆盖 90% 考点" |
| G6 留痕 | 是否标明需教师人工判断处 | 把重难点取舍写成产品结论 |

## 五、必要的工具能力与技术接口

### 依赖的工具能力

| 能力 | 用途 | 缺失时 |
|---|---|---|
| 文件读取 | 读教材页图片、成绩表、作答图片 | 请教师改用文本粘贴 |
| 图像识别 | 识别教材页、手写作答、图表 | 只处理可辨部分，声明不可辨 |
| 表格处理 | 成绩统计、细目表、批改表 | 用 Markdown 表格替代 |
| 文档生成（docx） | 打印版交付 | 降级为带 `@media print` 的 HTML |
| 演示文稿生成（pptx） | 课件骨架 | 降级为分页 Markdown 大纲 |
| 文件呈现 | 交付附件 | 直接在对话内给全文 |

### 不依赖的接口

- 不需要联网（知识范围内置；真题与教材由教师提供）
- 不需要数据库（不落地保存学生数据）
- 不需要第三方 API

### 数据契约

| 数据 | 格式要求 | 缺字段的影响 |
|---|---|---|
| 成绩表 | 每行一个学生，含总分；理想含各题得分 | 无题号得分 → 只能分布诊断，不能板块归因 |
| 学生作答 | 图片或文本，一题一份或一人一份 | 图片不清 → 只判可辨部分 |
| 教材页 | JPG/PNG，能看清字 | 不清 → 请重拍，不猜内容 |

**隐私契约**：不索取姓名，一律用编号；数据仅用于本次分析，不落地、不上传。

## 六、对结果质量、速度和稳定性的要求

### 质量要求（可验收）

| 指标 | 要求 | 怎么验 |
|---|---|---|
| 史实准确率 | 抽查 20 处史实，错误 ≤1 处 | 人工核对教材 |
| 落点覆盖率 | 100% 的目标/结论能追到坐标 | 逐条查 |
| 结构完整率 | 输出清单项齐全 | 对照第三节表格 |
| 可执行率 | 教学动作 100% 能落到"第几分钟做什么" | 抽 3 条试排课 |
| 判分一致性 | 同一份作答两次批改分差 ≤1 分（15 分制 ≤2 分） | 重复批改比对 |

### 速度要求

| 任务 | 目标 | 说明 |
|---|---|---|
| 单课教案 | 一次交付，不需多轮追问 | 首次输出即含完整 9 项 |
| 单元卷（19 题） | 蓝图 1 轮 + 组卷 1 轮 | 蓝图确认后才出题，避免返工 |
| 单份批改 | 即时 | 30 份以上先建码表再批量 |
| 学情报告 | 一次交付 | 数据齐则可一次成稿 |

**速度的关键不在生成快，在少返工。** 一次问清（任务卡）+ 先给蓝图再出题，是本产品控制返工的两个机制。

### 稳定性要求

| 情况 | 要求 |
|---|---|
| 输入不全 | 不卡住，按默认档出并声明假设（X08） |
| 材料不可读 | 不猜内容，只做可辨部分（X04） |
| 越界请求 | 明确拒绝并给替代方案（X09/X10/X12） |
| 同一输入两次 | 结构一致，措辞可不同，结论不得互相矛盾 |

## 七、产品结构

### 架构：史源层 + 六条流 + 共享质检

```
        ┌───────── 史源层 L1/L2/L3 ─────────┐
        │  课标条目 · 教材子目 · 史料出处   │
        └───────────────┬──────────────────┘
                        │
   ┌────────┬────────┬──┴─────┬────────┬────────┐
   W1备课   W2命题   W3批改   W4诊断   W5论证   W6复习
   └────────┴────────┴──┬─────┴────────┴────────┘
                        │
              ┌─────────┴─────────┐
              │  六道质检门 G1–G6  │
              └───────────────────┘
```

### 工作流之间的数据流

```
W1 ──问题链──→ W2（变成材料题）
W2 ──卷子──→ 学生作答 ──→ W3
W3 ──码频次──→ W4
W4 ──处方──→ W1（重讲哪一课）
W4 ──补题方向──→ W2
W5 ──变式题──→ W2
W5 ──量规──→ W3（判小论文）
W6 ──检测题──→ W3
```

**闭环在 W4 → W1**：诊断出的薄弱点回到备课，下一轮从这里开始。这是本产品与"一次性工具"的根本区别。

## 八、与同类产品的差异

| 维度 | 通用 AI 助手 | 题库类产品 | 本产品 |
|---|---|---|---|
| 备课 | 给泛化教案模板 | 不涉及 | 给到"第几分钟做什么" |
| 命题 | 直接出题，考点随机 | 有题但不可改 | 先蓝图后出题，可校准 |
| 批改 | 给分数和评语 | 只判客观题 | 给分数 + 固定编码 + 累计 |
| 诊断 | 描述性统计 | 有报表无处方 | 统计 + 归因 + 三层动作 |
| 沉淀 | 每次从零 | 题库沉淀 | 错因码跨次累计 |

**核心差异一句话**：别人给你一次答案，本产品给你一套能累积的判断标准。
