# 使用说明

> 这份说明写给一线老师，不写技术术语。
> 读完大概 8 分钟。真要用的时候只需要看第三节的六句话。

---

## 一、第一次用，先做一件事

打开后不要急着问"帮我写个教案"。先给它你的**常用信息**，一句话就够：

```
我带高二，统编版纲要上，两个平行班，学生基础中等，学校要求每节课有学案。
```

它会把这几项记住（在本次对话里），后面的活就不用来回问了。

如果不想说，也可以。它会默认按"高二新授、中等平行班"处理，并在开头告诉你它假设了什么。

---

## 二、六种活，六种说法

### 1. 备课

```
把《两宋的政治和军事》备成一节 45 分钟的高二新授课，要有一段史料研习活动和分层作业。
```

**会拿到**：这节课在单元里的位置 → 3 条目标 → 2–3 则能"打架"的史料 → 4–6 个问题 → 45 分钟时间表 → 阶段特征表 → 三层作业 → 学案 → 课件 16 页骨架。

**想改**：直接说"史料太难了，换成带注释的""时间不够，压到 40 分钟""不要课件"。

### 2. 出卷

```
给第三、四单元出一套单元卷，16 道选择加 3 道材料题，总分 100，先给我命题蓝图。
```

**它会先给一张表**（考点 × 认知层级 × 题号 × 分值 × 预估难度），问你"这样分行不行"。**点头之后再出题。**

这一步别跳。跳过的话，出完发现考点扎堆，等于重来。

**会拿到**：蓝图 → 试卷 → 答案与解析（选择题每项标了干扰类型）→ 评分细则（采分点/容忍度/分层描述）→ 答题卡。

### 3. 批改

```
这是 12 个学生同一道材料题的作答（图片），帮我批改，给每个错处编码，并告诉我这节课该补什么。
```

**会拿到**：采分表 → 逐份批改表（编号/得分/命中/错因码/一句批注）→ 错因 Top5 → 采分点得分率 → 三条教学动作 → 15 分钟讲评脚本。

**关键**：它会用固定的 24 个码给错处编码。这些码是可以跨次累加的——下次批改用同一套码，一个月后你就能看到趋势。

### 4. 看成绩

```
这是这次月考的历史成绩（Excel），满分 100，帮我找真正的薄弱点，并按三层给后续安排。
```

**会拿到**：统计口径声明 → 统计表 → 三个异常发现 → 归因（四类）→ 三层处方（每层 ≤3 条，带验证方式）→ 一句话结论。

**注意**：如果表里只有总分没有各题得分，它会告诉你"只能做分布诊断，做不了板块归因"——这是实话，不是推脱。

### 5. 练史料与小论文

```
这是我班学生的一篇小论文，帮我按维度打分，说清每维差在哪、怎么改。
```

或者：

```
这段材料（附图片）的史料价值怎么讲？我要在课上用 10 分钟讲透。
```

**会拿到**：四维判定（来源/时代/目的/类型）或四维四档评分，每维一句"再往上一档缺什么"，然后是"改三处"清单。

### 6. 复习

```
帮我做"唐宋变革"专题，二轮用，要一条时间轴、一张阶段特征表和易混清单。
```

**会拿到**：时间轴 → 4–6 个阶段 → 阶段特征表（政治/经济/文化/对外）→ 2 条跨阶段因果链 → 易混清单 → 10 道判断 + 2 道材料 → A4 速记版。

## 三、六句话，贴在显示器边上

1. **先给范围。** 课题、单元、专题，或者"考哪几课"。不给范围它只能列清单让你选。
2. **出卷先看蓝图。** 蓝图不对就改，改表比改十道题省事。
3. **批改一次别超 30 份。** 超过 30 份，它会先做 10 份样本建码表，再批量——这样前后才一致。
4. **成绩表尽量带题号得分。** 多记一列，诊断就从"描述"变成"归因"。
5. **不满意就说具体哪里。** "史料太长""问题太多""作业太难"——比"再改改"有效十倍。
6. **它会问你一个问题。** 每次交付完都会问一句"要不要我接着做某某"。不想做就说不用，不会追问。

## 四、拿到东西之后

### 打印

默认给的是 `.docx`，可以直接改、直接印。

- **印之前先看灰度**：所有靠颜色区分的地方，黑白打印后会消失。
- **双面印注意页数**：总页数是奇数时最后一面空白，它会在文档里标注。
- **主观题留白**：如果觉得学生写不下，说一句"每道材料题多留两行"。

### 归档

建议按这个结构存，下次找东西不费劲：

```
2026学年/
├── 01_教案/        按册-单元-课名存，文件名带版本号
├── 02_试卷/        按"年月-范围"存
├── 03_批改/        按"年月-班级-题号"存
├── 04_诊断/        按月存
└── 05_错因统计/    每次一行，攒趋势用
```

`05_错因统计` 是最值得坚持的一个。每次批改记一行：日期、人数、各码次数、均分。一个学期后你手上就有别的老师没有的东西。

## 五、遇到问题怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 它一直问我要范围 | 范围是唯一硬门槛 | 给一个单元名或"某次考试考第 X 到 X 课" |
| 教案里出现"待核实" | 它拿不准某处史实 | 这是好事。按它给的坐标去教材核一眼 |
| 出的题感觉超纲 | 可能调用了选必的框架 | 说"这道题超纲了，落点是哪一册" |
| 批改分数比我严 | 细则的容忍度不同 | 说"表述不规范但意思对的给分"，它会调整 |
| 学情报告太短 | 数据字段不够 | 补题号得分，或接受"只能做分布诊断" |
| 头像显示成一个字 | 见下一节 | — |

### 关于"头像显示成一个字"

如果导入后专家列表里显示的是文字而不是头像，通常是**头像文件没被正确读取**。三个常见原因：

1. **导入时二进制文件丢了**——有些导入方式只带走了 `.md` 和 `.json`，`avatars/` 目录没跟过去。
2. **头像文件过大**——平台读取头像有体积上限，超过会被判为空值。
3. **路径写错**——`plugin.json` 里的 `avatar` 字段与实际文件路径不一致（大小写、扩展名）。

本产品的应对：
- 头像用 PNG、512×512、约 434 KB，远低于上限；
- 提供了 `scripts/embed_avatar.py`，可以生成一份"头像内联版"清单（把图片直接编码进 `plugin.json`），专治导入丢文件；
- `scripts/validate_package.py` 会在打包前检查头像路径、尺寸、体积、水印。

如果导入后仍不显示，运行 `python scripts/embed_avatar.py`，用生成的 `plugin.inline-avatar.json` 替换原清单即可。

## 六、它不会做什么

提前说清，省得失望：

- **不押题。** 问"今年考什么"，它只会讲能力覆盖，不给命中承诺。
- **不编史料。** 要它"编一段像《史记》的材料"，它会拒绝。这是本行业最不能碰的底线。
- **不代写。** 学生作业、论文，它只给思路和修改意见。
- **不评价立场。** 历史事件只做教材框架内的史实梳理。
- **不做升学规划。** 历史分数推不出录取结果。

---

## 七、一句建议

这个产品最有价值的不是"生成得快"，是**它逼你把话说清楚**。

你必须给范围，必须确认蓝图，必须说清哪一步不满意。这些动作本身，就是备课的一部分。

用得久了你会发现：真正被改好的不是文档，是你自己判断一节课好坏的标准。
