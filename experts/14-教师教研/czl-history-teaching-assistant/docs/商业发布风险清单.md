# 商业发布风险清单

> 这份清单只写**没解决的和不确定的**。已经解决的放在最后一节，附证据。
>
> 用法：发布前逐条看 R 级。**红色（高）不能带着发**；黄色（中）可以发，但要知道自己在承担什么；绿色（低）记录备查。

**清单版本**：2026-11-01　｜　对应产品版本：1.0.0

---

## 一、高风险（发布前必须处理或明确接受）

### R1　"卓识"字样的商标状态未知

| 项 | 内容 |
|---|---|
| 等级 | **高** |
| 事实 | 我在本机无法完成商标检索。产品职称含"卓识教育"，displayName 为"卓识史鉴"。 |
| 风险 | 若"卓识"在第 41 类（教育服务）已被他人注册，公开上架使用该名称可能构成商标侵权；平台也可能因名称冲突下架。 |
| 我做了什么 | 已确认该名称**未与其他已安装专家重名**（扫描 82 个专家，displayName 与 profession 均无重复）。这只排除了"平台内重名"，**不排除商标冲突**。 |
| 你要做什么 | 到中国商标网（sbj.cnipa.gov.cn）检索"卓识"在 41 类的注册情况。 |
| 替代方案 | 若冲突，改用不含"卓识"的名称，例如"史鉴""鉴往""青简"等；`displayName` 与 `profession` 两处改动即可，其余文件不受影响。 |

### R2　平台原创性审核结果无法预判

| 项 | 内容 |
|---|---|
| 等级 | **高** |
| 事实 | 产品为独立撰写，但**功能定位**与平台上已有的高中历史教师助手高度重叠。平台审核可能从"功能重复"而非"文本抄袭"的角度判定。 |
| 风险 | 被判定为"重复上架"而驳回；或要求提供差异化说明。 |
| 我做了什么 | 全部文本独立撰写；工作流分解方式不同（六条"流水线"而非七个并列模块）；核心资产（24 码编码本、四维量规、三层处方）为原创；未沿用原文表述；`validate_package.py` 与 `run_tests.py` 均含越界文本检测。 |
| 你要做什么 | 提交时主动说明差异点（可直接引用 `docs/产品规格说明.md` 第八节"与同类产品的差异"）。 |
| 替代方案 | 若被驳回，缩小定位：从"全流程助手"改为"错因编码与学情诊断"单点工具，差异更硬。 |

### R3　AI 生成头像的著作权存在不确定性

| 项 | 内容 |
|---|---|
| 等级 | **高**（法律层面）／低（实务层面） |
| 事实 | 头像由 AI 图像生成工具产出，后经人工裁切、缩放、去水印。 |
| 风险 | 不同法域对 AI 生成物的可版权性判断不一。若平台要求"原创证明"，可能难以提供传统意义上的创作证据。 |
| 我做了什么 | 生成后做了实质性人工处理（构图裁切方案、去除平台水印、尺寸与格式规范）；保留了生成原图于 `assets-src/`（不进发布包）。 |
| 你要做什么 | 保留生成记录（提示词、原始输出、处理步骤）。若平台要求，可提供这套过程证据。 |
| 替代方案 | 换成自行绘制或委托绘制的插画，权利链条最干净。成本约数百元。 |

## 二、中风险（可以发，但要知情）

### R4　史实准确性只做了结构检查，未逐条核校

| 项 | 内容 |
|---|---|
| 等级 | **中** |
| 事实 | 我核对了教材的册次、单元数、课数、单元名称（与公开目录一致），并抽查了部分课名。但**包内所有史实表述未逐条对照教材核校**。 |
| 风险 | 个别年代、人物、制度归属可能有误。这类错误对教育产品是致命的——一个错年代会毁掉全部可信度。 |
| 我已核的部分 | 五册单元数与课数、33 个单元名称、纲要上 29 课课名、部分选必课名。见 `references/01-curriculum-map.md`。 |
| 你要做什么 | 找一位在职高中历史教师通读 `01-curriculum-map.md` 与 `04-error-codebook.md` 的示例部分，重点看易混对与典型错误示例。约 2 小时。 |
| 兜底机制 | 产品内的异常码 X05 与"待核实"标注机制，会在不确定时明确标注而不是硬写。 |

### R5　卷型结构与分值会随省份和年份变化

| 项 | 内容 |
|---|---|
| 等级 | **中** |
| 事实 | `09-exam-patterns.md` 给的是"常见结构"，不是某一省某一年的事实。 |
| 风险 | 教师若直接照用，可能与学生实际考试不符。 |
| 我已做的 | 文件开头有醒目口径声明；要求教师提供"本省+年份+卷型"；给不出时标注"默认结构，请按本省调整"。 |
| 你要做什么 | 上架文案里不要写"精准匹配某省高考"这类话。 |

### R6　教材修订会导致目录过时

| 项 | 内容 |
|---|---|
| 等级 | **中** |
| 事实 | 统编版教材有过修订，部分印次在纲要上第十单元后增列内容，选必 3 个别单元名称有措辞差异。 |
| 风险 | 目录过时 → 定位错误 → 教案对不上书。 |
| 我已做的 | 在 `01-curriculum-map.md` 两处加了"版本提示"，说明以在用印次为准。 |
| 你要做什么 | 每年 9 月核对一次目录，有新印次就发修订版（升修订号）。 |

### R7　导入兼容性：头像可能不显示

| 项 | 内容 |
|---|---|
| 等级 | **中** |
| 事实 | 平台的专家服务在解析头像时，若文件不存在、路径越界或超过 5 MB，会返回空字符串，界面退化为显示名称首字——这正是你遇到的"小图标变成一个字"。 |
| 证据 | 该逻辑位于客户端主进程的专家插件服务 `resolveAvatarUrl`：相对路径按插件目录解析，转成本地文件 URL；文件不存在或 `size > 5MB` 或路径逃出插件目录，均返回空。详见 `docs/功能测试报告.md` 附录。 |
| 我已做的 | 头像改为 PNG（与 48 个正常显示的同批专家一致，而非 JPEG）；512×512；434 KB；无水印；提供 `embed_avatar.py` 生成内联版清单（把图片 base64 进 `plugin.json`，不依赖外部文件）。 |
| 未验证 | 内联版清单在真实客户端中的加载行为未经实测（只能在你的环境里试）。 |
| 你要做什么 | 导入后若仍显示文字，运行 `python scripts/embed_avatar.py --apply`，重启客户端再看。 |

### R8　商业分成与结算规则未知

| 项 | 内容 |
|---|---|
| 等级 | **中** |
| 事实 | 我不掌握平台的专家市场分成比例、结算周期、退款规则。 |
| 风险 | 定价与收益预期可能落空。 |
| 你要做什么 | 上架前在平台的创作者协议里确认三项：分成比例、结算门槛、下架后的已售订单处理。 |

### R9　教育类目的资质要求未知

| 项 | 内容 |
|---|---|
| 等级 | **中** |
| 事实 | 部分平台对 K12 学科类内容有额外审核（如是否涉及学科培训）。 |
| 风险 | 被要求补充资质或调整定位。 |
| 你要做什么 | 确认平台对"面向教师的教学工具"与"面向学生的学科培训"是否区别对待。本产品定位是**教师工具**，不是学生课程，这一点在文案里要写清。 |

## 五、我没能验证的（如实列出）

| 事项 | 为什么没验证 | 影响 |
|---|---|---|
| 真实客户端中的完整对话效果 | 我无法在本机加载新专家并与之对话；当前会话加载的是另一份专家配置 | 工作流在真实交互中的流畅度、追问是否得体，需你实测 |
