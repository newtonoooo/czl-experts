## 这是什么

一个给高中历史老师用的**教学流水线工具**，不是历史百科问答。

它做四件具体的事：

| 你手上有 | 它给你 | 交付物 |
|---|---|---|
| 一个课题 | 一节 45 分钟能上的课 | 教案 + 学案 + 课件骨架 |
| 一个考试范围 | 一套能直接印的卷子 | 双向细目表 + 试卷 + 评分细则 + 答题卡 |
| 一堆学生作答 | 分数、批注、和一张能累计的错因表 | 批改表 + 24 码错因统计 + 讲评脚本 |
| 一张成绩表 | 薄弱点排序和分层安排 | 学情报告 + 三层处方 |

另外两条支线：**史料与论证训练**（史料价值判定、材料题拆解、小论文评分与升格、真题反解）和**专题复习**（时间轴、阶段特征、易混清单）。

---

## 它跟"通用 AI"有什么不一样

三件事，都能验证：

**一、每条结论都有落点。**
不说"学生概括能力差"，说"B3 概括不全，占本次材料题失分的 41%，集中在分层概括这一步——抄了第一层，漏了转折后的第二层"。落点是三层：课标条目 / 教材子目 / 史料出处。

**二、批改能累计。**
24 个固定错因码，跨作业、跨月考累加。一个月后你能看到"B3 出现 47 次、C2 出现 31 次"，这时候补什么不用讨论。

**三、输入不全也能出活。**
12 个异常码配降级路径。没给学情就按中等班出并声明假设；只给总分就只做分布诊断并说清限制；材料看不清就只判可辨部分。不卡住，也不假装知道。

## 快速开始

### 三条最常用的开场白

```
把《两宋的政治和军事》备成一节 45 分钟的高二新授课，要有一段史料研习活动和分层作业。
```

```
给《明清中国版图的奠定与面临的挑战》出一套单元卷，16 道选择加 3 道材料题，先给我命题蓝图。
```

```
这是 12 个学生同一道材料题的作答，帮我批改、给每个错处编码，并告诉我这节课该补什么。
```

### 它一定会先问你的一件事

**范围**。课题、单元、专题，或者"某次考试考哪些课"。这是唯一的硬门槛——范围给不出，它只能列清单让你选。

其他都可以自己定，定完在开头一句话交代。

## 边界（先说清楚，省得后面尴尬）

**它不做**：

- 押题、保分、"覆盖 90% 考点"这类承诺
- 编造史料、虚构书名页码（这是本行业最不可原谅的错误）
- 代写学生作业与论文（可以给思路、骨架、修改意见）
- 对历史事件做立场化评价（只做教材框架内的史实梳理与学术共识表述）
- 升学规划、录取预测

**它做不好**：

- 字迹潦草的图片作答（只判可辨部分，不猜）
- 没有题号得分明细的成绩表（只能做分布诊断，做不了板块归因）
- 大学层级的历史研究（会给高中教学可用的简化版本，并说明是简化）
