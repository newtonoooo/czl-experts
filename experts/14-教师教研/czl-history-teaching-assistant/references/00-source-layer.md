# 史源层：一条结论怎么落到地上

> 本文件只管一件事——**任何一句关于历史的话，能不能被另一个人按你写的坐标找到并核对**。
> 找不到坐标的结论，在课堂上就是一句漂亮话；在学生卷面上就是一处失分点。

---

## 一、三层史源

### L1 课标层

《普通高中历史课程标准（2017 年版 2020 年修订）》。它是**边界**，不是素材。用途有三个：

1. 划定"该讲到什么程度"——超出内容要求的部分，讲了是加负担。
2. 提供素养落点——每条目标要能对应到某一项核心素养的可观察行为。
3. 提供学业质量水平——水平 2 对应合格性考试，水平 4 对应等级性考试。命题难度定位看这一条。

引用格式：

```
[课标] 内容要求 · 秦汉大一统国家的建立与巩固
```

不写页码，不写"第 X 页第 X 段"。不同印次页码不同，写页码是在制造错误坐标。

### L2 教材层

统编版高中历史五册。它是**主线索**，也是学生唯一人手一册的东西。

| 册次 | 简称 | 单元数 | 课数 |
|---|---|---|---|
| 必修·中外历史纲要（上） | 纲要上 | 10 | 29（+活动课 1） |
| 必修·中外历史纲要（下） | 纲要下 | 9 | 23 |
| 选择性必修1·国家制度与社会治理 | 选必1 | 6 | 18（+活动课 1） |
| 选择性必修2·经济与社会生活 | 选必2 | 6 | 15（+活动课 1） |
| 选择性必修3·文化交流与传播 | 选必3 | 6 | 15 |

引用格式（三要素：册次 · 单元 · 课 · 子目）：

```
[教材] 纲要上 · 第三单元 · 第9课《两宋的政治和军事》· 子目「宋初专制集权的加强」
```

**写到子目这一级就够。** 再往下要页码，而页码不可靠；再往上只到"课"，教师备课时又要自己找。

### L3 史料层

原始文献、档案、实物、图像、口述、统计材料。它是**证据**，不是装饰。

引用格式：书名/档号 + 卷次篇名 + 作者 + 时代（古籍四要素）；或 作者 + 篇名 + 出处 + 年份（近现代文献）。

```
[史料] 《史记》卷六十八《商君列传》，司马迁，西汉
[史料] 《宋史》卷一百六十一《职官志一》，脱脱等，元
[史料] 《实业计划》，孙中山，1919 年
[史料] 国家统计局《中国统计年鉴 1985》，中国统计出版社
```

**图像与实物**要写收藏地或图录来源：

```
[史料] 战国水陆攻战纹铜壶，四川成都百花潭出土，四川博物院藏
```

## 二、引用纪律：五条不许

1. **不许编造书名、卷次、篇名。** 宁可写"教材'史料阅读'栏目所引材料"，也不要造一个看着很像的《XX 志》卷 XX。
2. **不许改原文。** 需要缩短时用省略号并保持原句顺序，不许把两句揉成一句再打引号。
3. **不许把转述当原文。** 只记得大意、无法核对字句时，去掉引号，改写成"某书大意谓……"，并标"原文待核"。
4. **不许把二手当一手。** 转引的材料要写"转引自"。转引两次以上的，视为不可靠，换材料。
5. **不许把教材结论当史料。** 教材是叙述，不是证据。要证据就往下找 L3。

## 三、材料进课堂前的三道筛

不是所有能查到的材料都该进课堂。进之前过三道：

### 第一道：读得完吗

高中生读一段陌生文言或一段译文，速度大约是 **每分钟 120–150 字**。一段材料如果超过 200 字，要么删，要么拆成两段配两个小问。

超过 300 字的单段材料，在 45 分钟课里基本用不动——学生读完就没时间想了。

### 第二道：答得出吗

每则材料必须能回答一个**具体问题**，且这个问题不能靠"感觉"回答。自测方法：把材料给你自己，不许看教材，你能不能在三句话内答出来？答不出，说明材料与问题的距离太远，中间缺脚手架。

### 第三道：有没有反证

单一材料只能证明一件事，容易让学生以为历史是"一边倒"的。**每两组材料里至少有一组要能互相拉扯**：官方记载与私人书信、中央档案与地方志、胜利者叙述与失败者叙述、文字材料与考古实物。

有张力的材料，才会长出真问题。

## 四、三种常见"假坐标"

| 假坐标 | 长什么样 | 为什么错 | 改成什么 |
|---|---|---|---|
| 页码坐标 | "见教材第 47 页" | 印次不同页码不同，学生翻不到就放弃 | 写到"课 + 子目" |
| 泛化坐标 | "据史料记载" | 等于没说，无法核对 | 写出具体书名卷次，或删掉这句 |
| 错位坐标 | 用《资治通鉴》证唐代制度 | 宋代人写唐代事，是二手叙述 | 换成《唐会要》《通典》等唐代文献，或注明是后代追述 |

第三条最隐蔽。判断方法很简单：**作者的生活年代，早于还是晚于事件发生年代？** 晚于，就是追述，价值要打折，且必须说明。

## 五、给不同用途的最小标注量

不必每处都标三层。按用途给最小量：

| 用途 | 最小标注 | 说明 |
|---|---|---|
| 课堂口头讲 | 不标 | 但心里要有，被学生追问时能答出 |
| 学案/课件 | 标 L2（册·单元·课） | 学生要能自己翻回去 |
| 教案（给同事看） | 标 L1 + L2 | 同事要判断你这节课合不合课标 |
| 试卷 | 材料必须标 L3 完整出处 | 无出处的材料不能进试卷 |
| 教研论文/公开材料 | 三层齐标 | 会被核查 |

## 六、一句提醒

标注不是为了显得严谨，是为了**让别人能推翻你**。

一个能被推翻的结论，才是真结论。一个谁也核不了的结论，只是话说得比较响。
