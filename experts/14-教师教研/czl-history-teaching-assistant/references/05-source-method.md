# 史料实证：一条材料的价值怎么判

> 学生答史料价值题最常见的答案是"这则材料是第一手史料，具有重要的史料价值"。
> 这句话一个字都没错，也一个字都没用。它没回答"对研究什么问题有价值、价值有多大、局限在哪"。

---

## 一、先分类，再判断

### 按载体分五类

| 类型 | 例 | 强项 | 弱项 |
|---|---|---|---|
| 文献 | 正史、档案、方志、书信、报刊 | 信息密度高、可引原文 | 有作者立场，可能有讳饰 |
| 实物 | 器物、建筑、遗址、墓葬 | 不经后人转述，最难伪造 | 不语自明程度低，解释空间大 |
| 图像 | 壁画、绘画、照片、地图 | 直观呈现空间与生活细节 | 有构图选择，可能美化或程式化 |
| 口述 | 访谈、回忆录、民歌 | 补官方记载之缺，有情感与细节 | 记忆偏差、事后重构 |
| 统计 | 户籍、赋税册、物价表、普查 | 可量化、可比较 | 统计口径可能变，漏报常见 |

**判断要点**：不要问"这是什么类型"，要问"这个类型最擅长回答什么、最不擅长回答什么"。

### 一手与二手

判定标准只有一条：**作者是不是事件的亲历者或同时代人，且记录的是自己直接获得的信息。**

- 亲历 + 直接记录 = 一手
- 同时代 + 转述他人 = 一手材料中的转述（价值打折）
- 后代追述 = 二手
- 现代研究著作 = 二手（甚至三手）

**三个常见误判**：

1. **《史记》写秦朝，是一手还是二手？** 对秦汉之际，司马迁部分亲历、部分访查，接近一手；对战国及以前，是二手整理。**同一本书，不同部分价值不同。**
2. **出土简牍一定是"最可靠"的？** 可靠在"未经后人改动"，但可能只是草稿、残篇，未必代表官方定论。
3. **照片一定是客观的？** 拍什么、不拍什么、怎么构图，都是选择。

## 二、四维价值法

每则材料，四个维度各写一句。四句写完，"史料价值"这道题就答完了。

### 维度一：来源（谁说的）

三个追问：
- 作者是谁？身份、职位、立场是什么？
- 他有没有能力知道这件事？（信息渠道）
- 他有没有动机歪曲？（利益关系）

**答题句式**：*该材料出自〔身份〕之手，其立场倾向于〔……〕，因此对〔某类问题〕的记载较为可信，而对〔另一类问题〕可能存在回避。*

### 维度二：时代（什么时候说的）

- 同时代记录 vs 事后追述，价值差别很大。
- 事后追述未必差：隔了时间反而更全面。但**细节的可靠性下降，判断的可靠性上升**。

**答题句式**：*该材料成于事件发生后〔X〕年，属事后追述，对事件整体脉络的把握较完整，但对具体时间、数字的记载需与同时代材料互证。*

### 维度三：目的（为什么说的）

- 写给谁看？想达到什么效果？
- 官方文书的目的通常是"行政"，私人书信的目的通常是"沟通"，报刊的目的通常是"影响舆论"。

**答题句式**：*该材料为〔呈报/宣传/私人通信〕而作，其目的在于〔……〕，故在〔某方面〕可能有所强调或省略。*

### 维度四：类型（这是什么性质的材料）

- 是孤证还是有旁证？
- 是原件还是转录？
- 是完整文本还是残篇？

**答题句式**：*该材料为〔类型〕，属〔一手/二手〕，可与〔另一材料〕互证；但为残篇，缺少〔某部分〕，难以据此判断〔某问题〕。*

## 三、四维合成：一段完整作答

把四句连起来，就是标准答案的骨架。

> 该材料出自北宋某地方官之手（来源），成于事件发生后约二十年（时代），为其向朝廷呈报地方情况的奏疏（目的），属一手文献但经过后人编纂（类型）。因此，它对研究北宋地方财政的实际运作具有较高价值，但对其中的数字需与《宋史·食货志》互证；由于是奏疏，作者可能强调困难以争取蠲免，对地方实情或有夸大。

这段话没有一句是套话。每一句都能被追问，也都能被反驳——这正是它成立的原因。

## 四、材料题四步

### 第一步：定时空（30 秒）

圈出材料里的时间、地点、人物。没有明确时间的，从出处推。

**为什么先做这个**：所有后续判断都依赖它。跳过这一步，后面的分析全是浮的。

### 第二步：分层次（1 分钟）

按三个信号切：
- 句号、分号（最基础）
- 转折词（但、然而、虽、然则、不过）
- 主语变化（从"朝廷"到"地方"、从"中国"到"外邦"）

切完之后标 ①②③，答案的点数基本就等于层数。

### 第三步：抓关键词（1 分钟）

每层抓 1–2 个词。抓什么：
- 动词（"设""废""禁""许"）——往往是措施
- 程度词（"皆""尽""稍""渐"）——往往是判断的分寸
- 限定词（"主要""直接""最初"）——往往决定答题范围

### 第四步：连所学（1 分钟）

把材料信息挂到教材的哪一课哪个子目。挂不上，说明材料超纲或你定位错了。

**四步走完才动笔。** 直接动笔的学生，答案通常是"材料里的话 + 教材里的话"，中间没有缝合线。

## 五、五类设问的答题骨架

### 概括类（"概括……的特点/内容"）

```
① 分层：材料有几层，答案就有几点
② 提炼：每层压成一个短句，不用原文
③ 校验：把答案遮住，能否从材料反推出答案
```

**不给分的样子**：整段抄材料，或只答一层。

### 原因类（"分析……的原因"）

```
① 分层：直接原因 / 根本原因；内因 / 外因
② 每层至少一条，不许只写一条"根本原因"
③ 每条后面加一句"何以见得"（材料依据或所学依据）
```

**不给分的样子**：只写"因为封建制度的腐朽"这类万能句。

### 比较类（"比较……的异同"）

```
① 先定维度（3 个以内），维度不定不写
② 逐维度两栏对照，不写"甲如何，乙如何"的两段式
③ 结论只写"差异的关键在哪"，不写"都很重要"
```

**不给分的样子**：各说各的，没有同一维度。

### 评价类（"评价……"）

```
① 先给标准："以……为标准"
② 再判断："从这一标准看，……"
③ 再给另一面："但以……为标准，则……"
④ 收口：给出你的取舍及理由
```

**不给分的样子**：只写"既有积极影响，也有消极影响"，不说是哪个更多、为什么。

### 启示类（"从中得到什么启示"）

```
① 从具体史实出发（不许脱离材料谈人生）
② 一句史实 → 一句道理 → 一句当下
③ 不超过三点
```

**不给分的样子**："我们要以史为鉴，面向未来"。

## 六、史料教学中的三个坑

### 坑一：用材料证明教材结论

材料被当成"教材结论的插图"。学生读完只会说"果然如此"。
**改法**：找一则与教材结论有张力的材料，让学生解释"为什么教材不这么说"。

### 坑二：只给成功的材料

全是"某措施取得显著成效"，学生会以为历史是线性进步。
**改法**：一组材料里至少有一则讲代价或失败。

### 坑三：把史料实证上成考据课

花一整节课辨真伪，学生觉得历史就是"挑错"。
**改法**：辨真伪只是手段，落点要回到"因此我们对这段历史的理解要修正哪里"。

---

## 七、一句话总结

判史料价值，不是给它打分，是给它**划定适用范围**：

> 这则材料，能证明什么，不能证明什么，需要和什么一起用。

三句话说清，就是满分答案。说不清，写多少字都是零。
