## 二、五大核心素养：可观察的行为动词

写目标时最容易犯的错是"培养唯物史观"——这是口号，不是目标。目标必须能看见学生在做什么。下表给每项素养配可观察行为，写到目标里就能被检测。

| 素养 | 学生实际在做什么（可观察） | 可用的动词 | 反面样例 |
|---|---|---|---|
| 唯物史观 | 用生产力与生产关系、经济基础与上层建筑的关系解释变化；识别历史评价的立场 | 运用……分析、从……角度解释、指出……的阶级/经济根源 | "树立唯物史观" |
| 时空观念 | 在时间轴上定位；在同一时段内比较不同区域；说明地理条件对事件的影响 | 定位、对照、绘制、说明……时期的……特征 | "增强时空感" |
| 史料实证 | 辨别史料类型与可信度；从材料中提取并互证；指出材料的局限 | 辨析、提取、互证、指出……的局限 | "培养史料意识" |
| 历史解释 | 对同一事件给出不同解释并说明理由；评价某种解释的成立条件 | 解释、评析、比较……两种说法、说明……的合理性 | "提高分析能力" |
| 家国情怀 | 在具体史实上体认共同体的形成过程；对文化遗产的价值作出判断 | 体认、认同、说明……对今天的意义 | "激发爱国热情" |

**写法公式**：`能 + 行为动词 + 具体史料/史实对象 + 达成标志`。

例：
- ✗ 培养史料实证素养
- ✓ 能依据《宋史·职官志》节选，指出北宋分割宰相事权的三条路径，并说明其中哪一条最能体现"分化事权"

## 三、学业质量水平与考试定位

课标把学业质量分为四级。教学上只需要记住两个锚点：

| 水平 | 对应考试 | 能力特征（概括） |
|---|---|---|
| 水平 2 | 合格性考试（学考） | 能在给定材料中识别基本信息，复述主要史实，说明基本因果 |
| 水平 4 | 等级性考试（选考/高考） | 能独立辨析材料、多角度解释、在陌生情境中迁移，并对解释本身作出评价 |

命题时的用法：**先定水平，再定难度**。定位水平 2 的卷子，不要出需要独立评价史料价值的题；定位水平 4 的卷子，不要用"指出""列举"占满全卷。

## 六、高频易混对（做复习表、设计干扰项时直接用）

| 易混对 | 区分点 | 一句话记法 |
|---|---|---|
| 分封制 / 宗法制 | 分封分的是"地"，宗法分的是"位" | 分封治天下，宗法治一家 |
| 郡县制 / 分封制 | 郡县长官由中央任免，不能世袭 | 郡县无世袭 |
| 三省六部 / 二府三司 | 前者唐，后者宋；前者分工制衡相权，后者分割相权 | 唐三省，宋二府 |
| 内阁 / 军机处 | 内阁明成祖设，军机处清雍正设 | 明有内阁，清有军机 |
| 行省制 / 郡县制 | 行省为元创，辖区大、权力受中央节制 | 元行省，秦郡县 |
| 租庸调 / 两税法 | 前者按人丁，后者按资产，唐中后期改 | 人丁改资产 |
| 一条鞭法 / 摊丁入亩 | 前者明张居正，后者清雍正；后者废人丁税 | 明并税，清废丁 |
| 洋务运动 / 戊戌变法 | 前者器物，后者制度；前者官办为主，后者士人推动 | 先器后制 |
| 旧民主主义 / 新民主主义 | 领导阶级不同：资产阶级 / 无产阶级 | 辛亥旧，五四新 |
| 文艺复兴 / 启蒙运动 | 前者解放"人"，后者设计"制度" | 文艺破神，启蒙立制 |
| 英国《权利法案》/ 美国 1787 年宪法 | 前者限制王权、确立议会主权，后者确立联邦制与三权分立 | 英限王，美分权 |
| 第一次工业革命 / 第二次 | 蒸汽 / 电力；轻工业起步 / 重工业主导 | 一蒸二电 |

**用法**：设计选择题干扰项时，把易混对的后一项放在正确项旁边，比随便编一个错项有效得多——因为它考的是学生真实的混淆点，不是考他会不会排除明显荒谬项。

## 七、跨册对应关系（做单元设计、跨模块命题时用）

同一主题在必修与选必中的落点不同，混用会超纲或重复。

| 主题 | 纲要上的落点 | 选必的落点 | 命题时的分工 |
|---|---|---|---|
| 中央集权制度 | 各朝代政治措施（叙事） | 选必1 第1课（制度演变逻辑） | 必修考"是什么、怎么变"，选必考"为什么这样设计" |
| 选官制度 | 提及科举 | 选必1 第5、7课（系统） | 细化放选必 |
| 赋税 | 提及 | 选必1 第16课 | 细化为选必 |
| 商业与市场 | 各朝经济 | 选必2 第7、8课 | 必修重现象，选必重机制 |
| 文化交流 | 中外文化交流片段 | 选必3 第9、10课 | 选必重路径与载体 |
| 民族关系 | 各族政权与交融 | 选必1 第11、13课 | 必修重过程，选必重制度 |

**判断规则**：如果一道题的答案要点必须调用选必的制度分析框架，而考生只学了必修，就是超纲。命题前先问一句：**这道题的得分点，落在哪一册的哪一课？**
