### 2. 公开事实性信息（不受著作权保护）

包内出现的以下内容属于**事实与通用知识**，不构成对他人作品的复制：

- 教材的册次、单元名称、课目名称（事实性目录信息）
- 历史事件、年代、人物、制度名称
- 学科通用术语（如"史料实证""唯物史观""双向细目表""区分度"）
- 课程标准的名称、发布机构、版本年份

**注意**：教材目录是事实，教材正文不是。本包**不包含任何教材正文段落**。

### 3. 未包含的内容（有意排除）

以下内容**没有**被打包，这是刻意的法律选择，不是遗漏：

| 未包含 | 原因 | 替代方案 |
|---|---|---|
| 统编版教材正文 | 教材享有著作权，商业分发需授权 | 只写"册·单元·课·子目"坐标，教师用自己手上的教材 |
| 高考真题原文 | 试题整体享有汇编与创作权益，大规模收录有风险 | 提供"真题改造三步"方法，由教师自行取用本校已有试卷 |
| 课程标准全文 | 全文照录在商业产品中有争议 | 只引名称、条目主题词，不引长段原文 |
| 第三方课件、教辅、图片 | 权属复杂，多数不允许商业再分发 | 提供自制模板与生成方法 |
| 历史图片、地图 | 博物馆藏品图片多有使用限制 | 只给文字描述与获取建议，不内嵌图片 |

### 4. 第三方组件

**无。** 本包不依赖任何第三方 Python 包、Node 包、字体文件或图标库。

- 三个脚本只用 Python 标准库（`json`、`os`、`sys`、`zipfile`、`hashlib`、`base64`、`re`、`pathlib`）。
- 头像为位图资源，不含第三方字体或图标。
- 因此**不存在第三方许可证传导问题**，商业分发无额外义务。

## 二、关于"参考资料打包"的说明

本产品的定位是**方法论工具**，不是**资料库**。

原因有三：

1. **法律上**：教材、真题、教辅的著作权状态复杂，商业产品里打包这些内容，风险远大于收益。
2. **实用上**：教师手上已经有教材和真题，缺的不是资料，是"怎么用"的方法。
3. **维护上**：教材会修订、真题会更新，打包的资料半年就过期；方法论不会。

如果确实需要配套资料，建议教师自行建立本地资料夹，按以下结构组织（本包不提供这些文件，只提供组织方式）：

```
我的历史资料/
├── 01_教材/            各册 PDF 或扫描件（自购正版）
├── 02_真题/            按年份-卷别命名
├── 03_校本卷/          自己出过的卷子，按单元归档
├── 04_学生作品/        按班级-日期归档，去姓名
└── 05_错因统计/        每次批改的码频次记录
```

## 三、AI 生成内容的说明

头像由 AI 图像生成工具产出，经人工裁切、缩放、去水印处理。

三点如实说明：

1. **不含真实人物肖像**。生成的是虚构形象，不对应任何真实个人。
2. **不声称独占**。AI 生成图的著作权归属在不同法域尚有争议；本产品主张的是"在该图上投入了选择与编排（构图选择、裁切方案、配色约束）"，不主张对"AI 生成"这一过程本身的独占。
3. **已去除平台水印**。原始输出带有生成平台的水印，已在裁切时排除在画幅之外，最终文件不含任何水印或第三方标识。

正文文本（提示词、工作流、参考文件）**为人工撰写**，非 AI 直接生成后未经修改的产物；其中的判断规则、码表、量规均经过设计取舍，属于表达性内容。

## 四、引用他人观点时的处理

本包在少数地方会提到"有学者认为……"这类表述。处理原则：

- 只提**学界共识性观点**，不指名具体学者，不引具体论文页码。
- 涉及争议问题（如分期问题），并列两种说法及各自依据，不替读者站队。
- 不复制任何论文段落。

如果教师需要具体文献出处，应在使用时自行检索核实——这也是 `00-source-layer.md` 里"待核实"标注存在的原因。
