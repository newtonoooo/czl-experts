## 1. 产品定位

一个面向高中生物教师的工作台型专家，覆盖"备课—命题—批改—诊断—交付"五个环节。不做通用问答，只做能落到纸面、能进课堂的产出。

与常见的"帮我写教案"类工具相比，本产品有三条硬约束：

1. **一切产出先过对齐**：教学目标、学习活动、评价证据三者必须互相指认，缺一环就打回。
2. **一切命题先过细目表**：分值、认知层级、难度、考点覆盖四项可计算、可校验。
3. **一切交付先过闸门**：学科口径、数据自洽、来源合规、可执行性、可打印性五项检查。

## 2. 目标用户与使用场景

### 2.1 目标用户

| 用户 | 特征 | 主要诉求 |
|---|---|---|
| 高中生物任课教师 | 每周 10–16 课时，兼班主任或备课组事务 | 少花时间在重复劳动上，产出别出错 |
| 备课组长 / 教研组长 | 需要统一进度与命题标准 | 组内产出可比、可审 |
| 带新教师的师傅 | 需要把经验显性化 | 有可交付的模板与判断标准 |
| 教培机构教研员 | 需要快速产出分层材料 | 结构规范、可批量改 |

### 2.2 典型场景

| 场景 | 时间点 | 现状痛点 | 本产品产出 |
|---|---|---|---|
| 备新课 | 前一晚 | 目标写成"理解"，活动与目标不对应，课上时间不够 | 三对齐表 + 教案 + 板书 + 分层作业 |
| 单元规划 | 开学前 | 课时不够，靠感觉砍内容 | 概念依赖图 + 课时表 + 单元评价 + 可砍顺序 |
| 出单元卷 | 考前一周 | 考点重复、难度漂移、评分细则写不出 | 双向细目表 + 卷子 + 答案 + 细则 |
| 批长句题 | 考后两天 | 批语写不出，学生看不懂 | 采分点打勾表 + 错因五分类 + 可照抄批语 |
| 考后分析 | 考后一周 | 只报均分，不决定下一步教什么 | 板块得分率 + Top 失分点 + A/B/C 处方 + 课时落点 |
| 开实验课 | 实验前一周 | 材料没有、时间不够、现象不明显 | 变量表 + 安全须知 + 预实验清单 + 失败预案 |
| 交材料 | 检查前 | 格式乱、要打印 | A4 打印版 docx + 复核清单 |

## 3. 需要解决的问题（按优先级）

1. **对齐缺失**：目标、活动、评价三张皮，课上完了不知道有没有达成。
2. **命题失据**：凭经验凑题，考点覆盖与难度分布不可控，事后无法归因。
3. **批改失语**：只会打分不会诊断，学生拿到卷子不知道改什么。
4. **分析失焦**：统计停留在均分与及格率，无法回答"下周教什么"。
5. **实验失备**：方案写得漂亮，材料与课时不落地。
6. **交付失形**：成稿无法直接打印，格式反复调。

## 4. 输入与输出

### 4.1 最小输入

| 类型 | 内容 | 是否必填 |
|---|---|---|
| 范围 | 节名 / 章名 / 考点清单 | 是 |
| 年级 | 高一 / 高二 / 高三 | 是 |
| 交付 | 教案 / 卷子 / 批改 / 分析 / 课件 / 全套 | 是 |
| 教材版本 | 人教 / 苏教 / 北师大 / 其他 | 否，缺省按课标口径 |
| 课时 | 可用课时数 | 否，缺省 1 课时（单元 6–8） |
| 学情 | 班型、均分、薄弱板块 | 否，缺省中等班 |
| 材料 | 教材照片、旧卷、成绩 CSV、答题卡 | 否 |

### 4.2 输出形态

| 形态 | 说明 | 载体 |
|---|---|---|
| 屏幕版 | 对话内直接可读的结构化内容 | Markdown |
| 打印版 | A4、宋体、表格带框线、页脚页码 | .docx |
| 课件骨架 | 页序 + 每页要点 + 图位说明 | Markdown（可转 .pptx） |
| 数据表 | 细目表、成绩统计、题目质量 | .csv / .md |
| 复核清单 | 需教师拍板的 3–6 条，具体到位置 | .md |

## 5. 处理步骤（通用流水线）

```
受理（W1）→ 规划（W2）→ 产出（W3/W4/W7）→ 回收（W5/W6）→ 定稿（W8）
```

每一步的进入条件、退出条件、异常回流都写在工作流文件里。核心规则：

- 上一环未确认，不进入下一环。
- 任何一环发现范围变化，退回 W1 重出任务卡。
- 产出不合格只回退到对应环节，不整条重来。

| 能力 | 实现 | 依赖 |

## 7. 质量、速度与稳定性要求

### 7.1 质量

| 指标 | 要求 | 验证方式 |
|---|---|---|
| 学科准确性 | 遗传比例、实验变量、概念表述无错 | 人工复核 + 关键计算验算四步 |
| 分值自洽 | 细目表合计 = 总分，误差 0 | `blueprint_check.py` |
| 评分细则可用 | 每条采分点含内容、分值、等价表述、扣分点 | W8 闸门第 2 项 |
| 目标可测 | 每条目标含行为动词 + 内容 + 产出 | W3 判断条件 |
| 时间可执行 | 教案环节时间合计 ≤ 课时 | W3 步骤 4 |
| 来源合规 | 引用真题/教材必标注；无出处数据不写 | W8 闸门第 3 项 |

### 7.2 速度

- 单课时教案：一次交互内出初稿。
- 一份 100 分单元卷：先出细目表（1 次交互），确认后出卷（1–2 次交互）。
- 成绩统计：脚本运行 < 2 秒（百人规模）。
- 打印版 docx：脚本运行 < 1 秒。

### 7.3 稳定性

- 脚本对缺失值、缺考、列数不匹配、编码异常均有明确报错，不静默出错。
- 读图失败、材料不清时，先复述已识别内容再请用户确认，不臆造。
- 环境不支持 docx 时，降级为 Markdown 打印版并注明原因。

## 8. 不做什么

| 不做 | 原因 |
|---|---|
| 替学生完成作业 | 违背教学伦理，且无法验证学习效果 |
| 押题、承诺分数 | 无法保证，属虚假宣传 |
| 修改或美化学生成绩 | 数据造假 |
| 危险实验操作指导 | 安全边界 |
| 医疗、用药建议 | 超出学科教学范围 |
| 打包教材原文、教辅扫描件、真题成卷 | 版权风险 |
| 输出学生姓名等个人信息 | 隐私 |

## 9. 与目标产品的关系说明

本产品为独立开发。开发前对目标专家（高中生物教师助手类产品）做了**功能层面的需求分析**，提取其覆盖的任务类别（教案、命题、批改、学情、实验、课件）作为需求来源；未复制其提示词、工作流文本、参考资料、脚本或头像。全部文件为本项目重新撰写，结构与表述方式均不同（详见 `04-开发记录.md` 第 3 节）。

在功能上做了以下补充：

1. 增加"三对齐"作为强制前置，而非仅产出教案。
2. 增加细目表的程序化校验（目标产品为人工检查）。
3. 增加错因五分类与可照抄批语，批改从"点评"变为"可执行"。
4. 增加实验开课三问与失败预案。
5. 增加交付闸门与复核清单。
6. 提供离线可跑的脚本，不依赖第三方库。
