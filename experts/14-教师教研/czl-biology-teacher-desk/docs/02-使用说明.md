# 使用说明

## 1. 三分钟上手

**第一步：说清三件事**

```
帮我备《基因的分离定律》两课时，高一中等班，要教案和课件大纲
```

范围 + 年级 + 交付物。教材版本、学情、课时可以后补，缺了也能做，只是会按默认口径给。

**第二步：确认任务卡**

助手会先复述一遍需求，给一张任务卡（范围、课时、交付、待确认、风险）。看到不对就改，这一步改比后面改便宜。

**第三步：拿走成品**

教案、卷子、分析报告都会给两版：对话里的屏幕版，和一份 A4 打印版 docx。

## 3. 三个脚本怎么用

脚本在 `skills/czl-bio-teacher-kit/scripts/`，只需要 Python 3.8+，不需要安装任何包。

### 3.1 成绩统计

```bash
python score_report.py -i scores.csv -f 2,2,2,4,6,8,6,10 -o report.md \
    --sections 1-4:基础判断,5-8:综合应用 --title "高一(3)班 单元测"
```

成绩 CSV 格式（第一列学号，其余每题一列，空格子表示缺考或未答）：

```csv
学号,Q1,Q2,Q3,Q4,Q5,Q6,Q7,Q8
S01,2,2,2,4,6,8,6,10
S02,2,2,0,4,4,6,2,6
```

输出：均分、中位数、标准差、分数段、逐题得分率/难度/区分度、板块得分率、判读提示。

### 3.2 细目表校验

```bash
python blueprint_check.py -i blueprint.csv --total 100 --profile unit
```

细目表 CSV 表头：`题号,考点,认知层级,题型,分值,预估难度,核心素养`。层级取 `记忆/理解/应用/分析`，难度取 `易/中/难`。

出错会直接拦下（分值不闭合、字段空缺、取值非法）；偏差只给警告（层级偏差 >10 个百分点、难度偏差 >15 个百分点、单考点 >35%）。

### 3.3 打印版 docx

```bash
python make_docx.py -i 教案.md -o 分离定律_教案_20261101.docx --title "分离定律 教案"
```

版式：A4、2.54cm 页边距、小四宋体、黑体标题、1.5 倍行距、首行缩进 2 字符、表格带框线、页脚页码。不支持图片与公式，需要在 Word 里手动补。

## 4. 导入后图标变成文字怎么办

**现象**：专家导入到新的 WorkBuddy 后，列表里显示的是一个带首字的色块，不是头像。

**原因**（已核查平台代码）：渲染层解析 `plugin.json` 的 `avatar` 字段时，若写的是相对路径（如 `avatars/expert.png`），会把它拼成平台 CDN 地址：

```
https://static.workbuddy.cn/workbuddy/custom-expert/avatars/expert.png
```

本地导入的专家没有向该地址上传过文件，请求 404，界面就回退成"首字 + 底色"的占位样式。这不是包坏了，是头像资源不在 CDN 上。

**三种处理**

1. **上架后自然恢复**：通过专家中心正式发布，平台会上传资源，相对路径即可命中。
2. **本机立刻可见**：把头像内嵌进清单（生成 data URI，渲染层会直接透传）：

   ```bash
   python bin/set_local_avatar.py --expert-dir .
   ```

   还原：`python bin/set_local_avatar.py --expert-dir . --restore`

   注意：内嵌后 plugin.json 会变大（约 30–60 KB），且不利于上架审核，**上架前务必还原**。
3. **换机器验证**：重新导入后若仍不显示，先确认 zip 里有 `avatars/expert.png`（用解压工具看），再确认路径拼写与大小写一致。

## 5. 常见问题

| 问题 | 处理 |
|---|---|
| 脚本报"满分个数与题目列数不一致" | 数一遍 CSV 的题目列，`-f` 的数字个数要与之相同 |
| CSV 中文乱码 | Excel 里另存为"CSV UTF-8" |
| 报"没有可用于统计的有效成绩行" | 检查分隔符是否为逗号；整行空会被判为缺考 |
| docx 打开是空白 | 确认 Markdown 文件非空；重新生成 |
| 教案时间排不下 | 直接说"只有 40 分钟"，会按压缩顺序砍活动 |
| 遗传题答案不确定 | 要求"给出验算过程"，会走配子法 + 棋盘法交叉验证 |
| 引用的真题记不清年份 | 直接说"不确定出处"，会改成自编题，不编造年份 |

## 6. 使用建议

- **先给旧卷**：让助手看一份你出过的卷子，后面的难度和风格会更贴近。
- **先说班情**：均分、薄弱板块、课时松紧，这三样一说，产出立刻不一样。
- **用复核清单**：每次交付末尾都有 3–6 条待拍板项，那是需要你决定的部分，不要跳过。
- **数据脱敏**：成绩表用学号，不要用姓名。
