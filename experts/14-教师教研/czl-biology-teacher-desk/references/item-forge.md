# 命题与评分细则手册

## 一、先定表，再定题

命题的顺序不能反。先有双向细目表，再有题；先有题再凑表，一定会出现"考点重复、层级塌陷、分值不闭合"。

### 细目表字段

| 字段 | 取值 | 说明 |
|---|---|---|
| 题号 | 1, 2, 3… | 连续，不跳号 |
| 考点 | 一句话，具体到概念 | 写"分离定律的实质"，不写"遗传" |
| 认知层级 | 记忆 / 理解 / 应用 / 分析 | 按 `concept-ladder.md` 的动词判 |
| 题型 | 单选 / 多选 / 填空 / 简答 / 实验设计 / 计算 | — |
| 分值 | 整数 | 合计必须等于总分 |
| 预估难度 | 易 / 中 / 难 | 对应得分率 ≈ 0.8 / 0.6 / 0.35 |
| 核心素养 | 生命观念 / 科学思维 / 科学探究 / 社会责任 | 一题一个主素养 |

### 校验规则（`blueprint_check.py` 会跑）

- 分值合计 = 设定总分（误差 0）
- 认知层级分布与目标配比偏差 ≤ 10 个百分点
- 同一考点分值占比 ≤ 35%
- 难度配比与用途匹配（见 W4 的表）
- 每题都有考点、层级、分值，无空字段

## 二、题干写作

**三条硬规矩**

1. **情境不超过 3 行**。超过说明背景写太多，删到只留解题必需的信息。
2. **数据必须自洽**。题目给的数字要能算出选项；算不出就改数据，不改选项。
3. **指向明确**。设问里出现"说明""分析"时，必须跟一个具体的对象，不写"请分析其原因"这种万能问法。

**情境来源的三种写法**

| 来源 | 写法 | 风险 |
|---|---|---|
| 教材实验 | 改变材料或条件，保留变量结构 | 改动后结论可能不成立，需重算 |
| 生产生活 | 用真实场景（育种、发酵、疾控） | 数据不能编，编了就是假情境 |
| 科研论文 | 只取结论方向，不搬数据 | 搬数据易超纲 |

**必须标注来源的情形**：直接引用或改编自真题、教材习题、其他教辅。格式：`（改编自 2023 年全国甲卷第 5 题）`。无法确认来源的题不用。

## 三、选择题干扰项设计

好干扰项来自学生的真实错误，不来自随手编。四个来源：

1. **迷思概念**：直接从 `misconception-atlas.md` 取（如"酶提供能量"）。
2. **半对半错**：前半句对、后半句错，考的是读完。
3. **概念串线**：把相近概念互换（分离 vs 自由组合、基因频率 vs 基因型频率）。
4. **程度错误**：把"多数"改成"所有"、把"主要"改成"一定"。

**不合格的干扰项**：明显荒谬（"细胞会飞"）、与题干无关、两个选项互斥但都对、用生僻术语凑数。

**选项长度要接近**，正确答案不能明显比其他选项长或短——这是最常见的泄题方式。

## 四、非选择题设问层级

一道大题内部要有梯度，按"识别 → 解释 → 推断 → 评价"排：

```
（1）据图指出……（2 分，理解）
（2）解释为什么……（4 分，理解→分析）
（3）若……，推测……（4 分，应用→分析）
（4）该方案是否合理，说明理由（4 分，评价）
```

四问全在同一层级，说明这道题只考了一件事，拆开或换掉一问。

## 五、评分细则

细则写到"另一个老师拿着它能给出同样的分"才算合格。

**每条采分点写四样**

1. 采分内容（必须出现的关键词或关系）
2. 分值
3. 可接受的等价表述（至少 1 条）
4. 扣分点（写错哪个词不给分）

示例：

```
17.（10 分）
① 等位基因随同源染色体的分开而分离（2 分）
   等价：减数第一次分裂时，同源染色体分离，其上的等位基因随之分开
   不给分：只写"基因分离"未说明"同源染色体"
② 受精时雌雄配子随机结合（2 分）
   等价：不同类型的雌雄配子结合机会均等
   不给分：写成"配子自由组合"（与自由组合定律混淆）
③ 因此 F₂ 出现 3:1 的性状分离比（2 分）
   等价：显性与隐性个体数之比接近 3:1
```

**禁止的细则写法**："意思对即可""酌情给分""视情况扣分"——这类表述等于没有细则。

## 六、难度预估

不看"感觉难不难"，看三个可数指标：

| 指标 | 易 | 中 | 难 |
|---|---|---|---|
| 解题步骤数 | 1–2 步 | 3–4 步 | ≥ 5 步 |
| 信息跨度 | 单句可读完 | 需前后对照 | 需跨图/表/文整合 |
| 认知层级 | 记忆/理解 | 应用 | 分析/评价 |

三项里两项落在"难"，就标难；两项落在"易"，标易；其余标中。

## 七、出卷后的自检（逐题过一遍）

1. 这道题考的是不是细目表上写的那个考点？
2. 答案是否唯一？（选择题四个选项有没有两个都对）
3. 学生要错，会错在哪一步？（写不出就说明题目指向不清）
4. 有没有依赖学生没学过的前提？
5. 分值是否与思维量匹配？（两步推理给 6 分是虚高）
6. 题干能不能删掉一半而不影响作答？（能删就删）

## 八、改编题的规矩

- 改情境不改考点，改数据必重算。
- 原题有图表，改编后图表必须重画，不能截图。
- 标注来源，写清"改编"还是"引用"。
- 一次考试里，引用真题不超过总分的 30%，其余自编。
