# 遗传推演工作台

> 遗传题不靠灵感，靠流程。本文件给一套固定动作：先定基因型，再定配子，再算比例，最后验算。四步走完还不对，就是题目数据有问题，不是学生的问题。

## 一、四步流程

1. **定关系**：判断显隐性、基因位置（常染色体 / X / Y）、是否连锁。
2. **定基因型**：从表现型反推，能确定的写死，不能确定的写"AA 或 Aa（比例未知）"。
3. **定配子**：先算每个亲本产生哪些配子及比例，再组合。配子法比棋盘法快，棋盘法用来验算。
4. **算比例**：独立事件相乘，互斥事件相加；遇到"已知表现型"要剔除不可能基因型（条件概率）。

## 二、显隐性与位置的判断

| 证据 | 结论 |
|---|---|
| 无中生有（双亲正常，子代患病） | 隐性 |
| 有中生无（双亲患病，子代正常） | 显性 |
| 隐性 + 女患者的父亲或儿子正常 | 非伴 X 隐性（常染色体） |
| 显性 + 男患者的母亲或女儿正常 | 非伴 X 显性（常染色体） |
| 患者全为男性且父传子 | 伴 Y |
| 正交反交结果不同 | 可能伴性遗传或细胞质遗传 |

口诀只用于快速筛，最终必须回到"基因型—配子—子代"验证一遍，口诀在伴性 + 致死的组合情境下会失效。

## 三、常用计算

### 1. 一对等位基因

- Aa × Aa → 1 AA : 2 Aa : 1 aa（表现型 3:1，完全显性）
- Aa × aa → 1 Aa : 1 aa（测交）
- 连续自交 n 代：杂合子比例 (1/2)ⁿ，纯合子 1 − (1/2)ⁿ（两种纯合子各占一半）

### 2. 两对等位基因（独立分配）

- AaBb × AaBb → 9 A_B_ : 3 A_bb : 3 aaB_ : 1 aabb
- AaBb × aabb → 1:1:1:1（测交）
- 配子种类：n 对杂合 → 2ⁿ 种

### 3. 自由交配（群体）

用基因频率算。A 频率 p，a 频率 q，p + q = 1：

- 子代 AA = p²，Aa = 2pq，aa = q²

注意：自交改变基因型频率、不改变基因频率；自由交配在理想条件下两者都不变。二者不可混用。

### 4. 9:3:3:1 的常见变形

| 表现型比 | 机制 | 典型情形 |
|---|---|---|
| 9:7 | 互补作用 | 两个显性基因同时存在才有表型 |
| 15:1 | 重叠作用 | 只要有任一个显性基因即同一表型 |
| 9:3:4 | 隐性上位 | 一对隐性基因掩盖另一对基因的表达 |
| 12:3:1 | 显性上位 | 一个显性基因掩盖另一对基因 |
| 9:6:1 | 累加作用 | 显性基因个数决定表型等级 |
| 13:3 | 抑制作用 | 一个显性基因抑制另一基因表达 |

识别方法：先把 16 份拆开看有没有 9、3、3、1 的组合，再判断"谁掩盖谁"。

### 5. 致死情形

- 显性纯合致死：Aa × Aa → 2 Aa : 1 aa（表现型 2:1）
- 隐性纯合致死：Aa × Aa → 1 AA : 2 Aa（全为显性）
- 配子致死：先去掉致死配子，再按剩余配子比例组合

遇到比例不是 3:1、9:3:3:1 的整数倍，先查致死，再查基因互作。

## 四、遗传图解规范（学生最常丢分的地方）

一个完整的遗传图解必须有五样：

1. 亲本表现型与基因型（P：高茎 AA × 矮茎 aa）
2. 配子（标明种类与比例）
3. 子代基因型（F₁：Aa）
4. 子代表现型与比例
5. 符号规范（× 表示杂交，⊗ 表示自交，箭头表示产生配子）

缺"配子"这一行是最常见的失分点，批改时直接扣该点分值，不整题扣。

## 五、验算四步（提交前必做）

1. **配子总数校验**：两亲本配子种类数相乘，应等于子代组合数（如 4 × 4 = 16）。
2. **比例加和校验**：所有表现型比例之和应等于总份数（16 份则加起来是 16）。
3. **极端情形校验**：把某个基因型换成纯合，结果是否退化为已知的简单比例。
4. **反推校验**：由子代比例反推亲本基因型，能否回到题设。

四步中任一步不通，先怀疑题目数据，再怀疑自己的推导。

## 六、命题时的数据自洽要求

出遗传题时，数据必须能被上述流程走出来。三条硬规矩：

- 给出的比例要能被 16、8、4 整除，或明确说明存在致死。
- 系谱图的人数与题干描述一致，不出现"图中 7 人、文字 8 人"。
- 若涉及两种遗传病，明确是否独立遗传，不默认。

## 七、常见陷阱清单

| 陷阱 | 表现 | 应对 |
|---|---|---|
| 把"自由交配"当"自交" | 直接用 (1/2)ⁿ | 看是否同一个体 |
| 忘记剔除致死个体 | 比例分母用错 | 先算总数再去掉 |
| 条件概率未剔除 | "已知表现型正常"仍按 1/4 算 | 分母改为 3/4 |
| 伴性遗传忽略性别 | 男女合并算 | 分性别列表 |
| 连锁当独立 | 直接 9:3:3:1 | 先看是否同一对同源染色体 |
| 把"基因频率"与"基因型频率"混用 | 数值对不上 | 先写 p、q 再算 |
