# 概念阶梯：模块、层级与可测动词

> 本文件是备课与命题时的"口径尺"。内容按《普通高中生物学课程标准（2017 年版 2020 年修订）》的模块划分整理，具体章节顺序以学校在用教材为准。

## 一、五个模块与枢纽概念

| 模块 | 枢纽概念（后面要靠它） | 常见课时 | 最容易塌的地方 |
|---|---|---|---|
| 分子与细胞 | 结构与功能相适应；蛋白质与核酸；ATP 是直接能源 | 30–36 | 酶的作用机理、光合与呼吸的物质去向 |
| 遗传与进化 | 基因的传递规律；基因表达；变异与选择 | 32–40 | 分离与自由组合的适用前提、概率计算 |
| 稳态与调节 | 反馈调节；神经—体液—免疫网络 | 26–32 | 静息/动作电位的离子流向、分级与反馈 |
| 生物与环境 | 种群数量变化；能量流动与物质循环 | 18–22 | 能量传递效率、J 型与 S 型的条件 |
| 生物技术与工程 | 目的基因的获取与表达；发酵工程 | 16–20 | 载体与工具酶的作用对象、无菌操作 |

## 二、认知层级与可测动词

命题和写目标时只从右列取词。左列的词不要出现在教学目标里。

| 层级 | 含义 | 不要用 | 改用 |
|---|---|---|---|
| 记忆 | 再认事实、术语、符号 | 了解、知道、熟悉 | 说出、写出、指出、列出、标注 |
| 理解 | 解释、转述、举例、比较 | 理解、掌握、领会 | 解释、说明理由、举例、比较……与……的异同、用自己的话概述 |
| 应用 | 在新情境中使用规则 | 运用、灵活运用 | 计算、预测、推断、绘制、根据……判断 |
| 分析 | 拆解关系、找因果、辨误 | 分析、深入理解 | 指出……的原因、判断……是否成立并说明依据、区分……与…… |
| 评价 | 依据标准判断方案优劣 | 体会、感悟 | 评价……的合理性、指出方案的不足并改进 |

**一条目标合格的三个条件**：有行为动词、有具体内容、有可观察的产出。缺一条就重写。

## 三、各模块的概念依赖链（节选）

### 分子与细胞

```
元素与化合物 → 蛋白质/核酸的结构 → 细胞结构与功能 → 物质跨膜运输
      ↓                                   ↓
  酶与ATP ←─────────────── 细胞代谢（光合 / 呼吸）
      ↓
  细胞增殖 → 分化 → 衰老与凋亡
```

关键依赖：不了解"蛋白质结构多样性与功能的关系"，后面学载体蛋白、酶、抗体都会变成背结论。

### 遗传与进化

```
孟德尔实验方法（假说—演绎） → 一对相对性状 → 分离定律
                                    ↓
                            两对相对性状 → 自由组合定律
                                    ↓
减数分裂（染色体行为） → 基因与染色体的关系 → 伴性遗传
                                    ↓
                        基因表达 → 变异 → 进化与选择
```

关键依赖：分离定律必须先于减数分裂讲清"分离的是什么"，否则学生会把"基因分离"和"染色体分离"当成两件事。

### 稳态与调节

```
内环境与稳态 → 神经调节（兴奋的产生与传导） → 体液调节 → 免疫调节
                          ↓                        ↓
                    分级调节与反馈调节 ←──── 神经—体液—免疫网络
```

### 生物与环境

```
种群特征 → 种群数量变化（J/S 型） → 群落结构 → 生态系统
                                              ↓
                                    能量流动 / 物质循环 / 信息传递
```

## 四、课时锚点（可按校情浮动）

## 五、跨版本差异提示

- 人教版把"遗传因子的发现"放在必修 2 第 1 章；部分版本先讲减数分裂再讲孟德尔，命题时若跨版本联考，需先统一顺序。
- "生物技术与工程"在不同版本的册次安排差异较大，选考范围以本省考试院文件为准。
- 教材实验的材料（如根尖材料、色素提取用的叶片）各版本表述略有差异，写实验方案时按本校教材核对。

## 六、使用方式

1. 写教学目标：从第二节取动词，从第一节取内容。
2. 排课时：用第三节的依赖链定先后，用第四节的锚点定课时。
3. 命题：按第一节的"易塌点"加权，保证每份卷子至少覆盖两个易塌点。
4. 遇到版本差异：按依赖链排，不按页码排，并在成品里标注差异。
