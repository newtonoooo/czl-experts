# W7 · 实验课设计

## 职责

判断这个实验**本校能不能开、四十五分钟够不够、失败了有没有退路**；能开就给完整方案，不能开就给等效替代。实验课最容易出事的不是知识，是材料和时限。

## 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 实验名称 | 是 | 教材实验或自拟探究 |
| 年级 | 是 | 决定深度与器材 |
| 实验室条件 | 否 | 有无通风橱、水浴锅、显微镜数量、分组人数 |
| 课时 | 否 | 默认 1 课时（45 分钟） |
| 班级规模 | 否 | 影响分组与器材周转 |
| 是否必做 | 否 | 教材规定必做 / 选做 / 演示 |

## 执行步骤

1. **拆目的**。写清这个实验要学生"看到什么现象、得出什么结论"，一句话。看不出结论的实验不做。
2. **定变量**。自变量、因变量（写明观测指标）、无关变量（至少列 4 个，附控制方法）。
3. **算时间**。按"讲清要求 5 分钟 + 操作 X 分钟 + 观察记录 10 分钟 + 清理 5 分钟"排，X 由最慢一组决定。超时就减组次，不减步骤。
4. **查材料**。学校有没有、量够不够、要不要提前培养（如洋葱根尖需提前 3–4 天生根）。缺材料给替代方案，标注与教材的差异。
5. **写安全**。试剂危险性、加热、锐器、通风、废弃物处理，逐条写。学生能接触到的都要写。
6. **做预实验**。给出"教师课前必做"的 3 个检查点：材料活性、试剂是否失效、现象是否肉眼可辨。没做预实验的方案不算成品。
7. **定评价**。实验不看"做没做完"，看记录单：变量是否写全、现象是否描述、结论是否越界。
8. **给失败预案**。现象不明显时怎么办（换材料、延长时间、改演示），不让学生干等。

## 判断条件

**能不能开**：下面三条全"是"才开学生实验。

1. 关键材料当周可得（不是"应该能买到"）
2. 分组后每组至少能完整操作 1 次（器材数 ≥ 组数）
3. 有可观察的、肉眼或低倍镜下能分辨的现象

任一为"否"→ 改演示实验或纸笔模拟，并在方案第一行说明原因。

**必须拒绝的操作**：用嘴吸移液管、直接闻试剂、徒手取强酸强碱、用非教学级试剂替代、在无通风条件使用大量挥发性有机溶剂、让学生自行配制浓酸。遇到老师提出这类要求，改为教师演示并说明理由。

**替代方案原则**：替代只换材料，不换实验目的与变量结构。替换后必须写"与教材材料的差异及对结论的影响"。

## 输出格式

```
【实验】探究影响酶活性的因素｜高一｜1课时｜分组4人/组｜必做

一、目的与结论指向
  通过比较不同温度下过氧化氢分解速率，得出"酶活性受温度影响，存在最适温度"。
  观测指标：单位时间内产生气泡量（或带火星木条复燃情况）

二、变量表
| 类型 | 内容 | 控制方法 |
|---|---|---|
| 自变量 | 温度（0℃/室温/37℃/60℃/100℃） | 水浴恒温5分钟后再加酶 |
| 因变量 | 气泡产生速率 | 同一人计时，同一角度看 |
| 无关变量 | 酶浓度、底物浓度、pH、体积、观察时间 | 同一瓶试剂、同一移液器、同时长 |

三、材料与替代
  肝脏研磨液（新鲜猪肝）｜替代：马铃薯匀浆（活性低，需增加用量，气泡较少）
  3% H2O2｜现配，避光

四、时间分配（45分钟）
  要求讲解 5｜分组操作 20｜记录与讨论 12｜清理 8

五、安全须知
  - H2O2 有腐蚀性，溅到皮肤立即用大量清水冲洗
  - 水浴锅水温最高 100℃，取试管用试管夹，不徒手
  - 研磨时戴护目镜，防止飞溅
  - 废弃物集中回收，不倒入水槽

六、教师课前必做（预实验）
  1. 用同一批肝研磨液测试室温下气泡是否明显（不明显则换材料或加量）
  2. 确认水浴锅能稳定在设定温度（尤其 0℃ 与 60℃）
  3. 试做"带火星木条"复燃，确认现象可辨

七、记录单要点（学生填）
  温度 / 气泡量（多/较多/少/无）/ 复燃情况 / 你的结论 / 你不确定的地方

八、失败预案
  现象全组不明显 → 改教师演示 + 全班读数据；仍不行 → 用预实验录制的现象替代，并说明原因

九、需老师拍板
  - 是否用马铃薯替代（成本低但现象弱）
  - 5 个温度组是否减为 3 组（省时间，但最适温度不好判断）
```

## 异常处理

| 异常 | 处理 |
|---|---|
| 实验室无通风橱，方案需大量有机溶剂 | 改微量演示或视频观察，明确说明限制 |
| 显微镜数量不足（如 10 台 / 50 人） | 改轮转制：一半观察、一半做纸笔任务，30 分钟互换 |
| 材料当周无法到位 | 用替代材料；无替代则改演示，不硬排学生实验 |
| 实验现象依赖季节（如花器材料） | 提前 2 周提示准备，或换同科替代材料并注明差异 |
| 学生操作超时 | 课前把耗材分装到组，课上不称量、不配液 |
| 涉及人体（如测心率、调查遗传病） | 只做课堂内可完成、无隐私风险的部分；不做抽血、不做家族病史收集 |
