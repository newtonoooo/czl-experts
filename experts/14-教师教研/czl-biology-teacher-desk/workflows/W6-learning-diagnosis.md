# W6 · 学情诊断与分层

## 职责

把分数翻译成教学动作。回答三个问题：**哪个板块真的塌了、塌在哪个环节、下周的课上什么**。不做"均分多少、及格率多少"这种只描述不决策的报告。

## 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 成绩数据 | 是 | CSV：一行一个学生，一列一题（或一列一板块） |
| 满分设置 | 是 | 每题满分，或用百分比得分 |
| 题目—考点对照 | 是 | 哪题考什么（W4 的细目表可直接用） |
| 班级信息 | 否 | 班型、人数、上次均分（用于纵向比较） |
| 批阅错因表 | 否 | 有则归因更准（W5 产出） |

## 执行步骤

1. **清洗**。缺考、零分卷、转学生单独列出，不混进统计。缺失值不填 0，标 NA。
2. **跑统计**。用 `score_report.py` 出：均分、中位数、标准差、分数段、每题得分率、难度 P、区分度 D（高分组/低分组各取 27%）。
3. **找塌方**。按得分率分三档：< 40% 全班塌方（要重教）、40%–60% 部分掌握（要补漏）、> 60% 基本过关（要巩固）。
4. **看区分度**。D < 0.2 的题：要么太容易（可删）、要么表述有歧义（要改）。D 为负的题必须查，通常是答案或题干有问题。
5. **归因**。把塌方题对回考点与认知层级，判断是"没教到""教了没练""练了没测"还是"测了但表述不过关"。参照 W5 错因表。
6. **开处方**。按 A/B/C 三层给任务，每层写清：补什么、用什么材料、花多少时间、怎么验。
7. **定课时**。处方必须落在具体课时上，不写"加强训练"这种没有着落的话。

## 判断条件

**分档阈值**（可按班情调，调了写明）：

| 指标 | 阈值 | 含义 |
|---|---|---|
| 得分率 | < 40% | 全班塌方，需重教（不是讲评） |
| 得分率 | 40%–60% | 部分掌握，需补漏 + 变式 |
| 得分率 | > 60% | 基本过关，需巩固与提速 |
| 区分度 D | < 0.2 | 题的质量问题，优先改题 |
| 区分度 D | 0.2–0.3 | 可用，留意 |
| 区分度 D | > 0.3 | 好题，进题库 |

**归因判定表**：

| 现象 | 归因 | 动作 |
|---|---|---|
| 同一考点，选择题对、长句题错 | 表达不过关 | 上表达模板课（`references/expression-templates.md`） |
| 同一考点，简单情境对、新情境错 | 迁移不足 | 变式训练，换情境不换考点 |
| 全班都错且选项集中 | 教学未覆盖或概念讲反 | 重教，先查自己的板书 |
| 高分组错、低分组对 | 题目歧义 | 改题，不改学生 |
| 计算题步骤对、结果错 | 计算习惯 | 限时计算专项，每次 5 题 |

**分层规则**：按本次总分 + 板块得分率双维度分，不按总分一刀切。存在"总分高但遗传板块塌"的学生，单独列。

## 输出格式

```
【学情诊断】高一(3)班 单元测｜46人（缺考2人已剔除）

一、总体
  均分 61.4｜中位数 63｜标准差 12.8｜最高 92｜最低 31
  分数段：≥85 3人｜70-84 12人｜60-69 15人｜45-59 11人｜<45 5人

二、板块得分率
| 板块 | 分值 | 得分率 | 判定 |
|---|---|---|---|
| 分离定律 | 28 | 71% | 过关 |
| 自由组合 | 30 | 43% | 补漏 |
| 遗传系谱 | 22 | 36% | 塌方 |
| 实验设计 | 20 | 52% | 补漏 |

三、失分点 Top 4（附归因）
  1. 系谱中"隔代遗传"判断（得分率 31%）→ 概念不清：把"隔代"当"伴性"
  2. 9:3:3:1 变形识别（38%）→ 迁移不足：只会标准比
  3. 遗传图解规范书写（45%）→ 表达不规范：缺配子一代
  4. 概率连乘（57%）→ 计算失误：独立事件前提没判断

四、分层处方
  A层（≥75，11人）：变式挑战 6 题 + 一道开放实验设计；不占正课，课后完成
  B层（60-74，20人）：系谱专项 1 课时 + 9:3:3:1 变形 1 课时；配变式卷
  C层（<60，15人）：回到"配子法"重教 1 课时；只做基础判断与图解书写

五、下周课时安排（落到具体节次）
  周二第2节：全班组卷讲评（只讲 Top 3，不逐题）
  周四第3节：B/C 分层走班（C 层配子法，B 层变形识别）
  周五：A 层挑战题反馈（10 分钟）

六、需老师拍板
  - C 层是否占用一节正课（会挤掉后面的新课进度）
  - A 层任务是否计入平时分
```

## 异常处理

| 异常 | 处理 |
|---|---|
| 只有总分，没有分题 | 只能出总体分布，明确写"缺题目级数据，无法定位板块"；建议下次按题录入 |
| 人数过少（< 15） | 不做区分度，只做得分率；说明统计意义有限 |
| 数据里带姓名 | 先脱敏再做统计，输出不含姓名 |
| 两次考试难度不同 | 不做均分直接对比，改用得分率与位次变化 |
| 班级间比较 | 只在同一份卷子、同一评分标准下比较；否则不比 |
| 老师要求"算出能上 985 的人数" | 不做个体预测；可给"当前得分段对应的能力缺口" |

## 依赖

- `skills/czl-bio-teacher-kit/scripts/score_report.py`
- W4 细目表（题目—考点对照）
- W5 错因表（可选，提升归因质量）
- `references/misconception-atlas.md`（把错因对到具体迷思）

## 与其他工作流的关系

- 上游：W4（卷子与细目表）、W5（批阅与错因）。
- 下游：W3（补漏课、讲评课）、W4（变式卷、补救卷）。
- 回流：处方执行后再测一次，用同一批考点做前后对比，不进 W1 重开任务。
