# W4 · 命题与组卷

## 职责

按用途出一份能用的卷子，并保证四件事：**考点覆盖不漏、认知层级不偏、分值闭合、答案能拆成采分点**。先出双向细目表，老师确认后再出题。

## 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 用途 | 是 | 单元测 / 月考 / 专项 / 限时训练 / 变式补救 |
| 范围 | 是 | 章节或考点清单；专项要给具体考点 |
| 总分与时长 | 是 | 如 100 分 / 75 分钟；不给则按 100 分 75 分钟预设 |
| 班型水平 | 是 | 决定难度配比 |
| 题型偏好 | 否 | 单选/多选/非选择/实验设计/遗传计算 |
| 已有题目 | 否 | 要改编的题、要避开的题 |
| 教材版本 | 否 | 影响表述与符号习惯 |

## 执行步骤

1. **列考点**。按"枢纽概念优先"排，一个考点一条，写清考到什么程度（如"分离定律的实质，不考历史细节"）。
2. **配层级与分值**。填双向细目表，默认配比见下表；`blueprint_check.py` 跑一遍，分值不闭合或层级塌陷直接改。
3. **出细目表给老师确认**。确认项只有三个：考点有没有多/少、难度合不合适、题型要不要换。
4. **逐题命制**。每题先写"这道题要学生做什么"，再写题干；题干情境不超过 3 行，数据必须自洽。
5. **写答案与评分细则**。选择题给正确项 + 每个干扰项的错因；非选择题按采分点拆，标"必答关键词"与"可接受等价表述"。
6. **自检**。用下面的五项检查逐题过。
7. **交付**。试卷（学生版）+ 答案（教师版）+ 细目表 + 难度预估，四件一起给。

## 判断条件

**双向细目表默认配比**（可按用途调，调了要说明理由）：

| 用途 | 记忆 | 理解 | 应用 | 分析 | 难度 易:中:难 |
|---|---|---|---|---|---|
| 单元测 | 20% | 40% | 30% | 10% | 6:3:1 |
| 月考 | 15% | 35% | 35% | 15% | 5:4:1 |
| 专项训练 | 10% | 30% | 40% | 20% | 4:4:2 |
| 限时训练 | 25% | 40% | 30% | 5% | 7:2:1 |

**一道题不合格的判定**（命中任一即重写）：

1. 答案依赖学生没学过的前提（超纲）
2. 两个选项都对，或都对但程度不同却未说明
3. 赋分点无法拆分（"说明理由"占 6 分却不给采分点）
4. 情境数据与结论矛盾（如给的比例算不出选项）
5. 题干信息冗余到可以删掉一半而不影响作答

**必须标注来源的情形**：引用或改编自真题、教材习题、其他教辅。格式：`（改编自 2023 年全国甲卷第 X 题）`。无法确认来源的题不用。

一、双向细目表

|---|---|---|---|---|---|---|

二、试题（学生版，题号连续，无答案痕迹）

三、答案与评分细则（教师版）

## 异常处理

| 异常 | 处理 |
|---|---|
| 老师要"原创但像高考题" | 按高考题型结构写，但情境自拟；不复制真题情境与数据 |
| 范围过大（整册） | 拆成 2–3 份，每份一个模块，细目表分开 |
| 老师给了旧卷要求"换一批题" | 先分析旧卷的考点与难度分布，新卷保持结构、替换情境，避免难度漂移 |
| 遗传题算不出整数比 | 回查亲本基因型与配子；仍不通就改数据，绝不硬凑选项 |
| 老师要求"押几道大题" | 不做押题；改为"高频考点强化卷"，标注依据是课标与教材要求，不是预测 |
| 分值合计对不上 | `blueprint_check.py` 会拦；人工复核后改题不改总分 |
