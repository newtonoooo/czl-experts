# W2 · 单元架构

## 职责

把一个单元（章）拆成有先后逻辑的课时序列，并给出单元级评价方案。解决三个具体问题：**先教什么后教什么、每节几课时、这个单元怎么算学明白了**。

## 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 单元范围 | 是 | 章名或"必修X第X章"，含节标题清单 |
| 总课时 | 是 | 学校给的实打实课时（含实验、讲评） |
| 年级与班型 | 是 | 影响深度与练习量 |
| 已有进度 | 否 | 已经上到哪、哪些内容学生学过 |
| 考试节点 | 否 | 月考/期中范围，决定哪里必须收口 |

## 执行步骤

1. **列概念**。把本单元的概念按"事实—概念—规律—模型"四类列出来，标出哪一个是本单元的"枢纽概念"（后面章节要靠它）。参照 `references/concept-ladder.md`。
2. **画依赖**。用箭头标出"不学 A 就学不了 B"的关系。出现环，说明概念切分有问题，回去拆。
3. **排课时**。每个概念群给基础课时，实验单列，讲评预留 1 课时。总课时不够时按下面的压缩优先级砍。
4. **定评价**。单元末要给一次"能不能过"的判断：用一份 20–25 分钟的小测（不是整卷），覆盖 3–4 个枢纽概念，达标线写清楚。
5. **标风险点**。列出本单元三个最容易塌的地方（如"自由组合的 9:3:3:1 变形""遗传系谱中'隔代'的判断"），在设计课时时就留出补救位。
6. **交给 W3**。每课时一行，写明节名、课时数、核心任务、对应评价证据。

## 判断条件

**课时不够时的压缩顺序**（从先砍到后砍）：

1. 拓展性应用举例（可移到作业）
2. 重复性练习课时（合并为一次限时训练）
3. 非枢纽概念的探究活动（改为演示实验）
4. 章节复习课（并入讲评课）

**不能砍的**：枢纽概念的新授课、教材规定的必做实验、单元评价。

**判断是否要拆单元**：单个概念群超过 4 课时仍讲不完，说明切分粒度过大，拆成两个单元或用"总—分—总"重组。

## 输出格式

```
【单元】必修2 第1章 遗传因子的发现   总课时 8（新授5 + 实验1 + 讲评1 + 单元评价1）

一、概念依赖
  孟德尔实验方法 → 一对相对性状杂交 → 分离现象的解释 → 分离定律的验证
                        ↘ 假说—演绎法（贯穿）
  两对相对性状 → 自由组合 → 9:3:3:1 及其变形

二、课时分配
| 序 | 内容 | 课时 | 核心任务 | 评价证据 |
|---|---|---|---|---|
| 1 | 一对相对性状的杂交实验 | 1 | 说出为什么选豌豆、怎么去雄 | 口述+实验设计单 |
| 2 | 对分离现象的解释 | 1 | 用配子法解释 3:1 | 板演+检测1 |
| ... |

三、单元评价
  形式：25 分钟小测（6 题）  达标线：枢纽概念题全对率 ≥ 70%
  必含：一道"解释异常分离比"的分析题（区分 3:1 的记忆与应用）

四、三个易塌点
  1. 去雄与套袋的时序（操作类，学生背步骤不理解原因）
  2. "假说"与"结论"混淆
  3. 9:3:3:1 变形的识别（16 份组合的拆分）

五、需老师拍板
  - 实验是否开（材料：豌豆花器小，可用替代方案，见 W7）
  - 单元评价放在讲评课前还是后
```

## 异常处理

| 异常 | 处理 |
|---|---|
| 总课时明显不足（如 4 课时上完 8 课时内容） | 给"最低可完成版本"+ 被砍内容清单，让老师签字式确认 |
| 学校不开实验 | 用 W7 的替代方案，改为演示或视频观察 + 纸笔模拟，评价方式同步改 |
| 跨版本章节顺序不同 | 按概念依赖排，不按教材页码排；标注"与本校教材顺序差异" |
| 老师只想"排个进度表" | 仍给概念依赖，否则进度表没有依据；但只输出课时表，不展开教案 |
