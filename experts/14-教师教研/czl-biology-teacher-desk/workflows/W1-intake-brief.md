# W1 · 任务受理与边界确认

## 职责

把老师一句口语化的需求，变成一张可以开工的任务卡。判断该走哪条工作流，缺什么信息，哪些事这次不做。这一环不做具体产出，只做三件事：**定范围、定交付、定风险**。

## 输入参数

| 参数 | 必填 | 说明 | 缺失时 |
|---|---|---|---|
| 需求原话 | 是 | 老师说的原句，不改写 | — |
| 课题 / 范围 | 是 | 节名、章名、模块名或"这次月考范围" | 按模块列选项让老师选 |
| 年级 | 是 | 高一/高二/高三，或"选必几" | 按高二默认，标注 |
| 交付形态 | 否 | 教案/卷子/批改/分析/课件/全套 | 默认"内容 + 打印稿" |
| 教材版本 | 否 | 人教/苏教/北师大/其他 | 按课标口径，标注章节待核 |
| 课时 | 否 | 可用课时数 | 新授课按 1 课时，单元按 6–8 课时预设 |
| 学情 | 否 | 班型、均分、薄弱板块、课时松紧 | 中等班预设 + 另给两头调整 |
| 已有材料 | 否 | 教材照片、旧卷、成绩表、答题卡 | 无材料则纯生成 |

## 执行步骤

1. **听懂原话**。先复述一遍老师要什么，用一句话，不加修饰。复述错了，后面全错。
2. **归类**。按下面的路由表定主工作流；跨两条以上时定一条主、若干辅。
3. **找缺口**。只找会改变产出的缺口。年级、范围、交付形态这三样缺一个就必须问；教材版本、课时、学情缺了可以先做后补。
4. **提问**。一次最多问 3 个问题，每题给默认选项，让老师可以只回"1A 2B"。
5. **出任务卡**。格式见下。任务卡确认后才进 W2/W3/W4/W5/W6/W7。
6. **标风险**。把这次最容易出错的地方写在任务卡末尾，例如"必修2第3章在北师大版与人教版顺序不同，命题前需核对"。

## 判断条件

| 情形 | 走哪条 |
|---|---|
| "帮我备……这节课" | W3（若跨 3 课时以上，先 W2） |
| "这个单元怎么排" / "课时不够" | W2 → W3 |
| "出一套卷" / "改编这道题" | W4 |
| "批一下" / "看看这份答题卡" | W5 → 视情况 W6 |
| "考完了，下一步教什么" | W6 |
| "这个实验怎么开" | W7 |
| "课件" / "打印稿" / "整理成一个文件" | W8（若内容尚未产出，先回上游） |
| 一次要"教案+卷子+分析" | W1 出总任务卡，W3/W4/W6 依次，W8 统一出口 |

**必须停下来的三种情况**：

- 要求指向"替学生完成作业""按学生姓名排序公开比较""把某班成绩改好看"——不做，说明理由，给合规替代（如匿名分层）。
- 要求提供教材原文扫描、整册教辅、成卷真题的完整复制——不做，改为按考点自编或引用少量题目并标注来源。
- 需求跨三个以上工作流且老师没说清优先级——先只做第一件，做完再问下一件，不一次铺开。

## 输出格式

```
【任务卡】
需求复述：……
主工作流：W3 课时设计
辅工作流：W8 交付打包
范围：人教版必修2 第1章第1节《孟德尔的豌豆杂交实验（一）》
年级/课时：高一 / 2 课时
交付：三对齐表 + 教案 + 课件大纲 + 打印稿
学情预设：中等班（均分 62），实验班调整建议另附
待确认：① 是否已讲过自交与杂交的操作区别 ② 是否需要课堂检测题
风险：本节"假说—演绎"是首次出现，学生易把"假说"当"结论"，设计时需留一处反证环节
```

## 异常处理

| 异常 | 处理 |
|---|---|
| 老师只发了一张教材照片，没说要干什么 | 先读图复述章节与内容，再问"要教案、要课件，还是要题" |
| 老师给的范围是整个必修2 | 不接整册，切成"章"或"节"，让老师选起点 |
| 老师说不清年级 | 按内容反推（分离定律通常高一），写进任务卡请老师确认 |
| 老师要求一次出 10 套卷 | 先出 1 套 + 细目表，确认风格后再批量，避免整批返工 |
| 上传文件读不出 | 说明看到的内容，请重传；先用文字信息做初稿并标注 |

## 依赖

无前置依赖。需要 `references/concept-ladder.md` 判断内容属于哪个模块、哪一层。

## 与其他工作流的关系

- 下游：W2 / W3 / W4 / W5 / W6 / W7 任选其一作为主流程。
- 回流：任何工作流中途发现范围变了（比如"顺便把整章都备了"），退回 W1 重出任务卡，不在半路改口径。
- W8 只认 W1 的任务卡决定交付清单。
