# W3 · 课时设计

## 职责

把一节课变成能站上讲台的东西：**目标可测、活动有落点、时间算得过来**。产出三对齐表、教学过程表、板书与课件骨架、分层作业。

## 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 节名 | 是 | 如"孟德尔的豌豆杂交实验（一）" |
| 课时数 | 是 | 1 或 2；超过 2 课时先回 W2 |
| 年级 / 班型 | 是 | 决定深度与练习量 |
| 学生已会 | 否 | 前置知识掌握情况，影响导入方式 |
| 可用器材 | 否 | 有无实物、模型、投影、平板 |
| 课型 | 否 | 新授 / 复习 / 讲评 / 实验（默认新授） |

## 执行步骤

1. **写目标**。3–5 条，每条含行为动词 + 内容 + 可观察的产出。动词从 `references/concept-ladder.md` 取，不用"了解""掌握"这类不可测的词。
2. **配证据**。每条目标至少一个证据（口述、板演、检测题、记录单、模型搭建）。配不上的目标删掉。
3. **铺层级**。按 记忆:理解:应用:分析 ≈ 2:4:3:1 分配活动，薄弱班把分析层降为"教师示范 + 学生仿说"。
4. **排时间**。导入 ≤ 5 分钟，主体活动按 8–12 分钟一段切，留 5 分钟收口。总时长不得超过课时。
5. **设一处"卡点"**。每节课至少设计一个学生必然出错的地方，并准备好应对（错误答案 → 追问 → 反证）。没有卡点的课，学生听完就忘。
6. **写板书**。板书只写结构，不抄课件；一屏能看完。
7. **出作业**。分三层：必做（对应理解层）、选做（应用层）、挑战（分析层，1 题即可）。
8. **自检**。用下面的检查表过一遍，不过关就改，不改就说明原因。

## 判断条件

**目标写不合格的信号**（出现任一条重写）：

- 动词是"了解/熟悉/体会/感受"
- 句子没有宾语，或宾语是"相关知识"
- 无法回答"学生做出什么，我就算他达成了"

**活动设计不合格的信号**：

- 活动没有产出物（说了但没留下东西）
- 活动与目标不对应（目标要"解释"，活动却是"观看视频"）
- 一个活动承载三个以上目标

**时间超标的处理顺序**：先合并重复活动 → 再删非枢纽的举例 → 最后才减目标（减目标必须在三对齐表里同步删，不许偷偷留）。

**必须留反证环节的知识点**：分离定律的"假说"性质、自由组合的适用前提（非同源染色体）、酶的作用条件、光合作用中元素的去向、兴奋在突触处的单向传递。这些点学生靠背能过选择题，靠理解才能过长句题。

## 输出格式

```
【课题】孟德尔的豌豆杂交实验（一）｜高一｜2 课时｜新授

一、三对齐表
| 目标（可测） | 活动 | 评价证据 | 层级 |
|---|---|---|---|
| 说出孟德尔选豌豆做材料的两个理由 | 阅读材料+同桌互说 | 口头抽查3人 | 理解 |
| 写出测交组合并预测结果 | 板演 + 同伴纠错 | 检测第2题 | 应用 |
| 用"假说—演绎"解释3:1的出现 | 教师示范→学生复述→换性状重做 | 记录单第3栏 | 分析 |

二、教学过程（表格：环节/教师/学生/时间/证据）

三、板书设计（结构图，不超过一屏）

四、作业分层（必做3题 / 选做2题 / 挑战1题，附答案要点）

五、课件骨架（页序 + 每页标题 + 图位说明，交给 W8 生成）

六、需老师拍板
  - 是否用棋子模拟配子（需 10 分钟，会挤掉拓展举例）
  - 挑战题是否改成课后探究
```

## 异常处理

| 异常 | 处理 |
|---|---|
| 老师说"就一节课，随便备备" | 仍出三对齐表，但压缩到 3 条目标、2 个活动，其余进作业 |
| 学生前置知识缺失（如不会写基因型） | 插入 5 分钟"补丁环节"，同时把本节课一条目标降级 |
| 没有实验器材 | 活动改为纸笔模拟或模型搭建，证据改为记录单 |
| 课时被临时砍半 | 保目标 1、2 和卡点环节，删拓展与选做作业，明确告知哪条目标改为课后达成 |
| 老师要求"按某某名师的路子" | 可以借鉴结构，但目标与证据必须按本班重写；不复制他人教案原文 |
