# W8 · 交付打包

## 职责

所有成品从这里出去。做三件事：**过质量闸门、统一形态、留下复核清单**。任何内容没通过闸门，不许打包。

## 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 成稿 | 是 | W3/W4/W5/W6/W7 的产出 |
| 交付清单 | 是 | 来自 W1 任务卡 |
| 是否需要打印稿 | 否 | 默认需要 |
| 是否需要课件 | 否 | 默认按教案骨架给大纲 |
| 文件命名前缀 | 否 | 默认"内容_形态_日期" |

## 执行步骤

1. **过闸门**。逐条核对下面的五项检查，任一不过就打回上游，不带病交付。
2. **统一术语**。同一份材料里，"基因型/遗传因子""配子/生殖细胞"等用法前后一致；符号（A/a、X^B）全文统一。
3. **生成打印稿**。用 `make_docx.py` 转 A4 纵向、单列、宋体正文、黑体标题，表格保留边框。页码与页眉（课题 + 日期）一起给。
4. **生成课件大纲**（如需）。结构固定：封面 → 目录 → 分节页 → 内容页（每页一个要点 + 图位说明）→ 小结 → 作业页。每页标注"重点/难点/易错"标签。
5. **写复核清单**。列出需要老师人工确认的 3–6 条，每条具体到位置，不写"请核对内容"。
6. **命名归档**。文件名不含空格与特殊符号；同一课题的多个形态用同一前缀。
7. **交付说明**。三句话：这份东西是什么、哪里要老师定、下一步能做什么。

## 判断条件

**五项质量闸门**（全过才放行）：

| # | 检查项 | 不通过的典型表现 |
|---|---|---|
| 1 | 学科口径 | 概念表述与课标/教材冲突；遗传比例算错；实验变量写反 |
| 2 | 数据自洽 | 分值合计对不上；题干数据与选项矛盾；统计人数与名单不符 |
| 3 | 来源合规 | 引用了教材原文/真题成段复制未标注；使用了无出处的数据 |
| 4 | 可执行性 | 时间排不下；材料学校没有；分组人数与器材不匹配 |
| 5 | 可打印性 | 表格跨页断裂；字号小于五号；图没有说明 |

**必须打回上游的情形**：

- 目标不可测（回 W3）
- 细目表分值不闭合（回 W4，用脚本重跑）
- 评分细则缺采分点（回 W4）
- 学情结论没有数据支撑（回 W6）
- 实验方案未做预实验（回 W7）

**课件页数控制**：新授课 12–18 页，复习课 20–28 页，讲评课按错题数 + 6。超过上限说明内容没提炼，回 W3 删。

## 输出格式

```
【交付包】分离定律（2课时）

1. 分离定律_教案_20261101.docx（A4，6页）
2. 分离定律_三对齐表_20261101.docx（1页，可单独印发）
3. 分离定律_课堂检测_20261101.docx（学生版+教师版）
4. 分离定律_课件大纲_20261101.md（16页）
5. 分离定律_复核清单_20261101.md

【复核清单】
1. 第2课时"测交"环节用了 12 分钟，若班级基础弱建议压到 8 分钟（位置：教案第3页）
2. 课堂检测第4题的选项 C 与 D 区分度可能不足，建议改成"…"（位置：检测卷第1页）
3. 课件第9页的系谱图需按本校教材符号习惯重绘
4. 本单元未覆盖"分离定律在育种中的应用"，若月考涉及请补一页

【说明】
结构：2 课时教案 + 课堂检测 + 课件骨架，可直接进课堂。
需老师定：第1条的时间压缩、第4条是否补内容。
下一步：可基于本课检测数据做 W6 学情诊断，或扩成 W4 单元卷。
```

## 异常处理

| 异常 | 处理 |
|---|---|
| docx 生成失败（环境缺依赖） | 退回 Markdown 打印版，并在交付说明里注明"本次未生成 docx，原因：…" |
| 表格过宽 | 拆成两张表或改纵向排版，不缩字号 |
| 图片分辨率不足 | 标注"建议重绘"，不放大糊图充数 |
| 交付清单与实际产出不一致 | 以清单为准补做，或在说明里明确删减了哪项及原因 |
| 老师临时加需求 | 回 W1 重出任务卡，不在打包环节临时塞内容 |
