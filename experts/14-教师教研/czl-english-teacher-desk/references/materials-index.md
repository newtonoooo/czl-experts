# 素材来源、版权边界与替代方案（Materials Index）

> 这份文件解决一个现实问题：教学需要大量语篇和题目，但**大多数现成材料不能直接打包分发**。下面写清哪些能用、哪些不能用、不能用的怎么替代。

## 一、可以直接使用

| 类型 | 说明 | 使用条件 |
|---|---|---|
| 自编语篇 | 本产品生成的原创短文、对话、通知、书信 | 自由使用；建议标注"原创语篇" |
| 自编题目 | 依据考点自行命制的题目 | 自由使用 |
| 教师自有材料 | 教师本人撰写的教案、题目、讲义 | 需教师确认版权归属（职务作品可能属学校） |
| 法律法规、国家机关公文 | 如教育政策文件、考试说明中的公开条文 | 可引用，注明来源；不整本复制 |
| 已过著作权保护期的作品 | 作者逝世满 50 年（中国）的作品原文 | 可用原文；译文的版权独立，需另判 |
| 公开统计与事实数据 | 政府统计、公开报告中的数字 | 注明来源与年份；不整段搬运报告文字 |

## 二、不能直接打包分发

| 类型 | 风险 | 替代方案 |
|---|---|---|
| 教材课文原文 | 出版社享有著作权，整篇复制属复制发行 | 由教师提供页面后做**教学设计**（引用关键句），或自编同话题语篇 |
| 高考真题整卷 | 考试院/出版社享有权利，整卷传播需授权 | 只做**考点统计与思路拆解**，题目自编同构变式 |
| 教辅、练习册扫描件 | 明确侵权 | 按其考点结构自编同难度题目 |
| 外刊原文整段 | 原文著作权 + 转载限制 | 读后**实质改写**（换结构、换设问、降难度），标注"改编" |
| 他人课件、教案 | 著作权 | 只借鉴结构思路，重写内容与活动 |
| 图片、音频、视频素材 | 素材库授权范围不同 | 用自制图、公版图（CC0）或纯文字替代；音频由教师自录 |

"实质改写"的判断标准：句子结构、段落组织、设问角度都发生变化，且不保留原文的独特表达。换几个同义词不算改写。

## 三、外部素材获取（教师自行获取，不随包分发）

| 需求 | 建议渠道 | 注意 |
|---|---|---|
| 课标文本 | 教育部官网、省市教研部门公开文件 | 引用要点并注明版本年份 |
| 高考真题 | 各省教育考试院公开渠道、正规出版物 | 校内教学使用；不对外分发整卷 |
| 教材配套资源 | 出版社官方平台（需账号/授权） | 遵守平台使用条款 |
| 分级阅读语料 | 公版文学、开放教育语料库（看清许可） | 核对 CC 许可类型，保留署名 |
| 图片 | CC0 / Unsplash / Pexels 等 | 保留来源记录；不用含人脸的商业图 |
| 音频 | 教师自录或用开源 TTS | 不打包第三方有版权的听力音频 |

## 四、自编语篇的四步模板（缺口时的标准替代）

1. **定话题**：从单元主题语境取一个具体场景（不要"环境保护"这种大词，要"社区旧衣回收"）。
2. **定结构**：问题—尝试—结果，或现象—原因—对策，200–350 词。
3. **控语言**：生词率 ≤2%，句均 14–18 词，每段 3–5 句。
4. **留考点**：预埋 2 处可推断、1 处指代、1 处转折，供命题使用。

自编语篇的使用声明：**本文为教学原创语篇，人物与事件均为虚构，如有雷同纯属巧合。**

## 五、引用规范

- 引用他人观点：文中注明"（作者，年份）"，文末列来源。
- 引用数据：写清统计口径、年份、发布机构。
- 引用课标：写"《普通高中英语课程标准（2017 年版 2020 年修订）》"，不写"新课标要求"这种模糊说法。
- 改编材料：标注"改编自 X，用于教学，非原文"。

## 六、给教师的三条实务建议

1. **建立自己的语篇库**：每篇自编语篇存为独立文件，标注话题、词数、难度、可考点，三年就能攒出校本资源。
2. **真题只做"考点卡"**：把每道真题拆成"考点 + 设问方式 + 干扰类型"，不给学生整卷，既合规又高效。
3. **教材内容以"任务"呈现**：不复印课文，改为"读后完成任务单"，任务单是自编的，版权清晰。
