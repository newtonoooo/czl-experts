# 交付与文件规范（Delivery Spec）

> 用法：生成 docx、课件、表格时按本文件执行。目标是"打印出来能直接用"，不是"看起来丰富"。

## 一、文件命名

```
{类型}-{学段/教材}-{单元或考试}-{YYYYMMDD}.{ext}
```

示例：

- `教案-人教必修一-U3阅读-20261101.docx`
- `试卷-高一上-Unit3单元测-20261101.docx`
- `答案与解析-高一上-Unit3单元测-20261101.docx`
- `学情诊断-高一3班-月考-20261101.docx`
- `课件-人教必修一-U3阅读-20261101.pptx`

规则：
- 不含空格、不含 `/ \ : * ? " < > |`。
- 同一批次文件加同一日期后缀，便于归档。
- 学生个人批改单用编号：`批改单-S07-续写-20261101.docx`。

## 二、docx 版式

| 项目 | 规范 |
|---|---|
| 纸张 | A4，纵向；表格过宽时该页可横向 |
| 页边距 | 上下 2.2 cm，左右 1.8 cm（试卷左右 1.6 cm 便于排版） |
| 正文中文 | 宋体 / 思源宋体，五号（10.5 pt） |
| 正文英文 | Times New Roman 或 Calibri，五号 |
| 行距 | 1.25–1.5 倍；试卷可用 1.15 倍省纸 |
| 一级标题 | 小三加粗，段前 12 pt、段后 6 pt |
| 二级标题 | 四号加粗，段前 8 pt |
| 表格 | 三线表或全框线，表头加粗底纹 5% 灰 |
| 页码 | 页脚居中，"第 X 页 / 共 Y 页" |
| 页眉 | 左侧：文档名；右侧：日期或班级 |
| 试卷 | 页眉加"姓名____ 班级____ 得分____"，密封线可选 |

排版纪律：
- 不用艺术字、不用彩色标题（打印失真）。
- 英文段落不首行缩进两字符（用段间距分隔）。
- 表格内文字不换行挤压，列宽按内容分配。

## 三、试卷版式补充

1. 卷头四行：名称 / 时间 / 满分 / 注意事项。
2. 大题标题居中加粗（如"第二部分 阅读理解"）。
3. 小题编号连续，选项四行或两行对齐，不混排。
4. 答题卡单独一页，题号与试卷一一对应。
5. 答案与解析单独成册，不与学生版混排。

## 四、课件（pptx）页纲规范

| 页 | 内容 | 要点 |
|---|---|---|
| 1 | 封面 | 课题 / 课型 / 年级 / 教材 / 课时 |
| 2 | 目标 | 3 条以内，行为动词开头 |
| 3 | 导入 | 一张图 + 一个问题 |
| 4–5 | 呈现 | 核心词块/句型，配教材原句或例句 |
| 6–7 | 语篇 | 结构图 / 时间线 / 段落功能标注 |
| 8 | 操练 | 2–3 题，答案放备注 |
| 9 | 产出 | 任务 + 评价点 |
| 10 | 小结 | 知识树或一句话口诀 |
| 11 | 作业 | 三层，标时长 |

单页纪律：一页一个信息；正文不超过 6 行；字号不小于 20 pt；不用整段文字。

## 五、表格交付

- 细目表、台账、统计表优先 `.xlsx` 或 markdown 表格；表头固定、列宽适配。
- 数字右对齐，文字左对齐，百分比保留 1 位小数。
- 统计表必须带"口径说明"脚注（满分、人数、是否含缺考）。

## 六、交付清单（每次交付前核对）

- [ ] 对话版已给（结论 + 证据 + 方案 + 质检单）。
- [ ] 打印版已生成（.docx），文件名合规。
- [ ] 文件已用文件呈现方式打开，不只给路径。
- [ ] 需要课件的已给页纲或 .pptx。
- [ ] 质检单已填，未通过项写明原因。
- [ ] 结尾三行：成品清单 / 可调整点 / 一个延伸问题。

## 七、归档建议（给教师）

按"学期 / 单元 / 类型"三层建目录：

```
2026秋季-高一/
  Unit3/
    教案/
    试卷/
    学情/
    批改/
```

同一单元的教案、试卷、答案放在同一单元目录下，便于下一轮直接复用与修订。
