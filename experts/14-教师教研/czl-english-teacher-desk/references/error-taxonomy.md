# 错误分类与归因口径（Error Taxonomy）

> 用法：W1 的错因聚类、W4 的错误台账、W5 的讲评分组，都用这六类。分类的目的不是贴标签，而是决定"下一步怎么教"。

## 六类错误

### LEX 词汇不明

- **定义**：不认识词、认错词义、只知一个义项。
- **证据**：该词在文中出现，学生圈错或旁注了另一个意思；同义替换题错。
- **典型**：把 address 只理解为"地址"（文中作"处理"）；把 critical 理解为"批评的"（文中作"关键的"）。
- **教学对策**：词块记忆 + 语境猜词训练；一次只补 8–10 个高频熟词生义，不背整表。
- **统计口径**：一题因词义错判，记 1 次 LEX；同一题若还涉及推断错，只记主因。

### SYN 句法不解

- **定义**：句子结构切不开，找不到主干，从句关系判断错。
- **证据**：长句理解题错；语法填空的从句/非谓语类错。
- **典型**：定语从句中"介词 + 关系代词"选错；非谓语逻辑主语判断错。
- **教学对策**：主干提取训练（每天 3 句）；从句先判"缺什么成分"再选词。
- **统计口径**：同一句因结构错导致两题错，记 1 次 SYN + 说明影响 2 题。

### DIS 语篇逻辑

- **定义**：句间/段间关系没抓住，指代、衔接、结构判断错。
- **证据**：七选五错、主旨题错、段落作用题错。
- **典型**：七选五只看空前后一句；主旨题选段落细节。
- **教学对策**：段落功能标注（主题句/例证/转折/结论）；七选五先通读再定位。
- **统计口径**：按题记，不按空记。

### STR 策略缺失

- **定义**：不会用应试策略，或策略用错。
- **证据**：时间不够、先读选项后读文、遇生词停下、写作不列提纲。
- **典型**：阅读每篇超时；作文写到一半发现要点漏了。
- **教学对策**：限时训练 + 流程卡（先题后文/先文后题按题型定）；写作前 3 分钟列要点。
- **统计口径**：需结合"未做完人数""修改痕迹"判断，不能只看得分。

### EXP 表达不准

- **定义**：知道要说什么，但写不对/说不地道。
- **证据**：作文中的语法错、搭配错、中式表达；口语中的词不达意。
- **典型**：I very like it；open the light；时态混用。
- **教学对策**：最小对比对纠错 + 句型框替换练习；一次只纠一个高频错。
- **统计口径**：按"错误句数"记，不按错误个数记（一句三错算 1 句）。

### NON 非智力失分

- **定义**：会做但没得分。
- **证据**：漏涂、错位、拼写大小写、卷面无法辨认、超时未写。
- **典型**：答题卡题号错位；作文超出答题区。
- **教学对策**：答题规范训练 + 时间分配演练；不占用正课太多时间。
- **统计口径**：单独统计，不进"知识性失分"，否则会高估教学问题。

## 归因优先级

同一个失分点，按以下顺序判定主因，只记一个：

1. 如果是 NON → 先排除非智力，再谈其他。
2. 如果多数人错在同一词 → LEX。
3. 如果错在同一结构 → SYN。
4. 如果错在"选得出但选错" → DIS 或 STR（看是否时间/流程问题）。
5. 如果懂但写不出 → EXP。

## 台账字段（供脚本与人工共用）

| 字段 | 说明 |
|---|---|
| `student` | 脱敏编号 S01 |
| `item` | 题号 |
| `type` | LEX / SYN / DIS / STR / EXP / NON |
| `evidence` | 一句证据（原文或错答） |
| `note` | 备注（是否共性） |

## 常见误判

- 把"没读完"当成"不理解"（其实是 STR 或 NON）。
- 把"词汇题错"一律记 LEX（有些是 DIS：靠上下文能推）。
- 把"作文分低"整体归为 EXP（有时是内容要点漏写，属任务完成问题）。
- 一个学生多处错就记多条（统计时按"人次"还是"人数"要写清，否则占比失真）。
