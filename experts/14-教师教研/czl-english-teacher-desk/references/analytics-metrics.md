# 统计指标定义与解读边界（Analytics Metrics）

> 用法：W1 与 W6 的所有数字都按本文件定义计算，避免"同一个词两种算法"。脚本 `scripts/item_stats.py` 与本文件口径一致。

## 一、基础统计

| 指标 | 公式 | 说明 |
|---|---|---|
| 参考人数 n | 有效作答人数 | 缺考不计入，缺考人数单列 |
| 均分 | Σ得分 ÷ n | 保留 1 位小数 |
| 标准差 sd | 总体标准差（除以 n） | 反映离散度，不做显著性检验时只作描述 |
| 最高/最低 | — | 用于判断是否有异常值 |
| 及格率 | 得分 ≥ 满分 × 60% 的人数 ÷ n | 满分口径要写清（150 还是 100） |
| 优秀率 | 得分 ≥ 满分 × 85% 的人数 ÷ n | 校内可自定义为 80%，但报告里要注明 |
| 分数段 | 按满分百分比切段 | 建议 10 段，段宽一致 |

## 二、板块指标

**得分率**

```
得分率 = 该板块均分 ÷ 该板块满分
```

用于横向比较不同满分的板块。注意：得分率低不等于问题大，还要看分值占比。

**失分贡献率**

```
贡献率 = 该板块平均失分 ÷ 全班平均总失分
```

用于回答"总分丢在哪"。贡献率高 + 得分率低 = 优先处理。

**达标率（板块）**

```
达标率 = 该板块得分 ≥ 该板块满分 × 60% 的人数 ÷ n
```

用于看"有多少人这一块没过去"，比均分更能反映教学缺口。

## 三、区分度（可选）

只有拿到逐题得分（0/1 或分档）才能算：

```
区分度 D = 高分组得分率 − 低分组得分率
高分组/低分组 = 总分前 27% / 后 27%
```

| D | 判断 |
|---|---|
| ≥ 0.4 | 很好 |
| 0.3–0.39 | 可用，需微调 |
| 0.2–0.29 | 偏弱，干扰项可能有问题 |
| < 0.2 | 需重写或删除 |

样本 < 30 人时不算区分度，直接标注"样本不足"。

## 四、分层与迁移

按总分把学生分为 A（前 25%）、B（中 50%）、C（后 25%）三层，比较两轮的分层人数变化：

- **上移率** = 本轮升层人数 ÷ 上轮该层人数
- **下滑率** = 本轮降层人数 ÷ 上轮该层人数

分层比均分更能说明"教学是否照顾到了两端"。

## 五、解读边界（必须写进报告）

1. **单次考试不能证明趋势**：至少两次同口径数据才能谈变化。
2. **变化小于 3 个百分点视为波动**，不归因于教学动作。
3. **试卷难度变化会污染对比**：换卷、改范围、改题型时，只比"同类题得分率"。
4. **小样本不做百分比结论**：n < 15 只做描述。
5. **平均分掩盖分布**：均分相同，标准差可能差一倍，必须同时看分布。
6. **贡献率不是因果**：某板块贡献率高，只说明它丢分多，不说明它是"根本原因"。
7. **不比较不同起点的班级**：平行班与实验班的均分差不能直接作为教学水平证据。
8. **不做学生个人排名公示**：分层结果仅供教学分组使用。

## 六、报告写作口径

- 数字后面必须跟判断句："阅读 C 篇得分率 41%（全班最低，低于年级均值 12 个百分点）"。
- 不下"学生不努力"结论；只写可观察事实与可执行动作。
- 目标达成情况要写"起点—目标—实际"三列，缺一列不算达成分析。
- 引用外部数据（年级均分、区均分）必须注明来源与时间。

## 七、常见算法错误

| 错误 | 正确做法 |
|---|---|
| 得分率 = 均分 ÷ 总分 | 分母是该板块满分 |
| 及格率按 60 分算（满分 150） | 按满分 × 60% = 90 分 |
| 贡献率 = 失分 ÷ 总分 | 分母是总失分 |
| 把缺考按 0 分计入 | 缺考单列，不计入均分 |
| 用人数算占比时混用人次 | 明确写"人数"或"人次" |
| 直接用原始分比较不同满分板块 | 先转得分率 |
