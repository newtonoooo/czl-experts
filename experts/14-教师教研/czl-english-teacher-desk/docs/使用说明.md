# 使用说明

面向使用本专家的高中英语教师。读完这一份就能上手。

## 一、它是什么

一个按"诊断 → 设计 → 命题 → 批改 → 讲评 → 复盘"六段组织的教学助手。你不需要先选菜单，直接说你要做什么，它会判断从哪一段进入。

## 二、第一次使用（3 步）

1. 在 WorkBuddy 专家列表中选择「卓识教育-高中英语老师助手」。
2. 直接说需求，例如：`人教版必修一 Unit 3 的阅读课，做成明天能上的教案`。
3. 拿到成品后，如需打印版就说 `出 docx`，需要调整就说 `把作业再降一档难度`。

## 三、六种典型用法

### 1. 备课

```
人教版必修一 Unit 3 阅读课，平行班，40 分钟，做成明天能上的教案，含分层作业
```

你会拿到：单元大概念 → 目标链 → 课时教案（含时间分配与支架）→ 评价量表 → 三层作业。

小技巧：告诉它"学生上节课刚学过定语从句"，它会把语言聚焦环节接上，不会重复教。

### 2. 出卷

```
出一套高一上 Unit 3 单元测，100 分，覆盖阅读、七选五、完形、语法填空、应用文
```

它会先给**双向细目表**（题号 × 考点 × 难度 × 分值），你确认或改完，它再逐题出卷、写答案解析、跑自检。想跳过确认就说"直接出"，它仍会给 5 行摘要。

### 3. 批作文

```
这是 8 篇读后续写，题目要求是……，按评分维度批，挑两个最值得改的问题，只示范改两句
```

份数多时（>20）它会先抽 8–10 篇做样板，给共性台账和通用评语，其余你按样板批。

### 4. 学情分析

```
这是我班月考成绩表（附 CSV），满分：阅读 50、七选五 12.5、完形 15、语法 15、应用文 15、续写 25
```

它会算：均分、标准差、分数段、板块得分率、失分贡献率，排出失分点前三，并给下一步动作。

成绩表格式：第一列编号，其余列板块分，一行一个学生。缺考留空即可。

### 5. 讲评课

```
这次月考阅读 C 篇和语法填空错得多，做一节 45 分钟讲评课
```

它会按错因聚类，选 3 个讲评点，每点给"数据—错因—判断流程—变式—当堂检测"。

### 6. 阶段复盘

```
这是期中、月考两次成绩，这一个月我加了每周两次限时阅读，帮我看看有没有用
```

它会做动作—结果对照，变化小于 3 个百分点判为波动，不会硬夸。

## 四、怎样给输入更省事

| 给法 | 效果 |
|---|---|
| `高一，必修一 U3，阅读课，平行班` | 一次到位，不用来回问 |
| `上 U3` | 它会按人教版、1 课时、中等班补全并标注 |
| 直接甩一张成绩截图 | 它会先确认"我按学情分析处理，对吗" |
| 直接甩一篇作文 | 它会先确认题型与要求，缺要求会问一句 |

**越具体越省轮次**：教材版本、年级、课型、班级层次、课时长度、用途（随堂/月考/诊断）这六项，给得越多，返工越少。

## 五、输出怎么用

- **对话版**：先看"结论"三行，再看证据表，最后看方案。
- **打印版**：说 `出 docx`，会按 A4、页眉页脚、三线表排版，文件名自带日期。
- **课件**：说 `出课件`，先给分页大纲，再导出 `.pptx`。
- **质检单**：每份成品末尾都有，标了未通过项的原因，别忽略。

## 六、四个脚本（可选，进阶）

包内 `scripts/` 有四个脚本，教师本人也可以用（需装 Python 3.8+，无其他依赖）：

```bash
# 1. 生成双向细目表（先从 tests/fixtures/spec.json 改一份自己的）
python scripts/blueprint.py --spec spec.json --out 细目表.md

# 2. 统计成绩（CSV + 满分 JSON）
python scripts/item_stats.py --csv scores.csv --full full.json --out 学情.md

# 3. 写作折算（四维 0–5 分）
python scripts/essay_score.py --type continuation --content 4 --language 4 --structure 3 --cohesion 3

# 4. 成品自检（试卷 + 答案）
python scripts/qa_check.py --paper 试卷.md --answers 答案.md
```

不想用命令行也没关系，直接让助手在对话里算，结论一样。

## 七、常见问题

**Q：能不能直接给我一套高考真题？**
不能整卷复制（版权）。可以给：某年某卷的考点分布、某道题的思路拆解、同考点的原创变式题。

**Q：能不能用我们学校自己的评分细则？**
可以。把细则贴进来，它会以校本细则为准，并提示与通用尺的差异。

**Q：批改会不会给我一个最终分数？**
给"建议分 + 档次 + 依据"，最终分由你定。写作定等是教师职责。

**Q：学生名字会不会被记录？**
不会。成绩表里的姓名会被脱敏成 S01、S02；也建议你直接给编号。

**Q：听力能不能生成音频？**
不能。只给脚本、设问与选项，音频用你校的工具合成。

**Q：能不能一次做一整个单元（含教案、卷子、课件）？**
可以，说 `走一遍`，它按 W1→W6 顺序推进，每段结束会停下来确认。

## 八、导入与迁移

- **安装**：把 `czl-english-teacher-desk` 整个目录放到
  `%USERPROFILE%\.workbuddy\plugins\marketplaces\my-experts\plugins\`，再注册即可。
- **换电脑**：直接复制整个目录；脚本与知识库都在包内，不依赖外部路径。
- **改头像**：替换 `avatars/expert.png`，要求 512×512、PNG/JPG、≤500KB，文件名不变。

## 九、边界提醒

- 生成的题目、答案、评分建议请务必复核后使用。
- 政策与考试结构以本省当年文件为准，产品内的结构表只作对齐参考。
- 不用于代写、造假、承诺提分等用途。
