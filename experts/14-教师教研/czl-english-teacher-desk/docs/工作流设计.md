# 工作流设计

本文件是六段工作流的总览与编排说明。每段的完整规格在 `workflows/` 下，主提示词只负责路由与纪律，不重复细节。

## 一、总览

| 段 | 文件 | 职责 | 主输入 | 主输出 | 关键判断 |
|---|---|---|---|---|---|
| W1 | `workflows/W1-diagnosis.md` | 把"考得差"翻译成可教学缺口 | 分板块成绩 / 错题清单 | 学情诊断单 | 有无数据、样本量、是否可比 |
| W2 | `workflows/W2-lesson-design.md` | 单元拆课时，课时拆活动 | 教材版本 + 单元 + 课型 | 单元设计 + 教案 + 分层作业 | 课型、班级层次、课时长度 |
| W3 | `workflows/W3-assessment.md` | 先细目表，再原创命题，最后校难度 | 范围 + 用途 | 细目表 + 试卷 + 答案 | 用途、时长、难度配比 |
| W4 | `workflows/W4-marking.md` | 同一把尺子批量批，沉淀错误类型 | 题目 + 学生原文 | 批改单 + 错误台账 | 份数、错误密度、清晰度 |
| W5 | `workflows/W5-review-lesson.md` | 错题 → 一节课 → 同类题不再错 | 台账 / 得分率 | 讲评课教案 + 变式题组 | 错因是否集中、课时是否够 |
| W6 | `workflows/W6-cycle-review.md` | 用数据判断教学动作是否有效 | 两次数据 + 动作记录 | 复盘报告 + 三个决策 | 口径是否可比、变化是否显著 |

## 二、数据流

```
                 ┌──────────────────────────────┐
                 │  W1 学情定位台                │
                 │  产出：诊断单（缺口 + 证据）   │
                 └───────┬───────────┬──────────┘
            定难度/支架   │           │  定题量与配比
                 ┌───────▼──────┐  ┌─▼─────────────┐
                 │ W2 设计台     │  │ W3 命题台      │
                 │ 教案/作业     │  │ 细目表/试卷     │
                 └───────┬──────┘  └─┬─────────────┘
                         │ 只考已教   │ 答案即批改尺
                         └──────┬─────┘
                        ┌───────▼────────┐
                        │ W4 批改与台账   │
                        │ 批改单/错误类型  │
                        └───────┬────────┘
                                │ 按错因分组
                        ┌───────▼────────┐
                        │ W5 讲评与迁移   │
                        │ 讲评课/变式题组  │
                        └───────┬────────┘
                                │ 补救是否生效
                        ┌───────▼────────┐
                        │ W6 周期复盘     │
                        │ 决策：保留/加强/停止│
                        └───────┬────────┘
                                └──→ 回到 W1（新基线）
```

三条不可跳的依赖：

1. **W2 → W3**：命题范围不得超出已教内容，否则数据不可解释。
2. **W3 → W4**：批改尺必须来自命题时的评分点，不能另立标准。
3. **W4 → W5**：讲评按错误类型分组，不按题号顺序。

## 三、每段的九要素（摘要）

### W1 学情定位台

- **输入**：`scores`、`full_marks`、`class_level`、`prev_scores`、`paper_notes`、`wrong_items`
- **步骤**：清洗脱敏 → 算分布/得分率/贡献率 → 双条件选失分点 → 错因聚类 → 写成可教学表述 → 排优先级
- **判断**：无数据走"三问定位法"；无板块分只做分布；n<15 只描述；换卷不做分数相减；得分率普遍>85% 转找高分段天花板
- **输出**：结论 3 行 + 总体表 + 分数段 + 板块表 + 失分点表 + 错因分布 + 下一步 + 质检单
- **异常**：乱码、满分不符、截图模糊、要求排名 → 各有处理（见文件）
- **依赖**：`item_stats.py`、`analytics-metrics.md`、`error-taxonomy.md`
- **关系**：闭环起点；向 W2/W3/W6 供数

### W2 单元与课时设计台

- **输入**：`textbook`、`unit`、`lesson_type`、`periods`、`class_level`、`source_text`、`constraints`
- **步骤**：定大概念 → 拆目标链 → 排课时 → 设计单课时（导入/输入/操练/产出/小结）→ 标三个卡点 → 配评价 → 出分层作业
- **判断**：复习课改"诊断—归类—变式—过关"；讲评课转 W5；薄弱班加支架；实验班加开放任务；无原文用替代语篇并标注；40 分钟砍一个操练
- **输出**：单元设计（5 节）+ 课时教案（8 节）+ 质检单
- **异常**：单元记错、要求一节课上完单元、课时被砍半、无设备
- **依赖**：`lesson-models.md`、`curriculum-map.md`、`delivery-spec.md`
- **关系**：受 W1 约束；向 W3 供范围；评价量表即 W4 的批改尺

### W3 命题组卷台

- **输入**：`scope`、`purpose`、`total_score`、`structure`、`difficulty`、`class_level`、`duration`、`must_include`
- **步骤**：确认口径 → 出细目表（等确认）→ 选材改写 → 逐题命制 → 标难度 → 写答案解析 → 过质检 → 交付四件套
- **判断**：教师说不用细目表也给 5 行摘要；纯语法范围出专项卷；诊断卷降难度提覆盖；选拔卷提区分度；时长不足先砍题量
- **输出**：细目表 + 学生版试卷 + 教师版答案解析 + 质检单（+ 答题卡）
- **异常**：语篇不够长、范围冲突、配比不达标、要求仿某年真题
- **依赖**：`blueprint.py`、`qa_check.py`、`item-writing-spec.md`、`exam-structure.md`、`writing-rubrics.md`
- **关系**：受 W2 范围约束、受 W1 配比约束；向 W4/W5/W6 供数据

### W4 批改与错误台账

- **输入**：`task_type`、`prompt`、`scripts_text`、`rubric`、`class_level`、`focus`
- **步骤**：拆必写要点 → 四维判分（引证据）→ 折算与一致性校验 → 列错误清单 → 写三条评语 → 建台账 → 出批改报告
- **判断**：≤5 份全批带改句；6–20 份给维度分；>20 份抽样做样板 + 通用评语库；错误密度>每句 1 处只改三处；疑似套作只记录不定性
- **输出**：单份批改单（5 节）+ 班级台账（类型×人次×典型例）+ 共性三条
- **异常**：图片不清、缺题目、校本标准冲突、多份无法切分、超纲但用对
- **依赖**：`essay_score.py`、`writing-rubrics.md`、`error-taxonomy.md`
- **关系**：上游 W3；下游 W5/W6

### W5 讲评与迁移台

- **输入**：`error_data`、`period`、`class_level`、`exam_scope`、`must_cover`
- **步骤**：按错因聚类 → 选 3 个讲评点 → 每点五步（数据/错因/建模/变式/过关）→ 设计三层变式 → 排时间 → 写页纲 → 留检测记录
- **判断**：错因分散转专题课；单因≥60% 判定教学未到位改重教；词因为主讲词块；非智力失分改答题规范；20 分钟只讲 1 点
- **输出**：讲评课教案（数据开场/讲评点/带过题/时间表/检测记录）
- **异常**：无分题数据、变式不够三层、检测仍<50%、基础太弱
- **依赖**：`error-taxonomy.md`、`exam-structure.md`、W4 台账
- **关系**：上游 W4；下游 W6；不达标回到 W2 重教

### W6 周期复盘台

- **输入**：`baseline`、`current`、`actions`、`period`、`target`、`notes`
- **步骤**：校口径 → 算四类变化 → 动作—结果对照 → 三层归因 → 三个决策 → 定下一轮起点
- **判断**：单次数据不下效果结论；范围不同只比重叠考点；变化<3 个百分点判波动；某板块涨但总均分不动查挤占；目标未达先查目标合理性
- **输出**：一页纸复盘（结论/口径/指标/对照/归因/决策/起点/质检）
- **异常**：只有感觉、口径不一、要写评职称材料、异常班级
- **依赖**：`analytics-metrics.md`、W1/W4/W5 过程数据
- **关系**：闭环收口；重设 W1 基线

## 四、质量门（Gate）

每段交付前必须过的四道门：

| 门 | 检查内容 | 谁来查 |
|---|---|---|
| 口径门 | 范围/对象/用途是否已明确并写在开头 | 模型自检 |
| 结构门 | 该段规定的骨架是否齐全（缺节即未完成） | 模型自检 |
| 事实门 | 数字、答案、真题出处是否可核对；不可核对是否标注 | 模型 + 脚本 |
| 语言门 | 英文拼写语法、中文标点、占位符 | `qa_check.py` + 人工清单 |

## 五、异常矩阵（跨段）

| 异常 | 统一处理 |
|---|---|
| 输入缺失 | 按默认档产出，开头一行写前提，末尾写"补 X 可优化 Y" |
| 输入冲突（范围 vs 进度） | 提示冲突，请教师二选一，不擅自决定 |
| 材料不可读 | 说明缺口，先按可读部分产出 |
| 脚本不可用 | 手工等价计算并标注"未跑脚本" |
| 要求越界（押题/造假/代写） | 拒绝并给合规替代 |
| 多轮仍不全 | 按中等班/常规难度产出并标注 |

## 六、提示词设计要点

1. **路由先于能力**：主提示词不列功能清单，而是列"教师这样说 → 进入哪段"，避免模型自由发挥。
2. **契约化输入**：每段给"必须/可选/默认"三列，模型知道缺什么可以补、缺什么必须问。
3. **输出骨架固定**：结构固定后，质量才有可比性；教师第二次使用时不必重新适应格式。
4. **异常前置**：把常见失败情形写进提示词，而不是等失败后补救。
5. **追问只一次**：避免把教学对话变成问卷。
