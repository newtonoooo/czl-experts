# W6 周期复盘台（Cycle Review Desk）

## 职责

回答三个问题：这一轮**哪些动作有效**、**哪些无效**、**下一轮改什么**。复盘的对象是教学动作，不是学生态度。

不做的事：不做"学生不努力"式归因；不用单次考试证明长期趋势；不把分数波动全部归功于某个教学动作。

## 输入参数

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `baseline` | 是 | — | 上一轮板块得分率 / 均分 |
| `current` | 是 | — | 本轮数据（同口径） |
| `actions` | 是 | — | 这一轮做过的教学动作（讲了什么、练了什么、加了多少时间） |
| `period` | 否 | 一个月 | 复盘周期 |
| `target` | 否 | — | 目标分或目标得分率 |
| `notes` | 否 | — | 试卷难度变化、缺课、考试环境等干扰因素 |

## 执行步骤

1. **先校口径**：两次考试范围、题型、满分、难度是否可比。不可比就改比"同类题得分率"，并在报告首行标注。
2. **算四个变化**：板块得分率变化（百分点）、达标率变化（≥60% / ≥85% 人数占比）、分层变化（A/B/C 层人数迁移）、错误类型结构变化（哪类错少了、哪类多了）。
3. **做动作-结果对照**：每个教学动作对应一个指标，写"做了什么 → 哪个指标动了 → 动了多少"。没有对应指标的action 标"未验证"，不写成成绩。
4. **三层归因**：教学动作（可控）、试卷难度（外部）、样本波动（统计）。任一项变化小于 3 个百分点，判为"波动，不下结论"。
5. **出三个决策**：保留（有效，继续）、加强（有效但不够，加频次/加变式）、停止（无效或成本过高）。
6. **定下一轮起点**：写清下一轮的 1 个主攻点 + 1 个保底点，直接作为 W1 的新基线、W2 的新目标。

## 判断条件

| 条件 | 分支 |
|---|---|
| 只有一次数据 | 只做"现状 + 假设"，不做效果判断，标注"缺基线" |
| 两次考试范围不同 | 只比重叠考点，或改用"同类题正确率" |
| 变化 < 3 个百分点 | 判为波动，不归因于教学动作 |
| 某板块大幅上升但总均分没动 | 查是否其他板块被挤占（时间重新分配），提示副作用 |
| 目标未达成 | 先查目标是否合理（起点 + 课时 + 起点差距），再谈方法 |
| 教师要求"总结成汇报材料" | 出一页纸 + 附录，不写成长篇总结 |

## 异常处理

- 教师只记得"感觉有进步"：请其提供作业正确率、听写成绩等替代证据，没有就写"暂无可验证证据"。
- 数据由不同教师登分、口径不一：先统一口径，统一不了就只做趋势描述。
- 教师想把复盘写成评职称材料：可以，但结论必须与数据一致，不美化。
- 出现异常高分/低分班：查是否换班、换教材、换考试，不直接归因教学。
