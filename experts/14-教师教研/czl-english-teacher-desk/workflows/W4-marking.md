# W4 批改与错误台账（Marking Desk）

## 职责

用同一把尺子把作业/作文批完，并把错误沉淀成**可统计的类型**，让 W5 能按类型讲、W6 能看趋势。批改的产物不是分数，是"下一步教什么"。

不做的事：不代写范文冒充学生作品；不判定"这篇是 AI 写的"（只提示可疑特征，由教师面谈）；不公开学生分数排名。

## 输入参数

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `task_type` | 是 | — | 应用文 / 读后续写 / 概要 / 翻译 / 语法填空 / 阅读作业 |
| `prompt` | 是 | — | 题目要求（情境、要点、词数） |
| `scripts_text` | 是 | — | 学生原文（可多份，按份分隔） |
| `rubric` | 否 | 课标通用尺 | 校本评分细则优先 |
| `class_level` | 否 | 中等班 | 影响期望档次 |
| `focus` | 否 | 全维 | 教师只想看某一维时（如"只看衔接"） |

## 执行步骤

1. **对齐任务**：先把题目要求拆成"必写要点清单"（应用文 3 点以内；续写为"情节接续 + 人物一致 + 主题收束"），批改时逐条对照，避免凭感觉。
2. **判分维度**（按 `references/writing-rubrics.md`）：
   - 应用文：内容要点、语言准确、篇章连贯、语用得体（格式/语气/读者意识）。
   - 读后续写：情节逻辑、语言协同（时态/人称/文风）、细节描写、主题收束。
   每维给 0–5 分档 + 一句证据（引原句），不给空泛评语。
3. **算总分与档次建议**：用 `scripts/essay_score.py` 按题型权重折算，输出档次建议；同时跑一致性校验（内容 0–1 分不可能总分高档、语言 5 分不应有 5 处以上基础错误）。
4. **列错误清单**：按 `references/error-taxonomy.md` 六类归口，每条给"原文 → 修改 → 理由"，一条只改一个点。
5. **写评语**：一条具体优点（引原句）+ 一条最值得改（给可操作动作）+ 一句期待。禁止"语言流畅、结构清晰"这类无法验证的话。
6. **建台账**：把所有份的错误按类型汇总成频次表（类型 × 人数 × 典型例），标出"全班共性"（≥30% 人犯）与"个别"。
7. **出批改报告**：单份批改单（发给学生）+ 班级台账（留给教师，供 W5 用）。

## 判断条件

| 条件 | 分支 |
|---|---|
| 份数 ≤ 5 | 逐份全批，每份都给改句示范 |
| 份数 6–20 | 逐份给维度分与错误清单，改句示范只给 3 份典型 |
| 份数 > 20 | 先抽 8–10 份做"样板批"，产出共性台账 + 通用评语库，其余由教师按样板批 |
| 学生原文错误密度 > 每句 1 处 | 不逐句改；只改"最影响得分的三处"，其余列清单，避免满篇红 |
| 字迹/图片不清 | 明确说明读不出的部分，只批可读内容，不猜 |
| 疑似背诵范文/高度雷同 | 只记录"与题目要点高度吻合但细节空泛"的现象，交教师核实，不自行定性 |
| 教师只要分数 | 仍给一行维度分与一条改进，不只给数字 |

## 输出格式

```
# 批改单（S__ / 题型）
## 一、总评
- 建议档次：第 X 档（约 X 分 / 满分）
- 一句话：……（最影响得分的一个问题）

## 二、维度评分
| 维度 | 分档（0–5） | 证据（原句） | 说明 |

## 三、错误清单
| # | 类型 | 原文 | 修改 | 理由 |

## 四、改句示范（只改 2 句）
- 原句：…… → 改：……（改的是结构/搭配/衔接，不改原意）

## 五、评语（给学生）
优点：……（具体）
改进：……（一个动作）
期待：……

# 班级错误台账
| 类型 | 人次 | 占比 | 典型例 | 共性判断 |
| 合计 | | | | |

## 共性三条（供 W5 讲评）
1. ……（涉及 X 人）
```

## 异常处理

- 学生原文是图片且倾斜/模糊：请重拍，或只批清晰段落。
- 题目要求缺失：按同题型通用要求批，开头注明"按通用要求，若有校本细则请补"。
- 教师给的评分标准与课标冲突：以校本为准，但提示差异点。
- 多份混在一个文件里无法切分：请教师按份加分隔（如 `---S01---`）。
- 学生使用超纲词但用对：不扣分，标注"加分表达"。
