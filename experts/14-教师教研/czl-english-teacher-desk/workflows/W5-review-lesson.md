# W5 讲评与迁移台（Review & Transfer Desk）

## 职责

把"错题"变成"一节课"，再把"一节课"变成"同类题不再错"。讲评课的标准不是讲完了，而是**当堂检测里同类题正确率明显上升**。

不做的事：不按题号从头讲到尾；不把讲评课上成对答案课；不布置"把错题抄三遍"。

## 输入参数

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `error_data` | 是 | — | W4 台账 / W1 得分率 / 教师口述错题 |
| `period` | 否 | 45 分钟 | 讲评课时长 |
| `class_level` | 否 | 中等班 | 决定讲评深度 |
| `exam_scope` | 否 | — | 本次考试范围，用于变式题取材 |
| `must_cover` | 否 | — | 教师点名要讲的题 |

## 执行步骤

1. **聚类不排序**：把错题按考点/错因分组（如"定语从句关系词 3 题、七选五指代 2 题"），同一错因合并讲，不同错因不混讲。
2. **选 3 个讲评点**：按"影响面（人数）× 可迁移性（换题还会考）÷ 讲解成本"排序，一节课最多 3 个。剩下的一句话带过或放进作业。
3. **每个讲评点走五步**：
   - 呈现数据（多少人错，错在哪一项）
   - 暴露错因（拿一份典型错答，让学生说思路）
   - 建模（给可复用的判断流程，不是给答案）
   - 变式（同考点换情境/换设问/换干扰，当场做）
   - 过关（当堂 2–3 题检测，正确率低于 70% 就再加一组）
4. **设计变式题组**：每个讲评点配 3 题——原型变式（换数字/换词）、情境变式（换语篇）、逆向变式（给答案找错因）。变式必须真的换，不是改人名。
5. **排时间**：数据开场 2 分钟，每个讲评点 10–12 分钟，当堂检测 6–8 分钟，收尾 2 分钟。留 3 分钟弹性。
6. **写板书/课件页纲**：一页一个讲评点，页面上只放"判断流程 + 一道变式"，不放大段文字。
7. **留痕迹**：课后记录"当堂检测正确率"，交给 W6 作为补救是否生效的证据。

## 判断条件

| 条件 | 分支 |
|---|---|
| 错题分散（无单一错因 ≥ 30%） | 改上"专题课"：按题型策略讲，不按错题讲 |
| 单一错因 ≥ 60% | 判定为"教学未到位"，先补教再讲评，讲评课改为"重教 + 检测" |
| 错因主要是词汇 | 不讲解题技巧，改"词块 + 语境猜词"训练 |
| 错因主要是非智力（漏涂、超时） | 讲评课改为"答题规范 + 时间分配"训练 |
| 课时只有 20 分钟 | 只讲 1 个讲评点 + 1 组变式 |
| 教师坚持按题号讲 | 说明代价（讲不完、不迁移），给"折中版"：同一错因的题合并，其余发答案自学 |

## 输出格式

```
# 讲评课教案（{考试名称} / {课时}）
## 一、数据开场（2'）
| 板块 | 得分率 | 班级问题一句话 |

## 二、讲评点（按优先级）
### 讲评点 1：{考点/错因}（涉及 X 人，得分率 Y%）
- 典型错答：……（匿名）
- 错因诊断：……
- 判断流程（板书）：
  1) …… 2) …… 3) ……
- 变式训练（3 题，附答案）
- 当堂检测（2 题，附答案与达标线）

### 讲评点 2 / 3：同上结构

## 三、一句话带过的题（发答案自学）
| 题号 | 答案 | 提示 |

## 四、时间分配表
| 环节 | 时长 | 教师动作 | 学生动作 |

## 五、课后记录表
| 讲评点 | 当堂正确率 | 是否达标（≥70%） | 需不需要再加一组 |
```

## 异常处理

- 没有分题数据，只有"这几题错得多"：按教师给的题号聚类，标注"无人数，按经验判断"。
- 变式题写不出三个层次：至少给"原型变式 + 情境变式"两组，第三组留作作业。
- 当堂检测正确率仍低于 50%：判定该点需要重教，写入 W6 的待补清单，不在本节课硬推下一个点。
- 学生基础太弱，讲评点讲不动：降到"识别 + 套用"层级，只要求认得出、用得上。

## 与其他工作流的关系

- 上游：W4（错误台账）、W1（得分率）。
- 下游：W6（补救效果证据）、W2（需要重教的内容回到备课）。
- 回环：讲评后仍不达标 → 回到 W2 重教，而不是再讲一遍。
