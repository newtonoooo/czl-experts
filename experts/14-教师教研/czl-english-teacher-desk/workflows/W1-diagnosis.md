# W1 学情定位台（Diagnosis Desk）

## 职责

把"这次考得不好"翻译成**可教学的具体缺口**：缺口在哪一段、涉及多少人、是什么类型的错、下一节课该先补哪一处。输出必须能直接喂给 W2（定教学难度）和 W3（定命题配比）。

不做的事：不做学生个体排名公示，不做"学习态度"这类无法从数据推出的归因。

## 输入参数

| 参数 | 必填 | 形式 | 说明 |
|---|---|---|---|
| `scores` | 是（无则走降级路径） | CSV / 表格 / 图片 | 每行一个学生，列为板块得分或总分 |
| `full_marks` | 是 | JSON / 口述 | 各板块满分，用于算得分率 |
| `class_level` | 否 | 文本 | 实验班 / 平行班 / 混合班，影响常模判断 |
| `prev_scores` | 否 | 同 `scores` | 有则做纵向对比，无则只做横向 |
| `paper_notes` | 否 | 文本 | 本次试卷的难度、范围、是否统考 |
| `wrong_items` | 否 | 文本 / 图片 | 错题清单，用于错因聚类 |

## 执行步骤

1. **清洗**：统一列名，剔除缺考行，把姓名列脱敏为 S01…；非数字单元格记为该板块缺失并计数。
2. **算三组数**：总分分布（均分、标准差、及格率、优秀率、分数段）、板块得分率（板块均分 ÷ 满分）、板块贡献率（该板块失分 ÷ 总失分）。
3. **找失分点**：按"得分率低 + 贡献率高"双条件排序，取前 3–5 个，而不是只看得分率最低的那个（低得分率可能只占 5 分）。
4. **错因聚类**：把错题按 `references/error-taxonomy.md` 归到六类——词汇不明、句法不解、语篇逻辑、策略缺失、表达不准、非智力失分（漏涂、超时）。每类给出典型题号与人数。
5. **定教学缺口**：每个失分点写一句"可教学表述"，例如"定语从句中介词+关系代词的选择，全班 62% 错，属句法不解"。
6. **排优先级**：按"影响面 × 可补性 ÷ 课时成本"排序，给出"下节课先讲什么"的一句话建议。

## 判断条件

| 条件 | 分支 |
|---|---|
| 无任何分数，只有"感觉" | 走"三问定位法"：最近一次失分最多的题型？哪种题型花时间最多仍错？课堂上听懂但考试错的是哪类？ |
| 只有总分，没有板块分 | 只做分布与分层，明确写"无法定位板块失分，建议下次按板块登分" |
| 样本 < 15 人 | 只做描述统计，不做百分比结论，标注"小样本" |
| 与上次数据不可比（换卷/换范围） | 不做分数直接相减，改比"班级位次变化"或"同类题得分率变化" |
| 得分率普遍 > 85% | 判定为"试卷偏易"，转而找"高分段的天花板"（完形、阅读 D 篇、续写） |

## 输出格式

```
## 一、结论（3 行内）
- 本次最该补的缺口：……
- 影响面：……人 / 占比……
- 建议动作：……（一节课能做完的事）

## 二、总体
| 参考人数 | 均分 | 标准差 | 最高 | 最低 | 及格率 | 优秀率 |

## 三、分数段分布
| 段 | 人数 | 占比 | 累计 |

## 四、板块得分率
| 板块 | 满分 | 均分 | 得分率 | 失分贡献率 | 判断 |

## 五、失分点 Top 3–5（含证据）
| 排名 | 失分点 | 证据（题号/人数/得分率） | 错误类型 | 可教学表述 |

## 六、错因分布
| 类型 | 涉及人数 | 典型题号 | 备注 |

## 七、下一步
1. 下节课先讲：……
2. 需要 W3 配的题：……（考点 × 题量 × 难度）
3. 需要 W2 调的进度：……

## 八、质检单
- [ ] 已脱敏，无姓名学号
- [ ] 得分率与满分对应，分母不是人数
- [ ] 小样本/不可比已标注
```

## 异常处理

- CSV 编码乱码：尝试 UTF-8 / GBK 两次，仍失败则请教师另存为 UTF-8 CSV。
- 板块满分与实际题量对不上：按教师确认的口径重算，不猜。
- 教师只发来一张成绩截图且模糊：只提取能确认的数字，缺口标"待补"。
- 教师要求"排个名看看谁最差"：改为分层名单（A/B/C 层人数与名单编号），不做公开排名建议。
