# W3 命题组卷台（Assessment Desk）

## 职责

按用途产出**可用的卷子**：先给双向细目表让教师确认考什么、考多难，再逐题原创，最后校难度、写解析、过质检。核心是"题服务于诊断"，不是"凑满一张卷"。

不做的事：不整段搬运真题或教材语篇；不出无答案的题；不用"略"代替解析。

## 输入参数

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `scope` | 是 | — | 考试范围（单元 / 语法项 / 题型专项） |
| `purpose` | 是 | 单元测 | 随堂 / 单元测 / 月考 / 诊断 / 模拟 |
| `total_score` | 否 | 100（诊断）/ 150（仿高考） | 满分 |
| `structure` | 否 | 按用途取默认 | 题型与题量，可自定义 |
| `difficulty` | 否 | 易:中:难 = 5:3:2 | 目标配比 |
| `class_level` | 否 | 中等班 | 决定语篇长度与设问方式 |
| `duration` | 否 | 按分值推算 | 考试时长（分钟） |
| `must_include` | 否 | — | 必须覆盖的考点（教师指定） |

## 执行步骤

1. **确认口径**：用途 → 题型结构 → 分值 → 时长 → 难度。四项缺一不可，缺则按默认档并标注。
2. **出双向细目表**（先给教师确认，不直接出卷）：每行 = 题号 / 板块 / 题型 / 考点 / 难度 / 分值 / 情境。用 `scripts/blueprint.py` 生成并校验：总分是否等于满分、难度配比偏差是否超 5%、考点是否重复设问。
3. **选材与改写**：优先自编语篇；需要真实语料时做实质改写（换结构、换设问角度、降生词密度），并在卷末注明"改编自公开语料，非原文"。
4. **逐题命制**（按 `references/item-writing-spec.md`）：
   - 阅读：题干指向明确，选项同质同长，干扰项来自真实误读路径（张冠李戴、以偏概全、过度推断、原文照抄但答非所问）。
   - 七选五：空格前后必须有可判定的衔接线索（指代、复现、逻辑词），干扰项要"局部通、整体不通"。
   - 完形：语篇先完整后挖空，每空四个选项词性一致、语义场相近，答案必须由上下文唯一确定。
   - 语法填空：给词与不给词比例合理，考点覆盖本范围，不考偏怪搭配。
   - 写作：情境真实、读者明确、要点可数（3 点以内），词数要求写清。
5. **校难度**：逐题标易/中/难并给依据（生词密度、句式复杂度、设问层级、干扰强度），统计配比；超配比就换题，不硬凑。
6. **写答案与解析**：答案 + 定位依据（原文句/规则）+ 易错点 + 干扰项分析。选择题必须解释"为什么错项错"。
7. **过质检**：跑 `scripts/qa_check.py`，检查题号连续、选项完整、答案覆盖、分值合计、占位符清零。
8. **交付**：试卷（学生版，无答案）+ 答案与解析（教师版）+ 细目表 + 答题卡（需要时）。

## 判断条件

| 条件 | 分支 |
|---|---|
| 教师说"直接出卷，不用细目表" | 仍先给 5 行摘要（题型 × 题量 × 分值 × 难度），确认后再出 |
| 范围只有语法项 | 出"语法专项卷"：单句 + 语篇两层，语篇占比不低于 40% |
| 用途是"诊断" | 提高覆盖面，降低单题难度，题目要能区分错误类型 |
| 用途是"选拔/模拟" | 提高区分度，难题集中在阅读 D 篇与续写 |
| 时长不足 | 先砍题量，不砍语篇完整度；标注"精简版" |
| 教师指定必须覆盖某考点 | 在细目表中单独标 ★，并保证至少两种题型涉及 |

## 输出格式

```
# {考试名称} 双向细目表
| 题号 | 板块 | 题型 | 考点 | 难度 | 分值 | 情境/语篇 |
（末尾）合计：题数 X，总分 Y，易:中:难 = a:b:c（目标 5:3:2，偏差 …）

# {考试名称} 试卷（学生版）
（卷头：名称 / 时间 / 满分 / 注意事项）
一、听力（如需要，仅文本脚本）
二、阅读理解
三、七选五
四、完形填空
五、语法填空
六、写作（应用文 / 读后续写）

# 答案与解析（教师版）
【答案】… 【定位】… 【解析】… 【易错】… 【干扰项】

# 质检单
- [ ] 题号连续无跳号
- [ ] 选择题选项 A–D 齐全，无重复项
- [ ] 答案数量 = 题目数量
- [ ] 分值合计 = 卷头满分
- [ ] 无 [TODO] / XX / 待补 占位
- [ ] 语篇长度符合年级（见 item-writing-spec）
```

## 异常处理

- 自编语篇写不出足够长度：缩短语篇并减少题量，不用废话灌水。
- 考点与教材进度冲突：列出冲突项，请教师选择"删题"或"改范围"。
- 难度配比无法达标：说明原因（如范围太窄导致难题无载体），给替代方案（换一篇更难的语篇）。
- 教师要求"和某年真题一样"：只做结构与考点对齐，不复制原文，明确说明。

## 与其他工作流的关系

- 上游：W2（只考已教）、W1（按失分点配题量与难度）。
- 下游：W4（答案与评分点即批改尺）、W5（错题来源）、W6（数据来源）。
- 回环：W6 发现某考点连续失分 → 下一轮 W3 提高该考点权重。
