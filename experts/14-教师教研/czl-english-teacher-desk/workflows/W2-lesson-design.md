# W2 单元与课时设计台（Lesson Design Desk）

## 职责

把一个单元变成**有目标链的课时序列**，再把一节课变成教师明天能照着上的流程。判据只有一条：拿走这份设计，另一位同层次教师能上出同样的课。

不做的事：不写"培养学生的核心素养"这类无法测评的目标；不为了好看堆活动。

## 输入参数

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `textbook` | 否 | 人教版 | 版本影响单元编排与话题 |
| `unit` | 是 | — | 单元号 / 课题 / 语篇标题 |
| `lesson_type` | 是 | 阅读 | 听说 / 阅读 / 语法 / 写作 / 复习 / 讲评 / 项目 |
| `periods` | 否 | 1 | 本单元总课时与本节是第几课时 |
| `class_level` | 否 | 中等班 | 决定支架密度与任务开放度 |
| `source_text` | 否 | — | 教材原文 / 图片 / 关键句；没有则用同话题替代语篇并标注 |
| `constraints` | 否 | — | 教室设备、班额、是否走班、作业时长上限 |

## 执行步骤

1. **定单元大概念**：用一句"学生学完能回答的问题"概括（如"人如何用语言描述一座城市的性格"），而不是"本单元学习……词汇和句型"。
2. **拆目标链**：单元目标 3–4 条，逐条落到课时；每条目标写"行为动词 + 内容 + 可测评证据"（如"能用 3 个以上描述性形容词语气中立地介绍一处地标，在 80 词口头输出中不重复用词"）。
3. **排课时**：按"输入课（读/听）→ 语言聚焦课（词汇/语法）→ 输出课（说/写）→ 综合任务"排，标明每课时产出物。
4. **设计单课时**（按 `references/lesson-models.md` 的课型模型）：
   - 导入（3–5 分钟，激活图式，不做无关联热身）
   - 输入/呈现（任务链，不是逐句翻译）
   - 操练（有反馈的练习，不是齐读）
   - 产出（可评价的任务，有评价量表）
   - 小结与作业（分层）
5. **写清三个"卡点"**：学生会在哪一步掉队、教师在那一步给什么支架、支架怎么撤。
6. **配评价**：每个产出任务给 2–4 条可观察的评价点，不用"好/较好/一般"。
7. **出分层作业**：基础（全会做，10 分钟内）/ 提高（需要思考，15 分钟）/ 挑战（选做，指向迁移），三档都要与本节目标对齐。

## 判断条件

| 条件 | 分支 |
|---|---|
| 课型为复习课 | 不走"导入—呈现"，改"诊断—归类—变式—过关" |
| 课型为讲评课 | 转到 W5，不在本流程硬做 |
| 班级为平行班/基础薄弱 | 支架加密：给句型框、给词块表、任务拆成两步 |
| 班级为实验班 | 减少机械操练，增加开放任务与语篇分析 |
| 教师只给单元号没给课文 | 按单元话题自编 250–350 词替代语篇，标题标注"替代语篇，可替换为教材原文" |
| 课时只有 40 分钟 | 砍掉一个操练环节，保留导入 + 输入 + 产出 |

## 输出格式

```
# 单元整体设计（单元名 / 版本 / 年级）
## 一、单元大概念与本质问题
## 二、单元目标链
| 目标 | 素养指向 | 可测评证据 | 落在第几课时 |
## 三、课时分配
| 课时 | 课型 | 核心任务 | 产出物 | 评价方式 |
## 四、单元评价任务（终结性）
## 五、资源与材料清单

# 课时教案（第 X 课时 / 课型）
## 一、教学目标（3 条以内，可测评）
## 二、重点与难点（难点写"学生会在哪一步卡住"）
## 三、学情预设（三层：会 / 半会 / 不会）
## 四、教学过程
| 环节 | 时间 | 教师活动 | 学生活动 | 设计意图 | 支架与撤除 |
## 五、板书 / 课件页纲
## 六、分层作业
| 档 | 内容 | 预计时长 | 对应目标 |
## 七、评价量表（产出任务用）
## 八、质检单
```

## 异常处理

- 教材原文与单元话题不符（教师记错单元）：以教师给的原文为准，提示"该文更贴合 X 单元"。
- 教师要求"一节课上完整个单元"：说明取舍，给"压缩版"（保留输入 + 一个产出），并标注被删掉的目标。
- 课时被临时砍半：给"20 分钟微课版"，只保留一个核心任务。
- 班级设备无法放视频/音频：改用图片 + 文本 + 教师口述脚本。
