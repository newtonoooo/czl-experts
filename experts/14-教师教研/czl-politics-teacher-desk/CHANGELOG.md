# 更新日志

本文件记录每一次对外发布的变更。版本号遵循语义化版本：主版本.次版本.修订号。

## 1.0.0 — 2026-11-01

首个公开版本。

### 新增：八条工作流

- **W1 任务受理与拆单**：把模糊需求翻译成工单，明确"做什么、按什么标准做"，含冲突拆单与追问上限（一轮、最多三问）。
- **W2 单元与专题规划**：单元/学期/一轮二轮三轮复习的差异化排法，含课时压力提示。
- **W3 课时教学设计**：五种课型骨架（新授议题式、复习、讲评、习题、公开课），目标—活动—评价三线对齐。
- **W4 课件与板书**：分页框架（页码/标题/内容/呈现方式/学生活动）+ 板书构图 + 翻页节奏 + 课前准备清单。
- **W5 作业与命题**：先填双向细目表再选题材，含干扰项八种错因、三档评分标准、常见错答给分。
- **W6 批阅与学情诊断**：得分率/区分度/选项集中度，五类错因（A—E），临界生识别，四类教学归因。
- **W7 试卷讲评**：只讲三题，错解还原 + 变式补偿 + 收口动作，含课后补偿清单。
- **W8 出门质检**：五道闸（事实/对齐/可教/可评/可核），未通过项如实标注，不假装合格。

### 新增：知识底稿（8 份）

- 教材模块地图：七册分工、主题群、核心概念、素养落点、常见考法、"由情境反推册次"训练法。
- 高频易混概念辨析：40 组，含一句话区分、判断口诀、典型设问。
- 课型框架与议题式教学设计：议题/情境/活动/评价四要素的合格标准，问题链三层结构与五种伪问题。
- 命题蓝图与评分细则：四项能力、情境三难度、干扰项八型、十二条命题硬伤、分档标准写法。
- 成绩分析与学情诊断：五个指标、五类错因判据、临界生找法、统计陷阱。
- 时政素材采编与核实规范：来源四级、五步核验、素材卡六字段、三条教学转化路径、六条敏感边界。
- 交付格式规范：五类产出的必备字段、版式、长度上限、命名规则。
- 权威来源索引：按用途分渠道、检索式写法、引用格式、引用边界。

### 新增：模板（5 份）

单元规划、课时教学设计、课件框架与板书、单题与评分细则、试卷讲评课设计。

### 新增：检查脚本（2 个运行时 + 2 个构建时）

- `lesson_lint.py`：教案/规划/讲评稿的章节完整性、占位符、时间加总、目标—评价对齐、禁用表述。
- `item_lint.py`：试题的设问/答案/分档/干扰项/命题意图/来源标注，拦截"言之有理即可"类空答案。
- `selfcheck.py`：按客户端实际规则校验头像可解析性（路径、格式、尺寸、体积）与元数据一致性。
- `build_release.py`：自检通过后打包，保证 zip 只有一个顶层目录（客户端导入的硬要求），输出 SHA256 与文件清单。

### 设计取舍

- 不写"名师""专家""三十年经验"一类无法验证的资历表述，产品定位放在"能交什么"上。
- 不内置任何具体时政结论；时政素材一律现查现核，核不实标"需核实"。
- 评分标准拒绝"言之有理即可"，一律要求分档 + 踩分点 + 常见错答给分。
- 质检不过的稿子如实标注未过项，不以"已完成"掩盖。

### 已知限制

- 教材单元名称与课次以本校在用教材目录为准，本包只提供模块级结构与教学判断。
- 各省高考卷型与考试说明未内置，涉及卷型结构时须用户提供或另行核实。
- 脚本只做机械检查，不能替代教学专业判断。
