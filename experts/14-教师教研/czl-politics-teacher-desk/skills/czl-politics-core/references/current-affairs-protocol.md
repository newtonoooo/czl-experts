# 时政素材采编与核实规范

> 用途：把一条新闻变成能上课、能出题的材料。
> 铁律：**本文件不预置任何时政结论。** 所有具体素材必须现查现核，写明来源与日期。宁可不用，不可用错。

## 一、来源分级

| 级别 | 来源 | 能否直接进课堂 | 备注 |
|---|---|---|---|
| A 级 | 中国政府网、新华社、人民日报、求是、国家统计局、部委官网、法律法规数据库 | 可以直接用 | 仍需记录发布日期 |
| B 级 | 省级党报、中央级媒体下属客户端、权威学术期刊 | 可用，需交叉验证一次 | 注意是否转载 |
| C 级 | 商业门户、垂直自媒体、短视频账号、境外媒体转述 | **不作为事实来源** | 只能用作"话题线索"，需回溯到 A/B 级 |
| D 级 | 来源不明、截图、聊天记录、AI 生成内容 | 一律不用 | 无法核实 = 不存在 |

**一条硬规矩**：课堂上引用的每一个数字，必须能回答"哪个机构、什么时候、什么口径发布的"。

## 二、五步核验

1. **回溯原始发布**：转发链条上的内容一律不算，找到首发机构原文。
2. **对齐日期**：确认是"新发生"还是"旧闻重提"。旧闻当新闻用，是时政课最常见的事故。
3. **核对口径**：同比还是环比？全国还是某省？绝对数还是占比？口径不清的数字不能用。
4. **交叉验证**：至少两个 A/B 级来源表述一致。只有一家在说，且措辞含糊，先搁置。
5. **判断可用性**：这条素材是否有明确的冲突点、是否与教材概念对得上、是否适合高中生认知。三问有一问"否"，换素材。

## 三、素材卡（每条素材一张，写清六项）

```
【标题】一句话，不加评论
【来源】机构名 + 文章标题 + 发布日期（YYYY-MM-DD）
【关键事实】不超过 3 条，每条一句，只用原文有的事实
【冲突点】这件事争议在哪（一句话）
【教材对接】册次 + 单元/主题 + 核心概念（1—2 个）
【可用设问】1 个判断层问题（不是"说明了什么"）
【核实状态】已核实 / 待核实（待核实的不得进课堂和试卷）
```

素材卡不超过 200 字。超过说明你抄多了，还没提炼。

## 四、从素材到教学的三种转化

### 路径一：情境化（用于新课导入）
把素材压成 150—250 字的冲突场景，去掉评论，只留事实和当事人的话。
要点：**保留具体数字和时间**，删掉所有形容词和记者的判断。

### 路径二：议题化（用于探究活动）
把素材里的冲突提炼成一个可判断的问句。
不合格：「谈谈对某某政策的认识」。
合格：「这项政策在 A 地见效、在 B 地遇阻，差别在哪？」

### 路径三：设问化（用于命题）
按 `exam-blueprint.md` 的设问动词表，把素材转成一道题。注意：**材料里不能出现结论句**，出现即失效。

## 五、引用格式（课堂与试卷统一）

课堂板书/课件：
> 据新华社 2026 年 X 月 X 日报道

试卷材料：
> 材料一：……（摘自《人民日报》2026 年 X 月 X 日）

**不要写"据了解""有关数据显示""网上有人说"。** 这三个短语在政治课上是禁用词。

## 六、敏感边界（写作时逐条过）

1. 涉及国家主权、领土完整、民族、宗教、历史定论的表述，严格按官方口径，不作个人化解读、不作引申。
2. 涉及重大政策效果，只陈述官方发布的事实与数据，不做好坏评价、不做预测。
3. 涉及具体企业、个人、地方的负面事件，不点名进材料；如必须用，改为"某地""某企业"并做去标识化处理。
4. 涉及境外事件与他国政治，只作事实陈述与教材概念对应，不作价值判断。
5. 不把未经证实的网络说法写进材料，哪怕它"很有讨论价值"。
6. 不使用可能引发误解的图片、图表；图表必须标数据来源与年份。

## 七、时效性管理

- **建立当学期素材夹**：按"经济/政治/法治/文化/国际"五类存放素材卡，每周更新一次。
- **三个月原则**：课堂情境优先用三个月内的素材；超过半年的，除非是标志性事件，否则换掉。
- **考前一个月冻结**：进入命题阶段的素材必须已核实，且不再更换，避免说法前后不一。
- **旧素材的用法**：可以留作"对比材料"（今昔对比、中外对比），但必须标明时间。

## 八、六个常见坑

| 坑 | 后果 | 防法 |
|---|---|---|
| 用自媒体转述当事实 | 数据或表述错误，课堂翻车 | 回溯原始发布 |
| 旧闻当新闻 | 学生一查就发现，信任崩塌 | 对齐发布日期 |
| 口径不明 | 学生记住了错的量级 | 问清同比/环比、范围 |
| 材料里带结论 | 探究变成抄写 | 删掉所有"这说明" |
| 素材太复杂 | 学生读不完，活动失败 | 压到 250 字内，一个冲突 |
| 只挑"正能量"素材 | 议题没有张力，学生不参与 | 允许呈现真实困难，再讨论怎么解决 |
