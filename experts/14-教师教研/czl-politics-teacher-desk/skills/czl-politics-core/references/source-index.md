# 权威来源索引与检索规范

> 用途：核实事实时的第一站。
> 说明：站点名称与域名以实际可访问情况为准，访问前请自行确认；**本文件不提供任何时政结论，只给渠道和方法。**

## 一、按用途分渠道

| 要核实什么 | 首选渠道 | 备注 |
|---|---|---|
| 政策文件原文、会议公报 | 中国政府网（www.gov.cn） | 认"国务院文件""中央文件"栏目 |
| 教育政策、课程标准、教材目录 | 教育部官网（www.moe.gov.cn） | 课程标准以正式出版文本为准 |
| 经济数据（GDP、CPI、收入、就业） | 国家统计局（www.stats.gov.cn） | 注意"初步核算"与"最终核实"的区别 |
| 重大时政报道 | 新华社（www.news.cn）、人民日报（paper.people.com.cn） | 转发稿要回溯首发 |
| 理论阐述 | 求是网（www.qstheory.cn） | 用于理解表述口径，不作数据来源 |
| 法律条文 | 国家法律法规数据库（flk.npc.gov.cn） | 优先于任何二手解读 |
| 立法过程、法律草案 | 中国人大网（www.npc.gov.cn） | 注意"草案"与"通过"的区别 |
| 司法案例（教学用） | 中国裁判文书网（wenshu.court.gov.cn） | 教学化处理，去标识化 |

## 二、检索式的写法

不要用"最近有什么时政新闻"这种问法，检索不到东西。用**限定式**：

```
site:gov.cn 关键词 2026
"关键词" 新华社 2026年
关键词 国家统计局 数据 同比
```

三条经验：
1. **加时间限定**。不加时间，搜到的多是三年前的旧闻。
2. **加机构名**。同一件事，机构稿和自媒体稿是两个东西。
3. **搜原文里的关键句**，不要搜你的概括。你想的词和文件用的词往往不一样。

## 三、引用格式

- 课堂/课件：`据新华社 2026 年 X 月 X 日报道`
- 试卷材料：`（摘自《人民日报》2026 年 X 月 X 日）`
- 数据：`（数据来源：国家统计局，2026 年 X 月）`
- 法律条文：`《中华人民共和国民法典》第 X 条`

**禁用表述**：据了解、有关数据显示、网上有人说、专家认为（不具名）、据说。

## 四、核实时的心态

1. **能查到原文才算核实**。查到转述不算。
2. **查不到就写"需核实"**，不要用"一般来说""大致"糊过去。
3. **数字宁少勿错**。少一个数据，教案照样能上；错一个数据，课上会被学生当场问住。
4. **旧闻新用要标时间**。对比材料尤其要标，否则学生以为是同时发生的。

## 五、教材与课标的引用边界

- 教材原文：只引短句，用引号标出，注明"以教材原文为准"；不整段复述。
- 课程标准：可引用核心素养名称、课程内容要点的**概括性表述**，不整段抄录。
- 教辅与试卷：不复制原题原文；需要改编时，改情境、改设问、改数据，保留考点。
- 他人课件：不直接使用其版式与原创图示；需要时重画。
