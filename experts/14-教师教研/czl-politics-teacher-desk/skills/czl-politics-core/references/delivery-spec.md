# 交付格式规范

> 用途：定稿排版。同一个内容，格式乱就等于没做完。
> 原则：**教师拿到手，不需要再排版就能用。**

## 一、通用规则

| 项 | 要求 |
|---|---|
| 语言 | 中文；术语用教材表述，不用网络语、不用口语缩写 |
| 标题层级 | 最多三级（`#` / `##` / `###`），不用四级 |
| 表格 | 只用于对照（目标/环节/分值/错因），不用来堆大段文字 |
| 段落 | 一段不超过 4 行；超过就拆 |
| 时间标注 | 写"第 3 个环节（约 8 分钟）"，不写"大约八分钟后" |
| 文件名 | `模块-课题-产出类型-YYYYMMDD.md`，例如 `必修2-我国的经济发展-课时设计-20261101.md` |
| 落盘位置 | 用户指定目录；未指定则当前目录下 `政治备课产出/` |
| 结尾 | 固定附"教师备注"三段：最可能出问题的地方 / 需按学情调整处 / 可替换素材 |

## 二、五类产出的必备字段

### 1. 单元规划（unit-plan）

必备：单元定位（在整册中的位置）｜学情起点｜单元目标（3—5 条，每条含素养落点）｜课时分配表（课时/课题/核心概念/主要活动）｜议题线（贯穿单元的主议题 + 每课时子议题）｜评价任务（过程性 + 终结性）｜作业配比｜单元结束时学生应能回答的三个问题。

不写：教材目录抄录、大段课标原文。

### 2. 课时教学设计（lesson-plan）

必备：课题与课时｜课型｜教学目标（3 条，行为动词可观察）｜教学重难点及突破策略｜教学准备｜教学过程（环节/时长/教师活动/学生活动/设计意图，五列）｜板书设计｜作业（分层：必做/选做/挑战）｜评价证据（怎么知道学生达成了）｜教学反思预设（两个可能出问题的地方）。

不写："通过本节课的学习，培养学生的核心素养"这类空目标。

### 3. 课件框架（slide-outline）

必备：每页一行，五列——页码｜页面标题｜呈现内容（要点，不超过 5 条）｜呈现方式（文字/图示/表格/视频/实物）｜学生活动。
另附：板书构图（文字描述即可）、翻页节奏说明（哪几页要停、停多久）、需要提前准备的材料清单。

不写：逐字稿（课件不是讲稿）。总页数建议 12—18 页，超过 20 页说明内容没删够。

### 4. 试题（exam-item）

必备：题干｜设问｜参考答案｜分档评分标准｜踩分点｜常见错答与给分｜命题意图（考什么能力、对应哪个概念、预估难度）。
选择题额外需要：四个选项 + 每个干扰项的错因类型。
一组题额外需要：双向细目表。

不写："言之有理即可"、无分档的总分标准、来源不明的材料。

### 5. 讲评课设计（review-lesson）

必备：数据摘要（3 行：人数/均分/得分率，不写排名）｜讲评优先级（讲哪三题、为什么是这三题）｜典型错解还原（匿名原答 + 错因归类）｜变式训练（同错因、换情境，至少 1 题，含答案）｜收口动作（学生写什么）｜课后补偿清单。

不写：全卷逐题讲、公布排名、只讲正确答案不讲错因。

## 三、版式细节（决定"能不能直接印"）

- **教案**：A4 纵向，教学过程用表格；表格列宽够放文字，不要挤成一列。
- **课件框架**：一页一条，不要合并；页码连续。
- **试卷**：题干与选项分行；主观题预留作答空间说明（如"请在答题卡指定区域作答"）。
- **讲评稿**：错解还原部分用引用块，与教师讲解区分开。
- **规划类**：课时表用表格，不要用项目符号列表。

## 四、长度上限（超过就是没删够）

| 产出 | 上限 |
|---|---|
| 单元规划 | 3 页 A4 |
| 单课时教案 | 3 页 A4 |
| 课件框架 | 1 页 A4（不含板书图） |
| 单道主观题（含答案与标准） | 1.5 页 A4 |
| 讲评课设计 | 2 页 A4 |
| 诊断报告 | 2 页 A4 |

## 五、定稿前必跑

```bash
python scripts/lesson_lint.py <文件>     # 教案/规划/讲评
python scripts/item_lint.py <文件>       # 试题
```

脚本会拦下：占位符残留、必备章节缺失、时间加总超课时、目标与评价数量不匹配、空答案、缺分档。
**脚本通过不等于合格**，还要人工过 `agents/czl-politics-teacher-desk.md` 第四节的五道闸。
