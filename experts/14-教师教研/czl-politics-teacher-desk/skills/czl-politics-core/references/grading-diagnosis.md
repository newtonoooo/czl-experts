# 成绩分析与学情诊断

> 用途：拿到一次考试的数据之后，把"分数"翻译成"下一步教什么"。
> 前提：**分数本身不是结论。** 同一个 62 分，可能是知识缺口，也可能是表达不规范，处理方式完全不同。

## 一、先看五个数，再看题

拿到一份班分成级表，按顺序看：

| 指标 | 怎么算 | 看什么 |
|---|---|---|
| 样本量 | 参考人数 | 少于 30 人，班级层面结论不可靠，只能看个人 |
| 均分 | 总分 / 人数 | 只看趋势，不和别的卷子横比 |
| 得分率 | 均分 / 满分 | 唯一可以跨卷比较的指标 |
| 标准差 | 见下 | 大于满分的 15%，说明班内分化严重 |
| 及格率/优秀率 | 按本校口径 | 口径必须写清，否则数字没意义 |

标准差（总体）：
```
σ = sqrt( Σ(xi - x̄)² / N )
```
课堂估算：把全班按分数排序，看前 1/6 和后 1/6 的分差。分差超过满分的 30%，就是双峰，不是正态。

**最常见的统计陷阱**：拿两次不同卷子的均分直接比。卷子难度不同，均分没有可比性，只能比得分率或位次。

## 二、逐题看三件事

1. **得分率**：低于 0.4 是重灾区，0.4—0.6 是薄弱区，0.6 以上基本过关。
2. **区分度**：把全班按总分排序，取前 27% 和后 27%，`D = 高分组该题得分率 − 低分组该题得分率`。
   - D ≥ 0.4：好题，能区分
   - 0.2 ≤ D < 0.4：一般
   - D < 0.2：该题没有区分作用（全班都不会，或全班都会，或题目本身有问题）
3. **选项分布**（选择题）：正确选项集中在某一个错误项上，说明这是**共性误区**，不是个别失误。这一条比得分率更有教学价值。

## 三、五类错因（诊断的核心工具）

所有错误归到这五类，不许归到"粗心"。

| 类型 | 表现 | 判据 | 教学对策 |
|---|---|---|---|
| A 知识缺口 | 完全不知道这个概念 | 答案里没有相关术语 | 补讲，但要补在结构里，不孤立补 |
| B 概念混淆 | 用了相邻但错误的概念 | 出现"国有经济主体""政府依法执政"这类 | 辨析训练（见 `concept-clinic.md`） |
| C 材料未读懂 | 术语对但和材料对不上 | 答案与材料无关，或只抄材料 | 材料精读训练：划主体、划冲突、划限定 |
| D 设问误读 | 答非所问（问措施答原因） | 答案方向与设问动词不符 | 设问动词专项训练 |
| E 表达不规范 | 意思对但不得分 | 无主体、无术语、无层次、口语化 | 答题模板 + 互评量规 |

**判据说明**：判断错因不能靠问学生"你懂不懂"，要看他的答案文本。答案里没有术语 → A；有术语但用错 → B；术语对但脱离材料 → C；方向错 → D；方向对但写不成句 → E。

## 四、临界生怎么找

不是"差一点及格的学生"，而是**"再多 5—8 分就能上一个档位"的学生**。

操作方法：
1. 定档位线（如本科线、重点线对应的校内外分数）。
2. 找出距离档位线 5—8 分的学生。
3. 看这些学生的失分集中在哪类错因：
   - 集中在 E（表达）：**提升最快**，两周专项训练可见效。
   - 集中在 B（概念混淆）：需要 3—4 周辨析训练。
   - 集中在 A（知识缺口）：需要更长时间，且要看缺的是主干还是枝节。
4. 临界生名单**只用于教学安排，不在班里公布**。

## 五、教学归因（写给自己的部分）

诊断报告的最后一段必须回答："这次的问题，有多少是我的教学造成的？"

四种常见的教学归因：

| 归因 | 证据 | 调整 |
|---|---|---|
| 讲过但没练过 | 该知识点课堂有讲，作业无对应题 | 补一道变式，不需要重讲 |
| 练过但没讲评 | 作业有，讲评课跳过了 | 下次讲评必须覆盖 |
| 讲评过但没变式 | 讲过，学生当时点头，考试仍错 | 讲评课必须带变式训练 |
| 从来没讲过 | 该考点不在本段教学计划内 | 排进复习计划，不追责 |

**禁止归因**："学生基础太差""这届学生不努力"。这类归因不产生任何教学动作。

## 六、诊断报告的标准结构

```
一、总体情况（3 行以内：人数、均分、得分率、标准差、与上次的得分率对比）
二、逐题诊断（表格：题号/考点/得分率/区分度/主要错因/典型错答）
三、错因分布（A—E 五类的占比，配一句结论）
四、临界生分析（人数、失分集中类型、两周内的具体动作）
五、教学归因（上面四类中的哪几类，各占多少）
六、下一步（三件事，每件写清谁做、什么时候做、怎么验证）
```

**长度控制**：班内诊断报告不超过 2 页 A4。写长了没人看，等于没写。

## 七、三条经验

1. **先看选项分布，再看得分率**。得分率告诉你"难"，选项分布告诉你"错在哪"。
2. **一次只改一件事**。诊断出五个问题，下周只解决最要命的那个，其余排队。
3. **诊断报告要给学生在课堂上看到**（匿名、去排名），否则学生不知道"原来大家都错在这"。
