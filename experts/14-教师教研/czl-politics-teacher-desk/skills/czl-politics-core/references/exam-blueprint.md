# 命题蓝图与评分细则

> 用途：出题、改题、审题。
> 前提：命题不是"找段材料配个问"，是**先定考什么能力，再选材料，最后定设问和标准**。顺序反了，题一定飘。

## 一、先定能力，再定材料

高中政治常说的四项能力（表述以本省考试说明与课程标准为准，此处为教学通用说法）：

| 能力 | 学生要做的动作 | 对应设问 |
|---|---|---|
| 获取和解读信息 | 从材料里提取有效信息、读懂图表、识别立场 | "材料反映了什么""概括……的变化" |
| 调动和运用知识 | 由信息反推知识点，选对册次和概念 | "运用……知识说明" |
| 描述和阐释事物 | 说清是什么、为什么、意味着什么 | "分析……的原因""阐释……的意义" |
| 论证和探究问题 | 立论、驳论、提出方案、评价观点 | "评析……""就……提出建议""论证……" |

**一张卷子的能力分布不能全压在第二项。** 全是"运用知识说明"的卷子，考的是默写，不是思维。

## 二、情境的三种难度

| 类型 | 特征 | 适合 |
|---|---|---|
| 简单情境 | 单一主体、单一事件、信息直给 | 选择题前半、基础题 |
| 一般情境 | 多主体、有背景、需要筛选信息 | 选择题后半、主观题第一问 |
| 复杂情境 | 有冲突、有反方、信息需要整合甚至补全 | 主观题压轴、开放性试题 |

结构良好（条件齐、答案唯一）适合训练；**结构不良（条件不全、需要自己补充假设）才是真实世界的样子**，一张卷子至少要有一道。

## 三、设问的三条硬标准

1. **指向清楚**：学生读完知道要答"原因"还是"措施"，不能两个都像。
2. **范围明确**：限定册次或知识点（"运用《政治与法治》的知识"），不写"运用所学知识"了事——那是把所有册次都打开，学生只会乱答。
3. **可推可答**：答案必须能从"材料 + 教材"推出来。推不出来的，是超标；材料里直接写着的，是送分。

**自检问句**：把设问和材料给我，我能不能写出三类不同的合格答案？写不出三类，说明设问太窄或太偏。

## 四、双向细目表（命题前先填）

| 题号 | 题型 | 分值 | 对应模块 | 核心概念 | 能力层级 | 情境类型 | 预估难度 |
|---|---|---|---|---|---|---|---|
| 1 | 单选 | 3 | 必修2 | 公有制主体地位 | 获取解读 | 简单 | 易 |
| … | | | | | | | |

填不满的表，说明这套卷子结构有问题：要么某册占比过高，要么能力层级单一。

**配比参考**（可按本省卷结构调整，需核实）：必修内容约占 70%—80%，选必内容约占 20%—30%；易:中:难 约 3:5:2。

## 五、选择题的干扰项设计（八种）

好的干扰项不是"编一个错的说法"，而是"设计一个学生真的会犯的错"。

| 类型 | 做法 | 例 |
|---|---|---|
| 主体错位 | 把政府的行为说成党 | "政府依法执政" |
| 概念偷换 | 用近义但不同层次的概念 | "国有经济是主体" |
| 程度失真 | 把"重要"说成"决定" | "XX 是根本保证"（原文只是"重要保障"） |
| 因果倒置 | 把结果说成原因 | 把"经济发展"说成"收入提高的结果" |
| 范围扩大 | 把局部说成整体 | "所有企业都必须……" |
| 条件缺失 | 少了限定条件就变成错的 | "市场调节可以实现资源最优配置"（缺"在……条件下"） |
| 时态错误 | 把"正在推进"说成"已经完成" | "已全面建成" |
| 无关正确 | 说法本身对，但与材料无关 | 最容易被忽略的一种 |

**每个干扰项都要写一句"错在哪"**，写不出来的干扰项，是凑数的。

## 六、主观题的答案结构

### 通用三层

1. **定性/表态**（是什么、对不对、合理与否）
2. **依据 + 材料对应**（哪个概念、材料哪句话）
3. **结论/条件**（所以应怎样；在什么条件下这个判断成立）

### 三类常见题型的差异

| 题型 | 结构 | 失分点 |
|---|---|---|
| 原因类 | 必要性 + 重要性 + （有时）现实紧迫性 | 只答重要性，漏必要性 |
| 措施类 | 主体 + 动作 + 对象 + 目的 | 主体缺失，写成"要加强" |
| 评析类 | 判断 + 合理之处 + 不合理之处 + 条件 + 结论 | 不表态，或只讲一面 |

## 七、评分细则怎么写

**不合格的细则**：
> 答出两点给 4 分，言之有理即可。

这句话的问题：学生不知道自己为什么得 4 分，教师之间也打不齐。

**合格的细则**必须能回答："这个学生得 6 分而不是 4 分，差在哪句话？"

结构：

```
【参考答案】
① ……（2 分）
② ……（2 分）
③ ……（2 分）

【分档标准】
第一档（5—6 分）：能完整表述①②③，且每点有材料对应。
第二档（3—4 分）：能答出两点，或三点中有一处未与材料对应。
第三档（1—2 分）：只能答出一点，或只有术语没有材料。
0 分：答非所问、空白、照抄材料。

【踩分点】
- 术语准确（如"公有制主体地位"而非"国有经济主体"）——每处错扣 1 分，最多扣 2 分
- 材料对应（引用或转述材料关键信息）——缺一处扣 1 分

【加分表述】（不超过 2 分）
- 能指出该做法的适用条件或局限
- 能联系另一册次的相关知识作补充
- 能提出可操作的改进方向

【常见错答与给分】
- 只写术语不结合材料：给术语分，不给材料分
- 只抄材料：0—1 分
- 术语正确但主体错位：该点不给分
```

**开放性试题**不能写"言之有理即可"，要写水平描述：

| 水平 | 分值 | 表现 |
|---|---|---|
| 水平 4 | 8—10 | 观点明确，论据充分，能回应反方，逻辑自洽 |
| 水平 3 | 6—7 | 观点明确，有论据，但未回应反方 |
| 水平 2 | 3—5 | 有观点，论据单薄或与观点不完全对应 |
| 水平 1 | 1—2 | 只有态度表述，无论证 |
| 0 分 | 0 | 空白、离题、价值观错误 |

## 八、十二条命题硬伤（逐条自查）

1. 材料虚构或来源不明。
2. 材料里已含结论，学生只需抄。
3. 设问与材料脱节（材料讲 A，问 B）。
4. 一道题考了三个不相干的知识点。
5. 选项之间互相提示答案（如两个选项互为反义）。
6. 正确选项明显比其他三项长或专业。
7. "以上都对/都不对"滥用。
8. 主观题答案超出材料与教材可推范围。
9. 评分标准只有总分，没有分档和踩分点。
10. 时政数据过时或口径不明（哪一年、哪一范围）。
11. 涉及具体人物、地区、学校的负面评价。
12. 存在导向问题的设问（诱导学生对制度、政策作否定性判断）。

第 12 条最重，一旦出现，整题作废，不是修改的问题。

## 九、难度控制

- 难度不是"题难"，是"学生想不到"。**想到就能答对的题，难度来自信息筛选；想到了也答不对的题，难度来自知识缺口。**
- 一张卷子里，纯知识缺口型难题不超过 20%，否则区分度会塌（大家都不会，等于没区分）。
- 预估难度靠"三问"：这个材料学生读过类似的吗？这个概念是重点讲过的吗？这个设问动词学生练过吗？三问都"是"，估 0.7 以上。

## 十、成品自检（用脚本先跑一遍）

```bash
python scripts/item_lint.py <试题文件.md>
```

脚本会查：题干是否完整、选项数量、答案是否齐全、解析是否写了干扰项错因、评分标准是否有分档、是否出现"略""言之有理即可"。
