## 五、关于 T6 的那一项不通过

官方 `validate_expert.py`（v2.0）内置分类表只有 12 个 ID，不含 `15-Education`，因此报 `invalid categoryId`。

我保留 `15-Education` 的依据：
- 本机市场内已有 **21 个**教育类专家使用该 ID（含本开发者此前发布的语文、数学、英语、物理、化学、生物、历史等学科助手）；
- 该分类是客户端从服务端拉取的，不由本地脚本决定；
- `register_expert.py` 与客户端加载逻辑均不校验分类 ID，实测注册成功。

如果平台侧拒绝该 ID，改一处即可：`plugin.json` 的 `categoryId` 改为 `09-OperationsHR`，重跑 `selfcheck.py` 与打包。

## 六、已知限制（不是缺陷，是设计边界）

1. 教材单元名称与课次以本校在用教材目录为准，包内只做模块级结构。
2. 各省高考卷型未内置，涉及卷型结构时需用户提供或另行核实。
3. 两个检查器只做机械检查，不能判断教学设计好坏。
4. 时政素材必须现查现核，包内不含任何具体时政结论。

## 七、最终交付包指纹

为避免文档微调导致哈希失效，本报告不写死 SHA256。以构建产物为准：

```
dist/czl-politics-teacher-desk.zip
dist/czl-politics-teacher-desk.zip.sha256     ← 用这个核对
dist/czl-politics-teacher-desk.manifest.json  ← 逐文件大小清单
```

核验命令：

```bash
python -c "import hashlib;print(hashlib.sha256(open('dist/czl-politics-teacher-desk.zip','rb').read()).hexdigest())"
```
