# 使用说明

## 一、装在哪

专家目录（不要放到别处，否则客户端检测不到）：

```
Windows：C:\Users\<用户名>\.workbuddy\plugins\marketplaces\my-experts\plugins\
macOS/Linux：~/.workbuddy/plugins/marketplaces/my-experts/plugins/
```

如果设置了 `WORKBUDDY_CONFIG_DIR`，根目录换成它。

装好后在 WorkBuddy「专家中心 → 我的专家」里应该能看到「卓识教育-高中政治老师助手」。
看不到时：确认目录名是 `czl-politics-teacher-desk`，`.codebuddy-plugin/plugin.json` 存在，然后重跑注册（见第五节）。

## 二、开场怎么说

三种给法，从省事到精确：

**① 一句话**
```
帮我把必修2《经济与社会》做成单元整体规划
```
它会按默认（6—8 课时、中等偏上学情）做，开头一行写清假设。

**② 带约束**
```
帮我把必修2第二单元做成单元规划，我们只有 5 课时，学生基础一般
```

**③ 带材料**
```
这是这次月考的成绩表（附件），全班 46 人，满分 100，帮我做诊断和讲评课设计
```

## 三、八种典型用法

### 1. 备一节新课
```
用一份真实材料设计一节议题式新课，必修3《政治与法治》"人民当家作主"，
40 分钟，要议题、情境、问题链、板书和评价量表
```
你会拿到：教案（六环节，含时长）+ 板书 + 分层作业 + 教师备注。

### 2. 配课件
```
按刚才这份教案，给我 15 页的课件框架，学校只有投影没有平板
```

### 3. 出题
```
按这个单元出 4 道单选和 1 道主观题，总分 27 分，要评分标准和双向细目表
```

### 4. 改题
```
这道题（附件）设问太宽，学生能答出七八点，帮我收窄并重写评分标准
```

### 5. 成绩诊断
```
这是两个班的成绩（附件），想看整体情况和临界生，不要排名
```

### 6. 讲评课
```
上周的卷子，第 7 题得分率 0.31，第 12 题错选集中在 C，
帮我设计一节 40 分钟讲评课
```

### 7. 复习规划
```
高三一轮复习，必修2 部分，大概 12 课时，帮我排一个专题计划
```

### 8. 质检
```
这是我写的教案（附件），帮我看能不能直接上，哪里会被听课老师挑出来
```

## 四、怎么让它做得更准

**给材料比给描述有用。** 一句"学生基础一般"不如贴一份上次的得分表；一句"要真实材料"不如直接给一条带出处的新闻。

**明确说课时。** 40 分钟和 45 分钟差一个环节，不说它就按 40 分钟排。

**不满意时说具体。** "再改改"没有信息量；"探究环节给多了 4 分钟，砍到 10 分钟，把展示合成一组"它能立刻改。

**别让它猜关键信息。** 模块、课题、课型这三项它不会瞎猜，会问你；其余它会假设并在开头声明。

## 五、自己动手检查与打包

在专家包根目录执行：

```bash
# 检查包是否合规（元数据、头像、引用、占位符）
python tools/selfcheck.py

# 生成可上传的 zip（先自检，通过才打包）
python tools/build_release.py . ./dist
```

产物在 `dist/`：`czl-politics-teacher-desk.zip`、`.sha256`、`.manifest.json`。
**上传前先看自检结果里的头像那一行**——头像不合格时客户端不报错，只会把头像换成"渐变底 + 姓名首字"。

## 六、常见问题

**Q：它写的教案能直接用吗？**
结构能直接用，内容要过一遍。特别是学情和本校教材目录，它只能按通用情况写，班级差异必须你自己调。

**Q：为什么它总要标注"需核实"？**
因为政治课说错一个数据，代价在考场上。核不实的东西它不会编，会留一个标记给你。

**Q：能帮我押题吗？**
不能。可以做"高频考点覆盖度分析"和"同类题训练"，不做押题。

**Q：评分标准为什么这么长？**
因为短的标准打不齐分。三档 + 踩分点 + 常见错答给分表，是为了让两位老师打同一份卷子能打到同一个分。

**Q：能改风格吗？**
可以。人设在 `agents/czl-politics-teacher-desk.md`，知识底稿在 `skills/czl-politics-core/references/`，改完跑一次 `selfcheck.py`。

**Q：我自己写了教案，能只做质检吗？**
能。直接说"帮我看看这份行不行"，它走 W8，只出质检单，不擅自改写你的风格。

## 七、边界

- 只覆盖高中思想政治统编教材必修 1—4、选择性必修 1—3。
- 不做押题、不编数据、不替学生写作业。
- 不评价具体教师、学校、地区，不出排名。
- 涉及真实法律纠纷只做教学化处理，不下结论。
- 学生成绩数据只用于当前任务，不额外留存。
