## 七、文件之间的依赖关系

```
plugin.json
 ├── agents/czl-politics-teacher-desk.md      ← 人设与路由
 ├── skills/czl-politics-core/SKILL.md        ← 技能入口
 │    ├── references/*.md                     ← 判据与知识
 │    ├── templates/*.md                      ← 成品骨架
 │    └── scripts/*.py                        ← 运行时检查
 └── avatars/expert.png                       ← 头像
workflows/*.md   ← 被 SKILL.md 与 agents MD 引用，按需读取
tools/*.py       ← 仅构建时使用，不影响专家运行
```

**运行时真正被加载的**：`plugin.json` → `agents/*.md` → `SKILL.md`（按需再读 references/templates/scripts）。
**不参与运行时的**：`workflows/`、`tools/`、`docs/`（由 agent 在需要时用文件工具读取）。
