## 四、版权与许可风险

### 4.1 已识别风险

| 编号 | 风险 | 影响 | 处置 |
|---|---|---|---|
| R1 | **"卓识教育"可能是在先商标** | 若他人在第 41 类（教育培训）注册，商用上架存在侵权风险 | 上架前做一次商标检索（中国商标网，第 41 类"教育""培训"）；如有冲突，改用不含该字号的名称，如"政治备课台""政课工坊" |
| R2 | **AI 生成头像的权利归属** | 生成物能否主张著作权，依服务条款与所在地规则而定；多数平台要求标注"AI 生成" | 保留生成提示词与生成时间（已在 `docs/开发记录.md` 记录）；上架时如实勾选"AI 生成"选项；如需强主张，改用人工绘制或购买授权图 |
| R3 | **教材与课标表述** | 大段引用教材或课标条文可能超出合理使用 | 本包只使用模块名称、核心素养名称等事实性信息，未复制条文；后续若扩充，需保持"只引短句并标注" |
| R4 | **时政素材** | 使用未核实来源的素材可能引发事实性错误与导向问题 | 产品内已内置来源分级与五步核验；但模型仍可能引用过时信息，交付前须人工核对 |
| R5 | **用户上传的试卷/教辅** | 用户可能上传受版权保护的材料要求改编 | 产品已写明"只做教学化改造，引用范围请自行确认授权"；平台侧建议再加一次上传提示 |
| R6 | **评分标准与真题的相似性** | 若产出与某套真题高度相似，可能被指抄袭 | 模板要求"改情境、改设问、改数据"，并在 W5 异常处理中明确 |
| R7 | **个人许可与商业授权的冲突** | `LICENSE` 写明商业使用需书面授权，但你自己就是权利人 | 你是著作权人，不受该条限制；若后续引入合作开发者，需补一份权属约定 |

## 六、需要你决定的事（按优先级）

1. **字号风险**：是否保留"卓识教育"？建议先查商标，再决定。
2. **分类 ID**：坚持 `15-Education`（教育专区，符合产品定位，但与官方 v2.0 校验脚本冲突），还是退回 `09-OperationsHR`（脚本能过，但会被放进"运营人力"）。
3. **AI 头像披露**：上架时是否勾选"AI 生成"；如平台要求人工原创，需要另绘。
4. **商业授权条款**：`LICENSE` 目前写"商业使用需书面授权"。如果这个专家就是你自己上架销售，这条要不要保留？（保留可以防别人转售，但会让人误以为你自己也受限）
5. **是否加免责声明**：政治学科内容敏感度较高，建议在详情页加一句"本产品为教学辅助工具，涉及政策表述请以官方发布与教材原文为准"。

## 七、我的建议

- 先做商标检索（半天），再决定字号——这是唯一可能导致整包下架的风险。
- 分类 ID 维持 `15-Education`，上架时如被拒，再改 `09`，改动成本只有一行。
- 头像保留当前版本，上架时如实标注 AI 生成；这是成本最低且不违规的做法。
- 首次上架前打一个 Git tag，把"什么时候写的、写了什么"变成可追溯记录。
