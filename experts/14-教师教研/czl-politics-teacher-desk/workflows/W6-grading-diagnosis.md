# W6 批阅与学情诊断

## 任务职责

把分数翻译成"下一步教什么"：算清指标、归对错因、找到临界生、给出三件可执行的事。
**不做排名，不做学生评价。**

## 输入参数

| 参数 | 必填 | 说明 | 缺省 |
|---|---|---|---|
| `score_data` | 是 | 成绩表（学号/姓名/总分/各题得分） | — |
| `full_scores` | 是 | 各题满分与全卷满分 | — |
| `answer_sheet` | 否 | 典型错答（匿名） | 无 |
| `class_context` | 否 | 班级层次、上次得分率 | 无 |
| `goal` | 否 | 关注整体/临界生/某类题 | 整体 |

## 执行步骤

1. **体检**：人数、均分、得分率、标准差（>满分 15% 视为分化严重）。
2. **逐题**：算每题得分率与区分度（前 27% − 后 27%）。
3. **看选项**：选择题看错选集中度，集中即共性误区。
4. **归错因**：按 A—E 五类归类，看答案文本判，不靠问学生。
5. **找临界生**：距档位线 5—8 分的学生，看其错因集中在哪类。
6. **做归因**：四类教学归因（讲过没练/练过没讲评/讲评没变式/从没讲过）。
7. **出三件事**：每件写清谁做、何时做、怎么验证。

## 判定条件

| 情况 | 处理 |
|---|---|
| 样本 <30 人 | 只做个人层面结论，不做班级统计推断 |
| 缺各题得分，只有总分 | 只能出总体报告，说明"无法逐题诊断"，请补数据 |
| 区分度 <0.2 的题超过 1/3 | 先审题（可能是题目本身有问题），再诊断学情 |
| 某题得分率 >0.9 | 不纳入讲评，避免浪费时间 |
| 数据含学生姓名 | 输出时一律去标识（学号或化名） |
| 用户要比"和别的班比" | 只比得分率，不排名，不评价其他教师 |

## 输出格式

按 `grading-diagnosis.md` 第六节六段结构，2 页 A4 以内。
逐题表格列：题号/考点/得分率/区分度/主要错因/典型错答。

## 异常处理

| 异常 | 处理 |
|---|---|
| 成绩表列名混乱 | 先说明"我按第 X 列理解为总分"，请用户确认后再算 |
| 满分口径不一致（如某题 4 分记成 5 分） | 停下来核对，不硬算；算错比不算更糟 |
| 数据里有缺考/免考 | 剔除并注明人数变化 |
| 用户要求"分析某某学生" | 只做学习层面分析，不做性格、家庭、智力评价；不给学生贴标签 |
| 只有得分率没有原始分 | 可以出诊断，但区分度算不出，需注明 |
