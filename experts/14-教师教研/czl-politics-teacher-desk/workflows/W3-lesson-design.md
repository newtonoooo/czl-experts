# W3 课时教学设计

## 任务职责

产出一份能直接照着上的教案：目标可观察、环节可执行、评价可取证、时间算得过来。
这是使用频率最高的一条工作流。

## 输入参数

| 参数 | 必填 | 说明 | 缺省 |
|---|---|---|---|
| `module` | 是 | 册次 | — |
| `topic` | 是 | 框题/考点 | — |
| `lesson_type` | 否 | 新授/复习/讲评/习题/公开课 | 新授 |
| `duration` | 否 | 40/45 分钟 | 40 |
| `class_level` | 否 | 基础薄弱/中等/重点 | 中等偏上 |
| `material` | 否 | 指定素材（用户提供） | 自选并标来源 |
| `constraints` | 否 | 必须包含/必须避开的内容 | 无 |

## 执行步骤

1. **定课型**：读 `lesson-frames.md` 对应骨架，不混用。
2. **写目标**：3 条，每条含"行为动词 + 内容 + 程度"，并标素养落点。目标里出现"培养""体会""感受"的，改成可观察动作。
3. **定重难点**：重点看"本课最核心的那个概念"，难点看"学生最容易混淆的那一步"。两者不能写成同一句。
4. **选素材**：按 `current-affairs-protocol.md` 核验；无合适素材时用教材情境或校本素材，并注明。
5. **立议题**：一个判断问句，能在一节课内做出具体判断。
6. **排环节**：按骨架排，时间加总等于课时；讲授连续不超过 15 分钟。
7. **写任务单**：四行（判断/依据概念/材料原句/反方与回应），第 4 行不能省。
8. **配评价**：用水平描述（4 级），至少能区分水平 2 和 3。
9. **写板书**：中部结构 + 右侧学生生成。
10. **过闸**：W8 五道闸，重点查 G2 对齐与 G3 可教。

## 判定条件

| 情况 | 处理 |
|---|---|
| 课题内容量明显超过 1 课时 | 不压缩活动，改为"本课时聚焦 X，Y 放到下一课时"，并给出拆分建议 |
| 公开课 | 设计量加倍：加"反方材料"、加一个开放生成点、准备两个备用环节（防超时/防冷场） |
| 复习课 | 不套新授骨架，走"诊断—重建—补漏—变式—收口" |
| 讲评课 | 转 W7，不在本工作流内做 |
| 学生基础薄弱 | 情境 ≤150 字，事实层问题占一半，活动改两人组口头+全班记录 |
| 无真实素材可用 | 用教材情境或校本素材，明确标注"非时政素材"，不编造新闻 |

## 输出格式

套用 `templates/lesson-plan.md`。教学过程必须是五列表格（环节/时长/教师/学生/意图），不接受段落式叙述。

## 异常处理

| 异常 | 处理 |
|---|---|
| 目标写不出 3 条 | 说明本课内容偏单一，改为 2 条目标 + 1 条方法目标，不硬凑 |
| 环节时间加总超课时 | 优先删"教师补充讲解"，其次合并展示环节，最后才压缩探究 |
| 议题立不起来（找不到冲突） | 换素材，不硬造冲突；实在没有，改用"问题链驱动"并在开头说明 |
| 用户要求"必须讲完所有知识点" | 说明容量与深度不可兼得，给出"精讲 3 个 + 其余自学清单"的方案 |
| 素材涉及敏感内容 | 按 `current-affairs-protocol.md` 第六节处理，或换素材 |

## 与其他工作流的关系

- **上游**：W1、W2（单元规划给出课时定位）
- **下游**：W4（配课件）、W5（配套作业）
- **回退**：W8 判定"对齐闸不通过"→ 回 W3 改目标或活动，不允许只改措辞
