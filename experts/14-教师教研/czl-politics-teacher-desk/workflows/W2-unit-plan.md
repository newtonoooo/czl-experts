# W2 单元与专题规划

## 任务职责

把"一个单元"或"一个复习专题"排成有先后逻辑、有课时分配、有评价落点的序列。
**不做课时设计**（那是 W3），只做骨架和顺序。

## 输入参数

| 参数 | 必填 | 说明 | 缺省 |
|---|---|---|---|
| `module` | 是 | 册次 | — |
| `scope` | 是 | 单元名 / 专题名 / 学期范围 | — |
| `periods` | 否 | 可用课时数 | 按常规 6—8 课时 |
| `class_level` | 否 | 学情层次 | 中等偏上 |
| `exam_context` | 否 | 本段是否对接某次考试 | 无 |
| `existing_plan` | 否 | 备课组已有进度表 | 无 |

## 执行步骤

1. **定位**：读 `curriculum-map.md`，确认本单元在整册中的位置、与前后单元的衔接概念。
2. **定问题**：写出"本单元要解决的一个核心问题"，必须是一句可判断的话，不是名词短语。
3. **拆课时**：按概念依赖关系排顺序，不按教材页码顺序硬排。先学"是什么"再学"为什么"，最后"怎么做"。
4. **立议题线**：一个单元主议题 + 每课时一个子议题，子议题必须能推出主议题。
5. **配评价**：每个课时至少一个可观察的评价证据；单元末一个终结性任务。
6. **排作业**：基础/迁移/拓展三层配比，控制单次时长。
7. **写收束**：学完本单元，学生应能回答的三个问题。
8. **自检**：过 W8 的对齐闸与可教闸。

## 判定条件

| 情况 | 处理 |
|---|---|
| 单元课时不够（如 4 课时要上完 6 课内容） | 明确标注"合并处理"，并说明合并后哪一课时的容量偏大，建议哪部分移到作业 |
| 单元课时过剩 | 增加一节"专题辨析/综合应用"课，不要稀释每节课 |
| 是复习专题而非新授单元 | 结构改为"诊断—重建—补漏—变式—收口"，不套新授骨架 |
| 一轮复习 | 按教材顺序，目标是"全覆盖、建结构"，每个专题含 1 道跨册题 |
| 二轮复习 | 按题型/主题重组，目标是"迁移、提分"，每节课必须有变式训练 |
| 三轮复习 | 只做"回看错题 + 限时训练 + 规范表达"，不再讲新内容 |

**复习规划的三轮差异必须写清**，写不清就会出现"三轮都在从头讲"。

## 输出格式

套用 `skills/czl-politics-core/templates/unit-plan.md`，字段一个不能少。
额外附一行"单元课时压力提示"：如果按此方案，哪一课时最容易赶不完。

## 异常处理

| 异常 | 处理 |
|---|---|
| 用户只给"这个单元"，没给课时数 | 按常规课时排，开头注明"按 N 课时排，如实际课时不同，告诉我，我重排" |
| 教材版本/印次与本文件不一致 | 以用户教材目录为准，说明"本方案按你提供的目录调整" |
| 涉及跨册整合 | 指定主册，另一册只做补充，并在方案里写明"以 X 册为主答" |
| 用户要求"覆盖所有考点" | 说明不可能在一轮内既覆盖又讲透，给出取舍建议（主干必讲、枝节进作业） |
