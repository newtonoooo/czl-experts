# W5 作业与命题

## 任务职责

产出可直接印的题目：题干、设问、答案、分档标准、干扰项分析、命题意图，一套齐全。
**先定考什么能力，再选材料，最后定设问。** 顺序反了题必飘。

## 输入参数

| 参数 | 必填 | 说明 | 缺省 |
|---|---|---|---|
| `module` | 是 | 册次 | — |
| `scope` | 是 | 考点/单元/整册 | — |
| `item_type` | 否 | 单选/主观/开放性/混合 | 混合 |
| `count` | 否 | 题量 | 单选 4 道或主观 2 道 |
| `total_score` | 否 | 总分 | 按题量定 |
| `difficulty` | 否 | 易/中/难/梯度 | 梯度（3:5:2） |
| `purpose` | 否 | 随堂/作业/单元测/模考 | 随堂 |
| `material` | 否 | 指定素材 | 自选并核验 |

## 执行步骤

1. **填蓝图**：先写双向细目表（题号/题型/模块/概念/能力/情境/难度），填不满就调整结构。
2. **选材料**：按 `current-affairs-protocol.md` 核验，材料里删掉所有结论句。
3. **写设问**：按 `exam-blueprint.md` 的动词表选动词，限定册次，不用"运用所学知识"了事。
4. **设干扰项**：每道选择题的四个选项对应八种错因之一，写清"错在哪"。
5. **写答案**：主观题按"定性—依据+材料—结论"三层组织。
6. **写标准**：分档（3 档 + 0 分）+ 踩分点 + 加分表述 + 常见错答给分。
7. **过硬伤**：逐条过 12 条命题硬伤。
8. **跑脚本**：`item_lint.py`。

## 判定条件

| 情况 | 处理 |
|---|---|
| 随堂小测 | 3—5 题，10 分钟内完成，不配双向细目表（但要写命题意图） |
| 单元测 | 必须有双向细目表；主客观比例按本校卷型 |
| 模考 | 全卷结构对齐本省卷型（**卷型需用户提供或核实**，不臆造） |
| 开放性试题 | 必须用水平描述（4 级），禁止"言之有理即可" |
| 材料涉及具体企业/个人负面事件 | 去标识化，改"某企业""某地" |
| 需要跨册综合 | 指定主册，答案以主册知识为主，另一册只作补充（≤1 个得分点） |

## 输出格式

套用 `templates/exam-item.md`，每题一块；一组题前面附双向细目表。

## 异常处理

| 异常 | 处理 |
|---|---|
| 找不到合适材料 | 用教材情境改编，标注"改编自教材情境"，不编造新闻 |
| 设问写出来自己能答出七八点 | 设问太宽，收窄范围（限定册次或限定主体） |
| 干扰项凑不出四个 | 减少选项到三个并说明，不硬编（硬编的干扰项会送分） |
| 评分标准写不出分档 | 说明该题不可评，重设设问；不交"意思对即可"的题 |
| 用户要求押题 | 拒绝，改为"高频考点覆盖度分析 + 同类题训练" |
| 用户给了原题要"改一改" | 改情境、改设问、改数据，保留考点；提示"原题引用范围请自行确认授权" |

## 与其他工作流的关系

- **上游**：W1、W2（单元测）、W3（配套作业）
- **下游**：W6（考后诊断）、W7（讲评）
- **回退**：W8 判定"可评闸不通过"→ 回 W5 重写标准，不允许只补一句"酌情给分"
