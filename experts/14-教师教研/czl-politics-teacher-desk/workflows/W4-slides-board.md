# W4 课件与板书

## 任务职责

把一节课的教案转成分页课件框架 + 板书构图，并给出翻页节奏。
**产出的是框架，不是逐字稿**；课件用来"撑住课堂"，不是用来念。

## 输入参数

| 参数 | 必填 | 说明 | 缺省 |
|---|---|---|---|
| `lesson_plan` | 是 | W3 的教案（或课题 + 环节安排） | — |
| `pages` | 否 | 页数上限 | 12—18 页 |
| `equipment` | 否 | 投影/白板/平板/无设备 | 有投影、无平板 |
| `style` | 否 | 简洁/图文/示意 | 简洁 |

## 执行步骤

1. **对环节**：教案几个环节，课件就几个板块；不增加教案里没有的环节。
2. **定页数**：按"每环节 2—3 页"估，总页控制在 12—18。
3. **排顺序**：情境页在前，概念页居中，任务单页放在探究全程可见的位置，收口页在最后。
4. **写内容**：每页 ≤5 条要点，每条 ≤15 字；能图示的不写字。
5. **标活动**：每页写清"学生在这一页做什么"，没有学生动作的页，考虑删掉。
6. **画板书**：左（情境关键词）/ 中（结构，留到最后）/ 右（学生生成）。
7. **排节奏**：标注哪几页要停、停多久、哪几页可以快过。
8. **列准备清单**：打印份数、视频试播、教具。

## 判定条件

| 情况 | 处理 |
|---|---|
| 教案环节超过 6 个 | 合并环节，不增加页数；课件页数跟着环节走，不跟着知识点走 |
| 无投影设备 | 只出板书设计 + 纸质任务单，不出分页框架 |
| 公开课 | 允许 20 页以内，但必须有 2 页"学生生成页"（现场填写，不是预设内容） |
| 需要放视频 | 单段 ≤90 秒，且必须写"备用方案：视频无法播放时用文字材料" |

## 输出格式

套用 `templates/slide-outline.md`：分页表（五列）+ 呈现方式规则 + 板书构图 + 翻页节奏 + 准备清单。

## 异常处理

| 异常 | 处理 |
|---|---|
| 页数超限 | 删"概念解释页"，把解释并入任务单或板书；不删情境页和任务页 |
| 某页放不下 | 拆成两页，或把内容移到板书；不要把字号压小 |
| 用户要"漂亮模板" | 说明本工作流只给内容结构，版式由学校模板决定；给三条排版建议即可 |
| 教案本身环节混乱 | 退回 W3 重排环节，不在一份混乱的教案上配课件 |

## 必要依赖

- `templates/slide-outline.md`
- W3 的教案产出

## 与其他工作流的关系

- **上游**：W3（强依赖，没有教案不单独做课件）
- **下游**：无（成品交付）
- **回退**：教案调整 → 课件同步调，不保留旧版页码
