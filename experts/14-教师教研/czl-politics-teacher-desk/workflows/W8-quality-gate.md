# W8 出门质检

## 任务职责

任何交付物在交给用户之前，过五道闸。**闸门不通过，不许标"已完成"。**
这条工作流的输出不是成品，是质检单；但它是整个产品区别于"聊天"的地方。

## 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `deliverable` | 是 | 待检的文件或内容 |
| `meta` | 是 | 任务类型、模块、课时、学情 |
| `auto_checks` | 否 | 是否跑脚本 | 默认跑 |

## 五道闸

### G1 事实闸（一票否决）

逐条查：
- [ ] 年份、数字、文件名称、会议名称是否有出处和时间
- [ ] 是否有"据了解""有关数据显示""专家认为"（无具名）
- [ ] 时政素材是否有来源媒体 + 发布日期
- [ ] 教材表述是否标注"以教材原文为准"
- [ ] 无法核实的是否明确标"需核实"

**判定**：出现任一无出处的数字或文件名称 → 不通过；仅"需核实"未标 → 不通过。

### G2 对齐闸

- [ ] 目标条数 = 评价证据条数（至少一一对应）
- [ ] 每个教学环节至少对应一条目标
- [ ] 每条目标都用了可观察的行为动词（说出/写出/判断/比较/论证）
- [ ] 没有"培养……素养""体会……情感"这类无法观察的表述

**判定**：有目标但无对应评价 → 不通过；活动与目标无关联 → 不通过。

### G3 可教闸

- [ ] 环节时间加总 = 课时（误差 ≤2 分钟）
- [ ] 无单个环节超过课时 40%
- [ ] 教师连续讲授不超过 15 分钟
- [ ] 需要学生课外额外投入 ≤ 作业规定时长

**判定**：时间加总超出 → 不通过；容量明显超载（一课时三个议题）→ 不通过。

### G4 可评闸

- [ ] 主观题有 3 档 + 0 分的分档描述
- [ ] 有踩分点，且踩分点能回答"6 分和 4 分差在哪"
- [ ] 选择题每个干扰项标了错因类型
- [ ] 开放性试题用水平描述，未出现"言之有理即可"
- [ ] 无"略""酌情给分""意思对即可"

**判定**：任一条不满足 → 不通过。

### G5 可核闸

- [ ] 材料来源、时间、关键句齐全
- [ ] 数据标明口径（同比/环比、范围、时间）
- [ ] 引用教材为短句并标注
- [ ] 无整段复制的教辅、试卷、教材内容

**判定**：来源缺失 → 不通过；整段复制 → 不通过。

## 执行步骤

1. 通读交付物，先判断"这是哪类产出"，取对应模板字段表。
2. 逐闸逐条勾选，**每条只判"过/不过"，不判"差不多"**。
3. 跑脚本（教案类 `lesson_lint.py`，试题类 `item_lint.py`）。
4. 汇总：通过的闸打 ✅，不通过打 ❌ 并写具体位置。
5. 不通过的，**先自己改一轮**，改完重跑；改不动的，写在"教师备注"里说明原因。
6. 输出质检单。

## 输出格式

```markdown
## 质检单

| 闸 | 结论 | 问题位置 | 处理 |
|---|---|---|---|
| G1 事实 | ✅/❌ | {{第 X 节}} | {{已改 / 需用户核实}} |
| G2 对齐 | | | |
| G3 可教 | | | |
| G4 可评 | | | |
| G5 可核 | | | |

**脚本结果**：{{lesson_lint: 通过 / 3 项告警}}
**未通过项**：{{逐条列出}}
**需要你确认的**：{{≤2 条，例如"某数据来源请你确认"}}
```

## 异常处理

| 异常 | 处理 |
|---|---|
| 用户催"先给我，别检查了" | 给，但在开头一行标"未过 G4，评分标准待补"，不假装合格 |
| 某闸因信息不足无法判定 | 标"待定"，写明缺什么信息，不算通过 |
| 脚本报错 | 如实说明脚本失败原因，人工检查替代，并在交付时注明"未跑脚本" |
| 交付物是用户自己写的 | 只做检查和建议，不擅自改写其风格；改动处标出来 |
| 五闸全过但内容平庸 | 质检单只保证"没硬伤"，另起一段写"可以更好的两处" |
