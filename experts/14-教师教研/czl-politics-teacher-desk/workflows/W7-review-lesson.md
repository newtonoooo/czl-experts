# W7 试卷讲评

## 任务职责

把诊断结论变成一节讲评课：讲哪三题、怎么还原错解、拿什么变式补偿、收口让学生写什么。
**讲评课的目标不是"讲清楚"，是"下次不错"。**

## 输入参数

| 参数 | 必填 | 说明 | 缺省 |
|---|---|---|---|
| `diagnosis` | 是 | W6 的诊断结论（或得分率 + 典型错答） | — |
| `duration` | 否 | 40/45 分钟 | 40 |
| `class_level` | 否 | 学情层次 | 中等 |
| `focus` | 否 | 指定讲某几题 | 按得分率与区分度选 |

## 执行步骤

1. **选三题**：得分率最低、错得最集中、最能迁移，各一题。不讲第四题。
2. **还原错解**：匿名照录学生原答，还原推理链，指出断在哪一步（A—E）。
3. **定归因**：三题归到同一类错因则合并讲；归到不同类则分开讲，不硬凑。
4. **设计变式**：同错因、换情境、换设问，至少 1 题，含答案与标准。
5. **排时间**：数据 3′ + 还原 10′ + 归因 7′ + 变式 15′ + 收口 5′。
6. **写收口**：每人写一句"下次遇到这类题先做什么"，收 3—5 张念出来。
7. **列补偿**：全班 1 题、临界生 3 题、个别面批。

## 判定条件

| 情况 | 处理 |
|---|---|
| 全班某题得分率 >0.9 | 不讲 |
| 只有个别人错 | 课后个别处理，不占课堂 |
| 错因集中在 E（表达） | 变式训练改为"改写答案"而非"再做一题" |
| 错因集中在 A（知识缺口） | 讲评课改为"补讲 + 当堂检测"，变式题减到 1 道 |
| 一道题错因跨三类 | 只讲占比最高的那一类，其余进补偿清单 |
| 课时不足 40 分钟 | 砍变式到 1 道，不砍收口 |

## 输出格式

套用 `templates/review-lesson.md`：数据摘要 / 讲评优先级 / 错解还原 / 归因表 / 变式 / 收口 / 补偿清单。

## 异常处理

| 异常 | 处理 |
|---|---|
| 没有学生原答 | 用"常见错答"替代，注明"非本班原始作答" |
| 用户要"全卷都讲" | 说明全卷讲等于没讲，给"三题精讲 + 其余发答案"的方案 |
| 用户要公布排名 | 拒绝，改为公布得分率分布（不落名） |
| 变式题出不出来 | 退 W5 用命题流程出题，不在讲评稿里凑题 |
| 学生情绪问题（考差了） | 只给教学动作，不做心理辅导；提示"如需心理支持，请联系学校心理老师" |

## 与其他工作流的关系

- **上游**：W6（强依赖，没有诊断不做讲评）
- **下游**：W2（据诊断调整后续规划）
- **回退**：诊断结论不清 → 回 W6，不凭感觉选讲评题
