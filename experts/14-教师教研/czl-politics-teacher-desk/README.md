# 卓识教育-高中政治老师助手

**包名**：`czl-politics-teacher-desk`　**版本**：1.0.0　**开发者**：虫志龙（47190078@qq.com）
**类型**：Agent 型专家（单角色）　**分类**：15-Education

高中政治老师的备课台。不是"什么都能聊两句"的助手，是一条教学生产线：单元怎么排、课怎么上、题怎么出、分怎么析、讲评怎么讲，每一件都有固定工序和出门标准。

## 它能接的八类活

| 代号 | 你说什么 | 它交什么 |
|---|---|---|
| W1 | "帮我备节课"（没说清） | 一页任务确认单，问不超过三个问题 |
| W2 | "这个单元怎么排""一轮复习怎么走" | 单元/专题规划：目标序列、课时分配、议题线、评价任务 |
| W3 | "设计一节课""要议题式""公开课" | 教案：目标（素养落点）→ 重难点 → 六环节 → 板书 → 分层作业 → 反思预设 |
| W4 | "配个PPT大纲""板书怎么设计" | 分页课件框架 + 板书构图 + 翻页节奏 |
| W5 | "出几道题""命一套卷" | 题 + 答案 + 三档评分标准 + 踩分点 + 干扰项错因 + 双向细目表 |
| W6 | "这是得分数据" | 诊断报告：得分率、区分度、五类错因、临界生、教学归因 |
| W7 | "讲评课怎么上" | 讲评设计：只讲三题、错解还原、变式补偿、收口动作 |
| W8 | "看看这份行不行" | 质检单：五道闸逐项结论，未过项如实标注 |

## 三个和同类工具不一样的地方

**一、不交"建议"，交成品。**
"建议关注时政""可以设计一些问题"这类句子在这个产品里是不允许出现的。要么给出具体素材卡（带来源和日期），要么给出成串的问题链。

**二、评分标准必须能回答"6 分和 4 分差在哪"。**
拒绝"言之有理即可"。主观题一律三档 + 零分，配踩分点、加分表述、常见错答给分表。

**三、出门前过五道闸。**
事实闸（有没有编数据）、对齐闸（目标—活动—评价是否对得上）、可教闸（40 分钟装不装得下）、可评闸（标准能不能打分）、可核闸（素材有没有出处）。过不了的会明确告诉你哪一闸没过，不会假装合格。

## 怎么用

装好后在专家中心选它，直接说要做什么。三种常见开场：

```
帮我把必修2《经济与社会》做成单元整体规划，含课时分配、议题线和评价任务
用一份真实材料设计一节议题式新课，给我议题、情境、问题链、板书和评价量表
这是我班这次月考的得分数据，帮我做讲评课设计和针对性补偿练习
```

信息给全了它直接开工；给不全它会问，但最多问一轮、三个问题。

## 自检与打包

```bash
# 自检（元数据、头像可解析性、引用完整性、占位符）
python tools/selfcheck.py

# 打包（先自检，通过后生成 zip + SHA256 + 文件清单）
python tools/build_release.py . ./dist
```

自检里的头像检查按客户端实际规则做：路径必须在包内、文件必须存在、格式必须是 PNG/JPG、体积不能超过 5MB。**头像不合格时客户端不会报错，只会把你的头像换成"渐变底 + 姓名首字"**，所以这一项必须过。

## 换头像

- 格式：PNG（推荐）或 JPG
- 尺寸：512×512（正方形，客户端会在列表里裁成圆形显示）
- 体积：≤500KB（客户端硬上限 5MB，但超过 500KB 加载会慢）
- 放好后确认 `plugin.json` 里的 `avatar` 字段指向它，然后跑一次 `selfcheck.py`

## 边界

做高中思想政治统编教材必修 1—4、选择性必修 1—3 的备课、命题、诊断、讲评、复习规划。
不做押题、不编数据、不替学生写作业、不评价具体教师与学校、不对真实法律纠纷下结论。
