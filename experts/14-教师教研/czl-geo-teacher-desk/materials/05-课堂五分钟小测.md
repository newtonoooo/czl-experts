# 课堂五分钟小测（20 题）

> 用途：课前测、课末测、讲评课前测。每题 15 秒，教师读题、学生举牌或写在纸条上。
> 形式：判断对错，错的要说"错在哪"。答案与一句解析在文末，裁下来用。
> 说明：全部为概念辨析题，不依赖地图，可脱离教材使用；题目为原创。

## 第一组 大气

1. 近地面大气的直接热源是太阳辐射。
2. 大气逆辐射对地面起保温作用。

## 第二组 热力环流

3. 热力环流的根本原因是地面冷热不均。
4. 北半球气旋近地面的气流呈逆时针方向辐合。

## 第三组 天气系统

5. 冷锋过境后，气温下降、气压升高、天气转晴。
6. 反气旋控制下的地区多阴雨天气。

## 第四组 气压带风带

7. 副热带高气压带是热力原因形成的。
8. 南亚夏季的西南季风主要与气压带、风带的季节移动有关。

## 第五组 水与洋流

9. 中低纬度海区北半球的大洋环流呈顺时针方向。
10. 寒流流经的海区对沿岸气候有增温增湿作用。

## 第六组 水循环

11. 城市地面硬化会使下渗量增加、地表径流减少。
12. 修建水库主要改变的是地表径流的时间分配。

## 第七组 地表形态

13. 外力作用的一般顺序是风化、侵蚀、搬运、堆积。
14. 板块消亡边界处一定形成高大的褶皱山脉。

## 第八组 自然带

15. 山地垂直自然带谱的基带与该山地所在地区的水平自然带一致。
16. 从沿海到内陆的地域分异规律，主导因素是热量。

## 第九组 人文地理

17. 一个地区农作物的熟制主要取决于热量条件。
18. 制糖工业属于市场导向型工业。

## 第十组 区域与人口

19. 污染较重的工业应布局在盛行风的下风向和河流的下游。
20. 荒漠化的实质是沙漠面积不断向周围扩张。

---

## 答案与解析（教师版，裁切线以下）

| 题 | 答案 | 一句解析 |
|---|---|---|
| 1 | ✗ | 近地面大气的直接热源是地面辐射；大气对太阳短波辐射吸收很少。 |
| 2 | ✓ | 大气吸收地面长波辐射后射向地面，补偿地面热量损失。 |
| 3 | ✓ | 冷热不均 → 垂直运动 → 同一水平面气压差 → 水平运动。 |
| 4 | ✓ | 北半球气旋为低压，气流逆时针辐合上升。 |
| 5 | ✓ | 冷气团取代暖气团，气温降、气压升、天气转晴。 |
| 6 | ✗ | 反气旋中心气流下沉，天气晴朗干燥。 |
| 7 | ✗ | 副热带高压带由高空气流堆积下沉形成，属动力原因。 |
| 8 | ✓ | 东南信风越过赤道右偏形成西南季风，海陆热力差异为次要因素。 |
| 9 | ✓ | 北半球中低纬环流呈顺时针，南半球相反。 |
| 10 | ✗ | 寒流降温减湿，暖流才增温增湿。 |
| 11 | ✗ | 硬化减少下渗、增加地表径流，易致内涝。 |
| 12 | ✓ | 水库调节径流的季节分配；跨流域调水改变空间分布。 |
| 13 | ✓ | 风化—侵蚀—搬运—堆积，顺序不能颠倒。 |
| 14 | ✗ | 消亡边界可形成海沟、岛弧或褶皱山脉，取决于板块性质与运动方向。 |
| 15 | ✓ | 基带反映当地水平气候带，是判断山地所在纬度的依据。 |
| 16 | ✗ | 该规律的主导因素是水分；热量主导的是由赤道到两极的分异。 |
| 17 | ✓ | 热量决定熟制，降水决定农业类型。 |
| 18 | ✗ | 制糖原料失重比大，属原料导向型。 |
| 19 | ✓ | 兼顾风向与河流流向，减轻对居住区和水源的影响。 |
| 20 | ✗ | 荒漠化是干旱半干旱地区的土地退化，不等于沙漠扩张。 |

## 使用建议

- **错 3 题以内**：概念基本过关，可进入应用训练。
- **错 4–7 题**：按错题所属模块，回看 `01-自然地理核心概念手册.md` 对应条目。
- **错 8 题以上**：不是粗心，是概念体系没建起来，建议整节重讲，不要靠刷题补救。

对应错因编码：本组题错因多为 **C1 概念不清**，少数为 **C3 审题偏差**（把"主导因素"看成"影响因素"）。
