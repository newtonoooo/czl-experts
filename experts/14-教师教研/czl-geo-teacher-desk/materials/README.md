# 教学资料包

本目录是专家的**离线教学资料**，全部为原创归纳，随专家包分发。教师可直接取用，也可作为命题与备课的取材库。

| 文件 | 内容 | 典型用法 |
|---|---|---|
| `01-自然地理核心概念手册.md` | 10 个核心概念的机制链与易错点 | 备课定口径、讲解稿底稿 |
| `02-人文地理区位分析框架.md` | 农业/工业/服务业/城市/交通/人口的区位维度 | 区位类设问的作答骨架 |
| `03-区域地理案例库.md` | 8 个经典区域的成因—问题—对策 | 命题情境、案例教学 |
| `04-高频易错点清单.md` | 30 条"错误说法→正解" | 干扰项设计、讲评课 |
| `05-课堂五分钟小测.md` | 20 道概念判断题 + 答案解析 | 课前测、课末测 |
| `06-资料索引与版权说明.md` | 官方资料入口与使用边界 | 引用合规、版权自查 |

## 使用约定

1. 资料包是"口径底稿"，不是教材替代品。具体页码、活动、插图仍以教师所用正版教材为准。
2. 涉及具体数值、区域数据时，一律回查权威来源并注明年份，不以本资料包的定性描述充当数据。
3. 命题时不得整段照搬案例原文，须改写情境、更换设问角度。
4. 中国地图一律使用标准地图服务底图，并按 `../references/map-compliance.md` 自查。
