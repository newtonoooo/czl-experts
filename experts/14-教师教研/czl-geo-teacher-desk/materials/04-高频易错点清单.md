# 高频易错点清单（30 条）

> 每条格式：**错误说法 → 为什么不成立 → 正确表述**。用于备课提醒、命题干扰项设计、讲评课素材。

## 自然地理

1. **"近地面大气直接吸收太阳辐射升温"**
   → 大气对太阳短波辐射吸收能力弱。
   → 近地面大气的直接热源是地面辐射。

2. **"大气逆辐射是地面辐射被反射回地面"**
   → 逆辐射是大气自身的辐射，不是反射。
   → 大气吸收地面长波辐射后，以长波辐射形式射向地面，起保温作用。

3. **"一天中气温最高出现在正午"**
   → 正午太阳高度最大，但地面热量积累有滞后。
   → 气温最高值通常出现在午后（14 时前后）。

4. **"热力环流中近地面高压处气温高"**
   → 近地面高压对应空气下沉、气温较低。
   → 近地面受热处空气上升，形成低压。

5. **"副热带高压带是热力原因形成的"**
   → 它由高空气流堆积下沉形成，属动力原因。
   → 赤道低压带与极地高压带才是热力原因。

6. **"南亚夏季西南季风只由海陆热力差异形成"**
   → 主要机制是气压带风带季节移动（东南信风越过赤道偏转）。
   → 海陆热力差异是次要因素。

7. **"冷锋过境时一定下暴雨"**
   → 降水强度取决于水汽条件与不稳定度。
   → 冷锋可带来阴雨、大风、降温，也可能是弱降水甚至无降水。

8. **"气旋控制下天气晴朗"**
   → 气旋中心气流辐合上升，易成云致雨。
   → 反气旋（高压）控制下气流下沉，天气晴朗干燥。

9. **"寒流一定使沿岸更干旱"**
   → 寒流降温减湿，但效果受纬度、离海距离、地形影响。
   → 寒流流经的中低纬大陆西岸易形成荒漠或半荒漠，需结合具体区域判断。

10. **"渔场都形成于寒暖流交汇处"**
    → 还有上升补偿流型（如秘鲁沿岸）。
    → 渔场成因分两类：寒暖流交汇、上升流带来营养盐。

11. **"水循环中修水库主要影响降水环节"**
    → 水库直接调节的是径流的季节分配。
    → 修水库主要改变地表径流的时间分布，跨流域调水改变空间分布。

12. **"城市硬化路面会增加地下径流"**
    → 硬化减少下渗。
    → 硬化使下渗减少、地表径流增加、汇流加快，易形成内涝。

13. **"风化就是风力侵蚀"**
    → 风化是岩石在原地崩解破碎，不需搬运营力。
    → 风化、侵蚀、搬运、堆积是外力作用的四个环节，风力侵蚀只是侵蚀的一种。

14. **"板块交界处一定形成高大山脉"**
    → 消亡边界可形成海沟、岛弧、褶皱山；生长边界形成裂谷、海岭。
    → 具体地貌取决于板块性质与运动方向。

15. **"垂直自然带谱的基带与山地所在纬度无关"**
    → 基带与该地水平自然带一致。
    → 基带反映当地水平气候带，带谱数量与纬度、海拔、相对高度相关。

16. **"从沿海到内陆的分异由热量决定"**
    → 该规律的主导因素是水分。
    → 由赤道到两极以热量为主，从沿海到内陆以水分为主。

17. **"荒漠化就是沙漠面积扩大"**
    → 荒漠化是干旱半干旱地区的土地退化过程。
    → 包括草地退化、沙化、盐渍化等，不等于沙漠推进。

18. **"自然灾害损失大都是自然原因造成的"**
    → 灾情由致灾因子、孕灾环境、承灾体共同决定。
    → 人口密度大、设防水平低、预警不足会显著放大灾情。

## 人文地理

19. **"农业类型完全由自然条件决定"**
    → 市场、交通、技术、政策同样起决定作用。
    → 城郊农业的蔬菜花卉乳畜布局主要由市场与交通决定。

20. **"制糖工业应靠近市场布局"**
    → 原料失重比大，运输成本高。
    → 制糖属原料导向型，应靠近原料产地。

21. **"所有工业都应布局在原料地附近"**
    → 不同工业导向类型不同。
    → 按原料、市场、动力、劳动力、技术五类分别判断主导因素。

22. **"商业区一定在市中心"**
    → 取决于付租能力与交通可达性。
    → 商业区多位于市中心或交通节点，但城市多中心化后可在副中心形成。

23. **"工业区只考虑盛行风下风向"**
    → 还要考虑河流下游、地价、交通、与居住区的隔离。
    → 污染型工业应布局在盛行风下风向（或垂直方向）与河流下游。

24. **"城镇化水平越高越好"**
    → 城镇化要与产业与公共服务相匹配。
    → 城镇化质量取决于就业、住房、交通、环境与公共服务的承载能力。

25. **"人口迁移对迁出地只有负面影响"**
    → 迁出可缓解就业压力、增加汇款收入。
    → 同时带来青壮年流失、老龄化加剧、人才外流等问题。

26. **"交通线越直越好"**
    → 线路受地形、地质、水文、城镇分布制约。
    → 选线要兼顾工程量、运营安全与沿线带动作用。

## 区域与综合

27. **"资源枯竭型城市转型就是发展旅游业"**
    → 单一途径风险高，需结合禀赋选择接续产业。
    → 转型路径包括替代产业培育、生态修复、技能培训、城市更新等组合。

28. **"流域开发就是建坝发电"**
    → 流域开发是防洪、发电、航运、灌溉、生态的综合。
    → 需统筹上中下游的利益与生态要求。

29. **"生态脆弱区应全面禁止人类活动"**
    → 绝对禁限不现实，也不利于当地生计。
    → 应采取分区管控、适度利用、替代生计与生态补偿。

30. **"区域发展措施可以套用到任何地区"**
    → 措施要对应成因与区域条件。
    → 先定成因，再提措施；同一条措施在不同区域的可行性不同。
