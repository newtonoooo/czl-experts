# 工作流说明

完整规格在 `../workflows/` 下，每个文件含职责、输入参数、执行步骤、判断条件、输出格式、异常处理、依赖与上下游关系。本文件只做总览与串联说明。

## 一、总览

| 编号 | 工作流 | 必填输入 | 主输出 | 常见下游 |
|---|---|---|---|---|
| W0 | 任务调度 | 原始请求 | 场景判定 + 工作流序列 | 全部 |
| W1 | 教案设计 | 课题 | 教案 + 板书 + 分层作业 | W9、W2、W8 |

## 二、依赖关系

```
                ┌──────── W0 调度 ────────┐
                │                          │
   W1 教案 ◀────┼── W5 讲解 ◀── W4 学情 ◀──┼── W3 批改 ◀── W2 命题 ◀── W6 真题
     │          │        │           │     │                    ▲
     ▼          │        ▼           ▼     │                    │
   W9 课件      │      W2 变式      W2     │        W7 图表 ────┘
     │          │                          │
     ▼          └──── W8 研学 ◀────────────┘
```

规则：

1. **单向推进**，不回环。需要回头时开新一轮，不在同一轮里反复改。
2. **编号引用**：后一份产出引用前一份的编号（如"针对 C2 读图失误，见下题 3–5"），不重复正文。
3. **一次一轮**：复合任务拆成序列后，逐轮交付，避免一份文档里塞三件事。

## 三、三个典型串联

**A. 考后闭环（最常见）**

```
W4 学情诊断 →（失分点 Top3）→ W2 变式命题 → W3 批改 → W4 复测
                     └─（概念性失分）→ W5 讲解 → W1 补救课教案
```

**B. 公开课准备**

```
W1 教案 →（确认设计）→ W9 课件 →（课堂需要素材）→ W7 图表判读
```

**C. 命题升级**

```
W6 真题解析（考法归类）→ W2 仿命题（换情境、改设问）→ 试卷 → 答案与解析
```

## 四、调用示例

| 你说 | 走的工作流 | 说明 |
|---|---|---|
| "帮我备《洋流》" | W0 → W1 | 单工作流 |
| "分析这份成绩，然后出补救题" | W0 → W4 → W2 | 串联，先诊断后命题 |
| "这道高考题讲一下，再改一道类似的" | W0 → W6 → W2 | 先拆真题再仿命题 |
| "照这份教案做个课件" | W0 → W1 → W9 | 教案为课件提供结构 |
| "帮我看看这份卷子的问题" | W0 → W3（单份）/ W4（≥10 份） | 按份数分流 |
