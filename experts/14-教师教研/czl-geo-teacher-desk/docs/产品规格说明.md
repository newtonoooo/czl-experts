## 1. 目标用户与使用场景

### 1.1 用户画像

| 用户 | 特征 | 核心痛点 | 使用频次 |
|---|---|---|---|
| 高中地理任课教师（主用户） | 带 2–6 个班，周课时 10–16 节，兼班主任或备课组长 | 备课与命题占满晚上；批改后没有时间做归因 | 每周 3–8 次 |
| 备课组长 / 教研组长 | 需要统一进度与命题标准 | 组内命题质量参差，缺少统一细目表 | 每月 2–4 次 |
| 新手教师（教龄 ≤3 年） | 教材不熟，重难点把握不准 | 教案写得出流程，写不出"为什么这么设计" | 每周 5 次以上 |
| 县域/乡镇教师 | 教研资源少，缺少同伴互评 | 没人给自己的题和课提意见 | 每周 2–5 次 |

**明确不服务的对象**：学生（不提供作业代写与答案直给）、家长（不做升学规划咨询）、大学地理研究者（不做科研数据处理）。

### 1.2 场景清单

| 场景 | 触发时机 | 输入 | 期望产出 | 时间压力 |
|---|---|---|---|---|
| 日常备课 | 前一晚或课前 | 课题 + 教材版本 | 可上课的教案 + 打印版 | 30 分钟内 |
| 单元命题 | 单元结束前一周 | 考查范围 + 题量 | 细目表 + 试卷 + 答案 | 当轮对话 |
| 作业批改 | 课后 | 学生作答图片 | 采分点批注 + 错因 | 单题即时 |
| 考后复盘 | 月考/期中/期末后 | 成绩表 | 失分点归因 + 分层补救 | 当天 |
| 讲评课准备 | 复盘后 | 失分点清单 | 讲评设计 + 变式题 | 次日课前 |
| 公开课/赛课 | 提前 1–2 周 | 课题 + 学情 + 时限 | 精细教案 + 课件 | 多轮迭代 |
| 研学组织 | 学期初 | 主题/地点 | 方案 + 任务单 + 安全预案 | 提前两周 |

## 2. 要解决的问题

按优先级排序，每条对应产品中的一个机制：

| # | 问题 | 现状 | 本产品的解法 | 对应机制 |
|---|---|---|---|---|
| P1 | 备课耗时且同质化 | 抄教案集，环节齐但设计意图空 | 强制写"设计意图"，每个环节必须回答"为什么这么设计" | W1 步骤 6 |
| P2 | 命题无结构，难度失控 | 东拼西凑，全卷集中在一个能力层级 | 先出双向细目表（考点×层级×分值×难度），教师确认后再命题 | W2 步骤 2–3 |
| P3 | 批改只给分不给因 | "注意审题""加强练习" | 采分点批注 + 错因编码 C1–C6 + 下一步具体动作 | W3 步骤 4–7 |
| P4 | 成绩分析停在均分 | "整体一般，需努力" | 板块得分率 + 失分点 Top3–5（带题号证据）+ 分层动作 | W4 步骤 4–7 |
| P5 | 地图合规风险 | 网上下图即用，出问题不自知 | 出图前 5 问清单 + 中国地图必绘要素表 + 标准地图入口 | `references/map-compliance.md` |
| P6 | 数据与事实不可追溯 | 数字来源不明，年份混乱 | 强制"指标+口径+年份+来源"，不确定标 `[待核]` | 硬规则 R1/R4 |
| P7 | 生成内容"AI 味"重 | 三段排比、总结句、套话 | 输出契约规定禁用词与结构，要求结论先行、表格承载结构 | `references/output-contracts.md` |

## 3. 输入与输出

### 3.1 输入

| 类型 | 形式 | 必需性 | 说明 |
|---|---|---|---|
| 文本指令 | 自然语言 | 必需 | 允许口语、省略；系统按场景判定补全 |
| 教材页 | 图片/PDF | 可选 | 用于课件与教案的教材定位；读不出时降级 |
| 试卷/题目 | 图片/文本 | 可选 | 批改与真题解析的输入 |
| 成绩表 | 表格/截图 | 可选 | 学情诊断；至少需总分字段 |
| 学情说明 | 文本 | 可选 | 班级层次、进度、已学内容 |

**最小输入原则**：一次最多追问 3 项；缺项按默认档推进，并在产出开头标注前提。

### 3.2 输出

| 工作流 | 主输出 | 附带 | 文件 |
|---|---|---|---|
| W1 | 教案（8 个模块） | 板书、分层作业、复核项 | `打印版_<课题>.docx` |
| W2 | 细目表 + 试卷 + 答案解析 | 合规提示、命题说明 | `试卷_<范围>_<用途>.docx` |
| W3 | 采分点批注 + 错因 + 评语 | 讲评建议、变式题 | 无（屏读为主） |
| W4 | 统计表 + 归因 + 分层方案 | 复测建议 | `学情_<考试>_<班级>.docx` |
| W5 | 讲解稿 + 学案 | 变式练习 | `学案_<知识点>.docx` |
| W6 | 考点定位 + 路径 + 规范作答 | 考法归类、变式 | 无 |
| W7 | 判读步骤 + 结论 + 训练建议 | 区位框架 | 无 |
| W8 | 研学方案 + 任务单 + 安全预案 | 评价量规 | `研学_<主题>.docx` |
| W9 | .pptx | 逐页大纲、配图清单 | `<课题>.pptx` |

**输出契约**：结论先行；表格承担结构；每条建议带依据；不确定标 `[待核]`；可打印成品附打印版区块并生成 docx。

## 4. 通用处理步骤

所有任务共用一条主流水线，差异体现在工作流的"执行步骤"：

```
① 场景判定（W0）
   动作词 + 对象 + 是否复合 → 选定工作流序列

② 输入校验（G1）
   必填项是否齐 → 缺则按默认档，标注前提
   材料是否可读 → 不可读则说明并降级

③ 资料调取（按需）
   课标定位 → curriculum-map.md
   命题规范 → item-blueprint.md
   作答骨架 → answer-templates.md
   错因判定 → error-codebook.md
   合规检查 → map-compliance.md
   输出格式 → output-contracts.md
   （只读当前任务需要的，不全量加载）

④ 结构生成（G2）
   按工作流规定的模块顺序产出，缺模块不交付

⑤ 学科校验（G3）
   概念/成因/分布/数据逐项过；不确定标 [待核]

⑥ 合规校验（G4）
   地图 → 必绘要素 + 标准地图 + 审图号
   数据 → 指标/口径/年份/来源
   隐私 → 无姓名学号
   表述 → 无绝对化、无效果承诺

⑦ 交付
   屏幕版 + 打印版区块 + docx/pptx（可用则生成，不可用则明示）
   列"需教师复核"项
```

## 5. 工具能力与技术接口

| 能力 | 实现方式 | 接口 | 失败处理 |
|---|---|---|---|
| 文档解析 | 平台内置读取 + 视觉识别 | 文件/图片输入 | 读不出则说明并降级 |
| 打印版 docx | `tools/build_print_docx.py`（python-docx） | CLI：输入 md，输出 docx | 缺库 → 退出码 2 + 明确提示，交付 md |
| 课件 pptx | `tools/build_ppt.py`（python-pptx） | CLI：输入 JSON 大纲，输出 pptx | 缺库 → 导出 md 大纲 |
| 包自检 | `tools/verify_package.py` | CLI：目录或 zip | 返回非 0 表示有失败项 |
| 安装与打包 | `tools/sync_install.py` | CLI：install/validate/package/all | 官方校验失败即停止打包 |
| 平台集成 | `plugin.json` + `agents/*.md` | WorkBuddy 专家协议 | 字段缺失时客户端回退为文字头像（已加自检） |

**不依赖外部 API、不联网抓取、不写入系统目录**；所有脚本只读写当前工作区与 `my-experts` 目录。

## 6. 质量、速度与稳定性要求

### 6.1 质量（可验收）

| 指标 | 要求 | 验收方式 |
|---|---|---|
| 结构完整率 | 交付物包含该工作流规定的全部模块 | 对照输出格式逐项检查 |
| 事实标注率 | 涉及具体数据的句子 100% 带口径或 `[待核]` | 抽检 20 句 |
| 命题结构合规 | 先细目表后组卷；tags/quickPrompts 数量正确 | 流程检查 |
| 地图合规 | 涉及中国地图的产出 100% 带合规提示 | 关键词检查 |
| 无编造 | 不出现编造的真题年份卷别、统计数据 | 抽检引用句 |
| 语言 | 无禁用套话；无三段以上同构排比 | 人工通读 |

### 6.2 速度

| 任务 | 目标 | 现实约束 |
|---|---|---|
| 单题批改 | 1 轮回复内完成 | 取决于图片清晰度 |
| 教案 | 1 轮回复内完成 | 2 课时以上需分轮 |
| 整卷命题 | 2 轮（细目表 → 组卷） | 12 题以上建议分两批 |
| 学情报告 | 1 轮 | 数据字段齐全时 |

### 6.3 稳定性

1. **输入不全不阻塞**：一律按默认档产出，前提写在最前。
2. **工具缺失不假装**：缺 python-docx/python-pptx 时明确降级，不输出"已生成"。
3. **不可读材料不臆造**：图片模糊、图例缺失时只说读不出，不猜内容。
4. **越界请求不迁就**：押题、编数据、代写论文一律拒绝并给替代方案。
5. **可回溯**：所有文件命名固定，产出可被教师按名检索。

## 7. 产品边界

| 做 | 不做 |
|---|---|
| 高中地理教学全流程辅助 | 大学地理研究、GIS 软件操作教学 |

| 地图合规提示 | 绘制或修改国界、提供地图数据下载 |
