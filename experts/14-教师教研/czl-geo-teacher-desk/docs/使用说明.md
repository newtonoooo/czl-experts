# 使用说明

## 一、第一次使用

导入或安装后，在专家列表中选「卓识教育-高中地理老师助手」，直接说你要做什么。**不需要记指令格式**，按平时跟同事说话的方式讲就行。

三句话就够：

```
帮我备《大气受热过程和大气运动》，人教版必修一，普通班
出一套自然地理单元测验，12 选择 + 2 综合，难度 0.65
这是月考成绩，帮我看看问题在哪（附成绩表）
```

## 二、按场景的用法

### 1. 备课

**最少给**：课题。**建议给**：教材版本、年级、课型、课时、学情。

一句好的请求：

> "《洋流》第二课时，湘教版，高二，学生能背分布但不会分析影响，40 分钟。"

好在哪：给了课时定位（第二课时）、版本、学情卡点（会背不会用），产出就会跳过基础铺垫，直接设计"影响分析"的活动。

**你会拿到**：课标定位 → 3 条可测评目标 → 重难点（写清难在哪一步）→ 学情 → 教学过程表 → 板书 → 分层作业 → 复核项 → 打印版 docx。

### 2. 命题

默认走两步：**先给双向细目表，你确认或改，再出题**。如果你赶时间，直接说"按你的结构出，不用等我确认"。

值得在请求里说清的三件事：用途（随堂/单元/月考）、难度、有没有出过的题（避免重复）。

**你会拿到**：细目表（含模块占比、能力层级分布、预估均分）→ 试卷 → 答案 → 四段式解析 → 命题说明与合规提示。

### 3. 批改

拍照或粘贴学生作答即可。单题批改会给到：采分点、逐点批注（你写了什么/缺什么/怎么补）、错因编码、评语、下一步动作。

**建议**：一次给 3–5 份同一题的作答，能顺带看出班级共性错；超过 10 份会自动转成学情统计，不再逐份写评语。

### 4. 学情分析

给成绩表时，字段越全结论越细：

| 字段 | 有 | 没有的后果 |
|---|---|---|
| 总分 | 必需 | 无法分析 |
| 小题分 | 强烈建议 | 只能做总量与分层，做不了考点归因 |
| 题号—考点对照 | 建议 | 归因只能到"选择题/综合题"这一层 |

**不会做的事**：不排名、不出现学生姓名、不评价教师。

### 5. 讲评与补救

分析完直接接一句"针对 C2 读图失误出 5 道专项训练"，会顺着上一轮的结论出题，不用重复背景。

### 6. 真题解析

把题目文字或清晰图片发来即可。**来源不确定时会标"待核"，不会编年份卷别**。图片模糊、缺图例时会直接说读不出，请重拍。

### 7. 研学设计

给主题或地点。涉及水域、山地、交通干道的，方案里会自动加安全等级与预案模板，但**最终必须由你和学校确认**。

### 8. 课件

可以只给课题，也可以传教材页照片。默认 12–16 页、浅底深字、一页一个要点。地图位置会用占位框标注"请插入标准地图"，不会自行生成地图。

## 三、让产出更好用的四个习惯

1. **说清学情卡点**，别只说"普通班"。"能背分布但不会分析影响"比"基础一般"有用十倍。
2. **给范围不给全书**。命题范围说"必修一第二章 + 第三章第一节"，别说"必修一"。
3. **要改就具体改**。"第二个环节的活动太满，砍成一个"比"再优化一下"有效。
4. **复核项要看**。标了"请教师复核"的地方，是它拿不准、需要你拍板的地方，不是客套。

## 四、常见问题

**Q：为什么有的产出没有 docx？**
A：环境缺 python-docx 时会明确提示并给 Markdown 版。装上库（`pip install python-docx`）再让它重出一份即可。

**Q：为什么专家图标显示成一个字？**
A：这是头像文件没被正确加载时的客户端回退显示。常见原因三条：头像文件缺失、路径写错、文件超过 5MB。本包已用 `tools/verify_package.py` 做前置拦截，重新导入本包即可恢复正常。

**Q：能不能直接给我一份完整试卷的 PDF？**
A：不提供 PDF 排版；交付 docx，你在 Word/WPS 里按学校模板调整页眉页脚更快。

**Q：能不能保证猜中考点？**
A：不能，也不做。可提供的是考法分布与备考清单。

**Q：数据从哪来？**
A：所有数字都要求带来源与年份；查不到来源的，会写成定性描述或标 `[待核]`。

## 五、边界

- 不替学生写作业、不直给答案（可以给解题路径）。
- 不编造真题、统计数据、学校评价。
- 不绘制或修改国界，不提供地图数据下载。
- 不评价具体教师与学校。
