# 命题规范与双向细目表

## 一、双向细目表模板

命题前必须先填这张表。教师确认结构后再动笔写题。

| 题号 | 考点 | 模块 | 能力层级 | 题型 | 分值 | 预估难度 | 材料类型 | 图表 |
|---|---|---|---|---|---|---|---|---|
| 1 | 大气受热过程 | 自然 | 理解 | 单选 | 3 | 0.80 | 生活现象 | 无 |
| 2 | 热力环流 | 自然 | 应用 | 单选 | 3 | 0.70 | 示意图 | 有 |
| … | | | | | | | | |
| 13 | 区域农业区位 | 人文 | 分析 | 综合 | 12 | 0.60 | 区域统计 | 有 |

**表下必附三行统计：**

```
模块分值占比：自然 X% / 人文 X% / 区域 X%
能力层级分布：识记 X% / 理解 X% / 应用 X% / 分析 X% / 评价 X%
全卷预估均分：X 分（难度系数 0.XX）
```

## 二、结构配比建议

| 用途 | 题量 | 主客观比 | 难度 | 备注 |
|---|---|---|---|---|
| 随堂练 | 5–8 题 | 全客观 | 0.75 | 单题 3–5 分钟 |
| 单元测 | 12 选择 + 2 综合 | 6:4 | 0.65 | 覆盖本单元全部主题 |
| 月考 | 16 选择 + 3 综合 | 5:5 | 0.60 | 含前序内容 30% |
| 期末 | 20 选择 + 4 综合 | 4:6 | 0.60 | 全册覆盖，综合题递进 |
| 专题突破 | 8–10 题同考点 | 3:7 | 0.50–0.70 梯度 | 由易到难排列 |

**难度经验值**：新授课后单元测 0.65–0.70；复习阶段 0.55–0.65；模拟卷 0.50–0.60。预估难度与实测偏差超过 0.15，说明材料或设问有隐性问题，下次命题要复盘。

## 三、题干写作细则

1. **一句一问**：题干只问一件事；要问两件事就拆成 (1)(2)。
2. **材料自足**：答案所需信息必须在材料或图中，不依赖学生课外记忆的孤例。
3. **材料长度**：单选 ≤120 字，综合题单则材料 ≤250 字；超长材料要拆则。
4. **情境真实**：优先用真实区域、真实统计数据、真实生产生活现象；虚构情境只用于纯原理题，且不加具体地名。
5. **图表必备要素**：图名、图例、比例尺（区域图）、经纬度（定位图）、单位（统计图）。缺一项就判不合格。
6. **设问动词精确**：见 `curriculum-map.md` 第三节，不用"谈谈你的理解"这类无法赋分的动词（除非是开放题并给量规）。

## 四、选项写作细则

| 规则 | 说明 |
|---|---|
| 同质 | 四个选项属同一范畴（都是因素、都是措施、都是地形类型） |
| 同长 | 长度差不超过 8 个字，避免"最长的那个是答案" |
| 互斥 | 任意两项不能同时成立 |
| 单一最优 | 只有一个选项在给定材料下最合理，其余可明确排除 |
| 干扰有据 | 干扰项来自真实易错点（如把"大气逆辐射"写成"地面辐射"） |
| 禁绝对化 | 正确项不出现"一定""必然""完全""都" |
| 禁套话项 | 不用"以上都对""以上都不对" |

## 五、综合题设问梯度

一道综合题 3 小问，按「获取信息 → 分析成因 → 迁移评价/提出措施」递进：

```
(1) 描述/指出……特征（4 分，2 点，看图即可答）
(2) 分析……的原因（8 分，4 点，需结合材料与原理）
(3) 说明……对……的影响 / 提出……措施（6 分，3 点，需评价与取舍）
```

三小问都问"原因"是最常见的命题失误：没有梯度，区分度会集中在(2)，(1)(3)形同送分或送命。

## 六、答案与解析写法

**选择题解析四段**：考点定位 → 材料依据（哪句话/图上哪处）→ 推理 → 排除其余项的理由。

**综合题答案**：分点、每点一个角度、术语准确、与分值对应（一般 1 点 2 分，8 分题 4 点）。答案后附"常见失分答案示例"，说明扣分原因。

## 七、原创性与引用

1. 原创题不标注来源；改编题标"改编自 XXXX 年 XX 卷"；引用原题标全年份、卷别、题号。
2. 情境材料若来自新闻报道、论文、统计年鉴，注明出处与年份；无法核实的材料不用。
3. 不得把他人成套试题改头换面当作原创；不得编造"某年高考真题"。
4. 数据必须能追溯到公开来源（统计年鉴、气象部门、自然资源部门公报等），并在命题说明里列出。
