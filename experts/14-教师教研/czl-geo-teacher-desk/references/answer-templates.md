# 综合题作答骨架（五类设问）

> 用途：命题时定采分点，批改时判命中，讲评时给模板。**模板是骨架，不是填空**——学生要往里填的是材料里的具体信息。

## 一、特征描述类

| 对象 | 必答维度 | 常见漏项 |
|---|---|---|
| 位置 | 经纬度位置（纬度带/热量带）、海陆位置、相对位置（邻接、交通） | 只写"位于某洲东部"，缺纬度 |
| 地形 | 主要地形类型、地势高低与起伏、地形分布格局 | 漏"地势"或漏"分布" |
| 气候 | 气温（年均、年较差）、降水（总量、季节分配）、组合特征 | 只写"高温多雨"，无季节分配 |
| 水文 | 流量、汛期、含沙量、结冰期（凌汛）、水位变化、流速 | 漏结冰期与凌汛 |
| 水系 | 流向、流程、流域面积、支流数量与分布、河网密度、形状 | 把水系当水文写 |
| 分布 | 数量、密度、分布格局（集中/分散、沿什么分布）、极值区 | 只写"分布不均"这类空话 |

**作答句式**：`×× 以 ×× 为主，×× 集中分布于 ××，×× 自 ×× 向 ×× 递减/递增。`

## 二、原因/成因类

**三步结构**：找条件 → 讲过程 → 得结果。只写条件不写过程，最多给一半分。

- 自然原因：位置、地形、气候、水文、土壤、植被、资源、洋流、地质作用。
- 人文原因：市场、交通、劳动力、技术、政策、地价、产业基础、历史因素。

**主导因素**：必须点明 1 个并给理由（"该地海运成本占产品总成本比重最高，故主导因素为交通"）。不点主导因素，答案会显得"什么都沾一点"。

## 三、影响类

**必须分维度**，否则容易漏分：

```
对生态：气候/水文/土壤/生物多样性
对经济：产业、就业、收入、成本
对社会：人口、城镇化、基础设施、文化
```

再按范围分：对本地 / 对流域下游 / 对区域整体。**有利与不利分开写**，只写有利或只写不利都会扣分。

## 四、措施类

按"针对成因"提措施，四类不重复：

| 类型 | 例 |
|---|---|
| 工程措施 | 修水库、建堤坝、梯田、防护林带、跨流域调水 |
| 生物措施 | 退耕还林还草、封育、物种保护、生态廊道 |
| 技术措施 | 节水灌溉、监测预警、改良品种、清洁生产 |
| 管理措施 | 立法执法、生态补偿、分区管控、宣传教育、产业准入 |

**常见错误**：把"加强管理""提高意识"当万能答案。这类表述只有在题目明确指向管理制度时才给分。

## 五、评价类

**三段式**：立场 → 依据（分点）→ 限定条件。

- 先明确"合理/不合理"或"利大于弊/弊大于利"，不骑墙。
- 依据分有利、不利两侧，各 2–3 点。
- 末尾给适用条件（"在××前提下更合理"），体现区域差异意识。

## 六、采分点规则

1. **一点一分值**：一般 2 分一点；8 分题 4 点，6 分题 3 点。
2. **角度不重复给分**：同一角度写三句同义话，只算一点。
3. **术语准确才给分**："风从海洋吹来"不给分，"盛行西风带来水汽"给分。
4. **因果链完整才给满分**：只写"降水多"给一半，写"迎风坡抬升→多地形雨"给全分。
5. **超出参考答案但合理**：给分，并在批注里注明"优于参考要点"。
6. **答非所问**：不给分，并按 C3（审题偏差）编码，不算 C4。

## 七、答题语言三原则

1. **先总后分**：第一句给结论性判断，后面分点支撑。
2. **一句一点**：不要把两个角度塞进一句话，阅卷时容易只认一个。
3. **不写废话**：删掉"众所周知""随着社会发展"这类开头，直接进入要点。
