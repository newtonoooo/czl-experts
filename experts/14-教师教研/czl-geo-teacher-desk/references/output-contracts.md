# 输出契约

> 所有工作流的交付物必须符合本文件。屏幕阅读版与打印版内容一致、形式分离。

## 一、通用结构

```
【标题】对象 + 用途（例：《大气受热过程》教案 · 人教版必修一 · 1 课时）
【前提】缺省项一行说明（没有缺省则省略）
【正文】按工作流规定的模块顺序，表格承担结构
【需教师复核】列表，≤4 条
【下一步】1 个方向（最多 2 个备选）
```

三条硬要求：

1. **结论先行**：第一段说清这份东西是什么、给谁用、怎么用。不写背景铺垫。
2. **每个建议带依据**：教学设计写"设计意图"，试题解析写"考点与依据"，学情建议写"数据来源"。
3. **不确定就标**：`[待核]` 用于事实存疑，`[推断]` 用于推理结论，`[观点]` 用于教学判断。

## 二、表格规范

- 教案的教学过程、试卷的细目表、学情的得分率，一律用表格。
- 表格不超过 7 列；超宽时拆表，不缩字号。
- 单元格内不换行超过 2 行；长内容移到表格下方作说明。
- 数字右对齐，文字左对齐；百分比统一保留一位小数。

## 三、打印版规范

打印版另起区块，标题为 `【打印版 · A4】`，规则：

1. 删除所有对话语句、追问、解释性旁白、"如需调整请告诉我"。
2. 标题行必须含：课题（或分析主题）、年级、教材版本、课时（适用时）。
3. 用分级标题 + 表格排版，A4 单栏，正文小四（12pt），标题层级递减。
4. 不依赖色块与底纹传达信息（黑白打印会丢失）。
5. 试卷、学案、研学任务单必须预留作答空白区（横线或空表格行）。
6. 页脚放"第 X 页 / 共 X 页"。

## 四、文件交付

| 类型 | 命名 | 格式 |
|---|---|---|
| 教案打印版 | `打印版_<课题>.docx` | docx（无 python-docx 时降级为 .md 并说明） |
| 试卷 | `试卷_<范围>_<用途>.docx` | docx |
| 学案 | `学案_<知识点>.docx` | docx |
| 学情报告 | `学情_<考试名>_<班级>.docx` | docx |
| 研学任务单 | `研学_<主题>.docx` | docx |
| 课件 | `<课题>.pptx` | pptx |

命名不用空格，不用特殊符号，课题中的书名号去掉。

## 五、docx 排版参数（默认）

| 项 | 值 |
|---|---|
| 页面 | A4，页边距上下 2.54cm、左右 3.17cm |
| 正文 | 宋体 / Times New Roman，小四（12pt），行距 1.5 倍 |
| 一级标题 | 黑体 三号（16pt） |
| 二级标题 | 黑体 四号（14pt） |
| 表格 | 五号（10.5pt），有边框，表头加粗 |
| 页脚 | 居中，页码 |

## 六、语言风格

- 短句为主，段落长短交错；不连续三句以上同构短句。
- 不使用装饰性 emoji。分节标记统一用【】包裹的方括号标签（如【打印版 · A4】【下一步】），便于打印与检索。
- 不用"首先/其次/最后"凑层次，用内容本身分点。
- 不写"综上所述""让我们一起""在这个…的时代"。
- 术语用课标口径；口语解释放在术语之后，用括号补充。

## 七、交付前自检（4 问）

1. 教师拿到这份东西，明天能不能直接用？还差什么？
2. 有没有哪句话是我猜的，但写得像事实？
3. 表格里的数字，能不能指回来源？
4. 涉及中国地图吗？第一节的合规清单过了吗？
