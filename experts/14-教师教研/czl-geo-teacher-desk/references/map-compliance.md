# 地图与数据合规清单

> 地理教学用图是"问题地图"高发区。以下清单用于每次出图、用图、讲图前的自查。**本文件不替代测绘主管部门的审核，公开出版、公开展示用图必须按规定送审。**

## 一、中国地图必须完整表示的要素

任何表示中国疆域的地图，以下要素**不得漏绘、错绘、变形或淡化处理**：

| 要素 | 要求 |
|---|---|
| 台湾岛 | 必须表示，且与大陆同色同层级，不得单独着色或以不同图例区分 |
| 南海诸岛 | 必须完整表示；可采用竖版全图或规范附图，附图不得缩小到无法辨识 |
| 钓鱼岛及其附属岛屿 | 必须表示 |
| 赤尾屿 | 必须表示 |
| 藏南地区 | 必须绘入中国版图 |
| 阿克赛钦 | 必须绘入中国版图 |
| 国界线 | 必须使用标准画法，不得自行描摹、简化或用虚线替代未定界以外的界线 |

**禁止行为**：使用境外机构制作的中国地图；使用来源不明的网络图片作区域底图；把中国地图裁切到只剩东部；用"示意图"名义绘制实际涉及边界的地图。

## 二、标准地图与审图号

1. **优先使用标准地图**：自然资源部标准地图服务（bzdt.ch.mnr.gov.cn）提供中国地图、世界地图、专题地图的标准样图，可直接下载使用。
2. **标注审图号**：使用标准地图时保留其审图号；自行编制并公开使用的地图，须按规定送审取得审图号后再用。
3. **教学内部使用**：课堂讲义、校本材料中的自制示意图，应在图注写明"**本图为教学示意图，不作边界判读依据**"。
4. **出版物/公开网络发布**：必须使用有审图号的地图，并在地图下方标注"审图号：GS(20XX)XXXX 号"。

## 三、地图要素完整性（教学用图通用）

| 要素 | 是否必需 | 说明 |
|---|---|---|
| 图名 | 必需 | 说明画的是什么、哪个区域、什么时间 |
| 图例 | 必需 | 符号、颜色、线型必须有对应解释 |
| 比例尺 | 区域图必需 | 示意图可省，但须在图注说明"未按比例" |
| 方向 | 区域图必需 | 指北针或经纬网，二者至少一项 |
| 经纬度 | 定位类图必需 | 至少标注两条经纬线 |
| 单位 | 统计图必需 | 气温 ℃、降水 mm、人口 %、产值 亿元 |
| 数据来源 | 数据图必需 | 注明来源与年份 |

## 四、数据引用规范

| 数据类型 | 应写明的信息 | 常见问题 |
|---|---|---|
| 气象数据 | 台站/格点来源、统计时段、气候平均值年限 | 只写"降水丰富"，无数据 |
| 人口数据 | 普查/年鉴年份、常住或户籍、统计口径 | 混用不同年份数据做比较 |
| 经济数据 | 指标定义（GDP/产值/增加值）、当年价或可比价 | 把"产值"当"增加值" |
| 面积/耕地 | 来源（自然资源公报/年鉴）、是否含某某地类 | 不同来源混用导致总量对不上 |
| 遥感/影像 | 影像时间、分辨率、来源 | 用旧影像说明现状 |

**通用要求**：每个数据点写清「指标 + 口径 + 年份 + 来源」。数据来自不同年份时，必须在表注里说明，不得直接相加或求平均。

## 五、出图前自查（5 问）

1. 这张图是不是中国地图？如果是，第一节的七项要素齐了吗？
2. 底图从哪来？有没有审图号？来源不明的换掉。
3. 图名、图例、比例尺、方向、单位，缺哪项？
4. 图中数据是哪一年、什么口径？表注写了吗？
5. 这张图会不会被公开使用（出版、公众号、公开课）？会的话送审了吗？

## 六、违规风险提示

- 使用"问题地图"（漏绘、错绘）在公开场合展示，属违法违规行为，责任在使用者。
- 教学场景不因"内部使用"而免责，尤其是公开课、录课、网络发布。
- 发现已用图存在问题，应立即停用、替换，并检查是否已对外发布。
