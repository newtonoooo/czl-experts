# 错因编码表（C1–C6）

> 用途：批改时打码、学情分析时汇总、补救时对症。**一道题只给一个主码**，避免"什么都是"。

## 一、编码总表

| 码 | 名称 | 典型表现 | 判据（怎么确认是这一类） |
|---|---|---|---|
| C1 | 概念不清 | 术语用错、原理颠倒、把现象当原因 | 换个情境仍错同一概念；能背定义但不会用 |
| C2 | 读图失误 | 图例看错、方向反、等值线判读错、漏图 | 文字材料题同类知识点答对，图题答错 |
| C3 | 审题偏差 | 问原因答措施、问影响答特征、漏限定词 | 答案本身正确，但与设问类型不匹配 |
| C4 | 角度不全 | 只答自然不答人文、只答有利不答不利 | 已答要点正确，但采分点缺 2 点以上 |
| C5 | 表述不规范 | 口语化、无术语、因果链断裂、重复同义 | 意思对但没拿到分，术语替换后可得分 |
| C6 | 时间与策略 | 空白、只做前两问、字迹潦草、答错位置 | 会做但没写完；同类题平时能做对 |

## 二、逐码补救动作

### C1 概念不清
- **课堂动作**：回到概念边界（包含什么/不包含什么/易混于谁），用对比表成对辨析。
- **练习设计**：概念判断题 5 道（正误判断 + 改错），不做综合题。
- **复测**：3 天后用同一概念的新情境题，正确率 ≥80% 才算过关。
- **关联**：转 W5 讲解。

### C2 读图失误
- **课堂动作**：固定四步（图名图例 → 方向尺度 → 递变极值 → 落结论），每步让学生口述。
- **练习设计**：同类图 5 题一组，由易到难；先做"只判读不设问"的纯读图训练。
- **复测**：换一张同类型图，判读步骤能独立复述。
- **关联**：转 W7。

### C3 审题偏差
- **课堂动作**：设问动词圈画训练——把"分析原因/说明影响/提出措施"分别标注，再动笔。
- **练习设计**：同一材料改 3 种设问，只写答题框架不写全文。
- **复测**：给 5 个设问，判断类型并写出第一句话。
- **关联**：转 W3 批注时重点标"问什么答什么"。

### C4 角度不全
- **课堂动作**：用"因素清单"强制过一遍（自然 6 项、人文 8 项），答完对照勾选。
- **练习设计**：只列提纲不写答案的"框架训练"，5 分钟列 6 个角度。
- **复测**：同一题重做，采分点覆盖 ≥80%。
- **关联**：转 `answer-templates.md` 对应类型。

### C5 表述不规范
- **课堂动作**：术语替换练习（"水多"→"流量大"；"风从海上来"→"盛行西风带来水汽"）。
- **练习设计**：给 5 句口语答案，改写成得分句。
- **复测**：新题作答中术语使用 ≥3 处且准确。
- **关联**：转 W3 批注，逐句给替换建议。

### C6 时间与策略
- **课堂动作**：限时训练 + 答题顺序策略（先易后难、综合题先写框架再补要点）。
- **练习设计**：单题限时（综合题 8 分钟/题），记录用时与得分。
- **复测**：同份卷重做，完成率 100%。
- **关联**：转 W4 做整卷时间分配分析。

## 三、汇总口径

学情分析时按主码统计人次与占比，输出表：

| 编码 | 人次 | 占比 | 涉及题号 | 主要补救动作 |
|---|---|---|---|---|
| C1 | | | | 概念辨析 + 判断题组 |
| C2 | | | | 读图四步 + 同类图训练 |
| C3 | | | | 设问动词训练 |
| C4 | | | | 角度清单 + 框架训练 |
| C5 | | | | 术语替换 |
| C6 | | | | 限时与策略 |

**判读原则**：占比最高的那一类，决定下周课堂的主攻方向；不要六类一起补，补不过来，也测不出效果。
