# 卓识教育 · 高中地理老师助手

> 一个面向高中地理教师的教学工作台。给课题，出教案；给范围，出卷子；给成绩，出诊断。
> 由虫志龙独立开发，v1.0.0。

---

## 一、这是什么

这不是一个"什么都能问"的通用助手，而是把高中地理教师每周都要重复做的五件事——备课、命题、批改、复盘、讲评——做成可复用的流程：

| 你手上的东西 | 你拿到的成品 | 耗时量级 |
|---|---|---|
| 一个课题 | 可上课的教案（含过程表、板书、分层作业、打印版 docx） | 1 轮对话 |
| 一个考查范围 | 双向细目表 → 试卷 → 答案 → 逐题解析 | 先确认结构，再组卷 |
| 一份学生作答 | 采分点批注 + 错因编码 + 评语 + 下一步动作 | 单题即时 |
| 一张成绩表 | 得分率表 + 失分点归因 + 分层补救 + 复测建议 | 1 轮对话 |
| 一道高考题 | 考点定位 + 解题路径 + 规范作答 + 考法归类 | 单题即时 |

**它不做什么**：不替学生写作业，不押题，不编造数据和真题，不评价具体学校与教师。

## 二、三个真实使用场景

**场景 1｜明天要上公开课**
> "帮我备《大气受热过程和大气运动》，人教版必修一，普通班，40 分钟。"

拿到：课标定位、3 条可测评目标、重难点（写清难在哪一步）、教学过程表（环节/时长/教师活动/学生活动/设计意图/评价）、结构化板书、三层作业，外加一份可直接打印的 docx。

**场景 2｜单元测要出卷**
> "出一套自然地理单元测验，12 选择 + 2 综合，难度 0.65。"

拿到：先给双向细目表（考点×能力层级×分值×难度），确认后逐题命制，附答案、四段式解析、地图与数据合规提示。

**场景 3｜月考考砸了**
> "这是月考成绩，帮我看看问题在哪。"

拿到：均分/分数段/板块得分率，失分点 Top3–5（每个带题号与得分率证据），错因编码汇总（C1 概念 / C2 读图 / C3 审题 / C4 角度 / C5 表述 / C6 策略），分三层给补救动作，并给出两周后的复测方案。

## 三、九个工作流

| 编号 | 工作流 | 解决什么 |
|---|---|---|
| W1 | 教案设计 | 目标可测评、环节有时间、活动有意图 |
| W2 | 试题命制 | 先细目表后组卷，原创优先，答案可复算 |
| W3 | 批改反馈 | 按采分点批注，错因编码，给下一步动作 |
| W4 | 学情诊断 | 从成绩表到"谁练什么"，带证据归因 |
| W5 | 概念讲解 | 是什么→为什么→在哪里→怎么考→错在哪→练一道 |
| W6 | 高考真题解析 | 拆到可复用的解题动作，来源不确定就标"待核" |
| W7 | 图表判读与区域分析 | 固定四步读图法 + 区位双维度框架 |
| W8 | 研学设计 | 有任务、有工具、有评价、有安全预案 |
| W9 | 课件制作 | 一页一个要点，生成 .pptx 或退化为大纲 |

工作流之间的串联规则见 `workflows/00-orchestration.md`：诊断出的失分点可以直接变成变式题，概念性失分可以直接变成补救课教案。

## 四、和常见"AI 备课"的差别

1. **五道闸门**：每份产出交出去之前要过 G0 受理 → G1 输入 → G2 结构 → G3 学科 → G4 合规。没过就说没过，不假装通过。
2. **地图合规是红线**：中国地图必须完整表示南海诸岛、台湾岛、钓鱼岛及其附属岛屿、赤尾屿；不自行描绘国界；用标准地图服务底图并提示审图号。这是地理学科独有的雷区，多数工具不管。
3. **事实/推断/观点分离**：数据必须带指标、口径、年份、来源；拿不准标 `[待核]`，不硬编。
4. **错因编码 C1–C6**：把"错了"变成"错在哪一类、下一步练什么"，批改结果能直接汇总成学情。
5. **资料包是原创的**：`materials/` 下 6 份教学资料为独立撰写，不含任何教材原文、成套试题或第三方课件。

## 五、安装与使用

### 方式 A：导入 zip（推荐给使用者）

1. 打开 WorkBuddy → 专家中心 → 导入专家；
2. 选择 `dist/czl-geo-teacher-desk-1.0.0.zip`；
3. 导入后在专家列表选择「卓识教育-高中地理老师助手」开始对话。

### 方式 B：放进本地专家目录（推荐给开发者）

```bash
python tools/sync_install.py install
# 目标目录：<用户目录>/.workbuddy/plugins/marketplaces/my-experts/plugins/czl-geo-teacher-desk
```

同步完成后重启或刷新专家列表即可看到。

### 自检与打包

```bash
python tools/verify_package.py .                      # 结构与头像自检
python tools/sync_install.py validate                 # 调用官方 validate_expert
python tools/sync_install.py package                  # 生成 dist/czl-geo-teacher-desk-1.0.0.zip
```
