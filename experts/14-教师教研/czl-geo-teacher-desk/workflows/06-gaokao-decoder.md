# W6 高考真题解析

## 1. 职责

把一道真题拆到"下次遇到同类题能自己走完流程"的程度。解析的价值不在读懂这道题，在于提炼出可复用的解题动作。

## 2. 输入参数

| 参数 | 类型 | 必填 | 默认 |
|---|---|---|---|
| 真题 | 文本/图片 | 是 | — |
| 年份 | 文本 | 否 | 从题干中识别，识别不出则标"待核" |
| 卷别 | 文本 | 否 | 全国甲/乙、新课标、地方卷，识别不出标"待核" |
| 题号 | 文本 | 否 | — |
| 学生作答 | 文本 | 否 | 无（有则加"错在哪一步"） |
| 目标学段 | 枚举 | 否 | 高三 |

## 3. 执行步骤

1. **确认来源**：年份 + 卷别 + 题号。**识别不出就写"来源待核"，绝不编造"2023 年全国乙卷"这类标注。**
2. **定位考点**：主考点 1 个 + 关联考点 1–2 个，标模块（自然/人文/区域）与能力层级。
3. **提取材料信息**：把材料与图表逐条拆成"可用信息"，注明每条支撑哪个设问。地理题的失分多半是信息没提取全，不是不会推理。
4. **写解题路径**：分步写，每步一个动作（读图例 → 定位置 → 找递变 → 比差异 → 得结论）。禁止写"综合分析即可"。
5. **给规范作答**：按设问类型（特征/原因/影响/措施/评价）组织分点，术语准确，每点一个角度，不重复。
6. **对照评分标准**：说明采分点如何分布，哪个点最容易漏。
7. **考法归类**：归到"设问类型 × 情境类型 × 图表类型"三维，指出这类题的通用套路。
8. **给变式**：改一个变量（换区域、换尺度、换设问），说明答案会怎么变。
9. **若有学生作答**：指出卡在第几步，对应 `error-codebook.md` 的编码。

## 4. 判断条件

| 条件 | 分支动作 |
|---|---|
| 图片模糊、图例缺失 | 明确说明无法判读的部分，请教师补图或文字描述，不猜 |
| 来源无法确认 | 标"来源待核"，解析照做，但不写具体年份卷别 |
| 选择题 | 逐项分析对错原因，不只说正确答案 |
| 综合题 | 给采分点表 + 满分答案 + 常见 3 分答案长什么样 |
| 一题多问且设问类型不同 | 每问单独走第 5 步，不合并 |
| 涉及中国区域图 | 加一句"边界以标准地图为准"，不描述国界走向 |

## 5. 输出格式

```
【来源】年份｜卷别｜题号（不确定写"待核"）
【考点】主考点｜关联考点｜模块｜能力层级
【材料信息】① … （支撑第 X 问）② …
【解题路径】第 1 步 … 第 2 步 … （3–6 步）
【规范作答】(1) … (2) …（分点，与采分点对应）
【采分点】① X 分 ② X 分（标出最易漏的点）
【考法归类】设问类型 × 情境类型 × 图表类型
【变式】改什么 → 答案怎么变
【易错提醒】2–3 条
```

## 6. 异常处理

- 教师给的题目与标注年份不符 → 指出疑点，按教师给的文字解析，注明"来源信息存疑"。
- 要求"预测明年考什么"→ 拒绝预测；改为给近三年同类考法的分布与备考清单。
- 要求"把这道题改成原创题"→ 转 W2，保留情境骨架但重写设问与选项。

## 7. 依赖

`references/curriculum-map.md`（考点定位）、`references/answer-templates.md`（作答骨架）、`references/error-codebook.md`（错因编码）。

## 8. 与其他工作流的关系

上游可接 W4（某考点全班低分 → 找真题佐证）；下游接 W2（仿命题）、W1（把真题当例题嵌进教案）。真题是命题的参照系，不是命题的替代品。
