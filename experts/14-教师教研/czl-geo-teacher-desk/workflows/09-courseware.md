# W9 课件制作

## 1. 职责

把教案或教材页转成能直接投影的课件。原则：**一页一个要点，图比字重要，字要能一眼看完**。课件不是把教案复制粘贴到幻灯片上。

## 2. 输入参数

| 参数 | 类型 | 必填 | 默认 |
|---|---|---|---|
| 课题 | 文本 | 是 | — |
| 教材页 | 图片/PDF | 否 | 无（按课标内容组织） |
| 页数 | 数字 | 否 | 12–16 页 |
| 风格 | 枚举 | 否 | 简洁投影（浅底深字，字号≥24） |
| 学情 | 文本 | 否 | 中等班 |

## 3. 执行步骤

1. **识别教材页**：读出章节标题、核心图、活动栏、思考题。识别不出时明确说明，改按课标内容组织。
2. **抽要点**：一节新课提炼 4–6 个要点，每个要点一页或两页（概念页 + 例证页）。
3. **定结构**：封面 → 学习目标（1 页，≤3 条）→ 情境导入（1 页）→ 新知（3–5 页）→ 图表解析（1–2 页）→ 规律总结（1 页）→ 当堂检测（1 页）→ 小结与作业（1 页）。
4. **写每页内容**：标题（≤12 字）+ 3–5 条要点（每条 ≤20 字）+ 图位说明。要点用短句，不用完整段落。
5. **标图位**：需要地图/示意图/统计图的位置，写清"图名 + 要表达什么 + 来源要求"，用占位框代替，**不臆造地图内容**。
6. **给动画/呈现建议**：哪些内容分步出现（如热力环流的三个环节），写在一页备注里。
7. **生成 pptx**：调用 `tools/build_ppt.py`（python-pptx）。环境无 python-pptx 时，交付 Markdown 大纲并说明。
8. **自检**：正文字号 ≥20、每页文字 ≤80 字、无整段粘贴、深底不用深字。

## 4. 判断条件

| 条件 | 分支动作 |
|---|---|
| 教材页模糊/缺页 | 说明缺哪页，按已有内容出框架，标注"待补页" |
| 页数要求 ≤8 | 只保留：目标、情境、核心原理（2 页）、总结、检测 |
| 课题为复习课 | 结构改为：知识网络 → 易错辨析 → 典型题 → 方法总结 |
| 需要中国地图 | 用占位框 + "请插入标准地图（附审图号）"，不生成地图 |
| 无 python-pptx 环境 | 交付 Markdown 逐页大纲（含版面说明），请教师用模板快速套用 |

## 5. 输出格式

```
【课题】… 【页数】… 【风格】…
逐页大纲：
P1 封面：主标题 / 副标题 / 年级·教材
P2 学习目标：3 条
P3 情境导入：图位 + 问题
…
末页 作业与预告
【配图清单】页码｜图名｜要表达的内容｜来源要求
【备注】分步呈现建议、板书对应关系
```

## 6. 异常处理

- 生成失败（缺库/权限）→ 交付大纲 + 明确的安装提示，不谎称已生成。
- 教材版本不同导致图序不一致 → 按内容组织，页脚标注"对应人教版第 X 章"。
- 教师要求加大量文字 → 提醒投影可读性，给"讲义版"与"投影版"两套。
