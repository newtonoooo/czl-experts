# W1 教案设计

## 1. 职责

把一节课题，做成教师拿着就能进课堂的教案：目标可测评、环节有时间、活动有意图、作业有分层。不做"教材目录式"的空教案。

## 2. 输入参数

| 参数 | 类型 | 必填 | 默认 |
|---|---|---|---|
| 课题 | 文本 | 是 | — |
| 教材版本 | 枚举 | 否 | 人教版 |
| 年级 | 枚举 | 否 | 高一 |
| 课型 | 枚举 | 否 | 新授课（另有复习课/习题课/实验课/研学课） |
| 课时 | 数字 | 否 | 1 课时（40 或 45 分钟，按学校作息） |
| 学情 | 文本 | 否 | 中等班：能读懂图，缺原理推导习惯 |
| 课标要求 | 文本 | 否 | 按 `references/curriculum-map.md` 对应条目 |

## 3. 执行步骤

1. **定位**：查 `curriculum-map.md`，确定本节所属模块、内容要求、学业质量层级；写清"前接什么、后续什么"，一句话即可。
2. **拆概念**：把课题拆成 2–4 个核心概念或原理。逐个标注：学生已有基础 / 常见前概念错误 / 需要何种直观支撑（图、实验、类比）。
3. **定目标**：不超过 3 条。格式「行为动词 + 具体内容 + 可观察的达成标准」。示例："能在示意图上标出太阳辐射、地面辐射、大气逆辐射三条箭头，并说明保温作用的因果链"。
4. **定重难点**：重点＝本节不可省的原理；难点＝认知跨度最大处，写清"难在哪一步"（如"短波辐射与长波辐射的区分"），不写"学生基础差"这类无效归因。
5. **设计主线**：选一条情境线贯穿全课（真实地理现象、本地案例、小实验、数据冲突）。环节之间必须是同一条线推进，不能三个情境各讲一段。
6. **排教学过程表**：列「环节 / 时长 / 教师活动 / 学生活动 / 设计意图 / 评价方式」。时长合计等于课时；设计意图要写"为什么这么设计"，不写"培养核心素养"。
7. **板书结构化**：给出板书骨架（层级符号 + 关键词），能反映因果链或空间分布，不是标题罗列。
8. **分层作业**：基础（必做，5–8 分钟）/ 提升（选做，1 题）/ 实践（周内完成，1 项，可观察可提交）。
9. **写复核项**：把重难点取舍、课时松紧、本地案例适配性列为"请教师复核"。
10. **出打印版**：按 `output-contracts.md` 生成纯净版，并调用 `tools/build_print_docx.py` 输出 `打印版_<课题>.docx`。

## 4. 判断条件

| 条件 | 分支动作 |
|---|---|
| 课型＝复习课 | 结构改为：知识网络重建 → 易错点辨析 → 典型题带练 → 当堂检测；不写"情境导入" |
| 课型＝习题课 | 结构改为：错题归因 → 同类题归纳 → 变式训练 → 方法固化 |
| 课型＝实验/观察课 | 增「器材清单 / 操作步骤 / 安全提示 / 数据记录表」四块；无器材则改演示或视频观察 |
| 课题属自然地理原理类 | 必须有示意图或过程动画的描述，不能纯文字讲原理 |
| 课题属人文地理 | 必须有真实区域数据或案例，不能用"某地"虚构 |
| 学情薄弱 | 增「前概念补救」环节（3–5 分钟），并把目标下调一档 |
| 学情较好 | 增「迁移挑战」环节（1 个开放性问题） |
| 教师给了课时 2 节以上 | 拆成两课时，标明各自落点，不把内容平均切 |

## 5. 输出格式

```
【课题】… 【教材】… 【年级】… 【课型】… 【课时】…
【前提假设】（缺省项一行说明）

一、课标与教材定位（2–3 行）
二、教学目标（≤3 条，编号）
三、教学重点 / 难点（各 1–2 条，难点写清难在哪）
四、学情分析（3–4 行，含前概念错误）
五、教学过程（表格：环节｜时长｜教师活动｜学生活动｜设计意图｜评价）
六、板书设计（结构化文本或图示说明）
七、分层作业（基础 / 提升 / 实践）
八、需教师复核（列表，≤4 条）
```

## 6. 异常处理

- 课题不在课标模块内（如"地理信息技术"拓展内容）→ 说明属选修/拓展，按拓展课处理并标注。
- 教材版本不明且不同版本编排差异大 → 按人教版写，标注"其他版本需调整顺序"。
- 教师要求"一节课讲完一章" → 说明课时与内容量矛盾，给"必讲/略讲/自学"三档取舍建议，由教师定。

## 7. 依赖

`references/curriculum-map.md`（定位）、`references/output-contracts.md`（格式）、`tools/build_print_docx.py`（打印版）。

## 8. 与其他工作流的关系

上游 W0 判定；下游可接 W9（转课件）、W2（配当堂检测）、W5（拆出学案）。W4 发现概念性失分时，反向触发 W1 做补救课。
