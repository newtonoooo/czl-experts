# W8 研学与实践活动设计

## 1. 职责

把"带学生出去一趟"变成有地理学习产出的实践活动：有任务、有方法、有成果、有评价、有安全底线。反对"到此一游 + 回来写感想"。

## 2. 输入参数

| 参数 | 类型 | 必填 | 默认 |
|---|---|---|---|
| 主题或地点 | 文本 | 是 | — |
| 时长 | 文本 | 否 | 1 天（校内半日可） |
| 学段 | 枚举 | 否 | 高二 |
| 人数 | 数字 | 否 | 40 人（1 个班） |
| 交通条件 | 文本 | 否 | 步行 + 公共交通 |
| 学科侧重点 | 枚举 | 否 | 自然地理（另有：人文/区域/地理实践力综合） |
| 安全约束 | 文本 | 否 | 无特殊要求 |

## 3. 执行步骤

1. **定主题**：一个可观察、可测量、可回答的地理问题。反例："感受自然之美"；正例："同一河段上下游河床沉积物粒径为什么不同"。
2. **对课标**：写清对应哪条内容要求、训练哪项核心素养（地理实践力为主，兼综合思维/区域认知）。
3. **选点位**：2–4 个观察点，说明每个点位能观察到什么、为什么非它不可。点位之间要有地理逻辑（沿某一变量梯度）。
4. **设任务**：每个点位 1–2 个任务，分「观察记录 / 测量 / 访谈 / 取样」四类。任务必须能在现场 15–25 分钟内完成。
5. **给工具**：记录表、测量方法、取样要求、照片拍摄规范（拍什么、拍几个角度、要不要放参照物）。
6. **排流程**：时间轴（集合—行进—点位—午餐—返程），标出每个环节的时长与负责人。
7. **写安全预案**：风险清单（交通/地形/水域/天气/过敏/走失）+ 应对措施 + 应急联系 + 家长告知要点。**这一块必须由教师和学校最终确认，助手只给模板。**
8. **设评价**：过程性（任务单完成度、合作）+ 成果性（报告/图件/数据表），给量规（3 档，描述可观察行为）。
9. **给成果形式**：明确交什么（1 张剖面草图 / 1 组数据 / 1 份 800 字报告），避免"交一篇感想"。
10. **出打印版**：任务单 + 安全须知独立成页，便于现场发放。

## 4. 判断条件

| 条件 | 分支动作 |
|---|---|
| 无法外出 | 改"校园/社区微研学"：校内地貌观察、周边商业网点调查、气象站数据记录 |
| 地点涉及水域、山地、交通干道 | 安全等级上调，必须写明"教师带队 + 家长知情 + 保险"三项 |
| 人数＞80 | 分组（每组 ≤12 人），每组配组长与对讲/联络方式 |
| 学段＝高一 | 任务以观察记录为主，减少测量与数据分析 |
| 学段＝高三 | 压缩为半日，任务直指高考设问类型（特征描述/成因分析） |
| 天气不可控 | 给"雨天替代方案"（室内观测/数据回放/博物馆线） |

## 5. 输出格式

```
【主题】… 【学段】… 【时长】… 【人数】… 【侧重】…
一、主题与课标对应（2–3 行）
二、学习目标（≤3 条，可观察）
三、点位与线路（表：点位｜观察对象｜地理问题｜停留时长）
四、任务单（每点一页，含记录表格与留白）
五、工具与材料清单
六、流程时间轴
七、安全预案（风险｜预防｜应对｜责任人）
八、评价量规（3 档 × 2–3 维度）
九、成果要求与提交方式
十、需教师/学校复核（安全、路线、家长告知）
```

## 6. 异常处理

- 地点信息不足（只给"某公园"）→ 按通用城市公园设计，标注"点位需按实际踏勘调整"。
- 涉及自然保护区/景区 → 提示需提前报备、遵守管理规定，不设计进入核心区的路线。
- 涉及采集标本 → 提示遵守当地法规，不采集保护物种、不破坏植被。
