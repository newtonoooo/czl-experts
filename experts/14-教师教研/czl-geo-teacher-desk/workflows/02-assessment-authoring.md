# W2 试题命制

## 1. 职责

按考查范围原创组卷。先出双向细目表让教师确认结构，再逐题命制，最后交答案、解析和合规提示。**没有细目表就直接出整卷，是这份工作最容易出错的地方。**

## 2. 输入参数

| 参数 | 类型 | 必填 | 默认 |
|---|---|---|---|
| 考查范围 | 文本 | 是 | — |
| 用途 | 枚举 | 否 | 单元测验（另有随堂练/月考/期末/专题突破） |
| 题量 | 结构 | 否 | 12 单选 + 2 综合（综合题 2–3 小问） |
| 难度 | 数值 | 否 | 0.65（中等偏易） |
| 题型 | 列表 | 否 | 单选、综合；可按需加判断、填空、绘图 |
| 分值 | 数字 | 否 | 100 分（单选每题 3 分，综合题共 64 分，按题量折算） |
| 已考题目 | 文本 | 否 | 无（避免重复命题） |

## 3. 执行步骤

1. **拆考点**：把范围拆成 8–14 个可测考点，标注能力层级（识记/理解/应用/分析/评价）与模块归属（自然/人文/区域）。
2. **配结构**：按分值权重分配考点，填双向细目表：`题号｜考点｜模块｜能力层级｜题型｜分值｜预估难度｜材料类型`。
3. **交确认**：把细目表单独呈现，请教师确认后再命题。教师说"直接出"则跳过等待，但细目表仍要附在卷首说明里。
4. **选情境**：每题一个情境，优先真实地理事象（区域统计、生产生活现象、科考发现、本地素材）。情境必须与设问直接相关，不写"背景介绍"式冗长材料。
5. **写题干**：一句话说清一个问题；单选四选项同质同长、互斥、只有一个最优；干扰项来自真实易错点，不放"以上都对/都不对"。
6. **配图**：需要图时给出**图的文字规格**（图名、图例、坐标范围、关键数值），并标注"此图需教师用标准地图/自绘图替换"。不臆造地图内容。
7. **写答案与解析**：解析四段式——考点定位 / 信息提取（从材料哪句、图上哪处）/ 推理路径 / 易错提醒。综合题给采分点与分值，按 `answer-templates.md` 的设问类型组织。
8. **过质检**：逐题对照第六节检查表，不合格的当场重写，不放水。
9. **出合规提示**：涉及中国地图、区域边界、统计数据的，写明来源与核对要求。
10. **组卷排版**：卷头（考试范围、时长、分值、注意事项）→ 试题 → 答题区 → 答案与解析（单独起页，便于裁切）。

## 4. 判断条件

| 条件 | 分支动作 |
|---|---|
| 教师未确认细目表且未说"直接出" | 停在细目表，不往下做 |
| 用途＝随堂练 | 题量压到 5–8 题，单题 3–5 分钟，不出综合大题 |
| 用途＝月考/期末 | 综合题为主（≥50% 分值），加一组图表判读 |
| 难度＜0.55 | 减干扰项迷惑度，材料缩短，设问指向明确化 |
| 难度＞0.75 | 增设第二级设问（原因→影响），材料信息密度提高 |
| 范围跨两个以上模块 | 按模块分块命题，块内由易到难 |
| 教师给了原题要求改编 | 保留情境骨架，改设问角度与选项，标注"改编自…" |
| 需要区域图 | 给图规格 + 指向标准地图服务，不描述具体国界线走向 |

## 5. 输出格式

**第一部分：双向细目表**

| 题号 | 考点 | 模块 | 能力层级 | 题型 | 分值 | 预估难度 | 材料类型 |
|---|---|---|---|---|---|---|---|

表下给三行统计：模块分值占比 / 能力层级分布 / 全卷预估均分。

**第二部分：试卷**

```
【卷头】范围｜时长｜满分｜作答要求
一、单项选择题（每题 X 分，共 X 分）
  材料（≤120 字）+ 设问 + A/B/C/D
二、综合题（共 X 分）
  材料 + 图规格说明 + (1)(2)(3)
```

**第三部分：参考答案与解析**（逐题，解析不少于 4 行）
**第四部分：命题说明与合规提示**（考点覆盖、原创声明、地图与数据来源、需复核项）

## 6. 质量检查表（逐题过）

| 检查项 | 不合格表现 |
|---|---|
| 单一考点 | 一道题同时考气候类型和洋流成因，说不清考什么 |
| 题干自足 | 必须看课外知识才能答，材料里没线索 |
| 选项同质 | 三个具体、一个笼统；或长度差异明显暗示答案 |
| 无绝对化 | "一定""必然""完全"出现在正确选项里 |
| 图题有图例 | 只给轮廓没图例、没比例尺、没经纬度 |
| 数据可核 | 出现"据统计"却不给年份与来源 |
| 综合题递进 | 三小问都是"分析原因"，没有梯度 |
| 无重复 | 与教师提供的"已考题目"重复 |

## 7. 异常处理

- 范围过大（"整本书"）→ 要求缩小到 2–3 章，或改为"模块综合卷"并说明覆盖不全的部分。
- 教师要求"必须押中"→ 拒绝预测具体题，改为给考法清单与高频设问角度。
- 需要真实统计图但无数据源 → 用文字材料替代，或给"数据待填"的表格模板，不编数字。
- 综合题答案与设问类型不匹配（问"措施"却答"原因"）→ 按 `answer-templates.md` 重写答案。
