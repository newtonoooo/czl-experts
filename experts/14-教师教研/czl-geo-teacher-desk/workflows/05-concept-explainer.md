# W5 概念讲解与学案

## 1. 职责

把一个地理概念讲到学生能自己用。顺序固定：是什么 → 为什么 → 在哪里 → 怎么考 → 错在哪 → 练一道。**顺序可以压缩，不能打乱**，因为地理概念的难点几乎都出在"成因"和"分布"之间断了链。

## 2. 输入参数

| 参数 | 类型 | 必填 | 默认 |
|---|---|---|---|
| 知识点 | 文本 | 是 | — |
| 学段 | 枚举 | 否 | 高一 |
| 教材版本 | 枚举 | 否 | 人教版 |
| 深度 | 枚举 | 否 | 新授（另有复习/竞赛拓展） |
| 配套形式 | 枚举 | 否 | 讲解稿 + 学案（另有仅讲解、仅学案） |
| 常见错误 | 文本 | 否 | 按 `materials/04-高频易错点清单.md` 取 |

## 3. 执行步骤

1. **界定概念**：一句话定义 + 三句边界说明（包含什么、不包含什么、容易和谁混）。边界说明比定义更重要。
2. **拆成因链**：把成因拆成"条件 → 过程 → 结果"三段，逐段给一句人话解释。凡有能量/物质流动的，标明方向与环节。
3. **给分布规律**：水平分布（纬度/海陆/地形）与垂直分布分开讲；规律要能画成图，不能只给结论。
4. **配典型例题**：1 道基础（直接应用）+ 1 道迁移（换区域/换尺度）。每题给"看什么→想什么→答什么"。
5. **列易错警示**：3–5 条，每条写"错误说法 → 为什么不成立 → 正确表述"。不写"注意区分"这种没有信息的话。
6. **给变式练习**：2 道，改变设问角度（如把"原因"改成"影响"），附答案要点。
7. **出学案**：留白式结构——填空（关键术语）、表格（对比/归纳）、简答（成因链）、图（标注）。留白处用 `______`，不直接给答案。
8. **标复核项**：涉及具体数值、区域案例的，标注"以教材/当年数据为准"。

## 4. 判断条件

| 条件 | 分支动作 |
|---|---|
| 概念属原理类（如热力环流） | 必须给过程图描述 + 三步推导，不能只给结论 |
| 概念属分类类（如气候类型） | 必须给判读流程（气温定带 → 降水定型 → 特殊型修正） |
| 概念属人文类（如区位因素） | 必须给"因素—影响—案例"三列对应表 |
| 学生常见错误集中在术语 | 增「术语辨析」小节，成对比较 |
| 深度＝复习 | 省略定义铺垫，直接上"知识网络 + 易错 + 综合题" |
| 深度＝竞赛拓展 | 补一层机制解释（如地转偏向力的数学直觉），标注"超出课标要求" |

## 5. 输出格式

```
【知识点】… 【学段】… 【深度】…
一、概念界定（定义 + 三条边界）
二、成因与过程（条件→过程→结果，含图示说明）
三、分布与规律（水平/垂直）
四、典型例题（2 道，含思路三步）
五、易错警示（3–5 条，错误说法→原因→正确表述）
六、变式练习（2 道 + 答案要点）
七、学案（留白版，可直接打印）
八、需复核
```

## 6. 异常处理

- 知识点过大（"大气"）→ 拆成 3–4 个子知识点，请教师选一个先讲。
- 涉及教材未讲的机制 → 标注"拓展，非课标要求"，由教师决定是否讲。
- 需要区域数据但无可靠来源 → 用定性描述替代，不编数字。
