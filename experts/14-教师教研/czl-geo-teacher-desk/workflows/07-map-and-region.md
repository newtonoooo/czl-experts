# W7 图表判读与区域分析

## 1. 职责

教"看图的方法"和"分析区位的框架"。地理的读图能力不是天赋，是固定动作的熟练度——所以输出必须是可复述的步骤，不是"仔细观察图形"。

## 2. 输入参数

| 参数 | 类型 | 必填 | 默认 |
|---|---|---|---|
| 图形 | 图片/文字描述 | 是 | — |
| 图形类型 | 枚举 | 否 | 按图形特征判断 |
| 设问要求 | 文本 | 否 | 描述特征并分析成因 |
| 学段 | 枚举 | 否 | 高一 |

**图形类型枚举**：等高线地形图 / 等温线图 / 等压线图 / 等降水量线图 / 经纬网图 / 剖面图 / 统计图（柱状、折线、扇形、三角坐标）/ 区域综合图 / 示意图。

## 3. 执行步骤（通用四步，任何图都先走这四步）

1. **读图名与图例**：图名定主题，图例定符号含义。缺图例直接说明无法判读。
2. **定方向与尺度**：经纬网定位置与半球；指向标或"上北下南"定方向；比例尺定尺度大小（大比例尺看细节，小比例尺看格局）。
3. **找递变与极值**：等值线的递变方向、闭合区、疏密、弯曲；统计图的时间趋势与结构占比。
4. **落结论并回验**：结论要能指回图上某处（"因为 A 处等值线向低值凸出"），不能凭印象。

### 分类型追加动作

| 图形 | 追加动作 | 常见陷阱 |
|---|---|---|
| 等高线 | 判地形部位（山峰/鞍部/山谷/山脊/陡崖）→ 判坡度（疏密）→ 判视线与路线 | 山脊山谷看弯曲方向（凸低为脊、凸高为谷） |
| 等温线 | 判南北半球（数值递变）→ 判海陆（同纬度陆高海低为夏季）→ 判地形（闭合、弯曲） | 把"等温线弯曲方向"直接当洋流方向 |
| 等压线 | 判高低压中心 → 判风向（水平气压梯度力→偏转）→ 判天气（低压上升多雨） | 近地面风向忘了摩擦力和偏转 |
| 等降水量线 | 判递变方向 → 找极值区 → 结合地形与风向解释 | 只背"迎风坡多雨"，不看水汽来源 |
| 经纬网 | 定半球 → 定纬度带 → 估距离（1°≈111km） | 东西经判断搞反 |
| 统计图 | 看坐标单位 → 看趋势 → 看结构 → 看异常点 | 三角坐标图读法错（沿轴平行线读） |

## 4. 区位分析框架（人文地理通用）

**自然因素**：位置（经纬度/海陆）、地形、气候（光热水）、水文（水源/航运）、土壤、资源（矿产/能源）、自然灾害。

**社会经济因素**：市场（距离/规模/消费能力）、交通（方式/通达度）、劳动力（数量/素质/成本）、技术、政策、地价、基础设施、产业基础与集聚、资金、环境容量。

**环境因素**：污染承载、生态敏感度、环境标准。

**输出要求**：
- 用「因素 → 具体表现 → 对布局的影响」三列写，不写孤立名词。
- 有利与不利分开列，**不做绝对化断言**（"必然形成工业区"一律不写）。
- 主导因素只能选 1–2 个，并说明为什么是它主导（"该地原料运输成本占比最高"）。

## 5. 判断条件

| 条件 | 分支动作 |
|---|---|
| 图缺图例/比例尺/经纬度 | 说明缺哪项、影响哪一步判断，请教师补图 |
| 图形为示意图（非真实区域） | 只讲判读方法与原理，不做区域结论 |
| 涉及中国地图 | 加"边界以自然资源部标准地图为准"提示 |
| 设问要"评价" | 有利/不利并列，各给 2–3 条，末尾给限定条件 |
| 设问要"措施" | 按"工程/技术/管理/政策"四类给，不重复同义项 |
| 学生反复在同一类图出错 | 转 W2 生成该类图的专项训练组（5 题一组，由易到难） |

## 6. 输出格式

```
【图形类型】… 【判读目的】…
一、判读步骤（4–6 步，每步一句动作）
二、图上依据（逐条：位置/数值/递变 → 说明什么）
三、结论（分点，术语准确）
四、延伸（若换一个区域/尺度，结论怎么变）
五、训练建议（练什么图、几道、注意什么）
```

## 7. 异常处理

- 图形分辨率过低看不清数值 → 只讲方法，不给具体数值结论。
- 教师要求"帮我把这张图改一下"→ 说明不能编辑图片；可给"重绘要点清单"，由教师用绘图工具或标准地图重绘。
- 区域不在教材范围内 → 照常分析，标注"拓展区域"。
