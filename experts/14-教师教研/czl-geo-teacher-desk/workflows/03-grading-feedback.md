# W3 批改与反馈

## 1. 职责

按采分点批改，把"错了"变成"错在哪一类、下一步练什么"。批改的产出不是分数，是可执行的补救动作。

## 2. 输入参数

| 参数 | 类型 | 必填 | 默认 |
|---|---|---|---|
| 学生作答 | 图片/文本 | 是 | — |
| 题目 | 图片/文本 | 否 | 从作答中识别 |
| 参考答案 | 文本 | 否 | 按学科标准自行判定，并标注"参考要点" |
| 评分标准 | 文本 | 否 | 按采分点赋分 |
| 班级层次 | 文本 | 否 | 中等班 |
| 批改粒度 | 枚举 | 否 | 单人单题（另有整班抽样） |

## 3. 执行步骤

1. **读题**：确认题号、设问类型（特征/原因/影响/措施/评价）、分值。
2. **列采分点**：按设问类型列 3–5 个采分点，标分值。采分点必须是可判定的表述，不写"意思对即可"。
3. **对照作答**：逐点判断"命中 / 半命中 / 未命中"，半命中要指出缺哪个限定词（如"只写了自然因素，漏了社会经济因素"）。
4. **编码错因**：按 `error-codebook.md` 打一个主码 + 可选次码。一题只给一个主码，避免"什么都是"。
5. **算分**：命中给满分，半命中给一半（按采分点分值取整），未命中不给分；给分要能复算。
6. **写批注**：每条批注三句话——你写了什么 / 缺什么 / 怎么补。不用"注意""加强""有待提高"这类空话。
7. **写评语**：三段——做到了什么（具体到题号）/ 主要问题（对应错因码）/ 下次动作（1–2 条可执行）。
8. **给讲评建议**：这道题如果全班共性错，给出讲评时的切入点和 1 道变式题。

## 4. 判断条件

| 条件 | 分支动作 |
|---|---|
| 作答为空白 | 不判错因，标"未作答"，单独统计（区分"不会"与"没时间"） |
| 作答字迹/图片不清 | 明确说读不出的部分，不猜内容 |
| 答案超出参考答案但合理 | 判"合理拓展"，给分并注明"优于参考要点" |
| 答案与设问类型错位（问措施答原因） | 主码 C3 审题偏差，采分点不给分 |
| 只给分数不给过程 | 要求补过程，或标注"仅按结果判分，无法定位错因" |
| 整班抽样（≥10 份） | 转 W4，输出统计而非逐份评语 |

## 5. 输出格式

```
【批改对象】题号｜设问类型｜满分
【采分点】① …（X 分）② …（X 分）③ …（X 分）
【得分】X / Y
【逐点批注】
  ① 命中/半命中/未命中 — 你写的："…"；缺："…"；补："…"
【错因编码】主码 C_ + 说明；次码（可选）
【评语】（三段，≤120 字）
【下一步】1–2 条具体动作（练什么题、看哪一页、改哪个习惯）
```

## 6. 异常处理

- 作答与题目对不上（拍错页）→ 请教师确认，不硬批。
- 参考答案缺失且设问开放 → 先给"参考要点"，注明"非唯一答案，按要点给分"。
- 学生答案中出现人名、校名等隐私信息 → 不回显，用"该生"替代。
