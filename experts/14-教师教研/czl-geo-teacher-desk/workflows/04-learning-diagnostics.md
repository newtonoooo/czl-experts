# W4 学情诊断

## 1. 职责

把一张成绩表，变成三样东西：班里到底哪儿弱、为什么弱、接下来两周谁练什么。不做"平均分 68.5，整体一般"这种没有信息量的结论。

## 2. 输入参数

| 参数 | 类型 | 必填 | 默认 |
|---|---|---|---|
| 成绩数据 | 表格/图片 | 是 | — |
| 试卷结构 | 文本 | 否 | 按题号推断选择题与综合题分界 |
| 班级层次 | 文本 | 否 | 中等班 |
| 教学进度 | 文本 | 否 | 按已考范围 |
| 历次成绩 | 表格 | 否 | 无（则只做单次横向分析） |

**字段要求**：至少需要「总分」；有「小题分」才能做板块得分率；有「题号—考点对照」才能做考点级归因。缺字段时先说明影响再统计。

## 3. 执行步骤

1. **清数据**：确认人数、满分、有无缺考；缺考不计入均分，单独列出。
2. **算总量**：均分、最高、最低、标准差、及格率、优秀率（阈值按学校口径，未给则用 60%/85%）。
3. **分分数段**：按 10 分一档或五档统计人数与占比，画出分布形状（正常/双峰/长尾）。
4. **拆板块**：自然地理 / 人文地理 / 区域地理；选择题 / 综合题。算各板块得分率＝该板块实得÷该板块满分。
5. **定位失分点**：找出得分率最低的 3–5 个考点，每个附证据（题号 + 得分率 + 典型错误表现）。
6. **归因**：用 `error-codebook.md` 判断主因是概念（C1）、读图（C2）、审题（C3）、角度（C4）、表述（C5）还是时间分配（C6）。归因必须有证据，不写"学生不认真"。
7. **分层**：按总分与板块表现分三层——保底层（及格线附近）、中间层（及格到良好）、提升层（良好以上），每层给不同动作。
8. **排优先级**：哪个失分点投入产出比最高（分值大、可短期补、影响后续学习），排第一。
9. **给复测方案**：两周后用同类题复测，明确复测题号与预期得分率变化。

## 4. 判断条件

| 条件 | 分支动作 |
|---|---|
| 只有总分，无小题分 | 只做总量+分数段+分层；明确说明无法做考点归因 |
| 分布双峰 | 提示班级内部存在分层教学需求，建议按层布置作业 |
| 某题得分率＜0.3 且为概念题 | 判定为教学进度问题或概念未讲透，回看 W1 教案 |
| 某题得分率＜0.3 且为读图题 | 判定为技能缺失，转 W7 做专项训练 |
| 综合题得分率显著低于选择题 | 主因多为 C4 角度不全或 C5 表述，转 W5 给答题骨架 |
| 标准差过大（＞15） | 提示"平均分掩盖了分层"，建议分班分层看数据 |
| 有历次成绩 | 加一条趋势线：进步/停滞/退步，退步要指出退在哪个板块 |

## 5. 输出格式

```
【数据说明】人数｜满分｜缺考｜字段完整性
一、总体（表：均分/最高/最低/标准差/及格率/优秀率）
二、分数段分布（表：区间/人数/占比）
三、板块得分率（表：模块×题型，标出最低三项）
四、失分点 Top3–5（每条：考点｜题号｜得分率｜典型表现｜归因码）
五、归因分析（3–5 段，每段一个主因，带证据）
六、分层补救（表：层级｜人数｜本周动作｜配套材料｜检查方式）
七、复测建议（时间、题号、预期）
八、需教师复核（分层名单判定、课时安排）
```

## 6. 异常处理

- 数据含姓名/学号 → 转为编号，输出中不出现真实姓名。
- 数据明显异常（总分超过满分、同一人重复）→ 指出并请教师核对，不擅自修正。
- 班级人数＜10 → 统计量不稳定，只做描述性分析，不给百分比结论。
- 教师要求"排名次"→ 不给学生排名，只给分层与群体统计。
