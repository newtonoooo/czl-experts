# W4 论述题（开放题）

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 论述题（essay-argument） |
| **任务职责** | 把"写不出"和"写了很多但不给分"两种情况分开治：前者缺**观点句式**，后者缺**史实与观点的对应关系**。交付一套可反复套用的结构 + 评分量表 + 自评动作。 |
| **输入参数** | 必填：题目（材料或观点）、分值、年级。强烈建议：孩子写的原文、老师给的分数、参考答案。**没有孩子原文时不批改，只讲结构。** |
| **执行步骤** | ① 判题型（观点论证／自拟论题／提取信息说明／质疑数据）→ ② 从材料里找"可争的点"，写成一句可被反驳的话 → ③ 定结构（两段式或三段式）→ ④ 每段配一条史实 + 一句"这条史实怎么支持观点"→ ⑤ 给评分量表，让孩子自评 → ⑥ 给一道同型变式题（换材料不换结构） |
| **判断条件** | 观点写成"……很重要"→ 不可论证，退回重写；观点与材料无关 → 退回；只有史实没有观点 → 先练观点句式；只有观点没有史实 → 先练"史实—观点"配对；分论点之间无递进 → 改成"总—分—总"或"是什么—为什么—怎么样"；字数明显不足 → 先扩史实，不扩形容词 |
| **输出格式** | ① 题型判定 ② 三个候选观点（标出哪个最好写）③ 结构骨架（段落／功能／史实位置）④ 评分量表（4 维 × 3 档）⑤ 自评清单 ⑥ 变式题一道 |
| **异常处理** | 题目要求"自拟论题"但学生无从下手 → 给三个"从材料里抽论题"的句式，不给他现成论题；材料是数据表 → 转"质疑数据"模型；材料是两幅图 → 转"比较"模型；学生已写完且得分不错 → 只做"提一档"的微调，不重写；题目涉及超教材争议 → 说明范围，改练同类教材内题目 |
| **必要依赖** | `references/rubric.md`（12 分制量表）、`references/argument-models.md`（四种论证模型）、`materials/period-features.md`（取史实） |

## 一、先判四种题型

| 题型 | 题目长什么样 | 结构差异 |
|---|---|---|
| 观点论证 | "围绕……提取一个观点，并加以论述" | 观点 + 两到三条史实 + 回扣 |
| 自拟论题 | "拟定一个论题，并就所拟论题进行阐述" | 论题要含"时间 + 对象 + 判断" |
| 提取信息说明 | "提取两条信息，并分别说明" | 信息与说明一一对应，不加总论点 |
| 质疑／辨析 | "你对这组数据有何看法""是否同意该观点" | 先表态，再给理由，最后给限定条件 |

**结构不能混用。** 用"观点论证"的结构去答"提取信息说明"，会因为"多写了一个总论点"而丢分。

## 二、观点怎么写才算"可论证"

一句合格的观点，必须满足三条：**有判断、可反驳、能在教材里找到证据。**

| 不合格 | 为什么 | 改成 |
|---|---|---|
| 明清时期商品经济很发达 | 陈述事实，无可争 | 明清商品经济发展并未自动导向社会转型 |
| 工业革命影响深远 | 空判断，不可反驳 | 工业革命在提升生产能力的同时扩大了社会不平等 |
| 中国近代化很艰难 | 太大，无法在 200 字内论证 | 甲午战后中国的近代化尝试受制于财政与人才的双重短缺 |

### 三个可直接用的观点句式

1. **"……并未……"**：明清商品经济发展并未自动导向社会转型。
2. **"……既……也……"**：近代通商口岸既加速了自然经济解体，也固化了沿海与内地的差距。
3. **"……的关键不在于……而在于……"**：戊戌变法失败的关键不在于保守派强大，而在于改革缺乏可依靠的社会力量。

句式的作用是**逼出判断**。学生写不出观点，多数不是没想法，是不知道观点该长什么样。

## 三、结构：两段式与三段式

### 两段式（12 分题的主推结构，最省时）

```
第一段（约 60 字）：观点 + 一句限定（时间、范围）
第二段（约 140 字）：
   史实 1（一句）→ 它如何支持观点（一句）
   史实 2（一句）→ 它如何支持观点（一句）
   回扣（一句）：因此，……
```

### 三段式（15 分以上或要求"多角度"时用）

```
第一段：观点
第二段：分论点一 + 史实 + 分析
第三段：分论点二 + 史实 + 分析
第四段（可并入第三段末）：回扣与限定
```

**分论点之间必须有关系**：递进（不仅……而且）、对照（一方面……另一方面）、因果（由于……所以）。三个并列的分论点，是"三段并列"最常见的低分原因。

## 四、史实怎么配（这是分数的实际来源）

| 配法 | 例（观点：明清商品经济发展未自动导向社会转型） |
|---|---|
| 正面支撑 | 江南丝织业出现"机户出资、机工出力"的雇佣关系 |
| 反向限定 | 但国家仍以重农抑商、闭关自守为基本政策，商业利润回流土地 |
| 对照参照 | 同期西欧的商业利润转向产业与海外贸易，形成不同的资本流向 |

**一条史实必须跟一句"所以"**。只写史实不作解释的段落，阅卷按"史实堆砌"给分，通常只拿到史实分，拿不到论证分。

## 五、评分量表（12 分制，四维三档）

| 维度 | 分值 | 3 档（满） | 2 档 | 1 档 |
|---|---|---|---|---|
| 观点 | 2 | 明确、可论证、与材料相关 | 有观点但空泛 | 无观点或抄材料 |
| 史实 | 6 | 两则以上、准确、与观点直接相关 | 有史实但关联弱 | 史实错误或空缺 |
| 论证 | 2 | 有"史实→观点"的解释链 | 有解释但不完整 | 只堆史实 |
| 结构 | 2 | 分段清晰、有回扣 | 有分段无回扣 | 一段到底 |

**自评动作：** 写完先数三样——观点句在第几行、史实有几条、有几个"因此／所以"。三个数字不达标，先别谈文采。

## 六、四种论证模型（详见 references）

| 模型 | 适用材料 | 一句话思路 |
|---|---|---|
| 纵向变迁 | 同一对象跨时段 | 抓转折点，说清"变在哪、为什么变" |
| 横向比较 | 两个地区／国家同期 | 找同一问题下的不同解法，别写"都很重视" |
| 多维解释 | 一个事件的多重原因 | 政治＋经济＋思想各一条，最后归到一条主线 |
| 质疑数据 | 统计表、户籍数、产量图 | 先问"这个数是怎么来的"，再给制度性原因 |

## 七、低分答案的四种典型

| 类型 | 表现 | 修法 |
|---|---|---|
| 抒情型 | "让我们铭记历史，砥砺前行" | 全删。论述题不看情感 |
| 复述型 | 把材料换句话再写一遍 | 加"这说明"，把复述变成判断 |
| 堆砌型 | 四条史实，无一句解释 | 每条后面加"这表明" |
| 跑题型 | 写成了另一道题的答案 | 回到设问圈动词 |

## 八、禁忌

- 不给整篇成文答案。给骨架、给句式、给史实位置，让学生自己填。
- 不鼓励背"万能素材"。同一段史实在不同观点下的用法完全不同，背素材会在考场上错配。
- 不评价文采。评分不看文采，把时间花在观点与史实对应上。
