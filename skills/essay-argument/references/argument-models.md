# 四种论证模型

用途：W4 第 6 步。**按材料形态选模型，不按题目字面选。** 模型选错，写得再工整也拿不到论证分。

## 模型一：纵向变迁

**适用：** 同一对象跨两个以上时段（如"中国古代选官制度""英国王权""中国经济重心"）。

**结构：**

```
观点：某对象在某一节点发生了性质变化，而非仅是程度变化
史实 1：变化前的状态（一个制度名 + 一句运作方式）
转折：什么事件／什么力量推动了变化
史实 2：变化后的状态（与变化前形成对照）
回扣：变化的关键变量是……
```

**要点：** 必须写清"变在哪一维"——是标准变了、主体变了，还是范围变了。只写"发生了变化"不得分。

**示例骨架：** 选官制度从察举到科举，变的是**标准**（德行为主 → 考试成绩为主）与**主导者**（地方长官 → 中央），而非仅"更公平了"。

## 模型二：横向比较

**适用：** 两个地区／国家在同一时期面对同一问题（如"中西封建社会的城市""中日近代化""英美政治制度"）。

**结构：**

```
观点：面对同一问题，两者选择了不同路径，差异源于……
方面 1（如政治）：A 的做法 ｜ B 的做法 ｜ 差异根源
方面 2（如经济）：A 的做法 ｜ B 的做法 ｜ 差异根源
回扣：差异不是程度差异，而是路径差异
```

**要点：** 比较不是"分别叙述"。每一行必须有"差异根源"这一格，否则就是两段介绍。

**易错：** 写成"两者都很重视""都取得了成就"。这类句子在比较题里是零分句。

## 模型三：多维解释

**适用：** 一个事件的原因或影响（如"鸦片战争的原因""工业革命的影响"）。

**结构：**

```
观点：某事件的主因在某一维度，其余维度是条件
维度 1（经济）：史实 + 如何构成根本原因
维度 2（政治）：史实 + 如何构成直接原因
维度 3（思想／外部）：史实 + 如何构成条件
回扣：三层不是并列，而是有主次
```

**要点：** 必须区分**根本原因／主要原因／直接原因**。三个原因平铺，是这一模型最常见的失败。

**判定：** 根本原因通常指向"生产力与生产关系的矛盾""制度的结构性缺陷"；直接原因通常是某个具体事件。如果学生把具体事件写成"根本原因"，先回 W2 补因果层级。

## 模型四：质疑数据

**适用：** 统计表、户籍数、产量图、人口曲线（近年开放题高频）。

**结构：**

```
第一步：指出数据本身的异常（增长过快／过慢／与常识冲突）
第二步：给出制度性解释（谁在统计、为什么这样统计、统计口径变没变）
第三步：说明这对结论的影响（因此不能直接用该数据说明……）
第四步（加分）：提出可以互证的其他材料
```

**示例骨架：** 明代某时期户籍户口数增长缓慢，可能不是人口停滞，而与**赋役按丁征收、隐匿人口**有关；因此该数据更适合用来说明赋役制度的影响，而非直接说明人口规模。

**要点：** 这一模型的分数几乎全在第二步。只说"数据可能不准"是 1 分答案，说出"为什么不准"才是满分解。

## 模型选择速查

| 材料长什么样 | 选哪个 |
|---|---|
| 一则材料讲一个对象的前后 | 纵向变迁 |
| 两则材料讲两个对象 | 横向比较 |
| 一则材料讲一个事件的多个侧面 | 多维解释 |
| 表格、曲线、柱状图 | 质疑数据 |
| 两幅图片／两张地图 | 横向比较（注意空间维度） |
| 一段引文加一句评论 | 观点论证（先判断引文立场） |

## 通用禁忌

1. **不要写"综上所述，历史告诉我们"**。这类结尾不加分。
2. **不要用第一人称抒情**。"我认为""我们应当"在论述题里是减分项（除题目明确要求"谈谈你的认识"）。
3. **不要超过规定字数太多**。写满格子外面通常不加分，还挤掉了检查时间。
