# 成本行清单：九层之外还有哪些钱

这张表用于两件事：一是搭账本时别漏项，二是跟用户对账时能快速指出"你说赚钱是因为漏了第几行"。

## 一、商品成本

| 项 | 说明 | 常见漏项 |
|---|---|---|
| 拿货价 | 含税/不含税要说清 | 含税与不含税差 6–13 个点，混用会让毛利完全错 |
| 头程/入仓 | 工厂到仓的运费与卸货 | 按箱报价没除件数 |
| 打样与模具 | 一次性投入 | 上新频繁的店，这一项摊到首批很容易被忽略 |
| 次品率 | 到仓质检不合格比例 | 3%–8% 常见；服装、陶瓷更高 |
| 包材 | 纸箱、气泡、贴纸、干燥剂 | 定制品起订量 5000 起，摊薄要用全生命周期 |

## 二、履约成本

| 项 | 说明 | 常见漏项 |
|---|---|---|
| 面单与运费 | 首重/续重、抛货计费重 | 体积重按 (长×宽×高)/6000 或 /8000，规则各快递不同 |
| 超区/偏远 | 新疆西藏、部分乡镇 | 一单能吃掉整单毛利 |
| 拦截与改址 | 发货后改地址 | 每单 3–8 元，旺季更高 |
| 仓租与操作费 | 按件或按托 | 一件代发没有这项，自营仓有 |

## 三、退货成本（最容易算错的一块）

退货不是"少卖一单"，是四笔钱同时发生：

1. **发货运费照付**（已经发出去了）
2. **回程运费**（除非买家承担，但拒收/揽收失败仍可能由商家付）
3. **货损**：拆封、试用、污损，能二次销售的比例往往只有 60%–85%
4. **时间成本**：退货入库、质检、重新上架，占用人工和库存

```bash
--refund 0.18 --return-ship 8 --return-handling 2 --restock 0.8
```

含义：18% 退货率，每退货单回程 8 元、处理 2 元，80% 可再卖，20% 按成本全损。

**敏感性直觉**：在毛利率 30% 的链接里，退货率从 10% 涨到 20%，单均贡献毛利通常掉 25%–40%。这就是为什么"退货率治理"比"多投广告"更赚钱。

## 四、平台与资金成本

| 项 | 说明 | 常见漏项 |
|---|---|---|
| 佣金 | 按类目，部分含技术服务费 | 活动期间临时费率 |
| 支付手续费 | 0.6% 起，分期/花呗类更高 | 大额订单分期占比高时明显 |
| 营销工具费 | 店铺装修、优惠券工具、数据工具 | 按月固定，计入固定费用更准 |
| 保证金与罚则 | 活动保证金、违规扣款 | 不进单均，但要进现金流 |
| 资金成本 | 账期与结算周期的差 | 见下 |

**资金成本算法**：现金占用天数 = 备货提前期 + 销售天数 + 平台结算周期 − 供应商账期。占用金额 × 天数 × 资金成本率（自有资金按机会成本，借贷按实际利率）。一个年化 8%、平均占用 45 天、占用 50 万的店，一年是 5 万——比很多店的净利润还高。

## 五、税费

- 小规模纳税人：按征收率，季度有免税额度
- 一般纳税人：13% / 9% / 6% 分档，可抵扣进项
- 平台代扣代缴与自行申报不同

**不要在账本里替用户决定税负**，只留一个参数位，让他填财务给的实际比例。填不出来就写"税费未计入，实际毛利低于此数"。

## 六、不同经营模式的差异

| 模式 | 要多算的 | 可以少算的 |
|---|---|---|
| 一件代发 | 供应商发货时效导致的退款、代发加价 | 仓租、自有库存资金占用 |
| 自营仓 | 仓租、操作费、库存资金占用、滞销 | — |
| 海外仓/跨境 | 头程、关税、目的国税费、退运成本 | — |
| 直播带货 | 达人佣金、坑位费、样品、退货率更高 | — |

## 七、对账时最常听到的三句话

| 用户说 | 通常意味着 |
|---|---|
| "我毛利率 50%" | 用拿货价算的，没扣运费和佣金 |
| "投产能打正" | 只看了广告 ROI，没看整体贡献毛利 |
| "这个链接是引流款，不赚钱正常" | 可能真的正常，但要算清它带来了多少利润款的连带销售，算不出来就是亏 |

## 八、账本可信度自检

交付前问自己四句：

1. 净成交额是按成交单还是发货单算的？
2. 退货成本是按"少卖"算的，还是按"四笔钱"算的？
3. 广告费是分摊的还是全算的？
4. 固定费用有没有被摊进单均？

四句里有任何一句答不上，账本就只能当参考，不能当决策依据。
