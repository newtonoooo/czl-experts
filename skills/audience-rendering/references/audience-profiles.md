# 受众写作档案

五类读者的信息需求、语言习惯、常见误写。

## 一、高管 / 业务负责人

**他们的问题**：要我做决定吗？要花多少钱？会不会出事？

**语言**：结论、数字、选项。不要过程，不要架构，不要"我们做了大量工作"。

**模板**

```
状态：绿 / 黄 / 红
结论：（一句话，含动作和范围）
需要你定：（一件事，含选项和截止时间）
支撑：（最多三条，每条带等级）
风险与应对：（一条，含触发条件）
下一步：（什么时候有什么产出）
```

**常见误写**

| 误写 | 问题 | 改法 |
|---|---|---|
| 汇报 12 条进展 | 没有重点 | 只留与目标相关的 3 条 |
| "预计""有望""争取" | 没有承诺 | 给范围或给检查点 |
| 把过程当成果 | "开了 6 次会"不是成果 | 只写结果和指标变化 |
| 风险写成"有一定挑战" | 等于没说 | 写具体风险和应对 |
| 没有"需要你定" | 这封更新白发了 | 至少一个具体请求 |

## 二、工程团队

**他们的问题**：我要做什么？哪里会卡？边界在哪？什么算做完？

**语言**：具体、可执行、带约束条件。可以用术语，不要用产品黑话（"赋能""闭环"）。

**模板**

```
背景：（为什么做，两句）
范围：（做什么 / 明确不做什么）
规则：（判断表，不是描述）
异常：（状态表）
验收：（AC → TC，异常路径占比）
依赖：（谁、承诺时间、未按期怎么办）
待定：（我还没想清楚的地方，需要你判断）
```

**常见误写**

| 误写 | 问题 | 改法 |
|---|---|---|
| "系统自动处理" | 没有规则 | 写判断条件和默认值 |
| "支持多种格式" | 没说是哪几种 | 列清单，不支持的写不支持 |
| 只写正常流 | 上线必出问题 | 空态/错态/超限态/并发都写 |
| 需求里带设计稿当规格 | 设计稿表达不了规则 | 规则写成表，设计稿放附件 |
| 什么都"可以商量" | 工程不敢决策 | 明确哪三处不能动 |

## 三、跨部门（销售、客服、市场、运营）

**他们的问题**：这事对我有什么影响？我要准备什么？什么时候？

**语言**：动作、时间、影响。不要技术细节。

**模板**

```
对你们有影响的三件事：
1. （什么变化）—（对你们的影响）—（你们要做什么，什么时候前）
需你们提供：（具体产出 + 截止时间 + 用途）
已定不变：（避免他们重复猜测）
有疑问找：（具体人）
```

**常见误写**

| 误写 | 问题 | 改法 |
|---|---|---|
| 发技术细节 | 他们不看，且会误传 | 换成"客户会看到什么" |
| 只说要上线，不说要他们做什么 | 上线后没人会用 | 明确动作和截止时间 |
| 承诺具体日期 | 延期后是他们面对客户 | 给范围，或给"延期我会第一时间告知" |
| 用产品内部代号 | 对外会说错 | 用客户能听懂的名字 |

## 四、客户 / 外部

**他们的问题**：我能多做什么？什么时候能用？有什么限制？

**语言**：能力、好处、限制、下一步。零内部术语。

**模板**

```
现在可以（做什么）。
（怎么用，两三步；或者一句"打开 X 页面即可"）
限制：（条数、时长、暂不支持什么）
已知问题：（如果客户会碰到，就写，附临时办法）
反馈：（怎么提）
```

**常见误写**

| 误写 | 问题 | 改法 |
|---|---|---|
| "全新升级""重磅上线" | 空话 | 直接说能做什么 |
| 隐藏限制 | 客户用到一半发现，信任受损 | 主动写清限制 |
| 给确切日期 | 延期就是失信 | "即将推出"或给季度 |
| 说"优化了底层架构" | 客户不关心，也听不懂 | 说体验上的变化 |

## 五、董事会 / 投资人

**他们的问题**：增长怎么样？风险在哪？钱花得对不对？

**语言**：指标、趋势、风险、判断。不超过 6 个数字。

**模板**

```
本期关键指标：3 个（本期值 / 上期 / 目标）
一句话判断：（好于 / 符合 / 差于预期，以及主要原因）
主要风险：（一个，含概率与影响）
下期重点：（两件事，可验证）
需要的支持：（如果有，具体）
```

**常见误写**

| 误写 | 问题 | 改法 |
|---|---|---|
| 只报好消息 | 一次坏消息会摧毁前面所有信任 | 好坏都报，坏的放前面 |
| 指标太多 | 记不住，等于没报 | 最多 6 个，选能反映本质的 |
| 用内部术语 | 听不懂 | 换成业务语言 |
| 预测给点值 | 一定打脸 | 给区间 + 关键假设 |

## 通用：同一事实的四种写法示例

事实：批量导出上线，但自定义字段没做。

**高管版**
> 批量导出 9/30 上线，自定义字段延到下季度——法务要求字段白名单先过审。需要你确认是否接受这个顺序。

**工程版**
> 导出已上线异步任务链路。自定义字段依赖权限服务的字段级鉴权，未就绪，本版按 9 个字段白名单实现。下版需要权限服务支持 per-field ACL。

**跨部门版**
> 客户可以批量导出了，字段是 9 个固定的。销售之前答应的"自选字段"这版没有，需要重新沟通时间。

**客户版**
> 现在可以批量导出 9 类常用字段。自选字段在计划中，上线后会通知你。

四份材料指向同一个事实，没有一份在粉饰，没有一份在夸大。这才是渲染。
