# czl-bio-teacher-kit · 高中生物教师工具包

三个脚本，只依赖 Python 3.8+ 标准库，不联网、不装包。教师机、学校机房、离线环境都能跑。

## 一、score_report.py — 成绩统计与题目质量

**什么时候用**：月考、单元测结束，要出班级统计、找失分板块。

**输入约定**

- CSV，UTF-8（带 BOM 也行），第一行表头。
- 第一列：学号（只用于计数，不出现在任何输出里）。
- 其余列：Q1、Q2…… 每题得分。
- 空单元格 = 缺失（不计入该题均值，不把学生总分记 0）；整行全空 = 缺考，单独计数。

**命令**

```bash
python score_report.py -i scores.csv -f 2,2,2,4,6,10 -o report.md \
    --sections 1-5:分离定律,6-10:自由组合 --title "高一(3)班 单元测"
```

参数说明：

| 参数 | 必填 | 说明 |
|---|---|---|
| `-i/--input` | 是 | 成绩 CSV |
| `-f/--full-marks` | 是 | 每题满分，逗号分隔，个数必须与题目列数一致 |
| `-o/--output` | 否 | Markdown 报告路径；不给则打印到屏幕 |
| `--sections` | 否 | 板块定义，`题号范围:板块名`，逗号分隔 |
| `--title` | 否 | 报告标题 |
| `--csv-out` | 否 | 另存题目统计 CSV |

**输出**：总体（均分/中位数/标准差/最高最低/分数段）、逐题（均分、得分率、难度、区分度、判定）、板块得分率、判读提示。

**判定口径**：得分率 <40% 塌方、40–60% 补漏、>60% 巩固；区分度 D = 高分组 27% 通过率 − 低分组 27% 通过率，D<0.2 提示题质待改。

**边界**：人数 <15 时区分度不稳定，报告会照常给数，但解读时要说明。

## 二、blueprint_check.py — 双向细目表校验

**什么时候用**：出卷前，确认细目表的分值、层级、难度、考点分布站得住。

**输入约定**：CSV，表头必须含 `题号,考点,认知层级,题型,分值,预估难度`（`核心素养` 可选）。认知层级取 `记忆/理解/应用/分析`，预估难度取 `易/中/难`。

**命令**

```bash
python blueprint_check.py -i blueprint.csv --total 100 --profile unit
python blueprint_check.py -i blueprint.csv --json
```

**四种用途预设**

| profile | 记忆 | 理解 | 应用 | 分析 | 难度 易/中/难 |
|---|---|---|---|---|---|
| unit（单元测） | 20% | 40% | 30% | 10% | 60/30/10 |
| monthly（月考） | 15% | 35% | 35% | 15% | 50/40/10 |
| drill（专项） | 10% | 30% | 40% | 20% | 40/40/20 |
| timed（限时） | 25% | 40% | 30% | 5% | 70/20/10 |

**判定**：分值不闭合、字段缺失、层级/难度取值非法、题号重复 → 错误（退出码 1）；层级偏差 >10 个百分点、难度偏差 >15 个百分点、单一考点 >35% → 警告。

## 三、make_docx.py — 打印版 docx

**什么时候用**：所有成品交付前（W8 交付打包）。

**命令**

```bash
python make_docx.py -i 教案.md -o 分离定律_教案_20261101.docx --title "分离定律 教案"
```

**版式**：A4 纵向、页边距 2.54cm、正文小四宋体、标题黑体、1.5 倍行距、首行缩进 2 字符、表格带框线、页脚页码。

**支持范围**：`#/##/###` 标题、段落、`-` 无序列表、`1.` 有序列表、Markdown 表格、`**加粗**`、`>` 引用、代码块。

**不支持**：图片嵌入、公式、脚注、多栏。需要图片时，在 Word 里手动插入，位置用 `【图：说明】` 标出。

## 四、组合用法

```
出卷：blueprint_check.py 过表 → 出题 → 交付
考后：score_report.py 出统计 → W6 写处方 → make_docx.py 出打印稿
```

## 五、常见问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 报"满分个数与题目列数不一致" | `-f` 少写/多写 | 数一遍题目列 |
| 中文乱码 | CSV 不是 UTF-8 | 用 Excel 另存为"CSV UTF-8" |
| 报"没有可用于统计的有效成绩行" | 全列空或分隔符不是逗号 | 检查分隔符，Excel 默认可能存成分号 |
| docx 打开提示损坏 | 极少见，多为磁盘写入中断 | 重新生成；仍失败则退回 Markdown |
| 表格太宽 | 列数过多 | 拆表，或改纵向排布 |
