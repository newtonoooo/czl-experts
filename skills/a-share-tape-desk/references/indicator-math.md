# 指标公式与计算口径

所有指标在 `atd/indicators.py` 里用纯 Python 实现，输入是前复权日线。
口径对齐国内行情软件，便于用户拿券商软件的数值对照。

## 为什么不用现成库

1. 装依赖会带来许可证与分发的额外问题；
2. 指标公式本身只有十几行，自己写反而更可控、可测；
3. 一旦厂商接口挂了，指标仍能算——它不依赖网络。

## 公式

**MA(n)**：最近 n 个收盘价算术平均。

**EMA(n)**：`EMA_t = C_t × 2/(n+1) + EMA_{t-1} × (1 - 2/(n+1))`，首值取第一期收盘价。

**MACD(12,26,9)**
```
DIF = EMA12 - EMA26
DEA = EMA9(DIF)
柱  = 2 × (DIF - DEA)        # 国内软件的"MACD柱"口径，带 2 倍系数
```

**KDJ(9,3,3)**
```
RSV = (C - LLV9) / (HHV9 - LLV9) × 100
K   = 2/3 × K_prev + 1/3 × RSV
D   = 2/3 × D_prev + 1/3 × K
J   = 3K - 2D
```
K、D 初值取 50（国内软件惯例）。`HHV9 == LLV9` 时 RSV 取 50，避免除零。

**RSI(6) / RSI(14)**：Wilder 平滑
```
RS  = 平均涨幅 / 平均跌幅
RSI = 100 - 100/(1+RS)
```
平均跌幅为 0 时 RSI 取 100。

**BOLL(20,2)**
```
MID = MA20
UP/DN = MID ± 2 × 总体标准差(20期)
```

**ATR(14)**：Wilder 平滑的真实波幅
```
TR = max(H-L, |H-C_prev|, |L-C_prev|)
ATR = 前值×(n-1)/n + TR/n
```

## 派生判定

| 字段 | 规则 |
|---|---|
| `ma_alignment` | MA5>MA10>MA20>MA60 = 多头排列；反向 = 空头排列；否则交织 |
| `vol_price` | 涨幅>1% 且量/5日均量>1.3 = 放量上涨；<0.8 = 缩量上涨；下跌同理 |
| 金叉/死叉 | 最近一根的前后两期快慢线穿越关系，两条线都要有值才判定 |
| `pivot_support/resistance` | 60 根内 3 根邻居的分形高低点，取距现价最近各 3 档 |

## 趋势评分（-100 ~ +100）

| 分项 | 满分 | 规则 |
|---|---|---|
| 均线排列 | ±40 | 多头 +40 / 短期多头 +22 / 交织 0 / 短期空头 −22 / 空头 −40 |
| 偏离 MA20 | ±20 | 0~8% 记 +20；>8% 记 +12（过热反而减分）；0~−8% 记 −12；<−8% 记 −20 |
| MACD | ±25 | 柱>0 +15 / <0 −15；零轴上方再 +10 / 下方 −10 |
| KDJ | ±15 | K>D +8；K>85 再 −6；K<15 再 +6 |

分档：≥45 偏强，≥15 偏多，>−15 中性，>−45 偏弱，否则偏空。

**注意**：这是"把多个指标压成一个数"的便利工具，不是预测模型。
它只回答"现在处于什么状态"，不回答"明天涨不涨"。
