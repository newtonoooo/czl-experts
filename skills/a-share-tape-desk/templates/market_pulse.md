# 模板：大盘情绪（W3）

适用：用户问"今天市场怎么样""情绪如何""该几成仓"。

```
## 大盘情绪 · {日期} {时间}（{阶段}）

**温度 {score}/100（{temperature}）｜风险 {risk_level}｜仓位上限 {max_position}%**

### 结构
| 项目 | 读数 |
|---|---|
| 上涨/下跌/平盘 | {up}/{down}/{flat} |
| 涨停/跌停 | {limit_up}/{limit_down} |
| 涨超5%/跌超5% | {up5}/{down5} |
| 中位涨幅 | {median}% |
| 两市成交额 | {amount} 亿（{vs 5日均额}） |
| 上证/深成/创业板 | ... |

### 分布
{涨跌分布，文字描述重心在哪一段，只写最厚的两段}

### 评分构成
{逐项：得分/权重 — 原始计数}

### 明天要验证的两件事
1. {如果 X 成立（如涨停家数回到 60 以上），则情绪可能修复}
2. {如果 Y 出现（如跌停家数继续增加），则继续防守}

### 这套环境适合什么打法
{温度 + 风险等级 → 一句话：适合/不适合做什么；给出仓位上限与理由}

数据：{source}，样本 {active} 只（停牌 {suspended} 只）｜{data_age}｜{disclaimer}
```

要点：
- 温度分与仓位上限直接引用脚本输出，不要自己"综合判断"出一个新数字。
- 结构比结论重要：把涨跌家数、涨停跌停这些"可核对的计数"放在最前面。
- 不许写"明天大概率上涨"。写"如果出现 X，则 Y 的概率上升"。
