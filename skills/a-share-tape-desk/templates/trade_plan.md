# 模板：交易计划（W5）

适用：用户给出资金，问"怎么买""止损放哪""买多少"。

```
## 交易计划 · {名称}（{代码}）· {日期}

### 前提（先讲清楚假设，再讲数字）
- 现价 {price}（{pct}），ATR14 {atr}（占股价 {atr_pct}%）
- 你会用到：总资金 {capital} 元，单笔风险 {risk}%，仓位上限 {max_pos}%
- 数据性质：{实时/定格/上一交易日收盘}

### 计划
| 项目 | 数值 | 依据 |
|---|---|---|
| 入场区间 | {entry_lo} – {entry_hi} | {回踩位/突破位/当前价} |
| 止损 | {stop}（{stop_pct}%） | {ATR倍数 / 结构位 / 用户指定} |
| 可买股数 | {shares} 股 | 约束项：{单笔风险预算 / 仓位上限} |
| 占用资金 | {position_value}（{position_pct}%） | |
| 触发止损亏损 | {actual_risk}（{risk_pct}%） | |
| 第一目标 | {t1}（{gain}%） | 1.5R，减仓 1/3 |
| 第二目标 | {t2}（{gain}%） | 2.5R，再减 1/3 |
| 第三目标 | {t3}（{gain}%） | 4.0R，剩余跟踪 |

### 触发条件（三个都要成立才做）
1. {价格条件：放量站上 X / 回踩不破 Y 并收出阳线}
2. {量能条件：成交额 ≥ 近5日均额的 1.2 倍}
3. {环境条件：大盘温度不低于 40 / 板块不处于跌幅前五}

### 什么情况下放弃
- 跌破 {stop} 且当日无法收回 → 第二天开盘处理（T+1 限制）
- 开盘跳空低开超过 {x}% → 止损价失效，按实际价格重新计算
- {涨停板排队成交概率低 / 停牌 / 重大事项}

### 这笔交易的真实风险
{用 2–3 句话讲清：亏多少、亏多久、什么情况下会超出预算}

### 仓位与组合
- 本笔占 {position_pct}%，加上现有持仓后的总风险敞口 {portfolio_risk}%
- 若总敞口 > 6%，说明押在同一逻辑上，建议降规模

数据：{source}｜{disclaimer}
```

要点：
- 所有数字来自 `plan` 命令输出，**不许手算**。
- 股数为 0 时，必须给出"最小可行规模"（1 手成本、1 手亏损、是否超预算、怎么调整）。
- 止损、目标价都要有依据（ATR 倍数 / 结构位 / 前高前低），不能是"感觉"。
- A 股 T+1：当日买入当天不能卖，止损只能次日执行，要主动提醒。
