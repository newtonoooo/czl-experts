# 这里的文件是什么

这两个 JSON 是 `topic_score.py` 的**回归样本**，只用于跑测试，不是产品模板，也不是选题示例。

| 文件 | 用途 | 当前基线 |
|---|---|---|
| `topics_demo.json` | 反例：5 个选题里有 2 个是同一件事的两种说法 | 相似度 0.45 判重，脚本应 exit 1 |
| `topics_clean.json` | 正例：5 个角度各不相同 | 无重复，脚本应 exit 0 |

## 题材为什么是升学的

查重阈值（bigram 相似度 ≥0.45 判重）是在这批文本上调出来的。换题目就要重新标定，
容易把"能抓出重复、又不误杀"这个已经验证过的区分度弄丢，所以保留原样。

## 这不代表产品预设了领域

本专家不预设任何行业、地区或读者类型。选题技能的使用前提是**使用者先给出账号方向**，
Agent 里写死了"没有任何默认值"。这里出现的题材只是测试数据。
