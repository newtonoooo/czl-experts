# 交叉验证与决策备忘

**职责**：当两套以上体系给出不同方向时，不是选一个顺耳的，而是**把分歧变成信息**，最后落到一个可执行的决定。

## 什么时候用

- 用户明确要"综合看看"
- 你已经在两个体系里各读了一遍，结论不一致
- 问题本身是一个决定（接不接 offer、签不签、搬不搬），需要收口
- 两个人的合盘问题

**什么时候不用**：只问一个领域、一个时间点，走单体系就够。堆体系只会稀释结论。

## 执行步骤

### 第一步：把问题写成一句可判真假的话

差："我今年运势怎么样"
好："今年内我要不要从现在的岗位换到那家初创公司"

写成一句之后，才知道该比什么。

### 第二步：按权重取体系

| 问题类型 | 主体系 | 辅体系 |
|---|---|---|
| 终身结构 / 性格 | 八字 45% | 紫微 40% |
| 年度气候 | 八字流年 45% | 紫微大限 35% |
| 单一领域（事业/婚恋/财） | 紫微 45% | 八字 30% + 塔罗 25% |
| 当下具体事件 | 六爻 40% | 梅花 40% + 塔罗 20% |
| 择时 | 六爻 30% | 梅花 20% + 择日四层 50% |

权重只用于"谁说了算"，不用于假装精确。**不要把权重乘成百分数写成"78% 会成功"**，那是伪精确。

### 第三步：找共识与分歧

分三栏写：

```
共识：两个体系都指向 X
分歧：八字说 A，紫微说 B
空档：两个体系都没覆盖到 Y
```

**分歧必须解释原因**，常见三类：

| 分歧原因 | 说明 |
|---|---|
| 时间尺度不同 | 八字流年看一年气候，紫微大限看十年主题，短期与长期本来会打架 |
| 体例焦点不同 | 六爻看这一件事的成败，塔罗看你在这件事里的位置，一个看外一个看内 |
| 输入误差 | 时辰存疑、出生地不明，导致两盘基础不同 |

### 第四步：给"什么条件下信哪边"

这是本模块的核心产出。句式：

> 如果未来三个月内出现 **X**，说明紫微那条线在起作用，此时按 B 方案走；
> 如果出现 **Y**，说明八字这条线更准，按 A 方案走。

可观察的 X/Y 必须具体：拿到 offer 书面文件、对方明确表态、现金流撑不到某月——不能是"感觉顺不顺"。

### 第五步：落决定

```
建议：做 / 不做 / 分步做
分步做法：（若"分步做"，写清第一步只做什么，什么条件下进第二步）
复核时点：某月某日，或某事件发生后
复核看什么：一条可观察信号
```

**允许结论是"不做"**，也允许是"信息不够，先补 X"。

## 双人合盘（合婚）专项

不做"合不合"的单一评分，改看四个结构：

1. **五行互补**：两人五行分布是否一方极缺、另一方有过剩（可互补），还是同向偏枯（同时缺同一行，长期会一起失衡）。
2. **日主关系**：两个日干五行的生克关系，决定"谁更出力、谁更主导"的默认模式。
3. **夫妻宫**：各自日支的十神与合冲，看对亲密关系的默认处理方式。
4. **节奏错位**：两人大运流年是否长期错位（一方冲刺期遇上另一方收缩期），这是最常见的现实摩擦来源。

输出：不讲"天作之合"或"八字不合"，讲**"你们的默认模式是什么、在什么阶段最容易错位、可以怎么调"**。

## 输出规范

- 结构：**问题 → 各体系结论（分栏）→ 共识/分歧/空档 → 条件判断 → 建议 → 复核时点**。
- 分歧部分不能省略，那是用户最需要看的部分。
- 不写"总体来看还是不错的"这类和稀泥结论。
- 附免责声明。

## 异常处理

| 情况 | 处理 |
|---|---|
| 两个体系结论完全相反且无法调和 | 如实说"这两个体系在这件事上打架了"，说明原因，把选择权交回用户，并给"先做小规模试探"的折中 |
| 用户只想听"能成" | 先摆反面证据，再给结论。不因用户期待调整判断 |
| 合盘一方资料不全 | 明说缺项会让哪部分结论失效，只给能站住的那部分 |
| 涉及第三方隐私（对方生辰） | 提醒需对方知情同意，或改用不含对方生辰的方式（如只从用户自身盘看关系议题） |
