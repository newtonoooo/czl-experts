# W5 图表专项

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 图表专项（czl-bio-chart） |
| **任务职责** | 把图/表读成可用信息：分清轴与单位，找到对照，定位关键点，写出带条件的趋势句。不重讲知识点，只训练"看图取信息"这一步。 |
| **输入参数** | 必填：图表（照片要能看清轴标与刻度）或原始数据；题目问什么。建议：图例说明、单位、学生已写的答案。 |
| **执行步骤** | ①判图型（曲线/柱状/表格/示意/装片） → ②读两轴：名称、单位、起点是否为零 → ③找对照：哪条是空白、哪条是条件组 → ④定关键点：起点、拐点、交点、极值、与轴交点 → ⑤分段说趋势（先……后……） → ⑥写结论句（带条件与范围） |
| **判断条件** | 双曲线或多因素 → 先各自读完，再比差异；柱状图有误差线 → 先看重叠程度再谈差异；表格数据多 → 先排序找极值再分组；只有结论没有数据 → 先要数据，不猜 |
| **输出格式** | 读图单（四问四答）+ 数据提取表（关键点数值）+ 一句结论（含条件）+ 一道同类图题 |
| **异常处理** | 图模糊看不清刻度 → 指出具体位置请重拍，不推测数值；图中出现教材未涉及的新概念 → 只讲读图方法，不展开概念；学生要求"直接告诉我这题选什么" → 给读图步骤，让他自己选 |
| **必要依赖** | `references/graph-reading-checklist.md`（逐步清单与陷阱）、`references/chart-question-bank.md`（原创题组与解析） |
| **与其他工作流的关系** | 上游：W2（若过程本身不清，先修链再看图，否则读出来也用不上）。下游：实验结果分析接 W4；错题进 W6。系谱图不在这里，走 W3。 |

## 一、四问读图（每一问都要有答案，答不出就停在那一步）

| 问 | 看什么 | 答不出的后果 |
|---|---|---|
| ① 轴是什么 | 横轴代表自变量，纵轴代表因变量；单位是 /h 还是总量 | 把"速率"当"总量"，全题错 |
| ② 对照是哪条 | 哪条线是空白对照，哪条是实验组 | 不知道跟谁比，结论无从谈起 |
| ③ 关键点在哪 | 起点、拐点、交点、最高/最低点、与横轴的交点 | 把最高点当拐点，答"一直增大" |
| ④ 分几段 | 上升段、平台段、下降段，各段的限制因素不同 | 结论写成"一直上升"，漏掉平台期 |

**四问的顺序不能换。** 先看轴，再找对照，再看点，最后分段——这个顺序就是阅卷老师找采分点的顺序。

## 二、六类图各看什么

| 图型 | 第一眼 | 第二眼 | 常见考法 |
|---|---|---|---|
| 坐标曲线 | 两轴与单位 | 拐点与平台段 | 限制因素、最适条件 |
| 柱状图 | 各组高度差 | 有没有误差线、是否重叠 | 差异是否显著、能否下结论 |
| 表格 | 行列表头 | 极值与排序 | 比较、排序、算比值 |
| 过程示意图 | 箭头方向 | 每个箭头的条件 | 补全环节、判断阻断点 |
| 显微照片/装片 | 结构特征 | 处于哪个时期 | 细胞分裂时期判断 |
| 电泳图 | 条带位置 | 一条带还是两条带 | 纯合/杂合、基因型判断 |

## 三、关键点的生物学含义（这是拿分的地方）

| 关键点 | 含义 | 怎么用 |
|---|---|---|
| 起点（与纵轴交点） | 自变量为零时的基线 | 判断"没有处理时"的本底值 |
| 与横轴交点 | 净效应为零 | 如净光合为零 → 光合 = 呼吸 |
| 拐点 | 限制因素换了一个 | "此处之后，限制因素变为……" |
| 平台段 | 该因素不再是限制因素 | 答"受……限制"的标准位置 |
| 交点（两条线相交） | 两个处理在此条件下效果相同 | 比较题的核心 |
| 极值 | 最适条件 | 求最适温度/浓度/光照 |
| 曲线下面积 | 一段时间内的累积量 | 速率图转总量时用 |

**一句话**：图上每个"弯"都是一个采分点。直线没有弯，说明这段里没有因素变化。

## 四、双曲线与多因素图

三步走，顺序不能乱：

1. **各自读完**：先只看一条线，说出它的趋势与拐点。
2. **再比差异**：两条线在同一横坐标下差多少，差在哪个区间。
3. **归因**：差异由哪个条件造成（温度、浓度、光照、品种）。

**最容易错的地方**：两条线一升一降时，学生按"都升高"答。看到一升一降，先在图上标箭头，再动笔。

## 五、结论句模板

```
在【横轴条件】范围内，随【横轴变量】增大，【纵轴变量】先【升/降】后【平/降】，
在【关键点数值】处达到【最大/最小】；
超过该点后，【限制因素】成为主要限制。
```

不合格："由图可知，光合速率随光照强度增大而增大。"（漏了平台段）
合格："在光强低于光饱和点的范围内，随光强增大光合速率增大；超过光饱和点后不再增大，此时限制因素为 CO₂ 浓度等。"

## 六、五种读图失误（对号入座）

| 失误 | 表现 | 一句话纠正 |
|---|---|---|
| 单位看错 | 把 mg/h 当 mg | 先读单位，再读数字 |
| 起点忽略 | 不看纵轴起点是不是零 | 起点不是零，比例会骗人 |
| 拐点错位 | 把最高点当拐点 | 弯的地方才是拐点，顶点不是 |
| 对照丢失 | 只说实验组 | 没有对照就没有结论 |
| 趋势说半句 | 只说"升高" | 分段说：先……后…… |

## 七、收口

读完一张图，让学生用一句话复述："这张图告诉我，在什么条件下，什么随什么怎么变，到哪儿为止。"说得出，这张图才算读完。
