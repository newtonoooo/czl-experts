# 版式炸弹目录

按"会不会让内容丢失"排序。A 闸门的问题不是审美问题，是数据丢失问题。

## 一级：内容会丢

| 炸弹 | 为什么会丢 | 现象 | 换法 |
|---|---|---|---|
| 图片里的文字 | 解析器不做 OCR | 头像、公司 logo、技能进度条、扫描版简历 | 全部改成文本；技能写清单不画条 |
| 文本框 / 形状 | Word 文本框内容常被整体丢弃 | 用文本框排的侧栏、姓名栏 | 改普通段落 |
| 表格嵌套 | 单元格被拆成碎片，顺序错乱 | 左右分栏用表格做 | 改单列，合并成一行 |
| 页眉页脚 | 多数解析器跳过或重复插入 | 姓名放页眉、页码放页脚 | 姓名放正文第一行 |
| 分栏（报纸式） | 按视觉顺序读，左右列会被交错拼接 | 双栏模板 | 改单栏 |

## 二级：字段会归错

| 炸弹 | 后果 | 换法 |
|---|---|---|
| 自造章节名（"我的这些年""关于我"） | 内容落到"其他"字段，检索不到 | 用标准词：工作经历／教育背景／专业技能 |
| 日期写法混用（2021.03 与 2021年3月 并存） | 起止时间解析失败 | 全文统一 `YYYY.MM` |
| 公司名与职位写在同一行且无分隔 | 字段错位，公司名可能被识别成职位 | 用 `公司 ｜ 职位 ｜ 时间` 三段式 |
| 全角字符混排（２０２１．０３） | 数字识别失败 | 数字与符号用半角 |
| 项目符号用装饰图标（★ ◆ ➤） | 部分解析器不识别为列表 | 用 `-` 或 `•` |

## 三级：不影响解析，影响阅读

| 问题 | 影响 | 建议 |
|---|---|---|
| 正文超过 11pt 或行距过松 | 一页塞不下，被迫两页 | 10.5pt，行距 1.4-1.6 |
| 用彩色底纹分区 | 打印成灰块，显得杂 | 最多一条细分割线 |
| 技能用进度条 / 星级 | 无标准，反而暴露自评 | 写具体工具＋熟练度事实（几年、几个项目） |
| 照片 | 中文简历可放，外企/英文简历不放 | 按投递市场决定；照片不得承载任何文字信息 |
| 超过两页 | 三年以内经验超过一页就是冗余 | 三年以内一页，五年以上最多两页 |

## 自查方法（30 秒）

1. 把简历复制到一个纯文本编辑器（记事本）里粘贴。
2. 看顺序对不对、有没有大段内容消失、公司职位时间是否还能对上。
3. 顺序乱了或内容少了，就是 A 闸门失败，先修版式再改文字。

这一步比任何"ATS 检测工具"都准，因为它用的就是解析器同款的纯文本提取。
