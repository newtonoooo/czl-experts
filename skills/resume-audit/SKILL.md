# 三闸门体检（resume-audit）

## 这个技能解决什么

"帮我看看简历"这句话背后有个错误前提：以为简历是被"读"的。实际不是。它先被机器拆成字段，再被人用六秒扫一遍，最后在面试里被逐条追问。三关的失败原因完全不同，用一句"整体不错，可以再突出亮点"回应，等于什么都没说。

这个技能把三关拆开，分别判死刑还是放行。

## 什么时候用

- 用户问"这份简历能不能过""为什么投了没回音"
- 用户要在改之前先知道问题在哪（改之前必须做，否则改错地方）
- 用户拿到一份别人的简历要评估
- 改完之后复检，对比分数变化

## 三闸门

| 闸门 | 谁在看 | 看什么 | 分值 | 失败长什么样 |
|---|---|---|---|---|
| A 机器解析 | 招聘系统 | 能不能正确提取字段 | 30 | 邮箱抓不到、章节归错、日期丢了 |
| B 六秒扫描 | 招聘方人眼 | 六秒内能不能抓到重点 | 40 | 全是职责没有结果，看完不知道这人什么水平 |
| C 追问耐受 | 面试官 | 每条要点经不经得起问 | 30 | 数字没口径、职责边界不清、形容词撑不住 |

总分 100。**分值的作用是排序问题，不是给简历打分。** 不要给用户"你现在 58 分，改完 88 分"这种伪精确的承诺——第二次评分是你自己打的，分差没有客观意义。可以说"致命项从 3 条降到 0 条"。

## 执行步骤

### 第 1 步：先跑脚本，拿到机械指标

```bash
python skills/resume-audit/scripts/resume_audit.py <简历文件> [--jd <JD文件>] [--json]
```

脚本产出：联系方式可解析性、章节标题、日期格式一致性、版式炸弹（表格/图片/制表符/空格分栏/页眉页脚）、要点数量与长度、量化率、动作动词开头率、空泛词命中、重复开头。

脚本只算能算的。**它算不出"这段经历值不值钱"**，那是你的事。

### 第 2 步：人工判三件事

脚本给不了的三件事，必须自己判，并且写明依据：

1. **经历层级对不对。** 投的是专员岗，简历里全是"统筹公司战略"，这叫层级错位，会被判为不实。投的是负责人岗，简历里全是执行细节，这叫降级陈述。
2. **重点在哪一行。** 六秒扫描时人眼落在页面中上部。如果最强的一条成果在第二页，等于没有。
3. **每条要点能不能被追问。** 逐条自问三句话：这个数字怎么算的？这件事你负责哪一段？换个人做会不会一样？三问里有一问答不上来，这条要点就是 C 闸门的洞。

### 第 3 步：按严重度排序，不按闸门顺序

输出顺序永远是最致命的在最前：

- **致命（BLOCKER）**：不改就一定被筛掉。联系方式缺失、零量化、要点全是职责。
- **重要（MAJOR）**：明显减分。表格排版、弱动词开头、章节自造名。
- **次要（MINOR）**：影响观感。日期格式混用、自我评价过长、个别空泛词。

**一次最多给 6 条。** 给 20 条等于没给，用户改不动。

### 第 4 步：每条给证据和改法

格式固定：

```
[致命] 闸门B · 几乎没有量化
证据：12 条要点里只有 1 条带数字（第 2 段第 3 条）。
改法：每条至少补一个数——规模（多少人/多少单）、周期（多久）、
      结果（提升多少/省了多少）。补不上就删掉这条，别用形容词凑。
```

"证据"必须能指回原文，不能是"感觉比较空"。

### 第 5 步：给结论和下一步

结论只有四档，不要自由发挥：

- 90-100：直接投。指出 1-2 个可优化点即可，不要为了显得有用而硬找问题。
- 75-89：小修后可投。列出要修的 2-3 处。
- 60-74：要点必须重写。此时不要谈排版和格式，先改内容。
- 60 以下：骨架重建。建议放弃原结构，重搭章节，再填内容。

## 判断条件（分支）

- **用户只贴了正文没给文件**：先落到工作目录的临时 md（文件名带日期），再跑脚本，并告诉用户路径。
- **用户给的是 PDF / 图片**：图片简历本身就是 A 闸门失败（文字提取不出来），要直接指出，并建议先转成文本再评。
- **用户给的是英文简历**：启用英文检查项——无照片无生日、过去时、动词开头、无第一人称、拼写。脚本对英文的动词识别有限，需人工补充。
- **简历长度超过 10000 字符**：先让用户精简到两页以内再评；超长简历本身是 B 闸门问题。

## 输出格式

按 `templates/audit-report.md` 的骨架输出。必须包含：一句话结论 / 三闸门分数与依据 / 问题清单（≤6 条，带证据和改法）/ 脚本未能判断的部分 / 下一步。

## 异常处理

- 脚本报错或读不到文件：不要假装有分数。改成纯人工评估，并在报告顶部写"本次未跑机械检测，仅人工判断"。
- 简历是纯图片：明确告知无法评估内容，只能评版式，并给出转文本的方法。
- 用户只要一个分数：给分数，但同时给一句"这个分数只代表机械指标，别拿它当结论"，并追问要不要具体清单。

## 依赖

- `scripts/resume_audit.py`（Python 3.8+，仅标准库）
- `references/rubric.md`（评分细则，判定时对照）
- `references/hazard-catalog.md`（版式炸弹目录）
- `templates/audit-report.md`（报告骨架）
- `samples/` 内两版样例，可用于演示和回归测试

## 与其他技能的关系

体检是入口。体检结论决定后面走哪条路：B 闸门问题 → `resume-rewrite`；有 JD 且覆盖率低 → `jd-tailor`；内容没问题只想交付 → `resume-export`。改完回到本技能复检，对比致命项数量，不要对比分数。
