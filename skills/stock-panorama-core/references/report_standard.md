# 报告标准

## 一、七节结构（标准诊断）

引擎渲染的就是这个结构，模型改写时不要增删章节，可以补充段落。

| 节 | 内容 | 不允许出现的写法 |
|---|---|---|
| 报告头 | 标的、行业、数据截止、报告期、复权、置信度、覆盖率、总分 | 缺项留空不写 |
| 一、结论摘要 | 总分与档位、最强/最弱维度、方法局限 | "后市可期""建议关注" |
| 二、六维评分 | 维度总表 + 每维分项表（数值、得分、权重、口径提示） | 只给总分不给分项 |
| 三、关键价位 | 支撑/压力/ATR 风险位/区间位置 | "目标价""第一目标" |
| 四、同业对标 | 3 家以上对比表 | 样本不足仍排名 |
| 五、多空证据 | 引擎反推的高分项与低分项 + 一条反驳与回应 | 只有利多 |
| 六、事件与治理 | 公告事件表、质押、审计意见 | 把传闻写成事实 |
| 七、数据体检 | 覆盖率、时效、归一化记录、风险提示、待确认项 | 省略缺失项 |

## 二、速览结构（用户只要一句话时）

```
结论：<档位> — <一句话定位>
三条支撑：<数据> / <数据> / <数据>
三条风险：<数据> / <数据> / <数据>
置信度：<高/中/低>（缺 <字段> 时下调）
```

速览也必须带置信度和免责声明，只是压到最后一行。

## 三、语气

- 用陈述句给事实，用条件句给判断。
  - 好："资产负债率 72%，利息保障倍数 1.8 倍，安全垫很薄。"
  - 差："公司财务稳健，具备较强抗风险能力。"
- 允许说"不知道"。数据缺失时写"未取到"，这比编一个行业均值专业。
- 允许说"这条结论不成立"。例如亏损股的估值结论，直接写"PE 无经济含义，本维度不评分"。
- 不用感叹号，不用"重磅/炸裂/王炸"这类词。

## 四、多标的对比

1. 每只先各自出六维分（同一套阈值），再做矩阵；
2. 矩阵只比较同口径字段，缺的格子留空不填 0；
3. 结论写成相对优势："A 的估值分高于 B 12 分，主要差在 PE 分位"，而不是"A 比 B 好"；
4. 超过 5 只时，先给排序表，再挑 2–3 只展开，不要每只都写全报告。

> 本报告由本地规则引擎生成，取数来自所标注的数据源，评分为机械推导。内容仅供研究参考，不构成投资建议，不承诺任何收益。市场有风险，决策需自负。
