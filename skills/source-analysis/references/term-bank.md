# 术语替换表

用途：W3 第 4 步"转化"。学生答案"看着对但不得分"，九成是因为写的是口语，不是学科术语。

## 使用方式

不要让学生背整张表。**每次批改只挑他这次用错的两到三条**，改完立刻让他重写那句话。

## 一、政治类

| 口语 | 术语 |
|---|---|
| 皇帝一个人说了算 | 君主专制强化 |
| 地方听中央的 | 中央集权加强 |
| 官员不能世袭了 | 官僚政治取代贵族政治 |
| 当官要靠考试 | 科举制成为主要选官方式 |
| 把权力分给几个人 | 分散相权，削弱相权 |
| 皇帝派人盯着地方 | 加强对地方的监察 |
| 换了个朝代但制度照旧 | 制度的延续与继承 |
| 少数民族自己管自己 | 因俗而治／民族区域自治 |

## 二、经济类

| 口语 | 术语 |
|---|---|
| 不让随便做生意 | 重农抑商／海禁 |
| 交税按人头 | 以人丁为主要征税标准 |
| 交税按家里有多少地 | 以资产为主要征税标准 |
| 用银子交税 | 赋役折银／白银货币化 |
| 种的东西拿去卖 | 农产品商品化 |
| 给地主打工 | 租佃关系 |
| 老板雇人干活给工钱 | 雇佣关系／资本主义萌芽（明清语境） |
| 外国货进来了，本地手工业垮了 | 外国商品倾销，传统手工业破产 |

## 三、思想文化类

| 口语 | 术语 |
|---|---|
| 大家思想放开了 | 思想解放 |
| 用老一套解释新问题 | 托古改制／借复古求解放 |
| 官方只认一种学说 | 思想大一统／确立正统地位 |
| 三种思想互相吸收 | 三教合一 |
| 读书人只会写八股 | 八股取士束缚思想 |
| 文化传到外国去了 | 文化外传／文化辐射 |

## 四、对外与民族类

| 口语 | 术语 |
|---|---|
| 跟外国做生意 | 朝贡贸易／互市 |
| 关起门来不跟外面来往 | 闭关自守 |
| 被别人欺负，签了不平等条约 | 主权丧失，沦为半殖民地 |
| 把土地割给别人 | 割地，领土主权受损 |
| 周边民族来朝见 | 朝贡体系 |
| 民族之间互相学习生活 | 民族交融 |

## 五、世界史类

| 口语 | 术语 |
|---|---|
| 大家都想赚钱，国家抢殖民地 | 重商主义／殖民扩张 |
| 机器的时代来了 | 工业革命，机器生产取代手工劳动 |
| 钱不值钱了 | 价格革命，货币贬值 |
| 世界连成一片 | 世界市场形成／全球联系建立 |
| 国家管经济 | 国家干预经济 |
| 两个大国互相不打架但对着干 | 冷战对峙 |
| 小国联合起来 | 区域集团化 |

## 六、评价类句式（写"影响"时必须成对出现）

| 只写一半（常见） | 补上另一半 |
|---|---|
| 加强了中央集权 | 但地方自主性受限，行政效率下降 |
| 促进了商品经济发展 | 但加剧了土地兼并与社会分化 |
| 推动了思想解放 | 但局限于少数知识分子，未触及制度 |
| 提高了国际地位 | 但代价是巨大的人力物力消耗 |
| 打击了封建势力 | 但保留大量封建残余（如明治维新） |

**规则：** 凡设问含"评价""影响""意义"，答案里至少要有一处"但"。没有转折的答案，最多一半分。

## 七、三个不能用的词

| 词 | 问题 |
|---|---|
| 促进了发展 | 万能词，等于没说。必须写"促进了什么的发展" |
| 加强了统治 | 同上。必须写"加强了哪一层对哪一层的控制" |
| 意义重大／影响深远 | 空评价，阅卷不给分 |
