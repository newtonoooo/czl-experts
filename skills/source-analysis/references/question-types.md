# 设问类型与答题动词

用途：W3 第 1 步拆设问时对照。**动词不同，答法完全不同**，这是"答偏"的第一来源。

## 一、八个高频动词

| 动词 | 真正在要什么 | 答案长什么样 | 常见误答 |
|---|---|---|---|
| 概括 | 把具体信息压缩成上位概念 | 短句 + 术语，一点一句 | 照抄原文；写成一段叙述 |
| 指出 | 直接说出某信息 | 一个词或一句话，不用解释 | 展开论证，浪费时间 |
| 分析 | 给因果链或多维解释 | "因为…所以…"或"从…看…" | 只罗列事实，不给关系 |
| 说明 | 用材料证明某个结论 | 结论 + 材料依据 | 只给结论，不给依据 |
| 评价 | 性质 + 作用 + 局限 | 三层，必须含局限 | 只讲积极意义 |
| 比较 | 同与异，分维度 | 表格化：相同点／不同点 | 分别叙述，不说异同 |
| 简析 | 简要分析，一点因果即可 | 两到三句 | 写成大段 |
| 谈谈认识 | 观点 + 史实 + 现实指向 | 见 W4 结构 | 抒情、喊口号 |

## 二、设问里的"来源限定"

| 表述 | 含义 | 违规后果 |
|---|---|---|
| 根据材料回答 | 答案必须在材料里 | 只写教材知识＝0 分 |
| 结合所学知识回答 | 必须用材料之外的知识 | 只抄材料＝最多一半分 |
| 根据材料并结合所学 | 两者都要 | 缺一边扣一半 |
| 综合上述材料 | 要看全部材料，不只第一则 | 只看一则＝要点不全 |
| 上述材料对我们有何启示 | 从材料推一般规律，可跨时空 | 复述材料＝不给分 |

## 三、分值对应点数（速查）

| 分值 | 点数 | 备注 |
|---|---|---|
| 2 分 | 1 点 | 一个术语即可 |
| 4 分 | 2 点 | 每点 2 分 |
| 6 分 | 3 点 | 概括题最常见的分值 |
| 8 分 | 4 点 | 分析题常见，建议按维度各一点 |
| 10 分 | 5 点 | 必须标号 |
| 12 分以上 | 5—6 点 + 一句总结 | 总结句单独占分时不能省 |

## 四、多问设问的处理

见到"（1）（2）"必须分开写，中间空一行。混写会被按一问判。

常见组合与应对：

| 组合 | 应对 |
|---|---|
| 概括 + 分析原因 | 第一问答"是什么"，第二问答"为什么"，第二问不得重复第一问内容 |
| 指出变化 + 说明影响 | 变化要写"从…到…"，影响要分积极与局限 |
| 比较异同 + 分析原因 | 先列表，再解释差异来源 |
| 提取信息 + 加以说明 | 信息一句，说明两句（依据＋结论） |

## 五、题干里的"陷阱词"

| 词 | 陷阱 |
|---|---|
| "分别" | 必须分清对象，混答不得分 |
| "各" | 同上，且通常要求一一对应 |
| "变化" | 要写前后对比，只写"变化很大"无效 |
| "趋势" | 要写方向（上升／下降／集中／分散），不是状态 |
| "特点" | 要写"与别人不一样的地方"，不是内容罗列 |
| "实质" | 要写阶级或制度层面的本质，不是现象 |
| "根本" | 只能有一个，给了两个等于没给 |
| "评价" | 必须含局限，只有正面最多一半分 |
