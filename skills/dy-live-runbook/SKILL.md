# 直播排品与场控台本

## 什么时候用

- 要开一场直播，需要货盘顺序和节奏表。
- 播过几场，数据不好看：人均停留短、进来就走、成交集中在某一款。
- 要写话术，但不想念得像电视购物。
- 想知道"这场卖多少才不亏"。

## 必填输入

| 项 | 为什么要 | 缺了怎么办 |
|---|---|---|
| 类目与货盘（每款的拿货价、售价、库存） | 决定排品顺序和利润结构 | 只有售价没有成本 → 只能排节奏，不能算保本，必须说明 |
| 客单价、毛利率、退款率 | 算保本 GPM | 退款率不知道就用类目常见区间并标注"假设值" |
| 单场固定成本（人力/场地/赠品/样品） | 算保本 GMV | 不知道就先按 0 算，并提示"这是不含固定成本的乐观口径" |
| 时长与时段 | 决定节奏环个数 | 默认 2 小时，说明理由 |
| 账号阶段 | 新号和老号的排品逻辑不同 | 必须问：开播过几场、场观大概多少 |

## 先算保本，再排品

顺序不能反。先跑：

```bash
python3 ${SKILL_DIR}/scripts/dy_boost.py live \
  --aov 129 --margin 0.4 --refund 0.15 \
  --fixed 3000 --spend 2000 --views 30000
```

拿到三个数：**保本 GMV、保本订单数、保本 GPM**。
保本 GPM 高（>800）说明这个货盘撑不住成本，先改客单或压固定成本，不要靠"多播两小时"硬扛。

## 货盘结构（按保本 GPM 调整比例）

| 类型 | 基础占比 | 作用 | 判定标准 |
|---|---|---|---|
| 引流款 | 15%—20% | 拉停留、拉互动 | 价格低于同类均价，库存 ≥ 50 件，能讲 3 分钟不重复 |
| 主推利润款 | 50% | 赚钱的主力 | 毛利 ≥ 40%，有可视化差异点，退款率可控 |
| 形象款 | 10% | 抬价格锚 | 单价 ≥ 客单价 3 倍，不指望卖，用来衬托 |
| 福利款 | 15% | 制造节奏峰 | 真便宜但限量，每 15 分钟放一次 |
| 清货款 | 5% | 收尾冲量 | 断码、尾货，明确说清瑕疵 |

**判定规则**：保本 GPM 越高，利润款占比越高、福利款越少（福利款拉人气但拉低 GPM）；新号第一场可以临时把引流款提到 30%，但必须在台本里写明"这一场只为拉停留，不追 GMV"。

## 15 分钟节奏环（循环，不是从头排到尾）

| 分钟 | 动作 | 目的 | 关键指标 |
|---|---|---|---|
| 0—2 | 留人：说清这场讲什么、有什么价 | 让人别划走 | 进入率、30 秒留存 |
| 2—7 | 讲品：一个品讲透（痛点 → 演示 → 差异） | 建立价值感 | 商品点击率 |
| 7—11 | 逼单：价格、库存、售后，只讲一次 | 转化 | 成交转化率 |
| 11—13 | 转场：预告下一个品 + 放福利 | 防掉人 | 在线人数是否回升 |
| 13—15 | 承接：答评论区最集中的两个问题 | 降低退货 | 评论互动数 |

每 15 分钟一个环，整场 2 小时 = 8 个环。**第 1 个环决定整场流量层级**，所以第一个品必须是引流款，且前 2 分钟必须报出具体价格。

## 话术三段式（每个品只讲这三段，别加第四段）

1. **痛点句**：一句具体场景，不用形容词。"毛衣起球，你穿一次就得拿剪刀修一次。"
2. **证据句**：一个能被验证的事实。"这是同款两种纱线的对比，左边这件洗了 20 次。"
3. **动作句**：一个低门槛动作 + 一个真实理由。"想试的拍 1 号链接，今天这批只有 80 件，因为尾单就这么多。"

**话术禁忌**（违反直接改写）：
- 不喊"史上最低""全网最便宜"——绝对化用语，且观众不信。
- 不做倒计时恐吓式逼单，库存说真话。
- 不承诺疗效、不承诺"用了就……"。
- 不说"最后 3 件"如果不是真的最后 3 件。

## 场控检查表

**开播前 60 分钟**
- [ ] 保本 GPM 已算，写在提词板上
- [ ] 货盘顺序已定，1 号链接是引流款
- [ ] 福利款数量、发放时点已定（每 15 分钟一次）
- [ ] 库存与真实数量核对过（说多少就是多少）
- [ ] 违规词已扫（`dy-compliance-lint`），话术卡改到位
- [ ] 网络、灯光、声音、备用机测试过
- [ ] 客服/售后话术准备好（退款、发货时效）

**开播后每 15 分钟**
- [ ] 在线人数是升还是降，决定下一环换品还是加福利
- [ ] 停留时长掉到 40 秒以下 → 立刻上福利款
- [ ] 点击率高但成交低 → 价格或信任问题，补证据句
- [ ] 评论区出现集中质疑 → 当场回答，不删评

**下播后 30 分钟**
- [ ] 记录：场观、峰值在线、人均停留、GPM、成交件数、退款预警
- [ ] 标出本场最好卖的和最没人问的各一个
- [ ] 把"讲了但没成交"的品单独列出，下一场换讲法

## 输出格式

1. **保本线**：保本 GMV / 订单数 / GPM，含口径说明。
2. **货盘表**：序号 / 品名 / 类型 / 售价 / 毛利 / 库存 / 上播时点 / 讲多久。
3. **节奏台本**：按 15 分钟环展开，写清每环的品、话术要点、指标。
4. **话术卡**：每个主推品一张，三段式 + 禁忌提醒。
5. **场控检查表**：开播前 / 中 / 后三张。

模板见 `templates/live-runbook.md`。

## 异常处理

| 情况 | 处理 |
|---|---|
| 新号第一场，场观很低 | 不追 GMV，先追停留和互动；台本里写明"本场目标是人均停留 ≥ 60 秒" |
| 库存不足，撑不满时长 | 缩时长或加"讲品不讲卖"的环节（测评、对比、答疑），不要重复讲同一个品 |
| 退款率特别高的类目（服饰、珠宝） | 保本 GMV 要按更高退款率重算，并在话术里前置"尺码/材质"说明 |
| 用户要求"憋单""演戏砍价" | 拒绝。这类做法违规且伤复购，改用真实限量 + 真实理由 |
| 用户没有成本数据 | 只做节奏与话术，明确声明"本场无法测算保本线" |
| 播到一半流量突然掉 | 判断是违规限流还是自然波动：看是否有系统提示；有限流先处理违规，别加投流 |

## 与其他技能的关系

- 保本线来自 `dy-boost-review` 的测算口径，两边数字必须一致。
- 话术卡必须过 `dy-compliance-lint`。
- 直播切片要发短视频时，交给 `dy-hook-script` 重写成 15—30 秒的独立脚本（切片不能直接当短视频用，开头没有钩子）。
