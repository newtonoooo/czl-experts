- 禁忌提醒：不说"最"、不承诺疗效、库存说真话、不演戏砍价

## 六、场控检查

**开播前**
- [ ] 保本 GPM 写在提词板上
- [ ] 1 号链接是引流款，前 2 分钟报价格
- [ ] 福利款数量与发放时点已定
- [ ] 库存真实数字核对过
- [ ] 话术过合规扫描，高等级命中为 0
- [ ] 设备与售后话术就绪

**开播中（每 15 分钟）**
- [ ] 在线人数趋势：升 / 平 / 降
- [ ] 停留 < 40 秒 → 上福利款
- [ ] 点击高成交低 → 补证据句
- [ ] 集中质疑 → 当场答

**下播后**
- [ ] 场观 / 峰值 / 人均停留 / GPM / 成交件数 / 退款预警
- [ ] 最好卖的与最没人问的各一个
- [ ] "讲了没成交"的品，下一场换讲法
