# 财税全流程技能包

这套技能解决一个具体毛病：**财税类回答很容易听起来都对、但落不了地**。所以这里不给通用原则，给的是可执行的步骤、可复算的公式、可验收的交付物。

## 什么时候用哪一段

| 用户说 | 走哪一段 | 主要产出 |
| --- | --- | --- |
| "帮我看看这个月的账／报表" | G1 → G2 | 数据体检表 + 经营诊断（三亮点三风险三动作） |
| "这个税怎么报／要报哪些税" | G3 | 涉税事项清单（必须做／可优化／需确认） |
| "报税截止到几号" | G3 轻量分支 | 申报日历 + 一句口径提示 |
| "帮我做预算／为什么超支" | G4 预算分支 | 预算表骨架 + 差异分析（量差／价差） |
| "报销流程怎么设／怎么防漏洞" | G4 内控分支 | 该环节三个关键控制点 + 自查表 |
| "这张发票能不能报／是不是真的" | G1 票据分支 | 五要素核对 + 查验路径 + 处理建议 |
| "从票到报表到税，整体过一遍" | G0 → G5 | 全套：体检 + 诊断 + 涉税 + 方案 + 交付 |

不确定走哪条时，先问一句"你现在卡在哪一步"。不要默认走全流程。

## 阶段与放行条件

| 阶段 | 一句话职责 | 放行条件（不满足就停） |
| --- | --- | --- |
| G0 接单与脱敏 | 把任务、身份、期间、数据钉死 | 身份与期间明确，至少一项可用数据 |
| G1 数据校准 | 先证明数字站得住 | 勾稽差异已解释，或不影响后续结论 |
| G2 经营诊断 | 数字说明什么 | 每个结论都能指回 G1 的某个数 |
| G3 税务判定 | 这笔业务涉及哪些税、怎么报 | 每个税种结论都写了适用前提 |
| G4 方案成型 | 明天谁做什么 | 每条动作有责任人、时限、验收方式 |
| G5 交付与留痕 | 存档与复核 | 有口径声明和待补清单 |

阶段细节见 `references/01`—`06`。十个高频场景的完整走法见 `references/07-场景剧本.md`。

## 可复算工具

位置：本技能目录下 `scripts/toolkit.py`。纯 Python 标准库，无第三方依赖，可离线运行。

```bash
# 1. 三表勾稽与表内合计校验
python scripts/toolkit.py check --file data.json

# 2. 比率、杜邦拆解、现金流质量
python scripts/toolkit.py ratios --file data.json

# 3. 预算差异与量价拆分
python scripts/toolkit.py variance --file var.json

# 4. 申报日历（周末顺延，节假日需手工覆盖）
python scripts/toolkit.py calendar --year 2026 --month 10

# 5. 自检
python scripts/toolkit.py selftest
```

输入 JSON 的字段约定见 `references/02-数据规范化与勾稽.md` 第三节。**字段名以文档为准，不要为了迁就数据去改脚本。**

工具的三条使用纪律：

1. **先 ls 定位再调用**。不同版本平台下专家目录路径不同，不要写死绝对路径。
2. **回读输出再引用**。工具只输出数字，引用前确认单位、期间、正负号与用户给的一致。
3. **工具不可用时手算**。把公式、代入值、结果三行写出来，一样可复核。

## 输出前自检

交付前逐条过一遍，任何一条不过就改：

- [ ] 结论在前三句，没有让人翻到最后才看到重点
- [ ] 关键数字后面标了口径（含税/不含税、期间、单体/合并、期末/平均）
- [ ] 至少有一处明确指出"这个数据缺失，所以这一项无法判断"
- [ ] 政策类表述带"截至"时间，且没有编造文号
- [ ] 建议都能验收（有责任人、时限、验证方式），没有"加强管理"类表述
- [ ] 风险分了级，A 级不超过 3 条
- [ ] 最后一句是下一步动作或需要用户确认的问题，不是客套收尾
- [ ] 没有出现"能帮你省多少税"这类承诺

## 边界

本技能包只提供知识框架与计算辅助，不构成税务筹划建议、审计鉴证或法律意见。涉及重大交易、税务争议、涉刑风险时，一律建议由持证税务师、注册会计师或律师复核。政策口径以国家税务总局、财政部及主管税务机关最新发布为准。
