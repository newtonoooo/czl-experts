# 04 税种判定树

税的问题容易答错，通常不是因为税率记不住，而是**身份搞错了、行为归错类了、期限记成了另一个税种的**。所以这里用判定树，一格一格往下走。

> 全文所有税率、标准、期限均为**截至 2026 年 10 月的通行口径**。近年小规模减免、小微优惠、加计扣除等政策多以三年为周期延续，历史上有过多次延期与调整，落地前必须核对国家税务总局当期公告与电子税务局提示。凡涉及地方口径（如核定征收率、房产原值扣除比例），以主管税务机关口径为准。

## 一、第一步：身份

| 身份 | 判据 | 关键差异 |
| --- | --- | --- |
| 增值税一般纳税人 | 年应征增值税销售额超过 500 万元，或主动登记 | 按适用税率计税，进项可抵，可开专票 |
| 增值税小规模纳税人 | 未超过标准且未登记 | 按征收率简易计税，进项不可抵，可自开或代开专票 |
| 个体工商户 | 登记为个体户 | 缴个人所得税（经营所得），非企业所得税；可查账或核定 |
| 自然人 | 未办理税务登记 | 代开发票、按次纳税、由支付方代扣代缴 |
| 非企业单位 | 机关、事业单位、社会团体 | 部分收入不征税，需单独判断 |

**身份判断的两个常见错误**：

1. 把"小规模"等同于"不用交税"。免税看的是销售额是否在免征额度内，不是身份。
2. 把"个体户"等同于"不用记账"。核定征收也要保存进销凭证，且销售额连续超标会被要求建账。

## 二、第二步：行为归类

把本期每一类收入与支出先归类，再对税种。不要拿"公司"整体去问"要交什么税"。

| 行为 | 典型场景 | 涉及税种 |
| --- | --- | --- |
| 销售货物 | 卖产品、卖材料、样品转销售 | 增值税、附加税费、企业所得税 |
| 提供劳务/服务 | 咨询、设计、维修、安装、餐饮、住宿 | 增值税、附加、企业所得税 |
| 销售或出租不动产 | 卖房、出租办公室、出租仓库 | 增值税、附加、土地增值税（销售时）、房产税（出租时）、印花税、企业所得税 |
| 转让无形资产 | 转让专利、商标、软件著作权 | 增值税、附加、企业所得税 |
| 进口货物 | 采购境外设备、原材料 | 进口环节增值税、关税、消费税（如涉及） |
| 支付给个人 | 付劳务费、稿费、租金、分红 | 代扣代缴个人所得税 |
| 发放工资 | 员工薪酬 | 代扣代缴个人所得税、社保、公积金 |
| 借款与利息 | 向银行/股东/员工借款 | 借款合同印花税；股东长期借款涉个税风险 |
| 签订合同 | 买卖、租赁、承揽、运输、借款 | 印花税 |
| 持有房产土地 | 自有厂房、办公楼 | 房产税、城镇土地使用税 |
| 安排残疾人就业未达比例 | 在职职工超 30 人 | 残疾人就业保障金 |

## 三、第三步：各税要素速查

税率是政策里变动最频繁的部分，用之前先看"变动风险"这一列。

### 增值税

| 情形 | 税率/征收率 | 变动风险 |
| --- | --- | --- |
| 销售货物、加工修理修配、有形动产租赁 | 13% | 低 |
| 交通运输、邮政、基础电信、建筑、不动产租赁、销售不动产、转让土地使用权、农产品、自来水暖气燃气、图书报刊 | 9% | 低 |
| 现代服务、生活服务、金融、增值电信、转让无形资产（除土地使用权） | 6% | 低 |
| 出口货物与部分跨境服务 | 0%（可退税或免税） | 中 |
| 小规模纳税人 | 征收率 3%；销售不动产、出租不动产等特定情形 5% | 中 |
| 小规模纳税人阶段性优惠 | 3% 征收率减按 1%；月销售额未超 10 万元（按季 30 万元）免征 | **高**，需核对当期公告 |

计税依据：不含税销售额。一般纳税人应纳税额 ＝ 销项税额 − 可抵扣进项税额；小规模应纳税额 ＝ 不含税销售额 × 征收率。

**最容易错的三处**：
- 用含税金额乘税率（应当先 ÷(1+税率) 还原）。
- 视同销售漏报：把货送给客户、给员工发实物福利、股东拿走产品，都要按视同销售处理（自产货物用于集体福利或个人消费）。
- 免税项目与应税项目混在一起，未分别核算，被要求全额计税。

### 企业所得税

| 项目 | 口径 |
| --- | --- |
| 基本税率 | 25% |
| 小型微利企业 | 年应纳税所得额不超过 300 万元、从业人数不超过 300 人、资产总额不超过 5000 万元且从事国家非限制和禁止行业，现行按优惠口径计算，实际税负约 5%（政策延续期需核对） |
| 高新技术企业 | 15% |
| 研发费用加计扣除 | 现行比例 100%（部分行业不适用，如烟草、住宿餐饮、批发零售、房地产、租赁和商务服务等，需核对目录） |
| 亏损弥补 | 一般 5 年，高新技术企业与科技型中小企业 10 年 |

计税依据：应纳税所得额 ＝ 会计利润 ± 纳税调整。**不是利润表上的利润总额直接乘税率**。

年度必做的调整项（前六项占实务问题的大部分）：

| 项目 | 调整方向 | 要点 |
| --- | --- | --- |
| 业务招待费 | 调增 | 按发生额 60% 扣除，且不超过当年营业收入 5‰，取小 |
| 广告费和业务宣传费 | 调增（可结转） | 一般企业不超过营业收入 15%，超部分结转以后年度 |
| 职工福利费 | 调增 | 不超过工资薪金总额 14% |
| 职工教育经费 | 调增（可结转） | 不超过 8% |
| 工会经费 | 调增 | 不超过 2%，且需取得专用收据 |
| 罚款、滞纳金、赞助支出 | 调增 | 行政性罚款与税收滞纳金不得扣除 |
| 不征税收入形成的费用 | 调增 | 如财政性资金用于支出所形成的费用 |
| 固定资产折旧年限差异 | 调增或调减 | 会计年限短于税法最低年限时调增 |

### 个人所得税

| 所得类型 | 税率 | 申报方式 |
| --- | --- | --- |
| 综合所得（工资薪金、劳务报酬、稿酬、特许权使用费） | 3%—45% 七级超额累进（年） | 单位按月预扣预缴，个人次年 3 月 1 日—6 月 30 日汇算 |
| 经营所得（个体户、个独、合伙） | 5%—35% 五级超额累进（年） | 按月或按季预缴，次年 3 月 31 日前汇算 |
| 利息股息红利、财产租赁、财产转让、偶然所得 | 20% 比例税率 | 按次，由支付方代扣代缴 |

综合所得基本减除费用：60000 元/年（5000 元/月）。专项附加扣除现行标准（2023 年提高后，需核对最新）：

| 项目 | 标准 |
| --- | --- |
| 子女教育 | 每孩每月 2000 元 |
| 3 岁以下婴幼儿照护 | 每孩每月 2000 元 |
| 赡养老人 | 独生子女每月 3000 元；非独生分摊，每人不超过 1500 元 |
| 继续教育 | 学历教育每月 400 元（最长 48 个月）；职业资格取得当年 3600 元 |
| 住房贷款利息 | 每月 1000 元，最长 240 个月 |
| 住房租金 | 按城市 1500 / 1100 / 800 元每月，与房贷利息不可同时享受 |
| 大病医疗 | 医保目录内自付超 15000 元部分，年度限额 80000 元 |

### 附加税费与财产行为税

| 税种 | 计税依据 | 税率 |
| --- | --- | --- |
| 城市维护建设税 | 实缴增值税＋消费税 | 市区 7%、县镇 5%、其他 1% |
| 教育费附加 | 同上 | 3% |
| 地方教育附加 | 同上 | 2% |
| 印花税（借款合同） | 借款金额 | 万分之零点五 |
| 印花税（买卖、承揽、建设工程、运输） | 合同金额 | 万分之三 |
| 印花税（租赁、仓储、保管、财产保险） | 合同金额 | 千分之一 |
| 印花税（产权转移书据） | 金额 | 万分之五 |
| 印花税（营业账簿） | 实收资本＋资本公积 | 万分之二点五 |
| 房产税（自用） | 房产原值 ×（1 − 扣除比例 10%—30%） | 1.2%，按年计征、分期缴纳 |
| 房产税（出租） | 租金收入 | 12%（个人出租住房 4%） |
| 城镇土地使用税 | 实际占用面积 | 按地段等级定额，各地不同 |
| 残疾人就业保障金 | 上年在职职工年平均工资 × 差额人数 | 比例与减免按当地规定 |

小规模纳税人、小型微利企业、个体工商户现行可享受"六税两费"减半征收（政策有执行期限，需核对）。

| 事项 | 时间 | 备注 |
| --- | --- | --- |
| 增值税及附加（按月） | 次月 15 日前 | 遇节假日顺延 |

| 经营所得汇算清缴 | 次年 3 月 31 日前 | 个体户、个独、合伙 |
| 综合所得年度汇算 | 次年 3 月 1 日—6 月 30 日 | 个人所得税 APP |

## 五、第五步：优惠适用性判定（四态）

用户问"我能不能享受优惠"时，不要给"能/不能"，给四态之一，并说清缺哪个条件。

```
状态① 符合      —— 全部条件已核，且资料齐备
状态② 大概率符合 —— 主体条件满足，但有一项无法从现有信息确认（写明是哪项）
状态③ 不符合    —— 有明确条件不满足（写明是哪一条，给出临界值差距）
状态④ 需确认    —— 涉及地方口径、行业目录、备案要求，须向主管税务机关确认
```

标准判定顺序（以小型微利企业为例）：

1. 行业：是否属于国家非限制和禁止行业？（查《产业结构调整指导目录》）
2. 应纳税所得额：≤ 300 万元？
3. 从业人数：≤ 300 人？含劳务派遣用工。
4. 资产总额：≤ 5000 万元？
5. 是否符合征收方式要求（核定征收企业通常不适用）？

四条都过 → 状态①。有一条数据缺失 → 状态②，并写"缺从业人数（含派遣），补上即可定"。有一条不满足 → 状态③，并给差距（"应纳税所得额 340 万，超出 40 万，超出部分不适用"）。

**红线**：判定适用性是合规工作；设计"如何刚好卡在 300 万以内"的方案，性质就变了。前者可以做，后者只能说清后果然后停手。

## 六、第六步：发票规则

| 情形 | 处理原则 |
| --- | --- |
| 开票内容 | 必须与实际交易一致：品名、数量、单价、金额、税率。汇总开票必须附清单 |
| 专票开具 | 一般纳税人可自开；小规模可自开或申请代开；自然人可申请代开 |
| 不得开专票 | 向消费者个人销售、免税项目、简易计税的部分情形（如小额零星） |
| 备注栏 | 建筑服务（项目名称与地址）、货物运输（起运地到达地车种车号）、差额征税（差额部分）、不动产销售与租赁（不动产地址）等需按规定填写 |
| 开错了 | 当月且未认证：作废重开；跨月或已认证：开具红字发票冲销后重开。跨年红冲的税务处理需按当期规定 |
| 丢失 | 凭发票记账联复印件或查验记录处理，具体按当期征管要求 |
| 查验 | 全国增值税发票查验平台（国家税务总局官网入口）；数电发票在电子发票服务平台查验。查验结果截图留存 |

**三流一致**：合同流、发票流、资金流指向同一交易主体与同一金额。不一致不必然违规（如委托付款、集团代付），但必须有书面说明与授权文件；无说明的三流不一致，是稽查中最常见的质疑点。详见 `05-内控与三流一致.md`。

## 七、小规模 vs 一般纳税人：要不要升

这是高频问题，给测算方法而不是给结论。

**比较的是"实际税负"，不是税率。**

```
一般纳税人税负 = 销项税 − 可抵扣进项税 = 不含税销售额 × 销项税率 − 可抵扣采购额 × 进项税率
小规模税负     = 不含税销售额 × 征收率（享受减免时按减免后）
临界点：当（销项税率 − 征收率）÷ 销项税率 = 可抵扣采购占销售额比重时，两者相等
```

以 13% 销项、3% 征收率为例：临界点 ≈ (13%−3%)/13% ≈ 76.9%。也就是说，**可抵扣采购占销售额比重低于约 77% 时，一般纳税人税负更重**；高于这个比重，一般纳税人更划算。

但这个测算只解决税，实际决策还要看四件事：

1. **客户要不要专票**。大客户、国企、上市公司基本要求专票，不给就丢单。这一条经常比税负测算更决定性。
2. **进项能不能取得**。上游是小作坊、个体户、自然人，拿不到专票，账面税负会远高于测算值。
3. **身份能否转回**。登记为一般纳税人后，通常不能随意转回小规模，这是单向门。
4. **核算成本**。一般纳税人要建账、要认证抵扣、要应对更细的申报，人力和代账费都会上升。

输出格式：「按你给的数测算，可抵扣采购占比约 55%，低于 77% 的临界点，单看税负一般纳税人不划算；但如果 A 客户（占收入 40%）明确要求专票，不升会丢这部分收入——这两件事要一起算。」
