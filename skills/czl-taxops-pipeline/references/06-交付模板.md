# 06 交付模板

交付物只有两种用途：**让人做决定**，或者**让下一个人能复核**。不符合这两个用途的表格一律删掉。

## 一、完整报告骨架（全流程任务用）

```
# XX 公司 20XX 年 X 月 财税体检报告

## 一、结论（三句话内）
1. 现状：本月收入 __ 万，净利 __ 万，经营现金流 __ 万。
2. 最大问题：__（一句话 + 一个金额）。
3. 先做什么：__（一件事，含责任人与期限）。

## 二、数据体检
（勾稽结果表：通过 / 差异 / 无法判断三档，差异附金额与原因）

## 三、经营诊断
### 3.1 结构
（收入构成、成本结构、费用结构三张表，各不超过 6 行）
### 3.2 关键指标
| 指标 | 本期 | 上期 | 变动 | 口径 | 说明 |
### 3.3 利润质量
（净利润 vs 经营现金流，差额归因到具体科目）

## 四、涉税事项
（必须做 / 可优化 / 需确认 三栏）

## 五、风险台账
| 级别 | 事项 | 金额敞口 | 整改动作 | 责任人 | 时限 |

| 缺什么 | 为什么需要 | 补上后能多回答什么 |

（见本文第五节）
```

## 二、老板一页纸（非财务视角）

老板不看指标表。他要三句话和一个数。

```
【本月一句话】
收入 86 万（环比 +12%），净利 4.2 万（净利率 4.9%，环比 −1.8 个点），
钱没进来：应收增加 11 万，账上现金从 23 万降到 9 万。

【三个数看健康】
毛利 26%（上月 32%）——降在采购，A 料单价涨了 12%
现金 9 万——只够 11 天开支（按上月日均支出算）
欠税 0——本期申报已清

【这周做三件事】
1. 找 A 料供应商谈价或换第二家（采购，10/31 前）
2. 催三笔超 60 天应收，共 7.8 万（销售，10/20 前）
3. 暂停两笔非紧急采购，共 3.4 万（老板，即刻）
```

一页纸的纪律：**不出现任何一个需要解释才能懂的指标名**。要用"只够 11 天开支"而不是"现金比率 0.31"。

## 三、风险台账

| 列 | 填写要求 |
| --- | --- |
| 级别 | A / B / C，标准见主提示词第五节。A 级不超过 3 条，多了等于没分级 |
| 事项 | 一句话说清是什么事，不写"税务风险"这种类别名 |
| 金额敞口 | 能算就算：补税 + 滞纳金（按日万分之五测算）+ 罚款区间；算不出就写"无法量化，原因：__" |
| 整改动作 | 一个动作，可验收 |
| 责任人 | 岗位而非人名（"财务负责人"），除非用户指定了人 |
| 时限 | 具体日期，不写"尽快" |

示例行：

```
A | 8 月 3 笔销售款进老板个人卡，共 12.4 万未入账 | 补增值税 1.4 万+附加 0.2 万+企税按利润影响测算+滞纳金，合计约 2.1 万起 | 转入公司账户并补记收入，评估是否补充申报 | 老板+财务 | 10/31
B | 供应商比价记录缺失，5 万以上采购仅 1 家报价 | 无法量化（采购价格可能高于市场 3—8%） | 11 月起两家报价，建立供应商名录 | 采购负责人 | 11/30
```

## 四、待补清单

格式固定三列，最后加一句"补哪个最划算"。

```
| 缺什么 | 为什么需要 | 补上后能多回答什么 |
| 上月同口径营业成本 | 分离价变与量变 | 毛利率下降的主因能定位到具体产品 |
| 应收账龄表 | 判断坏账敞口 | 能给出预计坏账金额与计提建议 |
| 本季度开票汇总 | 核对申报完整性 | 能确认是否存在未申报收入 |
```

## 五、口径声明（每份交付物都要有）

```
口径声明
1. 数据来源：用户提供的 2026 年 9 月利润表、资产负债表（单位：元，不含税）。
2. 计算口径：周转类指标按期末余额计算（缺期初数），与平均值口径存在偏差。
3. 政策口径：税率、扣除标准、申报期限为截至 2026 年 10 月的通行口径，
   以国家税务总局、财政部及主管税务机关最新发布为准。
4. 假设：视同销售未单独核算；未考虑跨期调整事项。
5. 本报告为管理分析用途，不构成审计、鉴证或税务筹划意见；
   涉及重大交易与税务争议，请由持证税务师、注册会计师复核。
```

第 4 条"假设"最容易被省略，但它是复核者最先要看的东西。假设不清，结论无法验证。

## 六、年度预算骨架

| 行次 | 项目 | 上年实际 | 本年预算 | 增减% | 编制依据 |
| --- | --- | --- | --- | --- | --- |
| 1 | 营业收入 | | | | 量 × 价，分产品线 |
| 2 | 营业成本 | | | | 单位成本 × 销量 |
| 3 | 毛利（1−2） | | | | |
| 4 | 毛利率 | | | | |
| 5 | 销售费用 | | | | 人员 + 推广 + 差旅 |
| 6 | 管理费用 | | | | 人力 + 房租 + 折旧 + 办公 |
| 7 | 研发费用 | | | | 项目立项数 × 人均 |
| 8 | 财务费用 | | | | 贷款余额 × 利率 |
| 9 | 税金及附加 | | | | 增值税 × 附加率 |
| 10 | 营业利润 | | | | |
| 11 | 所得税费用 | | | | 按适用税率与优惠 |
| 12 | 净利润 | | | | |
| 13 | 折旧摊销（加回） | | | | 非付现 |
| 14 | 营运资金变动 | | | | 应收 + 存货 − 应付 的增量 |
| 15 | 资本性支出 | | | | 设备、装修、软件 |
| 16 | 预计经营净现金流 | | | | 12+13−14−15 |

编制顺序不能跳：**收入 → 变动成本 → 固定费用 → 税费 → 资本支出 → 现金流**。先算利润再倒推收入，做出来的预算一定完不成。

自检三条：
- 毛利率是否与历史区间相符？突变必须有依据。
- 费用增速是否低于收入增速？如果高于，利润从哪来？
- 经营现金流是否为正？长期为负的预算等于计划烧钱。

## 七、月度差异分析表

| 科目 | 预算 | 实际 | 差异额 | 差异率 | 原因归类 | 责任部门 | 措施 |
| --- | --- | --- | --- | --- | --- | --- | --- |

原因归类只有四类，选一类，不要写"综合因素"：

- **量差**：数量变了（卖多了/卖少了、用量多了）
- **价差**：单价变了（采购价、售价、人工单价）
- **时间差**：发生时间提前或推后（预付年费、季度集中采购）
- **口径差**：分类变了、含税口径变了、部门归属变了

处理规则：差异率 ≥ 10% 或绝对额超阈值的必须写原因；连续三个月同向超预算的，启动专项分析而不是继续解释。

## 八、量价拆分（可直接套用）

对单价 × 数量型的科目：

```
价差 =（实际单价 − 预算单价）× 实际数量
量差 =（实际数量 − 预算数量）× 预算单价
差异合计 = 价差 + 量差 = 实际金额 − 预算金额（恒等）
```

工具：`toolkit.py variance`，输入 items 数组，自动输出价差、量差与占比。

用它的意义在于：**"超支 8 万"是现象，"价差 6.2 万、量差 1.8 万"才是可执行的结论**——前者只能批评，后者能派人去谈价。
