# W3 化学用语与方程式门诊

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 化学用语与方程式门诊（czl-chem-equation） |
| **任务职责** | 把"会写但总扣分"的方程式问题定位到具体一查，并用检查表把习惯改过来。不代写整页作业。 |
| **输入参数** | 必填：学生手写的方程式（原图或原文，至少 2 个）。选填：题目原文、老师批改痕迹、教材版本 |

| **判断条件** | 化学事实就错（产物不对）→ 停，先修事实，不谈配平；事实对但配平错 → 只练电子守恒；配平对但符号漏 → 只练符号清单；离子方程式拆错 → 回到拆写规则表，不练新题 |
| **输出格式** | 批改单（原式 / 错在哪一查 / 规范式 / 一句话原因）+ 三条个人易错点 + 5 道同类题 |
| **异常处理** | 学生只发答案不发过程 → 要求发过程，"我要看你第几步开始不对"；一次发来 20 个错式 → 只挑 3 个同类，其余下次；学生坚持"老师就是这么写的" → 请他把老师原话或板书拍来，按证据说话；方程涉及危险物质（Cl₂、H₂S、浓 HNO₃）→ 只讲书写与原理，注明实验须在老师指导下进行 |
| **必要依赖** | `references/07-化学用语规范清单.md`（逐条检查表）、`references/01-元素化合物转化网络.md`（产物是否正确） |

## 一、三查法（每次写完都查，按顺序）

| 查 | 查什么 | 怎么查 | 扣分点 |
|---|---|---|---|
| 一查事实 | 产物对不对？浓稀、冷热、过量少量有没有影响 | 回到物质性质：这条件下它到底生成什么 | 稀硝酸写成 NO₂、Fe 与 Cl₂ 写成 FeCl₂ |
| 二查守恒 | 原子守恒、电荷守恒、电子守恒 | 左右两边逐元素点数；离子式看总电荷；氧化还原看升降总数 | 少一个 H₂O、电荷不平 |
| 三查符号 | 条件、状态、箭头、可逆 | 逐项打勾：△ / 催化剂 / 浓 / 稀 / ↑ / ↓ / ⇌ | 漏 ↑、可逆写成等号 |

**顺序不能换。** 先查事实，事实错了，配平再漂亮也是零分。

## 二、配平的四把工具

| 工具 | 什么时候用 | 步骤 |
|---|---|---|
| 观察法 | 简单复分解、系数小的反应 | 先定最复杂的物质系数为 1，逐个配 |
| 最小公倍数法 | 只有一两种元素出现奇偶不匹配 | 找出现次数最少且左右奇偶不同的元素，取最小公倍数 |
| 电子守恒法 | 一切氧化还原 | 标变价 → 算升降数 → 求最小公倍数 → 配变价物质 → 补水与 H⁺/OH⁻ → 查电荷 |
| 电荷守恒法 | 离子方程式 | 先配原子，再用总电荷差补 H⁺ 或 OH⁻，最后补水 |

酸性条件补 $\mathrm{H^+}$ 和 $\mathrm{H_2O}$，碱性条件补 $\mathrm{OH^-}$ 和 $\mathrm{H_2O}$，**不能两边同时补 H⁺ 和 OH⁻**。

## 三、离子方程式拆写规则

| 类别 | 处理 | 例子 |
|---|---|---|
| 强酸（HCl、H₂SO₄、HNO₃、HBr、HI） | 拆 | $\mathrm{H^+ + Cl^-}$ |
| 强碱（NaOH、KOH、Ba(OH)₂） | 拆 | $\mathrm{Na^+ + OH^-}$ |
| 可溶性盐 | 拆 | $\mathrm{NaCl \to Na^+ + Cl^-}$ |
| 弱酸（CH₃COOH、H₂CO₃、HClO、HF） | 不拆 | 写 $\mathrm{CH_3COOH}$ |
| 弱碱（NH₃·H₂O） | 不拆 | 写 $\mathrm{NH_3\cdot H_2O}$ |
| 水、沉淀、气体、氧化物、单质 | 不拆 | 写化学式 |
| 微溶物 | 看状态：澄清溶液拆，浊液/乳状不拆 | 澄清石灰水拆，石灰乳写 $\mathrm{Ca(OH)_2}$ |
| 酸式盐 | 看电离程度 | $\mathrm{NaHCO_3 \to Na^+ + HCO_3^-}$；水溶液中 $\mathrm{NaHSO_4 \to Na^+ + H^+ + SO_4^{2-}}$ |
| 浓硫酸 | 以分子为主，通常不写离子式 | $\mathrm{Cu + 2H_2SO_4(浓) \xrightarrow{\triangle} CuSO_4 + SO_2\uparrow + 2H_2O}$ |

## 四、十二个高频扣分点

| # | 错误 | 正确做法 |
|---|---|---|
| 1 | 铁与稀硝酸生成 H₂ | 稀硝酸有氧化性，生成 NO |
| 2 | Fe 与 Cl₂ 生成 FeCl₂ | 氯气过量时生成 FeCl₃ |
| 3 | Na₂O₂ 与水按普通复分解写 | 氧为 −1 价，发生歧化：$2\mathrm{Na_2O_2} + 2\mathrm{H_2O} = 4\mathrm{NaOH} + \mathrm{O_2}\uparrow$ |
| 4 | 铝与 NaOH 不反应 | $2\mathrm{Al} + 2\mathrm{NaOH} + 2\mathrm{H_2O} = 2\mathrm{NaAlO_2} + 3\mathrm{H_2}\uparrow$ |
| 5 | Fe³⁺ 与 SCN⁻ 写成沉淀 | 是络合显色，写 $\mathrm{Fe^{3+} + 3SCN^- \rightleftharpoons Fe(SCN)_3}$，不写 ↓ |
| 6 | SO₂ 通入氯水不反应 | $\mathrm{SO_2 + Cl_2 + 2H_2O = H_2SO_4 + 2HCl}$ |
| 7 | 可逆反应写等号 | 用 ⇌，并注明条件 |
| 8 | 热化学方程式漏状态 | 每个物质标 (g)(l)(s)(aq)，$\Delta H$ 带单位与正负 |
| 9 | 电极反应式漏电子 | 阳极/负极写 $-\mathrm{e^-}$，阴极/正极写 $+\mathrm{e^-}$，两边电荷要平 |
| 10 | 盐类水解写成一水合 | 多元弱酸根分步写，一般只写第一步 |
| 11 | 沉淀转化写成不可逆 | 用 ⇌ 表示平衡，如 $\mathrm{AgCl + I^- \rightleftharpoons AgI + Cl^-}$ |
| 12 | 电子式漏孤对电子 | 先画骨架，再补孤对，最后查每个原子是否达稳定结构 |

## 六、怎么练（每天 5 个，15 分钟）

1. **3 个改错**：从自己的错题里挑，重写一遍并口头说出"我刚才错在哪一查"。
2. **1 个新写**：换一个物质，同一类反应。
3. **1 个听写**：家长念现象，孩子写方程式；或孩子念，家长对照答案打勾。

规则：**改一个符号也算改对。** 不要因为"意思对了"放过，高考按符号给分。

## 七、三条提醒

1. **不要让学生抄十遍。** 抄十遍记住的是位置，不是规则。改一遍 + 说出原因，比抄十遍有用。
2. **不要一次修所有毛病。** 一张卷子 8 个方程式有 5 种错，只挑出现最多的那一种。
3. **条件与状态是"送分点"，也是"送命点"。** 每周固定花 5 分钟专练符号，比刷一套卷子划算。
