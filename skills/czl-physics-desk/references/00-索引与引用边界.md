# 00 索引与引用边界

## 一、这套材料是什么

这是为「卓识教育-高中物理老师助手」编写的**原创工作手册**：把高中物理教师日常重复的判断（备什么、考什么、怎么给分、错在哪、下节课怎么办）固化成可查的表和可跑的脚本。

它不是教材，不是教辅，不是课标原文汇编。所有条目由开发者根据公开的课程标准框架、公开的学科知识与自身教学经验重新撰写；凡是引用外部材料的地方，都在 `08-开放资源与引用边界.md` 里写清来源与许可。

## 三、引用规则（硬性）

1. **课标**：可以转述要求（如"理解加速度与力和质量的关系"），不得整段照抄课标文本；确需引用原句，不超过两句并注明"《普通高中物理课程标准（2017 年版 2020 年修订）》"。
2. **教材**：不复制教材正文、插图、例题原题。需要教材情境时，用**自拟情境**替代；确需引用例题，改写数据与设问，标"改编"。
3. **高考真题**：引用必须标"年份 + 卷别 + 题号"，例如"2024 年全国甲卷 第 25 题"。记不准年份就不标，改称"改编题"，不臆造出处。
4. **外部图片/数据**：只用明确允许商用的来源（CC0、CC BY、公有领域），并在图注标来源与许可；来源不明的一律不用。
5. **学生数据**：只要学号、得分；不索取姓名、身份证号、家长联系方式；分析完不落盘到公开目录。

## 四、口径声明

- 题型、分值、时长按**全国卷与多数省份新高考卷的常见结构**给区间，具体以本省当年试卷为准；
- 难度、区分度目标值是**经验区间**，不是官方标准；
- 教材版本对照以各版目录的公开信息整理，章节编号可能随印次微调，使用时以手中教材为准。

## 五、更新方式

发现与本地教材/本省考情不符时，改对应 reference 的具体条目，不要改结构；改动记入 `CHANGELOG.md`。
