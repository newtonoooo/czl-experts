# 02 知识结构与公式

> 用法：写教案、出题、批改时对照本表核对表达式与适用条件。凡本表未列条件的公式，不要直接用于计算题给分。
> 符号约定：g 取 9.8 m/s²（题目另有说明除外）；矢量的正方向在列式前先声明。

## 一、力学

### 1.1 运动学

| 公式 | 表达式 | 适用条件 | 高频错 |
|---|---|---|---|
| 速度公式 | v = v₀ + at | 匀变速直线运动 | 把 a 的正负与方向搞混 |
| 位移公式 | x = v₀t + ½at² | 同上 | 忘记初速度项 |
| 速度位移 | v² − v₀² = 2ax | 同上，不含 t | 用于非匀变速 |
| 平均速度 | x = (v₀+v)t/2 | 仅匀变速 | 用于一般变速 |
| 逐差法 | Δx = aT² | 连续相等时间间隔 | 间隔数数错 |
| 自由落体 | v = gt，h = ½gt² | 只受重力、v₀=0 | 忽略空气阻力前提 |

### 1.2 力与牛顿定律

| 公式 | 表达式 | 适用条件 | 高频错 |
|---|---|---|---|
| 重力 | G = mg | 近地 | 与万有引力混用 |
| 滑动摩擦 | f = μN | 相对滑动；N 为正压力 | 认为 N 一定等于 mg |
| 静摩擦 | 0 < f ≤ f_max | 相对静止 | 用 μN 直接算静摩擦 |
| 牛顿第二定律 | F合 = ma | 惯性系、宏观低速 | 漏力、把某个力当合力 |
| 牛顿第三定律 | F₁₂ = −F₂₁ | 任意两物体 | 与平衡力混淆（不同物体） |
| 超重失重 | N = m(g±a) | 竖直方向有加速度 | 把"失重"当成重力消失 |

### 1.3 曲线运动与圆周

| 公式 | 表达式 | 适用条件 | 高频错 |
|---|---|---|---|
| 平抛 | x=v₀t，y=½gt² | 只受重力、初速度水平 | 忘记分解 |
| 线速度 | v = ωr = 2πr/T | 圆周运动 | r 取错（不是直径） |
| 向心加速度 | a = v²/r = ω²r | 瞬时指向圆心 | 认为向心力是"新的力" |
| 向心力 | F向 = mv²/r | 沿半径方向的合力 | 把某个力直接当向心力 |
| 竖直圆周临界 | 最高点 v ≥ √(gr)（绳）；v ≥ 0（杆） | 绳/杆模型区分 | 绳杆混用 |

### 1.4 万有引力

| 公式 | 表达式 | 适用条件 | 高频错 |
|---|---|---|---|
| 万有引力 | F = GMm/r² | 质点或均匀球外部 | r 用成高度 |
| 环绕速度 | v = √(GM/r) | 圆轨道 | 与第一宇宙速度混 |
| 周期 | T = 2π√(r³/GM) | 圆轨道 | 与地表重力加速度混 |
| 黄金代换 | GM = gR² | 忽略自转、地表附近 | 用于高空 |

### 1.5 功、能与动量

| 公式 | 表达式 | 适用条件 | 高频错 |
|---|---|---|---|
| 功 | W = Flcosθ | 恒力 | θ 取成力与位移夹角的一半 |
| 功率 | P = W/t = Fvcosθ | 平均/瞬时 | 机车启动两种模式混 |
| 动能定理 | W合 = ΔEk | 惯性系，所有力做功代数和 | 漏某个力的功 |
| 重力势能 | Ep = mgh | 需先定零势面 | 零势面不声明 |
| 机械能守恒 | Ek1+Ep1 = Ek2+Ep2 | 只有重力/弹力做功 | 有摩擦仍用 |
| 动量 | p = mv | 矢量 | 忘方向 |
| 动量定理 | F合t = Δp | 矢量式 | 只算一个力的冲量 |
| 动量守恒 | m₁v₁+m₂v₂ = m₁v₁′+m₂v₂′ | 合外力为零或内力远大于外力 | 有外力仍直接用 |
| 完全非弹性 | 碰后共速 v = (m₁v₁+m₂v₂)/(m₁+m₂) | 碰后粘在一起 | 动能也当守恒 |
| 弹性碰撞 | 动能、动量同时守恒 | 无机械能损失 | 忘记联立两个方程 |

### 1.6 振动与波

| 公式 | 表达式 | 适用条件 | 高频错 |
|---|---|---|---|
| 单摆周期 | T = 2π√(l/g) | 摆角 < 5° | 大角度仍用 |
| 弹簧振子 | T = 2π√(m/k) | 弹性限度内 | 与单摆混 |
| 波速 | v = λf = λ/T | 机械波 | 把质点振动速度当波速 |
| 波的叠加 | 频率相同、相位差恒定才干涉 | 相干条件 | 任意两波都当能干涉 |

## 二、电磁学

| 公式 | 表达式 | 适用条件 | 高频错 |
|---|---|---|---|
| 库仑定律 | F = kQ₁Q₂/r² | 真空、点电荷 | 用于带电体近距离 |
| 场强定义 | E = F/q | 任意电场 | 与 E=kQ/r² 混用 |
| 点电荷场强 | E = kQ/r² | 真空点电荷 | 叠加时方向错 |
| 匀强电场 | E = U/d | 匀强场，d 沿场线 | d 取成两点距离 |
| 电势差 | U_AB = W_AB/q | 任意电场 | 正负号 |
| 电势能 | Ep = qφ | 需定零势点 | 与电场力做功符号混 |
| 电容定义 | C = Q/U | 任意电容器 | 认为 C 随 Q 变 |
| 平行板电容 | C = εS/(4πkd) | 平行板 | 介质变化判断错 |
| 欧姆定律 | I = U/R | 金属导体、常温 | 用于非线性元件 |
| 闭合电路 | I = E/(R+r) | 闭合回路 | 漏内阻 |
| 路端电压 | U = E − Ir | 闭合回路 | 认为 U 恒定 |
| 电功率 | P = UI = I²R = U²/R | 纯电阻用后两式 | 非纯电阻用 U²/R |
| 焦耳热 | Q = I²Rt | 任意 | 与电功混 |
| 安培力 | F = BIL | B⊥I，L 为有效长度 | 不垂直时忘 sinθ |
| 洛伦兹力 | f = qvB | v⊥B，不做功 | 认为能改变速率 |
| 圆周半径 | r = mv/(qB) | v⊥B | 与周期混 |
| 磁通量 | Φ = BS | B⊥S | 不垂直忘 cosθ |
| 法拉第定律 | E = nΔΦ/Δt | 普遍 | 与动生公式混用 |
| 动生电动势 | E = BLv | B⊥L⊥v | 有效长度判断错 |
| 楞次定律 | 感应电流阻碍磁通量变化 | 一切电磁感应 | 只看方向不看增减 |
| 正弦交流有效值 | U = Um/√2 | 正弦 | 非正弦仍用 |
| 变压器 | U₁/U₂ = n₁/n₂ | 理想变压器 | 用于有漏磁情形 |

## 三、热学

| 公式 | 表达式 | 适用条件 | 高频错 |
|---|---|---|---|
| 状态方程 | p₁V₁/T₁ = p₂V₂/T₂ | 一定质量理想气体 | 质量变化仍用 |
| 热力学第一定律 | ΔU = Q + W | 约定 W 为外界对气体做功 | 符号约定不声明 |
| 分子直径估算 | d ≈ V/S（单分子油膜） | 油膜法 | 单位换算 |

## 四、光学

| 公式 | 表达式 | 适用条件 | 高频错 |
|---|---|---|---|
| 折射率 | n = sin i/sin r = c/v | 光从真空射入介质 | i、r 颠倒 |
| 全反射临界角 | sin C = 1/n | 光密→光疏 | 方向反了 |
| 双缝干涉 | Δx = Lλ/d | 相干光、小角度 | L、d 混淆 |
| 薄膜干涉 | 光程差为半波长奇数倍→暗 | 反射光 | 半波损失漏算 |

## 五、原子与原子核

| 公式 | 表达式 | 适用条件 | 高频错 |
|---|---|---|---|
| 光子能量 | E = hν = hc/λ | 任意光子 | 单位（eV/J）混 |
| 光电效应 | Ek_max = hν − W₀ | 单光子、金属表面 | 认为光强决定最大初动能 |
| 玻尔能级 | hν = E_m − E_n | 氢原子 | 能级差符号 |
| 质能方程 | E = mc² | 核反应 | 质量亏损算错 |
| 半衰期 | m = m₀(1/2)^(t/T) | 大量核统计 | 用于少数原子核 |

## 六、使用提醒

1. 上表所有公式在写进教案或评分细则时，**条件列必须同步出现**，不能只写表达式。
2. 学生最容易错的不是公式本身，是"条件不满足还用"。讲评时优先讲条件。
3. 数值计算用 `scripts/physics_calc.py` 复算，避免有效数字和单位错误。
