# W1 学情首诊

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 学情首诊（czl-chem-intake） |
| **任务职责** | 用孩子自己做出来的材料，把"化学不好"拆成 1—2 个可动手的卡点，并给出六周优先级。不做知识讲授，不出全套题单。 |
| **输入参数** | 必填：年级（高一/高二/高三）、地区与选科（如四川·物化生）、最近一次化学分数或分数段。选填但强烈建议：一份完整卷子（含答题卡）、一道完整计算题的草稿、两道手写方程式、一道推断或流程题原题与作答、学生自述三问、家长观察三问。 |
| **执行步骤** | ①确认年级、教材版本、选科与考试类型（合格考/等级考）→②列证据清单，标出已有与缺失→③逐份读材料，记录失分位置与作答痕迹→④按 E1—E8 编码归因→⑤定 1—2 个主卡点，其余进"观察区"→⑥排六周优先级与本周第一个 20 分钟动作→⑦请家长或学生确认体感是否一致 |
| **判断条件** | 材料 ≥3 份且含一份完整卷子 → 出完整诊断卡；只有分数 → 出"最小诊断版"并注明待补；材料互相矛盾（分数高但方程式全错）→ 以原始作答为准并写明矛盾；发现疑似视力、注意力、情绪问题 → 转介，不做学科归因；跨版本教材（如鲁科版转人教版）→ 先对齐章节再诊断 |
| **输出格式** | 诊断卡（三段：已经会的 / 卡住的 / 待确认的）+ 错因编码表 + 六周优先级表 + 本周第一个 20 分钟动作。全表不超过一屏半。 |
| **异常处理** | 家长代答学生情况 → 说"这三问要孩子自己答，答不上来也是信息"；材料带姓名学校 → 提醒删除，输出用"学生A"；家长要求直接下结论"他就是懒" → 不接受标签，改成可观察行为；孩子拒绝提供材料 → 降级为"家长观察版"，只做时间与习惯诊断；只有一张照片且模糊 → 明确说明"这份诊断的可信度低"，不硬编 |
| **必要依赖** | `references/06-错因编码表.md`（编码定义与判定证据）、`references/08-教材版本与选科差异.md`（版本对齐）、`assets/学情诊断问卷.md`（问法库） |
| **与其他工作流的关系** | 上游：无。下游：把主卡点交给 W2（概念）、W3（方程式）、W4（计算）、W5（推断）或 W6（流程）；六周后把执行记录交给 W7 复盘。**W1 不做完，W7 不启动。** |

## 一、材料怎么要（照抄就能用）

对家长说：

> 不用整理，原样发我就行：①最近一次化学卷子，正反面都拍，包括答题卡上老师批改的地方；②孩子做一道计算题时打的草稿，拍那一张就行——我要看他从哪一步开始乱；③他手写的两个方程式，随便哪两个；④一道他做错的推断题或流程图题，把题干和图一起拍。有这四样，我就能看出大半。

不要一次要十样。要得越多，家长越不给。

对学生本人说：

> 卷子别挑，考得差的那张更有用。我不看分数，我看你在哪一步停下来的。

## 二、读材料读什么

| 材料 | 只看三件事 | 不要看 |
|---|---|---|
| 卷子 | 失分集中在哪两个板块；方程式题有没有"会写但漏条件"；计算题是不是从第二行就崩 | 总分、排名、字迹好坏 |
| 计算草稿 | 有没有写单位；有没有先写"设 n=…"；中间步骤是否跳步；结果有没有回头验算 | 草稿是否整洁 |
| 手写方程式 | 配平了没；条件（△、催化剂、浓/稀）标了没；↑↓ 有没有；可逆号还是等号 | 写字好不好看 |
| 推断/流程作答 | 卡在哪个物质；有没有把已知条件抄到图上；空白处是因为不会还是没时间 | 单题对错 |
| 选择题 | 错的是"概念辨析"还是"计算型"；有没有成组错（说明同一模型没建起来） | 蒙对的题 |

## 三、四类缺口怎么分

同一个"化学不及格"，可能是四种完全不同的原因。分错类，后面全错。

| 缺口 | 典型证据 | 该做什么 | 不该做什么 |
|---|---|---|---|
| 模型缺口 | 结论对但说不出依据；换个情境就错；E1 集中 | 回到微观模型，用一个反例打破错误直觉 | 加做题量 |
| 用语缺口 | 方程式会写但总扣分；E2、E3 集中 | 用检查表逐条对照，一次只改一个符号习惯 | 罚抄整本笔记 |
| 方法缺口 | 会算但算不完；推断题不知从哪头切；E4、E5、E6 集中 | 给固定步骤和题眼库，练三遍 | 直接讲答案 |
| 习惯缺口 | 主观题留白、时间不够、写完不检查、单位从不写 | 改流程与时间分配，不改内容 | 讲道理、谈前途 |

规则：**一次只处理一个缺口。** 四类都写进报告，但只对第一个动手。

## 四、六周优先级怎么排

| 周 | 目标 | 判断达成的标志 |
|---|---|---|
| 第 1 周 | 止血：把"会做但写错"的分拿回来（方程式规范、单位、有效数字） | 同类方程式连续 5 个不再漏条件或漏 ↑↓ |
| 第 2 周 | 立一个模型：主卡点对应的那个微观模型 | 能用自己的话讲清"谁给电子、谁得电子"或"平衡为什么这么移" |
| 第 3 周 | 上一个固定步骤：计算四步法或推断双通道 | 独立做完一道同类题，步骤齐全 |
| 第 4 周 | 迁移：换一个情境（换物质、换条件） | 同一方法在新情境下正确率不低于第 3 周 |
| 第 5 周 | 上强度：限时 | 同题量下用时缩短，正确率不掉 |
| 第 6 周 | 收口：回看六周材料，用同一指标对比 | 能自己说出进步在哪、还差在哪 |

## 五、材料不足怎么办

| 情况 | 给什么 | 必须写清的话 |
|---|---|---|
| 只有分数 | 最小诊断版：三条最可能的卡点 + 一份 3 天材料清单 | "这是按分数段推的，等你发卷子我改。" |
| 只有卷子没有草稿 | 用语 + 模型两层诊断，计算层标注"待补" | "计算这块我不敢下结论，缺草稿。" |
| 家长口述、孩子不配合 | 家长观察版：时间分配、作业完成度、错题处理方式 | "学科结论暂缺，先改流程。" |
| 材料是别人的卷子/网图 | 只做题型分析，不做个人诊断 | "这不是他的卷子，只能讲题。" |

## 七、三条提醒

1. **先判对错再判错。** 孩子做对的地方要点名说出来，否则整份诊断会被当成批评，后面的话他就不听了。
2. **不要用"基础不牢"当结论。** 这四个字等于没说，必须落到具体的物质、具体的步骤、具体的符号。
3. **诊断书的长度和孩子愿意看的长度成反比。** 一屏半是上限，剩下的放你自己心里，下次课再用。
