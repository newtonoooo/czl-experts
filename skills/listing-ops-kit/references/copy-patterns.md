# 文案构建模式库

本文件是写法骨架，不是可直接发布的成品文案。所有示例为说明结构而虚构，不对应任何真实在售商品。

## 一、标题骨架

标题只有一个任务：**在字符预算内，让搜索和人都能确认"这是我要的东西，而且规格对"**。

### 骨架 A · 主词优先（适用于红海类目）

```
[品牌] + [主关键词] + [关键规格] + [结构/材质差异] + [数量/套装]
```

示例结构：`NORDVIK Collapsible Coffee Cup 350 ml Leak-Proof Silicone Cup with Lid`

- 主关键词必须在前 5 个词内。
- 规格用阿拉伯数字 + 单位，不用 "large" 这种相对词。
- 差异点只留一个，留最能与竞品区分的那个。

### 骨架 B · 场景优先（适用于礼品、季节性、人群细分）

```
[品牌] + [主关键词] + [适用人群/场景] + [规格] + [数量]
```

示例结构：`NORDVIK Travel Mug for Commuters 350 ml Insulated Cup 2-Pack`

- 只在主词竞争极强、需要靠长尾切入时使用。
- 场景词必须是买家真的会搜的词，不是你想强调的卖点。

### 骨架 C · 属性堆叠（适用于配件、耗材、标准件）

```
[品牌] + [主关键词] + [适配对象] + [尺寸/规格] + [材质] + [数量]
```

示例结构：`NORDVIK Replacement Gasket for 350 ml Cup Food-Grade Silicone 3-Pack`

- 适配对象必须写清，避免被判为兼容性误导。
- 不写"universal"，除非真的全适配并能举证。

### 标题禁令

| 不要 | 原因 |
|---|---|
| 全大写单词 | 影响可读性，部分类目直接判违规 |
| 符号装饰（★ ✔ 🔥） | 非标准字符，多数类目禁止 |
| 同义词堆砌（cup mug tumbler 连写） | 稀释主词权重，且是典型堆砌特征 |
| 促销语（Sale / Free Shipping） | 与价格体系冲突 |
| 绝对化（Best / #1 / 100%） | 无法举证，属禁止表述 |
| 品牌位编造 | 无品牌就留空，编品牌会导致品牌备案冲突 |

## 二、五点骨架

五点的顺序由**决策权重**决定，不由写作顺序决定。默认权重序：

1. 这个东西解决的核心问题（买家为什么买）
2. 关键规格与适配边界（会不会买错）
3. 结构与材质证据（凭什么信）
4. 使用与维护（买了之后麻不麻烦）
5. 包装内容与售后边界（下单前最后的疑虑）

### 单条结构：锚点 + 利益 + 证据 + 场景

```
**锚点短语（2–4 词）**：一句利益陈述，紧跟一个可验证的证据（数字/材质/结构/标准），最后落到具体使用场景。
```

示例（虚构）：

> **350 ml 刚好一杯**：容量按常见外带杯型设计，装满约 350 ml，杯身直径 8 cm，能放进大多数车型杯架。通勤路上单手开合，不用停车拧盖。

拆解：
- 锚点 `350 ml 刚好一杯`——4 个词以内，一眼知道这条讲什么。
- 利益：容量匹配常见需求。
- 证据：350 ml、8 cm、放得进杯架（可验证）。
- 场景：通勤、单手、不停车。

### 五点常见错误

| 错误 | 表现 | 修法 |
|---|---|---|
| 全是形容词 | "high quality, durable, premium" | 每个形容词换成一个数字或一个结构描述 |
| 五点互相重复 | 三条都在讲"便携" | 合并成一条，腾出的位置写维护或包装 |
| 只讲功能不讲后果 | "double wall" | 补一句"所以外壁不烫手，能直接握" |
| 锚点过长 | 一整句话加粗 | 压到 4 词以内 |
| 结尾写促销 | "buy now" | 删除 |

## 三、描述骨架

描述只写五点和标题放不下的东西。四段式：

1. **一段话说清这是什么**（2–3 句，不重复标题）
2. **使用步骤**（编号 3–5 步，具体到动作）
3. **适配边界与不适用场景**（明确写出"不适合什么"，这条最能降低退货率）
4. **包装清单与维护**（逐项列出，含清洁方式与禁忌）

> 第 3 段是大多数卖家会跳过的一段。写清"不适合什么"看起来在劝退，实际在筛掉错配买家。

## 四、后台搜索词

- 只放标题、五点、描述里**没出现过**的词。
- 不重复、不逗号分隔、不加引号、不写品牌名、不写竞品名、不写拼写错误变体以外的东西。
- 按字节算预算（非 ASCII 字符占更多字节），写完用脚本核一次。

## 五、多站点写作要点

| 站点 | 关键差异 |
|---|---|
| US / CA / AU | Title Case；英制与公制都给；AU 以公制为主 |
| UK | 英式拼写；与 DE 共用部分合规要求 |
| DE | 名词首字母大写，不用 Title Case；复合词长，按字符算预算；必须德语 |
| FR | 标点前后空格规则影响字符计数；必须法语 |
| IT / ES | 句子首字母大写即可；必须本地语言 |
| JP | 汉字 1 字符但信息密度高；全角半角混用会浪费后台字节预算 |

**语言纪律**：非英语站点不要"中文写完机翻"。你不确定的表达标 `[待母语校对]`，把不确定暴露出来，比假装地道安全。

## 六、改写前后对照的记录方式

每次改写都留一张对照表，交付时附上：

| 位置 | 改前 | 改后 | 改的理由 | 字符变化 |
|---|---|---|---|---|

没有这张表，就无法证明改动是有效的，也无法在下次复用判断。
