# AI 推荐就绪度评分口径

这份口径回答一个问题：**这份 Listing 被问答式购物助手引用、被站内搜索结构化召回的概率有多高。**

它不评"文案好不好看"。文采不在计分项里。

满分 100，七个维度。每个维度都由可观测的文本特征判定，不靠感觉。脚本 `score` 子命令按本文件实现，文档与代码必须保持一致。

| # | 维度 | 权重 | 判定方式 |
|---|---|---|---|
| D1 | 属性完整度 | 20 | 8 个标准属性槽位的填充率 |
| D2 | 场景与人群覆盖 | 15 | 命中的场景/人群词类数 |
| D3 | 问答覆盖 | 15 | 10 个买家高频问题探针的覆盖率 |
| D4 | 实体一致性 | 15 | 标题中的规格数字在正文复现率 + 主词在正文复现 |
| D5 | 结构化程度 | 15 | 五点数量、锚点、段落、长度区间 |
| D6 | 差异化证据 | 10 | 带单位数字、材质词、标准/测试引用 |
| D7 | 关键词自然度 | 10 | 主词落位 + 重复度 |

## D1 · 属性完整度（20 分）

八个标准槽位：`material` `color` `size` `weight` `quantity` `audience` `style` `care`。

- 每个槽位在 `attributes` 里非空得 2.5 分。
- 槽位值只写"其他""无""标准"视为未填。
- **为什么重要**：问答式助手优先从结构化属性里取答案，属性缺失时它只能拒答或从别处推断。

## D2 · 场景与人群覆盖（15 分）

场景词类：室内 / 户外 / 通勤旅行 / 办公 / 运动 / 厨房餐桌 / 车载 / 礼品。
人群词类：婴幼儿 / 儿童 / 成人 / 老人 / 宠物。

- 命中 0 类 0 分，1 类 6 分，2 类 10 分，3 类及以上 15 分。
- **为什么重要**："适合谁、在哪用"是问答场景里最高频的两类追问。

## D3 · 问答覆盖（15 分）

十个探针，每个探针有一组触发词，命中任一即算已答：

| 探针 | 触发词方向 |
|---|---|
| 尺寸多大 | cm / mm / inch / 尺寸 / 长宽高 |
| 什么材质 | 材质词（silicone / cotton / ABS / stainless / 硅胶 / 棉 / 不锈钢） |
| 多重 / 容量 | g / kg / oz / ml / L / 重量 / 容量 |
| 怎么清洁 | wash / clean / dishwasher / 清洗 / 可机洗 |
| 适合谁 | for + 人群词 / 适合 |
| 包装里有什么 | includes / package / 1 x / 含 / 配件 |
| 兼容什么 | compatible / fits / 适用 |
| 安全吗 | safe / safety / 圆角 / 无毒 / 认证 |
| 怎么用 | step / how to / 安装 / 使用步骤 |
| 耐用吗 | durable / 耐磨 / 寿命 / 保修 |

得分 = 命中数 / 10 × 15。

## D4 · 实体一致性（15 分）

- 从标题抽出所有"数字+单位"规格（如 `750ml`、`12 oz`、`30 cm`），检查是否在五点或描述中出现。占比 × 10。
- 标题的前三个实词（去停用词）是否在五点或描述中出现。全部出现得 5，部分出现按比例。
- **为什么重要**：同一份 Listing 里规格自相矛盾，是被助手判为低可信内容的最常见原因。

## D5 · 结构化程度（15 分）

- 五点数量恰好 5 条：5 分；4 或 6 条：3 分；其他：0 分。
- 每条五点以加粗短语开头（`**...**` 或 `【...】`）：每条 0.8 分，上限 4 分。
- 描述有 ≥2 个空行分段：3 分。
- 描述长度落在 400–2000 字符：3 分。
- 合计上限 15。

## D6 · 差异化证据（10 分）

- 五点中带单位的数字（cm/mm/inch/ml/oz/g/kg/L/lb）：0 个 0 分，1–2 个 4 分，3 个及以上 7 分。
- 出现具体材质词：2 分。
- 出现标准/测试/结构证据（如 `EN 71`、`drop tested`、`double wall`、`食品级`）：1 分。

## D7 · 关键词自然度（10 分）

- 主关键词出现在标题：4 分。
- 主关键词出现在至少一条五点：3 分。
- 标题中最高频实词出现次数 ≤ 3：3 分；4 次：1 分；5 次及以上：0 分（堆砌）。

## 分数怎么读

| 区间 | 含义 | 建议动作 |
|---|---|---|
| 85–100 | 结构完整，可被稳定引用 | 保持，转向图片与评论 |
| 70–84 | 有明确缺口 | 按扣分项补，通常补 D1 + D3 收益最大 |
| 50–69 | 只能回答基础问题 | 重写五点结构，补齐属性 |
| 0–49 | 基本无法被结构化召回 | 重写，不要局部修补 |

## 三条使用纪律

1. 分数是坐标，不是承诺。85 分不代表会爆，只代表"信息结构上没明显漏洞"。
2. 扣分项必须逐条给出**可执行的改写动作**，只给分数等于没交付。
3. 每次重写后重跑，用分数变化证明改动有效——不要用"感觉更好了"结案。
