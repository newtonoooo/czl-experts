# W4 三表编制与勾稽

三表不是三张独立的表。它们是同一套账的三种视图：资产负债表是时点，利润表是期间，现金流量表是期间的现金切片。三者之间的连接点断了，表就一定有问题。

## 工作流卡片

| 字段 | 内容 |
|------|------|
| **工作流名称** | W4 三表编制与勾稽（statement-tieout） |
| **任务职责** | 从试算平衡表出三大表，跑通五条勾稽关系，标出列报与附注需处理的事项 |
| **输入参数** | 科目余额表（含期初/本期发生/期末）；损益类结转结果；所有者权益变动数据（分配、资本公积变动）；现金流量明细或间接法调整项；上期报表；期间与单位 |
| **执行步骤** | ① 校验试算平衡 → ② 结转损益 → ③ 出资产负债表（先资产后负债再权益） → ④ 出利润表 → ⑤ 出现金流量表（间接法为主，直接法补充） → ⑥ 跑 `tieout` 五条勾稽 → ⑦ 列报与附注检查 → ⑧ 出勾稽校验单 |
| **判断条件** | 任一勾稽差额 ≠ 0 → 不得发布，按"差在哪张表哪一行"倒查；试算不平衡 → 回到 W3；现金流量表期末现金与货币资金不等 → 优先查受限资金与现金等价物口径 |
| **输出格式** | 三张报表 + 勾稽校验单（逐条通过/不通过/差额）+ 列报调整建议 + 附注提示清单 + 未决事项 |
| **异常处理** | 无现金流量明细 → 用间接法从净利润倒推，并标注"间接法编制，未做直接法交叉验证"；存在外币报表折算 → 单独列折算差额，不并入当期损益；本期有以前年度损益调整 → 在权益变动与利润表间做衔接说明 |
| **必要依赖** | `bin/ledgerkit.py tieout`；上游 W3 的对账结果（余额必须已核实） |
| **与其他工作流关系** | 上游 W2/W3；下游 W5（差异分析以本表数据为基础）；W6 的 T+4/T+5 依赖本工作流产出；勾稽不过则回流 W3 |

## 编制顺序（不可颠倒）

```
科目余额表 → 试算平衡 → 结转损益（本年利润）
      → 资产负债表（资产=负债+权益 必须当场成立）
      → 利润表（净利润必须等于结转进本年利润的数）
      → 现金流量表（期末现金必须等于资产负债表货币资金）
```

顺序颠倒的典型症状：先做利润表再做资产负债表，结果权益那头永远差一个"净利润"，然后开始编调平分录。

## 五条勾稽关系

| # | 关系 | 依据 | 差额常见原因 |
|---|------|------|-------------|
| 1 | 资产 = 负债 + 所有者权益 | 会计恒等式 | 漏结转损益、科目串表、抵销未做 |
| 2 | 未分配利润期末 = 期初 + 净利润 − 分配 | 权益变动衔接 | 利润表净利润与结转数不一致、分红未过账 |
| 3 | 现金流量表期末现金 = 资产负债表货币资金 | 现金口径 | 受限资金未剔除、现金等价物口径不一致 |
| 4 | 期初现金 + 经营 + 投资 + 筹资 = 期末现金 | 现金流量表加法 | 汇率变动影响未单列、分类遗漏 |
| 5 | 间接法起点净利润 = 利润表净利润 | 补充资料衔接 | 两张表用了不同版本净利润（调整前后混用） |

```bash
python bin/ledgerkit.py tieout -f 三表数据.json
```

一项不通过就不出报告。**不允许**用"表格取整差异"解释，除非你能指出具体是哪一行、差多少分、为什么。

## 资产负债表列报要点（CAS 30）

- **流动/非流动划分**：以 12 个月或一个营业周期为界；一年内到期的非流动负债必须重分类到流动负债。
- **应收账款**：按减去坏账准备后的净额列示；坏账政策在附注披露，本期计提/收回/核销要做变动表。
- **存货**：成本与可变现净值孰低；跌价准备单独披露本期计提与转回。
- **合同资产 / 合同负债**：按履约进度与收款权利区分，不得与应收账款混列。
- **其他应收款**：金额异常的必须逐笔说明性质，这是审计最常问的一栏。
- **递延所得税**：资产与负债分别列示，不得抵销（除非同一税务机关且可依法抵销）。
- **未分配利润**：与利润表、权益变动表三处数字必须一致。

## 利润表列报要点

- 收入按主营业务/其他业务分列；与收入对应的成本同期同口径结转。
- 期间费用四项（销售、管理、研发、财务）不得合并成一栏"费用"。
- 其他收益（政府补助）、投资收益、公允价值变动损益、信用减值损失、资产减值损失单列。
- 所得税费用 = 当期所得税 + 递延所得税；与利润总额×税率不一致的必须能解释（纳税调整）。
- 终止经营损益单列（如有）。

## 现金流量表编制要点

**间接法调整项清单**（从净利润倒推经营活动现金流）：

| 调整方向 | 项目 |
|---------|------|
| 加回 | 资产减值准备、信用减值损失、固定资产折旧、无形资产摊销、长期待摊费用摊销 |
| 加回 | 处置资产损失、公允价值变动损失、财务费用（筹资相关）、递延所得税资产增加/负债减少 |
| 扣除 | 处置资产收益、公允价值变动收益、递延所得税资产减少/负债增加 |
| 调整 | 存货减少、经营性应收减少、经营性应付增加（反向则减） |

**三个分类不准混**：利息支出通常归筹资；收到的税费返还归经营；与资产相关的政府补助按性质归投资或经营，且需前后期一致。

## 常见错误自查（12 条）

1. 试算不平衡就直接出表
2. 损益未结转，"本年利润"里还留着余额
3. 应收账款按总额列示，未扣坏账准备
4. 一年内到期的长期借款未重分类
5. 应交税费负数挂在资产方，未区分留抵税额与多缴税款
6. 现金流量表投资/筹资分类按"付款用途"而非"款项性质"
7. 受限资金计入"现金及现金等价物"
8. 净利润在利润表与权益变动表里不是同一个数
9. 期间费用漏分研发费用（高新技术企业常见）
10. 政府补助全额进当期损益，未区分与资产相关
11. 外币报表折算差额进损益
12. 报表单位不统一（元与万元混用）

## 附注提示清单

出表时同步提示哪些附注必须写，不做就当未完成：

- 会计政策与会计估计变更（本期有无、影响金额）
- 应收账款账龄与坏账准备变动
- 存货构成与跌价准备
- 固定资产本期增减（原值、累计折旧、减值）
- 应交税费明细（增值税、企业所得税、个税、附加）
- 关联方及关联交易（金额、定价方式、未结算余额）
- 或有事项与承诺事项
- 期后事项（报表日至批准报出日）
- 分部信息（如需）
- 现金流量表补充资料

## 勾稽不平的倒查顺序

1. **先看第 1 条**：不平说明账本身有问题（科目串表/未结转）。回到 W3。
2. **再看第 2 条**：差的是净利润衔接，查"本年利润"结转与分红过账。
3. **第 3、4 条一起看**：现金口径问题，查受限资金、现金等价物定义、汇率变动影响。
4. **第 5 条**：两处净利润版本不一致，统一到最终版再跑。

四步走完仍不平，把差额与已排除原因写进未决事项，不许用调平分录收尾。
