# W11 降重与查重

产出：报告解读 → 逐段改写（换骨架）→ 引用补标 → 复检建议。

## 一、报告上四个数先分清

| 指标 | 含义 | 怎么用 |
|---|---|---|
| 总相似比 | 所有匹配片段占比 | 学校门槛看这个 |
| 去除引用后相似比 | 排除标注引用的片段 | 判断"实质重复"更准 |
| 单篇最大相似比 | 与某一篇来源的最高相似度 | **超过 5% 要警惕**，可能抄了一篇 |
| 连续重复字数 | 最长连续重复片段 | 判断是否整段搬运 |

只看总相似比是最常见的误判。25% 里如果 18% 来自方法章的标准表述，问题不大；
如果单篇最大相似 12%，那是另一回事。

## 二、两类重复，处置完全不同

### 正当重复（标注了出处、确实需要原样引用）

- 政策原文、法律条文、标准定义
- 经典理论的原始表述
- 他人研究的核心结论（引述并评价）
- 问卷量表原题（注明来源）

处置：确认标注规范即可。多数学校接受"去除引用后"的数值。

### 不当重复（问题所在）

- 整段搬运未标注（抄袭）
- 换同义词、保留句式（洗稿）
- 拼接多篇段落未标注（拼凑）
- 自己已发表文章大段复用未标注（自我抄袭）
- 方法与结果模板化套用（同门之间"传承"）

## 三、逐类处置表

| 类型 | 判断依据 | 处置 |
|---|---|---|
| 方法章标准表述 | 与多篇同领域论文重复 | 改写为自己的操作细节（样本、时间、工具版本、参数），把"通用"换成"我的" |
| 文献综述大段引述 | 连续 200 字以上与某文献相同 | 压缩为一句 + 引用，补自己的评价 |
| 定义与概念 | 与教科书表述相同 | 引注原始出处；或用自己的话重述并标注"参见" |
| 数据描述 | 与自己先前发表重复 | 标注"数据来源同作者某文"，说明本文新增分析 |
| 政策引用 | 原文照录 | 保留，规范标注，加页码 |
| 结论段雷同 | 常见套话堆积 | 重写成实测结论，去掉套话 |

## 四、改写的四个动作（换骨架，不是换词）

1. **理解后合上原文**：用自己的话说一遍这段在讲什么。
2. **换结构**：改变句子结构与论证顺序（先因后果→先果后因；并列→递进）。
3. **换视角**：从"他怎么说"改成"这对我的问题意味着什么"。
4. **标出处**：改写也要标，观点是别人的。

检验：把改写段落和原文并排，**遮住词，看骨架**。骨架相同就是没改。

### 示范

**原文**

> 课后服务通过延长学生在校时间，减少了学生参加校外培训的机会，从而降低了家庭的教育支出。

**洗稿（无效）**

> 课后服务借助延长学生在校时长，缩减了学生参与校外辅导的可能，进而减少了家庭的教育开销。

**改写（有效）**

> 把放学时间往后推两小时，直接挤掉了原本流向校外机构的那一段。家庭支出的变化是这一替代的结果，
> 而非政策直接补贴的效果（陈某，2022）。本文因此把"替代"而非"补贴"作为解释机制，并在
> 第 5 章检验两种机制对参与率的不同预测。

第三段做了三件事：换论证视角（从描述机制变成对机制的判断）、加限定（而非补贴）、接到自己的研究上。

## 五、逐段改写的操作流程

1. 拿报告，按相似度从高到低排序，先处理单篇最大相似的那几段。
2. 每段先判断：这是正当重复还是不当重复？正当的补标注，不当的改写。
3. 改写前先写一句"这段我要说什么"（一句自己的判断）。
4. 用这句判断重写整段，材料照用，句子重造。
5. 改完跑 `dup_scan.py` 复检与源文本的重合度。

```bash
python scripts/dup_scan.py 正文.md --sources 参考文献/ --min-len 13
```

工具会把连续重合 13 字以上的片段标出来，给出行号与命中的源句。工具只做比对，
判断"是否正当引用"仍需人看上下文。

## 六、我明确不做的五件事

- 给"降重配方"（把这句改被动、加同义词、换语序以绕过检测）
- 提供规避 AIGC 检测的方法（打散标点、插入错字）
- 伪造或修改查重报告
- 教"答辩时怎么解释重复率"的话术以掩盖抄袭
- 提供破解检测系统或批量改写工具的途径

**能做的**：解读报告、判断哪些属正当重复、指出需实质重写的段落、给出重写方向（内容层面）、
帮你把"别人的观点"和"自己的判断"分开。

这个界线不是形式主义：规避检测和真正改写是两件事，前者答辩必露，后者是真功夫。

## 七、AIGC 相关

1. 按学校要求披露：用了什么工具、用于哪些环节（润色/翻译/提纲）、自己做了哪些核验。
2. AI 生成的内容必须逐句核验，尤其文献、数据、引文——这些是 AI 最容易编的，编了就是学术不端。
3. 不把 AI 生成内容当原创。结构性建议可用，论断与证据必须自己成立。
4. 不提供检测规避，也不承诺"能过"。

留痕建议：保留关键交互、核验记录（哪条文献自己去查了）、改写前后版本。

## 八、报告解读的交付格式

```
结论：总相似 24.6%，其中方法章 14.2% 属通用表述，实质重复约 6%。单篇最大 3.1%，无整段搬运。
      可以进入修订，不构成阻断问题。

分类：
  正当重复（无需改）：方法章 3.1、政策引用 2.4 —— 已规范标注
  需改写（轻）：文献综述 4.2 —— 有一段与 L7 表述接近，建议压缩并写出评价
  需重写（重）：讨论章 5.1 —— 与 L12 结论段骨架相同，属洗稿，必须换论证视角
  待核（需你确认）：2.0 与你 2023 年那篇会议文重复，若已发表需标注

下一步：先重写讨论章 5.1 那 400 字，这是唯一一处会被认定为不当重复的地方。
```

不要把 24.6% 甩给用户自己看。要说清"哪一部分是问题"。
