# W12 引用与格式

产出：排好格式的参考文献表 + 图表格式修正 + 格式核对清单。

## 一、先定以谁为准

冲突顺序：**学校/期刊官方模板 > GB/T 7714-2015 > 全文统一**。

三处最常见的冲突，不要自己拍板，摆出来让用户问导师或编辑部：

| 冲突点 | 国标 | 学校模板常见 |
|---|---|---|
| 文献类型标识 | 必须标 `[J]` `[M]` | 部分要求省略 |
| 作者数量 | 超 3 人列前 3 加"等" | 有的要求全列 |
| 页码 | 期刊给起止页 | 有的只要起始页 |

## 二、GB/T 7714-2015 类型标识

| 标识 | 类型 | 标识 | 类型 |
|---|---|---|---|
| `M` | 专著 | `J` | 期刊论文 |
| `C` | 论文集 | `D` | 学位论文 |
| `N` | 报纸 | `R` | 报告 |
| `S` | 标准 | `P` | 专利 |
| `A` | 析出文献 | `Z` | 其他 |
| `EB/OL` | 电子公告 | `J/OL` | 在线期刊 |

## 三、五类条目的要素

### 期刊 `[J]`

```
主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
陈某, 王某. 县域课后服务参与率调查[J]. 教育研究, 2022, 43(5): 45-52.
```

必查：作者、题名、`[J]`、刊名、年、卷或期、页码。

### 专著 `[M]`

```
主要责任者. 题名[M]. 版本项. 出版地: 出版者, 出版年: 页码.
某某. 教育社会学[M]. 2 版. 北京: 高等教育出版社, 2020: 88-92.
```

**出版地缺失是最常见错误**——"北京: 高等教育出版社"不能只写出版社。

### 学位论文 `[D]`

```
主要责任者. 题名[D]. 保存地: 保存单位, 年份.
王某. 通勤时间与课后服务选择[D]. 上海: 华东师范大学, 2021.
```

### 析出文献 `[A]`

```
析出责任者. 析出题名[A]//专著责任者. 专著题名. 出版地: 出版者, 年: 页码.
```

注意 `//` 这个连接符，写成"见"或"In"都不合国标（英文文献可用 In）。

### 电子资源 `[EB/OL]`

```
责任者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
教育部. 关于做好课后服务工作的通知[EB/OL]. (2021-07-20)[2024-03-12]. http://www.moe.gov.cn/xxx.
```

**缺引用日期是电子资源最常见的错误。**

## 四、其他常用格式（换刊时对照）

| 格式 | 期刊论文样式 |
|---|---|
| GB/T 7714 | 陈某, 王某. 县域课后服务参与率调查[J]. 教育研究, 2022, 43(5): 45-52. |
| APA 7 | Chen, X., & Wang, M. (2022). Participation in county after-school programs. *Educational Research, 43*(5), 45–52. https://doi.org/10.xxxx |
| MLA 9 | Chen, Xin. "Participation in County After-School Programs." *Educational Research*, vol. 43, no. 5, 2022, pp. 45–52. |
| IEEE | X. Chen and M. Wang, "Participation in county after-school programs," *Educational Research*, vol. 43, no. 5, pp. 45–52, 2022. |

转换注意：APA/IEEE/MLA 需要**姓前名后 + 名字缩写**。中文姓名要转拼音并调序
（"陈某"→"Chen, X."），这一步机器做不准，必须人工核。`cite_format.py` 会给出结构转换结果
并标记"姓名需人工调整"的条目——**不要直接交稿**。

## 五、十条高频错误

| # | 错误 | 后果 |
|---|---|---|
| 1 | 缺 `[J]` 等类型标识 | 无法解析，形式审查退回 |
| 2 | 期刊缺页码 | 无法核验 |
| 3 | 专著缺出版地 | 同上 |
| 4 | 电子资源缺引用日期 | 同上 |
| 5 | 全角半角标点混用 | 显得不专业 |
| 6 | 作者超 3 人未用"等/et al." | 与国标不符 |
| 7 | 同一文献出现两个编号 | 正文引用混乱 |
| 8 | 编号跳号（7 后直接 9） | 说明删过文献没改正文 |
| 9 | **正文编号与文献表错位** | 最严重，属引用不实 |
| 10 | DOI 拼写错误打不开 | 说明是拼的 |

第 9 条要人工核：脚本只查文献表内部一致性。

## 六、图表格式

| 项 | 要求 |
|---|---|
| 编号 | 按章编（图 3-1）或全文连续（图 1），全文只能一种 |
| 题注 | 图题在下、表题在上（中文惯例） |
| 三线表 | 顶线、表头线、底线，无竖线 |
| 单位 | 坐标轴与表头必须标（"参与率（%）"） |
| 注 | 表下注明数据来源与显著性标记 |
| 引用 | 正文必须有"如图 3-1 所示" |
| 分辨率 | 位图 ≥300 dpi，线条图用矢量 |

跑 `figtable.py` 查编号连续性与引用悬挂；三线表与分辨率要人工看。

## 七、页面与版式（只能对着模板核）

- 纸张与页边距（上下左右、装订线）
- 正文字体字号、各级标题字体字号、行距、段前段后
- 页眉页脚（学校名、题目、页码位置与格式）
- 标题最多几级、编号制（1 / 1.1 / 1.1.1 还是 一、（一）1.）
- 目录层级与是否自动生成
- 摘要、关键词、附录、致谢的顺序与格式
- 参考文献表位置（正文后还是每章后）

## 八、核对流程

```bash
python scripts/cite_format.py 参考文献.md            # 检查
python scripts/cite_format.py 参考文献.md --to apa   # 转换（换刊/英文稿用）
python scripts/figtable.py 正文.md                   # 图表编号与引用
```

然后人工补三件事：

1. 正文引用编号与文献表逐条对（抽查 10%，全部核更好）。
2. 每条文献是否真的支持它所在的那句判断（内容问题，脚本查不了）。
3. 模板逐项对照，用勾选表，别凭印象。

## 九、参考文献表排序

- **顺序编码制**：按正文首次出现顺序编号（多数中文期刊与学位论文）。
- **著者-出版年制**：按作者字母/拼音排序，正文用（作者, 年）。

混用是最常见的低级错误：正文 `[1]`，文献表按拼音排。脚本会报编号不连续，但混排要人看。

## 十、工具与工作流

- **Zotero**：免费开源，浏览器抓元数据最方便，Word 插件可自动生成文献表，GB/T 7714 样式需从样式库安装。
- **NoteExpress**：中文文献支持好，知网导出直接导入。
- **EndNote**：期刊兼容性最好，多数刊物提供样式文件。

流程：库导出 RIS/BibTeX → 导入工具 → 补全缺失字段 → 工具生成文献表 → 导出 Word 后再跑一次 `cite_format.py`。
**不要手工敲文献表**，那是错误的主要来源。

## 十一、交付格式

```
一、参考文献表（已按目标格式排好，可直接粘贴）
二、修改清单（哪几条补了什么字段）
三、需人工处理的条目（姓名调序、语言混排、机构作者）
四、格式核对清单（对照学校模板逐项勾选）
```
