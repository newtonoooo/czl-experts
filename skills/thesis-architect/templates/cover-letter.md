# 投稿信模板（Cover Letter）

> 一页以内，四段。不要写"本研究具有重大意义"，写具体。

## 模板 A：常规投稿

```
Dear Editor,

We submit our manuscript entitled "____" for consideration as a [research article / brief report /
review] in [Journal Name].

The paper asks ____. Using ____ (data, n = ____), we find that ____. This matters because ____.
We believe it fits the journal's recent attention to ____, particularly the discussion in
[Author] ([Year], Vol. __, No. __).

The manuscript is original, has not been published elsewhere, and is not under consideration
by another journal. All authors have approved the submission and declare no conflict of interest.
[Ethical approval: ____, approval no. ____.]

Thank you for your consideration.

Sincerely,
[Name], [Affiliation]
[Email] | [ORCID]
```

## 模板 B：换刊重投（被拒后）

第二段加一句，说明前次评审意见如何改进了稿件（不要提刊名，不要抱怨）：

```
An earlier version of this work was reviewed elsewhere. In response to those comments we have
[strengthened the identification strategy / added a robustness check / expanded the sample],
which we believe substantially improves the paper.
```

## 模板 C：约稿/专刊投稿

第一段改为回应征稿：

```
We submit the enclosed manuscript in response to your call for papers on ____.
```

第二段最后加一句说明与专刊主题的契合。

## 四条禁忌

1. 不写"本研究填补了国内外空白"——编辑最反感。
2. 不列全部作者履历——一页装不下，也没人看。
3. 不承诺"如能被录用，我们将……"。
4. 不群发同一封信（编辑能看到称呼是否写错刊名）。

## 附：投稿材料清单

- [ ] 正文（按刊物模板排版）
- [ ] 标题页（作者、单位、通讯作者、基金号）
- [ ] 中英文摘要与关键词
- [ ] 参考文献（按刊物样式，跑 `cite_format.py`）
- [ ] 图表源文件（矢量优先，位图 ≥300 dpi）
- [ ] 作者贡献声明 / 利益冲突声明
- [ ] 伦理审批说明与批号
- [ ] 数据可用性声明
- [ ] 投稿信（本模板）
- [ ] 推荐审稿人（如要求，注意回避利益关系）
