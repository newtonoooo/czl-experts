# 分章写作卡

> 每写一章前先看这张卡，写完按卡自查。六章通用。

## 第 1 章 引言

| 项 | 内容 |
|---|---|
| 要回答 | 这个问题为什么值得研究？别人缺什么？我要做什么？ |
| 字数 | 8—10%（本科 800—1200 字，硕士 1500—2500 字） |
| 四段 | 背景（带数据）→ 缺口（三条文献 + 一个"但"）→ 问题与目的 → 贡献与结构 |
| 不许写 | 综述式铺陈、结果预告、"具有重大意义" |
| 自查 | 有具体数字？有明确研究问题句？贡献与缺口一一对应？ |

## 第 2 章 文献与框架

| 项 | 内容 |
|---|---|
| 要回答 | 前人做到哪？分歧在哪？我用什么概念工具分析？ |
| 字数 | 20—25% |
| 四段 | 分组评述（3—5 组）→ 分歧解释 → 概念界定 → 分析框架 |
| 不许写 | 编年罗列、只引结论不引方法、与后文无关的概念 |
| 自查 | 每组末尾有"所以"？至少一条冲突文献？框架在第 4/5 章真用到了？ |

## 第 3 章 研究设计

| 项 | 内容 |
|---|---|
| 要回答 | 别人照着我写的能不能重做一遍？ |
| 字数 | 15—20% |
| 六节 | 设计 → 对象与抽样 → 工具 → 程序（含伦理）→ 分析 → 效度威胁 |
| 不许写 | 教科书式的"问卷法简介"、只写做法不写理由 |
| 自查 | 每个选择都有理由和代价？样本量/回收率/缺失有数字？信效度报了？三条威胁是本研究的具体问题？ |

## 第 4 章 结果

| 项 | 内容 |
|---|---|
| 要回答 | 数据说了什么？（不说为什么） |
| 字数 | 20—25% |
| 结构 | 按研究问题排，节标题即结论方向 |
| 不许写 | "这说明……"、重复数字表、无效应量的显著性 |
| 自查 | 每个统计结论带效应量/CI？表是三线表有单位有注？图有"如图 X 所示"？ |

## 第 5 章 讨论

| 项 | 内容 |
|---|---|
| 要回答 | 为什么是这样？和谁一致/冲突？到哪为止？ |
| 字数 | 15—20% |
| 四段 | 发现重述（不带新数字）→ 与文献对话（必有冲突）→ 机制（触发—中间—结果）→ 边界 |
| 不许写 | 复述结果表、只有一致没有冲突、"可能与社会环境有关" |
| 自查 | 有至少一条冲突文献并解释？机制写得能"拍出来"？三条局限各带影响？ |

## 第 6 章 结论与建议

| 项 | 内容 |
|---|---|
| 要回答 | 回答了开篇的问题吗？所以该怎么办？ |
| 字数 | 5—8% |
| 三段 | 回答研究问题 → 分层建议（每条追到结果）→ 后续方向 |
| 不许写 | 新数据、新内容、"有待进一步研究" |
| 自查 | 第一段回扣引言？每条建议能指回某条结果？后续方向具体可做？ |

## 通用自查（每章都过）

- [ ] 首段独立说清"本章干什么"
- [ ] 每段有判断句，无纯资料段
- [ ] 每条引用在支撑它所在的那句判断
- [ ] 无空转句式（跑 `style_lint.py`）
- [ ] 字数在预算 ±15%（跑 `wordstat.py`）
- [ ] 占位符 `〔待补〕` 与 `〔核验〕` 已列清单
