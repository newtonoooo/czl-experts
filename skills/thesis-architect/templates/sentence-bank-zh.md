# 中文学术句式库

> 取材用的，不是抄的。取一句的骨架，换成你的内容，别整段搬。

## 一、起段与定位

1. 围绕……，近十年形成了三条相对独立的研究脉络。
2. 关于……的讨论，主要集中在三个方面：……、……与……。
3. 本节先说明数据来源与样本构成，再报告描述统计与组间比较。
4. 要回答这一问题，需要先厘清两个概念：……与……。
5. 上述判断成立与否，取决于一个前提：……。

## 二、提问题与立论点

6. 本研究要回答的问题是：……？
7. 具体而言，本文考察三件事：……、……与……。
8. 与既有研究不同，本文把……作为解释变量。
9. 本研究不讨论……，只聚焦于……。
10. 本文的核心判断是：……，而非……。

## 三、呈现分歧

11. 支持方认为……（L1 L2）；持相反意见的研究则强调……（L3 L4）。
12. 上述结论的差异，可能来自样本、测量口径或模型设定的不同。
13. 两项结论相反的研究使用了同一批数据，差异主要出现在因变量的构造上。
14. 这一分歧至今未获解决，原因之一是缺乏可比的县域样本。

## 四、评价文献

15. 该研究的主要贡献在于……，但其样本仅覆盖……，外推需谨慎。
16. 这一结论在……条件下成立，一旦……则未必。
17. 上述研究普遍未处理……问题，这为本文留下了空间。
18. 该文的测量方式值得借鉴，但其对……的处理较为粗略。

## 五、收口与过渡

19. 综合来看，已有研究在……方面积累了较充分证据，但在……方面仍显不足。
20. 因此，本研究不重复验证……，而是转向……。
21. 如果说上述研究回答的是"有没有"，那么尚未回答的是"为什么"。
22. 上述分析确认了差异的存在，但尚未说明差异如何形成。
23. 由此可以确认……，接下来要问的是……。

## 六、报数据

24. 三校参与率分别为 82.1%、64.5% 与 48.7%，相差 33 个百分点。
25. 差异在统计上显著（F(2, 309) = 24.7，p < .001，η² = 0.14），效应量处于中等水平。
26. 通勤时间与参与时长呈负相关（r = −0.38，p < .001），即通勤每增加 30 分钟，周参与时长减少约 0.7 小时。
27. 控制家庭收入后，通勤时间的系数为 −0.24（SE = 0.05，p < .001），家庭收入不显著。
28. 该模式在三个子样本中保持一致（见附录表 A1）。
29. 受样本限制，该估计不够稳定，此处仅作描述性报告。

## 七、解释与机制

30. 这一差异可以归因于……。
31. 其作用路径可能是：……，进而……。
32. 一个可检验的推论是：若……成立，则在……中应观察到……。
33. 机制上，……直接替代了原本……的时段。
34. 这一结果提示，……并非通过……起作用，而是通过……。

## 八、处理替代解释

35. 一种可能的解释是……，但这一解释难以说明……。
36. 另一种解释是……，本研究的数据不足以区分二者，需后续检验。
37. 上述替代解释可以部分成立，但无法解释……这一事实。

## 九、交代限制

38. 本研究的主要局限有三：其一，……；其二，……；其三，……。
39. 受横截面设计限制，本研究无法排除反向因果。
40. 样本来自三所县域学校，外推至城区需谨慎。
41. 参与时长依赖家长自报，可能高估实际到课。

## 十、结论与建议

42. 由此可以回答本文提出的问题：……。
43. 本研究不主张……，只主张……。
44. 在……条件下，这一结论成立；超出该条件，需另行检验。
45. 就实践而言，……的关键不在……，而在……。
46. 后续需纵向追踪同一批学生，以识别因果方向。

## 十一、引用嵌入

47. 已有研究表明……（陈某，2022）。
48. 陈某（2022）在 X 县发现……，但样本仅两所学校。
49. 这一判断可追溯至……的经典表述（L5：47）。
50. 与……的结论相反，本文认为……。

## 十二、质性材料引用

51. 家长 C（女，38 岁，务农）说："……"
52. 这一说法在低参与组 8 位家长中出现 6 次，构成该组最集中的解释。
53. 相较之下，高参与组家长多能自行接送，时间约束不明显。
54. 教师的说法略有不同：……（教师 B，男，教龄 12 年）。

## 十四、慎用与禁用

| 慎用/禁用 | 换成 |
|---|---|
| 随着……的不断发展 | 具体时间 + 具体事件 |
| 具有重要的理论意义和现实意义 | 对哪个理论/哪类实践有用 |
| 在一定程度上 | 具体量级 |
| 起到了积极的推动作用 | 具体机制 |
| 众所周知 / 值得注意的是 | 删 |
| 综上所述 | 一句实质结论 |
| 有待进一步深入研究 | 具体设计 + 具体情境 |
| 越来越多的研究 | 近五年有 N 项研究（列编号） |
