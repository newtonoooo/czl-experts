# 格式核对清单

> 对着学校模板逐项勾。勾完再交，别凭印象。

## 一、整体

- [ ] 纸张与页边距（上 / 下 / 左 / 右 / 装订线）
- [ ] 页眉内容（学校名 / 论文题目）与位置
- [ ] 页脚页码格式（位置、起始页、罗马数字与阿拉伯数字分段）
- [ ] 行距、段前段后
- [ ] 正文与各级标题字体字号
- [ ] 标题最多几级、编号制（1 / 1.1 / 1.1.1 或 一、（一）1.）

## 二、前置部分

- [ ] 封面（校名、题目、姓名、学号、专业、导师、日期）
- [ ] 独创性声明 / 授权书（是否需手写签名）
- [ ] 中文摘要（字数、关键词 3—5 个）
- [ ] 英文摘要（与中文对应）
- [ ] 目录（层级、页码、是否自动生成、是否含图表目录）
- [ ] 图表清单（如要求）

## 三、正文

- [ ] 每章另起页
- [ ] 图表编号制统一（章序 or 全文序）
- [ ] 图题在下、表题在上
- [ ] 表格三线表，无竖线
- [ ] 坐标轴与表头有单位
- [ ] 表下有数据来源注
- [ ] 公式编号右对齐，连续
- [ ] 正文引用与文献表编号对应
- [ ] 术语全文一致

## 四、参考文献

- [ ] 格式统一（GB/T 7714 或模板要求）
- [ ] 类型标识齐全
- [ ] 期刊有年卷期页
- [ ] 专著有出版地与出版者
- [ ] 学位论文有学校与年份
- [ ] 电子资源有引用日期与 URL
- [ ] 编号连续，无重复条目
- [ ] 排序方式统一（顺序编码制 or 著者-出版年制）

## 五、后置部分

- [ ] 附录（编号 A、B；表 A1；正文有引用）
- [ ] 致谢（是否单独成页、字数）
- [ ] 攻读学位期间成果（如要求）
- [ ] 页数是否达标

## 六、自动检查

```bash
python scripts/cite_format.py 参考文献.md
python scripts/figtable.py 正文.md
python scripts/wordstat.py 正文.md --target 字数
python scripts/abstract_check.py 正文.md
```

## 七、人工必核（脚本查不了）

- [ ] 正文引用编号与文献表逐条对照（抽查 10%）
- [ ] 每条文献是否真支持它所在的那句判断
- [ ] 模板逐项对照（本清单）
- [ ] 图片分辨率 ≥300 dpi
- [ ] 打印预览一遍，看分页是否难看（表格跨页、标题孤行）
