# 工序 ③ 装配

## 名称

装配（Assembly）——先立骨架，再一块一块装，装一块就能用一次。

## 任务职责

把数据账变成可运行的单文件 HTML。核心纪律是**骨架先跑通，模块后填装**：骨架不通就填模块，最后一定在"为什么页面是白的"上耗掉半天。

## 输入参数

| 参数 | 必需 | 说明 |
|---|---|---|
| `scope_card` | 是 | 收束卡（块数、主卡类型） |
| `data_ledger` | 是 | 数据账（字段、键名、种子） |
| `palette` | 否 | 色板，默认：底 `#fbfaf7`、墨 `#1f2328`、主 `#2f6f6a`、警示 `#c0392b`、收入 `#2e7d4f` |
| `target_size` | 否 | 单文件体积上限，默认 300KB |

## 执行步骤

```
S0  写骨架（一次性，不夹带模块业务）
    · <head>：<meta viewport width=device-width,initial-scale=1,viewport-fit=cover>
    · 字体：系统字体栈，不引字体文件
    · CSS 变量：色板、圆角、间距、断点
    · 布局：顶栏（今天要处理）→ 模块容器（data-module="1..n"）→ 底部安全区
    · <script> 三段分明：
        ① 数据层：KEY 常量、load()、save()、seed()、exportJSON()、importJSON()、clearAll()
        ② 计算层：纯函数，只吃数组吐数组（todayGroup()、statsOf()、trendOf()）
        ③ 渲染层：refreshAll() + 每块一个 render*()
    · 初始化：DOMContentLoaded → load() → 空则 seed() → refreshAll()
S1  空跑骨架：打开页面，控制台无报错，顶栏显示空态，模块容器显示占位
S2  填第 1 块：写 render*(1)、事件绑定、空状态；跑一次；存档
S3  填第 2 块：同上；跑一次；存档
S4  填第 3/4 块：同上
S5  补图表：按卡片参数手写 SVG（柱 rect / 折线 polyline / 环 stroke-dasharray）
S6  补响应式：<768px 单列堆叠；触控 ≥44px；输入 ≥16px；底部 env(safe-area-inset-bottom)
S7  补空状态与异常态：每块都要有"还没有数据"的文案 + 一个主操作按钮
S8  自检体积：超 300KB 先压 SVG 精度与示例数据，不要删功能
```

## 判断条件

**S1 之后（骨架闸）**

- [ ] 页面能打开，控制台 0 报错
- [ ] `refreshAll()` 能空跑，不依赖任何模块数据
- [ ] 三个 script 段边界清楚，渲染函数里没有 `localStorage` 直呼

**每块之后（模块闸）**

- [ ] 该块能增 / 删 / 改（或按卡片定义的操作）
- [ ] 该块有空状态
- [ ] 该块的数据变化能反映到指标卡/顶栏（如有依赖）

**S7 之后（整页闸）**

- [ ] 无任何 `http://` / `https://` / `//` 外部资源引用
- [ ] 图标全部为内联 SVG，无 emoji 充当图标
- [ ] 渲染函数互不调用，只由 `refreshAll()` 统一调度
- [ ] 只有 1 个初始化入口

## 输出格式

产出 `{台子名}.html`，并附一份装配清单（可直接贴进出厂单）：

```markdown
## 装配清单 · {台子名}
| 块 | 主卡 | 渲染函数 | 空状态 | 存档次第 |
|---|---|---|---|---|
| 1 | list | renderTasks() | 有 | S2 |
| 2 | metric | renderStats() | 有 | S3 |

骨架闸：通过 / 未通过（说明）
整页闸：通过 / 未通过（说明）
体积：{n} KB ｜ 外链：0 ｜ emoji 图标：0
```

## 异常处理

| 情况 | 处理 |
|---|---|
| 单文件预计超 600KB | 分两次写：先写骨架 + 前两块，再增量追加后两块；每次追加后必须仍可运行 |
| 图表数值不对 | 先查计算层（纯函数最容易错在边界），不要在渲染层凑数 |
| 用户中途要加第 5 块 | 停手，回工序 ① 重压规模，不在装配阶段扩容 |
| 改了某块导致别的块坏 | 回滚到上一块存档，再重做；不要边坏边修 |
| 控制台报 `xxx is not defined` | 先用 `dom_probe.py` 定位，再改；不许用 `window.onerror` 掩盖 |
| 手机打开横向滚动 | 查三处：固定宽度元素、`white-space:nowrap` 的表格、超长不换行的数字串 |
