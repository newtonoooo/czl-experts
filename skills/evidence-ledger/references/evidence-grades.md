# 证据等级手册（细则与争议判例）

## 等级总表

| 级别 | 名称 | 一句话判据 | 能不能进结论句 |
|---|---|---|---|
| A | 一手行为数据 | 自己系统产出，定义可复述，别人能重跑 | 能 |
| B | 一手原文 | 有原话，能指认谁在什么场景说的 | 能 |
| C | 公开可核事实 | 点得开、有日期、不是自吹 | 能（对外需带日期） |
| D | 转述与二手 | 中间隔了一个人或一层加工 | 不能单独用 |
| X | 无来源 | 印象、直觉、类比、推测 | 只能写成假设 |

## 争议判例

### 判例 1：截图里的数字

> 同事在群里发了一张 GMV 截图，"这个月 412 万"。

判 **B**（有原文、有来源人），不判 A。原因：不知道口径（含不含退款、含不含未支付），不知道是不是某一渠道。若要用它做结论，必须先拿到定义。

### 判例 2：客户在录音里说的原话

判 **B**。即使录音清晰，它仍然是"陈述"，不是"行为"。如果客户说"我们一定会买"，这是 B 级的陈述，但仍然可能不买。要看行为（是否付了定金、是否走了采购流程）。

### 判例 3：竞品官网写着"支持千万级并发"

判 **C**（事实：官网这么写）但 **不能判 C（能力：真能支持）**。涉及能力上限时，只有自测或第三方压测才能算 A/B。写作时用"官网宣称（C，2026-09-12）"。

### 判例 4：自己做的 11 人访谈

判 **B**。11 条原话是 11 条 B 级证据。但它们**不能合并升级**成 A。11 人不支持任何比例结论。

### 判例 5：行业报告说"70% 的企业有计划"

判 **D**。报告是可核的（C），但报告里的调研方法你看不到、样本你看不到、时间是去年的。引用时必须写"某报告 2025 年调研显示（D，方法未公开）"。

### 判例 6：自己跑的实验

判 **A**，但前提是：分流随机、样本量够、跑满预设周期、没有中途改规则。中途偷看结果就停的实验，降到 B。

### 判例 7：老用户的流失原因问卷

判 **B**，且要标注**幸存者偏差的反面**：已经彻底不用的用户不会来填。这份数据只能代表"还在意的人"。

### 判例 8：模型自己推断出的用户需求

判 **X**。永远。

## 降级规则（容易漏的三条）

1. **定义不明降一级**：任何数字，只要说不清口径，降一级。
2. **矛盾降一级**：同级证据互相矛盾时，两侧都降一级，并写出矛盾。
3. **时效过期降一级**：超过 12 个月的定性材料、超过 6 个月的市场与竞品信息，降一级并注日期。

## 越级用词的禁用清单

以下词只能配 A/B/C 级证据。配 D/X 级出现即为"越级"，脚本会报错：

```
多数 · 大部分 · 大多数 · 普遍 · 绝大多数 · 几乎所有 · 所有 · 全部
显著 · 明显 · 大幅 · 远超 · 证明了 · 充分说明 · 一致认为 · 公认
```

替代写法：

| 想写 | D 级证据下改成 |
|---|---|
| 多数客户需要 | 有 3 条工单提到，其中 1 条明确要求 |
| 显著提升 | 从 12% 到 14%（样本 800，两周） |
| 证明了假设 | 与假设一致，未能排除 ___ 的影响 |
| 客户一致认为 | 6 位受访者中 4 位提到同一问题，2 位未提及 |

## 结论等级的计算

一条决策结论通常由多条证据支撑。计算方式：

```
结论等级 = 最强单条证据的等级
但如果：
  - 最强证据有明确反例 → 降一级
  - 最强证据本身依赖未验证的假设 → 降一级
```

**不是取平均，也不是取最弱。** 取最强，然后按反例和依赖关系打折。这样做的原因：一条 A 级数据足够推翻十条 D 级猜测，但一条反例也足以推翻一条 A 级结论。

## 门槛

| 用途 | 最低等级 |
|---|---|
| 投入资源（排期、招人、花钱） | B |
| 砍掉已有功能 | B |
| 对外公开宣称 | C + 日期 |
| 改变定价 | B + 财务复核 |
| 声明合规 | 不由证据等级决定，需要法务签字 |

砍功能要求 B，这条容易被忽略。团队常对"新增"要求证据，对"砍掉"只凭感觉，结果把最难的、价值最高的一批用户砍掉了。

## 台账 CSV 格式

`scripts/evidence_check.py` 读取的列：

| 列名 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 断言编号 |
| `claim` | 是 | 断言原文 |
| `evidence_grade` | 是 | A / B / C / D / X |
| `evidence_type` | 否 | data / quote / public / hearsay / guess |
| `source_ref` | 否 | 来源位置（文件名、链接、截图名） |
| `counter_searched` | 否 | yes / no，是否做过反例检索 |
| `sample_size` | 否 | 支撑该断言的样本量（数字） |

示例见 `scripts/fixtures/ledger_sample.csv`。
