# 标书体检（tender-clause-audit）

这个技能不判断方案好坏，只干一件事：找出"会让你的标书当场被判无效"的句子。

规则来自招标文件的通用结构，不是某一家的文件模板。命中只是提示，最终以招标文件原文为准。

## 一、什么时候用

| 用户说的 | 用哪条命令 |
|---|---|
| "这份招标文件帮我看看有没有坑" | `scan` |
| "投标文件自查，怕废标" | `scan`（把自家投标文件也扫一遍，看是否漏项） |
| "条款响应表怎么搭" | `response` |
| "要准备哪些材料" | `materials` |
| "规则太粗，我要加自己的" | `--rules 自定义规则.json` |

## 二、入口

```bash
python <技能目录>/scripts/tender_audit.py scan --file 招标文件.txt --out 体检报告.md
python <技能目录>/scripts/tender_audit.py scan --file 招标文件.txt --min-level 致命
python <技能目录>/scripts/tender_audit.py response --out 响应表.md
python <技能目录>/scripts/tender_audit.py materials --out 材料清单.md
```

文件支持 `.txt` / `.md`。PDF 与 Word 先用工具转成文本再扫，本技能不做格式解析。
任何命令加 `--json` 输出结构化结果。

## 三、扫描逻辑

1. 按行切分，逐行匹配规则库（`scripts/rules/tender_rules.json`）。
2. 同一规则在同一行只记一次；一行命中多条时分别记录。
3. 按严重度排序，同级按出现顺序。
4. 单独抽取三类东西：
   - **星号/三角条款**（★ ▲ ＊），这类通常是实质性要求，一条不响应即无效；
   - **时间节点**（报名、澄清、质疑、递交截止、开标），用来排倒排计划；
   - **强制性措辞**（必须、应当、不得、须）的出现密度，密度过高说明这份文件对偏离零容忍。

## 四、分级口径

| 级别 | 含义 | 处理方式 |
|---|---|---|
| 致命 | 漏了直接判无效投标，没有补救机会 | 逐条落实到人、到时间，闭环前不排版 |
| 严重 | 可能扣分或触发澄清，累计过多会被认定未实质响应 | 投标前必须逐条答复 |
| 一般 | 影响观感或形式审查，属于低级失误 | 装订前统一检查 |

级别是提示而不是定论。同一句话在不同文件里的后果可能不同——比如"提供原件备查"，有的文件是形式审查，有的文件写明"未提供原件视为无效"。

## 五、输出格式

`scan` 默认输出 markdown：

1. **概览**：命中条数、致命条数、星号条款数量、时间节点数量。
2. **致命清单**：行号、原文摘录、为什么致命、要做什么。
3. **严重清单**、**一般清单**：同上。
4. **星号条款汇总**：逐条列出，供做响应表。
5. **时间节点倒排**：按日期排序，留出内部截止时间。
6. **使用说明**：本报告为提示性检查，以招标文件原文为准。

`--json` 输出：

```json
{"file": "...", "counts": {"致命": 4, "严重": 9, "一般": 3},
 "hits": [{"line": 37, "level": "致命", "rule": "seal", "quote": "...", "why": "...", "action": "..."}],
 "stars": [{"line": 52, "quote": "..."}], "dates": [{"line": 12, "quote": "..."}]}
```

## 六、异常处理

- 文件为空或全是页眉页脚 → 提示"文本提取可能失败"，让用户改用可复制文本。
- 命中数为 0 → 不要报"没问题"，改为提示"规则库未命中，请人工核对资格性审查与符合性审查两章"。
- 用户只给了评分办法没给正文 → 只跑评分相关规则，输出"评分办法体检"，并说明缺正文无法查废标项。
- 规则误报（例如"保证金"出现在"无需缴纳保证金"）→ 报告里保留原文摘录，让人一眼判断，不自动删除。

## 七、边界

- 不做法律意见。条款是否构成歧视性、是否可质疑，需要法务或代理机构判断。
- 不替代人工通读。机器只保证"这一句被看到了"，不保证"这一句被理解了"。
- 规则库是可维护资产：每做完一个项目，把新踩到的坑加成一条规则，写进 `references/rule-changelog.md`。
