# 资料索引与引用边界

## 一、这个包里有什么、没有什么

**有**：本项目自己编写的模型卡、判据表、错因码、评分点规范、实验流程、家长话术、公式速查。这些是从教学经验里整理出来的操作材料，不是任何教材或教辅的摘录。

**没有**：教材原文、教辅题目、真题原卷、出版社图片、名师讲义。这些受版权保护，不随包分发。

## 二、需要原始资料时去哪儿取

以下都是公开渠道，用户自行获取，本产品不转存、不再分发：

| 资料 | 渠道 | 用途 |
|---|---|---|
| 普通高中物理课程标准（2017 年版 2020 年修订） | 教育部官网、人民教育出版社 | 核对某知识点的要求层级（了解/理解/应用） |
| 各版本教材目录与样章 | 人民教育出版社、上海科技教育出版社、广东教育出版社、教育科学出版社官网 | 核对章节顺序与册次 |

| 各省教育考试院 | 各省考试院官网 | 本省考试说明、选科要求、赋分规则 |
| 高考真题 | 各省考试院公布的试卷、官方出版物 | 只做题，不转载 |

> 链接与栏目会调整，站内检索比记死链更可靠。本包不保证上述站点长期可达。

## 三、引用规则

1. **引结构不引原文**：可以说"人教版把万有引力放在必修二第六章"，不要把教材段落抄进来。
2. **引结论要能追溯**：凡是"某省考什么"这类判断，必须落到"某省考试院某年考试说明"，说不清就标注"待核对"。
3. **题目来源要标**：用真题讲解时说明"这是某年某卷改编"，并做改动，不整卷照搬。
4. **不确定的说法降级**：从"必考"降为"近年常考"，从"一定"降为"多数情况下"。

## 四、给用户的提示

如果用户希望获得成套真题或教材原文，正确做法是告诉他去上表中的官方渠道获取，而不是由本产品生成"看起来像真题"的题目。生成的题目一律标注为"自编题"，避免与真题混淆。

## 五、本包材料的来源说明

- 物理规律、公式、单位：公开的科学常识，无版权问题。
- 模型分类、错因码、评分点、话术：本项目独立编写，属于方法性表达。
- 脚本：本项目独立实现，仅用 Python 标准库。
