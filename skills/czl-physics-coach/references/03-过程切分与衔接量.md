# 过程切分与衔接量

## 一句话原则

**一道多过程题，错不在规律，在段与段之间的那个接口。**

切开段，标好接口，题就剩下一堆单段小问题；切不开，所有公式都像能用，又都不对。

---

## 一、七个下刀的地方

看到下面任意一种描述，必须在这里切一刀。切点写不出来，说明题没读透。

| 事件 | 题面常见说法 | 为什么要切 |
|---|---|---|
| 速度反向 | "滑到最高点""速度减为零后返回" | 加速度方向可能改变，前后不是同一段匀变速 |
| 离开接触面 | "恰好离开""脱离轨道""飞出" | 支持力变为零，受力结构变了 |
| 进入/离开场区 | "进入磁场""穿过边界""进入电场" | 多了场力，规律可能从力学换成电磁 |
| 绳突然绷直 | "绳被拉直""突然绷紧" | 沿绳方向速度突变，有能量损失，机械能不守恒 |
| 弹簧恢复原长 | "弹簧恢复原长时" | 弹力方向反转，之后是减速 |
| 发生碰撞 | "碰后""粘在一起""弹开" | 动量守恒但机械能一般不守恒 |
| 达到稳定状态 | "最终匀速""稳定后""最大速度" | 合力为零，可作为方程条件 |

补充两个隐形的：
- **摩擦力方向翻转**（传送带上共速那一刻）；
- **电路状态改变**（开关闭合、滑动变阻器到位、电容器击穿）。

---

## 二、五类衔接量

每一段的"出口"，必须能作为下一段的"入口"。物理量只有五类能跨段传递：

| 衔接量 | 什么情况下是接口 | 注意 |
|---|---|---|
| 速度 $v$ | 绝大多数过程接口 | 碰撞、绳绷直时**不连续**，要单独算 |
| 位置 $x$ / 高度 $h$ | 几何约束、势能基准 | 高度要统一零势能面 |
| 能量 $E$ | 有摩擦、有非保守力时 | 机械能不守恒时要算热 |
| 动量 $p$ | 碰撞、爆炸、反冲 | 只在一瞬间守恒，不能跨整段用 |
| 电荷量 $q$ | 电磁感应中跨段求位移或热量 | $q=\Delta\Phi/R_{总}$，与过程快慢无关 |

**接口检查法**：把每段的入口量和出口量写成两列，逐个对。对不上的地方，就是你漏掉的事件。

## 三、三段式切片模板

讲课时按这个格式写，学生照着填，填不满就是没切开：

```
第 ① 段：从 ______ 到 ______
  对象：
  受力/场：
  运动性质：            （匀变速 / 类平抛 / 圆周 / 变加速）
  用律：
  入口量：              出口量：

第 ② 段：从 ______ 到 ______
  ...
```

空着的格子不要替他填，让他自己填。填错的格子就是下一个要讲的地方。

## 四、三个典型切法

### 例 1：斜面 + 水平面 + 弹簧

- ① 斜面下滑：匀加速，出口是斜面底端速度。
- ② 水平面减速：匀减速，出口是接触弹簧瞬间速度。
- ③ 压缩弹簧：变加速。**注意：速度最大点在 $kx=\mu mg$ 处，不是最低点。**
- ④ 反向弹回：变加速，出口是离开弹簧瞬间速度（与③对称，若有摩擦则不相等）。
- ⑤ 水平面减速到停：匀减速。

切点全在"接触/离开弹簧""速度为零"上。学生常把③④并成一段，于是算不出最大速度。

### 例 2：传送带 + 共速

- ① 物块速度小于带速：摩擦力向前，匀加速。
- ② 共速瞬间：**这一刻必须切**，之后摩擦力可能反向或消失。
- ③ 共速后：比较 $\mu g$ 与带是否匀速——带匀速则物块随带一起走（静摩擦），带加速则重新判断。

漏掉②，就会出现"一直加速"的错误结论。

### 例 3：线框穿过磁场

- ① 进入过程：磁通量增加，感应电流方向由楞次定律定，安培力阻碍进入。
- ② 完全在磁场内：**磁通量不变，无感应电流**，只受重力（或外力）。
- ③ 穿出过程：磁通量减少，电流反向，安培力阻碍穿出。

②这一段经常被整个忘掉，于是热量算多了，时间算少了。

## 五、段数判断的快速自检

讲完问三个问题：

1. 每一段是不是只有一种运动性质？
2. 每一段的受力是不是不变的（大小和方向）？
3. 每个接口是不是都有明确的物理量接上？

三个都是"是"，段就切对了。有一个"否"，回去重切。

---

## 六、常见错误清单

- 把"速度为零"当成"过程结束"（竖直上抛的最高点是分界，不是终点）。
- 把"同一物体"当成"同一过程"（一个人先跑后走，是两段）。
- 段切对了，但每段重新设了一套符号（$v_1$ 在第一段是初速度，在第二段又当末速度），导致方程自相矛盾。**规定：同一物理量只用一个符号，不同状态用下标。**
