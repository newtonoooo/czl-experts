# 错因卡

## 单张卡（一次一张，写满一张再写下一张）

```
日期：
题目来源：
主码：        （E/P/L/C/R + 编号）
次码：

卡在哪一句/哪一步：

当时的错误想法：

正确的想法（一句话）：

补救动作（今天能做完，≤15 分钟）：

回访：3 天后 ______   7 天后 ______   15 天后 ______
三次结果：□ 全过  □ 有一次没过（回到第 3 天）
```

**读表规则**
- 主码连续两周不变 → 动作没落地，换动作。
- 主码变了 → 上一阶段过关，进入下一类。
- E 类占比高 → 补概念；P 类高 → 练切段；C 类高 → 练书写；R 类高 → 练读题。
