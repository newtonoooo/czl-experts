# 图表与排版规范

图不是装饰，是**让一句话被看懂得更快**。这张规范约束渲染出来的所有视觉元素。

---

## 一、先决定"这张图要说明什么"

| 你要说明 | 用这个 | 不要用 |
|---|---|---|
| 一段时间怎么变 | 折线图（带外推虚线 + 区间带） | 饼图、3D 柱 |
| 内部由什么组成 | 横向条形图（按占比降序） | 饼图（超过 5 项就看不清） |
| 谁离群 | 散点或条形 + 标注具体行 | 只用一句"存在异常" |
| 两维交叉 | 热力表（数值着色） | 双轴图（误导性极强） |
| 单值对比 | 大数字 + 一句注释 | 仪表盘 |

**一个图只讲一件事。** 一张图想同时说趋势和结构，最后两个都没说清。

---

## 二、必须遵守的六条

1. **纵轴从 0 开始**（折线图如非 0 起点，必须在轴上标出截断符号）。
2. **不截断、不拉伸、不用双轴。**
3. **标注单位和口径**：图下方一行小字，写清"单位：元""口径：含税销售额""粒度：月"。
4. **标出异常点和拐点**：拐点加标记，离群点标行号——让读者能回到原表核对。
5. **颜色只承担一种含义**：本产品统一用蓝＝主指标、青＝次要、琥珀＝预警/外推、红＝高危、绿＝下降/改善。
6. **中文优先**：标题、坐标轴、图例全中文；不出现英文缩写，除非是行业通用（GMV、HHI）。

---

## 三、报告结构（固定顺序）

```
1  一页纸结论        3–5 条，每条带证据等级
2  数据体检          评级 + 问题清单 + 时间轴
3  走势线            图 + 关键统计 + 拐点 + 外推
4  拆解线            图 + 占比表 + 集中度 + 位移
5  验伤线            异常清单（级别/行号/数值/建议动作）
6  证据链            每条结论的复算结果
7  口径与免责        口径全文 + 使用限制
```

**顺序不能换。** 先给结论，再给证据，最后给限制——这是开会时的阅读顺序。

---

## 四、数字书写

| 场景 | 写法 |
|---|---|
| 金额 ≥ 1 万 | 1,234.56 万元（保留两位） |
| 百分比 | 43.36%（两位），变化用 +/− 号 |
| 百分点 | 用 "pp"，不要用 "%" |
| 比率 | 0.53，不要写成 53% |
| 大额整数 | 1,392,924 元（千分位） |
| 无数据 | 写 "—"，不要写 0 或空白 |

**同一份报告里，同一个指标的小数位必须一致。**

---

## 五、排版细节

- 标题不超过 20 字，能直接当结论读（"销售额上行 43%，但头部依赖度升至 76%"优于"销售分析"）
- 每节结尾一句"所以呢"（so-what），不要只摆数据
- 表格不超过 6 列，超出就拆表或改图
- 免责声明放最后，不放开头——开头放免责，读者会以为你心虚
- 打印成 PDF 时每节不跨页（CSS `break-inside: avoid` 已内置）

---

## 六、常见翻车

| 翻车 | 后果 | 正确做法 |
|---|---|---|
| 用饼图展示 12 个区域 | 谁也看不出差别 | 横向条形图 Top 6 + 其他 |
| 折线图纵轴从 80 开始 | 把 2% 波动画成断崖 | 从 0 开始，或标截断 |
| 双轴图（金额 + 增长率） | 两条线的交叉点纯属巧合 | 拆成两张图 |
| 颜色表示"重要性" | 读者以为红色是坏消息 | 颜色只表示方向或级别 |
| 图里写"显著增长"但没给数 | 无法核对 | 标题直接写 43.36% |
