# 合规与话术风控

## 什么时候用

- **每次交稿前都要过一遍**，不是可选步骤。
- 用户问某句话能不能说。
- 做医疗、保健、美妆、金融、教育、母婴类内容。
- 投流被拒审，要定位是哪句话的问题。
- 直播间话术要过一遍再上播。

## 定位说清

本技能做的是**机械扫描 + 替换建议**，不是法律意见。
它能做：把凭手感的判断变成可复核的清单，标出高风险表述并给改法。
它不能做：替代法务审核、替代平台规则、保证"改完一定过审"。

## 执行步骤

### S1 取全文
把要发的所有文字都凑齐，缺一段就漏一段：
口播稿、字幕、标题、封面文案、话题、置顶评论、商品卖点、直播话术、评论区回复模板。

### S2 扫描

```bash
python3 ${SKILL_DIR}/scripts/dy_lint.py --file draft.txt
python3 ${SKILL_DIR}/scripts/dy_lint.py --text "全网最低价，加微信领券"
python3 ${SKILL_DIR}/scripts/dy_lint.py --file draft.txt --format json --out lint.json
```

脚本会输出：等级统计、命中明细（原文/建议改法/行号）、类目提示、逐条替换后的改后稿。
**有高等级命中时脚本退出码为 1**，可以直接串进发布流程做闸门。

### S3 人工复核（不许省）
逐条看命中项，判断三种情况：
1. 真问题 → 按建议改，或换一种说法。
2. 误伤（词表匹配到了正常表达）→ 记下来，把词加进对应类目的 `except` 数组。
3. 灰区 → 不给结论，明确写"建议由具备资质的主体或法务确认"，并给一个更保守的替代表述。

### S4 出结论
三种结论，不许模糊：
- **可发**：无高等级命中，中等级已处理。
- **改后可发**：列出必须改的句子和改后版本。
- **不建议发**：涉及资质缺失（医疗断言、金融荐股、疗效承诺），改词也解决不了，只能说清风险。

## 词表结构（`references/banned-words.json`）

| 类目 | 等级 | 典型触发 |
|---|---|---|
| 绝对化用语 | 高 | 最好、最强、最低价、第一品牌、国家级、100% |
| 功效与疗效承诺 | 高 | 治疗、根治、养胃、调理、增强免疫力、无副作用 |
| 金融收益承诺 | 高 | 稳赚、零风险、保本保收益、年化收益 |
| 未成年人保护 | 高 | 长高、增高、童星、小孩子都在用 |
| 站外导流 | 高 | 加微信、加V、公众号、淘宝搜、电话咨询 |
| 诱导互动与虚假稀缺 | 中 | 点赞过万、最后3件、全网最低、清仓价 |
| 封建迷信 | 中 | 转运、开光、招财、改命 |

每条包含 `term`（触发词）与 `replacement`（建议改法）；`replacement` 以"（删除"开头时，改后稿会直接删除该词。

维护方式：误伤 → 类别里的 `except` 加词；漏检 → 类别里的 `items` 加条目。改完跑一遍 `--demo` 确认没把词表写坏。

## 五类高风险场景的处理口径

1. **医疗健康**：普通食品、化妆品不得宣称疾病治疗功能。涉及症状、病程、用药，一律不给表述，让用户找具备资质的主体。
2. **金融理财**：不得承诺收益、不得暗示保本。给历史数据必须标注区间和时间，并加风险提示。
3. **教育培训**：不得承诺"保过""提分多少"，不得用"名师""官方指定"这类无依据表述。
4. **母婴与未成年人**：不得利用未成年人作效果证明，不得诱导未成年人消费，不得出现危险动作示范。
5. **站外导流**：不在内容里引导到站外成交或留联系方式。合规承接用主页、私信、团购、小店、直播间。

## 输出格式

1. **结论**：可发 / 改后可发 / 不建议发。
2. **统计**：高 / 中 / 低各几处。
3. **类目提示**：命中了哪些强监管类目，为什么更严。
4. **命中明细表**：等级 / 类目 / 原文 / 建议改为 / 位置。
5. **改后稿**：可直接复制的版本，并注明"删词后需人工顺语序"。
6. **边界声明**：本报告不构成法律意见。

## 异常处理

| 情况 | 处理 |
|---|---|
| 用户说"别人都这么说" | 说明违规不因普遍而合法，且被投诉时是按条处理的 |
| 用户要求"换个说法绕过审核" | 拒绝。规避审核不是合规，是把风险推给用户 |
| 词表误伤正常表达 | 记入 `except`，并在报告里说明是误伤，不用改稿 |
| 用户不给全文只给一句 | 只对这一句负责，明确说明"其余段落未检" |
| 强监管类目且用户无资质 | 不给"改词方案"，直接说明资质是前置条件 |
| 平台规则更新导致判断变化 | 以平台最新规则为准，词表只作自查参考，定期复核 |

## 与其他技能的关系

- 所有技能的输出都要过这一关：`dy-hook-script` 的稿子、`dy-live-runbook` 的话术卡、`dy-boost-review` 的投放素材文案。
- 若限流原因是表述违规，处理完再回 `dy-account-diagnosis` 重新建基线，否则数据不可比。
