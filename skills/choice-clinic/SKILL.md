# W5 选择题错因门诊

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 选择题错因门诊（choice-clinic） |
| **任务职责** | 把"这题选错了"分解成**可训练的八类错因**，并指出这一类的干扰项是怎么设计出来的，最后给同类变式题。目标不是讲懂这一道，是让他在下一道同型题上不出错。 |
| **输入参数** | 必填：错题原文（题干 + 四个选项 + 正确答案 + 孩子选的答案）。强烈建议：孩子选错时的理由（一句话就行）、这组题的正确率、年级。 |
| **执行步骤** | ① 先让孩子说"你当时为什么选它"（不给理由就直接归因，八成归错）→ ② 归入八类错因 → ③ 定位是"知识缺口"还是"读题动作缺口" → ④ 讲这一类的干扰项套路 → ⑤ 给三步排除动作 → ⑥ 出三道同因变式（换材料不换错因） |
| **判断条件** | 孩子说不出理由 → 先做"错因口述"训练，不进入讲题；同一类错因出现三次以上 → 定为专题，连续练一周；错因分散在五类以上 → 停，回到 W2 补框架；题目本身有争议 → 说明争议点，不硬讲成唯一答案；四个选项里有两个都能选 → 教"最优项"判断法，并说明这类题的比例不高 |
| **输出格式** | ① 错因判定（一句话）② 归因表（选项／孩子理由／错在哪一步）③ 干扰项套路说明 ④ 三步排除动作 ⑤ 三道同因变式（含答案与错因标注） |
| **异常处理** | 只给了题没给答案 → 先问正确答案；答案是"以上都对"类 → 跳过，这类题占比低；错题涉及超教材知识 → 说明不在考查范围；孩子坚持"我选的是对的" → 不争论，用"如果按你的选法，题干哪一句可以支持它"来检验 |
| **必要依赖** | `references/error-taxonomy.md`（八类错因）、`references/distractor-patterns.md`（七种干扰项套路）、`materials/concepts.md`、`materials/timeline-cn.md` |

## 一、八类错因（先归类，再讲题）

| 编号 | 错因 | 一句话识别 | 训练方向 |
|---|---|---|---|
| E1 | 时空错位 | 把不同时期的事混在一道题里 | 补时间轴与分界事件 |
| E2 | 概念混淆 | 两个近义术语分不清 | 概念辨析表，一次一组 |
| E3 | 主体错配 | 把 A 的主张安到 B 头上 | 人物／派别—主张对应表 |
| E4 | 程度失当 | 选项里"开始""完成""彻底""根本"用过头 | 程度词敏感度训练 |
| E5 | 因果倒置 | 把结果当原因，或把背景当影响 | 因果层级训练 |
| E6 | 材料误读 | 以偏概全、脱离材料、把材料当常识 | 分层与概括训练 |
| E7 | 设问误读 | 问"原因"答"表现"，问"反映"答"说明" | 圈设问动词 |
| E8 | 史观偏差 | 用今天的标准评价当时，或只从单一维度看 | 历史主义与多维视角 |

**分类铁律：一道题只归一类。** 归两类等于没归，训练无法落地。

## 二、先分清"不会"还是"没看"

| 表现 | 性质 | 处理 |
|---|---|---|
| 四个选项里有两个不认识 | 知识缺口 | 补史实，本题不讲技巧 |
| 认识全部选项，仍选错 | 读题动作缺口 | 讲干扰项套路，本题不补史实 |
| 选对了但说不出为什么 | 侥幸，后续必错 | 补"说理由"环节 |
| 改答案改错了 | 决策不稳 | 定"不改原则"：无新证据不改 |

**这一分法决定了后续所有动作。** 把读题问题当知识问题补，是家庭辅导里最耗时间又最无效的做法。

## 三、干扰项七套路（讲套路，不讲这道题）

| 套路 | 怎么设计 | 破法 |
|---|---|---|
| 时空错位 | 把后一时期的现象放进前一时期的题干 | 先在题干上写世纪 |
| 概念偷换 | 用近义术语替换关键词 | 圈出题干的核心名词 |
| 程度加码 | 把"有所"改成"彻底" | 圈程度词，逐一核对 |
| 主体替换 | 换掉行为主体（政府→民间，中央→地方） | 圈主语 |
| 因果倒置 | 把结果写成原因 | 问一句"哪个在前" |
| 以偏概全 | 用材料中的一句代替整体 | 看材料有没有"但" |
| 无关正确 | 说法本身正确，但与题干无关 | 问"它在回答题干的问题吗" |

## 四、三步排除动作（可复制的考场动作）

```
第一步：在题干上圈三样——时间、主体、设问动词。
第二步：逐项判"它错在哪一类"，能归类的先划掉，不靠感觉。
第三步：剩下两项时，问"哪一项与题干的时间、主体、程度完全对齐"，选对齐的那个。
```

三步写在纸上，练两周就会变成习惯。**不要教"凭语感"**，语感是不可复制的。

## 五、同因变式怎么出

变式不是换一道难题，是**保留错因、换掉材料**。

| 原题错因 | 变式设计 |
|---|---|
| E1 时空错位 | 换一个相邻时期，仍放一个错位选项 |
| E2 概念混淆 | 换一组易混概念（如把"君主专制／中央集权"换成"均田制／井田制"） |
| E4 程度失当 | 保留正确项，把干扰项的程度词加码 |
| E6 材料误读 | 换一段带转折的材料，仍设"以偏概全"项 |

三道变式的答案与错因标注必须一起给。**只给题不给答案，家长没法判断孩子是真会了还是又蒙对了。**

## 六、一周错因专题怎么排

| 天 | 动作 | 时长 |
|---|---|---|
| 第 1 天 | 把本周错题按八类归档，只归一类 | 20 分钟 |
| 第 2—3 天 | 每天三道同因变式，做完口述错因 | 各 15 分钟 |
| 第 4 天 | 回看原错题，重做一遍（不看答案） | 10 分钟 |
| 第 5 天 | 换一类错因，只做归类不做题 | 15 分钟 |
| 周末 | 用一套新卷的选择题验证：同类错因是否减少 | 25 分钟 |

**验收看"同类错因数量"，不看总分。** 总分受题目难度影响，错因数量才反映能力变化。

## 七、禁忌

- 不要一题一题往下讲。讲十道不如归一类。
- 不要说"这题很简单，你应该会"。这句话之后，孩子就不再说真实理由了。
- 不要用"排除法"三个字当方法。排除法不是方法，"按哪一类排除"才是方法。
