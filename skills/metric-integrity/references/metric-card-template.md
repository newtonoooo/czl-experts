# 指标口径卡模板

## 单指标卡（可直接贴进汇报材料）

```
指标名称：付费转化率
定义：注册后 30 天内完成首次成功支付的用户，占同期注册用户的比重。
分子：首次成功支付的用户数（按 user_id 去重，退款订单不计）
分母：同期完成注册的用户数（排除内部账号、测试账号）
时间窗：注册后 30 天（滚动窗口，不是自然月）
来源系统：dw.fact_order + dw.dim_user（每日 06:00 更新，T+1）
负责人：增长组
已知偏差：企业账号一次付费多席位，会低估席位级转化
变更记录：2026-08 起排除测试账号；此前版本包含，故 8 月前数据不可直接对比
```

## 卡片字段的意义

| 字段 | 为什么必须有 | 缺失后果 |
|---|---|---|
| 定义 | 决定别人能否重算 | 会上各说各的数 |
| 分子/分母 | 决定可比性 | 换分母后趋势全废 |
| 时间窗 | 自然月与滚动 30 天差异可达 10%+ | 月初月末结论相反 |
| 来源系统 | 决定能不能查原始数据 | 无法归因、无法反驳 |
| 去重规则 | 多设备/多账号用户会重复计 | 总量虚高 |
| 排除规则 | 内部账号和测试数据会污染 | 小体量产品偏差极大 |
| 变更记录 | 决定趋势线是否可连 | 把不可比的数画成一条线 |

## 几个高频指标的常见坑

### 活跃用户（DAU/MAU）

- "活跃"到底指打开、登录、还是有核心行为？三者差异通常是 2–5 倍。
- 多端用户按设备算还是按账号算？按设备算会随换机上升。
- 是否包含小程序、H5、第三方入口？
- 冷启动、推送拉起算不算活跃？很多产品靠推送把 DAU 做高。

### 转化率

- 分母是"访问用户"还是"注册用户"还是"到达该页面的用户"？三者不可混用。
- 分子是否含退款、是否含试用、是否含线下签约？
- 归因窗口多长？（7 天归因和 30 天归因能差 40%）

### 留存

- 次日留存的分母是"新注册"还是"新访问"？
- 是否排除当天注册当天流失的？（排除会显著抬高留存）
- N 日留存是"第 N 天当天回来"还是"N 天内回来过"？前者低得多。

### 收入 / GMV

- 含税还是不含税？
- 含退款还是不含？
- 含未支付订单还是只算已支付？（这是最大的坑）
- 一次性收入是否按期分摊？

### 客户数 / 企业客户数

- 按签约主体算还是按使用主体算？
- 集团客户算一个还是算子公司数？
- 试用期客户算不算？

## 口径变更的处理

任何口径变更都要留三条记录：

1. **变更内容**：从什么改成什么
2. **变更日期**：哪一天起生效
3. **可比性**：是否回溯重算过；未重算则明确写"此前数据不可直接对比"

没有第三条，半年后一定会有人把两段不可比的数连成一条趋势线，而且没人能发现。

## 快速自检（五个问题）

拿任何一份指标汇报，问这五句，能问出八成问题：

1. 这个数是谁算的，从哪个系统出的？
2. 分母是什么？
3. 时间窗是怎么切的？
4. 最近三个月口径改过吗？
5. 换一个人按你说的去查，能查出同一个数吗？
