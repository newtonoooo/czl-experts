# W4 实验设计与评价

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 实验设计与评价（czl-bio-experiment） |
| **任务职责** | 把实验目的变成能照着做的六步设计单；判清对照类型；写出分情况的预期结果与合规的结论句；评价题则按五个常见错误逐条找。 |
| **输入参数** | 必填：实验目的或题目原文（要设计、要评价还是要写结果）。建议：给定材料与器材、题目分值、教材章节、学生已写出的设计。 |
| **执行步骤** | ①读目的，圈出"要证明什么" → ②定自变量、因变量、观测指标 → ③列无关变量与每一项的控制方法 → ④分组并指明对照类型 → ⑤写预期结果（按"若……则……"分情形） → ⑥写结论句（带条件） → ⑦给一处主要误差与改进 |
| **判断条件** | 题目已给出完整设计 → 转评价模式，按五个错误逐条查；没有对照 → 先补对照再谈其他；观测指标不可测（如"观察长得好不好"） → 换成可测指标（株高、干重、气泡数、褪色时间）；变量多于一个 → 只保留一个，其余全部固定 |
| **输出格式** | 六步设计单（表格）+ 变量矩阵（四列）+ 结果预期表（分 2—3 种情形）+ 一句结论 + 一处误差。评价题输出"错误点—为什么错—怎么改"三列表。 |
| **异常处理** | 涉及人体或活体动物 → 提示伦理与安全，改为离体或模拟方案；材料无法获得 → 给等效替代（如用酵母菌代替组织匀浆测呼吸）；要求编造数据 → 拒绝，改为"预期结果"并说明理由；题目本身设计有缺陷 → 指出缺陷，先按题意作答再补一句说明 |
| **必要依赖** | `references/variable-matrix.md`（变量写法与控制方法库）、`references/conclusion-templates.md`（句式与采分点拆解） |
| **与其他工作流的关系** | 上游：W1 判定为实验专项；若涉及光合/呼吸/酶的过程不清，先回 W2。下游：结果分析涉及曲线，接 W5；错题进 W6。 |

## 一、六步设计单（这就是答题纸上的六行）

| 步 | 写什么 | 不合格的写法 |
|---|---|---|
| 1 目的 | 探究/验证 X 对 Y 的影响 | "研究一下这个现象" |
| 2 材料与分组 | 同种、同生长状况的材料，随机均分 n 组 | "取一些……" |
| 3 自变量与处理 | 一组给处理，一组不给（或给不同浓度） | 两组都给处理，只是"多给一点" |
| 4 因变量与观测指标 | 具体到"测什么、怎么测、什么时候测" | "观察变化" |
| 5 无关变量与控制 | 逐条列出并写方法 | "其他条件相同且适宜"（一句概括，不给分） |
| 6 结果与结论 | 分情形的"若……则……" + 一句结论 | "结果说明我的假设是对的" |

**第 5 步是最大的失分点。** "其他条件相同且适宜"这七个字，在多数评分标准里不给分；写出具体是哪几个条件、怎么控制，才给。

## 二、四类变量怎么写

| 变量 | 定义 | 写法示例 |
|---|---|---|
| 自变量 | 你主动改变的那个 | "一定范围内不同浓度的生长素类似物（0、10⁻⁸、10⁻⁶ mol/L）" |
| 因变量 | 随自变量变化的那个 | "插条生根的数量" |
| 观测指标 | 因变量怎么变成数字 | "培养 14 天后统计每组生根条数的平均值" |
| 无关变量 | 会干扰结果但你不研究的 | "枝条粗细与长度、处理时间、温度、光照、水分" |

**判据**：如果换一个人照你的设计做，能做出同样的结果，说明变量写清楚了。做不到，就是没写清楚。

## 三、对照四型（选错类型，整题跑偏）

| 类型 | 做法 | 什么时候用 |
|---|---|---|
| 空白对照 | 一组不给处理，其余相同 | 证明"这个处理有没有效果" |
| 自身对照 | 同一材料处理前后比 | 证明"处理前后发生了变化"（如质壁分离及复原） |
| 相互对照 | 几个实验组互相比，不设空白 | 找最适浓度（如不同浓度生长素类似物） |
| 标准对照 | 与已知标准（阳性对照）比 | 证明"效果达到某个已知水平" |

**单一变量原则**：一次只让一个因素不同。两组之间有两个因素不同，结论一定不成立。

## 四、预期结果怎么写（不许写死）

用"若……则……"覆盖 2—3 种可能，把自己从"押答案"里摘出来。

```
若甲组生根数明显多于乙组，则说明该浓度促进生根；
若甲组少于乙组，则说明该浓度抑制生根；
若两组无显著差异，则说明该浓度既不促进也不抑制。
```

判据：**预期结果里不出现"一定""必然"。** 出现就是押题。

## 五、结论句的四要素

```
在【条件】下，【自变量】对【因变量】有【促进/抑制/无显著】作用，
且【随……变化的趋势或最适值】。
```

不合格："说明生长素能促进生根。"（缺条件、缺浓度、缺趋势）
合格："在一定浓度范围内，随生长素类似物浓度升高，插条生根数先增多后减少，最适浓度约为 10⁻⁸ mol/L。"

## 六、误差四源与改进

| 来源 | 表现 | 改进 |
|---|---|---|
| 取样误差 | 材料个体差异大 | 增加样本量、随机分组、取平均值 |
| 测量误差 | 读数不准、计时不准 | 统一测量工具与方法、同一人操作、重复测三次取均值 |
| 条件漂移 | 温度、光照、pH 中途变化 | 恒温、遮光或定时光照、缓冲液 |
| 时间误差 | 观察时间点不一致 | 统一时间点，必要时设时间序列 |

**改进只写一条就够**，写太多反而分散。挑"影响最大、最容易改"的那一条。

## 七、评价题：五个错误，逐条查

| 错误 | 长什么样 | 怎么改 |
|---|---|---|
| 没有对照 | 只有实验组 | 补一组不给处理的空白对照 |
| 多变量 | 两组温度不一样，光照也不一样 | 只留一个变量，其余固定 |
| 样本太少 | 每组 1 株、1 只 | 每组至少若干个体，随机分组 |
| 指标不可测 | "观察生长情况""看是否健康" | 换成数量、长度、质量、时间等可测指标 |
| 结论过头 | 由一次实验得出"一定""所有" | 加限定："在本实验条件下" |

评价题答题格式：**错在哪 → 为什么错（违反了什么原则） → 怎么改**。三句话一句一分，比写一段话更容易拿分。

## 八、伦理与安全

- 涉及人体（如测量血压、血糖、视力）的实验，只讨论设计，不指导自行操作，并提示"以专业医疗机构意见为准"。
- 涉及活体动物，必须写明减少数量、减轻痛苦的措施。
- 涉及微生物，写明灭菌与废弃处理。不指导培养致病微生物。

## 九、收口

设计单交出去时，附一句自检："我这个设计里，变量只有一个吗？对照组跟谁比？观测指标能测出数字吗？"三问都过，再动笔写答案。
