# W7 试卷复盘与提分路径

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 试卷复盘与提分路径（czl-chem-review） |
| **任务职责** | 把一张卷子的失分变成可执行的六周动作，并给出可观测的验收标准。不预测分数，不押题。 |
| **输入参数** | 必填：一张完整卷子（含答题卡与批改）。强烈建议：考试时间分配（哪道题花了多久）、前一阶段的诊断结论（W1）、这段时间的执行记录 |
| **执行步骤** | ①按板块记分（选择题 / 方程式 / 计算 / 推断 / 流程 / 实验），算出各板块失分率→②逐题编 E1—E8 码→③统计编码频次，找出"出现最多"和"最不该丢"的两类→④区分"不会丢分"和"会做丢分"→⑤定六周动作，每周一个编码→⑥给可观测的验收标准→⑦约六周后的第二次复盘 |
| **判断条件** | 会做丢分 > 不会丢分 → 先改流程与规范，不补新课；同一编码占失分 40% 以上 → 只打这一个；失分分散且无主因 → 先补"化学用语 + 计算"两块地基；卷面空白多 → 先查时间分配，不查知识 |
| **输出格式** | 板块失分表 + 错因编码统计 + 六周动作表（含验收标准）+ 家长配合事项 + 一句实话 |
| **异常处理** | 只有分数没有卷子 → 出"板块占比估算版"，明确标注是估算；家长要求"给个提分承诺"→ 拒绝，改成给出可观测指标；成绩波动大 → 先看是否与睡眠、考试节奏相关，不急着归因学科；连续两轮无变化 → 检查执行率，而不是换方法 |
| **必要依赖** | `references/06-错因编码表.md`（编码定义）、`assets/错题复盘卡模板.md`（每次复盘用同一张卡） |
| **与其他工作流的关系** | 上游：W1 的诊断、W2—W6 的执行记录。下游：把下一轮主卡点交回 W1，形成闭环；每周的小复盘不进本工作流，只在月末或大考后启动。 |

## 一、先算板块，不算总分

| 板块 | 满分 | 实得 | 失分率 | 备注 |
|---|---|---|---|---|
| 选择题 | | | | 概念型 / 计算型分开记 |
| 化学用语（方程式） | | | | 单独列，因为它跨题型 |
| 定量计算 | | | | 含填空里的计算 |
| 推断 | | | | |
| 工艺流程 | | | | |
| 实验 | | | | |

**化学用语一定要单列。** 它散落在各个大题里，不单列就永远看不见它是最大失分点。

## 二、错因编码统计

| 编码 | 含义 | 本题数 | 占比 | 典型题号 |
|---|---|---|---|---|
| E1 | 概念模型错 | | | |
| E2 | 化学用语不规范 | | | |
| E3 | 方程式与配平 | | | |
| E4 | 定量关系错 | | | |
| E5 | 推断断链 | | | |
| E6 | 流程目的读不懂 | | | |
| E7 | 实验操作与装置 | | | |
| E8 | 审题与表达 | | | |

两条判断规则：

1. **占比最高的编码，是下一阶段唯一的主攻方向。**
2. **"会做丢分"优先于"不会丢分"。** 会做丢分是纯利润，补起来最快。

## 三、六周动作表

| 周 | 主攻编码 | 具体动作（每天 20—30 分钟） | 验收标准（可观测） |
|---|---|---|---|
| 第 1 周 | E2/E3 | 每天 5 个方程式，写完自查三查表 | 连续 5 天，漏条件 ≤1 处 |
| 第 2 周 | E1 或 E5 | 每天 1 个模型复述 + 1 道同型题 | 能不看笔记讲清模型，同型题独立完成 |
| 第 3 周 | E4 或 E6 | 每天 1 道计算或 1 道流程，只写步骤不追答案 | 步骤齐全率 ≥ 90% |
| 第 4 周 | 主攻编码 | 限时半张卷子，只统计主攻编码的错误处数 | 同一编码的错误处数比第 1 周减少 |
| 第 5 周 | 主攻编码 | 换一个情境（换物质、换题型）复用同一套步骤 | 新情境下正确率不低于第 4 周 |
| 第 6 周 | 全部 | 回看六周记录，用同一套题重做；只数“同类错还剩几处” | 能自己说出进步在哪一项、还差哪一项 |

**验收标准必须能被家长看见**（写了几道、漏了几处、能不能讲出来），不能是"感觉懂了"。

## 四、复盘会怎么开（20 分钟，家长 + 学生）

1. **学生先说**（5 分钟）：这次哪道题最可惜？哪道题到现在还不会？
2. **看表不说话**（5 分钟）：一起看板块失分表和编码统计，家长只提问不评价。
3. **定一件事**（5 分钟）：这六周只改一个编码，写下来贴桌上。
4. **说清怎么帮**（5 分钟）：家长负责什么（时间、材料、检查符号），不负责讲题。

家长三句可以说的话：

> "这道你当时是怎么想的？"
> "这六周只改这一样，其他的先放着。"
> "需要我帮你掐时间吗？"

家长三句不要说：

> "你就是不认真。"
> "这么简单都不会？"
> "再这样下去就完了。"

## 五、一句实话

**复盘的价值不在找出多少问题，在敢删掉多少问题。** 一张卷子能列出二十个毛病，但六周只能改一个。写多了，等于没写。
