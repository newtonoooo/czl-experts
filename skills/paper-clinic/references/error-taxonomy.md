# 错因码：五个码，一个判据，一条对策

错因分类最容易变成"我觉得他是粗心"。所以每个码必须配一个**能当场问出口的判据问题**——问不出来，就是没判准。

## C · 概念不清

**判据问题**：「这个公式/定理，你能说出它为什么成立吗？」

说不出来，或者能背但换个问法就懵，是 C。

| 典型表现 | 数学例子 | 对策 |
|---|---|---|
| 只会套公式 | 会算 f'(x)，但说不清 f'(x)>0 为什么意味着递增 | 回到定义，用两个具体点算差值 |
| 混淆近邻概念 | 极值点与极值、单调区间与定义域、充分与必要 | 做"概念对照表"，两列并排 |
| 忽略前提条件 | 用基本不等式不验"一正二定三相等" | 每次用前先念一遍条件 |
| 把特例当通例 | 用 f(1)<f(2) 代替"任意 x₁<x₂" | 给反例，让他自己找漏洞 |

**C 码的补救不能靠刷题。** 刷十道同类题，他还是不知道为什么，只是把错误答案背熟了。

## K · 计算失误

**判据问题**：「你把这一步重算一遍，思路不变，能算出一样的结果吗？」

思路对、式子对、数错，是 K。

| 典型表现 | 数学例子 | 对策 |
|---|---|---|
| 符号错 | 去分母时两边乘负数不变号 | 每步问"我乘的是正还是负" |
| 移项错 | 从 a+b=c 得 a=c+b | 移项单独写一行 |
| 约分/开方错 | √(a²+b²) 写成 a+b | 用具体数代入检验 |
| 抄错 | 上一行的 3 抄成 8 | 关键步骤回读一遍 |
| 单位/范围漏 | 概率算出 1.2 不检查 | 每问结束做"合理性三问" |

**K 码的危险在于它会被误判成"会了"。** 老师看到思路对就给满分，学生也以为自己会了，考场上还是错。所以 K 码要单独统计——如果一个班 K 码超过 40%，说明该练计算，不是该讲新课。

## R · 审题偏差

**判据问题**：「题目问的是什么？你算的是什么？」

会做，但做的不是题目问的，是 R。

| 典型表现 | 数学例子 | 对策 |
|---|---|---|
| 看漏限定词 | "取值范围"答成"最大值" | 读题时圈出疑问词 |
| 忽略隐含条件 | 三角形里边长为负、概率大于 1 | 答完做一次"现实检验" |
| 多问只答一问 | (1)(2) 只做了 (1) | 答完数一遍小问 |
| 把"求"看成"证" | 该证明的写了计算 | 读题时标"求/证/判断" |

**R 码的对策是动作，不是提醒。** "下次认真点"无效；"下次在题目上圈出疑问词"有效。

## M · 方法不当

**判据问题**：「还有别的做法吗？哪种更快？」

能做出来但绕远，或者做到一半做不下去，是 M。

| 典型表现 | 数学例子 | 对策 |
|---|---|---|
| 该用几何用了代数 | 立体几何硬算坐标，其实一步垂直定理就够 | 讲"识别特征"：出现什么条件先想什么方法 |
| 分类讨论不全 | 含参只讨论了 a>0 | 先找临界点，再分段 |
| 不会构造 | 证明不等式想不到构造函数 | 记住三种构造套路：作差、同构、放缩 |
| 陷在死路不回头 | 联立后算出四次方程还在硬解 | 设"止损点"：算过 3 行没进展就换法 |

**M 码最难补，因为它不是知识点问题，是决策问题。** 有效办法是"题型—首步动作"对照训练，不是多做题。

## S · 步骤不规范

**判据问题**：「这一步如果我不写，会扣几分？」

答案对但被扣过程分，是 S。

| 典型表现 | 数学例子 | 对策 |
|---|---|---|
| 跳步 | 直接写"由题意得 f'(x)>0" | 补一句"因为……所以……" |
| 不写依据 | 用韦达定理不说明方程有两解 | 写"由 Δ>0 得" |
| 结论不完整 | 求出 x=1 不写"所以极值点为 x=1" | 每问结尾写结论句 |
| 符号乱用 | 用"⇒"代替"所以" | 统一用汉字连接词 |

**S 码是最容易补的分。** 一个中等生规范书写，通常能多拿 5–8 分。这是投入产出比最高的补救。

## 一个学生身上多种码怎么办

先补 S（一周见效），再补 K（两周），再补 R（一个月），最后补 C 和 M（一学期）。

顺序反了会挫败：先补最难的 C，学生练两周没进步，就放弃了。

## 全班错因分布怎么读

| 分布特征 | 说明 | 讲评课怎么办 |
|---|---|---|
| C 码集中 | 这节课的概念没落地 | 重讲概念，不刷新题 |
| K 码集中 | 计算能力问题 | 当堂限时计算训练，5 分钟 10 题 |
| R 码集中 | 读题习惯问题 | 当堂做"只读不算"训练：读题圈词，不写解答 |
| M 码集中 | 方法选择问题 | 做"首步动作"专项：只看题说第一步 |
| S 码集中 | 书写规范问题 | 展示两份卷子对比：答案一样，分差 7 分 |
