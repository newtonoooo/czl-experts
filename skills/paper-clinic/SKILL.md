# 批改产线

批改的价值不在"打个分"，在两件事：**这份卷子暴露了什么**，**下节课先讲哪题**。

所以这条产线分两段：单份批改（对着一个学生）和整班学情（对着一张表）。两段可以用同一套错因码，这样"某个学生的错"能汇进"全班的错"。

## 第一段：单份批改

### 批注按评分细则走

批改前先有细则（没有就用 `paper-forge` 的评分细则模板倒推）。批注要落到**具体那一步**：

```
第 17 题（15 分）　得分 9/15
(1) 证明线面平行 ✔ 5/5　建系正确，方向向量找对
(2) 求二面角余弦 ✘ 4/10
    第 2 步：法向量 n₁ 算错（应为 (2,-1,2)，你写 (2,1,2)）→ 扣 3 分
    第 4 步：未判断二面角是锐角还是钝角，直接取正值 → 扣 3 分
    前 3 步方法正确，给分
```

**"方法对但算错"必须明确说出来。** 学生最怕的是不知道自己到底是不会还是算错。

### 错因码

每个错点打一个码，全产品统一，见 `references/error-taxonomy.md`：

| 码 | 含义 | 一句话判据 |
|---|---|---|
| C | 概念不清 | 说得出公式，说不出为什么 |
| K | 计算失误 | 思路对，式子对，数错了 |
| R | 审题偏差 | 会做，但做的不是题目问的 |
| M | 方法不当 | 能做出来，但绕远或做不下去 |
| S | 步骤不规范 | 答案对，被扣过程分 |

### 评语三条规矩

1. **两句话：一句说做对了什么，一句说下一步改什么。** 不要写"继续努力"。
2. **改什么必须是下一次能执行的动作。** "注意审题"没用，"下次先在题目上圈出'取值范围'三个字"有用。
3. **不只夸结果，夸动作。** "你把 Δ>0 单独写了一行，这个习惯保住了 2 分"比"很好"有用。

## 第二段：整班学情

### 先算，再说

老师给一张分题得分表（CSV / Excel 复制过来的纯文本 / 手写照片转文字），一律用脚本算：

```bash
python bin/score_report.py 成绩.csv --full-marks 5,5,5,5,5,5,5,5,6,6,6,5,5,5,13,15,15,17,17
```

脚本出：均分、中位数、标准差、分数段分布、各题得分率与难度判断、失分点排序、临界生名单。**不要用模型心算均分**——算错一个数，整份分析作废。

### 失分点怎么排

不是按"得分率最低"排，按**可挽回的分**排：

```
可挽回分 = 该题分值 × (1 - 得分率) × 覆盖人数比例
```

一道 17 分的压轴题得分率 0.18，可挽回 13.9 分；一道 5 分的选择题得分率 0.4，可挽回 3 分。但压轴题的可挽回分**大部分挽不回**（学生就是不会），所以还要乘一个"可教性系数"：

| 题型 | 可教性 | 说明 |
|---|---|---|
| 基础选择/填空 | 0.9 | 讲一遍就会 |
| 中档解答前两问 | 0.7 | 练几次能拿 |
| 压轴题(3) | 0.2 | 讲了多数人还是不会 |

**讲评顺序 = 可挽回分 × 可教性 排序，取前 3。** 这个算法脚本里已经实现。

### 报告结构

按 `templates/analysis-report.md` 写。核心三块：数据表、失分点归因、分层动作。
**不写"整体情况良好，但仍需努力"这类评语。** 数据说话。

## 两段怎么接

单份批改的错因码可以直接汇总成整班数据：

```
C 码 23 次 → 概念问题集中在"法向量方向"
K 码 41 次 → 计算问题集中在"去分母变号"
```

这时候讲评课的重点就有了，不用猜。

## 边界

- 不索要学生姓名、学号、身份证号。要名单就用"1 号—45 号"，或让老师自己对应。
- 分数表有缺项——按能给的部分算，缺的列出来，不猜。
- 老师要求"把分数改高一点"——拒绝，说明这是成绩造假。
- 照片批改看不清——指出哪一题哪一步看不清，请补拍那一处，不猜学生写了什么。
