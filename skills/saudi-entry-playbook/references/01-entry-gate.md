# 01 · 准入闸门

> 用途：G1 闸门。判断「这件事在沙特能不能做、以什么条件能做」。
> 时效：本卡片为结构性框架。具体清单与门槛**必须**回到 MISA（沙特投资部）与行业监管机构最新公告核对。文中所有带 `待核实` 的项，不得直接写进对客户的承诺。

## 三条并行判定线

准入不是一道题，是三道题同时过。任何一条不过，整体就是 `BLOCKED` 或 `CONDITIONAL`。

### 线一：外资准入（能不能由外资做）

| 判定项 | 要查什么 | 结论形态 |
|---|---|---|
| 活动是否在受限/禁止清单内 | MISA 外资活动分类与负面清单（最新版） | 可做 / 需特别批准 / 禁止 |
| 外资持股上限 | 该活动允许 100% 外资，还是必须本地持股 | 100% / 有上限 / 需特批 |
| 最低投资额或实体要求 | 部分活动对资本金、实体规模、经营年限有门槛 | 金额与条件（待核实） |
| 是否需要本地服务代理 | 部分受监管产品要求本地售后与备件责任方 | 需要 / 不需要 |

**结构性判断（不需要查清单就能下的结论）**

- 外资持股 < 100% 且没有本地股东 → 股权结构不成立，直接阻断。
- 100% 外资 + 纯贸易类活动 → 历史上长期受限，通常需要额外门槛或改走「本地代理 + 本地库存」结构，**不能默认可行**（待核实最新规则）。
- 上游油气勘探开发、麦加与麦地那的特定房地产活动、部分人力招聘与安保服务，属于长期高敏感领域，默认按「需特别批准」处理。

### 线二：行业许可（能不能拿到经营资格）

按行业找监管机构，不要只盯 MISA。MISA 发的是投资许可，行业许可另发。

| 行业 | 通常需要的许可/资质 | 主管机构 |
|---|---|---|
| 一般贸易与制造 | 投资许可 + 商业注册（CR）+ 商会会员 | MISA / 商务部 |
| 工程承包 | 承包商分类分级 | 沙特承包商管理局（SCA） |
| 医疗、药品、器械 | 产品与机构双重许可 | SFDA |
| 食品 | 进口与工厂许可 | SFDA |
| 通信与 IT 服务 | 服务与频谱类许可 | CST |
| 金融、支付、保险 | 牌照制，门槛高 | SAMA / 保险监管 |
| 教育、培训 | 机构许可 | 教育部 / TVTC |
| 物流与运输 | 运输与仓储许可 | TGA |
| 能源与工业 | 工业许可、能效与标准 | 能源部 / SASO |

判断口径：**先问「谁发牌」，再问「发牌条件是什么」，最后问「拿牌要多久」**。三个都答不上来，这个行业的准入就是没做完。

### 线三：产品准入（货能不能进、能不能卖）

- 受管制产品需通过 SASO 体系认证，进口环节走 SABER 平台出具产品证书与批次证书（详见 `06-product-compliance.md`）。
- 标签、说明书、能效、计量、儿童用品与化学品有强制要求。
- 涉及通信、医疗、食品、化妆品、建材的品类，认证周期通常以「月」计，必须写进时间表。

## 判定输出

| 结论 | 含义 | 允许的下一步 |
|---|---|---|
| `GO` | 三条线均可满足，无阻断项 | 进 G2 路径比选 |
| `CONDITIONAL` | 存在必须先解决的前置条件 | 先补条件，条件清单必须逐条可执行 |
| `BLOCKED` | 存在结构性阻断 | 不出渠道方案，只给替代路径 |

`CONDITIONAL` 是最常见的结论。写判定书时，前置条件必须写成「谁、向谁、交什么、多久」，不能写「办理相关许可」。

## 常见误判（都是真实踩过的坑）

1. **把投资许可当成全部**：拿到 MISA 许可不等于能经营，行业许可、CR、商会、税务登记、社保登记是串行还是并行，决定了你是三个月还是九个月。
2. **默认 100% 外资可行**：贸易、代理、部分服务类活动对持股与本地化有额外要求。
3. **忽略产品认证周期**：认证没下来就签了供货合同，违约在你自己身上。
4. **把「可以注册」当成「可以投标」**：投标还有分类分级、沙特化、保函、业绩要求（见 `04-etimad-tender.md`）。
5. **用别国经验类推**：沙特的政策更新快，两年前的结论经常已经作废。

## 需要官方核对的清单

- MISA：外资活动分类、负面清单、投资许可申请条件
- 商务部：商业注册（CR）与活动代码
- 行业监管机构：本行业许可条件与办理周期
- SASO / SABER：产品认证范围与流程
- ZATCA：税务登记与电子发票要求
