# 09 · 风险台账与退出

> 用途：G5 闸门。每类风险必须有一条可执行的止损线，否则不给启动建议。
> 原则：**没有止损线的计划不是计划，是愿望。**

## 一、风险分类

| 类别 | 具体表现 | 早期信号 | 止损线（示例） |
|---|---|---|---|
| 政策与准入 | 清单调整、许可收紧、激励条件变化 | 监管征求意见、同行被罚 | 核心许可连续两次被拒 → 暂停投入，评估替代路径 |
| 合规 | 认证失效、发票不合规、用工违规 | 扣货、罚款通知、审计约谈 | 出现首次实质性处罚 → 冻结扩张，先整改 |
| 回款 | 账期拉长、验收拖延、保留金难退 | 付款节点连续两次逾期 | 逾期超过合同账期 60 天 → 停止新交付，启动催收 |
| 伙伴依赖 | 单一代理、客户信息不透明 | 拒绝共享客户、拒绝业绩承诺 | 连续两个季度未达承诺 → 降级并启动第二渠道 |
| 汇率与资金 | 本币成本上升、保函占额度 | 银行额度使用率过高 | 保函占用超过授信 60% → 停止接新标 |
| 人才 | 关键岗位招不到、流失率高 | 招聘周期超预期、沙特化不达标 | 关键岗位空缺超过 90 天 → 启动外包或调整编制 |
| 竞争 | 价格战、指定品牌、本地对手 | 报价持续走低、规格被定制 | 毛利率跌破底线 → 退出该品类 |
| 声誉 | 交付事故、劳资纠纷、媒体负面 | 客户投诉集中、社交媒体扩散 | 出现公开负面 → 24 小时内响应预案 |

## 二、风险台账格式

每条风险必须写满六列，缺一列即视为未完成：

| 编号 | 风险 | 触发条件 | 影响 | 止损动作 | 责任人 / 复核周期 |
|---|---|---|---|---|---|

- **触发条件**必须是可观测的事件或数值，不能写「情况恶化」。
- **止损动作**必须是可执行的动作，不能写「加强管理」。
- **复核周期**建议按季度，政策类按月。

## 三、退出路径（进入前就要设计）

| 退出方式 | 适用场景 | 关键条款 |
|---|---|---|
| 代理关系终止 | 渠道不达预期 | 通知期、库存回购、在履行合同承接 |
| 股权转让 | 合资僵局 | 优先购买权、定价公式、僵局触发条件 |
| 实体休眠或注销 | 试水失败 | 税务清算、员工安置、许可注销顺序 |
| 资产处置 | 设厂失败 | 设备残值、土地租约违约、员工补偿 |
| 业务收缩 | 品类失败 | 客户交接、备件承诺的持续期 |

**注意**：沙特商业代理关系的终止有法定程序与登记要求，单方面终止可能面临补偿主张。退出条款必须在签约时写入，事后再谈代价极高。

## 四、止损线的三种写法（对比例子）

| 不合格 | 合格 |
|---|---|
| 「如果市场不好就撤」 | 「首年签约额低于承诺额的 40%，第二季度启动降级流程」 |
| 「注意合规风险」 | 「出现首次实质性处罚，冻结新增投入，30 天内完成整改复核」 |
| 「控制成本」 | 「累计投入超过预算 120%，暂停第二阶段，重做单位经济模型」 |

## 五、必须单列的三类风险

1. **伙伴绑死**：独家条款 + 无业绩承诺 = 结构性风险，必须在 G3 就解决。
2. **认证卡壳**：产品认证未通过，整个商业计划失去前提，必须在 G1 就确认范围。
3. **沙特化不达标**：影响投标资格与用工合法性，是持续性问题，需要季度复核。

## 六、交付物要求

`风险台账` 与 `落地清单` 必须同时交付。台账里每条风险都要能追到一个具体的清单节点——如果一条风险找不到对应的动作节点，说明它只是担心，不是风险。
