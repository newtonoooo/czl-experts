# 04 · Etimad 与政府投标

> 用途：G4 闸门。回答「该不该投、投什么、缺什么资格」。
> 时效：资格条件、保函比例、分类分级规则以 Etimad 平台公告与各采购单位招标文件为准。本卡片给出核对结构，不替代招标文件。

## 沙特政府采购的基本盘

政府与国企采购大量通过 **Etimad（沙特政府采购平台）** 发布与执行：公告、投标、开标、澄清、授标、合同与付款节点。不熟悉平台流程，会在技术之外的地方出局。

关键事实：**政府项目通常不是「价格最低者得」**。技术评分、本地化承诺、业绩、沙特化、交付能力往往与价格一起进入综合评分。

## 投标资格核对表（逐项打勾，缺一项就是废标风险）

### 主体资格
- [ ] 商业注册（CR）有效，且活动代码覆盖招标内容
- [ ] 商会会员有效
- [ ] 投资许可（外资企业）
- [ ] 税务登记与增值税登记
- [ ] 扎卡特与所得税完税证明（按主体类型）
- [ ] 社保（GOSI）缴纳记录
- [ ] 沙特化等级满足招标要求
- [ ] 无欠缴、无失信、无禁止投标记录

### 专业资格
- [ ] 行业分类分级证书（工程承包类由 SCA 分级，其他行业按主管部门）
- [ ] 相关业绩证明（合同、验收单、客户证明）
- [ ] 技术人员资质与本地团队配置
- [ ] 质量管理体系等第三方证书（如要求）

### 财务与担保
- [ ] 初步担保（投标保函），比例与形式按招标文件
- [ ] 履约保函能力（授标后通常需要，额度显著高于投标保函）
- [ ] 近三年财务报表（部分项目要求审计报告）
- [ ] 银行授信或资金证明

### 产品与合规
- [ ] SASO/SABER 认证（受管制产品）
- [ ] 原产地与本地含量要求（如适用）
- [ ] 技术规格逐条响应表（偏离项必须显式声明）

## 常见废标原因（比技术不过关更常见）

1. 保函格式或有效期不符，或提交渠道错误。
2. 报价表漏项、单位错、含税口径不一致。
3. 技术规格未逐条响应，或「完全满足」但无支撑文件。
4. 证书过期（CR、商会、完税证明），临期未续。
5. 沙特化等级或社保记录不达标。
6. 未在规定时间内在平台提交澄清回复。
7. 分包比例或本地含量承诺不满足要求。
8. 语言与签署：阿语版本与英文版本不一致，或授权签字缺失。

## 投标决策口径

| 结论 | 触发条件 |
|---|---|
| `可投` | 资格齐备，技术可满足，价格有空间，保函可开 |
| `补格后可投` | 缺口明确且能在投标窗口内补齐（写清补齐动作与天数） |
| `不投` | 缺口无法在窗口内补齐，或技术规格指向特定厂商，或保函能力不足 |

**劝退也是交付物。** 把「不投」的理由写清楚，比陪着投一次废标更有价值。

## 商机优先级（配合 `pipeline_rank.py`）

排序不要只看合同额。至少四个维度：

- **金额与毛利**：合同额不等于利润，要扣保函成本、账期资金成本、本地化成本。
- **可及性**：有没有资格、有没有关系入口、有没有本地伙伴。
- **时间**：从投标到授标到首笔回款要多久，账期多长。
- **竞争**：指定品牌倾向、 incumbent 供应商、本地竞争者数量。

输出：`优先级 A/B/C`，A 类投入资源，B 类保持跟踪，C 类明确放弃并说明原因。

## 付款与回款

- 政府项目付款流程长，验收与结算环节多，**账期必须计入现金流模型**。
- 预付款比例、里程碑付款、保留金比例，全部写进报价测算。
- 保函占用银行额度，是隐性成本，不能忽略。

## 官方核对路径

- Etimad：招标公告、投标人资格、澄清与授标结果
- SCA（沙特承包商管理局）：工程类分类分级
- ZATCA：完税与电子发票合规
- GOSI / Qiwa：社保与沙特化状态
