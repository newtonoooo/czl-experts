# 05 · 税费与财政口径

> 用途：G2 与 G5 闸门。做三年账和报价测算时的口径来源。
> 时效：税率与规则由 ZATCA 等机构发布，可能调整。**下列标注 `待核实` 的项，签约与报价前必须逐项确认。**

## 主要税种（结构性说明）

| 税种 | 适用对象 | 口径要点 | 状态 |
|---|---|---|---|
| 企业所得税（CIT） | 外资持股部分 | 按应税所得计征，标准税率 20% | 相对稳定 |
| 扎卡特（Zakat） | 沙特/GCC 国籍持股部分 | 按扎卡特基数计征，常见口径 2.5% | 相对稳定 |
| 混合持股 | 按持股比例分别适用 CIT 与 Zakat | 需要分别核算，不能合并简化 | 需会计确认 |
| 增值税（VAT） | 货物与服务 | 标准税率 15%；部分项目零税率或免税 | 相对稳定 |
| 预提税（WHT） | 向非居民支付特定款项 | 股息、利息、特许权使用费、服务费等，按类别适用不同税率（常见区间 5%–15%） | 待核实 |
| 关税 | 进口货物 | 按 HS 编码与自贸安排适用 | 待核实 |
| 不动产交易税 | 不动产处置 | 按交易类型适用 | 待核实 |
| 社保（GOSI） | 用工 | 沙特籍与外籍适用不同险种与比例 | 待核实 |
| 人力资源相关费用 | 外籍用工 | 按人头计征的年度费用，随政策调整 | 待核实 |

> 提示：CIT 与 Zakat 的适用取决于股权结构，**不是按公司注册地判断，而是按股东国籍构成判断**。混合持股是最容易算错的一类。

## 报价时必须显式声明的五个口径

1. **含税 / 不含税**：VAT 是否已包含在报价内。
2. **币种与汇率基准**：SAR 与 USD 的换算基准日；SAR 与 USD 长期挂钩，但成本项中的其他币种仍需处理。
3. **账期与资金成本**：政府项目账期长，报价里是否计入资金占用。
4. **关税与物流责任**：DDP / DAP / FOB 对应不同成本承担。
5. **保函成本**：投标保函与履约保函占用的银行额度与手续费。

少写任何一条，报价都会在后期被吃掉利润。

## 三年账的推荐结构

```
年度净贡献 = 收入
           − 直接成本（货物/服务成本 + 关税 + 物流）
           − 本地运营成本（人力全成本 + 租金 + 合规与认证 + 保险）
           − 市场与渠道成本（代理佣金 + 市场投入 + 差旅）
           − 税费（VAT 为价外税不计入损益；CIT/Zakat 按应税所得）
           − 资金成本（账期占用 + 保函额度）
```

`route_cost.py` 使用的就是这个结构，参数全部要求显式输入，脚本不会替你猜费率。

## 常见误判

1. **把 VAT 当成本**：VAT 是价外税，进项可抵扣；真正影响利润的是无法抵扣的部分与现金流占用。
2. **只算 CIT 不算 Zakat**：混合持股时两者并存。
3. **忽略预提税**：向境外母公司支付技术费、管理费、利息时会被扣缴，影响集团层面的实际收益。
4. **忽略人头费**：外籍用工的年度费用是持续性成本，不是一次性支出。
5. **用中国税负直觉做决策**：沙特的税负结构不同，且合规成本（认证、审计、代理）占比更高。

## 交付物要求

在路径决策备忘中，税负部分必须给出一张表：

| 年度 | 收入 | 直接成本 | 运营成本 | 渠道成本 | 税前利润 | CIT | Zakat | 净贡献 |
|---|---|---|---|---|---|---|---|---|

并在表下注明：税率来源、假设、以及哪些项是 `待核实`。

## 官方核对路径

- ZATCA（税务与海关总局）：CIT、Zakat、VAT、WHT、电子发票
- GOSI：社保口径
- HRSD / Qiwa：用工相关费用
- 海关：HS 编码与关税
