# 原创过程图谱（czl-bio-atlas 参考）

本图谱按"场所—条件—物质—能量—意义"五段整理，供 W2 直接取用。表述以人教版高中生物必修与选择性必修的通行说法为准；不同版本措辞有差异时，以学生手上的课本为准。

---

## 一、光合作用

```
H₂O ──(类囊体薄膜·需光与色素)──> O₂ ↑ + NADPH([H])
ADP + Pi ──(类囊体薄膜·需光)──> ATP
                    │
                    ▼  提供 ATP 与 NADPH
CO₂ + C₅ ──(叶绿体基质·需酶)──> 2C₃
C₃ ──(叶绿体基质·需 ATP、NADPH、酶)──> (CH₂O) + C₅（再生）
```

| 环节 | 场所 | 条件 | 输入 → 输出 |
|---|---|---|---|
| 水的光解 | 类囊体薄膜 | 光、色素、酶 | H₂O → O₂ + NADPH |
| ATP 合成 | 类囊体薄膜 | 光、ADP、Pi | 光能 → 活跃化学能 |
| CO₂ 固定 | 叶绿体基质 | C₅、酶 | CO₂ + C₅ → 2C₃ |
| C₃ 还原 | 叶绿体基质 | ATP、NADPH、酶 | C₃ → (CH₂O) + C₅ |

**最易断的一环**：光反应与暗反应之间的物质互供。学生能背"光反应提供能量"，但说不出"提供 ATP 和 NADPH，暗反应把 ADP、Pi、NADP⁺ 还回去"。这一句说不出，条件变化题必错。

**条件突变的固定推法**（短时间内的变化）：

| 变化 | C₃ | C₅ | ATP / NADPH | O₂ 释放 |
|---|---|---|---|---|
| 突然停止光照 | 增多 | 减少 | 减少 | 停止（水的光解停） |
| 突然停止 CO₂ | 减少 | 增多 | 短时增多（用不掉） | 短时继续，随后减慢 |
| 光照由弱变强（未到饱和） | 减少 | 增多 | 增多 | 增多 |

推理的口子只有一句话：**先看哪一步断了原料或断了下游，再看这一步的"上游堆积、下游断供"。**

## 二、细胞呼吸

```
【有氧】
葡萄糖 ──(细胞质基质·不需氧)──> 丙酮酸 + [H] + 少量ATP
   丙酮酸 ──(线粒体基质·需水)──> CO₂ + [H] + 少量ATP
   [H] + O₂ ──(线粒体内膜·需酶)──> H₂O + 大量ATP

【无氧·乳酸发酵】
葡萄糖 ──(细胞质基质)──> 2 乳酸 + 少量ATP

【无氧·酒精发酵】
葡萄糖 ──(细胞质基质)──> 2 酒精 + 2CO₂ + 少量ATP
```

| 环节 | 场所 | 条件 | 输入 → 输出 |
|---|---|---|---|
| 糖酵解 | 细胞质基质 | 不需氧、需酶 | 葡萄糖 → 丙酮酸 + [H] + 少量 ATP |
| 丙酮酸彻底分解 | 线粒体基质 | 需水、需酶 | 丙酮酸 → CO₂ + [H] + 少量 ATP |
| 氧化磷酸化 | 线粒体内膜 | 需 O₂、需酶 | [H] + O₂ → H₂O + 大量 ATP |
| 无氧呼吸第二阶段 | 细胞质基质 | 不需氧 | 丙酮酸 + [H] → 乳酸 / 酒精 + CO₂（**不产 ATP**） |

**最易断的一环**：以为无氧呼吸两个阶段都产 ATP。实际只有第一阶段产。另一处常错：把"二氧化碳"当成人呼出的气体与"呼吸作用"混为一谈。

## 三、光合与呼吸的接口（净光合）

```
真光合固碳量 ──减去──> 呼吸消耗 ──等于──> 净积累（表现为生长、有机物增加）
```

| 概念 | 含义 | 常见考法 |
|---|---|---|
| 真（总）光合速率 | 叶绿体实际同化的 CO₂ 量 | 用 "¹⁴CO₂ 固定量""叶绿体 O₂ 产生量" 表示 |
| 净光合速率 | 表观积累量 | 用 "O₂ 释放量""CO₂ 吸收量""有机物积累量" 表示 |
| 呼吸速率 | 线粒体消耗量 | 用 "黑暗中 CO₂ 释放量" 表示 |

**三条恒等式**（当公式用，不要当口诀背）：

- 真光合 = 净光合 + 呼吸
- 光合产 O₂ 量 = 释放到外界的 O₂ + 呼吸消耗的 O₂
- 光合耗 CO₂ 量 = 从外界吸收的 CO₂ + 呼吸产生的 CO₂

**最易断的一环**：把"净光合为零"理解成"不进行光合"。净为零时真光合 = 呼吸，光合仍在进行，只是刚好被呼吸抵消。

## 四、基因表达与中心法则

```
DNA ──(细胞核·转录·RNA聚合酶·需能量)──> mRNA
mRNA ──(核糖体·翻译·tRNA运氨基酸·需能量)──> 多肽链 ──折叠──> 蛋白质
```

| 环节 | 场所（真核） | 条件 | 输入 → 输出 |
|---|---|---|---|
| 复制 | 细胞核 | 模板两条链、四种脱氧核苷酸、解旋酶与聚合酶、能量 | DNA → 2 个 DNA |
| 转录 | 细胞核 | 模板一条链、四种核糖核苷酸、RNA 聚合酶 | DNA → mRNA |
| 翻译 | 核糖体 | mRNA 作模板、tRNA 运氨基酸、酶与能量 | mRNA → 多肽 |

**补充两条（选择性必修）**：RNA 复制（RNA → RNA）、逆转录（RNA → DNA），见于某些病毒。原核细胞无核膜，转录与翻译可同时进行。

**最易断的一环**：把"转录的模板是整条 DNA"当成"两条链都转录"。实际以其中一条链为模板。另一处：混淆"密码子（mRNA 上）"与"反密码子（tRNA 上）"。

## 五、减数分裂与配子形成

```
精原细胞 ──(间期·复制)──> 初级精母细胞
   │
   ├─(减数第一次分裂：同源染色体联会→四分体→可交叉互换；后期同源分离、非同源自由组合)
   ▼
2 个次级精母细胞
   │
   ├─(减数第二次分裂：着丝粒分裂，姐妹染色单体分开)
   ▼
4 个精细胞 ──变形──> 4 个精子
```

卵细胞形成：同样两次分裂，但细胞质不均等分裂，最终形成 1 个卵细胞 + 3 个极体。

| 时期 | 染色体行为 | 数目特征 |
|---|---|---|
| 减Ⅰ前期 | 同源染色体联会、形成四分体、可发生交叉互换 | 染色体数不变，DNA 已加倍 |
| 减Ⅰ后期 | 同源染色体分离，非同源染色体自由组合 | 染色体数不变 |
| 减Ⅱ后期 | 着丝粒分裂，姐妹染色单体分开 | 染色体数暂时加倍，与体细胞相同 |
| 减Ⅱ末期 | 形成四个子细胞 | 染色体数为体细胞一半 |

**最易断的一环**：染色体数、DNA 数、染色单体数三个量混着记。记一条：**着丝粒一分裂，染色体数就翻倍，染色单体数归零。**

**配子种类速算**：n 对同源染色体 → 一个精原细胞产生 2 种精子（不考虑交叉互换）；一个个体产生 2ⁿ 种。

## 六、神经调节

```
静息：K⁺ 外流 ──> 膜外正、膜内负（静息电位）
兴奋：Na⁺ 内流 ──> 膜外负、膜内正（动作电位）
恢复：Na⁺/K⁺ 泵工作，恢复到静息状态

突触传递：
轴突末梢（电信号）──> 突触小泡释放递质（化学信号）──> 突触后膜受体 ──> 新的电信号
```

| 环节 | 场所 | 条件 | 关键点 |
|---|---|---|---|
| 静息电位维持 | 神经纤维膜 | K⁺ 通道开放 | 外正内负 |
| 动作电位产生 | 受刺激部位 | Na⁺ 通道开放 | 外负内正，局部电流形成 |
| 传导 | 神经纤维上 | 局部电流刺激邻近部位 | 双向传导 |
| 突触传递 | 突触 | 递质、受体、酶 | 单向：递质只由突触前膜释放 |

**最易断的一环**：把"兴奋在神经纤维上双向、在突触处单向"记反。另外常错：以为递质一定引起兴奋，实际有抑制性递质。

## 七、体液调节（两个必考模型）

**甲状腺激素的分级调节与反馈**

```
下丘脑 ──TRH──> 垂体 ──TSH──> 甲状腺 ──甲状腺激素──> 全身细胞
   ▲                                │
   └────────── 负反馈抑制 ───────────┘
```

| 环节 | 分泌者 | 靶器官 | 结果 |
|---|---|---|---|
| TRH | 下丘脑 | 垂体 | 促进 TSH 分泌 |
| TSH | 垂体 | 甲状腺 | 促进甲状腺激素合成与分泌 |
| 甲状腺激素 | 甲状腺 | 全身细胞 | 促进代谢与发育；过多时抑制前两级 |

**血糖调节**

```
血糖升高 ──> 胰岛B细胞 ──胰岛素──> 促进摄取、利用、储存（降血糖）
血糖降低 ──> 胰岛A细胞 ──胰高血糖素──> 促进肝糖原分解、非糖物质转化（升血糖）
```

**最易断的一环**：只记住"胰岛素降血糖"，说不出降的三条路径（促进细胞摄取、促进氧化分解、促进合成糖原与脂肪）。答题时写不出具体路径，采分点拿不全。

## 八、免疫调节

```
【体液免疫】
抗原 ──> 吞噬细胞处理呈递 ──> 辅助性T细胞 ──> B细胞
                                              ├─> 浆细胞 ──> 抗体 ──> 与抗原结合
                                              └─> 记忆B细胞（二次免疫）

【细胞免疫】
抗原（胞内寄生）──> 细胞毒性T细胞 ──> 识别并接触靶细胞 ──> 靶细胞裂解死亡
```

| 环节 | 执行者 | 作用对象 | 结果 |
|---|---|---|---|
| 呈递 | 吞噬细胞等 | 抗原 | 把抗原信息呈给辅助性T细胞 |
| 产生抗体 | 浆细胞 | 细胞外抗原 | 抗体与抗原特异性结合 |
| 裂解靶细胞 | 细胞毒性T细胞 | 被寄生的细胞 | 靶细胞裂解，病原体暴露 |
| 二次免疫 | 记忆细胞 | 同种抗原再次入侵 | 更快、更强 |

**最易断的一环**：把"浆细胞能识别抗原"当常识。浆细胞不识别抗原，它只分泌抗体——识别靠 B 细胞等。

## 九、生态系统的能量流动

```
生产者固定太阳能 ──> 初级消费者同化 ──> 次级消费者同化 ──> 三级消费者同化
        │                   │                  │
        └─ 呼吸散失          └─ 呼吸散失         └─ 呼吸散失 + 遗体残骸入分解者
```

| 规律 | 内容 | 考点 |
|---|---|---|
| 单向流动 | 从生产者到各级消费者，不能逆向 | 判断"能否循环利用" |
| 逐级递减 | 传递效率通常 10%—20% | "至少/最多"的计算 |
| 能量去向 | 呼吸散失、流入下一营养级、流向分解者、未被利用 | 四去向必须齐 |

**计算口径（务必区分）**：

- 求"至少消耗"生产者 → 用 **20%** 逐级**除**（消耗少）
- 求"最多消耗"生产者 → 用 **10%** 逐级**除**（消耗多）
- 求"最多获得" → 用 **20%** 逐级**乘**；求"至少获得" → 用 **10%** 逐级**乘**

**最易断的一环**：把"同化量"与"摄入量"混用。同化量 = 摄入量 − 粪便量。

## 十、细胞分裂中三个量的变化（速查）

| 时期（有丝分裂） | 染色体数 | DNA 数 | 染色单体数 |
|---|---|---|---|
| 间期（复制前） | 2n | 2n | 0 |
| 间期（复制后） | 2n | 4n | 4n |
| 前期、中期 | 2n | 4n | 4n |
| 后期（着丝粒分裂） | 4n | 4n | 0 |
| 末期（分裂完成） | 2n | 2n | 0 |

一句话：**只要有染色单体，DNA 数就等于染色单体数；着丝粒一分裂，染色体数翻倍、染色单体归零。**
