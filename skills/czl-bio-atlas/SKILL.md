# W2 过程攻坚与知识图谱

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 过程攻坚与知识图谱（czl-bio-atlas） |
| **任务职责** | 把一条断掉的生理过程重建成可复述的因果链，标出断点，用三种验法确认链条通了，再留一道迁移题。一次只修一条链。 |
| **输入参数** | 必填：过程名称（如"光合作用""减数分裂""体液免疫"）、孩子卡住的原话。建议：教材版本与章节、一道相关原题、孩子自己画的图或笔记。 |
| **执行步骤** | ①确认链条的起点与终点 → ②按"场所—条件—物质—能量—意义"五段画链 → ③在链上标出断点位置 → ④讲链，每段不超过 5 分钟并跟一道 30 秒小问 → ⑤三种验法验链（反向问、换条件问、跨界问） → ⑥给一道同类迁移题 → ⑦留一句可背的口诀（可选，能不用就不用） |
| **判断条件** | 说不出顺序 → 先补顺序，不进入条件题；说得出顺序但说不出场所 → 补场所；链条通但一变条件就错 → 转条件变化专项（仍在 W2 内）；两条链互相干扰（光合/呼吸） → 先各画一条，再画一张接口图 |
| **输出格式** | 一张箭头链（每环括号标场所与条件）+ 环节要点表（场所/条件/输入/输出）+ 三道验链小问 + 一道迁移题。链图上断点用 `◀ 卡这里` 标出。 |
| **异常处理** | 孩子要求"直接把整章总结给我" → 只给一条链，其余章节列成待办清单；教材版本表述冲突 → 按人教版讲并注明差异；孩子只想背不想画 → 允许，但要求他闭眼复述一遍顺序，说不清就回来画；内容超出高中范围 → 一句"超出高考范围"后停止展开 |
| **必要依赖** | `references/process-atlas.md`（原创过程图谱）、`references/compare-tables.md`（易混概念对照）、`references/formula-sheet.md`（计算类公式与算式模板） |
| **与其他工作流的关系** | 上游：W1 判定为"过程不清"或"概念混淆"。下游：验链通过后进 W3（遗传）／W4（实验）／W5（读图）；条件变化类错题转 W5。与 W6 的关系：本工作流产出的链条摘要进错题本。 |

## 一、一条链的五段

任何一条生理过程，都按这五段拆。缺哪段，就在哪段停住。

| 段 | 问什么 | 例（有氧呼吸第三阶段） |
|---|---|---|
| 场所 | 在哪发生 | 线粒体内膜 |
| 条件 | 需要什么才能发生 | 需要 [H] 与 O₂，需要酶 |
| 物质 | 进什么、出什么 | [H] + O₂ → H₂O |
| 能量 | 能量怎么走 | 释放大量能量，合成大量 ATP |
| 意义 / 调控 | 这一步对整体有什么用，被什么调节 | 提供绝大部分 ATP；受 ADP 浓度与氧供应影响 |

**为什么必须这五段**：学生丢分，八成丢在"场所"和"条件"。他知道有这一步，但不知道在哪、靠什么。五段填满，答题时条件自然写得出来。

## 二、链怎么画

只用三种符号，不要发明第四种：

```
葡萄糖 ──(细胞质基质·不需氧)──> 丙酮酸 + [H] + 少量ATP
                                      │
                                      ▼
                          ──(线粒体基质·需水)──> CO₂ + [H] + 少量ATP
                                      │
                                      ▼
                          ──(线粒体内膜·需O₂)──> H₂O + 大量ATP
```

- 箭头上写**条件**，括号里写**场所**。
- 分支用 `├─` `└─`，不要画斜线。
- 断点用 `◀ 卡这里`，写在断掉的那一环后面。
- 一条链不超过 8 环。超过 8 环，说明你在抄课本，不是在画链——拆成两条。

## 三、三种验链法（讲完必验，不验不算讲完）

| 验法 | 怎么问 | 通了的表现 |
|---|---|---|
| **反向问** | 给你产物，倒推场所和条件 | "有 H₂O 生成、释放大量 ATP，这是哪一步？在哪？" |
| **换条件问** | 抽掉一个条件，问哪一环先停 | "没有 O₂ 了，这条链停在哪？产物变成什么？" |
| **跨界问** | 问两条链的交点 | "光合产生的 O₂ 去哪了？呼吸产生的 CO₂ 又被谁用了？" |

三种验法里，**换条件问最有效**。会做原题不算通，换条件还能答才算通。

## 四、对比表只比三列

概念混淆的修法不是重讲，是摆在一起比。比三列就够：**定义第一句、成立条件、一个实例**。列多了没人看。

例（详见 `references/compare-tables.md`）：

| 项 | 协助扩散 | 主动运输 |
|---|---|---|
| 定义 | 需载体、顺浓度、不耗能 | 需载体、逆浓度、耗能 |
| 条件 | 载体 + 浓度差 | 载体 + 能量 + 浓度差（逆） |
| 实例 | 葡萄糖进入红细胞 | 小肠上皮细胞吸收葡萄糖、根细胞吸收无机盐 |

## 五、讲解节奏（这一段最容易讲砸）

- 每段讲解不超过 5 分钟，讲完停，问一个问题。**连讲三段不问，孩子已经在走神。**
- 讲的时候说出你的判断过程，不要只报结论。例："我看到题干写'突然停止光照'，先想光反应靠什么——光。光没了，ATP 和 NADPH 就断供，那暗反应里需要它们的那一步就停。"
- 孩子答错，不要立刻纠正。先问"你刚才想到哪一步了"，让他自己发现断点。
- 一条链讲完，让孩子**合上材料复述一遍**。复述不出来，说明链还没通，回头重走，不要往前赶。

## 六、四种常讲错的说法（看到就要改）

| 错说法 | 为什么错 | 改成 |
|---|---|---|
| "暗反应在黑暗中进行" | 暗反应不需要光直接参与，但需要光反应提供的 ATP 与 NADPH，长期无光就停 | "暗反应不直接需要光，但离不开光反应的产物" |
| "无氧呼吸不产生 ATP" | 第一阶段照样产生少量 ATP | "无氧呼吸只在第一阶段产生少量 ATP" |
| "酶在新陈代谢中提供能量" | 酶只降低活化能，不供能 | "酶降低反应所需活化能，能量由 ATP 等提供" |
| "伴性遗传就是男孩得病" | 伴 X 显性、伴 Y 遗传规律完全不同 | "先定是哪种伴性，再套对应规律" |

## 七、收口

一条链修完，交三样东西：

1. 链图（可拍照存进错题本）
2. 三道验链小问（当天做）
3. 一道迁移题（次日做，不问人）

迁移题必须与刚讲的是**同一类、不同一道**。给同一道题改个数字，等于没留。
