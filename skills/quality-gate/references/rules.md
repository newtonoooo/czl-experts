# 八项指标的完整定义与调参

> 这份文件是 `scripts/quality_gate.py` 的说明书。脚本改阈值时，这里必须同步改。
> 当前版本：v1.0.0

## 为什么不用"AI 检测器"

现有 AI 文本检测器大多基于困惑度与词频分布，对中文长文的误判率高，而且只给一个分数，不给改法。创作者需要的不是"87% 像 AI"，是"第 12 句开始连排四个短句，删掉两个"。

所以这里不做 AI 概率判定，只做**可指认的特征测量**。每一分都能落到具体句子。

## 1. 节奏变化（20 分）

**指标**：句长变异系数 CV = 句子字数标准差 ÷ 句子字数均值。

**为什么用 CV**：均值看不出问题。一篇 20 字均值的长文，可以是"全部 20 字"，也可以是"8 字、45 字、12 字"交替——前者死板，后者有呼吸。CV 能区分。

**计算**：
```
score = clamp((CV - 0.28) / 0.32 × 20, 0, 20)
```
- CV = 0.28 → 0 分（几乎一样长）
- CV = 0.60 → 20 分

**参考值**（中文写作抽样经验，非实验数据）：真人写作常见 0.45—0.70；模板化文本常在 0.25—0.40。

## 2. 套话控制（20 分）

**指标**：每千字命中的套话词个数。

```
score = clamp(20 - (命中数 / 千字数) × 3.5, 0, 20)
```

词表见脚本 `CLICHE`，分三组：公文腔（赋能/抓手/闭环/颗粒度）、议论文套话（首先/其次/最后/综上所述）、时代腔（在这个…的时代/让我们一起）。

**注意**："首先/其次/最后"这类词不是绝对的错，但在公众号短文中它们几乎只起占位作用。命中后必须逐处判断：删掉这句话，上下文缺信息吗？缺就保留，不缺就删。

## 3. 元叙述（15 分）

**指标**：作者跳出来指挥读者阅读的地方。

```
score = clamp(15 - 元叙述×7 - 总结句标签×5, 0, 15)
```
**一处命中即 8 分以下，三处即 0 分**——这是全表最严的一项，因为它是"AI 味"最稳定的信号。

**元叙述**：这才是全文最要紧的一段 / 请注意 / 多说一句 / 下面我们 / 划重点 / 看到这里你会发现
**总结句标签**：一句话概括 / 说到底 / 归根结底 / 本质上讲

区别：元叙述是**提示读者怎么读**；总结句标签是**用标签代替论证**。两者都不是信息，删掉不影响理解。

## 4. 句式变化（15 分）

**指标 A**：三句以上连续、长度差 ≤ 4 字、且都不超过 30 字的句串（同构短句）。
**指标 B**：启发式对仗检测——连续 3 句长度差 ≤ 2 字且含并列结构。

```
score = clamp(15 - 同构句串×6 - 对仗×3, 0, 15)
```

**为什么"三句"是阈值**：两句短句是节奏，三句是模式。第四句开始读者会预判你的句式，注意力从内容转到形式。

## 5. 段落功能（10 分）

**指标**：首句以连接词开头（因此/所以/此外/然而）或以总结语结尾（因此/总之/以上就是）的段落，占全部段落的比例。

```
score = clamp(10 - 比例 × 22, 0, 10)
```

**为什么这算病**：每段都带过渡和总结，说明作者在替读者做逻辑连接。真人写作常常直接甩事实，读者自己会接上。比例 45% 以上就该动手删。

## 6. 比喻密度（5 分）

**指标**：含"像/如同/仿佛/好似/宛如"的句子数 ÷ 段落数。

```
score = clamp(5 - max(0, 密度 - 0.4) × 12, 0, 5)
```
密度 ≤ 0.4 满分。一段一个比喻是"漂亮句子通货膨胀"，读到第五个读者就不信了。

## 7. 生活痕迹（10 分）

**指标**：证据数 ÷ 千字，证据 = 口语词数 + 2×成对引语数 + 1.5×时间场景标记数。

```
score = clamp(证据 / 千字 × 2.4, 0, 10)
```

时间场景标记：第一天/那天下午/去年/临走/有一次/当时。
**这一项不是要求加"呢、吧、啊"**。加语气词是假口语；补一个具体时刻才是真生活。

## 8. 具体信息（5 分）

**指标**：阿拉伯数字 + 中文数量词 + 引号专名，总数 ÷ 千字。

```
score = clamp(总数 / 千字 × 1.0, 0, 5)
```

**中文数量词**必须单独统计（"四十来岁""十二页""两万多张"），否则会严重低估——这是 v1.0 开发时踩过的坑，只数 `\d` 会把一篇满是数字的稿子判成"没有具体信息"。

## 总分与结论

| 条件 | 结论 |
|---|---|
| 有硬伤 | 需修（有硬伤） |
| 无硬伤且 ≥ 80 | 可发 |
| 无硬伤且 ≥ 通过线（默认 75） | 可发（轻度打磨） |
| 60—74 | 需修 |
| < 60 | 建议重写 |

**硬伤优先于分数**：一篇 85 分但有三处元叙述的稿子，比 78 分没有元叙述的稿子更需要改。元叙述是读者能直接感觉到的"不对劲"。

## 调参指引

应用在不同账号上时，可调三处：
1. `--min-score`：垂直类干货号可放宽到 70；人格化强的号建议 80。
2. `CLICHE` 词表：把用户所在行业的高频套话加进去（教育号常见"赋能、闭环"，财经号常见"逻辑、周期"）。
3. `MAX` 权重：如果用户明确不在意修辞（比如政策解读号），可把"比喻密度"降到 3 分，"具体信息"提到 8 分。

调参后必须用 `samples/` 里的两份样本回归一次，确认排序没有反转（坏样本分数必须显著低于好样本）。
