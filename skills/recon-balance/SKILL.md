# W3 对账与余额调节

对账的目的不是把两个数字弄成一样，而是说清每一个差额的来路。差额分两种：会自己消失的（时间性），和不会自己消失的（永久性）。分错了，下个月还会再错一次。

## 工作流卡片

| 字段 | 内容 |
|------|------|
| **工作流名称** | W3 对账与余额调节（recon-balance） |
| **任务职责** | 找出两套记录之间的全部差额，逐项归因分类，给出调账或挂账处置 |
| **输入参数** | 科目及编码；期间；账面余额（A/B 级来源）；外部对手方余额（银行对账单/客户对账单/函证/子账）；上期未达账项清单；账龄口径；重要性门槛 |
| **执行步骤** | ① 锁定两侧余额与截止时点 → ② 跑四柱滚算确认账面自身闭合 → ③ 逐笔匹配，未匹配项进差异池 → ④ 差异分类（时间性/永久性 × 方向） → ⑤ 出调节表并跑 `bank-rec`（资金类） → ⑥ 对永久性差异出调账分录 → ⑦ 更新未达账项台账 → ⑧ 出复核签字页 |
| **判断条件** | 两侧调节后差额 ≠ 0 → 不得出"已对平"结论，标 R0；单项差异挂账 >90 天 → R1；差异性质无法判断 → 列待查，禁止默认归为时间性；单边挂账（只有一方有记录）→ 必须列双向核对清单 |
| **输出格式** | 调节表（两侧调至一致）+ 差异明细表（金额/类别/方向/账龄/处置）+ 调账分录 + 未达账项台账 + 复核签字栏 |
| **异常处理** | 银行未达账超 6 个月 → 提示可能存在错账或票据异常，建议逐笔追查；同一客户双边余额 → 出重分类建议；受限资金（保证金/冻结）→ 单独列示，不得并进"货币资金"可用额度 |
| **必要依赖** | `bin/ledgerkit.py bank-rec`、`rollforward`；调账分录转 W2 生成 |
| **与其他工作流关系** | 上游为 W1 任务单与 W2 记账结果；下游为 W4（余额不平则报表必不平）；差异原因若属业务问题回流 W2 改分录；W6 结账日历中占 L2—L3 层 |

## 三类对账，别混着做

| 类型 | 比谁和谁 | 典型对象 | 目的 |
|------|---------|---------|------|
| **账实** | 账面 vs 实物/外部凭证 | 银行、现金、存货、固定资产、往来函证 | 证明资产真的存在 |
| **账账** | 总账 vs 明细账 / 子账 | 应收应付子账、存货明细、固定资产卡片 | 证明汇总没错 |
| **账证** | 账簿 vs 凭证 | 科目发生额与凭证汇总 | 证明过账没错 |

顺序固定：先账证（凭证过账对不对），再账账（汇总对不对），最后账实（外部认不认）。反过来做，会把过账错误当成未达账项，越查越乱。

## 四柱滚算

所有余额类科目都能这么验：

```
旧管（期初） + 新收（本期增加） − 开除（本期减少） = 实在（期末）
```

```bash
python bin/ledgerkit.py rollforward -f 滚算输入.json
```

返回差额为 0 才算账面自身闭合。这一步不过，后面的对账没有意义——你连"账内是不是自洽"都没确认。

## 银行存款余额调节表

四类调节项，方向不能搞错：

| 调节项 | 含义 | 加在哪一侧 |
|--------|------|-----------|
| 企业已收、银行未收 | 企业记了收款，银行还没到账（在途存款） | 加到**银行**侧 |
| 企业已付、银行未付 | 企业记了付款，票据未兑付（未兑现支票） | 从**银行**侧扣 |
| 银行已收、企业未收 | 银行记了收款，企业没入账（利息、代收） | 加到**账面**侧 |
| 银行已付、企业未付 | 银行扣了款，企业没入账（手续费、代扣） | 从**账面**侧扣 |

```bash
python bin/ledgerkit.py bank-rec -f 调节输入.json
```

判定：两侧调节后余额相等 → 通过；否则差额属未查明事项，**禁止挂"其他"科目抹平**，先查对账单完整性与企业日记账漏记。

调节项检查清单：

- [ ] 对账单页码连续，无缺页；截取时点在期末最后一个工作日
- [ ] 在途存款是否有对应收款凭证与银行进账时间
- [ ] 未兑现支票是否超过有效期（超 6 个月提示异常）
- [ ] 银行手续费、利息已全部入账（最常见漏项）
- [ ] 银行已代扣的税费、社保、贷款本息已入账
- [ ] 票据贴现、保理、保证金账户是否单独核算
- [ ] 上期未达账项本期是否已清，未清的继续挂并注账龄

## 往来对账

**匹配顺序**：先按金额精确匹配 → 再按单据号匹配 → 再按日期邻近匹配 → 剩下的进差异池。

差异归因矩阵：

| 差异 | 常见原因 | 处置 |
|------|---------|------|
| 我方已记、对方未记 | 货物在途、发票未寄达 | 时间性，挂账并跟踪，下期核销 |
| 对方已记、我方未记 | 我方漏记采购/收款 | 永久性，补记分录（W2） |
| 双方金额不同 | 折让、退货、运费归属、税率差 | 永久性，查明后调整 |
| 单边挂账 | 预付误记应收、收款未核销 | 重分类或补核销 |
| 同一对象双边余额 | 预收与应收未对冲 | 出重分类建议，需业务确认 |
| 长期不动 | 呆账、争议款 | 评估坏账准备，按政策计提 |

账龄口径统一：按**发票日**或**业务发生日**起算，一份底稿内不许混用；90 天、180 天、1 年以上分档。

## 调账分录规则

- 只有**永久性**差异才能出调账；时间性差异挂账，不许调。
- 调账分录必须引用差异编号，摘要写清"调整 XX 差异，原凭证 XXX"。
- 调账后重跑一次滚算，确认闭合。
- 涉及以前年度且金额重大的，走"以前年度损益调整"，不直接进本期费用。

## 未达账项台账

每期必须滚动更新，字段固定：

| 编号 | 首次出现期间 | 对象 | 金额 | 性质 | 已挂账期数 | 本期变动 | 预计清理期 | 责任人 |
|------|-------------|------|------|------|-----------|---------|-----------|--------|

超过 3 期未清的时间性差异，性质存疑，必须升级为待查事项。

## 异常处理

- **调节后仍有差额**：按顺序排查——对账单是否完整 → 企业日记账是否漏记 → 是否有银行已扣未通知项 → 是否存在重复记账。四步走完仍不平，出"未查明差异"报告，附金额与已排除原因。
- **同一科目多账户**（多个银行户）：分户做调节，再汇总；不许合并后调节，会掩盖单户异常。
- **受限资金**：保证金、冻结存款、票据保证金单独设明细，报表列报时提示"使用受限"。
- **对账差异影响现金流分类**：若差异改变了款项性质（如押金变收入），W4 编现金流量表时必须同步调整分类。
