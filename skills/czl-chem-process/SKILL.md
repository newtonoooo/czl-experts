# W6 工艺流程与实验题

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 工艺流程与实验题（czl-chem-process） |
| **任务职责** | 让学生看懂"这一步在干什么、为什么这么干"，把流程题从"看天书"变成"按四段拆"。 |
| **输入参数** | 必填：流程图与题干（原图最佳）。选填：设问、学生作答、教材版本 |
| **执行步骤** | ①先不看设问，通读流程图，用一句话说清"原料 → 产品"→②按四段切分（原料处理 / 核心转化 / 分离提纯 / 产品成型）→③每一步只回答四问：进什么、出什么、除什么、为什么→④圈出循环物质与副产物→⑤回到设问，按题型套答法→⑥把每一步的反应写成方程式→⑦留一道同类流程图做迁移 |
| **判断条件** | 流程图有循环箭头 → 必考"循环物质是什么、为什么循环"；有温度/ pH 标注 → 必考"为什么是这个范围"；有"滤渣/滤液" → 必考成分判断；设问出现"能否用…代替" → 按四维比较（是否引入杂质、成本、腐蚀性、氧化性/还原性）；涉及产率 → 转 W4 计算 |
| **输出格式** | 四段拆解表（段 / 操作 / 目的 / 对应方程式）+ 设问答题框架 + 一句话总览 + 迁移题 |
| **异常处理** | 流程图模糊到看不清箭头 → 要求重拍；学生只问"这步为什么"→ 只答这一步，但补一句"整条线的逻辑是…"；遇到超纲工艺（如离子交换、膜分离）→ 说明"高考只考到目的层面，不考装置细节"；涉及强酸强碱、有毒气体 → 只讲原理，注明实验须在老师指导下进行 |
| **必要依赖** | `references/05-工艺流程常见操作目的.md`（操作目的库）、`references/04-实验与装置要点.md`（装置与安全）、`references/01-元素化合物转化网络.md`（反应是否成立） |
| **与其他工作流的关系** | 上游：W3（会写方程式）、W5（会推断）。下游：产率与纯度计算转 W4；整题错因进 W7。 |

## 一、四段拆解（任何流程题都这么切）

| 段 | 常见操作 | 这一段要回答的问题 |
|---|---|---|
| ① 原料处理 | 粉碎、研磨、焙烧、酸浸、碱浸、水浸 | 把目标元素从矿石里"弄出来"，弄成可溶的 |
| ② 核心转化 | 氧化、还原、沉淀、置换、电解 | 把目标元素变成想要的形式，把杂质变成好除的形式 |
| ③ 分离提纯 | 过滤、调 pH、萃取、反萃取、蒸馏、离子交换 | 目标物与杂质分开 |
| ④ 产品成型 | 蒸发浓缩、冷却结晶、过滤、洗涤、干燥 | 拿到合格产品，且不损失、不分解 |

读图顺序：**先看两头（原料、产品），再看箭头（加了什么、走了什么），最后看循环（回去了什么）。**

## 二、操作目的库（答题直接套）

| 操作 | 目的（标准答法） | 常考追问 |
|---|---|---|
| 粉碎、研磨 | 增大接触面积，加快反应速率，提高浸出率 | 为什么不是越细越好（能耗、粉尘、后续过滤难） |
| 焙烧 | 除去硫、碳等杂质；把难溶物转化为可溶于酸的氧化物 | 为什么要在空气中焙烧（提供氧气，氧化） |
| 酸浸 | 溶解金属氧化物，使目标元素进入溶液 | 为什么用稀硫酸不用盐酸（盐酸挥发、腐蚀，可能引入 Cl⁻） |
| 碱浸 | 除去油污；溶解 Al₂O₃、SiO₂ 等酸性/两性氧化物 | 为什么铝能溶于碱（两性） |
| 加 H₂O₂ 氧化 | 把 Fe²⁺ 氧化为 Fe³⁺，便于后续沉淀；不引入新杂质 | 为什么不用氯水（引入 Cl⁻）、不用 HNO₃（引入 NO₃⁻、产生氮氧化物） |
| 调 pH | 使 Fe³⁺、Al³⁺ 水解沉淀完全，而目标离子不沉淀 | 为什么不用 NaOH 直接调（可能沉淀目标离子、引入 Na⁺） |
| 加 Na₂S / NaF | 沉淀重金属离子 / 沉淀 Ca²⁺、Mg²⁺ | 为什么控制用量（过量引入杂质、增加成本） |
| 萃取 | 用有机溶剂把目标物从水相转移到有机相，实现富集分离 | 为什么选 CCl₄ 或苯（不互溶、目标物溶解度大） |
| 反萃取 | 用 NaOH 等把目标物从有机相转回水相并回收 | 为什么能反萃（生成可溶的盐） |
| 蒸发浓缩、冷却结晶 | 适合溶解度随温度变化大的物质 | 为什么不用蒸发结晶（会析出杂质） |
| 蒸发结晶、趁热过滤 | 适合溶解度受温度影响小的物质 | 为什么要趁热（防止降温析出杂质） |
| 冰水洗涤 | 减少晶体溶解损失 | 为什么不用热水（溶解度大，损失多） |
| 乙醇洗涤 | 洗去表面水分，加快干燥，减少溶解损失 | 为什么不用水（溶解损失、干燥慢） |
| 低温干燥 | 防止产品分解或失去结晶水 | — |

## 三、四个高频设问的答法

| 设问 | 答题框架 | 例 |
|---|---|---|
| "粉碎的目的是什么" | 增大接触面积 + 加快反应速率 + 提高浸出率（三个点，按分值取舍） | 只写"增大接触面积"通常只给一半分 |
| "能否用 X 代替 Y" | 先答"能/不能"，再从四维说理：是否引入新杂质、成本、腐蚀性、氧化性够不够 | 用 H₂O₂ 代替氯水：能，不引入 Cl⁻ |
| "为什么控制 pH 在 a—b" | 下限：杂质离子沉淀完全；上限：目标离子不沉淀（或产品不分解） | 两边都要说，只说一边扣分 |
| "如何提高产率" | 从"反应更完全 + 损失更少 + 循环利用"三条找 | 适当过量、控制温度、洗涤回收、母液循环 |

## 四、读图三个动作

1. **把已知条件抄到图上**：题干的温度、pH、过量少量，全部标到对应箭头旁。
2. **给每个方框编号**：① ② ③…，答题时按编号说话，不写"那个溶液"。
3. **标出循环**：凡是有箭头回到前面的，一定问"循环的是什么、为什么能循环"。

## 五、实验题的接口

流程题的后半段常常接实验题。四件事必须能答：

| 项 | 要点 |
|---|---|
| 气密性检查 | 微热法（看导管口气泡与液柱回升）或液差法；说清"封口—加热/加压—观察—结论" |
| 除杂顺序 | 先除杂后干燥；先除气体杂质再除水；用洗气瓶时"长进短出" |
| 尾气处理 | Cl₂、SO₂ 用 NaOH 溶液吸收；HCl、NH₃ 用水或酸吸收（注意防倒吸）；CO 用点燃法 |
| 防倒吸 | 安全瓶、倒扣漏斗、干燥管；说清"为什么这样能防" |

安全红线：涉及强腐蚀试剂、剧毒气体、易燃易爆物或加热加压的操作，一律注明**必须在老师指导下于实验室进行，不要在家尝试**。

## 七、三条提醒

1. **先讲人话，再讲术语。** 学生听不懂"调 pH 使杂质水解完全"，就先说"把酸度调到某个范围，让铁先沉下去，目标物还留在水里"。
2. **每一步只回答一个问题。** 一步答三个目的，学生记不住。
3. **流程题的分数在"目的"上，不在方程式上。** 方程式写对只拿基础分，说清"为什么"才拿剩下的分。
