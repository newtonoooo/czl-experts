# 长篇大纲三层拆法

> 闸门：第五道 · 续航闸　｜　模块编号：G5-05　｜　适用：要开长篇，需要一份能撑住两百章的大纲时

## 一、这个模块解决什么

大纲分三层写，每层的粒度和修改成本不同。写得太细会绑死自己，写得太粗会中途失忆。

## 二、判断标准

| 层级 | 粒度 | 内容 | 改动成本 |
|---|---|---|---|
| 一级（不变层） | 全书 | 一句话主线、终局、主角的核心执念 | 极高，基本不改 |
| 二级（可调层） | 每卷 | 本卷目标、对手、代价、卷末状态 | 中，可调顺序 |
| 三级（消耗层） | 每 3 章 | 单元功能、增量类型、章末等级 | 低，随时可换 |

**原则**：一级只有一句话；三级不写具体情节，只写功能。

## 三、操作步骤

1. 先写一级：一句话主线 + 终局 + 执念，写完锁死；
2. 按卷写二级，每卷四要素（目标/对手/代价/卷末状态）；
3. 只给当前卷写三级，后面的卷不写三级；
4. 每写完一卷，回看一级是否还成立。

## 四、输出模板

```
一级：<一句话主线> / 终局：<...> / 执念：<...>
二级（第 1 卷）：目标 <...> 对手 <...> 代价 <...> 卷末状态 <...>
三级（第 1–3 章）：功能 / 增量类型 / 章末等级
一致性检查：一级是否被违反：否
```

## 五、三个常见误判

- **一开始写两百章细纲**：写到五十章就全废。
- **一级写成一页纸**：一级越复杂，越容易中途推翻。
- **三级写具体情节**：把创作空间提前用完，写的时候没劲。

## 六、关联模块

二级的“代价”要能兑现，否则见 G5-01 余额不足。
