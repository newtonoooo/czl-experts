# 收益结构拆解

> 闸门：第六道 · 变现闸　｜　模块编号：G6-01　｜　适用：想知道自己的钱到底从哪来、哪块能涨时

## 一、这个模块解决什么

把收入拆成几块独立的分项，分别看趋势。只看总收入会掩盖结构问题：某一块在涨、另一块在塌，合计却看不出变化。

## 二、判断标准

收入通常由以下分项构成（各平台口径不同，以作者后台实际展示项为准）：

| 分项 | 性质 | 可优化点 |
|---|---|---|
| 阅读/分成收益 | 与有效阅读量相关 | 留存、追读、章节长度 |
| 广告分成 | 与曝光和广告展示相关 | 更新稳定性、读者停留 |
| 平台奖励 | 与达成条件相关 | 条件达标而非数量堆叠 |
| 版权/改编 | 与作品质量与谈判相关 | 改编适配度、条款 |

**说明**：本模块不写死任何金额与比例——具体档位、分成比例、结算周期以作者后台当月公告与合同为准。

## 三、操作步骤

1. 从后台导出最近三个月各分项数据；
2. 分项各自看趋势，不看合计；
3. 找出“在涨的”和“在塌的”；
4. 只对塌的那一项做动作，别全线改。

## 四、输出模板

```
分项（近 3 月）：
阅读/分成：<趋势>
广告：<趋势>
奖励：<趋势>
版权：<有无>
结构判断：健康 / 单腿走路 / 某项塌陷
优先动作：<针对哪一项>
```

## 五、三个常见误判

- **只看合计**：合计持平可能是两块互相抵消。
- **把奖励当稳定收入**：奖励有条件和周期，不能当底盘。
- **用短期波动推长期**：至少看三个月。
