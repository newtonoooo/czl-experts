# 断更风险评估

> 闸门：第五道 · 续航闸　｜　模块编号：G5-06　｜　适用：担心自己撑不到完结时

## 一、这个模块解决什么

断更多数不是意志问题，是排产问题。提前识别风险点，比事后靠毅力硬撑有效。

## 二、判断标准

| 风险项 | 高危信号 | 对策 |
|---|---|---|
| 存稿 | 存稿 < 3 章 | 停更一天补存稿，比断更三天好 |
| 剧情储备 | 三级大纲只写到本周 | 一次补足两周 |
| 情绪 | 连续一周写作时长为平时的两倍 | 降低单章目标，先保连续 |
| 外部 | 有出差、考试、项目节点 | 提前两周加更存稿 |

**判据**：任意两项同时高危，视为断更概率 > 50%，立即减量保连续。

## 三、操作步骤

1. 每周日盘一次四项；
2. 存稿低于 3 章立刻补；
3. 三级大纲永远保持 2 周余量；
4. 已知外部节点提前 2 周备稿。

## 四、输出模板

```
存稿：<N> 章
大纲储备：<N> 周
写作时长：平时 <X> / 本周 <Y>
外部节点：<日期>
风险等级：低 / 中 / 高
动作：<补稿 / 减量 / 保持>
```

## 五、三个常见误判

- **靠“我一定能坚持”**：连续性靠排产，不靠决心。
- **断更后不重置习惯窗口**：断一次等于重启读者习惯（见 G3-07）。
- **用加更补断更**：会形成“断更—爆发—再断更”的循环。

## 六、关联模块

断更直接影响 G3-07，需同步评估读者习惯损耗。
