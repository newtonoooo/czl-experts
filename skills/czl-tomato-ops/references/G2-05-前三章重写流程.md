# 前三章重写流程

> 闸门：第二道 · 开局闸　｜　模块编号：G2-05　｜　适用：开篇确定不行，要动手改时

## 一、这个模块解决什么

一套固定顺序的重写流程，避免“改了三遍越改越乱”。核心原则：先改结构，再改句子，最后才润色。

## 二、判断标准

重写必须按顺序走，跳步会导致返工：

1. **结构**：三章各自承担什么功能（建置/加压/兑现）；
2. **信息顺序**：哪些信息必须前置，哪些可以后置；
3. **场景切分**：每章至少两个场景，避免单场景拖满一章；
4. **章末**：三章章末各是什么等级；
5. **句子**：最后才动文字。

## 三、操作步骤

1. 写出三章功能表（每章一句话职责）；
2. 标出所有信息点，重新排列优先级：必须第一屏知道的 / 第一章内知道的 / 可以后置的；
3. 按场景重切，每章≥2 个场景；
4. 定三章章末等级目标；
5. 最后过一遍句子，删掉解释性段落。

## 四、输出模板

```
第 1 章职责：<建置>
第 2 章职责：<加压>
第 3 章职责：<首次兑现>
章末等级：★★★★ / ★★★★ / ★★★★★
字数：<各章字数>
```

## 五、三个常见误判

- **边改结构边润色**：白润一遍，结构一改全废。
- **只改第一章**：三章是一个整体，单改一章会把断裂点推到第二章。
- **改到第五版还在改**：两轮不达标，问题在选题，不在文字，回 G1。
