# 流量异常归因表

> 闸门：第四道 · 爆发闸　｜　模块编号：G4-05　｜　适用：数据忽高忽低，判断不出是内容问题还是流量问题时

## 一、这个模块解决什么

把“流量波动”拆成流量侧与内容侧两组指标，先分清是哪一类，再决定要不要动正文。大多数误判来自把流量问题当成内容问题去改稿。

## 二、判断标准

| 现象 | 归因方向 | 判断依据 |
|---|---|---|
| 曝光涨、首章点击涨、留存跌 | 内容侧 | 承接不行 |
| 曝光跌、首章点击跌、留存稳 | 流量侧 | 平台分发变化，别改稿 |
| 曝光稳、点击跌 | 封面/标题侧 | 展示面问题 |
| 全指标同步下滑 | 外部侧 | 档期、竞品、平台活动 |

**原则**：留存稳的时候不要改正文。

## 三、操作步骤

1. 取三个指标：曝光、首章点击、首章留存；
2. 对照上表定位方向；
3. 只有落在“内容侧”才动正文；
4. 其余三类，记录观察，等一个完整周期再判断。

## 四、输出模板

```
曝光：<涨/跌/稳>
首章点击：<涨/跌/稳>
首章留存：<涨/跌/稳>
归因：内容侧 / 流量侧 / 展示侧 / 外部侧
动作：改稿 / 不改稿，观察 <N> 天
```

## 五、三个常见误判

- **一跌就改稿**：改完数据回升，你会误以为是改稿的功劳。
- **把平台分发当内容质量**：两套系统。
- **只看单日数据**：至少看 7 天移动平均。
