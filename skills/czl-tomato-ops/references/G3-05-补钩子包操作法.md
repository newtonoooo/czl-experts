# 补钩子包操作法

> 闸门：第三道 · 留存闸　｜　模块编号：G3-05　｜　适用：已写好的章节钩子不足，但不想大改正文时

## 一、这个模块解决什么

在不动正文结构的前提下，用最小的手术给每章补一个未闭合问题。这是性价比最高的留存急救手段。

## 二、判断标准

补钩子三原则：

1. **不新增情节**，只重组已发生的信息；
2. **必须能接住**：补的钩子要在下一章开头有着落，不能空许；
3. **一次一章**，不要一次性给 20 章全加钩子，读者会疲劳。

四种低改动补法：
- 把本章最后一句从“结果”改成“代价”；
- 在结尾插入一个别人的反应镜头（视角切换）；
- 把下一章开头的一句话提前挪到本章末尾；
- 让本章出现过的某个人物，说一句没头没尾的话。

## 三、操作步骤

1. 按 G3-01 选出待改章；
2. 逐章选一种补法，只改最后 3 行；
3. 检查下一章开头是否接住；
4. 改完 5 章停一次，读连贯性，再继续。

## 四、输出模板

```
待改章：<N> 章
各章补法：第 X 章 改代价 / 第 Y 章 视角切换 / ...
接住检查：全部接住 / 有 <N> 处断链
处理记录：<改了哪些行>
```

## 五、三个常见误判

- **补的钩子和后文无关**：这是骗读，读者会记住你骗过他。
- **一次补太多**：读者疲劳，钩子边际效用递减。
- **只补不删**：原来的平结尾要删掉或改写，不能叠加。

## 六、关联模块

补完用 G3-01 复检；连续十章补完仍无改善，进 G5-07（完结止损判定）评估切书。
