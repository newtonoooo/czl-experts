# IP 长期价值评估

> 闸门：第六道 · 变现闸　｜　模块编号：G6-07　｜　适用：想判断这本书除了连载收益还有没有长期价值时

## 一、这个模块解决什么

一本书的价值不只在连载期。这个模块评估它能不能在完结之后继续产生价值。

## 二、判断标准

四项长期指标：

| 指标 | 判断方式 |
|---|---|
| 可重读性 | 完结后有没有读者二刷、三刷 |
| 角色资产 | 有没有角色能脱离本书单独被记住 |
| 世界观可扩展 | 能不能在同世界观下写新书而不违和 |
| 圈层沉淀 | 有没有稳定的讨论群体、二创、同人 |

两项以上成立 → 具备长期价值；四项都不成立 → 这是一本一次性消费的书，别在它身上追加投入。

## 三、操作步骤

1. 完结三个月后回看数据：老章阅读量有没有回升；
2. 搜索站外有没有角色名被单独提及；
3. 判断世界观能不能再开一本；
4. 得出结论：追加投入 / 保持 / 转向新书。

## 四、输出模板

```
可重读性：有 / 无
角色资产：<角色名> 是否被单独提及
世界观可扩展：能 / 不能
圈层沉淀：有 / 无
结论：长期价值 高 / 中 / 一次性
```

## 五、三个常见误判

- **连载期热度当长期价值**：热度和留存是两回事，长期价值看的是完结后。
- **靠续写硬撑**：没有世界观支撑的续写是消耗。
- **一次性作品就不该认真写**：一次性作品也可以是好作品，只是别追加投入。

## 六、关联模块

结论为“高”时，回 G5-05 规划同世界观新书的三层大纲。
