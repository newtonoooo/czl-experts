# 主线张力余额盘查

> 闸门：第五道 · 续航闸　｜　模块编号：G5-01　｜　适用：写到中段，感觉主线越写越空时

## 一、这个模块解决什么

把“还有多少内容可写”从感觉变成账。张力余额＝还没兑现的承诺数量 × 每个承诺的剩余难度。余额见底就会出现“靠加新设定续命”的症状。

## 二、判断标准

| 余额状态 | 表现 | 处理 |
|---|---|---|
| 充足 | 手上有 3 条以上未兑现的主线承诺，且难度递增 | 正常推进 |
| 偏薄 | 只剩 1–2 条，且都是“最终决战”级别 | 立刻补中层目标 |
| 见底 | 只能靠加新角色、新地图、新体系维持 | 停，进完结评估 |

**承诺清单要包含**：主角要得到的东西、要打败的人、要弄清的事、要修复的关系。

## 三、操作步骤

1. 列出全书所有已抛出的承诺（未兑现的）；
2. 每条标注：预计兑现章、当前难度、是否还有吸引力；
3. 数一数还剩几条；
4. 少于 3 条 → 补中层目标（不是加新设定，是把已有承诺拆成阶段目标）。

## 四、输出模板

```
未兑现承诺：<N> 条
明细：
- <承诺>：预计第 <X> 章兑现，难度 <高/中/低>
余额判定：充足 / 偏薄 / 见底
补救方案：<拆阶段目标 / 提前引爆 / 完结>
```

## 五、三个常见误判

- **把“还能编”当余额充足**：能编出新设定不等于有张力。
- **只留最终决战**：中间没有可兑现的东西，读者会中途走。
- **用完就补新承诺**：无限加承诺等于无限拖长，要设总量上限。
