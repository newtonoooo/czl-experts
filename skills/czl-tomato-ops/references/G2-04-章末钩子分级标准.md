# 章末钩子分级标准

> 闸门：第二道 · 开局闸　｜　模块编号：G2-04　｜　适用：判断章末够不够“想让人点下一章”时

## 一、这个模块解决什么

把章末钩子分成五级，用于自查与批量体检。等级比数量重要。

## 二、判断标准

| 等级 | 类型 | 读者反应 |
|---|---|---|
| ★★★★★ | 反转/身份揭穿/生死一线 | 必须马上看下一章 |
| ★★★★ | 新威胁出现/关键信息被抛出一半 | 强烈想看 |
| ★★★ | 目标受阻/关系生变 | 想看 |
| ★★ | 情绪落点（感慨、回忆收束） | 可看可不看 |
| ★ | 场景自然结束 | 容易弃 |

**验收线**：开局期（前 10 章）章末不低于 ★★★★；日常连载期不低于 ★★★。

## 三、操作步骤

1. 逐章给章末钩子评级；
2. 统计各等级占比；
3. 找出 ★ 和 ★★ 的章，逐章改写章末最后 3 行；
4. 改写方向：把“结果”改成“代价”，把“解答”改成“半个解答”。

## 四、输出模板

```
总章数：<N>
★★★★★：<n> 章　★★★★：<n>　★★★：<n>　★★：<n>　★：<n>
不达标章号：<列表>
改写重点：<章号 + 改法>
```

## 五、三个常见误判

- **把情绪收束当钩子**：情绪落点是让读者放下书，不是拿起下一章。
- **每章都用 ★★★★★**：读者会疲劳，等级需要起伏。
- **只在最后一句加问句**：伪钩子，读者一眼看穿。
