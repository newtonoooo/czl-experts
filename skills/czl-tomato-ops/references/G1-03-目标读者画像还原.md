# 目标读者画像还原

> 闸门：第一道 · 选题闸　｜　模块编号：G1-03　｜　适用：说不清“谁会看这本书”的时候

## 一、这个模块解决什么

把“读者”从抽象人群还原成具体的阅读场景：他在什么时间、什么设备、什么状态下打开这本书，想看什么。

## 二、判断标准

必须能回答这四问，答不出就是没想清：

| 问题 | 答不出的后果 |
|---|---|
| 他在什么场景下打开（通勤 / 睡前 / 摸鱼） | 决定单章长度与信息密度 |
| 他上一本看的是什么 | 决定你的开头要和谁抢注意力 |
| 他想要的是“爽”还是“熬" | 决定冲突强度与节奏 |
| 他会在第几章决定弃书 | 决定你必须把什么提前 |

## 三、操作步骤

1. 写下三个具体的读者场景（不要写“年轻男性”这种标签）；
2. 对每个场景，标注他打开这本书时的**注意力余额**（高/中/低）；
3. 按注意力最低的那个场景，定单章信息密度与钩子位置；
4. 写出一句“他会在第 N 章决定要不要继续”，作为开局闸的验收线。

## 四、输出模板

```
主场景：<场景>（注意力：高/中/低）
主诉求：爽感 / 情绪 / 悬念 / 知识
上一本对标：<书名>
弃书临界点：第 <N> 章
由此约束：单章 <X> 字，钩子位置 <...>
```

## 五、三个常见误判

- **用人口学标签代替场景**："25–35 岁男性“不是画像，说不出他什么时候打开书。
- **假设读者很有耐心**：绝大多数弃书发生在开头三章内。
- **同时讨好两类读者**：爽文读者和文学读者要的信息密度是相反的，选一边。

## 六、关联模块

画像定完，进 G2 开局闸做压强测试。
