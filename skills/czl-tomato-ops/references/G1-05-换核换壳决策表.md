# 换核换壳决策表

> 闸门：第一道 · 选题闸　｜　模块编号：G1-05　｜　适用：题材不错但差异不足，需要调整方向时

## 一、这个模块解决什么

用“核心冲突”和“题材外壳”两个变量做四象限判断，决定该换哪个、保留哪个。壳是给读者的第一印象，核是支撑全书的矛盾。

## 二、判断标准

| | 壳强（题材热） | 壳弱（题材冷） |
|---|---|---|
| **核强**（矛盾有张力） | 直接写，重点做开局 | **换壳不换核**：把好矛盾装进热门题材 |
| **核弱**（矛盾没张力） | **换核不换壳**：题材留着，重造矛盾 | 两个都换，回选题闸重来 |

判断“核强”的三个问题：
1. 这个矛盾能不能撑过 100 章不重复？
2. 双方有没有各自的道理（不是纯正邪对立）？
3. 主角每前进一步，是不是都要付出代价？

## 三、操作步骤

1. 先判核：用上面三问打分，三问都“是”才算核强；
2. 再判壳：用 G1-04 的趋势结论定壳的强弱；
3. 落到四象限，确定换哪个；
4. 换完回到 G1-02 重做差异度自检。

## 四、输出模板

```
核判定：强 / 弱（三问结果：是/是/是）
壳判定：强 / 弱（趋势：上升/平稳/退潮）
象限：<哪一格>
动作：换核 / 换壳 / 都换 / 直接写
换法：<具体一句话>
```

## 五、三个常见误判

- **频繁换壳不换核**：同一个矛盾换三个题材写，读者会觉得每本都似曾相识。
- **把“设定新奇”当核强**：核强弱看矛盾张力，不看设定复杂度。
- **舍不得已经写好的三万字**：沉没成本不参与决策。
