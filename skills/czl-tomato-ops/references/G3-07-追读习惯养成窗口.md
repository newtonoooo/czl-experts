# 追读习惯养成窗口

> 闸门：第三道 · 留存闸　｜　模块编号：G3-07　｜　适用：想知道读者从哪一章开始“变成习惯”时

## 一、这个模块解决什么

追读不是一次性说服，是习惯养成。习惯有窗口期，窗口内要稳定供给，窗口外再努力也难追回。

## 二、判断标准

习惯养成的三个前提（缺一不可）：

1. **可预期**：更新稳定，读者知道什么时候能看；
2. **可回忆**：读者能说出至少两个角色名和一个未解之谜；
3. **可参与**：有能让读者讨论、猜测、站队的东西。

窗口期判断：
- 第 1–3 章：决定要不要看下去；
- 第 4–10 章：决定要不要收藏；
- 第 11–30 章：决定要不要变成习惯。

## 三、操作步骤

1. 检查更新是否稳定（断更一次，窗口重置）；
2. 随机问三个读者：能说出几个角色名、几个未解之谜；
3. 看评论区有没有自发猜测；
4. 缺哪项补哪项：缺可回忆就强化角色标签，缺可参与就埋可讨论的道德困境。

## 四、输出模板

```
更新稳定性：稳定 / 有断更
角色可回忆度：<N> 个
未解之谜数：<N> 个
讨论活跃度：有 / 无
当前窗口：第 <N> 章段
判断：在窗口内 / 已错过
```

## 五、三个常见误判

- **以为收藏＝习惯**：收藏可能永远不会再打开。
- **靠加更硬拉**：加更解决“看得到”，解决不了“想得起”。
- **断更后当成没发生**：断更一次，习惯窗口重置，要重新养。

## 六、关联模块

窗口错过时，用 G3-05 补钩子 + G3-06 补情绪线做二次拉回。
