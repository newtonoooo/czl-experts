# 弃题清单与止损线

> 闸门：第一道 · 选题闸　｜　模块编号：G1-06　｜　适用：犹豫“这个题到底要不要放弃”的时候

## 一、这个模块解决什么

把“要不要弃”从情绪判断变成清单判断。弃题不是失败，是在成本最低的时点停止投入。

## 二、判断标准

**出现以下任两条，建议弃题**：

1. 五维评分里有两项以上判“弱”；
2. 同类近 90 天呈退潮，且你没有任何差异化手段；
3. 一句话说不清“谁、想要什么、被什么挡住”；
4. 需要向别人解释三分钟才能说明白这个故事好在哪；
5. 你自己写前三章时，写得很顺但没有一处让自己想继续写下去。

**止损线**：开题阶段投入上限 = 前三章 + 一份大纲。超过这个量还没想清，弃。

## 三、操作步骤

1. 逐条对照上面五条，勾选命中项；
2. 命中两条及以上 → 弃；命中一条 → 进 G1-05 调整后再评；
3. 记录弃题原因，存进自己的“题材库”，下次避免重复踩坑；
4. 弃题后不要马上开新题，隔一天再选。

## 四、输出模板

```
命中条款：<编号>
判定：弃 / 调整后再评 / 继续
弃题原因归档：<一句话>
下一步：<新题材方向 or 调整方向>
```

## 五、三个常见误判

- **因为已经想了两周就舍不得**：时间已经花掉，不构成继续的理由。
- **把“没人写过”当优势**：也可能是没人看。
- **弃了立刻开新题**：情绪上头时选的题，通常是下一个要弃的题。

## 六、关联模块

弃题后回 G1-01 重新筛选题；保留题材则进 G1-05。
