# 窗口期内容排产

> 闸门：第四道 · 爆发闸　｜　模块编号：G4-06　｜　适用：窗口期内要连续输出，需要排一份可执行清单时

## 一、这个模块解决什么

窗口期最怕“边写边想”。排产的核心是把窗口期内的剧情单元提前定死，写作时只做填充，不做决策。

## 二、判断标准

窗口期排产三原则：

1. **单元先定**：窗口期内每个三章单元的功能提前写死；
2. **不换线**：窗口期不开新支线，只推进已有线；
3. **留余地**：预留 2 章弹性，用于回应评论区热点。

## 三、操作步骤

1. 按窗口长度（通常 7 天）排出 14 章的功能表；
2. 每章标注：推进哪条线、增量类型、章末等级；
3. 预留最后 2 章不写死，用于接读者反馈；
4. 每天写完核对：是否按表执行，偏离就记原因。

## 四、输出模板

```
窗口期：<起止日期>
章号 → 功能 → 增量类型 → 章末等级
第 X 章：推进主线 / 关系 / ★★★★
...
弹性章：第 <N>、<N+1> 章
执行偏离记录：<...>
```

## 五、三个常见误判

- **窗口期开新支线**：读者还没建立信任，新线会被当成注水。
- **把 14 章全部写死**：没有弹性，热点来了接不住。
- **排产表不做核对**：偏离三天以上，表就失效了。
