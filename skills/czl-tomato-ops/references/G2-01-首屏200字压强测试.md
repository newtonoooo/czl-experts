# 首屏 200 字压强测试

> 闸门：第二道 · 开局闸　｜　模块编号：G2-01　｜　适用：开篇写完了，不确定第一眼能不能抓住人时

## 一、这个模块解决什么

用 200 字为单位检查开篇的“信息压强”。压强不够，读者在点开的三秒内就会退出去。

## 二、判断标准

200 字内必须出现以下至少一项，且读者能感知到：

| 类型 | 表现 | 强度 |
|---|---|---|
| 异常 | 一件不该发生的事发生了 | 强 |
| 冲突 | 有人明确要阻止主角 | 强 |
| 缺口 | 一个必须被解释的东西（悬念物） | 中强 |
| 危机 | 主角马上要失去什么 | 强 |
| 纯氛围描写 | 天气、心情、背景 | 无 |

**判据**：把前 200 字单独摘出来给一个没看过的人读，问他“接下来会怎样"——如果他答”不知道，也没什么想知道“，压强不足。

## 三、操作步骤

1. 摘出前 200 字，单独成段；
2. 标注这段里出现了上表哪一类；
3. 若只有氛围描写，把第 3 章才出现的异常提到第 1 段；
4. 重测：问一个人“接下来想看什么”。

## 四、输出模板

```
首屏类型：异常 / 冲突 / 缺口 / 危机 / 无
是否达标：是 / 否
植入建议：<把哪段提上来>
重测结果：<能说出想追什么 / 说不出>
```

## 五、三个常见误判

- **以为“文笔好”就是压强**：开篇的美文在番茄的阅读场景里是减分项。
- **把设定说明当前 200 字**：读者不关心世界观，关心这个人要出什么事。
- **压强给足但后面不接**：前 200 字抛的钩子必须在第一章内有着落。
