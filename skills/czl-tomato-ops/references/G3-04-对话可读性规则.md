# 对话可读性规则

> 闸门：第三道 · 留存闸　｜　模块编号：G3-04　｜　适用：觉得对话“像念台词”或读者反馈看不下去时

## 一、这个模块解决什么

网文的阅读场景决定了对话必须短、有信息、有潜台词。长篇对话是留存杀手。

## 二、判断标准

| 规则 | 标准 | 违反后果 |
|---|---|---|
| 单句长度 | ≤ 30 字 | 超出即视线疲劳 |
| 单次发言 | ≤ 3 句 | 变成演讲 |
| 信息含量 | 每段对话推进至少一件事 | 纯寒暄＝水章 |
| 潜台词 | 关键对话里，角色说的和想的不一致 | 太直白＝没有张力 |
| 说话人标识 | 连续对话中，每三次发言至少一次动作提示 | 读者分不清谁在说 |

## 三、操作步骤

1. 抽出全章对话，统计单句长度超 30 字的比例；
2. 标出纯寒暄段（不推进任何事）；
3. 给关键对话补潜台词：让角色说 A，意思是 B；
4. 长段发言拆成问答，用动作打断。

## 四、输出模板

```
对话占比：<X>%
超长句：<N> 处
纯寒暄段：<N> 段
潜台词缺失的关键对话：<位置>
改法：<拆句 / 加动作 / 改潜台词>
```

## 五、三个常见误判

- **以为对话短就是文笔差**：短句是场景要求，不是水平问题。
- **所有对话都藏潜台词**：全藏等于全不藏，要害处藏，其余直说。
- **用旁白解释对话**：解释越多，对话越没用。
