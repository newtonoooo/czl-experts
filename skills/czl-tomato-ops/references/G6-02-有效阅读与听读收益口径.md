# 有效阅读与听读收益口径

> 闸门：第六道 · 变现闸　｜　模块编号：G6-02　｜　适用：搞不清自己的阅读量为什么换算不成收益时

## 一、这个模块解决什么

阅读量和收益之间隔着“有效”两个字。这个模块帮你分清哪些是计数口径问题，哪些是内容问题。

## 二、判断标准

三层口径，逐层核对：

| 层级 | 含义 | 常见误解 |
|---|---|---|
| 曝光 | 被展示过 | 以为等于有人看 |
| 点击/进入 | 点开了 | 以为等于读完 |
| 有效阅读 | 达到平台判定标准的阅读行为 | 以为所有阅读都计费 |

**核对方法**：把这三个数放在一起看比例。曝光高但进入低＝展示面问题；进入高但有效低＝内容承接问题。

## 三、操作步骤

1. 取曝光、进入、有效阅读三个数，算两级转化率；
2. 转化率低于同类时，先判断是展示面还是内容；
3. 展示面问题改封面与标题；内容问题回 G2/G3；
4. 核对听读部分是否单独计量，不要与阅读混算。

## 四、输出模板

```
曝光：<N>　进入：<N>（转化 <X>%）　有效阅读：<N>（转化 <Y>%）
听读：<有无单独计量>
问题定位：展示面 / 内容 / 口径误解
动作：<...>
```

## 五、三个常见误判

- **把曝光当读者数**：曝光包含大量无效展示。
- **用累计阅读量算单价**：口径不一致，算出来的数是错的。
- **忽略听读单独计量**：听读与阅读的计费规则常不同。

内容型问题转 G3-08；展示面问题转 G4-05。
