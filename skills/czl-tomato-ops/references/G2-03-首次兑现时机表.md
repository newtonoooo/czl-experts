# 首次兑现时机表

> 闸门：第二道 · 开局闸　｜　模块编号：G2-03　｜　适用：开篇给了承诺，但迟迟不兑现，担心读者等不住时

## 一、这个模块解决什么

开篇每给出一个承诺（金手指、复仇、悬念），都要在规定章节内首次兑现一次小的。承诺积压会直接杀死追读。

## 二、判断标准

| 承诺类型 | 最晚首次兑现 | 兑现形式 |
|---|---|---|
| 金手指/能力 | 第 1 章末或第 2 章 | 用一次，哪怕很小 |
| 复仇/翻身 | 第 3 章 | 拿到第一个筹码 |
| 悬念物 | 第 5 章 | 揭开一角，不是全解 |
| 感情线 | 第 8 章 | 一次正面互动 |

超过最晚时点未兑现 → 该承诺失效，读者会认为你在骗他。

## 三、操作步骤

1. 列出前三章抛出的所有承诺；
2. 逐个标注最晚兑现章；
3. 检查实际兑现位置；
4. 逾期项：要么提前兑现，要么删掉这个承诺。

## 四、输出模板

```
承诺清单：
- <承诺1>：承诺章 <N>，最晚 <M>，实际 <X>，状态 正常/逾期
处理：<提前兑现 / 删除>
```

## 五、三个常见误判

- **把所有兑现都推到高潮**：读者等不到高潮就走了。
- **兑现太大**：第一章就给爽点全开，后面无牌可打。
- **只兑现不新增**：兑现一个，就要补一个新的小悬念。

## 六、关联模块

兑现节奏定完后，用 G2-04 检查章末钩子。
