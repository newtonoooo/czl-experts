# 三章一起伏排布法

> 闸门：第三道 · 留存闸　｜　模块编号：G3-03　｜　适用：担心节奏太平、读者读着累时

## 一、这个模块解决什么

以三章为一个最小节奏单元排布情绪：两章推进、一章转向。避免长篇连载最典型的“匀速疲劳”。

## 二、判断标准

三章单元的结构：

| 位置 | 功能 | 情绪走向 |
|---|---|---|
| 第 1 章 | 推进：目标前进一小步 | 升 |
| 第 2 章 | 加压：代价出现或对手升级 | 升中有压 |
| 第 3 章 | 转向：出现意外变量，原计划作废 | 陡降或陡升 |

**判据**：连续两个三章单元的情绪走向完全一致 → 节奏平板化。

## 三、操作步骤

1. 把最近 30 章切成 10 个三章单元；
2. 给每个单元标注情绪走向（升/降/陡转）；
3. 找出走向完全相同的相邻单元；
4. 在重复的单元里，把第 3 章换成转向章。

## 四、输出模板

```
单元划分：1-3 / 4-6 / ...
各单元走向：<升 / 降 / 陡转>
重复单元：第 <A>-<B> 与第 <C>-<D>
调整方案：<把哪一章改成转向>
```

## 五、三个常见误判

- **每三章都要大高潮**：高潮密度过高会让高潮失效。
- **转向等于换地图**：转向是变量出现，不是场景搬家。
- **三个单元都靠同一个手段转向**：重复三次读者就免疫了。

## 六、关联模块

转向章通常是钩子最强的章，可回 G3-01 交叉验证。
