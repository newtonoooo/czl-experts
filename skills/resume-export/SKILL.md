# 简历交付（resume-export）

## 这个技能解决什么

内容改完不等于能投。导出环节的坑很集中：Word 里好看但系统读出来是乱序、PDF 打印被裁掉一行、文件名还是"简历最终版3"。

这个技能只做一件事：**把定稿的 markdown 变成三种能直接用的文件，并跑完六项交付自查。**

## 什么时候用

- 内容已经定稿，要出文件
- 用户要 Word / PDF / 纯文本
- 用户从招聘网站下载了模板，需要判断能不能用（先跑纯文本测试）
- 投递前最后一遍检查

## 三种输出来自同一份 markdown

工作主格式永远是 markdown：改一处，三种输出同步重生成。**不要在不同格式里分别改内容**，那是版本地狱的起点。

```bash
# Word
python skills/resume-export/scripts/md2docx.py 简历.md -o 王小明-数据分析师-3年-20261026.docx

# A4 打印版（再用浏览器打印成 PDF）
python skills/resume-export/scripts/md2html.py 简历.md -o 简历.html --theme navy

# ATS 纯文本
python skills/resume-export/scripts/md2txt.py 简历.md -o 简历.txt
```

`--theme` 可选 `plain`（默认，无色）/ `ink`（近黑，最稳）/ `navy`（深蓝，偏商务）。

## 执行步骤

1. **确认定稿**：内容还在改就不要导出，浪费。
2. **选形态**：按 `references/export-spec.md` 的用途表选，不要一次要五种格式。
3. **生成文件**：跑上面三条命令，一条对一种格式。
4. **跑六项自查**（见下）。
5. **规范命名**：`姓名-岗位-年限-日期.扩展名`。
6. **交付说明**：告诉用户怎么打印成 PDF（三步），不要说"已生成 PDF"——除非确实生成了。

## 六项交付自查

| # | 检查 | 方法 | 不通过怎么办 |
|---|---|---|---|
| 1 | 纯文本顺序 | 全选复制到记事本 | 顺序乱＝版式有问题，回 `resume-audit` |
| 2 | 实际页数 | 打开 PDF 数页 | 超出就删内容，不要压字号 |
| 3 | 文字非图片 | 搜索一个关键词能否命中 | 改成文本 |
| 4 | 日期格式统一 | 全文搜 `.` `/` `年` | 统一成 `YYYY.MM` |
| 5 | 文件名规范 | 看文件名 | 重命名 |
| 6 | 联系方式可复制 | 选中邮箱看能否复制 | 改成纯文本 |

## 判断条件

- **用户要 PDF**：先出 HTML，再让他用浏览器打印。**只有当环境里确实有可用的转换工具时**才直接生成 PDF；没有就说没有，不要交付一个假的 PDF。
- **用户要图片/表格/头像**：本生成器有意不支持（会破坏 ATS 解析）。要用就手动在 Word 里加，并提醒风险。
- **两页压一页**：先删内容，再考虑调行距（最低 1.4），最后才动字号（最低 10pt）。
- **投北美岗位**：纸张换 Letter，去掉照片、生日、性别，用英文模板。

## 输出格式

交付时给一张清单：

```
已生成：
- 王小明-数据分析师-3年-20261026.docx（4.1 KB）
- 王小明-数据分析师-3年-20261026.html（A4，浏览器 Ctrl+P 可打印为 PDF）
- 王小明-数据分析师-3年-20261026.txt（ATS 自查用）

自查：6/6 通过 / 第 2 项不通过（实际 2 页，建议删第 2 段第 4 条）
```

## 异常处理

- 脚本报错：报原文错误，不要静默重试。常见原因是文件路径带空格未加引号。
- 输出目录不存在：脚本会自动建；如果权限不足，改输出到工作目录。
- 中文乱码：确认源文件是 UTF-8（脚本会依次尝试 UTF-8-SIG / UTF-8 / GB18030）。
- 生成后 Word 打不开：先检查是否是 0 字节或压缩包损坏（`python -c "import zipfile;zipfile.ZipFile('x.docx').testzip()"`）。

## 依赖

- `scripts/md2docx.py`（OOXML 直写，无第三方依赖）
- `scripts/md2html.py`（A4 打印版）
- `scripts/md2txt.py`（ATS 纯文本）
- `references/export-spec.md`（页面规格与限制）
- `templates/resume-cn.md`、`templates/resume-en.md`（骨架）

## 与其他技能的关系

本技能是链条终点。导出后如果改了内容，回 `resume-rewrite` 改 markdown，再重新导出，不要在 docx 里改。
