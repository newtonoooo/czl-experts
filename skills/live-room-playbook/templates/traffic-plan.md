## 二、三道闸门

| 闸门 | 设定值 | 依据 |
|---|---|---|
| 绝对线（保本 ROI） | | 不打折 |
| 单场预算上限 | | = min(可承受亏损/单均亏损, 保本CPA×目标单量) |
| 可承受最大亏损 | | 本场最多亏多少 |

## 三、放量与止损

| 条件 | 动作 | 观察窗口 |
|---|---|---|
| ROI ≥ 保本 × 1.2 | 预算 +30% | 30 分钟 |
| 保本 ×0.9 ≤ ROI < 保本 ×1.2 | 不动 | — |
| ROI < 保本 × 0.9 | 减半或关停 | 立即 |
| 单计划花费 > 保本 CPA ×10 且零成交 | 关停 | 立即 |
| 2 小时不消耗 | 按素材→出价→人群→账户排查 | 一次一变量 |
