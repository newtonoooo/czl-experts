# 七大类目差异手册

同一个动作在不同类目里的效果差很远。下面只写"这个类目跟别人不一样的地方"，通用的部分不重复。

---

## 一、美妆护肤

| 维度 | 特点 |
|---|---|
| 停留 | 天然偏高，观众愿意看讲解和上脸 |
| 关键动作 | 上脸演示 + 前后对比 + 成分表实拍 |
| 排品 | 引流款用卸妆/洁面/小样，主力款用精华/面霜，利润款用套装 |
| 退货率 | 中等，但"效果不符预期"是主因 |
| 高风险 | 功效表述最容易踩线：祛痘、消炎、修复、淡斑一律不能说 |

**讲法要点：** 把"效果"转成"肤感与使用过程"——质地、吸收速度、上脸后的即时感受、和什么产品叠涂。效果交给评论区，不给承诺。
**排品要点：** 小样或旅行装是这类目最好的引流款，成本低、体验门槛低、能带正装复购。

---

## 二、食品生鲜

| 维度 | 特点 |
|---|---|
| 停留 | 偏低，决策快，容易冲动下单 |
| 关键动作 | 吃给你看 + 拆包装的声音 + 产地/配料实拍 |
| 排品 | 引流款用单包尝鲜，主力款用组合装，利润款用礼盒 |
| 退货率 | 生鲜类高（破损、化冻、口感），预包装食品低 |
| 高风险 | 普通食品不得宣称保健功能、不得涉及疾病预防治疗 |

**讲法要点：** 只讲口感、配料、吃法、场景（"加班回来煮一包"）。禁止"增强免疫力""调理肠胃""降三高"。
**履约要点：** 生鲜必须提前说清发货时效与赔付规则，这一条比话术更能降退货。

---

## 三、服饰鞋包

| 维度 | 特点 |
|---|---|
| 停留 | 高，试穿与搭配天然留人 |
| 关键动作 | 上身 + 转身 + 抬手臂看版型 + 真人身高体重对照 |
| 排品 | 引流款用基础款/袜子配饰，主力款用当季主推，利润款用外套/套装 |
| 退货率 | 高，常 30% 以上，主因尺码 |
| 高风险 | 材质成分需与标注一致；"塑形瘦身"类表述慎用 |

**讲法要点：** 每件衣服必须报三个数：主播身高、体重、穿着尺码。这三个数能直接砍掉一部分尺码退货。
**排品要点：** 同类不同色放在相邻位置，用"刚才买了 A 色的可以配 B 色"做连带。

---

## 四、家居日用

| 维度 | 特点 |
|---|---|
| 停留 | 中等，靠"解决一个具体麻烦"留人 |
| 关键动作 | 脏乱→整理后的对比 + 承重/容量实测 |
| 排品 | 引流款用收纳小件，主力款用锅具/床品/清洁组合，利润款用大件 |
| 退货率 | 中低，但大件物流破损是主要问题 |
| 高风险 | 材质（食品接触材料）需合规；"抗菌""除菌"类表述需资质 |

**讲法要点：** 先说场景里的麻烦（"灶台油污擦三次还黏"），再做一次真实演示，不加速、不剪辑。
**排品要点：** 这类目适合做"三件套打包"，客单价能拉起来且退货率低于单件大件。

## 五、3C 数码

| 维度 | 特点 |
|---|---|
| 停留 | 高，参数党会一直看 |
| 关键动作 | 参数对比 + 上手实测（跑分、充电速度、噪音） |
| 排品 | 引流款用配件（线材、支架），主力款用主力机型，利润款用套装/延保 |
| 退货率 | 中低，但比价导致的"买完就退"存在 |
| 高风险 | 不得虚构参数、不得贬低其他品牌；认证类表述需真实 |

**讲法要点：** 参数只讲三个"能感知的"，其余让观众看商品页。讲满 20 个参数，观众一个都记不住。
**排品要点：** 价格敏感度高，主力款必须给一个明确的"比日常便宜多少"，否则观众会去比价。

## 六、母婴

| 维度 | 特点 |
|---|---|
| 停留 | 中等，但信任成本极高 |
| 关键动作 | 材质安全证明实拍 + 使用场景演示 + 售后承诺 |
| 排品 | 引流款用消耗品（湿巾、口水巾），主力款用喂养/出行用品，利润款用套装 |
| 退货率 | 中等 |
| 高风险 | 儿童用品标准、材质认证、不得诱导未成年人、不得做"长高/变聪明"表述 |

**讲法要点：** 这个类目卖的不是卖点，是"敢不敢给自己孩子用"。主播必须能回答"你家孩子用吗"。
**合规要点：** 涉及儿童安全标准的表述必须有真实依据（标准号、检测报告），没有就不提。

---

## 七、本地生活（到店/团购）

| 维度 | 特点 |
|---|---|
| 停留 | 低，决策快 |
| 关键动作 | 门店实拍 + 套餐内容清单 + 使用规则口播 |
| 排品 | 引流款用低价体验券，主力款用双人/家庭套餐，利润款用储值或高客单套餐 |
| 真实指标 | **核销率**，不是 GMV。卖出去不核销等于没卖 |
| 高风险 | 不得虚构原价、不得隐藏使用限制（节假日不可用等） |

**讲法要点：** 使用规则必须完整口播一遍（有效期、可用时段、是否需要预约、能否叠加），少说一条就是后续投诉的来源。
**排品要点：** 套餐设计要留"到店加购"的空间，核销时的二次消费才是这类目的真实利润。

## 通用横向对比

| 类目 | 停留 | 点击 | 支付转化 | 退货风险 | 合规风险 |
|---|---|---|---|---|---|
| 美妆护肤 | 高 | 中 | 中 | 中 | **高** |
| 食品生鲜 | 低 | 高 | 高 | **高** | 中 |
| 服饰鞋包 | 高 | 中 | 低 | **高** | 低 |
| 家居日用 | 中 | 中 | 中 | 中 | 中 |
| 3C 数码 | 高 | 高 | 低 | 低 | 中 |
| 母婴 | 中 | 中 | 中 | 中 | **高** |
| 本地生活 | 低 | 高 | 高 | 低（但核销是坎） | 中 |

用这张表调参考线：服饰类不要拿 3.5% 的支付转化率去要求它，食品类也不要因为停留 40 秒就判死刑。
