# 06 · 交付物模板与装配规则

> 用途：W5、W6。**不要每次都写长篇报告**——先确认交付形态，再选模板。

---

## 一、形态选择

| 用户说法 | 形态 | 模板 |
|---|---|---|
| "简单说说 / 能不能做" | 速答 | 主 Agent 第七节速答模式 |
| "给我一页纸 / 老板要看" | 一页纸 | `templates/one-pager.md` |
| "要上会 / 投委会" | 决策备忘 | `templates/decision-memo.md` |
| "监管来函了，怎么回" | 回函框架 | `templates/regulator-reply.md` |
| "舆情爆了 / 要发声明" | 危机声明 | `templates/crisis-statement.md` |

---

## 二、通用装配规则

1. **首屏必须是结论**，不超过 3 行。
2. **每个判断带依据**：`（依据：… · 来源等级 · 日期）`
3. **数字带口径**：币种 / 含税与否 / 适用主体 / 年度。
4. **行动项必须可验收**：动作 + 责任方 + 时点 + 验收标准。
5. **固定尾栏**：信息截止日 + 三条待复核项 + 合规声明。
6. **篇幅纪律**：一页纸 ≤ 1 页 A4；决策备忘 ≤ 3 页；回函 ≤ 2 页；危机声明 ≤ 300 字（中文）。

---

## 三、一页纸结构

```
标题：{主体} — {议题} 公共事务判断
1 结论（3 行内）
2 三个关键判断（各 1 行 + 依据）
3 酋长国分列（表格，2–7 列）
4 下一步（3 条，带时点）
5 风险与红线（2 条）
尾：信息截止日 / 待复核 / 声明
```

## 四、决策备忘结构

```
1 议题与决策请求（要批什么）
2 背景（不超过 5 行）
3 方案对比（A/B/不做，各含成本、时间、风险分）
4 推荐方案与理由
5 风险与缓释（含停止条件、升级路径）
6 资源与时间表
7 待决策事项清单
附件：来源清单
```

## 五、回函框架结构

```
1 致函对象与事由（引用来函编号与日期）
2 事实确认（只写可核实的事实）
3 合规说明（对应规则条款方向，不臆造条文号）
4 整改或承诺（可验收）
5 后续联系人（职务，不写私人联系方式）
6 附件清单
```

**纪律**：不辩解、不推测、不承诺无法兑现的时限；不引用未经核实的外部说法。

## 六、危机声明结构（三段式）

```
第一段 关注与态度（对受影响方表达关注，表明重视）
第二段 已知事实与已采取行动（只写已核实内容 + 具体动作）
第三段 承诺与联系方式（整改承诺 + 官方渠道）
```

**禁用**：猜测原因、推测伤亡、指责第三方、使用"个别现象""恶意抹黑"等对抗性表述。

---

## 七、装配后自检（打印在交付物末尾或内部）

- [ ] 结论是否在第一屏
- [ ] 是否做了酋长国分列（涉及选址/监管时）
- [ ] 每条判断是否有来源等级
- [ ] 数字是否带口径
- [ ] 是否过了红线体检（涉及对外内容时）
- [ ] 是否写了信息截止日与待复核项
- [ ] 是否附合规声明
