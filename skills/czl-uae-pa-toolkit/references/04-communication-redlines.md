# 04 · 对外沟通红线清单与改写对照

> 用途：W4 红线体检。原则：**先合规，再效果**。任一项"禁止"未清除，不得发布。
> 本清单为作业检查表，不替代媒体监管机构的正式审批。

---

## 一、红线清单（逐项打勾）

| # | 议题 | 判断要点 | 结论 |
|---|---|---|---|
| 1 | 宗教 | 是否出现宗教符号、经文、宗教人物形象？是否调侃、戏仿、比较宗教？是否在宗教节日做促销？ | 通过 / 需修改 / 禁止 |
| 2 | 政治与区域议题 | 是否涉及他国内政、地区冲突、阵营表态？是否出现政治口号、旗帜、地图争议？ | 同上 |
| 3 | 王室与国家象征 | 是否使用王室成员姓名、肖像、称号？是否使用国旗、国徽、政府标识？ | 同上（使用需书面许可） |
| 4 | 国家与主权表述 | 是否出现不完整或错误的地图？台湾/香港/澳门是否被表述为独立国家？ | 同上（必须表述为中国台湾/中国香港/中国澳门） |
| 5 | 性别与家庭 | 是否物化、刻板化性别？家庭场景是否符合本地主流价值观？ | 同上 |
| 6 | 劳工与外籍工人 | 是否出现工地/宿舍/劳工形象？是否暗示剥削、欠薪、扣押护照？ | 同上 |
| 7 | 酒类、猪肉、烟草 | 是否面向穆斯林受众推广？投放渠道是否合规？ | 同上（多数渠道受限） |
| 8 | 斋月与宗教节日 | 白天时段是否展示饮食、饮水、娱乐消费场景？ | 同上 |
| 9 | 绝对化与比较宣传 | 是否使用"最好/第一/唯一/100%"等无依据表述？是否贬损竞品？ | 同上 |
| 10 | 数据与隐私 | 是否使用可识别的个人信息、客户案例未经授权？是否有同意依据？ | 同上 |
| 11 | 代言与网红合作 | 是否披露商业合作？代言人是否具备资质（如医疗、金融类需持牌）？ | 同上 |
| 12 | 抽奖与促销 | 规则是否公开、是否有许可要求、是否含博彩性质？ | 同上 |
| 13 | 图像与音乐版权 | 素材是否有商用授权？字体是否可商用？ | 同上 |
| 14 | 危机期一致性 | 是否与正在进行的危机声明口径冲突？ | 同上 |

## 二、常见违规表达 → 合规改写

| 原表达 | 问题 | 改写方向 |
|---|---|---|
| "阿联酋最好的储能方案" | 绝对化、无依据 | "面向海湾高温工况设计的储能方案，附第三方测试数据" |
| "保证 30 天拿到牌照" | 承诺审批结果 | "在资料齐备的前提下，通常需要 X–Y 周，具体以受理机构为准" |
| "我们的产品符合所有海湾标准" | 笼统、不可核 | "已取得 XX 认证（证书号 …），适用型号 …" |
| 地图缺南海诸岛/台湾着色错误 | 主权表述错误 | 使用标准地图，标注中国台湾/中国香港/中国澳门 |
| 用国旗做产品包装主视觉 | 国家象征使用受限 | 改用企业自有视觉符号或中性地域元素 |
| "开斋节狂欢大促·全场酒水 5 折" | 宗教节日 + 酒类 | 改为非宗教主题的季节性促销，去掉酒类 |
| 工地劳工群像配"低成本劳动力" | 劳工敏感 | 改为"本地就业与技能培训计划"叙事 |
| 引用客户 Logo 做案例 | 未授权商用 | 取得书面授权，或匿名化描述 |

## 三、渠道适配规则

| 渠道 | 额外要求 |
|---|---|
| 官方新闻稿 | 需企业正式署名；涉及政府机构联合发布须书面许可；建议中英双语 |
| 社媒（Instagram / X / LinkedIn / TikTok） | 内容需过红线表；网红合作需披露；评论区需有响应机制 |
| 户外与印刷广告 | 需市政审批；阿语优先或双语；图片需符合公共场合规范 |
| 展会展台 | 视觉素材、视频、赠品均属宣传内容；酒类赠品受限 |
| 内部沟通 | 员工口径必须与对外口径一致，避免内部文件外流 |

---

## 四、危机期专属红线

1. 不猜测原因、不推测伤亡、不评价责任方。
2. 不与受影响方公开争论。
3. 不在事实未清时使用"个别现象""被恶意抹黑"等定性与对抗性表述。
4. 不使用未经核实的第三方截图作为证据对外发布。
5. 不删除已发布内容来"消痕"——删除会被截图对比，通常放大问题；如需更正，用更正声明。

## 六、边界说明

本清单基于公开的合规常识与本地商业惯例整理，用于企业内部预审。正式发布前，涉及政府机构、宗教内容、医疗与金融宣传的素材，应提交本地持牌公关/律师或相关监管机构审核。
