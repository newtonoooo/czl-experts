# 双层评分模型与反证规则

## 一、为什么要两层

"适合"和"现在值得投入"是两件事。把两者合成一个分数，会出现"最像客户的不是最该打的"这种结果被掩盖的问题。因此：

- **Fit（适配度）**：这个账户的需求与我们产品是否匹配。
- **Priority（开发优先级）**：以现有资源和当前时点，能不能在 12 个月内推进。

**排序只看 Priority。** Fit 用来解释"为什么这家值得长期跟踪"，Priority 用来决定"这个季度先打谁"。

## 二、Fit 五维

| 维度 | 判断问题 | 高分特征 | 低分特征 |
|------|---------|---------|---------|
| 需求匹配 `need_match` | 我们的能力是否直接对应它的业务痛点 | 痛点在其核心流程上 | 只在外围场景沾边 |
| 场景体量 `scene_scale` | 单点可覆盖的规模是否够 | 多站点/多产线/连续流程 | 单点、一次性 |
| 技术邻接 `tech_adjacency` | 现有系统与我们的方案是否容易衔接 | 已有同类自动化或数字化基础 | 全人工、无系统 |
| 预算能力 `budget_capacity` | 是否有与该业务直接相关的资本开支能力 | 有该业务板块的扩建/技改记录 | 只有集团总收入可查，业务板块无投入迹象 |
| 增长性 `growth` | 业务量是否在增长 | 有扩产、扩仓、增员、新市场记录 | 收缩、关店、裁员 |

权重（可用 `score.py --weights` 覆盖）：需求匹配 0.30、场景体量 0.20、预算能力 0.20、技术邻接 0.15、增长性 0.15。

## 三、Priority 六维

| 维度 | 判断问题 | 高分特征 | 低分特征 |
|------|---------|---------|---------|
| 信号等级 `signal_level` | 是否有明确采购或投资信号 | 一级/二级信号 | 只有行业层面背景 |
| 可进入性 `accessibility` | 有没有公开入口与可触达部门 | 有供应商注册页/公开招标/协会活动 | 完全封闭、只走既有伙伴 |
| 决策链 `decision_chain` | 决策链长度 | 单一主体决策 | 多主体、需集团审批 |
| 周期 `cycle` | 从接触到下单的预计时长 | 6 个月内 | 18 个月以上 |
| 供应商锁定 `vendor_lock` | 现有供应商替换难度 | 多供应商、按项目采购 | 长期独家、封闭生态 |
| 12 个月转化 `convert_12m` | 综合判断一年内能否成单 | 可能性较高 | 基本不可能 |

权重：信号 0.25、可进入性 0.25、供应商锁定 0.15、12 个月转化 0.15、决策链 0.10、周期 0.10。

注意：`决策链` 与 `供应商锁定` 是**反向维度**——链越短、锁定越弱，得分越高。

## 四、档位与换算

不用 0–100 分。每维取三档：`high` / `mid` / `low`（对应 1.0 / 0.6 / 0.3），加权求和后映射：

| 加权值 | 档位 |
|--------|------|
| ≥ 0.75 | 高 |
| 0.50 – 0.74 | 中 |
| < 0.50 | 低 |

**为什么不给小数**：输入本身是判断而非测量，输出小数会制造不存在的精度。`score.py` 默认只输出档位与各维强弱，`--explain` 才输出中间加权值，且标注"仅供内部比较，不作为对外结论"。

## 五、缺失维度处理

1. 某维无证据支撑 → 记为 `missing`，该维权重按比例分摊到其余维度。
2. 单层缺失 ≥3 维 → 该层档位输出"信息不足"，不参与排序。
3. 缺失项必须写入"待核实清单"，并对应一个补证动作。

## 六、置信度

```
confidence = 0.5 * 有证据维度占比 + 0.3 * min(独立证据条数/4, 1) + 0.2 * (反证是否已回应 ? 1 : 0)
```

| 置信度 | 含义 | 允许的输出 |
|--------|------|-----------|
| ≥0.75 | 高 | 可进前三 |
| 0.5–0.74 | 中 | 可排序，需标注"证据偏薄" |
| <0.5 | 低 | 只能作为"资格待定账户"，不得进前三 |

## 七、反证规则

每家账户必须写三条反证，格式：

```
反证1：<为什么它可能不需要我们>
回应：<用什么事实或动作排除/确认>
```

合格反证的类型（至少覆盖两类）：

- **需求反证**：它的痛点可能已被现有方案解决。
- **能力反证**：它没有与该业务匹配的预算或组织。
- **进入反证**：采购封闭、已有长期伙伴、本地化门槛过高。
- **时点反证**：项目已结束、预算已花完、决策人刚变动。

不合格反证："竞争激烈""市场有风险"——这类不是针对该账户的判断。

**门禁**：反证少于 3 条或未回应 → 该账户不得进前三，`score.py` 会返回 `gate: BLOCKED`。

## 八、A/B/C/D 分级

| 级别 | 条件 | 动作 |
|------|------|------|
| A | Priority 高 + 可进入性 高/中 + 门禁通过 | 立即开发，30 天内首触 |
| B | Priority 高 + 可进入性 低，或 Priority 中 + 可进入性 高 | 需伙伴或行业关系切入 |
| C | Priority 中 + 可进入性 中/低 | 长期培养，季度回访 |
| D | Priority 低 | 降低优先级或放弃 |

规则：企业规模大不构成 A 级的理由；A 级必须同时满足"信号明确"与"能进去"。

## 九、排序后的解释义务

若 Fit 最高者不是 Priority 第一，必须补一段：

> Fit 最高的是 X（原因：……），但其 Priority 为 Y 档，原因是 <可进入性/信号等级/周期>。因此本次排序第一为 Z。

没有这段解释，视为评分与排名不一致，输出不合格。
