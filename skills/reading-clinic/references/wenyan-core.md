# 文言解码：推断方法、高危词、虚词、文化常识

> 用途：配合 W4 的"每日 20 分钟"。不背整本词典，先在句子里推断。
> 方法为通用文言教学经验整理（E）；篇目与作者依据统编教材（K）；例句为常见课文用例，**具体字句以学生课本为准**。

## 一、词义推断四法（按顺序用）

### 1. 字形推断

看到偏旁先想义类：

| 偏旁 | 常指 | 例 |
|---|---|---|
| 贝 | 财物、买卖 | 货、赂、质 |
| 刂 | 切割、刑罚 | 刑、刎 |
| 纟 | 丝线、纺织 | 绳、绝 |
| 阝（右） | 城邑、地名 | 鄙、郭 |
| 攵 | 击打、行为 | 攻、败 |

### 2. 语境推断

把词放回前后三句，看它和谁搭配：

> "沛公军霸上"——"军"后接地名，前面是人名，只能是动词"驻军"。

### 3. 课文迁移

用学过的句子反推：

> "除臣洗马"的"除"，联系"除旧布新"的"除去"讲不通，联系官职语境，应为"授职"。

### 4. 结构对称

文言常对举，位置相同的词义相近或相反：

> "奉之弥繁，侵之愈急"——"弥"与"愈"对举，都是"越、更加"。

四法用完仍不通，才查注释。查完只记一条：这句里它是哪个义项。

## 三、八个高频虚词（只记功能，不背条目）

| 虚词 | 常见功能 | 判断办法 |
|---|---|---|
| 之 | ①助词"的" ②取消句子独立性 ③代词 ④往、到 | 后面跟名词多为①；在主谓之间多为②；前面有动词多为③ |
| 其 | ①他的 ②大概 ③难道 ④那 | 句首表语气多为②③；后接名词多为①④ |
| 而 | ①并列 ②转折 ③修饰 ④承接 | 前后意思相反为②；前状后动为③ |
| 以 | ①因为 ②用、拿 ③来 ④认为 | 后接名词多为②；后接完整句子多为① |
| 于 | ①在 ②比 ③被 ④向 | 后接比较对象多为②；后接施动者多为③ |
| 乃 | ①才 ②竟然 ③于是 | 出乎意料为②；顺承为③ |
| 则 | ①就 ②却 ③那么 | 前后相反为② |
| 焉 | ①于此 ②哪里 ③语气词 | 句末多为③；句首疑问多为② |

## 五、每天怎么练（20 分钟）

| 段 | 时长 | 动作 |
|---|---|---|
| 猜 | 8 分钟 | 拿一段无注释文言，圈动词，说出谁在做什么 |
| 对 | 7 分钟 | 看注释，标出推错的地方，归到"词义/句法/语境/文化/题型"其中一类 |
| 记 | 5 分钟 | 只记一条：一个词的一个义项，或一个句式 |

**七日检查点**：同一类错因是否减少。不减少，降低材料难度，不加量。
