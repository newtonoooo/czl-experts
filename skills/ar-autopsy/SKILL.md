# 六维诊断

诊断的目的不是把一只股票说完，是回答一句：**这只票值不值得我继续花时间。** 答案可以是"不值得"，而且这个答案常常更值钱。

## 职责

**做**：六维打分、找出最要命的那一条、给可检验结论与证伪条件。
**不做**：不给定目标价（交 `ar-value`）、不写成稿（交 `ar-thesis`）、不判断大盘（交 `ar-tape`）。

## 输入参数

| 参数 | 必填 | 说明 | 缺失处理 |
|---|---|---|---|
| 标的代码 | 是 | `600519.SH` | 交 `ar-intake` |
| 证据台账 | 是 | `ar-evidence` 产出 | 无台账先补 |
| 关注角度 | 否 | 短线交易 / 中长期持有 / 只排雷 | 默认中长期 |

## 六个维度

顺序不可打乱。这是**从"这生意行不行"到"现在这个价行不行"**的顺序，颠倒过来就会变成先有结论后找理由。

### 维度一 · 生意质量（权重 25%）

回答：它靠什么赚钱，这个钱能赚多久。

- 收入结构：主营构成、前三大产品/客户占比、区域集中度
- 盈利模式：毛利率水平与稳定性、是价驱动还是量驱动、议价能力在哪一端
- 护城河：牌照/成本/网络效应/转换成本/品牌，**必须指出是哪一种，说不出来就是没有**
- 周期位置：处在产能周期/库存周期/政策周期的哪一段（用行业数据，不用感觉）

判据：毛利率连续 3 年下滑且无解释 → 扣分；前五大客户占比 >50% → 扣分并标注客户依赖风险。

### 维度二 · 财务质量（权重 25%）

回答：报表上的利润，是真的吗，能不能变成现金。

- 增长：营收/扣非净利同比与两年复合，**看扣非不看归母**
- 盈利：ROE 拆三因素（净利率×周转×杠杆），判断高 ROE 是靠什么撑的
- 现金流：经营现金流净额/净利润（连续三年 <0.8 需解释）
- 资产质量：应收账款增速 vs 营收增速、存货周转、商誉/净资产、在建工程转固
- 会计风险：非经常性损益占比、政府补助依赖、关联交易、审计意见类型

判据：应收账款增速 > 营收增速 20 个百分点以上 → 必查；商誉/净资产 >30% → 标注减值风险；经营现金流连续两年为负 → 一票降级。

### 维度三 · 定价位置（权重 15%）

回答：现在的价格，在它自己的历史上、在同业里，处于什么位置。

- 自身分位：PE-TTM / PB 处于近 5 年百分位（要给具体数值，不给"较低"）
- 同业比较：申万二级行业内的中位数与四分位，它在哪一档
- 隐含前提：当前估值需要多高的增长才能撑住（具体算法交 `ar-value`）
- 估值与质量匹配：高 PE 是否伴随高 ROE/高增速，还是靠故事

判据：PE 分位 >80% 且 ROE 分位 <50% → 明确标注"贵得没有理由"。周期股在盈利高点用 PE 判断会反向误导，须改用 PB 或 EV/EBITDA。

### 维度四 · 交易结构（权重 15%）

回答：想买能不能买到，想卖能不能卖掉，现在的位置是不是有人在派发。

- 趋势：MA20/60/120 排列、价格相对年线位置
- 量能：近 20 日量比、放量位置（突破放量 vs 高位放量滞涨）
- 筹码：股东户数变化、前十大股东机构占比变化、质押比例
- 可交易性：日均成交额、涨跌停历史、停牌记录、流动性折价

判据：日均成交额 <5000 万 → 标注流动性风险；连续一字板 → 明确写"价格存在但不可成交"；股东户数骤增 + 股价滞涨 → 筹码分散信号。

### 维度五 · 资金与预期（权重 10%）

回答：钱在往哪走，预期在往哪改。

- 资金：龙虎榜席位性质（机构专用 vs 营业部）、融资余额趋势、大宗折价率
- 预期：卖方一致预期的方向（上调/下调/分歧度）、覆盖机构数量变化
- 预期差：市场共识与我判断的差异点在哪，这个差异凭什么存在

**北向资金 2024 年 8 月起无实时净流入数据，不得引用"今日北向净买入"。** 只能用季度持股或十大股东中的陆股通。

判据：一致预期近 3 个月连续下调 → 标注"预期在恶化"。覆盖机构 <3 家 → 标注"关注度低，定价效率差"。

### 维度六 · 事件与风险（权重 10%）

回答：未来 6 个月，什么事会让这只票突然变样。

- 催化：财报窗口、产能投放、审批节点、政策落地
- 风险：解禁时间与比例、减持计划、股权质押、诉讼、监管问询
- 退市线：是否触及财务类/交易类退市指标（ST 股必查）

判据：未来 3 个月解禁比例 >总股本 10% → 必须写进风险段；质押比例 >50% → 标注平仓风险。

## 综合判断

按权重加权得 0-100 分，再**用一句话推翻它**：

- 80+：值得深入研究，进入 `ar-value`
- 65-79：有条件关注，写清成立条件
- 45-64：只跟踪不投入，写明观察触发点
- 30-44：有明显硬伤，指出是哪一条
- <30：排除，一句话说清为什么不必再看

评分不是重点，**"最要命的那一条"才是重点**。六维里找出一票否决项（现金流造假嫌疑、退市风险、治理问题、流动性枯竭），有则直接给结论，不再加权。

## 异常处理

| 情形 | 处理 |
|---|---|
| 某维数据缺失 | 该维标 `[MISSING]`，权重按剩余维度归一，报告注明"结论稳定性下降" |
| 财务数据超过 1 年 | 只做定性判断，不给评分 |
| ST / 退市整理期 | 跳过估值维，直接出风险清单 |
| 周期股 | 定价维改用 PB/EV-EBITDA，并提示"盈利高点 PE 失真" |
| 借壳/重组未完成 | 明确写"主体已变，历史财务不可比" |
| 用户只要短线 | 权重调整为交易结构 40%、资金 25%，但仍须保留财务排雷 |
