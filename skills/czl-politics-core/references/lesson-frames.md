# 课型框架与议题式教学设计

> 用途：任何一节课的设计底稿。先定课型，再套骨架，最后填内容。
> 铁律：**课型不同，结构不同。** 用新授课的骨架去上复习课，一定上成"再讲一遍"。

## 一、五种课型的骨架

### 1. 新授课（议题式，1 课时 40 分钟）

| 环节 | 时长 | 教师做什么 | 学生做什么 |
|---|---|---|---|
| 情境入场 | 5′ | 给一份带冲突的真实材料，不解释 | 读，说出"这里矛盾在哪" |
| 议题立起 | 3′ | 把矛盾提炼成一个可判断的议题 | 确认议题、明确判断任务 |
| 知识支架 | 10′ | 精讲本课核心概念（不超过 3 个） | 记结构，做一次快速复述 |
| 探究活动 | 14′ | 下发任务单，巡视，只点拨不代答 | 分组用概念分析材料，形成判断和理由 |
| 展示与交锋 | 6′ | 组织两组对冲，追问"你的依据是哪个概念" | 互评，修正自己的表述 |
| 收口与迁移 | 2′ | 回到议题，给一句结论性表述，布置迁移任务 | 用一句话写出自己的判断 |

**判断标准**：这节课结束时，学生能否用本课概念回答那个议题，而不是背出定义。

### 2. 复习课（1 课时）

结构不是"再讲一遍"，而是**重建结构 + 补漏洞**：

1. **诊断开场（5′）**：三道小题，暴露本专题最典型的三个错误。
2. **结构重建（12′）**：不给现成框架，让学生先自己画，再对比修正。教师只补"学生画不出来的那条线"。
3. **错因归类（8′）**：把开场三题的错误归到"知识缺口/概念混淆/材料没读懂/设问误读/表达不规范"五类。
4. **变式训练（12′）**：同一考点换情境、换设问、换册次。
5. **收口（3′）**：给一张"这个专题最容易错的三个地方"的清单。

**判断标准**：学生能否说出"我这个专题错在哪一类"，而不只是"我这个地方没背熟"。

### 3. 讲评课（1 课时）

不讲全卷，讲三类题：**得分率最低的、错得最集中的、最能迁移的。**

1. **数据开场（3′）**：公布三道典型题的得分率，不公布排名。
2. **错解还原（10′）**：把学生的真实错答（匿名）投出来，问"他为什么会这么想"。
3. **归因（7′）**：错因归到五类，落到"下一步做什么"。
4. **变式补偿（15′）**：同一错因，换情境再练一道。
5. **收口（5′）**：每人写一句"我下次遇到这类题，先做什么"。

**判断标准**：讲评课的效果不在"讲清楚了"，在"下次不错"。所以必须有变式训练，否则等于没上。

### 4. 习题课（1 课时）

用于**方法训练**，不是用来赶进度的。

1. 给一类题（如"评析类"），先让学生做，暴露原始思路（8′）。
2. 拆解这类题的通用动作：读设问→定题型→找主体→调知识→搭结构（10′）。
3. 学生按动作重做一遍（15′）。
4. 对比两次作答，说出差异（5′）。
5. 布置一道同型题（2′）。

### 5. 公开课（1 课时，但设计量约为常规课 3 倍）

公开课的差别不在环节，在**三个"看得见"**：

- **看得见的设计**：议题必须有张力，情境必须真实，问题链必须能推着学生往前走。
- **看得见的学生**：至少有两个环节是学生自己 produce（说、写、辩），不是回答教师预设的填空。
- **看得见的生成**：留一个"教师也不知道答案"的开放点，现场处理。

风险提示：公开课最容易翻车的地方是**容量超载**。删掉一个环节，比加一个环节更难，也更重要。

## 二、议题式教学的四要素

### 要素一：议题（Issue）

**合格的议题 = 一个真实的价值冲突 + 一个需要判断的问句 + 与本课核心概念强相关。**

| 不合格 | 为什么 | 改成 |
|---|---|---|
| "谈创新" | 名词，没有判断任务 | "地方财政吃紧时，还要不要给创新企业补贴？" |
| "走进人民代表大会" | 话题，不是议题 | "人大代表该不该公开自己的投票？" |
| "认识市场经济" | 无法判断 | "景区淡季涨价，是市场调节还是趁火打劫？" |

判断口诀：**把议题念给一个高中生听，他会不会想说"我觉得……"？** 不会，就是没立起来。

议题的三个来源：政策争议点（某地新规）、生活冲突点（校园/家庭/消费）、认知分歧点（学生中间已有两种看法）。

### 要素二：情境（Scenario）

真实、结构化、有细节、有冲突、可核查。

- **必须有出处**：媒体、时间、可查证的关键事实。编的情境经不起学生一句"真的假的"。
- **必须有细节**：数字、时间、当事人身份。没有细节的情境只能得出空泛结论。
- **必须留白**：不要把结论写进材料。材料里出现"这充分说明……"，这个情境就废了。
- **控制长度**：课堂材料不超过 250 字；考试材料按题型定，但一段材料只承载一个冲突。

### 要素三：活动（Activity）

活动不是"讨论一下"，而是**有产出物的任务**。

合格的活动任务单包含四行：
1. 你们的判断是什么（一句话）
2. 依据是本课哪个概念（写出概念名）
3. 材料里的哪句话支持这个判断（引用原文）
4. 可能有人会反对，反对的理由是什么，你们怎么回应

第 4 行是分水岭。没有第 4 行，活动就是"找证据支持老师"，不是探究。

### 要素四：评价（Assessment）

评价要能看见"思维到了哪一层"，所以用**水平描述**，不用对错判断：

| 水平 | 表现 |
|---|---|
| 水平 1 | 能复述概念，但不会用 |
| 水平 2 | 能用概念解释材料，理由单一 |
| 水平 3 | 能用概念分析冲突，给出依据，识别对立观点 |
| 水平 4 | 能权衡不同观点，指出本方判断的适用条件和局限 |

课堂上至少要能区分水平 2 和水平 3，否则评价是假的。

## 三、问题链设计

### 三层结构

| 层 | 问什么 | 动词 | 作用 |
|---|---|---|---|
| 事实层 | 材料里发生了什么 | 指出、概括、描述 | 保证全班同一起点 |
| 分析层 | 为什么会这样、依据是什么 | 分析、说明、比较、推断 | 逼出概念使用 |
| 判断层 | 应该怎么做、你站哪边 | 评析、建议、论证、反驳 | 产出素养表现 |

**三层比例**：事实 2 : 分析 4 : 判断 3。全是事实层，课上得平；全是判断层，学生接不住。

### 设问动词表（写错动词，答案就跑偏）

| 动词 | 要什么 | 不要什么 |
|---|---|---|
| 说明 | 原因 + 依据 | 不要只列现象 |
| 分析 | 拆开讲，分层说 | 不要一句话概括 |
| 评析 | 先判断对错/合理与否，再讲理由，再讲条件 | 不要只讲理由不表态 |
| 阐释 | 是什么 + 为什么 + 意味着什么 | 不要只答"是什么" |
| 建议 | 具体动作 + 主体 + 落点 | 不要写"加强""重视"这类空话 |
| 论证 | 观点 + 论据 + 推理 | 不要只堆例子 |

### 五种伪问题（必须删）

1. **答案在材料里**："材料说明了什么？"——材料已经写了。
2. **答案在教材标题里**："这体现了什么制度？"——标题就是答案。
3. **只能答"是"**："这样做对不对？"——没有思维含量。
4. **太大无法回答**："如何看待全球化？"——一节课答不完。
5. **教师心里只有一个标准答案**："你同意吗？"（其实不同意也得同意）。

## 四、时间分配的三条经验

1. **讲授连续不超过 15 分钟**。超过就必须插一个学生动作（写一句话、和同桌对答案、举手表决）。
2. **每个环节留 30 秒空白**。学生需要时间把想法组织成句子，抢答的都是那几个。
3. **最后 2 分钟必须收口**。不收口的课，学生带走的是"今天聊得挺热闹"。

## 五、六种常见失败模式

| 失败模式 | 表现 | 修正 |
|---|---|---|
| 情境装饰化 | 材料只在开头出现一次，后面全是讲知识 | 让材料在探究环节再出现一次，且必须被引用 |
| 议题空心化 | 议题很大，最后落到"我们要努力" | 议题必须能在 40 分钟内做出一个具体判断 |
| 活动形式化 | 四人小组讨论 2 分钟，没人写字 | 讨论必须有书面产出，哪怕只有四行 |
| 评价缺位 | 学生说完，教师只说"很好" | 用水平描述回应："你给了依据，但没回应反方" |
| 容量超载 | 一节课塞三个议题 | 一个议题，最多两个冲突 |
| 结论前置 | 教师先给结论，学生找证据 | 结论放在收口环节，前面不给 |

## 六、学情适配

| 学情 | 调整 |
|---|---|
| 基础薄弱班 | 情境减到 150 字以内；事实层问题占到一半；活动改成"两人一组口头说 + 全班记录" |
| 中等班 | 按标准骨架走；分析层多给一个支架（概念清单贴在黑板上） |
| 重点班/精英班 | 情境可加一层"反方材料"；判断层要求写出"我的判断在什么条件下不成立" |
| 复习班 | 新授课骨架不适用，走复习课骨架；每节课必须有一道跨册综合题 |

> 提醒：重点班不等于可以省掉事实层。省掉事实层的结果是"三个学生说得很漂亮，其余四十个没跟上"。
