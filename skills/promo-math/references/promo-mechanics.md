# 大促机制手册：每一种优惠的真实成本

这份手册只回答一个问题：**这一层优惠，商家实际掏了多少钱。**

平台规则每年改，具体条款以后台活动规则页为准。这里给的是机制原理与算账方式，不会过期。

## 一、跨店满减（最容易算错）

**机制**：买家在多个店铺凑单到门槛，平台按各商品金额占比分摊优惠。

**真实成本**：`本商品承担 = 满减金额 × 本商品金额 ÷ 整单金额`

例：满 300 减 50，本商品 199，买家凑到 300。本商品承担 = 50 × 199/300 = 33.2 元。

**坑**：

1. **凑单金额越大，单件承担越少**，所以低价款反而更"抗满减"，高价单品独自承担时最贵。
2. 用户凑单到 599，你的单品承担比例会被动变化——大促期间要看**真实成交整单金额分布**，不要用门槛值算。
3. 满减报名后，活动期间不能随意退出，报名前必须算完。

## 二、店铺券 / 店铺满减

**机制**：商家自己出钱，门槛通常按"单品优惠后金额"判定。

**坑**：

1. **门槛判定基数**：打完单品折扣和会员折扣之后才判门槛。很多商家按原价设计门槛，结果券全不生效——让利没让出去，但备货和话术都按"让了"准备。
2. **券与满减叠加**：多数场景可叠加，成本是相加的。
3. **领取率与核销率**：券发出去不等于钱花出去。核销率 30%–60% 常见，预算按核销算，不按发放算。

## 三、定金膨胀 / 预售

**机制**：买家付定金，尾款时定金按倍数抵扣。

**真实成本**：`膨胀部分 = 定金 × (倍数 − 1)`，由商家承担。

**坑**：

1. 定金不退，但**尾款未付的订单会释放库存**——预售量不等于最终销量，备货要按历史"定金转尾款率"折算（常见 70%–90%）。
2. 预售期的价格承诺要覆盖到尾款期，中途改价会触发价保和投诉。

## 四、限时折扣 / 秒杀

**真实成本**：`让利 = 原价 − 秒杀价`，且秒杀期间广告费不变，单位毛利被摊薄。

**坑**：秒杀常常带来大量**非目标人群**，退货率明显高于日常。算账时用该类目的大促退货率，不要用日常值。

## 五、赠品

**真实成本**：赠品成本 + 赠品包装 + 赠品发货运费增量。

**坑**：

1. 赠品按**成本**计，不按售价计。按售价计会把账算得过分悲观，按 0 计会过分乐观。
2. 赠品缺货导致的补偿（补发/退款）要预留，常见 2%–5%。

## 六、价保

**机制**：活动后一定期限内降价，买家可申请补差。

**成本**：`价保支出 ≈ 活动销量 × 后续降价幅度 × 申请率`。申请率通常不高，但**返场降价越狠，价保越高**。

**坑**：返场价低于活动价，等于把活动期的利润再吐一部分。设计返场价时要把它算进活动总账。

## 七、平台补贴

**机制**：平台承担一部分让利（如平台券、百亿补贴）。

**算法**：`商家实际承担 = 总让利 − 平台承担部分`。平台承担部分要看结算单，不要按宣传口径估。

**坑**：补贴往往附带条件（价格力要求、库存要求、不得中途退出），违约会扣保证金。

## 八、达人佣金与坑位费（内容电商）

| 项 | 计入方式 |
|---|---|
| 佣金 | 按成交额比例，退款通常不返还佣金（或按规则返还部分）→ 实际佣金率 = 名义佣金率 ÷ (1 − 退货率) |
| 坑位费 | 一次性，按场次摊到该场销量 |
| 样品 | 按成本计，寄样不退回 |
| 服务费 | 部分机构另收 |

**这条最容易漏**：20% 佣金 + 25% 退货率，实际佣金负担是 26.7%，不是 20%。

## 九、活动总账模板

```
活动总账
├─ 活动期实收 = Σ(单件实收 × 销量)
├─ 商品成本 = Σ(成本 × 销量) + 退货损失
├─ 履约 = 发货 + 回程 + 拦截
├─ 平台费 = 佣金 + 支付 + 税
├─ 推广 = 站内 + 站外 + 达人佣金 + 坑位费
├─ 赠品与补偿
├─ 价保支出
= 活动贡献毛利
```

判定三问：

1. 活动贡献毛利是否为正？为负，活动就是在买流量，要写清买到了什么。
2. 活动期的单位毛利，是否低于日常？低多少？用销量能不能补回来？
3. 活动带来的新客，90 天复购率是多少？这是"亏着卖值不值"的唯一答案。

## 十、报活动前的五个必查

1. 活动价是否低于保本实收（`promo_math.py stack` 的 `breakeven_received`）
2. 门槛判定基数是否会让券失效
3. 报名后能否退出，退出代价是什么
4. 备货现金峰值是否超过可动用现金
5. 退货率是否按大促口径重估过
