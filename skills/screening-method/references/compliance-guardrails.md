# 合规红线（compliance-guardrails）

面向公开发布的金融类工具，措辞风险高于功能风险。交付前逐条过。

## 一、禁用词表（出现即重写）

| 类别 | 禁用表达 |
|------|----------|
| 交易指令 | 买入、卖出、加仓、减仓、建仓、清仓、抄底、逃顶、梭哈、上车、止盈止损位 |
| 价格预测 | 目标价、上涨空间、看涨到、支撑位/压力位（作为操作依据时）、翻倍、几连板可期 |
| 收益承诺 | 稳赚、必涨、保本、无风险、高胜率、上涨概率、胜率 xx% |
| 评价性名词 | 牛股、黑马、金股、龙头首选、潜力股、妖股 |
| 权威暗示 | 强烈推荐、专家一致看好、内部消息、官方认证、独家数据源 |
| 资质虚构 | 持牌、投顾资质、合作机构、交易所授权（未取得时一律不得出现） |

## 二、替代表达

| 想表达 | 写法 |
|--------|------|
| 这只票不错 | 该票在五维打分中位于第 N 位，主要得分来自 {维度} |
| 可以买入 | 条件命中，位置 {距高点}，需自行判断 |
| 建议关注 | 纳入观察清单（清单为信息整理结果，不是操作建议） |
| 风险较大 | 命中风险标注：{具体标注} |
| 大概率上涨 | 删除。改为陈述已发生事实 |

## 三、必须出现的四要素

涉及任何具体标的时，免责声明四要素缺一不可：

1. **来源与性质**：AI 基于可获取数据整理，仅为信息参考。
2. **非建议**：不构成投资建议、要约或承诺。
3. **风险提示**：股市有风险，投资需谨慎，决策与后果自负。
4. **数据免责**：数据可能延迟、缺失或有误，以交易所与公司公告为准。

固定文本：

> ⚠️ 本内容由 AI 基于可获取的行情与财务数据整理，仅用于信息参考与条件筛选演示，不构成任何投资建议、要约或承诺。所载数据可能存在延迟、缺失或误差，请以交易所及上市公司公告为准。股市有风险，投资需谨慎，决策与后果由投资者自行承担。本工具不提供买卖指令，不预测价格，不保证任何收益。

## 四、发布前自检清单

- [ ] 全文无禁用词（建议直接全文搜索一遍关键词）
- [ ] 每个数字都能指回一个字段和一个时点
- [ ] 没有把"评分"说成"胜率、概率、上涨可能性"
- [ ] 没有承诺收益、没有暗示确定性
- [ ] 缺失字段全部标 `N/A`，没有一处用 0 或均值顶替
- [ ] 闸门淘汰的标的被列出，没有被悄悄删掉
- [ ] 免责声明原文在位，四要素齐全
- [ ] 没有声称数据来自官方授权或合作关系
- [ ] 用户数据字段做过映射，映射表随交付附上
- [ ] 若榜单跨 3 个以上行业，已提示 PE 未做行业中性化

## 五、越界请求的处理口径

用户提出下列要求时，不执行，但要把"能做的部分"给足：

| 用户要求 | 回应方式 |
|----------|----------|
| "直接告诉我买哪只" | 给"条件命中 + 位置 + 风险标注"三行事实，说明不能给操作指令 |
| "帮我算能赚多少" | 说明无法预测收益，可给历史波动区间（若有数据）并标注为历史统计 |
| "保证这几只没问题吧" | 明确不能保证，列出已识别的风险标注与数据缺口 |
| "用你的内部消息" | 说明无任何内部信息渠道，所有结论仅来自公开可获取数据 |

## 六、行业特殊口径

| 行业 | 注意点 |
|------|--------|
| 银行 / 保险 / 券商 | 资产负债率、PE 口径与制造业不可比，需单独声明 |
| 房地产 | 预收账款影响负债率，需说明口径 |
| 亏损公司 | PE 为负按"亏损"单列，不得当作低估 |
| 次新股 | 无 250 日数据，距高点与均线口径缺失，需标注 |
| ST 类 | 一律先过闸门，不因"重组预期"放行；用户坚持放行须带"人工放行"标记 |
