# 作文问题十二型与面批话术

> 用途：给一篇作文定位问题，按影响排序，最多取两个。
> 分型依据为通用作文批改经验整理（E），不是评分量表；类型之间可以并存，但一次只处理两个。
> 文中示例均为虚构。

## 二、逐型：信号、原因、改法、话术

### P1 没回答题目

- **信号**：题目要求谈"选择"，全文在谈"努力"；或关键词只在开头结尾各出现一次。
- **原因**：审题时只抓了材料的表层故事，没抓任务。
- **改法**：把题干拆成"情境 + 任务 + 限定"三块，重写中心句，一句里必须含任务词。
- **话术**："这道题让你谈的是哪件事？你文章里哪一句在谈它？指给我看。"

### P2 答了一半

- **信号**：题目有"二者关系"，全文只写一方。
- **原因**：写到一半没材料了，索性只写熟悉的那半。
- **改法**：在第三段后加一段，专门写另一方，再补一句两者的关系。
- **话术**："另一半你怎么看？不用写长，先说出三句。"

### P3 中心说不成一句话

- **信号**：段落各自精彩，合起来不知在说什么。
- **原因**：动笔前没写中心句，边写边想。
- **改法**：删到只剩三段，问自己"这三段共同指向哪一句"，把这句话提到开头。
- **话术**："如果只留一句给别人记住，你留哪句？"

### P4 立意停在口号

- **信号**："坚持很重要""我们要努力""只有这样才会成功"。
- **原因**：把"正确的结论"当成了"自己的发现"。
- **改法**：连着追问三次"为什么"，或反过来问"什么时候它不成立"，把答案写进结尾前一段。
- **话术**："这句话你不同意的时候，是什么情况？说说那种情况。"

### P5 材料是借来的

- **信号**：例子里的时间、地点、动作都对不上，或者像作文选里的标准故事。
- **原因**：平时不记自己的事，考场只能调别人的。
- **改法**：换成一个你自己见过的场景，写清一个动作、一个声音、一个时间。
- **话术**："这个人是你在哪儿见过的？那天几点，他在干什么？"

### P6 材料和观点不咬合

- **信号**：例子很感人，但读完不知道它证明了哪句。
- **原因**：先有例子，后配观点，硬接。
- **改法**：在例子后加一句"这正说明……"，如果接不上，换例子。
- **话术**："这个例子，证明了你的哪一句？用一句话接上去试试。"

### P7 三段说一件事

- **信号**：三个分论点调换顺序，文章意思不变。
- **原因**：凑结构，不是真想清楚三层。
- **改法**：把三段改成"是什么—为什么—怎么办"，或"个人—群体—时代"，让它们不能互换。
- **话术**："第二段和第三段，哪个放前面都行吗？如果都行，说明它们是一件事。"

### P8 该详的略了

- **信号**：铺垫两段，关键转折一句"后来他终于成功了"。
- **原因**：不会写过程，只会写结果。
- **改法**：把最关键的 5 分钟展开：他先做什么，遇到什么，怎么改的。
- **话术**："最难的是哪一分钟？把那一分钟写出来，别的都可以删。"

### P9 只有判断没有画面

- **信号**：通篇"他很感动""场面很震撼"，没有一个具体动作。
- **原因**：习惯用形容词代替观察。
- **改法**：删掉形容词，换成动作与声音："他把碗放下，手在桌沿停了两秒。"
- **话术**："'感动'是什么样子？他手上在做什么？"

### P10 句子长而空

- **信号**：一句四五十字，删掉修饰语意思不变。
- **原因**：怕短句显得简单，往上堆词。
- **改法**：一句只留一个动作，长句拆成两句，删掉"非常""十分""在一定程度上"。
- **话术**："这句删掉一半，意思变了吗？没变就删。"

### P11 不知道写给谁

- **信号**：开头像演讲，中间像日记，结尾像论文。
- **原因**：没想过读者是谁。
- **改法**：先定一个具体读者（同班同学、父母、某个反对你的人），全文用同一种语气。
- **话术**："这篇你希望谁看？他看到哪一句会点头？"

### P12 没写完

- **信号**：600 字左右，末段一句收尾，字迹突然变快。
- **原因**：时间分配，不是能力。
- **改法**：限时 50 分钟训练；前 5 分钟只写提纲；到 40 分钟必须进入结尾。
- **话术**："考试时你写到第几段发现时间不够？下次把哪一段砍掉？"

## 三、面批单（照这个顺序写，800 字内）

```
《题目》 学生A 高X 文体：议论文 是否限时：是

一、亮点（引原句，说清好在哪）
1. "……"——这句好在有一个具体动作，读者能看见。
2. "……"——这里把两件事并在一起，推进了一层。

二、两个主问题（按影响排序）
1. P7 三段说一件事：第二、三段都在讲"坚持能成功"，互换位置文章不变。
   改法：第二段改成"什么时候坚持是错的"，用反例。
2. P8 该详的略了：第四段"后来他成功了"一句带过，最关键的过程没有。
   改法：把这句话展开成 150 字，写他失败那一次具体怎么改的。

三、示范（只改一句）
原句：坚持是非常重要的品质，我们每个人都应该坚持。
示范：那年冬天他每天五点起，跑到操场时天还是黑的，跑到第七圈才看见东边亮。

四、这一段你来改
把第四段"后来他成功了"改成 150 字的过程描写，只写一次失败和一次调整。

五、下次检查点
下次只看两件事：三个分论点能不能互换；第四段有没有超过 120 字。

本内容由 AI 生成，供家庭参考，请结合孩子实际情况判断使用。
```

## 四、批语的三条禁忌

1. **不用标签**："没有思想""文笔差""态度不端正"——这些话学生记一辈子，且不解决任何问题。
2. **不只说不好**：每一处问题后面必须跟一个动作。
3. **不一次全改**：十个问题一次抛给学生，等于零。
