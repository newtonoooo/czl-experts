# W1 学情首诊与四周计划

## 工作流契约

| 项 | 内容 |
|---|---|
| **名称** | 学情首诊与四周计划（czl-bio-diagnosis） |
| **任务职责** | 用孩子自己做出来的材料，把"生物不好"拆成 1—2 个能当天动手的断点；排出四周优先级。不做系统教学，不出全套复习方案。 |
| **输入参数** | 必填：年级、一句卡点描述。强烈建议：最近一次生物卷面（正反面含答题卡）、2—3 道错题（题干+孩子答案+标准答案）、孩子自己的笔记或错题本、教材版本。选填：每周可用于生物的时间、最近三次分数。 |
| **执行步骤** | ①确认提问者身份（学生/家长/家教）→ ②列"五份证据"清单，标出已有与缺失 → ③逐份读，只记失分位置与作答痕迹 → ④按五类卡点归因，每类给出证据原句 → ⑤定 1—2 个主断点，其余入"观察区" → ⑥排四周优先级，每周 1 个主任务 + 1 个可观测指标 → ⑦请提问者确认与体感是否一致 |
| **判断条件** | 材料 ≥3 份且含完整卷面 → 出完整诊断卡；只有分数或一句描述 → 出"最小诊断版"并标注待补；材料互相矛盾（分数不低但错题集中） → 以原始作答为准并在卡里写明矛盾；出现视力、睡眠、情绪、注意力等疑似非学科问题 → 转介，不做学科归因 |
| **输出格式** | 诊断卡（三段：已经会的 / 断在哪 / 待确认的）+ 五类归因表 + 四周优先级表 + 今晚第一个 20 分钟动作。表格之外的解释不超过 200 字。 |
| **异常处理** | 家长代答学生情况 → "这几问要孩子自己答，答不上来本身也是信息"；材料带姓名学校班级 → 提醒删除，输出统一用"学生A"；家长直接下结论"他就是懒" → 不接受标签，改成可观察的行为（"错题本只抄题不写错因"）；孩子拒绝提供材料 → 降级为"家长观察版"，只做时间与习惯诊断 |
| **必要依赖** | 无。参考 `references/intake-questions.md`（问法库）、`references/bottleneck-rules.md`（判定规则、高频断点清单、反例） |
| **与其他工作流的关系** | 上游：无。下游：主断点交给 W2（过程不清）/ W3（遗传）/ W4（实验）/ W5（读图）；四周后把执行记录交给 W6 复盘。W1 没做完，W6 不启动。 |

## 一、材料怎么要（照抄就能用）

对家长说：

> 不用整理，原样发我就行：①最近一次生物卷子，正反面都拍，答题卡也要；②挑三道他做错的题，把题干、他写的答案、标准答案放一起拍；③他平时用的笔记或错题本，拍两页。有这三样，我大致能看出他断在哪。

对学生说：

> 不用挑"最难的"，挑"最冤的"——那种你觉得自己会、结果没得分的题，最有诊断价值。

**两轮上限**：问两轮还拿不到材料，直接给最小诊断版，不要继续追。要得越多，家长越不给。

## 二、读材料只看这几件事

| 材料 | 只看 | 不看 |
|---|---|---|
| 卷面 | 失分集中在哪个模块（代谢/遗传/调节/生态）、选择题错在概念还是图形、非选择题有没有空白 | 总分、排名、字迹 |
| 错题 | 孩子答案停在哪一步、有没有写条件、有没有用因果词 | 单纯的对错 |
| 笔记 | 有没有画过程图、有没有写"为什么"、还是整页抄课本 | 抄得工不工整、用了多少种荧光笔 |
| 口述 | 能不能说出顺序、场所、产物；说到哪一环开始含糊 | 态度、用词是否专业 |

一张卷子上如果选择题错得多、非选择题反而稳，通常不是过程不清，是**概念边界糊**或**读图失位**。反过来，选择题稳、非选择题大片空白，多是**过程不清**加**表述失分**。这个方向判断错了，后面四周全白排。

## 三、五类断点怎么判（每类必须给证据原句）

| 类型 | 判据（满足一条即可） | 证据长什么样 |
|---|---|---|
| 过程不清 | 说得出名词，说不出顺序/场所/产物；同一过程换个问法就答不出 | "光合作用分光反应和暗反应"——再问"暗反应在哪、消耗什么"就停住 |
| 概念混淆 | 两个同族概念的边界说不清，或把 A 的定义套到 B 上 | "无氧呼吸就是不消耗氧气的那种呼吸"——把发酵与有氧呼吸的产物混在一起 |
| 条件缺失 | 结论方向对，但漏掉前提；换条件后答案不变 | 答"光合速率增大"，没写"在一定光强范围内" |
| 读图失位 | 不看轴的含义、不找对照组、把拐点当最高点、不会读双曲线 | 图上一升一降两条线，他按"都升高"答 |
| 表述失分 | 缺主语、缺因果词、把现象当结论、答非所问但方向对 | "因为酶"——三个字 |

判定规则与反例见 `references/bottleneck-rules.md`。**一道错题只归一类。** 归了两类以上，说明还没问到真正的断点，继续往下追一层。

## 四、四周怎么排（排序不是平均分）

排序只用两条规则，先满足第一条：

1. **先修最上游的断链。** 光合与呼吸不清，后面"净光合""产量""气孔限制"全都站不住；遗传的分离定律不清，自由组合与伴性遗传全塌。上游不清，先补上游。
2. **先修高频考点。** 同为过程不清，细胞呼吸与光合的比较每年必考，某个人体激素的细节三年一考，先修前者。

四周里每周只能有 **1 个主任务**。第二、三、四周的主任务必须建立在前一周通过检验之上；前一周没通过，第四周不加新内容，回头重走。

## 五、诊断卡模板

```
【学情诊断卡】学生A · 高一 · 人教版
一、已经会的（要具体）
- 能独立写出有氧呼吸三阶段的场所与产物（第 3 题全对，产物没漏）
- 选择题中"细胞结构"类正确率 5/5

二、断在哪（主断点 1—2 个，附证据）
1. 过程不清：光反应与暗反应的物质联系说不清
   证据：第 8 题只写"光反应提供能量"，未提 NADPH；追问"C₃ 还原靠什么"停住 6 秒以上
2. 表述失分：结论句缺条件
   证据：第 9 题答"光合速率增大"，标准答案要求"在一定光强范围内"

三、待确认的（观察区，别急着下结论）
- 遗传题样本只有 1 道，暂不判定是方法问题还是概念问题
- 每周实际可支配时间未知

四、四周优先级
| 周 | 主任务 | 可观测指标 | 通过标准 |
|---|---|---|---|
| 第1周 | 光反应与暗反应的物质联系（一条链） | 能不看书画出链并说出 3 个场所/条件 | 连画 2 次全对 |
| 第2周 | 条件变化题（断光/断CO₂） | 5 道变式题答对 4 道并写出变化理由 | 正确率 ≥80% |
| 第3周 | 净光合与真光合的区分 | 能自己举一个"净为零但真不为零"的例子 | 说清 3 个概念差 |
| 第4周 | 表述改写 | 3 道题的答案补全条件后与答案要点对齐 | 采分点齐 2/3 以上 |

五、今晚的第一个动作（20 分钟）
拿一张白纸，画出"光反应 → 暗反应"的箭头链，每个箭头旁写清"给出去什么、要回来什么"。
画完拍照发我，我只看三个地方：场所标了没、ATP 和 NADPH 写了没、CO₂ 的去向对不对。
```

## 六、可观测指标怎么写

不许写"提高理解能力""加强基础""培养兴趣"。指标必须满足三条：一周内能看到、不用考试也能判断、家长自己能检查。

| 不合格 | 合格 |
|---|---|
| 理解光合作用 | 不看书画出光反应到暗反应的链，标出 3 个场所 |
| 掌握遗传规律 | 独立把一道系谱图推到每个个体的基因型，并说出依据 |
| 提高实验能力 | 给一个实验目的，能写出自变量、因变量、对照组三行 |
| 加强记忆 | 隔三天不看笔记，说出有氧呼吸三阶段的产物 |

## 七、收口与交付

诊断卡发出后，加一句确认："这三条里，哪一条最像他？哪一条你觉得不像？"不像的那条划掉——诊断是给孩子用的，不是给我自己看的。

四周后回到本工作流重测一次，用同一套指标对比。**不许凭感觉说"有进步"。**
