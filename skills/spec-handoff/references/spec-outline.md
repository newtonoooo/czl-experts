# 规格书骨架与填写示例

## 完整骨架（可直接复制使用）

```markdown
# 规格书：批量导出

## 0 一页摘要
- 问题：付费账号需要把明细带出系统做二次加工，现在只能逐条复制。
- 范围：导出任务创建、异步生成、下载通知、7 天有效期。
- 不做什么：不做自定义报表、不做定时推送、不做 API。
- 成功标准：上线 30 天，月付费账号导出使用率 ≥ 8%，相关工单下降 50%。
- 预计：8 人周（含设计 1、测试 1.5）。

## 1 背景与问题
现状：用户在列表页逐页复制，或联系客服后台导。
证据：3 条工单原文（B）；近 30 天导出接口日均调用 412 次（A）。
缺口：缺少可自助、可批量的一次性导出。

## 2 目标与非目标
目标：
1. 让付费账号在 3 步内发起一次导出
2. 30 天使用率 ≥ 8%
非目标：
1. 不做自定义字段选择——需求未验证，且会显著增加字段权限复杂度
2. 不做定时导出——现有客户未提出，优先验证一次性导出
3. 不做跨实体合并导出——涉及数据权限重构，另立项

## 3 用户与场景
角色：财务/运营岗的普通成员（非管理员）
触发：月末对账、客户临时要数据
频次：每月 1–4 次
```

## 第 5 节：规则与逻辑怎么写

这一节最容易写成愿望。对照表：

| 愿望写法 | 规则写法 |
|---|---|
| 系统自动判断权限 | 导出范围 = 用户可见记录 ∩ 导出白名单字段；任一为空则拒绝并提示具体缺失项 |
| 数据量大时异步处理 | 记录数 > 5000 → 异步任务；≤5000 → 同步返回。异步任务状态：pending/running/done/failed/expired |
| 支持常见格式 | 仅 CSV（UTF-8 BOM）；不支持 XLSX，理由：导出体积与内存 |
| 过期后提示 | 任务创建后 7×24 小时失效；访问失效链接返回 410 并展示"已过期，请重新导出" |

**判断表**适合有多个条件的逻辑，比文字清楚：

| 条件 | 记录数 | 用户角色 | 行为 |
|---|---|---|---|
| 正常 | ≤5000 | 成员 | 同步下载 |
| 超限 | >5000 | 成员 | 异步任务 |
| 越权 | 任意 | 无导出权限 | 403，提示申请权限 |
| 超额 | 当日已导 3 次 | 任意 | 429，提示明天再试 |

## 第 6 节：状态与异常表

| 状态 | 触发 | 界面 | 用户可做什么 |
|---|---|---|---|
| 空 | 无记录 | 空态插图 + "当前没有可导出的记录" | 返回列表 |
| 加载 | 请求中 | 骨架屏，>3 秒加提示 | 无 |
| 错误 | 接口失败 | 错误提示 + 重试按钮 | 重试 |
| 无权限 | 无导出权限 | 说明 + 申请入口 | 申请 |
| 超限 | 次数/条数超限 | 具体数字 + 下次可用时间 | 等待 |
| 部分失败 | 异步任务部分记录失败 | 下载成功部分 + 失败清单 | 下载失败清单 |

**"部分失败"这一行最常被漏掉。** 批量操作几乎一定会遇到，漏了就要在上线后补。

## 第 7 节：AC → TC 映射示例

| 编号 | 验收标准 | 测试用例 |
|---|---|---|
| AC-01 | Given 用户有导出权限且记录 ≤5000，When 点击导出，Then 3 秒内开始下载 CSV | TC-01 构造 100 条记录，断言响应 200 且 Content-Type 为 text/csv |
| AC-02 | Given 记录 6000 条，When 点击导出，Then 返回异步任务并在完成后站内信通知 | TC-02 构造 6000 条，断言 202 + 30 秒内收到通知 |
| AC-03 | Given 用户无导出权限，When 访问导出接口，Then 返回 403 且不产生任务 | TC-03 用无权限账号调用，断言 403 且任务表无新增 |
| AC-04 | Given 任务已过期，When 访问下载链接，Then 返回 410 | TC-04 手动改过期时间，断言 410 |

正常路径 1 条，异常路径 3 条。这个比例是健康的。

## 附：DoR 检查表

```
[ ] 用户场景写清（谁 / 什么情况 / 要完成什么）
[ ] 现状与缺口有证据（标明等级）
[ ] 范围与非目标都写了
[ ] 成功标准可测（指标 + 目标值 + 观测时间）
[ ] 验收标准覆盖正常 / 异常 / 边界
[ ] 依赖项有对方承诺时间
[ ] 埋点事件与字段已定义
[ ] 设计覆盖空态 / 错态 / 超限态
```

八项全勾才能进排期。缺项就在表上标"缺"，不要标"待补"——"待补"会被忘掉。
