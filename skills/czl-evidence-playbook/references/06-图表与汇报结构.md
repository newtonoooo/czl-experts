# 06 · 图表与汇报结构

> 图是给别人看的，不是给自己看的。选错图，等于把结论藏起来。

## 一、按"要说的话"选图

| 你要说的是 | 用 | 不要用 |
|---|---|---|
| 一个数比另一个大多少 | 条形图（横向） | 饼图、3D 柱 |
| 随时间怎么走的 | 折线图（时间在横轴） | 柱状图堆太多期 |
| 变化由哪几块组成 | 堆叠柱 / 瀑布图 | 多系列折线叠一起 |
| 分布长什么样 | 直方图 / 箱线图 | 只给平均值 |
| 两个量的关系 | 散点图 | 折线（会把顺序读成因果） |
| 各步流失在哪 | 漏斗图或横向条形 | 饼图 |
| 留存随周期衰减 | 热力矩阵（群 × 期） | 一条平均留存线 |

**三条硬规矩**：纵轴从 0 开始（除非差异极小且已标注）；时间轴必须等距；不超过 5 条系列。

## 二、数字怎么摆

- 变化同时给绝对与相对：`-18%（42.6 万 → 34.9 万）`。
- 比较给基线与差异：`本渠道 4.2%，全店 5.1%，低 0.9 个百分点`。
- 百分比的分母写出来。
- 金额用中文习惯单位（万、亿），并在表头标单位。
- 小数位统一：比率两位，金额按量级（万级不留小数）。

## 三、汇报的三层结构

| 层 | 给谁 | 长度 | 内容 |
|---|---|---|---|
| 一页纸 | 决策人 | 1 页 | 结论（带级别）+ 三条证据 + 一个动作 + 翻盘条件 |
| 正文 | 业务团队 | 2–3 页 | 问题、口径、定位、归因、动作与预期、局限 |
| 附录 | 复核者 | 不限 | 口径账、质量账、方法参数、复现命令、已排除解释 |

**顺序不能倒。** 先写一页纸，再写正文——逼自己先想清结论。

## 四、一页纸的写法

四行，每行一个功能：

1. **结论**：一句话，40 字内，带 A/B/C/D。
2. **证据**：三条，每条一个数字，能独立成立。
3. **动作**：谁、做什么、何时、预期动多少（区间）。
4. **翻盘**：什么数据出现就作废。

四行之外的内容，全部进附录。

## 五、常见汇报毛病

| 毛病 | 表现 | 改法 |
|---|---|---|
| 结论藏最后 | 讲了三页才说重点 | 结论放第一行 |
| 只给现象 | "转化率下降" | 补：哪一步、降多少、和谁比 |
| 没有动作 | 分析完就结束 | 至少给一个可执行动作或"暂不动"的理由 |
| 动作与证据不匹配 | 证据是 B 级，动作要投 50 万 | 动作强度跟着级别走 |
| 不敢说不确定 | 一律说"建议优化" | 明确写"这条只能观察，不能决策" |
| 图太多 | 十张图没有一句结论 | 一图一句，删掉不改变结论的图 |

## 六、看板规格怎么写

| 项 | 内容 |
|---|---|
| 北极星指标 | 一个，全公司都认的那个 |
| 一级指标 | 3–5 个，能拆到团队 |
| 二级指标 | 每个一级下 2–4 个过程指标 |
| 维度 | 渠道、地区、品类、新老客（不超过 4 个） |
| 刷新频率 | 日 / 周 / 实时，按决策节奏定 |
| 告警线 | 每个一级指标设上下限，写清触发后找谁 |
| 口径卡 | 每个指标链接到口径卡，别写在看板备注里 |

**看板的第一原则**：一个屏幕看得完。看不完说明指标太多，不是屏幕太小。
