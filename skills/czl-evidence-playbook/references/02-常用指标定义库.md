# 02 · 常用指标定义库

> 只给定义与坑，不代替你所在公司的口径文件。凡与公司口径冲突，以公司口径为准，但要写明差异。

## 一、规模类

| 指标 | 定义 | 常见坑 |
|---|---|---|
| GMV | 所有成交订单金额之和，通常不扣退款 | 与收入混淆；含未支付、含取消 |
| 净销售额 | GMV − 退款 − 优惠 − 折扣 | 优惠摊销方式不统一 |
| 订单数 | 统计期内订单去重计数 | 拆单与合单规则不同 |
| 客单价 | 净销售额 / 订单数 | 用人数当分母，结果偏高 |
| 动销 SKU 数 | 有成交的 SKU 数量 | 把 0 元赠品算作动销 |

## 二、用户类

| 指标 | 定义 | 常见坑 |
|---|---|---|
| DAU / MAU | 日/月活跃去重用户数 | 活跃定义（登录/浏览/下单）不统一 |
| 粘性 | DAU / MAU | 跨月对比时未固定同一批用户 |
| 新增用户 | 首次出现（注册或首单）的用户 | 首次定义变了没重算历史 |
| 留存率（N 日） | 首日活跃用户中，第 N 日仍活跃的比例 | 分母用注册数、分子用活跃数，口径错位 |
| 流失率 | 一段时间未活跃的比例 | 窗口长度随口径变，不可跨公司比较 |
| 复购率 | 期内购买 ≥2 次的用户占比 | 与"复购订单占比"混用 |

## 三、转化与留存

| 指标 | 定义 | 常见坑 |
|---|---|---|
| 漏斗转化率（单步） | 下一步人数 / 上一步人数 | 步骤之间存在跳步，人数会大于 100% |
| 整体转化率 | 末步人数 / 首步人数 | 与单步相乘不相等（存在旁路） |
| 同期群留存 | 按首次出现周期分组，看后续各期留存 | 未对齐周期长度就直接比较 |
| 回流率 | 沉默后重新活跃的比例 | 沉默阈值主观，需固定 |

## 四、收益类

| 指标 | 定义 | 常见坑 |
|---|---|---|
| ARPU | 收入 / 活跃用户数 | 分子分母时间窗不一致 |
| ARPPU | 收入 / 付费用户数 | 与 ARPU 混报 |
| 毛利率 | （收入 − 成本）/ 收入 | 成本是否含物流、退货损耗 |
| LTV | 单个用户生命周期内贡献的毛利 | 用收入替代毛利，虚高 |
| CAC | 获客总成本 / 新增付费用户 | 把品牌广告费用摊进来后不可比 |
| 回本周期 | CAC / 月均毛利贡献 | 用首月收入算，低估周期 |

## 五、运营类

| 指标 | 定义 | 常见坑 |
|---|---|---|
| 履约时效 | 支付到签收的小时数中位数 | 用均值，被极端值拉长 |
| 退款率 | 退款订单 / 支付订单 | 分子含部分退款时未加权 |
| 客诉率 | 投诉工单 / 订单数 | 一单多工单未去重 |
| 库存周转天数 | 平均库存 / 日均销货成本 | 用销售额代替销货成本 |

## 六、使用建议

1. 报告里每个指标第一次出现时，用括号补一句口径，如"客单价（净销售额/订单数）"。
2. 跨期对比时，两期口径必须一致；不一致就重算历史，或标注断点。
3. 跨公司对比只比方向与量级，不比绝对值——口径几乎不可能完全一致。
4. 建自己的指标字典，一指标一卡，跟着业务改，别一次写完放三年。
