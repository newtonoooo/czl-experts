# 01 · 指标口径怎么写

> 口径写不清，后面全是猜。这一份讲怎么写一张别人能照着复算的指标卡。

## 一、一张合格的口径卡要回答六个问题

1. **它是什么**：一句人话，不用术语。
2. **分子是什么**：数的是什么。
3. **分母是什么**：拿什么去除。
4. **按哪个时间**：下单、支付、发货、签收，四个时间点结果能差一截。
5. **排除了什么**：退款、取消、测试、内部、赠品、0 元单。
6. **一个人算几次**：按人算还是按单算，去重还是累加。

六个问题答不全，这个指标就不该出现在报告正文里。

## 二、最常见的六种口径歧义

| 词 | 两种常见理解 | 差多少 |
|---|---|---|
| 销售额 | 下单金额 / 实收金额（扣退款、扣优惠） | 常见差 5–20% |
| 活跃用户 | 登录过 / 有浏览 / 有下单 | 差 2–5 倍 |
| 新客 | 首次注册 / 首次下单 / 首次有效购买 | 差 10–30% |
| 复购率 | 二次购买人数占比 / 复购订单占比 | 差 1.5–3 倍 |
| 客单价 | 销售额 / 订单数 / 人数 | 差 10–40% |
| 转化率 | 支付 / 访问 / 加购 | 差 3–10 倍 |

写口径卡时，先把这类词单独列一行，注明"本报告采用 X，若用 Y 则结果见附注"。

## 三、时间口径怎么选

| 业务 | 默认用 | 理由 |
|---|---|---|
| 电商 | 支付时间 | 收入确认最接近 |
| 到店/餐饮 | 核销时间 | 履约才产生价值 |
| 订阅 | 扣费时间 | 与现金流一致 |
| 内容 | 曝光/播放时间 | 与广告收入一致 |

选定后在口径卡写明，并加一句：若改用另一种时间口径，结论会往哪个方向偏。能给数字就给数字。

## 四、去重与粒度

三种粒度不可混用：

- **按行**：原始记录数。只适合看数据量。
- **按单**：一个订单一行。适合客单价、订单转化。
- **按人**：一个主体一行。适合留存、复购、LTV。

同一份报告里出现两种粒度时，必须在表头标清。混用最常见的事故是"人数加起来不等于总人数"。

## 五、口径变更怎么处理

1. 记录变更日期与原因。
2. 变更前后各算一次，给出差异。
3. 时间序列上打一个断点标记，别把两种口径连成一条线。
4. 对外汇报时说明断点，不要悄悄抹平。

## 六、模板

```
指标：支付转化率
含义：访问用户里最终完成支付的比例
分子：统计期内完成支付的去重用户数
分母：统计期内有访问行为的去重用户数
时间：支付按支付时间，访问按访问时间，均落在统计期内
粒度：按人（去重）
排除：退款订单不计入分子；内部账号与测试账号不计入双方
边界：跨期支付的订单计入支付发生的那个期，不回算访问期
备注：口径自 2026-03 起由"下单/访问"改为"支付/访问"，历史数据已按新口径重算
```
