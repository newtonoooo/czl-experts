# 04 · 统计检验速查

> 目的不是让你去考试，是让你在报告里说的每个"显著"都站得住。

## 一、先分清你要比什么

| 你的数据 | 比的量 | 用什么 |
|---|---|---|
| 两组各自的"成功/总数"（转化人数/访客数） | 比例之差 | 两比例 z 检验 |
| 两组各自的连续值（客单价、时长） | 均值之差 | Welch t 检验 |
| 样本小、分布怪、或有明显离群值 | 均值或中位数之差 | Bootstrap 区间 |
| 两组以上的比例 | 多组是否一致 | 卡方检验（本包未内置，可用分组两两比较替代并说明） |

## 二、两比例 z 检验

直觉版：把两组各自的比例算出来，再看这个差相对于"随机波动"有多大。

```
合并比例 p = (x₁ + x₂) / (n₁ + n₂)
标准误 SE = sqrt( p × (1 − p) × (1/n₁ + 1/n₂) )
z = (p₁ − p₂) / SE
```

双侧 p 值由 z 换算。p < 0.05 只能说"如果两组真没差别，出现这么大差异的概率低于 5%"，不等于"差别一定真实"。

**必须同时报**：绝对差（百分点）、相对差（百分比）、95% 区间、两组样本量。

## 三、Welch t 检验（不等方差）

用于连续值，不假设两组方差相同，比经典 t 检验更稳妥。

```
t = (m₁ − m₂) / sqrt(s₁²/n₁ + s₂²/n₂)
自由度按 Welch–Satterthwaite 近似
```

报告写：均值各是多少、差多少、区间、样本量。均值对离群值敏感，如果分布右偏，补一个中位数对比。

## 四、Bootstrap 区间

做法：从各组里有放回地抽样 B 次（建议 ≥2000），每次算一次差值，取 2.5% 与 97.5% 分位作为区间。

优点：不依赖正态假设，能处理偏态与异常值。
缺点：样本太少（每组 <30）时区间会很宽，宽到没有信息量——这本身也是结论（"数据不够"）。

## 五、样本量与最小可检测效应（MDE）

在开跑之前算，不是跑完再算。

常用近似（α=0.05，双侧，power=80%）：

```
每组所需样本 n ≈ 16 × p(1 − p) / δ²
```

其中 δ 是你希望能检测出的绝对差（如 0.01 即 1 个百分点）。示例：基线转化率 5%，想检测出 1 个百分点的提升，每组约需 16 × 0.05 × 0.95 / 0.0001 ≈ 7600 人。

含义反过来用：样本只有 2000 人时，能稳定检测出的差异大约要 2 个百分点以上。差 1 个百分点测不出来，别硬下结论。

## 六、多重比较

同时比较 20 组，按 p<0.05 判，平均会有 1 组"显著"——纯属偶然。

处理办法（任选，报告里写明用了哪个）：

1. 减少比较次数，只比事先定好的少数几组；
2. 用更严的阈值（如 Bonferroni：0.05 / 比较次数）；
3. 把结果标为"探索性发现，需独立验证"。

## 七、常见误用

| 误用 | 为什么错 | 正确说法 |
|---|---|---|
| p = 0.06 说"接近显著" | 阈值不是渐变的 | "未测出显著差异" |
| 不显著说"两组一样" | 可能只是样本不够 | "未测出差异，样本量不足以排除小效应" |
| 只报相对提升不报绝对值 | 基数小会夸大 | "从 0.5% 到 0.8%，绝对 +0.3 个百分点" |
| 反复看数据，看到显著就停 | 会大幅提高假阳性 | 事先定样本量，跑满再看 |
| 拿 5 组里最好的一组汇报 | 选择性报告 | 报全部组，或说明筛选规则 |

## 八、报告模板（照抄可用）

```
对照组：n=10,000，转化 512（5.12%）
实验组：n=10,000，转化 583（5.83%）
差异：+71 人，绝对 +0.71 个百分点，相对 +13.9%
检验：两比例 z 检验，z=2.19，双侧 p=0.029
95% 区间：绝对差 [0.07, 1.35] 个百分点
判断：差异显著，但区间下限接近 0，建议延长观测或扩大样本再确认
```
