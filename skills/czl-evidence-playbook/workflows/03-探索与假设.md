# W3 · 探索与假设

## 职责

先看形状，再看关系。产出一份**假设清单**：每条假设都写明"如果它成立，数据里应该看到什么"。没有可验证预测的假设，一律删掉。

这一步不给结论，只给候选解释和验证路径。

## 输入参数

| 参数 | 是否必需 | 说明 | 缺失时怎么办 |
|---|---|---|---|
| 目标指标 | 必需 | 要解释的那个数 | 从 W1 任务书取 |
| 时间粒度 | 必需 | 日/周/月 | 默认按数据量选：≥90 天用周，≥24 个月用月 |
| 主要维度 | 建议 | 渠道、地区、品类、新老客 | 缺失则只做整体趋势，标注"未做维度拆解" |
| 对比基线 | 建议 | 上月、去年同期 | 无基线 → 本工序只能出 C 级观察 |

## 执行步骤

1. **看趋势形状。** 三段：长期水平、周期波动、突发拐点。拐点用"连续两期同向偏离基线"定义，不用肉眼看。
2. **看分布。** 均值与中位数差多少。差得多说明右偏，后面所有"平均"都要谨慎。分位数（P50/P90/P99）一并给出。
3. **看结构。** 按主要维度拆目标指标，找出占比与增速两个方向上的异常组。
   - 占比大且增速降 → 主要拖累；
   - 占比小但增速暴跌 → 早期信号，值得记一笔。
4. **做交叉。** 两个维度交叉一次（如渠道 × 新老客），看是否出现"整体跌、某组涨"的反向情况。这是辛普森悖论的入口，必须在 W4 之前排掉。
5. **写成假设清单。** 每条含：假设陈述、可验证预测、所需数据、验证方法（对应 W4 的哪一法）、优先级。

## 判断条件

| 判断点 | 条件 | 动作 |
|---|---|---|
| 数据周期数 | <2 个完整周期 | 不做趋势判断，只做截面描述，标 C 级 |
| 均值/中位数偏离 | 偏离 >20% | 后续一律用中位数或分位数口径，并在报告注明 |
| 是否存在反向交叉 | 是 | 先做分群对比（W4 方法四），再谈整体 |
| 假设数量 | >5 条 | 按"影响量级 × 验证成本"排序，只留前 3 条往下走 |
| 假设无法给出可验证预测 | 是 | 删除，或降级为"待补数据的猜想" |

## 输出格式

`T4-假设清单.md` 一份，表格列固定：

| # | 假设 | 若成立应看到 | 需要的字段 | 验证方法 | 优先级 |

另附"形状摘要"三行：趋势、分布、结构各一句，每句都要带数字。

## 异常处理

- **数据点太少画不出形状**：只报首末与极值，明说"样本不足以判断形态"。
- **维度基数过大**（如按 SKU 拆出 3000 组）：先聚合到前 20% 覆盖率，其余归"长尾"，在报告注明。
- **多个维度都异常**：不并列罗列。按贡献量级排序，只讲前两个，其余进附录。
- **发现数据本身有断层**：回 W2 复核，不在断档上做趋势。

## 与其他工作流的关系

- **上游**：W2 通过体检（或 W1 判定无表格时直接进入）。
- **下游**：W4 按假设类型选方法。
- **回流**：W5 反例验若把假设全部推翻，回本工序重列假设，最多重来一次；第二次仍推翻，直接给"无法归因"的结论。
