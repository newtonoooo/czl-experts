# 00 · 方法卡：五问定框与证据纪律

> 这张卡是全部闸门的地基。任何一次分析，先过五问，再过证据。

## 一、五问定框

客户说"我想去埃及"，先问五个问题，答不上来就不要往下算：

| 问 | 为什么必须先答 | 答不上时的默认处理 |
|---|---|---|
| 卖什么 | 决定 HS 归类、许可类型、监管口 | 无法默认，必须问 |
| 卖给谁 | 本地内销 / 出口欧盟非洲 / 工程承包，三条路的税、含量、物流完全不同 | 默认"本地为主 + 出口为辅"，并标注为假设 |
| 多大体量 | 决定是租厂房还是拿地、是代理还是设厂 | 给保守/中性/进取三档让客户选 |
| 多少钱、多久 | 资本开支与时间窗直接排除掉一半路径 | 无法默认，必须问 |
| 亏得起吗 | 决定能不能扛过 18–30 个月的爬坡期 | 默认"可承受首年经营性亏损"，标注假设 |

五问之外还有一个隐藏问题：**这笔投资的真实目的是什么**——是拿埃及当低成本制造基地出口欧美，还是打进埃及本地市场，还是为了拿原产地证规避某国的贸易壁垒。目的不同，最优路径可能完全相反。这个问题不要直接问，从客户的客户、订单来源、结算币种反推。

## 二、证据分级

| 级别 | 定义 | 允许的用法 |
|---|---|---|
| E1 | 埃及官方一手：中央银行、中央统计局（CAPMAS）、财政部、GAFI、IDA、SCZone、EEAA、投资法/税法原文 | 可单独支撑结论 |
| E2 | 多源一致的二手：国际组织报告 + 本地主流媒体 + 行业机构交叉印证 | 可支撑结论，标注"多源一致" |
| E3 | 单一二手：单篇报道、单一咨询报告、单一行业人士说法 | 只能作参考线索，不得单独支撑判定 |
| E4 | 顾问推断 | 必须写明推断链，并给出"看到什么就该推翻它" |

**引用写法**：`[E1] 埃及中央银行 — USD/EGP 牌价 — 2026-10-27`。没有级别的引用视为 E4。

## 三、七个常见谬误

1. **把国家风险当成项目风险**。埃及主权层面确实承压，但一个出口导向、美元收入、自由区落地的项目，和一个内销、埃镑收入、靠进口件的项目，风险敞口差一个量级。先算项目敞口，再谈国家风险。
2. **用平均工资算人工**。埃及的名义最低工资、行业实际工资、以及"含津贴与社保的全口径成本"是三个数，差距可达 1.8 倍。必须用全口径。
3. **用官方牌价算所有美元成本**。官方牌价与实际换汇可得性、手续费、时间成本不是一回事。进口件、利润汇出、设备采购的换汇路径要分别说。
4. **把意向书当许可**。MOU、land allocation letter、golden license 申请回执，都不是可开工的许可。许可链条要写到"哪一份文件拿到才允许动土"。
5. **忽略 ACID**。埃及进口的 ACID 预登记是硬门槛，单据不符会直接卡在装运港。任何进口成本模型不含 ACID 与清关时效，都是假的。
6. **把自由区当免税天堂**。自由区免的是关税和部分税，但产品进入埃及境内销售要按成品缴关税；且自由区有本地含量与出口比例要求。
7. **用"政策鼓励"替代"政策可执行"**。政策文件写了鼓励，不等于你的项目能拿到那个激励。要落到"哪个部门、哪份表格、什么前置条件、历史批复周期"。

## 四、闸门纪律

- 上一道闸门没有判定（PASS / CONDITIONAL / STOP），不允许开下一道。
- 客户跳步时：先答，再声明"该结论建立在未验证的前置假设上"，并列出需要回补的输入。
- G5 的单位经济如果推翻了 G3 的选址或 G4 的路径，必须回退重做，不允许在 G5 内部用"打个折"消化矛盾。
- 每道闸门的输出都要能被第三方复算：参数、公式、口径写清楚。

## 五、写文件的三条硬规矩

1. 每个数字后面跟口径与时点，缺一不可。
2. 每个判断后面跟"如果……就翻转"的条件。
3. 每个待办后面跟责任角色与截止月份，不写"适时推进"。

## 复核渠道

| 需要什么 | 去哪 |
|---|---|
| 汇率、利率、储备、外债 | 埃及中央银行官网 |
| 通胀、人口、贸易、就业 | CAPMAS |
| 财政、债务、补贴 | 财政部 |
| 投资法、激励、公司设立 | GAFI |
| 工业许可、工业用地 | IDA |
| 经济区政策与地块 | SCZone |
| 环评要求 | EEAA |
| 关税与 ACID | 埃及海关 / Nafeza 平台 |
| 税务申报与裁定 | 埃及税务局（ETA） |
