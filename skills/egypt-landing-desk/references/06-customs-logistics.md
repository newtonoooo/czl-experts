# 06 · 清关与物流卡（G5）

> 目的：让进口成本模型里"清关"这一项不再是拍脑袋。

## 一、ACID 预登记：进口的硬门槛

ACID（Advanced Cargo Information）是埃及海关的装运前申报制度，通过 Nafeza 平台完成。要点：

- **必须在装运前完成**，由埃及进口商发起、出口方在出口国确认。
- 单据信息（品名、HS 编码、数量、金额、发票号、船名航次）必须与实际装运完全一致。
- 不一致 → 货物到港后无法清关，滞港费按天计，可能被退运。
- 结果是：**报价、合同、发票、装箱单、提单五套文件必须一次对齐**，改一个字都可能重来。

这是最容易造成"看起来很简单的进口，实际卡两个月"的环节。

## 二、清关流程（进口）

```
ACID 预登记（Nafeza）
  → 装运前检验（按品类的强制检验/认证）
  → 到港申报（报关行提交）
  → 海关估价与 HS 归类
  → 缴关税 + 增值税（+ 可能的其他费）
  → 查验（抽查或必查）
  → 放行 → 内陆运输
```

**时效基准**（用于模型，非承诺）：资料齐全、无查验 3–7 个工作日；有查验或归类争议 2–6 周；ACID 或单据问题可无限期。

## 三、关税结构怎么用

- 按 HS 编码归类，工业品分档，原料与成品通常税率不同——这正是本地组装的经济性来源。
- 投资法下的项目可能获得设备与必需原料的关税减免，但需要批复文件，不是自动享受。
- 自由区企业进口料件免关税，但产品进入埃及境内销售按**成品**缴关税。
- 从埃及出口到欧盟、非洲、阿拉伯国家，能否享受优惠税率取决于**原产地规则与本地含量**，不是"在埃及生产就行"。

## 四、原产地与本地含量

| 目标市场 | 依据 | 判定要点 |
|---|---|---|
| 欧盟 | 联系国协定 | 需原产地证明与足够的本地增值；具体规则按产品 HS 逐条看 |
| 阿拉伯国家 | 大阿拉伯自由贸易区 | 本地增值比例门槛 |
| 非洲 | 非洲大陆自贸区 / COMESA | 规则仍在演进，需逐案确认 |
| 美国 | 无全面自贸协定 | 一般按最惠国税率，个别产品有特殊安排 |

**关键判断**：如果客户的商业逻辑是"在埃及组装、拿埃及原产地证出口欧洲"，那么本地含量能不能达标就是这个项目的生死线，必须在 G2 阶段就确认，而不是等到 G5。

## 五、内陆物流

- 亚历山大港、塞得港、达米埃塔是主要进口口；苏伊士与 Ain Sokhna 面向红海方向。
- 重货公路运输成本与距离强相关，上埃及项目要单独算内陆段。
- 铁路货运能力有限，别把铁路当默认选项。
- 冷链、危化品、超限设备的运输许可要单独申请。

## 六、常被忽略的成本项

1. 滞港费与堆存费（ACID 出问题时按天烧钱）。
2. 报关行服务费与查验陪同费。
3. 强制检验与认证费用（按批次或按型号）。
4. 内陆保险费（埃及段）。
5. 资金占用：从付汇到放行的在途资金成本。

## 七、输出要求

进口成本模型必须逐项列出：FOB、海运与保险、ACID 与报关、关税、增值税（可抵扣部分单列）、查验与滞港预备金、内陆运输、在途资金成本。缺任何一项都不算完整模型。

## 复核渠道

- 埃及海关 / Nafeza 平台：ACID 规则、HS 归类、税率
- 埃及标准与质量组织（EOS）：强制认证目录
- 港口管理局：港口费率与堆存规则
- 报关行：当期实际时效
