# R5 留存分档与跃迁

> 用途：Q6 档位站。
> 口径：**官方口径**，来源为七猫中文网福利页「纯分成阶梯全勤奖」（2025-02 版本）。
> 平台会调整，每次使用前先核对官方页；本卡不作为合同依据。

## 为什么是"档位"不是"趋势"

纯分成作者的全勤单价，不看你涨了几个点，看你**落在哪一档**。同样掉 1 个点：

- 从 11% 掉到 10%，还是一档（10 元），损失有限；
- 从 10.5% 掉到 9.5%，掉一档（10 元 → 7 元），全月单价直接降三成。

所以诊断的第一步永远是：**先定位档位，再谈趋势。**

## 达标天数规则

不是"当月平均达标"就行。官方口径是：

> 连载状态下，当月需同时满足平均留存与阅读 UV 的天数，**超过当月出该数据总天数的一半**。

例：当月出数据 31 天，一半是 15.5 天，则至少 16 天要同时达标。

这一条的实际含义：**月底冲量没用。** 月底两天把均留拉上去，达标天数不够，一样拿不到。

## 前两个月

签约头两个月属于"未出均留"阶段，规则不同：日更 ≥ 4000 字、无断更灌水抄袭，按 6 元/千字计。

这条只能用来度过启动期，**不能拿来算长期收入**。第二个月之后，一切看十万字均留。

## 每一档的典型症状与动作

### 0 ~ 6%：没有全勤，先保命

症状：读者点进来，三章内走掉一半以上。

动作顺序：改开头 200 字 → 改第一章事件 → 改第二章代价。别改后面，后面没人看。

### 6% ~ 10%：留不住，但有人留

症状：能过前三章，掉在 5–15 章。

动作：查"每章有没有新信息"。这个区间掉，典型是"主线停了，开始写日常"。

### 10% ~ 15%：主线在，节奏慢

症状：读者知道要看什么，但等得太久。

动作：把爽点兑现的间隔从 5 章压到 3 章；删掉所有"过渡章"。

### 15% ~ 25%：进入 UV 门槛区

症状：均留够了，UV 不够，单价拿不满。

动作：这已经不是正文问题。把力气放在分类是否正确、标签是否精准、封面点击率、简介转化上。

### 25% 以上：守档比冲档重要

症状：已经在高位，任何一次断更都可能掉档。

动作：囤稿。高位作者的第一风险不是写不好，是断更。

## 掉点定位法：卷 → 章 → 段

1. **按卷拆**：哪一卷的均留最低。通常只有一卷特别低。
2. **按章拆**：在那一卷里找"读完率断崖"的章号，通常是连续 2–3 章。
3. **按段拆**：打开那几章，看第几段开始跳读。判断标准：删掉这段，剧情有没有损失？没有，就是它。
4. **归因**：四选一——主线断了 / 反派太弱 / 感情线拖 / 更新不稳。

四类归因对应四种改法，别混着改。一次只改一类，改完看 7 天。

## 三个容易踩的坑

1. **只看均留不看 UV。** 15% 以上的档位都有 UV 门槛，UV 不到，单价打折。
2. **用单日数据下结论。** 单日波动是噪声，看 7 天移动趋势。
3. **拿别人的均留当目标。** 不同题材的合理区间不同，年代重生 18% 已是不错，玄幻 18% 可能是顶。
