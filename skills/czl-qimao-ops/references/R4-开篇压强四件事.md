# R4 开篇压强四件事

> 用途：Q4 样章站。前 200 字决定读者留不留，第一章决定编辑签不签。
> 口径：结构判断为本产品原创；平台无官方"开篇标准"，这里给的是可检验的替代标准。

## 前 200 字的四项

缺一项就要重写开头，不是改，是重写。

### 1. 有人

必须有一个具体的人在场，且这个人在做事。代词（他/她/我）也算，但不能只有环境。

### 2. 有事

必须有一个正在发生的动作。判断方法：把这段的动词全部划出来，如果动词少于三个，说明你在描写，不在叙事。

### 3. 有不对劲

必须有一个"不该这样"的信号。可以很小：一扇不该开的门、一句不该说的话、一个不该出现的人、一笔对不上的账。

没有异常，读者没有理由往下看。异常不需要解释，只需要出现。

### 4. 有具体物

一个能被拍出来的东西：搪瓷缸、欠费单、红纸、账本、粉笔灰。具体物负责让读者相信这件事真的发生过。

## 第一章的结构

第一章不是"介绍"，是**一个完整事件**。

```
起因（一个具体麻烦）
  → 对抗（有人挡着，主角做了一个选择）
    → 结果（这个选择产生了后果）
      → 改变（主角的处境或认知发生了变化）
```

四步走完，才叫一章。只写"她醒来，看了看屋子，想起前世"——这是序章，不是第一章。

### 检验方法

读完第一章，问三个问题：

1. 主角做了一件什么事？（答不出 = 没有事件）
2. 谁挡着她？（答不出 = 没有对抗）
3. 章末她的处境和开头有什么不同？（答不出 = 没有改变）

## 三种常见死法

### 死法一：设定倾倒

开头三百字介绍世界观、等级、家族关系。

改法：把设定拆成"需要时才说"的信息，第一次出现时只给一句，剩下的等用到再补。

### 死法二：环境开场

"清晨的阳光透过窗棂洒在地上，院子里的老槐树沙沙作响……"

改法：把人放进环境里，让环境成为动作的一部分（她推开窗，看见树下站着三个人）。

### 死法三：回忆开场

"她想起了十年前的那个下午……"

改法：回忆只能在读者已经关心这个人之后出现。第一章用回忆开场，等于让读者关心一个还不认识的人。

## 钩子分级

按强度从高到低：

1. **身份悬念**：这个人不是他以为的那个人。
2. **危机逼近**：有一件事将在某个时间点发生，读者知道，主角不知道。
3. **信息缺口**：一个关键信息被拿走了（账本缺一页、照片少一个人）。
4. **情绪未了**：一句话没说完、一个动作没做完。

章末钩子至少要到第 3 级。只写"她睡着了"不算钩子。

## 前三章的分工

- 第一章：给事件，给异常，给一个明确的对手。
- 第二章：给代价。主角为第一章的选择付出什么。
- 第三章：给希望。让读者看到这件事有解，但解法很难。

三章走完，读者应该能说出"这本书讲一个人要干什么，谁不让"。
