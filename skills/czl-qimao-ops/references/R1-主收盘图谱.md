# R1 七猫主收盘图谱

> 用途：Q1 选品站的判断依据。看的是**结构**，不是情节。
> 口径：分类归属与榜单实例来自七猫公开榜单页（采集于 2026-10），题材结构为本产品原创拆解。

## 读者是谁

- 主体是三四线城市 30–45 岁读者，女性占比高，免费阅读、广告容忍度高。
- 同时存在一批年轻读者，偏好强冲突、高爽点，男频系统流、女频逆袭在这部分人里跑得好。
- 结论：**同一个题材要同时满足"看得懂"和"够刺激"**。太文艺的写法两边都不讨好。

## 女频六类

| 类型 | 结构公式 | 开篇第一件事 | 常见死法 |
|---|---|---|---|
| 现实婚姻 / 离婚逆袭 | 受辱 → 决裂 → 翻身 → 对方后悔 | 当场把婚离了，或当场把条件谈清 | 忍三十章不离婚，读者先跑 |
| 豪门关系 / 追妻火葬场 | 男主误判 → 女主退出 → 男主追悔 | 一个具体的误会动作（签错文件、认错人） | 误会靠"她不解释"硬撑 |
| 多胎 / 带娃 | 身份错位 → 生育绑定 → 家族接纳 | 一次体检、一张单子、一场认亲 | 孩子只当道具，没有自己的事 |
| 年代重生 | 重生 → 改命 → 致富 → 守成 | 回到命运转折当天，立刻改一个决定 | 重生后只谈恋爱不干事 |
| 古言权谋 | 低位 → 借势 → 上位 → 清算 | 一场婚约或一道旨意把人逼到墙角 | 权谋写成吵架 |
| 玄学 / 轻悬疑 | 异常 → 试探 → 反杀 | 一件不该发生的小事（不该响的铃响了） | 解释太多，恐怖变科普 |

## 男频七类

| 类型 | 结构公式 | 开篇第一件事 | 常见死法 |
|---|---|---|---|
| 神医 / 医术 | 被轻视 → 一针见效 → 身份揭晓 | 当场救一个没人敢救的人 | 医术全靠旁白夸 |
| 战神 / 兵王归来 | 隐忍 → 亮身份 → 清算 | 一个不该受的委屈（被赶、被退） | 亮身份太早，后面没牌 |
| 系统流 | 触发 → 任务 → 兑现 → 升级 | 系统第一次弹窗，代价同时出现 | 系统无限制，爽感贬值 |
| 都市重生 / 复仇 | 重生 → 布局 → 反杀 | 回到被害当天，先改一个细节 | 复仇对象太蠢，赢得没劲 |
| 玄幻升级 | 蒙难 → 得法 → 越阶 → 压场 | 一次退婚、一次夺宝、一次被逐 | 升级数值化，读者记不住 |
| 历史 / 权谋 | 低位 → 立功 → 入局 → 掌权 | 一场必死的差事被他接下 | 现代思维硬套古代制度 |
| 武侠仙侠（特色） | 拜师 → 试炼 → 破境 → 问道 | 一次出手（救人或杀人） | 境界写得像游戏面板 |

## 两个特色类型值得单独说

七猫对**男频武侠仙侠**和**女频年代重生**设了独立的纯分成全勤档，起跳线比其他类型低：

- 武侠仙侠（男频）：8% 均留就进第一档（15 元/千字），18% 进第二档（25 元）。
- 年代重生（女频）：10% 进第一档（10 元），18% 进第二档（25 元），28% 进第三档（50 元）。
- 普通类型要 15% 才摸到 15 元档，20% 才到 25 元档。

意思是：**同样写到 20% 均留，写年代重生的女频作者拿 25 元，写普通都市的也是 25 元，但年代重生只用了两档就到了，中途的每一档都比普通类型更容易踩上去。** 这不是让你改题材，是让你知道自己在哪个赛道上有政策顺风。

## 用这张表的三条纪律

1. **只拆结构，不抄情节。** 抄结构叫学习，抄情节叫侵权。
2. **榜单是结果，不是原因。** 在榜说明它跑通了，不说明照着写就能跑通。
3. **逆流题要标价。** 选了表外的题材，就在工单上写清"读者基数打折、前 3 章要额外给主收盘读者一个理由"。
