# 市场规则差异（A 股 / 港股 / 美股）

同一套策略换个市场，结论可能反过来。建模前先把这张表过一遍。

## 一、总表

| 项目 | A 股（沪深/北交所） | 港股 | 美股 |
|---|---|---|---|
| 最小交易单位 | 100 股一手（科创板 200 股起、以 1 股递增） | 每手股数由发行人定（100/200/500/1000 不等） | 1 股 |
| 交收 | T+1（当日买入次日可卖） | T+2 交收，但多数标的当日可回转 | T+1 交收，可当日回转 |
| 涨跌停 | 主板 ±10%、创业板/科创板 ±20%、ST ±5% | 无涨跌停（有 VCM 冷静期） | 无涨跌停（有 LULD 熔断） |
| 卖出印花税 | 0.05%（2023-08 后减半） | 0.1%（双边，2023-11 后下调） | 无 |
| 佣金 | 万分之 2.5 左右，最低 5 元 | 万分之 8 左右，另有征费 | 多数券商 0 佣金，有 SEC/TAF 费 |
| 过户费 | 沪深 0.001% | 无（含在征费内） | 无 |
| 做空 | 个人投资者基本不可行（融券受限） | 有限（借券成本高） | 常规，但有借券费与 SSR |
| 货币 | CNY | HKD（部分标的 USD） | USD |

内核已把这些打包成 `CostModel.china_a()` / `hk_stock()` / `us_stock()`，并用手数、`t_plus_1` 两个开关控制交易约束。

## 二、A 股要特别小心的地方

1. **一字板买不到**：信号次日开盘就涨停时，实盘无法成交。回测默认照常成交，**必须在局限里写明"未建模涨跌停不可成交"**；若策略高度依赖涨停，宁可在成交前加一条 `open >= prev_close * 1.095 → 放弃该笔` 的过滤并单独说明。
2. **停牌**：长期停牌的标的会缺 bar，引擎沿用上一收盘价计价，会造成"净值不动"的假象。数据清单里要记录停牌区间。
3. **ST / 退市**：样本里包含后来退市的标的，天然带幸存者偏差。用户给的股票池要问清是哪一天的快照。
4. **复权**：长期持有必须用前复权；做"当日涨跌幅"类信号时，前复权会改变历史价格但保持收益率一致，一般没问题；**不要**把复权价当成"当时真实成交价"去算手数与资金。
5. **科创板/创业板**：最小 200 股、以 1 股递增，100 股一手的假设在这里不成立，`lot_size` 要单独设。

## 三、港股

- 每手股数不统一，取不到就按 100 并注明；股数错了会让资金占用与收益同时失真。
- 印花税是双边的，且按成交金额计；`CostModel.hk_stock()` 用 10bp 近似。
- 无涨跌停，但小市值标的流动性差，未建模冲击成本时回测会显著偏乐观。
- 货币是 HKD，报告里不要套 ¥。

## 四、美股

- 1 股起，无 T+1 限制（日内可回转）；`t_plus_1=False`。
- 做空可以建模：`side="short"`，但要说明未计借券费与 SSR 限制。
- 盘前盘后不在日线范围内，别用日线近似"盘后财报公布后立即交易"。
- 拆股频繁，务必用复权序列。

## 五、跨市场组合

默认**不混币种**。非要混，必须先统一到一种计价货币并写明汇率来源与日期，否则净值曲线没有意义。做不到就分市场各跑一份，分别报告。

## 六、市场层参数对照（照抄即可）

```python
# A 股
Engine(..., lot_size=100, t_plus_1=True,  market="china_a", cost=CostModel.china_a())
# 港股
Engine(..., lot_size=100, t_plus_1=False, market="hong_kong", cost=CostModel.hk_stock())
# 美股
Engine(..., lot_size=1,   t_plus_1=False, market="us",       cost=CostModel.us_stock())
```

`market` 只是标签，写进 `summary.json` 与报告，不改变撮合逻辑；真正的约束来自 `lot_size` / `t_plus_1` / `cost` 三个参数。改市场时**三个一起改**，只改一个是最常见的错误。
