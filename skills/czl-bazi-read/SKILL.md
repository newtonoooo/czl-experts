# 八字解读

**职责**：把四柱盘读成"这个人的运行结构 + 当前处在哪一段"，不读成"这个人的命运判决"。

## 前置

必须先有 `czl-oracle-engine` 跑出的 `bazi` JSON。没有盘，不解读。

## 六步读法

### 第一步：立日主

看 `day_master`：日干五行 + 阴阳 + 月令长生状态。

一句话定基调，例如："辛金生于午月，火当令而金处病地，是**外柔内紧**的结构——表面配合，内里有自己的硬边。"

不要写成"金命人如何如何"，那是属相级的话术，不是解读。

### 第二步：定强弱，给"需要什么/怕什么"

用 `strength.support_percent`（同类+印星占比）定强弱档，然后：

| 判读 | 结构含义 | 需要的 | 怕的 |
|---|---|---|---|
| 偏强（≥55%） | 自我供给足，容易过刚 | 泄（食伤）、耗（财）、制（官杀） | 再加比劫印星 |
| 中和（40–55%） | 弹性最好，看大运引动 | 补短板那一行 | 极端偏枯 |
| 偏弱（<40%） | 承压能力有限，靠外部支撑 | 生（印）、助（比劫） | 再叠财官食伤 |

**注意**：强弱不是好坏。偏强的人扛得住事但容易硬碰；偏弱的人敏感但善于借力。把这个差别讲清楚，比贴"身弱"标签有用。

### 第三步：看十神格局

统计 `pillars_detail` 里透干与坐月的十神，找出"主导的那一两个"，再看它们落在哪一柱。

| 主导十神 | 行为倾向（说人话，不说术语） |
|---|---|
| 比肩 / 劫财 | 靠自己和同辈，独立性强；劫财重则易在分配上吃亏 |
| 食神 | 输出稳定、口味与手感好，适合做产品/内容/手艺 |
| 伤官 | 表达锋利、不服管，适合靠本事说话的位置，不适合层层审批的体系 |
| 正财 | 稳收、看重确定性，适合经营性收入 |
| 偏财 | 抓机会、多线并行，收入波动大但弹性高 |
| 正官 | 讲规则、能被托付，适合有明确职责的岗位 |
| 七杀 | 靠压力和对抗驱动，扛得住硬仗，也容易把自己绷断 |
| 正印 | 靠学历、资质、体系背书，学习吸收强 |
| 偏印 | 非线性思维，靠偏门知识与洞察，容易想得多做得少 |

**要看的三个细节**：
1. **透干还是藏支**：透干的是"摆在外面的行为"，藏支的是"底下的动机"。
2. **坐月令**：坐月令的那个十神，是这一生的主旋律。
3. **有没有被合走/冲开**：`zhi_relations` 里有六合、六冲、三合的，说明这股力量是被牵住还是被打散。

### 第四步：看偏枯

`wuxing.percent` 里低于 8% 或高于 35% 的五行要单独说：

- 某行极弱 → 对应的领域容易是短板（木弱：生长/规划；火弱：表达/热度；土弱：稳定/落地；金弱：决断/边界；水弱：流动/变通）
- 某行极旺 → 对应的领域是优势，也容易是执念
- **两行相战**（如水火各占 30%+）→ 结构内部长期拉扯，表现为"两套标准同时要求自己"

### 第五步：宫位与六亲

| 柱 | 管什么 |
|---|---|
| 年柱 | 家族底色、早年环境、行业大背景 |
| 月柱 | 父母与成长资源，也是事业的社会位置 |
| 日柱 | 自己与伴侣（日支为夫妻宫） |
| 时柱 | 晚年、子女、长期作品 |

读法：某柱被冲、被合、被空亡（`xunkong`），就在对应领域给一句提示。**不要据此断"父母缘薄"这类话**，只描述结构。

### 第六步：定节奏

- `dayun.list`：找出当前年龄段所在大运，说这一步的主题（该大运天干的十神）。
- `liunian`：看未来 3–5 年流年十神与该大运的配合——同向叠加则势大，反向则拉扯。
- 起运 `dayun.meta.start_age`：告诉用户"你的大运按 X 岁换轨"，这是可自行核对的锚点。

节奏的表达要给"松紧"而不是"吉凶"：**"2027–2029 这三年是伤官叠食神的输出期，适合把东西做出来并推出去；2030 转正官，是收口和接受规则的一年。"**

## 分领域写作要求

按用户问的挑，不硬凑。每条都要落到"结构 → 表现 → 建议"。

- **事业**：官杀（对抗/职责）+ 食伤（输出）+ 印（背书）三者的配比决定适合的组织形态。
- **财务**：正财偏财的比例决定收入结构；财库（辰戌丑未）看储蓄习惯；比劫重则提醒分配与合伙风险。
- **关系**：日支为夫妻宫，看其十神与合冲；不看"桃花几朵"这种数数。
- **身心**：只讲"长期偏枯可能带来的消耗倾向"（如木火过旺易亢、水多土少易滞），**绝不诊断任何疾病**，并提示就医。

## 输出规范

- 走 Agent 的六段式。
- 盘面依据段要能让用户自己核对（引用具体四柱、具体百分比）。
- 术语首次出现给一句白话。
- 结论用"偏/更容易/这一段"，不用"必定"。
- 结尾附免责声明。

## 异常处理

| 情况 | 处理 |
|---|---|
| 无时辰（B 级） | 只读年月日三柱，明确说"时柱缺失，晚年、子女与起运细节不可判" |
| 时辰存疑 | 两盘并列，指出差异，不下判断句 |
| 用户问"我什么时候能发财" | 拒绝给金额与年份的确定承诺，改为给"财星被引动的时间段 + 可做的准备" |
| 用户问"我是不是克夫/克妻" | 直接否定这种说法，改讲夫妻宫的结构特征与相处方式 |
