# 话术卡（可打印贴在冰箱上）

用途：W6。家长在最累的时候不会思考，只会条件反射。所以给能直接读出口的句子。

## 一、每天只用得上三句

| 时机 | 读这一句 |
|---|---|
| 开始 | "今天的二十分钟，做哪一项？" |
| 中途卡住 | "先说说这题在问什么。" |
| 结束 | "今天哪一步你自己想通的？" |

三句话的共同点：**都不评价对错**。评价一出现，孩子就开始为"不被批评"而做题，不再为"弄懂"而做题。

## 二、按场景查

### 孩子说"我背不下来"

| 别回 | 改回 |
|---|---|
| "别人怎么背得下来" | "我们不分段背，你先说这条线上有几步。" |
| "多读几遍就记住了" | "你记得住哪个朝代，从那个朝代往后说。" |
| "那你就是不努力" | "背不下来通常是没结构，我们画个表。" |

### 孩子考差了

| 别回 | 改回 |
|---|---|
| "怎么考成这样" | "卷子给我，我们看错的是哪几类。" |
| "下次必须考到 XX 分" | "下次只看一件事：同一类错因有没有少。" |
| "是不是又没复习" | "这次错题里，有几道是你复习过的？" |

第三句很关键——它把"没复习"这个笼统指责，变成可核对的事实。

### 孩子做对了一道难题

| 别回 | 改回 |
|---|---|
| "真聪明" | "你哪一步想通的？" |
| "早这样不就行了" | "这个方法记下来，下次同类题用。" |
| "你看，认真就有用" | （不说话，点个头即可） |

夸"聪明"会让孩子回避难题（怕失去聪明的评价）；夸"方法"才会让他重复方法。

### 孩子情绪崩了

| 别说 | 说 |
|---|---|
| "至于吗" | "今天先停，明天这个时间再来。" |
| "我都是为你好" | "我知道这很难，我们先做五分钟最简单的。" |
| "你这样子以后怎么办" | （沉默，递水，等十分钟） |

情绪处理不属于教学环节。**在情绪里讲道理，只会把"历史"和"难受"绑定。**

## 三、家长自我检查（每周一次，两分钟）

- [ ] 这周我有没有在孩子做题时纠正过他？
- [ ] 这周我有没有提过"别人家孩子"？
- [ ] 这周我有没有用分数评价过他？
- [ ] 这周我有没有说过"我当年"？
- [ ] 这周我有没有一次只是听他讲，不给建议？

五个里"没有"少于三个，说明这周家长的存在是负担而不是支持。**先改自己，再改孩子。**

## 四、和学校老师的沟通模板

家长常想找老师问，但问得笼统，老师也答不出有效信息。给三个具体问法：

```
1. "孩子这次材料题失分主要在'概括'还是'分析'？"（问题型，不问分数）
2. "他在课堂上是听懂了但写不出，还是跟不上？"（问环节）
3. "我们在家练'分点作答'，会不会和您的要求冲突？"（问配合）
```

不要问"我孩子还有希望吗"。这个问题没有信息量，只会让老师给一句安慰。

## 五、给孩子的三条自我话术（家长转述）

| 场景 | 说给自己听 |
|---|---|
| 背不下来 | "我不是记性差，我是没结构。先画表。" |
| 又选错了 | "错在哪一类？归了类就不算白错。" |
| 大题写不出 | "先写观点，再想两条史实，别想整篇。" |

这三句的作用是**把"我不行"换成"我下一步做什么"**。归因方式改变，练习才持续得下去。
