# JD 四栏拆解方法

## 为什么拆四栏

JD 是招聘方随手写的，混着硬条件、日常工作和团队黑话。逐句读会被"我们是一个年轻有活力的团队"这类内容干扰。拆成四栏后，能立刻看出这份 JD 真正在筛什么。

## 第一栏：硬门槛

**识别线索**：学历、年限、证书、语言等级、地点、是否接受远程、是否有行业准入要求。

**处理**：不满足就是硬伤，改写简历无用。先确认两件事：

1. 这个门槛是硬性的还是写的比实际高？（看同公司同类岗位的写法，或直接问 HR）
2. 有没有等价的替代证明？（无学位但有同等年资 + 项目；无证书但有可验证作品）

**注意**：JD 写"本科及以上"，实际筛人时常按"本科 + 3 年"或"硕士 + 1 年"折算，年限和学历是联动的。

## 第二栏：职责动作

**识别线索**：以动词开头的条目。"负责""搭建""推动""优化""支持""对接"。

**处理**：把 JD 的动词抄成一张对照表，看你简历里有没有对应的动作。JD 说"搭建指标体系"，你写"维护报表"，这是动作层级差一档，不是同义词问题。

| JD 动作 | 你写的 | 判定 |
|---|---|---|
| 搭建 | 维护 | 层级低一档，需要补"从 0 建了什么"的经历 |
| 推动跨部门 | 配合完成 | 角色被动，需要改成你发起的那部分 |
| 优化 | 负责 | 需要补优化前后的对比 |

## 第三栏：工具与方法

**识别线索**：具体软件、编程语言、方法论名词、行业术语。

**处理**：只写你真的用过的。工具名后面最好跟一句"用它做了什么"，否则就是个词。

- 弱：熟练使用 Tableau
- 强：用 Tableau 搭 6 张运营看板，替代原来每周手工汇总的 Excel 周报

## 第四栏：隐性信号

这一栏最值钱，也最容易被跳过。

| 信号 | 说明 | 简历该怎么调 |
|---|---|---|
| 同一词出现 3 次以上 | 这是这个岗位的真实痛点 | 相关内容提到最前面 |
| "独立负责""从 0 到 1" | 缺人干活，要能自己扛 | 强调独立完成的模块 |
| "跨部门""协调""推动" | 组织复杂度高，光会做事不够 | 补推动类经历和结果 |
| "快速迭代""敏捷" | 节奏快，流程不完善 | 强调短周期交付 |
| "体系建设""规范化" | 从混乱走向规范 | 强调你建过什么标准 |
| 汇报对象写得很高 | 需要能直接对话高层 | 补汇报与影响决策的经历 |
| JD 里全是"配合""支持" | 这个岗位是支撑角色 | 别把自己写成主角，会不匹配 |

## 拆完之后做一次现实检查

回答三个问题，答不上来说明 JD 没读透：

1. 这个岗位入职后前三个月最可能被考核的一件事是什么？
2. 招聘方最怕招到什么样的人？（JD 里那些反复强调的词，往往就是上一任踩过的坑）
3. 我简历里哪一行能让招聘方相信我能扛住第 1 条？

## 反模式

- **把 JD 复制进简历**：技能栏和 JD 原文高度重合，是最明显的应试痕迹。
- **为了匹配改事实**：把"参与"写成"主导"，入职第一天就穿。
- **一份简历投所有岗位**：改三个词的边际成本很低，不改的代价是全军覆没。
- **只改关键词不改顺序**：招聘方先看位置，再看词。相关经历埋在第二页，词写得再准也没人看到。
