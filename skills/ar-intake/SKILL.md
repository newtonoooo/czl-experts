# 受理与分型

任务是这个流程里最便宜的一步，也是最容易毁掉全部后续工作的一步。**标的错了，后面全错；类型错了，交付物就是废纸。**

## 职责

**做**：锁定标的、判定任务类型、确定输出形态与时间口径、列出未知项。
**不做**：不取数（交 `ar-evidence`），不做分析判断（交下游），不写内容（交 `ar-thesis`）。

## 输入参数

| 参数 | 必填 | 说明 | 缺失处理 |
|---|---|---|---|
| 标的 | 诊断/估值/成稿类必填 | 代码、全称或简称 | 反问，一次只问一个 |
| 任务类型 | 否 | 由动词推断 | 推断置信度<80% 时给两个选项 |
| 时间口径 | 否 | 盘中 / 最近交易日 / 指定日期 | 默认最近交易日收盘 |
| 输出形态 | 否 | 报告 / 公众号稿 / 内部过会 / 口头 | 默认 HTML+MD+摘要 |
| 持仓信息 | 体检类必填 | 代码、数量、成本价 | 缺成本价则不算盈亏，只算敞口 |

## 执行步骤

### 1. 标的归一

按下面顺序把用户说法映射到唯一代码：

1. 已是 6 位数字 → 直接判板块（见 `rules/ar-market-rules.md` 代码归属表）
2. 带市场前缀（sh/sz/bj、.SH/.SZ/.BJ）→ 去掉前缀取数字
3. 中文全称/简称 → 查证代码；**简称重名时（如"中金""东方"）必须让用户确认**
4. 描述性说法（"沪市股王""锂电龙头"）→ 给出候选 2-3 个让用户选，不要自作主张

输出统一格式：`600519.SH`（代码 + 交易所后缀）。

### 2. 任务分型

按动词判定，不看名词：

| 动词信号 | 类型 | 首站工作流 |
|---|---|---|
| 怎么样 / 值不值得看 / 帮我看看 / 有没有雷 | 诊断 | `ar-autopsy` |
| 值多少 / 贵不贵 / 给个价 / 高估了吗 | 估值 | `ar-value` |
| 财报 / 公告 / 这个新闻影响 | 事件解读 | `ar-autopsy` 事件维 |
| 大盘 / 复盘 / 板块 / 情绪 | 复盘 | `ar-tape` |
| 写篇 / 成稿 / 发出去 / 整理成文 | 成稿 | `ar-thesis` |
| 这几个票 / 持仓 / 仓位 / 风险集中 | 体检 | `ar-position` |
| 还算数吗 / 上次 / 复盘我的判断 | 复核 | `ar-position` 台账 |

一个请求里有多个动词时，取最终交付物对应的那个。**"帮我看看这票然后写篇文章" → 类型是成稿，诊断是其上游步骤。**

### 3. 输出形态确认

只在以下情况问：用户没说清用途，且形态会显著改变产出（口头 3 句 vs 6000 字深度稿）。

其余情况直接按默认走，不要为了确认而确认。

### 4. 未知项清单

动手前在内部列出三类未知，只把**会改变结论**的那一类问出来，最多问一个问题：

- 阻断性未知：标的无法锁定、任务类型无法判定 → 必须问
- 影响性未知：时间口径、是否含持仓成本 → 可先用默认，报告里注明
- 无关未知：用户为什么关心、打算持有多久 → 不问，除非影响情景设定

## 判断条件

| 情形 | 动作 |
|---|---|
| 标的落在港股/美股/期货/期权 | 明确说明超出范围，停止。不要"顺便看看" |
| 标的是 B 股 | 可做，但须提示外币计价与流动性差异 |
| 标的是退市整理期股票 | 可做，但只出风险清单，不出估值 |
| 用户同时给 5 只以上标的 | 先问优先看哪 1-2 只，其余排队 |
| 用户要求"预测明天涨跌" | 说明不做点位预测，改为给出情景与触发条件 |
| 用户提供未公开信息 | 拒绝使用，说明原因，仅基于公开信息继续 |

## 输出

一份内部受理单（不需要展示给用户，除非用户要）：

```
标的：600519.SH 贵州茅台（上交所主板，±10%）
类型：诊断
口径：2026-10-29 收盘
形态：HTML + MD + 对话摘要
已知缺口：无最新季报（三季报 10 月底披露，可能未出）
下一步：ar-evidence → ar-autopsy
```

## 异常处理

- 名称查不到：不猜。列出可能的 2-3 个候选让用户选。
- 代码不存在（如 600000 以下预留段）：说明该代码无对应上市证券，请用户核对。
- 用户拒绝提供必需信息：说明缺它会怎样影响结论，然后给出"降级版"能力范围（如无成本价 → 只算敞口不算盈亏）。
