# 写作评分与批改口径

> 下面是我教学用的档次描述，用来定位"现在在哪一档、下一档缺什么"。它不是官方评分细则的复述；各省细则以当地考试院文件为准。

---

## 一、应用文（15 分）

| 档 | 分数 | 内容 | 语言 | 结构 |
|---|---|---|---|---|
| 五档 | 13—15 | 要点全覆盖，读者、目的、语气都对 | 句式有变化，偶有小错不影响理解 | 三段以内，衔接自然，不堆连接词 |
| 四档 | 10—12 | 要点基本覆盖，缺一个次要信息 | 基本正确，错误不影响理解 | 分段合理，衔接靠少量连接词 |
| 三档 | 7—9 | 缺 1—2 个要点，或某个要点写偏 | 错误较多，主要意思仍可懂 | 段落功能不清，句子之间靠 and/so 硬连 |
| 二档 | 4—6 | 要点缺一半，或写成另一件事 | 错误多，理解受阻 | 结构松散，读不出段落 |
| 一档 | 1—3 | 只写出个别词句 | 无法成句 | 无结构 |

**常见扣分点**

| 扣分点 | 说明 |
|---|---|
| 格式缺件 | 书信缺称呼或落款；通知缺标题或时间地点 |
| 语气错位 | 给老师写信用 `Wanna`、`BTW`；给朋友写信用 `I am writing to inform you` |
| 字数不足 | 明显少于要求（如 80 词只写 50），要点必然缺 |
| 抄题干 | 大段照抄题目中文要点译成英文，不算内容 |
| 要点堆砌无过渡 | 三个要点三句独立句，中间没有逻辑关系 |

## 二、读后续写（25 分）

| 档 | 分数 | 内容（衔接与情节） | 语言 | 连贯 |
|---|---|---|---|---|
| 五档 | 21—25 | 与原文人物、情节、伏笔衔接自然；情节合理且有细节；结尾接住所给首句 | 词汇准确，句式有变化，错误极少 | 段落之间推进自然，衔接手段多样 |
| 四档 | 16—20 | 衔接较好，情节基本合理，细节偏少 | 语言较准确，有少量错误 | 连贯尚可，偶有跳跃 |
| 三档 | 11—15 | 衔接一般，情节简单或有一处不合逻辑 | 错误较多，但不影响整体理解 | 靠时间词推进，段落功能弱 |
| 二档 | 6—10 | 与原文脱节，人物性格走样 | 错误多，理解受阻 | 连贯差，事件顺序乱 |
| 一档 | 1—5 | 内容极少或与原文无关 | 无法成句 | 无 |

**常见扣分点**

| 扣分点 | 说明 |
|---|---|
| 抄原文 | 大段复述所给材料，不计入内容 |
| 人物错位 | 名字写错、性格突变（前文胆小，续写突然勇敢且无铺垫） |
| 时态混乱 | 记叙主体用一般过去时，突然切到现在时 |
| 没有细节 | 全篇"他很紧张，然后他成功了"，无动作、无场景 |
| 对话过多 | 通篇对话推进，缺少叙述与描写 |
| 不接首句 | 两段首句已给，续写内容与之重复或冲突 |
| 字数不足 | 明显少于 150 词，通常伴随情节单薄 |

## 三、四层批改怎么落到句子上

### 第一层 内容

问三个问题：
1. 题目要求的点，逐条打勾，缺哪个？
2. 有没有写偏（写成议论文、写成另一个话题）？
3. 续写：这一段接住了前文的哪一句？伏笔用了吗？

**只在这一层发现问题时，语言问题全部暂缓。**

### 第二层 结构

- 应用文：每段一句话概括功能（目的 / 细节 / 期待回复）。功能重复就合并。
- 续写：第一段承接冲突，第二段收束。两段都写"他们继续走"，就是没推进。

### 第三层 语言

按错误密度决定改几处：

| 错误密度 | 处置 |
|---|---|
| 每句都有错 | 只挑两个高频错（如时态、主谓一致），其余标记不改 |
| 两三句一处 | 改 4—5 处，集中在他反复犯的类型 |
| 偶有错误 | 只改影响理解的，其余保留他的表达 |

**保留孩子的表达**很重要。全改成老师的句子，下次他还是不会写。

### 第四层 升格

只改两句，格式固定：

```
原句：...
改句：...
为什么：把"很紧张"换成手抖这个动作，读者能看见；形容词换动作，是续写最省力的升格。
```

## 四、批改语气

| 不说 | 说 |
|---|---|
| 这篇很差 | 要点齐了，问题在段落之间没有推进 |
| 语言太低级 | 这三句都是 `He was very + 形容词`，我们换一个写法 |
| 你怎么又错时态 | 时态这次错了 3 处，都是同一类，我们只修这一类 |
| 多背好词好句 | 这两个句型能换主语反复用，先造三句自己的 |
