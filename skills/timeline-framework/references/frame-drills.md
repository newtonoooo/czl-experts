# 框架训练题（反向自测）

用途：W2 第 5 步。**给特征猜时期**，比正着背有效，因为它逼学生调取结构而不是回忆文字。

## 使用方法

- 一次五题，三分钟。
- 答不出时不给答案，先提示"这三个特征分别属于哪三个维度"。
- 全对之后，让学生自己出三题考家长。**出题是最强的复习动作。**

## 第一组：中国古代

1. "相权一分为三，选官靠考试，土地税按资产分夏秋两次征收。"
   → 唐（三省六部、科举、两税法）

2. "皇帝直接管六部，另一个机构在边上拟旨，海外贸易只留一口。"
   → 明（废丞相设内阁、海禁）

3. "设了一个机构在皇帝身边跪着记话，边疆设驻藏大臣，税按田亩摊丁。"
   → 清（军机处、驻藏大臣、摊丁入亩）

4. "门阀按门第做官，北方人口大批南下，佛教寺庙占了大量土地。"
   → 魏晋南北朝（九品中正、北民南迁、寺院经济）

5. "交子出现，市镇兴起，理学成为官方哲学，经济重心南移完成。"
   → 宋（交子、市镇、理学、重心南移）

## 第二组：中国近现代

6. "设总理衙门，办机器局，派留学生，但坚持'中体西用'。"
   → 洋务运动（19 世纪 60—90 年代）

7. "废科举，办新式学堂，预备立宪，但革命派已在组织起义。"
   → 清末新政（1901—1911）

8. "提倡民主与科学，反对旧道德，马克思主义开始传播。"
   → 新文化运动（1915 年起）

9. "土地改革，三大改造，一五计划，同时提出'双百'方针。"
   → 1950 年代新中国

10. "设经济特区，提出社会主义市场经济体制目标，加入世贸。"
    → 改革开放时期（1980—2001）

## 第三组：世界史

11. "公民大会抽签产生，发津贴，但妇女与奴隶不参与。"
    → 雅典民主政治（前 5 世纪）

12. "封君封臣，庄园经济，王权与教权并立，大学兴起。"
    → 中古西欧

13. "商业革命，价格革命，殖民扩张，三角贸易。"
    → 新航路开辟后的 16—17 世纪

14. "工厂制度，城市化，工人运动，世界市场形成。"
    → 工业革命后的 19 世纪

15. "国家干预经济，福利国家，冷战对峙，殖民体系瓦解。"
    → 二战后

## 第四组：易混对照（最容易错的一组）

16. "加强了君主专制" 与 "加强了中央集权"，分别对应哪两件事？
    → 前者如废丞相、设军机处；后者如郡县制、推恩令、行省制

17. "商品经济发展" 与 "资本主义萌芽"，区别在哪？
    → 前者指为交换而生产普遍化；后者特指雇佣关系的出现（明清江南丝织业）

18. "自然经济解体" 与 "民族资本主义产生"，谁是因谁是果？
    → 解体提供劳动力和市场，是产生的前提之一

## 出题模板（学生自己出题用）

```
这件事发生在____（朝代／时期），
政治上____，经济上____，文化上____，
所以它的阶段特征是____。
```

四行填满，就是一个合格的"反向题"。填不满的那一行，就是他的缺口。

## 训练频率

| 阶段 | 频率 | 时长 |
|---|---|---|
| 高一 | 每周两次 | 各 5 分钟 |
| 高二 | 每周一次 | 8 分钟（含自己出题） |
| 高三 | 每周一次，随机抽三个时段 | 10 分钟 |

不要一次做二十题。做多了会变成"背题面"，反向自测就失效了。
