# 工序 04 · 质检闸

## 名称

质检闸（QC Gate）—— 发布前唯一的拦截点。

## 职责

对一张笔记卡做四查：**事实、合规、人味、结构**。任何高危项命中，卡片不放行。这是硬闸，用户催也得过。

质检不是"读一遍觉得还行"。每个判断都要能落到具体句子、具体规则编号。

## 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `note_card` | 是 | 03 产出的笔记卡（T4） |
| `material_card` | 是 | 用于核对每个数字的出处 |
| `strict` | 否 | 严格模式：低危项也必须改。缺省关闭 |

## 执行步骤

**第 1 步：跑脚本。** 先把正文和标题存成 `.md` 或 `.txt`，跑：

```bash
python scripts/note_lint.py 笔记卡.md --json > lint.json
```

- 退出码 `0`：无高危命中，可进第 2 步人工查。
- 退出码 `1`：有高危命中，逐条改完再跑一遍。
- 退出码 `2`：输入文件读不到或格式不对，先修输入。

脚本查的是**能机器判定的部分**：字数、标题长度、标签数、极限词、功效词、导流词、承诺词、AI 腔正则、段落长度、emoji 密度、CTA 数量。查不了的部分在第 2–4 步人工过。

**第 2 步：事实查。** 逐句问：这句话的事实依据在素材卡的哪一条？

| 类型 | 处理 |
|---|---|
| 数字能对上素材卡 | 通过 |
| 数字对不上，但用户口头说过 | 补进素材卡，标注来源 |
| 数字是模型推的 | 删掉，或改定性表述 |
| "我亲测/自用"但用户没做 | **高危，必须改**。改成可核实的第三方观察，或删掉这段 |

**第 3 步：合规闸。** 按 `references/07-compliance.md` 逐类过：

1. 绝对化用语（最、第一、顶级、国家级、独家、唯一）
2. 功效与医疗暗示（治疗、修复、消炎、祛、瘦、降、防癌）
3. 站外导流（加微信、私我、评论区留联系方式、谐音变体）
4. 虚假体验与虚假数据（亲测未测、销量未核）
5. 特殊类目（食品、化妆品、医疗器械、教育培训、金融）的额外限制
6. AI 生成内容的标识要求

命中的不是"删掉"，是**给替换写法**。质检报告里必须写"改成什么"。

**第 4 步：人味闸。** 按 `references/06-human-voice.md` 的十二条逐条过。重点是句子级：

- 连续三句以上同构短句
- "不是 A，而是 B" 结构（一篇最多 1 处）
- 每段都在承担转折或金句（一篇至少留 3–5 段没功能的）
- 替读者总结（"说到底""一句话概括""这才是最重要的"）
- 段末金句化（每段最后一句都是警句）
- 元叙述（"这里我要多说一句""请注意下面这段"）
- 三段式排比
- 泛化建议（换到任何同类文章都成立的建议）
- 结尾升华（"更值得问自己的是…"）

**第 5 步：结构查。** 四问：

1. 前 3 行交出具体承诺了吗？
2. 标题有没有自答？
3. 有没有埋一个能被具体回答的问题？
4. CTA 是不是只有一个？

**第 6 步：出结论。**

- 高危项 = 0 且 中危项已改 → **放行**
- 高危项 > 0 → **打回**，附逐条修改项
- 只有低危项且未开严格模式 → **放行**，但把低危项列成"可选微调"

## 判断条件

| 情况 | 判定 |
|---|---|
| 用户说"先发出去看看" | 不放行。高危项命中就是不放行，说明理由 |
| 用户说"这是我的真实经历" | 采信，但要求补一个可核对细节（时间/价格/地点），补不上则视为不可核实，按高危处理 |
| 笔记是纯知识科普，无产品 | 合规闸放宽到只查绝对化用语与医疗暗示；人味闸不放松 |
| 笔记涉及医疗、金融、教育、减肥 | 全部按最严处理，且必须提示"该类目需资质，发布前自行确认" |

## 输出格式

```
【质检结论】☑ 放行 / ☒ 打回
高危：n 项（逐条：规则编号 · 原文片段 · 改成什么）
中危：n 项
低危：n 项（可选微调）
事实查：n 处数字，出处齐全 / n 处缺出处
结构查：4 项通过 n 项
```

## 异常处理

| 异常 | 处理 |
|---|---|
| 脚本报的命中是误判（如"第一支"被当成极限词） | 人工复核后放行，并在报告里注明"误判，已复核"。不因为误判就关掉整条规则 |
| 用户拒绝修改高危项 | 不交付该卡片。给替代写法，必要时降级为"仅供内部参考，不建议发布" |
| 平台规则已更新，词表滞后 | 明说词表版本，建议用户核对平台最新规则。词表是下限，不是上限 |
| 卡片里有多篇笔记 | 逐篇跑，不合并跑 |
