# 工序 06 · 复盘

## 名称

复盘（Review）—— 从一篇已发布笔记的数据里，定位断在哪一级。

## 职责

把"数据不好"翻译成"哪一级坏了、下一轮改哪一个"。只给一个动作。

复盘最容易犯的错是拿行业平均值当判据。不同类目、不同粉丝量级、不同内容形态的基准差几倍，平均值没有意义。**基线用账号自己的历史中位数。**

## 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `note_metrics` | 是 | 曝光、点击（阅读）、点赞、收藏、评论、涨粉。缺哪个标"缺" |
| `note_card` | 是 | 对应笔记卡（标题、封面、标签、正文） |
| `history` | 否 | 该账号过去 10–20 篇的同类数据。没有则无法建基线 |
| `publish_time` | 否 | 发布时间，用于排除时段因素 |

## 执行步骤

**第 1 步：算三个率。** 只用四则运算，不需要工具。

```
点击率 = 点击 / 曝光
互动率 = (点赞 + 收藏 + 评论) / 点击
关注转化 = 涨粉 / 点击
```

三个率都要和**同账号同类内容的最近 10 篇中位数**比。没有历史数据就只做单点判断，并在结论里写"无基线，判断置信度低"。

**第 2 步：找断点。** 按顺序，从上游往下游查，**只查第一个明显低于自身基线的环节**。

| 级 | 指标 | 断了通常意味着 | 下一轮该动什么 |
|---|---|---|---|
| 1 | 曝光 | 选题没需求 / 标签跑偏 / 账号权重低 / 发布太密 | 换长尾词选题，不加量 |
| 2 | 点击率 | 封面与标题没给打开理由 | 只改封面主标和标题，正文不动 |
| 3 | 互动率 | 内容没有可带走的东西，或没有可回答的问题 | 补一个具体信息点 + 埋一个真问题 |
| 4 | 关注转化 | 单篇有用但账号看不出"关注了能得到什么" | 改简介与合集，不改单篇 |

顺序很重要。曝光只有 800，去改封面是无意义的——没有人看到封面。

**第 3 步：排除干扰项。** 断点找到后，先排掉三种假原因：

- 发布时间异常（凌晨发、大促当天发）
- 账号状态异常（近期有违规提示、连续断更）
- 内容形态换了（突然从图文改视频）

排不掉就把这些写进结论，别硬把锅扣在封面上。

**第 4 步：给一个动作。** 一次只给一个，且必须具体到能当天做。

- ✅ `把封面主标从「护手霜测评」改成「第四支才不裂」，副标保留 39 元，重发同正文。`
- ❌ `优化封面和标题，提升内容质量。`

**第 5 步：记账。** 把这次判断写成一条假设，进 `templates/T6-review-sheet.md`：

```
假设：点击率低是因为封面主标没有具体物。
动作：只改主标，保留标题与正文。
预期：下一篇同类内容点击率不低于账号中位数。
验证：下一篇发布 48 小时后对比。
```

没写验证方式的假设不算假设，算许愿。

## 判断条件

| 情况 | 判定 |
|---|---|
| 曝光 < 账号中位数一半 | 先查级 1。不查封面，不查正文 |
| 曝光正常、点击率低 | 级 2。只改标题与封面 |
| 点击正常、互动率低 | 级 3。查正文是否有可带走的信息、有没有埋问题 |
| 互动正常、不涨粉 | 级 4。查账号主页与简介 |
| 三率全部正常但曝光极低 | 账号层问题（权重/垂直度/发布频率），不在单篇复盘范围内，明说 |
| 只有曝光数、没有点击数 | 无法定位。要用户从后台补点击，否则只做定性判断 |

## 输出格式

`templates/T6-review-sheet.md`：

```
【诊断】断点：级 2（点击率）
【数据】曝光 3200 / 点击 128 / 点击率 4.0%；账号中位数 6.2%；缺口 -2.2pt
【依据】曝光接近中位数（3120），排除级 1；互动率 5.1% 略高于基线，排除级 3
【干扰项】发布时间正常；账号无异常提示
【一个动作】改封面主标为「第四支才不裂」，其余不动
【假设与验证】见上；48 小时后对比点击率
【下一轮】若点击率回到 6% 以上，说明封面假设成立，把该封面结构存为模板
```

## 异常处理

| 异常 | 处理 |
|---|---|
| 用户只给点赞数 | 无法定位。列出需要的 3 个数字（曝光、点击、评论），说明为什么 |
| 用户给的是"别人的笔记"数据 | 只能做结构拆解，不能做账号诊断。明说 |
| 数据看起来自相矛盾（点击 > 曝光） | 指出口径问题，让他核对后台定义（不同入口的"阅读"口径不同） |
| 用户想一次改五处再发 | 拒绝。五个变量同时改，改完不知道哪个起了作用 |
| 用户拿一次爆文当基线 | 基线用中位数，不用最高值。爆文是异常值，不是常态 |

## 与其他工序的关系

- 前置：已发布且有数据。
- 后继：结论回流 `02 选题`（变成新假设），或回流 `03`（只改被定位的那一处）。
- 本工序不产出新笔记，只产出判断与一条假设。
