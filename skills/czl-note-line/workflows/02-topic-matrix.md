# 工序 02 · 选题矩阵

## 名称

选题矩阵（Topic Matrix）—— 把"写什么"变成一个可排序的表。

## 职责

产出 ≥20 条选题，每条都带着搜索词、角度、骨架、素材命中情况和优先级。目标是让用户**不用再想**，照着表往下做。

选题不靠灵感。选题是「搜索词 × 角度 × 骨架」的组合，缺一维就会写空。

## 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `position_card` | 是 | 01 的道具卡；若是跳过 01 的老号，用"三条内容支柱"代替 |
| `material_card` | 是 | 00 的素材卡 |
| `industry` | 是 | 赛道，如 护肤 / 家居 / 考研 / 咖啡 |
| `competitor_notes` | 否 | 用户给的竞品笔记标题或截图；没有就用赛道常识推 |
| `count` | 否 | 需要多少条，缺省 20 |

## 执行步骤

**第 1 步：建搜索词三层。** 每层至少 8 个词。

| 层 | 特征 | 例子（护肤） |
|---|---|---|
| **大词** | 品类名，搜索量大、竞争密集 | 护手霜、身体乳 |
| **中词** | 场景/人群修饰 | 冬天手裂、学生党护肤、干皮救急 |
| **长尾问句** | 读者原话式的具体问题 | 手裂口涂什么、护手霜涂完还是干 |

长尾词最值钱：搜索意图明确，竞争少，且能直接当标题。

词从哪来：平台搜索框的下拉联想、笔记评论区里重复出现的问题、用户自己被问过的问题。**不要凭空造词**，拿不准就标"待验证"。

**第 2 步：找竞品缺口。** 三种缺口，优先级从高到低：

| 缺口类型 | 怎么认 | 为什么是好选题 |
|---|---|---|
| **高赞但没讲透** | 点赞很高，评论区一堆人在问同一个细节 | 需求已证明，供给不到位 |
| **有搜索没内容** | 联想词有，但搜出来内容少、或都是两年前的 | 需求在，供给空缺 |
| **全是品牌稿** | 同词下内容全是整齐的产品图 + 一样的卖点 | 用户看不到真实体验，你的真实素材是优势 |

反面：同词下已经有一堆真人实测且写得好 → 这条不选，除非你有新角度。

**第 3 步：组合成矩阵。** 每条选题 = 一个搜索词 × 一个角度 × 一个骨架。

- 角度取 `references/05-material-angles.md` 的十二种切法之一（亲历/对照/拆解/清单/避坑/时间线/花费账单/反面教材/工具流/场景还原/提问征答/对比淘汰）
- 骨架取 `references/03-body-skeletons.md` 的四种之一（亲历型/清单型/对照型/拆解型）

同一批选题里，**同一角度不超过总数的 1/3**，否则账号看起来只有一种腔调。

**第 4 步：标素材命中。** 每条选题写清用哪条素材。素材命中为空的选题，标红，要么补料，要么删。

**第 5 步：定优先级。**

| 级 | 条件（三条同时满足） |
|---|---|
| **P0 先写** | 长尾词有明确搜索意图 · 素材三问中≥2 问 · 竞争不饱和 |
| **P1 排后** | 满足两条，或需要用大词但角度新 |
| **P2 备着** | 只有一条，或素材还没到 |

P0 的数量控制在 5–7 条。全是 P0 等于没有优先级。

## 判断条件

- 矩阵里出现"XX 好物推荐""XX 必买清单"这类无人群无场景的题 → 打回，这是没做定位的题。
- 同一搜索词占了 3 条以上 → 合并，同词多篇会互相抢流量。
- 有选题的素材命中为空却标了 P0 → 逻辑错误，降级。

## 输出格式

`templates/T3-topic-matrix.csv`，字段固定：

```
序号,选题,支柱,搜索词,词层,角度,骨架,素材命中,痛点等级,竞争程度,优先级,备注
```

交付时附三行结论：P0 有哪几条、先写哪一条、为什么是它。

## 异常处理

| 异常 | 处理 |
|---|---|
| 用户赛道极窄（如"左撇子剪刀"） | 词层降级：大词用上位品类，长尾词用真实问句。宁可少而准 |
| 用户不给竞品信息 | 用赛道常识推，但每条标"竞争程度=未验证"，并在交付里说明 |
| 用户要 100 条 | 先给 20 条能写的，说明产量边界：写不出来的选题等于没有 |
| 用户要求"必须都是爆款选题" | 明说：爆款不可预判，可预判的是需求是否明确。把 P0 的判据解释给他 |

## 依赖

读 `references/05-material-angles.md`、`references/03-body-skeletons.md`、`references/04-tag-and-search.md`、`templates/T3-topic-matrix.csv`。

## 与其他工序的关系

- 前置：`01 定位`（或已有支柱）。
- 后继：`03 成稿`，一次取 1 条 P0 进稿。
- 回流：`06 复盘` 的结论变成新的选题假设，追加进本矩阵，标"来自复盘"。
