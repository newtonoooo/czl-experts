# 四级漏斗诊断

## 一、为什么不用行业平均值做判据

同一个"点击率 5%"，在美妆号和家居号里含义完全不同；1 万粉和 100 粉的账号，曝光结构也不一样（新号推荐流量占比更高，波动更大）。

拿行业均值判断单篇笔记，结论通常是错的。

**正确做法：用这个账号自己最近 10–20 篇同类内容的中位数当基线。** 只回答一个问题：这篇比我自己平时的水平，差在哪一级。

中位数不用最高值。爆文是异常值，拿它当基线会让后面每一篇都"不达标"。

---

## 二、三个率的算法

```
点击率   = 点击（阅读） / 曝光
互动率   = (点赞 + 收藏 + 评论) / 点击
关注转化 = 涨粉 / 点击
```

三个率都只做除法，不需要工具。算完之后和基线并排放：

| 指标 | 本篇 | 基线（近 10 篇中位数） | 差 |
|---|---|---|---|
| 曝光 | 3200 | 3120 | +80 |
| 点击率 | 4.0% | 6.2% | −2.2pt |
| 互动率 | 5.1% | 4.6% | +0.5pt |
| 关注转化 | 0.8% | 1.1% | −0.3pt |

看这张表就能定位：曝光持平、互动率高于基线、只有点击率明显低 → 问题在封面和标题，不在正文。

## 三、断点判定表

**从上游往下游查，只查第一个明显低于基线的环节，后面的先不看。**

| 级 | 环节 | 判定条件 | 常见原因 | 下一轮动作 |
|---|---|---|---|---|
| 1 | 曝光 | 低于基线 50% 以上 | 选题没搜索需求 / 标签跑偏 / 账号近期异常 / 发布过密 | 换长尾词选题；查账号状态；降频 |
| 2 | 点击率 | 低于基线 1.5 个百分点以上，且曝光正常 | 封面主标无具体物 / 标题自答 / 封面缩略图不可读 | 只改封面主标与标题 |
| 3 | 互动率 | 低于基线 1 个百分点以上，且点击正常 | 没有可带走的信息 / 没埋可回答的问题 / 全篇没有立场 | 补一个具体信息点 + 埋一个具体问题 |
| 4 | 关注转化 | 低于基线 0.5 个百分点以上，前三率正常 | 单篇有用但账号看不出关注价值 | 改简介、建合集、加系列感 |

### 为什么必须按顺序

曝光只有 800，去改封面没有意义——没有人看到封面。
点击率 2%，去改正文没有意义——没有人读到正文。

诊断顺序错了，改的每一处都是浪费。

## 四、五种常见误判

**误判 1：把波动当趋势。**
单篇数据腰斩可能只是发布时段撞上了大促。判断要看连续 3 篇同类型内容。

**误判 2：把爆文当能力。**
一篇突然起来，先看它和平时有什么不同（选题？封面？还是刚好踩了热点）。找不到差异就别复制，复制不出来。

**误判 3：把评论区热闹当内容好。**
评论多但都是"求链接""多少钱"，说明内容只是引子，没有交付价值。这类笔记涨粉少是正常的。

**误判 4：把收藏高当一切好。**
收藏高说明有用，但收藏是"以后再看"，不等于当下被打动。收藏高、评论低，往往意味着内容像工具书。

**误判 5：一次改五处。**
五个变量同时改，改完不知道哪个起了作用。**一次只改一处**，这是复盘能积累经验的前提。

## 五、干扰项排查

在把锅扣给内容之前，先排掉这三个：

| 干扰项 | 怎么查 |
|---|---|
| 发布时间异常 | 是否凌晨发、是否大促当天发、是否和账号固定活动撞车 |
| 账号状态异常 | 近期是否有违规提示、是否连续断更超过 7 天、是否刚改过简介或头像 |
| 内容形态突变 | 是否突然从图文改视频、是否突然换了封面风格 |

排不掉就写进结论，不要硬解释。

---

## 六、结论怎么写

一份能用的复盘结论，必须包含五句：

1. **断点**：断在第几级（只有一个）
2. **依据**：哪两个数据支持这个判断
3. **排除**：为什么不是上一级、不是下一级
4. **动作**：一个当天能做完的具体改动
5. **验证**：多久之后、看哪个数字、达到什么算这个假设成立

少了第 5 句，复盘会变成循环——每次都"感觉封面不好"，每次都在改封面。

## 七、数据不全怎么办

| 只有 | 能做什么 | 不能做什么 |
|---|---|---|
| 点赞 | 几乎什么都判断不了 | 不能定位断点 |
| 曝光 + 点击 | 能判断级 1 和级 2 | 不能判断内容价值 |
| 曝光 + 点击 + 互动 | 能判断级 1–3 | 不能判断账号定位 |
| 全套 + 历史 | 能完整诊断 | — |

数据不全时，如实说"无法定位"，并列出需要补的三个数字。**不要用猜测填满表格**——猜出来的诊断比没有诊断更糟，因为它会让用户去改错的地方。
