# 笔记卡 T4

> 用法：把每个 `〔〕` 里的占位内容换成实际内容。正文区保持干净——不要夹批注、不要写"这里可以加一句"。
> 保存为 `.md` 后可直接跑 `python scripts/note_lint.py 你的笔记卡.md` 做体检。

---

## 基本信息

- 选题：〔一句话，来自选题矩阵〕
- 角度：〔亲历 / 对照 / 拆解 / 清单 / 避坑 / 账单 / 时间线 / 场景还原 / 工具流 / 淘汰 / 提问征答 / 反面教材〕
- 骨架：〔亲历型 / 清单型 / 对照型 / 拆解型〕
- 素材来源：〔对应素材卡编号，用于排期时拉开间隔〕

## 标题候选

1. 〔留空型〕〔标题文字，≤20 字〕
2. 〔代价型〕〔标题文字〕
3. 〔对照型〕〔标题文字〕
4. 〔亲历型〕〔标题文字〕
5. 〔清单型〕〔标题文字〕

## 封面

主标：〔≤9 字，一个具体物〕
副标：〔一个数字或动作，≤14 字〕
角标：〔身份或场景，≤10 字〕

配图：

- 封面：〔拍什么 / 什么光〕
- 信息图：〔放什么内容〕
- 实拍：〔几张，各拍什么〕

## 正文

〔正文全文，400–700 字。段间空行。这里不要写任何批注。〕

## 首评

〔30 字内，一句补充或一个问题〕

## 标签

#〔品类词1〕 #〔品类词2〕 #〔品类词3〕 #〔场景词1〕 #〔场景词2〕 #〔场景词3〕 #〔长尾词1〕 #〔长尾词2〕

## 可选微调

- 〔不放进正文、但用户可能想加的备选句〕
- 〔需要用户补拍/补数的位置说明〕
