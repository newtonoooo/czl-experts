# 指标口径与公式推导

> 本文件是 `scripts/live_metrics.py` 的口径说明书。所有公式在此给出推导过程，任何人可用计算器复核。
> 参考线是**经验区间**，来自公开的行业讨论与通用运营常识，不是任何平台官方发布的考核标准。平台后台的字段定义以各平台当期文档为准。

---

## 一、五个基础量

先把口径钉死，后面所有指标才不会互相打架。

| 量 | 定义 | 常见混用 |
|---|---|---|
| 曝光次数 | 直播间在推荐流/关注页/搜索等位置被展示的次数 | 与"观看人次"混用 |
| 进房人次 | 进入直播间的人次，同一人进出多次计多次 | 与"观看人数"（去重 UV）混用 |
| 商品点击 | 用户点开商品卡/购物袋的次数 | 与"商品曝光"混用 |
| 付款单量 | 完成支付的单数 | 与"下单数"（含未付款）混用 |
| 成交额 GMV | 付款口径的商品金额合计，通常未扣退款 | 与"结算金额"（扣退款扣佣金）混用 |

**一条硬规则：一篇文章、一张表里，同一指标只能有一种口径。** 要换口径就换名字（如"下单转化率"与"支付转化率"）。

---

## 二、漏斗指标

### 1. 进房率

```
进房率 = 进房人次 / 曝光次数
```

含义：曝光给你了，多少人愿意进来。它同时受封面、标题、开播时间、画面第一帧影响。
**它是最上游的一层**——这一层低，后面的停留和转化再好，绝对值也起不来。

### 2. 平均停留

```
平均停留 = 观看总时长 / 进房人次
```

含义：进来的人平均待多久。这是平台判断"这场直播值不值得继续推流"的核心信号之一。
**参考线 45 秒是下限不是目标**：低于 45 秒意味着大部分人在第一屏就划走了，此时讲什么产品都没用。

### 3. 互动率（综合）与评论率

```
互动率 = (点赞数 + 评论数) / 进房人次
评论率 = 评论数 / 进房人次
```

为什么拆两个：点赞几乎没有成本，评论需要打字。**评论率比互动率更能反映真实意愿**，诊断时优先看评论率。
综合互动率的价值在于对齐平台后台的通用口径。

### 4. 转粉率

```
转粉率 = 新增关注数 / 进房人次
```

新人场次这个指标比 GMV 重要：它决定下一场开播时你手里有多少免费流量。

### 5. 商品点击率

```
商品点击率 = 商品点击次数 / 进房人次
```

含义：听完讲解，有多少人愿意点开看一眼。
**这一层是话术质量的直接体现**——讲得让人想点，点击率就上；讲得空，点击率就掉。
注意：讲解与点开必须绑定（"3 号链接"），否则点击率会被"用户不知道点哪里"拉低。

### 6. 下单转化率与支付转化率

```
下单转化率 = 下单数 / 商品点击次数
支付转化率 = 已付款单量 / 商品点击次数
弃单率     = 1 - 支付转化率 / 下单转化率
```

**为什么分母用点击而不是进房**：进房到点击这一段已经在第 5 层被衡量过，用点击作分母才能把"讲得让人想买"和"买了付不付"分开。
**弃单率高**通常不是话术问题，是支付路径问题（规格要选三项、优惠券要手动领、运费异常）。

### 7. 客单价

```
客单价 AOV = 成交额 / 付款单量
```

注意：AOV 不等于"件单价 × 件数"。套装的 AOV 高但件单价可能低，分析时要拆开。

### 8. GPM（千次观看成交额）

```
GPM = 成交额 / 进房人次 × 1000
```

含义：每一千个进房的人，能产生多少成交额。**跨场次比较必须用 GPM，不能用 GMV**——GMV 高可能只是流量多。
参考线：冷启动 500、成长期 700、成熟期 900（元/千进房）。

### 9. UV 价值

```
UV 价值 = 成交额 / 进房人次
```

与 GPM 是同一件事的不同单位（GPM ÷ 1000）。写报告时二选一，不要并列出现，容易让人以为是两个指标。
**UV 价值是判断"这个流量值不值得买"的直接依据**：UV 价值 0.24 元，意味着每一个进房的人平均只值 0.24 元，广告买贵了就是亏。

### 10. 退款率与净成交额

```
退款率   = 退款金额 / 成交额
净成交额 = 成交额 - 退款金额
```

退款率要**按发货后 7-15 天**再看一次，播完当天的退款率只是第一波（冲动退单）。
如果退款率明显高于类目常态，先查话术的预期管理，再查尺码/色差/物流，最后才怀疑产品。

### 11. 投产比 ROI 与 CPA

```
ROI = 成交额 / 广告花费
CPA = 广告花费 / 付款单量
```

**ROI 的分子是成交额（未扣退款）**，所以它天然比真实回报好看。要看真实回报，用净成交额重算：
```
净 ROI = (成交额 - 退款金额) / 广告花费
```

### 12. 流量结构

```
付费进房占比 = 广告进房人次 / 总进房人次
自然进房占比 = 1 - 付费进房占比
```

**这是复盘的第一张表，不是最后一张。** 同样 5 万 GMV：
- 自然进房 80%、广告花 800 元 → 账号在长，可以加投放大规模
- 自然进房 20%、广告花 12000 元 → 一旦停投就归零，先修内容留人

## 三、单件经济模型与保本 ROI

### 推导

设售价 P、货品成本 C（含包装）、履约成本 F（按件，含人工与快递，退货也发生过一次）、退货率 r、平台佣金率 m、支付通道费率 f、退货物流损失 L（按退货件）。

每卖出 1 件（含 r 概率退货的期望）：

| 项目 | 金额 | 说明 |
|---|---|---|
| 实收货款 | P(1−r) | 退货部分金额退回买家 |
| 减 货品成本 | C(1−r) | 退货可回库二次销售，不计成本 |
| 减 履约成本 | F | 按件全额发生，退货也已发货 |
| 减 平台佣金 | P·m(1−r) | 按实收计 |
| 减 支付通道费 | P·f(1−r) | 按实收计 |
| 减 退货物流 | L·r | 退回来的运费与损耗 |

```
单件净毛利 = P(1−r) − C(1−r) − F − P·m(1−r) − P·f(1−r) − L·r
净毛利率   = 单件净毛利 / P
```

### 保本 ROI

保本意味着"广告花掉的钱刚好等于这批货赚的净毛利"：

```
广告花费 = 单件净毛利 × 件数
成交额   = P × 件数
保本 ROI = 成交额 / 广告花费 = P / 单件净毛利 = 1 / 净毛利率
```

**保本 CPA** 就是单件净毛利本身：单均广告花费超过它，这一单就是亏的。

### 单场保本 GMV

有单场固定成本 K（场地、人力、设备折旧）时：

```
保本销量  = K / 单件净毛利
保本 GMV  = 保本销量 × P
```

### 算例（可手算核对）

P=129、C=41、F=7、r=0.22、m=0.05、f=0.006、L=9、K=1200

```
实收         129 × 0.78            = 100.62
货品成本      41 × 0.78            =  31.98
履约          7                    =   7.00
佣金         129 × 0.05 × 0.78     =   5.03
支付费       129 × 0.006 × 0.78    =   0.60
退货物流       9 × 0.22            =   1.98
单件净毛利                          =  54.03
净毛利率      54.03 / 129           = 41.9%
保本 ROI      129 / 54.03           =  2.39
单场保本销量  1200 / 54.03          =  22 件
单场保本 GMV  22 × 129             ≈ 2865 元
```

结论：这场直播如果投流，投产比低于 2.39 就是在给平台打工；单场 GMV 低于 2865 元，连场地人力都没赚回来。

**退货率是这个模型里最凶的变量。** 同上例，退货率从 22% 涨到 40%：单件净毛利从 54.03 元掉到 37.87 元，保本 ROI 从 2.39 涨到 3.41——**退货率涨 18 个点，对投放的要求提高 43%**。所以退货率异常时，先修产品与预期管理，不要用加投来对冲。

## 四、目标反推

```
需要付款单量 = 目标 GMV / 客单价
需要商品点击 = 需要付款单量 / 支付转化率
需要进房人次 = 需要商品点击 / 商品点击率
需要曝光     = 需要进房人次 / 进房率
广告预算     = 目标 GMV / 目标 ROI
需要时长     = 需要进房人次 / 每小时进房人次
```

### 反推结果的现实性判断

| 情况 | 判断 |
|---|---|
| 所需进房人次 > 50 万 | 单场常规直播很难达到，拆场或提客单价 |
| 所需时长 > 8 小时 | 主播状态会崩，必须拆场 |
| 目标 ROI < 2 | 广告费占成交额一半以上，先核毛利能不能覆盖 |
| 所需点击 > 进房人次 × 20% | 点击率要求高于类目常见上限，目标定高了 |

反推的价值不是算出精确数字，而是**在开播前告诉你这个目标合不合理**。很多时候问题不在执行，在目标本身。

## 五、类目修正（经验方向，不是精确系数）

| 类目 | 停留 | 点击率 | 支付转化率 | GPM | 关键变量 |
|---|---|---|---|---|---|
| 美妆护肤 | 偏高（讲解长） | 中 | 中 | 高 | 退货率与功效合规 |
| 食品生鲜 | 偏低（决策快） | 高 | 高 | 中 | 履约时效、破损率 |
| 服饰鞋包 | 高（试穿演示） | 中 | 低 | 中 | 尺码退货率，常 30%+ |
| 家居日用 | 中 | 中 | 中 | 中低 | 客单价跨度大 |
| 3C 数码 | 高（参数讲解） | 高 | 低 | 高 | 比价、售后 |
| 母婴 | 中 | 中 | 中 | 中 | 合规与信任成本 |
| 本地生活 | 低 | 高 | 高 | 低 | 到店核销率才是真指标 |

用法：先按阶段取参考线，再按类目方向做定性调整（例如服饰类支付转化率普遍偏低，就不要拿 3.5% 去要求它），**不要在报告里编造精确到小数点的类目基准**。
