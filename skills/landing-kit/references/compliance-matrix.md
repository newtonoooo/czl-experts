# 合规矩阵（compliance-matrix）

> 机读版本在 `compliance-rules.json`（`compliance_gate.py` 读取）。本文件是人工可读版，用于理解"为什么需要这一项"和"找谁办"。
> **定位：作业清单，不是法律意见。** 最终以目标国官方机构与持牌服务商书面口径为准。

---

## 一、四类要求，别混在一起

| 类别 | 例子 | 谁管 | 缺了会怎样 |
|---|---|---|---|
| 产品准入 | CE、FCC、PSE、CPC、UKCA、KC、RCM | 目标国监管机构 | 海关扣货、平台下架、罚款 |
| 经营主体 | 税号（VAT/GST/JCT）、进口商（IOR）、责任人（EU RP/UK RP） | 税务机关、海关 | 无法清关、平台停售、资金冻结 |
| 环保延伸 | 包装 EPR、WEEE、电池法规 | 各国 EPR 机构 | 罚款、平台强制下架（德国最严） |
| 标识与语言 | 本地语言标签、警示语、原产地、条形码 | 消费者保护机构 | 下架、召回、索赔 |

**平台侧要求是第五类，与上面四类不是一回事。** 亚马逊的合规文件上传、TikTok Shop 的类目资质审核，都建立在国别法规之上，两边都要过。

## 二、按市场看（高频市场）

### 欧盟（含 DE / FR / IT / ES / NL / PL / SE）

| 要求 | 触发条件 | 找谁 | 常见周期 |
|---|---|---|---|
| CE 标志 | 玩具、电子、PPE、机械、医疗、部分建材 | 实验室 / 公告机构 | 4–10 周 |
| 欧盟责任人（GPSR） | 几乎所有消费品（自 2024-12-13 适用） | 欧代服务商 | 1–3 周 |
| 包装 EPR 注册 | 有包装就要，按销售国逐一注册 | EPR 服务商 | 2–8 周 |
| WEEE 注册 | 电子电气产品 | 各国 WEEE 机构 | 2–6 周 |
| 电池法规 | 含电池产品 | 电池合规服务商 | 2–8 周 |
| VAT / IOSS | 全部销售 | 欧洲税务代理 | 2–6 周 |
| 本地语言说明书 | 全部消费品 | 翻译 + 母语审校 | 1–3 周 |

**德国特别注意**：VerpackG（LUCID）注册是硬门槛，未注册直接禁售；包装数量申报与实际不符会被罚。
**法国特别注意**：Triman 标识 + 三国别 EPR（包装 / 电子 / 纺织）分别注册。

### 英国

| 要求 | 触发条件 | 找谁 | 常见周期 |
|---|---|---|---|
| UK VAT | 海外卖家强制 | 英国税务代理 | 2–6 周 |
| 英国责任人 | 受产品安全法规约束的品类 | 英代服务商 | 1–2 周 |
| UKCA / CE | 视品类与过渡安排 | 实验室 | 视品类 |
| 包装 EPR 申报（pEPR） | 有包装 | EPR 服务商 | 2–4 周 |

> UKCA 与 CE 的互认安排会变，**不要凭记忆判断**，查 gov.uk 当期公告。

### 美国

| 要求 | 触发条件 | 找谁 | 常见周期 |
|---|---|---|---|
| FCC | 含射频或数字电路 | 认可实验室 | 3–8 周 |
| FDA | 食品接触、化妆品、医疗器械 | 美国代理人 + 实验室 | 2 周–12 月 |
| CPC | 12 岁以下儿童产品 | CPSC 认可实验室 | 4–10 周 |
| 州销售税 | 达到经济关联门槛 | 美国 CPA | 2–6 周 |
| 加州 65 | 含铅、邻苯等化学物质 | 实验室 + 法务 | 2–4 周 |
| 美国商标 | 品牌备案前置 | 商标代理 | 受理 1–2 周 / 注册 8–14 月 |

**美国没有"统一市场准入"**，联邦（FCC/FDA/CPSC）与州（销售税/Prop 65）是两套体系。

### 日本

| 要求 | 触发条件 | 找谁 | 常见周期 |
|---|---|---|---|
| PSE | 电气用品 | 日本认证机构 | 4–10 周 |
| 技适（Giteki） | 无线产品 | 日本认证机构 | 4–8 周 |
| 进口商（IOR）+ JCT | 全部进口销售 | 日本进口代理 / 税理士 | 3–8 周 |
| 日语标签 | 全部消费品 | 自行设计 + 日本审校 | 2–4 周 |
| 食品卫生法 | 食品接触材料 | 日本检测机构 | 3–6 周 |

**日本特别注意**：没有 IOR 就无法完成合规标称；药机法用词（治る・効く）会把化妆品打成医药部外品。

### 东南亚 / 中东 / 拉美

| 市场 | 核心要求 | 说明 |
|---|---|---|
| 新加坡 / 马来 | GST / SST 登记，本地进口商，马来语标签（化妆品与食品接触最严） | 马来另有 SIRIM 认证 |
| 泰国 | VAT，TISI 认证（电子与部分日用品），泰语标签 | |
| 越南 / 印尼 / 菲律宾 | VAT，本地进口商，本地语言标签；印尼 SNI、菲律宾 FDA | 印尼流程最慢 |
| 沙特 / 阿联酋 | SABER / ESMA 注册，阿拉伯语标签 | 沙特需逐批出证 |

## 三、五个最常见的误解

1. **"有 CE 报告就能进欧盟"** —— 不够。还要欧盟责任人、DoC、技术文档、本地语言说明书、包装 EPR。
2. **"亚马逊没查我，说明合规"** —— 平台抽查是概率事件，事后追责不看概率。
3. **"一份 CE 覆盖所有型号"** —— 检测报告列明型号与标准版本，改结构、改材料就可能要重测。
4. **"借用朋友的证书"** —— 证书持有人不是你，属伪造文件，刑事责任。
5. **"VAT 晚点注册没事"** —— 平台会核验，无税号直接停售并冻结资金。

## 四、放行判定的三条纪律

- **阻断项为 0 才给 GO。** 不给"先发一批试试"的绿灯。
- **CONDITIONAL 必须带日期。** 只写"正在办"不算，要写"谁办、几号前完成、到期未完成即停售"。
- **周期不给承诺。** 一律写"常见区间，不含排队与补测"。
