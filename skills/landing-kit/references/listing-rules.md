# 页面结构与本地化（listing-rules）

> 机读档案在 `listing-profiles.json`（`listing_lint.py` 读取）。本文件讲**怎么写**，档案管**怎么查**。

---

## 一、标题

### 结构公式

```
品牌 + 核心品类词 + 关键属性（材质/功能）+ 规格（容量/尺寸/数量）+ 适用人群或场景
```

例：`AquaCup Collapsible Water Bottle 750ml BPA-Free Silicone for Travel and Gym`

### 五条硬规矩

1. **品牌在前五个词内。** 既是识别，也是品牌备案的常规要求。
2. **一个核心词，不塞同义词。** `water bottle` 与 `drinking flask` 二选一，另一个放后台。
3. **不出现绝对化表达。** best / No.1 / 100% / 最 / 日本一，一律删。这不是风格问题，是平台会拦。
4. **不出现价格、运费、促销词。** 价格一变标题就失效。
5. **不出现联系方式。** 邮箱、电话、网址、社交账号、二维码，都属站外引流。

### 字数怎么控

| 平台 | 默认上限 | 实操建议 |
|---|---|---|
| 亚马逊 US / EU | 200 字符 | 移动端只显示前 70–80 字符，核心信息放最前 |
| 亚马逊 JP | 100 字符（部分类目 200） | 更短，删修饰语 |
| TikTok Shop | 255 字符 | 前 40 字符决定是否点开 |
| Shopee | 120 字符 | 超长在移动端截断 |
| Temu | 120 字符 | 冗余词会被核价压低 |
| 独立站 | 70 字符 | 搜索结果展示上限 |

## 二、五点（Bullet Points）

顺序不是随便排的，按买家决策顺序：

1. **最痛的点先解决**（如"折叠后 5cm，能塞进侧袋"）
2. **结构与材料证据**（如"食品级硅胶，通过 FDA 21 CFR 177.2600 测试"）
3. **使用场景**（如"健身房、通勤、登山，单手开合"）
4. **规格与兼容**（容量、重量、适配杯架、洗碗机）
5. **售后与保障**（保修期、退换方式，不写"联系我"）

每条只讲一件事，首句给结论，其后给依据。**每条都要能指到一条证据**，指不到就删。

## 三、描述与 A+

- 前 300 字符必须能独立说清"这东西解决什么问题"，因为折叠后只剩这一段。
- 可以讲故事，但故事里出现的数据必须真实（尺寸、时长、测试结果）。
- A+ 的模块顺序：使用场景大图 → 结构拆解 → 对比表 → 品牌故事。对比表只与自家型号比，不与竞品比。
- 独立站可写长文案，但首屏必须自洽：标题、卖点、价格、CTA 都在第一屏。

## 四、图形

| 图位 | 要传达什么 | 常见错误 |
|---|---|---|
| 主图 | 白底、产品占画面 85%、无文字 | 加促销角标、加多产品、加背景 |
| 图 2 | 尺寸标注（双单位） | 只标 cm 不标 inch |
| 图 3 | 材质/结构特写 | 用渲染图代替实物，收货后落差大 |
| 图 4 | 使用场景（真实人种与场景） | 用国内模特拍欧美场景，违和 |
| 图 5 | 包装内含物平铺 | 数量与标题不一致 |
| 图 6 | 对比表 | 与竞品直接对比（违规） |

图片里的文字不得超过画面 20%，不得出现水印、二维码、其他平台 logo。

## 五、本地化，不是翻译

| 维度 | 中国习惯 | 目标市场 |
|---|---|---|
| 计量 | cm / kg / ml | 美国 inch / lb / fl oz；欧洲日本 cm / kg |
| 尺码 | S/M/L 一套打天下 | 美国、欧洲、日本、东南亚尺码体系不同，必须换算表 |
| 颜色词 | "藕粉""雾霾蓝" | dusty pink / slate blue，且颜色寓意按市场调整 |
| 数字表达 | "买二送一" | 美国用 bundle / 2-pack，欧洲注意单价标示法规 |
| 场景 | 家宴、送礼 | 美国户外与健身，日本收纳与细节，德国功能与耐用 |
| 幽默与夸张 | 可接受 | 德国、日本偏保守，夸张表述易被视为不实宣传 |

### 三处必须母语审校

1. **标题**：语序与搭配错一处，整条看起来就像机翻。
2. **卖点首句**：五点的第一句决定要不要往下读。
3. **场景描述**：文化错位最容易出在这，比如把"送礼"场景写成"给领导送礼"。

机翻直接上架是最常见的转化率杀手，且平台对"翻译质量低"有降权机制。

## 六、关键词布局

| 位置 | 放什么 | 权重 |
|---|---|---|
| 标题 | 1 个核心词 + 1–2 个属性词 | 最高 |
| 五点 | 场景词、人群词、同义词 | 高 |
| 描述 | 长尾、问题式表达 | 中 |
| 后台 Search Terms | 未覆盖的同义词、拼写变体、竞品未注册的词 | 中（不重复标题已用的词） |

后台词不重复堆，平台不做加权叠加；同一词根在标题超 2 次会被判堆砌。

## 七、交付前的最后四问

1. 标题里的每个词，买家真的会用这个词搜吗？
2. 五个卖点，每个都能指到一条证据吗？
3. 尺寸、容量、数量，与包装实物一致吗？
4. 三处母语审校点，标出来了吗？
