# 工序 ③ 成本

## 名称

成本（Landed Cost & Breakeven）——算到"每成交一单"，出三条保本线。

## 任务职责

把"出厂价 × 汇率 = 成本"这种算法换掉。产出《成本定价》与三条保本线：保本售价、保本 ACOS、保本日销。
这一步算错，后面所有环节都在为一个亏钱的生意做优化。

## 输入参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 售价 | 是 | 目标售价，含币种 |
| 出厂价 | 是 | 中国侧成本，可人民币给 |
| 包装 / 头程单件 | 是 | 头程按公斤或按方分摊到单件 |
| 关税税率 | 是 | 按 HS 编码查，注明来源 |
| 平台佣金率 | 是 | 按类目查，注明取数日期 |
| 配送费（FBA/SLS） | 是 | 按尺寸重量档位查 |
| 退货率 | 是 | 没有历史数据就用类目经验值并标注 |
| 广告占比 | 是 | 冷启动期一般 10–20%，成熟期 5–10% |
| 收款手续费 / 其他变动 | 否 | 缺则 0，但要在交付里写明"未计" |
| 仓储费与月数 | 否 | 缺则按 2 个月估，标注为估 |
| 固定费用（月） | 否 | 店租、软件、人工分摊；用于算保本日销 |
| 目标净利率 | 否 | 默认 15% |
| 汇率与取数日 | 条件必需 | 中国侧成本用人民币时必需 |

## 执行步骤

```
1  按 references/cost-lines.md 的科目顺序填表，逐项标来源与日期
2  跑脚本：
     python scripts/landed_cost.py --input case.json
   （中国侧成本用人民币时，case 里写 "cost_in_cny": true 与 "fx"）
3  读三张表：成本瀑布、三条保本线、价格阶梯
4  做敏感性：采购价 ±10% × 退货率 ±5 个点，看净利率是否翻负
5  按判断条件给结论，写《成本定价》，附脚本原始输出
6  若净利率 <10%，给出"什么条件下才成立"：提价到多少、落地成本压到多少、改什么规格
```

## 判断条件

| 门槛 | 结论 |
|---|---|
| 净利率 ≥ 15% | 可做，进入工序 ④ |
| 10% ≤ 净利率 < 15% | 偏薄：可做，但必须写明"广告试错空间小"，且首批量压到 30–45 天 |
| 净利率 < 10% | 不给"可以做"的结论，只给成立条件 |
| 保本 ACOS < 当前广告占比 | 立刻警示：当前投放强度下必然亏损 |
| 主流价带 < 落地成本 × 1.3 | 结构性问题，回工序 ② 换切口 |

**三条保本线怎么读**

- **保本售价**：定价的下限。低于它卖一件亏一件。
- **保本 ACOS**：广告投放的天花板。ACOS 高于它，广告就是在亏钱买排名。
- **保本日销**：覆盖固定费用的最低销量。低于它，固定费用吃光利润。

## 异常处理

| 情况 | 处理 |
|---|---|
| 缺 3 个以上关键费率 | 不做结论，只出"费率待补清单"与各项去哪查 |
| 用户给的是"含税出厂价"但目标国有 VAT | 说明 VAT 是流转税，通常可抵扣，不重复计入成本；不可抵扣时才计入 |
| 退货率无历史数据 | 用类目经验值（服饰 15–25%、家居 8–12%、3C 5–10%），标注"经验值，需用实际数据替换" |
| 头程按整柜报价 | 先折算到单件：整柜运费 ÷ 装箱数，再加报关与内陆段 |
| 多 SKU 共用头程 | 按体积或重量占比分摊，不许平均分 |

## 依赖与上下游

- **前置**：工序 ①（品类、市场、币种）、工序 ②（结论为"进"）
- **后置**：工序 ④（净利率过线才值得付合规成本）、工序 ⑥（保本 ACOS 直接变成广告止损线）
- **回退**：净利率不过线时回工序 ② 换切口，或在本工序做"降本三选一"

> 铁律：交付里的每个金额都要能追到脚本输出；不许出现"大概""差不多""按 15% 估"却没有标注的数字。
