# 论点台账

这是整个产品的记忆体。没有它，你每次都在从零开始，而且永远无法知道自己错在哪——包括对自己。

## 职责

**做**：建立与更新论点台账、支柱记分卡、反面证据栏、跟踪简报。
**不做**：不改估值（`czl-model-value`），不改仓位（`czl-position-plan`）。

## 输入参数

**台账模式**

| 参数 | 必填 | 说明 | 缺失处理 |
|---|---|---|---|
| 标的与方向 | 是 | 多 / 空 / 观察 | 问 |
| 论点陈述 | 是 | 一两句，必须可检验 | 无则先建，不得凭记忆补 |
| 支柱（3–5 条） | 是 | 每条含"预期 + 指标 + 阈值" | 少于 3 条说明论点太单薄，提示 |
| 目标价区间 | 是 | 判断是否兑现的基准 | 缺则引用上游结论 |
| 推翻条件 | 是 | 与目标价同等重要 | 缺则本台账无效 |
| 新增数据点 | 更新时必需 | 日期 + 内容 | 用户只说"更新一下" → 先问清变了什么 |

**简报模式**

| 参数 | 必填 | 说明 |
|---|---|---|
| 覆盖范围 | 是 | 哪几只 / 哪个板块 |
| 撰写时点 | 是 | 盘前还是盘中，几点写的 |
| 隔夜关键事件 | 否 | 有则优先处理 |

## 依赖与关系

- **上游**：任何模块的结论都可以入库
- **下游**：`czl-decision-memo`（触发决策调整）、`czl-position-plan`（调整仓位）
- **横向**：结论标准见 `czl-verdict-standard.md`

## 执行步骤

### 台账模式 · 建档

每条支柱必须写成可检验的形式：

| 要素 | 要求 | 不合格示例 | 合格示例 |
|---|---|---|---|
| 预期 | 一个具体结果 | 毛利率会改善 | 毛利率回到 35% 以上 |
| 指标 | 可观测的数据项 | 经营变好 | 单季毛利率 |
| 阈值 | 判定成败的数 | 明显提升 | ≥ 35%，连续两季 |

三条要素缺一条，这条支柱作废重写。

### 台账模式 · 更新

每个新数据点记五行：

```
日期：
数据点：
影响哪根支柱（第几条）：
影响方向（强化 / 弱化 / 中性）：
动作（不动 / 加 / 减 / 退）+ 信心变化
```

**更新不是重写。** 载入已有台账，追加记录，保留历史。要改过去的判断，新增一条并注明"修正"，不许直接覆盖。

### 台账模式 · 记分卡

| # | 支柱 | 当初预期 | 当前状态 | 趋势 |
|---|---|---|---|---|
| 1 | | | 达成 / 部分 / 未达 / 无法验证 | 改善 / 稳定 / 恶化 |

**"无法验证"连续停留超过一个复盘周期，这根支柱就判为无效项**，要么换指标，要么承认论点少了一条腿。

### 台账模式 · 反面证据栏

独立一栏，与记分卡同等地位：

| 日期 | 反面证据 | 与哪条支柱冲突 | 是否已推翻 |
|---|---|---|---|

**每记录一条支持证据，强制去找一条可能的反面证据。** 只记好消息的台账没有用。

### 台账模式 · 整体状态判定

| 状态 | 判据 | 对应动作 |
|---|---|---|
| 成立 | 多数支柱达成，无反面证据推翻 | 持有 / 可加 |
| 部分受损 | 有一条关键支柱未达，但未被推翻 | 减仓或降信心 |
| 已被推翻 | 推翻条件已触发 | 清仓 |
| 无法判断 | 关键支柱长期无法验证 | 降为观察 |

### 简报模式 · 三段结构

```
头条：一句话（今天最要紧的那件，且它改变了某个动作）
隔夜与盘前：每条一句话 + 我们的看法
今日事件：按时间列，每项给"预期 vs 我们的看法"
```

一页为限。**隔夜无事就写"隔夜无重大变化，维持现有判断"**——这是合格简报，不要为填版面硬找内容。

## 判断条件

| 判据 | 处置 |
|---|---|
| 用户想改论点以适配现状 | 区分"论点变了"和"论点被推翻"，前者须留改动理由与日期 |
| 支柱之间互相矛盾（如份额升但降价） | 指出矛盾，不要两边都写"进展良好" |
| 数据点无法归因到某条支柱 | 单列"背景信息"，不硬塞 |
| 隔夜无重大事件 | 直接写无变化，这是有效产出 |
| 简报超过一页 | 删，不分段 |

## 输出格式

**台账摘要**：

```
标的 | 方向 | 论点一句话 | 整体状态 | 信心
支柱记分卡（表格）
最近三条变动
反面证据（有 / 无，是什么）
下一步验证点（事件 + 时间）
动作建议
```

**简报**：

```
[日期] 简报 — [覆盖范围]
撰写时间 HH:MM（盘前 / 盘中）
头条
隔夜与盘前
今日事件
（可选）想法与风险
```

## 异常处理

- **没有原始论点记录**：说明"缺原始表述，无法逐条对照"，改为重建基线并注明重建日期，此后以此为准。
- **用户描述与台账不符**：以台账为准并指出差异，让用户确认哪一版是对的。
- **长期未更新的台账**：复活时先声明"已 X 个月未更新，以下判断可能已过期"，再给当前状态。
- **摘要写不出来（信息太散）**：说明该标的目前不构成可跟踪的论点，建议降为观察名单。

## 质量红线

- 不记好消息的台账视为无效
- 支柱不许停在"待观察"，超过一个周期即判无效
- 简报不许写成新闻摘要，每条要有"所以呢"
- 不许悄悄改历史记录
